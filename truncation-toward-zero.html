Truncation toward zero (trunc(x)={⌊x⌋⌈x⌉​x≥0x<0​)

Truncation toward zero removes the fractional magnitude of a real number, giving the integer obtained by applying the floor function to its absolute value and restoring the original sign; a magnitude below one gives zero. More precisely,
trunc(x)={⌊x⌋⌈x⌉​x≥0,x<0.​
(10)
The result is zero for −1<x<1. For example, trunc(2.7)=2 and trunc(−2.7)=−2, whereas ⌊−2.7⌋=−3. Python's math.trunc uses this towards-zero convention, so replacing it by math.floor changes calculations with negative noninteger inputs. [ref].
For every real number x,
∣x−trunc(x)∣<1,trunc(−x)=−trunc(x).
(11)
The discarded difference x−trunc(x) has the sign of x when x is noninteger. In contrast, the fractional part x−⌊x⌋ is always in [0,1). At x=−2.7, these two differences are −0.7 and 0.3. Thus specifying a signed fractional remainder requires specifying which integer-valued operation is used.
Unlike the floor function and ceiling function, truncation toward zero need not commute with adding an integer. At x=−0.7 and j=1, trunc(x+j)=trunc(0.3)=0, whereas trunc(x)+j=1. This matters if negative coordinates are assigned to equal-width bins by converting a quotient to an integer: x=−0.7 belongs to the bin [−1,0) under the floor function, but truncation gives zero. The appropriate operation follows from the declared bin intervals.
Truncation toward zero is a nondecreasing function with a discontinuity of a function at each nonzero integer. It has no discontinuity of a function at zero, because it is identically zero on (−1,1). Its agreement with the floor function on the positive side and the ceiling function on the negative side explains the different closed endpoints in the diagram.
