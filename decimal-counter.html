Decimal counter (A∈{0,…,9}k)

 Home Computer science Data structure
OurBigBook.com Words: 68
A decimal counter stores a nonnegative integer using an array of base-ten digits, with the least significant digit first. Increment resets trailing nines and increases the next digit, or wraps modulo 10k if all k digits are nines. Starting at zero, the exact number of digit changes in n increments is ∑i=0k−1​⌊n/10i⌋≤10n/9. This is an aggregate analysis proving a constant amortized cost per increment under unit-cost digit updates. An arbitrary initial value contributes an additional O(k) in Big O notation.
