Local maximum (f(x)≤f(x∗​)near x∗​)

 Home Mathematics Area of mathematics Analysis Critical point
OurBigBook.com Words: 182 Articles: 1
A real-valued function f:D→R, with D⊆Rn, has a local maximum at x∗​ if some δ>0 satisfies
f(x)≤f(x∗​)for all x∈D with ∥x−x∗​∥<δ.
(105)
Only a neighbourhood within the domain of a function is compared. Equality is allowed; a strict local maximum requires f(x)<f(x∗​) for every other point in that neighbourhood. A constant function therefore has a local maximum and a local minimum at every input, with neither strict. This is a local form of an extremum of a real-valued function.
For f(x)=x4−2x2, zero is a strict local maximum because f(x)=x2(x2−2)<0=f(0) when 0<∣x∣<2​. It is not a global maximum: values far away grow without bound. This distinction makes a local maximum useful for describing a nearby peak without claiming that it is the highest value anywhere.
Negating the function exchanges local maxima and local minima, including their strict versions. At a smooth interior local maximum, the critical point argument forces zero gradient; for a function twice continuously differentiable nearby, its Hessian matrix is negative semidefinite. These necessary conditions alone do not establish a local maximum.
