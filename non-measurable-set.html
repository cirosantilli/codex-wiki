Non-measurable set (A∈/Σ)

 Home Mathematics Area of mathematics Analysis Real analysis Measure theory
OurBigBook.com Words: 124
A subset A of a measurable space (X,Σ) is non-measurable when A∈/Σ. On the real line, unless another sigma-algebra is specified, this commonly means that A is not a Lebesgue measurable set. By completeness of Lebesgue measure, such a set cannot be contained in a Lebesgue null set.
For an example, use the axiom of choice to select one representative from each equivalence class of [0,1] under x∼y if x−y∈Q, and call the resulting set V. The translates V+q, for q∈Q∩[−1,1], are pairwise disjoint, their union contains [0,1], and their union is contained in [−1,2]. If V were a Lebesgue measurable set, translation invariance and countable additivity would make that union have measure zero when m(V)=0 and infinite measure when m(V)>0. Both conclusions contradict these inclusions. Thus V is non-measurable.
