Log-log plot

 ... Analysis Real analysis Calculus Exponential function Logarithm Logarithmic scale
OurBigBook.com Words: 105
A log-log plot uses logarithmic scales on both axes. For a positive power law y=Cxp with x,C>0, positive references x0​,y0​ give
logb​(y/y0​)=logb​(Cx0p​/y0​)+plogb​(x/x0​).
(32)
Its transformed slope is the exponent p when both axes use the same logarithm base and the slope is measured in logarithmic coordinate units. For example, y=2x2 takes the values 2,8,32 at x=1,2,4. Every doubling of x quadruples y, giving slope two on a log-log plot.
This differs from a semi-log plot: a power law has constant proportional response to a proportional change of input, whereas exponential growth has constant proportional response to an additive change of input. Both can appear straight with appropriate axes, so one must read the scale labels before interpreting a slope.
