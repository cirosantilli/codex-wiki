Definable set (D={a:M⊨φ(a,b)})

 ... Mathematics Area of mathematics Foundations of mathematics Mathematical logic First-order logic First-order structure
OurBigBook.com Words: 308 Articles: 3
A definable set in a first-order structure M is the set of tuples satisfying one first-order formula, possibly with a specified finite tuple of parameters b from the structure. A set definable over B⊆M uses parameters from B. Parameter-free definability uses no extra named elements. The distinction matters: any singleton becomes definable if its own element is allowed as a parameter, while many singletons are not definable without parameters. Finite Boolean combinations of definable sets are definable, using logical conjunction, logical disjunction and logical negation.
