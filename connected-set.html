Connected set

 Home Mathematics Area of mathematics Geometry and topology Connected space
OurBigBook.com Words: 206 Articles: 1
A subset of a topological space is a connected set when its subspace topology is connected. Thus connectedness is tested using relatively open sets, not only subsets open in the ambient space.
