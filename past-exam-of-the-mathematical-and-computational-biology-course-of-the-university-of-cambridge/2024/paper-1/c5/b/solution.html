Count the number of descendant leaves on each branch during each phylogenetic epoch. From the tips backward, both topologies have branch-size lists (1,1,1,1) during T4​, then (2,1,1) during T3​. During T2​, type A has (3,1) and type B has (2,2).
Let Lj​ be the total length of branches carrying j descendant leaves. Adding the relevant phylogenetic epoch durations gives
AB​E[L1​]4E4​+2E3​+E2​4E4​+2E3​​E[L2​]E3​E3​+2E2​​E[L3​]E2​0​​​.
(41)
For example, type A has one external branch and one three-descendant branch throughout T2​, while type B has two two-descendant branches. In either case the total expected branch length is 4E4​+3E3​+2E2​, a useful accounting check. The stem above the common root is excluded because mutations there would be shared by all four samples.
