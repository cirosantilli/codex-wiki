Countability of point atoms of a finite measure (#{x:μ({x})≥1/m}≤mμ(Ω))

 ... Analysis Real analysis Measure theory Measure Atom (measure theory) Point atom of a measure
OurBigBook.com Words: 107
For a finite measure on a measurable space whose singletons are measurable sets, the set of point atoms of a measure is at most countable. For each positive integer m, let Dm​ consist of the points with singleton measure at least 1/m. If Dm​ contained more than mμ(Ω) distinct points, finite additivity on those disjoint singletons would exceed the total measure. Thus each Dm​ is finite.
Every strictly positive real number exceeds or equals 1/m for some m, so the point atoms of a measure form the countable union ⋃m≥1​Dm​. This proves that the set is countable. It also shows that a cumulative distribution function has only countably many jumps. The result does not say the measure is concentrated on those points: a non-atomic measure may assign them total measure zero.
