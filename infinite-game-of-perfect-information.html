Infinite game of perfect information

 Home Mathematics Area of mathematics Foundations of mathematics Set theory Descriptive set theory
OurBigBook.com Words: 254 Articles: 8
For A⊆Mω, the game G(A) has two players alternately choose elements of the move set M, producing x∈Mω. Player I wins exactly when x∈A. Both players see the whole finite position before making each move.
