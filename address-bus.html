Address bus

 Home Computer science Computer bus Shared computer bus
OurBigBook.com Words: 50
The computer bus path identifying the destination or location of a bus transaction. An initiator supplies an address; decoding selects the intended target. Address width describes the available address encodings, whereas data bus width describes how many bits can be carried at once.[ref]
