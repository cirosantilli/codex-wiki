Kernel dimensions of powers of a nilpotent map (di​=dimkerTi)

 ... Mathematics Area of mathematics Algebra Linear algebra Operator theory Nilpotent linear map
OurBigBook.com Words: 115
For a nilpotent linear map with minimal polynomial xm, set Ki​=kerTi and di​=dimKi​, with d0​=0. Then
0=d0​<d1​<⋯<dm​=dimV,di+1​−di​≤di​−di−1​​.
(49)
For strictness, choose w with Tm−1w=0. The vector Tm−1−iw belongs to Ki+1​∖Ki​ for 0≤i<m. For the second inequality, the rank-nullity theorem gives
dimTi(Ki+1​)=di+1​−di​,dimTi−1(Ki​)=di​−di−1​.
(50)
The first image is contained in the second because T(Ki+1​)⊆Ki​.
If the Nilpotent Jordan block sizes are s1​,…,sr​, then
di​=∑j=1r​min(i,sj​),di​−di−1​=#{j:sj​≥i}.
(51)
Thus successive increments count the Jordan blocks reaching a given size, and (di​−di−1​)−(di+1​−di​) counts blocks of size exactly i, with dm+1​=dm​. The nullities determine the entire Jordan normal form. Conversely any positive nonincreasing integer increments summing to dimV are realized by taking the corresponding numbers of each Nilpotent Jordan block.
