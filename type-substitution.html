Type substitution (S)

 Home Computer science Programming language Type system Type variable
OurBigBook.com Words: 31
A type substitution replaces type variables by type expressions consistently. For example, S={α↦int} gives S(α→α)=int→int. Applying a type substitution to a type scheme must respect its bound type variables; separate instantiation first replaces those bound placeholders by fresh ones.
