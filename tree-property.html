Tree property (TP(κ))

 ... Foundations of mathematics Set theory Set Partially ordered set Set-theoretic tree Kappa-tree
OurBigBook.com Words: 88
For an infinite cardinal κ, the tree property says that every tree of height κ with nonempty levels of cardinality less than κ has a cofinal branch. In the all-trees-of-size-κ convention it also forces regularity: disjoint chains of lengths cofinal in a singular κ form a counterexample. It does not, by itself, imply strong inaccessibility. A strong limit cardinal with the tree property satisfies the self-partition relation by applying it to the end-homogeneous coloring tree. At a strongly inaccessible cardinal this is the usual weak-compactness characterization.
