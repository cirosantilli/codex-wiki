Multidimensional scaling

Words: 190 Articles: 2
Unsupervised learning OurBigBook.com
Construct low-dimensional coordinates representing a dissimilarity matrix. Different methods preserve different features: classical multidimensional scaling approximates a centered Gram matrix, while other methods minimize discrepancies between fitted and supplied distances or preserve distance ordering. The method and dimension determine what geometric claims the resulting display supports.

Classical multidimensional scaling (G=−21​HD(2)H,Xk​=Uk​Λk1/2​)

Words: 149 Articles: 1
Multidimensional scaling OurBigBook.com
For a symmetric zero-diagonal dissimilarity matrix D, square each entry to obtain D(2) and put H=I−11T/n. Take the eigenvectors of G=−HD(2)H/2 corresponding to its largest positive eigenvalues. Multiplying them by square roots of these eigenvalues gives coordinates. If D contains Euclidean distances, G is a centered Gram matrix, so retaining all positive eigenvalues reconstructs those distances exactly. Retaining fewer approximates the Gram matrix, not generally the sum of squared errors in raw distances. Negative eigenvalues signal failure of an exact Euclidean representation. Coordinates are unchanged in meaning by orthogonal transformations.
Euclidean distance matrix criterion (D is Euclidean⟺−21​HD(2)H⪰0)
Words: 67
Classical multidimensional scaling OurBigBook.com
For symmetric nonnegative D with zero diagonal, a centered Euclidean realization implies Dij2​=Gii​+Gjj​−2Gij​ and hence the displayed double-centering identity. Conversely, if the double-centered matrix is positive semidefinite, factor it as XXT. Its reconstructed squared distances equal the original squared distances: their difference has zero double-centering, so is of the form 1aT+a1T; the zero diagonal forces a=0. The minimum exact embedding dimension is rankG.

Hebbian learning

Words: 207 Articles: 3
Unsupervised learning OurBigBook.com
Activity-dependent strengthening associated with coactivation of an input and its postsynaptic output. The idealized update Δwi​∝yxi​ requires normalization, competition or other constraints to prevent indefinite weight growth.

Quartic norm stabilization of Hebbian learning (τw˙=yx−αy2w∣w∣2)

Words: 55
Hebbian learning OurBigBook.com
With y=w⋅x, the squared weight norm s=∣w∣2 satisfies τs˙=2y2(1−αs2). It moves monotonically toward s∗​=α−1/2 without crossing it. Explicitly (s−s∗​)/(s+s∗​) equals its initial value times exp[−(4α​/τ)∫0t​y(u)2du]. Persistent excitation therefore drives ∣w∣ to α−1/4; without excitation it can remain stationary. This nonlinear normalization avoids the unbounded amplification of unmodified Hebbian learning.

Oja's rule (τw˙=yx−αy2w)

Words: 123 Articles: 1
Hebbian learning OurBigBook.com
For a linear output y=wTx, the second term limits the growth produced by the Hebbian term. On the averaged dynamics with C=E[xxT], τw˙=Cw−α(wTCw)w. For α>0, positive-eigenvalue equilibria have norm 1/α​ and align with eigenvectors of C. If inputs are centered, C is their covariance matrix.
Stability and normalization of averaged Oja learning (τu˙j​=(λj​−λi​)uj​,τu˙i​=−2λi​ui​)

At the equilibrium vi​/α​, linearization along orthonormal eigenvectors of C gives the displayed rates, with the first equation applying to j=i. A simple positive largest eigenvalue makes its two normalized eigenvectors locally asymptotically stable; smaller eigenvalues have an unstable direction. Repeated largest eigenvalues give a manifold of equilibria with neutral directions. Generic convergence also needs a nonzero initial component in the largest eigenspace. Cluster analysis

Words: 659 Articles: 14
Statistical learning OurBigBook.com
Cluster analysis groups observations using similarities or dissimilarities without supplied class labels. A distance choice specifies which features and scales matter. Agglomerative hierarchical clustering merges groups recursively, producing partitions at different resolutions rather than one intrinsically determined number of groups.

Cluster in cluster analysis

Words: 45
Cluster analysis OurBigBook.com
A cluster in cluster analysis is a nonempty group of observations treated as similar under the chosen representation and dissimilarity. A partition assigns each observation to exactly one cluster; agglomerative hierarchical clustering supplies a nested sequence of such partitions. An algorithmic cluster need not correspond to a distinct probabilistic population.

K-means clustering (minC1​,…,CK​​∑k=1K​∑i∈Ck​​∥xi​−mk​∥2)

Words: 76
Cluster analysis OurBigBook.com
For a prescribed number of groups, minimize within-cluster squared Euclidean distances. At fixed assignments, differentiating the objective gives the mean as the optimal centroid. At fixed centroids, assigning each point to a nearest centroid minimizes its contribution. Alternating these steps cannot increase the objective but can converge to a local optimum, so multiple starts are useful. Empty clusters and ties need an explicit handling rule. The method favors roughly spherical groups and depends on variable scaling.

Jaccard index (J(A,B)=∣A∩B∣/∣A∪B∣)

Words: 83 Articles: 1
Cluster analysis OurBigBook.com
The index measures similarity of finite sets by shared presence relative to total presence. For binary profiles it ignores joint absences, unlike the simple matching coefficient. When both sets are empty, define the similarity to be one. The complementary Jaccard distance measures dissimilarity.

Jaccard distance (dJ​(A,B)=1−J(A,B))

Words: 44
Jaccard index OurBigBook.com
The dissimilarity is the number of mismatched presences divided by the number of coordinates present in at least one profile. It differs from normalized Hamming distance because coordinates absent from both profiles do not enter its denominator. Define the distance of two empty sets to be zero.

Dissimilarity matrix (Drt​=d(xr​,xt​))

Words: 51
Cluster analysis OurBigBook.com
A dissimilarity matrix records pairwise separation of observations or profiles. Usually it is symmetric, nonnegative and zero on the diagonal. A metric space additionally requires the triangle inequality and separation of distinct profiles. Agglomerative hierarchical clustering can be applied to many dissimilarity matrices that are not Euclidean distance matrices; the claimed geometry must be checked separately.

Simple matching coefficient (S1​(x,y)=#{j:xj​=yj​}/p)

Words: 87 Articles: 1
Cluster analysis OurBigBook.com
For binary vectors, this similarity counts agreements on both presences and absences. Its complement is the normalized Hamming distance. Whether joint absences should count as similarity depends on the application; rare-presence data may call for a different coefficient.

Metric property of simple matching dissimilarity (1−S(x,y)=p−1∑j=1p​1{xj​=yj​}​)

Words: 51
Simple matching coefficient OurBigBook.com
The displayed distance is the normalized Hamming distance. Each coordinate mismatch between x,z implies a mismatch between x,y or y,z, so summing the indicator inequalities proves the triangle inequality. Nonnegativity, symmetry and separation follow immediately. It is a metric on profiles; on separately labelled individuals with identical profiles it is a pseudometric.

Agglomerative hierarchical clustering

Words: 280 Articles: 6
Cluster analysis OurBigBook.com
Start with singleton clusters and repeatedly merge the two clusters with the smallest chosen intercluster dissimilarity. Single-linkage clustering uses the smallest cross-pair distance; complete-linkage clustering uses the largest. Merge heights and sensitivity to ties help assess a proposed number of groups.

Ward minimum-variance clustering (Δ(A,B)=∣A∣+∣B∣∣A∣∣B∣​∥xˉA​−xˉB​∥2)

Words: 39
Agglomerative hierarchical clustering OurBigBook.com
Ward clustering merges the pair causing the smallest increase in within-cluster sum of squares. Expanding each cluster's squared deviations about the merged mean gives the displayed increase. Its Euclidean sum-of-squares interpretation must not be asserted for arbitrary non-Euclidean dissimilarities.

Average-linkage clustering (d(A,B)=∣A∣∣B∣1​∑x∈A,y∈B​d(x,y))

Words: 40
Agglomerative hierarchical clustering OurBigBook.com
Average linkage merges the pair with the smallest mean cross-pair dissimilarity. This differs from the minimum used by single-linkage clustering and the maximum used by complete-linkage clustering. The convention here weights individual cross-pairs equally; weighting already formed clusters equally is a different algorithm.

Agglomerative clustering of nonmetric dissimilarities

Words: 49
Agglomerative hierarchical clustering OurBigBook.com
The min and max cross-pair definitions of single-linkage clustering and complete-linkage clustering remain meaningful for a symmetric nonnegative dissimilarity matrix that violates the triangle inequality. Such a calculation gives a valid algorithmic dendrogram, but does not turn the original matrix into Euclidean distances. A triangle-inequality counterexample identifies that source defect without requiring invented replacement data.

Dendrogram

Words: 42
Agglomerative hierarchical clustering OurBigBook.com
A dendrogram displays successive cluster merges, with the height of each merge equal to its intercluster dissimilarity. Cutting at a height gives a partition. Single-linkage clustering measures the closest cross-pair and can form chains, while complete-linkage clustering measures the farthest cross-pair and favors smaller within-cluster diameters.

Complete-linkage clustering (d(C,D)=maxx∈C,y∈D​d(x,y))

Words: 34
Agglomerative hierarchical clustering OurBigBook.com
The farthest cross-pair distance determines the next merge. It favors groups with small diameter and reduces the chaining effect of single-linkage clustering, but can be sensitive to isolated extreme observations. Ties can affect intermediate partitions.

Single-linkage clustering (d(C,D)=minx∈C,y∈D​d(x,y))

Words: 39
Agglomerative hierarchical clustering OurBigBook.com
The nearest cross-pair distance determines the next merge. At a threshold, clusters are connected components of the graph joining pairs below that threshold. This handles nonconvex shapes but can join otherwise separate groups through a chain of intermediate observations.

Principal component regression

Words: 85
Principal component analysis OurBigBook.com
Regress a response on selected principal component scores of centered predictors. If X=UDVT is a singular value decomposition and the first q positive-singular-value components are retained, the retained score matrix is Uq​Dq​ and the fitted coefficient in predictor coordinates is Vq​Dq−1​UqT​y. The fitted centered response is Uq​UqT​y: this follows by applying the least-squares normal equations to the orthogonal score columns. Truncating small singular directions limits variance amplification, but directions of large predictor variance need not be those best predicting the response; select q using prediction assessment rather than explained predictor variance alone.

Scree plot

Words: 53
Principal component analysis OurBigBook.com
A scree plot graphs ordered covariance or correlation eigenvalues against component number. A transition from a steep decline to a flatter tail suggests a dimension, but this is a diagnostic rather than a proof of the number of latent factors. In factor analysis, it should be combined with model fit, substantive interpretation and uncertainty assessment.

Principal component loading (rj​=λj​​ℓj​)

Words: 59
Principal component analysis OurBigBook.com
Two conventions occur for principal-component loadings: the unit eigenvector ℓj​ defining a principal component, and the scaled vector rj​=λj​​ℓj​. For principal component analysis on a correlation matrix, the entries of the latter are the correlations between each standardized variable and the component scaled to variance one. Indeed, Cov(Z,ℓjT​Z)=Cℓj​=λj​ℓj​ and Var(ℓjT​Z)=λj​. Thus ∥rj​∥2=λj​, whereas ∥ℓj​∥=1; reporting the convention avoids confusing component directions with correlations.

Principal component

Words: 81 Articles: 1
Principal component analysis OurBigBook.com
A principal component is the projection of centered data onto a unit eigenvector of its covariance matrix. Ordering the components by their eigenvalues orders their variances. Repeated eigenvalues allow any orthonormal basis of the corresponding eigenspace.

Principal component score (zij​=qjT​(xi​−xˉ))

Words: 51
Principal component OurBigBook.com
A score is an observation's coordinate along a principal component direction. Center an observation by the fitted sample mean, apply the fitted variable scaling when using principal component analysis on a correlation matrix, then take its inner product with the unit principal component loading vector. New observations must use the training center and scaling. The score variance equals the corresponding eigenvalue when the covariance normalization is consistent.

Explained variance of a principal component (λj​/trΣ)

A population principal component explains the displayed fraction of total variance. The first q components explain ∑j≤q​λj​/∑j​λj​. Comparing covariance and correlation analyses requires different denominators: the original variance sum for the former and the number of nonconstant standardized variables for the latter.

Principal component analysis on a correlation matrix (Z=D−1/2(X−μ),Cov(Z)=D−1/2ΣD−1/2)

Words: 54
Principal component analysis OurBigBook.com
For positive marginal variances, standardizing each variable to variance one converts covariance-based PCA on Z into correlation-based PCA on X. This makes the analysis insensitive to the original measurement units but changes the optimization criterion. Standardization gives small-variance variables the same marginal weight as large-variance variables; it is a modelling choice, not an automatic improvement.

Population principal component (Yj​=qjT​(X−μ),Σqj​=λj​qj​)

Words: 45
Principal component analysis OurBigBook.com
The population principal components are centered linear compounds along an orthonormal eigenbasis of the covariance matrix, ordered by decreasing eigenvalue. They are uncorrelated and have variances λj​. Each successive direction maximizes variance subject to unit length and orthogonality to earlier directions. Uncorrelatedness does not imply independence unless additional distributional assumptions hold.

Misclassification rate (P(g​(X)=Y))

Words: 56
Classification in statistical learning OurBigBook.com
The misclassification rate is the expected zero-one loss of a classification in statistical learning rule. Its empirical version is the fraction of incorrectly labeled observations. Evaluation on the fitting sample gives a training error; evaluation on an independent test set estimates prediction error. For a majority-class leaf of a classification tree, the training error count is nt​−maxk​ntk​, unlike classification-tree deviance, which also uses the fitted class probabilities.

Classification tree

Words: 195 Articles: 2
Classification in statistical learning OurBigBook.com
A classification tree partitions predictor space recursively and attaches a class probability vector to each terminal region. For a categorical response, a fitted leaf commonly uses its observed class proportions and predicts their largest entry. Binary numerical splits compare one coordinate with a threshold. Growing a tree greedily by reducing classification-tree deviance gives an interpretable rule but does not globally optimize the tree. Cost-complexity tree pruning and cross-validation control complexity and assess prediction error.

Cost-complexity tree pruning (Rα​(T)=R(T)+α∣L(T)∣)

Words: 62
Classification tree OurBigBook.com
Pruning balances a tree's empirical loss R(T) against the number of leaves. Increasing α favors a nested sequence of smaller subtrees, obtained by removing splits with the smallest effective cost per removed leaf. Choose complexity using cross-validation or a validation set, and assess the selected tree on a separate test set. The loss can be deviance or misclassification loss; the chosen convention must be specified.

Classification-tree deviance (D(t)=−2∑k​ntk​log(ntk​/nt​))

Words: 66
Classification tree OurBigBook.com
Maximizing a node's multinomial likelihood gives class probabilities p​tk​=ntk​/nt​. Twice the negative maximized log-likelihood relative to perfect classification is the displayed deviance, with 0log0=0. It equals twice the node size times its Shannon entropy. A split is chosen by maximizing D(t)−D(tL​)−D(tR​), and tree deviance is the sum over terminal nodes. The training misclassification count is instead ∑t​(nt​−maxk​ntk​); the two criteria are different.

Words: 63
