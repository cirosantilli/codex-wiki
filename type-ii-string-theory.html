Type II string theory

 Home Physics Branches of physics String theory
OurBigBook.com Words: 924 Articles: 21
Type II superstring theory is a ten-dimensional closed oriented superstring theory with spacetime supersymmetry and no tachyon. Its massive closed-string levels have squared masses separated by 4/α′.
