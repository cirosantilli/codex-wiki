Typing context (Γ)

 Home Computer science Programming language Type system Typing judgment
OurBigBook.com Words: 42
A typing context records the types assumed for available program names. In Γ={x:int,y:int}, looking up either name yields int. Checking a lambda abstraction extends the typing context with its argument's type for the body. In the Hindley-Milner type system, a typing context can also hold type schemes for names introduced by let polymorphism.
