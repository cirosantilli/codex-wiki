Rank-zero elliptic curve with cubic x cubed plus x (y2=x3+x,r=0)

OurBigBook.com Words: 45
For E:y2=x3+x, the two-torsion square-class homomorphism has image {1}: prime-support bounds allow only ±1, and every nonzero affine x is positive. Its two-isogeny formula companion E′:y2=x3−4x has possible image classes {1,−1,2,−2}, all realized by its rational two-torsion. The two-isogeny rank formula gives 2r=1⋅4/4=1, so the rank is zero.
