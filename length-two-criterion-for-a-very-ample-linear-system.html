Length-two criterion for a very ample linear system (V↠H0(E,L∣E​),lengthE=2)

 ... Geometry and topology Algebraic geometry Weil divisor Linear system of divisors Base-point-free linear system Very ample linear system
OurBigBook.com Words: 60
For a finite generating space V⊆H0(X,L) on a projective scheme, its map to projective space is a closed immersion exactly when, after algebraic closure of the ground field, the displayed evaluation is surjective for every length-two closed subscheme E. Two distinct points test point separation; a double point tests a direction in the Zariski tangent space. For the complete section space, this characterizes a very ample line bundle.
