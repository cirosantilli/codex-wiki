Innovations in a binary Markov source (Zn​=Xn​⊕Xn−1​)

OurBigBook.com Words: 133
Generate the binary Markov source by taking independent and identically distributed Bernoulli random variables Z2​,Z3​,… of parameter q, independent of a fair initial bit, and setting Xn​=Xn−1​⊕Zn​. Here ⊕ is exclusive or. Each Zn​ is the unpredictable flip decision.
The transformation between (X1​,…,Xn​) and (X1​,Z2​,…,Zn​) is a bijection. It preserves information entropy, so
H(X1​,…,Xn​)=H(X1​,Z2​,…,Zn​)=1+(n−1)h2​(q).
(128)
Sending the initial bit and encoding the innovation sequence describes every source word exactly. This does not by itself specify a practical compressor, but it identifies the uncertainty which a prefix code or other lossless source coding method must handle.
For a word with k flips among its n−1 transitions,
P(X1​=x1​,…,Xn​=xn​)=21​qk(1−q)n−1−k.
(129)
There are 2(kn−1​) such words: choose the initial bit and the flip positions. At q=1/8 and n=16, each constant word has probability (1/2)(7/8)15≃0.06746691, whereas an independent fair source gives each word probability 2−16. Equal marginal probabilities plainly do not imply equal word probabilities.
