Cycle class map (cl:CHr(X)→H2r(X,Z))

 ... Geometry and topology Algebraic geometry Intersection theory Algebraic cycle Rational equivalence Chow group
OurBigBook.com Words: 102 Articles: 1
For a smooth complex projective algebraic variety, the cycle class map sends an algebraic cycle of codimension r to the Poincare dual of its homology class. Rational equivalence gives the same cohomology class, so the map descends to the Chow group. It respects intersection products, pullback and proper pushforward; a cohomological obstruction therefore obstructs the corresponding proposed identity of Chow classes.
