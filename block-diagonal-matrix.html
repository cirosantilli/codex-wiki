Block diagonal matrix (diag(B1​,…,Br​))

 ... Algebra Linear algebra Vector space Linear map Matrix Block matrix
OurBigBook.com Words: 25
A block matrix is block diagonal if all off-diagonal blocks vanish. It represents independent actions on a direct sum of vector spaces. Its determinant is the product of the diagonal-block determinants.
