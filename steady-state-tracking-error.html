Steady-state tracking error (ess​=limt→∞​e(t))

 Home Mathematics Area of mathematics Control theory Closed-loop control Tracking error
OurBigBook.com Words: 708
The steady-state tracking error is
ess​=limt→∞​e(t),
(15)
when this finite limit exists. A finite steady-state tracking error does not require the reference signal, the plant output, or the control input to become constant: all can grow while their difference settles. If the tracking error grows without bound or keeps oscillating, report that behavior rather than assigning a finite steady-state tracking error. Eventual accuracy and asymptotic stability are different questions.
For the first-order low-pass filter τy˙​+y=Ku+d introduced in reference signal, assume exact measurement, constant control disturbance d, and no actuator saturation or feedback delay. Under proportional control u=kp​(r−y) with kp​>0, a constant reference signal r=R gives
τy˙​+(1+Kkp​)y=Kkp​R+d,ess​=1+Kkp​R−d​.
(16)
The decaying homogeneous solution has rate (1+Kkp​)/τ>0, so this equilibrium point is approached from any finite initial condition. A nonzero tracking error is needed to maintain the control input that balances the model's tendency to relax toward y=d. This differs from the accumulating controlled plant x˙=u+w, for which proportional control already tracks a constant reference signal exactly when w=0. The presence or absence of a step offset depends on both the controlled plant and the controller.
For a ramp reference signal r=vt, the same proportional control gives
τe˙+(1+Kkp​)e=τv+vt−d.
(17)
Its long-time particular solution grows with slope v/(1+Kkp​) when v=0. Thus the controlled plant and homogeneous closed-loop response are stable, but the tracking error has no finite steady-state tracking error. A changing goal requires a different performance test from a fixed destination.
Now use proportional-integral control u=kp​e+ki​z, z˙=e, with ki​>0. For the same controlled plant, differentiate the error equation on intervals where the inputs are smooth:
τe¨+(1+Kkp​)e˙+Kki​e=τr¨+r˙−d˙.
(18)
The characteristic polynomial τλ2+(1+Kkp​)λ+Kki​ has both roots of a polynomial in the open left half-plane: real roots have negative sum and positive product, and a nonreal complex conjugate pair has negative real part. This proves decay of the homogeneous error for this model. It does not prove stability of an arbitrary controlled plant controlled by positive gains. At a reference jump, use the original ordinary differential equations to set the new initial conditions, rather than treating the reference as smooth at that jump.
With a constant reference signal and constant control disturbance, proportional-integral control therefore gives ess​=0. At its equilibrium point, y∗​=R, u∗​=(R−d)/K, and z∗​=(R−d)/(Kki​). The stored integral maintains the required command while the current tracking error vanishes. For a ramp reference signal, however, the forcing above is v, and
ess​=Kki​v​.
(19)
The tracking error settles even though the accumulated integral and the required control input grow. This finite offset is the error needed to keep increasing that command. For r=at2/2 with a=0, the forcing is τa+at and even this proportional-integral control leaves a tracking error growing with slope a/(Kki​). Integral action is therefore a precise mechanism for selected input classes, not a promise of perfect tracking for every reference signal. [ref]
Here are completely explicit synthetic examples with y(0)=z(0)=0, d=0, and no sensor bias. Choose τ=2s, K=1∘C per percentage point, kp​=1 percentage point per degree, and ki​=0.5 percentage points per degree-second. Thus Kkp​=1 is dimensionless, and Kki​=0.5s−1. In the following formulas, t denotes the numerical time in seconds and y,e,r denote numerical temperature rises in degrees. For the unit-step reference signal r=1, proportional control and proportional-integral control respectively give
yP​(t)=21​(1−e−t),eP​(t)=21​(1+e−t),uP​(t)=eP​(t);
(20)
yPI​(t)=1−e−t/2,ePI​(t)=e−t/2,uPI​(t)=1.
(21)
For the ramp reference signal r=0.2t, the corresponding solutions are
yP​(t)=0.1(t−1+e−t),eP​(t)=0.1(t+1−e−t),uP​(t)=eP​(t);
(22)
yPI​(t)=0.2(t−2+2e−t/2),ePI​(t)=0.4(1−e−t/2),uPI​(t)=0.2t.
(23)
The control inputs here are numerical heater-command percentage points. Substitution into 2y˙​+y=u and into the controller equations checks these solutions without invoking an unverified limiting rule. The proportional control step offset is 0.5 degrees; the proportional-integral control step offset is zero. The proportional control ramp error grows; the proportional-integral control ramp offset is 0.4 degrees, exactly v/(Kki​).
The conclusions have specific limits. With constant sensor bias b, stable proportional-integral control for a feasible constant reference signal drives the measured tracking error to zero but leaves the physical discrepancy εss​=b. Under proportional control, the measured offset instead becomes (R−b−d)/(1+Kkp​). If actuator saturation prevents the required control input, zero step offset is not achievable by these formulas. A changing control disturbance contributes −d˙ to the error equation, while feedback delay can change stability; neither is covered by the constant-disturbance result. These restrictions are what make steady-state tracking error useful: it identifies the input, measurement convention, and model for which an accuracy claim is actually justified.
