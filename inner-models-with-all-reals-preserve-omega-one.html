Inner models with all reals preserve omega-one (ω1W​=ω1​)

 ... Foundations of mathematics Set theory Definable power set Constructible hierarchy Constructible universe Relative constructible universe
OurBigBook.com Words: 103
An inner model W of ZF containing all ambient subsets of ω computes the same countable ordinals as the ambient universe. Every ambient countably infinite ordinal has a well-order code coded by a subset of ω, hence that code belongs to W; finite ordinals are already shared. The Mostowski collapse theorem inside W recovers the actual ordinal and its countability witness. Conversely any countability witness in W remains one outside. If W also contains the full power set of ω as a set, its Continuum hypothesis would give an ambient bijection from ω1​ onto that same power set. Thus an ambient failure of this well-orderable formulation of the Continuum hypothesis is preserved in such an inner model. No internal axiom of choice is required for this argument.
