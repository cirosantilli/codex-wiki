Constant function (f≡c)

 Home Mathematics Area of mathematics Foundations of mathematics Set theory Function
OurBigBook.com Words: 114
On a nonempty domain of a function X, a constant function f:X→Y has one fixed value c in its codomain:
f(x)=cfor every x∈X.​
(5)
For example, f(x)=2 on the real line is a horizontal graph. Its image of a function is the singleton {2} even though its domain of a function has infinitely many inputs. A constant function from the real line to the real numbers has derivative zero and every nonzero real period of a function; there is no smallest positive period. It supplies a reference level from which variation can be measured.
A constant map between vector spaces is a linear map only when its value is the zero vector, since a linear map must preserve zero. A nonzero constant map is still an affine map. In a Fourier series, the constant term records the period average, while the other terms describe oscillation around that level.
