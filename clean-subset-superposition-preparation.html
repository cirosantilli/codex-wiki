Clean subset superposition preparation (∣0n0m⟩⟼∣ψA​⟩∣0m⟩)

 Home Physics Branches of physics Quantum theory Grover's algorithm Known-subset Grover search
OurBigBook.com Words: 110
Suppose a known list of 2m distinct n-bit strings aj​ is available and computational basis transpositions on n+m qubits have polynomial-size implementations. Start with the uniform superposition state of index labels j, leaving the data zero. First swap ∣0n,j⟩ with ∣aj​,j⟩ for each nonzero aj​. Next, for each j=0, swap ∣aj​,j⟩ with ∣aj​,0m⟩. Distinct index labels separate the first-stage pairs, and distinct data strings separate the second-stage pairs. Thus no later transposition disturbs an earlier term. At most 2m+1−1 transpositions prepare the uniform data state and return the quantum ancilla to zero. For m=O(logn) the quantum circuit has polynomial size. This assumes the list is available; a membership predicate alone does not supply it.
