Induced linear map on a quotient vector space (T(v+U)=T(v)+U)

 ... Mathematics Area of mathematics Algebra Linear algebra Vector space Quotient vector space
OurBigBook.com Words: 56
For a linear map T:V→V and an invariant subspace U, the rule T(v+U)=T(v)+U defines a linear map on the quotient vector space V/U. Indeed, two representatives differ by an element of U, so their images also differ by an element of U. Conversely, this rule is well-defined only if T(U)⊆U, by comparing every u∈U with zero.
