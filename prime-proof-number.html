Prime-proof number

 Home Computer science Theoretical computer science Computational complexity theory Primality testing
OurBigBook.com Words: 39
An integer for which replacing any one decimal numerical digit by a different digit never produces a prime number. The convention must specify whether changes creating a leading zero are permitted. An exact test enumerates the allowed substitutions and applies primality testing to each result.
