Lattice path

 Home Mathematics Area of mathematics Combinatorics
OurBigBook.com Words: 2k Articles: 28
A lattice path is a sequence of points in an integer lattice whose consecutive differences belong to a prescribed finite set of steps.
For instance, a north-east lattice path uses only unit steps east or north in the integer lattice Z2. Restricting the allowed steps makes the counting question precise: the endpoint fixes how many of each step must occur, but their order remains free. Pascal's rule counts these lattice paths by their last step; the same binomial coefficient counts selections of step positions.
