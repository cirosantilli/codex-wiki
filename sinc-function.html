Sinc function (sinc(x)=sinx/x)

 Home Mathematics Area of mathematics Analysis Fourier transform
OurBigBook.com Words: 141 Articles: 3
The unnormalized sinc function is sinc(x)=sinx/x, extended by value one at zero. The normalized sinc function is sin(πx)/(πx), with the same removable value. These arise, with convention-dependent scaling, as inverse Fourier transforms of frequency-interval indicator functions, so they describe ideal low-pass filters and the Shannon scaling function.
