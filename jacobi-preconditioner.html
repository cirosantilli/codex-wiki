Jacobi preconditioner (M=diag(a11​,…,ann​))

 ... Area of mathematics Analysis Numerical analysis Numerical linear algebra Matrix preconditioning Matrix preconditioner
OurBigBook.com Words: 87
The Jacobi preconditioner keeps only the diagonal entries of the matrix A. For a symmetric positive-definite matrix, these entries are positive, so its auxiliary solve is zi​=ri​/aii​. It rescales coordinates with very different diagonal sizes, but cannot remove arbitrary off-diagonal coupling.[ref]
This shares a diagonal matrix with the Jacobi method, but the roles differ. The Jacobi method specifies a whole stationary iterative method for a linear system; a Jacobi preconditioner supplies an auxiliary solve to another iterative method, including the Preconditioned conjugate gradient method.
