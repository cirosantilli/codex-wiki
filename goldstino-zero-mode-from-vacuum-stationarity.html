Goldstino zero mode from vacuum stationarity (Wij​Wj​​=0)

 Home Physics Branches of physics Supersymmetry Supersymmetry breaking Goldstino
OurBigBook.com Words: 36
Stationarity of a canonical global F-term scalar potential gives ∂i​V=∑j​Wij​Wj​​=0. If some Fj​=−Wj​​ is nonzero, this vector is in the kernel of the chiral-superfield fermion mass matrix. It supplies the massless goldstino direction. If every Fj​ vanishes, this argument gives no broken-symmetry mode.
