Measurable set (A∈F)

 ... Mathematics Area of mathematics Analysis Real analysis Measure theory Sigma-algebra
OurBigBook.com Words: 41
A subset of X is measurable relative to a sigma-algebra F when it belongs to F. A measure defined on F assigns sizes to these sets. Measurability depends on the chosen sigma-algebra; for example, a Lebesgue measurable set need not be a Borel set.
