File offset

 Home Computer science Operating system File system Computer file
OurBigBook.com Words: 31
A byte position measured from the start of a file, beginning at zero. A memory-mapped file combines a starting file offset with a displacement inside its mapping; this is distinct from an open file description's current read/write position.
