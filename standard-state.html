Standard state

 ... Physics Branches of physics Statistical physics Thermodynamics Chemical potential Chemical equilibrium
OurBigBook.com Words: 68 Articles: 2
A standard state is a specified reference state used to define a species' standard chemical potential μi∘​. The reference convention, including temperature, must be consistent when calculating thermodynamic activities, reaction quotients, and equilibrium constants.
