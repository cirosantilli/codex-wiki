Poisson kernel of a three-dimensional quarter-space (P=2πz​(r−−3​−r+−3​))

 ... Mathematics Area of mathematics Analysis Green's function Dirichlet Green function Dirichlet Green function for a three-dimensional quarter-space
OurBigBook.com Words: 127
For the face z=0 of x>0,z>0, set r∓2​=(x∓ξ)2+(y−η)2+z2, with source boundary coordinates ξ>0, η∈R. The Poisson kernel for data on that face and zero data on x=0 is the displayed positive difference. It follows by differentiating the Dirichlet Green function for a three-dimensional quarter-space in the inward source direction. Integrating it against bounded continuous face data gives the bounded harmonic solution away from compatibility issues at the edge. Without a boundedness or suitable infinity condition, uniqueness fails because the harmonic function xz vanishes on both faces.
Its integral over this one face is 2arctan(x/z)/π, the harmonic measure of that face. To calculate it, integration in η first gives z{[(x−ξ)2+z2]−1−[(x+ξ)2+z2]−1}/π; the remaining half-line integral is an elementary arctangent difference. This mass lies between zero and one: the other face carries the remaining boundary influence.
