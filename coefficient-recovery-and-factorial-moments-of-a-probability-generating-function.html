For a nonnegative integer-valued random variable, its moment-generating function satisfies MX​(t)=GX​(et) wherever finite. The guaranteed probability generating function domain therefore supplies finite values for real t≤0; it does not guarantee positive exponential moments or a finite moment-generating function on a neighborhood of zero. Bounded nonnegative integer-valued random variables have polynomial probability generating functions, but their convenient behavior is not a general existence theorem.
