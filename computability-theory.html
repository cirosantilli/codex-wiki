Recursive triple colouring with no computable infinite homogeneous set (c:[N]3→2)

Words: 77
Computability theory OurBigBook.com
Let Ks​ be increasing finite stage approximations to a noncomputable computably enumerable set K. For x<y<z, colour the triple zero exactly when Ky​∩[0,x]=Kz​∩[0,x]. An infinite homogeneous set has colour zero, since each bounded approximation eventually stabilizes. Its first two elements above any requested bound recover the final approximation at that bound, so the homogeneous set computes K. Thus no infinite homogeneous set is computable. This illustrates the difference between a Ramsey's theorem existence result and an effective construction.

Jockusch triple coloring computing the halting set (c(x,y,z)=1{Ky​∩x=Kz​∩x})

Words: 105
Computability theory OurBigBook.com
Let Ks​ be a computable increasing finite-stage enumeration of the halting problem set K. Color x<y<z by whether the approximations below x differ at stages y,z. This is a recursive two-color partition of triples. An infinite homogeneous set cannot have color one: for fixed x, the finite approximation below x eventually stabilizes. If its color is zero, choose x from that set above an input n, then another member y>x; agreement with arbitrarily large later stages gives K(n)=Ky​(n). Thus every infinite homogeneous set computes K, and none is a recursive set. This makes the failure of an effective version of Ramsey's theorem explicit.

Function in extension

A function in extension is a function specified by its domain and the value at each input in that domain. Distinct functions in intension can have this same extension. Properties of the extension of an arbitrary program are semantic properties, to which Rice theorem applies when the property is nontrivial.

Binary diagonally noncomputable function (f:N→{0,1},φe​(e)↓⟹f(e)=φe​(e))

Computability theory OurBigBook.com
A total binary-valued function is diagonally noncomputable if it differs from each defined diagonal value in an effective enumeration of partial computable functions. Nonbinary diagonal outputs are automatically different. No such function is computable: its own program index would contradict the defining condition. Choosing the opposite bit at every defined binary diagonal value proves existence without supplying a computable procedure.

A set P is productive when a partial computable function returns an element of P outside any computably enumerable subset supplied by its index. The function must halt for every index of a subset of P, including finite subsets. Productive sets are not computably enumerable.

Kolmogorov complexity (CU​(σ))

Words: 217 Articles: 4
Computability theory OurBigBook.com
Kolmogorov complexity measures the length of a shortest effective description of an object. Fixing an optimal description machine gives an invariant quantity up to an additive machine-dependent constant. Plain Kolmogorov complexity is especially convenient for counting descriptions shorter than a binary string.

Plain Kolmogorov complexity (CU​(σ)=min{∣p∣:U(p)=σ})

Words: 131 Articles: 2
Kolmogorov complexity OurBigBook.com
For a fixed optimal description machine U, the plain Kolmogorov complexity of a binary string is the minimum length of a finite program producing it. The admissible programs need not satisfy a prefix restriction. There are at most 2n−1 descriptions shorter than n, which is the counting fact behind the existence of incompressible strings.

Incompressible string (CU​(σ)≥∣σ∣)

A binary string is incompressible relative to a fixed optimal description machine when its plain Kolmogorov complexity is at least its length. A counting argument gives at least one such string at each length, and their set is immune.
Immunity of incompressible strings
Words: 53
Incompressible string OurBigBook.com
If an infinite computably enumerable family contained only incompressible strings, select its first enumerated string of length at least n. This is a total computable selection rule, and its selected string has a description of length O(logn) encoding the threshold. For large n that is shorter than the selected string. This contradiction proves immunity.

Undecidable decision problem

Words: 55
Computability theory OurBigBook.com
A decision problem for which no algorithm terminates with the correct yes-or-no answer on every input. For example, if the diagonal halting set had a decision algorithm, a program could halt on its own code exactly when that algorithm says it does not halt, producing a contradiction. An undecidable decision problem may still admit a partial procedure that terminates on every yes-instance.

Finite-injury priority construction

Words: 389 Articles: 5
Computability theory OurBigBook.com
A finite-injury priority construction orders countably many requirements so that each has finitely many predecessors. A strategy may discard lower-priority strategies' current witnesses and restraints when it acts. If each requirement acts finitely often after its last such initialization, induction on priority shows that every requirement is injured only finitely often and eventually has a stable strategy. The Friedberg–Muchnik theorem is a central example.

Priority restraint (r∈N)

Finite-injury priority construction OurBigBook.com
A priority restraint protects finitely many oracle answers by requiring lower-priority enumerations to avoid positions below a numerical bound. Higher-priority action can cancel the priority restraint by initializing its owner. After the last such injury, the protected computation is permanent.

Preservation of a restrained oracle computation (B↾u=Bs​↾u⟹ΦeB​(x)=ΦeBs​​(x))

Priority restraint OurBigBook.com
An oracle computation queries only finitely many positions. If the oracle remains unchanged below its use, the same computation has the same output. In a finite-injury priority construction, a successful requirement imposes this bound on lower priorities; the induction that higher priorities stop acting then makes the disagreement permanent.

Private-witness diagonalization for incomparable enumerable sets

Words: 120
Finite-injury priority construction OurBigBook.com
To prevent a Turing functional ΦeB​ from computing the indicator function of an enumerated set A, reserve a permanently unique fresh witness x. On observing a convergent computation with oracle use u, enumerate x into A if the answer is zero; otherwise keep it out. Restrain subsequent lower-priority enumerations into B below u. Higher-priority actions may initialize this strategy and retire its witness, but witnesses are never reused. In a finite-injury priority construction, mathematical induction on priority shows that the final computation, if observed, remains correct as a computation from the final oracle and disagrees with A at x. If no computation is ever observed after the final initialization, the final oracle computation diverges, since any convergent computation uses only finitely many eventually stable oracle bits.

Friedberg–Muchnik theorem

Words: 77
Finite-injury priority construction OurBigBook.com
There are computably enumerable sets A,B with A≤T​B and B≤T​A. A finite-injury priority construction alternates requirements preventing oracle programs for B from computing A and programs for A from computing B. Each requirement uses a private witness, enumerates it when the opposing computation gives zero, and restrains the oracle segment preserving that disagreement. Verification inducts on priority. Both degrees are noncomputable and strictly below the halting degree, resolving Post problem.
The incomparable-degree formulation is stated in Steffen Lempp's notes, section 1.1.

Finite injury

An injury discards a strategy's current witness or restraint when a higher-priority action changes its assumptions. Finite injury means that each strategy experiences only finitely many such resets. The final uninjured strategy must still be checked to satisfy its requirement; finite injury alone is not the conclusion.

Oracle-assisted finite-extension construction

Words: 76
Turing reduction OurBigBook.com
Build an infinite oracle as an increasing union of finite binary strings. With the diagonal halting set as an oracle, decide whether some finite extension makes a specified Turing functional halt with a binary output at a fresh input. In a yes case, preserve that finite computation and commit the opposing set's bit to the opposite value. In a no case, no subsequent infinite extension can yield a characteristic-function value there. Length growth makes the resulting sets computable in the halting oracle.

Turing functional (ΦeB​(x))

A Turing functional is a partial computation performed by an oracle machine, viewed as a function of both the oracle B and input x. Oracle programs admit an effective enumeration. Every convergent computation inspects only a finite part of its oracle, recorded by its oracle use.

The use of a convergent oracle computation is one more than its largest queried position, or zero if there are no queries. Preserving the oracle below this number preserves the computation. This finite dependence supplies the restraints in a finite-injury priority construction.

Turing degree

The Turing degree of a set is its equivalence class under mutual Turing reducibility. Degrees inherit the partial order induced by Turing reducibility. The Friedberg–Muchnik theorem gives incomparable degrees represented by computably enumerable sets.

Kleene–Post incomparability theorem (0<a,b<0′,a≤b, b≤a)

Words: 63
Turing degree OurBigBook.com
There are incomparable Turing degrees strictly between the computable degree and the degree of the diagonal halting set. An oracle-assisted finite-extension construction alternately defeats each Turing functional in the two directions. Since the sets are computable in the halting oracle, their degrees are at most 0′; incomparability makes them nonzero and strictly below 0′. This theorem does not require the constructed sets to be computably enumerable. The Friedberg–Muchnik theorem supplies that stronger conclusion.

Post problem

Post problem asks whether a computably enumerable set can have a Turing degree strictly between the computable degree and the degree of the halting problem. The Friedberg–Muchnik theorem answers yes by constructing two incomparable computably enumerable degrees.

Church–Turing thesis

The Church–Turing thesis asserts that every effectively calculable function is computable by a formal model equivalent to a Turing machine. It identifies an informal notion of effective procedure with a mathematical class rather than stating a theorem within one formal system.

Pairing function (⟨x,y⟩)

Words: 1k Articles: 2
Computability theory OurBigBook.com
A pairing function is a computable function that gives a bijection from the Cartesian product N02​ to N0​, with two computable functions recovering its coordinates. Here N0​={0,1,2,…} consists of the natural numbers, including zero. If p is the pairing function and L,R its decoding functions, the requirements are
L(p(x,y))=x,R(p(x,y))=y,p(L(z),R(z))=z.
(1)
Every ordered pair has exactly one code, every code represents an ordered pair, and decoding always terminates. For a bijection given by a total computable function, computability of the inverse function also follows by enumerating all ordered pairs until the one with code z appears. A primitive recursive pairing function makes the stronger requirement that both encoding and coordinate decoding are primitive recursive.
The Cantor pairing function makes this concrete through triangular numbers:
T(s)=2s(s+1)​,π(x,y)=T(x+y)+y.
(2)
On the diagonal x+y=s, list (s,0),(s−1,1),…,(0,s). There are s+1 ordered pairs there, and T(s) ordered pairs on earlier diagonals. Their codes therefore occupy precisely the consecutive natural numbers from T(s) through T(s+1)−1. These intervals touch without overlapping and cover all natural numbers; within each interval the offset y determines the ordered pair. This proves both injectivity and surjectivity, hence the bijection. It also explains why the infinite grid is a countably infinite set: every ordered pair is reached after finitely many steps. A row-by-row listing would never finish its first infinite row. Authored treatments give the same diagonal construction with the coordinates exchanged.[ref]
For example, the Cantor pairing function gives
π(0,0)=0,π(1,0)=1,π(0,1)=2,π(2,3)=T(5)+3=18.
(3)
The order of the coordinates matters: (1,0) and (0,1) are different ordered pairs with different codes.
To decode a natural number z, find the unique diagonal index s satisfying
T(s)≤z<T(s+1),y=z−T(s),x=s−y.
(4)
The inequality gives 0≤y≤s, so both recovered coordinates are natural numbers. At z=18, T(5)=15≤18<T(6)=21, hence s=5, y=18−15=3, and x=5−3=2. At z=0, s=0 and both coordinates are zero. Solving the quadratic inequality gives the equivalent floor function expression
s=⌊28z+1​−1​⌋.
(5)
This is exact as a statement about the real numbers and their square roots. An implementation using floating-point arithmetic can round across a diagonal boundary, especially for large z. Use an exact integer square root instead: with q=⌊8z+1​⌋ computed using integer arithmetic, s=⌊(q−1)/2⌋. Alternatively, search for the diagonal using exact integer comparisons. The primitive recursive pairing function proof below uses bounded minimization and needs no approximate square root.
A pairing function is a reversible encoding: unlike a hash function mapping arbitrarily many inputs into a fixed finite range, it loses no coordinates. This works because the mathematical natural numbers have no upper bound. A machine word with b binary digits has 2b possible values, while two such words have 22b possible ordered pairs; a bijection into one word of the same width is impossible. Evaluating the Cantor pairing function in a fixed-width integer type can overflow, including in the intermediate product (x+y)(x+y+1). Exact implementation requires sufficiently large integer storage or an explicit restricted input range. One mathematical code need not occupy fewer binary digits than its two inputs.
Iterating a pairing function gives a reversible encoding of tuples of any fixed positive length. With the left-nesting convention, the Cantor pairing function encodes (2,3,4) as
π(π(2,3),4)=π(18,4)=T(22)+4=253+4=257.
(6)
Decode the outer ordered pair first: T(22)≤257<T(23)=276 gives (18,4). Decode its first coordinate 18 to recover (2,3), giving the nested ordered pair ((2,3),4) and thus the original tuple (2,3,4).
The tuple length and nesting convention must be known. The same code 257 represents (18,4) as a two-entry tuple and (2,3,4) as a three-entry tuple; nesting alone does not make variable-length tuples self-describing. To encode variable-length tuples, supply their length or another explicit termination convention as part of the encoding. This simple change of representation is useful in computability theory and Gödel numbering: a function of several natural numbers can be studied through a single numerical input, while all coordinates remain recoverable. The striking fact is that a whole infinite grid can be serialized without omitting a point.
A historical reference for comparing sets through bijections is Georg Cantor's paper Ein Beitrag zur Mannigfaltigkeitslehre, published in 1878 in volume 84 of Journal für die reine und angewandte Mathematik, pages 242–258.[ref]

Primitive recursive pairing function (⟨x,y⟩)

Words: 502
Pairing function OurBigBook.com
A primitive recursive pairing function is a pairing function whose encoding function and both coordinate functions of its inverse function are primitive recursive functions. Thus the bijection can be used in either direction inside a construction by primitive recursion and function composition in recursion theory. A decoder that is merely a computable function would not establish this stronger closure property. Sutner's definition of a primitive recursive pairing system explicitly includes the decoding functions; his more general systems need only be injective, whereas a pairing function here is a bijection.[ref]
The Cantor pairing function is a primitive recursive pairing function. For its encoding, construct the triangular numbers directly by primitive recursion:
T(0)=0,T(s+1)=T(s)+s+1,π(x,y)=T(x+y)+y.
(7)
Since addition is primitive recursive, so are T and π by primitive recursion and function composition in recursion theory. This establishes the claim without treating division by two as an unexplained primitive operation.
For decoding, use bounded minimization to define
s(z)=min{t∈N0​:t≤z and z<T(t+1)}.
(8)
The bound is valid for every natural number z: T(z+1)=(z+1)(z+2)/2>z, so the candidate t=z always succeeds. The search includes zero; when z=0, it immediately returns s(0)=0. If s(z)>0, the preceding candidate failed, which gives T(s(z))≤z; when s(z)=0, that lower inequality follows from T(0)=0. Thus this search finds exactly the diagonal in the Cantor pairing function inverse, with
T(s(z))≤z<T(s(z)+1).
(9)
The comparison is primitive recursive, and bounded minimization of a primitive recursive predicate is primitive recursive. Therefore s is a primitive recursive function. Recover the coordinates by
R(z)=z−T(s(z)),L(z)=s(z)−R(z).
(10)
In constructions on the natural numbers, implement these subtractions using the primitive recursive operation a−˙​b=max(a−b,0): apply the predecessor function b times to a by primitive recursion. On these inputs it agrees with ordinary subtraction, since the diagonal inequalities imply 0≤R(z)≤s(z). Consequently L and R are primitive recursive functions, and π(L(z),R(z))=z. Zimmermann proves the relevant closure under bounded minimization and the primitive recursive character of the Cantor encoding and coordinate decoding; his convention adds the first coordinate, so its coordinates are exchanged relative to π here.[ref]
For a worked bounded minimization, take z=18. Candidates t=0,1,2,3,4 give T(t+1)=1,3,6,10,15, none exceeding 18. Candidate t=5 gives T(6)=21>18, so s(18)=5, R(18)=3, and L(18)=2. The search bound was 18; it terminates much earlier in this example. The bound proves membership in the primitive recursive functions; it is not a claim that scanning all candidates is the fastest implementation.
For each fixed k≥1, define a tuple encoder by
E1​(a1​)=a1​,Ek+1​(a1​,…,ak+1​)=π(Ek​(a1​,…,ak​),ak+1​).
(11)
Each Ek​ and each coordinate decoder is primitive recursive, by finitely many applications of function composition in recursion theory to π,L,R. For the three-entry tuple encoded as 257, applying R returns 4, applying L returns 18, and then L(18)=2, R(18)=3. The tuple length remains part of the agreed convention, as explained for a general pairing function.
This makes primitive recursive pairing functions useful for encoding several evolving values as one state in primitive recursion. For example, store consecutive Fibonacci numbers as c(0)=π(0,1) and update by
c(n+1)=π(R(c(n)),L(c(n))+R(c(n))).
(12)
The codes start 2,4,8,18, decoding to (0,1),(1,1),(1,2),(2,3). Every step uses primitive recursive encoding, decoding and addition; a single numerical state therefore carries the two values needed for the next step. This is also the reason a suitable Gödel numbering should permit sufficiently simple decoding: representation should preserve the class of functions being studied.

If E is easy, then ET is easy for every closed T: use the consistent equation E=λx.M to obtain ET=M. Since I is not easy and solvability produces I by applications, easy terms are unsolvable.
