Because r<n, choose a unit vector v in the null space of XT, so that vTX=0. Let J∈Rm×n have orthonormal columns, for example the first n columns of Im​, and choose a real number α>1. Set
A=J(In​+(α−1)vvT)​.
(29)
Its singular value along v is α, and its other singular values are 1. Thus σ1​(A)=α>1=σ2​(A). Meanwhile AX=JX. If X has full column rank, the column space of the thin QR decomposition is exactly range(JX), which is orthogonal to Jv. Hence PJv=0 for P=QQT, and
∥(Im​−P)A∥2​≥∥(Im​−P)Av∥2​=∥αJv∥2​=α.
(30)
Conversely, an orthogonal projection is a contraction in the Euclidean norm, so ∥(Im​−P)A∥2​≤∥A∥2​=α. Therefore
∥A−A∥2​=σ1​(A)=α>σ2​(A)=1​.
(31)
If X is rank deficient, complete the QR decomposition within J(v⊥): this space has dimension n−1≥r and contains all columns of JX, so the required orthonormal completion exists there. The same proof applies. For rank-deficient data the choice of unused columns of Q matters; the construction specifies a valid choice. If Q instead contains only a basis of range(AX), the conclusion holds without any completion. A fixed sampling matrix can thus miss the unique largest singular value completely.
