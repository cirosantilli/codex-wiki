Deterministic finite automaton

 Home Mathematics Area of mathematics Foundations of mathematics Formal language theory Finite-state machine
OurBigBook.com Words: 778 Articles: 13
A deterministic finite automaton has exactly one automaton transition for every automaton state and input symbol. Formally, a DFA is a tuple (Q,Σ,δ,q0​,F): Q is a nonempty finite set of automaton states, Σ a finite alphabet, δ:Q×Σ→Q a function, q0​ the initial automaton state, and F⊆Q the accepting automaton states. Its unique path on a word accepts if it ends in F after consuming the entire input. Visiting F earlier does not suffice.
For a concrete binary divisibility automaton, recognize the words whose values in the binary numeral system are divisible by three. Choose Q={0,1,2}, Σ={0,1}, q0​=0, and F={0}. Each automaton state names the congruence class of the integer read so far. Appending a binary digit b changes its value n to 2n+b, so the automaton transition is
δ(r,b)=(2r+b)mod3.
(5)
The modular arithmetic therefore needs only three automaton states, whatever the input length. The full function is δ(0,0)=0, δ(0,1)=1, δ(1,0)=2, δ(1,1)=0, δ(2,0)=1, and δ(2,1)=2.
For 1102​=6, the successive automaton states are 0→1→0→0, so the word is accepted. For 1012​=5, they are 0→1→2→2, so it is rejected. Leading zeros are allowed: they leave the initial automaton state unchanged. We explicitly assign value zero to the empty word, which is accepted because the initial automaton state is accepting. This is a convention for a formal language, rather than a claim that ordinary written numerals include a blank numeral.
The generator checks every word of up to eight binary digits, comparing the final automaton state with the integer value modulo three. Each length n includes all 2n words, preserving leading zeros as distinct inputs:

They are useful for catching a reversed arrow or mistaken label, but the reason the DFA works at every length is its invariant: after reading any word of value n, its automaton state is nmod3. The update n↦2n+b preserves that statement by mathematical induction. Through the extended transition function of a deterministic finite automaton, this becomes δ(0,w)=value(w)mod3.
