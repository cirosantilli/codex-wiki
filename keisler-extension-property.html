Keisler extension property

 ... Area of mathematics Foundations of mathematics Set theory Cardinal number Large cardinal Strongly inaccessible cardinal
OurBigBook.com Words: 53
An inaccessible cardinal κ has the Keisler extension property when there is a proper transitive set X⊋Vκ​ for which
(Vκ​,∈)≺(X,∈).
(22)
Such a κ is not the least inaccessible cardinal: X regards κ as inaccessible, elementarity reflects the existence of an inaccessible into Vκ​, and strong-inaccessibility absoluteness from rank agreement makes the resulting witness genuinely inaccessible below κ.
