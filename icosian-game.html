Icosian game

 ... Foundations of mathematics Graph theory Path in a graph Cycle in a graph Cycle graph Hamilton cycle
OurBigBook.com Words: 77
The Icosian game made the vertex-visit puzzle tangible. The report of its 1857 presentation describes a plane projection of a regular dodecahedron, with holes at the vertices for ivory pins. The Trinity College Dublin archive connects this game with the search for closed routes visiting each vertex exactly once. This puzzle supplies a historical illustration of the Hamilton cycle requirement.[ref]
