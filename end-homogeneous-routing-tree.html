End-homogeneous routing tree (∣Tα​∣≤λ∣[α]r∣)

 ... Mathematics Area of mathematics Foundations of mathematics Set theory Partition relation Erdős-Rado theorem for finite arities
OurBigBook.com Words: 128
For a coloring of (r+1)-subsets of an ordinal, route a vertex through the least earlier vertices matching its colors on every r-subset of previously chosen ancestors. The path stops when the vertex itself is selected. Common path prefixes agree, yielding a set-theoretic tree; a node at level α is determined by its color table on [α]r. Along a branch, the color of an (r+1)-tuple is independent of its last entry. If the domain has size (2μ)+ and λ≤μ, levels below μ+ have size at most 2μ; counting all those levels forces a branch of length μ+. If the domain is a regular strong-limit cardinal κ, those levels instead have size below κ, and the tree property supplies a cofinal branch when needed.
