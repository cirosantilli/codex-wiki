Ultrafilter

 Home Mathematics Area of mathematics Foundations of mathematics Set theory Filter (set theory)
OurBigBook.com Words: 1k Articles: 25
An ultrafilter on a set X is a proper filter on a set that contains exactly one of A and X∖A for every A⊆X.
