Ultrafilter

 Home Mathematics Area of mathematics Foundations of mathematics Set theory Filter on a set
OurBigBook.com Words: 358 Articles: 10
An ultrafilter on a set X is a proper filter on a set that contains exactly one of A and X∖A for every A⊆X.
