Equivalence class ([x]R​={y:xRy})

 ... Area of mathematics Foundations of mathematics Set theory Finitary relation Binary relation Equivalence relation
OurBigBook.com Words: 232 Articles: 1
An equivalence class collects all the set elements indistinguishable from a specified set element under an equivalence relation. For an equivalence relation R on a set X, the precise definition is
[x]R​={y∈X:xRy},x∈X.
(14)
The ambient set matters: a finite class for integer congruence restricted to {0,…,8} differs from the infinite residue class for the same integer congruence on all integers. We write [x] when the equivalence relation and ambient set are clear.
In the finite modulo-three example,
[0]=[3]=[6]={0,3,6},[1]=[4]=[7]={1,4,7},[2]=[5]=[8]={2,5,8}.
(15)
There are nine names [x] but only three distinct equivalence classes. In particular, 3∈[0], whereas [3]=[0]: the first statement is membership of a set element; the second is equality of two sets.
For any equivalence relation on X, the essential rule is
xRy⟺[x]R​=[y]R​⟺[x]R​∩[y]R​=∅.
(16)
Reflexivity puts x in [x]R​, so the equivalence classes are nonempty and cover X. If two equivalence classes share z, the symmetric relation property and transitivity relate their defining elements through z; transitivity then makes their members coincide. Thus distinct equivalence classes are disjoint, giving a partition of a set. Conversely, declare two set elements equivalent when they belong to the same block of a partition of a set. The three relation properties follow immediately and its equivalence classes recover the blocks. [ref]
