Metropolis–Hastings algorithm

The Metropolis–Hastings algorithm proposes y from q(x,⋅) at state x and accepts it with probability
1∧π(x)q(x,y)π(y)q(y,x)​.
(35)
This acceptance rule enforces detailed balance with the target density π.
