Karatsuba practical crossover

 Home Computer science Algorithm Karatsuba multiplication
OurBigBook.com Words: 170
Karatsuba digit-operation cost explains eventual scaling, while a practical base-case threshold depends on the costs of addition, subtraction, copying and function calls relative to small integer multiplication. Using M(n)=An2+Dn+E for a base-case cost, one Karatsuba level costs 3M(n/2)+Fn+G: the quadratic coefficient falls to 3A/4, but the linear contribution includes 3Dn/2+Fn. Small operands can therefore cost more despite the smaller exponent. This comparison and the effect of implementation improvements on the threshold are described in the GMP manual.[ref]
The plotted crossover belongs only to the stipulated constants in its caption; its ordinary-method curve counts digit products alone, while the Karatsuba curve includes the chosen internal overhead. Selecting a threshold for real software requires measuring the actual implementation on its intended machine. With base B=2w for a fixed machine digit width w, the same analysis counts machine digits; it does not establish a universal crossover in decimal digits, bits, or elapsed time.
