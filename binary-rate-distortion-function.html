For a stationary source of independent and identically distributed fair bits, with Hamming distortion and binary reconstruction alphabet,
R(D)={1−h2​(D),0,​0≤D≤1/2,D≥1/2.​​
(99)
The binary entropy convention is 0log2​0=0. Once D≥1/2, always reconstructing zero meets the distortion constraint without sending any bits. The formula 1−h2​(D) must not be extended to D>1/2: a looser constraint cannot increase the required rate.[ref]
The short argument identifies both sides of the optimum. For any feasible binary reconstruction, put E=X⊕X, using exclusive or. Knowing X makes X and E determine one another, so the conditional entropy obeys
H(X∣X)=H(E∣X)≤H(E)=h2​(P(E=1))≤h2​(D)
(100)
when 0≤D≤1/2. The last step uses the increase of binary entropy on that interval. Hence I(X;X)=1−H(X∣X)≥1−h2​(D). Conversely, choose X=X⊕N with an independent Bernoulli random variable N of parameter D. This binary symmetric channel has expected distortion D and mutual information 1−h2​(D), attaining the bound.
