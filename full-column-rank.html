Full column rank (rankA=n)

 ... Algebra Linear algebra Vector space Linear map Matrix Matrix rank
OurBigBook.com Words: 89
An m×n matrix has full column rank when its matrix rank is n, equivalently when its columns are linearly independent vectors. This requires n≤m. Its kernel is {0}, so the represented linear map is injective and every solvable linear system Ax=b has a unique solution. It need not reach every output.[ref]
