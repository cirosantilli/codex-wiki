Residual network (Gf​)

 ... Mathematics Area of mathematics Foundations of mathematics Graph theory Flow network Max-flow min-cut theorem
OurBigBook.com Words: 653 Articles: 6
For a feasible flow f, each original directed edge u→v supplies a forward residual network edge of capacity cuv​−fuv​ and a backward one v→u of capacity fuv​; zero-capacity residual edges may be omitted. The forward edge permits an increase, while the backward edge permits cancellation of existing flow. In particular, backward residual capacity is the amount already sent, rather than unused original capacity. If both original orientations exist, keep their residual contributions separate, or add capacities for contributions with the same direction. An augmenting path uses these permitted changes while preserving flow conservation and the capacity constraints.
To see why cancellation matters, give all five directed edges s→a, s→b, a→b, a→t, b→t unit flow network edge capacities. Starting from zero flow, an augmenting path s→a→b→t carrying 1 yields
(fsa​,fsb​,fab​,fat​,fbt​)=(1,0,1,0,1),∣f∣=1.
(90)
The remaining unused original edges are s→b and a→t, which do not form a source-to-sink graph path. However, the backward residual edge b→a has capacity fab​=1. Consequently the residual network contains the augmenting path s→b→a→t, with residual capacities 1,1,1.
Augment by 1: increase fsb​ and fat​ from 0 to 1, and decrease fab​ from 1 to 0. The result is
(fsa​,fsb​,fab​,fat​,fbt​)=(1,1,0,1,1),∣f∣=2.
(91)
Now flow conservation is 1=0+1 at a and 1+0=1 at b. The final flow sends one unit along each of s→a→t and s→b→t. The cut of a flow network S={s} has cut capacity 1+1=2, proving this is a maximum flow. Traversing b→a in the residual network revised the earlier routing decision; it did not send actual traffic along a nonexistent original edge.
