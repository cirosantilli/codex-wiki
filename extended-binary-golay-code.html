Extended binary Golay code (G24​=[24,12,8])

OurBigBook.com Words: 220 Articles: 2
The extended binary Golay code is the parity extension of the length-23 binary Golay code. It is a self-dual code and a doubly even code, with minimum Hamming distance eight. Its radius-three Hamming balls are disjoint but do not cover its Hamming space; it is not a perfect code.
