Lock-in harmonic rejection

 ... Physics Branches of physics Electromagnetism Electrical circuit Electronic amplifier Lock-in amplifier
OurBigBook.com Words: 261
Consider this original constructed input electric potential difference, with t in seconds and f0​=1Hz:
s(t)=(0.4V)cos(2πf0​t+π/3)+(0.9V)cos(6πf0​t+π/5).
(24)
The unwanted component has three times the reference frequency and more than twice the wanted peak amplitude. Nevertheless, the lock-in quadratures over T=4/f0​=4s are exactly
X=0.4cos(π/3)V=0.2V,Y=0.4sin(π/3)V=0.23​V≈0.34641016V,
(25)
so R=0.4V and atan2(Y,X)=π/3=60∘. This is a peak amplitude calculation, not an SR830 display prediction.
To see why the larger component vanishes, multiply Bcos(3ωt+ψ) by each reference:
2Bcos(3ωt+ψ)cosωt−2Bcos(3ωt+ψ)sinωt​=Bcos(2ωt+ψ)+Bcos(4ωt+ψ),=Bsin(2ωt+ψ)−Bsin(4ωt+ψ).​
(26)
Each sinusoid has zero average value of a function over a whole reference cycle. More generally, a component Bcos(nωt+ψ) with integer n≥2 gives products at (n−1)ω and (n+1)ω, whose integrals vanish over any integer number of reference cycles. This is the orthogonality behind selecting a Fourier coefficient with sinusoidal references. A nonsinusoidal reference can contain additional frequencies and need not have the same rejection property.
An unwanted component at the reference frequency survives. If u(t)=Bcos(ωt+ψ) is added to the input, its coordinate vector adds to the wanted one:
Z=Aeiϕ+Beiψ.
(27)
For example, adding B=0.1V with ψ=0 to the wanted component gives X=0.3V, Y=0.23​V, R=0.21​V≈0.458258V, and phase difference atan2(0.23​,0.3)≈49.1066∘. Longer averaging cannot separate these two synchronized contributions.
