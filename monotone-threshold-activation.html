Monotone threshold activation (v activates when ∣N(v)∩A∣≥tv​)

 Home Mathematics Area of mathematics Foundations of mathematics Graph theory Graph
OurBigBook.com Words: 228 Articles: 1
In a finite graph, start with an active vertex set A0​ and thresholds tv​. An inactive vertex becomes active once sufficiently many neighbours are active, and activated vertices remain active. Add eligible vertices until no more can be added. If C is any threshold-closed set containing A0​, induction shows every activated vertex lies in C. The terminal active set is itself closed, so it is the least such closure and is independent of the eligible-vertex processing order.
For integer thresholds, compute active-neighbour counts and keep a work queue of vertices newly reaching their thresholds. Each vertex is queued once and each edge is inspected a constant number of times, giving O(∣V∣+∣E∣) running time. Strict-majority activation has tv​=⌊deg(v)/2⌋+1, so an isolated inactive vertex never qualifies. A maximum priority queue of activation margins is an alternative implementation.
