Continuous extension

 ... Area of mathematics Analysis Real analysis Calculus Limit of a function Continuous function
OurBigBook.com Words: 43
A continuous extension of a function f:D→Y to a larger domain E⊇D is a continuous function F:E→Y satisfying F(x)=f(x) for x∈D. The domain and codomain carry specified topologies. Prescribing values on a dense subset does not by itself prove the existence of a continuous extension.
