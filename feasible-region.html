Feasible region (F)

 Home Mathematics Area of mathematics Mathematical optimization Feasible point
OurBigBook.com Words: 848 Articles: 3
The set of all feasible points of an optimization problem. It depends on the optimization constraints and the decision domain; the objective function ranks its members.
Think of three successive questions. Which decisions can be represented in the model? Which satisfy every optimization constraint? Which of those receive the best objective function value? For decisions z in a domain D, inequalities gi​(z)≤0 and equations hj​(z)=0 define the feasible region
F={z∈D:gi​(z)≤0 for every i, hj​(z)=0 for every j}.
(24)
The domain must be contained in the domain of a function for every function being evaluated; choosing integers rather than real numbers as decisions can also change the feasible set. Constraint satisfaction determines membership of F. Minimizing an objective function f then compares its members by f(z), with optimal value infz∈F​f(z). Changing the scores while keeping D and the optimization constraints fixed leaves F unchanged, provided the new objective function is defined throughout D. These distinctions separate an allowed decision from a best decision.[ref]
