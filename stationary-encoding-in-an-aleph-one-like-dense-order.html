Stationary encoding in an aleph-one-like dense order (LS​=∑α<ω1​​Bα​)

 ... Area of mathematics Foundations of mathematics Set theory Set Total order Aleph-one-like linear order
OurBigBook.com Words: 69
For a subset S of the nonzero countable limit ordinals, let Bα​=1+Q when α∈S and Bα​=Q otherwise. The order sum is an aleph-one-like linear order whose nonempty proper initial segments are Q or Q+1. At the limit cut before block δ, the complementary final segment has a least point exactly when δ∈S. Club agreement of countable filtrations makes this condition invariant modulo a nonstationary difference. Disjoint stationary subsets of omega-one consequently supply 2ℵ1​ nonisomorphic orders.
