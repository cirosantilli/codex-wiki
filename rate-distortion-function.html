Rate-distortion function (R(D))

 Home Mathematics Area of mathematics Probability and statistics Information theory Rate-distortion theory
OurBigBook.com Words: 1k Articles: 11
Fix a finite source alphabet X, a probability mass function pX​, a finite reconstruction alphabet X, and a nonnegative distortion measure d(x,x^). The information rate-distortion function is
R(D)=infpX∣X​:E[d(X,X)]≤D​I(X;X).
(95)
The source probability distribution stays fixed; the conditional distribution of the reconstruction is what we optimize. Each feasible test channel must keep expected distortion at most D. The objective is mutual information, measured in bits when the logarithms have base two. If no test channel satisfies the constraint, the infimum is +∞.[ref]
Consider independent and identically distributed fair bits and Hamming distortion, which charges one for an incorrect bit. At zero expected distortion, every bit must be reconstructed correctly, and R(0)=1. If an average fraction D=1/4 of incorrect bits is allowed, the binary rate-distortion function gives
R(1/4)=1−h2​(1/4)≈0.18872 bits per source symbol.​
(96)
Here h2​ is binary entropy. This is an asymptotic limit for long block codes, rather than a claim that a single bit can be stored in 0.18872 physical bits. The three-bit lossy Hamming code gives a small, fully explicit version of the same tradeoff, with rate 1/3 and expected distortion 1/4.
Rate-distortion theory separates the question of what is possible from the design of a practical encoder and decoder. It also forces the fidelity criterion to be explicit. Hamming distortion treats all symbol mismatches alike; mean squared error instead penalizes larger numerical errors more strongly. Those objectives can favor different reconstructions of the same data. An average error criterion does not by itself control the error on every individual input.
Claude Shannon's Coding Theorems for a Discrete Source With a Fidelity Criterion by Claude Shannon was published in 1959. Its formulation fixes a cost for replacing one source letter by another and studies the communication rate compatible with the allowed average cost. The important shift is to quantify which distinctions may be discarded, rather than requiring exact recovery of every letter.[ref]
