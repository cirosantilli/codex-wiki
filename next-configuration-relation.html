Next-configuration relation (C⊢M​C′)

 Home Computer science Theoretical computer science Turing machine Instantaneous description of a Turing machine
OurBigBook.com Words: 21
For a Turing machine, the one-step binary relation between Turing machine configurations specified by its Turing machine instructions. Its reflexive transitive closure ⊢M∗​ describes any finite number of computation steps, including zero.
