Process noise (wt​,Qt​=Cov(wt​))

 Home Mathematics Area of mathematics Control theory State estimation
OurBigBook.com Words: 45
Process noise is the random contribution to a state transition in a state-space model. It represents uncertainty in how the state evolves. Measurement noise instead affects the observed value of the state. In the local-level state-space model xt​=xt−1​+wt​, yt​=xt​+vt​, the first disturbance changes the state itself; the second changes its measurement.
