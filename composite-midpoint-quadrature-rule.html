Composite midpoint quadrature rule (Mn​(f)=h∑j=0n−1​f(a+(j+1/2)h))

Apply the midpoint quadrature rule on each of n equal panels of a partition of an interval, with h=(b−a)/n:
Mn​(f)=h∑j=0n−1​f(a+(j+21​)h).
(100)
Each quadrature node is a panel midpoint and each quadrature weight is h. For f∈C2[a,b], put K=maxx∈[a,b]​∣f′′(x)∣. Summing the panel quadrature errors gives
Mn​(f)−I(f)=−24b−a​h2f′′(ξ),∣Mn​(f)−I(f)∣≤24b−a​h2K
(101)
for some ξ∈(a,b). Each panel contributes at most Kh3/24; there are n=(b−a)/h panels, explaining the composite midpoint rule error of order O(h2) in big O notation. On a nonuniform partition of an interval with panel widths hj​ and largest width H, the corresponding bound is K∑j​hj3​/24≤K(b−a)H2/24.
For f(x)=x2 on [0,1], summing the sampled polynomial exactly yields
Mn​(f)=31​−12n21​.
(102)
Doubling n divides the absolute error by exactly four. For a general C2 function, halving h divides the displayed error bound by four, but the actual absolute error need not follow that ratio: cancellation can make it smaller or zero. Continuous functions still give convergence as the largest panel width tends to zero, by uniform continuity; without the bounded second derivative, the second-order rate is not guaranteed. Noise sensitivity of a quadrature rule explains a separate limitation when samples are inexact.
