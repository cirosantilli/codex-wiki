Weak definability of a numerical function (f(n)=m⟹S⊢D(nˉ,mˉ),S⊢¬D(nˉ,rˉ) (r=m))

A logical formula weakly defines a total numerical function in a first-order theory when, at every standard input tuple, it proves the graph instance with the correct standard output and refutes graph instances with every incorrect standard output. This is numeralwise representation of the graph; it does not yet assert uniqueness against nonstandard outputs inside a first-order model.
