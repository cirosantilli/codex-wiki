Zero and one have the same quantifier-free type in the multiplicative integers

 ... Foundations of mathematics Mathematical logic First-order logic First-order theory Partial type Quantifier-free type
OurBigBook.com Words: 84
In the constant-free language with multiplication as its sole nonlogical symbol, every term in one free variable is xk for some k≥1. Every atomic formula xr=xs holds at both zero and one. Hence every quantifier-free formula, being a finite Boolean combination of those atoms, has the same truth value at both points. They have the same quantifier-free type, and neither singleton is quantifier-free definable. Quantifiers distinguish them: ∀y(xy=x) defines zero, while ∀y(xy=y) defines one. These formulas do not rely on named zero or one constants.
