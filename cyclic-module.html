Cyclic module (M=Rm)

 Home Mathematics Area of mathematics Algebra Commutative algebra Module theory
OurBigBook.com Words: 227 Articles: 1
A module is cyclic if one element m generates it: every element is rm for some scalar r∈R. The generating element need not give unique coefficients. The module homomorphism R→M, r↦rm, is surjective. Over a commutative ring, its kernel is the annihilator AnnR​(m), giving
M≅R/AnnR​(m).
(25)
Thus cyclic modules are exactly the quotient modules R/I for ideals I in R. For a left module over a noncommutative ring, use a left ideal and interpret the quotient as a module, with no claim that it is a quotient ring. See John A. Beachy's Abstract Algebra Online, section 10.1.
The module Z/6Z is generated by 1, and also by 5, whose successive multiples are 0,5,4,3,2,1. The element 2 generates only {0,2,4}, a submodule with three elements. A cyclic module can be infinite and free, as Z=Z⋅1 shows, or finite and torsion, as Z/6Z shows. One generator counts directions of generation, not the number of elements and not freedom from relations.
