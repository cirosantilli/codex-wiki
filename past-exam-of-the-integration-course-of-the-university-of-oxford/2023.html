Writing L for the collection of Lebesgue measurable sets, saying that L is a sigma-algebra means that R∈L, that R∖A∈L whenever A∈L, and that ⋃n=1∞​An​∈L whenever every An​∈L. These properties also imply closure under countable intersections and differences.
A real-valued function f is a Lebesgue measurable function precisely when the inverse image of every Borel set is in L. Equivalently, it suffices to test the half-lines:
{x:f(x)>a}∈Lfor every a∈R.​
(1)
The equivalence follows because these half-lines generate the Borel sigma-algebra, and inverse images preserve complements and countable unions.

First suppose m(E)<∞. The interval-cover definition of Lebesgue outer measure, together with m∗(E)=m(E), provides bounded open intervals Ij​ covering E such that ∑j​∣Ij​∣<m(E)+ε. If the definition uses intervals that are not open, enlarge each by an amount whose total is smaller than the available error. The exact criterion is
m(E)<∞.​
(5)
Necessity follows already from one approximation with error less than one: a compact set K⊆R is bounded, hence has finite Lebesgue measure, so m(E)=m(K)+m(E∖K)<∞.
Conversely, suppose m(E)<∞. By continuity from above of a measure, the decreasing sets E∖[−N,N] have measures tending to zero. Choose N≥1 so that m(E∖[−N,N])<ε/2. Put B=[−N,N]∖E. By part (b)(i), there is an open set V⊇B with m(V∖B)<ε/2. Define
K=[−N,N]∖V.
(6)

(7)
The second term is at most m(V∖B). This proves the claimed inner regularity of Lebesgue measure with an arbitrarily small absolute error.

Minkowski inequality states that on a measure space (X,Σ,μ), for 1≤p≤∞ and measurable real or complex f,g of finite Lp norm,
∥f+g∥p​≤∥f∥p​+∥g∥p​.​
(25)
For p=1, integrate the scalar triangle inequality ∣f+g∣≤∣f∣+∣g∣. For p=∞, the almost everywhere bounds ∣f∣≤∥f∥∞​ and ∣g∣≤∥g∥∞​ give the same result by taking the essential supremum.
For 1<p<∞, first ensure that the left side is finite. The convex function s↦sp on [0,∞) gives
∣f+g∣p≤(∣f∣+∣g∣)p≤2p−1(∣f∣p+∣g∣p),
(26)
so f+g has finite Lp norm. Set q=p/(p−1) and H=∥f+g∥p​. Since (p−1)q=p, Holder inequality gives
Hp≤∫X​(∣f∣+∣g∣)∣f+g∣p−1dμ≤(∥f∥p​+∥g∥p​)(∫X​∣f+g∣pdμ)1/q=(∥f∥p​+∥g∥p​)Hp−1.
(27)
If H=0 the result is immediate; otherwise divide by Hp−1. This proves the triangle inequality for every claimed exponent.

Use Lebesgue measure restricted to the Lebesgue measurable set E. For 1≤p<∞, start with the measurable real-valued functions f on E satisfying ∫E​∣f∣pdm<∞. Define an equivalence relation by f∼g when f=g almost everywhere, and let Lp(E) consist of their equivalence classes. Addition and scalar multiplication are defined using representatives. The Lp norm is
∥[f]∥p​=(∫E​∣f∣pdm)1/p,1≤p<∞.​
(28)
For p=∞, use measurable functions bounded almost everywhere, apply the same identification, and define the L-infinity norm by
∥[f]∥∞​=x∈Eesssup​∣f(x)∣=inf{C≥0:m({x∈E:∣f(x)∣>C})=0}.​
(29)
These expressions are independent of the representative. For finite p, zero norm is equivalent to f=0 almost everywhere: each set {∣f∣>1/n} must have measure zero, and their union is {f=0}. The same implication follows from the essential supremum for p=∞. Absolute homogeneity is immediate; Minkowski inequality proves the triangle inequality and closure under addition. Thus these are normed vector spaces. Using complex-valued representatives gives their complex versions by the same construction.
