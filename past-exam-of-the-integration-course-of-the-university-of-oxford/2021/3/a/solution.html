Set C0​=[0,1]. Inductively, replace each component interval of Cn​ by its two closed end intervals, each of length ℓn+1​:=qn+1​/2n+1. The current component length is ℓn​=qn​/2n. Because qn+1​<qn​, the removed central gap has positive length
ℓn​−2ℓn+1​=2nqn​−qn+1​​.
(18)
This is a generalized Cantor set construction. The three required properties are checked in parts i, ii and iii.
The sets are closed, measurable, decreasing, and contained in [0,1], which has finite Lebesgue measure. By continuity from above of a measure,
m(C)=m(n=0⋂∞​Cn​)=n→∞lim​qn​.​
(19)
This limit exists because (qn​) is a bounded decreasing monotone sequence. To exclude a nondegenerate interval J⊆C, note that its connectedness forces it into a single component interval of every Cn​: crossing two components would cross a removed gap. Its length would therefore be at most 2−n for every n, which is impossible for a positive-length interval. Thus C contains no nondegenerate interval, even when its Lebesgue measure is positive.
