Use Lebesgue measure restricted to the Lebesgue measurable set E. For 1≤p<∞, start with the measurable real-valued functions f on E satisfying ∫E​∣f∣pdm<∞. Define an equivalence relation by f∼g when f=g almost everywhere, and let Lp(E) consist of their equivalence classes. Addition and scalar multiplication are defined using representatives. The Lp norm is
∥[f]∥p​=(∫E​∣f∣pdm)1/p,1≤p<∞.​
(28)
For p=∞, use measurable functions bounded almost everywhere, apply the same identification, and define the L-infinity norm by
∥[f]∥∞​=x∈Eesssup​∣f(x)∣=inf{C≥0:m({x∈E:∣f(x)∣>C})=0}.​
(29)
These expressions are independent of the representative. For finite p, zero norm is equivalent to f=0 almost everywhere: each set {∣f∣>1/n} must have measure zero, and their union is {f=0}. The same implication follows from the essential supremum for p=∞. Absolute homogeneity is immediate; Minkowski inequality proves the triangle inequality and closure under addition. Thus these are normed vector spaces. Using complex-valued representatives gives their complex versions by the same construction.
