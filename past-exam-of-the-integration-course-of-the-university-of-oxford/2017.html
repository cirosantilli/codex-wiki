If ∑n​m∗(An​)=∞, the required inequality is automatic. Otherwise each An​ has finite Lebesgue outer measure. Fix ε>0. By the defining infimum, for each n≥1 choose a countable interval cover {Jn,k​:k≥1} with
∑k≥1​∣Jn,k​∣<m∗(An​)+ε2−n.
(1)
The family indexed by (n,k)∈N2 is countable and covers ⋃n​An​. Since all lengths are nonnegative, its total length is at most ∑n​m∗(An​)+ε. Taking the infimum over covers of the union and then letting ε↓0 gives
m∗(n≥1⋃​An​)≤n≥1∑​m∗(An​).​
(2)
This proves countable subadditivity of Lebesgue outer measure directly from interval covers, without assuming that any An​ is measurable.

If the intervals Jk​ cover A, their translates Jk​+a cover A+a and have the same lengths. Every candidate total length in the definition of m∗(A) is therefore also a candidate for m∗(A+a). Taking infima gives m∗(A+a)≤m∗(A). Apply the same argument to A+a and the translation −a to obtain the reverse inequality. Hence
m∗(A+a)=m∗(A).​
(3)
This translation invariance of Lebesgue outer measure holds for every subset A, including non-measurable sets and sets of infinite outer measure.

A subset E⊆R is a Lebesgue measurable set when it satisfies Carathéodory's criterion: for every T⊆R,
m∗(T)=m∗(T∩E)+m∗(T∖E).
(4)
Suppose m∗(A)=0 and let B⊆A, allowing B=A. The monotonicity of Lebesgue outer measure follows directly from covers: every cover of a larger set covers a smaller set. Thus m∗(B)=m∗(T∩B)=0, while m∗(T∖B)≤m∗(T). Consequently
m∗(T∩B)+m∗(T∖B)≤m∗(T).
(5)
The reverse inequality is countable subadditivity of Lebesgue outer measure applied to T=(T∩B)∪(T∖B). Equality follows, even if m∗(T)=∞. Therefore A and every subset B⊆A are Lebesgue measurable sets of measure zero. This is the completeness of Lebesgue measure, obtained without presupposing measurability of the outer-null set.

For a Lebesgue measurable function f:R→R, the preimage f−1(U) of every open set U is a Lebesgue measurable set. For a Borel measurable function, each such preimage must instead be a Borel set. Equivalently, both definitions can test all Borel target sets: the collection
Cf​={B⊆R:f−1(B) belongs to the source sigma-algebra}
(6)
is a sigma-algebra, since preimages preserve complements and countable unions. Containing all open sets therefore makes it contain the Borel sigma-algebra.
Now let U be open. Since h is a Borel measurable function, h−1(U) is Borel. Since g is a Lebesgue measurable function, g−1(h−1(U)) is a Lebesgue measurable set. But
(h∘g)−1(U)=g−1(h−1(U)).
(7)
Thus h∘g is a Lebesgue measurable function. The intermediate sigma-algebra is Borel; this is why Borel postcomposition preserves Lebesgue measurability.

The dominated convergence theorem says that if measurable fn​ converge almost everywhere to f and ∣fn​∣≤H almost everywhere for a single Lebesgue integrable function H≥0, then f is integrable and
∫∣fn​−f∣⟶0,∫fn​⟶∫f.
(8)
Here, for x>0, put H0​(x)=x−1/2e−x and fn​(x)=H0​(x)(1−(−1)ne−nx). The exponential function gives e−nx→0 at every such x, so fn​→H0​. Also ∣fn​(x)∣≤2H0​(x). This dominator is integrable: on (0,1), H0​(x)≤x−1/2, whose integral is two; on [1,∞), H0​(x)≤e−x, whose integral is finite. DCT therefore proves the required limit.
The limiting value can also be evaluated. Substitute x=t2 and use the Gaussian integral:
n→∞lim​∫0∞​fn​(x)dx=∫0∞​x−1/2e−xdx=π​.​
(9)
In fact, scaling the second exponential term gives the exact integral π​[1−(−1)n/n+1​]. The integral error decays as n−1/2 despite exponential convergence at each fixed positive x; the slow part lies near the endpoint zero.

Let ϕ:I→J be a C1 diffeomorphism between intervals, which may be unbounded. For a nonnegative Lebesgue measurable function f on J, Lebesgue substitution on an interval gives
∫J​f(y)dy=∫I​f(ϕ(x))∣ϕ′(x)∣dx,​
(10)
allowing the value infinity. The same identity applied to ∣f∣ shows that f is Lebesgue integrable exactly when the transformed integrand is integrable; in that case the displayed formula holds for signed or complex f as well. The absolute value on the derivative makes the formula valid for both increasing and decreasing substitutions. Finite endpoints can be omitted without changing a Lebesgue integral, because individual points are null sets.

The monotone convergence theorem states that, for nonnegative measurable fn​ on a Lebesgue measurable set E with fn​↑f almost everywhere,
∫E​fn​↑∫E​f,
(14)
allowing infinity. Fatou's lemma states that, for nonnegative measurable fn​,
∫E​liminfn​fn​≤liminfn​∫E​fn​.
(15)
Now write C=supn​∫E​∣gn​∣<∞. A pointwise limit superior of measurable functions is measurable, and it agrees with g off the exceptional null set. By completeness of Lebesgue measure, assigning any values on that null set preserves measurability. Therefore g is measurable. Since ∣gn​∣→∣g∣ almost everywhere, Fatou's lemma gives
∫E​∣g∣≤nliminf​∫E​∣gn​∣≤C<∞.​
(16)
Thus g is finite almost everywhere and is a Lebesgue integrable function. This is an almost-everywhere limit under a uniform L1 bound. The argument proves integrability of the limit, not convergence in L1 space.

A sufficient theorem is dominated differentiation under the integral sign. Let t0​ be interior to a parameter interval, suppose u(⋅,t) is measurable for each t, and suppose u(⋅,t0​) is integrable. Assume u(x,⋅) is differentiable near t0​ for x outside one fixed null set, and that throughout this neighborhood
∣∂t​u(x,t)∣≤H(x)
(26)
for one nonnegative Lebesgue integrable function H. Then F(t)=∫E​u(x,t)dx is defined near t0​, is differentiable at t0​, and
F′(t0​)=∫E​∂t​u(x,t0​)dx.​
(27)
Indeed the mean value theorem bounds both ∣u(x,t)−u(x,t0​)∣ by ∣t−t0​∣H(x) and the difference quotient by H(x). The first bound proves local integrability; the second lets the dominated convergence theorem pass the limit of difference quotients through the integral.

i OurBigBook.com
On sigma-finite measure spaces, including the real line with Lebesgue measure, Tonelli's theorem says that a nonnegative measurable function H has equal product and iterated integrals:
∫X×Y​Hd(μ×ν)=∫X​(∫Y​H(x,y)dν(y))dμ(x)=∫Y​(∫X​H(x,y)dμ(x))dν(y),
(33)
with infinity allowed. Finiteness is not a prerequisite.
Fubini's theorem says that if a measurable signed or complex H is absolutely integrable on the product, then its sections are integrable for almost every value of the other variable, the iterated integral functions are integrable, and the same equalities hold with finite values. For completed Lebesgue measure, exceptional sections need not themselves be measurable; the integrals use the almost-everywhere defined sections. Thus Tonelli can first establish absolute integrability using ∣H∣, after which Fubini permits changing the order for H.

Because f is continuous, g(x,y)=e−x2f(e−x2/2y) is continuous on R2, so ∣g∣ is a nonnegative measurable function. Apply Tonelli's theorem before assuming integrability. For each fixed x, set z=e−x2/2y, so dy=ex2/2dz. Lebesgue substitution on an interval gives
∫R​∣g(x,y)∣dy=e−x2/2∫R​∣f(z)∣dz.
(34)
Therefore the Gaussian integral yields
∬R2​∣g(x,y)∣dxdy=2π​∫R​∣f(z)∣dz<∞.​
(35)
This proves that g is Lebesgue integrable on R2. Fubini's theorem now permits changing the order for g itself. The same substitution without absolute values gives the stronger exact identity
∫R​∫R​g(x,y)dxdy=2π​∫R​f(z)dz.
(36)
Taking absolute values and using the triangle inequality for an integral proves
​∫R​∫R​g(x,y)dxdy​≤2π​∫R​∣f(z)∣dz.​
(37)
The constant is sharp: any nonzero nonnegative continuous integrable f gives equality. This is a weighted dilation kernel with a(x)=e−x2 and b(x)=e−x2/2. The inner x integral in the requested order is guaranteed to be integrable for almost every y, which is all the iterated integral requires.
