Stable model reduct (KI)

 Home Computer science Logic programming Datalog Datalog with negation Stable model semantics
OurBigBook.com Words: 35
Ground the rules, delete every rule having a negative body atom true in the candidate I, and remove all remaining negative premises. The result is a positive program whose least Herbrand model is compared with I.
