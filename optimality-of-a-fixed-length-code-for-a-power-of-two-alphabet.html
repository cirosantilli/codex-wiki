Optimality of a fixed-length code for a power-of-two alphabet

 ... Mathematics Area of mathematics Probability and statistics Information theory Huffman coding Optimal prefix code
OurBigBook.com Words: 207
For a strictly positive probability distribution on 2n source symbols, with n>1, every optimal binary prefix code has common length n if and only if px​+py​>pz​ for every three distinct symbols. It suffices to compare the sum of the two smallest probabilities with the largest.
An optimal binary prefix tree has no node with only one child, because removing that detour would strictly shorten positive-probability words. It therefore satisfies equality in the Kraft inequality. If it is not a fixed-length tree, it has a deepest sibling pair at depth L>n and a short leaf at depth ℓ<n. Exchanging that pair with the short leaf changes the expected codeword length by (L−ℓ−1)(pz​−px​−py​). Strict positivity of every pair sum over a third probability makes this change negative, contradicting optimality.
Conversely, if px​+py​≤pz​, begin with the complete depth-n tree, place x,y at sibling leaves, replace their parent by z, and replace the previous z leaf by children x,y. The new expected length is n+px​+py​−pz​≤n and its lengths are unequal. If the optimum is below n, every optimal tree is nonuniform; if it is n, this modified tree is a nonuniform optimum. Thus equality in the probability condition already defeats the assertion that every optimum has fixed length.
