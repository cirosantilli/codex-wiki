For a finite set F⊆I and open sets Ui​⊆Xi​ for i∈F, the sets
B(F,U)=⋂i∈F​πi−1​(Ui​)=∏i∈I​Vi​,Vi​={Ui​Xi​​i∈F,i∈/F​
(57)
form a basis of a topology for the product topology. The empty set intersection is X. Each basic open set is a cylinder set; all coordinates outside F are free. Arbitrary open sets are unions of these basic tests and need not themselves depend on one fixed finite collection of coordinates.[ref]
Why finitely many? Any topology making the projection maps continuous must contain their preimages of open sets, and hence finite set intersections of those preimages. Taking arbitrary unions supplies exactly the product topology. Intersecting two basic cylinder sets still restricts only the finite union of their coordinate sets.
