Marginal increment of a set function (Δx​f(S)=f(S∪{x})−f(S))

 ... Mathematics Area of mathematics Foundations of mathematics Set theory Function Set function
OurBigBook.com Words: 48
The marginal increment measures how much a set function changes when one new element is added. Usually x∈/S is required; if x∈S, the displayed difference is zero. The marginal increments of a modular set function depend only on x. The marginal increments of a submodular set function can only decrease as the input subset grows without acquiring x.
