Subtyping (S<:T)

 Home Computer science Programming language Type system
OurBigBook.com Words: 378 Articles: 6
A relationship in which values of one type can be used wherever values of a broader type are required, subject to the language's compatibility rules. In nominal object-oriented programming, extending a class or implementing a trait establishes relevant subtype relationships. Type variance describes how these relationships lift through parameterized types.
