Vector order parameter (p)

 Home Physics Branches of physics Statistical physics Critical phenomenon Order parameter
OurBigBook.com Words: 31
A vector order parameter has several components transforming together as a vector under spatial rotations. A polar order parameter is an example. Its functional derivative δF/δp has one component for each component of the order parameter.
