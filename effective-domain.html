Effective domain (domE)

 Home Mathematics Area of mathematics Analysis Real analysis Proper extended-real function
OurBigBook.com Words: 18
The effective domain of an extended-real function is domE={u:E(u)<+∞}. An infinite value can impose a hard constraint through an indicator functional of a constraint set.
