Permutation (σ:S→S bijective)

 Home Mathematics Area of mathematics Combinatorics
OurBigBook.com Words: 2k Articles: 27
A permutation of a set S is a bijection σ:S→S: every element has exactly one image and every element appears exactly once as an image. For a finite set, a permutation can also be recorded as an ordering of all its elements, once a reference order has been chosen. For three distinct letters A,B,C, the six orderings are
ABC,ACB,BAC,BCA,CAB,CBA.
(65)
There are three choices for the first letter, two unused letters for the second, and one for the third. Every path in the tree gives one complete ordering, and every ordering has one such path, so the rule of product gives 3⋅2⋅1=3!=6, a factorial.
Ordering versus mapping. Label the reference positions 1,…,n. An ordering tuple (a1​,…,an​) of these labels describes the function σ(i)=ai​; conversely, reading the images σ(1),…,σ(n) recovers the ordering. For example,
σ=(13​21​34​42​)
(66)
means 1↦3, 2↦1, 3↦4, 4↦2. Its ordered image list is (3,1,4,2), whereas its cycle decomposition of a permutation is (1342): starting at 1, follow its successive images back to 1. Parentheses in the latter expression encode arrows around a permutation cycle, rather than an image list in reference order. [ref]
The two viewpoints answer different useful questions about the same object. An ordering tells us which object occupies each position; a bijection tells us where each label is sent and allows successive rearrangements through function composition. All permutations of n labels form the symmetric group, whose subgroups are permutation groups. The counting viewpoint supplies n! possibilities, a factorial; the mapping viewpoint reveals how rearrangements combine.
Composition convention. Apply the rightmost permutation first:
(στ)(i)=σ(τ(i)).
(67)
For the displayed σ=(1342) and the transposition τ=(12), direct evaluation gives
στ=(11​23​34​42​)=(234),τσ=(13​22​34​41​)=(134).
(68)
For instance, (στ)(1)=σ(2)=1, but (τσ)(1)=τ(3)=3. Thus function composition of permutations need not be commutative; the omitted labels in these permutation cycles are fixed points.
