Elliptic boundary value problem

 Home Mathematics Area of mathematics Analysis Partial differential equation
OurBigBook.com Words: 1k Articles: 28
An elliptic boundary value problem couples an elliptic differential equation in a domain to boundary conditions. Its weak formulation is often an equation for a bounded bilinear form on a Sobolev space.
