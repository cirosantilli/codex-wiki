Independent repetition of a polynomial identity test (pk​=p1k​≤(d/∣S∣)k(d<∣S∣))

 Home Computer science Algorithm Randomized algorithm Polynomial identity testing
OurBigBook.com Words: 258
Repeat the random evaluation test for a polynomial identity with fresh independent random variables, keeping the same fixed polynomial. Reject as soon as any polynomial evaluation is nonzero; accept only if all k values vanish. An identity is always accepted, preserving one-sided error. If a nonzero polynomial has single-trial false acceptance probability p1​, independence gives pk​=p1k​. The Schwartz-Zippel lemma bounds this by (d/∣S∣)k when d<∣S∣.
For G(x)=(x−1)(x−2) over the finite field F5​, two uniform independent choices (a,b) have 25 equally likely ordered outcomes, each with probability 1/25. Both polynomial evaluations are zero only at (1,1),(1,2),(2,1),(2,2). Hence false acceptance falls from 2/5 in one trial to 4/25 in two trials, and correct rejection rises from 3/5 to 21/25.
If the second choice reuses the first, the pair is (a,a) and only five diagonal outcomes are possible. Two still falsely accept, so the error remains 2/5. Choosing fresh independent points is precisely what makes the full 25-cell grid and the product of probabilities valid. For a target error 0<ε<1, this example needs
k≥⌈log(5/2)log(1/ε)​⌉.
(65)
The ceiling function makes the trial count an integer. Four trials give (2/5)4=16/625>1/100, while six give 64/15625<1/100; five still give 32/3125>1/100, so six is the first count below one percent. This is an exact error guarantee for each run on G, rather than an observed success rate.
