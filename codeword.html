Codeword (c∈C)

 Home Mathematics Area of mathematics Algebra Coding theory
OurBigBook.com Words: 73 Articles: 1
A codeword is a member of the specified set of words used to encode messages. For a linear code specified by a parity-check matrix H, the codewords are precisely the vectors satisfying Hc=0. The minimum distance between distinct codewords controls error correction.
