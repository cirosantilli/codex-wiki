Sign extension (sextm→w​(b))

 Home Computer science Programming language Two's complement
OurBigBook.com Words: 54
To widen an m-bit two's complement integer to w>m bits, preserve the original low bits and fill the new high positions with the old sign bit s. The change in signed positional weights is −s2w−1+s∑i=m−1w−2​2i=−s2m−1, so the represented signed value is unchanged. Zero extension instead preserves the unsigned interpretation, and changes the signed value of negative inputs.
