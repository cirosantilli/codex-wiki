Implicit solution (F(x,y)=C)

 Home Mathematics Area of mathematics Analysis Differential equation Ordinary differential equation
OurBigBook.com Words: 510
An implicit solution describes a solution of a differential equation through a relation F(x,y)=C, instead of isolating y in an explicit formula. The relation describes a level set; an actual scalar solution of a differential equation must be a differentiable function y(x) on an interval whose function graph lies in the equation's domain. A whole level set need not be one such function graph.
For example, consider
y′=−yx​,D={(x,y):y=0}.
(5)
Implicit differentiation of x2+y2=C gives 2x+2yy′=0. For C>0, the circle contains two solutions of a differential equation,
y+​(x)=C−x2​,y−​(x)=−C−x2​,−C​<x<C​.
(6)
Both satisfy the equation on the stated open interval, and their function graphs stay in D. An initial condition (x0​,y0​)∈D fixes C=x02​+y02​ and selects the sign of y0​. In particular, y(0)=2 gives C=4 and the upper branch on (−2,2). The constant alone does not select the branch.[ref]
The precise local criterion uses the implicit function theorem. Let F be continuously differentiable on an open subset of the plane, with F(x0​,y0​)=C. If its partial derivative Fy​(x0​,y0​)=0, the nearby level set is a unique continuously differentiable function graph y=g(x) through that point. The chain rule gives
Fx​(x,g(x))+Fy​(x,g(x))g′(x)=0,g′(x)=−Fy​(x,g(x))Fx​(x,g(x))​.
(7)
This proves that the local function graph solves y′=−Fx​/Fy​ there. For a different prescribed equation y′=f(x,y), one must also check Fx​+Fy​f=0 along that branch and that it stays in the domain of f. A level set by itself does not verify an arbitrary ordinary differential equation.[ref]
For F=x2+y2, the upper branch through (1,3​) has Fy​=23​ and tangent line slope −1/3​. At (2,0), however, Fy​=0 and Fx​=4. The circle remains a smooth regular level set with a vertical tangent line: it can be written locally as x=4−y2​, but not as a single function graph y=g(x) over an open interval containing 2. Moreover, −x/y is undefined there, so the scalar solution of a differential equation cannot include this point in its domain. Changing the parameter draws the curve through the point but does not extend that scalar initial value problem.
When both partial derivatives vanish, even the geometry needs separate inspection. The level x2+y2=0 is an isolated point, not a function graph on any nonempty open interval. The zero level set of G(x,y)=y2−x2 instead consists of the two lines y=x and y=−x crossing at the origin, where ∇G=0. Each line satisfies the implicit ordinary differential equation yy′=x, including at the origin; the explicit form y′=x/y excludes the origin. Thus algebraically dividing by a vanishing coefficient changes the domain and can change which solutions of a differential equation are admissible. Vanishing Fy​ alone is only failure of a sufficient test: F(x,y)=y3 has the smooth zero function graph y=0 despite Fy​=0 everywhere on it.
Implicit solutions are especially useful for exact first-order ordinary differential equations and for finding a first integral of an ordinary differential equation: a conserved relation can reveal allowed states without an explicit formula. For the normalized harmonic oscillator written as x˙=y, y˙​=−x, the energy H=(x2+y2)/2 has H˙=xx˙+yy˙​=0. Its positive level sets are the same circles. Where y=0, eliminating time gives dy/dx=−x/y and the local implicit solution above. The harmonic oscillator's parametric curve continues through y=0 because its vector field governing evolution in time is defined there; treating x as the independent variable fails at that turn. The origin is an equilibrium point of the harmonic oscillator, although it is excluded from the scalar equation y′=−x/y.
