Hypergeometric distribution (K∼Hypergeom(n,c,r))

 ... Mathematics Area of mathematics Probability and statistics Probability theory Probability distribution Discrete probability distribution
OurBigBook.com Words: 800 Articles: 2
The hypergeometric distribution counts marked objects in a uniformly chosen sample of fixed size from a finite population, using sampling without replacement. Let n≥1 be the population size, let 0≤c≤n objects be marked, and sample 0≤r≤n distinct objects. If K counts the marked objects selected, its probability mass function is
P(K=k)=(rn​)(kc​)(r−kn−c​)​,max(0,r−(n−c))≤k≤min(c,r).
(49)
The bounds describe the support of a probability distribution and k must be an integer; the mass is zero elsewhere. The denominator counts all size-r subsets, while the numerator counts choices of k marked and r−k unmarked objects using binomial coefficients. This counting argument requires every size-r sample to have the same probability.[ref]
For a constructed example, a box contains ten labelled objects, four red and six blue. Select five without replacement. There are (510​)=252 possible samples. The probabilities for K=0,1,2,3,4 are
421​,215​,2110​,215​,421​.
(50)
In particular, P(K=2)=(24​)(36​)/252=120/252=10/21. Five red objects are impossible because the box only contains four. The expected value is r(c/n)=2, and the variance is 2/3.
The count law also answers a detection question: what is the chance that five draws find at least one red object? By the complement rule of probability, it is 1−P(K=0)=41/42, approximately 0.9762. This can model inspecting five distinct objects from a known finite collection, with a mark indicating the property we want to detect. If repeated inspections can select the same object again, the replacement model instead gives 1−0.65=0.92224. Equal expected values therefore do not imply equal chances of detecting a marked object.
The corresponding binomial distribution counts red draws when each selected object is put back before the next independent draw: Krep​∼Bin(5,0.4). It has the same expected value 2, but variance 5(0.4)(0.6)=6/5, and it permits five red draws. Without replacement, a red first draw leaves red probability 3/9 for the next draw; a blue first draw leaves 4/9. This statistical dependence pulls the total toward the fixed composition of the population, producing the finite population correction.
The useful modelling question is whether previously selected objects remain available. A fixed-size sample of distinct items calls for a hypergeometric distribution; fresh independent trials with constant success probability call for a binomial distribution. When the population grows with c/n→p while r stays fixed, the hypergeometric masses tend to the corresponding binomial distribution masses: removing finitely many objects has an increasingly small effect on the next draw's probability.
