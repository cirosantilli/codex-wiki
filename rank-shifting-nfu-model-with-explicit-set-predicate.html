Rank-shifting NFU model with explicit set predicate (S(y)⟺j(y)⊆D,xEy⟺S(y)∧x∈j(y))

 ... Foundations of mathematics Set theory New Foundations New Foundations with urelements Type-shifting automorphism Rank-shifting automorphism construction of NFU
OurBigBook.com Words: 1k Articles: 1
Let M be a membership structure satisfying extensionality and every pure-membership separation instance, with an external automorphism j and domains Di​=ji(D0​) represented by objects of M. Suppose every M-subset of Di​ is an element of Di+1​. Interpret NFU on the objects of D0​ using the displayed set predicate and membership, with all subset statements evaluated in M. Atoms have no members, and extensionality applied to j(y),j(z)⊆D0​ gives extensionality for sets. A stratified formula becomes an ordinary pure-membership formula by sending each variable of type i to ji(x) and restricting its quantifier to Di​. A set predicate on sort i means containment in Di−1​; adjacent-sort membership is guarded by containment in the lower domain. Separation yields the extension X⊆Di​, the closure hypothesis places it in Di+1​, and j−(i+1)(X)∈D0​ is the required untyped set. This proves every comprehension instance. The guard is essential: an object not contained in a lower domain can still have some ordinary members there, which must not become members of a typed atom. Internal ranks Vji(α)​ with j(α)>α give one instance of these hypotheses; shifted rank objects in an elementary model of an expanded Vω+ω​ give a consistency proof without assuming Con(ZFC).
