Completely multiplicative function (f(1)=1,f(mn)=f(m)f(n) for all m,n>0)

 Home Mathematics Area of mathematics Number theory Arithmetic function Multiplicative function
OurBigBook.com Words: 44
An arithmetic function f is a completely multiplicative function when f(1)=1 and f(mn)=f(m)f(n) for every pair of positive integers m,n. In particular f(pa)=f(p)a for every prime number p and every nonnegative exponent a. Both the constant-one arithmetic function and the identity arithmetic function are completely multiplicative functions: 1(mn)=1=1⋅1 and id(mn)=mn=id(m)id(n). The divisor function fails this stronger condition at m=n=2.
