Function (f:X→Y)

 Home Mathematics Area of mathematics Foundations of mathematics Set theory
OurBigBook.com Words: 5k Articles: 75
A function f:X→Y assigns exactly one output in the specified codomain Y to each input in its domain of a function X. Its rule may be a formula, a finite table, or another unambiguous assignment. The outputs actually reached form its image of a function f(X)⊆Y. A codomain states where outputs are allowed; the image of a function records where they actually land. Oscar Levin's introduction makes this distinction explicit. [ref].
For example, f:R→R, f(x)=x2, has the entire real line as its domain of a function and codomain, but its image of a function is [0,∞). Both −2 and 2 give the output 4: several inputs sharing an output is permitted. Assigning two distinct outputs to one input is not permitted. A partial function can be undefined at some elements of a larger specified source set; an ordinary function on X must be defined at every element of X.
Three properties describe how a function uses its target. An injective function never sends distinct inputs to the same output. A surjective function reaches every member of its specified codomain. A bijection does both, pairing each source element with exactly one target element. These are different requirements, as finite arrow diagrams show.
The chosen codomain matters even when the formula does not change. The function x↦x2 from R to R is not surjective, whereas the same rule from R to [0,∞) is surjective. Both fail injectivity. Further restricting the domain of a function to [0,∞) makes it a bijection onto [0,∞), with square root as its inverse function.
Functions make transformations composable: if f:X→Y and g:Y→Z, their function composition is (g∘f)(x)=g(f(x)). Identifying each intermediate codomain prevents attempting to feed an output into a rule that is not defined there. When a transformation is a bijection, an inverse function recovers the original input without ambiguity. This is useful whenever information must be transported or a calculation reversed.

Scalar-valued function (f:X→F)

Function OurBigBook.com
A scalar-valued function is a function whose codomain is a field, typically the real numbers or complex numbers. Its output is a single scalar, while its input can belong to an arbitrary set. For example, the square of the norm of a vector is real-valued. In a relativistic application, being scalar-valued alone does not establish Lorentz invariance: the transformation of the input and of the complete quantity must also be specified.

Implicit function

Words: 95
Function OurBigBook.com
An implicit function is a function specified through a relation between its input and output, rather than an explicit output formula. Locally, an equation F(x,y)=0 may specify y=g(x) if one output y is selected for each input x in a suitable domain. Different branches can define different functions; the relation itself need not give a unique output globally. For example, x2+y2=1 gives the two branches y=±1−x2​ on −1<x<1.
The implicit function theorem gives sufficient conditions for a unique local differentiable branch, while implicit differentiation computes its derivative by the chain rule. If F is continuously differentiable and Fy​=0, that derivative is g′(x)=−Fx​/Fy​ along the branch.

Function composition (∘)

Words: 86
Function OurBigBook.com
For functions f:X→Y and g:Y→Z, their function composition is g∘f:X→Z, defined by (g∘f)(x)=g(f(x)). The rightmost function is applied first. Matching the intermediate codomain and domain of a function makes the expression well-defined.
For self-maps of the real numbers, take f(x)=x+1 and g(x)=2x. Then (g∘f)(x)=2x+2, whereas (f∘g)(x)=2x+1. Thus function composition need not be commutative. It does have the associative property: both (h∘g)∘f and h∘(g∘f) evaluate to h(g(f(x))) whenever each intermediate codomain matches the next domain of a function. The identity function leaves composition unchanged, making self-maps particularly useful as a monoid of transformations.

Germ (mathematics, [f]x​)

Function OurBigBook.com
A germ at a point is an equivalence class of functions defined on a neighbourhood of the point: two representatives are equivalent if they agree on some smaller neighbourhood. A germ of a holomorphic function requires its representatives to be holomorphic functions; smooth and continuous germs use their corresponding classes of functions. The germ retains local behavior while forgetting the representative's values farther from the point.

Finite modification of the identity on the real line (∣{x:f(x)=x}∣<∞)

Function OurBigBook.com
A finite modification agrees with the identity map outside a finite exceptional set. Sorting that set gives a unique finite record of pairs (x,f(x)). Real-number pairing by separated digits encodes the record in (0,1), and placing length-n records in disjoint intervals (n,n+1) gives an injection from all finite modifications into the real line. Conversely, changing the value at one fixed point gives a real-parameter family, so the Cantor-Schröder-Bernstein theorem shows this family has continuum cardinality.

Pointwise periodic self-map (∀x ∃nx​≥1: fnx​(x)=x)

Words: 162 Articles: 1
Function OurBigBook.com
A pointwise periodic self-map returns each point to itself after a positive number of iterates which may depend on the point. It is a bijection: each finite cycle supplies predecessors; equality of two images can be undone by an iterate with an exponent one below a common multiple of the two periods. The set consequently decomposes into disjoint finite permutation cycles. Pointwise periodicity does not imply that one iterate is the identity on an infinite set.

Uniform period criterion for pointwise periodic maps (fN=id⟺all cycle lengths divide N)

Words: 88
Pointwise periodic self-map OurBigBook.com
A pointwise periodic self-map has a uniform positive period exactly when its finite cycle lengths are bounded. A uniform period is divisible by every length; conversely, bounded lengths divide the least common multiple of 1,…,M for some bound M. Arbitrarily many bounded-length cycles are allowed. Every such map on a finite set has a uniform period. On any infinite set containing a countably infinite subset, cycles of unbounded finite lengths and fixed points elsewhere give a counterexample. Thus, with the usual axiom of choice assumption, the sets on which every pointwise periodic self-map has a uniform period are exactly finite sets.

Function collision (x=x′,f(x)=f(x′))

Words: 138
Function OurBigBook.com
A function collision is a pair of distinct inputs x=x′ with f(x)=f(x′). An injective function has no collisions. For a two-to-one function every nonempty fiber has two elements and hence one unordered collision pair. Finding such a pair through an oracle is the task of quantum collision finding.
In the finite example under image and preimage of a function, the pair {a,b} is a function collision: both inputs give zero. The function retains their shared output but loses the distinction between them. If a finite set has more inputs than the number of available outputs, the pigeonhole principle forces a function collision. Equal source and target cardinalities alone do not prevent one.
For a finite function, let my​ be the cardinality of its fiber of a function over y. The number of unordered function collisions is ∑y​(2my​​), because each pair must lie in one common fiber. The example's nonempty fiber sizes are 2,1,1, giving exactly one collision pair.

Fiber of a function (f−1(y))

Words: 420 Articles: 1
Function OurBigBook.com
For a function f:X→Y and y∈Y, its fiber of a function over y is the set of all inputs producing that one output:
f−1(y)=f−1({y})={x∈X:f(x)=y}.
(1)
Here f−1(y) is shorthand for a preimage of a singleton set, rather than a claim that an inverse function exists. A fiber can contain several inputs or be empty. It describes exactly which distinctions the function forgets.
For the finite function under image and preimage of a function, the fibers over 0,1,2,3 are {a,b}, {c}, {d} and the empty set, respectively. The nonempty fibers form a partition of a set: they are disjoint sets whose union is the domain of a function. Every input belongs to the fiber over its unique output, and two fibers with distinct output labels cannot share an input. A function is injective exactly when every fiber has at most one member; it is surjective exactly when every member of its specified codomain has a nonempty fiber.
More generally, f−1(U) is the union of the fibers over all y∈U. The relation x∼x′ defined by f(x)=f(x′) is an equivalence relation, and its equivalence classes are precisely the nonempty fibers. The resulting quotient set is naturally in bijection with the image of a function. This links an input partition to the output values actually reached, without choosing one representative from each class.
Fibers are useful when an output is known but the input is not uniquely determined. A solution set g−1({0}) is one fiber, and factorization through a surjection explains when another function depends only on the retained output. Quantum hidden subgroup problem algorithms use functions whose fibers are cosets, giving the same idea a structured form in group theory.

Factorization through a surjection (g=h∘f)

Words: 174
Fiber of a function OurBigBook.com
For a surjective function f:B→A and a function g:B→C, there is a unique function h:A→C with g=h∘f if and only if g is constant on each fiber of a function of f. Define h(a) to be the common value on f−1(a); it is well-defined and unique because that fiber is nonempty. This uniquely specified value requires no simultaneous arbitrary choices.
For a concrete example, restrict the codomain of the finite function above to its image of a function I={0,1,2}, making f:A→I surjective. Define g(a)=g(b)=5, g(c)=7 and g(d)=9. Then h(y)=2y+5 on I gives g=h∘f: knowing the output of f is enough to compute g. If instead g(a)=g(b), no such h can exist, because h(f(a))=h(f(b)) must be the same value.
The surjectivity assumption supplies uniqueness on the full target. If the original unused target value three were retained, the factorization would impose no condition on h(3), and different extensions could agree on every actual input. Thus factorization through a surjection formalizes when a compressed description retains all information needed for a later calculation.

Inverse function (f−1)

Words: 613 Articles: 5
Function OurBigBook.com
An inverse function reverses a bijection. For f:X→Y, it is a function g:Y→X satisfying
g∘f=idX​,f∘g=idY​.
(3)
Equivalently, g(f(x))=x for all x∈X and f(g(y))=y for all y∈Y. We write g=f−1. The superscript denotes reversal through function composition; it does not mean the pointwise multiplicative inverse 1/f(x). The preimage notation f−1(B) for a set B is also distinct: a preimage exists even when no inverse function exists.
For a computed example, let f:R→R be f(x)=2x+1. Solving y=2x+1 for x gives g(y)=(y−1)/2. Thus f(1)=3 and g(3)=1; direct substitution gives g(f(x))=x and f(g(y))=y throughout the real line. In contrast, 1/f(3)=1/7, which does not undo f(1)=3.
Why must f be a bijection? If f(x1​)=f(x2​), applying g gives x1​=x2​, proving injectivity. For any y∈Y, the equation f(g(y))=y supplies a source element, proving surjectivity. Conversely, a bijection supplies exactly one predecessor for each y, defining a unique inverse function. A left inverse or right inverse requires only one of the two composition identities.
For f(x)=x2 on the real line, the equation f(x)=4 has two solutions, x=±2, so its arrows cannot be reversed as one function on all inputs. The restriction to [0,∞) removes that ambiguity. As a bijection from [0,∞) onto [0,∞), it has inverse function g(y)=y​. The identity x2​=∣x∣ explains why x2​=x works on the restricted domain of a function but fails for negative x. [ref].
More generally, (a,b) lies on the graph of a function f precisely when (b,a) lies on the graph of a function of its inverse function. This coordinate swap explains the geometric reflection and the horizontal line test. It also explains why inverse sensitivity is reciprocal locally: the inverse function rule divides by the original derivative at the corresponding input, when that derivative is nonzero.

Horizontal line test

For a real-valued function drawn in the plane, the horizontal line test asks whether every horizontal line intersects its function graph at most once. Periodic function (f(x+T)=f(x))

Function OurBigBook.com
A periodic function repeats exactly after a nonzero shift of its input. For f:R→Y, a positive period of a function T satisfies
f(x+T)=f(x)for every x∈R.​
(6)
One interval of length T therefore determines the whole function. For another domain of a function D, a period must also preserve the domain, D+T=D; equality only where two domains happen to overlap is weaker. Periodicity is an exact translation of a function symmetry, rather than merely two similar-looking pieces of its graph.
The sine sin(2πx) has fundamental period one. The function sin2(2πx) repeats after half a unit: the sine changes sign under that shift, but squaring removes the sign. The mixed function g(x)=2+sin(2πx)+21​cos(4πx) again has fundamental period one. All positive integer multiples of a period are periods, so specifying one period need not identify the shortest repetition.
If the input is time and T0​ is the fundamental period, the frequency is 1/T0​ and the angular frequency is 2π/T0​. Repetition lets a Fourier series describe a cycle using sines and cosines; the period average separates the reference level from the oscillating terms. Strang develops this representation and its Fourier coefficients in §4.1 of Computational Science and Engineering by Gilbert Strang.[ref]
This connection grew out of a physical problem. In his 1822 book Théorie analytique de la chaleur by Joseph Fourier, Joseph Fourier used periodic functions to extend profiles beyond their initial interval while treating heat conduction. Chapter III, §§233–234 combines even functions and odd functions into sine–cosine expansions and rescales their period.[ref] A modern Fourier series interpretation still requires the appropriate convergence conditions.
A constant function has every real shift as a period and no fundamental period. Without continuity, even a nonconstant periodic function can lack a smallest positive period; periodic function without a least positive period gives a concrete example. The period group of a function organizes all these possibilities.
