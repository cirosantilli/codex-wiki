Germ (mathematics, [f]x​)

Words: 54
Function OurBigBook.com
A germ at a point is an equivalence class of functions defined on a neighbourhood of the point: two representatives are equivalent if they agree on some smaller neighbourhood. A germ of a holomorphic function requires its representatives to be holomorphic functions; smooth and continuous germs use their corresponding classes of functions. The germ retains local behavior while forgetting the representative's values farther from the point.

Nonnegative function (f(x)≥0)

Words: 39
Function OurBigBook.com
A real-valued function is nonnegative when all its values are at least zero. Products and nonnegative linear combinations of nonnegative functions remain nonnegative. A nonnegative partition of unity gives convex combinations, hence a convex-hull bound for a geometric basis.

Commuting functions (R∘S=S∘R)

Words: 59
Function OurBigBook.com
Two self-maps R,S:X→X commute when R∘S=S∘R. Induction then gives Rn∘S=S∘Rn and Rn∘Sm=Sm∘Rn for all nonnegative integers m,n. Sharing a fixed point or invariant set does not by itself imply commutation. For rational sphere maps of degrees at least two, commutation does imply equality of their Fatou sets and Julia sets, by the commuting rational maps of degree at least two have the same Julia set theorem.

Finite modification of the identity on the real line (∣{x:f(x)=x}∣<∞)

Words: 67
Function OurBigBook.com
A finite modification agrees with the identity map outside a finite exceptional set. Sorting that set gives a unique finite record of pairs (x,f(x)). Real-number pairing by separated digits encodes the record in (0,1), and placing length-n records in disjoint intervals (n,n+1) gives an injection from all finite modifications into the real line. Conversely, changing the value at one fixed point gives a real-parameter family, so the Cantor-Schröder-Bernstein theorem shows this family has continuum cardinality.

Pointwise periodic self-map (∀x ∃nx​≥1: fnx​(x)=x)

Words: 162 Articles: 1
Function OurBigBook.com
A pointwise periodic self-map returns each point to itself after a positive number of iterates which may depend on the point. It is a bijection: each finite cycle supplies predecessors; equality of two images can be undone by an iterate with an exponent one below a common multiple of the two periods. The set consequently decomposes into disjoint finite permutation cycles. Pointwise periodicity does not imply that one iterate is the identity on an infinite set.

Uniform period criterion for pointwise periodic maps (fN=id⟺all cycle lengths divide N)

Words: 88
Pointwise periodic self-map OurBigBook.com
A pointwise periodic self-map has a uniform positive period exactly when its finite cycle lengths are bounded. A uniform period is divisible by every length; conversely, bounded lengths divide the least common multiple of 1,…,M for some bound M. Arbitrarily many bounded-length cycles are allowed. Every such map on a finite set has a uniform period. On any infinite set containing a countably infinite subset, cycles of unbounded finite lengths and fixed points elsewhere give a counterexample. Thus, with the usual axiom of choice assumption, the sets on which every pointwise periodic self-map has a uniform period are exactly finite sets.

Vector-valued function (F:X→V)

Words: 33
Function OurBigBook.com
A vector-valued function is a function with values in a vector space. For finite-dimensional real or complex target spaces, choosing a basis represents it by scalar coordinate functions; continuity and differentiability can then be checked coordinatewise.

Set function (f:P(V)→R)

Words: 136 Articles: 3
Function OurBigBook.com
A real-valued set function assigns a real number to each subset of a specified ground set.

Finite additivity of a set function (F(A∪B)=F(A)+F(B)(A∩B=∅))

Words: 59
Set function OurBigBook.com
A real-valued set function on an algebra of sets is finitely additive if it has the displayed property for disjoint pairs. It follows that F(∅)=0. On a finite ambient set, induction gives F(A)=∑x∈A​F({x}), so arbitrary signed singleton weights describe all such functions. Summing the pointwise indicator function identity for the inclusion-exclusion principle against these weights proves the same formula for F.

Supermodular set function (f(S∪T)+f(S∩T)≥f(S)+f(T))

Words: 44
Set function OurBigBook.com
A real-valued set function is supermodular if it satisfies the displayed inequality. Its negative is a submodular set function. Equivalently, the gain from adding an element cannot decrease as the set grows. This is the defining property of a convex cooperative game, and makes coalition marginal allocations lie in the core of a cooperative game.

Submodular set function (f(A)+f(B)≥f(A∪B)+f(A∩B))

Words: 17
Set function OurBigBook.com
A set function is submodular if f(A)+f(B)≥f(A∪B)+f(A∩B) for every pair of subsets. Entropy submodularity is a fundamental example.

Function collision (x=x′,f(x)=f(x′))

Words: 45
Function OurBigBook.com
A function collision is a pair of distinct inputs x=x′ with f(x)=f(x′). An injective function has no collisions. For a two-to-one function every nonempty fiber has two elements and hence one unordered collision pair. Finding such a pair through an oracle is the task of quantum collision finding.

Fiber of a function (f−1(y))

Words: 108 Articles: 1
Function OurBigBook.com
For a function f:X→Y and y∈Y, its fiber is the set f−1(y)={x∈X:f(x)=y}. Fibers partition the domain after empty fibers are omitted. A function is injective exactly when every fiber has at most one element. Quantum hidden subgroup problem algorithms use functions whose fibers are cosets.

Factorization through a surjection (g=h∘f)

Words: 64
Fiber of a function OurBigBook.com
For a surjective function f:B→A and a function g:B→C, there is a unique function h:A→C with g=h∘f if and only if g is constant on each fiber of a function of f. Define h(a) to be the common value on f−1(a); it is well-defined and unique because that fiber is nonempty. This uniquely specified value requires no simultaneous arbitrary choices.

Translation of a function (Th​f(x)=f(x−h))

Words: 37
Function OurBigBook.com
Translation shifts the argument without changing the shape of a function. On the real line, the displayed convention shifts a graph to the right by h. Lebesgue measure invariance preserves every finite Lp norm; its Fourier transform is multiplied by e−ihξ.

Graph of a function (graph(f))

Words: 128 Articles: 2
Function OurBigBook.com
For a function f:A→B, its graph is the subset {(x,f(x)):x∈A} of A×B. It differs from a graph in graph theory. A solution curve of a scalar differential equation can be a graph over its independent coordinate.

Compact graph of a continuous map

Words: 39
Graph of a function OurBigBook.com
The map x↦(x,f(x)) is continuous into the product topology. It maps a compact space X onto the graph of a function of a continuous f. Hence that graph is compact, whether or not the codomain is a Hausdorff space. Projection to X is its continuous inverse.

Closed graph of a map into a Hausdorff space

Words: 51
Graph of a function OurBigBook.com
For a continuous map f:X→Y with Hausdorff space Y, its graph of a function is closed in the product topology. If y=f(x), choose disjoint neighborhoods of those two points in Y. Continuity supplies a neighborhood of x whose image lies in the neighborhood of f(x); its product with the other neighborhood misses the graph.

Partial function (f:X⇀Y)

Words: 127 Articles: 2
Function OurBigBook.com
A partial function from X to Y assigns at most one value in Y to each element of X; it may be undefined outside a subset of X.

Partial unary operation (α:D⊆A→A)

Words: 51
Partial function OurBigBook.com
A partial unary operation on a set A is a partial function with specified domain D⊆A and values in A. A map preserving such operations must send each point of the source domain into the target domain and preserve its assigned value. It need not reflect whether the operation is defined.

Composition of partial functions

Words: 46
Partial function OurBigBook.com
Composition of partial functions is strict: g(h1​(x),…,hr​(x)) is defined only if every hi​(x) is defined and g is defined on the resulting tuple. An argument discarded by the outer function still has to be defined. A representation in a non-strict programming language therefore needs an explicit sequencing guard.

Inverse function

Words: 153 Articles: 3
Function OurBigBook.com
If a function f:X→Y is bijective, its inverse function f−1:Y→X is characterized by f−1(f(x))=x and f(f−1(y))=y.

Right inverse (f∘g=idY​)

Words: 101 Articles: 1
Inverse function OurBigBook.com
A right inverse of a function f:X→Y is a function g:Y→X satisfying f∘g=idY​. It forces f to be a surjective function. A surjective linear map onto a finite-dimensional vector space has a linear right inverse: lift a basis of the target and extend by linearity.

Right-inverse characterization of the axiom of choice

Words: 60
Right inverse OurBigBook.com
The assertion that every surjective function has a right inverse is equivalent to the axiom of choice. Choice selects one member of each nonempty fiber of a function, giving a right inverse. Conversely, for a family (Xi​)i∈I​ of nonempty sets, the projection from the disjoint union {(i,x):i∈I, x∈Xi​} onto I is surjective. A right inverse selects one element from each Xi​, giving a choice function.

Left inverse (g∘f=idX​)

Words: 33
Inverse function OurBigBook.com
A left inverse of a function f:X→Y is a function g:Y→X satisfying g∘f=idX​. It forces f to be injective, since equal images can be mapped back to equal original elements.

Projection (mathematics, p2=p)

Words: 112 Articles: 2
Function OurBigBook.com
A projection is a function that fixes the points in its image: applying it twice has the same effect as applying it once. A coordinate projection can be represented this way when its target is identified with a retract; a linear projection additionally respects the vector-space operations.

Projection map

Words: 69 Articles: 1
Projection (mathematics) OurBigBook.com
A projection map from a Cartesian product selects specified coordinates, for example pj​:∏i​Xi​→Xj​ with pj​((xi​)i​)=xj​.

Empty-set cases for Cartesian projections (pi​:X1​×X2​→Xi​)

Words: 52
Projection map OurBigBook.com
For a coordinate projection map onto Xi​, write Xj​ for the other factor. The map is surjective exactly when Xi​ is empty or Xj​ is nonempty. It is injective exactly when Xi​ is empty or Xj​ has at most one element. In particular, a surjection onto an empty Cartesian product need not induce a surjection onto a nonempty factor.

Fixed point

Words: 16
Function OurBigBook.com
A fixed point of a function f:X→X is an element x∈X satisfying f(x)=x.

Conjugate functions

Words: 35
Function OurBigBook.com
Functions f:X→X and g:Y→Y are conjugate through a bijection σ:X→Y when g=σfσ−1. The bijection transports orbits and fixed points of every iterate of f to the corresponding objects for g.

Piecewise linear function

Words: 70 Articles: 1
Function OurBigBook.com
A piecewise-linear function is linear on each member of a finite or locally finite partition of its domain into intervals or polyhedral pieces.

Linear interpolation ((1−t)f(a)+tf(b))

Words: 47
Piecewise linear function OurBigBook.com
Between two prescribed values, linear interpolation assigns (1−t)f(a)+tf(b) at (1−t)a+tb, for 0≤t≤1. Joining successive samples produces a piecewise linear function. For a continuous function on a compact interval, interpolants along grids with mesh tending to zero converge in the uniform norm; their error is bounded by the modulus of continuity at the mesh size.

Global maximum

Words: 28
Real-valued function OurBigBook.com
A global maximum of a real-valued function is a value f(x0​) satisfying f(x)≤f(x0​) throughout its domain.
A global maximum is one type of extremum of a real-valued function; global minima reverse the inequality.

Positive part of a real-valued function (f+​)

Words: 22
Real-valued function OurBigBook.com
The positive part of a real-valued function f is f+​(x)=max(0,f(x)). Together with the negative part f−​(x)=max(0,−f(x)), it gives f=f+​−f−​ and ∣f∣=f+​+f−​.

Bijection

Words: 19
Function OurBigBook.com
A bijection is a function that is both injective and surjective, so every target element has exactly one preimage.

Periodic function

Words: 202 Articles: 4
Function OurBigBook.com
A function is periodic when f(x+T)=f(x) for some nonzero period T and every x in its domain.

Simply periodic function (Per(f)=ωZ)

Words: 41
Periodic function OurBigBook.com
A nonconstant meromorphic function on the complex plane is simply periodic when its group of periods is generated by one nonzero complex number. It is distinct from a doubly periodic elliptic function, whose period lattice has two real-linearly independent generators. Single periodicity alone imposes no algebraic addition law.

Cardinality of integer-periodic function spaces

Words: 61
Periodic function OurBigBook.com
For fixed positive integer period n, integer-valued periodic functions on Z are in bijection with Zn and hence form a countable set. Their union over periods is a countable union of countable sets. In contrast, period-one integer-valued functions on Q can prescribe arbitrary binary values on its infinitely many distinct classes modulo Z. The power set of a countably infinite set injects into them, proving uncountability.

Period average (⟨f⟩=T1​∫t0​t0​+T​f(t)dt)

Words: 29
Periodic function OurBigBook.com
For an integrable periodic function f with period T, its period average is ⟨f⟩=T−1∫t0​t0​+T​f(t)dt, independent of t0​. In particular a sinusoidal square has period average 1/2.

Triangular wave (P(s+2π)=P(s))

Words: 54
Periodic function OurBigBook.com
A triangular wave is a continuous piecewise linear periodic function whose slope alternates between two values. The even 2π-periodic extension of bx from [0,π] is P(s)=b∣s−2kπ∣ for (2k−1)π≤s≤(2k+1)π. Its Fourier cosine series contains a constant term and odd modes with coefficients proportional to the inverse square of the mode number. Such extensions describe reflection under Neumann boundary conditions.
