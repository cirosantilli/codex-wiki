Count leading zeros (clzn​(x))

 ... Computer science Theoretical computer science Computational complexity theory Circuit complexity Boolean circuit Combinational logic
OurBigBook.com Words: 216 Articles: 2
The number of zero bits before the first one, reading a fixed-width binary representation from its most significant bit. The all-zero n-bit input has count n. Thus clz8​(00000101)=5, and clz8​(00000000)=8; the width is part of the definition.
