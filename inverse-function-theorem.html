Inverse function theorem

 ... Area of mathematics Analysis Real analysis Calculus Multivariable calculus Differentiable map
OurBigBook.com Words: 2k Articles: 12
The inverse function theorem answers a practical question: can nearby outputs be used to recover nearby inputs uniquely and smoothly? Its useful surprise is that a nonlinear function can be tested using its linear derivative. If the first-order changes preserve all input directions, then, on a sufficiently small region, the nonlinear map can also be reversed. This is the basis for treating a nonlinear map as a coordinate transformation.
Precisely, let f:U→Rn be continuously differentiable on an open subset U of Euclidean space, let a∈U, and put b=f(a). If Df(a) is an invertible linear map, there are open neighbourhoods U0​ of a and V0​ of b such that f:U0​→V0​ is a bijection with a continuously differentiable inverse function g. Thus this restriction is a diffeomorphism. In coordinates the test is detDf(a)=0, using the Jacobian determinant. The derivative of a local inverse map is obtained by inverting the Jacobian matrix, at the corresponding input. [ref]
For a one-dimensional example, f(x)=x2 has f′(1)=2. Near x=1, the inverse function is g(y)=y​, and the inverse function rule gives g′(1)=1/2. But x2 has no inverse function on the whole real line, since x and −x give the same output. The theorem supplies a local restriction, not global injectivity. At zero, the derivative test fails; the nonnegative branch still has a square root inverse, but that inverse has no finite derivative at zero. [ref]
Here is a two-dimensional example with an invertible derivative everywhere and infinitely repeated outputs:
f(s,θ)=(escosθ,essinθ),Df(s,θ)=es(cosθsinθ​−sinθcosθ​),detDf=e2s>0.
(104)
The exponential function turns s into a positive radius, while θ is the angle in polar coordinates. Restricting, for example, to ∣s∣<0.35 and ∣θ∣<0.6 produces the reversible patch pictured below. On its image, with Cartesian coordinates (u,v) and u>0, the inverse function is
s=21​log(u2+v2),θ=arctan(v/u).
(105)
The arctangent selects the angle near zero. Without an angle restriction, f(s,θ+2πk)=f(s,θ) for every integer k, so there is no single global inverse function. This map is a local diffeomorphism but is not injective.
The short proof idea is to correct a guessed input using the inverse linear response. With A=Df(a), solving f(x)=y is equivalent to finding a fixed point of
Ty​(x)=x+A−1(y−f(x)).
(106)
At a, the derivative DTy​(a)=I−A−1Df(a) vanishes. Continuity makes Ty​ a contraction mapping on a sufficiently small closed ball, which it maps into itself when y is sufficiently close to b. The contraction mapping theorem then gives existence and uniqueness there. Establishing the smooth dependence on y completes the inverse theorem. This explains why the nonlinearity can be tolerated: its correction has a small local slope.[ref]
