Propositional logic

 Home Mathematics Area of mathematics Foundations of mathematics Mathematical logic
OurBigBook.com Words: 4k Articles: 90
Propositional logic studies reasoning with whole propositions represented by letters such as p and q, and propositional formulas built from them using logical connectives. The classical two-valued, truth-functional presentation below assigns each primitive proposition either true or false: each compound value depends only on its component values. This is classical propositional logic; other systems, including Intuitionistic propositional logic, have different semantics and rules.
Starting with p and q, one can build ¬p by logical negation, p∧q by logical conjunction, p∨q by logical disjunction, and p→q by logical implication, then combine these into larger propositional formulas. Parentheses specify the construction: (p→q)∧p has logical conjunction as its outermost logical connective. Primitive propositions have no internal structure in this language; a first-order formula can additionally describe objects and quantify over them. The formation rules are given in forall x: Calgary, chapter 6.
The following truth table shows the four basic logical connectives. Logical disjunction is inclusive: p∨q is true when either or both inputs are true. Classical logical implication has exactly the same values as ¬p∨q; its only false row has p true and q false. These truth conditions are specified in forall x: Calgary, chapter 9.

With the opposite assignment p=F,q=T, the logical implication is true but the logical conjunction is still false because its second input p is false. Recursive evaluation and exhaustive truth tables are explained in forall x: Calgary, chapter 11.
The last column is always true: ((p→q)∧p)→q is a tautology. This expresses the logical validity of the modus ponens rule: whenever both premises p→q and p are true, q is true. It does not say the premises are true under every Boolean valuation; their logical conjunction is true only on the first row. For a short natural deduction proof outline, assume (p→q)∧p, extract both conjuncts, apply the implication elimination rule to obtain q, then discharge the assumption by the implication introduction rule. See forall x: Calgary, sections 17.3–17.5.
Three tests answer different questions: Boolean satisfiability requires at least one true row, a tautology requires every row true, and a contradiction has every row false. Thus p∨¬p is a tautology, p∧¬p is a contradiction, and p∧q is satisfiable but not a tautology: it is true only at p=q=T. See forall x: Calgary, sections 12.1–12.4.
Propositional logic is useful because an inference pattern can be checked once and reused for many choices of propositions. Its beauty is that a finite truth table completely settles classical truth-functional questions about a fixed propositional formula. But logical validity does not verify real atomic claims. If p means “the switch is closed” and q means “the lamp is lit”, a valid use of the modus ponens rule still requires establishing its premises about the apparatus; the truth table supplies neither an observation nor a causal explanation. See forall x: Calgary, chapter 2 and chapter 10.
