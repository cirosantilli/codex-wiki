 Home Mathematics Area of mathematics Foundations of mathematics Set theory
OurBigBook.com Words: 8k Articles: 157
A set is a collection of distinct objects regarded as its set elements. Membership, written a∈A, is the basic question: is a one of the objects in A? For example, {1,2,2}={1,2}={2,1}: repeated entries and their written order do not change a set. A multiset retains multiplicities, while a tuple retains positions as well. Choosing the right object therefore determines which distinctions the mathematics remembers.
A set can collect possible outcomes of a probability space, vertices of a graph, or allowed inputs of a function. The empty set contains none; a subset selects members of a previously given set; the power set collects every such selection. These constructions are useful because they can be stated once and reused regardless of what the members represent. In an axiomatic account, rules such as the axiom schema of separation specify which collections exist as sets.

Solution set (S={x∈D:P(x)})

Words: 320
Set OurBigBook.com
The solution set of a mathematical condition P in a specified domain D collects every allowed value that satisfies it:
S={x∈D:P(x)}.
(1)
It describes the answer without committing to the steps used to find it. For the equation x2=1 over the real numbers, the solution set is {−1,1}; restricting to positive real numbers leaves {1}. For 2x=1, the solution set is {1/2} over the rational numbers and the empty set over the integers. The domain is part of the question.
An equation can have one solution, several solutions, no solutions, or an entire domain of solutions. Over the real numbers, 2x+3=9 gives the singleton set {3}, x2+1=0 gives the empty set, and the mathematical identity (x+1)2=x2+2x+1 gives the whole real line. Changing that second equation's domain to the complex numbers gives {−i,i}. The elementary definition by values that satisfy an equation and the classification by solution sets appear in College Algebra 2e, §2.2: Solving Linear Equations in One Variable.
Requiring several conditions simultaneously takes the intersection of their solution sets. The squared equation x=(x−2)2 has solution set {1,4}. Adding the restriction x≥2 gives
{1,4}∩[2,∞)={4},
(2)
which is also the solution set of x​=x−2. The extraneous solution example explains why the sign restriction is needed. Requiring at least one of several conditions instead takes their union. This turns logical combinations of constraints into reusable operations on sets.
For several variables, a solution is an ordered assignment, usually represented by a tuple. The real equation x+y=1 has solution set {(t,1−t):t∈R}, a straight line in the Euclidean plane with coordinates (x,y). Adding x−y=0 intersects that straight line with another, leaving the single tuple (1/2,1/2). A system of linear inequalities has no solution exactly when the intersection of its individual solution sets is the empty set. For optimization constraints, this common solution set is the feasible region.
Because a solution set is a set, the order in which its members are listed is irrelevant. The multiple root of (x−1)2=0 is still the one solution 1; its multiplicity of a root is additional polynomial information, rather than a second occurrence inside the solution set. Equivalent equations preserve the solution set on the stated domain, even if their algebraic forms differ.

Cover (topology, E⊆⋃i​Ui​)

Words: 70
Set OurBigBook.com
A cover of a set E is a family of sets whose union contains E. The members may overlap and may include points outside E; intersecting each member with E gives a cover by its subsets. An open cover requires its members to be open sets. In Hausdorff measure, countable covers with a bound on each member's diameter determine geometric size. Constructing one inexpensive cover supplies an upper bound, while a lower bound must control all allowed covers.

Dedekind-finite set (N↪X)

Words: 160 Articles: 2
Set OurBigBook.com
A set X is Dedekind-finite when no injective function N→X exists. In classical Zermelo–Fraenkel set theory this is equivalent to X not being in bijection with a proper subset: an injective non-surjective self-map generates distinct iterates from an element outside its image, and a countably infinite subset permits a shift fixing its complement. A finite set is Dedekind-finite. Without the axiom of choice, some infinite sets can also be Dedekind-finite.

Finite repetition-free sequences preserve Dedekind-finiteness

Words: 62
Dedekind-finite set OurBigBook.com
If X is a Dedekind-finite set, its set of finite repetition-free sequences is also Dedekind-finite. An injective sequence of distinct finite lists would, by countable union of explicitly ordered finite lists without choice, either produce an injection N→X or use only finitely many entries. The latter possibility is impossible because a fixed finite pool supports only finitely many repetition-free lists. If X is infinite, the one-entry lists also show that the resulting set is infinite.

Infinite Dedekind-finite set

Words: 39

An infinite Dedekind-finite set is an infinite set with no subset that is a countably infinite set. The name Dedekind set is sometimes used for this combination of properties. Under the axiom of choice no such set exists; results about these sets must avoid obtaining arbitrary enumerations of finite subsets by unstated choices.

Set difference (A∖B)

Words: 179
Set OurBigBook.com
The set difference A∖B keeps the set elements of A that do not belong to B:
A∖B={x∈A:x∈/B},x∈A∖B⟺(x∈A)∧¬(x∈B).
(3)
Thus set difference combines logical conjunction (AND) with logical negation (NOT): pass the first condition and fail the second. The definition applies to any two sets; B need not be a subset of A.
For A={1,2,3} and B={3,4}, the two orders give different answers:
A∖B={1,2},B∖A={4}.
(4)
The common member 3 is removed in both directions. A database filter illustrates the usefulness: if A is the set of records matching the first condition and B the set matching the second, A∖B selects records matching the first but not the second. The Venn diagram in set union shades both directions separately.
The name relative complement emphasizes that the ambient set is A: A∖B is the complement of A∩B within A. If a larger universal set U contains A and B, then A∖B=A∩(U∖B). Changing that larger universal set does not change the set difference, because membership still requires belonging to A. In ZF the set difference exists by the axiom schema of separation. It also gives relative complements within a fixed tuple domain in finite relation closure for set-theoretic coding.

Complement of a set (X∖A)

Words: 375 Articles: 1
Set OurBigBook.com
The complement of a subset A within a specified universal set U contains exactly the set elements of U excluded from A:
Ac=U∖A={x∈U:x∈/A},x∈U⟹(x∈Ac⟺¬(x∈A)).
(5)
Here Ac depends on the chosen universal set. Within U, taking a complement performs logical negation (NOT) on membership. Writing U∖A keeps the ambient set visible when there could be ambiguity.
For A={1,2,3}, B={3,4}, and U={1,2,3,4,5,6}:
U∖A={4,5,6},U∖B={1,2,5,6}.
(6)
If the universal set grows to U′={1,2,3,4,5,6,7}, the same sets have different complements: U′∖A={4,5,6,7} and U′∖B={1,2,5,6,7}. In a database illustration, “records that fail this condition” therefore requires deciding which records are eligible to begin with; those eligible records form U.
For subsets A,B⊆U, De Morgan's laws exchange union and intersection when taking complements:
U∖(A∪B)=(U∖A)∩(U∖B),U∖(A∩B)=(U∖A)∪(U∖B).
(7)
For the same example, failing both conditions leaves U∖(A∪B)={5,6}=(U∖A)∩(U∖B). Failing at least one condition leaves U∖(A∩B)={1,2,4,5,6}=(U∖A)∪(U∖B). This is useful for rewriting exclusion rules into separate membership tests. The symmetry is also pleasing: exchanging union with intersection turns one rule into its partner.
A brief membership proof works in classical propositional logic. For any x∈U, let P mean x∈A and Q mean x∈B. The truth table below checks all four possibilities, with 1 meaning true and 0 false:
P0011​Q0101​¬(P∨Q)1000​¬P∧¬Q1000​¬(P∧Q)1110​¬P∨¬Q1110​​
(8)
Each paired column agrees. Translating logical disjunction (OR), logical conjunction (AND), and logical negation (NOT) back into membership proves the two set equalities. For the general method of reducing set equalities to equivalences in propositional logic, see Lehman, Leighton and Meyer, Mathematics for Computer Science (2015), §4.1.5 and Problem 4.5.
A historical perspective appears in Augustus De Morgan's [ref]: he describes treating each name together with its contradictory name. In the membership viewpoint here, a set and its complement likewise pair a condition with its logical negation.

Universal set (U)

A universal set U fixes the objects under consideration in a particular discussion; each set under consideration is a subset of U. For example, U={1,2,3,4,5,6} makes the complement of {1,2,3} equal to {4,5,6}. This use of “universal” is local to the discussion: it does not assert the existence of a set containing every set. Power set (P(X))

Words: 245 Articles: 1
Set OurBigBook.com
The power set P(X) is the set of all subsets of X, including the empty set and X itself. It is useful whenever an object is a selection rather than an individual member: a possible collection of active vertices in a graph, for example, belongs to the power set of the vertex set.
For X={a,b,c}, the power set has eight members:
P(X)={∅,{a},{b},{c},{a,b},{a,c},{b,c},{a,b,c}}.
(10)
Each of the three set elements is either included or excluded. More generally, if ∣X∣=n<∞, these n independent binary choices give ∣P(X)∣=2n. This is a bijection between subsets and binary strings of length n, not a probabilistic independence assumption.
Ordering the subsets by inclusion gives a Boolean lattice. In the picture an upward edge adds one member. Complementation reverses inclusion, and union and intersection combine selections. The empty-input case is worth checking: P(∅)={∅} has one member, not zero, consistently with 20=1.

Cantor's theorem

Words: 96
Power set OurBigBook.com
There is no surjection from a set X onto its power set P(X). Consequently P(X) has strictly greater cardinality than X.
For any candidate function f:X→P(X), form D={x∈X:x∈/f(x)}. This is a subset of X by set comprehension. If f(d)=D, then d∈D holds exactly when d∈/D, a contradiction. Thus D is missing from the image of f. On the other hand, x↦{x} is an injection from X into its power set, establishing the strict comparison of cardinalities. For X=N, the omitted selection is the subset version of Cantor's diagonal argument.

Set union (⋃)

Words: 278 Articles: 2
Set OurBigBook.com
The union A∪B collects the set elements belonging to either set, including those belonging to both:
A∪B={x:x∈A or x∈B},x∈A∪B⟺(x∈A)∨(x∈B).
(11)
Thus membership in a union uses logical disjunction (OR). For A={1,2,3} and B={3,4}, the union is A∪B={1,2,3,4}: the shared member 3 occurs only once, because a set records membership without repeated entries.
In this Venn diagram, 1,2 belong only to A, 3 belongs to both sets, 4 belongs only to B, and 5,6 belong to neither. The surrounding universal set is U={1,2,3,4,5,6}. Numbers are placed by membership; circle areas do not represent cardinalities. Each panel shades the region selected by its operation.
For a database illustration, let A collect records matching one condition and B collect records matching another. Their union selects records matching at least one condition, with a record satisfying both still appearing once. This interpretation turns an abstract operation into a reusable rule for combining selections. For an authored treatment of union, intersection, set difference, and complement, see Lehman, Leighton and Meyer, Mathematics for Computer Science (2015), Definition 4.1.1, pp. 82–83.
More generally, the union ⋃i∈I​Ai​ contains exactly the set elements belonging to at least one set Ai​:
x∈⋃i∈I​Ai​⟺∃i∈I: x∈Ai​.
(12)
The existential quantification expresses “at least one”. With no indexing members, the union is the empty set. Combining a set with the empty set leaves it unchanged: A∪∅=A.

Set intersection (⋂)

Words: 241 Articles: 3
Set OurBigBook.com
The intersection A∩B keeps exactly the set elements common to both sets:
A∩B={x:x∈A and x∈B},x∈A∩B⟺(x∈A)∧(x∈B).
(13)
Membership in an intersection therefore uses logical conjunction (AND). For A={1,2,3} and B={3,4}, the only shared member is 3, so A∩B={3}. The Venn diagram in set union shades only the overlap for this operation.
An intersection is useful when every requirement must hold. If A and B are the sets of database records passing two separate conditions, their intersection gives the records passing both. Similarly, satisfying two equations requires belonging to the intersection of their solution sets. The same membership rule applies even when the objects have entirely different meanings.
For a family of sets, the intersection ⋂i∈I​Ai​ contains exactly the set elements belonging to every set Ai​:
x∈⋂i∈I​Ai​⟺∀i∈I: x∈Ai​.
(14)
Here universal quantification expresses “every”. If all the sets lie within a fixed universal set U, the intersection over no indexing members is defined to be U: there are no requirements to fail. This convention depends on specifying U. By contrast, intersecting with the empty set always gives A∩∅=∅.
