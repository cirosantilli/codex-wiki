Single-level grand partition function in the dilute limit (Ξk​=1+xk​+O(xk2​),xk​=e−β(ϵk​−μ))

For a single one-particle state with xk​≪1, the empty and singly occupied contributions dominate. A fermion state gives Ξk​=1+xk​, a boson state gives (1−xk​)−1, and Maxwell–Boltzmann statistics give exk​. Thus all have the same leading dilute response, lnΞk​=xk​+O(xk2​). This approximation does not impose an exclusion principle on classical particles.
