 ... Past exam of the model theory and Gödel's incompleteness theorems course of the University of Oxford 2009 B 6 d ii
OurBigBook.com Words: 191
No infinite cardinal is categorical for this theory, as described by no categorical cardinal for the complete named rational diagram. For an arbitrary infinite κ, choose a dense linear order Iκ​ without endpoints of size κ; for example the lexicographic order on κ×Q works, since every rational block is dense and has no endpoints.
Construct one order by inserting Iκ​ into a fixed irrational cut of the named rational order. Every element of this order is bounded above by some named rational. Construct a second order by putting an Iκ​ tail above all named rationals, as the ordered sum Q+Iκ​. Both are dense linear orders without endpoints, both have cardinality κ, and both contain the named rational copy as an elementary substructure by quantifier elimination. Hence both satisfy its complete diagram T.
They are not isomorphic over the named constants: the second has an element greater than every named rational, and the first has none. This property need not be expressible by a single sentence in the infinite language to be an isomorphism invariant. Finite cardinalities have no models at all because the constants name infinitely many distinct Elements, so the existence clause excludes categoricity there too.
