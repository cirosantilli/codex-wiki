Let C denote the addition-commutativity first-order sentence and put d=┌¬C┐. In the ordinary checker for PA derivations, replace the axiom test AxPA​(u) by
AxS​(u)≡AxPA​(u)∨u=dˉ.
(15)
Keep all tests for sequence formation, earlier lines, logical axiom schemes and inference rules unchanged. This gives a formal proof checker QS​(u,w) which recognizes exactly ordinary S-derivations. The finite syntactic modification is arithmetizable by the same bounded coding apparatus as the original checker.
For the proof-order comparison in the next part, make the choice of coding explicit. Reserve code 0 for the one-line derivation of the newly added axiom ¬C, and give an ordinary derivation with code w the new code w+1. A corresponding bounded relation is
ProvS​(u,v)≡(v=0∧u=dˉ)∨(∃w≤v)(v=w+1∧QS​(u,w)).​
(16)
Every code has a specified decoding, every genuine formal proof is represented, and no false formal proof is admitted. The reserved code duplicates one genuine derivation, which is harmless. This is one explicit arithmetized arithmetical proof relation obtainable from the PA checker by the requested axiom change and a simple renumbering. Stating the proof-order convention matters because a Rosser predicate symbol uses code order, not merely the existence of formal proofs.
