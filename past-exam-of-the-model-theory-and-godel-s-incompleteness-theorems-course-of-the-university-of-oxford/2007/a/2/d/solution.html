Let d(n) be the Gödel number of the diagonal first-order sentence obtained by substituting nˉ into the one-free-variable logical formula with code n, with an arbitrary default value on noncodes. By the assumptions and (c), this total function has a strong defining logical formula D(x,y).
For the specified F, form the one-variable logical formula
H(x)=∃y(D(x,y)∧F(y)).
(16)
Let h be the Gödel number of H and put C=H(hˉ). Then d(h)=┌C┐. Strong definability of a numerical function at this particular standard input gives
S⊢∀y[D(hˉ,y)↔y=┌C┐].
(17)
Substitution into the existential definition yields
S⊢C↔F(┌C┐).​
(18)
The permitted equivalence between the source's two substitution notations identifies this with its requested fixed point. Bound variables are renamed when necessary before forming H, so the substitution is capture-free. This constructs one particular first-order sentence from the code of the logical formula which applies F to its own diagonal output.
