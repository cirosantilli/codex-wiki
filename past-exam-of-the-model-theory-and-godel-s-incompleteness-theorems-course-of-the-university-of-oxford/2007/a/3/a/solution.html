Write □A for P(┌A┐). A standard arithmetical provability predicate obeys the Hilbert-Bernays-Löb derivability conditions:
S⊢A⟹S⊢□A,S⊢□(A→B)→(□A→□B),S⊢□A→□□A.
(19)
The first condition is a rule about theorems; the latter two are statements proved within the first-order theory. When the terminology also includes external adequacy, require that P(nˉ) be true in the standard natural numbers exactly when the logical formula with code n has an S-proof.
For Peano arithmetic, code finite strings, logical formulas and formal proof sequences by natural numbers. Formal proof checking is effective and has an arithmetized bounded checking relation with its computation data. Existentially assert the existence of a correct formal proof code and any required checking data. The resulting predicate symbol is Sigma-1, and its standard truth means exactly that an actual finite PA formal proof exists. Effective operations on formal proof codes combine an implication formal proof with an antecedent formal proof, and turn a formal proof into a formal proof that its code is a formal proof; PA verifies those constructions. They give distribution and positive introspection, while an actual theorem's finite formal proof gives its internal provability assertion. This is the requested rough construction, with the three internal formal proof properties distinguished from external agreement.
