An arithmetic logical formula is Σ0​, or bounded, if all its quantifiers are bounded by arithmetical first-order terms. A Σ1​ logical formula has an initial block of existential quantifiers followed by a bounded matrix, up to the usual logical transformations. Soundness of an arithmetic theory at a given level means that every first-order sentence of that level proved by the first-order theory is true in the standard natural numbers. Here Σ0​-completeness means that every true bounded arithmetic sentence is provable.
A first-order theory is one-consistent if there is no bounded arithmetic formula A(x) for which it proves ∃xA(x) while proving ¬A(nˉ) for every standard natural number n. This is a restricted form of omega-consistency. In particular one-consistency implies first-order consistency, since an inconsistent first-order theory proves every first-order sentence and its negation.
Suppose a Σ0​-complete first-order theory S is first-order consistent. If it proved a false bounded arithmetic sentence θ, the true bounded arithmetic sentence ¬θ would also be provable by completeness, contradicting first-order consistency. Thus S is Σ0​-sound. Conversely Σ0​-soundness excludes inconsistency because an inconsistent first-order theory proves the false bounded arithmetic sentence 0=1. Therefore
Σ0​-complete:Con(S)⟺Σ0​-soundness.​
(1)
If S is one-consistent but proved a false existential sentence ∃xA(x) with bounded matrix, every standard instance ¬A(nˉ) would be true and hence provable. This violates one-consistency. Thus it is Σ1​-sound. Conversely, Σ1​-soundness implies first-order consistency by the previous argument, since bounded arithmetic sentences are included at the existential level. If S proved ∃xA(x), soundness of an arithmetic theory would give a standard witness n with A(n) true. Bounded completeness of an arithmetic theory would then give S⊢A(nˉ), so first-order consistency prevents simultaneous formal proofs of all the negated instances. Hence
Σ0​-complete:1-consistency⟺Σ1​-soundness.​
(2)
Multiple existential logical variables can be treated as a finite tuple of witnesses; the same reasoning applies.

If PA is inconsistent, every desired conclusion is already a theorem, so it suffices to analyze the first-order consistent case. Use Q(u,v) for the bounded arithmetical proof relation and neg(u) for the code of the negation of the logical formula coded by u.
Suppose PA⊢En​ and let m be the code of an actual formal proof. By first-order consistency there is no formal proof of ¬En​, in particular none with code at most m. Thus
Q(nˉ,mˉ)∧(∀z≤mˉ)¬Q(neg(n)​,z)
(12)
is a true bounded arithmetic sentence. Bounded completeness of an arithmetic theory proves it in PA, and existential introduction gives PA⊢PrPA∗​(nˉ).
Conversely suppose PA⊢¬En​ and choose an actual formal proof code k of that negation. First-order consistency excludes every formal proof of En​, so each of the finitely many statements ¬Q(nˉ,jˉ​) for j<k is true and provable. The supplied finite-case theorem permits PA to combine them into the assertion that no formal proof code below k proves En​.
PA also proves Q(neg(n)​,kˉ). For any candidate formal proof code v≥kˉ, this one code already refutes the universal no-earlier-negation condition in the Rosser predicate symbol. For v<kˉ, the finite verification refutes its positive formal proof condition. The supplied order dichotomy and finite-case expansion cover all v. Therefore
PA⊢¬PrPA∗​(nˉ).​
(13)
The argument uses bounded verification of a finite initial segment and one fixed counter-witness beyond it; it does not infer that PA proves the absence of all ordinary formal proofs merely from first-order consistency.

Use the arithmetical proof relation and coding just constructed. A formal proof of C cannot have code 0, since that code was reserved for ¬C. Every candidate code v for a formal proof of C is therefore positive. But code 0≤v is already a formal proof of ¬C, so the no-earlier-negation condition fails for every candidate. Hence
N⊨¬PrS∗​(┌C┐).​
(17)
PA proves C by induction, while S has ¬C as an added axiom. Thus S is inconsistent and its ordinary arithmetical provability predicate is true of every first-order sentence, including C. The displayed negative Rosser assertion can nevertheless be true, because the Rosser condition compares the order of opposite formal proofs rather than asking for their mere existence.
There is an important coding qualification. The PDF refers to a course formal proof coding but does not specify its numerical ordering. The truth of this Rosser assertion for an inconsistent first-order theory is not coding-invariant, so formal proof length alone cannot establish it for an unspecified fixed coding. For example, a different legitimate numbering could reserve code 0 for a known PA formal proof of C, code 1 for the new axiom ¬C, and higher codes for all other derivations. Then code 0 would witness PrS∗​(┌C┐) instead. The explicit allowed construction in part (i) supplies a convention under which the requested assertion holds; interpreting it as a claim about some externally fixed course numbering requires that numbering's corresponding order property.

S⊢A⟹S⊢PA,S⊢P(A→B)→(PA→PB),S⊢PA→PPA.

These are the usual theoremhood, distribution and positive-introspection conditions intended by a standard arithmetical provability predicate; arbitrary predicate symbols merely agreeing with provability externally need not satisfy them.
Since S⊢¬Y, it proves Y→G. The first two conditions give S⊢PY→PG. For the converse, the fixed-point equivalence gives S⊢G→(PG→Y). Applying theoremhood and distribution gives

S⊢G↔¬PY.​

S⊬¬PY.​

Under the arithmetical interpretation □A=PS​(┌A┐), the Löb axiom says that a formal proof of the local reflection implication for A already entails a formal proof of A:
PS​(┌PS​(┌A┐)→A┐)→PS​(┌A┐).
(40)
It is a formalized constraint on self-verification of a formal proof system. Externally, Löb's theorem says that if the system itself proves its own local reflection implication for A, it proves A. Distribution reflects closure of formal proofs under implication, necessitation reflects that a theorem has an arithmetically recognizable formal proof, and positive introspection reflects formal proof verification inside arithmetic.
Taking A to be a refutable first-order sentence, especially a contradiction, recovers the obstruction behind the second incompleteness theorem: a first-order consistent sufficiently strong system cannot prove the corresponding claim that no formal proof of that first-order sentence exists. This does not identify provability with truth, nor grant the unrestricted factivity principle □A→A as a theorem of the system. The Löb axiom is the characteristic additional scheme of Gödel–Löb provability logic.

An L-structure has a nonempty underlying set A. It assigns to each constant symbol ck​ an element ckA​∈A, to each n-ary function symbol fj​ a function An→A, and to each n-ary predicate symbol Pi​ a relation contained in An. Logical equality, when included as logical equality, is interpreted as actual identity.
The arities belong to the specification of the first-order language. An assignment of logical variables to elements of A then evaluates first-order terms recursively and determines satisfaction of logical formulas through the logical connectives and quantifiers. A first-order sentence has no free variables, so its truth in the first-order structure is independent of the assignment.

The set Σ is satisfiable if there is one L-structure A satisfying every first-order sentence in Σ simultaneously. It is finitely satisfiable if each finite subset Σ0​⊆Σ has a first-order model; that first-order model is allowed to depend on the chosen finite subset.
Thus the two statements have different quantifier orders:
∃A ∀σ∈Σ (A⊨σ),∀Σ0​⊆finite​Σ ∃A (A⊨Σ0​).
(41)
Satisfiability immediately implies finite satisfiability by using the same first-order structure for every finite subset. The converse is the substantive content of compactness theorem.

iii OurBigBook.com
The compactness theorem states that a set of first-order sentences has a first-order model if and only if every finite subset has a first-order model.
For the nontrivial direction suppose every finite subset of Σ is satisfiable. If Σ were inconsistent, a finite formal derivation of a contradiction would use only finitely many premises Σ0​⊆Σ. Soundness of an arithmetic theory would then exclude a first-order model of Σ0​, contradicting finite satisfiability. Therefore Σ is first-order consistent. The completeness theorem, proved by adjoining witnesses and constructing a Henkin term model, supplies a first-order model of Σ.
The reverse direction is immediate by restriction of the list of required first-order sentences. The key reason compactness theorem follows from syntactic completeness is that every formal proof uses only finitely many premises, even when the whole first-order theory is infinite.

Expand the ring first-order language by a new constant c and consider
Th(Z)∪{c=0}∪{∃y (nˉ⋅y=c):n=1,2,3,…}.
(42)
Every finite subset is satisfiable in the integer ring itself. Only finitely many divisibility conditions occur; interpret c as a nonzero common multiple of their positive integer indices, using 1 if none occur. All first-order sentences from Th(Z) are automatically true there.
Compactness theorem therefore gives a first-order model. Its reduct R to the original ring first-order language satisfies the complete theory of Z, so R≡Z. Its element cR is nonzero and divisible by every positive standard integer. Thus
R≡Z,cR=0,(∀n∈N>0​) R⊨∃y (nˉy=cR).​
(43)
Such an element cannot be an ordinary nonzero integer, since an integer of absolute value less than n cannot be a nonzero multiple of n. The statement concerns each standard integer index separately; it does not assert divisibility by every internally nonzero element of R.

Let LA​ expand L by a constant ca​ for each a∈A, and let AA​ be the canonical expansion interpreting ca​ as a. Its diagram of a structure is the set of all atomic and negated atomic LA​-sentences true in AA​. Its elementary diagram is the set of all LA​-sentences true there:
Diag(A)={θ:θ atomic or negated atomic, AA​⊨θ},
(44)
CDiag(A)=Th(AA​).
(45)
A substructure inclusion A⊆B means that A⊆B, constants have the same interpretations, the operations of B restrict to those of A, and each relation restricts to the corresponding relation on A.
An elementary substructure additionally preserves the truth of every logical formula with parameters from A:
A≼B⟺A⊨ϕ(a)⟺B⊨ϕ(a) for every ϕ,a∈A.​
(46)
Here the right-hand condition includes the substructure requirements by applying it to atomic logical formulas and their negations.

If A⊆B, interpret each new constant ca​ in B as the same element a. Atomic logical formulas and their negations then have exactly their truth values in AA​, so the expansion satisfies the diagram of a structure. If the inclusion is elementary, every logical formula with those named parameters has the same truth value, so the expansion satisfies the elementary diagram.
Conversely, from any expansion B+ satisfying the diagram of a structure define
e:A→B,e(a)=caB+​.
(47)
The diagram of a structure contains ca​=ca′​ whenever a=a′, so e is injective. It contains every true function-value equation, so e commutes with all operations and constants. Positive and negative relation instances ensure both preservation and reflection of the relations. Thus e is an embedding of first-order structures. If the expansion satisfies the elementary diagram, for every logical formula ϕ and tuple a it also gives
A⊨ϕ(a)⟺B⊨ϕ(e(a)),
(48)
so e is an elementary embedding of first-order structures.
The precise conclusion for an arbitrary expansion is an embedding of first-order structures, rather than a literal inclusion of the original carriers. The source's inclusion notation is correct when one uses the customary identification of A with its embedded copy, or requires the expansion to interpret ca​ as the actual element a of a carrier already containing A. With that naming convention, e is the inclusion and the requested two equivalences follow exactly.
Without the convention the literal wording fails, even in the first-order language of logical equality: singleton first-order structures with carriers {0} and {1} have a diagram-satisfying expansion by sending the first first-order structure's named point to 1, but the first carrier is not a subset of the second. The embedding of first-order structures formulation proved above states the invariant result and makes the intended inclusion formulation precise.

The Downward Lowenheim-Skolem theorem says that for an L-structure M and a subset S⊆M, there is an elementary substructure N≼M containing S with
∣N∣≤max(∣S∣,∣L∣,ℵ0​).​
(49)
If an infinite cardinal κ satisfies max(∣L∣,ℵ0​)≤κ≤∣M∣, one can in particular obtain size exactly κ by starting with a subset of that size.
Choose a default element a0​∈M. For every logical formula ∃xϕ(x,y​) choose a Skolem function Fϕ​ which returns a witness in M when one exists, and returns a0​ otherwise. Begin with S, the interpretations of the first-order language's constants, and a0​. Successively adjoin the values of all the original functions and these Skolem functions on finite tuples already chosen. Let N be the union of the resulting countable sequence of closure stages.
There are at most max(∣L∣,ℵ0​) logical formulas, and each function has finite arity. With κ=max(∣S∣,∣L∣,ℵ0​), each closure stage has size at most κ, and so does their countable union. Closure under the original functions makes N an L-substructure. Whenever M⊨∃xϕ(x,a) for parameters in N, its chosen Skolem witness belongs to N, since the finitely many parameters lie in some common stage. The Tarski–Vaught test therefore gives N≼M.
For the exact-cardinality version, choose an initial set of κ elements, enlarged to contain any prescribed subset of size at most κ. The construction gives an upper bound κ while containment gives the matching lower bound.

The Ryll-Nardzewski theorem says that for a complete theory T in a countable first-order language with infinite first-order models, the following are equivalent: T is ℵ0​-categorical; for every positive integer n, the set Sn​(T) of complete parameter-free n-types is finite; every such finite-arity complete type is isolated by a logical formula. The countable-language hypothesis and the requirement for every finite arity are important.
The omitting types theorem says that, for a first-order consistent complete theory in a countable first-order language, a countable family of nonprincipal partial types in finite tuples of logical variables can all be omitted in a countable first-order model. Here nonprincipal means that no logical formula first-order consistent with the first-order theory implies every logical formula of the partial type. Omission means that no tuple in the constructed first-order model satisfies all logical formulas of that partial type. The complete one-type version is the special case of one partial type in one logical variable.

This first-order theory is complete and eliminates quantifiers. Every first-order term reduces to fk(xi​), and atomic logical formulas reduce to statements xj​=fk(xi​). To eliminate an existential logical variable in a conjunction of literals, first remove self-equalities using the no-finite-cycle axioms. If an equation fixes that logical variable as an integer translate of another logical variable, substitute that value. If no such equation remains, only finitely many points are excluded by the remaining inequalities, so some value exists in the infinite domain. Apply this to disjunctive normal form and then induct on logical formulas. The resulting parameter-free first-order sentences are decided, proving completeness.
For each fixed finite n, a complete type records a partition of the logical variables into common orbits and finitely many integer offsets within each block. There are countably many possibilities. Countable first-order models with one orbit and with two orbits are not isomorphic, so the first-order theory is not ℵ0​-categorical.
