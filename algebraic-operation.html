Binary operation (∗:S×S→S)

Words: 3k Articles: 49
Algebraic operation OurBigBook.com
A binary operation on a set S is a function ∗:S×S→S. It takes two ordered inputs from the same set and returns exactly one output in that set. The codomain is part of the definition: ordinary subtraction is a binary operation on the integers, but not on the positive integers, since 2−3=−1 leaves that set. Ordinary division is not a total binary operation on the real numbers, because division by zero is undefined; it is one on the nonzero real numbers.
The same set can carry several different binary operations. On S={0,1,2}, both a∗b=(a+b)mod3 and a⋄b=(a−b)mod3 return an element of S, using modular arithmetic. Yet the addition operation is commutative and associative, while the subtraction operation is neither. Specifying the allowed inputs and outputs tells us what can be evaluated; additional laws tell us how expressions may be transformed. [ref].
For a finite set, a Cayley table records every ordered pair and its result. This turns abstract laws into checkable examples. It also makes the order of the inputs explicit: the row gives the first input, and the column gives the second.

Cancellation law (ax=ay⇒x=y)

Words: 24
Binary operation OurBigBook.com
Left cancellation means ax=ay⇒x=y; right cancellation means xa=ya⇒x=y. A group has both laws, since multiplication by an inverse element cancels the common factor.

Magma (algebra, (S,∗))

Words: 22
Binary operation OurBigBook.com
An algebraic magma is a set equipped with a binary operation. No associative property, commutativity, or identity element is required. A semigroup adds the associative property; a monoid also adds an identity element.

Closure under a binary operation (a,b∈A⟹a∗b∈A)

Words: 53
Binary operation OurBigBook.com
A subset A⊆S is closed under a binary operation on S when the result of combining any two elements of A is again in A. The even integers are closed under addition, but the odd integers are not: 1+3=4 is even. Closure permits restricting the binary operation to A×A→A. It is different from being a closed set in topology.

Cayley table

Words: 111
Binary operation OurBigBook.com
A Cayley table records a binary operation on a finite set: the cell at row a, column b contains a∗b. Every cell must contain an element of the specified set. With the same ordering of row and column labels, the table is symmetric across its main diagonal exactly when the binary operation is commutative. Checking the associative property instead requires comparing (a∗b)∗c with a∗(b∗c) for every triple; symmetry alone cannot establish it.[ref]

Identity element (e∗a=a∗e=a)

Words: 103 Articles: 1
Binary operation OurBigBook.com
An identity element e for a binary operation satisfies e∗a=a∗e=a for every element a of the underlying set. It is a two-sided identity: merely satisfying one of the two equations is insufficient. It is unique when it exists, since two candidates satisfy e=e∗e′=e′. This uniqueness does not require the associative property.
Zero is the identity element for addition of integers, one for multiplication of integers, and the identity function for function composition of self-maps. The empty word is the identity element for concatenation. An associative operation with an identity element makes a monoid; inverse elements are an additional requirement for a group.

Additive identity (0)

Words: 20
Identity element OurBigBook.com
An identity element for addition: 0+a=a+0=a. In a vector space, it is the zero vector; among matrices of fixed dimensions, it is the zero matrix.

Distributive property (x(y+z)=xy+xz,(y+z)x=yx+zx)

Words: 46
Binary operation OurBigBook.com
For two binary operations, multiplication distributes over addition on the left or right when the respective displayed identity holds. If multiplication is commutative, either law gives the other. Repeated distribution expands expressions in an incline into finite sums of monomials. This property is distinct from associativity of either operation.

Idempotence (x∗x=x)

Words: 29
Binary operation OurBigBook.com
For a binary operation, idempotence means repeating an input does not change it: x∗x=x. An associative commutative idempotent operation defines a join order by x≤y⟺x∗y=y.

Commutativity

Words: 85 Articles: 2
Binary operation OurBigBook.com
A binary operation is commutative if a∗b=b∗a for every pair in its domain. A particular pair may commute even when the operation is not commutative. For example, ordinal addition and ordinal multiplication are not generally commutative.

Commuting elements (ab=ba)

Words: 28
Commutativity OurBigBook.com
Two elements commute when their two products in opposite orders agree. A particular pair of matrices may commute even when matrix multiplication is not a commutative operation on the whole set of matrices.

Noncommutativity (∃a,b: a∗b=b∗a)

Words: 27
Commutativity OurBigBook.com
A binary operation is noncommutative if some pair of elements fails to commute. Thus reversing their order can change the result. The same operation may still have many commuting elements.

Associative property ((a∗b)∗c=a∗(b∗c))

Words: 2k Articles: 37
Binary operation OurBigBook.com
The associative property says that regrouping three inputs does not change the result of a binary operation: (a∗b)∗c=a∗(b∗c) for every a,b,c in its domain of a function. It changes parentheses while keeping the order of the inputs. Commutativity instead exchanges two inputs; the two properties are different.
For addition modulo three, (2+1)+1≡2+(1+1)≡1(mod3). For subtraction modulo three,
(2−1)−1≡0,2−(1−1)≡2(mod3),
(1)
so the second binary operation fails the associative property. One failed triple disproves associativity; checking a few successful triples does not establish it for all inputs.
The useful consequence is that a finite ordered sequence can be combined in chunks. For an associative operation, (a∗b)∗(c∗d) has the same value as ((a∗b)∗c)∗d. Intermediate results can therefore summarize parts of a computation without retaining their internal parentheses. The order must still be preserved when the binary operation is not commutative. Function composition and concatenation provide examples where grouping is harmless but exchanging entries changes the result.

Semigroup ((S,∗))

Words: 2k Articles: 36
Associative property OurBigBook.com
A semigroup is an algebraic magma whose binary operation has the associative property. Its products can be regrouped while preserving the order of their elements. An identity element and inverse elements are not required.
For example, the positive integers with addition form a semigroup, since (a+b)+c=a+(b+c) and a sum of positive integers is positive. They have no identity element: it would have to be zero, which is outside that set. Nonempty words over an alphabet with concatenation give a noncommutative example without an identity element. Including the empty word instead gives a free monoid.
The usefulness of a semigroup is that an ordered list has one product regardless of its parentheses. This permits replacing a consecutive block by its already computed value. Here the empty set is also allowed as a semigroup; a monoid is necessarily nonempty because it contains an identity element.
Finite cancellative semigroup
Words: 50
Semigroup OurBigBook.com
A nonempty finite set with an associative binary operation satisfying both cancellation laws is a group. For fixed a, cancellation makes x↦ax and x↦xa injective, hence surjective. Choose e with ae=a. Then a(ex)=ax gives ex=x, and (xe)x=xx gives xe=x. Choose ab=e=ca; associativity gives c=c(ab)=(ca)b=b, so a has a two-sided inverse element.
Numerical semigroup
Words: 109 Articles: 1
Semigroup OurBigBook.com
A numerical semigroup is an additive subset of the nonnegative integers that contains zero and has finite complement. Positive generators with greatest common divisor one generate such a semigroup; the missing nonnegative integers are its gaps.
Consecutive-base induction for additive semigroups
Words: 78
Numerical semigroup OurBigBook.com
Suppose an additively closed subset M of the nonnegative integers contains a positive integer a and every integer from N to N+a−1. Then it contains every integer at least N. The first a values are the base cases. For n≥N+a, the smaller number n−a≥N belongs to M by strong induction, and closure under addition gives n=(n−a)+a∈M. Equivalently, write n=N+qa+r by division with remainder, with 0≤r<a; start at N+r∈M and add a exactly q times.
Rectangular band (x∗x=x,(x∗y)∗(z∗w)=x∗w)
Words: 115 Articles: 1
Semigroup OurBigBook.com
A rectangular band is a semigroup satisfying the displayed identities; these also imply associativity. Every nonempty such algebra is a product B×C with (b,c)∗(b′,c′)=(b,c′). Fixing e, the factor sets are B={x∗e} and C={e∗x}, and x↦(x∗e,e∗x) has inverse (b,c)↦b∗c. Homomorphisms between nonempty products are exactly pairs of maps on the two factors.
Cartesian closed category of rectangular bands
Words: 59
Rectangular band OurBigBook.com
The category of rectangular bands is Cartesian closed. For nonempty products A=B×C, D=E×F, the exponential is EB×FC. Also D0=1 and 0A=0 for nonempty A. It has no subobject classifier: the classifier would have two elements, hence would be left-zero or right-zero, while its characteristic maps on a two-by-two product could not single out a one-point subalgebra.
Idempotent element of a semigroup (e2=e)
Words: 54
Semigroup OurBigBook.com
An element of a semigroup is idempotent when multiplying it by itself leaves it unchanged. Every element of a left-zero or right-zero semigroup is idempotent, whereas a group has only its identity as an idempotent. The Ellis–Numakura lemma guarantees such an element in a nonempty compact one-sided topological semigroup. Additive idempotence on ultrafilters gives the idempotent ultrafilter relation p+p=p.
Semigroup presentation (⟨X∣ui​=vi​⟩)
Words: 224 Articles: 2
Semigroup OurBigBook.com
A semigroup presentation specifies generators X and equalities between nonempty words. The resulting semigroup is the quotient of the free semigroup X+ by the smallest congruence containing these equalities. Two words are equal precisely when one can be transformed into the other by finitely many replacements in contexts, using the defining equalities in either direction.
Finite semigroup presentation
Words: 170 Articles: 1
Semigroup presentation OurBigBook.com
A semigroup presentation is finite when both its generator set and its list of defining equalities are finite. A finite transition table for a Turing machine can be encoded this way: state-and-tape words simulate transitions, boundary rules supply blank cells, and halting-state rules erase the configuration to one distinguished symbol.
Semigroup simulation of a Turing machine (hq1​wh=q)
Words: 122
Finite semigroup presentation OurBigBook.com
A finite deterministic Turing machine can be represented by a finite semigroup presentation whose generators are tape symbols, state symbols, a boundary marker h, and an accept symbol q. Defining equalities replace the local scanned symbol and state according to machine instructions, with separate boundary cases for implicit blanks. Only terminal-state equalities erase tape letters and then replace hqH​h by q. A derivation from an initial description to q must encounter a terminal state before its first erasure. Simulation equalities preserve halting membership in either direction: for a deterministic transition C→D, C halts if and only if D halts. Thus reverse use of defining equalities cannot create a false halting certificate. Boundary and erasure rules require explicit checking for every chosen encoding.
Subsemigroup
Words: 40
Semigroup OurBigBook.com
A subsemigroup is a nonempty subset of a semigroup closed under its associative operation. In a compact Hausdorff space carrying a left-topological semigroup, descending chains of nonempty compact subsemigroups have a nonempty compact subsemigroup as their intersection. This supplies the minimal object used in the Ellis–Numakura lemma.
Monoid ((M,∗,e))
Words: 1k Articles: 20
Semigroup OurBigBook.com
A monoid is a semigroup with a two-sided identity element e: e∗a=a∗e=a for every element a. Associativity handles the grouping of a nonempty sequence; the identity element also supplies the result for an empty sequence. This makes the same rules apply to combining zero, one, or many contributions. [ref].
The nonnegative integers {0,1,2,…} with addition form a commutative monoid, with identity element zero. They do not form a group: a positive integer has no additive inverse in that set. All words over an alphabet with concatenation form a free monoid, whose identity element is the empty word. The full transformation monoid consists of all self-maps of a set, with function composition and the identity function.
These examples explain why monoids are useful: accumulation needs an operation and a starting value, but it need not be reversible. Adding counts, joining strings, and composing transformations all share the same grouping and identity laws. Requiring every element to have an inverse element gives a group, a stronger structure suitable for reversible operations.
Inverse element (a−1a=aa−1=e)
Words: 91
Monoid OurBigBook.com
An inverse element of a in a monoid is an element b satisfying a∗b=b∗a=e, where e is the identity element. Its notation is a−1. Some elements of a monoid can lack an inverse element; a group requires one for every element. Associativity makes a two-sided inverse element unique: if b,c both invert a, then b=b∗(a∗c)=(b∗a)∗c=c.
For the full transformation monoid, a self-map has an inverse element exactly when it is a bijection; that element is its inverse function. On {0,1}, the swap s(0)=1,s(1)=0 is its own inverse element, while a constant function has none because it merges the two inputs.
Transformation monoid (M⊆XX)
Words: 162 Articles: 1
Monoid OurBigBook.com
A transformation monoid is a collection of self-maps of a fixed set X that contains the identity function and is closed under function composition. The associative property comes from function composition. A monoid action describes transformations of a set that obey a monoid's multiplication and identity laws.
Full transformation monoid (TX​=XX)
Words: 128
Transformation monoid OurBigBook.com
The full transformation monoid consists of every self-map of X, with function composition as its binary operation. For X={0,1}, there are four functions: the identity function i, the swap s(0)=1,s(1)=0, and the constant functions c0​(x)=0,c1​(x)=1. Their composition order matters: c0​∘s=c0​, whereas s∘c0​=c1​. Thus associativity does not imply commutativity.
Only i and s are bijections, and their inverse elements are themselves. They form a two-element group within this monoid. The constant functions instead satisfy c0​∘c0​=c0​ and c1​∘c1​=c1​, so they are idempotent elements of a semigroup. Such irreversible transformations explain why the monoid setting is useful even when a group would be too restrictive.
Monoid action (M×A→A)
Words: 231 Articles: 5
Monoid OurBigBook.com
A left monoid action assigns each m∈M a map a↦m⋅a with 1⋅a=a and (mn)⋅a=m⋅(n⋅a). It need not be invertible or injective. A left M-set is equivalently a covariant functor from the one-object category determined by M.
Right monoid action (X×M→X,(xm)n=x(mn))
Words: 138 Articles: 2
Monoid action OurBigBook.com
A right monoid action has x1=x and (xm)n=x(mn). It is a contravariant functor from the one-object category of the monoid to sets. The regular right action is multiplication on M itself. Products of right actions use the diagonal action.
Exponential of right monoid actions (YX=HomM​(M×X,Y))
Words: 102 Articles: 1
Right monoid action OurBigBook.com
Give M×X the diagonal right monoid action. On its equivariant maps into Y, define (ek)(g,x)=e(kg,x). The evaluation map of an exponential object is e(1,x) and currying of h:Z×X→Y is h(z)(g,x)=h(zg,x). Both maps are equivariant, and they are inverse under evaluation. The left multiplication kg in this right action is essential in a noncommutative monoid.
Exponential of right group actions ((fg)(x)=f(xg−1)g)
Words: 52
Exponential of right monoid actions OurBigBook.com
For a group, evaluation at the identity identifies the monoid exponential with all set functions X→Y. Its inverse is ef​(g,x)=f(xg−1)g, and the resulting function action is the displayed formula. Fixed functions are precisely equivariant maps. The inverse on the input is necessary for equivariance of evaluation and for the right-action law.
Equivariant map of monoid sets (h(m⋅a)=m⋅h(a))
Words: 26
Monoid action OurBigBook.com
An equivariant map h:A→B between left M-sets obeys h(m⋅a)=m⋅h(a). These are the natural transformations of the corresponding functors from the one-object monoid category.
M-set (m⋅a)
Words: 24
Monoid action OurBigBook.com
An M-set is a set carrying a monoid action. This terminology here uses left actions. Morphisms are equivariant maps of monoid sets, and the resulting functor category [M,Set] is an elementary topos.
Monoid homomorphism (h(xy)=h(x)h(y),h(1M​)=1N​)
Words: 32
Monoid OurBigBook.com
A monoid homomorphism h:M→N preserves multiplication and identity: h(xy)=h(x)h(y) and h(1M​)=1N​. It therefore preserves every finite ordered product, including the empty product. The monoids with these maps form the category Mon.
Monoid automorphism
Words: 46
Monoid OurBigBook.com
A monoid automorphism is a bijective operation- and identity-preserving self-map of a monoid. Its inverse is also a monoid homomorphism. Permuting prime numbers and extending by prime factorization gives all automorphisms of the multiplicative monoid of positive natural numbers; extending by 0↦0 gives automorphisms of the multiplicative monoid including zero.
Free monoid (Σ∗)
Words: 169
Monoid OurBigBook.com
The free monoid Σ∗ on an alphabet Σ consists of all finite words over an alphabet, including the empty word ε, with concatenation as its binary operation. Distinct strings represent distinct elements: there are no imposed equalities between different sequences of letters. The empty word is its identity element, and concatenation has the associative property.[ref]
For Σ={a,b}, the elements begin ε,a,b,aa,ab,ba,bb,…. Both (ab)a and a(ba) give the same word aba, but ab=ba, so this monoid is not commutative. The length of a word over an alphabet obeys ℓ(uv)=ℓ(u)+ℓ(v); it is a monoid homomorphism to the nonnegative integers with addition. A nonempty word has no inverse element, since joining it to any other word cannot decrease its length to zero.
The defining benefit of being free is that letters can stand for arbitrary elements of another monoid. Choose a value h(a) for each letter a∈Σ; then h(a1​⋯an​)=h(a1​)∗⋯∗h(an​), with h(ε)=e, is the unique monoid homomorphism extending those choices. Associativity and the identity element make this evaluation consistent for every finite word. For example, interpreting the letters as self-maps evaluates a word as a composed transformation; interpreting them as nonnegative counts evaluates it by addition.
Commutative monoid
Words: 386 Articles: 7
Monoid OurBigBook.com
A commutative monoid is a monoid whose operation is commutative. The natural numbers with addition form a commutative monoid that is not an abelian group, because positive elements have no additive inverses.
Free commutative monoid (Nd)
Words: 40
Commutative monoid OurBigBook.com
The free commutative monoid on d generators consists of the nonnegative integral sums of those generators, with unique coefficients. Its semigroup algebra over a commutative ring is the polynomial ring in d variables. In a smooth toric chart, the dual-cone lattice points form such a monoid, yielding affine-space coordinates.
Cancellative commutative monoid (a+c=b+c⟹a=b)
Words: 218 Articles: 4
Commutative monoid OurBigBook.com
A commutative monoid is cancellative when a+c=b+c implies a=b. Cancellation makes the natural map into its Grothendieck group injective.
Congruence submonoid of the positive integers (Sm​={n≥1:n≡1(modm)})
Words: 113 Articles: 1
Cancellative commutative monoid OurBigBook.com
For an integer m≥2, the positive integers congruent to one modulo m form a cancellative commutative monoid under multiplication. The identity is one, and it is the only unit. Proper factors outside this congruence class do not witness reducibility inside the monoid. Hence irreducible elements of a commutative monoid need not coincide with ordinary prime numbers.
Nonunique factorization in a congruence submonoid (21⋅221=51⋅91)
Words: 66
Congruence submonoid of the positive integers OurBigBook.com
The congruence submonoid of the positive integers with modulus ten has four distinct irreducible elements of a commutative monoid 21,221,51,91 with equal pairwise products. Their ordinary prime factors are respectively (3,7),(13,17),(3,17),(7,13). None of these proper prime factors is congruent to one modulo ten. The Euclid lemma proves that a product of two distinct primes has no other proper positive divisors, so all four are irreducible in this monoid. This gives nonunique factorization without assuming the fundamental theorem of arithmetic.
Irreducible element of a commutative monoid (a=bc⟹b∈M× or c∈M×)
Words: 52
Cancellative commutative monoid OurBigBook.com
A nonunit element of a commutative monoid is irreducible if each factorization has a unit factor. In a submonoid of the positive integers under multiplication, the only unit is one. Irreducibility is relative to the allowed factors: a composite integer can be irreducible in a smaller monoid even though it is not a prime number.
Torsion-free cancellative commutative monoid (na=nb⟹a=b)
Words: 37
Cancellative commutative monoid OurBigBook.com
A cancellative commutative monoid is torsion-free in this sense when na=nb implies a=b for every positive integer n. Its Grothendieck group is then a torsion-free abelian group, because n(a−b)=0 forces na=nb. This is the condition inherited by a submonoid of a torsion-free abelian group.
Category of commutative monoids (CMon)
Words: 98
Commutative monoid OurBigBook.com
This category has commutative monoids and their homomorphisms. Pointwise addition makes each hom-set a commutative monoid, and composition is additive in both variables. Finite cartesian products are also coproducts, using the coordinate injections with zero in the other coordinates and summing images. Therefore it is a semi-additive category, but it is not an additive category. The reflexive pair from the submonoid {(m,n):m≤n≤2m} of N2 to N, using the two projections and section m↦(m,m), has an arrow from 1 to 2 and none from 2 to 1 in its represented graph. Thus a reflexive pair here need not yield a groupoid.

Face of an additive monoid
Words: 58
Additive semigroup OurBigBook.com
A face F of an additive monoid S is a submonoid such that a+b∈F implies a,b∈F. If S=C∩M for a rational polyhedral cone, its faces are precisely S∩ν for faces ν of C. Finite generation and clearing rational denominators identify these monoid faces with the exposed faces of the cone.

Ellis–Numakura lemma
Words: 39
Left-topological semigroup OurBigBook.com
Every nonempty compact Hausdorff left-topological semigroup contains an idempotent. Choose a minimal nonempty compact subsemigroup K. For a∈K, minimality gives Ka=K; the nonempty compact subsemigroup {x∈K:xa=a} is therefore all of K, so a2=a.
