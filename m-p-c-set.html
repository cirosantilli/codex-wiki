M-p-c set ((m,p,c)-set)

 ... Mathematics Area of mathematics Combinatorics Ramsey theory Partition regular matrix Columns property
OurBigBook.com Words: 261 Articles: 4
An (m,p,c)-set has positive integer generators z1​,…,zm​ chosen so that every expression below is positive, and consists of all their values:
czj​+∑s>j​λs​zs​,λs​∈Z,∣λs​∣≤p.
(13)
The required positivity is equivalent to czj​>p∑s>j​zs​ for each j; it is not defined by discarding nonpositive values from the displayed family.
