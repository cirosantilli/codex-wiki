Normal-form game

 Home Mathematics Area of mathematics Mathematical optimization Game theory
OurBigBook.com Words: 833 Articles: 8
A normal-form game specifies each player's strategy set and their payoff for every strategy profile. In a finite two-player game these data form a bimatrix game; if the two payoffs always sum to zero, one payoff matrix describes the matrix game. The representation specifies choices and incentives, without a temporal order of observed moves.
