A cubic root from existence to a quantitative bracket (f(x)=x3+x−1)

 ... Analysis Real analysis Calculus Limit of a function Continuous function Intermediate value theorem
OurBigBook.com Words: 233
Consider the original worked example f(x)=x3+x−1 on [0,1]. First, existence: a polynomial function is a continuous function, and f(0)=−1<0<1=f(1). The intermediate value theorem therefore supplies a zero of a function r∈(0,1), even before its value has been calculated.
Second, uniqueness is a separate argument. The derivative is f′(x)=3x2+1>0. The derivative criterion for monotonicity, obtained from the mean value theorem, makes f a strictly increasing function. Two distinct zeros of a function would contradict that strict increase. Thus this root bracket contains exactly one zero of a function; indeed the same derivative argument proves uniqueness on the entire real line.
Third, localization uses the existing bisection method. Set [a0​,b0​]=[0,1]; after k completed halvings, retain [ak​,bk​] with opposite endpoint signs. Each update tests the old midpoint mk−1​=(ak−1​+bk−1​)/2. The first five exact updates are

Every retained root bracket contains r by the intermediate value theorem. After ten halvings, exact arithmetic gives
a10​=512349​,b10​=1024699​,f(a10​)=−134217728220923​<0,f(b10​)=1073741824744899​>0.

Hence 0.681640625<r<0.6826171875. The new midpoint and its bisection error bound are
m10​=20481397​=0.68212890625,∣m10​−r∣≤20481​=0.00048828125.
(78)
This midpoint is the estimate after the tenth update; the last tested point was m9​=699/1024. In general the retained width is 2−k, so the bisection error bound is 2−(k+1). Nine halvings already suffice for an error at most 10−3, since 2−10=0.0009765625<10−3. This guarantee comes from the width of the root bracket, independently of any displayed decimal approximation to the unknown zero of a function. Endpoint signs must be established reliably if evaluations use floating-point arithmetic.
