Weight enumerator (WC​(s,t))

 Home Mathematics Area of mathematics Algebra Coding theory Linear code
OurBigBook.com Words: 71 Articles: 1
The homogeneous weight enumerator of a length-n linear code C is the polynomial
WC​(s,t)=∑x∈C​swt(x)tn−wt(x).
(14)
Its coefficients count words of each Hamming weight. In this convention WC​(1,1)=∣C∣; some references interchange s,t.
