Type IIB superstring theory (N=(2,0) in ten dimensions)

 Home Physics Branches of physics String theory Type II string theory
OurBigBook.com Words: 267 Articles: 5
A closed superstring theory whose left and right Ramond projections have the same ten-dimensional chirality. It has 32 real supercharges and is chiral. Its low-energy fields form type IIB supergravity. Circle T-duality exchanges this theory with type IIA superstring theory.
