Full second-order replacement rank obstruction (Vλ​⊨ZFC2⟹λ inaccessible)

 Home Mathematics Area of mathematics Foundations of mathematics Set theory Axiom schema of replacement
OurBigBook.com Words: 62
If Vλ​, for an infinite cardinal number λ, satisfies Axiom schema of replacement for every external functional class, then an external cofinal function from an ordinal below λ cannot exist: its range would have rank of a set λ and would have to belong to Vλ​. Similarly, a surjection P(θ)→λ with θ<λ is impossible. Infinity therefore makes λ an uncountable regular cardinal and a strong limit cardinal. Full semantics for second-order logic, allowing arbitrary external functional relations, is essential.
