Statistical separation of objects in clutter

 ... Probability and statistics Statistical model Statistical modelling Statistical learning Unsupervised learning Competitive learning
OurBigBook.com Words: 78
Independently varying companions can make an individual object’s features more consistently related than the features of any particular multi-object conjunction. Competitive networks can exploit this difference to learn separate object representations without being shown each object in isolation. The result depends on the training distribution; a fixed co-occurring group can instead be learned as a conjunction.[ref][ref]
