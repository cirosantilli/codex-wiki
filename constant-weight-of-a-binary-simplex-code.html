Constant weight of a binary simplex code (wt(aH)=2l−1(a=0))

 ... Area of mathematics Algebra Coding theory Linear code Hamming code Binary simplex code
OurBigBook.com Words: 69
When the columns of H are every nonzero vector in F2l​, a nonzero row vector a defines a nonzero linear functional v↦a⋅v. Exactly half the 2l input vectors take value 1: translation by any vector on which the functional is 1 pairs its zero and one fibres. Removing the zero input removes only a zero value. Thus every nonzero word in the binary simplex code has Hamming weight 2l−1.
