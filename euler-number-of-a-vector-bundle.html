Euler number of a vector bundle (⟨e(E),[B]⟩)

 ... Algebraic topology Fiber bundle Vector bundle Orientation of a vector bundle Thom class Euler class of a vector bundle
OurBigBook.com Words: 45
When an oriented rank-d vector bundle E has a closed oriented d-dimensional base B, its Euler number is the integer obtained by evaluating the Euler class of a vector bundle on the fundamental class of B. A nonzero Euler number obstructs a nowhere-zero section and therefore obstructs a framing.
