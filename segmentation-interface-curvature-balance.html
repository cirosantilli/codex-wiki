Segmentation interface curvature balance (βκ=(cj​−g)2−(ci​−g)2)

 Home Computer science Image processing Variational image processing Mumford–Shah functional Piecewise-constant Mumford–Shah problem
OurBigBook.com Words: 114 Articles: 1
When grey values are fixed but region labels vary, a smooth interface satisfies βκ=(cj​−g)2−(ci​−g)2. The curvature uses the normal pointing out of region i, positive on an outward-oriented circle. It balances the change in data cost against the first variation of interface length. Fixing a full spatial image signal instead fixes its jumps and leaves no such boundary-relocation freedom.
