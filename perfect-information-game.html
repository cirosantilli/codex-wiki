Perfect-information game

 Home Mathematics Area of mathematics Mathematical optimization Game theory
OurBigBook.com Words: 31
An extensive-form game in which each information set contains a single decision node. Each acting player knows the entire preceding sequence of moves. Finite games with this property can be solved for a subgame perfect equilibrium by backward induction.
