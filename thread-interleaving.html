Thread interleaving

 ... Computer science Operating system Process (computing) Thread (computing) Synchronization (computing) Mutual exclusion
OurBigBook.com Words: 126 Articles: 1
An ordered execution obtained by mixing steps of several software threads while retaining each one's own step order. In the sequential consistency model of mutual exclusion, an indivisible step finishes before the next begins. Selecting the step boundaries is part of the model: an atomic read-modify-write increment has one boundary, whereas a separate read, local addition and write have three. Enumerating all such orders checks this specified model, not an arbitrary memory model or a real mutex implementation.
