Axis-aligned bounding box (B=∏i=1d​[mi​,Mi​])

 ... Mathematics Area of mathematics Analysis Numerical analysis Computer aided geometric design Bounding volume
OurBigBook.com Words: 309
An axis-aligned bounding box is a Cartesian product of closed intervals aligned with a chosen Cartesian coordinate system:
B=∏i=1d​[mi​,Mi​],mi​≤Mi​.
(36)
Only the two opposite corners (m1​,…,md​) and (M1​,…,Md​) need to be stored. In two dimensions it is a rectangle. Changing the Cartesian coordinate system can change how tightly the axis-aligned bounding box fits the same object.[ref]
For a nonempty finite set of points P, the smallest such axis-aligned bounding box has
mi​=minp∈P​pi​,Mi​=maxp∈P​pi​.
(37)
These minimum and maximum values also enclose the convex hull of P: each coordinate of a convex combination lies between the smallest and largest input coordinates. In particular, three vertices of a polygon determine the axis-aligned bounding box of a filled triangle. For a general nonempty compact set, the same formulas use all its points; inspecting only an arbitrary finite sample is insufficient.
Given nonempty boxes B=∏i​[mi​,Mi​] and C=∏i​[ni​,Ni​], the closed interval convention gives
B∩C=∅⟺max(mi​,ni​)≤min(Mi​,Ni​)for every i.
(38)
Equivalently, reject as soon as Mi​<ni​ or Ni​<mi​ in any coordinate. The surviving set intersection has endpoints max(mi​,ni​) and min(Mi​,Ni​). This is an exact box test, while its conclusion about enclosed objects remains a conservative enclosure test.[ref]
Equality counts as touching: [0,1]×[0,1] and [1,2]×[0,1] share an edge, so their set intersection is nonempty. Replacing every ≤ in the overlap formula by < tests intersection of the interiors of full-dimensional boxes and excludes this contact. A zero-width closed interval can represent a point or a lower-dimensional enclosure, and must not automatically be discarded when touching counts. A box with some mi​>Mi​ is empty; test emptiness before applying rules intended for nonempty boxes. The broad phase must retain touching candidates whenever the narrow phase counts touching as a hit.
For nonempty boxes, the smallest enclosing axis-aligned bounding box of their set union is
∏i=1d​[min(mi​,ni​),max(Mi​,Ni​)].
(39)
This operation supplies the parent boxes in a bounding volume hierarchy. It is an enclosure of the set union, rather than generally the set union itself. In floating-point arithmetic, comparisons are conclusive only for endpoints that still enclose the intended exact objects; use certified bounds such as interval arithmetic with outward rounding when that guarantee is required.
