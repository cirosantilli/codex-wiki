The quasi-steady-state approximation for Y sets Y=aY​h(X;KXY​,nXY​). Substituting into the Z equation gives
dtdZ​=aZ​h(X;KXZ​,nXZ​)h(aY​h(X;KXY​,nXY​);KYZ​,nYZ​)−Z.
(16)
Its equilibrium concentration is therefore
ZAND∗​(X)=aZ​KXZnXZ​​+XnXZ​XnXZ​​KYZnYZ​​+(aY​XnXY​/(KXYnXY​​+XnXY​))nYZ​(aY​XnXY​/(KXYnXY​​+XnXY​))nYZ​​​.
(17)
For constant input this is also the exact equilibrium of the full two-variable model: the fast-Y assumption is needed to replace the transient dynamics, not to calculate a fixed point.
Relative to the direct-activation result, ZAND∗​=Zdirect∗​h(Y∗;KYZ​,nYZ​)≤Zdirect∗​​. The extra activation gate suppresses the response at low input and can sharpen its rise. The high-input limit is aZ​h(aY​;KYZ​,nYZ​), which need not reach aZ​ because Y∗ saturates at aY​.
For the parameters in part (d), the following Python continuation plots the expression and changes each Hill constant separately:
def z_equilibrium(X, Kxy=1, Kxz=2, Kyz=1):
    Yeq = 2 * hill(X, Kxy, 2)
    return 3 * hill(X, Kxz, 4) * hill(Yeq, Kyz, 4)

Increasing KXY​ lowers Y∗ at fixed finite X, delaying opening of the indirect gate. Increasing KXZ​ delays opening of the direct gate. Neither changes the limiting response as X→∞, provided the constants remain finite. Increasing KYZ​ makes a given Y less effective and also lowers the high-input plateau. These changes are visible in the preceding figure. At small X, the response is proportional to XnXZ​+nXY​nYZ​, while both gates are far below saturation, explaining the increased low-input suppression.
For a persistence detector, retain finite Y dynamics and use, for example,
aY​=aZ​=1,KXY​=KXZ​=1,nXY​=nXZ​=4,KYZ​=0.7,nYZ​=8​,
(18)
with unit loss rates, Xoff​=0, Xon​=2, and initially Y=Z=0. On switching the input on, Y∞​=16/17 and
Y(t)=1716​(1−e−t).
(19)
The time to reach the half-activation threshold of the indirect gate is
tgate​=−log(1−16/170.7​)=log(160/41)≈1.362​.
(20)
An isolated input pulse of duration 0.25 ends well before this threshold; a duration-four pulse persists long enough to open the gate. The large but finite Hill coefficient makes this a graded filter, not a perfectly sharp cutoff. Once X vanishes, its direct gate closes immediately and stops production of Z, which then decays with time constant one. The protein output itself does not drop discontinuously. This delayed-on, prompt-production-off mechanism is the characteristic persistence detector interpretation of an AND-type coherent feed-forward loop.[ref]
This final Python continuation simulates both pulse durations. Each discontinuity is placed on the time grid and the input is held constant within each integration step:
def persistence_rhs(state, X):
    Y, Z = state
    return np.array([hill(X, 1, 4) - Y,
                     hill(X, 1, 4)*hill(Y, 0.7, 8) - Z])

def pulse_trajectory(duration, dt=0.005):
    times = np.arange(round(8/dt) + 1) * dt
    out = np.zeros((len(times), 2))
    for j in range(len(times)-1):
        X = 2.0 if 1 <= times[j] + dt/2 < 1 + duration else 0.0
        # Each step is integrated with its constant input.
        out[j+1] = integrate(lambda s: persistence_rhs(s, X),
                             out[j], [0, dt])[-1]
    return times, out

fig, axes = plt.subplots(1, 2, figsize=(10, 4))
for duration in [0.25, 4]:
    times, out = pulse_trajectory(duration)
    axes[0].plot(times, out[:, 0], label=f"Y, duration {duration}")
    axes[1].plot(times, out[:, 1], label=f"Z, duration {duration}")
    print(duration, "maximum output", out[:, 1].max())
axes[0].axhline(0.7, color="black", linestyle=":")
for ax in axes:
    ax.set_xlabel("Time")
    ax.set_ylabel("Concentration")
    ax.legend()
plt.tight_layout()
plt.show()
The chosen example produces peak Z of about 1.72×10−6 for the short pulse and 0.766 for the long pulse. These are original illustrative simulations, not fitted experimental measurements.
Finally, the strict instantaneous-Y reduction used for the equilibrium calculation has no separate intermediate accumulation delay. Its remaining one-variable dynamics can still attenuate short pulses through ordinary output relaxation, but it cannot demonstrate the additional delay caused by finite Y buildup. The pulse test therefore uses the full two-variable model.
