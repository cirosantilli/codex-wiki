Two assumptions of the usual normal linear model used for the reported coefficient Student t-tests are:
  • The errors are independent random variables across mice.
  • Conditional on the predictors, each error has a normal distribution with mean zero and the same variance σ2: εi​∣wi​,si​∼N(0,σ2).
The second statement includes homoscedasticity. Normality concerns the conditional errors, rather than requiring the weights themselves to have a normal distribution.

The identity
∑i​(xi​−μ)2=∑i​(xi​−xˉ)2+n(μ−xˉ)2
(4)
shows that the likelihood function is a bell-shaped curve in μ, maximized at the sample mean, with width 1/n​. Its actual vertical scale also depends on the within-sample sum of squares.
Continue the R script with:
sse <- sum((x - xbar)^2)

  -n/2 * log(2*pi) - 0.5 * (sse + n * (mu - xbar)^2)

The exponential distribution prior has rate λ=1/3 and support μ≥0, so its prior density is (1/3)e−μ/31{μ≥0}​. By Bayes' theorem,
p(μ∣x)=Cexp[−21​i∑​(xi​−μ)2−3μ​]1{μ≥0}​​,
(5)
where C is a normalizing constant independent of μ.
Completing the square gives a useful exact reference for the numerical sampling. Put
m=xˉ−3n1​,s=n​1​.
(6)
Then this normal mean posterior with an exponential prior is a normal distribution with location m and variance s2, truncated below at zero. With ϕ the standard normal distribution density and Φ its cumulative distribution function,
p(μ∣x)=sΦ(m/s)ϕ((μ−m)/s)​1{μ≥0}​​.
(7)
The exponential rate is 1/3, not three; the prior mean is three. The support restriction must be retained in both the formula and the sampler.

Use the random-walk Metropolis algorithm with proposal μ′=μ+ε, where ε∼N(0,1). The proposal is symmetric, so for a nonnegative proposal the acceptance probability is
a(μ,μ′)=min{1,exp[ℓp​(μ′)−ℓp​(μ)]}​,ℓp​(u)=−21​∑i​(xi​−u)2−3u​.
(8)
Negative proposals are rejected. They are not redrawn until positive, since that would change the proposal kernel and require a different acceptance ratio. On rejection, store the current state again; keeping accepted moves alone would bias the empirical posterior distribution.
This R continuation makes exactly 10,000 proposals, starting at μ0​=4:
set.seed(20240528)
B <- 10000L
mu <- numeric(B + 1L)
mu[1L] <- 4
logpost <- function(u) {
  if (!is.finite(u) || u < 0) return(-Inf)
  loglik(u) - u/3
}
lp <- logpost(mu[1L])
accepted <- 0L
for (i in seq_len(B)) {
  proposal <- rnorm(1L, mean = mu[i], sd = 1)
  lp_new <- logpost(proposal)
  if (log(runif(1L)) < min(0, lp_new - lp)) {
    mu[i + 1L] <- proposal
    lp <- lp_new
    accepted <- accepted + 1L
  } else {
    mu[i + 1L] <- mu[i]
  }
}
cat("Acceptance fraction =", accepted/B, "\n")
# A provisional discard; assess it with the trace in part (e).
burn <- 1000L
post <- mu[(burn + 2L):(B + 1L)]
m <- xbar - 1/(3*n)
s <- 1/sqrt(n)
posterior_density <- function(u) {
  ans <- numeric(length(u))
  ok <- u >= 0
  ans[ok] <- exp(dnorm(u[ok], m, s, log = TRUE) -
                   pnorm(m/s, log.p = TRUE))
  ans
}
png("q2-posterior.png", width = 900, height = 600)
hist(post, breaks = 40, probability = TRUE, xlab = expression(mu),
     main = "Retained Metropolis draws and exact posterior")
u <- seq(0, max(post) + 3*s, length.out = 4001L)
lines(u, posterior_density(u), col = "firebrick", lwd = 2)
dev.off()
The exact truncated normal distribution density overlays the histogram as a check; it does not replace the requested Markov chain Monte Carlo procedure. The 9,000 retained states exclude the initial state and the first 1,000 transitions. The particular histogram and acceptance fraction remain dependent on the missing measurements.

A satisfactory trace plot should show an initial transient, if any, followed by repeated exploration of one stable range with no continuing drift. Repeated values are expected because rejections are stored. If n is large, the prescribed proposal standard deviation one can be much wider than the posterior scale 1/n​, giving low acceptance and conspicuous plateaus. A flat-looking trace is therefore not by itself evidence of good exploration.
Compare the retained histogram with the exact posterior density, inspect autocorrelation, compare separate retained windows, and assess sensitivity to the discarded count. Agreement supports the adequacy of this run; neither 10,000 iterations nor a chosen burn-in of 1,000 proves convergence. The effective sample size of a Markov chain can be much smaller than the number of stored states.
The actual trace cannot be diagnosed without Iris_data.csv. The code produces the required trace when the measurements are available; the comments here specify what to examine rather than asserting an unseen chain has converged.

Treat X≥0 as a prescribed input protein concentration, and Y(t),Z(t)≥0 as the downstream gene-product concentrations. Define the Hill activation function
h(u;K,n)=Kn+unun​,K>0,n>0.
(11)
A minimal model with no basal expression is
dtdY​=aY​h(X;KXY​,nXY​)−Y,dtdZ​=aZ​h(X;KXZ​,nXZ​)−Z​.
(12)
Here aY​,aZ​>0 are maximal production rates, KXY​,KXZ​ are Hill constants with the same units as X, and nXY​,nXZ​ are dimensionless Hill coefficients. The negative terms describe a first-order reaction for loss of each gene product, with both rate constants set to one in the chosen time units. Thus aY​,aZ​ have units of concentration per time and the unit loss rates have units of inverse time.
The equations model regulation of gene expression at the level of its effective protein output, without separate messenger RNA dynamics. The independent branches mean that neither Y nor Z regulates the other in this initial model. Additive basal production could be included, but is not required by the question and is set to zero throughout this example.

For a constant X, set both ordinary differential equation derivatives to zero:
Y∗(X)=aY​KXYnXY​​+XnXY​XnXY​​,Zdirect∗​(X)=aZ​KXZnXZ​​+XnXZ​XnXZ​​​.
(13)
These equilibrium concentrations are unique for each input. For a loss rate γ other than one, divide the corresponding production term by γ.
Choose aY​=2, KXY​=1, nXY​=2 and aZ​=3, KXZ​=2, nXZ​=4. The following Python code plots the requested equilibrium concentrations and defines the functions used in part (c):
import numpy as np
import matplotlib.pyplot as plt

def hill(u, K, n):
    u = np.asarray(u)
    return u**n / (K**n + u**n)

X_grid = np.linspace(0, 5, 501)
Y_eq = 2 * hill(X_grid, 1, 2)
Z_eq = 3 * hill(X_grid, 2, 4)
plt.figure(figsize=(6, 4))
plt.plot(X_grid, Y_eq, label="Y equilibrium: K=1, n=2")
plt.plot(X_grid, Z_eq, label="Z equilibrium: K=2, n=4")
plt.xlabel("X concentration")
plt.ylabel("Equilibrium concentration")
plt.legend()
plt.tight_layout()
plt.show()
The Hill constant sets the half-maximum input: Y∗(1)=1 and Zdirect∗​(2)=1.5. Increasing that constant shifts activation toward larger X. The Hill coefficient changes steepness rather than the half-maximum position; the normalized slope at X=K is n/(4K). Because the two examples also differ in K and maximal production, compare normalized responses when isolating the effect of n alone. Both curves vanish at zero and saturate toward their respective maxima.

At a fixed input the production terms are constant, so both linear ordinary differential equations can also be solved exactly:
Y(t)=Y∗+[Y(0)−Y∗]e−t,Z(t)=Zdirect∗​+[Z(0)−Zdirect∗​]e−t​.
(14)
Each displacement from its equilibrium concentration decays with time constant one. The Jacobian matrix is −I, with two eigenvalues equal to −1, so the fixed point is globally asymptotically stable for the nonnegative state space.
Here is a numerical solver using the classical fourth-order Runge-Kutta method; it uses only the repository's existing NumPy and matplotlib dependencies. Continue the definitions from part (b):
def integrate(rhs, initial, times):
    out = np.empty((len(times), len(initial)))
    out[0] = initial
    for j, dt in enumerate(np.diff(times)):
        state = out[j]
        k1 = rhs(state)
        k2 = rhs(state + dt*k1/2)
        k3 = rhs(state + dt*k2/2)
        k4 = rhs(state + dt*k3)
        out[j+1] = state + dt*(k1 + 2*k2 + 2*k3 + k4)/6
    return out

def direct_rhs(state, X):
    Y, Z = state
    return np.array([2*hill(X, 1, 2) - Y,
                     3*hill(X, 2, 4) - Z])

times = np.linspace(0, 8, 801)
plt.figure(figsize=(7, 4))
for initial, style in [([0, 0], "-"), ([3, 4], "--")]:
    trajectory = integrate(lambda s: direct_rhs(s, 2), initial, times)
    exact = np.array([1.6, 1.5]) + (np.array(initial) - [1.6, 1.5]) \
            * np.exp(-times[:, None])
    assert np.max(np.abs(trajectory - exact)) < 1e-8
    plt.plot(times, trajectory[:, 0], style, label=f"Y, initial {initial}")
    plt.plot(times, trajectory[:, 1], style, label=f"Z, initial {initial}")
plt.xlabel("Time")
plt.ylabel("Concentration")
plt.legend()
plt.tight_layout()
plt.show()

Over eight time units the initial displacement is reduced by e−8≈0.000335, explaining why both trajectories nearly coincide with the equilibria from part (b). The two-panel figure above displays these simulations.

Add the activating link from Y to Z and multiply the two Hill activation functions for the target:
dtdY​=aY​h(X;KXY​,nXY​)−Y,dtdZ​=aZ​h(X;KXZ​,nXZ​)h(Y;KYZ​,nYZ​)−Z​.
(15)
The extra Hill constant KYZ​>0 has units of Y concentration and nYZ​>0 is its Hill coefficient. Both inputs are required for substantial target production: if either is zero, the production term for Z vanishes. This all-activating circuit is a coherent feed-forward loop. A product of graded input functions implements the specified AND rule; it is a phenomenological rule rather than a complete molecular promoter model.
Retain the parameter values of parts (b) and (c), and set KYZ​=1, nYZ​=4. Continue the same Python script with the altered right-hand side:
def and_rhs(state, X):
    Y, Z = state
    return np.array([2*hill(X, 1, 2) - Y,
                     3*hill(X, 2, 4)*hill(Y, 1, 4) - Z])

times = np.linspace(0, 10, 1001)
plt.figure(figsize=(7, 4))
for X in [1, 3]:
    trajectory = integrate(lambda s: and_rhs(s, X), [0, 0], times)

    plt.plot(times, trajectory[:, 1], label=f"Z, X={X}")

In both simulations Y first accumulates and opens the additional gate; Z therefore initially grows more slowly than under direct activation alone. The equilibrium concentration of Y is unchanged by the added outgoing interaction.

The quasi-steady-state approximation for Y sets Y=aY​h(X;KXY​,nXY​). Substituting into the Z equation gives
dtdZ​=aZ​h(X;KXZ​,nXZ​)h(aY​h(X;KXY​,nXY​);KYZ​,nYZ​)−Z.
(16)
Its equilibrium concentration is therefore
ZAND∗​(X)=aZ​KXZnXZ​​+XnXZ​XnXZ​​KYZnYZ​​+(aY​XnXY​/(KXYnXY​​+XnXY​))nYZ​(aY​XnXY​/(KXYnXY​​+XnXY​))nYZ​​​.
(17)
For constant input this is also the exact equilibrium of the full two-variable model: the fast-Y assumption is needed to replace the transient dynamics, not to calculate a fixed point.
Relative to the direct-activation result, ZAND∗​=Zdirect∗​h(Y∗;KYZ​,nYZ​)≤Zdirect∗​​. The extra activation gate suppresses the response at low input and can sharpen its rise. The high-input limit is aZ​h(aY​;KYZ​,nYZ​), which need not reach aZ​ because Y∗ saturates at aY​.
For the parameters in part (d), the following Python continuation plots the expression and changes each Hill constant separately:
def z_equilibrium(X, Kxy=1, Kxz=2, Kyz=1):
    Yeq = 2 * hill(X, Kxy, 2)
    return 3 * hill(X, Kxz, 4) * hill(Yeq, Kyz, 4)

X_grid = np.linspace(0, 5, 501)
plt.figure(figsize=(7, 4))
plt.plot(X_grid, 3*hill(X_grid, 2, 4), ":", label="Direct activation")
for parameters, label in [((1, 2, 1), "Baseline"),
                          ((2, 2, 1), "Kxy=2"),
                          ((1, 3, 1), "Kxz=3"),
                          ((1, 2, 2), "Kyz=2")]:
    plt.plot(X_grid, z_equilibrium(X_grid, *parameters), label=label)
plt.xlabel("X concentration")
plt.ylabel("Equilibrium Z")
plt.legend()
plt.tight_layout()

Increasing KXY​ lowers Y∗ at fixed finite X, delaying opening of the indirect gate. Increasing KXZ​ delays opening of the direct gate. Neither changes the limiting response as X→∞, provided the constants remain finite. Increasing KYZ​ makes a given Y less effective and also lowers the high-input plateau. These changes are visible in the preceding figure. At small X, the response is proportional to XnXZ​+nXY​nYZ​, while both gates are far below saturation, explaining the increased low-input suppression.

aY​=aZ​=1,KXY​=KXZ​=1,nXY​=nXZ​=4,KYZ​=0.7,nYZ​=8​,
(18)
with unit loss rates, Xoff​=0, Xon​=2, and initially Y=Z=0. On switching the input on, Y∞​=16/17 and
Y(t)=1716​(1−e−t).
(19)

tgate​=−log(1−16/170.7​)=log(160/41)≈1.362​.
(20)
An isolated input pulse of duration 0.25 ends well before this threshold; a duration-four pulse persists long enough to open the gate. The large but finite Hill coefficient makes this a graded filter, not a perfectly sharp cutoff. Once X vanishes, its direct gate closes immediately and stops production of Z, which then decays with time constant one. The protein output itself does not drop discontinuously. This delayed-on, prompt-production-off mechanism is the characteristic persistence detector interpretation of an AND-type coherent feed-forward loop.[ref]
This final Python continuation simulates both pulse durations. Each discontinuity is placed on the time grid and the input is held constant within each integration step:
def persistence_rhs(state, X):
    Y, Z = state
    return np.array([hill(X, 1, 4) - Y,
                     hill(X, 1, 4)*hill(Y, 0.7, 8) - Z])

def pulse_trajectory(duration, dt=0.005):
    times = np.arange(round(8/dt) + 1) * dt
    out = np.zeros((len(times), 2))
    for j in range(len(times)-1):
        X = 2.0 if 1 <= times[j] + dt/2 < 1 + duration else 0.0
        # Each step is integrated with its constant input.
        out[j+1] = integrate(lambda s: persistence_rhs(s, X),
                             out[j], [0, dt])[-1]
    return times, out

fig, axes = plt.subplots(1, 2, figsize=(10, 4))
for duration in [0.25, 4]:
    times, out = pulse_trajectory(duration)
    axes[0].plot(times, out[:, 0], label=f"Y, duration {duration}")
    axes[1].plot(times, out[:, 1], label=f"Z, duration {duration}")
    print(duration, "maximum output", out[:, 1].max())
axes[0].axhline(0.7, color="black", linestyle=":")
for ax in axes:
    ax.set_xlabel("Time")
    ax.set_ylabel("Concentration")
    ax.legend()
plt.tight_layout()
plt.show()
The chosen example produces peak Z of about 1.72×10−6 for the short pulse and 0.766 for the long pulse. These are original illustrative simulations, not fitted experimental measurements.
Finally, the strict instantaneous-Y reduction used for the equilibrium calculation has no separate intermediate accumulation delay. Its remaining one-variable dynamics can still attenuate short pulses through ordinary output relaxation, but it cannot demonstrate the additional delay caused by finite Y buildup. The pulse test therefore uses the full two-variable model.
