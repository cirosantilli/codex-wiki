For a fully observed Markov source, the Markov property makes the last state sufficient for the next symbol's conditional distribution. With stationary distribution π, the conditional entropy is therefore
h=H(X2​∣X1​)=−∑i​πi​∑j​Pij​log2​Pij​,
(122)
using 0log2​0=0. The chain rule for information entropy gives the exact finite-block identity
H(X1​,…,Xn​)=H(π)+(n−1)h.
(123)
Dividing by n proves the displayed entropy rate. The weighting by πi​ matters: rows with high uncertainty contribute in proportion to how often their states occur.
For an original asymmetric example, take
P=(7/83/8​1/85/8​),π=(3/4,1/4).
(124)
The equality πP=π verifies the stationary distribution. The single-symbol information entropy is h2​(1/4)≃0.81127812, whereas
h=43​h2​(1/8)+41​h2​(3/8)≃0.64628183 bits per symbol.​
(125)
This formula describes observed states. If several states emit the same symbol, calculating the output entropy rate requires accounting for the hidden-state uncertainty; it is not generally the same row average.
