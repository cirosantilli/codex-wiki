For this homogeneous tangent differential equation, set u=y/x on an interval not containing x=0. Since y′=u+xu′, cancellation gives xu′=2tanu. Away from zeros of tanu, separation and integration give
∫cotudu=2∫xdx​,log∣sinu∣=2log∣x∣+C0​.
(9)
Restoring a signed constant yields the compact implicit solution
sin(y/x)=Cx2.​
(10)
A complete real branch description is
y=x[kπ+(−1)karcsin(Cx2)],k∈Z.​
(11)
Here C is real and the interval must satisfy x=0 and ∣Cx2∣<1. The strict inequality excludes points with cos(y/x)=0, where the original tangent function is undefined. Separating divided by tanu, so its zeros must be checked separately: u=kπ gives y=kπx. These are exactly the C=0 branches already included. The branch integer is fixed on each connected solution interval; it cannot be changed arbitrarily at a regular point.
