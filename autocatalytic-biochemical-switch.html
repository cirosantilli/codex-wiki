Autocatalytic biochemical switch

 Home Physics Branch of physics Mathematical biology Autocatalysis
OurBigBook.com Words: 69 Articles: 2
An autocatalytic biochemical switch uses bistability and a transient input to move a system from one stable concentration to another. A saddle-node bifurcation supplies a threshold above which the low-concentration equilibrium disappears.
