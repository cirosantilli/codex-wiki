Probability monotonicity of optimal prefix-code lengths

 ... Mathematics Area of mathematics Probability and statistics Information theory Huffman coding Optimal prefix code
OurBigBook.com Words: 37
If symbols of probabilities pi​>pj​ have codeword lengths li​ and lj​ in an optimal prefix code, then li​≤lj​. Otherwise, exchanging their codewords preserves the prefix property and changes the expected length by
(pi​−pj​)(lj​−li​)<0,
(153)
contradicting optimality.
