Discrete memoryless channel (Wn(yn∣xn)=∏j=1n​W(yj​∣xj​))

 Home Mathematics Area of mathematics Algebra Coding theory

A discrete memoryless channel models transmission through finite input and output alphabets using fixed conditional probabilities W(y∣x). For each input x, these nonnegative numbers sum to one over the output symbols. Discrete refers to the symbols, and memoryless means that the noise of one use does not remember earlier uses.
For a fixed input word xn=(x1​,…,xn​) sent without feedback, the output law is
Wn(yn∣xn)=∏j=1n​W(yj​∣xj​).
(7)
This is conditional independence of the outputs given the prescribed input word. It does not require an encoder to choose independent input symbols: the codewords of a block code deliberately impose relationships among them. Those relationships let a decoder distinguish possible messages after noise.
The binary symmetric channel and binary erasure channel make two different memoryless noise models with a binary input. One hides flipped bits; the other marks missing bits. Their different channel capacities show why the whole transition matrix matters, as the flips versus erasures in a binary channel demonstrate.
