Logical failure of the three-qubit phase-flip repetition code (pL​=3ϵ2−2ϵ3)

 ... Physics Branches of physics Quantum theory Quantum error correction Stabilizer code Phase-flip repetition code
OurBigBook.com Words: 77
The phase-flip repetition code with codewords ∣+++⟩,∣−−−⟩ corrects any one physical Pauli Z gate error. Its two adjacent-pair error syndromes cannot distinguish an error pattern from its three-bit complement. Minimum-weight recovery therefore leaves no residual error at weight zero or one, and leaves Z1​Z2​Z3​ at weight two or three. This residual operator exchanges the codewords, so inverse encoding gives a logical Pauli X gate. For independent physical phase errors of probability ϵ, the decoded quantum channel is (1−pL​)ρ+pL​XρX, where pL​=3ϵ2(1−ϵ)+ϵ3. For 0<ϵ<1/2, ϵ−pL​=ϵ(1−ϵ)(1−2ϵ)>0.
