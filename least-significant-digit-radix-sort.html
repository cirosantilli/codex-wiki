Least-significant-digit radix sort

 Home Computer science Algorithm Sorting algorithm Radix sort
OurBigBook.com Words: 389 Articles: 1
A least-significant-digit radix sort processes numerical digits from smallest to largest place value. Fix integers R≥2 and d≥1, and take n complete sorting records whose sort keys satisfy 0≤k<Rd. Use exactly d positions in positional notation with radix R, including leading zeros. At pass j=0,…,d−1, apply a stable digit sort to the current array using
δj​(k)=⌊Rjk​⌋modR.
(45)
The floor function selects the integer quotient, and the remainder selects the current numerical digit. Move the complete sorting record, including its associated data. There are exactly d passes, so this procedure terminates even for an empty array. The radix sort suffix invariant supplies its algorithm correctness argument.
For an original input, let the letters identify the attached data:
(314A​,027B​,305C​,042D​,217E​,005F​,127G​,040H​).
(46)
Here R=10, d=3, and leading zeros only align place values; 005 represents the integer five. The exact pass ledger is:
inputunitstenshundreds​314A​040H​305C​005F​​027B​042D​005F​027B​​305C​314A​314A​040H​​042D​305C​217E​042D​​217E​005F​027B​127G​​005F​027B​127G​217E​​127G​217E​040H​305C​​040H​127G​042D​314A​​
(47)
After the units pass, the numerical digits are 0,2,4,5,5,7,7,7. The ties retain C before F and B before E before G. This array is not yet ordered by its whole integer sort keys: 314 still precedes 305. After the tens pass, the two-position suffixes are 05,05,14,17,27,27,40,42. In particular, 217E​ now precedes 027B​: their tens numerical digits differ, so stable sorting does not require retaining their previous order. The hundreds pass produces the final sorted array, with all attached letters preserved.
