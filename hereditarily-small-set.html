Hereditarily small set (Hκ​={x:∣tc({x})∣<κ})

 ... Mathematics Area of mathematics Foundations of mathematics Set theory Cumulative hierarchy Transitive closure
OurBigBook.com Words: 79 Articles: 1
For an infinite cardinal number κ, Hκ​ consists of the sets x for which ∣tc({x})∣<κ, where tc is transitive closure. The entire transitive membership ancestry is bounded, not only the size of x. These collections are transitive sets. At κ=ω1​ the elements are the hereditarily countable sets.
