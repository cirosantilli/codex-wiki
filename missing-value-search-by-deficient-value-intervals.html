Missing-value search by deficient value intervals

 Home Computer science Algorithm Binary search
OurBigBook.com Words: 138
Suppose a candidate integer interval contains W possible values and an active array segment contains exactly all occurrences from that interval, with m<W entries. The pigeonhole principle guarantees a missing value. Split the value interval into widths WL​,WR​ and use array partitioning to obtain occurrence counts mL​,mR​. If mL​<WL​, retain the left side. Otherwise mR​=m−mL​<W−WL​=WR​, so retain the right side. This works with duplicate entries because it needs only the inequality between occurrences and possible values.
Balancing the value widths gives Wi+1​≤⌈Wi​/2⌉, while the active scan length remains less than Wi​. The total work is bounded by a geometric series and logarithmic loop overhead, hence O(W0​) time complexity. On reaching width one, the retained occurrence count is zero, proving that the sole candidate is absent globally. This is a binary search over deficient value intervals, with local in-place array partitioning, rather than repeated full-array scans.
