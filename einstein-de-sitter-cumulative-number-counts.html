Einstein-de Sitter cumulative number counts (N(<zf​)=3H03​8n0​c3​[1−(1+zf​)−1/2]3)

For constant comoving number density and complete selection in a spatially flat Einstein-de Sitter universe, integrate the present-epoch shell volume up to the population's formation redshift. The radial distance is DM​=2c[1−(1+z)−1/2]/H0​, so the count per unit solid angle is n0​DM3​(zf​)/3. It tends to a finite value as zf​ tends to infinity because this model's present comoving particle-horizon radius is 2c/H0​. Formation, mergers or an incomplete observed sample change this ideal count.
