The homogeneous linear system has solution set kerA, a vector subspace. If it contains only the zero vector, no two different solutions of the full system can exist: their difference would be a nonzero homogeneous solution.
A particular solution vp​ to the full system exists exactly when w belongs to the image of a linear map imA. If it exists, every solution is
v=vp​+vh​,vh​∈kerA​.
(58)
Indeed, subtracting Avp​=w from Av=w gives A(v−vp​)=0, and conversely adding a kernel vector preserves the right-hand side. Thus there are no solutions, one solution if the kernel is trivial, or infinitely many solutions if it is nontrivial. The last solution set is an affine subspace of dimension dimkerA, determined by the rank-nullity theorem. For a square nonsingular matrix there is one solution for every right-hand side.
