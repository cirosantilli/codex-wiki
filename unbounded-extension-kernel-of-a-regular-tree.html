Unbounded-extension kernel of a regular tree (T∗={t:supht(T≥t​)=κ})

 ... Foundations of mathematics Set theory Set Partially ordered set Set-theoretic tree Well-pruned set-theoretic tree
OurBigBook.com Words: 58
For a kappa-tree, retain nodes whose extension heights are unbounded in κ. The retained nodes are predecessor-closed. Each level remains nonempty: otherwise regularity would bound the union of fewer than κ bounded extension sets. The same argument above a retained node ensures retained extensions at every later level. Singular height invalidates this proof and the unrestricted conclusion.
