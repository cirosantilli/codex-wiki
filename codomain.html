Codomain (Y in f:X→Y)

 Home Mathematics Area of mathematics Foundations of mathematics Set theory Function
OurBigBook.com Words: 37
The codomain of a function is its specified target set. The image of a function is a subset of the codomain, and equals it precisely for a surjective function. Changing a codomain can change whether the same input-output rule is surjective, as the quadratic function examples under function show.
