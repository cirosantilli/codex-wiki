Critical points escaping to infinity in a Gaussian-weighted bilinear function (fα​(x,y)=xye−α(x2+y2))

 ... Analysis Real analysis Calculus Multivariable calculus Hessian matrix Second-derivative test
OurBigBook.com Words: 78
The origin is a saddle point of a scalar function for every real parameter. For α>0 four further critical points have x2=y2=1/(2α). Equal-sign coordinates give global maxima and opposite-sign coordinates give global minima, with values ±1/(2eα). The Hessian matrix there is −4αxye−1I. Their distance from the origin is α−1/2, so as α↓0 they escape every compact region. At nonpositive α the origin is the only critical point. This illustrates why the number of critical points on an unbounded domain can change without a finite degenerate critical point appearing.
