Interval square range (sqr(X)={x2:x∈X})

 ... Mathematics Area of mathematics Analysis Numerical analysis Interval arithmetic Interval arithmetic operations
OurBigBook.com Words: 104
The interval square range treats squaring as one function of one input. For X=[a,b] it is exactly
sqr([a,b])={[0,max{a2,b2}],[min{a2,b2},max{a2,b2}],​a≤0≤b,otherwise.​
(22)
It retains the relationship that ordinary interval multiplication loses: for Z=[−1/2,1/2], the interval square range is [0,1/4], whereas the independent-input product ZZ is [−1/4,1/4].
Consequently, completing the square for x(1−x) and using the interval square range gives
Z=X−[1/2,1/2]=[−1/2,1/2],[1/4,1/4]−sqr(Z)=[0,1/4].
(23)
This is the exact image of a function on X=[0,1]. Merely rewriting the expression and evaluating [1/4,1/4]−ZZ gives [0,1/2], so it does not achieve the same sharpening. A mathematical Z2 must be interpreted explicitly here: a square range operation and an independent-input interval product have different meanings. Choosing an operation that preserves known structure can save many steps of interval subdivision.
