Phase mismatch (Δk)

 ... Physics Branches of physics Optics Physical optics Interference (wave propagation) Phase matching
OurBigBook.com Words: 89 Articles: 1
The residual wave vector difference in a wave-conversion process. For collinear sum-frequency generation, choose Δk=k1​+k2​−k3​. Contributions separated by z then differ by wave phase Δkz. At phase matching this residual is zero. The sign convention changes some amplitude phases but not the unseeded conversion factor sinc2(ΔkL/2).
