Hard link

 Home Computer science Operating system File system File-system namespace
OurBigBook.com Words: 355 Articles: 1
A directory entry associating a name directly with an existing file. In the inode-based example, successful link("a", "b") adds the second name for inode 42 and increases its hard link count from 1 to 2. Both directory entries have equal status; removing a leaves b usable. This example assumes both names are in the same file system, the destination name is unused, and the operation is permitted.
