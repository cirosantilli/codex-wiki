Catastrophic cancellation (1+x​−1=1+x​+1x​)

 Home Mathematics Area of mathematics Analysis Numerical analysis Floating-point arithmetic
OurBigBook.com Words: 384
Catastrophic cancellation occurs when subtraction of nearly equal approximations removes their matching leading digits and exposes earlier roundoff error. The subtraction can itself be exact on the stored operands: the information may already have been lost while obtaining them. Goldberg distinguishes this from cancellation of accurately known quantities, which can be harmless.[ref]
For x>0, consider the single real-valued function
f(x)=1+x​−1=1+x​+1x​.
(7)
The rationalization of a square-root difference proves equality in exact arithmetic. The two evaluations use the same input x, but the direct version first forms a value near one and then subtracts one. The rearranged version keeps the small input in its numerator and divides by a denominator near two.
For binary64 x = 1e-16, the rounded sum 1.0 + x is one, so sqrt(1.0 + x) - 1.0 is zero. The rationalized evaluation returns approximately 5×10−17. A 100-digit Decimal calculation using the exact stored input gives relative errors of one and about 2.50×10−17 respectively. At x = 1e-12, the direct result is about 5.0004445029×10−13, with relative error 8.89×10−5; the rearranged result is about 4.99999999999875×10−13, with relative error 1.21×10−17.
The plot uses Decimal.from_float(x) to preserve the binary input exactly, computes x/(1+x​+1) at 100 decimal digits, and verifies the reference at 160 digits. Exact conversion of a stored binary value is documented by Python.[ref] Each error is ∣f​−f∣/∣f∣, with the computed result converted exactly to Decimal before comparison. Hence the curves measure evaluation error for one common input, rather than a mixture of input conversion error and evaluation error. The plotted interval 10−16≤x≤10−1 is far above the subnormal number range.
The original problem is well conditioned with respect to relative changes in x. Using the derivative f′(x)=1/(21+x​) and rationalization of a square-root difference, its relative condition number is
κf​(x)=​f(x)xf′(x)​​=21+x​1+x​+1​,21​<κf​(x)<1(x>0).
(8)
It tends to one as x tends to zero. The direct evaluation instead introduces the intermediate difference s−1 with s=1+x​; an error of order unit roundoff in s is large relative to f(x)≈x/2. This is a failure of the chosen algorithm's accuracy despite a small condition number for the same real-valued function. The rationalized evaluation avoids that intermediate catastrophic cancellation, retaining relative accuracy near the unit roundoff scale throughout the plotted interval. Recognizing this structure can improve a calculation far more than merely printing extra digits.
