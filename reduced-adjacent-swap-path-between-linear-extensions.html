Reduced adjacent-swap path between linear extensions

 ... Area of mathematics Foundations of mathematics Set theory Set Partially ordered set Linear extension
OurBigBook.com Words: 71
Two linear extensions of a finite partially ordered set can be joined using as many admissible adjacent swaps as the inversion count of their relative permutation. Label the current list by the desired positions in the target. An adjacent descent consists of incomparable elements, since comparable elements have the same order in both lists. Swap that descent; its inversion count decreases by one. Iteration sorts the list and gives a path of minimal Coxeter length.
