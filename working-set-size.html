Working set size (∣W(t,Δ)∣)

 Home Computer science Operating system Virtual memory Working set
OurBigBook.com Words: 30
The number of distinct memory pages in a working set, measured by its cardinality. It depends on both the current memory reference index t and the declared window Δ, not just on the resident set capacity.
