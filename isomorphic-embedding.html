Isomorphic embedding (c∥x∥≤∥Tx∥)

 ... Mathematics Area of mathematics Analysis Functional analysis Topological vector space Continuous linear operator
OurBigBook.com Words: 55
An isomorphic embedding of normed vector spaces is an injective bounded linear operator whose inverse on its image is bounded. Equivalently ∥Tx∥≥c∥x∥ for some c>0. The two-sided bounds make the domain and its image carry equivalent norms. If the domain is a Banach space, a convergent sequence Txn​ has a Cauchy sequence of preimages, so its limit remains in the image; thus the image is closed.
