Interpolation (g(xi​)=yi​)

 Home Mathematics Area of mathematics Analysis Numerical analysis
OurBigBook.com Words: 3k Articles: 24
Interpolation constructs a function agreeing exactly with prescribed values at sample points. The resulting function is an interpolant. Choosing a family determines how missing values are filled: polynomial interpolation selects a polynomial, while linear interpolation joins adjacent samples by straight segments. The McShane extension theorem instead permits any Lipschitz function with a specified bound and provides envelopes controlling all allowed choices.

Extrapolation

Words: 49
Interpolation OurBigBook.com
Estimating values beyond the range of the supplied sample points. For two distinct points P,Q, the affine combination (1−t)P+tQ lies beyond an endpoint of their line segment when t<0 or t>1. The construction specifies an extension of the chosen model; it does not show that an unknown underlying function follows that extension.

Interpolant (g(xi​)=yi​)

Words: 46
Interpolation OurBigBook.com
An interpolant is a function satisfying the prescribed sample conditions g(xi​)=yi​. It agrees with the data exactly, but need not agree with an unknown underlying function between samples. The polynomial interpolation example shows that a family or a polynomial degree restriction can supply uniqueness; the McShane extension theorem shows a useful nonunique alternative.

Polynomial interpolation (pn​(xi​)=yi​,degpn​≤n)

Words: 3k Articles: 21
Interpolation OurBigBook.com
Polynomial interpolation constructs a polynomial that passes exactly through prescribed data. Given n+1 distinct interpolation nodes x0​,…,xn​ and values y0​,…,yn​, there is exactly one interpolation polynomial pn​ of polynomial degree at most n with pn​(xi​)=yi​ for every i. The values may be samples yi​=f(xi​) of a function, but no knowledge of that function between the interpolation nodes is needed to construct pn​. The Lagrange polynomial and Newton polynomial are two representations of this same answer.[ref]
For example, the three data points (0,1),(1,2),(2,5) give the quadratic polynomial
p2​(x)=x2+1,p2​(0)=1,p2​(1)=2,p2​(2)=5.
(1)
Thus polynomial interpolation supplies p2​(1/2)=5/4 as an intermediate value. Whether this approximates an unknown underlying function well is a separate question about polynomial interpolation error.
Both hypotheses in the uniqueness statement matter. The Lagrange cardinal polynomials prove existence constructively. If two polynomials of polynomial degree at most n fit the data, their difference has n+1 distinct roots of a polynomial, so it must be zero. Repeated interpolation nodes with conflicting values have no solution, and repeated equal values provide no additional independent condition; prescribed derivatives instead lead to Hermite interpolation. Without the polynomial degree restriction there are infinitely many solutions:
p(x)=pn​(x)+q(x)∏i=0n​(x−xi​),
(2)
where q is any polynomial. By the factor theorem, this describes every polynomial fitting the same data. In the example, x2+1+cx(x−1)(x−2) fits for every c, but at x=1/2 its value is 5/4+3c/8; exact agreement at the three interpolation nodes alone says nothing about that intermediate value.
The usefulness of polynomial interpolation is that data become an explicit function whose values, derivatives, and integrals can be calculated. Differentiating or integrating the Lagrange cardinal polynomials produces differentiation weights from nodal evaluations or a quadrature rule. Exact passage through observations is the defining constraint. In polynomial regression, linear least squares instead chooses a polynomial degree and minimizes a sum of squared residuals, generally without passing through every observation. Interpolating noisy values reproduces their errors at the interpolation nodes and can amplify them between interpolation nodes; polynomial interpolation does not itself smooth measurement noise. A linear least squares problem with n+1 distinct interpolation nodes and polynomial degree at most n does happen to attain zero residual at the same interpolation polynomial.

Interpolation polynomial (p(xi​)=yi​)

Words: 52
Polynomial interpolation OurBigBook.com
An interpolation polynomial for distinct nodes x0​,…,xn​ and prescribed values y0​,…,yn​ is a polynomial p satisfying p(xi​)=yi​. There is a unique such polynomial of degree at most n: the Lagrange interpolation polynomial constructs it explicitly, and uniqueness follows because a nonzero degree-at-most-n difference cannot have n+1 distinct roots. Newton interpolation polynomials express the same object using divided differences.

Interpolation nodes from best uniform approximation (ℓn​(f)=pn∗​)

Words: 84
Polynomial interpolation OurBigBook.com
For a real continuous function on a compact interval, choose its best uniform approximation pn∗​ of polynomial degree at most n. If its error is nonzero, the Chebyshev alternation theorem supplies n+2 ordered alternating extrema. The intermediate value theorem gives a zero of f−pn∗​ in each intervening interval. At these n+1 distinct points, the polynomial interpolant is exactly pn∗​. If the best error is zero, arbitrary distinct nodes suffice. The Weierstrass approximation theorem shows that these function-dependent interpolants converge uniformly. The nodes depend on the target function; the conclusion does not provide one universal node sequence for every continuous target.

Interpolation node (xi​)

Words: 186 Articles: 1
Polynomial interpolation OurBigBook.com
An interpolation node is an argument value xi​ at which an interpolation polynomial must take a prescribed value yi​. The interpolation nodes specify where the constraints apply; the values specify how high the graph must pass there. In the three-point example, the interpolation nodes are 0,1,2, while the prescribed values are 1,2,5. Changing the interpolation nodes changes the Lagrange cardinal polynomials and the polynomial interpolation error, even if their number stays fixed.

Chebyshev-Lobatto node (xk​=cos(kπ/n),k=0,…,n)

Words: 126
Interpolation node OurBigBook.com
For n≥1, the n+1 Chebyshev-Lobatto nodes are the extrema of the Chebyshev polynomial Tn​ on [−1,1], including both endpoints: Tn​(xk​)=(−1)k. Imagine n+1 equally spaced angles on a semicircle and project their points onto the horizontal axis. The interpolation nodes crowd near −1 and 1 because equal angular steps have smaller horizontal projections there. Reversing the order gives the same set. These are distinct from the roots of a polynomial cos((2k+1)π/(2n+2)) of Tn+1​, which omit the endpoints. Driscoll and Braun call this endpoint-including family Chebyshev points of the second kind or Chebyshev extreme points.[ref]
On an interval [a,b], use xk​=(a+b)/2+(b−a)cos(kπ/n)/2. The Runge phenomenon example compares polynomial interpolation at eleven Chebyshev-Lobatto nodes with eleven equally spaced interpolation nodes. The distinction matters whenever sampling locations are a choice rather than fixed observations.

Runge's phenomenon

Words: 295
Polynomial interpolation OurBigBook.com
The Runge phenomenon is the failure of increasing-degree polynomial interpolation at equally spaced interpolation nodes to converge to some smooth target functions, with large oscillations near the ends of the interval. It is a property of the approximation problem, and can occur even with exact arithmetic. A numerically stable evaluation method cannot remove it. Endpoint clustering, as in Chebyshev-Lobatto nodes, changes the approximation problem and can greatly improve it.[ref]
Take f(x)=1/(1+25x2) on [−1,1] and polynomial degree at most 10. Use either xk​=−1+k/5 or xk​=cos(kπ/10) for k=0,…,10. Each interpolation polynomial passes through all eleven of its own samples, yet the first has severe endpoint oscillations and the second stays much closer to the target function. Evaluating both by the barycentric interpolation formula on 20,001 equally spaced points, including the endpoints, gives sampled maximum absolute errors of approximately 1.915659 and 0.132197, respectively: about a 14.49-fold reduction. These are maxima over the stated grid, not certified maxima over the continuous interval. The generator separately checks exact reproduction of all stored nodal values.
The polynomial interpolation error formula explains why interpolation nodes enter the analysis. If f has n+1 continuous derivatives on an interval containing x and all the interpolation nodes, then for a suitable ξx​ in that interval,
f(x)−pn​(x)=(n+1)!f(n+1)(ξx​)​∏i=0n​(x−xi​).
(3)
At an interpolation node the error is zero directly. Away from the interpolation nodes, both the product and the high-order derivative matter. A short proof applies Rolle's theorem repeatedly to f(t)−pn​(t)−[f(x)−pn​(x)]∏i​(t−xi​)/∏i​(x−xi​), which vanishes at n+2 distinct points.[ref]
The successful comparison here does not assert that Chebyshev-Lobatto nodes solve every approximation problem for every function. The derivatives, the polynomial degree, and measurement errors still matter. The Lebesgue constant of interpolation measures worst-case amplification of nodal errors, while the polynomial reproduction error bound relates interpolation to the best uniform approximation available at that polynomial degree.

Lagrange polynomial (pn​(x)=∑i=0n​yi​ℓi​(x))

Words: 825 Articles: 6
Polynomial interpolation OurBigBook.com
The Lagrange polynomial writes the interpolation polynomial as a linear combination of Lagrange cardinal polynomials. Each one selects a single interpolation node, so the data values themselves become the coefficients:
pn​(x)=∑i=0n​yi​ℓi​(x),ℓi​(x)=∏0≤j≤nj=i​​xi​−xj​x−xj​​.
(4)
Distinct interpolation nodes make every denominator nonzero. At xj​, all terms vanish except yj​ℓj​(xj​)=yj​. This gives an explicit construction without solving for monomial coefficients. The elegance of the Lagrange polynomial is that it builds all constraints into the basis, leaving no equations to solve for the data values.
For (x0​,x1​,x2​)=(0,1,2) and (y0​,y1​,y2​)=(1,2,5), substitution gives
p2​(x)=2(x−1)(x−2)​−2x(x−2)+25x(x−1)​=x2+1.
(5)
At x=1/2, the Lagrange cardinal polynomial values are 3/8,3/4,−1/8, so p2​(1/2)=3/8+2(3/4)+5(−1/8)=5/4. A negative Lagrange cardinal polynomial value is allowed: these weights sum to one but need not be probabilities.
The product form is especially useful for deriving differentiation weights from nodal evaluations and quadrature rules. For repeated numerical evaluation, the barycentric interpolation formula reorganizes the same Lagrange polynomial into precomputed weights and sums; it avoids evaluating every full product at every argument.

Discrete minimax interpolation on ordered nodes (p=t−λr,λ=[xn+1]t/[xn+1]r)

Words: 107
Lagrange polynomial OurBigBook.com
For n+2 increasingly ordered nodes yj​, let rj​ be their Lagrange cardinal polynomials, t=∑f(yj​)rj​, and r=∑(−1)jrj​. The leading coefficient of rj​ has sign (−1)n+2−j, so all summands in the leading coefficient of r have the same nonzero sign. There is a unique λ canceling degree n+1 in t−λr. Its errors at the nodes are λ(−1)j, and a better degree-at-most-n approximation would have a difference polynomial with at least n+1 roots. Thus it minimizes the maximum node error. Increasing order matters: for the permutation (0,1/3,1,2/3) the alternating interpolant is already the quadratic −1+9x(1−x), so the leading-coefficient assertion for n=2 fails.

Lagrange cardinal polynomial (ℓi​)

Words: 341 Articles: 2
Lagrange polynomial OurBigBook.com
For distinct interpolation nodes x0​,…,xn​, the Lagrange cardinal polynomial ℓi​ has value one at its own interpolation node and zero at every other interpolation node:
ℓi​(x)=∏j=i​xi​−xj​x−xj​​,ℓi​(xj​)=δij​={1,0,​i=j,i=j.​
(6)
Here δij​ is the Kronecker delta. These Lagrange cardinal polynomials form a basis of the vector space of polynomials of polynomial degree at most n: every such polynomial has the unique expansion p(x)=∑i​p(xi​)ℓi​(x). The nodal evaluation linear functionals Ej​(p)=p(xj​) form the dual basis, since Ej​(ℓi​)=δij​.
For the interpolation nodes 0,1,2, the three Lagrange cardinal polynomials are
ℓ0​(x)=2(x−1)(x−2)​,ℓ1​(x)=−x(x−2),ℓ2​(x)=2x(x−1)​.
(7)
Their values on the interpolation nodes are the rows of the identity matrix. In the figure, each colored curve passes through its own unit-height marker and through zero at the other two interpolation nodes. Multiplying the curves by the data 1,2,5 and adding gives the Lagrange polynomial x2+1.
Since the constant polynomial one interpolates data values all equal to one, uniqueness gives ∑i​ℓi​(x)=1. Nevertheless, ℓ2​(1/2)=−1/8, so Lagrange cardinal polynomials need not stay between zero and one. If a single data value yi​ changes by ε, the interpolation polynomial changes by exactly εℓi​(x). Thus a Lagrange cardinal polynomial describes how one observation influences the entire graph, and ∑i​∣ℓi​(x)∣ controls the worst amplification of simultaneous data errors at x; its maximum is the Lebesgue constant of interpolation.
Endpoint derivative signs of Lagrange cardinal polynomials ((−1)iLi(k)​(1)>0)
Words: 68
Lagrange cardinal polynomial OurBigBook.com
At decreasing distinct interpolation nodes 1≥t0​>⋯>tn​≥−1, the Lagrange cardinal polynomial Li​(x)=∏j=i​(x−tj​)/∏j=i​(ti​−tj​) has denominator sign (−1)i. For 1≤k≤n, its numerator's kth derivative at one is k! times a sum of products of n−k nonnegative factors 1−tj​. At most one factor vanishes, and at least one product avoids it, so that sum is strictly positive. The same alternating nodal signs therefore maximize every endpoint derivative simultaneously.
Nodal derivative norm from Lagrange cardinal polynomials (sup∣p(ti​)∣≤1​∣p(k)(x)∣=∑i​∣ℓi(k)​(x)∣)
Words: 75
Lagrange cardinal polynomial OurBigBook.com
At distinct interpolation nodes, differentiating Lagrange interpolation gives p(k)(x)=∑i​p(ti​)ℓi(k)​(x). The triangle inequality gives the displayed upper bound, attained by prescribing each nodal value to be the sign of the corresponding derivative weight. For increasingly ordered real nodes, the Markov interlacing lemma and monotonicity of polynomial critical points in their roots imply that (−1)iℓi(k)​(x) has at most one sign change, ignoring zero weights. Thus an extremizer has alternating nodal signs with at most one reversal of that alternating pattern. This reduces a choice among 2n+1 sign patterns to n+1 candidate polynomials.

Barycentric interpolation formula (pn​(x)=∑i​wi​/(x−xi​)∑i​wi​yi​/(x−xi​)​)

Words: 196
Lagrange polynomial OurBigBook.com
The barycentric interpolation formula evaluates the same Lagrange polynomial using weights that depend only on the distinct interpolation nodes:
wi​=∏j=i​(xi​−xj​)1​,pn​(x)=i=0∑n​x−xi​wi​​i=0∑n​x−xi​wi​yi​​​,x=xi​.
(8)
At x=xi​, return yi​ directly, before dividing; the formula has removable singularities at the interpolation nodes. Multiplying every wi​ by the same nonzero constant leaves the answer unchanged. Driscoll and Braun derive this formula as a more efficient, numerically stable way to evaluate polynomial interpolation.[ref]
For the interpolation nodes 0,1,2, the weights are (1/2,−1,1/2), or equivalently (1,−2,1). With data (1,2,5), at x=1/2 the denominator using the latter weights is 2+4−2/3=16/3 and the numerator is 2+8−10/3=20/3, giving p2​(1/2)=5/4 again. For eleven interpolation nodes in the Runge phenomenon figure, the generator computes the weights by the direct products above and returns stored values exactly at every interpolation node.
The direct products require O(n2) arithmetic operations once; each subsequent value uses O(n) arithmetic operations. Here O denotes Big O notation. At large polynomial degree or on poorly scaled intervals, forming these products can exceed the range of floating-point arithmetic; normalization or specialized weight formulas may be needed. Stable evaluation also cannot cure sensitivity intrinsic to the chosen interpolation nodes, measured by the Lebesgue constant of interpolation, or the approximation failure in the Runge phenomenon.

Divided difference (f[x0​,…,xk​])

Words: 1k Articles: 7
Polynomial interpolation OurBigBook.com
For k+1 distinct interpolation nodes, the divided difference f[x0​,…,xk​] is the coefficient of xk in the interpolation polynomial of polynomial degree at most k through those interpolation nodes. It is the leading coefficient when that polynomial degree is exactly k, and zero when it is smaller. Explicitly,
f[x0​,…,xk​]=∑j=0k​∏i=j​(xj​−xi​)f(xj​)​.
(9)
starting with f[xi​]=f(xi​). The divided differences obey the recurrence
f[x0​,…,xk​]=xk​−x0​f[x1​,…,xk​]−f[x0​,…,xk−1​]​.
(10)
For data f(0)=1, f(1)=2, f(2)=5, the first divided differences are f[0,1]=(2−1)/(1−0)=1 and f[1,2]=(5−2)/(2−1)=3. The second divided difference is f[0,1,2]=(3−1)/(2−0)=1, the leading coefficient of x2+1. The first divided difference is the slope of a secant line; higher divided differences supply successive coefficients for the Newton polynomial.

Divided difference table (Di,k​=f[xi​,…,xi+k​])

Words: 269
Divided difference OurBigBook.com
A divided difference table arranges divided differences by starting interpolation node i and order k. Its base column is Di,0​=f(xi​); every later entry uses two neighboring entries from the previous column:
Di,k​=xi+k​−xi​Di+1,k−1​−Di,k−1​​,1≤k≤n,0≤i≤n−k.
(11)
The denominator spans all k+1 interpolation nodes of that entry, even though the numerator uses adjacent table entries. The interpolation nodes must be distinct; they need not be equally spaced or sorted.[ref]
Take the polynomial f(x)=x3−2x+1 at the interpolation nodes (−1,0,2,3), giving values (2,1,5,22). Its divided difference table is
xi​−1023​Di,0​21522​Di,1​−1217​Di,2​15​Di,3​1​​
(12)
The first divided differences are (1−2)/(0+1)=−1, (5−1)/(2−0)=2, and (22−5)/(3−2)=17. The second divided differences use the wider spans: (2+1)/(2+1)=1 and (17−2)/(3−0)=5. The third divided difference is (5−1)/(3+1)=1. Reading the top row gives the Newton polynomial coefficients (2,−1,1,1), rather than all the entries in any one column.
The resulting Newton polynomial grows through four partial interpolants:
p0​(x)p1​(x)p2​(x)p3​(x)​=2,=2−(x+1)=1−x,=2−(x+1)+(x+1)x=x2+1,=2−(x+1)+(x+1)x+(x+1)x(x−2)=x3−2x+1.​
(13)
At x=2, p1​(2)=−1 misses f(2)=5 by 6; the correction (x+1)x supplies exactly 6 there and vanishes at the earlier interpolation nodes −1,0. At x=3, p2​(3)=10 misses f(3)=22 by 12; the correction (x+1)x(x−2) supplies exactly 12 there and vanishes at all three earlier interpolation nodes. Each added term therefore preserves the previous agreements while satisfying the next one.
For n+1 interpolation nodes, the triangle contains n+(n−1)+⋯+1=n(n+1)/2 recurrence steps. Once the top row is known, nested evaluation of the Newton polynomial uses only n multiplications and n additions per argument. The triangle organizes the work; the factors explain why the construction works.

Symmetry of divided differences (f[xσ(0)​,…,xσ(k)​]=f[x0​,…,xk​])

Words: 146
Divided difference OurBigBook.com
A divided difference depends on the chosen interpolation nodes and their data, but is unchanged by any permutation σ of those same interpolation nodes. The explicit sum in divided difference makes this visible: a permutation merely rearranges its summands.[ref]
There is also a short explanation using Lagrange cardinal polynomials. The coefficient of xk in the jth Lagrange cardinal polynomial is 1/∏i=j​(xj​−xi​). Taking that coefficient in their weighted sum gives exactly the explicit divided difference formula. Since polynomial interpolation has a unique answer for a fixed set of distinct interpolation nodes, this coefficient cannot depend on their ordering. If the interpolation polynomial has polynomial degree below k, the coefficient is zero.
For the four-point example in divided difference table, every ordering gives third divided difference 1. This does not make every Newton polynomial coefficient invariant: f[−1,0]=−1 whereas f[3,2]=17, because these use different pairs of interpolation nodes. Even at second order, f[−1,0,2]=1 and f[3,2,0]=5 use different triples. The node order in Newton interpolation determines which subsets occur along the top row.

Newton polynomial (pn​(x)=∑k=0n​f[x0​,…,xk​]∏i=0k−1​(x−xi​))

Words: 566 Articles: 1
Divided difference OurBigBook.com
The Newton polynomial expresses the interpolation polynomial in products that successively vanish at all previously used interpolation nodes. With yi​=f(xi​), the coefficients are divided differences:
pn​(x)=f(x0​)+∑k=1n​f[x0​,…,xk​]∏i=0k−1​(x−xi​).
(16)
A triangular divided difference table computes all its coefficients using exactly n(n+1)/2 divisions. The Newton polynomial and the Lagrange polynomial have the same polynomial degree bound and the same nodal values, hence are equal by uniqueness of polynomial interpolation.
For f(0)=1, f(1)=2, f(2)=5, the complete divided difference table is
xi​012​f[xi​]125​f[xi​,xi+1​]13​f[xi​,xi+1​,xi+2​]1​​
(17)
The first divided differences are 1 and 3, and their divided difference is (3−1)/(2−0)=1. Reading the top entries gives
p2​(x)=1+1(x−0)+1(x−0)(x−1)=1+x+x(x−1)=x2+1.
(18)
The initial term fits (0,1); adding x also fits (1,2); adding x(x−1) fits (2,5) while leaving the first two data values unchanged. This is the practical beauty of the Newton polynomial: each new correction respects all previous interpolation constraints.
If a new distinct interpolation node xn+1​ with value yn+1​ arrives, append one term:
pn+1​(x)=pn​(x)+c∏i=0n​(x−xi​),c=∏i=0n​(xn+1​−xi​)yn+1​−pn​(xn+1​)​.
(19)
For example, appending (3,11) to the three-point data gives c=(11−10)/(3⋅2⋅1)=1/6, hence p3​(x)=x2+1+x(x−1)(x−2)/6. Changing the order of the interpolation nodes changes the Newton polynomial coefficients and products, but not the final interpolation polynomial in exact arithmetic.
The products also permit nested evaluation analogous to Horner's method. If ak​=f[x0​,…,xk​], start with bn​=an​ and work backwards by bk​=ak​+(x−xk​)bk+1​; the answer is b0​. The three-point example becomes 1+x[1+(x−1)], needing two multiplications for each evaluation. This organization is useful when adding observations incrementally or evaluating a stored Newton polynomial many times; the Runge phenomenon still depends on the interpolation nodes rather than on which representation is used.
To justify the update formula, its added product vanishes at every previous interpolation node. Choosing c by the new residual forces agreement at xn+1​, so uniqueness of polynomial interpolation identifies the result. For n≥0, pn​ has polynomial degree at most n, and the added product has leading coefficient one. Thus the new coefficient c is exactly f[x0​,…,xn+1​]. The initial state is p0​(x)=f(x0​), with the empty product interpreted as one.[ref]
Appending (4,57) to the four-point example in divided difference table leaves the Newton polynomial unchanged: p3​(4)=57, so the new fourth divided difference is zero. If the appended value is instead 58, the new coefficient is
c=(4+1)⋅4⋅(4−2)⋅(4−3)58−57​=401​,p4​(x)=x3−2x+1+40(x+1)x(x−2)(x−3)​.
(20)
This polynomial still takes values 2,1,5,22 at the original interpolation nodes, and now takes value 58 at 4. A zero update is a valid completed step: adding another exact sample of the original polynomial need not increase the polynomial degree.
Node order in Newton interpolation
Words: 185
Newton polynomial OurBigBook.com
Reordering the interpolation nodes changes the successive subsets used for the divided differences and the factors of the Newton polynomial. The final interpolation polynomial remains unchanged in exact arithmetic. For f(x)=x3−2x+1, reversing (−1,0,2,3) gives (3,2,0,−1) and values (22,5,1,2). The successive divided difference columns are now
Di,1​Di,2​Di,3​​:17, 2, −1,:5, 1,:1.​
(21)
For example, the first second divided difference is (2−17)/(0−3)=5. The top row becomes (22,17,5,1), giving
q0​(x)q1​(x)q2​(x)q3​(x)​=22,=22+17(x−3)=17x−29,=22+17(x−3)+5(x−3)(x−2)=5x2−8x+1,=22+17(x−3)+5(x−3)(x−2)+(x−3)(x−2)x=x3−2x+1=p3​(x).​
(22)
The earlier partial interpolants differ because they fit different subsets: p2​ fits −1,0,2, whereas q2​ fits 3,2,0. The highest divided difference is invariant because both complete top rows finish with the same set of four interpolation nodes; this is symmetry of divided differences.
This distinction is useful when checking a divided difference table: permuting all the interpolation nodes must preserve its final divided difference, even though the intermediate entries change. It also explains why data can be appended in their arrival order. In floating-point arithmetic, the subtractions and divisions may accumulate different rounding errors in different orders; exact invariance describes the mathematical polynomial, rather than guaranteeing bit-for-bit equality of numerical results.
