Abstraction function (α:Rvalid​→Q)

 Home Computer science Encapsulation (computer programming) Abstract data type
OurBigBook.com Words: 805 Articles: 2
An abstraction function maps a valid concrete representation to its abstract value. Write Rvalid​={r:I(r)} and α:Rvalid​→Q. Different storage states can denote the same abstract value. Correct implementation requires both preservation of the representation invariant and agreement with the specified operation after applying the abstraction function; preserving a length bound alone would not prove first-in, first-out behavior.
The representation invariant answers "is this storage state allowed?" The abstraction function answers "which value does it represent?" Thus I(r) is a truth value, whereas α(r) is a value of the abstract data type. Treating α as a partial function on all storage states, or as a function defined on Rvalid​ only, expresses the same restriction. The abstraction function may forget storage details, and need not be executable code: its purpose is to connect an implementation to its formal specification.[ref]
This distinction makes functional correctness manageable one operation at a time. The unreduced rational representation below separates valid storage from mathematical meaning; correct operations through an abstraction function then checks whether an implementation performs the promised addition. For an example with hidden mutable storage and failure cases, the bounded queue with encapsulation supplies a different abstraction function, reading an occupied prefix of an array as a sequence.
