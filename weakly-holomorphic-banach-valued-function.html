Weakly holomorphic Banach-valued function (φ∘f holomorphic for every φ∈X′)

 Home Mathematics Area of mathematics Analysis Complex analysis Holomorphic function
OurBigBook.com Words: 199 Articles: 1
A map from an open subset of C into a complex Banach space is weakly holomorphic when every composition with a bounded complex-linear functional is a scalar holomorphic function. Norm holomorphy requires its difference quotients to converge in the Banach norm. Weak holomorphy is initially a condition on scalar observations; the weak holomorphy implies norm holomorphy argument recovers an actual vector derivative. A closed target subspace containing values on a sequence with an interior accumulation point contains every value on the connected domain: annihilate the subspace, apply the scalar identity theorem, and use Hahn-Banach separation.
