Serre class of finitely generated abelian groups (Cfg​)

 ... Area of mathematics Algebra Group theory Group Abelian group Serre class
OurBigBook.com Words: 30
The class of all finitely generated abelian groups has the closure properties needed for the Hurewicz theorem modulo a Serre class. In a simply connected space, degreewise membership of homotopy groups and integral homology groups in this class is equivalent.
