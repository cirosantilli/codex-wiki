Pt100 local linear model (R=R0​(1+αt))

OurBigBook.com Words: 250
Choose the illustrative local model
R(t)=R0​(1+αt),R0​=100Ω,α=0.00385(∘C)−1.
(18)
Here t is the Celsius temperature, measured relative to 0∘C, so αt is dimensionless. For this chosen affine function, the derivative and inverse relation are
dtdR​=R0​α=0.385Ω/∘C,t=αR/R0​−1​,Δt=0.385Ω/∘CΔR​.
(19)
Calculated values are R(0∘C)=100Ω, R(20∘C)=107.70Ω, R(25∘C)=109.625Ω, and R(50∘C)=119.25Ω. These are model outputs, not measurements or an assertion that any real Pt100 follows this line exactly. The number 0.00385 here is the chosen slope parameter; it is not a universal local derivative for all platinum resistance thermometers. Curvature, manufacturing differences, and the fitted calibration interval matter. A wider-range calibration uses a validated response curve rather than extrapolating this line indefinitely.
For a separate synthetic thermometer calibration, stipulate Ra​=100.20Ω at ta​=0∘C and Rb​=119.60Ω at tb​=50∘C. A two-point affine function has slope 0.388Ω/∘C and gives
t=0.388Ω/∘CR−100.20Ω​.
(20)
Thus R=109.90Ω would indicate 25∘C. If an additional synthetic check at reference 25∘C instead supplied 110.10Ω, the line would indicate 25.515…∘C. The 0.20Ω residual exposes disagreement that two fitted points cannot reveal. This separate example changes both offset and slope; it is not a replacement specification for the nominal Pt100 local linear model.
