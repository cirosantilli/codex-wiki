Heap order (A⌊(i−1)/2⌋​≤Ai​(1≤i<n))

 Home Computer science Data structure Priority queue Binary heap
OurBigBook.com Words: 41
The minimum convention for heap order requires every parent in a rooted tree to have priority no greater than each of its children in a rooted tree. The displayed formula uses the array representation of a binary heap. It permits equal priorities and does not require a sorted array; the maximum convention reverses the inequality.
