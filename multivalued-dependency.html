Multivalued dependency (X↠Y)

 Home Computer science Database Relational database Relational model Relational schema
OurBigBook.com Words: 48
For database tuples agreeing on X, requires the combinations obtained by swapping their values on Y∖X and on the remaining database attributes to occur too. A functional dependency implies the corresponding multivalued dependency; complementation exchanges Y with the remaining database attributes. A multivalued dependency is trivial if Y⊆X or X∪Y is the full relational schema.
