Use the Poisson distribution with probability mass function πn​=e−λλn/n! on N0​. A symmetric nearest-neighbour proposal with a reflecting boundary is
q(n,n+1)=21​(n≥0),q(n,n−1)=21​(n≥1),q(0,0)=21​.
(6)
All other entries vanish. In particular, the boundary proposal does not force a move to one: retaining the probability q(0,0)=1/2 makes q(0,1)=q(1,0).
The adjacent ratios of the Poisson distribution are πn+1​/πn​=λ/(n+1) and πn−1​/πn​=n/λ. The Metropolis–Hastings acceptance probability consequently gives
un​=21​min{1,λ/(n+1)},dn​=21​min{1,n/λ} (n≥1),d0​=0,
(7)
where the symbol un​ denotes the upward transition probability. Thus the complete transition matrix is
P(n,n+1)=un​,P(n,n−1)=dn​,P(n,n)=1−un​−dn​,​
(8)
with no downward entry at zero and all other entries zero. In matrix form,
P=​1−u0​d1​0⋮​u0​1−u1​−d1​d2​⋮​0u1​1−u2​−d2​⋱​00u2​⋱​⋯⋯⋯⋱​​.
(9)
Every row is nonnegative and sums to one. An executable Python step of this Poisson Metropolis chain is:
def poisson_step(n, lam, rng):
    if lam <= 0 or n < 0 or int(n) != n:
        raise ValueError("require lam > 0 and an integer n >= 0")
    y = n + 1 if rng.random() < 0.5 else max(0, n - 1)
    ratio = lam / (n + 1) if y > n else n / lam if y < n else 1.0
    return y if rng.random() < min(1.0, ratio) else n
Supply a pseudorandom number generator such as random.Random(2021) and retain each returned state, including repeats. No normalizing constant or evaluation of a factorial is needed by the algorithm.
