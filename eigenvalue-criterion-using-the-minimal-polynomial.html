Eigenvalue criterion using the minimal polynomial (mT​(λ)=0⟺λ is an eigenvalue of T)

 ... Mathematics Area of mathematics Algebra Linear algebra Operator theory Minimal polynomial
OurBigBook.com Words: 61
For a linear operator on a finite-dimensional vector space, an eigenvector gives mT​(T)v=mT​(λ)v=0, proving the forward implication from eigenvalue to root. Conversely write mT​(X)=(X−λ)q(X). If T−λI were invertible, the equation (T−λI)q(T)=0 would imply q(T)=0, contradicting minimal degree. Thus T−λI has a nonzero kernel of a linear map. The equivalence concerns roots in the scalar field; roots in an extension describe eigenvalues after extending scalars.
