Density process (Lt​=E[LT​∣Ft​])

 ... Area of mathematics Analysis Real analysis Measure theory Measure Change of measure
OurBigBook.com Words: 30
For a Radon-Nikodym derivative LT​≥0 with ELT​=1, its conditional-expectation process is a nonnegative martingale. If LT​>0 almost surely, it defines an equivalent probability measure. A stochastic exponential satisfying the Novikov condition is a common positive density process.
