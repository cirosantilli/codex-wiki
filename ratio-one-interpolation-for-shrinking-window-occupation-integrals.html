Ratio-one interpolation for shrinking-window occupation integrals

OurBigBook.com Words: 64
For any measurable real path x, put An​(t)=n∫0t​1{∣x(s)∣<1/n}​ds. If nk​≤n≤nk+1​, nested windows give (n/nk+1​)Ank+1​​(t)≤An​(t)≤(n/nk​)Ank​​(t). Consequently, when nk+1​/nk​→1 and the subsequence Ank​​ converges uniformly on bounded time intervals, the full sequence does also, to the same limit. This deterministic interpolation turns summable-subsequence First Borel-Cantelli lemma estimates into almost-sure convergence without incorrectly claiming that convergence in L2 alone implies full-sequence almost-sure convergence.
