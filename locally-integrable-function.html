Locally integrable function (Lloc1​(U))

 Home Mathematics Area of mathematics Analysis Distribution theory Test function
OurBigBook.com Words: 28
A function is locally integrable when its absolute value has finite integral over every compact subset of its domain. It defines a regular distribution by integration against test functions.
