Neuronal firing threshold (ϑ)

 Home Biology Neuroscience Neuron Synaptic integration
OurBigBook.com Words: 42
A neuronal firing threshold specifies the condition for initiating an action potential. The leaky integrate-and-fire model uses a prescribed membrane potential ϑ; real initiation involves active voltage-gated ion channels and depends on recent activity and recording site. A threshold drawn on a passive voltage trace is a comparison criterion, not a simulated action potential.
