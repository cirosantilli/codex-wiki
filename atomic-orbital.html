Atomic orbital (ϕnℓm​(r))

OurBigBook.com Words: 270 Articles: 7
An atomic orbital is a one-electron spatial wavefunction used to describe an electron's state in a chemical atom. For a one-electron hydrogen atom, orbitals can be exact energy eigenstates; descriptions of many-electron atoms instead use an orbital approximation. A normalized atomic orbital has ∫∣ϕ∣2d3r=1, and the Born rule gives the position probability density ∣ϕ∣2. It is a function extending through space, not a prescribed classical orbit. [ref]
The linear combination of atomic orbitals combines these single-centre functions to approximate a molecular orbital. The orbital overlap measures their inner product, and their relative quantum phase controls the interference shown in molecular orbital theory.
