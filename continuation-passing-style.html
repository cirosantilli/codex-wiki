Continuation-passing style

 Home Computer science Programming language Programming language semantics Continuation (computer science)
OurBigBook.com Words: 27
Pass the remaining computation explicitly as a continuation. Returning a value means invoking that continuation; a different control destination can be selected by invoking a different continuation.
