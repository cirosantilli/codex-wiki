Error control for ODE solvers

 Home Mathematics Area of mathematics Analysis Numerical analysis
OurBigBook.com Words: 2k Articles: 9
Error control selects discretization parameters and checks approximations against requested accuracy. Local error estimators, absolute and relative error tolerances and an adaptive step-size controller provide practical local control. Propagation of defects determines the global error, while stiffness, roundoff error and algebraic-solve accuracy impose additional limits.
For an ordinary differential equation, the practical loop is to propose a step, form a local error estimator, scale it by absolute and relative error tolerances, and accept or retry before choosing the next step. An embedded Runge-Kutta pair supplies two endpoints from shared Runge-Kutta stages, making this extra accuracy check inexpensive. The Euler-Heun embedded pair below exposes the distinction between the accepted formula's order of a numerical method and the estimator's step exponent; its Adaptive Euler-Heun integration of exponential growth shows accepted local tests alongside accumulated global error.

Adaptive step-size controller (hnew​=hηE−1/r)

Words: 210
Error control for ODE solvers OurBigBook.com
If a scaled local error estimator behaves as E∝hr with approximately unchanged error scale, the displayed update targets a fixed local level. A safety factor 0<η<1 aims below the acceptance boundary. For an embedded Runge-Kutta pair with order of a numerical method p for the accepted output and p−1 for the companion formula, the difference generally has r=p; for the actual unscaled local truncation error of an order-p formula, r=p+1. The exponent belongs to the quantity being controlled. Dividing the defect by h changes that exponent. This follows by solving E(hnew​)≈E(h)(hnew​/h)r for the next step.[ref]
Rejecting a trial means retrying from the same accepted time and state, with a smaller step. Advancing time or retaining the rejected output would change the initial value problem being approximated. Minimum and maximum change factors prevent extreme updates; a zero estimate requires finite capped growth. After acceptance, cap the next step at the remaining interval length. Detect a step that cannot advance time in floating-point arithmetic, and report failure rather than an endless retry. An adaptive step-size controller can use earlier estimates to smooth step sequences, but the memoryless rule here is sufficient to explain acceptance and rejection.[ref]

Absolute and relative error tolerances (si​=atoli​+rtoli​max(∣yi​∣,∣Yi​∣))

Words: 218
Error control for ODE solvers OurBigBook.com
Absolute tolerances provide a nonzero error scale near zero, while relative tolerances follow component magnitude. A max-norm test maxi​∣ei​∣/si​≤1 controls every scaled estimated component locally. A root-mean-square test has a different componentwise implication. Neither test automatically certifies the complete trajectory's global error.
Write Yi​ for the candidate accepted component and require si​>0. The absolute and relative error tolerances scale in the title produces the dimensionless maximum norm test
E=max1≤i≤m​atoli​+rtoli​max(∣yi​∣,∣Yi​∣)∣ei​∣​≤1.
(1)
Absolute tolerances have the same units as the corresponding solution components; relative tolerances are dimensionless. Choose separate absolute scales for components measured in different units or with different significant magnitudes. Near zero, a purely relative test can demand a zero allowable error; a positive absolute scale avoids that difficulty. The crossover is max(∣yi​∣,∣Yi​∣)≈atoli​/rtoli​ when rtoli​>0. Official solver documentation specifies the analogous blend atol+rtol∣y∣ and allows component-specific absolute tolerances; the old/new maximum above is the convention used in this example.[ref]
A root mean square version replaces the maximum norm by Erms​=m−1∑i​(∣ei​∣/si​)2​. It permits one scaled component as large as m​ when all others vanish, so passing that test does not mean every component is at most one. State the aggregation rule along with the absolute and relative error tolerances. Neither rule is a bound on actual global error.

Local error estimator (en+1​)

Words: 1k Articles: 5
Error control for ODE solvers OurBigBook.com
A local error estimator approximates a numerical step's defect from the exact solution starting at the same input. Differences between formulas estimate error only after their asymptotic orders and constants are accounted for. Step-doubling error estimation, an embedded Runge-Kutta pair and predictor-corrector error estimation are common constructions. They do not by themselves bound accumulated global error.
Let Φh​(tn​,yn​) be the exact endpoint of the ordinary differential equation started at the numerical value yn​, and let Yn+1​ be the candidate numerical endpoint. The signed local defect being estimated is ℓn+1​=Φh​(tn​,yn​)−Yn+1​. In contrast, actual global error compares Yn+1​ with the solution of the original initial value problem, including all previous steps. The local truncation error convention inserts original exact data instead. These starting-value distinctions matter even when the same formula is used for every step. A practical local error estimator also relies on a smooth Taylor expansion; a small difference can reflect accidental cancellation rather than a rigorous upper bound.

Predictor-corrector error estimation

Words: 48
Local error estimator OurBigBook.com
A predictor and corrector give distinct approximations from the same local history. Their difference, scaled by their leading error constants and orders, can estimate a local defect. Raw differences without that calibration need not estimate the corrected solution's error. Variable-step multistep methods also require updated coefficients and controlled history handling.

Embedded Runge-Kutta pair

Words: 812 Articles: 2
Local error estimator OurBigBook.com
Two Runge-Kutta methods share a stage matrix and nodes but use different output weights. An order-p and order-q pair with q<p gives an output difference generally of order hq+1, estimating the lower-order defect. Shared stage evaluations reduce the cost. The adaptive step-size controller exponent must reflect this estimator order, rather than blindly the higher reported solution order.
Using the slope convention for Runge-Kutta stages, an embedded Runge-Kutta pair computes
Y[p]=yn​+h∑i=1s​bi​ki​,Y[q]=yn​+h∑i=1s​bi​ki​,d=Y[p]−Y[q]=h∑i=1s​(bi​−bi​)ki​.
(2)
Its Butcher tableau has two output rows, bT and bT. Evaluating f is often the expensive part of solving an ordinary differential equation; after the shared slopes have been computed, the extra row needs only another linear combination.[ref]
Write Φ for the exact endpoint from the current numerical state, and define signed local defects ℓq​=Φ−Y[q] and ℓp​=Φ−Y[p]. Then d=ℓq​−ℓp​. If ℓq​=Cq​hq+1+O(hq+2) and ℓp​=O(hp+1), with Cq​=0, the difference reproduces the leading lower-order defect. It does not reproduce the leading higher-order defect. Here the powers use big O notation and a smooth Taylor expansion; a vanishing leading coefficient or accidental cancellation can make the estimate misleading.
A common choice accepts Y[p] after testing d with absolute and relative error tolerances. With the scale approximately unchanged on a retry, the adaptive step-size controller uses exponent 1/(q+1). Accepting a better endpoint does not change the power in the quantity being tested. The Euler-Heun embedded pair makes this visible without a large coefficient table.[ref]

Euler-Heun embedded pair (d=h(k2​−k1​)/2)

Words: 569 Articles: 1
Embedded Runge-Kutta pair OurBigBook.com
The Euler-Heun 1(2) pair combines the explicit Euler method and Heun's method. Here 1(2) names their respective order of a numerical method; the accepted endpoint in this article is the second-order one. Its shared Runge-Kutta stages and endpoints are
k1​Y[1]d​=f(tn​,yn​),=yn​+hk1​,=Y[2]−Y[1]=2h​(k2​−k1​).​k2​Y[2]​=f(tn​+h,yn​+hk1​),=yn​+2h​(k1​+k2​),​01​0121​1​0021​0​​
(3)
The first output row in this Butcher tableau is Heun's method; the second is the explicit Euler method. Both outputs cost two evaluations of f together, rather than one for Euler method plus two for a separately computed Heun's method.
For the initial value problem y′=y, y(0)=1, take h=0.2. The first slope is k1​=1; the stage state is 1+0.2k1​=1.2, giving k2​=1.2. Therefore
Y[1]=1.2,Y[2]=1.22,d=0.02,y(0.2)=e0.2≈1.22140275816.
(4)
The exact exponential function gives signed local defects approximately 0.02140275816 for the explicit Euler method and 0.00140275816 for Heun's method. Their difference is exactly 0.02. Thus the pair difference estimates the larger Euler defect; calling it the actual Heun defect would miss by a factor about fourteen here.
More generally, a step from yn​ on y′=y has
ℓ1​ℓ2​d​=yn​(eh−1−h)=yn​(2h2​+6h3​+O(h4)),=yn​(eh−1−h−h2/2)=yn​(6h3​+O(h4)),=yn​2h2​.​
(5)
These original Taylor expansions separate three quantities: the accepted Heun's method has local truncation error O(h3) and global error O(h2) under suitable numerical stability, while the tested local error estimator is O(h2). For E=∣d∣/s with s held approximately fixed, use hnew​=ηhE−1/2. A cube-root update would model a different quantity, the actual higher-order local defect.
Adaptive Euler-Heun integration of exponential growth
Words: 362
Euler-Heun embedded pair OurBigBook.com
Continue the initial value problem y′=y, y(0)=1, to t=4 using the Euler-Heun embedded pair. Choose absolute and relative error tolerances atol=10−3 and rtol=0, so the scalar scale is s=10−3 throughout. This intentionally absolute-only test makes the local and accumulated errors directly comparable. Start with h=0.2, accept the Heun's method endpoint precisely when E=∣d∣/s≤1, and after every trial use the capped adaptive step-size controller
hnext​=hmin(2,max(0.2,0.9E−1/2)).
(6)
For E=0 use the growth factor two. Cap every trial at 4−tn​; on rejection retain the old time and state. These choices specify an original computation, rather than a claim about the defaults of a particular software solver.
The initial trial has E=20 and is rejected. Retrying from (0,1) with h=0.9(0.2)/20​≈0.0402492236 gives E=0.81 and is accepted. The run takes 315 accepted steps and one rejected trial. Increasing exponential growth makes the local error estimator ∣d∣=∣yn​∣h2/2 grow at a fixed h, so subsequent steps shrink roughly like ∣yn​∣−1/2. The final step is additionally shortened to land at t=4.
The right panel plots errors against the accepted-step number, all divided by the same s. The actual Heun local defect uses the restarted exact endpoint yn​ehn​, while actual global error uses etn+1​. All accepted E are at most one, and the actual Heun local defects here are even smaller, at most about 0.01143s. Nevertheless the endpoint is yN​≈54.5833912205, versus e4≈54.5981500331, with absolute error about 0.0147588=14.7588s. Passing local tests therefore does not certify the original trajectory's global error.
This failure of a global guarantee has an exact explanation for this example. Put R(h)=1+h+h2/2 and gn​=etn​−yn​. Then
gn+1​=ehn​gn​+yn​(ehn​−R(hn​)).
(7)
Each new local defect is added to the previous error amplified by ehn​. Iterating this identity, rather than merely inspecting E, accounts for accumulation. The variable-step global ODE error bound describes the corresponding mechanism for more general ordinary differential equations.
Repeating with atol=10−2 gives 98 accepted steps, one rejection and endpoint absolute error about 0.153252; with atol=10−4 it gives 1001 accepted steps, two rejections and endpoint absolute error about 0.00145642. Accuracy improves on this smooth problem, but the endpoint error remains about fifteen times the requested local scale. A different initial value problem can amplify or damp defects differently.

Step-doubling error estimation (efine​=(Yh/2,h/2​−Yh​)/(2p−1))

Words: 56
Local error estimator OurBigBook.com
For an order-p one-step method with leading numerical error Chp+1, two half steps have leading error Chp+1/2p. The displayed difference estimates exact minus the finer approximation. Adding it implements Richardson extrapolation. It requires a common starting value, the smooth local expansion, and accuracy of all algebraic solves; it can fail across a nonsmooth event.

Adaptive Euler step doubling for exponential decay (y′=−y,y(0)=1)

Words: 636
Error control for ODE solvers OurBigBook.com
Consider the nonstiff scalar initial value problem y′=−y, y(0)=1, on 0≤t≤8. Its exact solution is the exponential decay y(t)=e−t. Use step-doubling error estimation with the explicit Euler method: from the same numerical starting value yn​, form one coarse step Cn​ and two half steps giving Fn​:
Cn​=(1−hn​)yn​,Fn​=(1−hn​/2)2yn​,en​=Fn​−Cn​=4hn2​yn​​.
(8)
Accept yn+1​=Fn​ when the absolute and relative error tolerances test En​=∣en​∣/sn​≤1 passes, with sn​=10−5+10−3max(∣yn​∣,∣Fn​∣). There is no Richardson extrapolation in the accepted value. Both approximations have order of a numerical method one, while this local error estimator has step exponent r=2. Consequently the adaptive step-size controller uses a square root, not a cube root:
qn​=min(5,max(0.2,0.9En−1/2​)),hnext​=qn​hn​.
(9)
Start with h0​=1. A rejected trial retains both tn​ and yn​, caps qn​ at one, and retries. A zero estimate uses qn​=5. Before every trial, cap hn​ at 8−tn​. Stop with a failure if floating-point arithmetic gives tn​+hn​=tn​, or after 100000 trials. These rules specify the example completely; they are not a prescription for every ordinary differential equation solver.
The first two trials, h=1 and h=0.2, have E≈247.525 and E≈9.90099 and are rejected. The next trial has h≈0.0572049 and E≈0.81 and is accepted. For positive decreasing numerical values, sn​=10−5+10−3yn​, so the local error estimator gives
En​=4(10−3+10−5/yn​)hn2​​.
(10)
When the relative term dominates, this suggests nearly constant accepted steps, approximately 2(0.9)10−3​. When yn​ falls below the crossover size 10−5/10−3=0.01, the absolute term increasingly permits longer steps. The sharp final decrease in h only lands on t=8; it does not indicate a sudden loss of smoothness.
The actual signed local defect from the same numerical input is
ℓn​=yn​e−hn​−Fn​=yn​(4hn2​​−6hn3​​+O(hn4​)).
(11)
Here O is Big O notation, obtained from Taylor's theorem for the exponential function. Thus en​ agrees with the leading term as hn​→0, but is not identical to ℓn​. At h=1, yn​=1, the estimate is 0.25 while the actual local defect is e−1−1/4≈0.117879. Their closeness improves for the smaller accepted steps. Had we added en​ using Richardson extrapolation, the accepted formula would instead be yn​(1−hn​+hn2​/2), of order of a numerical method two; the same raw difference would still scale as hn2​ and would not estimate that improved value's leading hn3​ defect.
The global error gn​=yn​−e−tn​ obeys an exact recurrence relation involving the actual local defects:
gn+1​=e−hn​gn​−ℓn​,g0​=0.
(12)
Each previous global error contracts, yet the local defects keep adding. In the plotted run, 101 steps are accepted and two trials are rejected. Every accepted En​ is at most approximately 0.81, while the largest ∣gn+1​∣/sn​ is approximately 38.6927. At t=8, the numerical value is approximately 0.00027184218, compared with the exact e−8≈0.00033546263, giving absolute error approximately 6.36204×10−5. The right-hand plot deliberately scales actual global error by the same sn​ used for local acceptance; it is not a new global error tolerance test.
Tightening both absolute and relative error tolerances by a factor ten gives 315 accepted steps and endpoint absolute error approximately 2.14922×10−5; tightening both by a factor one hundred gives 991 accepted steps and endpoint absolute error approximately 6.94171×10−6. This is a convergence comparison for this particular initial value problem. The endpoint error decreases by about a factor three per tenfold tightening, rather than by ten: a first-order Euler method accumulates defects across many steps, while its local error estimator varies quadratically with h. A variable-step global ODE error bound needs propagation information as well as accepted local tests.
The absolute stability boundary remains a separate constraint. On the Dahlquist test equation y′=−λy with λ>0, the accepted two-half-step formula has stability function R(−λh)=(1−λh/2)2. It strictly damps perturbations only for 0<λh<4. Its local error estimator is λ2h2yn​/4, which can pass an absolute-tolerance test at tiny yn​ even outside this damping interval. In a stiff two-mode linear system, a fast mode can therefore constrain the step long after its visible amplitude has become small. An adaptive step-size controller does not turn an explicit Euler method into an A-stable method. Official solver documentation likewise distinguishes explicit Runge-Kutta methods for nonstiff problems from implicit Runge-Kutta methods and backward differentiation formulas for stiff equations.[ref]
