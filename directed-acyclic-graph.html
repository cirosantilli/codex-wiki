Directed acyclic graph

 Home Mathematics Area of mathematics Combinatorics
OurBigBook.com Words: 1k Articles: 16
A Directed acyclic graph is a directed graph with no directed cycle: following its directed edges can never return to the starting vertex. A directed edge u→v can represent the requirement that task u finish before task v starts. A directed path then records a chain of prerequisites. The essential prerequisite for topological sorting is that these requirements contain no circular dependency. For finite directed graphs, this is equivalent to the existence of a topological order. [ref]
Consider an invented publishing workflow with five tasks: A drafts the text, B draws a figure, C reviews the text, D lays out the text and figure, and E publishes the result. Its directed edges are A→C, A→D, B→D, C→E, and D→E. Reviewing needs the draft; layout needs both the draft and figure; publication needs both review and layout. The drawing below encodes only these prerequisites, with no measured durations or resource constraints.
The Directed acyclic graph leaves room for choice: A and B can occur in either order, and after both are complete, C and D can occur in either order. Task C may even precede B, since the review does not need the figure. A topological order turns these local prerequisites into a complete executable list while retaining this freedom. It supplies a feasible sequential plan; task durations, available workers, and earliest finishing times require additional information.
