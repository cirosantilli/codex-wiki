Logical variable (x)

 Home Mathematics Area of mathematics Foundations of mathematics Mathematical logic Logical formula
OurBigBook.com Words: 47
A logical variable is a symbol whose value is supplied by the semantics of a logical language. A propositional variable receives a truth value under a Boolean valuation. An individual variable of first-order logic receives an element of a structure under an assignment. These are different kinds of variable and should not be identified.
