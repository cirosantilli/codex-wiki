Vector line integral weighted by a scalar field (∫C​Vdr)

 ... Analysis Real analysis Calculus Multivariable calculus Vector calculus Line integral
OurBigBook.com Words: 102
For an oriented parametric curve r(t) and scalar field V, define the componentwise line integral
∫C​Vdr=∫V(r(t))r′(t)dt.
(78)
Its value is a vector and reversing orientation changes its sign. It differs from the scalar arc length integral ∫C​Vds=∫V(r(t))∣r′(t)∣dt, which is independent of orientation. A request to integrate a scalar field along a curve should specify which differential is intended.
For the counterclockwise circle r(ϕ)=(Rcosϕ,Rsinϕ,z0​), suppose the restricted field has Fourier series V(ϕ)=A0​+∑n≥1​(An​cosnϕ+Bn​sinnϕ). Orthogonality gives
∮C​Vdr=πR(−B1​,A1​,0),∮C​Vds=2πRA0​.
(79)
The oriented vector integral selects the first angular harmonics, whereas the scalar arc-length integral selects the mean.
