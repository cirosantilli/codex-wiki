Write V∗=V′ for the dual space. Define θ(v)(f)=f(v). For fixed v, this is a linear functional on V∗; evaluation is also linear in v, so θ:V→V∗∗ is a linear map. If v=0, extend v to a basis and take its first coordinate linear functional f; then f(v)=1. Thus θ is injective. A dual basis has the same number of elements as the original basis, so dimV=dimV∗=dimV∗∗. The rank-nullity theorem now makes θ an linear isomorphism.

U∘={f∈V∗:f(u)=0 for every u∈U}.
