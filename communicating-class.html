Communicating class

 ... Mathematics Area of mathematics Probability and statistics Probability theory Markov process Markov chain
OurBigBook.com Words: 783 Articles: 8
In a finite, time-homogeneous Discrete-time Markov chain with row-stochastic transition matrix P, write i→j when j is accessible from i, meaning (Pn)ij​>0 for some n≥0. States communicate, written i↔j, when both i→j and j→i. Communication is an equivalence relation, and a communicating class is an entire equivalence class
C(i)={j∈S:i↔j}.
(132)
Thus communicating classes form a partition of the state space; a smaller mutually communicating subset is not itself a class. See Maria Cameron's Markov Chains notes, section 1.2.
The allowance of zero steps matters: P0=I, the identity matrix, makes i→i true even for a state with no possible positive-time return. Symmetry is built into communication. For transitivity, concatenate a positive-probability path from i to j with one from j to k, and do the same in reverse. These observations prove the equivalence relation directly. One-way accessibility alone is not symmetric and does not define the classes; see Accessible state of a Markov chain.
A closed communicating class satisfies Pij​=0 for every i∈C and j∈/C. Once entered, it cannot be left. A singleton class is an absorbing state exactly when it is closed. An open communicating class has an outgoing transition; after a path leaves it, it cannot return, since that would make the visited outside states communicate with it. The internal motion of a closed class can nevertheless continue forever.
For this constructed example, in state order (s,c1​,c2​,a), the transition matrix is
P=​1/2000​1/4010​0100​1/4001​​.
(133)
There are exactly three communicating classes: {s}, {c1​,c2​}, and {a}. Only the first is open. The second is closed but neither of its states is an absorbing state; they alternate deterministically. Although s→c2​ via c1​, the reverse accessibility fails. A direct matrix power check gives (P2)s,c2​​=1/4 and (P2)c2​,s​=0.
Starting at s, let τ be the first hitting time of either closed class. Staying at s for n steps has probability 2−n, so Ps​(τ>n)=2−n and Es​τ=∑n≥0​2−n=2. The two eventual destination classes each have probability ∑k≥0​(1/2)k(1/4)=1/2. Hence the hitting probability of the absorbing state a is only 1/2, and its unconditional expected hitting time from s is infinite: on half the paths it is never hit. In particular, entering a closed class with certainty does not imply entering an absorbing state with certainty.
Classifying the state space separates two questions: which closed region will eventually be entered, and how does the Markov chain move inside that region? In this example the restriction to {c1​,c2​} is an irreducible Markov chain with period two; the restriction to {a} is a one-state irreducible Markov chain with period one. The whole Markov chain is reducible. The absorbing state example illustrates a different possibility: every closed class is a singleton, so eventual class selection is also terminal outcome selection.
