Iteration matrix (H)

 ... Mathematics Area of mathematics Analysis Numerical analysis Numerical linear algebra Stationary iterative method for a linear system
OurBigBook.com Words: 540 Articles: 2
For a stationary iteration x(k+1)=Hx(k)+v, the matrix H propagates the error by e(k+1)=He(k). Convergence from every initial error is equivalent to ρ(H)<1.
For a matrix splitting A=M−N, the iteration matrix is H=M−1N=I−M−1A, where I is the identity matrix. If Ax∗​=b, subtracting its fixed point equation from the update gives
e(k)=x(k)−x∗​,e(k+1)=He(k),e(k)=Hke(0).
(110)
Thus b determines the fixed point, while H determines how the forward error moves. An eigenvector v with eigenvalue λ is an error direction whose coefficient is multiplied by λ on every step. A negative real eigenvalue reverses its sign; a zero eigenvalue removes that component in one step.
