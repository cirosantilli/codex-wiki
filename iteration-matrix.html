Iteration matrix (H)

 ... Mathematics Area of mathematics Analysis Numerical analysis Numerical linear algebra Stationary iterative method for a linear system
OurBigBook.com Words: 25
For a stationary iteration x(k+1)=Hx(k)+v, the matrix H propagates the error by e(k+1)=He(k). Convergence from every initial error is equivalent to ρ(H)<1.
