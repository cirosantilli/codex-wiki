A profile likelihood maximizes over it; Bayesian model evidence integrates over it using a proper prior distribution. These operations differ and need not give the same inference. A baseline hazard in a Cox proportional-hazards model is an infinite-dimensional example.

A covariate is an observed explanatory variable used to model the conditional distribution of a response. A vector of covariates can enter a linear predictor, a treatment-effect adjustment or a hazard multiplier. Conditioning on a covariate does not itself establish that its effect is causal.

Baseline covariate

A baseline covariate is measured before treatment assignment or exposure. A prognostic baseline covariate predicts the outcome. Adjusting for such variables in a randomized controlled trial can improve statistical efficiency without conditioning on a treatment consequence. This precision role of prognostic baseline adjustment is described in the FDA statistical guidance on covariate adjustment.

Identifiability

A statistical model is identifiable when distinct parameter values determine distinct probability distributions. In a nonidentifiable parameterization, data can at most estimate combinations of parameters that remain unchanged along each equivalent parameter set.

In a shared zero-inflated Gamma-Poisson count model, write mj​=(1−π)μj​ and κ=(τ+π)/(1−π). Its first two moments are Var(Yj​)=mj​+κmj2​ and Cov(Yj​,Yk​)=κmj​mk​. These moments do not separately identify π, τ, and the component-mean intercept: taking π′=0, τ′=κ and μj′​=mj​ gives the same first two moments. The full count distribution can carry information absent from the moments. A consistent estimator of a marginal mean ratio therefore need not consistently estimate a structural-zero fraction from a misspecified moment parameterization.

In a normal linear model with an intercept and factor effects, set the effect of one factor level to zero. For a known mean-zero noise law with finite variance σ2, observing only Y=a+ϵ with unrestricted a∈R has minimax risk σ2 under squared-error loss. The observation itself attains this risk. A probabilistic graphical model represents factorization and conditional-independence structure using a graph whose vertices are random variables.

Junction tree

Probabilistic graphical model OurBigBook.com
A junction tree connects the maximal cliques of a chordal graph into a tree satisfying the running intersection property. Its edges carry separators equal to the intersections of the endpoint cliques. Assigning original factors to containing cliques permits exact sum-product belief propagation without summing independently over the entire collection of variables.

Junction tree algorithm

Words: 60
Junction tree OurBigBook.com
The junction tree algorithm performs exact inference in a finite probabilistic graphical model. First moralize a Bayesian network if necessary; then apply triangulation of an undirected graph, organize its maximal cliques into a junction tree, and assign each original factor to one containing clique. Inward and outward junction-tree sum-product messages compute the normalizing constant and marginal distributions. Its cost depends exponentially on the largest clique's number of variables, rather than necessarily on the total number of variables.

Assign each factor exactly once to a containing clique and multiply the factors there into ψi​. The displayed sum-product belief propagation message sums out variables of Ci​ outside the separator Sij​=Ci​∩Cj​. By the running intersection property, eliminating all variables in the subtree on the i side creates precisely this function of the separator. An inward pass computes the normalizing constant at the root; an outward pass produces marginal distributions. For pedigree likelihoods, observed genotypes and penetrance factors simply multiply the relevant potentials.

Running intersection property (Ci​∩Cj​⊆Ck​along the path from i to j)

The running intersection property says that every variable belongs to a connected subtree of a junction tree. Equivalently, every clique along the path between two cliques contains their intersection. This ensures that eliminating variables on one side of a tree edge leaves a message depending only on its separator with the other side.

Bayesian network (p(x)=∏j​p(xj​∣xpa(j)​))

A Bayesian network consists of a Directed acyclic graph G whose nodes are random variables, together with conditional distributions satisfying p(x)=∏j​p(xj​∣xpaG​(j)​). Its Directed acyclic graph encodes conditional independence constraints. For unrestricted binary variables it has ∑j​2∣paG​(j)∣ free conditional probabilities. A Directed acyclic graph used this way need not have a causal interpretation.

Bayesian network structure score (p(G∣D))

Words: 90

For observations D and graph G, Bayes' theorem gives p(G∣D)∝π(G)∫p(D∣θG​,G)π(θG​∣G)dθG​. Here π(G) is the graph prior distribution and θG​ the local distribution statistical parameters. The integral is Bayesian model evidence; it averages over nuisance parameters with a proper statistical parameter prior distribution. For independent complete observations, the node-factorized likelihood function and independence of local statistical parameter prior distributions make the evidence factor over nodes; suitable conjugate priors can make the local integrals analytic. With missing node observations, integrating out unobserved values can couple the local parameters, so independence of local prior distributions alone does not guarantee this factorization. Proper priors and coherent hyperparameters matter for comparing different graphs.

A Markov blanket of a variable is a set that makes it conditionally independent of every remaining variable. In a Directed acyclic graph, the parents, children, and other parents of the children form the standard Markov blanket.

A missing adjacent vertex leaves a one-edge active path; a missing other parent of a child leaves the active path k→h←u, since the child h is necessarily conditioned. Thus the graphical blanket is the unique smallest screening set.
