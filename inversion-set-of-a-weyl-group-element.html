Inversion set of a Weyl-group element (N(w))

 ... Root-space decomposition Root system Weyl reflection Reflection group of a root system Weyl group Coxeter length
OurBigBook.com Words: 35
For a chosen positive system of a root system Π, the inversion set is
N(w)={β∈Π:w(β)∈−Π}.
(31)
For a finite Weyl group, ∣N(w)∣=ℓ(w).
Its cardinality is the Coxeter length; this root-sign definition should not be silently identified with an unspecified permutation inversion convention.
