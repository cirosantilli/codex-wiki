Type inference

 Home Computer science Programming language Type system
OurBigBook.com Words: 93 Articles: 1
Type inference discovers types consistent with a program's structure and typing context. In our examples, it introduces fresh type variables, generates equations from typing judgments, and solves them by type unification. For f3, if f initially has unknown type α and the result has fresh type β, lambda application requires α=int→β.
