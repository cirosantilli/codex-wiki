Three-bit lossy Hamming code (R=1/3,D=1/4)

 ... Area of mathematics Probability and statistics Information theory Rate-distortion theory Rate-distortion function Hamming distortion
OurBigBook.com Words: 204
Let X1​,X2​,X3​ be independent fair bits. The encoder sends their majority bit: zero when at least two inputs are zero, and one otherwise. The decoder reconstructs 000 or 111 by repeating that received bit three times. This is lossy compression: different original strings deliberately share a reconstruction.
There are eight equally likely inputs. The strings 000 and 111 have zero Hamming distance from their reconstructions; each of the other six has Hamming distance one. One transmitted bit represents three source symbols, so
R=31​,D=8⋅32⋅0+6⋅1​=41​.​
(100)
Every input has average Hamming distortion at most 1/3, whereas the population average is 1/4. The actual block code therefore obeys R≥R(D)≈0.18872, but does not reach the optimal long-block rate.
This construction uses the same reconstruction strings as the threefold binary repetition code, but the tasks differ. An error-correcting encoder expands one source bit into three transmitted bits; this lossy compression example compresses three source bits into one transmitted bit. The source distribution and the direction of the mapping matter.
