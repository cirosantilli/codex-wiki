Open bosonic string mass spectrum (α′M2=N−a)

 ... Physics Branches of physics String theory Bosonic string theory String oscillator Bosonic string mass spectrum
OurBigBook.com Words: 48 Articles: 1
The string level operator for a free-ended open string is N=∑k>0​α−k​⋅αk​. The quantum condition is α′M2=N−a, where a is the normal-ordering constant of a string. Lorentz-consistent bosonic string theory has a=1.
