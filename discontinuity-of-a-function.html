Discontinuity of a function

 ... Area of mathematics Analysis Real analysis Calculus Limit of a function Continuous function
OurBigBook.com Words: 277 Articles: 2
A function is discontinuous at a point in its domain of a function when it fails the epsilon-delta definition of continuity there. Two basic failures are an incorrect assigned value and unequal one-sided limits. They demand different repairs.
For a removable discontinuity, consider
r(x)={x2,1,​x=0,x=0.​
(72)
The limit at zero is 0, but r(0)=1. Replacing that one value by 0 gives the continuous square function. The sequence xn​=1/n makes the mismatch visible: r(xn​)=1/n2→0=r(0). A removable discontinuity can also describe an expression with a missing value, in which case the question is whether a continuous extension to the missing input exists.
For a jump discontinuity, take j(x)=0 for x<0 and j(x)=1 for x≥0. The left and right one-sided limits at zero are 0 and 1. No assignment to j(0) can equal both, so changing only the point value cannot make the function continuous there. Contrast both examples with the corner of ∣x∣: that function is continuous at zero even though its derivative is absent.
