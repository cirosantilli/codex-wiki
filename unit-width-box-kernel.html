Unit-width box kernel (K(u)=1[−1/2,1/2]​(u))

 ... Statistical inference Nonparametric statistics Nonparametric regression Local polynomial regression Kernel for nonparametric regression Uniform smoothing kernel
OurBigBook.com Words: 46
The unit-width centred box kernel is K(u)=1[−1/2,1/2]​(u). It has integral one and squared L2 norm one. Its rescaling Kh​(u)=h−1K(u/h) averages a function on intervals of length h. It is obtained from the uniform smoothing kernel with support [−1,1] by rescaling, and is useful in both kernel density estimation and local polynomial regression.
