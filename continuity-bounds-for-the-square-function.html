Continuity bounds for the square function (δ=min{1,ε/(2∣a∣+1)})

 ... Analysis Real analysis Calculus Limit of a function Continuous function Epsilon-delta definition of continuity
OurBigBook.com Words: 133
For f(x)=x2 at any real a, polynomial factorization gives
∣f(x)−f(a)∣=∣x−a∣∣x+a∣.
(71)
If ∣x−a∣<1, the triangle inequality yields ∣x+a∣≤∣x−a∣+2∣a∣<2∣a∣+1. Therefore the displayed choice of δ makes ∣x−a∣<δ imply ∣f(x)−f(a)∣<ε. This proves continuity and gives an explicit local error bound, rather than an inference from a drawing.
At a=1 and ε=0.6, this sufficient choice is δ=0.2. The permitted function inputs satisfy 0.8<x<1.2; their actual function outputs lie in (0.64,1.44), inside the requested band (0.4,1.6). A sufficient input window need not be the largest possible one.
