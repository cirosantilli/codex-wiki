Cokernel (cokerT=W/imT)

 Home Mathematics Area of mathematics Algebra Linear algebra
OurBigBook.com Words: 450 Articles: 1
The cokernel records output information that a linear map cannot produce. For T:V→W, it is the quotient vector space
cokerT=W/imT.
(102)
Its elements are cosets [b]=b+imT. Two vectors b,c∈W represent the same class exactly when b−c is in the image of a linear map. The zero class is the whole image of a linear map, so
T(x)=b is solvable⟺[b]=0 in cokerT.​
(103)
Changing b by an attainable output does not change its obstruction. This is useful because one can test compatibility before trying to find an input. The quotient vector space construction is described in Axler's §3E. [ref]
For the linear map T:R2→R2 given by T(x,y)=(x+2y,0), the image of a linear map is the horizontal line. All outputs (b1​,b2​) with the same second coordinate have the same cokernel class, because their difference is horizontal. Thus this cokernel is isomorphic to R via [(b1​,b2​)]↦b2​. In particular, (3,0) has zero class and is attainable, while (3,1) has nonzero class and is unattainable.
If W is finite-dimensional, the dimension rule for a quotient vector space gives
dimW=rankT+dimcokerT.
(104)
Compare this with the rank-nullity theorem, dimV=rankT+dimkerT. The kernel counts invisible inputs; the cokernel counts missing output directions. They need not have the same dimension: B(x,y,z)=(x+2y,0) has a two-dimensional kernel and a one-dimensional cokernel. A linear map is surjective exactly when its cokernel is zero.
The cokernel is a quotient, rather than a chosen perpendicular vector subspace. With a finite-dimensional inner product space as output, one may represent each class by its unique component in the orthogonal complement of the image of a linear map. That representation depends on the chosen inner product. For matrices over the complex numbers, this complement is kerA∗, leading to the cokernel compatibility equations.
The same quotient definition applies to a group homomorphism of abelian groups. For T:Z→Z given by T(n)=2n, the cokernel is Z/2Z. The equation 2n=b is solvable exactly when b is an even integer; the two cosets record integer parity. A quotient captures the obstruction here just as it captures a missing output coordinate for a linear map.
