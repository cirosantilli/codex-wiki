Rearrangeable triangular loss network

 ... Area of mathematics Probability and statistics Probability theory Queueing theory Stochastic network Loss network
OurBigBook.com Words: 220 Articles: 1
Three nodes have integer link capacities C12​,C13​,C23​. Calls between a node pair use either its direct link or the two-link alternative. With unrestricted instantaneous rearrangement of existing calls, counts n12​,n13​,n23​ are feasible exactly when n12​+n13​≤C12​+C13​, n12​+n23​≤C12​+C23​ and n13​+n23​≤C13​+C23​. Necessity follows by counting calls crossing each node cut. For sufficiency, the inequalities allow at most one count to exceed its direct-link capacity. Divert precisely that excess to the other two links; the same inequalities ensure capacity there. The counts thus have the same feasible set as a fixed routing loss network with one virtual resource at each node, capacity equal to the sum of its two incident physical-link capacities, and each call using its two endpoint resources. With independent Poisson processes for arrivals and independent routing-independent exponential distributions for holding times, this gives the usual product-form stationary distribution of a loss network and exact Poisson arrivals see time averages blocking probabilities.
