Chain in a partial order

 ... Mathematics Area of mathematics Foundations of mathematics Set theory Set Partially ordered set
OurBigBook.com Words: 24
A subset of a partially ordered set on which the inherited order is total. The upper-bound hypothesis in Zorn lemma concerns all such subsets, not just countable increasing sequences.
