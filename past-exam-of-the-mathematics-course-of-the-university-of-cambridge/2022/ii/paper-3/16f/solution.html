The compactness theorem says that a set T of first-order sentences has a model if and only if every finite subset of T has a model. One implication follows by taking the same model. Conversely, if T had no model, then by the Godel completeness theorem it would prove a contradiction. A formal proof uses only finitely many assumptions, so some finite subset of T would already have no model. This contradiction proves compactness.
