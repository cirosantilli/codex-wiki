Past exam of the mathematics course of the University of Cambridge / 2012 / iii / Paper 83 / 5 / Solution

An Aronszajn tree is a set-theoretic tree of height ω1​, with countable levels and no uncountable chain in a partial order, equivalently no cofinal branch. The strict predecessors of a node are well-ordered, and its height is their order type. Such trees exist in ZFC, as the following rationally labelled Aronszajn tree construction shows.
We build countable nonempty levels Tα​ for all α<ω1​. A node t∈Tα​ is a strictly increasing function t:α→Q∩(0,1), and the tree order is proper initial-segment extension. Every restriction t↾β must lie in Tβ​. Give nonempty t the rational label
ℓ(t)=supran(t)<1,
(30)
and give the empty root label 0. We require labels to increase strictly along the tree. We also maintain the bounded rational extension property:
s∈Tβ​,β<α,ℓ(s)<q<1, q∈Q⟹(∃t∈Tα​) s⊂t, ℓ(t)<q.
(31)
Keeping room below every rational cap is what makes the limit step possible.
Start with T0​={∅}. At a successor stage, for every s∈Tα​ and every rational r with ℓ(s)<r<1, include
s⌢r=s∪{(α,r)}
(32)
in Tα+1​. Its label is r, strictly larger than its predecessor's. This level is countable. To extend an earlier node below a prescribed cap q, first extend to Tα​ below q by the inductive property, if necessary, then choose a new rational label between that label and q. Thus the extension property is preserved.
Now let λ<ω1​ be a nonzero limit. The whole tree below λ is countable. For each pair (s,q) with s∈Tβ​, β<λ, and ℓ(s)<q<1, construct one node at height λ extending s below q. There are only countably many such pairs.
Choose a rational r with ℓ(s)<r<q and an increasing sequence
β=α0​<α1​<⋯<λ,supn​αn​=λ.
(33)
Set s0​=s. Given sn​∈Tαn​​ with ℓ(sn​)<r, set
rn​=2r+max{ℓ(sn​),r−1/(n+1)}​.
(34)
This is rational and satisfies max{ℓ(sn​),r−1/(n+1)}<rn​<r. The successor rule supplies un​=sn⌢​rn​ at height αn​+1. If αn+1​=αn​+1, take sn+1​=un​; otherwise use the already established extension property below λ to extend un​ to sn+1​∈Tαn+1​​ with label below r.
The union t=⋃n​sn​ has domain λ and extends s. It is strictly increasing, and every shorter restriction is already in its prescribed level. All its values are below r, while it contains the values rn​>r−1/(n+1). Hence
supran(t)=r∈Q,ℓ(t)=r<q.
(35)
Every predecessor's label is below the label of some sn​, and hence below r. Thus strict increase of labels survives at the limit. Include one such t for each pair (s,q) in Tλ​, discarding duplicates. This gives a countable level and preserves every bounded extension requirement. In particular applying it to the root makes the level nonempty. The choices here are permitted by the ambient axiom of choice; transfinite recursion through the set ω1​ completes the construction.
Put T=⋃α<ω1​​Tα​. A node of domain α has exactly the restrictions of domains β<α as predecessors, so its height is α. Therefore T has height ω1​ and countable levels. Since ℓ:T→Q is strictly increasing on comparable nodes, an uncountable chain would inject into the countable set Q, which is impossible. Each label fiber is a tree antichain, so the tree is even a special Aronszajn tree:
ZFC proves the existence of a special Aronszajn tree.​
(36)
