Past exam of the mathematics course of the University of Cambridge / 2012 / iii / Paper 83 / 2 / Solution

We work in the ambient theory ZFC for this question. Write t(x)=TC({x}), using the transitive closure convention that t(x) contains x and all its membership descendants.
First construct a set containing exactly the intended objects. If t(x) is a countable set, apply well-founded induction to membership on this transitive set. If all members z of y∈t(x) have countable set-theoretic rank, then
rank(y)=supz∈y​(rank(z)+1)<ω1​.
(7)
Indeed y⊆t(x) is countable, and a countable union of countable sets is countable in ZFC. The induction therefore gives rank(x)<ω1​. The collection
C={x∈Vω1​​:t(x) is countable}
(8)
is now a genuine set by the axiom schema of separation inside the cumulative hierarchy level Vω1​​, and it contains every hereditarily countable set. It is a transitive set, since y∈x implies t(y)⊆t(x).
If a is a countable subset of C, then
t(a)⊆{a}∪⋃x∈a​t(x).
(9)
The right side is countable, so a∈C. Thus C has countable-subset closure. This proves existence of a set with the required closure before taking any intersection.
To make the least-set argument precise, form the nonempty set
F={B⊆C:every countable subset of B belongs to B}.
(10)
It is a subset of P(C) and contains C. Its intersection H=⋂F is also closed: a countable subset of H is a countable subset of every B∈F and therefore belongs to each such B. For any set X with the prescribed closure, C∩X∈F, whence H⊆X. This is leastness among all such sets, not just among subsets of C.
Finally, well-founded induction on C shows C⊆X for every such X: when all members of x∈C are in X, the countable set x is a countable subset of X, so x∈X. Hence H=C, proving that the definition gives precisely
HC={x:TC({x}) is countable}.​
(11)
For the cardinal bound, code the entire countable membership ancestry. A code is a triple (D,R,n), where D⊆ω, R⊆D2 is a well-founded relation and an extensional relation, and n∈D is distinguished. There are at most 2ℵ0​ such codes: D and R are coded by subsets of countable sets, and a Cantor pairing function with finitely many tags codes the triple as a subset of ω.
The well-founded recursion
cR​(k)={cR​(l):lRk}
(12)
defines its collapse, as in the Mostowski collapse theorem. The range {cR​(k):k∈D} is countable and transitive; thus each decoded cR​(n) belongs to HC. Conversely, for x∈HC, choose a bijection e:D→t(x) and the point n with e(n)=x. Set lRk exactly when e(l)∈e(k). Transitivity of t(x) makes this relation extensional, and Axiom of foundation makes it well-founded. The recursion then gives cR​(k)=e(k), so this code decodes to x.
We have a surjection from a set of at most continuum many codes onto HC. Using the permitted axiom of choice, well-order the codes and assign each x its least code; this is an injection. In fact every subset of ω is hereditarily countable, giving the reverse bound as well:
∣HC∣=2ℵ0​,in particular ∣HC∣≤2ℵ0​.​
(13)
Every member has rank below ω1​, while every countable ordinal α belongs to HC and has rank α. Consequently
rank(HC)=ω1​.​
(14)
The axioms hold except Power Set. axiom of extensionality and Axiom of foundation are inherited by this transitive structure. The empty set and ω belong to it, giving the empty-set axiom and the axiom of infinity. The axiom of pairing follows from countable-subset closure. For a∈HC, ⋃a is a countable subset of HC, giving the Axiom of union. Any subset of a is countable and lies in HC, so the axiom schema of separation holds for all formulas interpreted in (HC,∈).
For the Axiom schema of replacement, let a formula interpreted in (HC,∈) assign a unique y∈HC to each x∈a∈HC. Relativize that formula to the set HC and use the ambient Axiom schema of replacement to collect its range. The range is countable and consists of members of HC, hence belongs to HC. The same argument, selecting one witness for each member of the countable domain, proves axiom schema of collection. An ambient choice function on a family a∈HC has a countable graph of ordered pairs of hereditarily countable sets. Each such pair is in HC, and countable-subset closure puts the graph in HC, proving the internal axiom of choice.
However, all external subsets of ω are elements of HC. An internal power set of ω would therefore have to be the full external P(ω), by transitivity and absoluteness of subset membership. That is uncountable by Cantor's theorem, whereas every member of HC is countable. Thus the axioms satisfied by hereditarily countable sets are
HC⊨ZFC with Power Set deleted,HC⊨Power Set.​
(15)
Here the asserted axiom list includes both Axiom schema of replacement and axiom schema of collection; no equivalence relying on Power Set is being silently invoked.
