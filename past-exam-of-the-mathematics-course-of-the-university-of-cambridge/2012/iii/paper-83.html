Here the power set notation gives xEy⟺P(x)⊆y. Suppose a nonempty set A has no E-minimal member. Form its intersection b=⋂A. This is a set: for any one a0​∈A, use the axiom schema of separation inside a0​ to define the elements common to all members of A. Selecting a single witness to nonemptiness is not an application of the axiom of choice.
For an arbitrary y∈A, lack of minimality supplies some x∈A with P(x)⊆y. Since b⊆x, every subset of b is a subset of x, so
P(b)⊆P(x)⊆y.
(1)
This conclusion holds for each y∈A, without choosing all the corresponding x simultaneously. Intersecting over y gives P(b)⊆b.
For completeness, the contradiction in Cantor's theorem is completely explicit here. By the axiom schema of separation put d={u∈b:u∈/u}. Then d∈P(b)⊆b, and consequently
d∈d⟺d∈/d,
(2)
which is impossible. Thus no such A exists:
E is well-founded, without Choice or Foundation.​
(3)
This power-set-predecessor relation proof uses neither a descending sequence nor a comparison of possibly non-well-orderable cardinalities. It proves well-foundedness directly from the minimal-member definition.

Order the collection Ch(P) of every chain in a partial order, including the empty chain, by inclusion. Suppose that j:Ch(P)→P is an order-preserving function and an injection. Let θ=h(P) be the Hartogs ordinal: by Hartogs theorem, no injection from θ to P exists.
Use transfinite recursion to define, for α<θ,
Cα​={pβ​:β<α},pα​=j(Cα​).
(4)
We verify both that j(Cα​) is defined and that the values are strictly increasing. Assume inductively that the earlier values are strictly increasing. Then Cα​ is a chain in a partial order. For any β<α, Cβ​⊆Cα​, so the fact that j is order-preserving gives pβ​≤pα​. Furthermore pβ​∈Cα​, whereas pβ​∈/Cβ​ by distinctness of the earlier values. Thus Cβ​=Cα​, and injectivity gives pβ​=pα​. We have proved
β<α⟹pβ​<pα​.
(5)
The empty initial chain starts the induction, and the same argument applies at every limit ordinal.
If a globally defined recursion rule is desired, apply j when the earlier range is a chain and otherwise use the fixed value j(∅). The induction shows that the fallback case never occurs. Thus no choices of new points are being made: the function j uniquely determines every stage.
The resulting function α↦pα​ is an injection from θ to P, contrary to its defining Hartogs ordinal property. Hence the chain-poset nonembedding lemma gives
No order-preserving injection Ch(P)⟶P exists.​
(6)

We work in the ambient theory ZFC for this question. Write t(x)=TC({x}), using the transitive closure convention that t(x) contains x and all its membership descendants.
First construct a set containing exactly the intended objects. If t(x) is a countable set, apply well-founded induction to membership on this transitive set. If all members z of y∈t(x) have countable set-theoretic rank, then
rank(y)=supz∈y​(rank(z)+1)<ω1​.
(7)
Indeed y⊆t(x) is countable, and a countable union of countable sets is countable in ZFC. The induction therefore gives rank(x)<ω1​. The collection
C={x∈Vω1​​:t(x) is countable}
(8)
is now a genuine set by the axiom schema of separation inside the cumulative hierarchy level Vω1​​, and it contains every hereditarily countable set. It is a transitive set, since y∈x implies t(y)⊆t(x).
If a is a countable subset of C, then
t(a)⊆{a}∪⋃x∈a​t(x).
(9)
The right side is countable, so a∈C. Thus C has countable-subset closure. This proves existence of a set with the required closure before taking any intersection.
To make the least-set argument precise, form the nonempty set
F={B⊆C:every countable subset of B belongs to B}.
(10)
It is a subset of P(C) and contains C. Its intersection H=⋂F is also closed: a countable subset of H is a countable subset of every B∈F and therefore belongs to each such B. For any set X with the prescribed closure, C∩X∈F, whence H⊆X. This is leastness among all such sets, not just among subsets of C.
Finally, well-founded induction on C shows C⊆X for every such X: when all members of x∈C are in X, the countable set x is a countable subset of X, so x∈X. Hence H=C, proving that the definition gives precisely
HC={x:TC({x}) is countable}.​
(11)
For the cardinal bound, code the entire countable membership ancestry. A code is a triple (D,R,n), where D⊆ω, R⊆D2 is a well-founded relation and an extensional relation, and n∈D is distinguished. There are at most 2ℵ0​ such codes: D and R are coded by subsets of countable sets, and a Cantor pairing function with finitely many tags codes the triple as a subset of ω.
The well-founded recursion
cR​(k)={cR​(l):lRk}
(12)
defines its collapse, as in the Mostowski collapse theorem. The range {cR​(k):k∈D} is countable and transitive; thus each decoded cR​(n) belongs to HC. Conversely, for x∈HC, choose a bijection e:D→t(x) and the point n with e(n)=x. Set lRk exactly when e(l)∈e(k). Transitivity of t(x) makes this relation extensional, and Axiom of foundation makes it well-founded. The recursion then gives cR​(k)=e(k), so this code decodes to x.
We have a surjection from a set of at most continuum many codes onto HC. Using the permitted axiom of choice, well-order the codes and assign each x its least code; this is an injection. In fact every subset of ω is hereditarily countable, giving the reverse bound as well:
∣HC∣=2ℵ0​,in particular ∣HC∣≤2ℵ0​.​
(13)
Every member has rank below ω1​, while every countable ordinal α belongs to HC and has rank α. Consequently
rank(HC)=ω1​.​
(14)
The axioms hold except Power Set. axiom of extensionality and Axiom of foundation are inherited by this transitive structure. The empty set and ω belong to it, giving the empty-set axiom and the axiom of infinity. The axiom of pairing follows from countable-subset closure. For a∈HC, ⋃a is a countable subset of HC, giving the Axiom of union. Any subset of a is countable and lies in HC, so the axiom schema of separation holds for all formulas interpreted in (HC,∈).
For the Axiom schema of replacement, let a formula interpreted in (HC,∈) assign a unique y∈HC to each x∈a∈HC. Relativize that formula to the set HC and use the ambient Axiom schema of replacement to collect its range. The range is countable and consists of members of HC, hence belongs to HC. The same argument, selecting one witness for each member of the countable domain, proves axiom schema of collection. An ambient choice function on a family a∈HC has a countable graph of ordered pairs of hereditarily countable sets. Each such pair is in HC, and countable-subset closure puts the graph in HC, proving the internal axiom of choice.
However, all external subsets of ω are elements of HC. An internal power set of ω would therefore have to be the full external P(ω), by transitivity and absoluteness of subset membership. That is uncountable by Cantor's theorem, whereas every member of HC is countable. Thus the axioms satisfied by hereditarily countable sets are
HC⊨ZFC with Power Set deleted,HC⊨Power Set.​
(15)
Here the asserted axiom list includes both Axiom schema of replacement and axiom schema of collection; no equivalence relying on Power Set is being silently invoked.

Put κ=∣X∣, an infinite cardinal number. The original PDF has the double exponent 22∣X∣; the single-exponent expression in the TeX aid is a transcription error.
We explicitly construct an independent family of subsets with 2κ members on a set of size κ. Let
D={(s,H):s∈[κ]<ω, H⊆P(s)}.
(16)
For each finite s there are finitely many possibilities for H. The collection of finite subsets of an infinite cardinal has size κ, so ∣D∣≤κ; the points ({ξ},∅) give the reverse bound. Thus ∣D∣=κ.
For every B⊆κ define
AB​={(s,H)∈D:B∩s∈H}.
(17)
To verify independence, take distinct B1​,…,Bn​ and bits ε1​,…,εn​. For each pair i<j, choose a point of Bi​△Bj​ and let s contain all these finitely many points. The traces Bi​∩s are pairwise distinct. Set
H={Bi​∩s:εi​=1}.
(18)
Then (s,H)∈ABi​​ exactly for those i with εi​=1. Every finite Boolean pattern is therefore realized. The cases n=0,1 work by the same definition, allowing s=∅. In particular the sets AB​ are all distinct, so the finite-trace independent family construction gives exactly 2κ independent members.
For each function ε:P(κ)→{0,1}, prescribe AB​ when ε(B)=1 and D∖AB​ when ε(B)=0. Independence gives the finite intersection property. Their finite intersections generate a proper filter on a set: its members are the subsets of D containing one of those intersections.
To extend this to an ultrafilter, order its proper filter extensions by inclusion. The union of a chain is again a proper filter, so Zorn's lemma supplies a maximal one, Uε​. If neither a subset Y nor its complement belonged to this filter, adjoining Y would still generate a proper filter: otherwise some existing member would be disjoint from Y and force its complement into the filter already. Maximality therefore gives the ultrafilter dichotomy. Using the ambient axiom of choice, choose such an extension for every ε.
Distinct functions differ at some B. Their ultrafilters respectively contain AB​ and its complement, and cannot be equal. There are 22κ such functions. Transporting the ultrafilters along a bijection D→X proves the lower bound. The upper bound is immediate because every ultrafilter is a subset of P(X):
22κ≤∣Ult(X)∣≤∣P(P(X))∣=22κ.
(19)
Thus the number of ultrafilters on an infinite set is
∣Ult(X)∣=22∣X∣.​
(20)

The maximum is 2ℵ1​. We construct that many aleph-one-like linear orders, whose proper initial segments are countable, and prove that they are nonisomorphic. As usual the rational-type requirement concerns nonempty proper initial segments; the empty segment occurs in every order.
Let D be the club set of nonzero limit ordinals below ω1​. For S⊆D, form the order sum
LS​=∑α<ω1​​Bα​,Bα​={1+Q,Q,​α∈S,α∈/S.​
(21)
Here 1+Q means a new least point followed by a copy of the rational numbers; distinct blocks are disjoint, and all points of an earlier block precede every point of a later one. Every block is countable, dense and has no greatest point. Since 0∈/S, the full total order has neither a least nor a greatest point. It has size ℵ1​.
The sum is dense: within a block use density, and for points in different blocks choose a larger point in the earlier block. If I is a proper initial segment and y∈/I lies in block α, then I is contained in the union of the blocks through α. There are only countably many such blocks, each countable. Thus I is countable, rather than an uncountable interval in an aleph-one-dense order.
Every nonempty I is dense and has no least point. If it has no greatest point either, the back-and-forth method gives I≅Q: enumerate both orders, alternately include the least unused element from either enumeration in a finite partial order isomorphism, and choose its partner in the appropriate open interval. Density and absence of endpoints always supply a new partner. The union is a bijective order isomorphism. If I has a greatest point, remove it, apply the same argument, and reattach it. Hence every nonempty proper initial segment is isomorphic to Q or Q+1.
The stationary information is recorded at the limit cuts. Write
FαS​=⋃β<α​Bβ​.
(22)
This is a continuous increasing kappa-filtration by countable initial segments. At a limit δ, the complement LS​∖FδS​ has a least point exactly when δ∈S.
Suppose f:LS​→LT​ is an order isomorphism. Since each filtration stage is countable, its image under f and the corresponding image under f−1 are bounded in block index: the supremum of their countable collection of countable ordinals remains below ω1​. Choose g(α)<ω1​ so that
f[FαS​]⊆Fg(α)T​,f−1[FαT​]⊆Fg(α)S​.
(23)
The set
C={δ∈D:(∀α<δ) g(α)<δ}
(24)
is a club set. To see unboundedness, start above any given ordinal and recursively choose γn+1​>γn​ larger than every g(α) for α≤γn​. The supremum of the countable sequence remains below ω1​ and belongs to C. Closure follows because below a limit of members of C, each fixed α lies below one of those members.
For δ∈C, continuity of the filtrations gives both inclusions needed for
f[FδS​]=FδT​.
(25)
The isomorphism therefore preserves whether the complementary final segment has a least point. Consequently
δ∈S⟺δ∈T(δ∈C).
(26)
This club agreement of countable filtrations proves the invariant: if S△T is stationary, the orders cannot be isomorphic.
We also construct enough pairwise different stationary encodings. For each β<ω1​, fix an injection eβ​:β→ω, and set
Aξ,n​={β∈D:ξ<β, eβ​(ξ)=n}.
(27)
For fixed ξ, these sets partition the stationary tail D∖(ξ+1). At least one Aξ,n​ is stationary: otherwise choose a club avoiding each one and intersect the countably many clubs to obtain a club avoiding the entire tail. The countable-intersection fact follows directly: above any starting point choose an increasing sequence, visiting each club infinitely often; its countable supremum belongs to every club by closure. For each ξ let n(ξ) be the least such n. One value n∗​ occurs for uncountably many ξ, since a countable union of countable sets is countable. For that fixed n∗​ the cells are pairwise disjoint, by injectivity of eβ​. Enumerating those cells gives
(Sη​:η<ω1​),
(28)
a family of pairwise disjoint stationary subsets of D. This is the explicit Ulam matrix on omega-one proof of disjoint stationary subsets of omega-one.
For A⊆ω1​ put S(A)=⋃η∈A​Sη​. If A=A′, their symmetric difference contains an entire Sη​ and is stationary. The stationary encoding in an aleph-one-like dense order therefore produces 2ℵ1​ pairwise nonisomorphic orders LS(A)​.
Finally, on a fixed carrier of size ℵ1​, every total order is a subset of its Cartesian square. That square has size ℵ1​, so there are at most 2ℵ1​ possible relations. Thus
2ℵ1​ pairwise nonisomorphic orders, the maximum possible.​
(29)

An Aronszajn tree is a set-theoretic tree of height ω1​, with countable levels and no uncountable chain in a partial order, equivalently no cofinal branch. The strict predecessors of a node are well-ordered, and its height is their order type. Such trees exist in ZFC, as the following rationally labelled Aronszajn tree construction shows.
We build countable nonempty levels Tα​ for all α<ω1​. A node t∈Tα​ is a strictly increasing function t:α→Q∩(0,1), and the tree order is proper initial-segment extension. Every restriction t↾β must lie in Tβ​. Give nonempty t the rational label
ℓ(t)=supran(t)<1,
(30)
and give the empty root label 0. We require labels to increase strictly along the tree. We also maintain the bounded rational extension property:
s∈Tβ​,β<α,ℓ(s)<q<1, q∈Q⟹(∃t∈Tα​) s⊂t, ℓ(t)<q.
(31)
Keeping room below every rational cap is what makes the limit step possible.
Start with T0​={∅}. At a successor stage, for every s∈Tα​ and every rational r with ℓ(s)<r<1, include
s⌢r=s∪{(α,r)}
(32)
in Tα+1​. Its label is r, strictly larger than its predecessor's. This level is countable. To extend an earlier node below a prescribed cap q, first extend to Tα​ below q by the inductive property, if necessary, then choose a new rational label between that label and q. Thus the extension property is preserved.
Now let λ<ω1​ be a nonzero limit. The whole tree below λ is countable. For each pair (s,q) with s∈Tβ​, β<λ, and ℓ(s)<q<1, construct one node at height λ extending s below q. There are only countably many such pairs.
Choose a rational r with ℓ(s)<r<q and an increasing sequence
β=α0​<α1​<⋯<λ,supn​αn​=λ.
(33)
Set s0​=s. Given sn​∈Tαn​​ with ℓ(sn​)<r, set
rn​=2r+max{ℓ(sn​),r−1/(n+1)}​.
(34)
This is rational and satisfies max{ℓ(sn​),r−1/(n+1)}<rn​<r. The successor rule supplies un​=sn⌢​rn​ at height αn​+1. If αn+1​=αn​+1, take sn+1​=un​; otherwise use the already established extension property below λ to extend un​ to sn+1​∈Tαn+1​​ with label below r.
The union t=⋃n​sn​ has domain λ and extends s. It is strictly increasing, and every shorter restriction is already in its prescribed level. All its values are below r, while it contains the values rn​>r−1/(n+1). Hence
supran(t)=r∈Q,ℓ(t)=r<q.
(35)
Every predecessor's label is below the label of some sn​, and hence below r. Thus strict increase of labels survives at the limit. Include one such t for each pair (s,q) in Tλ​, discarding duplicates. This gives a countable level and preserves every bounded extension requirement. In particular applying it to the root makes the level nonempty. The choices here are permitted by the ambient axiom of choice; transfinite recursion through the set ω1​ completes the construction.
Put T=⋃α<ω1​​Tα​. A node of domain α has exactly the restrictions of domains β<α as predecessors, so its height is α. Therefore T has height ω1​ and countable levels. Since ℓ:T→Q is strictly increasing on comparable nodes, an uncountable chain would inject into the countable set Q, which is impossible. Each label fiber is a tree antichain, so the tree is even a special Aronszajn tree:
ZFC proves the existence of a special Aronszajn tree.​
(36)
