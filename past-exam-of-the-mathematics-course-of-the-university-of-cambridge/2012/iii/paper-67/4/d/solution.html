Again put a=(1+λ)/2, b=(1−λ)/2. If computational strings z,y differ in h places, the matrix element of Uϕ⊗n​ between them is an−hbh: an unchanged bit contributes a, and a flipped bit contributes b. Hence the given operator is
Uϕ(n)​=Uϕ⊗n​.​
(32)
The printed factored expression an(b/a)h is undefined at a=0, namely ϕ=1/2. Its polynomial form an−hbh gives the natural continuous extension there, U1/2(n)​=X⊗n. For n≥2 the strict promise ϕ<1/n avoids that singular value; for n=1 the extension is needed to include the allowed phase 1/2. This is a removable defect of the formula, not a failure of unitarity of the tensor-product operator.
Prepare ∣−⟩⊗n. Its eigenvalue is λn=e2πinϕ, giving tensor-product eigenphase amplification. Write n=2s. If s<m, then
nϕ=2m−sx​,0≤x<2m−s,
(33)
where the upper bound is exactly the promise ϕ<1/n. Thus the amplified phase has only m−s unknown binary digits and no modulo-one aliasing. Run exact quantum phase estimation with m−s controls on the controlled-Uϕ(n)​ black box. It returns x exactly, after which division by the original 2m recovers ϕ.
The number of joint black-box uses is
2m−s−1=n2m​−1=O(2m/n).​
(34)
If s≥m, the dyadic promise and ϕ<1/n force x=0, so output ϕ=0 without querying the oracle. This covers the zero-control edge case without an invalid negative number of phase bits. The improvement counts one supplied controlled-Uϕ(n)​ call as one query. Implementing such a joint call from n individual controlled-Uϕ​ calls would remove the claimed factor-n primitive-query saving, and preparing the n target qubits is a separate gate cost.
