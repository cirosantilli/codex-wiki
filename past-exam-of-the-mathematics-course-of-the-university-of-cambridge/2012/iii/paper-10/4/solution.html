Past exam of the mathematics course of the University of Cambridge / 2012 / iii / Paper 10 / 4 / Solution

Write Ω=[N]ω for the space of infinite subsets of the natural numbers, identifying a set with its increasing enumeration. If s is finite and A is infinite with every element of A above maxs, set
[s,A]={s∪B:B∈[A]ω}.
(20)
For the empty stem there is no lower-bound restriction. These sets form the basis of the Ellentuck topology, also called the star topology. The stem s is fixed, while the infinite tail may be thinned.
A completely Ramsey set E⊆Ω is one for which every [s,A] admits an infinite B⊆A with [s,B]⊆E or [s,B]∩E=∅. This keeps the same stem. A Ramsey set of infinite subsets requires that every infinite A admit an infinite B⊆A with a homogeneous empty-stem cone [B]ω. It does not require preserving a nonempty finite stem.
A set is a star-Baire set if it differs from a star-open set by a star-meagre set, equivalently E△U is star-meagre for some star-open U. A nowhere dense set has closure with empty interior, and a meagre set is a countable union of such sets, with both notions interpreted in the specified topology.
For a non-Ramsey example, put M={2,3,…} and well-order all infinite subsets of M as (Aα​)α<c​, where c=2ℵ0​. Recursively choose two fresh points Xα​,Yα​∈[Aα​]ω, not used at earlier stages. This is possible because each cone has cardinality c and fewer than c points have been used before any stage. Let
C={Xα​:α<c},
(21)
keeping all the Yα​ outside C. Every infinite-subset cone on M meets both C and its complement. Thus C is not Ramsey, even when regarded as a subset of Ω: any infinite set can first be thinned to avoid 1. This uses the axiom of choice, rather than claiming a Borel counterexample.
Now set
E={{1}∪X:X∈C}.​
(22)
Every infinite A has an infinite subset B avoiding 1, and then [B]ω∩E=∅. Hence E is Ramsey. But no stem-preserving thinning of [{1},M] is homogeneous for E, because C splits every tail cone. Hence E is not completely Ramsey.
To prove the topological equivalence, we first establish the Ellentuck meagre-set fusion lemma: every star-meagre set can be avoided in a refinement [s,B] with the original stem. Call a set completely Ramsey-null if this avoidance holds in every [s,A].
If N is star-nowhere dense, then U=Ω∖N is star-open and dense. By the granted complete-Ramsey property of star-open sets, every [s,A] has a refinement [s,B] either contained in U or disjoint from U. The latter alternative would put a nonempty open set inside N, contradicting density of U. Thus N is completely Ramsey-null.
For a countable union ⋃j​Nj​ of completely Ramsey-null sets, use fusion, taking care of every possible finite stem. Starting with A0​=A, at stage j choose bj​∈Aj−1​ above all previous choices. From the part of Aj−1​ above bj​, successively thin an infinite tail for each of the finitely many subsets t⊆{b1​,…,bj​} so that
[s∪t,Aj​]∩Nj​=∅.
(23)
Each thinning keeps the stem s∪t fixed; subsequent thinnings preserve earlier avoidance. Let B={b1​,b2​,…}. For any X∈[s,B] and fixed j, put t=(X∖s)∩{b1​,…,bj​}. The rest of X lies in Aj​, because all later selected points do. Therefore X∈[s∪t,Aj​] and X∈/Nj​. Since j was arbitrary,
[s,B]∩j⋃​Nj​=∅.​
(24)
This proves the fusion lemma. Considering all subsets t, not merely the single selected prefix, is essential: elements of [s,B] need not use every bi​.
Suppose first that E is star-Baire, with E△U star-meagre and U star-open. Thin [s,A] to [s,B] avoiding the meagre difference by the lemma. Then apply the granted complete-Ramsey property of U to find [s,D] homogeneous for U, with D⊆B. On this refinement E and U agree, so it is homogeneous for E. Thus E is completely Ramsey.
Conversely, let E be completely Ramsey and let U be the union of all basic neighborhoods wholly contained in E, namely its star-interior. Every [s,A] has a homogeneous refinement. If that refinement lies in E, it lies in U; if it avoids E, it also avoids E∖U. Consequently every basic neighborhood contains a nonempty open refinement disjoint from E∖U. Since such a refinement is also disjoint from the closure of E∖U, this difference is star-nowhere dense. Thus E△U=E∖U is star-meagre, and E is star-Baire. We have proved
E completely Ramsey⟺E has the Baire property in the star topology.​
(25)
Finally, Ω is not star-meagre: otherwise apply the fusion lemma to its purported meagre cover inside any nonempty basic neighborhood, obtaining a nonempty [s,B] disjoint from Ω, a contradiction.
The printed paper does not define τ. In the coarser Ramsey cone topology, whose basic open sets are [A]ω without finite stems, Ω is τ-meagre. To prove this, let Dj​={X:minX=j}. Its cone-topology closure is Hj​={X:j∈X}: every cone neighborhood of a point containing j has a subset with least element j, whereas if j∈/X the neighborhood [X]ω avoids Dj​. No nonempty cone lies in Hj​, since its infinite ground set can be thinned to remove j. Therefore each Dj​ is nowhere dense, but Ω=⋃j≥1​Dj​. This proves meagreness of the Ramsey cone topology and exhibits the contrast with the star topology.
If τ instead denotes the ordinary topology on infinite subsets, with basic cylinders [s]={X:s is an initial segment of X}, the answer is not τ-meagre. Indeed, given countably many nowhere dense sets, extend a finite increasing prefix successively so that its cylinder avoids the closure of the next set. Make the prefix longer at each step. Their union is an infinite increasing enumeration belonging to every chosen cylinder and avoiding the whole proposed cover. The same construction starts inside any nonempty cylinder, so this alternative product topology is also a Baire space. The two conventions have different answers, so the distinction must be made explicitly rather than inferred from the symbol alone.
