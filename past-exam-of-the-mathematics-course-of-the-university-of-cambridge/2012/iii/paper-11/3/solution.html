Use the external external vertex boundary convention
B(A)={X∈/A: ∣X△A∣=1 for some A∈A}.
(17)
Equivalently, its closed graph neighbourhood is N[A]=A∪B(A). Some boundary conventions use this closed graph neighbourhood itself; because the compared set families have equal size, either convention gives the same inequality.
Order the Boolean lattice first by increasing size, and within a size by lexicographic order, with the smallest differing coordinate in the earlier set. If I is the initial segment in this simplicial order on the discrete cube with ∣I∣=∣A∣, Harper inequality is
∣B(A)∣≥∣B(I)∣​,equivalently∣N[A]∣≥∣N[I]∣.
(18)
In particular, writing Sn​(t)=∑j=0t​(jn​), if ∣A∣≥Sn​(t) then ∣N[A]∣≥Sn​(t+1).
Here is the full simplicial section compression proof. The cases n=0,1 are immediate. A simplicial initial segment has an initial-segment closed graph neighbourhood: it contains every smaller level, and its remaining upper level is the upper shadow of a lexicographic initial segment. That upper shadow is lexicographic initial because a set has a face in the segment exactly when its earliest face does, and earliest faces preserve lexicographic order.
Assume the result in dimension n−1. For a coordinate i, delete it from the present section and write the two sections as A0​,A1​. Their neighbourhood sections are exactly
N[A]0​=N[A0​]∪A1​,N[A]1​=N[A1​]∪A0​.
(19)
Replace both sections by equally large simplicial initial segments I0​,I1​. The mathematical induction hypothesis controls each internal neighbourhood. Both sets in each new union are initial segments, so that union has size equal to the larger of their sizes. The corresponding old union has at least that size. Therefore this simplicial section compression does not enlarge N[A].
Repeatedly compress any noninitial section. Every change strictly reduces the sum of the global simplicial positions of the set family members, so the process terminates at a set family C compressed in every section. Suppose an earlier vertex X is missing while a later vertex Y is present. If they agree in any coordinate, they contradict compression of that coordinate's section. Thus Y=[n]∖X. They must also be consecutive in simplicial order: an intermediate vertex, whether present or absent, would create another inversion and would have to equal one of these two complementary vertices. No other inversion is possible for the same reason. Hence C is either the required initial segment or that segment with its last vertex X exchanged for the next vertex Y, with X,Y complementary.
For completeness, these terminal families for simplicial section compression can be checked explicitly. If n=2k+1, the exceptional consecutive vertices are the last k-set X={k+2,…,2k+1} and first (k+1)-set Y={1,…,k+1}. For k≥1, the initial segment is all levels through k. After the exchange every vertex of size at most k+1 is still in its closed graph neighbourhood: a (k+1)-set has at least two k-faces, so deleting the one face X cannot remove it, and X itself neighbours a retained smaller set. Thus the new neighbourhood contains the old one. For k=0, the two single-vertex set families have the same neighbourhood.
If n=2k, the exceptional pair is X={1,k+2,…,2k} and Y={2,…,k+1}. The initial segment consists of every level below k and all k-sets containing coordinate one. Its closed graph neighbourhood consists of every level through k and the (k+1)-sets containing coordinate one. For k≥2, each of the latter has k≥2 faces containing coordinate one, so deleting X removes no such neighbour. Every lower level remains covered. For k=1, the added vertex Y itself keeps the sole two-element neighbour covered. Again the exchange does not decrease the neighbourhood. These are the only complementary consecutive pairs, as is seen by checking the central ranks and the lexicographic transition between middle-rank sets containing and avoiding coordinate one.
We have reached a set family whose neighbourhood is at least the initial segment's, without increasing the original neighbourhood. This proves Harper inequality by mathematical induction, including the exceptional compressed set families often omitted from the argument.
For the final request, the usual two-coordinate shift does not increase the boundary of a uniform set family. To see this carefully, let i=j and let Cij​ move a set containing j but not i to its partner with j replaced by i, only if that partner is absent. For any uniform set family F,
∂(Cij​F)⊆Cij​(∂F),∇(Cij​F)⊆Cij​(∇F).
(20)
Here is the local witness check for the lower shadow inclusion. A shadow member containing neither or both of i,j has an old witness after possibly exchanging i,j in that witness. For a paired shadow vertex containing i only, either its old version or its j-partner has an old witness, which suffices for its membership in the shifted shadow. For a vertex containing j only that survives in the new shadow, its new witness either contains both coordinates, supplying both old shadow partners directly, or is an unshifted j-only witness whose i-partner was already present. In either event both old shadow partners existed, which is exactly the condition for the j-vertex to survive the shadow shift. This exhausts the coordinate patterns.
Taking complements converts an upper shadow into a lower shadow and converts Cij​ into Cji​, proving the second inclusion. Each shift preserves cardinality on the shadow level. The external boundary of an r-uniform set family is the disjoint union of its lower and upper shadows, so
∣B(Cij​F)∣=∣∂Cij​F∣+∣∇Cij​F∣≤∣∂F∣+∣∇F∣=∣B(F)∣.​
(21)
The endpoint levels r=0,n have an empty shadow on one side and obey the same conclusion.
