Let (We​)e∈N​ enumerate all computably enumerable sets, with finite uniformly computable approximations We,s​ increasing to We​. For example, take We​=domφe​ and
We,s​={x<s:φe​(x) halts within s steps}.
(10)
We construct a simple set by meeting the requirements Re​: if We​ is infinite, then We​∩X=∅. Begin with no enumerated elements and all requirements unmarked. At stage s, process e=0,1,…,s in this order. For an unmarked Re​, if there is an x∈We,s​ with x>2e, enumerate the least such x into X and mark Re​ permanently. All membership tests at a stage are finite, and marking requires no test for eventual infinitude. The sparse-witness construction of a simple set therefore gives a computably enumerable set X; it is semidecidable by simulating this enumeration and halting when the input appears.
Each requirement enumerates at most one element. If an element in [0,2n] is enumerated by Re​, then 2e<x≤2n, so e<n. At most n elements of that interval can therefore enter X, even if some requirements choose the same element. Consequently
∣[0,2n]∖X∣≥(2n+1)−n=n+1.​
(11)
The complement of a set N∖X is infinite.
If We​ is infinite, it contains some x>2e, and that element eventually belongs to We,s​ at a stage with s≥e. If Re​ has already acted, it already placed an element of We​ in X. Otherwise it acts by this stage and does so now. Thus every infinite semidecidable set meets X. Equivalently, its infinite complement of a set is an immune set. The constructed X is semidecidable, coinfinite, and meets every infinite semidecidable set.
As a useful check on the construction, X cannot be a computable set. If it were, its infinite complement of a set would also be a computably enumerable set disjoint from X, contradicting the property just proved. The argument requires neither deciding which We​ are infinite nor protecting a prechosen infinite list of omitted numbers; the numerical witness bound provides all the required room.
