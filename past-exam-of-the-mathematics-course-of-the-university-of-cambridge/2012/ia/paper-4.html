An equivalence relation R on X is a reflexive relation (xRx), a symmetric relation (xRy⇒yRx), and a transitive relation (xRy, yRz⇒xRz). Its equivalence class at x is [x]R​={y∈X:xRy}. Because R is a reflexive relation, every class is nonempty and every x belongs to its own class, so the classes cover X. If [x]R​ and [z]R​ share an element y, symmetry and transitivity give xRz. For every w∈[x]R​, transitivity then gives zRw, so [x]R​⊆[z]R​; exchanging x,z gives equality. Thus distinct classes are disjoint. The equivalence classes form a set partition of X. On the empty set, the empty family is the corresponding partition.

The final property concerns a pointwise periodic self-map. Such a map is a bijection: each point has a predecessor in its finite cycle, giving surjectivity; if f(x)=f(y), choose a common multiple N of periods of x,y and apply fN−1 to get x=y. Its finite cycles are therefore disjoint.
If X is finite, choose the least common multiple of the finitely many cycle lengths. This positive integer N gives fN=idX​. The empty set satisfies the property with N=1.
Conversely, in the usual set theory with choice, every infinite X contains a countably infinite set. Divide such a subset into disjoint finite blocks Bj​ of sizes j+1, j≥1, make f a cyclic permutation on each block, and fix every other point. Every point returns to itself, but an identity iterate would have to be divisible by every block length j+1. No positive integer has that property: take a block longer than that integer. Thus the uniform period criterion for pointwise periodic maps gives
X has the property exactly when X is finite.​
(9)
The axiom of choice assumption is stated here because extracting a countably infinite subset of an arbitrary infinite set is not an unrestricted theorem in set theory without choice.

For p=2, x=1 is a square root of minus one modulo a prime. If p is odd and x2≡−1, Fermat's little theorem gives
1≡xp−1=(−1)(p−1)/2(modp),
(10)

p=2 or p≡1(mod4),​
(11)
and in the latter case x=h! supplies a solution.
For the multiplicative order assertion, divide k by d: k=qd+r, 0≤r<d. Since xd≡1 and xk≡1, it follows that xr≡1. Minimality of the positive order excludes 0<r<d, hence r=0 and

In particular d∣p−1 by Fermat's little theorem. Negative k, if included, are handled by the same division using the modular inverse of x.
A Fermat number in the paper has n≥1. If a prime p divides Fn​=22n+1, it is odd and 22n≡−1(modp). Squaring gives 22n+1≡1, so the order d divides 2n+1. It does not divide 2n, since −1=1 modulo an odd prime. Every divisor of 2n+1 is a power of two, so the only possibility is
ordp​(2)=2n+1.​
(13)

A prime 1 modulo 4 need not occur: take p=13. It is prime, 26=64≡−1(mod13), and 24≡3=1. Since the order divides 12, the first congruence excludes every divisor of 6 and the second excludes 4; hence the order is 12. This is not a power of two, so 13 is not a prime divisor of a Fermat number. The index restriction matters: the conventional extra number F0​=3 is outside the paper's positive-n family.

First apply the Cantor theorem by diagonalization. If an injection j:P(R)→R existed, it would define a surjection h:R→P(R) by the unique inverse value on j's image, and by h(x)=∅ elsewhere. The set D={x∈R:x∈/h(x)} cannot equal h(a) for any a, since a∈D would be equivalent to a∈/D. This contradicts surjectivity. There is no injection from the power set of the real line into the real line.
For the opposite type of encoding, let b(x)=21​+π−1arctanx, an injective map from R to (0,1). Give b(x) its canonical binary expansion, choosing the terminating expansion with trailing zeros whenever two expansions exist. If the binary digits of b(x),b(y) are aj​,bj​, define a real-number pairing by separated digits:
H(x,y)=∑j≥1​(32j−12aj​​+32j2bj​​).
(19)
This uses ternary digits only 0,2, alternating the two input digit sequences. If two outputs first differ at ternary position k, that difference has magnitude 2⋅3−k, while every later digit together contributes at most ∑j>k​2⋅3−j=3−k. Their outputs therefore differ. The digits recover both binary sequences, hence both inputs. Neither output endpoint 0 nor 1 occurs because the input numbers lie strictly between zero and one. Thus H is an injection from R2 into (0,1)⊂R. The ternary construction avoids an unjustified decimal-interleaving argument at ambiguous expansions.
For a finite modification of the identity on the real line, let Df​={x:f(x)=x} have size n, and sort it uniquely as x1​<⋯<xn​. Its finite record is (x1​,f(x1​),…,xn​,f(xn​)). Different lengths occupy disjoint intervals (n,n+1), and within a fixed length the record is recoverable. Hence

P1​⋅P2​=P10​P20​−p1​⋅p2​≥P10​P20​−∣p1​∣∣p2​∣>0.
(43)
This is stronger than the requested nonnegative inequality. For an electron and a positron of rest mass m>0, their future-pointing timelike four-momenta have P12​=P22​=m2c2. Thus
(P1​+P2​)2=2m2c2+2P1​⋅P2​>0,
(44)
which cannot equal the null norm of a single photon. Four-momentum conservation forbids spontaneous photon decay into an electron-positron pair in vacuum. An external body or field able to exchange momentum would be a different system.

For u>0, take the initial electron direction as the longitudinal axis and put β=u/c. Incoming four-momentum conservation gives
h(ν1​+ν2​)=mc2(γ+1),ch​(ν1​e1​+ν2​e2​)=mγuu^.
(45)
The transverse components must cancel. In the noncollinear case the two transverse directions are opposite, and ν1​sinθ1​=ν2​sinθ2​. Hence the ratio of longitudinal momentum times c to energy is
γ+1γβ​=ν1​+ν2​ν1​cosθ1​+ν2​cosθ2​​=sinθ1​+sinθ2​sin(θ1​+θ2​)​.
(46)
Writing s=(θ1​+θ2​)/2 and d=(θ1​−θ2​)/2, the last ratio is coss/cosd. It also equals (1+cos(θ1​+θ2​))/(cosθ1​+cosθ2​) whenever that denominator is nonzero. Since γ2β2=γ2−1, the angular relation for two-photon electron-positron annihilation is
cosθ1​+cosθ2​1+cos(θ1​+θ2​)​=γ+1γβ​=γ+1γ−1​​.​
(47)
The positive root follows from u>0. For noncollinear emission the positive momentum-to-energy ratio ensures coss>0, and ∣d∣<π/2 ensures the stated denominator is positive.
The printed quotient needs a qualification for exactly collinear photons. The allowed configuration θ1​=0, θ2​=π has positive frequencies
hν1,2​=2mc2​[(γ+1)±γβ],
(48)
which obey both conservation equations, but the printed left side is 0/0. Thus the quotient holds for noncollinear angles, or as its appropriate noncollinear limit. The undivided identity
1+cos(θ1​+θ2​)=γ+1γ−1​​(cosθ1​+cosθ2​)
(49)
remains true in the collinear case, where both sides vanish. The limit u=0 similarly requires care because the initial direction is then undefined and the photons are antiparallel.
