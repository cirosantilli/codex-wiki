For every Borel set A⊆Rd, let
N(A)=#(Π∩A)
(291)
be its random point count. A Non-homogeneous Poisson point process with intensity function of a point process λ is characterized by:
  • N(A) is finite almost surely for every bounded Borel set A;
  • for every bounded Borel set A,
N(A)∼Poisson(Λ(A)),Λ(A)=∫A​λ(x)dx;
(292)
  • the counts N(A1​),…,N(Am​) are independent random variables whenever A1​,…,Am​ are pairwise disjoint bounded Borel sets.
Because Λ has a density with respect to Lebesgue measure, it is atomless, so the process is simple: almost surely no location occurs more than once.
