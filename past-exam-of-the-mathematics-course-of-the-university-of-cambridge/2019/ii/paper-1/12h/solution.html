Let δ be the extended transition function of a deterministic finite automaton. States p,q∈Q are equivalent, or indistinguishable, when
p∼q⟺(δ(p,w)∈F⟺δ(q,w)∈F)for every w∈Σ∗.
(84)
The quotient deterministic finite automaton by indistinguishable states D/∼ has state set Q/∼, initial state [q0​], accepting states {[q]:q∈F}, and transition
δ([q],a)=[δ(q,a)].
(85)
Right invariance of ∼ makes this well-defined, and the quotient accepts L(D).
To prove minimality, choose for each state q of the accessible automaton D a word wq​ with δD​(q0​,wq​)=q. Run the same word in any DFA A accepting L(D), and assign the class [q] the reached state of A. If two distinct classes [p]=[q] reached the same state of A, every continuation u would have the same acceptance result after wp​ and wq​. Since A and D accept the same language, this would make p and q indistinguishable in D, a contradiction. Thus A has at least one distinct state for every class in D/∼, proving that the quotient is the minimal deterministic finite automaton.
For divisibility by seven, take states Q={0,1,…,6}, initial state 0, accepting set F={0}, and transitions
δ(r,b)=2r+b(mod7)​,b∈{0,1}.
(86)
After reading a word, the state is its binary value modulo seven, so this binary divisibility automaton accepts exactly the multiples of seven, with leading zeros allowed. Every state is accessible: the three-bit words representing 0,1,…,6 reach the corresponding residues.
For distinct residues p,q, let wp​ be the three-bit representation of −p(mod7), chosen in {0,…,6}. Since 23≡1(mod7), reading wp​ from state p ends at
23p+(−p)=0(mod7),
(87)
whereas reading it from q ends at q−p=0. Thus wp​ distinguishes p from q. All seven states are pairwise distinguishable, so the DFA is minimal by the Myhill-Nerode theorem.
