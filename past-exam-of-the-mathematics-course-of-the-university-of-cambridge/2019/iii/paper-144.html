The Tarski-Vaught test states that a substructure M⊆N is an elementary substructure if and only if every formula φ(x,yˉ​) and tuple aˉ∈M satisfy
N⊨∃xφ(x,aˉ)⟹N⊨φ(b,aˉ) for some b∈M.
(1)
Necessity follows immediately from elementarity. Conversely, assume the witness condition. Induct on formulas to prove that M⊨ψ(aˉ) exactly when N⊨ψ(aˉ) for every aˉ∈M. Atomic formulas agree because M is a substructure, and Boolean connectives follow by induction. A witness in M is also one in N; a witness in N can be replaced by one in M by hypothesis, after which induction applies to the matrix. Universal formulas follow by negation. Thus the witness condition is equivalent to M≼N.

Define a parameter-free equivalence relation by
E(x,y)⟺∀z(φ(x,z)↔φ(y,z)).
(2)
Its classes correspond exactly to the distinct sets φ(a,U). If there are exactly n<∞ classes, that fact is a first-order sentence, so the elementary substructure M contains representatives b1​,…,bn​ of all of them. Every a∈U is E-equivalent to some bi​, and φ(a,U)=φ(bi​,U) is definable over M.
The converse also holds because M is small and U is a monster model. If there were infinitely many E-classes, the partial complete type
p(x)={¬E(x,b):b∈M}
(3)
would be finitely satisfiable. Saturation of U would realize p, producing a class with no representative in M, contrary to the hypothesis. Therefore there are only finitely many sets φ(a,U).

The theory of the random graph has the extension property: for finite disjoint vertex sets A,B, there is a new vertex adjacent to every point of A and to no point of B.
Let M,N be countable models and let f0​ be a finite partial embedding. Enumerate M=(mi​)i<ω​ and N=(ni​)i<ω​. At an even stage, take the first mi​ outside the domain. Its adjacency pattern to the finite domain prescribes finite disjoint subsets of the range; the extension property in N supplies a new image with exactly that pattern. At an odd stage, apply the same argument to the inverse map and the first unused ni​. This back-and-forth method produces an increasing sequence of finite partial embeddings whose union is an isomorphism. Hence every finite partial embedding extends to an isomorphism M≅N.

Assume no induced graph on Pi​ has the random-graph extension property. For each i, choose finite disjoint Ai​,Bi​⊆Pi​ such that no vertex of Pi​∖(Ai​∪Bi​) realizes the prescribed adjacency pattern. The unions A=⋃i​Ai​ and B=⋃i​Bi​ are finite and disjoint. The extension property in M supplies a new vertex v adjacent to all of A and none of B. But v∈Pj​ for some j, contradicting the choice of Aj​,Bj​. Thus some Pj​ satisfies the extension property. It is a countable model of the theory of the random graph, so part (a) gives
M≅Pj​ for some j.​

Suppose a∈acl(A) in the sense of model-theoretic algebraic closure. Some formula φ(x,cˉ) over A has exactly n<∞ realizations in the monster model and includes a. Every model M containing A is an elementary substructure of the monster and therefore contains n distinct realizations. Since there are only n in the monster, it contains all of them, including a. Hence
a∈acl(A)⟹a∈M for every model M⊇A.​

Suppose a∈/acl(A). Choose a small model M0​ containing A. The complete type tp(a/A) is nonalgebraic, so choose a realization a′∈/M0​. Strong homogeneity of the monster model gives an automorphism σ fixing A with σ(a)=a′. Then M=σ−1(M0​) contains A, but a∈M would imply a′=σ(a)∈M0​. Taking the contrapositive proves
a∈M for every model M⊇A⟹a∈acl(A).​

Put B=N∖acl(A). We seek a model containing A and omitting every element of B. Every finite set of these omission requirements is satisfiable: if a finite C⊆B met every model containing A, the supplied result would imply C∩acl(A)=∅, a contradiction.
Apply the compactness theorem to the elementary-diagram formulation of these requirements, using the Tarski-Vaught test to axiomatize the selected elementary submodel. It gives a model M containing A and omitting all of B. Part (a) gives acl(A)⊆M∩N, while omission of B=N∖acl(A) gives the reverse inclusion. Therefore
M∩N=acl(A).​
(7)

Let D=dom(f) and take a formula φ(x,dˉ) over D. Since T is a strongly minimal theory, the set φ(U,dˉ) is finite or cofinite. If φ(b,dˉ) holds, it cannot be finite because b∈/acl(D), so it is cofinite. Elementarity of f makes φ(U,fdˉ) cofinite. Its finite complement is algebraic over f(D), so c∈/acl(ranf) lies in the set. Applying the same argument to ¬φ gives the reverse implication. Hence f∪{(b,c)} is elementary: both elements realize the generic type in a strongly minimal theory over the corresponding domains.
If models M,N have bases B,C of the same dimension of a pregeometry, choose a bijection B→C. Repeated use of the one-point result makes it elementary on every finite subset and hence on B. Every model is the algebraic closure of a basis. Extending the map back and forth across algebraic elements produces an isomorphism M→N. Thus models of a strongly minimal theory with the same dimension are isomorphic.

Let κ=∣N∣. If the saturated model N had a basis B of cardinality below κ, then N=acl(B) would omit the consistent generic type in a strongly minimal theory over B. This contradicts κ-saturation. A basis is a subset of N, so its cardinality is at most κ. Therefore
N saturated⟹dim(N)=∣N∣.​

Assume dim(N)=∣N∣=κ, with κ≥∣L∣+ℵ0​. Let A⊆N have size below κ and let p(x)∈S1​(A) be a complete type. If p is algebraic, its realizations lie in acl(A)⊆acl(N)=N. If p is nonalgebraic, strong minimality makes it the unique generic type over acl(A). The pregeometry exchange property gives
dimacl(A)≤∣A∣<κ=dim(N),
(9)
so some basis element of N lies outside acl(A) and realizes p.
Thus N realizes every one-type over every parameter set of size below κ. The standard one-type characterization, applied successively to tuple coordinates, makes N κ-saturated. Consequently
dim(N)=∣N∣⟹N saturated.​
(10)
