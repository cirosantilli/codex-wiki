Downward absoluteness of cardinalhood holds because, if the larger transitive model sees no bijection with a smaller ordinal, neither can the smaller model, whose functions form only a subset of those in the larger model. Cardinalhood is not described by an upward absolute formula, because the larger model can contain a new bijection collapsing an ordinal that the smaller model regards as a cardinal number.

U. A witness in the smaller model that x is a countable set remains a function in the larger model, so countability is described by an upward absolute formula. It is not downward absolute: the larger model may have a new enumeration of x that is absent from the smaller model, as explained by upward absoluteness of countability.

ii OurBigBook.com
Suppose that the countable ordinal α satisfied Vα​⊨ZFC. The axioms force α to be a limit ordinal above ω, so choose an externally countable cofinal function n↦αn​ into α, with αn​+1<α. The internal Axiom of choice gives a bijection in Vα​ between each Vαn​​ and some ordinal below α. Every such ordinal is externally a countable set, hence every Vαn​​ is externally countable. The countable union of countable sets is countable, so
Vα​=⋃n<ω​Vαn​​
(1)
would be countable. But Vα​ contains the full power set P(ω), which is uncountable by Cantor theorem. This contradiction is the result Countable rank-initial segment cannot model ZFC, and therefore
Vα​⊨ZFC.​
(2)

iii OurBigBook.com
Let M be the given transitive model and suppose that its ordinal height of a model of set theory Ord∩M were a countable set. For every x∈M, the internal Axiom of choice gives a bijection from x to an ordinal of M; transitivity makes this an actual bijection, and the ordinal is externally countable. Thus every element of M is externally countable.
For each α∈Ord∩M, the internal rank VαM​ belongs to M and is therefore countable. Every x∈M lies in one of these ranks, so M is a countable union of countable sets and is itself countable, contrary to the hypothesis. By uncountable transitive set model has uncountable ordinal height, M contains uncountably many ordinals.

a OurBigBook.com
Let N be a well-founded model of set theory of the complete theory T, and suppose that a Paris model M⊨T were ill-founded. Its internal ordinals would then contain an external descending sequence
α0​∋Mα1​∋Mα2​∋M⋯.
(3)
For every n, choose a first-order formula φn​ that uniquely defines αn​ in M. The sentences asserting that φn​ uniquely defines an ordinal and that the object defined by φn+1​ belongs to the object defined by φn​ are true in M. Since T is complete, all its models satisfy the same first-order sentences, so the corresponding uniquely defined ordinals in N form an external descending membership sequence. This contradicts the well-foundedness of N. Thus Paris models are well-founded when their complete theory has a well-founded model proves that every Paris model of T is well-founded.

By part (a), the Paris model M is well-founded. Let π be an automorphism of a first-order structure of (M,∈M). External epsilon induction shows that every element is fixed: if π(y)=y for every y∈Mx, then preservation of membership and extensionality give
π(x)={π(y):y∈Mx}=x.
(4)
Hence π is the identity function. This is Paris models are rigid when their complete theory has a well-founded model, so every Paris model of T is a rigid first-order structure.

ii OurBigBook.com
Fix a∈L. Inside the ambient transitive model M, the Axiom of power set makes the collection of constructible subsets of a a set. For each such subset x, choose the least stage of the constructible hierarchy at which x appears. The Axiom schema of replacement and the supremum of a set of ordinals give an ordinal β bounding all these stages; enlarge β so that a∈Lβ​.
Now
PL(a)={x∈Lβ​:x⊆a}
(6)
is definable over Lβ​ with parameter a. It therefore belongs to the definable power set D(Lβ​)=Lβ+1​⊆L. This set contains exactly the subsets of a that belong to the constructible universe, so it witnesses the Axiom of power set in L. Therefore L⊨ Power Set.

iii OurBigBook.com
The definable power set D(A) performs one definability step over the single structure (A,∈), whereas the constructible power set PL(A) contains subsets of A created at arbitrarily late stages of the constructible hierarchy.
For the concrete case A=ω, there are only countably many first-order formulas and finite tuples of natural-number parameters, so D(ω) is a countable set. In contrast, the constructible universe satisfies ZFC, and Cantor theorem makes its full power set PL(ω) uncountable inside L. Consequently
D(ω)⊊PL(ω),​
(7)
so the two notions do not agree in general.

iv OurBigBook.com
Take a transitive model M⊨ZFC+2ℵ0​=ℵ2​. In M, choose a bijection e:ω2​→P(ω) and encode its graph by a set A⊆ω2​, using a fixed bijection between ω2​×ω and ω2​. The relative constructible universe L(A) can decode e, and therefore contains every real number of M; being an inner model of M, it has no additional reals.
Models with the same reals have the same first uncountable ordinal, because their reals code exactly the same countable well-orders. If L(A) satisfied the Continuum hypothesis, its bijection between ω1​ and the reals would also belong to M, contradicting M⊨2ℵ0​=ℵ2​. This is the construction in relative constructible universe can violate the continuum hypothesis, and it gives
A⊆ω2​andL(A)⊨¬CH.​
(8)

Solution

Words: 130
ii OurBigBook.com
Let λ≥κ be a cardinal number of M. If forcing collapsed λ, some condition would force a surjective function f˙​:μ→λ for an ordinal μ<λ. Replacing μ by its ground-model cardinality lets us assume that μ is a cardinal.
For each ξ<μ, choose in M a maximal antichain in a forcing order deciding f˙​(ξ). The chain condition for forcing makes its size less than κ, so the set Bξ​ of possible values of f˙​(ξ) has size below κ. This is the possible-values lemma for chain-condition forcing. Every interpreted range is contained in B=⋃ξ<μ​Bξ​. If μ<κ, the fact that κ is a regular cardinal gives ∣B∣<κ≤λ; if κ≤μ<λ, infinite cardinal arithmetic gives ∣B∣≤μ<λ. Either way B cannot contain the range of a surjection onto λ, a contradiction. By cardinal preservation by chain-condition forcing, P preserves every cardinal at least κ.

Suppose first that p⊩∗φ. If G is any generic filter over M containing p, the forcing theorem gives M[G]⊨φ. Hence p⊩φ in the semantic forcing relation.
Conversely, suppose p⊩∗φ. By the stated density equivalence for the syntactic forcing relation, some r≤p satisfies r⊩∗¬φ. The Rasiowa–Sikorski lemma supplies a generic filter G over the countable model M containing r, and upward closure then gives p∈G. The forcing theorem yields M[G]⊨¬φ, so p⊩φ semantically. Therefore
p⊩φ⟺p⊩∗φ.​
(12)

y˙​={(τ,r):∃q((τ,q)∈x˙∧r≤q∧r⊩∗φ(τ,a˙1​,…,a˙n​))}.

Let F=⋃G, the generic union for the Finite-condition Lévy collapse, and fix an infinite cardinal number λ<κ in M. For every n∈ω, the set of conditions defining a value at (λ,n) is dense: extend a condition at that fresh coordinate with any value below λ. Hence Fλ​(n)=F(λ,n) is a total function ω→λ.
For every β<λ, the set of conditions assigning the value β at some fresh coordinate (λ,n) is also dense. Genericity therefore makes Fλ​ surjective. Thus
Fλ​:ω↠λ,​
(15)
so λ is a countable set in M[G]. Finite cardinals are already countable.

Solution
Words: 150
b OurBigBook.com
Assume that κ is regular and uncountable in M, as required for this claim. If an antichain A∈M had size κ, apply the delta-system lemma at a regular uncountable cardinal inside M to the finite domains of its conditions. After thinning, their domains form a delta-system with finite root R.
There are fewer than κ possible restrictions to R, because each coordinate (α,n)∈R has fewer than κ possible values. Since κ is a regular cardinal, we can thin again to κ conditions agreeing on R. Any two now have disjoint domains outside R and agree on R, so their union is a common extension. This contradicts that A is an antichain. Therefore
P has the κ-chain condition.​
(16)
If the word “regular” is allowed to include κ=ω, the printed claim needs the additional hypothesis that κ is uncountable; the finite-condition order can have an infinite antichain when κ=ω.

Suppose first that κ is regular and uncountable in M. Part (b) and cardinal preservation by chain-condition forcing show that κ remains a cardinal number in M[G], while part (a) makes every infinite ground-model cardinal below κ countable. Every ordinal below κ has ground-model cardinality below κ and is therefore countable in the extension. Thus κ is the least uncountable ordinal there:
M[G]⊨κ=ℵ1​.
(17)
Conversely, suppose M[G]⊨κ=ℵ1​ and κ were singular in M. Let μ=cfM(κ)<κ and take in M a cofinal function f:μ→κ. Part (a) makes μ countable in M[G], while the same f remains cofinal there. This would give κ countable cofinality, contradicting first uncountable ordinal is regular. Hence κ was regular in M, and for the intended uncountable κ,
κ is regular in M⟺M[G]⊨κ=ℵ1​.​
