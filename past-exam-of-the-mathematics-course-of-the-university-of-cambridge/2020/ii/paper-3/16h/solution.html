A class in set theory in the model V is a collection
C={x∈V:V⊨φ(x,a1​,…,ak​)}
(75)
defined by a first-order formula with parameters ai​∈V. A set-theoretic class function is a definable class relation F for which every input in its domain has exactly one output. Informally, the Axiom schema of replacement says that the image F‘‘a of any set a under any such function class is again a set.
Define the class function F:ω→V by the natural-number recursion theorem,
F(0)=ω,F(n+1)=P(F(n)).
(76)
Then F(n)=zn​, and Replacement applied to the set ω gives
y=F‘‘ω={zn​:n∈ω}
(77)
as a set.
Call a set small when it injects into some zn​. Every natural number m is finite, and every member of TC({m}) is finite, so each injects into z0​=ω. Hence m∈HS. The set ω itself injects into z0​, and its hereditary members are natural numbers, so ω∈HS.
We next prove zn​∈HS by mathematical induction. The case z0​=ω was just proved. If zn​∈HS and u∈zn+1​=P(zn​), then u⊆zn​, so inclusion injects u into zn​ and makes u small. Every set below u in its transitive closure is already below zn​ and is small by the induction hypothesis. The set zn+1​ itself injects into zn+1​. Thus every member of TC({zn+1​}) is small.
By Cantor theorem, ∣zn+1​∣>∣zn​∣, so the zn​ are distinct and zn​↦n injects y into ω=z0​. Thus y is small. Every other member of TC({y}) belongs to TC({zn​}) for some n, and is small by the preceding paragraph. Therefore y∈HS. This proves the finite-power-set hereditary-small construction.
The structure (HS,∈) is not a model of ZF because it fails the Axiom of union. If ⋃y were small, it would inject into some zm​. But zm+1​⊆⋃y, since zm+1​∈y, so restriction would inject
zm+1​=P(zm​)⟶zm​.
(78)
Together with the singleton injection zm​→P(zm​), the Cantor-Schröder-Bernstein theorem would produce a bijection, contradicting Cantor theorem. Hence ⋃y is not small and therefore does not belong to HS. Since y∈HS has no union inside the class, the Union axiom fails.
