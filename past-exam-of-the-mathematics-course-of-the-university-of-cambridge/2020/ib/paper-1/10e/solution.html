A function f:Rm→Rr is differentiable at x if there is a linear map L:Rm→Rr such that
f(x+h)=f(x)+Lh+o(∥h∥)as h→0.
(43)
The map L, which is unique, is the derivative f′(x).
Expanding in a matrix increment H gives
(A+H)3=A3+A2H+AHA+HA2+O(∥H∥2).
(44)
Therefore p is differentiable everywhere and
p′(A)H=A2H+AHA+HA2−3H​.
(45)
The inverse function theorem states that if f is continuously differentiable near a and f′(a) is invertible, then f restricts to a bijection between neighbourhoods of a and f(a); its local inverse is continuously differentiable, with derivative
(f−1)′(y)=[f′(f−1(y))]−1.
(46)
In the normalized case f(0)=0 and f′(0)=I, continuity of f′ gives a closed ball Br​(0) on which
∥I−f′(x)∥≤q<1.
(47)
For small y, define Ty​(x)=x−f(x)+y. The mean value inequality makes Ty​ a contraction mapping with constant q. If ∥y∥≤(1−q)r, then
∥Ty​(x)∥≤q∥x∥+∥y∥≤r,
(48)
so Ty​ maps the ball into itself. The contraction mapping theorem gives a unique fixed point xy​, and the fixed-point equation is precisely f(xy​)=y. Moreover,
∥xy​−xz​∥≤q∥xy​−xz​∥+∥y−z∥,
(49)
so ∥xy​−xz​∥≤∥y−z∥/(1−q). Thus y↦xy​ is a continuous local inverse.
For the polynomial map in the question,
p(2I)=I,p′(2I)H=(4+4+4−3)H=9H.
(50)
The derivative is invertible, so the inverse function theorem supplies some ϵ>0 and a continuously differentiable q:Dϵ​(I)→Mn​ such that
p∘q=id∣Dϵ​(I)​​.
(51)
There can be no inverse on all of Mn​, because
p(2I)=I=p(−I),
(52)
so p is not injective.
