The set T is uncountable. Partition N into countably many infinite sets B1​,B2​,…, and choose bijections hj​:Bj​→Z. For every subset A⊆N, define a permutation fA​ separately on each block by
hj​(fA​(x))={hj​(x)+1,hj​(x)−1,​j∈A,j∈/A.​
(45)
Every positive iterate translates each integer coordinate by a nonzero amount, so it has no fixed point and fA​∈T. Distinct subsets A give distinct permutations, yielding an injection P(N)↪T. Since the power set is uncountable,
T is uncountable​.
(46)
In fact its cardinality is the continuum, because it is a subset of all functions N→N.
