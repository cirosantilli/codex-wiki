Because F:Set→Set preserves finite limits and colimits, F(1) is a singleton and F(∅)=∅. For x∈X, let xˉ:1→X select x and define

where ∗ is the unique element of F(1). This is natural in X. Any natural transformation 1Set​→F has the unique possible component at 1, and naturality along every xˉ forces the displayed value, so α is unique.
If x=y, the equalizer of xˉ,yˉ​:1⇉X is empty. Since F preserves this equalizer, F(xˉ)(∗)=F(yˉ​)(∗). Hence every αX​ is injective, so α is pointwise monic.
Finite-colimit preservation makes αn​:n→F(n) bijective for every finite set. Use the stated characterization of N by the coproduct diagram

∐n​F(An​)⟶F(∐n​An​)

Now choose x∈F(A)∖αA​(A) and define
U={A′⊆A:x∈im(F(A′)→F(A))}.

It is upward closed. Since A=A′⊔(A∖A′) and F preserves binary coproducts, x lies in exactly one of the two summands, so exactly one of A′ and its complement lies in U. Pullback preservation gives closure under finite intersections.
For countable completeness, take An​∈U and put B=⋂n​An​. If B∈/U, then A∖B∈U. Partition A into B and the sets
Cn​=(A∖An​)∖⋃k<n​(A∖Ak​),

Finally no finite K belongs to U. Indeed, F(K)≅K through αK​, so if x came from F(K) then naturality would put x in the image of αA​. Thus U is a countably complete ultrafilter and is nonprincipal.
Conversely, let U be such an ultrafilter on A and define the ultrapower endofunctor of sets
F(B)=BA/∼U​.
(31)
It preserves the terminal object and products: the map
[(f,g)]⟼([f],[g])
(32)
is bijective because U is closed under finite intersections. It preserves equalizers because an equality holding for an equivalence class holds on a U-large set, and the representative can be changed off that set to land in the equalizer. Hence it preserves all finite limits.
For f:A→∐n​Bn​, countable completeness implies that one index fiber
{a:f(a)∈Bn​}
(33)
belongs to U; otherwise the countable intersection of all complementary fibers would be empty and belong to U. Thus every class [f] lies in one and only one F(Bn​), proving preservation of countable coproducts.
The class of the identity map A→A is not represented by a constant map, since every equality set {a:a=a0​} is a singleton and is not in U. Therefore αA​:A→F(A) is not surjective. Since α is the unique natural transformation from the identity functor to F, a natural isomorphism 1Set​≅F would have to equal α, which is impossible.
