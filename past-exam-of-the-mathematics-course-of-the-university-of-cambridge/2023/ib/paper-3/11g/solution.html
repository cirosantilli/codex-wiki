For a∈U, the function f:U→Rn is differentiable at a if there is a linear map A:Rm→Rn such that
f(a+h)=f(a)+Ah+r(h),∥h∥∥r(h)∥​⟶0as h⟶0.
(58)
The linear map is unique and is the Frechet derivative Dfa​=A. The function is continuously differentiable at a if it is differentiable on a neighbourhood of a and the map x↦Dfx​, with values in the space of linear maps equipped with the operator norm, is continuous at a.
If T:Rm→Rn is linear, then
T(a+h)−T(a)−T(h)=0.
(59)
Consequently DTa​=T at every a. The derivative is a constant function of a, hence is continuous, so every linear map is continuously differentiable everywhere.
The mean value inequality says that if the line segment [x,y] lies in U and
∥Dfz​∥≤M(z∈[x,y]),
(60)
then
∥f(y)−f(x)∥≤M∥y−x∥.
(61)
To prove it, put v=f(y)−f(x). The claim is immediate if v=0. Otherwise set e=v/∥v∥ and apply the one-dimensional mean value theorem to the real-valued function
ϕ(t)=e⋅f(x+t(y−x)),0≤t≤1.
(62)
For some c∈(0,1), the chain rule gives
∥f(y)−f(x)∥​=ϕ(1)−ϕ(0)=e⋅Dfx+c(y−x)​(y−x)≤∥Dfx+c(y−x)​∥∥y−x∥≤M∥y−x∥,​
(63)
as required.
Now suppose that U is open and connected and that Dfa​=0 for every a∈U. Every point has an open ball contained in U. The mean value inequality with M=0 shows that f is constant on each such ball, so f is locally constant. Fix a0​∈U. The level set
E={x∈U:f(x)=f(a0​)}
(64)
is nonempty and open in U; its complement is also open because f is locally constant. Since U is connected, E=U. This proves the zero derivative on a connected open set result: f is constant.
The inverse function theorem states that if f:U→Rm is continuously differentiable, a∈U, and Dfa​ is an invertible linear map, then there are open neighbourhoods V of a and W of f(a) such that f∣V​:V→W is a bijection whose inverse is continuously differentiable.
