The same curve therefore satisfies a nonaffine geodesic equation in the conformal metric. It becomes affine there after choosing dλ/dλ=CΩ2, obtained by setting dlog(dλ/dλ)/dλ=2u′. Conformal transformations preserve unparameterized null geodesics.
In two dimensions each antisymmetric index pair of the Riemann curvature tensor has only one possible independent component, the pair 01. Pair exchange symmetry then leaves just R0101​. Contracting with the inverse metric gives
R=2(g00g11−(g01)2)R0101​=2det(gab)R0101​​.
(93)
Choose u solving □u=R/2, using the granted solvability, and let Ω=eu>0. The stated conformal transformation formula gives R=0. The one-component result makes the full curvature zero. A flat Lorentzian metric is locally isometric to Minkowski spacetime: parallel transport on a simply connected small neighbourhood supplies a parallel orthonormal frame, whose closed dual coframe integrates to flat coordinates. This is a local conclusion; vanishing curvature does not supply global Minkowski coordinates on an arbitrary topology.
In local two-dimensional Minkowski coordinates U=T−X, V=T+X, a regular smooth null curve obeys U′V′=0. Its nonzero continuous tangent stays on one of the two null directions locally, hence the curve lies on U=constant or V=constant, a straight null line. It is a reparameterized null geodesic. Conformal invariance proves that every regular null curve in the original two-dimensional metric is a null geodesic, without requiring global flat coordinates.
For the displayed metric put u=log∣t∣. When t>0, ds2=t(−du2+dθ2); when t<0, ds2=∣t∣(du2−dθ2). In both cases the two null families are
θ=±log∣t∣+θ0​.​
(94)
If θ is angular, the endpoints 0,2π are identified and these wind repeatedly around the cylinder as t→0 and as ∣t∣→∞. To find the original affine behaviour, the Killing momentum ℓ=tθ˙ is constant and the null condition gives t˙2=ℓ2. A nontrivial null curve has ℓ=0, so t is affine-linear: it reaches the excluded boundary t=0 in finite affine time despite infinitely many windings, and reaches ∣t∣=∞ only in infinite affine time.
The metric is already locally flat. For t>0, set T=2t​cosh(θ/2), X=2t​sinh(θ/2); for t<0 interchange the hyperbolic sine and cosine with 2∣t∣​. Both give ds2=−dT2+dX2. The angular identification acts as a Lorentz boost, so these are not global single-valued Minkowski coordinates. Constant-t circles are spacelike for t>0 and timelike for t<0; the negative branch therefore has closed timelike curves, though its null curves continue to change t. If the angular endpoints are not identified, the formulas describe the corresponding unwrapped strips instead. This exhibits concretely the local/global qualification in the earlier request.
