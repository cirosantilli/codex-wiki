The supplied hint interchanges its item and bidder indices in the first-value identity. If the first greedy choice assigns item n to bidder m, the correct quantity is w=vm​({n}), and the identity is
A(v)=w+A(v′).​
(16)
Indeed, the eventual bundle of bidder m has the form Sm′​∪{n}, whose value is w+vm′​(Sm′​); the other bidders' values are unchanged. Every later marginal contribution for bidder m is exactly its marginal in the residual problem, and this is also true for every other bidder. Thus the remainder of the greedy run is the greedy run on v′, with the same tie choices. The residual values are nonnegative and increasing; they remain submodular set functions as allowed in the question.
We prove the greedy half-approximation for submodular welfare by induction on the number of items. The zero-item case has A(v)=Opt(v)=∑i​vi​(∅)≥0, so the claimed inequality holds. This base case also handles the fact that the question does not explicitly normalize empty-bundle values to zero.
For the induction step, let
δ=vm​({n})−vm​(∅)≥0
(17)
be the first greedy marginal. Since the choice maximizes all available marginals,
vi​({n})−vi​(∅)≤δ≤wfor every bidder i.
(18)
Take an optimal allocation and let i be the owner of item n. If i=m, remove that item from i's bundle and give it to m. By submodularity, the loss to its old owner is
vi​(Si​)−vi​(Si​∖{n})≤vi​({n})−vi​(∅)≤δ.
(19)
Monotonicity makes the recipient's gain nonnegative. The modified allocation, now with n assigned to m, therefore has value at least Opt(v)−δ. If i=m, no modification is necessary and this bound still holds. Removing n and translating bidder m's value by w produces a feasible residual allocation, so
Opt(v′)≥Opt(v)−δ−w≥Opt(v)−2w.
(20)
Induction applied to that residual problem now gives
A(v)=w+A(v′)≥w+21​Opt(v′)≥21​Opt(v).
(21)
Thus the greedy algorithm is a one-half approximation. Empty-bundle constants cause no difficulty because all are nonnegative and δ≤w.
At each of n stages evaluate the marginal for at most m bidders and n remaining items. This requires O(mn2) value queries, and polynomial additional work with bundle bit-vectors and cached current values. Hence it is a polynomial time approximation algorithm in the value-oracle model, assuming polynomial time bid evaluations. If every bundle bid is explicitly listed, this query bound is polynomial in that larger explicit input as well. The exponentially many possible bundles do not require enumerating allocations.
