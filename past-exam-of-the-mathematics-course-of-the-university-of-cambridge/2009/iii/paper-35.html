Introduce nonnegative slack variables si​ and write z=cTx. A maximizing simplex dictionary is dual feasible when every nonbasic coefficient in the objective is nonpositive. After inserting a constraint, the dual simplex algorithm retains this property while repairing any negative basic value. For a leaving row xB​=β+∑j​dj​xj​ with β<0, only dj​>0 can enter; choose a column minimizing the ratio of its objective penalty to dj​.
For the first linear program, x1​ has the best profit-to-resource ratio. Pivot it into the initial slack basis to obtain
x1​=5−2x2​−3x3​−4x4​−s1​,z=5−x2​−2x3​−3x4​−s1​.
(1)
All basic values are nonnegative and all reduced costs are nonpositive, so the optimal point is (5,0,0,0), with value five. Adding the second constraint gives
s2​=1+3x2​+4x3​+5x4​+2s1​.
(2)
The same basis remains feasible and optimal: the second constraint does not change the answer.
The third constraint gives the new row
s3​=−1−x2​+x3​+x4​−s1​.
(3)
The current dictionary is dual feasible but primal infeasible. The eligible entering variables are x3​,x4​, with dual ratio-test values 2 and 3 respectively. Enter x3​ and leave s3​; solving that row and substituting into the old rows yields
x3​x1​s2​z​=1+x2​−x4​+s1​+s3​,=2−5x2​−x4​−4s1​−3s3​,=5+7x2​+x4​+6s1​+4s3​,=3−3x2​−x4​−3s1​−2s3​.​
(4)
This is a feasible optimal simplex dictionary. Thus the new optimal point is (2,0,1,0), with value three. As an independent linear programming optimality certificate, dual multipliers (3,0,2) have weighted objective bound 3⋅5+2(−6)=3 and weighted coefficient row (1,4,1,2), which dominates the profit row.
On inserting the fourth constraint the slack is
s4​=1−x2​−2x3​−2x4​=−1−3x2​−2s1​−2s3​.
(5)
It has a negative constant and no eligible entering column. Since all its nonbasic variables are nonnegative, this row cannot be satisfied: the fourth linear program is infeasible, and adding the fifth constraint cannot restore feasibility. The requested optimal values are therefore
valP({1})=5,valP({1,2})=5,valP({1,2,3})=3;k=4,5 are infeasible.​
(6)
The arbitrary-data selection question is a maximum feasible subsystem problem. With rational input it is in NP: guess the selected row indices, and test their linear programming feasibility in polynomial time. Equivalently, a nonempty rational polyhedron has a feasible rational point of polynomially bounded encoding length, which serves as a certificate.
For an explicit NP-hardness reduction, take an independent set instance with graph H having r vertices and desired independent-set size K. Use variables xv​≥0, one inequality −xv​≤−1 for each vertex, and M=r+1 identical copies of xu​+xv​≤1 for each edge. Ask for a feasible subsystem of size M∣E(H)∣+K. An independent set of size K gives such a subsystem: include all edge rows and those K vertex rows, and use its indicator vector. Conversely, omitting every copy of even one edge row leaves at most M(∣E(H)∣−1)+r<M∣E(H)∣+K selectable rows. Hence any qualifying subsystem retains every edge inequality and at least K vertex inequalities. Their vertices must be independent, since two adjacent selected vertices would force xu​+xv​≥2. The construction has polynomial size; c is irrelevant to feasibility. Thus the rational-input decision problem is NP-complete, not merely difficult because there are many subsets to enumerate.

A chain of r diamond-shaped graph stages has 3r+1 vertices and 4r edges, but 2r distinct source-to-target paths: at each stage choose either of two branches. Each path has its own inequality. Therefore the number of displayed path constraints is not polynomially bounded in the graph size. Redundancy among some inequalities would not change this count of the given formulation.
The positive integer edge costs imply, for any feasible point,
∥x∥2​≤∥x∥1​=∑e​xe​≤∑e​ce​xe​≤k≤100.
(7)
Thus the feasible set lies in the Euclidean ball of radius 100 centered at zero. That ball lies inside [−100,100]m, so its volume is at most 200m. This proves the requested O(200m) enclosing-volume bound, and provides an initial ellipsoid, for example with center zero and shape matrix 104I.
The ellipsoid method needs a separation oracle, rather than an explicit list of every constraint. For a proposed center z, first scan the coordinates and the budget inequality. If some ze​<0, some ze​>1, or ∑e​ce​ze​>k, return the corresponding violated inequality as the separating half-space. These tests take O(m) arithmetic operations.
Once those tests pass, assign nonnegative edge length ze​ to every edge and solve the shortest path problem from s to t. The Dijkstra algorithm finds a minimum-length path and stores its predecessors in polynomial time. If its length is less than one, return
∑e∈p​xe​≥1
(8)
for the minimizing path p. This inequality contains every feasible point and is violated by z. If the shortest length is at least one, every path constraint holds; if no path exists, those constraints are vacuous. In either case z is feasible. This is path-constraint separation by shortest paths; checking a single shortest path replaces checking exponentially many paths.
The rational ellipsoid method feasibility theorem now gives polynomial running time in the dimension and coefficient encoding bounds when the oracle runs in polynomial time. Here every path row has coefficients zero or one, and all other coefficients and right sides are bounded integers. Although there are exponentially many rows, their individual encoding lengths are polynomial in m. The containing-radius bound and the rational precision bounds are also polynomially describable. For a simple graph m=O(n2), this gives a worst-case running time polynomial in n; in general the natural bound is polynomial in the encoded graph size n+m.
Use the exact rational feasibility version of the ellipsoid method, which handles lower-dimensional polyhedra by rational precision bounds or an appropriate relaxation. Nonemptiness must not be inferred from a positive-volume argument: this feasible set can have empty interior. The allowed algorithmic theorem supplies that detail, while the explicit shortest-path oracle supplies the crucial efficient separation.

For NP-completeness, use the decision version with an objective threshold. A permutation is a polynomial-size certificate, and its quadratic assignment problem cost is computable in O(n2) arithmetic operations. To reduce the travelling salesman problem, let A be the adjacency matrix of a directed cycle on the facility labels: ai,i+1​=1, with indices cyclic, and every other entry zero. Let B be the matrix of city-to-city distances. Then
f(π)=∑i=1n​bπ(i),π(i+1)​,π(n+1)=π(1),
(9)
which is exactly the tour length. Every tour arises from such a permutation. Hence the decision QAP is NP-complete, and finding its optimal value is NP-hard. No factor of two appears in this directed-cycle construction, even when the distance matrix is symmetric.
Fix any complete assignment π. Its restriction to the facilities other than i is an admissible bijection in the definition of ℓi,π(i)​, so
∑j=i​aij​bπ(i),π(j)​≥ℓi,π(i)​.
(10)
Summing this inequality over i gives f(π)≥∑i​ℓi,π(i)​. Restricting to Πk​ and minimizing proves
π∈Πk​min​f(π)≥g(Πk​).​
(11)
This is the Gilmore-Lawler bound. Its row minima may come from mutually incompatible assignments, so equality is not automatic. To find g(Πk​), fix facility one at location k, delete that row and column from L, and solve the residual assignment problem using the Hungarian algorithm, adding ℓ1k​ to its value.
For the supplied instance, the two residual assignment sums at each initial branch are
g(Π1​)g(Π2​)g(Π3​)​=31+min(26+37,20+48)=94,=38+min(22+37,20+41)=97,=29+min(22+48,26+41)=96.​
(12)
Use branch and bound to explore Π1​, the branch with smallest bound. Its minimizing linear assignment is π=(1,2,3). Evaluating the true ordered-pair objective gives
f(1,2,3)=2(2⋅5+7⋅3+4⋅4)=94.
(13)
This supplies an incumbent of value 94 and meets the lower bound of Π1​. Alternatively, after branching on facility two, the other leaf (1,3,2) has row-sum bound 31+20+48=99 and is pruned. The initial bounds 97 and 96 prune Π2​ and Π3​ as well, since neither can improve the incumbent. Thus
OPT=94,π=(1,2,3) is optimal.​
(14)
The factor two in this numerical evaluation is necessary because both matrices are symmetric and the objective counts both directions of each unordered pair.

Represent a feasible allocation by a label for each item saying which bidder receives it. Every such label vector gives disjoint bundles covering all items, so the following heuristic optimization methods can search without violating allocation feasibility.
In local search, begin with any feasible partition and repeatedly make an improving move, such as transferring one item between bidders or exchanging two items. For a transfer j:i→r, evaluate the change
vi​(Si​∖{j})−vi​(Si​)+vr​(Sr​∪{j})−vr​(Sr​).
(15)
Stop when no allowed move improves the objective. Several starting partitions can avoid dependence on one local optimum, but no guarantee of a global optimum follows for general bids.
In simulated annealing, use the same feasible neighborhood but also accept a worsening move of loss Δ>0 with probability e−Δ/T at temperature T. Begin with a relatively high temperature, gradually cool, and retain the best allocation seen. Worsening moves can cross a barrier between local optima; a practical finite cooling schedule does not guarantee optimality.
In tabu search, retain a short memory of recent transfers or exchanges and temporarily prohibit their reversal. Select the best admissible move, possibly worsening the objective, to escape a local optimum. Permit an otherwise tabu move if it improves the best solution found, an aspiration rule. For the winner determination problem, bidder/item pairs or recent reverse transfers provide convenient tabu attributes. All three methods preserve the partition, but for arbitrary bids they are heuristics rather than algorithms with a proved constant approximation ratio.

The supplied hint interchanges its item and bidder indices in the first-value identity. If the first greedy choice assigns item n to bidder m, the correct quantity is w=vm​({n}), and the identity is
A(v)=w+A(v′).​
(16)
Indeed, the eventual bundle of bidder m has the form Sm′​∪{n}, whose value is w+vm′​(Sm′​); the other bidders' values are unchanged. Every later marginal contribution for bidder m is exactly its marginal in the residual problem, and this is also true for every other bidder. Thus the remainder of the greedy run is the greedy run on v′, with the same tie choices. The residual values are nonnegative and increasing; they remain submodular set functions as allowed in the question.
We prove the greedy half-approximation for submodular welfare by induction on the number of items. The zero-item case has A(v)=Opt(v)=∑i​vi​(∅)≥0, so the claimed inequality holds. This base case also handles the fact that the question does not explicitly normalize empty-bundle values to zero.
For the induction step, let
δ=vm​({n})−vm​(∅)≥0
(17)
be the first greedy marginal. Since the choice maximizes all available marginals,
vi​({n})−vi​(∅)≤δ≤wfor every bidder i.
(18)
Take an optimal allocation and let i be the owner of item n. If i=m, remove that item from i's bundle and give it to m. By submodularity, the loss to its old owner is
vi​(Si​)−vi​(Si​∖{n})≤vi​({n})−vi​(∅)≤δ.
(19)
Monotonicity makes the recipient's gain nonnegative. The modified allocation, now with n assigned to m, therefore has value at least Opt(v)−δ. If i=m, no modification is necessary and this bound still holds. Removing n and translating bidder m's value by w produces a feasible residual allocation, so
Opt(v′)≥Opt(v)−δ−w≥Opt(v)−2w.
(20)
Induction applied to that residual problem now gives
A(v)=w+A(v′)≥w+21​Opt(v′)≥21​Opt(v).
(21)
Thus the greedy algorithm is a one-half approximation. Empty-bundle constants cause no difficulty because all are nonnegative and δ≤w.
At each of n stages evaluate the marginal for at most m bidders and n remaining items. This requires O(mn2) value queries, and polynomial additional work with bundle bit-vectors and cached current values. Hence it is a polynomial time approximation algorithm in the value-oracle model, assuming polynomial time bid evaluations. If every bundle bid is explicitly listed, this query bound is polynomial in that larger explicit input as well. The exponentially many possible bundles do not require enumerating allocations.

A Nash equilibrium is a profile in which each player's strategy is a best response to all the others: no unilateral change increases that player's payoff. In this routing game the payoff can be taken as minus delay. A pure strategy is a single route; a mixed strategy is a probability distribution over routes, with different players randomizing independently. A non-zero-sum game does not require the players' payoffs to add to a fixed total. Nash's theorem guarantees a mixed Nash equilibrium for every finite game with finitely many pure strategies. Pure equilibria need not exist in general; the congestion game here does have them, since a unilateral delay change equals the change in its finite congestion potential.
Put x=n1​+n3​ and y=n2​+n3​. The three current delays, in the order ABD,ACD,ABCD, are
C1​=3+100x​,C2​=3+100y​,C3​=49​+100x+y​.
(22)
For a player using the first route, switching to the second makes the new second-route load y+1, while switching to the third retains that player's use of AB and adds one user to CD. The two comparisons are therefore
3+100x​≤3+100y+1​,3+100x​≤49​+100x+y+1​.
(23)
They reduce to x≤y+1 and y≥74. Reversing the two outer routes gives y≤x+1 and x≥74 for each second-route user. A third-route user who switches to the first retains their own use of AB, and one who switches to the second retains their own use of CD. The corresponding comparisons give y≤75 and x≤75. Thus the necessary and sufficient conditions, together with nonnegative integer counts summing to n, are
n1​>0n2​>0n3​>0​⟹x≤y+1 and y≥74,⟹y≤x+1 and x≥74,⟹x≤75 and y≤75.​​
(24)
They are sufficient because each used route has been compared with both alternatives, and necessary because each comparison is an available unilateral deviation. The unit changes in loads matter in a finite-player congestion game.
For n=100, the counts (25,25,50) give x=y=75 and every player's delay is 15/4. They satisfy all the conditions. To find every pure Nash equilibrium, first note that n3​=0 is impossible: if either outer route is empty, its other route users fail the lower-load condition; if both are used, x,y≥74 contradict x+y=100. Thus n3​>0, so x,y≤75. Since x=100−n2​ and y=100−n1​, this forces n1​,n2​≥25. Both are positive, so the remaining conditions force x,y≥74 and hence n1​,n2​≤26. Their differences are at most one, so every such pair works. The complete equilibrium count vectors are
(25,25,50),(25,26,49),(26,25,49),(26,26,48).​
(25)
Each vector also represents many pure profiles obtained by choosing which labeled players use each route. Therefore the displayed equilibrium is not unique, even as an aggregate count vector.
A coordinated allocation with fifty players on each outer route and nobody on ABCD gives every player delay 7/2, strictly better than 15/4. It is not a Nash equilibrium: a first-route user can switch to ABCD and obtain delay
49​+10050+51​=50163​<27​.
(26)
This exhibits the conflict between coordinated welfare and unilateral incentives. In fact 7/2 is below every user's delay in all four pure equilibrium count vectors above.
For a symmetric Nash equilibrium when n=100, let each player independently choose the two outer routes with probability q each and the middle route with probability 1−2q. Conditional on choosing the first route, that player certainly uses AB, while each of the other 99 players uses it with probability 1−q. The expected delays of the first and third routes are consequently
EC1​=3+1001+99(1−q)​=4−10099q​,EC3​=49​+1002+198(1−q)​=417​−100198q​.
(27)
The second has the same expected delay as the first by symmetry. Equalizing these gives
Pr(ABD)=Pr(ACD)=9925​,Pr(ABCD)=9949​.​
(28)
All three probabilities are positive and all three pure routes have expected delay 15/4, so every route is a best response to the other players' common mixture. This proves a symmetric mixed Nash equilibrium. Using probabilities 1/4,1/4,1/2 would omit the player's own-load correction and would not make all three expected delays equal.
For completeness, the same calculation works for every positive number of players. If n≤75, every player choosing ABCD is a symmetric pure Nash equilibrium. For 75<n<149, a symmetric mixed equilibrium has
Pr(ABD)=Pr(ACD)=n−1n−75​,Pr(ABCD)=n−1149−n​.
(29)
For n≥149, each player choosing either outer route with probability one half is a symmetric mixed equilibrium. In that last regime the unused middle route has expected cost at least that of the outer routes, since their difference is −3/4+(n+1)/200≥0. These formulas agree at the regime boundaries.

The characteristic function of a coalitional game assigns each coalition S⊆N its total attainable transferable payoff v(S), with v(∅)=0. In a transferable utility game the members may divide that total among themselves. This game-theoretic characteristic function is not the characteristic function of a probability distribution.
The Shapley value assigns to player i the average marginal contribution that player makes over all uniformly random orderings of the players. If Piπ​ is the predecessor set in ordering π, then
ϕi​(v,N)=n!1​∑π​(v(Piπ​∪{i})−v(Piπ​))=∑S⊆N∖{i}​n!∣S∣!(n−∣S∣−1)!​(v(S∪{i})−v(S)).
(30)
For any ordering, summing all contributions telescopes to v(N), so the Shapley value is efficient. It treats interchangeable players equally, pays a null player zero, and is additive in the characteristic function. These properties give its standard fairness axioms and uniquely characterize the Shapley value. The random-order interpretation explains why every position and predecessor coalition receives a principled weight rather than privileging a particular bargaining order.
For a convex cooperative game, couple a uniform ordering of N with its restriction to T. The restricted ordering is uniform on T. For i∈T, the restricted predecessor set is Piπ​∩T⊆Piπ​, so increasing marginal contributions give
v(Piπ​∪{i})−v(Piπ​)≥v((Piπ​∩T)∪{i})−v(Piπ​∩T).
(31)
Averaging proves Shapley population monotonicity in a convex game:
ϕi​(v,N)≥ϕi​(v,T)(i∈T).​
(32)
The comparison is meaningful for players who participate in the restricted game; no restricted value is defined for a player outside T. Summing over i∈T and applying efficiency in that restricted game gives
∑i∈T​ϕi​(v,N)≥∑i∈T​ϕi​(v,T)=v(T).
(33)
Together with efficiency for N, these are exactly the core of a cooperative game inequalities. Hence the Shapley value belongs to the core of a convex game. This proves the requested stability, not just individual rationality.
Now label the entrepreneur by 0 and the n≥1 workers by 1,…,n. A coalition without the entrepreneur has value zero; one containing the entrepreneur and k workers has value p(k). Workers are interchangeable, so their Shapley values agree. Fix one worker. Their contribution is zero if the entrepreneur appears after them. If the entrepreneur and exactly k of the other n−1 workers appear before them, it is p(k+1)−p(k). For a fixed choice of those workers, the k+1 predecessors can be ordered in (k+1)! ways and the remaining n−k−1 successors in (n−k−1)! ways. Therefore the probability of this event, summing over the (kn−1​) predecessor choices, is
(kn−1​)(n+1)!(k+1)!(n−k−1)!​=n(n+1)k+1​.
(34)
The fair wage is thus
w=n(n+1)1​k=0∑n−1​(k+1)(p(k+1)−p(k))=n(n+1)np(n)−∑k=0n−1​p(k)​.​
(35)
This is Shapley wages in an entrepreneur-worker game. The entrepreneur's payoff, by efficiency, is
x0​=p(n)−nw=n+11​k=0∑n​p(k).​
(36)
It also follows directly because the entrepreneur has each possible number k of predecessors with probability 1/(n+1), and their contribution is then p(k). When p(k)=αk, the differences are all α and ∑k=0n−1​(k+1)=n(n+1)/2, so
w=2α​,x0​=2αn​.​
(37)
Finally suppose p is convex and nondecreasing on nonnegative integers, so dk​=p(k+1)−p(k) is nonnegative and nondecreasing. We verify that the entire coalitional game is convex. The entrepreneur's contribution to a set of k workers is p(k), which increases with that set. A worker's contribution is zero when the entrepreneur is absent and is dk​ when the entrepreneur and k other workers are present. Enlarging a predecessor set either leaves both contributions zero, introduces the entrepreneur and a nonnegative contribution, or increases k and hence dk​. Every player's marginal contributions therefore increase, giving a convex cooperative game. The result already proved yields the complete Shapley allocation lies in the core, including the entrepreneur's payoff.
One can also verify the core inequalities directly. Nonentrepreneur coalitions receive kw≥0, their value. For a coalition containing the entrepreneur and k<n workers, it suffices that
w≤n−kp(n)−p(k)​.
(38)
Since k+1≤n+1 in the wage sum, w≤n1​∑j=0n−1​dj​. Nondecreasing dj​ makes this full average no greater than the average of the final n−k differences, which is the displayed right side. Thus x0​+kw=p(n)−(n−k)w≥p(k); the grand coalition has equality by efficiency. This confirms the core conclusion without assuming p(0)=0.
