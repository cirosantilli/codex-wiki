A measurable cardinal is an uncountable cardinal κ carrying a nonprincipal κ-complete ultrafilter U: intersections of fewer than κ members of U remain in U. Such an ultrafilter contains no set of size less than κ. Indeed each singleton is absent, and intersecting fewer than κ singleton complements shows that every small set's complement is in U. In particular every tail of κ is in U.
Form the ultrapower of the universe by functions f:κ→V, identifying functions agreeing on a member of U, and interpreting membership coordinatewise modulo U. The Łoś theorem, applied separately to each formula, makes the map x↦[cx​] elementary. Countable completeness makes the ultrapower well-founded: an infinite descending chain [fn+1​]∈[fn​] would give U-large sets witnessing each step, whose countable intersection is nonempty; a coordinate in that intersection would give an infinite descending membership chain in the original universe. The relation is extensional and set-like, so the Mostowski collapse theorem gives a transitive class M and an elementary ultrapower embedding j:V→M.
For each α<κ, every function κ→α is constant modulo U. If no fibre were in U, intersecting the fewer than κ fibre complements would give the empty set in U. Induction on α therefore shows that the collapsed ultrapower ordinal j(α) has precisely the elements β<α, so
j(α)=α(α<κ).
(16)
The identity function id:κ→κ represents an ordinal below j(κ), and every constant α<κ is below it modulo U, since a tail is large. Consequently
κ≤[id]collapse<j(κ),crit(j)=κ.​
(17)
Thus the canonical collapsed embedding is not the identity; its first moved ordinal is κ. For a general measure the identity-function class need not collapse to exactly κ; that stronger equality holds for a normal measure. The argument above needs only its lower bound.
Conversely, suppose j:V→M is elementary, M is transitive, its critical point is κ, and its derived measure is a set, as for the usual definable or amenable class embeddings. Define
U={A⊆κ:κ∈j(A)}.
(18)
Because κ<j(κ), elementary preservation of complements and intersections makes this an ultrafilter. It is nonprincipal since j({α})={α} for α<κ. For a sequence of γ<κ large sets, j fixes the index ordinal γ and takes the intersection to the intersection of their images; κ belongs to every image and hence to the intersection. Thus U is κ-complete. The set-existence qualification excludes treating an arbitrary external class map as a set parameter without justification.
For context, measurability already implies regularity and the strong-limit property. A cofinal sequence of length below κ partitions κ into that many bounded, hence small, pieces; completeness and their absent fibres contradict covering all of κ. If there were κ distinct subsets of some λ<κ, for each coordinate choose the U-large side deciding its membership bit. The intersection of these λ large sets would still be large, but all its indices would label the same subset, so it would have at most one member. This contradiction gives 2λ<κ. Thus the first moved ordinal is an uncountable strongly inaccessible cardinal, in addition to being measurable.
