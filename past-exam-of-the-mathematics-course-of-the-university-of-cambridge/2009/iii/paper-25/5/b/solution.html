Write θ→(η)λr​ when every λ-coloring of the r-element subsets of θ has a homogeneous subset of order type η. The Erdős-Rado theorem for pairs states, for infinite λ,
(2λ)+⟶(λ+)λ2​.​
(19)
In particular a countable-color partition of pairs from (2ℵ0​)+ has an uncountable homogeneous set. The standard Erdős-Rado theorem for finite arities is
ℶr​(λ)+⟶(λ+)λr+1​,ℶ0​(λ)=λ,ℶr+1​(λ)=2ℶr​(λ).
(20)
We prove it, including the pair case, by constructing an end-homogeneous routing tree.
For a coloring c:[θ]r+1→λ, r≥1, route each vertex β<θ as follows. Given its previously selected increasing ancestors, choose the least γ≤β greater than all those ancestors such that
c(s∪{γ})=c(s∪{β})for every r-subset s of those ancestors.
(21)
The candidate β always qualifies. Select it and stop if it is the minimum; otherwise add the selected γ to the ancestors and continue, including at limit stages. The ancestors are strictly increasing below β, so the process must stop. If a selected ancestor γ is routed separately, its earlier path is the same: its color constraints agree with those of β and the same least choices are forced. Thus the paths define a tree order on the vertices.
A node at depth α is determined by the table of its colors on the r-subsets of its ancestors. Given the table on [α]r, recursively take the least compatible candidate at each depth; at a limit depth use all preceding constraints. This recovers both the path and its final node. Therefore
∣Tα​∣≤λ∣[α]r∣.
(22)
Along any branch, once an r-tuple s of ancestors is fixed, the color c(s∪{β}) is independent of all subsequent choices of β on that branch. This is exactly end-homogeneity.
For the pair case take r=1 and θ=(2λ)+. If all node depths were below λ+, then each level would have size at most λλ≤2λ, and the union of λ+ levels would have size at most 2λ. This contradicts the number of vertices. Hence some node has at least λ+ ancestors. On that branch assign to each ancestor its constant color to all later ancestors. Regularity of λ+ implies that one of the λ colors occurs λ+ times, giving the desired homogeneous set. Its increasing enumeration has a subsequence of order type λ+.
For the higher-arity induction let μ=ℶr−1​(λ), so θ=(2μ)+. At depths below μ+ the same bound is at most λμ≤2μ, forcing a branch of length μ+. End-homogeneity defines a coloring d of its r-tuples by the common color of adjoining a later branch vertex. The previous-arity theorem gives a subset of order type λ+ homogeneous for d, and every (r+1)-tuple from it then has the same color under c. The base case r=0 is the infinite pigeonhole principle at λ+. This proves the full finite-arity statement.
One suitable ordinal partition-bound function is
f(α)=min{β≥α: ∀ nonzero cardinals ν<α, β→(α)ν2​}.
(23)
It is nondecreasing and f(α)≥α. It is total: choose an infinite cardinal λ≥∣α∣; the pair theorem supplies a homogeneous subset of size λ+ for every allowed color number, and its order type contains a copy of α. Thus (2λ)+ is a bound in the displayed minimum.
Let an uncountable cardinal κ be the supremum of a cofinal increasing sequence of iterates of f, with each iterate and its successor still below κ. For every ξ<κ, monotonicity and some later iterate give f(ξ)<κ. Thus the relevant consequence of being such a supremum is
f‘‘κ⊆κ.
(24)
If the iteration already reaches a fixed point, its constant continuation of course has that fixed point as supremum as well. A strictly increasing countable iteration instead has a countable-cofinality supremum and cannot satisfy the uncountable regular tree-property condition below; one must not assume existence of the extra condition from iteration alone.
Here closure under f forces a strong-limit bound. For infinite λ<κ, color distinct binary strings in 2λ by their first differing coordinate. Three strings cannot have all three first-difference coordinates equal, because there are only two bit values at that coordinate. Hence this λ-coloring has no homogeneous triangle, and in particular no homogeneous subset of order type λ+1. Therefore
f(λ+1)>2λ.
(25)
Since λ+1<κ and f(λ+1)<κ, it follows that 2λ<κ for every λ<κ.
Now impose the tree property: every tree of height κ, with nonempty levels of size below κ, has a cofinal branch. If this definition is extended to singular cardinals, it also forces regularity. For a singular κ, take disjoint chains of lengths cofinal in κ, one for each index below cfκ. Every level has at most cfκ<κ nodes and the height is κ, but each branch remains in one shorter chain. A common new root may be added if rooted trees are required. Under the more usual convention the tree property is only defined at regular uncountable cardinals, so regularity is part of the convention instead.
For a coloring c:[κ]2→ν with ν<κ, the routing tree has levels of size at most ν∣α∣<κ by the strong-limit property. If some node has height at least κ, there is already an end-homogeneous branch of that length. Otherwise the tree has height exactly κ: a smaller number of levels of size below κ could not contain its κ nodes, by regularity. The tree property then supplies a cofinal branch. Along it, one of the fewer than κ ancestor colors occurs κ times, again by regularity. Thus κ→(κ)ν2​ for every ν<κ, giving
f(κ)=κ.​
(26)
Moreover the closure argument gives strong limit and the tree argument gives regularity. Thus an uncountable f-closed cardinal with the tree property is strongly inaccessible.
The final printed assertion requires that qualification. The ordinary tree property alone does not imply strong inaccessibility. At ω it is König's infinity lemma and ω is not uncountable. Even when the convention excludes ω, there are relative-consistency models in which ℵ2​ has the tree property, although a successor cardinal is never strongly inaccessible; this result is recalled in the introduction of Friedman, Honzik and Stejskalová. No proof of the bare implication is possible under that standard definition. The preceding paragraphs prove the corrected implication in the actual f-closure setting and the requested fixed-point conclusion, without silently replacing tree property by weak compactness.
