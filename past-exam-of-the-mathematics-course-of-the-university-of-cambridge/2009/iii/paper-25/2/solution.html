The Rieger-Bernays permutation model changes membership, not the underlying domain. In a model M of ZF, let π be a definable class bijection, with parameters allowed, and define
xEy⟺x∈π(y).
(5)
Every old set b is the new extension of precisely the object π−1(b). Translation of formulas replaces each membership assertion by this definable relation. Both images and inverse images of old sets under π are sets by replacement.
Here are the axiom checks. Extensionality follows because equal new extensions mean π(x)=π(y) and hence x=y. The new empty set is π−1(∅) and the new pair is π−1({x,y}). For an object a, new union and power set have representatives
π−1(⋃z∈π(a)​π(z)),π−1({π−1(b):b⊆π(a)}).
(6)
These formulas verify the actual new membership conditions. A definable subset of the new extension π(a) is an old set by separation after translation, and its representative gives new separation. Similarly, a functional new formula on that extension has an old set as range by replacement; apply π−1 to its range. For infinity, iterate the new successor operation
sE​(x)=π−1(π(x)∪{x})
(7)
starting from the new empty set. Old recursion and replacement collect its finite iterates into a set B, and π−1(B) is a new inductive set. Thus all axioms of ZF except possibly foundation hold.
Now swap the old objects 0=∅ and 1={0} and fix everything else. The old object 0 then satisfies 0E0, and its entire new extension is {0}. It is a Quine atom, so foundation fails. Taking π to be the identity gives the original model where foundation holds. Foundation is independent of the other ZF axioms, relative to consistency of ZF.
A full permutation of a model of choice does not destroy choice. Given a new family of nonempty new sets, old choice selects an element of each old extension π(y); replacement converts its graph into new ordered-pair coding. Thus simply repeating the preceding unrestricted permutation construction would not prove independence of choice. The extension needed is the hereditarily finite-supported Quine-atom model.
Start with a model of ZFC and simultaneously swap an​=ω+n with {an​} for all n<ω. These transpositions have disjoint supports: none of these infinite ordinals is a singleton, and the ordinals and their singletons are separately distinct. Put A={an​:n<ω}, whose members now have new extensions {an​}. Build the universe over these Quine atoms by allowing arbitrary new sets of previously constructed objects at each successor stage, and taking unions at limit stages. More explicitly, begin with U0​=A, put
Uα+1​=A∪{π−1(b):b⊆Uα​},Uλ​=⋃α<λ​Uα​,
(8)
and take the union over all ordinals. The singleton with sole member an​ is already an​, as extensionality requires; it is not added as a different atom or set. Every other object's membership has a well-founded construction rank once these designated atomic self-loops are treated as rank-zero leaves.
Every permutation g of A extends to an automorphism of this universe: on atoms use g, and on every non-atomic object recurse by
g​(x)=π−1{g​(y):yEx}.
(9)
The inverse permutation gives its inverse, and the formula preserves E. Call an object supported by a finite S⊆A when every permutation fixing S pointwise fixes that object. Retain only objects which are supported and all of whose members are hereditarily supported; the recursion here again stops at atoms, whose support is their singleton. Denote this class by H.
We verify that (H,E) is a model of ZF without foundation. It is membership-closed and hence retains extensionality. Pairing uses the union of the two parameter supports, and union uses the support of its input. For separation, use the finite union of the supports of the domain and all parameters: permutations fixing them preserve satisfaction in H, so they fix the defined subset. Every member remains hereditary. For replacement, the same support fixes the image of a definable functional relation; its elements already lie in H by the internal range condition, and old replacement supplies the underlying set of them. These assertions are legitimate class translations because construction ranks, supports and hereditary support are definable in the starting model.
For power set, start with the set of all new subsets of a supported set and retain exactly those lying in H. The resulting collection is fixed by every permutation fixing the original set's support: the action preserves hereditary support and permutes its subsets. Every retained member is hereditary, so this is the internal power set. The empty set and the pure finite and infinite natural-number hierarchy have empty support, yielding infinity. The new pairing, union and comprehension representatives discussed above therefore remain inside H. Foundation still fails because all the Quine atoms are in H.
The set A itself has empty support and hereditary members. So does the family of its two-element subsets, each of which has a finite support in a permutation action. If this family had a choice function f∈H, let S be a finite support in a permutation action of f, and choose distinct a,b∈A∖S. The transposition of a,b fixes S and the unordered pair {a,b}, but interchanges either possible chosen value f({a,b}). It cannot fix the function graph, contradicting its support. Thus choice fails in (H,E).
The unrestricted permutation model over the same initial ZFC model satisfies choice and fails foundation, whereas its hereditarily supported submodel fails both. Hence choice is independent of ZF with foundation omitted. These are relative-consistency constructions, not an assertion that ZF proves its own consistency. Starting with ZFC is harmless for the usual consistency comparison with ZF, by the constructible-universe relative-consistency theorem.
