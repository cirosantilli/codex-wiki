A useful precise form of the Ehrenfeucht-Mostowski theorem is this: for an infinite structure M and any linear order I, a model of Th(M) can be generated as a Skolem hull by distinct order indiscernibles (ai​)i∈I​. Every order automorphism of I extends to an automorphism of that hull in the chosen Skolem language. One may first name all elements of M, giving an elementary extension containing the original structure. The generation and uniqueness assertions concern this specified expansion, not arbitrary automorphisms of its reduct.
Choose a Skolem expansion M∗: for each existential formula add a function selecting a witness whenever one exists. Introduce constants ci​ for i∈I. Take the theory of M∗, distinctness of these constants, and all equivalences
φ(ci1​​,…,cir​​)↔φ(cj1​​,…,cjr​​)(i1​<⋯<ir​, j1​<⋯<jr​).
(12)
The formulas here are in the fixed expanded language, without the newly added ci​ as extra parameters. If naming M, use its complete elementary diagram and allow those original names in the formulas.
Every finite fragment has a model by Ramsey's theorem. Only finitely many formulas and constants occur. Take a sequence of distinct elements of M. For each arity appearing, color the increasing tuples from this sequence by the finite vector of truth values of all formulas of that arity. Successive Ramsey thinning gives an infinite subset homogeneous for each of these finitely many colorings. Assign the finitely many constants in increasing order to distinct elements of this subset. This satisfies every displayed equivalence in the fragment; the original theory is satisfied because the underlying structure remains M∗. Compactness now gives a model of the full theory, with the required order-indiscernible sequence.
The substructure generated by the constants under the Skolem functions is elementary: any existential formula with parameters which are terms in the generators has its Skolem witness in that same hull. If g is an order automorphism of I, define
t(ai1​​,…,air​​)⟼t(ag(i1​)​,…,ag(ir​)​).
(13)
Indiscernibility makes this well-defined, by applying it to the equation between any two term representations using the increasing tuple of all their indices. The same argument preserves every relation and function; g−1 supplies the inverse. It is unique in the generated Skolem structure. This completes the Ramsey proof, rather than stopping at the existence of indiscernibles.
For simple typed set theory with atoms, use sorts D0​,D1​,… and membership only from Di​ to Di+1​. A set predicate distinguishes sets from atoms, extensionality compares sets of the same positive type, and comprehension produces in type i+1 every subset of Di​ defined by a well-typed formula. Atoms have no members. First-order models use Henkin semantics; they are not required to have their next domain equal to the full external power set. Typical ambiguity is the schema ϕ↔ϕ+ for each closed sentence, where every sort index in ϕ+ is raised by one.
We show finite satisfiability of this entire typed theory with ambiguity. Choose a list of ranks ρ0​<ρ1​<⋯ above ω, spaced by at least two. For a finite increasing selection of ranks r−1​<r0​<⋯<rm​, let
Di​=Vri​​,Si​=P(Vri−1​​),
(14)
where Si​ is the set of objects declared to be sets at type i. Membership from Di​ to Di+1​ is ordinary membership restricted to objects of Si+1​=P(Di​); all other type-i+1 objects are atoms. The spacing puts P(Di​) inside Di+1​. Thus comprehension and set extensionality hold exactly, and atoms have no typed members. There are infinitely many objects at every visible type, so any usual typed infinity requirement also holds.
The auxiliary rank r−1​ provides a uniform interpretation if a set predicate is allowed at type zero; no type-minus-one domain is used in the theory. This avoids artificially declaring all type-zero objects to be atoms, which would not be invariant under type-raising. If the language has no type-zero set predicate, simply ignore this auxiliary interpretation.
A finite set of ambiguity instances uses finitely many closed sentences of bounded highest type, say at most m. Color increasing (m+2)-tuples of ranks by their finite truth vector in the structure with visible domains D0​,…,Dm​ and the auxiliary preceding rank. Ramsey's theorem gives an infinite homogeneous rank set. Choose m+3 consecutive ranks from it and build the hierarchy on all these ranks. The first window evaluates each original sentence; shifting the window one place evaluates its uniform type-raise. Homogeneity makes the truth vectors equal. All finite typed axioms and the selected ambiguity instances therefore hold together. Choosing m large enough covers every sort needed by the finite fragment. Many-sorted compactness, equivalently ordinary first-order compactness after encoding sorts, yields
Con(TSTU+typical ambiguity).​
(15)
This is a model existence argument in the ambient set theory; no equality of adjacent type cardinalities is claimed. The gaps between ranks supply atoms, and the ambiguity is about truth of sentences, not a bijection between domains.
