The arrow in the original PDF permits partial functions. A partial computable function Nk⇀N is computed by a finite program which halts with the specified value on every input in its domain and diverges on inputs outside the domain. A total computable function is the special case with full domain. Coding finite tuples by a primitive recursive pairing function identifies the different finite arities effectively, without identifying total and partial computability.
One precise machine model is a Turing machine. Its finite transition rules and configurations admit effective numerical coding. Bounded simulation is primitive recursive, and unbounded execution gives the partial result. Equivalently, start from zero, successor and projections and close under composition, primitive recursion and unbounded minimization. The Kleene normal form theorem makes the equivalence concrete:
φe​(x)≃U(μs T(e,x,s)),
(1)
where T is a primitive recursive predicate checking a coded halting computation and U reads its output. If no computation exists, the minimum and hence the value are undefined. Checking a finite history is effective because every consecutive configuration must obey one of the finitely many transition rules.
The universal partial computable function evaluates the program indexed by e on an input. The S-m-n theorem says that fixing finitely many input parameters can be done by a total computable operation on program Gödel numbers: a new program stores those parameters and calls the original universal evaluator. These facts explain both universal simulation and uniform reductions. A set is computably enumerable when it is the domain of a partial computable function, equivalently the range of an effective enumeration. It is recursive when its characteristic function is total computable. A set is recursive precisely when it and its complement are computably enumerable: dovetail the two enumerations to decide each input.
The diagonal halting problem K={e:φe​(e)↓} is computably enumerable but not recursive. A total decider would yield a program which, on e, diverges if the decider says e∈K and halts otherwise. Applying this program to its own index gives a contradiction. There is likewise no total computable universal listing of all total computable functions: the diagonal function n↦U(n,n)+1 would be total and absent from the listing.
Here is a full proof of the Rice theorem. Let P be a nonempty proper class of partial computable functions whose property depends only on the function, not its program. First suppose the everywhere-undefined function ⊥ is not in P, and choose a program for a function g∈P. Given an index e, construct uniformly a program which on x first waits for φe​(e) to halt and, only then, simulates g(x). The S-m-n theorem gives a total computable index map h. If e∈/K, then φh(e)​=⊥; if e∈K, then φh(e)​=g. Thus
e∈K⟺φh(e)​∈P.
(2)
A decision procedure for the property would decide K, impossible. If ⊥∈P, apply the same argument to its nontrivial complement. Every nontrivial extensional property of partial computable functions has an undecidable index set. Totality, having finite domain, and taking a particular value somewhere are examples. A syntactic property such as program length is not covered; nor does the theorem say that no individual program's behaviour can be established.
Self-reference can also be made effective. For a total computable index transformation f, let d(x) be an index for the program which first computes φx​(x) and then runs the program with that resulting index on its own input. The S-m-n theorem makes d total computable. Choose an index e for the total function x↦f(d(x)), and put n=d(e). Then
φn​=φφe​(e)​=φf(d(e))​=φf(n)​.
(3)
This proves the recursion theorem: every effective transformation of programs has a fixed point at the level of the function computed, though not necessarily at the level of its numerical code.
Finally, consider the Jockusch triple coloring computing the halting set. Fix computable finite approximations K0​⊆K1​⊆⋯ with union K. For x<y<z, define
c({x,y,z})={0,1,​Ky​∩{0,…,x−1}=Kz​∩{0,…,x−1},otherwise.​
(4)
This is a total recursive two-coloring because both stages are finite computations. Suppose H is infinite and homogeneous. Its color cannot be one: fix x∈H, wait until every enumeration below x has stabilized, and choose later y<z from H beyond that stage. Their color is zero.
If H has color zero, it computes K. On input n, use H to find x>n and y>x in H. For arbitrarily large z∈H with z>y, homogeneity gives Ky​∩x=Kz​∩x. Taking stages sufficiently large to reach the final finite approximation gives Ky​∩x=K∩x. Consequently membership of n in K is decided by the finite stage Ky​. A recursive H would therefore make K recursive, a contradiction. There is a recursive partition of triples with no infinite recursive homogeneous set. This is the nontrivial finite-color meaning of the partition of an infinite domain; if “infinite partition” meant infinitely many colors, the coloring by the least member would already give a trivial example. Ramsey's theorem still guarantees infinite homogeneous sets for the displayed two-coloring, but every such set is computationally nontrivial.
