The arrow in the original PDF permits partial functions. A partial computable function Nk⇀N is computed by a finite program which halts with the specified value on every input in its domain and diverges on inputs outside the domain. A total computable function is the special case with full domain. Coding finite tuples by a primitive recursive pairing function identifies the different finite arities effectively, without identifying total and partial computability.
One precise machine model is a Turing machine. Its finite transition rules and configurations admit effective numerical coding. Bounded simulation is primitive recursive, and unbounded execution gives the partial result. Equivalently, start from zero, successor and projections and close under composition, primitive recursion and unbounded minimization. The Kleene normal form theorem makes the equivalence concrete:
φe​(x)≃U(μs T(e,x,s)),
(1)
where T is a primitive recursive predicate checking a coded halting computation and U reads its output. If no computation exists, the minimum and hence the value are undefined. Checking a finite history is effective because every consecutive configuration must obey one of the finitely many transition rules.
The universal partial computable function evaluates the program indexed by e on an input. The S-m-n theorem says that fixing finitely many input parameters can be done by a total computable operation on program Gödel numbers: a new program stores those parameters and calls the original universal evaluator. These facts explain both universal simulation and uniform reductions. A set is computably enumerable when it is the domain of a partial computable function, equivalently the range of an effective enumeration. It is recursive when its characteristic function is total computable. A set is recursive precisely when it and its complement are computably enumerable: dovetail the two enumerations to decide each input.
The diagonal halting problem K={e:φe​(e)↓} is computably enumerable but not recursive. A total decider would yield a program which, on e, diverges if the decider says e∈K and halts otherwise. Applying this program to its own index gives a contradiction. There is likewise no total computable universal listing of all total computable functions: the diagonal function n↦U(n,n)+1 would be total and absent from the listing.
Here is a full proof of the Rice theorem. Let P be a nonempty proper class of partial computable functions whose property depends only on the function, not its program. First suppose the everywhere-undefined function ⊥ is not in P, and choose a program for a function g∈P. Given an index e, construct uniformly a program which on x first waits for φe​(e) to halt and, only then, simulates g(x). The S-m-n theorem gives a total computable index map h. If e∈/K, then φh(e)​=⊥; if e∈K, then φh(e)​=g. Thus
e∈K⟺φh(e)​∈P.
(2)
A decision procedure for the property would decide K, impossible. If ⊥∈P, apply the same argument to its nontrivial complement. Every nontrivial extensional property of partial computable functions has an undecidable index set. Totality, having finite domain, and taking a particular value somewhere are examples. A syntactic property such as program length is not covered; nor does the theorem say that no individual program's behaviour can be established.
Self-reference can also be made effective. For a total computable index transformation f, let d(x) be an index for the program which first computes φx​(x) and then runs the program with that resulting index on its own input. The S-m-n theorem makes d total computable. Choose an index e for the total function x↦f(d(x)), and put n=d(e). Then
φn​=φφe​(e)​=φf(d(e))​=φf(n)​.
(3)
This proves the recursion theorem: every effective transformation of programs has a fixed point at the level of the function computed, though not necessarily at the level of its numerical code.
Finally, consider the Jockusch triple coloring computing the halting set. Fix computable finite approximations K0​⊆K1​⊆⋯ with union K. For x<y<z, define
c({x,y,z})={0,1,​Ky​∩{0,…,x−1}=Kz​∩{0,…,x−1},otherwise.​
(4)
This is a total recursive two-coloring because both stages are finite computations. Suppose H is infinite and homogeneous. Its color cannot be one: fix x∈H, wait until every enumeration below x has stabilized, and choose later y<z from H beyond that stage. Their color is zero.
If H has color zero, it computes K. On input n, use H to find x>n and y>x in H. For arbitrarily large z∈H with z>y, homogeneity gives Ky​∩x=Kz​∩x. Taking stages sufficiently large to reach the final finite approximation gives Ky​∩x=K∩x. Consequently membership of n in K is decided by the finite stage Ky​. A recursive H would therefore make K recursive, a contradiction. There is a recursive partition of triples with no infinite recursive homogeneous set. This is the nontrivial finite-color meaning of the partition of an infinite domain; if “infinite partition” meant infinitely many colors, the coloring by the least member would already give a trivial example. Ramsey's theorem still guarantees infinite homogeneous sets for the displayed two-coloring, but every such set is computationally nontrivial.

The Rieger-Bernays permutation model changes membership, not the underlying domain. In a model M of ZF, let π be a definable class bijection, with parameters allowed, and define
xEy⟺x∈π(y).
(5)
Every old set b is the new extension of precisely the object π−1(b). Translation of formulas replaces each membership assertion by this definable relation. Both images and inverse images of old sets under π are sets by replacement.
Here are the axiom checks. Extensionality follows because equal new extensions mean π(x)=π(y) and hence x=y. The new empty set is π−1(∅) and the new pair is π−1({x,y}). For an object a, new union and power set have representatives
π−1(⋃z∈π(a)​π(z)),π−1({π−1(b):b⊆π(a)}).
(6)
These formulas verify the actual new membership conditions. A definable subset of the new extension π(a) is an old set by separation after translation, and its representative gives new separation. Similarly, a functional new formula on that extension has an old set as range by replacement; apply π−1 to its range. For infinity, iterate the new successor operation
sE​(x)=π−1(π(x)∪{x})
(7)
starting from the new empty set. Old recursion and replacement collect its finite iterates into a set B, and π−1(B) is a new inductive set. Thus all axioms of ZF except possibly foundation hold.
Now swap the old objects 0=∅ and 1={0} and fix everything else. The old object 0 then satisfies 0E0, and its entire new extension is {0}. It is a Quine atom, so foundation fails. Taking π to be the identity gives the original model where foundation holds. Foundation is independent of the other ZF axioms, relative to consistency of ZF.
A full permutation of a model of choice does not destroy choice. Given a new family of nonempty new sets, old choice selects an element of each old extension π(y); replacement converts its graph into new ordered-pair coding. Thus simply repeating the preceding unrestricted permutation construction would not prove independence of choice. The extension needed is the hereditarily finite-supported Quine-atom model.
Start with a model of ZFC and simultaneously swap an​=ω+n with {an​} for all n<ω. These transpositions have disjoint supports: none of these infinite ordinals is a singleton, and the ordinals and their singletons are separately distinct. Put A={an​:n<ω}, whose members now have new extensions {an​}. Build the universe over these Quine atoms by allowing arbitrary new sets of previously constructed objects at each successor stage, and taking unions at limit stages. More explicitly, begin with U0​=A, put
Uα+1​=A∪{π−1(b):b⊆Uα​},Uλ​=⋃α<λ​Uα​,
(8)
and take the union over all ordinals. The singleton with sole member an​ is already an​, as extensionality requires; it is not added as a different atom or set. Every other object's membership has a well-founded construction rank once these designated atomic self-loops are treated as rank-zero leaves.
Every permutation g of A extends to an automorphism of this universe: on atoms use g, and on every non-atomic object recurse by
g​(x)=π−1{g​(y):yEx}.
(9)
The inverse permutation gives its inverse, and the formula preserves E. Call an object supported by a finite S⊆A when every permutation fixing S pointwise fixes that object. Retain only objects which are supported and all of whose members are hereditarily supported; the recursion here again stops at atoms, whose support is their singleton. Denote this class by H.
We verify that (H,E) is a model of ZF without foundation. It is membership-closed and hence retains extensionality. Pairing uses the union of the two parameter supports, and union uses the support of its input. For separation, use the finite union of the supports of the domain and all parameters: permutations fixing them preserve satisfaction in H, so they fix the defined subset. Every member remains hereditary. For replacement, the same support fixes the image of a definable functional relation; its elements already lie in H by the internal range condition, and old replacement supplies the underlying set of them. These assertions are legitimate class translations because construction ranks, supports and hereditary support are definable in the starting model.
For power set, start with the set of all new subsets of a supported set and retain exactly those lying in H. The resulting collection is fixed by every permutation fixing the original set's support: the action preserves hereditary support and permutes its subsets. Every retained member is hereditary, so this is the internal power set. The empty set and the pure finite and infinite natural-number hierarchy have empty support, yielding infinity. The new pairing, union and comprehension representatives discussed above therefore remain inside H. Foundation still fails because all the Quine atoms are in H.
The set A itself has empty support and hereditary members. So does the family of its two-element subsets, each of which has a finite support in a permutation action. If this family had a choice function f∈H, let S be a finite support in a permutation action of f, and choose distinct a,b∈A∖S. The transposition of a,b fixes S and the unordered pair {a,b}, but interchanges either possible chosen value f({a,b}). It cannot fix the function graph, contradicting its support. Thus choice fails in (H,E).
The unrestricted permutation model over the same initial ZFC model satisfies choice and fails foundation, whereas its hereditarily supported submodel fails both. Hence choice is independent of ZF with foundation omitted. These are relative-consistency constructions, not an assertion that ZF proves its own consistency. Starting with ZFC is harmless for the usual consistency comparison with ZF, by the constructible-universe relative-consistency theorem.

A well-quasi-ordering is a preorder ⪯ in which every infinite sequence has i<j with xi​⪯xj​. A sequence without such a pair is a bad sequence. We use rooted-tree homeomorphic embedding: an injective map of vertices preserving lowest common ancestors, so edges may become paths and a source root may map below the host root. Labels, when present, must increase in their label preorder. This convention is important; adjacency-preserving embeddings do not give the same theorem.
We first prove the auxiliary Higman lemma. If Q is a well-quasi-order, its finite words are well-quasi-ordered by subsequence embedding with increased letters. Suppose not, and choose a minimal bad sequence of words: at each position choose one of least length among those permitting a bad continuation of the preceding prefix. No word is empty. Write wi​=vi​ai​ by deleting its last letter. A well-quasi-order has an infinite nondecreasing subsequence of any sequence: if no member of an infinite subsequence had infinitely many later upper bounds within it, one could recursively avoid the finitely many upper bounds of earlier choices and construct a bad sequence. Choose a member with infinitely many later upper bounds, restrict to those bounds and repeat. Apply this to get ai0​​⪯ai1​​⪯⋯.
The sequence w0​,…,wi0​−1​,vi0​​,vi1​​,… is still bad. An earlier prefix word embedding into a vij​​ would embed into wij​​, contrary to the original bad sequence. An embedding vij​​⪯vik​​ would extend by the comparable last letters to wij​​⪯wik​​, equally impossible. But its next word at position i0​ is strictly shorter than wi0​​, contradicting minimality. This proves Higman's lemma, including the possibility that a deleted word is empty, since that would make the proposed bad continuation impossible immediately.
We now prove the labelled version of Kruskal's tree theorem for labels in any well-quasi-order Q. Assume there is a bad sequence T0​,T1​,…, and choose one minimal in vertex count at each position, subject to bad extendibility. Let S be the collection of rooted subtrees obtained by deleting a root and taking one of its child branches, over all Ti​.
This collection is well-quasi-ordered. Otherwise take a bad sequence Uj​ from S. Only finitely many of these objects can come from any bounded initial segment of the Ti​, since that segment has only finitely many child branches and a bad sequence cannot repeat an object. Pass to a subsequence with Uj​ a child branch of Tkj​​ and k0​<k1​<⋯. Then
T0​,…,Tk0​−1​,U0​,U1​,…
(10)
is bad: a prefix tree embedding into Uj​ would embed into Tkj​​, and the Uj​ are already bad among themselves. The next object U0​ has fewer vertices than Tk0​​, contradicting the minimal bad choice. Notice that a child branch does embed into its full tree under the stated homeomorphic convention.
List each tree's child branches in any chosen order. The preceding result and Higman's lemma make these finite lists well-quasi-ordered. The product of two well-quasi-orders is well-quasi-ordered: first thin to an infinite nondecreasing subsequence in one coordinate and then find an increasing pair in the other. Therefore there are i<j such that the root label of Ti​ increases to that of Tj​, and the child list of Ti​ embeds as a subsequence into the child list of Tj​, with each source branch homeomorphically embedding into its matched branch.
Map the root of Ti​ to the root of Tj​, and use these branch embeddings below it. Different child branches map into different host branches, so their lowest common ancestor maps to the host root. Within each branch it is preserved by the chosen embedding. Thus the whole map is injective, preserves all lowest common ancestors and respects labels, contradicting badness. Finite rooted trees labelled by a well-quasi-order are well-quasi-ordered under homeomorphic embedding. Taking one label proves Kruskal's tree theorem. If one uses a root-preserving convention, mark the root by a separate label incomparable with all ordinary labels and apply the labelled theorem; the marked root then has to map to the marked root. No adjacency-preservation assertion is being made.
For Friedman's finite form of Kruskal's theorem, fix k∈N. The required finite conclusion is
∃N ∀T1​,…,TN​(∣Ti​∣≤k+i ∀i) ⟹ ∃i<j (Ti​⪯Tj​).​
(11)
Assume there were arbitrarily long bad sequences satisfying these size bounds. Form the tree of their finite prefixes, using rooted-tree isomorphism classes as objects. At position i only finitely many finite rooted trees have at most k+i vertices, so this prefix tree is finitely branching and has nodes at arbitrarily large depths. König infinity lemma supplies an infinite branch: at each step some child must still have arbitrarily deep extensions, because there are only finitely many children. The branch is an infinite bad sequence of finite rooted trees, contradicting Kruskal's theorem. Thus such an N exists. The argument also works for any prescribed size-bound function, or any fixed finite label set, because each position then still has finitely many possible objects.

A useful precise form of the Ehrenfeucht-Mostowski theorem is this: for an infinite structure M and any linear order I, a model of Th(M) can be generated as a Skolem hull by distinct order indiscernibles (ai​)i∈I​. Every order automorphism of I extends to an automorphism of that hull in the chosen Skolem language. One may first name all elements of M, giving an elementary extension containing the original structure. The generation and uniqueness assertions concern this specified expansion, not arbitrary automorphisms of its reduct.
Choose a Skolem expansion M∗: for each existential formula add a function selecting a witness whenever one exists. Introduce constants ci​ for i∈I. Take the theory of M∗, distinctness of these constants, and all equivalences
φ(ci1​​,…,cir​​)↔φ(cj1​​,…,cjr​​)(i1​<⋯<ir​, j1​<⋯<jr​).
(12)
The formulas here are in the fixed expanded language, without the newly added ci​ as extra parameters. If naming M, use its complete elementary diagram and allow those original names in the formulas.
Every finite fragment has a model by Ramsey's theorem. Only finitely many formulas and constants occur. Take a sequence of distinct elements of M. For each arity appearing, color the increasing tuples from this sequence by the finite vector of truth values of all formulas of that arity. Successive Ramsey thinning gives an infinite subset homogeneous for each of these finitely many colorings. Assign the finitely many constants in increasing order to distinct elements of this subset. This satisfies every displayed equivalence in the fragment; the original theory is satisfied because the underlying structure remains M∗. Compactness now gives a model of the full theory, with the required order-indiscernible sequence.
The substructure generated by the constants under the Skolem functions is elementary: any existential formula with parameters which are terms in the generators has its Skolem witness in that same hull. If g is an order automorphism of I, define
t(ai1​​,…,air​​)⟼t(ag(i1​)​,…,ag(ir​)​).
(13)
Indiscernibility makes this well-defined, by applying it to the equation between any two term representations using the increasing tuple of all their indices. The same argument preserves every relation and function; g−1 supplies the inverse. It is unique in the generated Skolem structure. This completes the Ramsey proof, rather than stopping at the existence of indiscernibles.
For simple typed set theory with atoms, use sorts D0​,D1​,… and membership only from Di​ to Di+1​. A set predicate distinguishes sets from atoms, extensionality compares sets of the same positive type, and comprehension produces in type i+1 every subset of Di​ defined by a well-typed formula. Atoms have no members. First-order models use Henkin semantics; they are not required to have their next domain equal to the full external power set. Typical ambiguity is the schema ϕ↔ϕ+ for each closed sentence, where every sort index in ϕ+ is raised by one.
We show finite satisfiability of this entire typed theory with ambiguity. Choose a list of ranks ρ0​<ρ1​<⋯ above ω, spaced by at least two. For a finite increasing selection of ranks r−1​<r0​<⋯<rm​, let
Di​=Vri​​,Si​=P(Vri−1​​),
(14)
where Si​ is the set of objects declared to be sets at type i. Membership from Di​ to Di+1​ is ordinary membership restricted to objects of Si+1​=P(Di​); all other type-i+1 objects are atoms. The spacing puts P(Di​) inside Di+1​. Thus comprehension and set extensionality hold exactly, and atoms have no typed members. There are infinitely many objects at every visible type, so any usual typed infinity requirement also holds.
The auxiliary rank r−1​ provides a uniform interpretation if a set predicate is allowed at type zero; no type-minus-one domain is used in the theory. This avoids artificially declaring all type-zero objects to be atoms, which would not be invariant under type-raising. If the language has no type-zero set predicate, simply ignore this auxiliary interpretation.
A finite set of ambiguity instances uses finitely many closed sentences of bounded highest type, say at most m. Color increasing (m+2)-tuples of ranks by their finite truth vector in the structure with visible domains D0​,…,Dm​ and the auxiliary preceding rank. Ramsey's theorem gives an infinite homogeneous rank set. Choose m+3 consecutive ranks from it and build the hierarchy on all these ranks. The first window evaluates each original sentence; shifting the window one place evaluates its uniform type-raise. Homogeneity makes the truth vectors equal. All finite typed axioms and the selected ambiguity instances therefore hold together. Choosing m large enough covers every sort needed by the finite fragment. Many-sorted compactness, equivalently ordinary first-order compactness after encoding sorts, yields
Con(TSTU+typical ambiguity).​
(15)
This is a model existence argument in the ambient set theory; no equality of adjacent type cardinalities is claimed. The gaps between ranks supply atoms, and the ambiguity is about truth of sentences, not a bijection between domains.

A measurable cardinal is an uncountable cardinal κ carrying a nonprincipal κ-complete ultrafilter U: intersections of fewer than κ members of U remain in U. Such an ultrafilter contains no set of size less than κ. Indeed each singleton is absent, and intersecting fewer than κ singleton complements shows that every small set's complement is in U. In particular every tail of κ is in U.
Form the ultrapower of the universe by functions f:κ→V, identifying functions agreeing on a member of U, and interpreting membership coordinatewise modulo U. The Łoś theorem, applied separately to each formula, makes the map x↦[cx​] elementary. Countable completeness makes the ultrapower well-founded: an infinite descending chain [fn+1​]∈[fn​] would give U-large sets witnessing each step, whose countable intersection is nonempty; a coordinate in that intersection would give an infinite descending membership chain in the original universe. The relation is extensional and set-like, so the Mostowski collapse theorem gives a transitive class M and an elementary ultrapower embedding j:V→M.
For each α<κ, every function κ→α is constant modulo U. If no fibre were in U, intersecting the fewer than κ fibre complements would give the empty set in U. Induction on α therefore shows that the collapsed ultrapower ordinal j(α) has precisely the elements β<α, so
j(α)=α(α<κ).
(16)
The identity function id:κ→κ represents an ordinal below j(κ), and every constant α<κ is below it modulo U, since a tail is large. Consequently
κ≤[id]collapse<j(κ),crit(j)=κ.​
(17)
Thus the canonical collapsed embedding is not the identity; its first moved ordinal is κ. For a general measure the identity-function class need not collapse to exactly κ; that stronger equality holds for a normal measure. The argument above needs only its lower bound.
Conversely, suppose j:V→M is elementary, M is transitive, its critical point is κ, and its derived measure is a set, as for the usual definable or amenable class embeddings. Define
U={A⊆κ:κ∈j(A)}.
(18)
Because κ<j(κ), elementary preservation of complements and intersections makes this an ultrafilter. It is nonprincipal since j({α})={α} for α<κ. For a sequence of γ<κ large sets, j fixes the index ordinal γ and takes the intersection to the intersection of their images; κ belongs to every image and hence to the intersection. Thus U is κ-complete. The set-existence qualification excludes treating an arbitrary external class map as a set parameter without justification.
For context, measurability already implies regularity and the strong-limit property. A cofinal sequence of length below κ partitions κ into that many bounded, hence small, pieces; completeness and their absent fibres contradict covering all of κ. If there were κ distinct subsets of some λ<κ, for each coordinate choose the U-large side deciding its membership bit. The intersection of these λ large sets would still be large, but all its indices would label the same subset, so it would have at most one member. This contradiction gives 2λ<κ. Thus the first moved ordinal is an uncountable strongly inaccessible cardinal, in addition to being measurable.

Write θ→(η)λr​ when every λ-coloring of the r-element subsets of θ has a homogeneous subset of order type η. The Erdős-Rado theorem for pairs states, for infinite λ,
(2λ)+⟶(λ+)λ2​.​
(19)
In particular a countable-color partition of pairs from (2ℵ0​)+ has an uncountable homogeneous set. The standard Erdős-Rado theorem for finite arities is
ℶr​(λ)+⟶(λ+)λr+1​,ℶ0​(λ)=λ,ℶr+1​(λ)=2ℶr​(λ).
(20)
We prove it, including the pair case, by constructing an end-homogeneous routing tree.
For a coloring c:[θ]r+1→λ, r≥1, route each vertex β<θ as follows. Given its previously selected increasing ancestors, choose the least γ≤β greater than all those ancestors such that
c(s∪{γ})=c(s∪{β})for every r-subset s of those ancestors.
(21)
The candidate β always qualifies. Select it and stop if it is the minimum; otherwise add the selected γ to the ancestors and continue, including at limit stages. The ancestors are strictly increasing below β, so the process must stop. If a selected ancestor γ is routed separately, its earlier path is the same: its color constraints agree with those of β and the same least choices are forced. Thus the paths define a tree order on the vertices.
A node at depth α is determined by the table of its colors on the r-subsets of its ancestors. Given the table on [α]r, recursively take the least compatible candidate at each depth; at a limit depth use all preceding constraints. This recovers both the path and its final node. Therefore
∣Tα​∣≤λ∣[α]r∣.
(22)
Along any branch, once an r-tuple s of ancestors is fixed, the color c(s∪{β}) is independent of all subsequent choices of β on that branch. This is exactly end-homogeneity.
For the pair case take r=1 and θ=(2λ)+. If all node depths were below λ+, then each level would have size at most λλ≤2λ, and the union of λ+ levels would have size at most 2λ. This contradicts the number of vertices. Hence some node has at least λ+ ancestors. On that branch assign to each ancestor its constant color to all later ancestors. Regularity of λ+ implies that one of the λ colors occurs λ+ times, giving the desired homogeneous set. Its increasing enumeration has a subsequence of order type λ+.
For the higher-arity induction let μ=ℶr−1​(λ), so θ=(2μ)+. At depths below μ+ the same bound is at most λμ≤2μ, forcing a branch of length μ+. End-homogeneity defines a coloring d of its r-tuples by the common color of adjoining a later branch vertex. The previous-arity theorem gives a subset of order type λ+ homogeneous for d, and every (r+1)-tuple from it then has the same color under c. The base case r=0 is the infinite pigeonhole principle at λ+. This proves the full finite-arity statement.
One suitable ordinal partition-bound function is
f(α)=min{β≥α: ∀ nonzero cardinals ν<α, β→(α)ν2​}.
(23)
It is nondecreasing and f(α)≥α. It is total: choose an infinite cardinal λ≥∣α∣; the pair theorem supplies a homogeneous subset of size λ+ for every allowed color number, and its order type contains a copy of α. Thus (2λ)+ is a bound in the displayed minimum.
Let an uncountable cardinal κ be the supremum of a cofinal increasing sequence of iterates of f, with each iterate and its successor still below κ. For every ξ<κ, monotonicity and some later iterate give f(ξ)<κ. Thus the relevant consequence of being such a supremum is
f‘‘κ⊆κ.
(24)
If the iteration already reaches a fixed point, its constant continuation of course has that fixed point as supremum as well. A strictly increasing countable iteration instead has a countable-cofinality supremum and cannot satisfy the uncountable regular tree-property condition below; one must not assume existence of the extra condition from iteration alone.
Here closure under f forces a strong-limit bound. For infinite λ<κ, color distinct binary strings in 2λ by their first differing coordinate. Three strings cannot have all three first-difference coordinates equal, because there are only two bit values at that coordinate. Hence this λ-coloring has no homogeneous triangle, and in particular no homogeneous subset of order type λ+1. Therefore
f(λ+1)>2λ.
(25)
Since λ+1<κ and f(λ+1)<κ, it follows that 2λ<κ for every λ<κ.
Now impose the tree property: every tree of height κ, with nonempty levels of size below κ, has a cofinal branch. If this definition is extended to singular cardinals, it also forces regularity. For a singular κ, take disjoint chains of lengths cofinal in κ, one for each index below cfκ. Every level has at most cfκ<κ nodes and the height is κ, but each branch remains in one shorter chain. A common new root may be added if rooted trees are required. Under the more usual convention the tree property is only defined at regular uncountable cardinals, so regularity is part of the convention instead.
For a coloring c:[κ]2→ν with ν<κ, the routing tree has levels of size at most ν∣α∣<κ by the strong-limit property. If some node has height at least κ, there is already an end-homogeneous branch of that length. Otherwise the tree has height exactly κ: a smaller number of levels of size below κ could not contain its κ nodes, by regularity. The tree property then supplies a cofinal branch. Along it, one of the fewer than κ ancestor colors occurs κ times, again by regularity. Thus κ→(κ)ν2​ for every ν<κ, giving
f(κ)=κ.​
(26)
Moreover the closure argument gives strong limit and the tree argument gives regularity. Thus an uncountable f-closed cardinal with the tree property is strongly inaccessible.
The final printed assertion requires that qualification. The ordinary tree property alone does not imply strong inaccessibility. At ω it is König's infinity lemma and ω is not uncountable. Even when the convention excludes ω, there are relative-consistency models in which ℵ2​ has the tree property, although a successor cardinal is never strongly inaccessible; this result is recalled in the introduction of Friedman, Honzik and Stejskalová. No proof of the bare implication is possible under that standard definition. The preceding paragraphs prove the corrected implication in the actual f-closure setting and the requested fixed-point conclusion, without silently replacing tree property by weak compactness.

We prove the Ehrenfeucht-Mostowski theorem by ordered products of ultrafilters, without using Ramsey's theorem. Choose a Skolem expansion M∗ of the infinite structure and distinct elements b0​,b1​,…. Fix a nonprincipal ultrafilter U on N.
For a finite increasing subset F={i1​<⋯<ir​} of the desired index order I, define the ordered Fubini product of ultrafilters UF​ on NF by
A∈UF​⟺Uni1​​ Uni2​​ ⋯ Unir​​ [(ni​)i∈F​∈A].
(27)
The notation Un P(n) means that the set of n satisfying P belongs to U; the leftmost quantifier is outermost. Upward closure and intersection follow successively at each coordinate, and applying complement at each step proves the ultrafilter dichotomy. Products are ordered; no false claim of symmetry is needed.
Put MF​=(M∗)NF/UF​, with M∅​=M∗. If F⊆G, pullback of a function by coordinate projection induces
σFG​:[f]UF​​⟼[f∘prF​]UG​​.
(28)
For a cylinder condition involving only coordinates in F, deleting the unused ultrafilter quantifiers makes its membership in UG​ exactly its membership in UF​. The Łoś theorem therefore makes σFG​ an elementary embedding, not merely a homomorphism. The projection identities give σGH​σFG​=σFH​.
Take the directed limit of this system: elements from two stages are identified if their images agree at a common larger finite stage, and formulas are evaluated at such a stage. Elementary coherence makes this well-defined. It also makes each stage elementary in the limit: a formula uses finitely many parameters, and an existential witness at a later stage can be pulled back at the level of existential truth because the transition maps are elementary. Denote the limit by N∗.
For each i∈I, let ai​ be the limit image of the coordinate function ni​↦bni​​. These elements are distinct. For i<j, after fixing ni​, equality bni​​=bnj​​ holds for at most one nj​, a set not in U; hence equality fails in the two-coordinate ultrapower and therefore in the limit.
For any increasing i1​<⋯<ir​, Łoś evaluates
N∗⊨φ(ai1​​,…,air​​)⟺Un1​⋯Unr​ [M∗⊨φ(bn1​​,…,bnr​​)].
(29)
The right-hand side depends on the formula and the number of increasing coordinates, not their particular indices. Thus (ai​)i∈I​ is order-indiscernible for every formula of the expanded language simultaneously; no preliminary homogeneous thinning is used. If elements of M were named before expanding, the same computation gives indiscernibility over those names and the initial stage embeds the original structure into the limit.
The Skolem hull of these generators is elementary by the witness property. Transporting the generators by any order automorphism of I transports every term, with well-definedness and relation preservation supplied by the formula equivalence just proved. The inverse transport supplies an inverse automorphism. The ordered-ultrapower construction gives the full Ehrenfeucht–Mostowski model and its order automorphisms without Ramsey's theorem.

A model-theoretic ultralimit is the elementary direct limit of a chain of successive ultrapowers along their diagonal embeddings. We will build two such chains with isomorphic limits. This is not a topological ultrafilter limit and does not require the stronger claim that one ultrapower of each structure is already isomorphic.
First prove the Frayne embedding lemma, including the relative form needed to make the diagrams commute. If C≡D, expand the language by constants naming every element of D, and let ED(D) be its complete elementary diagram. Index by finite subsets s of this diagram. The finitely many constants in s can be interpreted in C so that s holds: existentially quantifying them gives a sentence true in D and hence in C. Choose such interpretations, and give unused constants an arbitrary fixed value in the nonempty domain of C.
For each diagram sentence δ, its cone {s:δ∈s} has the finite intersection property with the other cones. Extend the generated filter to an ultrafilter U. For d∈D, let fd​(s) be its chosen interpretation at coordinate s. The map
e:D⟶CJ/U,d⟼[fd​]U​
(30)
is elementary by Łoś: every formula true of a tuple from D, or its negation, is a diagram sentence and holds on its corresponding cone. In particular distinct named elements stay distinct.
If C⪯D, the construction can keep every constant naming c∈C equal to that same c at every coordinate. For a finite diagram fragment, existentially quantify just the names outside C; the resulting formula with parameters in C is true in D, hence true in C. Thus the finite realizations still exist with all those old names fixed. Consequently
e:D⟶CJ/U is elementary and e(c)=[constant c] for c∈C.​
(31)
This relative extension of the diagonal map is the essential strengthening.
Now let A0​≡B0​. The nonrelative lemma embeds B0​ into an ultrapower A1​ of A0​. Identify the image with a copy of B0​ inside A1​. Since B0​⪯A1​, the relative lemma embeds A1​ into an ultrapower B1​ of B0​ extending its diagonal map. Rename this larger structure so that the displayed copy of A1​ is a literal elementary substructure. Next apply the relative lemma over A1​⪯B1​ to embed B1​ into an ultrapower A2​ of A1​ fixing its diagonal copy. Continue alternately. We obtain a coherent elementary chain
B0​⪯A1​⪯B1​⪯A2​⪯B2​⪯⋯,
(32)
with A0​⪯A1​ as well. Each inclusion An​→An+1​ is, up to these coherent identifications, the diagonal embedding into its ultrapower; the same holds for Bn​→Bn+1​. It is the relative clause, not merely the existence of arbitrary elementary embeddings, which guarantees this.
By the elementary chain theorem, the unions of the two subsequences are elementary limits. They are the same structure: each An​ lies in a subsequent Bn​, and each Bn​ lies in An+1​. Hence the alternating ultrapowers give isomorphic ultralimits construction proves
A0​≡B0​⟹A∞​≅B∞​.​
(33)
Conversely each ultrapower and each elementary direct limit has the same first-order theory as its starting structure. Isomorphic ultralimits therefore imply A0​≡B0​ as well. Thus the conclusion exactly characterizes elementary equivalence at the level of ultralimits.
