A subset U⊆Rn is an open set when every x∈U has some radius r>0 for which B(x,r)⊆U. If a continuous function takes only the values zero and one, continuity at x with tolerance 1/2 gives a neighborhood on which ∣f(y)−f(x)∣<1/2. The two possible values differ by one, so f(y)=f(x) throughout that neighborhood. Thus f is locally constant, and the zero linear map is its derivative, since the difference f(x+h)−f(x) is exactly zero for all sufficiently small h. Hence Dfx​=0 everywhere.

If the endpoints agree the estimate is immediate. No continuity of the derivative is required.
For the finite-line complement, each removed line ℓi​ is closed, so V is open. Because a,b∈/ℓi​, there is a unique affine plane Pi​ containing a and ℓi​, and a unique affine plane Qi​ containing b and ℓi​. Choose c outside the union of these finitely many planes, using the permitted fact about finite plane covers. In particular c∈V. If [a,c] met ℓi​ at a point d, then d=a, and the line through a,d lies in Pi​. Since c is on that same line, it would belong to Pi​, a contradiction. The same argument using Qi​ applies to [c,b]. Thus a and b can be joined in V by these two segments, proving polygonal connectivity of a finite-line complement.
Finally a continuous f:V→{0,1} has zero derivative by the first argument. Apply the proved segment estimate with M=0 separately on [a,c] and [c,b]. It gives f(a)=f(c)=f(b). Since a,b were arbitrary, f is constant on V.
