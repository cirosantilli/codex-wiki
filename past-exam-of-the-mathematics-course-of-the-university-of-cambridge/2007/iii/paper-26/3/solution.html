Use the embedding characterization of a supercompact cardinal: for every cardinal μ≥κ there is an elementary embedding j:V→M into a transitive class with critical point κ, j(κ)>μ and Mμ⊆M. In the Lévy hierarchy, a Σ2​ sentence can be put into the form ∃x∀yθ(x,y) with bounded matrix θ. The same argument allows parameters p∈Vκ​, which the embedding fixes.
Suppose V⊨∃x∀yθ(x,y,p) and choose a witness a. Pick an ordinal λ with a,p∈Vλ​, and a cardinal μ≥κ large enough that μ≥∣Vλ​∣ and μ>λ. Take the corresponding supercompact embedding. Its closure implies Vλ​⊆M: induct on rank, enumerate each set in this rank segment by at most μ elements already in M, and use Mμ⊆M followed by taking the range. Thus a∈M and rank(a)<j(κ).
Bounded formulas are absolute between transitive classes. Since ∀yθ(a,y,p) holds in V, it holds in M and then in the transitive rank segment Vj(κ)M​. This segment contains a,p, so
M⊨Vj(κ)​⊨∃x∀yθ(x,y,p).
(3)
Apply elementarity to the first-order assertion that this sentence holds in the indicated cumulative hierarchy level, and use j(p)=p. We obtain the supercompact Sigma-two downward reflection conclusion
V⊨σ(p)⟹Vκ​⊨σ(p)(σ∈Σ2​, p∈Vκ​).​
(4)
The closure requirement is used to put the original witness into the target; elementarity alone would not do that.
