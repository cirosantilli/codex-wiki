View a set family as a set of vertices of the Boolean lattice. The operation Di​ acts independently on each pair {S,S∪{i}}, where i∈/S: it keeps a full or empty pair and moves a sole upper member down. Thus downward coordinate compression preserves cardinality.
Fix a tracing set Y. If i∈/Y, compression leaves the trace of a set family on Y unchanged. If i∈Y, write B0​,B1​⊆P(Y∖{i}) for the two sections of the old trace, according to absence or presence of i. The absent-i section of the new trace is B0​∪B1​. Its present-i section is contained in B0​∩B1​: an upper member survives only when its lower partner was also present in the original family. Consequently
∣(Di​F)∣Y​∣≤∣B0​∪B1​∣+∣B0​∩B1​∣=∣B0​∣+∣B1​∣=∣F∣Y​∣.​
(28)
In particular, downward coordinate compression cannot create new set shattering.
Repeatedly apply any changing downward coordinate compression. Each change strictly decreases ∑A∈F​∣A∣, so the process terminates at a down-set D with the same cardinality and with no larger trace on any Y. The Sauer-Shelah lemma says that a family shattering no k-element set satisfies
∣F∣≤j=0∑k−1​(jn​)(1≤k≤n).​
(29)
Indeed, the compressed down-set also shatters no k-element set. If it contained any member of size at least k, all subsets of a k-subset of that member would belong to the down-set, contradicting this restriction. Every member therefore has size at most k−1, giving the bound. Equivalently, VC dimension at most d gives size at most ∑j=0d​(jn​). The family of all sets of size at most d attains this bound.
There is a different extremal example when n≥3. Toggle a fixed coordinate in the family of sets of size at most two:
F={B△{1}:B⊆[n], ∣B∣≤2}.​
(30)
The symmetric difference is a bijection, so this family has 1+n+(2n​) members. On each tracing set Y, it simply toggles coordinate 1 if 1∈Y; thus it preserves trace cardinality and set shattering. A triple has seven trace patterns, not eight. The new family differs from the original one because it contains {1,2,3}. For n≤2 the specified cardinality is 2n, so the entire power set is the unique family of that size; the different example requires n≥3.
For the final bound, let ei​(F) count pairs S,S∪{i} both in the family. Deleting coordinate i identifies precisely these pairs, so
∣F∣[n]∖{i}​∣=∣F∣−ei​(F).
(31)
Suppose every deletion lost at least two members, so ei​(F)≥2 for every i. The trace inequality and preservation of cardinality show that ei​(D)≥ei​(F) after downward coordinate compression. The down-set D contains the empty set and every singleton. For each i, its second edge in direction i has an upper endpoint of size at least two. Downward closure then supplies a pair {i,j}∈D. The pairs in D therefore cover all n coordinates, so at least ⌈n/2⌉ pairs are needed. This proves two cube edges in every direction force many vertices:
∣F∣=∣D∣≥1+n+⌈n/2⌉=⌈3n/2⌉+1.
(32)
Taking the contrapositive gives the required answer:
∣F∣≤⌈3n/2⌉ ⟹ ∃i: ∣F∣[n]∖{i}​∣≥∣F∣−1.​
(33)
The threshold is sharp for every n≥2. Take the empty set, all singletons and ⌈n/2⌉ pairs covering every coordinate. For even n, use the disjoint pairs 12,34,…,(n−1)n; for odd n, pair the first n−1 coordinates and add (n−1)n. This down-set has exactly ⌈3n/2⌉+1 members and at least two edges in every direction, so every (n−1)-coordinate trace has size at most ∣F∣−2. Adding further members preserves those pairs and therefore preserves the failure whenever a larger cardinality is feasible. For n=1, the putative counterexample cardinality is three, exceeding the size of the Boolean lattice; the sharpness construction naturally starts at n=2.
