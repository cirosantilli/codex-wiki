This formula assumes the local polynomial Gram matrix XTWX is invertible. It is invertible whenever at least p+1 distinct sites have positive weights: a nonzero degree-p polynomial cannot vanish at all of them. With fixed p, a nonzero continuous regression kernel, and nh→∞, this condition holds eventually at the target points considered here. Using weights h−1K((xi​−t)/h) instead gives exactly the same fit.
Use the usual unit-integral normalization μ0​(K)=1. A regression kernel need not intrinsically have unit integral, but multiplying all weights by a positive constant leaves local polynomial regression unchanged. With unnormalized raw moments the interior coefficient below is μ2​(K)/μ0​(K); the version written using μ2​(K) alone requires this normalization. A zero regression kernel cannot define an estimator.
