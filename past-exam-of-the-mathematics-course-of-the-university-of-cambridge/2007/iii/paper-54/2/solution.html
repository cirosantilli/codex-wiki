In conformal gauge, a free closed bosonic string has (∂τ2​−∂σ2​)Xμ=0, periodicity in σ, and the two Virasoro constraints (X˙±X′)2=0. Its left- and right-moving string oscillator families have independent Virasoro generators Ln​ and Ln​. In old covariant string quantization, a physical string state obeys
Ln>0​∣Φ⟩=Ln>0​∣Φ⟩=0,(L0​−a)∣Φ⟩=(L0​−a)∣Φ⟩=0,
(12)
with a=1 in the critical bosonic string theory. The two zero-mode conditions also impose closed-string level matching. For an open string, keep just one string oscillator family. Negative-mode constraints are adjoints on bras, not additional annihilation conditions on physical string states.
A spurious string state is a Virasoro descendant orthogonal to every physical string state: if ∣s⟩=∑n>0​L−n​∣χn​⟩, then ⟨Φ∣s⟩=0 follows from Ln​∣Φ⟩=0 and Ln†​=L−n​. A null string state is a spurious state that is itself physical. It consequently has zero norm and is removed in the null-state quotient of a string. The calculations below concern one string oscillator family and use
[Lm​,Ln​]=(m−n)Lm+n​+12d​(m3−m)δm+n,0​,[Lm​,αnμ​]=−nαm+nμ​.
(13)
For ∣n1​⟩=L−1​∣χ1​⟩ with L0​∣χ1​⟩=0 and all positive modes zero, L0​∣n1​⟩=∣n1​⟩. Also
L1​∣n1​⟩=2L0​∣χ1​⟩=0,Lm​∣n1​⟩=(m+1)Lm−1​∣χ1​⟩=0(m≥2).
(14)
It is therefore physical for string intercept one and spurious by construction. In particular ∥n1​∥2=⟨χ1​∣2L0​∣χ1​⟩=0. This proves the requested level-one descendant is null.
For the scalar descendant, write ∣vb​⟩=(L−2​+bL−12​)∣χ2​⟩ with L0​∣χ2​⟩=−∣χ2​⟩ and positive modes zero. Direct commutation gives
L0​∣vb​⟩=∣vb​⟩,L1​∣vb​⟩=(3−2b)L−1​∣χ2​⟩,L2​∣vb​⟩=(2d​−4−6b)∣χ2​⟩.
(15)
For instance [L1​,L−12​]∣χ2​⟩=−2L−1​∣χ2​⟩ and L2​L−12​∣χ2​⟩=−6∣χ2​⟩. Modes m≥3 annihilate ∣vb​⟩ because every remaining positive mode annihilates its parent. Hence the physical scalar descendant requires b=3/2 and d=26:
∣n2​⟩=(L−2​+23​L−12​)∣χ2​⟩is null at d=26.​
(16)
It is spurious, so physicality also proves orthogonality and zero norm without an extra positivity assumption.
The printed coefficient 3/4 does not give this null string state. It instead gives L1​∣v3/4​⟩=23​L−1​∣χ2​⟩, generally nonzero. For a normalized highest-weight parent with weight −1 at d=26, the descendant Gram matrix is
(⟨L−2​χ2​∣L−2​χ2​⟩⟨L−12​χ2​∣L−2​χ2​⟩​⟨L−2​χ2​∣L−12​χ2​⟩⟨L−12​χ2​∣L−12​χ2​⟩​)=(9−6​−64​).
(17)
Thus the printed vector has norm 9/4, whereas the corrected vector has norm zero. This is a genuine PDF coefficient error. Away from 26 dimensions even the corrected coefficient does not give the claimed physical null string state; the remaining condition is L2​∣v3/2​⟩=(d−26)∣χ2​⟩/2.
The level-two open string state also needs a source correction: its vector string oscillator must be α−2μ​, not the printed α−1μ​. A single α−1​ has level one and cannot share the stated mass-shell condition with the two-α−1​ term. Put qμ=α0μ​=2α′​pμ, and write the genuine level-two state as
∣ϕ⟩=(aμν​α−1μ​α−1ν​+bμ​α−2μ​)∣p⟩,aμν​=aνμ​.
(18)
The mass-shell condition L0​=1 gives α′p2+2=1, so q2=−2. The commutators above give
L1​∣ϕ⟩=2(qμaμν​+bν​)α−1ν​∣p⟩,L2​∣ϕ⟩=(aμμ​+2q⋅b)∣p⟩.
(19)
For the second formula, the contraction from the two α−1​ operators is exactly aμμ​, not twice that value. Modes m>2 vanish automatically. We have derived
bν​=−qμaμν​,t:=aμμ​=−2q⋅b.​
(20)
The coefficient formulas in the question are consequently consistent after the string oscillator correction and with d=26.
To prove the full level-two open-string polarization decomposition, not merely check one candidate, define
Aμ​=21​(bμ​−4t​qμ​),cμν​=aμν​−20t​(3qμ​qν​+ημν​)−qμ​Aν​−qν​Aμ​.
(21)
The constraints give q⋅b=−t/2 and therefore q⋅A=0. Contracting c with q gives
qμcμν​=−bν​+4t​qν​+2Aν​=0.
(22)
Its trace is t−t(26+3q2)/20−2q⋅A=0. Thus c is symmetric, traceless and transverse. Conversely, arbitrary t, a vector A with q⋅A=0, and such a tensor c give
aμν​=20t​(3qμ​qν​+ημν​)+qμ​Aν​+qν​Aμ​+cμν​,bμ​=4t​qμ​+2Aμ​,​
(23)
and direct contraction verifies both constraints. The number 20 uses d=26; it would not reproduce the same unrestricted trace in arbitrary dimension.
Finally the two unphysical pieces are precisely the descendants already proved null. The vector part is
∣n1​⟩=L−1​(2A⋅α−1​∣p⟩),
(24)
whose parent has L0​=0 and all positive modes zero because q⋅A=0. For the scalar part use
L−2​∣p⟩=(q⋅α−2​+21​α−1​⋅α−1​)∣p⟩,L−12​∣p⟩=((q⋅α−1​)2+q⋅α−2​)∣p⟩.
(25)
Then
∣n2​⟩=10t​(L−2​+23​L−12​)∣p⟩
(26)
has exactly the scalar tensor t(3qμ​qν​+ημν​)/20 and vector tqμ​/4. The momentum vacuum has L0​=−1 and positive modes zero, as required. Hence
∣ϕ⟩=cμν​α−1μ​α−1ν​∣p⟩+∣n1​⟩+∣n2​⟩.​
(27)
The physical quotient contains only the transverse traceless tensor. Its massive little-group space has dimension 25⋅26/2−1=324, agreeing with the light-cone gauge in string theory count 24⋅25/2+24=324 at level two.
