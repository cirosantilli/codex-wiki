Use ⊕ for addition modulo two, or exclusive or. The key is to write the known Boolean function as an XOR of products of locally computable bits. An explicit separated Boolean decomposition avoids any need to assume a particular circuit for the function. For every possible Alice input ξ∈{0,1}m, put
uξ​(x)=1{x=ξ}​,vξ​(y)=f(ξ,y).
(19)
Alice can compute the first bit from her actual input and the public label ξ; Bob can compute the second bit from his own input because ξ and the full function are public. Exactly one of the indicators is one, namely the one with ξ=x. Hence
f(x,y)=ξ∈{0,1}m⨁​uξ​(x)vξ​(y).​
(20)
For each label ξ, invoke one independent Popescu–Rohrlich box with inputs uξ​(x) and vξ​(y). Denote its outputs by aξ​ and bξ​. By the given correlation, aξ​⊕bξ​=uξ​vξ​. Alice locally forms A=⨁ξ​aξ​, and Bob locally forms B=⨁ξ​bξ​. Taking the XOR of all box constraints yields
A⊕B=⨁ξ​(aξ​⊕bξ​)=⨁ξ​uξ​(x)vξ​(y)=f(x,y).
(21)
Thus the protocol is
Alice sends the single bit A;Bob outputs A⊕B=f(x,y).​
(22)
It succeeds exactly for every input and every allowed sequence of box outputs. Randomness of the individual outputs introduces no error because each parity relation is exact. All box calls can be made before the message, with no extra classical communication. This proves one-bit computation using Popescu–Rohrlich boxes.
The truth-table construction uses 2m PR boxes. If Bob's input is shorter, use the equally valid decomposition f(x,y)=⨁η∈{0,1}n​f(x,η)1{y=η}​. Alice computes the first factor, Bob the indicator, and Alice still sends her output parity. Therefore at most 2min(m,n) boxes are enough. This is a bound on box use, not on local computational work; the communication complexity remains one bit.
Another standard route is the algebraic normal form over the two-element field:
f(x,y)=⨁I⊆{1,…,m}, J⊆{1,…,n}​cIJ​(∏i∈I​xi​)(∏j∈J​yj​),cIJ​∈{0,1}.
(23)
The empty products are one. For completeness, this representation follows by induction on the number of bits from f(z′,zd​)=f(z′,0)⊕zd​[f(z′,0)⊕f(z′,1)], which adds a new variable only to its corresponding coefficients. Each nonzero monomial supplies one local product to each party and can be evaluated in distributed parity form by one PR box. Terms depending on only one party can instead be included directly in that party's final parity; the constant may be assigned to either side. For example, a single cross-product needs one box, whereas f(x,y)=x1​⊕y1​ needs no boxes and just the one-bit message x1​.
Finally, the scheme does not make the boxes themselves signalling devices. At any fixed box inputs, the two allowed output pairs give each party an individually uniform bit, independent of the distant input. Independence across box calls makes Bob's entire uncommunicated output string uniform, for any Alice input. Without A he generally cannot identify the answer. The communicated parity combines with the nonlocal correlations to reveal it; it does not contradict the uniform local marginals of these no-signalling boxes.
