Let c:N→{1,…,r} be the given finite colouring, with N={1,2,…}. Give each unordered pair {a,b} the colour c(a+b). The infinite Ramsey theorem for r-sets, in its two-element case, gives an infinite homogeneous set for a colouring X. Enumerate it as x1​<x2​<⋯. Every distinct-index sum xi​+xj​ has the common pair colour, so
{xi​+xj​:i=j} is monochromatic.​
(1)
This application of the infinite Ramsey theorem for r-sets uses only unordered pairs.

Use the alternating dyadic colouring excludes symmetric weighted pair sums construction:
c(n)=⌊log2​n⌋(mod2).​
(3)
Thus consecutive dyadic intervals [2k,2k+1) have opposite colours. Suppose an increasing infinite sequence X=(xj​) had all its distinct-index weighted sums in one colour class. Set δ(y)=2⌊log2​y⌋+1−y, the distance to the next strictly larger power of 2.
If δ is unbounded on X, fix a term x and choose a later term y>2x with δ(y)>2x. Put L=2⌊log2​y⌋, so y=2L−δ(y). Then
L≤y+2x<2L,2L≤2y+x=4L−2δ(y)+x<4L.
(4)
These two weighted sums lie in adjacent dyadic intervals and therefore have opposite colours.
If δ is bounded by D on X, choose a term x>2D and a later term y>2x. With the same L, we have
2L<y+2x=2L−δ(y)+2x<4L,4L<2y+x=4L−2δ(y)+x<8L.
(5)
For the upper bounds, y+2x<2y<4L and 2y+x<25​y<5L<8L. These weighted sums also lie in adjacent dyadic intervals. In both cases they are xi​+2xj​ and xj​+2xi​ for two distinct indices, contradicting the common colour class. Hence the symmetric distinct-index conclusion is false, even for this two-colour finite colouring.

Every ultrafilter contains exactly one cell of any finite set partition. Indeed, two disjoint cells cannot both belong to a proper filter, while if none belonged to the ultrafilter, all their complements would belong to it and their finite intersection would be empty.
Apply this property to the two colour classes in (iii). One belongs to any proposed ultrafilter, but neither contains a symmetric weighted-pair configuration from an increasing infinite sequence. This contradicts the proposed property of every member. Therefore no such ultrafilter exists.

Van der Waerden theorem says that for every pair of positive integers r,k there is W(r,k) such that every finite colouring of [W(r,k)]={1,…,W(r,k)} using at most r colours contains a monochromatic arithmetic progression of length k and positive common difference. Consequently every finite colouring of N contains arbitrarily long monochromatic arithmetic progressions.
Here is a colour-focusing proof of Van der Waerden theorem. Induct on k, simultaneously for all r. For k=1, take W(r,1)=1. Suppose W(R,k) exists for every number of colours R, and fix r. We will construct finite bounds Ft​, 1≤t≤r, with the following property: every finite colouring of [Ft​] using at most r colours contains either a monochromatic length-(k+1) arithmetic progression, or t length-k arithmetic progressions of pairwise distinct colours, all focused at the same point f∈[Ft​]. Specifically, their terms are
f−di​,f−2di​,…,f−kdi​,di​>0,1≤i≤t.
(6)
“Focused” means that adjoining f completes the corresponding length-(k+1) arithmetic progression if f has its colour.
For t=1, put F1​=2W(r,k). Find a monochromatic length-k arithmetic progression in the first W(r,k) points. Its next point is at most 2W(r,k) and supplies the focus. For k=1, give the selected singleton common difference 1.
Suppose Ft​=N has been constructed. Set
M=W(rN,k),Ft+1​=2NM.
(7)
Divide [2NM] into 2M consecutive blocks of length N. Colour the first M block indices by their full colour profiles, that is, the ordered list of their N colours. There are at most rN profiles, so the induction hypothesis on k gives equally profiled blocks with indices
j0​,j0​+D,…,j0​+(k−1)D.
(8)
When k=1, choose D=1. Otherwise D>0 and j0​+kD≤2M, since the last selected block is at most M and D≤M.
Assume the original finite colouring contains no monochromatic length-(k+1) arithmetic progression. Applying the property of Ft​ to the common profile gives t focused length-k arithmetic progressions at a position f, with common differences di​ and distinct colours qi​. The colour q of position f differs from every qi​: otherwise the profile already contains a length-(k+1) monochromatic arithmetic progression, and so does any selected block.
Put j∗​=j0​+kD and F=N(j∗​−1)+f, a point in the original interval. For 1≤h≤k, the point
F−h(ND+di​)=N(j∗​−hD−1)+(f−hdi​)
(9)
lies in a selected block at profile position f−hdi​, so has colour qi​. Similarly F−hND has colour q. Thus t+1 length-k arithmetic progressions of distinct colours focus at F. This proves the step in t. At t=r, the focus necessarily has the colour of one of the r progressions, giving a monochromatic length-(k+1) arithmetic progression. Hence W(r,k+1) exists, completing the mathematical induction and the proof of Van der Waerden theorem.
For the partition regularity deduction we first prove a strengthened progression lemma, the Brauer progression theorem: for positive r,s,L with L≥2, there is B(r,s,L) such that every finite colouring of [B(r,s,L)] using at most r colours contains a monochromatic set
{sd,a,a+d,…,a+(L−1)d},a,d>0.
(10)
Induct on r. For r=1, take B(1,s,L)=max(s,L) and a=d=1. Given the result for r−1, put
N=B(r−1,s,L),K=(L−1)N+1,W=W(r,K),B(r,s,L)=max(W,sNW).
(11)
Van der Waerden theorem supplies a colour-q arithmetic progression a+jd0​, 0≤j<K, inside [W]. If some sjd0​, 1≤j≤N, also has colour q, take d=jd0​ and use the L terms a,a+jd0​,…,a+(L−1)jd0​. They are in the progression because (L−1)j≤K−1.
Otherwise the integers sjd0​, 1≤j≤N, use at most r−1 colours. Colour j∈[N] by the colour of sjd0​ and apply the induction hypothesis. It supplies a monochromatic set {se,b,b+e,…,b+(L−1)e}. Multiplying by sd0​ gives the required configuration with a=sd0​b and d=sd0​e: its distinguished member is s2d0​e=sd. All of these points are at most sNd0​≤sNW, so the finite bound is valid. This proves the Brauer progression theorem using only the just-proved Van der Waerden theorem.
A row is a partition regular matrix over the positive integers if every finite colouring of N admits a positive vector x whose coordinates have one colour and whose product with the row is zero. Coordinates may repeat. Since the coefficients are rational numbers, multiplying them by a common positive denominator leaves the equation and every zero subset sum unchanged, so write the row as nonzero integer coefficients b1​,…,bn​.
To prove necessity, suppose no nonempty subset of the bi​ sums to zero. Choose a prime p>∑i​∣bi​∣ and use the last nonzero digit coloring
c(x)=p−vp​(x)x(modp) ∈Fp×​,
(12)
where vp​ is the P-adic valuation. If positive xi​ all had the same colour u and satisfied ∑i​bi​xi​=0, let m=mini​vp​(xi​) and I={i:vp​(xi​)=m}. After division by pm and reduction modulo p, the equation becomes
u∑i∈I​bi​=0in Fp​.
(13)
As u=0, this says p∣∑i∈I​bi​. The latter sum is nonzero and has absolute value at most ∑i​∣bi​∣<p, a contradiction. This explicitly proves the necessary obstruction without invoking a general partition regularity criterion.
Conversely, suppose ∅=I⊆{1,…,n} and ∑i∈I​bi​=0. Select an index j∈I, and put
S=∑i∈/I​bi​,s=∣bj​∣,q=−bj​sS​∈Z,u=max(0,−q),L=max(2,∣q∣+1).
(14)
For any finite colouring, the Brauer progression theorem gives one-coloured {sd,a,a+d,…,a+(L−1)d}. The indices u and u+q both lie between 0 and L−1. Define positive, same-coloured coordinates by
xi​=⎩⎨⎧​sd,a+ud,a+(u+q)d,​i∈/I,i∈I∖{j},i=j.​
(15)
Then
∑i​bi​xi​=(a+ud)∑i∈I​bi​+d(bj​q+sS)=0.
(16)
This also covers I equal to the whole index set and q=0. Reversing the clearing of denominators proves the exact criterion:
(a1​,…,an​) is partition regular⟺∃∅=I⊆{1,…,n}: i∈I∑​ai​=0.​
(17)

An ultrafilter on N={1,2,…} is a family p⊆P(N) satisfying the proper filter axioms: N∈p, ∅∈/p, closure under finite intersections, and upward closure under inclusion. In addition, for every A⊆N, exactly one of A and Ac belongs to p. Equivalently, an ultrafilter is a maximal proper filter. The principal ultrafilter at n consists of all subsets containing n; an ultrafilter not of this form is a nonprincipal ultrafilter.
To prove existence, start with the cofinite filter and order the proper filters containing it by inclusion. The union of a chain is still a proper filter: finitely many of its members lie in one filter of the chain, and no constituent contains the empty set. Thus Zorn lemma supplies a maximal such filter p. If A∈/p, adjoining A cannot generate a proper filter; otherwise maximality fails. Consequently some B∈p has B∩A=∅, so Ac∈p by upward closure. This proves the ultrafilter alternative. No finite A can belong to p, because Ac is cofinite and already belongs to p. In particular p contains no singleton and is a nonprincipal ultrafilter. The same argument, starting from any proper filter, proves the ultrafilter lemma used below.
Define βN to be the set of all ultrafilters on N, with basic open sets
A={p∈βN:A∈p},A⊆N.
(18)
They form a topological basis because N=βN and A∩B=A∩B. Moreover (A)c=Ac, so they are clopen sets. This is the compact Hausdorff topology on ultrafilters. If p=q, some A belongs to p but not q, and then A and Ac are disjoint open neighbourhoods of the two points. Thus βN is Hausdorff.
For compactness, take an open cover and refine it by basic open sets Aλ​​. If no finite subfamily covers, then for every finite collection of indices the intersection ⋂Aλc​ is nonempty. Indeed, if that intersection were empty, the corresponding Aλ​ would cover N, and every ultrafilter would contain at least one of them by the finite ultrafilter alternative. The complements therefore have the finite intersection property and generate a proper filter. Extend it to an ultrafilter q by the proved ultrafilter lemma. Then Aλc​∈q for every λ, so q belongs to none of the covering Aλ​​, a contradiction. A finite basic subcover lies inside a finite subcover of the original cover. Hence
βN is compact and Hausdorff.​
(19)
The map n↦pn​, where pn​ is the principal ultrafilter at n, identifies the discrete natural numbers with a dense subset: any nonempty A has A=∅ and contains pn​ for n∈A.
Hindman theorem states that every finite colouring of the positive integers admits an increasing sequence x1​<x2​<⋯ whose finite-sums set
FS(x1​,x2​,…)={∑i∈F​xi​:∅=F⊆N finite}
(20)
is monochromatic. We now give the Idempotent-ultrafilter proof of Hindman's theorem. For A⊆N, write A−x={y∈N:x+y∈A}. The addition on βN is defined by
A∈p+q⟺{x∈N:A−x∈q}∈p.
(21)
Take an idempotent ultrafilter on the natural numbers p, whose existence is allowed, so p+p=p. It is a nonprincipal ultrafilter: addition of principal points is pm​+pn​=pm+n​, whereas no positive integer satisfies 2m=m.
Exactly one colour class A belongs to p. Define
A∗=A∩{x:A−x∈p}.
(22)
By idempotence, A∗∈p. The idempotent-ultrafilter star-set lemma needed for the recursion is that A∗−x∈p whenever x∈A∗. To prove it, put D=A−x∈p. Idempotence again gives
D∗=D∩{y:D−y∈p}∈p.
(23)
For y∈D∗, we have x+y∈A and A−(x+y)=D−y∈p, hence x+y∈A∗. Thus D∗⊆A∗−x, proving the lemma by upward closure.
Choose x1​∈A∗. Suppose Fn​=FS(x1​,…,xn​)⊆A∗ has been constructed. Every factor of
A∗∩⋂s∈Fn​​(A∗−s)∩{z:z>∑i=1n​xi​}
(24)
belongs to p: the translate factors do by the just-proved lemma, and the last factor does because it is cofinite and p is a nonprincipal ultrafilter. The finite intersection is therefore nonempty. Choose xn+1​ in it. Then xn+1​ and every s+xn+1​ with s∈Fn​ lie in A∗, so Fn+1​⊆A∗. This constructs a strictly increasing sequence, indeed xn+1​>∑i≤n​xi​, and proves Hindman theorem.
Finally apply Hindman theorem to obtain a monochromatic finite-sums set FS(y1​,y2​,…). We construct a divisibility chain inside a finite-sums set using disjoint successive blocks of indices. Start with x1​=y1​. If xi​=m, take 2m unused terms after all indices used so far, and split them into two groups of m consecutive terms. In each group its m+1 partial sums, including 0, contain two in the same congruence class modulo m by the pigeonhole principle. Their difference is a nonempty consecutive sum divisible by m, and positivity makes it at least m. Let xi+1​ be the sum of these two selected sums. Then m∣xi+1​ and xi+1​≥2m>m.
The index set defining xi+1​ lies strictly after all previous index sets. Discard the other terms in these two groups before continuing. Because the chosen index sets are disjoint, every finite sum of distinct xi​ is a finite sum of distinct yj​, retaining the same colour. Therefore
x1​<x2​<⋯,xi​∣xi+1​ for every i,FS(x1​,x2​,…) is monochromatic.​
(25)

Write [M]ω for the set of all infinite subsets of M. A family Y⊆[N]ω is a Ramsey family in the homogeneous-cone sense if there is an infinite M such that either [M]ω⊆Y or [M]ω∩Y=∅. Thus membership in Y is constant on an infinite homogeneous cone. We will prove the stronger version for open families: such a cone exists inside every prescribed infinite ground set, as in the definition of a Ramsey set of infinite subsets.
The symbols in the question refer to the ordinary topology on infinite subsets τ and the Ellentuck topology ∗. For a finite set s, let
[s]={X∈[N]ω:s is the initial segment of X}.
(26)
These sets form a topological basis for τ, equivalently the subspace topology inherited from the product topology on {0,1}N. For an infinite A with maxs<minA, the sets
[s,A]={s∪B:B∈[A]ω}
(27)
form a topological basis for ∗; take max∅=0. In particular [s]=[s,{n:n>maxs}], so ∗ is finer than τ.
For a non-Ramsey example use the finite-symmetric-difference parity colouring. On [N]ω, define the equivalence relation X∼Z if their symmetric difference X△Z is finite. By the axiom of choice, select a representative R in every equivalence class. Give X the colour
c(X)=∣X△RX​∣(mod2),
(28)
where RX​ is its class representative. Deleting one point stays in the same class and toggles the parity. Thus for every infinite M, the sets M and M∖{minM} are both in [M]ω but have opposite colours. Either colour class, regarded as a family Y, is therefore not Ramsey.
Now let U be τ-open. We prove that for every infinite A0​ there is an infinite C⊆A0​ with [C]ω⊆U or [C]ω∩U=∅. The proof uses acceptance and rejection of finite stems, which we define explicitly. For a finite stem s and an infinite tail A above maxs, say that A accepts s if [s,A]⊆U, and rejects s if no infinite subset of A accepts s. Both properties persist on taking infinite subsets. Every tail has an infinite subset that decides s: take an accepting subset if one exists, and otherwise it already rejects s.
First thin A0​ to decide the empty stem. Then construct b1​<b2​<⋯ and nested infinite tails. At step n, choose bn​ from the current tail, discard its points at most bn​, and successively thin what remains to decide every stem s⊆{b1​,…,bn​}. There are only finitely many such stems, so an infinite tail remains. Let B={b1​,b2​,…} and write B/s={b∈B:b>maxs}. For every finite s⊆B, the tail B/s decides s, since it lies in the tail obtained at the stage when the largest point of s was selected. The empty stem is also decided. This is deciding all finite stems by fusion.
If B accepts the empty stem, then [B]ω⊆U, as required. Otherwise B rejects it. We need the finitely many accepting extensions of a rejected stem observation. Suppose a tail B/s rejects s. Only finitely many a∈B/s can have B/a accepting s∪{a}. Indeed, if infinitely many such a formed a set D, every member of [s,D] would have some first new point a and all later points in B/a, hence would lie in U. This would make D an accepting subset of B/s, contradicting rejection.
Choose c1​<c2​<⋯ in B recursively so that for every finite s⊆{c1​,…,cn​}, the tail B/s rejects s. The empty stem satisfies this initially. At the next step, each of the finitely many previous stems has only finitely many accepting one-point extensions by the observation. Choose cn+1​ larger than all previous points and outside all those finite exceptional sets. The first fusion ensured that the tail for every new stem decides it; since it does not accept it, it rejects it. This maintains the recursion.
Put C={c1​,c2​,…}. If some X∈[C]ω belonged to U, ordinary openness would give a finite initial segment s of X with [s]⊆U. In particular [s,C/s]⊆U. But C/s is an infinite subset of B/s, which rejects s, a contradiction. Hence [C]ω∩U=∅. We have proved
Every τ-open family is Ramsey, even inside every infinite ground set.​

Take the cone on an infinite coinfinite ground set
E=[2N]ω.​
(30)
It is ∗-open because E=[∅,2N] is a basic open set of the Ellentuck topology. It is not τ-open: if X∈E, every ordinary basic neighbourhood [s] of X contains an infinite extension of s having an odd point larger than maxs. That extension is outside E. Therefore no point of E has an ordinary open neighbourhood contained in E.

The same cone on an infinite coinfinite ground set works:
E=[2N]ω.​
(31)
It is τ-closed: a set outside E has an odd point, and the ordinary neighbourhood given by its initial segment through that point remains outside E. Its τ-interior is empty, since every ordinary basic open set admits an extension having an odd point. Hence its ordinary closure equals itself and has empty interior, proving that it is a τ-nowhere dense set.
In the Ellentuck topology, however, E is itself a nonempty open set. Its ∗-closure therefore has nonempty ∗-interior, so E is not ∗-nowhere dense.

Let
D={X⊆N:X is cofinite}.​
(32)
This is the dense countable family of cofinite infinite subsets. Every ordinary basic open set [s] contains the cofinite set s∪{n:n>maxs}. Thus D is τ-dense: its ordinary closure is the whole space, so it is not τ-nowhere dense.
It is ∗-closed. Indeed, for an infinite noncofinite X, the Ellentuck topology neighbourhood [∅,X] contains only noncofinite sets, because every subset of X misses the infinite complement of X. This neighbourhood is disjoint from D.
Finally every nonempty basic ∗-open set [s,A] contains a smaller basic ∗-open set disjoint from D: enumerate A and let B consist of every second point. Then A∖B is infinite, and [s,B]⊆[s,A] contains no cofinite set. In particular D has empty ∗-interior. As it is already ∗-closed, its ∗-closure has empty ∗-interior, proving that it is ∗-nowhere dense.
