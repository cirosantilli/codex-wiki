Use binary codes, so the polynomial modulus is f(X)=XN+1=XN−1 in F2​[X]. A cyclic code C is a linear subspace of F2N​ invariant under the cyclic shift (a0​,…,aN−1​)↦(aN−1​,a0​,…,aN−2​). Identify a word with a(X)=∑i=0N−1​ai​Xi. Addition is coefficientwise, and multiplication is polynomial multiplication reduced modulo f. In the quotient ring
R=F2​[X]/(f),
(31)
multiplication by X is exactly that cyclic shift. Closure under this map and linear combinations gives closure under multiplication by every polynomial, so a cyclic code is an ideal of R. Conversely, an ideal is a linear subspace closed under multiplication by X, proving the correspondence.
Take the inverse image of C in F2​[X]. This is an ideal containing (f). The polynomial division algorithm shows directly that it has a unique monic generator g: choose a nonzero polynomial of least polynomial degree and divide any other member by it; the remainder is in the ideal and has smaller polynomial degree, so must vanish. If two monic generators existed, mutual divisibility would make them equal. Because f belongs to the ideal, g∣f. Conversely every monic divisor of f defines an ideal of R. Thus the generator polynomial of a cyclic code satisfies
C=(g)⊆R,g∣XN+1.​
(32)
For a nonzero code, g is its nonzero polynomial representative of least polynomial degree. For the zero code, use g=f, whose residue in R is zero; this standard convention covers that endpoint despite its having no nonzero codeword.
Let r=degg and k=N−r, and put h=f/g. Every codeword has a unique representation bg with degb<k: dividing an arbitrary multiplier by h does not change its product with g modulo f. The words g,Xg,…,Xk−1g have distinct leading degrees below N and are independent. Consequently
dimC=N−degg=k.​
(33)
The statement remains valid for the zero code, with an empty basis, and the full code, with g=1.
For length 16, characteristic two gives X16+1=(X+1)16. Its only monic divisors are (X+1)j for 0≤j≤16. Hence all binary cyclic codes of length a power of two in this case are
Cj​=((X+1)j),dimCj​=16−j,0≤j≤16.​
(34)
There are exactly 17 codes, forming the chain C16​⊂C15​⊂⋯⊂C0​. This is a repeated-root cyclic code situation, so it would be incorrect to count just square-free factors. Their canonical check polynomials of a cyclic code are (X+1)16−j. An explicit expansion of each generator is ∏b:bit b of j is 1​(1+X2b).
The canonical check polynomial of a cyclic code is
h(X)=g(X)XN+1​,g(X)h(X)=XN+1.​
(35)
Indeed ah≡0(modf) means f∣ah. Since f=gh, cancellation in the polynomial ring gives g∣a, exactly code membership. No coprimality of g and h is needed, including for length 16.
There is a normalization qualification in the printed definition. The kernel condition alone does not force the supplied polynomial h to equal this canonical h. If d=gcd(f,h), write f=df1​ and h=dh1​ with gcd(f1​,h1​)=1. Then f∣ah holds exactly when f1​∣a, so its kernel is the ideal generated by f/d. Therefore
ker(a↦ahmodf)=C⟺gcd(f,h)=f/g.​
(36)
Equivalently h=hu with gcd(u,g)=1. Requiring the monic divisor of f selects the canonical check polynomial of a cyclic code. For example Xh gives the same kernel as h, since X is a unit modulo f, but is generally a different polynomial. Given any permitted h, taking gcd(f,h) recovers the canonical h.
To construct a parity-check matrix, write the canonical h=∑l=0k​hl​Xl and its reciprocal polynomial h∗(X)=Xkh(X−1). Take coefficient vectors, padded to length N, of
h∗, Xh∗,…,Xr−1h∗​
(37)
as the r rows of H. Here h0​=1 because h∣f, so these rows have successive leading degrees k,k+1,…,N−1 and are independent. For a word a, row j has dot product ∑l=0k​hk−l​aj+l​, the coefficient of Xk+j in the ordinary product ah. If a∈C, then ah=bf with degb<k. This product has no terms in degrees k,…,N−1, so HaT=0. The kernel of H has dimension N−r=k, the same as C, proving kerH=C. This proves the reciprocal-polynomial parity-check matrix construction and identifies its rows as a basis for the dual of a cyclic code.
Alternatively, a supplied check polynomial of a cyclic code reduced modulo f, h=∑l=0N−1​hl​Xl, gives the polynomial multiplication parity-check matrix
Bti​=ht−imodN​(0≤t,i<N).
(38)
This circulant matrix represents multiplication by h modulo f, so its kernel is C and its matrix rank is r. Selecting independent rows yields a rank-r parity-check matrix even without initially normalizing the supplied polynomial.
The syndrome s(y)=HyT labels the coset C+y. Indeed s(y)=s(z) if and only if H(y−z)T=0, equivalently y−z∈C. There are 2r cosets, each with 2k words, and the syndrome classification of code cosets gives a bijection between them and F2r​. If y=c+e is a transmitted codeword plus an error, then s(y)=s(e): the syndrome determines the error coset. Choosing a minimum-weight coset leader and subtracting it performs minimum-distance decoding. The error itself need not be uniquely identified, but it is unique when its weight is at most ⌊(d−1)/2⌋, since the corresponding error-correction balls are disjoint.
For the repetition code, the nonzero codeword is the all-ones word, so
grep​(X)=1+X+⋯+XN−1,hrep​(X)=X+1.​
(39)
Their product is XN+1, and the generator polynomial degree N−1 gives dimension one. For the single parity-check code, membership is a(1)=0, equivalent to divisibility by X+1. Thus
gpar​(X)=X+1,hpar​(X)=1+X+⋯+XN−1.​
(40)
Its dimension is N−1; it is the even-weight code.
Finally, factor the binary length-seven modulus:
X7+1=(X+1)(X3+X+1)(X3+X2+1).
(41)
A standard cyclic realization of the Hamming code of length seven uses
g(X)=X3+X+1,h(X)=(X+1)(X3+X2+1)=X4+X2+X+1.​
(42)
Its dimension is four. The reciprocal-check construction gives
H=​100​010​101​110​111​011​001​​.
(43)
Its columns are exactly the seven distinct nonzero vectors of F23​, so no word of weight one or two is in its kernel. The generator itself has weight three, so the minimum Hamming distance is exactly three; this is the [7,4,3] Hamming code. Reversing the cyclic coordinate order gives the equally valid reciprocal choice
g(X)=X3+X2+1,h(X)=X4+X3+X2+1.​
(44)
The polynomial answer therefore depends on the cyclic coordinate convention, while the resulting codes are equivalent.
