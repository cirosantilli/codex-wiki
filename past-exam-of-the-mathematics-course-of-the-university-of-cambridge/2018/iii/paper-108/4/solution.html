The Rudolph measure rigidity theorem has an essential ergodicity hypothesis. If a Borel probability measure μ on the circle group is invariant under both T2​ and T3​, is ergodic for the semigroup generated jointly by these maps, and either map has positive Kolmogorov-Sinai entropy, then
μ=m.​
(40)
Equivalently, a jointly ergodic common invariant measure other than Lebesgue measure has zero entropy for both maps. Joint ergodicity means that every set invariant modulo μ under both maps has measure zero or one. Positive entropy without this hypothesis is insufficient: 21​m+21​δ0​, with δ0​ a Dirac measure, is a common invariant measure of positive entropy and is not m.
The Host equidistribution theorem states that if p,q≥2 are relatively prime integers and ν is invariant and ergodic under Tp​, with hν​(Tp​)>0, then for ν-almost every x the sequence (Tqn​x) is an equidistributed sequence for Lebesgue measure. Explicitly, for every continuous g on the circle,
N1​n=0∑N−1​g(Tqn​x)⟶∫gdmfor ν-almost every x.​
(41)
The non-ergodic form assumes Tp​ invariance and positive entropy for almost every component in the ergodic decomposition ν=∫νω​dλ(ω). Applying the ergodic theorem of Host on each such component gives the same almost-everywhere conclusion for ν. More generally, its conclusion holds on the part supported on positive-entropy components. A positive value of hν​(Tp​) alone does not eliminate zero-entropy components.
To deduce the joint version of the Rudolph measure rigidity theorem, suppose hμ​(T2​)>0; if only T3​ has positive entropy, interchange the roles. Write the T2​ ergodic decomposition as μ=∫νdτ(ν). Since T3​ commutes with T2​, its pushforward measure sends a T2​ ergodic component ν to a T2​ ergodic component (T3​)∗​ν. On each component, T3​ is a factor of a measure-preserving system with fibres of size at most three. We use the standard entropy preservation under a finite-to-one factor:
h(T3​)∗​ν​(T2​)=hν​(T2​).
(42)
The reason for this standard entropy fact is that, conditional on a complete factor point, every finite orbit name has at most three possibilities; its conditional entropy is bounded by log3, and division by the orbit length gives zero relative entropy.
The component at T3​x is (T3​)∗​νx​ almost everywhere; this follows from commutation and the componentwise ergodic averages. The component entropy function r(x)=hνx​​(T2​) is therefore invariant under both T2​ and T3​. Joint ergodicity makes it constant almost everywhere, and affinity of entropy under ergodic decomposition identifies the constant as hμ​(T2​)>0. Thus almost every T2​ component has positive entropy, exactly the condition required in the non-ergodic Host equidistribution theorem. It follows that μ-almost every point equidistributes for m under T3​.
For any continuous g, invariance under T3​ and the dominated convergence theorem now give
∫gdμ=∫N1​∑n=0N−1​g(T3n​x)dμ(x)⟶∫gdm.
(43)
Continuous functions determine Borel probability measures on the circle, so μ=m, proving the deduction.
For the normal-number example, let ω1​,ω2​,… be independent fair binary digits and define
π(ω)=∑j=1∞​3j2ωj​​,ν=π∗​((21​,21​)N).
(44)
This Cantor Bernoulli measure is supported on the middle-third Cantor set C. If S is the Bernoulli shift, then T3​∘π=π∘S on the circle. Consequently ν is T3​ invariant and ergodic: a T3​ invariant event pulls back to an S invariant event, which has probability zero or one.
Take the ternary digit measurable partition η={[0,1/3),[1/3,2/3),[2/3,1)}. Its block partition of length n has, up to null endpoints, 2n positive-measure atoms under ν, each of measure 2−n, and all other atoms have measure zero. Hence
Hν​(η0n−1​)=nlog2,hν​(T3​)≥hν​(T3​,η)=log2>0.
(45)
Apply the Host equidistribution theorem with p=3, q=2. For ν-almost every x∈C, the sequence (T2n​x) equidistributes for Lebesgue measure, so x is a normal number in base 2 by normality and equidistribution under integer multiplication.
The ternary expansion of ν-almost every such x contains only 0 and 2, so the frequency of digit 1 is zero rather than 1/3. The ambiguous ternary endpoints form a countable ν null set and can be removed. Therefore x is not a normal number in base 3. We have proved the stronger almost-everywhere existence statement
ν{x∈C∩[0,1):x is normal in base 2 and not normal in base 3}=1.​
(46)
