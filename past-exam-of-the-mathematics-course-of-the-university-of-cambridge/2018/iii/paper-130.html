Hales–Jewett and the arithmetic-progression consequence. For a finite alphabet [m] and a positive integer r, the Hales-Jewett theorem gives an integer N such that every r-color finite coloring of [m]N contains a monochromatic combinatorial line. A combinatorial line has a nonempty active coordinate set: all those coordinates receive the same freely varying letter, and the remaining coordinates are fixed.
We first prove the alphabet insensitivity lemma. Fix two letters a,b∈[m], with m≥2, and a desired dimension d. There is a combinatorial subspace of dimension d on which changing a to b in any variable coordinate, with all other variable coordinates arbitrary, preserves the color.
For the construction, divide the coordinates into d consecutive blocks. Choose their lengths from left to right by
Pi​=∑j<i​Lj​,Li​=rmPi​+d−i.
(1)
Process the blocks from right to left. When processing block i, the later blocks already form a (d−i)-dimensional combinatorial subspace. Color each word in block i by the vector of its original colors for every prefix word of length Pi​ and every assignment to those later variables. There are mPi​+d−i contexts, and at most rmPi​+d−i=Li​ such color vectors.
The Li​+1 words ajbLi​−j, 0≤j≤Li​, contain two, indexed by u<v, with the same vector by the pigeonhole principle. Fix the first u coordinates to a, the coordinates after v to b, and make coordinates u+1,…,v the active set of one new variable. Its values a,b now have identical colors for every prefix and later-variable context. The active set is nonempty. Insensitivity already obtained in later blocks survives, because it held for every unrestricted earlier prefix. After all d blocks have been processed, changing a,b in any of the d variables preserves the color. This proves the lemma.
Now induct on m. For m=1, a one-coordinate combinatorial line is automatically monochromatic. For m≥2, let d be a length supplied by the theorem for alphabet [m−1] and r colors. Apply the alphabet insensitivity lemma for the letters m−1,m to obtain a d-dimensional combinatorial subspace. Restrict its variables to [m−1]. Induction gives a monochromatic combinatorial line in those variables. Its values 1,…,m−1 have the same color, and its value m has the same color as its value m−1 by successively switching the active variables. Lifting this line to the original coordinates proves
every finite coloring of a sufficiently long word space has a monochromatic line.​
(2)
For the Van der Waerden theorem, fix a progression length k≥2 and use the alphabet {0,…,k−1}. Pull back an r-color finite coloring of {1,…,1+(k−1)N} along
(x1​,…,xN​)⟼1+∑j=1N​xj​.
(3)
A combinatorial line with active set S maps to the arithmetic progression a,a+q,…,a+(k−1)q, where a≥1 and its common difference is q=∣S∣>0. The Hales-Jewett theorem makes this progression monochromatic. Length one is trivial, so every finite coloring of the positive integers contains monochromatic arithmetic progressions of every finite length.
The active-coordinate obstruction. Color a word red when its first coordinate is 1, and blue otherwise. Any combinatorial line whose active coordinate set contains 1 has a red word at variable value 1 and a blue word at variable value 2, since m>1. Thus
{S⊆[n]:1∈S} is not adequate.​
(4)
Here adequacy is the adequate family of active coordinate sets property; an active coordinate set is always nonempty.

Let F be an intersecting family. For a word w∈[m]n, put S(w)={i:wi​=1}. Give w the red color if S(w) contains some member of F, and the blue color otherwise.
Consider any combinatorial line with active set A∈F. At variable value 1, A⊆S(w), so that word is red. At variable value 2, S(w)∩A=∅. No member of F can be contained in this S(w), because every member meets A. Thus that word is blue. No such line is monochromatic, proving
F intersecting ⟹F not adequate.​
(5)
If F is empty there is no permitted active set at all, so it is also not an adequate family of active coordinate sets.

Let N be a word length supplied by the Hales-Jewett theorem for alphabet [m] and two colors. For n≥2N, embed [m]N into [m]n by the coordinate duplication for combinatorial lines map
(x1​,…,xN​)⟼(x1​,x1​,x2​,x2​,…,xN​,xN​,1,…,1).
(6)
Pull back any two-color finite coloring to this word space. The Hales-Jewett theorem gives a monochromatic combinatorial line with nonempty active set S. Its image is a combinatorial line whose active set is
⋃j∈S​{2j−1,2j},
(7)
and hence has size 2∣S∣, a positive even integer. Therefore
{A⊆[n]:∣A∣ is even} is adequate for all n≥2N.​
(8)
The empty set's presence in the family causes no difficulty: the line just constructed has at least two active coordinates.

Rado's criterion. Let A be a matrix over the rational numbers, with columns a1​,…,aq​. A partition regular matrix is one for which every finite coloring of the positive integers gives a monochromatic positive vector x∈Nq with Ax=0; repeated coordinates are allowed. The columns condition is the existence of an ordered set partition B1​,…,Bs​ of [q] into nonempty blocks such that
∑i∈B1​​ai​=0,∑i∈Bj​​ai​∈spanQ​{ai​:i∈B1​∪⋯∪Bj−1​}(j>1).
(9)
Rado's theorem states
A is partition regular if and only if it satisfies the columns condition.​
(10)
Necessity. Clear denominators so the columns are integer vectors. For each pair of disjoint index sets I,B, with B=∅, for which vB​=∑i∈B​ai​ is outside the linear span of the I-columns, choose an integer linear functional ϕI,B​ that vanishes on those columns and satisfies ϕI,B​(vB​)=0. Such a functional exists by extending a basis of the span to one also containing vB​, defining a functional on that basis, and clearing its rational denominators.
There are only finitely many such pairs. Choose a prime number p dividing none of these nonzero integer evaluations. If there are no such pairs, any prime will do. Use the last nonzero digit coloring: write x=pvp​(x)u, with p∤u, and color x by umodp∈{1,…,p−1}. Since A is a partition regular matrix, this coloring supplies a monochromatic positive solution, so all its unit parts have a common nonzero residue d.
Group the coordinates by increasing P-adic valuation, obtaining blocks B1​,…,Bs​ with valuations e1​<⋯<es​. Suppose for some j the sum vBj​​ lay outside the linear span of the earlier columns, with earlier index set I. Apply ϕI,Bj​​ to Ax=0. Earlier terms vanish exactly. Divide the remaining integer equation by pej​ and reduce modulo p. Later terms vanish modulo p, while the current block gives
0≡dϕI,Bj​​(vBj​​)(modp),
(11)
contrary to the choice of p. Thus every block sum lies in the earlier linear span, and for the first block this means it is zero. This proves the columns condition by the finite separating-functional proof of the columns condition.
Sufficiency. Suppose the columns condition holds. For j>1, choose rational coefficients λij​, indexed by earlier columns, such that
∑i∈Bj​​ai​+∑i∈B1​∪⋯∪Bj−1​​λij​ai​=0.
(12)
Take a positive integer c clearing their denominators and p≥1 bounding all ∣cλij​∣. We use the allowed monochromatic m-p-c set theorem with s levels. Its M-p-c set is the full set
D=⋃h=1s​{czh​+∑j>h​μj​zj​:μj​∈Z, ∣μj​∣≤p},
(13)
where the generators make every displayed expression positive. Positivity is part of this convention, rather than a rule that discards nonpositive expressions. For i∈Bh​, set
xi​=czh​+∑j>h​cλij​zj​.
(14)
All these numbers lie in the monochromatic set D. The coefficient of zj​ in Ax is
c(∑i∈Bj​​ai​+∑i∈B1​∪⋯∪Bj−1​​λij​ai​)=0,
(15)
with the first coefficient zero by ∑i∈B1​​ai​=0. Hence Ax=0. This Rado solution inside an m-p-c set proves sufficiency.
The equality-or-inequality dichotomy. If every finite coloring gives a monochromatic solution with x1​=x2​, the first alternative holds. Otherwise fix a finite coloring χ admitting no such solution. Given any other finite coloring ψ, use the refinement of a finite coloring n↦(χ(n),ψ(n)). Since A is a partition regular matrix, it supplies a solution monochromatic for both colorings. Its first two coordinates cannot be equal, by the defining property of χ, so it is the required unequal solution for ψ. Thus one of the two universal alternatives always holds. This is the partition regularity dichotomy under an extra constraint; the alternatives are not asserted to be mutually exclusive.
Both restrictions can fail. The Schur matrix
A=(1  1  −1)
(16)
is a partition regular matrix: blocks {1,3} and {2} satisfy the columns condition. Color n by v2​(n)mod2, using the 2-adic valuation. An equal-coordinate solution would have x3​=2x1​, and v2​(2x1​)=v2​(x1​)+1, so its coordinates cannot be monochromatic. This exhibits failure of the equality restriction.
Conversely, A=(1  −1) satisfies the columns condition in one block. Every solution has x1​=x2​, so even the constant one-color finite coloring admits no unequal-coordinate solution. Consequently
equality can be impossible for one coloring, and inequality can be impossible for every coloring.​
(17)

The ultrafilter space. An ultrafilter U on N is a proper filter on a set: it is upward closed, closed under finite intersections, excludes ∅, and contains exactly one of A,Ac for each A⊆N. The Stone-Čech compactification of the natural numbers is the set of these ultrafilters, with basic sets
A={U:A∈U}.
(18)
They form a basis since A∩B=A∩B and N=βN. Moreover (A)c=Ac, so each is a clopen set. The principal ultrafilter at n embeds N in this space; every nonempty A contains such a point, so the embedded copy is dense.
Distinct ultrafilters U,V have some A∈U with A∈/V. Then Ac∈V, and A,Ac are disjoint open sets separating them. Thus the space is Hausdorff.
For compactness, any open set cover can be refined to a cover by basic sets. If {Ai​​} has no finite subcover, the sets Aic​ have the finite intersection property: otherwise finitely many Ai​ cover N, and their basic sets cover every ultrafilter. Extend the proper filter on a set generated by these complements to an ultrafilter U. This extension follows from Zorn lemma: unions of chains of proper filters remain proper, and a maximal proper filter decides every A versus Ac. Indeed, if adding A made the filter improper, some existing filter member would be disjoint from A, forcing Ac into the filter. This U contains every Aic​ and misses every Ai​​, a contradiction. Hence
βN is compact and Hausdorff.​
(19)
This proves the compact Hausdorff topology on ultrafilters directly.
An idempotent. The addition on the Stone-Čech compactification of the natural numbers can be defined by
A∈U+V⟺{n:A−n∈V}∈U,A−n={k:n+k∈A}.
(20)
Associativity is supplied. For fixed V, the inverse image of A under U↦U+V is {n:A−n∈V}​, so this translation is continuous directly from the definition. This makes a left-topological semigroup in the convention used here.
We prove the Ellis–Numakura lemma in this case. Among nonempty compact subsemigroups choose one, K, minimal by inclusion. It exists by Zorn lemma: a descending chain has nonempty intersection by compactness, and that intersection is again a compact subsemigroup. For a∈K, the set K+a is a nonempty compact subsemigroup contained in K. Compactness follows from continuity; closure under addition follows from
(x+a)+(y+a)=(x+a+y)+a∈K+a.
(21)
Minimality gives K+a=K. Hence there is b∈K with b+a=a. The set
L={x∈K:x+a=a}
(22)
is nonempty, compact, and a subsemigroup: if x,y∈L, then (x+y)+a=x+(y+a)=x+a=a. Thus minimality gives L=K, and in particular a+a=a. Therefore
there is an idempotent ultrafilter in βN.​
(23)
This is an idempotent ultrafilter on the natural numbers.
Isolating the sequence terms. Now use the hypothetical convergent sequence of distinct ultrafilters. For each n, choose Cn​∈Un​ with Cnc​∈U, possible since Un​=U. Convergence implies Cnc​∈Um​ for all sufficiently large m. Thus only finitely many indices m=n have Cn​∈Um​. Call this finite set En​.
For each m∈En​, choose Dn,m​∈Un​ with Dn,m​∈/Um​, using distinctness. Set
An​=Cn​∩⋂m∈En​​Dn,m​.
(24)
Finite-intersection closure puts An​ in Un​. For m=n, either Cn​∈/Um​ or one of the chosen Dn,m​ is absent from Um​; upward closure then prevents An​ from belonging to Um​. Hence
An​∈Um​⟺m=n.​
(25)

Let E=⋃j≥1​B2j​. For every even index 2j, B2j​⊆E and B2j​∈U2j​ imply E∈U2j​. For every odd index 2j−1, disjointness gives B2j−1​⊆Ec, so Ec∈U2j−1​ and E∈/U2j−1​. Consequently
E∈Un​⟺n is even.​
(29)
The limit ultrafilter U contains either E or Ec. Whichever it contains, the corresponding basic clopen set E or Ec is a neighbourhood of U, but infinitely many sequence terms lie outside it. This contradicts convergence. Therefore pairwise distinct ultrafilters cannot form a convergent sequence in βN, the key step in no nontrivial convergent sequences in the Stone-Čech compactification.

Let (Vn​) be a convergent sequence in the Stone-Čech compactification of the natural numbers, with limit V. Each fixed W=V occurs only finitely often: the Hausdorff property gives a neighbourhood of V excluding W, and eventually the sequence is in that neighbourhood.
If (Vn​) were not eventually equal to V, infinitely many terms would differ from V. They could not take only finitely many distinct values, because each such value occurs only finitely often. Recursively select a subsequence of pairwise distinct terms, all different from V. It still converges to V, contradicting the preceding parts. Hence
Vn​=V for all sufficiently large n.​
(30)
This establishes no nontrivial convergent sequences in the Stone-Čech compactification for arbitrary sequences, including ones with repetitions.

The two Ramsey properties and the topologies. Write [N]ω for the space of infinite subsets of the natural numbers, and [A]ω for the infinite subsets of A. The positive integers are used throughout. A Ramsey set of infinite subsets E has the property that every infinite A contains an infinite B for which [B]ω lies wholly in E or wholly in Ec.
For finite s and infinite A above maxs, let
[s,A]={s∪B:B∈[A]ω},max∅=0.
(31)
These are the basic neighbourhoods of the Ellentuck topology, denoted ∗ in the question. They form a basis: if X belongs to two such sets, their stems are comparable initial segments of X; take the longer stem and the intersection of the two tails beyond that stem. This intersection contains the infinite remaining tail of X and yields a basic set contained in both.
A completely Ramsey set E allows such a homogeneous refinement [s,B] inside every [s,A], with B⊆A infinite and the stem s kept fixed. Taking s=∅ shows that complete Ramseyness implies Ramseyness. The ordinary topology on infinite subsets τ has basic cylinders
[s]={X:s is an initial segment of X}=[s,{n:n>maxs}].
(32)
It is the usual product topology on increasing enumerations and is coarser than the Ellentuck topology.
Examples distinguishing the properties. A non-Ramsey example uses the axiom of choice. Let κ=2ℵ0​ and enumerate all infinite sets as (Aα​)α<κ​. Each [Aα​]ω has cardinality κ: an enumeration of Aα​ gives the upper bound, and choosing one element from each of infinitely many disjoint pairs gives an injection from all binary sequences for the lower bound.
By transfinite recursion, choose two distinct, previously unused elements Xα​,Yα​∈[Aα​]ω at each stage. Fewer than κ elements have been used at stage α<κ, so this is possible without any assumption on the Continuum hypothesis. Put R={Xα​:α<κ}. All the Yα​ remain outside R, since subsequent choices also avoid previously chosen elements. Every [A]ω contains one Xα​ and one Yα​, so R is not a Ramsey set of infinite subsets. This is the non-Ramsey set from transfinite selection construction.
Perform the same construction on T=N∖{1}, giving a non-Ramsey set RT​⊆[T]ω, and put
E={{1}∪X:X∈RT​}.
(33)
For any infinite A, the infinite set B=A∖{1} has [B]ω∩E=∅, so E is a Ramsey set of infinite subsets. But no [{1},B] with infinite B⊆T is homogeneous, because [B]ω meets both RT​ and its complement. Therefore E is not a completely Ramsey set.
Every star-open set is completely Ramsey. We give the full fusion proof for open Ellentuck sets, without quoting an infinite Ramsey theorem. Fix a star-open set O and a basic set [s,A]. For finite a⊆A and an infinite tail D⊆A above maxa, say D accepts a if [s∪a,D]⊆O; it rejects a if no infinite subset of D accepts a. Both properties persist under passing to infinite subsets. Every infinite tail can be thinned to decide a: take an accepting subset if one exists, and otherwise the original tail rejects it.
First thin A to decide a=∅. If it accepts, the required homogeneous neighborhood has already been found. Otherwise keep a rejecting tail. We now fuse to an infinite set B deciding every finite a⊆B, where the decision for a is made by B/a={b∈B:b>maxa}.
To do this, choose b1​<b2​<⋯ successively from an infinite current tail. After choosing bj​, thin the tail above bj​ to decide each of the finitely many subsets of {b1​,…,bj​}, one after another, before choosing the next element. For any finite a⊆B, at the stage when its largest element is selected, the current tail decides a and contains every later selected element. Heredity therefore gives a decision on B/a. For a=∅, rejection persists from the initial tail.
If B/a rejects a, only finitely many n∈B/a can have B/n accepting a∪{n}. Otherwise let D be the infinite set of those n. Every member of [s∪a,D] has a first new element n, and its remaining tail lies in B/n. It therefore belongs to O by acceptance of a∪{n}. This would make D accept a, contradicting rejection.
Thin B a second time to C={c1​<c2​<⋯} so that every finite a⊆C is rejected. Start with the rejected empty set. At a finite stage, all subsets of the selected elements are rejected. For each of these finitely many subsets, avoid its finitely many next elements that would give an accepted extension, and choose the next cj​ beyond all excluded elements. Since B decides every finite extension, each new extension is rejected. Induction gives the asserted property of C.
We claim [s,C]∩O=∅. If X∈[s,C]∩O, openness provides a basic set [t,D]⊆O containing X. Extend t, if necessary, to an initial segment u of X containing s. Write u=s∪a with finite a⊆C. The infinite tail X∖u lies in B/a and
[s∪a,X∖u]⊆[t,D]⊆O.
(34)
It is therefore an accepting subtail for a, contradicting rejection. We have found either an accepting neighborhood or a neighborhood disjoint from O. Thus
O star-open ⟹O completely Ramsey.​
(35)
Basic neighborhoods are clopen. Consider [s,A] and a point X outside it. If s is not an initial segment of X, take an initial segment t of X of length at least ∣s∣; its ordinary cylinder [t] cannot meet [s,A]. Otherwise some element of X∖s is outside A; take t through that element, and again [t] is disjoint from [s,A].
Thus the complement of [s,A] is already open in the ordinary topology on infinite subsets, and hence in the finer Ellentuck topology. A basic neighbourhood is open by definition, so
[s,A] is star-clopen, and is also τ-closed.​
(36)

The answer is no. Let X0​=N, regarded as one point of the space of infinite subsets of the natural numbers, and put
O=[N]ω∖{X0​}=⋃j≥1​[∅,N∖{j}].
(37)

Take A={2,4,6,…} and
O=[∅,A]=[A]ω.
(39)
This is a nonempty basic open set in the Ellentuck topology. It is a closed set in the ordinary topology on infinite subsets: an infinite set outside O contains an odd integer, and its finite initial segment through that integer gives an ordinary cylinder disjoint from O.
Its ordinary interior is empty. In any nonempty ordinary cylinder [s], choose an odd integer b>maxs and continue s∪{b} by any infinite increasing tail. The resulting point belongs to [s] and lies outside O. Indeed the smaller cylinder [s∪{b}] is disjoint from O. Since O is ordinary-closed with empty ordinary interior, it is a nowhere dense set for τ. Hence
[2N]ω is nonempty and star-open, but τ-nowhere-dense.​
