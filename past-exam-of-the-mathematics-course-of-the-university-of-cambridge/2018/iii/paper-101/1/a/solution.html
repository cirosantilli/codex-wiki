The spectrum of a commutative ring is the set
SpecR={p⊊R:p is a prime ideal}.
(1)
For an ideal I⊆R, set V(I)={p:I⊆p}. The Zariski topology declares precisely these subsets to be closed sets. Using arbitrary subsets instead of ideals gives the same definition, because a prime ideal contains a subset exactly when it contains the ideal generated by that subset.
We verify the closed set axioms directly. First, V(0)=SpecR and V(R)=∅. For any family of ideals,
⋂λ​V(Iλ​)=V(∑λ​Iλ​),
(2)
since containing the sum is equivalent to containing every summand. For two ideals,
V(I)∪V(J)=V(IJ).
(3)
Indeed, containing either I or J implies containing their product of ideals. Conversely, if a prime ideal p contains IJ but does not contain I, choose a∈I∖p. For every b∈J, ab∈p, so the prime ideal property forces b∈p. Thus J⊆p.
The displayed identities establish arbitrary intersections and finite unions of closed sets, including their empty cases. Therefore these sets define a topology on SpecR.
