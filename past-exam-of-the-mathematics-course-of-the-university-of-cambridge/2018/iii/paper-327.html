Use the Fourier transform convention f​(ξ)=∫e−ix⋅ξf(x)dx and Dj​=−i∂xj​​. Thus Dj​ has Fourier symbol ξj​. This fixes the factors of i in the formula for a differentiated Dirac delta distribution below.
With the Japanese bracket ⟨θ⟩=(1+∣θ∣2)1/2, the symbol class Sym(X,Rk;N)=S1,0N​(X×Rk) consists of smooth functions a such that, for every compact set K⊂X and all multi-indices α,β,
∣∂xα​∂θβ​a(x,θ)∣≤CK,α,β​⟨θ⟩N−∣β∣(x∈K).​
(1)
Here N is one fixed finite real order; the constants may depend on K. Differentiation in x preserves the symbol class order, whereas differentiation in θ lowers it.
A phase function is real-valued and smooth on X×(Rk∖{0}), is a positively homogeneous function of degree one in θ, and has nonzero total differential:
Φ(x,tθ)=tΦ(x,θ)(t>0),(∇x​Φ,∇θ​Φ)=0(θ=0).
(2)
The nonvanishing condition concerns both sets of variables, not just ∇θ​Φ. The homogeneous convention is imposed away from θ=0; a smooth completion at low frequency is another equivalent convention for the high-frequency construction. Low-frequency changes contribute a smooth function of x.
Choose a cutoff function ρ(θ) equal to one near zero. The low-frequency part with oscillatory integral amplitude ρa is an ordinary convergent integral and defines a smooth function: all x derivatives of Φ are OK​(∣θ∣) near zero, so differentiation under this integral preserves integrability. For the remaining part define, when θ=0,
G=∣∇x​Φ∣2+∣θ∣2∣∇θ​Φ∣2,L=iG1​(∑j​∂xj​​Φ∂xj​​+∣θ∣2∑ℓ​∂θℓ​​Φ∂θℓ​​).
(3)
Then LeiΦ=eiΦ. On K×{θ:∣θ∣=1}, compactness and the phase function condition give a positive lower bound for G. Homogeneity consequently gives G≥cK​∣θ∣2. The coefficient of each x derivative in L has symbol class order −1, and the coefficient of each θ derivative has order zero.
If L=∑bj​∂xj​​+∑cℓ​∂θℓ​​, its formal transpose is
Ltf=−∑j​∂xj​​(bj​f)−∑ℓ​∂θℓ​​(cℓ​f).
(4)
This is the bilinear transpose for integration by parts, without complex conjugation. It lowers the symbol class order by one. For a test function φ supported in K, choose a nonnegative integer r>N+k and set
⟨IΦ​(a),φ⟩=​∫X​∫Rk​eiΦρaφdθdx+∫X​∫Rk​eiΦ(Lt)r((1−ρ)aφ)dθdx.​
(5)
Both integrals are absolutely convergent, because the last oscillatory integral amplitude has order N−r<−k and compact support in x.
To verify that this defines the intended oscillatory integral, take any χ∈Cc∞​(Rk) equal to one near zero and insert χ(εθ) in the original integral. Repeated integration by parts gives the preceding expression with (Lt)r applied also to this cutoff function. Its derivatives satisfy uniform symbol class bounds: on the annulus where they are nonzero, ε∣β∣≤C⟨θ⟩−∣β∣. The transformed integrands are bounded by an integrable multiple of ⟨θ⟩N−r. The dominated convergence theorem therefore proves
⟨IΦ​(a),φ⟩=ε↓0lim​∫X​∫Rk​eiΦ(x,θ)a(x,θ)φ(x)χ(εθ)dθdx.​
(6)
It also proves independence of the cutoff function, the chosen r, and the integration-by-parts representation.
At most r derivatives fall on φ, so the same estimates give
∣⟨IΦ​(a),φ⟩∣≤CK​∣α∣≤rmax​∥∂αφ∥∞​,IΦ​(a)∈D′(X).​
(7)
This proves linearity and continuity on the space of test functions. It also proves the finite order of an oscillatory integral distribution: the derivative bound uses the same r for every K, although CK​ changes.
For x0​∈X, take k=n, Φ=(x−x0​)⋅θ, and a=(2π)−nθα. This phase function is valid because ∇x​Φ=θ=0 for nonzero θ, and the oscillatory integral amplitude is in symbol class S1,0∣α∣​. The required identity is
Dαδx0​​=(2π)−n∫Rn​ei(x−x0​)⋅θθαdθ.​
(8)
Indeed, extending a test function by zero outside X and integrating in x first gives the absolutely convergent expression
(2π)−n∫e−ix0​⋅θθαφ​(−θ)dθ=(2π)−n∫eix0​⋅ξ(−ξ)αφ​(ξ)dξ=i∣α∣∂αφ(x0​).
(9)
Here Fourier inversion applies because φ is a Schwartz function. By the definition of a distributional derivative, the last expression is precisely ⟨Dαδx0​​,φ⟩. If Dα is instead used for plain ∂α, the oscillatory integral amplitude in the boxed formula is (2π)−n(iθ)α, and the pairing is (−1)∣α∣∂αφ(x0​).
Not every distribution is one oscillatory integral of the stated class. On X=R, consider the locally finite distribution of unbounded order
T=∑j=1∞​Djδj​.
(10)
Only finitely many differentiated Dirac delta distributions contribute to each test function, so T is a distribution. Near j it is exactly Djδj​, which cannot satisfy a bound using only r<j derivatives. Explicitly choose η∈Cc∞​((−1/4,1/4)) with η(j)(0)=0 and use
φε​(x)=εrη((x−j)/ε).
(11)
The derivatives through order r remain bounded for 0<ε≤1, whereas
∣⟨T,φε​⟩∣=εr−j∣η(j)(0)∣⟶∞.
(12)
Any single oscillatory integral with finite k and a fixed finite symbol class order N has the uniform order bound just proved, so it cannot equal T. The same construction works on any nonempty open set in positive dimension by choosing points that leave every compact set and taking locally finite differentiated Dirac delta distributions there. This obstruction concerns a single fixed-order oscillatory integral, rather than local representations or an infinite sum of them.

The space of test functions is D(R)=Cc∞​(R). A sequence φj​ converges to φ when all functions eventually have compact support in one compact set K and every derivative converges uniformly:
∥φj(q)​−φ(q)∥∞​⟶0for each integer q≥0.
(13)
A distribution is a continuous linear functional on this space of test functions. Equivalently, for each compact set K, there are CK​ and a finite integer mK​ such that
∣⟨u,φ⟩∣≤CK​max0≤q≤mK​​∥φ(q)∥∞​whenever suppφ⊆K.
(14)
The integer mK​ is permitted to depend on K. The usual weak convergence of distributions is
uj​⟶u in D′(R)⟺⟨uj​,φ⟩⟶⟨u,φ⟩ for every φ∈D(R).​
(15)
Thus the convergence convention on the distribution space is its weak dual topology.
For the principal-value reciprocal distribution, the symmetric truncations can be written
⟨pvx1​,φ⟩=limε↓0​∫∣x∣>ε​xφ(x)​dx=∫0∞​xφ(x)−φ(−x)​dx.
(16)
The numerator is O(x) near zero by the mean value theorem, and the integrand vanishes for large x because φ has compact support. For suppφ⊂[−R,R],
​⟨pvx1​,φ⟩​≤2R∥φ′∥∞​.
(17)
Consequently the Cauchy principal value defines a distribution of order of a distribution at most one.
The function log∣x∣ has local integrability, since ∫01​∣logx∣dx<∞, and therefore defines a distribution. For its distributional derivative, remove (−ε,ε) and use integration by parts on both remaining intervals:
−∫∣x∣>ε​log∣x∣φ′(x)dx=∫∣x∣>ε​xφ(x)​dx+logε[φ(ε)−φ(−ε)].
(18)
The boundary term is O(ε∣logε∣) and tends to zero. The omitted integral of log∣x∣φ′ tends to zero by local integrability. Hence the distributional derivative of the logarithmic modulus satisfies
dxd​log∣x∣=pvx1​in D′(R).​
(19)
Symmetric truncation is essential to this normalization of the principal-value reciprocal distribution.

Let Tq​φ(x)=∑k=0q​φ(k)(0)xk/k! denote the Taylor polynomial at zero. On 0<∣x∣<1, the integrand defining the Hadamard finite-part reciprocal-power distribution is
x−m(φ(x)−Tm−2​φ(x))=(m−1)!φ(m−1)(0)​x1​+x−m(φ(x)−Tm−1​φ(x)).
(20)
The first term is odd, so it cancels under symmetric truncation. The Taylor remainder in the second term has absolute value at most ∣x∣m∥φ(m)∥∞​/m!. The integral near zero therefore has a finite limit. For ∣x∣≥1, the original terms are integrable: x−mφ has compact support, and each subtracted power has exponent k−m≤−2.
This proves existence and linearity. It also gives the global estimate
∣⟨Λm​,φ⟩∣≤​m!2​∥φ(m)∥∞​+m−12​∥φ∥∞​+k=0∑m−2​k!(m−k−1)2​∣φ(k)(0)∣.​
(21)
Thus
Λm​∈D′(R),ordΛm​≤m.​
(22)
In particular the order of a distribution is bounded by one integer on all compact sets, not merely separately on each of them.
For the recurrence, write the truncated Hadamard finite-part integral as
Am​(ε,φ)=∫∣x∣>ε​x−mφ(x)dx−Cm​(ε,φ),
(23)
where parity evaluates all subtraction integrals explicitly:
Cm​(ε,φ)=2∑0≤k≤m−2m−k even​​k!(m−k−1)φ(k)(0)​εk−m+1.
(24)
Set C1​=0 and Λ1​=pv(1/x). On the two truncated intervals, integration by parts gives
∫∣x∣>ε​x−mφ′(x)dx=m∫∣x∣>ε​x−m−1φ(x)dx+ε−m[(−1)mφ(−ε)−φ(ε)].
(25)
There are no boundary contributions at infinity. The coefficients of the subtraction terms satisfy
mCm+1​(ε,φ)−Cm​(ε,φ′)=2∑0≤k≤m−1m−k odd​​k!φ(k)(0)​εk−m.
(26)
This is exactly the negative of the boundary term's Taylor polynomial through degree m; the degree-m term itself vanishes by parity. Hence
​Am​(ε,φ′)−mAm+1​(ε,φ)=ε−m[(−1)m(φ(−ε)−Tm​φ(−ε))−(φ(ε)−Tm​φ(ε))]=O(ε).​
(27)
Taking the limit proves the full distributional identity
⟨Λm​,φ′⟩=m⟨Λm+1​,φ⟩,Λm′​=−mΛm+1​.​
(28)
The same calculation includes m=1. Starting with the distributional derivative of the logarithmic modulus from part (i), induction yields
Λm​=(m−1)!(−1)m−1​(dxd​)mlog∣x∣,cm​=(m−1)!(−1)m−1​.​
(29)
This identity holds on all of R as a distributional identity. It is stronger than matching the ordinary derivatives away from zero, which would leave possible differentiated Dirac delta distributions at zero undetermined.

Take Dj​=−i∂xj​​ and the Fourier transform convention f​(λ)=∫e−ix⋅λf(x)dx. Write the scalar polynomial as P=PN​+PN−1​+⋯+P0​, with Pj​ homogeneous of degree j. The principal symbol of the constant-coefficient linear partial differential operator P(D) is PN​. It is an elliptic differential operator exactly when
PN​(λ)=0for every real λ=0.​
(30)
Complex coefficients are allowed, but the frequency λ is real.
By compactness of the unit sphere, c=min∣ω∣=1​∣PN​(ω)∣>0. Homogeneity gives ∣PN​(λ)∣≥c∣λ∣N, whereas the lower-degree terms are bounded by C∣λ∣N−1 for ∣λ∣≥1. The triangle inequality then gives the high-frequency lower bound for an elliptic polynomial:
∣P(λ)∣≥c∣λ∣N−C∣λ∣N−1≥2c​∣λ∣N≥c′⟨λ⟩N
(31)
for sufficiently large ∣λ∣. Thus
∣P(λ)∣≳⟨λ⟩N(∣λ∣≥R).​
(32)
The Japanese bracket is ⟨λ⟩=(1+∣λ∣2)1/2. If N=0, a nonzero constant P satisfies the same assertion directly.
For real s, the Sobolev space is the tempered distribution space
Hs(Rn)={u∈S′(Rn):u is a function and ∫Rn​⟨λ⟩2s∣u(λ)∣2dλ<∞}.
(33)
One may include (2π)−n in the squared norm for this Fourier transform normalization; it does not change the space. The Local Sobolev space is
Hlocs​(X)={u∈D′(X):χu∈Hs(Rn) for every χ∈Cc∞​(X)},
(34)
where multiplication of a distribution by a smooth function is followed by extension by zero.
If u is a compactly supported distribution, choose a cutoff function χ equal to one near its compact support. The finite order of a distribution gives an integer M and a bound
∣⟨u,ψ⟩∣≤Cmax∣α∣≤M​supx∈K​∣∂αψ(x)∣
(35)
for a fixed compact set K. This also makes u a tempered distribution. Its Fourier transform of a compactly supported distribution is the smooth function
u(λ)=⟨u,χ(x)e−ix⋅λ⟩,∣u(λ)∣≤C′⟨λ⟩M.
(36)
The Leibniz rule gives the last estimate, and parameter differentiation under the finite-order pairing proves smoothness of this Fourier transform. Therefore the negative Sobolev regularity of a compactly supported distribution is
u∈Hs(Rn)for every s<−M−2n​.​
(37)
Indeed ⟨λ⟩2(s+M) is integrable precisely when 2(s+M)<−n. This proves the claimed existence of a sufficiently negative Sobolev space index.
We use three elementary Sobolev space facts: differentiation of order q maps Ht continuously into Ht−q; Ha⊆Hb for a≥b; and Sobolev multiplication by a smooth cutoff is bounded on Ht for every real t. The first two follow directly from the frequency weights. For the third, multiplication of a distribution by a smooth function becomes convolution with the rapidly decaying χ​, and
⟨λ⟩t≤Ct​⟨λ−η⟩∣t∣⟨η⟩t
(38)
together with Young's convolution inequality gives the bound. These facts apply after localization as well.
The high-frequency lower bound for an elliptic polynomial gives a useful global implication. If w∈Hr(Rn) and P(D)w∈Ht(Rn), split its Fourier transform into ∣λ∣≤R and ∣λ∣>R. The low-frequency part is controlled by ∥w∥Hr​, while the high-frequency part is controlled by ∥P(D)w∥Ht​. Thus, for arbitrary real r,t,
∥w∥Ht+N​≤Cr,t​(∥P(D)w∥Ht​+∥w∥Hr​).​
(39)
The conclusion that w∈Ht+N is obtained directly by integrating these frequency bounds; it is not an assumption made to state the estimate.
For the cutoff bootstrap for local elliptic regularity, fix U⋐X. A cutoff function equal to one near U makes u a compactly supported distribution after multiplication, so the preceding negative-index argument gives u∈Hlocr​(U) for some finite r. Suppose inductively that u∈Hlocq​(U). For any test function χ∈Cc∞​(U),
P(D)(χu)=χP(D)u+[P(D),χ]u.
(40)
The Leibniz rule shows that this commutator has order at most N−1, with smooth functions as coefficients, all with compact support:
[P(D),χ]=∑∣α∣≤N​pα​∑0<β≤α​(βα​)(Dβχ)Dα−β.
(41)
A second cutoff function equal to one near suppχ lets us apply the stated Sobolev space bounds to every term. Hence [P(D),χ]u∈Hq−N+1(Rn), while χP(D)u∈Hs(Rn). For N≥1, the global estimate yields
χu∈Hmin(s,q−N+1)+N=Hmin(s+N,q+1).
(42)
This holds for every such χ, so it improves the Local Sobolev space index by one until s+N is reached. A finite number of iterations starting at r proves
P(D)u∈Hlocs​(X)⟹u∈Hlocs+N​(X).​
(43)
Since U⋐X was arbitrary, the conclusion holds throughout X. For N=0, division by the nonzero constant P proves it immediately. This is the asserted elliptic regularity, proved without assuming an initial nonnegative Sobolev space index.
A first-order example on R2 is the first-order Cauchy-Riemann operator
P(D)=D1​+iD2​=−2i∂zˉ​,P1​(λ)=λ1​+iλ2​,∣P1​(λ)∣=∣λ∣.​
(44)
It is an elliptic differential operator with complex coefficients. In one real variable, D=−id/dx is already a first-order elliptic differential operator.
There is no scalar elliptic differential operator of odd order in three variables. If its order N were odd, its principal symbol would satisfy PN​(−ω)=−PN​(ω) on S2. Regard the continuous map
f:S2⟶R2,f(ω)=(RePN​(ω),ImPN​(ω)).
(45)
The Borsuk-Ulam theorem gives f(ω)=f(−ω) for some ω. Oddness then gives f(ω)=0, contradicting ellipticity. This is the odd-order obstruction for scalar elliptic operators in at least three dimensions; restricting to a three-dimensional subspace proves the higher-dimensional case too. For real coefficients alone, the same obstruction follows from the intermediate value theorem along a path between antipodal points.
The scalar qualification matters. An elliptic system of differential equations can be first order in three variables: with the Pauli matrices, the matrix symbol A(λ)=∑j=13​σj​λj​ satisfies A(λ)2=∣λ∣21 and is invertible for λ=0. This does not contradict the scalar polynomial obstruction.
