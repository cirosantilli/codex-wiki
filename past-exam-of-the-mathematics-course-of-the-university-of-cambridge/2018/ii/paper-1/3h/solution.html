Let a memoryless source have probabilities p1​,…,pm​, and let a uniquely decodable D-ary code have word lengths ℓi​ and mean length L=∑i​pi​ℓi​. The Shannon source coding theorem states
HD​(p)≤L,HD​(p)=−∑i​pi​logD​pi​,
(6)
and that some prefix code satisfies
HD​(p)≤L<HD​(p)+1.
(7)
For the lower bound, the Kraft inequality gives K=∑i​D−ℓi​≤1. Set qi​=D−ℓi​/K. The Gibbs inequality, or nonnegativity of relative entropy, gives
0≤∑i​pi​logD​qi​pi​​=−HD​(p)+L+logD​K.
(8)
Therefore L≥HD​(p)−logD​K≥HD​(p).
For achievability choose ℓi​=⌈−logD​pi​⌉. Then ∑i​D−ℓi​≤∑i​pi​=1, so the converse part of the Kraft theorem supplies a prefix code with these lengths, and
L<∑i​pi​(−logD​pi​+1)=HD​(p)+1.
(9)
Hence the entropy is the optimal mean code length up to less than one code symbol.
