The epsilon-recursion theorem says that for every definable operation G assigning a set G(x,h) to each set x and each function h with domain x, there is a unique class function F such that
F(x)=G(x,F↾x)​
(117)
for every set x.
For uniqueness, suppose F and F′ both satisfy the recursion. If they agree on every y∈x, then their restrictions to x agree and hence
F(x)=G(x,F↾x)=G(x,F′↾x)=F′(x).
(118)
The epsilon induction principle therefore gives F=F′.
For existence, call a function f coherent on a transitive set T when
f(z)=G(z,f↾z)(z∈T).
(119)
The same epsilon-induction argument shows that any two coherent functions agree on the intersection of their transitive domains. Assuming coherent functions have been constructed below every member of x, their compatible union defines all values below x; adjoining the value prescribed by G(x,⋅) extends the construction to x. Epsilon induction establishes this construction for every x. The compatible local functions therefore unite to the required class function F.
A relation r on x is well-founded when every nonempty subset of x has an element with no r-predecessor in that subset. It is extensional when
{b:bra}={b:bra′}⟹a=a′.
(120)
The Mostowski collapse theorem states that every well-founded extensional relation (x,r) is isomorphic to membership on a unique transitive set M. Define recursively
π(a)={π(b):bra}.
(121)
Well-founded recursion makes π well defined. Epsilon-style induction along r, together with extensionality, shows that π is injective. By definition,
bra⟺π(b)∈π(a),
(122)
so π is an isomorphism from (x,r) onto (M,∈), where M=ranπ. If z∈π(a)∈M, then z=π(b) for some bra, so z∈M; hence M is transitive. If another collapse π′ has transitive range, induction gives π′(a)={π′(b):bra}=π(a), proving uniqueness.
Finally, suppose x is finite. Its collapse M is a finite transitive set, so every member of M is hereditarily finite. Therefore every well-founded extensional relation on x collapses to a transitive subset of Vω​.
Conversely, let x be infinite. Choose the initial infinite ordinal κ equinumerous with x. The successor ordinal κ+1 has the same cardinality as κ. Pulling its membership relation back along a bijection x→κ+1 gives a well-founded extensional relation on x whose collapse is κ+1. But κ∈κ+1 is not hereditarily finite, so κ+1⊈Vω​. Consequently,
the required sets x are exactly the finite sets.​
(123)
