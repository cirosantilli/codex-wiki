The compactness theorem for first-order logic says that a set T of first-order sentences has a model if and only if every finite subset of T has a model. The forward implication is immediate. Conversely, if every finite subset is satisfiable, then T is syntactically consistent: any proof of a contradiction would use only finitely many premises. The Godel completeness theorem then gives a model of T.
The Upward Lowenheim-Skolem theorem says that a first-order theory with an infinite model has arbitrarily large models. Given an infinite model of T and any cardinal κ, enlarge the language by constants cα​ for α<κ and add

Every finite subset can interpret its finitely many constants as distinct elements of the original infinite model. By the compactness theorem, the enlarged theory has a model containing at least κ distinct elements; its reduct is a model of T.
Finally, suppose a set S and a finite set T axiomatize the same class. Let τ be the conjunction of the sentences in T. Since S⊨τ, the set S∪{¬τ} is unsatisfiable. Compactness gives a finite S0​⊆S such that S0​⊨τ. Because τ⊨S, we also have S0​⊨S, while S⊨S0​ is immediate. Therefore yes: the finite subset S0​ axiomatizes the same theory. This is finite subaxiomatization from an equivalent finite theory.
