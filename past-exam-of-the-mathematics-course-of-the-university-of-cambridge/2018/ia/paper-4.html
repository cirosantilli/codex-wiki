Fermat's little theorem states that if p is prime, then ap≡a(modp) for every integer a; equivalently, ap−1≡1(modp) when p∤a.
If p≡3(mod4) and x2≡−1(modp), then
xp−1=(x2)(p−1)/2≡(−1)(p−1)/2=−1(modp),
(1)
because (p−1)/2 is odd. This contradicts Fermat's theorem, so x2≡−1(modp) has no solution.
If the primes congruent to 1(mod4) were p1​,…,pk​, set N=(2p1​⋯pk​)2+1. Any prime divisor q of N is odd and has −1 as a quadratic residue. The preceding result forces q≡1(mod4), but q divides none of the pi​ because N≡1(modpi​). This contradiction proves that infinitely many primes are congruent to 1(mod4).

A set is countable if it is finite or bijects with a subset of N. For any f:X→P(X), the Cantor diagonal argument set D={x:x∈/f(x)} differs from every f(y) at y. Hence no such map is surjective. Binary sequences are indicator functions of subsets of N, so {0,1}N≅P(N) is uncountable.
Every member of L corresponds to a unique permutation (a0​,a1​,…) of N, with Fn​={a0​,…,an−1​}. Let p(j) be the position of j.
For L0​, p(n)<n eventually. Choose N after which this holds and then m larger than all p(0),…,p(N−1). The m positions 0,…,m−1 would contain all m+1 values 0,…,m, a contradiction. Thus L0​ is empty, hence countable.
For L1​, p(n)≤n eventually. For every sufficiently large m, all values 0,…,m occur in positions 0,…,m, so this initial segment is invariant. Comparing consecutive invariant initial segments gives p(m)=m eventually. These are the finite-support permutations, of which there are countably many. Hence L1​ is countable.
