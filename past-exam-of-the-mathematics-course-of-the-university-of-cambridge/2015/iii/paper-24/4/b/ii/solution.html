Past exam of the mathematics course of the University of Cambridge / 2015 / iii / Paper 24 / 4 / b / ii / Solution

 ... 2015 iii Paper 24 4 b ii
OurBigBook.com Words: 146
Let M⊆N be transitive models of ZFC containing the set relation R and its underlying set X. If M judges R well founded, it has an ordinal rank function for a relation ρ∈M by the preceding rank characterization. Being a function to ordinals and satisfying
∀x,y∈X (xRy⇒ρ(x)<ρ(y))
(39)
is absolute: the values are actual ordinals and the checks use only bounded formulas in set theory. The same rank function exists in N, so N judges R well founded.
Conversely, if M judged it not well founded, it would contain a nonempty set Y with no R-minimal element. The property of this particular Y is bounded and remains true in N, contradicting well-foundedness there. Thus
M⊨“R is well founded”⟺N⊨“R is well founded”.​
(40)
This is absoluteness of well-foundedness. The hypotheses that both models are transitive and satisfy ZFC matter; a small transitive set without sufficient recursion axioms need not contain the required rank witness.
