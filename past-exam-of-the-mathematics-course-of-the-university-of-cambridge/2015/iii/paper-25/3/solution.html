Past exam of the mathematics course of the University of Cambridge / 2015 / iii / Paper 25 / 3 / Solution

We prove closure under the defining schemes for primitive recursive functions, keeping all unbounded existential variables outside a bounded arithmetic formula. A bounded quantifier means ∃v<t or ∀v<t, where t does not contain v. All formulas are interpreted in the standard natural numbers.
First we need a finite sequence code using only the permitted language of ordered rings. Define the bounded arithmetic formula
B(b,c,i,a):⟺a<1+(i+1)c ∧ (∃q<b+1)[b=q(1+(i+1)c)+a].
(7)
For given b,c,i, it specifies the unique remainder of b modulo 1+(i+1)c. In particular the quotient and remainder variables are bounded by arithmetic terms; division is not a new language symbol.
Every finite list a0​,…,an​ can be coded by some pair b,c. Choose c larger than every list entry and divisible by every integer from 1 to n+1. The moduli mi​=1+(i+1)c are pairwise coprime. Indeed a prime dividing both mi​,mj​ cannot divide c, but then divides j−i; since 0<j−i≤n and c is divisible by that integer, this is impossible. The Chinese remainder theorem gives b with b≡ai​(modmi​) for every i. Since ai​<c<mi​, each B(b,c,i,ai​) holds. This is Gödel beta-function sequence coding. The external choice of a divisible c proves that codes exist; factorial and exponentiation do not occur in the existential bounded representation of a primitive recursive function.
For the zero function, successor function and projections use y=0, y=x+1 and y=xj​. These formulas need no auxiliary variables. For function composition in recursion theory, suppose g1​,…,gm​,h have representations with bounded arithmetic formulas θ1​,…,θm​,θh​. A bounded arithmetic formula for h(g1​(x),…,gm​(x)) is
⋀j=1m​θj​(uj​,x,vj​) ∧ θh​(y,u1​,…,um​,w).
(8)
Treat every uj​,vj​,w as an auxiliary variable in the outer existential block. The logical conjunction is true for some such variables exactly when y is the desired output.
Now suppose
f(0,x)=g(x),f(i+1,x)=h(i,f(i,x),x).
(9)
By structural induction for primitive recursive functions, assume θg​(a,x,v) and θh​(a′,i,a,x,w1​,…,wm​) are bounded arithmetic formulas representing g,h. We code the values f(0,x),…,f(n,x) with b,c. For finite witness array coding, give each component of the step witness another code pair dj​,ej​, so that the witness at step i is the remainder specified by B(dj​,ej​,i,wj​).
With these code pairs and v as free auxiliary variables, take the following bounded arithmetic formula:
ϕ(y,n,x,b,c,d,e,v):⟺​B(b,c,n,y)∧(∃a<1+c)[B(b,c,0,a)∧θg​(a,x,v)]∧(∀i<n)(∃a<1+(i+1)c)(∃a′<1+(i+2)c)(∃w1​<1+(i+1)e1​)⋯(∃wm​<1+(i+1)em​)[B(b,c,i,a)∧B(b,c,i+1,a′)∧j=1⋀m​B(dj​,ej​,i,wj​)∧θh​(a′,i,a,x,w)].​
(10)
The displayed line breaks are only for readability: the bounded quantifiers on the last three lines bind the entire bracket. If m=0, their empty block and logical conjunction are omitted. Expanding every occurrence of B leaves only bounded quantifiers, logical conjunctions, the bounded arithmetic formulas already obtained, and the symbols 0,1,+,×,<,=.
If y=f(n,x), take the actual finite computation values and select witnesses for the finitely many true instances of θh​, together with witnesses for θg​. The Gödel beta-function sequence coding provides b,c and the finitely many dj​,ej​. These make ϕ true. Conversely, suppose some code pairs and initial witnesses make ϕ true. The unique remainders of b give values a0​,…,an​. The initial clause makes a0​=g(x). Every step clause makes ai+1​=h(i,ai​,x), since its coded witnesses satisfy the representing matrix for h. Induction on i gives ai​=f(i,x), and the final remainder clause gives y=an​. This argument includes n=0, when the step condition is empty.
Closure under the initial functions of recursion theory, composition and primitive recursion proves
y=f(x)⟺(∃z)ϕ(y,x,z),ϕ has only bounded quantifiers.​
(11)
Coding the step witnesses is essential: leaving an unrestricted existential witness block inside ∀i<n would not give the required syntactic form.
