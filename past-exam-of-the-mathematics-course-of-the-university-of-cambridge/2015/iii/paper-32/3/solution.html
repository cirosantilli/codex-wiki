The familywise error rate is the probability of rejecting at least one true null:
FWER=P(i∈I0​⋃​{Hi​ is rejected}).​
(17)
A valid p-value is super-uniform under its null: P(pi​≤t)≤t for 0≤t≤1. The Bonferroni correction rejects Hi​ if pi​≤α/m. The union bound gives
FWER≤∑i∈I0​​P(pi​≤α/m)≤m∣I0​∣​α≤α.
(18)
This controls the familywise error rate for every configuration of true and false nulls, without any independence assumption on the p-values.
For a nonempty index set I⊆{1,…,m}, the intersection hypothesis HI​=⋂i∈I​Hi​ asserts that every null indexed by I holds. The closure of a family of statistical hypotheses consists of all these nonempty intersections, including the original hypotheses. For each intersection choose a local test ϕI​ of size at most α under HI​. Such tests always exist: for example, within I use the Bonferroni correction, rejecting HI​ if mini∈I​pi​≤α/∣I∣. More powerful local intersection tests can be substituted whenever valid.
The closed testing procedure rejects an elementary hypothesis Hi​ only when every local test ϕI​ with i∈I rejects its intersection hypothesis. If I0​=∅, the intersection HI0​​ is true. Rejecting any true Hi​ requires rejection by its local test ϕI0​​, so
FWER≤P(ϕI0​​=1)≤α.​
(19)
If I0​=∅, there is no possible false rejection. This proves closed-testing control of the familywise error rate. The same argument applies if intersection hypotheses themselves are reported as rejected: requiring all their supersets to reject includes I0​ whenever the reported intersection is true.
Finally, consider the given hierarchical family as a laminar family of sets. Call a set I∈I true when I⊆I0​, so its entire intersection hypothesis is true. Let M be the inclusion-maximal true sets in I. Distinct members of M are disjoint: if they met, laminarity would make one contain the other, contradicting maximality. Consequently,
∑J∈M​∣J∣≤∣I0​∣≤m.
(20)
Every true set I lies in a maximal true J. If HI​ is rejected by the prescribed adjusted p-value rule, the maximum over its ancestors includes J, hence
pJ​≤mα∣J∣​.
(21)
Thus the event of any false rejection is contained in the union of these events over the disjoint maximal true sets. Using validity of each pJ​ under its true intersection and the union bound,
P(at least one false rejection)≤J∈M∑​mα∣J∣​≤α.​
(22)
Equivalently, with probability at least 1−α every rejection is correct. This proves familywise error control for a laminar hypothesis family. It requires neither independence nor the presence of all possible intersections or singletons in I. Empty index sets are excluded, as required by the denominator ∣J∣; if there are no true sets the result is immediate. Adjusted values exceeding one can be truncated at one without changing decisions for α<1.
