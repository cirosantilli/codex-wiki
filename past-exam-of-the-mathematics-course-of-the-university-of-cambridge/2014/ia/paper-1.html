An eigenvector of a matrix A is a nonzero vector v for which Av=λv. The scalar λ is its eigenvalue. For a fixed eigenvalue, the zero vector together with all corresponding eigenvectors forms the eigenspace ker(A−λI). The requirement v=0 prevents every scalar from being an eigenvalue merely because A0=λ0.

3D OurBigBook.com
Call an index n a peak if an​≥am​ for every m>n. If there are infinitely many peaks, list their indices increasingly. Each selected value is at least every later selected value, so this gives a nonincreasing subsequence.
If there are only finitely many peaks, choose an index beyond the last one. Every index from then onward has a later index with strictly larger value. Select these recursively: nj+1​>nj​ with anj+1​​>anj​​. This gives an increasing subsequence. Neither complex argument requires the original sequence to be bounded. Every real sequence therefore has a monotone subsequence, as asserted by the monotone subsequence theorem.

View a possible complex eigenvector v using the Hermitian inner product. For a real symmetric matrix, A†=A, so v†Av is real. Since v†Av=λv†v and v†v>0, every eigenvalue is real.
For eigenvectors v,w with distinct eigenvalues λ,μ, symmetry gives
λv†w=(Av)†w=v†Aw=μv†w,
(13)
so v†w=0. In particular, real eigenvectors are orthogonal in the real dot product.
Use the permitted diagonalizability assumption to take bases of the real eigenspaces whose union spans Rn. Apply the Gram-Schmidt process within each eigenspace. Its linear combinations remain eigenvectors of that same eigenvalue; vectors in different eigenspaces are already orthogonal. The resulting union is an orthonormal basis of eigenvectors, giving an orthogonal diagonalization of a real symmetric matrix.

The mean value theorem states that a function continuous on [p,q] and differentiable on (p,q) has some c∈(p,q) with f(q)−f(p)=f′(c)(q−p).
Take any p<q inside the given open interval. Differentiability implies the continuity needed on [p,q], and the derivative is zero throughout it. The mean value theorem therefore gives f(q)=f(p). Since the two points were arbitrary, the function is constant on the interval.

For a bounded real function on [0,1], take a partition P with nodes 0=x0​<⋯<xN​=1. Its lower Darboux sum and upper Darboux sum are
L(f,P)=∑j​inf[xj−1​,xj​]​f(xj​−xj−1​),U(f,P)=∑j​sup[xj−1​,xj​]​f(xj​−xj−1​).
(37)
The function is Riemann integrable when supP​L(f,P)=infP​U(f,P); their common value is its Riemann integral. Equivalently, for every η>0 some partition has U−L<η. Indeed a common refinement of nearly extremizing upper and lower partitions proves necessity, while arbitrarily small gaps force equality of the two integrals. This is the Riemann integrability criterion.
A continuous function on a compact interval is bounded and uniformly continuous. Choose a mesh small enough that its oscillation on each subinterval is less than η. Then U−L≤η∑j​(xj​−xj−1​)=η; using η/2 first makes the desired inequality strict. Thus every continuous function on [0,1] is Riemann integrable.

For a nondecreasing function, the endpoint bounds show it is bounded. On the uniform partition into N intervals, its Darboux sums satisfy
U−L=N1​∑j=1N​[f(Nj​)−f(Nj−1​)]=Nf(1)−f(0)​⟶0.

For the unheaded rational-weight example, each summand is nonnegative, and increasing x only adds indices. Hence its sum is nondecreasing and lies between zero and one, including the separately specified value at zero. It is a left-continuous cumulative function of an atomic measure.
If qj​∈[0,1) and qj​<x≤1, the index j appears in the sum at x but not at qj​. All other changes are nonnegative, so f(x)−f(qj​)≥2−j. This remains true for arbitrarily small positive x−qj​, proving discontinuity at qj​, including a right discontinuity at zero when that rational is encountered. Every interval of positive length contains such a rational in its interior. The discontinuities are therefore dense, although the function is Riemann integrable by the monotone-function result just proved.
More concretely, truncate after the first N weights. The resulting finite sum of step functions is integrable, and the uniform tail is at most 2−N. This also proves integrability and gives, if its value is desired,
