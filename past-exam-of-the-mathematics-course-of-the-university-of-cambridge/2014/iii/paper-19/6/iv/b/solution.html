Use the displayed family to form the coherent-injection Aronszajn tree. A node at level β is a restriction eα​↾β for some α≥β. Every such node differs only finitely from eβ​. There are countably many finite subsets of the countable domain β and countably many assignments of natural-number values to each, so there are only countably many possible finite modifications. Hence each level is countable. It is nonempty because it contains eβ​.
Every shorter restriction of a node is again a node, and its predecessors have order type its domain ordinal. Thus this is a set-theoretic tree of height ω1​. If it had an uncountable chain in a partial order, its domain heights would be unbounded in ω1​, since the levels below any countable height contain only countably many nodes. The union of that chain in a partial order would be an injection ω1​→ω, impossible. Therefore
T is an ℵ1​-Aronszajn tree.​
(42)
The countable-level proof uses coherence, whereas the no-branch proof uses injectivity; the two features play different roles.
