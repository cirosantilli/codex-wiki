The axiom of infinity excludes Vω​ and all smaller stages, so the cardinal λ is uncountable. Full semantics for second-order logic is decisive: every externally specified functional relation whose ordered pairs lie in Vλ​ is an allowed class parameter, even if the relation itself is not an element of Vλ​.
If cf(λ)=μ<λ, choose an external cofinal function h:μ→λ. Its graph is an allowed class parameter: each input, output and ordered pair has rank of a set below the infinite cardinal λ, which is a limit ordinal. The domain μ belongs to Vλ​. The second-order form of Axiom schema of replacement would give its range as an element of Vλ​. But a cofinal subset of λ has rank of a set λ and cannot belong to Vλ​. Therefore cf(λ)=λ.
If 2θ≥λ for a cardinal θ<λ, choice supplies an external surjection q:P(θ)→λ. The domain belongs to Vλ​ and the ordered pairs of its graph have ranks below λ. Applying Axiom schema of replacement to this external functional class would put its range, the ordinal λ, in Vλ​, again impossible. Hence 2θ<λ for every θ<λ.
Consequently
λ>ℵ0​,cf(λ)=λ,∀θ<λ (2θ<λ).​
(6)
These are exactly the defining conditions for a strongly inaccessible cardinal. This full second-order replacement rank obstruction would not follow from Henkin semantics, where the available class relations may exclude the external functions just used.
