We give an explicit Gimel recursion for cardinal exponentiation. First recover the continuum function by induction on infinite cardinals. At a regular κ,
2κ=κκ=ℷ(κ),
(19)
because 2κ≤κκ≤(2κ)κ=2κ. At a singular κ, put θ=cf(κ) and s=supρ<κ​2ρ, whose value is already known. A cofinal sequence (κi​)i<θ​ gives
2κ=sθ.​
(20)
Indeed ∏i​2κi​=2∑i​κi​=2κ≤sθ, while s≤2κ gives the reverse inequality after raising to θ.
If the supremum s is attained, the continuum function is eventually constant below κ, and we may choose ρ<κ with ρ≥θ and 2ρ=s. Then sθ=(2ρ)θ=s. If it is not attained, the increasing cofinal power values show cf(s)=θ. To verify the reverse cofinality bound, fewer than θ such lower power values have indices bounded below κ, and cannot be cofinal in s; the upper bound comes from (κi​). Consequently
2κ={s,ℷ(s),​s attained below κ,s not attained below κ.​​
(21)
Every singular-stage value is therefore determined by the previously computed powers and the given Gimel function.
Now fix an infinite exponent λ and recurse on the infinite base κ. If 2≤κ≤λ, then κλ=2λ, already known. For a successor base κ=ρ+>λ, every function λ→κ has bounded range, and each bounded range has size at most ρ. Hence
κλ=max{κ,ρλ}.​
(22)
This is the Hausdorff formula for cardinal exponentiation. For a limit base κ>λ, put a=supρ<κ​ρλ and θ=cf(κ). If θ>λ, all ranges are bounded and counting over those bounds gives κλ=a (here a≥κ).
If θ≤λ, then κλ=aθ. To see the nontrivial upper bound, use a cofinal sequence of bounds κi​. A function λ→κ is coded by the assignment of each argument to one of these θ bounds, together with θ padded functions into the corresponding bounds. The assignment has at most θλ=2λ≤a possibilities, and the functions have at most aθ possibilities. Conversely a≤κλ and (κλ)θ=κλ, giving the lower bound. If a is attained as ρλ, then aθ=a by currying; otherwise cf(a)=θ by the same cofinal-index argument as above. Thus
κλ=⎩⎨⎧​a,a,ℷ(a),​cf(κ)>λ,cf(κ)≤λ and a attained,cf(κ)≤λ and a not attained.​​
(23)
Only smaller-base powers occur in a, so this is a genuine recursion, not an implicit appeal to the unknown power.
Finally, finite positive exponents give κn=κ for infinite κ; finite bases at infinite exponents satisfy mλ=2λ for m≥2. The cases with base 0 or 1, exponent 0, or both arguments finite are elementary, with 00=1 under the empty-function convention. The Gimel function therefore determines both requested class functions completely.
