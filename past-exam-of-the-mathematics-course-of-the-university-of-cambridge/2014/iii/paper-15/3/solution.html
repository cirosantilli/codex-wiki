A fiber metric on a real vector bundle E→M is a smoothly varying positive-definite inner product on each fiber. Choose a trivializing open cover {Ui​} and a smooth partition of unity {ρi​} subordinate to it. The partition theorem gives nonnegative functions summing to one, a locally finite family of subsets of supports, and suppρi​⊂Ui​; the usual Hausdorff second-countable smooth manifold hypotheses ensure this theorem applies. Transfer the Euclidean inner product to each local vector bundle trivialization, obtaining hi​, and set
hx​(v,w)=∑i​ρi​(x)(hi​)x​(v,w).
(11)
Each weighted term extends smoothly by zero outside Ui​, and local finiteness makes the sum smooth in every vector bundle trivialization. At each x some weight is positive, so hx​(v,v)>0 for every nonzero v. This proves existence of a fiber metric, with no orientability or triviality assumption.
A vector bundle morphism covering the identity is a smooth map F:E′→E′′ that preserves base points and is a linear map on each fiber. Its induced map on the module of smooth sections is s↦F∘s, and is C∞(M)-linear. We prove the converse by constructing bundle morphisms from maps of smooth sections.
First the given map α is local. If a global section s vanishes on a neighborhood of x, take a smooth bump function χ supported there with χ=1 near x. Then χs=0, so χα(s)=α(χs)=0, and hence α(s)(x)=0. Thus sections agreeing near x have images agreeing at x.
Choose a local frame e1​,…,er​ on U, and a bump function equal to one on a smaller neighborhood V of x and supported in U. Multiplying the frame by that bump and extending by zero gives global smooth sections tj​ whose restrictions to V are the frame. If s(x)=0, write s=∑aj​ej​ on V. A second bump extends each aj​ to a global smooth function aj​ agreeing near x. By locality and C∞(M)-linearity,
α(s)(x)=∑j​aj​(x)α(tj​)(x)=0.
(12)
Every fiber vector v∈Ex′​ is the value of a global smooth section, by the same bumped-frame construction. Define Fx​(v)=α(s)(x) for any such section. The just-proved vanishing statement makes this well-defined. The maps Fx​ are linear maps, and locally their matrix columns are the smooth sections α(tj​) in a frame of E′′. Thus F is smooth, is a vector bundle morphism, and satisfies α(s)=F∘s. Fiberwise evaluation also proves uniqueness.
Finally apply the fiber metric construction to the tangent bundle. A Riemannian metric g defines the musical isomorphism
♭g​:TM⟶T∗M,v⟼g(v,⋅).​
(13)
Positive definiteness makes it a fiberwise bijection; its inverse is smooth because inverse metric matrices vary smoothly. Hence TM and T∗M are isomorphic as real smooth vector bundles on every such manifold. The isomorphism depends on the chosen metric and is not canonical.
