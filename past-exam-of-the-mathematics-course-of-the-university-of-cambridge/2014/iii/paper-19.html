In the Lévy hierarchy, a bounded formula in set theory has only quantifiers of the forms ∀x∈y and ∃x∈y. A Sigma-one formula in set theory is an existential unbounded quantifier block followed by a bounded formula in set theory, and a Pi-one formula in set theory has a universal unbounded block. A formula is a Delta-one formula modulo ZFC if ZFC proves it equivalent, with the same free variables, both to a Σ1​ formula and to a Π1​ formula. Equivalence modulo the specified theory is part of the definition; it is not necessary that the original string have both syntactic forms. Such formulas satisfy the usual Delta-one absoluteness between transitive models satisfying the relevant axioms. The modulo-ZF analogue is a Delta-one formula in set theory.

A Sierpiński set is an uncountable subset S of R such that S∩N is countable for every set N of Lebesgue measure zero. Equivalently it is enough to test Borel null sets, because every null set is contained in a Borel null set. Uncountability and countable intersection with every null set are both required. This is the measure analogue of the category-based Luzin set condition; it does not say that S itself is measurable.

The cumulative-hierarchy reflection principle says that for every finite collection Φ of formulas and every ordinal γ, there is an ordinal α>γ such that for all φ∈Φ and all parameters a1​,…,an​∈Vα​,
φ(a1​,…,an​) ⟺ (Vα​,∈)⊨φ(a1​,…,an​).​
(1)
Equivalently, all quantifiers on the right are relativized to Vα​. It is a theorem schema of ZF for finite lists of formulas, with reflecting stages arbitrarily high. It does not assert one set-sized stage elementary for every formula at once. By beginning above the ranks of any specified finite parameter list, the parameters can also be required to belong to the reflecting stage.

The Gödel constructible universe theorem gives Con(ZFC)⇒Con(ZFC+CH). The forcing independence theorem for the Continuum hypothesis gives Con(ZFC)⇒Con(ZFC+¬CH). For example, the latter can be obtained by first passing to the constructible universe and then adding sufficiently many Cohen reals. By the equivalence in part (b), these are respectively models of the negation and affirmation of the free-pair assertion. Thus if ZFC is consistent, the assertion is independent of ZFC. The consistency qualification is essential: an inconsistent theory proves every sentence. These are syntactic relative-consistency implications, not a claim that bare consistency supplies a countable transitive model.

The axiom of infinity excludes Vω​ and all smaller stages, so the cardinal λ is uncountable. Full semantics for second-order logic is decisive: every externally specified functional relation whose ordered pairs lie in Vλ​ is an allowed class parameter, even if the relation itself is not an element of Vλ​.
If cf(λ)=μ<λ, choose an external cofinal function h:μ→λ. Its graph is an allowed class parameter: each input, output and ordered pair has rank of a set below the infinite cardinal λ, which is a limit ordinal. The domain μ belongs to Vλ​. The second-order form of Axiom schema of replacement would give its range as an element of Vλ​. But a cofinal subset of λ has rank of a set λ and cannot belong to Vλ​. Therefore cf(λ)=λ.
If 2θ≥λ for a cardinal θ<λ, choice supplies an external surjection q:P(θ)→λ. The domain belongs to Vλ​ and the ordered pairs of its graph have ranks below λ. Applying Axiom schema of replacement to this external functional class would put its range, the ordinal λ, in Vλ​, again impossible. Hence 2θ<λ for every θ<λ.
Consequently
λ>ℵ0​,cf(λ)=λ,∀θ<λ (2θ<λ).​
(6)
These are exactly the defining conditions for a strongly inaccessible cardinal. This full second-order replacement rank obstruction would not follow from Henkin semantics, where the available class relations may exclude the external functions just used.

The bounding number b is the least size of an unbounded family in (ωω,≤∗). The almost disjointness number a is the least size of an infinite maximal almost disjoint family on omega of infinite subsets of ω. Requiring the family to be infinite excludes trivial finite maximal partitions.
A countable family {fi​:i<ω} is bounded by g(n)=1+maxi≤n​fi​(n). Thus ℵ1​≤b.
Suppose an infinite almost disjoint family on omega A has size less than b. Choose distinct members An​ and put Cn​=An​∖⋃i<n​Ai​. These are infinite and pairwise disjoint. For each B∈A, define hB​(n)=max((B∩Cn​)∪{0}) whenever the intersection is finite. If B=An​ at the exceptional index n, set hB​(n)=0. These are the only possible infinite intersections. A single g eventually dominates every hB​, because there are fewer than b of them. Pick xn​∈Cn​ with xn​>g(n) and put X={xn​:n<ω}.
For B not among the selected An​, only finitely many xn​ can lie in B. The same is true for B=Aj​, with its single exceptional index j ignored. Thus X is infinite and almost disjoint from every member of A, so the family was not maximal. This bounding-to-almost-disjointness inequality proves b≤a.
Finally start with an infinite pairwise disjoint family and use Zorn's lemma to extend it to a maximal almost disjoint family on omega. It is a family of subsets of ω, so has cardinality at most 2ℵ0​. Therefore
ℵ1​≤b≤a≤2ℵ0​.​
(11)

Fix a,p​∈L and a formula θ(x,p​). The reflection theorem for definable hierarchies supplies a stage Lβ​ containing these parameters at which the finitely many subformulas of θ have the same truth values as in L, for arguments in Lβ​.
This reflection can be proved in the ambient ZF without presupposing Axiom schema of separation in L: starting at a stage containing the parameters, collect for each relevant existential subformula and every tuple in the current stage the least constructible stage in which a witness occurs, whenever a witness exists in L. Ambient Axiom schema of replacement bounds these ordinals. Iterate these witness-stage bounds for ω steps and take their supremum. Induction on subformulas gives the required finite reflection at the resulting union stage. Only the least stage is chosen, so no ambient axiom of choice is needed.
Since Lβ​ is transitive and contains a, the desired separated subset is
b={x∈Lβ​:x∈a and (Lβ​,∈)⊨θ(x,p​)}.
(12)
It is definable over Lβ​ with parameters there, so b∈Def(Lβ​)=Lβ+1​⊂L. Reflection gives b={x∈a:θL(x,p​)}. Hence ZF proves every Axiom schema of separation instance relativized to L. This is a direct Separation proof in the constructible universe, not an appeal to the assertion being proved.

Use the transitive-model convention for “standard” in this assertion: the domain is a transitive set and membership is actual membership. A standard membership model of set theory without transitivity is a weaker notion and would not justify the asserted absoluteness. Ordinalhood is bounded-formula absolute, so the internal ordinals are precisely A∩Ord. For an infinite cardinal, the Gimel function is ℷ(κ)=κcf(κ). The Gimel hypothesis asserts, for every singular cardinal κ,
ℷ(κ)=max{2cf(κ),κ+}.​
(17)
These are the unavoidable lower bounds supplied by monotonicity of exponentiation and König theorem for cardinal numbers. Martin's axiom at κ, denoted MAκ​, says that whenever a forcing order satisfies the countable chain condition for forcing and {Dξ​:ξ<κ} is a family of dense subsets, there is a filter in an ordered set meeting every Dξ​. Equivalently, allow any family of at most κ dense subsets. The filter in an ordered set is directed towards stronger common extensions and closed towards weaker conditions. A well-pruned set-theoretic tree of height κ has the property that every node t extends to every higher level below κ: if ht(t)<β<κ, there is u of height β with t<T​u. The Beth numbers form a strictly increasing continuous sequence: strictness comes from Cantor theorem, and at a limit δ one has ℶδ​=supξ<δ​ℶξ​. A cofinal sequence in δ of length cf(δ) therefore induces a cofinal sequence in ℶδ​, giving cf(ℶδ​)≤cf(δ).

We give an explicit Gimel recursion for cardinal exponentiation. First recover the continuum function by induction on infinite cardinals. At a regular κ,
2κ=κκ=ℷ(κ),
(19)
because 2κ≤κκ≤(2κ)κ=2κ. At a singular κ, put θ=cf(κ) and s=supρ<κ​2ρ, whose value is already known. A cofinal sequence (κi​)i<θ​ gives
2κ=sθ.​
(20)
Indeed ∏i​2κi​=2∑i​κi​=2κ≤sθ, while s≤2κ gives the reverse inequality after raising to θ.
If the supremum s is attained, the continuum function is eventually constant below κ, and we may choose ρ<κ with ρ≥θ and 2ρ=s. Then sθ=(2ρ)θ=s. If it is not attained, the increasing cofinal power values show cf(s)=θ. To verify the reverse cofinality bound, fewer than θ such lower power values have indices bounded below κ, and cannot be cofinal in s; the upper bound comes from (κi​). Consequently
2κ={s,ℷ(s),​s attained below κ,s not attained below κ.​​
(21)
Every singular-stage value is therefore determined by the previously computed powers and the given Gimel function.
Now fix an infinite exponent λ and recurse on the infinite base κ. If 2≤κ≤λ, then κλ=2λ, already known. For a successor base κ=ρ+>λ, every function λ→κ has bounded range, and each bounded range has size at most ρ. Hence
κλ=max{κ,ρλ}.​
(22)
This is the Hausdorff formula for cardinal exponentiation. For a limit base κ>λ, put a=supρ<κ​ρλ and θ=cf(κ). If θ>λ, all ranges are bounded and counting over those bounds gives κλ=a (here a≥κ).
If θ≤λ, then κλ=aθ. To see the nontrivial upper bound, use a cofinal sequence of bounds κi​. A function λ→κ is coded by the assignment of each argument to one of these θ bounds, together with θ padded functions into the corresponding bounds. The assignment has at most θλ=2λ≤a possibilities, and the functions have at most aθ possibilities. Conversely a≤κλ and (κλ)θ=κλ, giving the lower bound. If a is attained as ρλ, then aθ=a by currying; otherwise cf(a)=θ by the same cofinal-index argument as above. Thus
κλ=⎩⎨⎧​a,a,ℷ(a),​cf(κ)>λ,cf(κ)≤λ and a attained,cf(κ)≤λ and a not attained.​​
(23)
Only smaller-base powers occur in a, so this is a genuine recursion, not an implicit appeal to the unknown power.
Finally, finite positive exponents give κn=κ for infinite κ; finite bases at infinite exponents satisfy mλ=2λ for m≥2. The cases with base 0 or 1, exponent 0, or both arguments finite are elementary, with 00=1 under the empty-function convention. The Gimel function therefore determines both requested class functions completely.

For a regular uncountable kappa-tree, keep exactly the nodes whose extensions have unbounded heights:
T∗={t∈T:sup{ht(u):u≥T​t}=κ}.
(24)
This set is predecessor-closed. At any level α, if no node survived, the extension heights above each of its fewer than κ nodes would be bounded. Regularity would give a single bound for their union, contradicting the height of the original set-theoretic tree. Thus every level of T∗ is nonempty and still has size less than κ.
If t∈T∗ and β>ht(t), consider its extensions at level β. If none survived, fewer than κ bounded extension sets would again bound every extension of t, a contradiction. Therefore a surviving level-β extension exists. Hence
T∗ is a well-pruned κ-subtree.​
(25)
This unbounded-extension kernel of a regular tree uses regularity essentially. If one permits singular-height set-theoretic trees in the term “κ-tree”, the unrestricted assertion is false: take fewer than κ disjoint branches with lengths cofinal in a singular κ. The levels are small and the height is κ, but no node has unbounded extensions. A common root can be added without creating a well-pruned subtree. The usual regular-height convention is therefore the one used here.

Prune an ℵ1​-Suslin tree as in part (a), then use its nodes as forcing conditions, with extensions stronger. Two conditions are compatible exactly when comparable, so the absence of uncountable tree antichains is the forcing countable chain condition for forcing. For each α<ω1​, the set Dα​ of nodes of height at least α is dense, by well-pruned set-theoretic tree.
If 2ℵ0​>ℵ1​, full Martin's axiom includes MAℵ1​​. It would provide a filter in an ordered set meeting all these dense subsets of a forcing order. Directedness makes that filter in an ordered set a chain in a partial order, and meeting every Dα​ makes its heights unbounded, producing an uncountable branch. This contradicts the Suslin-tree property. A Suslin set-theoretic tree together with failure of Continuum hypothesis therefore implies failure of Martin's axiom. This is the Suslin-tree obstruction to Martin's axiom.

Use the standard normal set-theoretic tree convention: a unique root, extensions at every higher level, splitting into at least two successors, and tree with unique limits. The small-level and height assumptions already give an ω1​-tree, while the given tree antichain condition gives the countable chain condition for forcing. We only need to exclude an uncountable branch.
If such a branch existed, its heights would be unbounded, since each initial segment contains only countably many nodes. Fill in predecessors to obtain its node bα​ at every level. At each successor step choose a successor sα​ of bα​ different from bα+1​. For α<β, the node sβ​ extends the branch successor bα+1​, and so is incompatible with sα​. Thus {sα​:α<ω1​} is an uncountable tree antichain, a contradiction.
Therefore the set-theoretic tree is ℵ1​-Suslin. The splitting part of normality matters: a single chain in a partial order of height ω1​ would satisfy the tree antichain condition but not the conclusion if one used a weakened definition of normality allowing no splitting.

At a limit stage, if Dα​ codes a maximal tree antichain of the current set-theoretic tree below α, require every chosen branch to meet it. This is possible: for any starting node t, maximality provides a comparable tree antichain member; if above t, first extend to it, and if below t, it has already been met. There is a club set of countable limit stages α closed under these witness choices: starting from any bound, repeatedly bound the heights of witnesses for all the countably many nodes below the current stage, and take the supremum after countably many steps. The decisive step is antichain sealing by diamond, with maximality below a correctly guessed club set stage verified explicitly.
