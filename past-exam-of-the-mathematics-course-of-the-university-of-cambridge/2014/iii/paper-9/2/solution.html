Past exam of the mathematics course of the University of Cambridge / 2014 / iii / Paper 9 / 2 / Solution

A rational matrix A=(a1​ ⋯ an​) is partition regular over the positive integers if every finite colouring of N admits a vector x∈Nn whose coordinates all have the same colour and satisfy Ax=0. Equal coordinates are allowed. Rado's theorem says that this holds exactly when the columns can be partitioned into nonempty blocks I0​,…,It​ with
b0​=∑i∈I0​​ai​=0,bj​=∑i∈Ij​​ai​∈spanQ​{ai​:i∈I0​∪⋯∪Ij−1​}(j≥1).
(8)
This is the columns condition. Clearing an overall denominator lets us prove necessity for an integer matrix.
Suppose the columns condition fails. There are only finitely many ordered partitions of the finite column index set. For each ordered partition, choose a failing block: its sum bj​ is outside the rational span of preceding columns, with that span interpreted as zero for the first block. Finite-dimensional linear algebra gives a rational linear functional vanishing on that span but not on bj​. For completeness, take a basis of the span, append bj​, extend to a basis of the column space, and prescribe values zero on the first basis vectors and one on bj​. Clearing the functional's denominators gives an integer row functional ℓ with ℓ(bj​)=0.
Choose one prime p larger than the absolute values of all these finitely many nonzero integers ℓ(bj​). Colour each positive integer by its first nonzero base-p digit:
χp​(x)=p−vp​(x)x(modp)∈{1,…,p−1}.
(9)
Assume a monochromatic solution x exists, and partition its coordinates into blocks of equal P-adic valuation, ordered by increasing valuations v0​<⋯<vt​. Their first nonzero digit is a common d=0(modp). For this ordered partition take its chosen failing block Ij​ and functional ℓ. Apply ℓ to ∑i​ai​xi​=0. All preceding-block terms disappear exactly. Divide the remaining integer equation by pvj​ and reduce modulo p. Later blocks disappear, while the current block gives
0≡dℓ(∑i∈Ij​​ai​)(modp).
(10)
This contradicts the prime's choice. Thus the colouring has no monochromatic solution, proving necessity. This is the finite separating-functional proof of the columns condition; it needs neither a limiting argument nor a bound on the valuations themselves.
For sufficiency, suppose the blocks satisfy the columns condition. Choose rational coefficients qji​, for i in preceding blocks, such that
bj​+∑i∈I0​∪⋯∪Ij−1​​qji​ai​=0(j≥1).
(11)
Let c be a positive integer clearing their denominators, and choose an integer P≥1 bounding all ∣cqji​∣. Use the allowed monochromatic m-p-c set theorem with t+1 generators. We use the triangular convention in which the resulting positive integer set contains every number
cuj​+∑k=j+1t​λk​uk​(0≤j≤t,λk​∈Z, ∣λk​∣≤P)
(12)
in one colour. This is an m-p-c set, with the generator indices reversed if the alternative lower-triangular convention is used. The permitted theorem applies to either convention, since it applies to every finite number of generators. Its set lies in N, so all of the displayed combinations are positive.
For i∈Ij​, define
xi​=cuj​+∑k=j+1t​cqki​uk​.
(13)
Each coordinate belongs to that monochromatic set. Summing the column contributions and collecting coefficients of uk​ gives
∑i​ai​xi​=c∑k=0t​uk​[bk​+∑i∈I0​∪⋯∪Ik−1​​qki​ai​]=0.
(14)
For k=0 the inner sum is empty and b0​=0. This proves sufficiency by a Rado solution inside an m-p-c set, and completes the theorem.
For the requested application, choose
r=1.​
(15)
The matrix, in the coordinate order (x,y,z,w), has columns
ax​=(3,1)T,ay​=(1,−2)T,az​=(−3,0)T,aw​=(0,−1)T.
(16)
The block I0​={x,z,w} has zero sum. The remaining column satisfies ay​=−az​/3+2aw​, so it is in the span of the first block. By Rado's theorem, positive monochromatic x,y,z,w satisfy the system. In particular,
3x+y=3z,x−2y=w>0.​
(17)
One can see the positivity directly in the same triangular construction: a monochromatic set containing 3u+λv for ∣λ∣≤6, together with 3v, gives
x=3u,y=3v,z=3u+v,w=3u−6v.
(18)
All four are positive because they belong to that positive m-p-c set. This is a partition-regular system forcing an ordered Schur relation.
