Suppose F:X→P(X) were a surjection onto the power set of the set X. Form the subset
D={x∈X:x∈/F(x)}.
(1)
Surjectivity would give a∈X with F(a)=D. But then a∈D holds exactly when a∈/F(a)=D, a contradiction. Hence no such surjection exists, and in particular there is no bijection between a set and its power set. This is the diagonal construction in Cantor's theorem; it also covers the empty set, whose power set has one element.

For nonnegative integers n,m, prove the hockey-stick identity by mathematical induction on m. The induction base case m=0 is (0n​)=(0n+1​)=1. If the formula holds through m−1, Pascal's identity gives
∑j=0m​(jn+j​)=(m−1n+m​)+(mn+m​)=(mn+m+1​).
(3)
This supplies the inductive step.
A binary string containing exactly n zeroes and j ones has length n+j. Choosing its j one-positions gives (jn+j​) possibilities. Different values of j give disjoint collections, so counting binary strings with bounded ones yields
j=0∑m​(jn+j​)=(mn+m+1​).​
(4)
This includes n=0: the m+1 strings are the empty string and the all-one strings of lengths one through m.

For a prime number p, the nonzero residue classes form the multiplicative group of the finite field Fp​. Every class has a unique multiplicative inverse. A class equals its own inverse precisely when x2=1, so (x−1)(x+1)=0 in the field and x=1 or x=−1.
For an odd prime, pair each remaining class with its distinct inverse. Each pair contributes one to the product, leaving
(p−1)!≡1⋅(−1)=−1(modp).​
(10)
For p=2, the same congruence is 1≡−1(mod2). This proves Wilson's theorem.

Mathematical induction consists of an induction base case P(1) and an inductive step P(n)⇒P(n+1) for every positive integer n. To derive it from the well-ordering principle, suppose the set of counterexamples were nonempty and take its least element n. The base case excludes n=1. If n>1, minimality gives P(n−1), and the step then gives P(n), a contradiction. Hence there are no counterexamples.
For the stated integer congruence, the base case is 9≡2(mod7). If 9n≡2n(mod7), multiplication and 9≡2(mod7) give
9n+1≡9⋅2n≡2n+1(mod7),
(23)
completing the induction.
The purported shifted-sum proof has a correct conditional successor calculation, but the base case is missing and false: at n=1 it would assert 1=1+126. An inductive step without a true induction base case cannot establish any instance.
