A combinatorial line in [k]N fixes all coordinates outside a nonempty set J and puts the same variable letter in every coordinate of J. The Hales-Jewett theorem asserts that for every k,r≥1, some N forces a monochromatic combinatorial line in every r-colouring of [k]N. We prove it by mathematical induction on k, using an explicit alphabet insensitivity lemma.
A d-dimensional combinatorial subspace fixes some coordinates and has d disjoint nonempty variable blocks. It is (a,b)-insensitive if changing any parameter from a to b or back leaves the colour unchanged. For k≥2, fixed a=b∈[k], r colours and any required dimension d, we now construct such a subspace without assuming the Hales-Jewett theorem.

Process blocks from right to left. When processing block i, the later blocks already have their variable templates. For each 0≤t≤Li​, consider atbLi​−t in block i. Record its colour profile for every earlier word in [k]Pi​ and every assignment of the d−i later parameters. There are kPi​+d−i contexts and at most rkPi​+d−i=Li​ profiles. The Li​+1 chain words therefore contain two equal profiles by the pigeonhole principle.
If their indices are s<t, replace the block by the variable template
asvt−sbLi​−t,v∈[k].
(8)
Its active block is nonempty. The values v=a,b recover those two equal-profile words, so the colour is unchanged by interchanging a,b, for every earlier word and every later parameter assignment. Insensitivity already established in a later block persists, since it was established uniformly over all earlier words, including every subsequent restriction of block i. Continuing leftward gives the promised d-dimensional combinatorial subspace. This proves the explicit block bound for alphabet insensitivity and its required uniformity.
The one-letter case of the Hales-Jewett theorem is immediate: take N=1. Suppose it is proved for k−1 letters and every number of colours. Let d be a dimension guaranteed for k−1 letters and r colours. Obtain a d-dimensional (k−1,k)-insensitive combinatorial subspace by the lemma. Restrict its parameter alphabet to [k−1] and apply the induction hypothesis. The resulting monochromatic combinatorial line uses some nonempty set of parameters. Its extra k-letter point has the same colour as its (k−1)-letter point: interchange k−1,k in those parameters one at a time. The union of their active blocks is nonempty, so the extended line is a genuine combinatorial line in the original word space. This completes the letter-merging proof of the Hales-Jewett theorem.
To deduce the Van der Waerden theorem, take alphabet {0,…,m−1} and pull a finite colouring of the positive integers back by
π(w)=1+∑j=1N​wj​.
(9)
A monochromatic combinatorial line with active set J maps to
a, a+d,…,a+(m−1)d,a=1+∑j∈/J​wj​>0,d=∣J∣>0.
(10)
Thus every finite colouring of the positive integers contains a monochromatic arithmetic progression of each prescribed finite length. Since the map only uses [1,1+N(m−1)], this also gives the finite interval version, with an interval bound W(r,m).
The Strengthened Van der Waerden theorem requires the common difference to have the same colour: for every r,m some finite interval forces a monochromatic set
{d,a,a+d,…,a+(m−1)d},a,d>0.​
(11)
For m=1, take a=d=1. For m≥2, prove the assertion by mathematical induction on r, writing B(r,m) for a sufficient interval bound. The one-colour case has a=d=1 and B(1,m)=m. Suppose M=B(r−1,m) is known. Apply the ordinary Van der Waerden theorem to find a monochromatic progression
a,a+d,…,a+(L−1)d,L=(m−1)M+1,
(12)
in [N], where N=W(r,L); call its colour γ. As (L−1)d<N, every point td with 1≤t≤M also lies in [N].
If one such td has colour γ, the m points a,a+td,…,a+(m−1)td lie in the original progression and have that colour, together with their difference td. Otherwise the pulled-back finite colouring t↦χ(td) on [M] uses at most r−1 colours. By the induction hypothesis it contains {e,b,b+e,…,b+(m−1)e} of one colour. Multiplication by d gives the required set with starting point bd and common difference ed. This proves the strengthened theorem with
B(r,m)=W(r,(m−1)B(r−1,m)+1)(r≥2,m≥2).
(13)
This is the colour-count argument behind the Brauer progression theorem.
The Gallai theorem for an integer lattice states that every finite colouring of Nd contains a monochromatic homothetic copy of each finite lattice pattern. More precisely, for finite S⊆Zd there exist q∈N and b∈Zd with b+qS⊆Nd monochromatic. For S⊆Nd, the translation vector can also be chosen positive.
The empty pattern is trivial. Otherwise first translate the pattern so its points v1​,…,vk​ have nonnegative coordinates. Pull the given finite colouring back to words through the sum map from words to homothetic copies
Φ(w)=1+∑j=1N​vwj​​∈Nd.

1+∑j∈/J​vwj​​+∣J∣vi​,1≤i≤k.
