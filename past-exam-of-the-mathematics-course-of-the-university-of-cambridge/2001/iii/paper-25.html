Use binary linear codes C⊆C′⊆F2N​, with dimensions k,k′. For each coset u+C in C′/C, define
∣u+C⟩=∣C∣​1​∑c∈C​∣u+c⟩.
(1)
Representatives of one coset give the same vector, and distinct cosets have disjoint computational supports, so these vectors are orthonormal. Their span is the CSS code X, encoding k′−k logical qubits in N physical qubits​.
For a,b∈F2N​, write Xa=⨂j​Xjaj​​ and Zb=⨂j​Zjbj​​. The code is stabilized by Xc for c∈C, because it permutes the sum, and by Zz for z∈(C′)⊥, because z⋅(u+c)=0. These Pauli operators commute: c⋅z=0. There are k+N−k′ independent stabilizer generators, so their common positive eigenspace has dimension 2N−(k+N−k′)=2k′−k; it is exactly the span above.
The commuting check measurements separate the two types of error. A bit error Xa changes the signs of the Z checks by (−1)z⋅a, giving the ordinary syndrome of a for C′. A phase error Zb changes the X checks by (−1)c⋅b, giving the syndrome of b for the dual code C⊥. If C′ corrects tX​ bit errors and C⊥ corrects tZ​ bit errors, these checks identify the respective patterns, and inverse Pauli operations recover the state without revealing the logical coset. This is the nested-code CSS syndrome recovery procedure.
The sharper distances account for harmless stabilizer errors. A Pauli XaZb commutes with every check precisely when a∈C′ and b∈C⊥. Among these, it acts as a stabilizer, up to a phase, precisely when a∈C and b∈(C′)⊥. To justify the latter assertion, Xa with a∈C′∖C permutes distinct logical cosets, while Zb with b∈C⊥∖(C′)⊥ has unequal signs on two such cosets. Neither can act as a scalar, and a combined operator has the same nontrivial permutation or phase distinction. For positive logical dimension set
dX​=mina∈C′∖C​wt(a),dZ​=minb∈C⊥∖(C′)⊥​wt(b).
(2)
The quantum code distance is d=min(dX​,dZ​)​: a nontrivial logical Pauli has at least one nonstabilizer component of weight at least the corresponding distance, while a pure X or pure Z logical operator attains the minimum. The weight of XaZb counts the union of its supports, so this argument also includes Y errors.
Here is the correction proof for coherent errors, not only a classical decoding argument. Let P be the code projector and let E,F have bit-component weights at most tX​ and phase-component weights at most tZ​. If 2tX​<dX​ and 2tZ​<dZ​, the corresponding components of E†F have weights below dX​,dZ​. If this product anticommutes with a stabilizer S, then P(E†F)P=−P(E†F)P=0, using SP=P. If it commutes with all stabilizers, the weight bounds force its two components into C and (C′)⊥, so its code compression is a scalar multiple of P. Thus the Knill--Laflamme condition holds for the entire error family.
To see directly why this gives a common recovery, diagonalize its positive Gram matrix cEF​ and form the corresponding error combinations Fj​. Their restrictions obey PFj†​Fl​P=cj​δjl​P. For cj​>0, Fj​P/cj​​ is an isometry onto a syndrome subspace, and the different images are orthogonal. Measure these subspaces and apply the inverse isometry; zero-cj​ combinations annihilate the code. This recovers every quantum channel whose Kraus operators lie in the error span. Arbitrary operators supported on at most t qubits expand in Pauli operators with the same support. Consequently the CSS code corrects all errors on up to t=⌊(d−1)/2⌋​ qubits, and more generally the asymmetric family just described. The sufficient classical bound is obtained by replacing dX​,dZ​ by the minimum distances of C′ and C⊥, respectively; degeneracy can improve it.

The four Pauli matrices form an orthogonal basis of 2×2 matrices for the Hilbert-Schmidt inner product, since Tr(σμ​σν​)=2δμν​. A Hermitian density matrix therefore has real coefficients in this basis, and its trace-one condition fixes the identity coefficient. Thus
ρ=21​(I+nx​σx​+ny​σy​+nz​σz​),nj​=Tr(ρσj​).​
(3)
The multiplication rule for the Pauli matrices σi​σj​=δij​I+iϵijk​σk​ implies (n⋅σ)2=∥n∥2I. Its trace is zero, so for n=0 its eigenvalues are ±∥n∥; for n=0 it vanishes. Hence
λ±​(ρ)=21±∥n∥​.
(4)
Positivity is equivalent to ∥n∥≤1. Conversely every real vector in this unit ball defines a positive trace-one matrix by the boxed formula. Therefore Φ(ρ)=n is a one-to-one correspondence with the Bloch ball, with the displayed inverse. Each coordinate is linear in ρ, proving the affine property under any convex mixture.
A density matrix is pure precisely when its eigenvalues are 1,0, equivalently when ρ2=ρ. The eigenvalue formula makes this equivalent to ∥n∥=1. Alternatively Trρ2=(1+∥n∥2)/2. Thus the pure states correspond exactly to the Bloch sphere.
For n=0, put n=n/∥n∥. The spectral projectors for the larger and smaller eigenvalues are
P+​=21​(I+n⋅σ),P−​=21​(I−n⋅σ).
(5)
They are orthogonal rank-one projections, have sum I, and give ρ=λ+​P+​+λ−​P−​. For normalized eigenvectors in this nondegenerate case they equal ∣ϕ1​⟩⟨ϕ1​∣ and ∣ϕ2​⟩⟨ϕ2​∣. Their Bloch vectors are therefore n1​=n/∥n∥,n2​=−n/∥n∥​, the antipodal eigenprojectors of a qubit density matrix.
At n=0, the state is I/2 and both eigenvalues coincide. There is no distinguished direction and the printed directional expression is undefined. Any orthonormal eigenbasis gives an antipodal pair of pure-state Bloch vectors, since its two projectors sum to I, but that pair can point in any direction. The nonzero-n qualification is essential. The PDF denominators are ∥n∥, not the converted TeX denominators involving n1​,n2​.

Use logarithms to base two and set 0log2​0=0. For a density matrix with eigenvalues (λj​), the Von Neumann entropy is
S(ρ)=−Tr(ρlog2​ρ)=−j∑​λj​log2​λj​.​
(6)
Thus it is the Shannon entropy of the spectrum. In dimension d, each term is nonnegative, and entropy vanishes exactly when one eigenvalue is one, namely for a pure state. The Jensen inequality applied to the strictly concave function −xlog2​x gives S(ρ)≤log2​d, with equality precisely at the maximally mixed state I/d. Unitary conjugation preserves eigenvalues, so S(UρU†)=S(ρ). Product eigenvalues give
S(ρ⊗σ)=−∑i,j​λi​μj​log2​(λi​μj​)=S(ρ)+S(σ).
(7)
The finite-dimensional entropy is continuous because the eigenvalues depend continuously on the matrix and −xlogx is continuous also at zero.
Define the partial trace over K2​ by choosing an orthonormal basis (eb​) and setting
ρ1​=∑b​(I⊗⟨eb​∣)ρ(I⊗∣eb​⟩).
(8)
Equivalently it is uniquely characterized by Tr(ρ1​A)=Tr(ρ(A⊗I)) for every operator A on K1​. This identity proves basis independence. Define ρ2​ similarly, with Tr(ρ2​B)=Tr(ρ(I⊗B)). Hermiticity is preserved by the displayed sum. For each u∈K1​,
⟨u,ρ1​u⟩=∑b​⟨u⊗eb​,ρ(u⊗eb​)⟩≥0.
(9)
Taking the trace in a product orthonormal basis gives Trρ1​=Trρ=1, and the same proof works for ρ2​. Thus both reductions are density matrices. This is the partial trace positivity from product vectors argument.
For a bipartite pure state ρ=∣ψ⟩⟨ψ∣, expand ψ in a product orthonormal basis with coefficient matrix C. A singular value decomposition gives the Schmidt decomposition
∣ψ⟩=∑j=1r​sj​∣aj​⟩⊗∣bj​⟩,sj​>0,∑j​sj2​=1,
(10)
with orthonormal families on both sides. Taking the two partial traces makes all cross terms vanish:
ρ1​=∑j​sj2​∣aj​⟩⟨aj​∣,ρ2​=∑j​sj2​∣bj​⟩⟨bj​∣.
(11)
The spectra may have different numbers of zeros but have identical nonzero eigenvalues. Consequently the reduced entropies coincide:
S(ρ1​)=S(ρ2​)=−j∑​sj2​log2​sj2​.​
(12)
This common value is the entanglement entropy. In infinite-dimensional trace-class systems the same partial-trace and Schmidt arguments apply, and the equality remains valid with the value +∞ allowed; the bound log2​d is specifically finite-dimensional.
For completeness, the basic mixing and correlation properties also admit short proofs. Define quantum relative entropy by D(τ∥σ)=Trτ(log2​τ−log2​σ) when supports are included, and by +∞ otherwise. Here is its nonnegativity proof without merely citing an operator inequality. Diagonalize τ,σ with eigenvalues ri​,sj​, and let qij​ be the squared overlaps of their eigenbases. Both row and column sums of q are one. The scalar inequality rln(r/s)≥r−s, with zero cases taken by limits, gives
(ln2)D(τ∥σ)=∑i,j​qij​ri​ln(ri​/sj​)≥∑i,j​qij​(ri​−sj​)=0.
(13)
Equality forces ri​=sj​ on every nonzero overlap, hence τ=σ. For ρ​=∑i​pi​ρi​, expanding the trace definition yields
S(ρ​)−∑i​pi​S(ρi​)=∑i​pi​D(ρi​∥ρ​)≥0,
(14)
which proves Concavity of Von Neumann entropy.
The complementary entropy bounds for a quantum mixture are
∑i​pi​S(ρi​)≤S(ρ​)≤H(p)+∑i​pi​S(ρi​).
(15)
To prove the upper bound, write the spectral pure-state decompositions of the ρi​ as one ensemble with weights wij​=pi​λij​. Form the column matrix with columns wij​​∣ψij​⟩. Its two Gram operators have the same nonzero spectrum: one is ρ​, and the other, G, has diagonal w. Relative entropy against diagw gives 0≤D(G∥diagw)=H(w)−S(G). Since H(w)=H(p)+∑i​pi​S(ρi​) and S(G)=S(ρ​), the bound follows. Zero-weight columns are omitted.
Finally the support of ρ is contained in suppρ1​⊗suppρ2​. Indeed, a vector in a marginal kernel gives a sum of nonnegative product-vector expectations equal to zero; positivity forces the corresponding product vectors into the kernel of ρ. The operator identity log(ρ1​⊗ρ2​)=logρ1​⊗I+I⊗logρ2​ on this support and the partial-trace identities give
0≤D(ρ∥ρ1​⊗ρ2​)=S(ρ1​)+S(ρ2​)−S(ρ).
(16)
This proves Subadditivity of Von Neumann entropy, with equality exactly for a product state. Purify ρ12​ by adjoining a third system, using its spectral decomposition. Equality of pure-state marginal entropies gives S(ρ13​)=S(ρ2​) and S(ρ3​)=S(ρ12​). Subadditivity on systems 1,3 then gives S(ρ2​)≤S(ρ1​)+S(ρ12​); swapping 1,2 gives the Araki–Lieb inequality ∣S(ρ1​)−S(ρ2​)∣≤S(ρ12​)​. These finite-dimensional proofs establish the usual basic entropy bounds, rather than attributing all mixed-state behavior to pure-state Schmidt decompositions.

On an N-dimensional register, the quantum Fourier transform with positive-exponent convention is
FN​∣x⟩=N​1​y=0∑N−1​e2πixy/N∣y⟩.​
(17)
It is the unitary version of the discrete Fourier transform on amplitudes. The inner product of columns x,x′ is N−1∑y​e2πi(x′−x)y/N, equal to one when x=x′ and zero otherwise by a finite geometric series, so the transformation is unitary.
For the qubit implementation take N=2n, write x=x1​⋯xn​ in most-significant-bit-first order, and put 0.xj​⋯xn​=∑l=jn​xl​2−(l−j+1). Expanding y=∑j​yj​2n−j separates the Fourier phase as a product. The resulting dyadic quantum Fourier transform circuit identity is
F2n​∣x1​⋯xn​⟩=2​∣0⟩+e2πi0.xn​∣1⟩​⊗2​∣0⟩+e2πi0.xn−1​xn​∣1⟩​⊗⋯⊗2​∣0⟩+e2πi0.x1​⋯xn​∣1⟩​.​
(18)
Indeed the phase on output bit yj​ is e2πixyj​/2j, depending on the last j input bits; multiplying the factors recovers e2πixy/2n and the normalization 2−n/2.
Implement the product in reverse wire order as follows. Process input wire j, starting at j=1. A Hadamard gate maps ∣xj​⟩ to (∣0⟩+e2πixj​/2∣1⟩)/2​. For each still-unprocessed wire l>j, apply a controlled phase gate with control l, target j, and target phase
Rl−j+1​=diag(1,e2πi/2l−j+1).
(19)
On a computational-basis input this multiplies the target's one-component by e2πixl​/2l−j+1, so the processed wire becomes exactly (∣0⟩+e2πi0.xj​⋯xn​∣1⟩)/2​. Continue through all wires and reverse their order using SWAP gates. This equals the boxed transform on every basis vector and therefore on arbitrary superpositions by linearity; it does not require learning the input bits by measurement.
There are n Hadamards,n(n−1)/2 controlled phase gates,⌊n/2⌋ swaps​. A swap is three controlled-NOT gates, since the alternating control directions send (a,b) successively to (a,a⊕b), then (b,a⊕b), and finally (b,a). Thus the exact transform uses O(n2) one- and two-qubit gates from this phase-gate family, polynomial in the register size n=log2​N. This is a circuit-complexity statement, not a claim that all N transformed amplitudes can be read out efficiently. If a fixed finite gate alphabet is required, the phase rotations must instead be synthesized to the desired accuracy; the exact count treats them as the available simple rotation gates.
