For distinct coordinates i,j, let Eij​(t)=I+teij​, where eij​ is the matrix unit. For t=0 this is a transvection: it fixes the hyperplane with jth coordinate zero pointwise, has determinant one and inverse Eij​(−t). We show these elementary transvection matrices generate SL(n,F) over any field.
Let M∈SL(n,F). Row addition is left multiplication by an Eij​(t). If the current diagonal pivot is zero, a nonzero entry occurs below it in the same remaining column, since the remaining square block is invertible; adding that row makes the pivot nonzero. Row additions then clear the entries below the pivot. Repeating produces an upper-triangular matrix with nonzero diagonal. Clearing the entries above the diagonal, starting from the last column, gives a diagonal matrix D=diag(a1​,…,an​) with ∏i​ai​=1. Thus it remains to realize determinant-one diagonal matrices using elementary transvections.
In a two-coordinate block put
w(a)=E12​(a)E21​(−a−1)E12​(a)=(0−a−1​a0​).
(18)
Direct multiplication gives
w(a)w(−1)=diag(a,a−1).​
(19)
The diagonal matrix D is the product, for i=1,…,n−1, of these blocks on coordinates i,n, with entries ai​,ai−1​. Their final nth entry is ∏i<n​ai−1​=an​. Therefore D, and hence M, is a product of elementary transvections. All row operations used are invertible transvections, and no division except by a nonzero pivot or ai​ has been made. This proves
SL(n,F)=⟨Eij​(t):i=j, t∈F⟩.​
(20)
The identity element Eij​(0) can be omitted from the generating set. This is transvections generate the special linear group; ordinary row scaling alone would not prove it, because such a scaling can leave SL(n,F).
