Start with the approximate surjectivity with geometric correction argument. For a fixed y, put r0​=y. Choose xj​ successively so that
∥xj​∥≤R∥rj−1​∥,rj​=rj−1​−Txj​,∥rj​∥≤k∥rj−1​∥.
(1)
Induction gives ∥rj​∥≤kj∥y∥ and ∥xj​∥≤Rkj−1∥y∥. The series ∑j​xj​ is absolutely convergent in the Banach space V, because the sum of its norms is bounded by the convergent geometric series R∥y∥/(1−k). Write its sum as x. The bounded linear operator T commutes with this limit, while T∑j=1m​xj​=y−rm​→y. Consequently
Tx=y,∥x∥≤1−kR​∥y∥.​
(2)
The choices need not depend linearly on y; no bounded linear right inverse is being asserted.
For the bounded extension, use the restriction bounded linear operator S:Cb​(X;R)→Cb​(Y;R) on the Banach spaces of bounded continuous functions, each with its supremum norm. We will construct an approximation to any g with ∥g∥∞​=M>0. The two sets
A={y∈Y:g(y)≤−M/3},B={y∈Y:g(y)≥M/3}
(3)
are disjoint closed sets in X, since Y is closed. If both are nonempty, the distance to a set construction defines a continuous function
u(x)=3M​d(x,A)+d(x,B)d(x,A)−d(x,B)​.
(4)
The denominator is positive at every point: zero distance to a closed set means membership in that set. Thus ∥u∥∞​≤M/3, with u=−M/3 on A and u=M/3 on B. On A and B, and also on the intervening range ∣g∣<M/3, this implies
∥Su−g∥∞​≤2M/3.
(5)
If only A is empty take u=M/3, if only B is empty take u=−M/3, and if both are empty take u=0; the same bounds hold. For M=0 take u=0. This proves the approximation hypothesis with R=1/3 and k=2/3. Applying the argument above to S yields an element h of the bounded continuous functions with h∣Y​=g and ∥h∥∞​≤∥g∥∞​. Restriction gives the reverse inequality, so the extension preserves the exact supremum norm:
∥h∥∞​=∥g∥∞​.​
(6)
This proves the bounded metric-space case of the Tietze extension theorem rather than presupposing it.
For an arbitrary real continuous function f on Y, let g=tanhf. Its values lie strictly between −1 and 1, although its supremum norm can be 1. The bounded result supplies an extension h with ∣h∣≤1. Let D={x:∣h(x)∣=1}, a closed set disjoint from Y. If D is nonempty and Y is nonempty, put
η(x)=d(x,D)+d(x,Y)d(x,D)​,q(x)=η(x)h(x).
(7)
Both factors are continuous functions; η=1 on Y and η=0 on D. Off D we have ∣h∣<1, and on D we have q=0, so ∣q(x)∣<1 everywhere. Therefore a real continuous extension is
F(x)=arctanhq(x).​
(8)
On Y it equals f. If D is empty use q=h; if Y is empty simply take F=0. This handles unbounded f without requiring a uniform margin between ∣g∣ and 1.
