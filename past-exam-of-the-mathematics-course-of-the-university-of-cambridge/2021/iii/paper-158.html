i OurBigBook.com
For a payoff set A⊆Mω, a quasistrategy for a player assigns a nonempty subset of M to every finite position at which that player moves. A play is consistent with it when each of that player's moves belongs to the assigned set. The set A, or equivalently the infinite game of perfect information G(A), is quasidetermined when one player has a quasistrategy under which every consistent play is won by that player.

Consider the following game on the real numbers. On their first moves, Player I plays y∈R and Player II replies with x∈R; later moves are ignored. Declare Player II the winner when
y∈/pAor(x,y)∈A.
(2)
Player I cannot have a winning strategy in an infinite game: its first move is some fixed y, and if y∈/pA then II wins automatically, while if y∈pA then II can reply with an x satisfying (x,y)∈A.
The axiom of determinacy for games on R therefore gives Player II a winning strategy τ. For every y∈pA, define f(y) to be II's first response to the move y. The winning condition forces
(f(y),y)∈A,
(3)
so f:pA→R is the required uniformization of a binary relation. This is the direct game proof of uniformization from determinacy.

Let T⊆(X×ω)<ω be a Suslin representation of A, and let f:X→Y be injective. Apply f coordinatewise to the first coordinate of every node and put
Tf​={(f∘s,t):(s,t)∈T}⊆(Y×ω)<ω.
(4)
The injectivity of f ensures that a sequence is a branch of Tf​ exactly when its first coordinate decodes to a branch of T. Hence p[Tf​]=p[T]=A, proving that every X-Suslin set is Y-Suslin whenever X injects into Y.

By part ii every subset of the Baire space of sequences is 2ℵ0​-Suslin. If 2ℵ0​≤ℵ2​, part i would make every such set ℵ2​-Suslin. Therefore
Ψℵ2​​⟹2ℵ0​>ℵ2​.​

If B were ℵ1​-Suslin, the Aleph-one-Suslin decomposition into analytic sets would write it as a union of ℵ1​ analytic sets. If all those analytic sets were countable, their union would have cardinality at most ℵ1​, so one of them is uncountable. i OurBigBook.com
An inner model M is projectively well-ordered when some projective relation well-orders the real numbers of M. The ordinal ℵ1M​=ω1M​ is the least ordinal that M regards as uncountable; equivalently, it is the supremum of the order types of the well-order codes in M.
Assume for contradiction that ω1M​ is uncountable in the ambient universe. Use the projective well-order of the reals of M to choose, for each α<ω1M​, the least M-real coding a well-order of type α. Standard closure properties of the projective hierarchy make the resulting set U⊆WF projective. It is uncountable because it contains one distinct code for every α<ω1M​.
The set U has no perfect subset. Indeed, a perfect subset P⊆U is closed and therefore analytic. The boundedness theorem for well-order codes bounds the ranks of its members below one countable ordinal β. Since U contains at most one code of each rank, P would then be countable, whereas every nonempty perfect set of reals is uncountable.
If every projective set is determined, projective determinacy holds and gives the perfect set property to every projective set. Applying it to the uncountable projective set U yields a perfect subset, a contradiction. Therefore
ω1M​ is countable in the ambient universe.​
(11)
This is projective determinacy collapses the inner-model omega-one.

Suppose ZFC proved that every ℵ1​-Suslin set is determined. The assumed consistency of ZFC and the relative consistency of the Continuum hypothesis would then give a model of
ZFC+CH+“every ℵ1​-Suslin set is determined”.
(12)
In that model 2ℵ0​=ℵ1​. By Every set of reals is continuum-Suslin, every subset of ωω is therefore ℵ1​-Suslin and hence determined. This is the axiom of determinacy.
But the axiom of choice produces an undetermined set of reals, so ZFC and the axiom of determinacy are incompatible. The displayed theory cannot have a model, contradicting the relative consistency of ZFC plus the continuum hypothesis. Hence ZFC cannot prove that all ℵ1​-Suslin sets are determined.

Apply the Friedman–Moschovakis coding lemma with
λ=ℵ2​.
(17)
The given map π:ωω↠ℵ2​ supplies the required real codes for ordinals below λ, while each gξ​:ωω↠P(ξ) supplies codes for all possible initial segments of a subset of λ.
For completeness, fix A⊆ℵ2​ and form the associated Friedman–Moschovakis coding game. The players use π to announce ordinals and gξ​ to announce candidate codes for A∩ξ, while each may challenge the other's code at a larger ordinal. The Friedman–Moschovakis diagonal argument shows that Player I cannot have a winning strategy. By the axiom of determinacy, Player II has one. The coherence tests in the game ensure that a fixed winning strategy for II can belong to at most one set A: if it purported to code distinct A and B, a play reaching an ordinal above the least point of disagreement would defeat it.
Every strategy for a game on ω is coded by a real. Define F:ωω→P(ℵ2​) by sending a code for a winning II-strategy to the unique set that it determines, and sending all other reals to the empty set. Every A⊆ℵ2​ has such a strategy, so F is surjective. Hence
ωω↠P(ℵ2​).​
(18)
