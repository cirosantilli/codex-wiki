The hidden subgroup problem supplies an oracle f:G→X promised to satisfy
f(g1​)=f(g2​)⟺g1​H=g2​H
(1)
for an unknown subgroup H≤G; the task is to determine H.
For a function f:ZK​→Z with least period r dividing K, use the additive group G=ZK​ and hidden subgroup
H=⟨r⟩={0,r,2r,…,K−r}​.
(2)
Its cosets are the residue classes modulo r. Periodicity makes f constant on each coset, while injectivity within a period makes values on distinct cosets different. Determining H, or its least positive generator r, is exactly quantum period finding.

Use m control qubits and exact quantum phase estimation. A controlled U2j on the unknown eigenstate can be synthesized from the available uncontrolled operation and the known eigenstate ∣ξ0​⟩: conditionally swap ∣ξ⟩ into an auxiliary register initialized to ∣ξ0​⟩, apply U2j to that register, and swap back. The auxiliary state is restored, while the control-one branch acquires e2πi2jϕ.
After Hadamard gates and these controlled powers, the control register is
2m/21​∑y=02m−1​e2πicy/2m∣y⟩.
(10)
The inverse quantum Fourier transform maps this state exactly to ∣c⟩, so measurement determines c with certainty. There are m controlled swaps of O(n) qubits, each promised power costs poly(n,j), and the inverse transform uses O(m2) elementary gates. The total cost is therefore poly(n,m).

Expand ∣b⟩=∑i​bi​∣λi​⟩ in the nondegenerate eigenbasis of A. Apply quantum phase estimation to U+​=e2πiA, using U−​ when inverse powers are needed, to coherently attach the eigenvalue:
∑i​bi​∣λi​⟩∣λi​⟩val​.
(11)
On an ancillary qubit perform the eigenvalue-controlled rotation
∣0⟩⟼1−e2(λi​−1)​∣0⟩+eλi​−1∣1⟩.
(12)
Uncompute the value register and measure the ancilla. Conditional on outcome one, the system is proportional to
∑i​bi​eλi​∣λi​⟩=eA∣b⟩,
(13)
and normalization gives the desired ∣ψ⟩.
The success probability is
PS​=e−2⟨b∣e2A∣b⟩​.
(14)

PS​>e−2​,

Reversibly test whether the measured integer x is a nontrivial divisor of N, and phase-flip exactly those computational basis states. This implements the good-subspace reflection in classical and quantum polynomial time. The reflection in CN​∣0n⟩ is
CN​(2∣0n⟩⟨0n∣−I)CN†​,
(18)
which is polynomial size by the stated assumption.
Here sin2θ=sin2(π/10), so θ=π/10. Two amplification iterations give
(2⋅2+1)θ=2π​.
(19)
The final measurement therefore returns a nontrivial factor with certainty whenever N is composite. Only two uses each of CN​,CN†​ up to a constant factor and polynomial-size verification circuits are required, so the complete algorithm is polynomial in n.

For a positive Hermitian matrix,
κ(A)=λmin​λmax​​​.
(20)
The HHL algorithm phase-estimates A, performs a controlled rotation with amplitude proportional to 1/λi​, uncomputes the estimate, and postselects the rotation ancilla. Resolving the smallest eigenvalue requires phase-estimation precision O(λmin​) and evolution time Ω(1/λmin​). Since λmax​≤1, this contributes a dependence at least linear in κ.
The controlled rotation must use a scale C≤λmin​. In the worst input direction its success probability is of order
λmax2​C2​=O(κ−2),
(21)
so obtaining constant success by amplitude amplification costs another O(κ) factor. Thus a runtime polynomial in logN requires
κ=O(poly(logN))​.
(22)
An exponentially ill-conditioned matrix would require exponentially fine phase resolution or exponentially many amplification steps.

The process is classically strongly efficiently simulatable if a deterministic classical algorithm can compute the probability of any specified K-bit output string to requested additive precision 2−m in time polynomial in n, the circuit description, and m. This is strong classical simulation of a quantum circuit, and is stronger than merely sampling its output.

For the first output qubit,
Pr(0)=21​[1+⟨ψ0​∣C†Z1​C∣ψ0​⟩].

A Clifford circuit maps the Pauli observable Z1​ under conjugation to a tensor-product Pauli operator ±P1​⊗⋯⊗Pn​, found by propagating it backward through the circuit in polynomial time. Since the input is a product state,
⟨ψ0​∣C†Z1​C∣ψ0​⟩=±∏j​⟨αj​∣Pj​∣αj​⟩.

Each factor is efficiently computable, so both one-bit output probabilities are strongly simulatable. This is Heisenberg propagation of a Pauli observable through a Clifford circuit.

Take any bounded-error polynomial-size quantum circuit for a language in BQP and express it using H,CX,S,T. Replace each T gate by the supplied T-gadget. Before measurements and conditional corrections, the resulting circuit uses only Clifford gates and has a product input consisting of the original input and one magic state ∣A⟩ per gadget.
Consider the branch in which all t=poly(n) gadget measurements return zero. No conditional S corrections are then needed, so the ancilla measurements may be deferred to the end. This branch has known probability 2−t, and conditioned on it the remaining output is exactly that of the original universal circuit.
The assumed simulator applies with K=t+1: ask it for the joint probabilities
p(0t,accept),p(0t)=2−t.
(25)
Using polynomially many bits of requested precision, compute
Pr(accept∣0t)=2tp(0t,accept).
(26)
The usual bounded-error gap separates yes instances from no instances, so this conditional probability decides the language deterministically in polynomial time. Hence BQP⊆P. The reverse inclusion is immediate because a quantum computer can implement classical deterministic computation, and therefore
P=BQP​.
(27)
