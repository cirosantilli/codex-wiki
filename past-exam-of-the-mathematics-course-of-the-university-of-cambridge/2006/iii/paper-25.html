A partial computable function is the function computed by a finite program, with an undefined value when its computation never terminates. A total computable function terminates on every input. Fix an effective enumeration (φe​)e∈ω​ of the partial computable functions, with a universal partial computable function U(e,x)=φe​(x). Composition, primitive recursion and unbounded minimization give a machine-independent description of this class. Unbounded minimization is allowed to diverge. The S-m-n theorem permits parameters in a program to be specialized effectively: an algorithm described uniformly in e has an index obtained computably from e.
The halting set K={e:φe​(e) halts} is computably enumerable: simulate all computations in parallel and enumerate each index whose diagonal computation terminates. It is not a computable set. Otherwise the program which terminates exactly when the proposed decision procedure says its own diagonal computation does not terminate gives a contradiction. There is also no effective enumeration consisting exactly of all total computable functions: from such an enumeration (fn​) the total computable function g(n)=fn​(n)+1 differs from every listed function. Thus the effective enumeration of partial programs cannot be replaced by a decidable catalogue of total ones.
For the Rice theorem, let C be a nontrivial property of partial computable functions, depending on the computed function rather than the program text. First suppose the nowhere-defined function is not in C, and choose a program computing some g∈C. Uniformly in e, define a program which, on input x, first waits for φe​(e) to terminate and then runs the computation of g(x). The S-m-n theorem gives a computable index map e↦p(e), and
φp(e)​={g,nowhere-defined function,​e∈K,e∈/K.​
(1)
Consequently a decision procedure for membership in C would decide the halting set. If the nowhere-defined function belongs to C, apply the same argument to its complement. Every nontrivial extensional property of partial computable functions has an undecidable index set. Syntactic properties of program descriptions are outside this assertion, and the theorem concerns unrestricted program indices, not merely an assumed list of terminating programs.
Here is an explicit Jockusch triple coloring computing the halting set. Choose computable increasing finite stages Ks​ with union K. For x<y<z, put
c({x,y,z})={0,1,​Ky​∩x=Kz​∩x,Ky​∩x=Kz​∩x.​
(2)
This is a computable colouring. An infinite monochromatic set cannot have color 1: fix its first element x and choose two later elements beyond the stage at which Ks​∩x stabilizes. Their triple has color 0.
Suppose H is infinite and homogeneous of color 0. To decide whether n∈K using H, find x∈H with x>n, and then y∈H with y>x. For every z∈H above y, homogeneity gives Ky​∩x=Kz​∩x. Such z are unbounded, so Ky​∩x=K∩x. Testing n∈Ky​ therefore decides n∈K. Hence every homogeneous set computes the halting set, and there is no infinite recursive monochromatic set. The infinity qualification is essential: finite homogeneous sets are recursive.

Work in a ground first-order model of set theory satisfying ZF, and let π be a definable bijection of its universe, whose inverse is also definable. Write ψ=π−1 and replace membership by
xEy⟺x∈π(y).
(3)
In this Rieger-Bernays permutation model, an object having prescribed extension b is represented by ψ(b). The Axiom schema of replacement in the ground model guarantees that images of sets under π and ψ are sets. The axiom of extensionality follows from injectivity of π; the new empty set is ψ(∅), and the new pair of x,y is ψ({x,y}).
For the Axiom of union and Axiom of power set, representatives are respectively
ψ(⋃y∈π(x)​π(y)),ψ({ψ(s):s⊆π(x)}).
(4)
Indeed, z is an E-subset of x exactly when π(z)⊆π(x). Translate every first-order formula by replacing membership with membership in π(y). Ground separation then forms each desired subextension of π(x), and ground replacement forms each functional image; applying ψ supplies its representative. To verify the axiom of infinity, define by ground recursion
a0​=ψ(∅),an+1​=ψ(π(an​)∪{an​}).
(5)
Then ψ({an​:n<ω}) is an E-inductive set. Thus every ZF axiom except possibly the Axiom of foundation survives.
Interchange two distinct objects a and {a}, fixing everything else. Then π(a)={a}, so a is a Quine atom: internally a={a}. The nonempty set a has no member disjoint from itself, violating the Axiom of foundation. The original membership model satisfies that axiom. Foundation is therefore relatively independent of the other ZF axioms.
A full Rieger-Bernays permutation model of a choice model still satisfies the axiom of choice: choose an old member of each nonempty extension π(y) and encode the resulting choice graph with the new ordered-pair operations. To obtain failure of choice, an additional restriction by symmetries is necessary.
Start instead with ZFC and use the definable permutation interchanging every an​=ω+n with {an​}. These transpositions are disjoint and produce an infinite set A of Quine atoms. Inside the resulting membership model build the cumulative universe over A, closing at successive stages under sets of previously constructed objects, represented by ψ(X). Atomic objects are kept as the designated base objects; ψ({a})=a for a∈A. Every permutation of A extends recursively to an automorphism of this universe, with the atomic self-loops fixed by the recursive convention.
An object has finite support if every permutation fixing some finite S⊆A pointwise fixes it. Retain the objects which have finite support and whose members recursively also have finite support, interpreting the atomic self-loops as the base case. This is the hereditarily finite-supported Quine-atom model. It is transitive for the new membership relation. Extensionality is inherited. Pairs and unions have supports contained in the union of the finitely many relevant supports. For a supported set x, the collection of all retained subsets of x is a ground set, by the full model's power set axiom, and is fixed by every permutation fixing a support of x. Its members are retained, so this collection supplies the internal power set. A first-order formula with retained parameters is invariant under their common stabilizer. Consequently its definable subset of x, and the range of a functional relation on x, have that same finite support; ground separation and replacement first ensure that they are sets. The pure natural-number hierarchy supplies infinity. These arguments verify all of ZF except Axiom of foundation, which fails at the Quine atoms.
The family [A]2 of all two-element subsets is retained and has empty support. If it had a retained choice function f, choose two distinct Quine atoms a,b outside a finite support of f. The transposition of a,b fixes f and fixes the unordered pair {a,b}, but moves either possible value f({a,b}). This is impossible. Thus ZF without Foundation has both choice models and models in which Choice fails, relative to the usual consistency assumption. The construction also explains why twisting membership alone was insufficient.

Use rooted-tree homeomorphic embedding: edges may be stretched into downward paths, different child branches stay disjoint, and the source root may map to any target vertex. Write S⪯T for this relation. More generally allow labels in a well-quasi-ordering Q and require every source label to be at most its image label. We prove this labelled version, which includes the unlabelled case by taking one label.
First, every infinite sequence in a well-quasi-ordering has an infinite nondecreasing subsequence. In every infinite set of indices there is an index with infinitely many later successors above its value. Otherwise repeatedly discard the finitely many successors of each chosen index, obtaining a bad sequence. Applying this observation successively within the infinite successor set produces the required subsequence.
We also need the Higman lemma, and prove it here. If finite words over Q admitted a bad sequence, choose one w0​,w1​,… with each word of least possible length among choices permitting a bad continuation of its fixed prefix. No word is empty. Write wi​=vi​ai​, and extract indices n0​<n1​<⋯ with an0​​≤an1​​≤⋯. The sequence
w0​,…,wn0​−1​,vn0​​,vn1​​,…
(6)
is bad: an earlier wi​ embedding into some vnj​​ would embed into wnj​​, while vni​​⪯vnj​​ together with ani​​≤anj​​ would give wni​​⪯wnj​​. This contradicts the minimal length of wn0​​, since vn0​​ is shorter. Hence finite words are well-quasi-ordered under subsequence embedding with increased labels.
Now suppose labelled rooted trees admitted a bad sequence T0​,T1​,…, chosen minimally by number of vertices at each successive position. Let B consist of all immediate child subtrees of all the Ti​, with the inherited labels. We claim B is a well-quasi-ordering. Otherwise take a bad sequence of members of B. Only finitely many distinct rooted trees occur among the children of any finite initial list of Ti​, so, by discarding terms and selecting a subsequence, we may arrange its members S0​,S1​,… to come from strictly increasing parent indices n0​<n1​<⋯. Then
T0​,…,Tn0​−1​,S0​,S1​,…
(7)
is bad. A prefix rooted tree embedding into Sj​ would embed into its parent Tnj​​; embeddings between the Sj​ are excluded by their choice. But S0​ has fewer vertices than Tn0​​, contradicting minimality. This proves the claim.
List the child subtrees of each Ti​ in any order. By the Higman lemma these child lists are well-quasi-ordered. Extract an infinite subsequence with nondecreasing root labels, and then compare two child lists on that subsequence. Their subsequence embedding gives distinct target child branches into which the source child subtrees embed. Map the source root to the target root and join each embedded child root to it by the corresponding downward path. The paths are disjoint except at the root, and labels increase. Thus Ti​⪯Tj​ for some i<j, contradicting badness. This proves Kruskal's tree theorem and its labelled version. If root preservation is required, mark the root with a special label incomparable with all ordinary labels; the same proof then forces root to map to root.
For Friedman's finite form of Kruskal's theorem, fix k∈ω and suppose there are arbitrarily long bad lists satisfying ∣Ti​∣≤k+i for i=1,2,…. Make a finite bad-sequence tree whose nodes are these lists, using one representative of each finite rooted-rooted tree isomorphism type. At each position only finitely many choices satisfy the size bound, so the rooted tree is finitely branching. An infinite path exists: at every stage choose a child having extensions of arbitrarily large length, which must exist because there are finitely many children. The path is an infinite bad sequence, contradicting Kruskal's tree theorem. Therefore
∀k∈ω ∃N ∀(Ti​)1≤i≤N​[(∀i ∣Ti​∣≤k+i)⇒(∃i<j Ti​⪯Tj​)].​
(8)
The identical argument works with finitely many labels and any fixed finite size bound at each position.

The axiom of determinacy, abbreviated AD, asserts that every length-ω infinite game of perfect information in which the two players alternately choose natural numbers is determined. For a payoff set A⊆ωω, player I wins exactly when the completed play belongs to A. A strategy specifies the next move at every finite position where its player is to move; determination means that one player has a winning strategy.
Finite games are determined by backward induction, choosing the least move leading to a guaranteed win when several are available. In ZF one can also prove open determinacy, hence determinacy for closed payoffs. Here is the full open-payoff argument. Let S be the finite positions s with [s]⊆A, so reaching S ensures a win for I. Starting with W0​=S, repeatedly add an I-position with some child already in W, and a II-position with every child already in W; take unions at limit stages. This increasing process stabilizes because the set of finite positions is a set: continuing strict enlargement through its Hartogs number would choose distinct new positions, contradicting that bound. Assign to each admitted position its least entry stage.
At an I-position in the final W, choose the least child of smaller entry stage. At a II-position in W∖S, every child has smaller entry stage. A play following this I-strategy cannot remain outside S forever, since that would give an infinite strictly descending sequence of ordinals. It reaches S and wins. Outside W, every child of an I-position remains outside W, and a II-position has at least one child outside W. Player II chooses the least such child. The play never reaches S, so it cannot belong to the open set A. The initial position is either inside or outside W, proving determination. For a closed payoff apply the same argument to the open complementary payoff for the other player, with the appropriate player assigned to each level. None of these strategies needs a choice principle because moves are natural numbers and least available moves are definable.
To refute simultaneous AD and the axiom of choice, assume choice and well-order all strategies of either player in length c=2ℵ0​. There are exactly c strategies for each player, and any fixed strategy has exactly c compatible plays, since the opponent's successive moves are arbitrary. At stage α<c, choose two fresh plays: xα​ compatible with I's αth strategy, and yα​ compatible with II's αth strategy. Fewer than c plays have previously been excluded, so this is possible even if c is singular. Put A={yα​:α<c}. No xα​ ever enters A. I's αth strategy loses on xα​, and II's αth strategy loses on yα​. Thus this game has no winning strategy for either player, and
AD ⟹ ¬AC.​
(9)

All assertions of independence below are relative consistency assertions. We construct structures satisfying the other ZF axioms but falsifying the indicated axiom; an ordinary model of ZF supplies the positive side. The convenient ground theory is ZFC, which has the same consistency strength as ZF by the constructible universe theorem.
For the Axiom of union, put λ=ℶω​ and use the hereditarily locally small membership model
Bλ​={x:∀y∈TC({x}) (∣y∣<λ)}.
(10)
It is a transitive class. The condition requires each individual set in the membership ancestry to have size below λ; it does not require its entire transitive closure to have size below λ. Extensionality and foundation are inherited. Pairs and subsets of members remain in the class, giving pairing and separation, and ω witnesses infinity. For x∈Bλ​, the actual P(x) also belongs to Bλ​: if ∣x∣=μ<λ, then 2μ<λ by the strong-limit property, while every subset of x and every member further below it remains locally small. This verifies the full power set axiom. If an internally definable functional relation has domain x∈Bλ​, ground replacement, applied to the relativized first-order formula, gives its range r. Since ∣r∣≤∣x∣<λ and every value is already in Bλ​, its range is also locally small. Thus every replacement instance holds.
However, a={Vω+n​:n<ω} belongs to Bλ​: its members have cardinalities ℶn​<λ, and their members are smaller still. Its actual union is Vω+ω​, of cardinality ℶω​=λ, which is not in Bλ​. Transitivity makes any internal union witness equal to this actual union. Hence Union fails while all the other ZF axioms hold.
For the Axiom of power set, use the hereditarily countable sets Hω1​​ in the ground choice universe. This is transitive and contains ω. Pairs, subsets and unions have countable transitive closure. For replacement, a functional image of a countable domain is countable, and the union of countably many countable transitive closures is countable; hence that image is again hereditarily countable. These observations, with inherited extensionality and foundation, verify all the remaining axioms. Every real, viewed as a subset of ω, belongs to Hω1​​. A power-set witness for ω would therefore contain every such real, but a hereditarily countable set has only countably many members, whereas P(ω) is uncountable by Cantor's theorem. Power set fails.
For the Axiom schema of replacement, use Vω+ω​ with actual membership. This limit-rank structure contains ω and is closed under pairs, unions and power sets: every relevant finite increase in rank stays below ω+ω. A separated subset has rank no higher than that of the original set. Extensionality and foundation are inherited. The internally definable function
f:ω⟶Vω+ω​,f(n)=Vω+n​,
(11)
is obtained by n successive power-set operations starting with the parameter Vω​. Each finite iteration, including its finite history, belongs to the structure. Its range has rank ω+ω and is not an element of Vω+ω​. Thus the replacement instance for this first-order formula fails, although every other ZF axiom holds.
For the axiom of extensionality, take the well-founded cumulative set universe over two distinct urelements, and forget the predicate distinguishing urelements from sets. Each urelement has no members, just as the ordinary empty set has no members, so extensionality fails. Every other axiom survives in this pure membership language. Pairing, union, separation and replacement are witnessed by the corresponding ordinary sets of urelements and sets; foundation follows from their well-founded ranks, and the pure ω supplies infinity. Here foundation is written with “has a member” as its nonemptiness antecedent, and disjointness means having no common member. Formulations using inequality to one designated empty object are not equivalent after removing extensionality. There is also one necessary adjustment to power set: an urelement is vacuously a subset of every object because it has no members. Thus the power-set witness for x is the ordinary set of all usual subsets of its extension, together with both urelements. This is still a set, and contains exactly the objects satisfying the unrestricted subset first-order formula. Consequently the countermodel falsifies Extensionality alone, without silently weakening Power set to sets only.
Finally, the hereditarily finite sets Vω​ satisfy extensionality, foundation, pairing, union, power set and separation. Every functional image of a finite domain is a finite set of hereditarily finite objects, hence also belongs to Vω​, giving all replacement instances. No finite set contains ∅ and is closed under successor: it would then contain every finite von Neumann ordinal. Infinity fails while the remaining axioms hold.

Let M be an externally countable model of ZFC, and let κ=(ω1​)M. In M form the forcing order
P={p:p is a finite partial function ω⟶κ},q≤p⟺q⊇p.
(12)
This is the finite-function collapse to countable size. For every n∈ωM and α∈κM, the internal sets
Dn​={p:n∈dom(p)},Eα​={p:α∈ran(p)}
(13)
are dense: extend a finite function by assigning a missing input, and use a fresh input to put any required value in its range.
Externally enumerate all the dense subsets of P which M recognizes as dense. There are only countably many, because M is countable. Recursively choose pi+1​≤pi​ in the ith such dense set and let G be the upward closure of this descending chain. This produces a generic filter over M. By the forcing theorem, its generic extension M[G] satisfies ZFC. The canonical forcing name g˙​=⋃G˙ is forced to be a function with domain ω and range κ: the dense sets Dn​ and Eα​ ensure exactly these assertions. Therefore
M[G]⊨“the old ω1​ is countable.”​
(14)
Its new first uncountable ordinal is accordingly different from κ.
For a transitive M, ordinary evaluation of names gives the familiar literal extension. The question only assumes a countable model, so one must also cover externally ill-founded models. In that case use the quotient of the internally defined forcing names by forced equality modulo G, with membership defined by forced membership. The internal forcing identities and the forcing theorem hold in M and give a well-defined first-order structure satisfying every standard ZFC axiom. Check names embed the original membership structure, so identify their images with M. Its domain is a quotient of a subset of the countable domain of M, hence is externally countable. Thus the required extension exists even without assuming transitivity. It is a membership extension, not an elementary extension: the assertion that the parameter κ is uncountable changes truth value.

For nonempty first-order structures (Mi​)i∈I​ in a common language and an ultrafilter D on I, identify product functions by
f∼D​g⟺{i:f(i)=g(i)}∈D.
(15)
The ultraproduct ∏i​Mi​/D has these equivalence classes as elements. Functions are interpreted coordinatewise, and a relation holds of classes exactly when its coordinatewise truth set belongs to D. Closure under finite intersections makes these interpretations independent of representatives.
The Łoś theorem asserts
∏i​Mi​/D⊨φ([f1​],…,[fn​])⟺{i:Mi​⊨φ(f1​(i),…,fn​(i))}∈D.
(16)
Prove it by induction on first-order formulas. Atomic first-order formulas hold by the definitions and induction on terms. Conjunction uses intersections, and negation uses the fact that an ultrafilter contains exactly one of a set and its complement. For an existential first-order formula, a product witness gives a coordinate witness on a D-large set. Conversely, on the D-large set where a coordinate witness exists, choose one in each factor, and choose arbitrary values elsewhere. Its class is a product witness by the induction hypothesis. This is the only witness-selection step; the surrounding argument is made in a choice metatheory. The special case with all factors equal is an ultrapower, and constant functions give an elementary embedding.
Here is a direct compactness theorem proof. Suppose every finite subset of a theory T has a model. Index factors by the finite subsets i⊆T, choosing Mi​⊨i. For finite F⊆T, the cone CF​={i:F⊆i} is nonempty, and CF​∩CH​=CF∪H​. Extend the generated proper filter to an ultrafilter D. For every sentence σ∈T, its truth set contains C{σ}​, so the Łoś theorem gives ∏i​Mi​/D⊨T. Finite satisfiability therefore implies satisfiability, directly from the ultraproduct construction rather than from a syntactic completeness argument.
For saturated models, a structure is κ-saturated if every complete type over fewer than κ parameters is realized. A useful concrete case is countable saturation of a nonprincipal ultraproduct over omega. In a countable language, enumerate any finitely satisfiable type over countably many parameters as φ1​(x),φ2​(x),…, and represent its parameters by product functions. By the Łoś theorem, the set An​ of coordinates where the first n first-order formulas have a simultaneous witness belongs to the nonprincipal ultrafilter D. Put
Bn​={i:i≥n}∩⋂j≤n​Aj​.
(17)
These are decreasing D-large sets. At coordinate i, let h(i) be the largest n≤i with i∈Bn​, or zero if none exists, and choose a witness for the first h(i) first-order formulas. For fixed n, every coordinate in Bn​ has h(i)≥n, so the resulting product function satisfies φn​ on a D-large set. Its class realizes the whole type. Thus such an ultraproduct is ℵ1​-saturated.
There is also an existence construction at every prescribed degree κ. Given an infinite model M, choose a regular cardinal λ≥κ and construct an elementary chain (Mα​)α≤λ​. At a successor stage, add a new constant for a realization of every type over every subset of Mα​ of size below κ, together with the elementary diagram of Mα​. Every finite part is satisfiable: only finitely many types and finitely many first-order formulas from each are involved, and each finite type fragment has a witness in Mα​. Compactness therefore supplies a simultaneous elementary extension. At limits take unions. To justify elementarity of a union, any existential first-order formula with parameters in an earlier stage has a witness in that stage whenever it has one at a later stage, by elementarity; this is the Tarski-Vaught test.
Any fewer-than-κ parameters of Mλ​ occur together in some Mα​, by regularity of λ. A type over them which is finitely satisfiable in Mλ​ is finitely satisfiable in Mα​, again by elementarity, and was realized in Mα+1​. Hence every infinite structure has a κ-saturated elementary extension for any prescribed cardinal κ. No bound on the size of this extension is asserted; full saturation at the model's own cardinality has additional cardinal-arithmetic issues.

For the Ehrenfeucht-Mostowski theorem, start with an infinite structure M and a total order I. Choose a Skolem expansion M∗, and adjoin constants ci​ for i∈I. Require the elementary diagram of M∗, distinctness of these new constants, and the order-indiscernible sequence schema: any two increasing tuples of the ci​ of the same length satisfy the same first-order formulas in the expanded language. Every finite fragment mentions finitely many new constants and finitely many first-order formulas. Enumerate a countably infinite subset of M. For each of the finitely many first-order formulas, color its increasing tuples by its truth value in M∗, including whatever fixed parameters occur in the fragment. Successive applications of the infinite Ramsey theorem leave an infinite subset homogeneous for all these colorings. Assign the finitely many new constants to distinct elements of this subset in their index order. Their finite indiscernibility requirements and the elementary diagram are then simultaneously satisfied.
The compactness theorem supplies an elementary extension N∗ containing the required distinct indiscernibles. Their Skolem hull is an elementary substructure: an existential first-order formula true of its elements has its chosen Skolem-function witness in the hull, so the Tarski-Vaught test applies. Any order automorphism σ of I acts on this hull by
t(ci1​​,…,cin​​)⟼t(cσ(i1​)​,…,cσ(in​)​).
(18)
Indiscernibility makes this well defined, since every equality of two term representations is preserved. The same argument preserves every first-order formula; the inverse is given by σ−1. Thus it is an automorphism, uniquely determined in the language of the chosen Skolem expansion by its values on the generators. This proves both the indiscernible-model and automorphism forms of the Ehrenfeucht-Mostowski theorem. Uniqueness is not claimed for automorphisms of the reduct which need not preserve the chosen Skolem functions.
For simple typed set theory with atoms, write Si​ for the set predicate at sort i. Members have sort one lower; urelements have no typed members, extensionality applies to sets, and every well-typed first-order formula defines a set at the next sort. Typical ambiguity adds ϕ↔ϕ+ for each closed sentence, where + raises every sort by one. We prove finite satisfiability using Ramsey theorem, rather than assuming that adjacent sorts have the same cardinality.
Let Xn​=Vω+2n​. If n<m, then P(Xn​)⊆Xm​. For increasing integers h0​<h1​<h2​<⋯, interpret sort i by Di​=Xhi+1​​, interpret Si​ by the objects of P(Xhi​​), and interpret adjacent-sort membership by actual membership restricted to these designated sets. All other objects of a sort are typed urelements. Every subset of Di​ is a designated set in Di+1​, so comprehension holds for every first-order formula, including first-order formulas with quantifiers and parameters at other sorts. Two designated sets with the same members are equal, while the other objects have no typed members. Thus this is a full model of the typed axioms for every increasing sequence of levels. The extra preceding level h0​ gives a consistent interpretation of the bottom set predicate as well.
Take finitely many ambiguity sentences and let r bound their highest sort before raising. Color increasing (r+2)-tuples (h0​,…,hr+1​) by the vector of truth values of these sentences in the corresponding finite sorted structure. There are finitely many colors. The infinite Ramsey theorem supplies an homogeneous set of indices. Choose the level sequence from it. The sentence ϕ is evaluated in the window (h0​,…,hr+1​), while ϕ+ is evaluated in the next window (h1​,…,hr+2​); homogeneity makes their truth values equal. Sentences using fewer sorts simply ignore the unused final levels. Thus every finite family of ambiguity axioms has a model satisfying all the typed axioms. Apply many-sorted first-order compactness theorem to obtain
Con(TSTU+Typical Ambiguity).​
(19)
This is a relative consistency construction in the ordinary set-theoretic metatheory. Allowing urelements is essential here: skipping ranks leaves objects outside the represented power sets, and those objects must be permitted as urelements.

An uncountable cardinal κ is a measurable cardinal if there is a nonprincipal κ-complete ultrafilter U on κ: intersections of fewer than κ members of U remain in U. Such an ultrafilter is uniform. No singleton belongs to it, and intersecting the complements of fewer than κ singletons shows that no set of cardinality below κ belongs to it.
Form the ultrapower of the universe by U, with classes [f] of functions f:κ→V, and [f]∈U​[g] exactly when {ξ:f(ξ)∈g(ξ)}∈U. The Łoś theorem proves that the map taking x to the constant function with value x is elementary. The ultrapower relation is well-founded: from an infinite descending sequence [f0​]∋U​[f1​]∋U​⋯, countable completeness gives a coordinate satisfying all the membership relations, producing an actual infinite descending membership sequence and contradicting foundation. It is also set-like. Predecessors of [g] can be represented by functions whose value at ξ lies in g(ξ)∪{∅}; these functions form a set. The Mostowski collapse theorem therefore gives a transitive class N and an elementary embedding
j:V⟶N.
(20)
The usual class-ultrapower notation is understood via set-sized representatives and this set-like collapse.
For α<κ, any function into α is constant on a U-large set: if none of its fewer-than-κ fibers belonged to U, intersect their complements to get the empty set in U. Consequently every member of the ultrapower ordinal represented by the constant α is represented by a constant ordinal below α. Induction on α now gives j(α)=α.
On the other hand the identity function d(ξ)=ξ represents an ordinal below j(κ). For every α<κ, the tail {ξ:ξ>α} belongs to U, so the collapsed ordinal [d] is above j(α)=α. Hence
crit(j)=κ,j(κ)>κ.​
(21)
This proves nonidentity explicitly. The collapsed identity class is at least κ; it need not equal κ unless an additional normality convention is imposed on U.
Conversely, an elementary embedding j:V→N into a transitive class with critical point κ yields
U={X⊆κ:κ∈j(X)}.
(22)
For the converse use the usual amenability assumption on the class embedding, so this collection is a set. Since j(κ)>κ, exactly one of j(X) and j(κ∖X) contains κ, proving the ultrafilter condition. Singletons are excluded because j(α)=α<κ. If λ<κ and Xi​∈U for i<λ, then j fixes λ and every index below it, giving j(⋂i<λ​Xi​)=⋂i<λ​j(Xi​); the intersection still contains κ. Thus U is κ-complete and κ is measurable.
In particular the first moved ordinal is a strongly inaccessible cardinal. If cf(κ)<κ, partition κ into fewer than κ bounded intervals. Each is too small to lie in U, contradicting completeness. Thus κ is regular. If 2λ≥κ for some λ<κ, choose distinct subsets Aξ​⊆λ for ξ<κ. For each η<λ, choose the U-large side of the question η∈Aξ​. Intersect these fewer-than-κ large sides. The intersection belongs to U, but all its indices have identical Aξ​, so it contains at most one index, contradicting nonprincipality. Therefore 2λ<κ for every λ<κ, as required.

For an infinite cardinal ρ put ℶ0​(ρ)=ρ and ℶn+1​(ρ)=2ℶn​(ρ). The Erdős-Rado theorem for finite arities is
ℶn​(ρ)+⟶(ρ+)ρn+1​(n<ω).​
(23)
The partition relation requires a homogeneous subset of order type ρ+ for every coloring of (n+1)-element subsets by at most ρ colors. In particular it gives uncountable homogeneous sets. The case n=0 is the infinite pigeonhole principle: a union of ρ sets each of size at most ρ cannot have size ρ+.
We give the induction step by a closed elementary-submodel construction of an end-homogeneous sequence. Let μ be infinite, θ=(2μ)+, and c:[θ]r+1→ρ with ρ≤μ. Choose a sufficiently large regular χ and an elementary submodel M≺Hχ​ with c,θ∈M, all ordinals below μ+ in M, ∣M∣=2μ, and closure under externally given sequences of length at most μ. To construct it, take μ+ successive elementary Skolem-hull closures, at each step including all such sequences from the preceding stage. Cardinality stays 2μ because (2μ)μ=2μ. In the final union every sequence of length at most μ has all its entries in some earlier stage, by regularity of μ+, and so was included at the next stage.
Put β=sup(M∩θ). Regularity of θ gives β<θ, and β∈/M since otherwise its successor would contradict the definition of the supremum. Recursively, for α<μ+ choose xα​∈M∩θ above all earlier xξ​ and satisfying
c({xξ1​​,…,xξr​​,xα​})=c({xξ1​​,…,xξr​​,β})(ξ1​<⋯<ξr​<α).
(24)
There are at most μ constraints. Their parameters and their colors belong to M, and closure puts their complete code in M. The point β witnesses their simultaneous satisfiability in Hχ​; elementarity supplies a witness in M. This gives an increasing end-homogeneous sequence of length μ+: on it, the color of an (r+1)-tuple depends only on the first r entries.
For the induction from arity n to n+1, take μ=ℶn−1​(ρ) and r=n. Color the n-tuples of the resulting sequence by their common color with a later point, equivalently by their color with β. Its index order has type μ+=ℶn−1​(ρ)+, so the induction hypothesis supplies a homogeneous index set of type ρ+. The original (n+1)-tuples on those indices have that same color. This completes the proof without substituting the theorem's name for its induction.
A useful ordinal partition-bound function is
f(α)=min{γ≥α: γ⟶(α)ν2​ for every nonzero cardinal ν<α}.
(25)
It is total: choose an infinite cardinal ρ≥∣α∣ with ρ+>α; the pairs case supplies (2ρ)+ with the required homogeneous order type for all these color numbers. It is nondecreasing and satisfies f(α)≥α. Start iterating f and take a supremum κ at a limit stage. If the increasing iterates do not attain that supremum, then for every α<κ some iterate aξ​ satisfies α≤aξ​<κ, and
f(α)≤f(aξ​)=aξ+1​<κ.
(26)
If the iterates have already stabilized, their supremum is a fixed point directly. Thus the relevant nontrivial case is an uncountable cardinal κ closed below itself under f.
Such closure implies that κ is a strong limit. Suppose λ<κ is infinite and κ≤2λ. Take distinct binary strings of length λ, indexed in order by κ, and color a pair by its first differing coordinate. No three strings are homogeneous: three bits cannot be pairwise different at the same coordinate. Closure would give f(λ+1)<κ, and its restriction would have a homogeneous subset of order type λ+1 in λ colors, a contradiction. Hence 2λ<κ; finite exponents are harmless for an uncountable κ.
Use the usual tree property: every set-theoretic tree of height κ with nonempty levels of cardinality below κ has a cofinal branch. For an uncountable cardinal satisfying this all-set-theoretic trees convention, κ must be regular. If it were singular with cofinality τ<κ, attach to one root τ chains whose lengths increase cofinally to κ. Every level has at most τ nodes, the height is κ, and no branch is cofinal. This contradiction proves regularity. Combined with the preceding closure argument it proves that the cardinal under discussion is strongly inaccessible.
For any c:[κ]2→ν, 0<ν<κ, make a separated set-theoretic tree of functions. Its level α consists of the functions t:α→ν realized as t(ξ)=c({ξ,β}) for some β≥α, with β<κ. Order these functions by restriction. Levels are nonempty and have size at most ν∣α∣<κ, using the strong-limit property. The tree property gives a branch b:κ→ν. Recursively select xη​ for η<κ, larger than all earlier selections, whose coloring function agrees with b through a level above those earlier selections; regularity allows that level to remain below κ, and its node has a realizing point. Then c({xξ​,xη​})=b(xξ​) for ξ<η. One of the fewer-than-κ colors occurs on κ selected points, by regularity. These points are homogeneous, proving κ→(κ)ν2​ for every ν<κ. Consequently
κ closed below itself under f + TP(κ)⟹f(κ)=κ.​
(27)
A strictly increasing countable iteration has a supremum of countable cofinality, so it cannot meet this regular set-theoretic tree-property condition; no continuity of f has been assumed.
The final printed assertion needs its convention specified. The usual tree property alone does not imply strong inaccessibility; it can consistently hold at successor cardinals. In the argument just given, strong inaccessibility follows from function closure together with that set-theoretic tree property. There is also a stronger branching form of the tree property for which the assertion holds literally: require a cofinal branch in every separated rooted height-κ set-theoretic tree whose nodes each have fewer than κ immediate successors, without restricting level sizes. The singular-chain example proves regularity under this convention too. If 2λ≥κ for λ<κ, take the full binary set-theoretic tree through level λ, choose κ distinct nodes on that level, and attach to its ξth chosen node a chain of length ξ, for ξ<κ. It has height κ and at most two successors per node, but every branch has length below κ. Thus this branching property implies the strong-limit condition and hence strong inaccessibility. At a strongly inaccessible cardinal it agrees, for separated set-theoretic trees, with the usual level-size convention: regularity bounds the union of fewer than κ successor sets, and strong-limit arithmetic bounds the possible predecessor sequences at limit levels.

We prove the Ehrenfeucht-Mostowski theorem by ultraproducts, with no application of Ramsey theorem. Expand the infinite structure M by Skolem functions, choose distinct elements a0​,a1​,…, and choose a nonprincipal ultrafilter D on ω. Let I be the desired total index order and put J=ωI.
For every finite ordered subset F={i1​<⋯<in​}, define an ultrafilter DF​ on ωF by the ordered Fubini product of ultrafilters: a set B belongs to DF​ exactly when
(Dm1​)(Dm2​)⋯(Dmn​)(m1​,…,mn​)∈B.
(28)
Here (Dm)ψ(m) means {m:ψ(m)}∈D, with the quantifiers nested in the displayed order. The resulting collection is an ultrafilter, by induction using the ultrafilter laws for negation and conjunction. For F⊆H, the inverse image of B⊆ωF under coordinate projection belongs to DH​ exactly when B∈DF​: quantifiers on unused coordinates leave a truth value unchanged.
Consequently there is a well-defined ultrafilter on the Boolean algebra of finite-coordinate cylinders in J, declaring a cylinder large by this test. Coherence proves finite intersection closure and ensures that the empty cylinder is not large. Extend its generated filter to an ultrafilter U on all subsets of J. Form the ultrapower N=(M∗)J/U, and for i∈I let bi​ be the class of s↦as(i)​.
If i=j, the coordinate equality test belongs to no corresponding two-coordinate product ultrafilter: for every value of the outer coordinate, the inner equality set is a singleton, excluded by nonprincipality. Hence the bi​ are distinct. For any first-order formula φ(x1​,…,xn​) and any i1​<⋯<in​, the Łoś theorem gives
N⊨φ(bi1​​,…,bin​​)⟺(Dm1​)⋯(Dmn​) M∗⊨φ(am1​​,…,amn​​).
(29)
The right side is independent of the actual increasing index tuple, so the bi​ form an order-indiscernible sequence. Constant functions embed M∗ elementarily into N. Take the Skolem hull of the generators. The Tarski-Vaught test gives an elementary substructure, and transporting terms along an index-order automorphism gives a well-defined automorphism of the hull, with inverse obtained by transporting along the inverse index automorphism. Equality of term representations is preserved by indiscernibility. This is the indiscernible and automorphism conclusion of Ehrenfeucht–Mostowski, obtained entirely from ultrafilters and Łoś's theorem. The ordered Fubini products need not be symmetric; order indiscernibility is exactly what their coherence supplies.

Use the bounded successor characterization of finite ordinals. Let Ord(x) assert that x is transitive, each of its members is transitive, and any two members are equal or comparable by membership. This is a bounded first-order formula; foundation makes its linear membership order well-founded, so it is precisely the Von Neumann ordinal predicate. Define
Succ0​(x)⟺x=∅ ∨ (∃y∈x)(∀z∈x)(z=y ∨ z∈y),
(30)
and put
Nat(x)⟺Ord(x) ∧ Succ0​(x) ∧ (∀y∈x)Succ0​(y).​
(31)
For an ordinal, having a greatest member y says exactly x=y∪{y}. The displayed definition makes no reference to an infinite inductive set or to ω; all quantifiers are bounded within the candidate and its members. Occurrences of x=∅ can also be expressed as (∀u∈x)u=u, so no unbounded quantifier is hidden in empty-set notation.
Every usual natural number satisfies this predicate, by induction: it is a finite ordinal, and every nonzero initial segment is a successor. Conversely, suppose an ordinal x is not a usual natural number. Ordinal comparability gives x≥ω. If x=ω, it has no greatest member, contradicting Succ0​(x). If x>ω, then ω∈x has no greatest member, contradicting the corresponding bounded requirement on members of x. Hence Nat(x) holds exactly for the usual natural numbers. The axiom of infinity and separation therefore collect this class as the usual set ω. This is a bounded definition of membership in the natural-number class; it does not claim that the infinite set ω itself can be produced without the infinity axiom.

An inner model of ZF is a transitive class N containing all ordinals and satisfying ZF with the inherited membership relation. The “all ordinals” requirement is important: an arbitrary transitive set model or a rank segment is not an inner model in this sense.
Every such inner model contains the ambient constructible universe L. Here is the reason. Inductively LαN​=Lα​. The zero stage is the same empty set. If the stages at α agree, satisfaction for the common set structure (Lα​,∈) is absolute: atomic first-order formulas agree, Boolean operations agree, and quantified variables range over the identical set. The codes of finite first-order formulas are also the same because a transitive model of ZF has the actual natural numbers. Consequently definability with parameters from Lα​ produces exactly the same subsets in both models, so their successor constructible stages agree. At a limit ordinal both constructions take the union of the same earlier stages. This proves agreement at every stage and hence L⊆N.
The constructible universe theorem provides models of ZF satisfying V=L and the axiom of choice, whenever ZF is consistent. In such a universe any inner model N of ZF satisfies
L=V⊆N⊆V,
(32)
so N=V and it also satisfies choice. Therefore
No uniform inner-model construction from arbitrary ZF models can establish ¬AC.​
(33)
Passing to L proves the consistency of choice, but the same downward method cannot prove its negation from an arbitrary starting model: it has no possible output when the starting universe is constructible. This is the precise obstruction intended in an inner-model independence argument. It is not a claim that every inner model of every choice universe satisfies choice; symmetric submodels of suitable forcing extensions can fail choice, and that method first changes the ambient universe.
