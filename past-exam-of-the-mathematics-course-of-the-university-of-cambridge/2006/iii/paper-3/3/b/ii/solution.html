Suppose 1=N⊲G is proper. The defining property makes N cyclic of order p. Conjugation gives a homomorphism
G⟶Aut(N),
(21)
whose kernel is the centralizer CG​(N). The automorphism group has order p−1, so the kernel has finite index in G. It contains N, because N is abelian. If this kernel were proper, it would be an order-p subgroup, and its finite index would force G itself to be finite. Therefore CG​(N)=G, so N is central.
Choose h∈/N. Part (i) shows that h has order p. Its cyclic subgroup meets N trivially, since two order-p subgroups with nontrivial intersection are equal. Since N is central,
⟨N,h⟩=N×⟨h⟩≅Cp​×Cp​.
(22)
This subgroup has order p2 and is proper because G is infinite, contradicting the assumed order of every proper nontrivial subgroup. Thus no such N exists:
G is simple.​
(23)
Together with part (i), this proves that Tarski monster groups are two-generated and simple.
