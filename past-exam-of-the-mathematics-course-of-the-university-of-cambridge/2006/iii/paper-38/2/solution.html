In a minimum-cost flow problem, every directed arc (i,j) has a per-unit cost cij​ and lower and upper capacities ℓij​,uij​. Each vertex has a prescribed net supply bi​, with ∑i​bi​=0. We seek flows minimizing ∑ij​cij​fij​ subject to the flow conservation equations
∑j​fij​−∑j​fji​=bi​,ℓij​≤fij​≤uij​.
(5)
The uncapacitated minimum-cost flow case has uij​=∞ and, here, ℓij​=0.
For project scheduling, augment the precedence graph with a source 0, of duration τ0​=0, and a sink n+1. Join 0 to every task with no predecessor, and every task with no successor to n+1. Extend the precedence matrix to these dummy arcs. This augmentation is needed because the printed n×n matrix by itself contains no start or finish vertex. Assuming the precedence graph is a Directed acyclic graph, every task lies on a source-to-sink path. Unlimited parallel work then gives the linear programming formulation
min(tn+1​−t0​),tj​−ti​≥τi​for every augmented arc (i,j).​
(6)
The time variables are unrestricted; a common translation changes nothing, so we may fix t0​=0. These inequalities say that each successor starts after its predecessor finishes. In a topological order, their coordinatewise earliest solution is tj​=maxi→j​(ti​+τi​), the recursion of the critical path method.
To derive project scheduling duality, associate a nonnegative multiplier fij​ with τi​+ti​−tj​≤0. The Lagrangian is
L(t,f)=tn+1​−t0​+∑(i,j)​fij​(τi​+ti​−tj​).
(7)
Its infimum over the free time variables is finite precisely when the coefficients of all ti​ vanish. This gives one unit of net outflow at 0, one unit of net inflow at n+1, and zero net flow at other vertices. Hence the dual is
max∑(i,j)​τi​fij​subject to f≥0 and a unit flow from 0 to n+1.
(8)
Equivalently, minimize ∑cij​fij​ with cij​=−τi​. The project duration is the negative of the optimal minimum-cost flow value. The sign is essential: the dual of the minimization problem maximizes total duration, selecting a longest precedence path.
The network simplex algorithm is a general method for minimum-cost flow. After shifting lower bounds to zero, first find a feasible flow, using artificial arcs and a phase-one objective if needed. A network simplex tree basis fixes each non-tree arc at a bound and determines the tree flows by flow conservation. Choose network dual potentials πi​ making the network reduced cost
rij​=cij​−πi​+πj​
(9)
zero on the tree. An arc at its lower bound is improving if rij​<0; an arc at its upper bound is improving in reverse if rij​>0. Adding that residual arc creates one fundamental cycle. Increase flow around this cycle until an arc reaches a bound, then exchange the entering and leaving tree arcs, or flip the entering arc to its other bound. The flow conservation equations remain satisfied. Use an anti-cycling rule for degenerate pivots. If a negative-cost residual cycle has no finite limiting capacity, the objective is unbounded below; if phase one cannot remove artificial flow, the problem is infeasible. Otherwise, termination with no negative residual network reduced costs certifies optimality, since potentials cancel around cycles and every residual network circulation has nonnegative cost.
For this project the augmented arcs are
(0,1),(0,2),(1,3),(2,4),(3,5),(4,5),(4,6),(5,7),(6,7).
(10)
In the specified initial spanning tree, the unique unit-flow path is 0→1→3→5→7. The flow on its arcs is one and that on all other tree arcs is zero. Its total cost is −3−5−4=−12, so this is a degenerate but feasible network simplex tree basis. Normalizing π0​=0, the tree equations give
(π0​,…,π7​)=(0,0,−2,3,2,8,8,12).
(11)
There are two nonbasic arcs. Their network reduced costs are
r02​=0−π0​+π2​=−2,r67​=−3−π6​+π7​=1.
(12)
Bring (0,2) into the tree. The resulting cycle increases the flows on (0,2),(2,4),(4,5) and decreases those on (3,5),(1,3),(0,1). The three decreasing arcs initially carry one unit, so the maximal step is one. Resolve the leaving-arc tie by removing (0,1). The resulting unit flow follows 0→2→4→5→7 and has cost −4−6−4=−14.
For the new tree, normalized potentials are
(π0​,…,π7​)=(0,2,0,5,4,10,10,14).
(13)
The only nonbasic arcs now have r01​=2 and r67​=1, both nonnegative. All tree network reduced costs vanish, proving optimality after this single pivot. The earliest feasible schedule, obtained by the critical path method, is
(t0​,t1​,t2​,t3​,t4​,t5​,t6​,t7​)=(0,0,0,3,4,10,10,14),T∗=14.​
(14)
The path 2→4→5 has duration 4+6+4=14, so it and the timetable furnish a unit-flow certificate for project duration.
