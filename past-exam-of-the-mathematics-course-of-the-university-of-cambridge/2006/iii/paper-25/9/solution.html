An uncountable cardinal κ is a measurable cardinal if there is a nonprincipal κ-complete ultrafilter U on κ: intersections of fewer than κ members of U remain in U. Such an ultrafilter is uniform. No singleton belongs to it, and intersecting the complements of fewer than κ singletons shows that no set of cardinality below κ belongs to it.
Form the ultrapower of the universe by U, with classes [f] of functions f:κ→V, and [f]∈U​[g] exactly when {ξ:f(ξ)∈g(ξ)}∈U. The Łoś theorem proves that the map taking x to the constant function with value x is elementary. The ultrapower relation is well-founded: from an infinite descending sequence [f0​]∋U​[f1​]∋U​⋯, countable completeness gives a coordinate satisfying all the membership relations, producing an actual infinite descending membership sequence and contradicting foundation. It is also set-like. Predecessors of [g] can be represented by functions whose value at ξ lies in g(ξ)∪{∅}; these functions form a set. The Mostowski collapse theorem therefore gives a transitive class N and an elementary embedding
j:V⟶N.
(20)
The usual class-ultrapower notation is understood via set-sized representatives and this set-like collapse.
For α<κ, any function into α is constant on a U-large set: if none of its fewer-than-κ fibers belonged to U, intersect their complements to get the empty set in U. Consequently every member of the ultrapower ordinal represented by the constant α is represented by a constant ordinal below α. Induction on α now gives j(α)=α.
On the other hand the identity function d(ξ)=ξ represents an ordinal below j(κ). For every α<κ, the tail {ξ:ξ>α} belongs to U, so the collapsed ordinal [d] is above j(α)=α. Hence
crit(j)=κ,j(κ)>κ.​
(21)
This proves nonidentity explicitly. The collapsed identity class is at least κ; it need not equal κ unless an additional normality convention is imposed on U.
Conversely, an elementary embedding j:V→N into a transitive class with critical point κ yields
U={X⊆κ:κ∈j(X)}.
(22)
For the converse use the usual amenability assumption on the class embedding, so this collection is a set. Since j(κ)>κ, exactly one of j(X) and j(κ∖X) contains κ, proving the ultrafilter condition. Singletons are excluded because j(α)=α<κ. If λ<κ and Xi​∈U for i<λ, then j fixes λ and every index below it, giving j(⋂i<λ​Xi​)=⋂i<λ​j(Xi​); the intersection still contains κ. Thus U is κ-complete and κ is measurable.
In particular the first moved ordinal is a strongly inaccessible cardinal. If cf(κ)<κ, partition κ into fewer than κ bounded intervals. Each is too small to lie in U, contradicting completeness. Thus κ is regular. If 2λ≥κ for some λ<κ, choose distinct subsets Aξ​⊆λ for ξ<κ. For each η<λ, choose the U-large side of the question η∈Aξ​. Intersect these fewer-than-κ large sides. The intersection belongs to U, but all its indices have identical Aξ​, so it contains at most one index, contradicting nonprincipality. Therefore 2λ<κ for every λ<κ, as required.
