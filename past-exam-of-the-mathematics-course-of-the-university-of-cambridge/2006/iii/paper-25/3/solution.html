Use rooted-tree homeomorphic embedding: edges may be stretched into downward paths, different child branches stay disjoint, and the source root may map to any target vertex. Write S⪯T for this relation. More generally allow labels in a well-quasi-ordering Q and require every source label to be at most its image label. We prove this labelled version, which includes the unlabelled case by taking one label.
First, every infinite sequence in a well-quasi-ordering has an infinite nondecreasing subsequence. In every infinite set of indices there is an index with infinitely many later successors above its value. Otherwise repeatedly discard the finitely many successors of each chosen index, obtaining a bad sequence. Applying this observation successively within the infinite successor set produces the required subsequence.
We also need the Higman lemma, and prove it here. If finite words over Q admitted a bad sequence, choose one w0​,w1​,… with each word of least possible length among choices permitting a bad continuation of its fixed prefix. No word is empty. Write wi​=vi​ai​, and extract indices n0​<n1​<⋯ with an0​​≤an1​​≤⋯. The sequence
w0​,…,wn0​−1​,vn0​​,vn1​​,…
(6)
is bad: an earlier wi​ embedding into some vnj​​ would embed into wnj​​, while vni​​⪯vnj​​ together with ani​​≤anj​​ would give wni​​⪯wnj​​. This contradicts the minimal length of wn0​​, since vn0​​ is shorter. Hence finite words are well-quasi-ordered under subsequence embedding with increased labels.
Now suppose labelled rooted trees admitted a bad sequence T0​,T1​,…, chosen minimally by number of vertices at each successive position. Let B consist of all immediate child subtrees of all the Ti​, with the inherited labels. We claim B is a well-quasi-ordering. Otherwise take a bad sequence of members of B. Only finitely many distinct rooted trees occur among the children of any finite initial list of Ti​, so, by discarding terms and selecting a subsequence, we may arrange its members S0​,S1​,… to come from strictly increasing parent indices n0​<n1​<⋯. Then
T0​,…,Tn0​−1​,S0​,S1​,…
(7)
is bad. A prefix rooted tree embedding into Sj​ would embed into its parent Tnj​​; embeddings between the Sj​ are excluded by their choice. But S0​ has fewer vertices than Tn0​​, contradicting minimality. This proves the claim.
List the child subtrees of each Ti​ in any order. By the Higman lemma these child lists are well-quasi-ordered. Extract an infinite subsequence with nondecreasing root labels, and then compare two child lists on that subsequence. Their subsequence embedding gives distinct target child branches into which the source child subtrees embed. Map the source root to the target root and join each embedded child root to it by the corresponding downward path. The paths are disjoint except at the root, and labels increase. Thus Ti​⪯Tj​ for some i<j, contradicting badness. This proves Kruskal's tree theorem and its labelled version. If root preservation is required, mark the root with a special label incomparable with all ordinary labels; the same proof then forces root to map to root.
For Friedman's finite form of Kruskal's theorem, fix k∈ω and suppose there are arbitrarily long bad lists satisfying ∣Ti​∣≤k+i for i=1,2,…. Make a finite bad-sequence tree whose nodes are these lists, using one representative of each finite rooted-rooted tree isomorphism type. At each position only finitely many choices satisfy the size bound, so the rooted tree is finitely branching. An infinite path exists: at every stage choose a child having extensions of arbitrarily large length, which must exist because there are finitely many children. The path is an infinite bad sequence, contradicting Kruskal's tree theorem. Therefore
∀k∈ω ∃N ∀(Ti​)1≤i≤N​[(∀i ∣Ti​∣≤k+i)⇒(∃i<j Ti​⪯Tj​)].​
(8)
The identical argument works with finitely many labels and any fixed finite size bound at each position.
