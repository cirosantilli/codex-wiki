We use the random alteration method, controlling large hypergraph independent sets and then removing the few forbidden overlaps. Fix k=2005, let n tend to infinity, and independently include each three-element subset of an n-vertex set as an hypergraph edge with probability p=n−7/4. Call the resulting three-uniform hypergraph H0​, and let s=⌈n/(2k)⌉.
For any prescribed s-vertex set, the probability that it is a hypergraph independent set is (1−p)(3s​). Hence the union bound gives
P(H0​ has an independent set of size s)≤(sn​)(1−p)(3s​)≤exp(nlog2−p(3s​))⟶0,
(8)
because p(3s​) has order n5/4, with a positive constant depending only on k.
Let Y count unordered pairs of distinct hypergraph edges meeting in two vertices. Each potential pair consists of its common pair and two distinct additional vertices, so
EY=(2n​)(2n−2​)p2=O(n1/2).
(9)
The Markov inequality implies P(Y≥n/2)=O(n−1/2). We may therefore fix one realization for which Y<n/2 and no s-vertex hypergraph independent set exists. For each offending hypergraph edge pair choose one vertex from its union, and let D be the set of all chosen vertices. Delete D, together with all incident hypergraph edges, and call the induced hypergraph H. Then ∣D∣≤Y<n/2, so N=∣V(H)∣>n/2. The next two parts verify both desired properties of this same H.
