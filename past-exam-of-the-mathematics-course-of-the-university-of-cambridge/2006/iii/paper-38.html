Introduce slack variables s1​,s2​,s3​. The initial simplex dictionary is
s1​=5−x1​,s2​=25−4x1​−x2​,s3​=125−8x1​−4x2​−x3​,z=4x1​+2x2​+x3​.
(1)
All six variables are nonnegative. The given rule is the Dantzig pivot rule: select the nonbasic variable with the largest positive reduced cost. It applies to slack variables too once they become nonbasic. At each step the simplex ratio test limits how far that entering variable can increase before a basic variable reaches zero.
The successive objective rows of the simplex dictionary, expressed in the current nonbasic variables, are
zzzzzzzz​=4x1​+2x2​+x3​,=20−4s1​+2x2​+x3​,=30+4s1​−2s2​+x3​,=50−4x1​−2s2​+x3​,=75+4x1​+2s2​−s3​,=95−4s1​+2s2​−s3​,=105+4s1​−2x2​−s3​,=125−4x1​−2x2​−s3​.​
(2)
These rows identify each entering variable unambiguously. Performing the corresponding simplex ratio tests gives the complete pivot sequence:
pivot1234567​enterx1​x2​s1​x3​x1​s2​s1​​leaves1​s2​x1​s3​s1​x2​x1​​step55525555​(x1​,x2​,x3​)(5,0,0)(5,5,0)(0,25,0)(0,25,25)(5,5,65)(5,0,85)(0,0,125)​z2030507595105125​​
(3)
For example, after pivot two the dictionary has x1​=5−s1​, x2​=5+4s1​−s2​ and s3​=65−8s1​+4s2​−x3​. Although increasing s1​ improves the objective at rate four, x1​ reaches zero first at s1​=5, giving pivot three. After pivot four, x2​=25−4x1​−s2​ and x3​=25+8x1​+4s2​−s3​; the upper bound x1​≤5 gives pivot five.
In the final objective row every reduced cost is nonpositive. Since x1​,x2​,s3​≥0, it also directly certifies the upper bound z≤125, attained only when all three vanish. Thus
x∗=(0,0,125),z∗=125,seven pivots.​
(4)
A greatest improvement pivot rule uses the total feasible increase in the objective, rather than its increase per unit of the entering variable. At the origin, the three candidate edge moves have improvements 4⋅5=20, 2⋅25=50 and 1⋅125=125. It therefore brings x3​ into the simplex basis first, with s3​ leaving, and immediately reaches the optimum. This rule solves this instance in one pivot.
This is a three-dimensional Klee-Minty cube example: the specified Dantzig pivot rule visits every vertex before reaching the optimum. Higher-dimensional versions require 2d−1 pivots, so that rule has exponential worst-case running time despite its strong practical performance. Each pivot requires only polynomially many arithmetic operations. An anti-cycling rule such as the Bland pivoting rule ensures finite termination; without one, degenerate pivots can cycle. A crude terminating bound is the number of possible bases, (mm+n​) for m constraints and n original variables, which can be exponential. This does not show that every conceivable pivot rule must take exponential time. Linear programming itself has polynomial-time algorithms, including the ellipsoid method and suitable interior-point methods.

In a minimum-cost flow problem, every directed arc (i,j) has a per-unit cost cij​ and lower and upper capacities ℓij​,uij​. Each vertex has a prescribed net supply bi​, with ∑i​bi​=0. We seek flows minimizing ∑ij​cij​fij​ subject to the flow conservation equations
∑j​fij​−∑j​fji​=bi​,ℓij​≤fij​≤uij​.
(5)
The uncapacitated minimum-cost flow case has uij​=∞ and, here, ℓij​=0.
For project scheduling, augment the precedence graph with a source 0, of duration τ0​=0, and a sink n+1. Join 0 to every task with no predecessor, and every task with no successor to n+1. Extend the precedence matrix to these dummy arcs. This augmentation is needed because the printed n×n matrix by itself contains no start or finish vertex. Assuming the precedence graph is a Directed acyclic graph, every task lies on a source-to-sink path. Unlimited parallel work then gives the linear programming formulation
min(tn+1​−t0​),tj​−ti​≥τi​for every augmented arc (i,j).​
(6)
The time variables are unrestricted; a common translation changes nothing, so we may fix t0​=0. These inequalities say that each successor starts after its predecessor finishes. In a topological order, their coordinatewise earliest solution is tj​=maxi→j​(ti​+τi​), the recursion of the critical path method.
To derive project scheduling duality, associate a nonnegative multiplier fij​ with τi​+ti​−tj​≤0. The Lagrangian is
L(t,f)=tn+1​−t0​+∑(i,j)​fij​(τi​+ti​−tj​).
(7)
Its infimum over the free time variables is finite precisely when the coefficients of all ti​ vanish. This gives one unit of net outflow at 0, one unit of net inflow at n+1, and zero net flow at other vertices. Hence the dual is
max∑(i,j)​τi​fij​subject to f≥0 and a unit flow from 0 to n+1.
(8)
Equivalently, minimize ∑cij​fij​ with cij​=−τi​. The project duration is the negative of the optimal minimum-cost flow value. The sign is essential: the dual of the minimization problem maximizes total duration, selecting a longest precedence path.
The network simplex algorithm is a general method for minimum-cost flow. After shifting lower bounds to zero, first find a feasible flow, using artificial arcs and a phase-one objective if needed. A network simplex tree basis fixes each non-tree arc at a bound and determines the tree flows by flow conservation. Choose network dual potentials πi​ making the network reduced cost
rij​=cij​−πi​+πj​
(9)
zero on the tree. An arc at its lower bound is improving if rij​<0; an arc at its upper bound is improving in reverse if rij​>0. Adding that residual arc creates one fundamental cycle. Increase flow around this cycle until an arc reaches a bound, then exchange the entering and leaving tree arcs, or flip the entering arc to its other bound. The flow conservation equations remain satisfied. Use an anti-cycling rule for degenerate pivots. If a negative-cost residual cycle has no finite limiting capacity, the objective is unbounded below; if phase one cannot remove artificial flow, the problem is infeasible. Otherwise, termination with no negative residual network reduced costs certifies optimality, since potentials cancel around cycles and every residual network circulation has nonnegative cost.
For this project the augmented arcs are
(0,1),(0,2),(1,3),(2,4),(3,5),(4,5),(4,6),(5,7),(6,7).
(10)
In the specified initial spanning tree, the unique unit-flow path is 0→1→3→5→7. The flow on its arcs is one and that on all other tree arcs is zero. Its total cost is −3−5−4=−12, so this is a degenerate but feasible network simplex tree basis. Normalizing π0​=0, the tree equations give
(π0​,…,π7​)=(0,0,−2,3,2,8,8,12).
(11)
There are two nonbasic arcs. Their network reduced costs are
r02​=0−π0​+π2​=−2,r67​=−3−π6​+π7​=1.
(12)
Bring (0,2) into the tree. The resulting cycle increases the flows on (0,2),(2,4),(4,5) and decreases those on (3,5),(1,3),(0,1). The three decreasing arcs initially carry one unit, so the maximal step is one. Resolve the leaving-arc tie by removing (0,1). The resulting unit flow follows 0→2→4→5→7 and has cost −4−6−4=−14.
For the new tree, normalized potentials are
(π0​,…,π7​)=(0,2,0,5,4,10,10,14).
(13)
The only nonbasic arcs now have r01​=2 and r67​=1, both nonnegative. All tree network reduced costs vanish, proving optimality after this single pivot. The earliest feasible schedule, obtained by the critical path method, is
(t0​,t1​,t2​,t3​,t4​,t5​,t6​,t7​)=(0,0,0,3,4,10,10,14),T∗=14.​
(14)
The path 2→4→5 has duration 4+6+4=14, so it and the timetable furnish a unit-flow certificate for project duration.

For decision problems, the usual meaning of “no harder” is a polynomial-time reduction: Π≤p​Π′ if there is a polynomial-time computable map f taking each instance x of Π to an instance of Π′ such that x is a yes-instance exactly when f(x) is. A polynomial-time algorithm for Π′ would then solve Π in polynomial time. A problem is NP-hard if every problem in NP admits such a reduction to it.
For a zero-sum game with rational payoff matrix A, the row player can calculate its value by linear programming:
maxvsubject top≥0,1⊤p=1,A⊤p≥v1.
(15)
The minimax theorem identifies this optimum with the game value. Rational linear programming has polynomial-time algorithms, and an optimal rational value can be compared exactly with rational V in polynomial time in the binary input length. Thus the decision problem belongs to P. If it were NP-hard, composing the reductions with this algorithm would put every problem in NP in P, contradicting the assumed separation. Therefore
P=NP ⟹ deciding whether a rational zero-sum game has value V is not NP-hard.​
(16)
The finite rational encoding is part of the computational model; arbitrary real inputs without an encoding would not define the same complexity question.
For the set cover reduction to equilibrium support, first take 2≤k<m and assume every element belongs to some subset. Suppose rows i1​,…,ik​ cover S. Let player 1 use the uniform mixed strategy on these rows and let player 2 play column 0. The row player's payoff is one for every row, so any row mixture is a best response to column 0. If qj​ denotes the probability that a random supported row covers element j, then qj​≥1/k, and player 2's payoff from column j>0 is
k−1k​(1−qj​)≤k−1k​(1−k1​)=1.
(17)
Column 0 also pays one. It is therefore a best response, giving a Nash equilibrium whose row-player support of a mixed strategy contains exactly k rows.
Conversely, suppose an equilibrium has row support I of size k, and some element is not covered by ⋃i∈I​Si​. For that column qj​=0, so player 2 can earn k/(k−1)>1. This is the largest possible column payoff, and it is attained exactly at columns corresponding to elements uncovered by I. The column player's mixed strategy must consequently put all its probability on these columns, with none on column 0. Every currently supported row gives player 1 payoff zero. Choose any positive-probability column j; because ⋃i​Si​=S, there is some row i′ containing j. Deviating to i′ gives strictly positive expected payoff, contradicting the best response condition. Thus I must be a cover, proving
a cover by k subsets exists⟺an equilibrium with row support exactly k exists​
(18)
under the stated union and k≥2 conditions.
The printed formulation omits both conditions. For k=1, its payoffs contain division by zero. Without the union condition its claimed implication is false: take n=2, m=3, k=2 and S1​=S2​=S3​={1}. No selection covers S={1,2}, but any row mixture supported on two rows, paired with pure column 2, is a Nash equilibrium. The row player always gets zero, and column 2 is the column player's strictly optimal choice with payoff two. This gives an explicit counterexample to the unrestricted wording.
These restrictions do not weaken the complexity conclusion. The set cover problem remains NP-complete when every element occurs in some subset and k≥2: globally uncovered elements and the easy cases k=0,1 can be recognized and replaced by fixed promised yes- or no-instances. A cover by at most k<m subsets can be padded to exactly k. The constructed game has polynomial size, so deciding whether a Nash equilibrium of the specified support size exists is NP-hard. Computing a complete description of all equilibria would resolve this question and hence is at least this difficult. In addition, the equilibrium set may be infinite; a complete output must then describe families rather than list individual points. There is a finite representation by feasible pairs of supports and their associated strategy polytopes, but there are exponentially many support pairs to consider. This reduction concerns locating specified supports or describing all equilibria, rather than finding one unrestricted equilibrium.

The SIPV model concerns a fixed number of bidders competing for one object. Each bidder knows their own private valuation; the value of winning depends on that valuation alone. Valuations are independent random variables with the same atomless distribution F, known to everyone, and bidders have identical roles and access to the same strategies. The standard revenue equivalence setting also assumes risk neutrality, quasilinear utility, and noncooperative bidding: expected utility is valuation times winning probability minus expected payment.
The revenue equivalence theorem states that auctions with the same equilibrium allocation probability p(v) for each type and the same expected utility for the lowest type have the same expected payment by each type, and therefore the same expected seller revenue. In particular, if the object goes to the highest valuation and the lowest type has zero expected utility, then all such auctions have the same expected revenue. In a strictly increasing symmetric equilibrium, p(v)=F(v)n−1.
For a bidder of valuation v, the profit as a function of winning probability is vp−e(p). At an interior stationary point p(v),
dpd​(vp−e(p))=v−e′(p)=0.
(19)
The chain rule then gives the first two identities:
e′(p(v))=v,dvd​e(p(v))=vp′(v).​
(20)
Integrating from zero and using integration by parts gives the interim payment identity
e(p(v))=e(p(0))+∫0v​wp′(w)dw=e(p(0))+vp(v)−∫0v​p(w)dw.
(21)
With the usual zero-payment normalization e(p(0))=0, this becomes
e(p(v))=vp(v)−∫0v​p(w)dw.​
(22)
Stationarity alone does not determine the integration constant: a fixed participation fee would add that constant. The stated formula uses the lowest-type normalization from revenue equivalence.
For the lowest-price auction with independent uniform distributions on [0,1], consider the symmetric increasing equilibrium, so that p(v)=vn−1. The zero type can bid zero, lose almost surely, and pay nothing. The interim payment identity therefore yields
e(p(v))=vn−∫0v​wn−1dw=nn−1​vn.
(23)
Sum this expected payment over the n bidders and average over their uniform distributions:
E[seller revenue]=n∫01​nn−1​vndv=n+1n−1​.​
(24)
This uses n≥2, as appropriate for this auction format.
For three bidders, assume the common bid is Av with A>0. If a bidder deviates to Az, 0≤z≤1, they win precisely when both opposing valuations u,w are below z. On that event they pay Amin(u,w), so their expected payment and profit are
ez​=A∫0z​∫0z​min(u,w)dudw=3A​z3,U(v,z)=vz2−3A​z3.
(25)
For 0<v<1, stationarity at z=v gives 2v2−Av2=0, hence
A=2.​
(26)
This is a global best response, not merely a stationary point: for A=2, ∂U/∂z=2z(v−z) is positive for 0<z<v and negative for v<z≤1. Any bid above 2 gives the same sure-win payment as z=1 and cannot improve the payoff.
The uniform lowest-price auction equilibrium also verifies the revenue calculation constructively for any n≥2. If opponents bid (n−1)u, a deviation to (n−1)z has profit

A Nash equilibrium of a multi-person game is a collection of strategies such that each player's strategy is a best response to the others: no unilateral change raises that player's expected payoff. For mixed strategies, every pure action used with positive probability must attain the same maximal payoff. Take c>0.
In this costly turnout game, compute the payoff difference between voting and abstaining, holding the others' strategies fixed. The opponent A is pivotal exactly when one of B,C votes. Without A the proposition then passes, while with A the tied ballot fails. The pivotal voting probability is 2β(1−β), so
ΔA​=8c⋅2β(1−β)−3c=c(16β(1−β)−3).
(28)
If A mixes with 0<α<1, indifference is necessary. Therefore
0<α<1 ⟹ β(1−β)=163​,β=41​ or 43​.​
(29)
For supporter B, voting is pivotal when A abstains and C abstains, or when A votes and C votes. Thus its voting advantage, and likewise that of C, is
ΔB​=ΔC​=4c((1−α)(1−β)+αβ)−3c.
(30)
At (α,β)=(1,3/4), this equals zero, while ΔA​=c(16(3/4)(1/4)−3)=0. Every player is indifferent between voting and abstaining at these opponent strategies; in particular, A's pure vote and both supporters' mixtures are best responses. Hence
(α,β)=(1,3/4) is an equilibrium.​
(31)
It is not unique. At (α,β)=(0,1/4), both supporter advantages are 4c(3/4)−3c=0, and ΔA​=0 again. This gives a second symmetric Nash equilibrium. To see these are the only equilibria with a common supporter probability, note that β=0 or 1 makes ΔA​=−3c, forcing α=0; neither endpoint then satisfies the supporters' best response condition. For 0<β<1, supporter indifference requires
(1−α)(1−β)+αβ=43​.
(32)
If A also mixes, its two possible values β=1/4,3/4 force α=0,1 respectively, contradicting strict mixing. Finally α=0 gives β=1/4, and α=1 gives β=3/4. Thus
The equilibria in the specified symmetric family are (0,1/4) and (1,3/4).​
(33)
Allowing B,C to have distinct probabilities β,γ gives two additional Nash equilibria. The three voting advantages are
ΔA​/cΔB​/cΔC​/c​=8(β(1−γ)+(1−β)γ)−3,=4((1−α)(1−γ)+αγ)−3,=4((1−α)(1−β)+αβ)−3.​
(34)
If both supporters mix, subtracting their indifference equations gives (2α−1)(γ−β)=0. At α=1/2 a supporter has advantage −c, so cannot mix; hence β=γ and the two symmetric equilibria result. If B always abstains and C mixes, the latter's indifference gives α=1/4, and A's indifference gives γ=3/8. Then ΔB​=−3c/4<0, so abstention really is optimal. Interchanging B,C gives the other equilibrium. If B always votes and C mixes, the corresponding equations give α=3/4, γ=5/8, but ΔB​=−3c/4, contradicting voting. The four configurations with both supporters pure also fail a best response condition. Consequently the full collection of turnout equilibria with two supporters and one opponent is
(α,β,γ)∈{(0,41​,41​), (1,43​,43​), (41​,0,83​), (41​,83​,0)}.​
(35)

A branch and bound algorithm partitions the feasible set into subproblems and attaches a valid lower bound to each subproblem's possible objective value. A completed feasible solution supplies an incumbent upper bound. For minimization, discard a node if it is infeasible or its lower bound is at least the incumbent; otherwise branch by fixing an additional decision. The best-bound search rule expands the active node with the smallest lower bound. Once every active bound is at least the incumbent, the incumbent is optimal.
For this assignment problem, use the assignment lower bound from independent task minima. For a partial assignment P, with unassigned machines M and unassigned tasks J, it is
L(P)=fixed cost(P)+∑j∈J​mini∈M​cij​.
(36)
This may reuse the same machine in several minima. Relaxing the distinct-machine constraint only reduces the cost, so the resulting lower bound is valid.

L(a=1,b=2)L(a=1,b=3)L(a=1,b=4)​=11+15+min(19,20)+min(23,28)=68,=11+13+min(17,14)+min(23,28)=61,=11+22+min(17,14)+min(19,20)=66.​
