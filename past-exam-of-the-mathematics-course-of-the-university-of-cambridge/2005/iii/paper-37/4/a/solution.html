A discrete memoryless channel is specified by discrete input and output alphabets and a transition probability W(y∣x), with W(y∣x)≥0 and ∑y​W(y∣x)=1. Its successive outputs are conditionally independent given the inputs, with the same transition rule at every use:
Pr(Y1​=y1​,…,Yn​=yn​∣X1​=x1​,…,Xn​=xn​)=∏j=1n​W(yj​∣xj​).
(34)
Operationally, its channel capacity is the supremum of communication rates in bits per use attainable by increasingly long block codes with decoding error probability tending to zero. For finite alphabets, the equivalent Shannon characterization is
C=maxPX​​I(X;Y),I(X;Y)=H(Y)−H(Y∣X),
(35)
where H is Shannon entropy, H(Y∣X) is classical conditional entropy, and the maximization is over the input probability distribution.
For the channel in question, the transition matrix, with input symbols indexing rows, is
W=​2/301/3​1/32/30​01/32/3​​.
(36)
Every row has the same Shannon entropy, namely the binary entropy h2​(1/3). Consequently H(Y∣X)=h2​(1/3) for every input probability distribution. Since the output has three symbols, the maximum entropy on a finite alphabet gives
I(X;Y)≤log2​3−h2​(1/3).
(37)
Choose a uniform input. Each column of W sums to one, so PY​(y)=1/3 for every output symbol and the upper bound is attained. Finally
h2​(1/3)=−31​log2​31​−32​log2​32​=log2​3−32​.
(38)
Thus the cyclic ternary channel capacity is
C=32​ bits per channel use,​
(39)
achieved by a uniform input probability distribution. This is a weakly symmetric channel capacity calculation: the matrix rows are permutations and the column sums agree. The channel is not the usual ternary symmetric-error channel, since an error has only one possible changed output for each input.
