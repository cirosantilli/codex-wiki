Let D=Cev​, and write Codd​=t+D for any odd-weight word t∈CH​. The parity functional on the four-dimensional binary linear code CH​ is nonzero, so its kernel D has dimension three and its other fibre is the coset t+D. For example t=(1,…,1) belongs to the standard length-seven Hamming code and has odd Hamming weight. Denote the two logical basis states by ∣ψ0​⟩ and ∣ψ1​⟩, corresponding to these two cosets. The eight computational orthonormal basis vectors in each sum are distinct, so both logical states have norm one; their disjoint supports make them orthogonal.
For a binary vector w∈F27​, define the product of Pauli Z gates
Z(w)=⨂j=17​Zjwj​​,Z(w)∣x⟩=(−1)w⋅x∣x⟩,
(50)
where the dot product is computed modulo two. The key diagonal overlap, with t0​=0 and t1​=t, is
⟨ψa​∣Z(w)∣ψa​⟩=8(−1)w⋅ta​​∑x∈D​(−1)w⋅x.
(51)
If w∈D⊥, every summand is one. If w∈/D⊥, choose x0​∈D with w⋅x0​=1. Translation x↦x+x0​ permutes D and negates every summand. The sum must then be zero. Thus
∑x∈D​(−1)w⋅x={8,0,​w∈D⊥,w∈/D⊥.​
(52)
Off-diagonal logical overlaps vanish for every w:
⟨ψ0​∣Z(w)∣ψ1​⟩=0,
(53)
because a diagonal Pauli operator cannot move a computational basis word from one coset to the disjoint other coset.
The possible errors are E0​=I and Ej​=Z(ej​) for j=1,…,7. Set e0​=0. Each phase flip is its own adjoint and inverse, so
Ei†​Ej​=Z(ei​+ej​).
(54)
If i=j, the vector ei​+ej​ is nonzero and has Hamming weight one or two. By the given dual code identity D⊥=CH​ and the minimum Hamming distance three of the Hamming code, it cannot belong to D⊥. Hence all its diagonal logical overlaps vanish. If i=j, the product is the identity and its logical overlaps are δab​. Combining both cases gives
⟨ψa​∣Ei†​Ej​∣ψb​⟩=δij​δab​(a,b∈{0,1}, i,j∈{0,…,7}).​
(55)
This proves the Knill--Laflamme condition with an identity error-overlap matrix, not merely a possibly degenerate scalar matrix. In particular the eight two-dimensional error subspaces Ei​XSteane​ are mutually orthogonal. This is precisely nondegenerate phase-flip correction in the Steane code.
To exhibit recovery rather than only the criterion, let P be the orthogonal projector onto the code and Pi​=Ei​PEi†​. The projective measurement consisting of these eight mutually orthogonal projectors, completed by I−∑i​Pi​, determines which error occurred. For an arbitrary encoded pure state ∣χ⟩=α∣ψ0​⟩+β∣ψ1​⟩ affected by Ej​, outcome j occurs with certainty and leaves Ej​∣χ⟩ unchanged. Applying Ej​ again recovers ∣χ⟩. The outcome gives the error syndrome and does not reveal α or β, so recovery preserves logical quantum superpositions.
An equivalent explicit error syndrome uses three commuting X-type stabilizer generators. Choose a parity-check matrix for CH​ with the seven different nonzero binary columns:
H=​100​010​110​001​101​011​111​​.
(56)
Its rows span CH⊥​=D. For a row hl​, the operator X(hl​)=⨂j​Xj(hl​)j​​ permutes each of D and t+D, and therefore has eigenvalue +1 on both logical states. A phase flip at position j changes its eigenvalue to (−1)Hlj​, since X(hl​)Zj​=(−1)Hlj​Zj​X(hl​). Measuring the three commuting stabilizer generators gives the jth column of H as a binary syndrome; no error gives the zero column. All eight outcomes are different, and applying the identified Zj​ restores the code state. Measuring these stabilizer generators never distinguishes the two logical states.
Finally, if a noise Kraus operator is a coherent linear combination F=∑j​cj​Ej​, the same syndrome measurement separates its mutually orthogonal components cj​Ej​∣χ⟩. Conditional recovery returns ∣χ⟩ in every nonzero branch. Linearity then also corrects any quantum channel whose Kraus operators lie in this span. The argument therefore corrects arbitrary unknown single-site phase flips nondegenerately, including coherent phase-error amplitudes, rather than only a known error on a basis codeword.
