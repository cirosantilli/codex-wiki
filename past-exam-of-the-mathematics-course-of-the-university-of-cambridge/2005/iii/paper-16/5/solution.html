We first prove invariance, before using any assertion that requires it. Write An​φ(x)=n−1∑k=0n−1​φ(fkx). Choose a point whose forward orbit has the prescribed convergence against every continuous function; the hypothesis gives a set of such points of full measure. For ergodicity, let B be a Borel set invariant modulo null sets, and set h=1B​, p=μ(B). Then h∘f=h almost everywhere. Since invariance preserves null preimages, deleting the union of all iterated preimages of the exceptional null set gives h(fkx)=h(x) for every k≥0 on one full-measure set. Thus An​h=h almost everywhere for every n.
