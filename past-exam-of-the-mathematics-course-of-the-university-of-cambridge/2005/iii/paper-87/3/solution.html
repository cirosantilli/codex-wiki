For distinct evaluation points a0​,…,an−1​∈Fq​ and 1≤k≤n, the Reed-Solomon code is
RSk​(a)={(f(a0​),…,f(an−1​)): f∈Fq​[x], degf<k}.
(17)
This is a linear code of dimension k: evaluation is linear, and a nonzero polynomial of degree less than k≤n cannot vanish at all n distinct points. The assertion of cyclicity concerns the primitive, unextended construction: set n=q−1 and aj​=ωj, where ω generates the multiplicative group of a finite field Fq×​. Arbitrary evaluation sets or arbitrary coordinate orders need not make a Reed-Solomon code a cyclic code.
For this ordered full-length construction, shifting the evaluation vector to the right gives (f(ωj−1))j​. This is the evaluation vector of f(ω−1x), whose degree is still less than k, so it is a cyclic code. Its generator polynomial follows from the finite geometric series
∑j=0n−1​ωjt={n,0,​n∣t,n∤t.​
(18)
Here the scalar n=q−1 is nonzero in Fq​. Write f(x)=∑a=0k−1​ma​xa and c(x)=∑j=0n−1​f(ωj)xj. For 1≤ℓ≤n−k,
c(ωℓ)=∑a=0k−1​ma​∑j=0n−1​ωj(a+ℓ)=0,
(19)
since 1≤a+ℓ≤n−1. Thus every word is divisible by g(x)=∏ℓ=1n−k​(x−ωℓ). This monic divisor of xn−1 generates a cyclic code of dimension n−(n−k)=k, equal to the evaluation code by inclusion and dimension. Hence
RSk​(1,ω,…,ωn−1)=⟨g⟩,g(x)=ℓ=1∏n−k​(x−ωℓ),n=q−1.​
(20)
It is useful to allow a starting exponent b for the consecutive zeros of a cyclic code. Define the primitive cyclic Reed-Solomon code
Ck,b​=⟨∏ℓ=bb+n−k−1​(x−ωℓ)⟩.
(21)
All exponents are understood modulo n. The same geometric-sum calculation shows that
Ck,b​={(aj1−b​f(aj​))j=0n−1​:degf<k}.
(22)
Indeed evaluating its word polynomial at ωb+ℓ, 0≤ℓ<n−k, gives sums with exponents a+1+ℓ between one and n−1. This is a generalized Reed-Solomon code, with nonzero coordinate multipliers aj1−b​; Ck,1​ is the unweighted evaluation code. Directly, a right shift corresponds to replacing f(x) by ωb−1f(ω−1x), so these offset codes are also cyclic codes.
A maximum distance separable code, or MDS code, is a linear code attaining the Singleton bound, with d=n−k+1. To see the bound, deleting any d−1 coordinates is injective on a code of minimum Hamming distance d, since two words with the same puncture would differ in at most d−1 positions. Therefore qk≤qn−d+1 and d≤n−k+1. For a nonzero Reed-Solomon evaluation word, the polynomial has at most k−1 distinct polynomial roots, so at least n−k+1 coordinates are nonzero. Nonzero coordinate multipliers do not change these zero positions. This proves d≥n−k+1 for both Reed-Solomon codes and generalized Reed-Solomon codes. Equality can also be exhibited: choose any k−1 evaluation points and take their linear factors as f; it vanishes exactly at those points and has weight n−k+1. Thus
RSk​ and Ck,b​ have parameters [n,k,n−k+1] and are MDS codes.​
(23)
The duality of primitive cyclic Reed-Solomon codes is especially transparent in the evaluation form. Assume first 1≤k<n. A vector of Ck,b​ has coordinates aj1−b​f(aj​), degf<k; a vector of Cn−k,1−b​ has coordinates ajb​h(aj​), degh<n−k. Their standard dot product is
∑j=0n−1​aj​f(aj​)h(aj​)=0.
(24)
Every monomial in xf(x)h(x) has exponent at least one and at most 1+(k−1)+(n−k−1)=n−1, and every such power sum vanishes. Thus Cn−k,1−b​⊆Ck,b⊥​. Both sides have dimension n−k, giving
Ck,b⊥​=Cn−k,1−b​,g⊥(x)=ℓ=1−b∏k−b​(x−ωℓ).​
(25)
In particular Ck,1⊥​=Cn−k,0​ has generator ∏ℓ=0k−1​(x−ωℓ). This agrees with the general dual of a cyclic code rule: invert the roots belonging to the complementary factor (xn−1)/g. The dual is a Reed-Solomon code in the consecutive-zero convention. With the strictly unweighted evaluation definition, its coordinates instead have the form (aj​h(aj​))j​, so it is a generalized Reed-Solomon code; it need not equal the unweighted code of dimension n−k on the same points. This convention distinction is essential. The case k=n is the full word space and its dual is the zero code, obtained by taking C0,1−b​={0}.
For code encoding, use the finite-field discrete Fourier transform and its inverse:
cℓ​=∑j=0n−1​cj​ωjℓ,cj​=n−1∑ℓ=0n−1​cℓ​ω−jℓ.
(26)
For a message (m0​,…,mk−1​), put cb−1−a​=nma​ for 0≤a<k, and set all other transform coordinates to zero. The inverse discrete Fourier transform returns
cj​=aj1−b​a=0∑k−1​ma​aja​,aj​=ωj.​
(27)
The n−k zero transform coordinates are precisely the root checks defining Ck,b​. This gives non-systematic encoding by evaluation. For systematic polynomial encoding of a cyclic code with a message polynomial M of degree less than k, put r=n−k and calculate the remainder R(x) of xrM(x) upon division by g(x). Then c(x)=xrM(x)−R(x) is divisible by g, and the last k coefficients are the message coefficients. Both methods use the same generator polynomial and the same ordered powers of ω.
For bounded-distance decoding, let y=c+e, put r=n−k, and assume at most T=⌊r/2⌋ symbol errors. The following description uses the Reed-Solomon key equation and fixes the transform and locator conventions explicitly.
  • Compute the syndromes Sℓ​=y(ωb+ℓ)=y​b+ℓ​ for 0≤ℓ<r. The corresponding codeword transform values vanish. An error of value Ei​ at coordinate ji​ contributes Ei​Xib+ℓ​, where Xi​=ωji​, so Sℓ​=∑i​Ei​Xib+ℓ​.
  • Form S(z)=∑ℓ=0r−1​Sℓ​zℓ. Use the Berlekamp-Massey algorithm, or the polynomial extended Euclidean algorithm applied to zr and S(z), to solve ΛS≡Ω(modzr) with Λ(0)=1, degΛ=ν≤T, and degΩ<ν. Choose the minimal-degree locator; zero syndrome gives Λ=1, Ω=0. The error locator polynomial is Λ(z)=∏i=1ν​(1−Xi​z), and Ω is the error evaluator polynomial.
  • Perform a Chien search: test Λ(ω−j) for 0≤j<n. Its ν distinct zeros identify the erroneous coordinates. A mismatch between the degree and the number of distinct permitted roots is a decoding failure.
  • Recover each error value by the Forney algorithm, with the present syndrome offset:
Ei​=−Xi1−b​Λ′(Xi−1​)Ω(Xi−1​)​.​
(28)
  • Set eji​​=Ei​, all other error coordinates to zero, and output c=y−e. Verify that all r root checks vanish and that the correction has weight at most T. Recover the message from the unconstrained transform coordinates by ma​=n−1cb−1−a​, or from the last k coefficients if systematic encoding was used.
The denominator in the Forney algorithm is nonzero for distinct locations. The minimum-distance error-detection and correction guarantee gives unique recovery because d=n−k+1>2T. If the required locator or a valid correction cannot be found, declare decoding failure. Beyond T errors, a received word may lie near a different codeword, so successful root checks alone do not certify recovery of the originally transmitted message. The guaranteed correction radius is ⌊(n−k)/2⌋ symbol errors.
