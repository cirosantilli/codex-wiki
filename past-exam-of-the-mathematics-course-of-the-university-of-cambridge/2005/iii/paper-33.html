Use a fixed logarithm base b>1, and write c=logb​e=1/lnb. All relative entropies below use this same base. Adopt 0log(0/q)=0 and plog(p/0)=+∞ for p>0.
For Gibbs inequality, if q(x)=0<p(x) at some point, the relative entropy is infinite and the required conclusion is immediate. Otherwise let S={x:p(x)>0}. The elementary inequality lnu≤u−1, with equality only at u=1, gives, for every x∈S,
p(x)logb​q(x)p(x)​≥c(p(x)−q(x)).
(1)
Consequently
D(p∥q)≥c(1−∑x∈S​q(x))≥0.
(2)
This argument applies to a countable discrete probability distribution too: the difference between the two sides of the pointwise inequality is nonnegative, and the negative part of the entropy summand is bounded by cq(x), hence summable. Thus no subtraction of divergent series is involved. Equality forces both ∑S​q=1 and equality in every pointwise inequality; hence q(x)=p(x) on S and q=0=p off S. Conversely p=q plainly gives zero. Therefore D(p∥q)≥0,D(p∥q)=0⟺p=q​.
For the log-sum inequality, set F=∑A​f, G=∑A​g, and normalize to the probability distributions pA​=f/F, qA​=g/G. When A is nonempty, positivity ensures F,G>0, and direct expansion gives
∑x∈A​f(x)logb​g(x)f(x)​=FD(pA​∥qA​)+Flogb​GF​≥Flogb​GF​.
(3)
Thus normalization reduces the log-sum inequality to Gibbs inequality. Equality holds exactly when f/F=g/G. The empty-set case is the zero identity under the usual zero-mass convention.
For the final bound, partition the alphabet using A={x:p(x)>q(x)} and put a=p(A), d=q(A). Since the total signed difference is zero,
a−d=∑x∈A​(p(x)−q(x))=21​∑x​∣p(x)−q(x)∣.
(4)
Apply the log-sum inequality separately to A and its complement. The same normalization argument works for countable sets of finite total mass, using the countable Gibbs inequality just proved. It yields the binary partition bound for relative entropy
D(p∥q)≥alogb​da​+(1−a)logb​1−d1−a​.
(5)
Zero block masses are interpreted by the stated conventions; a positive mass divided by zero makes the bound infinite. The given binary estimate now implies
D(p∥q)≥2c(a−d)2=2logb​e​(x∑​∣p(x)−q(x)∣)2​.
(6)
This is Pinsker's inequality. Equivalently, for the total variation distance ∥p−q∥TV​=21​∑x​∣p(x)−q(x)∣, the bound is D(p∥q)≥2logb​e∥p−q∥TV2​. The factor logb​e keeps the statement valid for either bits or natural-logarithm units.

For discrete random variables, write p(u,v) for the joint probability mass function and pU​(u) for its marginal. The conditional entropy is the average of the entropies of the conditional distributions:
h(V∣U)=−∑u:pU​(u)>0​∑v​p(u,v)logp(v∣u),p(v∣u)=pU​(u)p(u,v)​.
(7)
Conditional distributions at zero-probability values of u can be chosen arbitrarily; they contribute nothing. Here h denotes Shannon entropy, with one common logarithm base and 0log0=0.
For p(u,v)>0, use logp(u,v)=logpU​(u)+logp(v∣u) and sum with weight −p(u,v). Summing out v in the first term gives
h(U,V)=h(U)+h(V∣U)​.
(8)
For countable alphabets, the entropy contributions are nonnegative, so the equality remains valid with extended values by summing nonnegative terms. Applying this identity successively to the prefix (X1​,…,Xi−1​) and Xi​ proves the chain rule for information entropy:
h(X1​,…,Xn​)=i=1∑n​h(Xi​∣X1​,…,Xi−1​)​.
(9)
For i=1, the conditioning tuple is empty and the term is h(X1​).
For the subset inequalities, first suppose the marginal entropies are finite, so all joint entropies below are finite by the chain rule and the assumed conditioning reduces entropy property. Put H=h(X1​,…,Xn​), and let H−i​ be the joint entropy with coordinate i omitted. Apply the two-variable chain rule in the order (X[n]∖{i}​,Xi​) to get
H−H−i​=h(Xi​∣X[n]∖{i}​)≤h(Xi​∣X1​,…,Xi−1​).
(10)
The inequality holds because the prefix conditioning set is contained in the set of all other coordinates. Summing over i and using the chain rule gives
nH−∑i=1n​H−i​≤H,so∑i=1n​H−i​≥(n−1)H.
(11)
This proves Han's entropy inequality. In terms of the normalized subset entropy, hn(n)​=H/n and hn−1(n)​=∑i​H−i​/[n(n−1)], hence hn(n)​≤hn−1(n)​​ for n≥2.
Apply the same result to each k-element coordinate set S. It gives
(k−1)h(XS​)≤∑i∈S​h(XS∖{i}​).
(12)
When this is summed over all k-subsets, each fixed (k−1)-subset T occurs once for each possible added coordinate, namely n−k+1 times. Therefore
(k−1)∑∣S∣=k​h(XS​)≤(n−k+1)∑∣T∣=k−1​h(XT​).
(13)
Substitute ∑∣S∣=k​h(XS​)=k(kn​)hk(n)​ and the analogous identity at k−1. The binomial coefficient identity k(kn​)=(n−k+1)(k−1n​) cancels the common positive factor and gives
hk(n)​≤hk−1(n)​(2≤k≤n)​.
(14)
This is the monotonicity of normalized subset entropies, obtained from the local k-coordinate inequality by explicit counting.
If some marginal entropy is infinite, each subset average contains at least one subset including that coordinate. The entropy of such a subset is at least that marginal entropy, by the nonnegative conditional-entropy chain rule, so every hk(n)​ is infinite. The inequalities then hold in the extended sense. Otherwise the finite-entropy proof applies. For independent random variables the averages are all n−1∑i​h(Xi​); repeated copies of one variable instead give hk(n)​=h(X1​)/k, illustrating the entropy reduction caused by redundancy.

A binary block code of length N is a nonempty subset C⊆F2N​. Its size is ∣C∣, the number of distinct codewords. The Hamming distance d(x,y) counts coordinates at which two words differ. The code's minimum Hamming distance is minx=y∈C​d(x,y) when there are at least two words. No pairwise minimum exists for a singleton code; it can be assigned +∞ as a convention when needed.
A binary linear code is a vector subspace of F2N​. If its dimension is k, a generator matrix G has a basis of C as its k rows, giving
C={uG:u∈F2k​},∣C∣=2k.
(15)
To match the coordinate-row convention, take a parity-check matrix P of size N×(N−k), with independent columns, and define
C={x∈F2N​:xP=0}.
(16)
The transpose H=PT is the usual parity-check matrix with one column per coordinate. By rank-nullity theorem, the displayed kernel has dimension k. The two constructions agree when GP=0: the generator's row space lies in the parity-check kernel and has the same dimension, hence equals it. Conversely, for a given C, choose the columns of P as a basis of its dual code C⊥; orthogonality and the dimension formula give exactly C as the kernel.
For a nonzero linear code, x−y is a nonzero codeword whenever x,y are distinct codewords, and d(x,y)=wt(x−y). Conversely compare any nonzero codeword with zero. Thus the minimum Hamming distance of a linear code is the least nonzero Hamming weight.
Write Pi​ for the row associated with coordinate i. A nonzero binary vector x is a codeword exactly when
xP=∑i:xi​=1​Pi​=0.
(17)
Its nonzero coordinate positions therefore index a linearly dependent set of rows. Conversely, a dependence among a set of rows has coefficients in F2​, not all zero; putting these coefficients in the corresponding coordinates gives a nonzero codeword of weight no greater than the number of rows in that set. Taking minima in both directions proves the parity-check dependencies determine minimum distance criterion:
d(C)=min{∣S∣:(Pi​)i∈S​ is linearly dependent}​.
(18)
Rows here are indexed by positions: equal row vectors at different positions are two distinct members of the indexed family. In the usual matrix convention, the same result refers to columns of H=PT. For the zero code, neither a nonzero codeword nor a dependent coordinate set exists, so both minima can consistently be interpreted as +∞.
For the Hamming code, let l≥1, set N=2l−1, and let the rows of P be all nonzero vectors of F2l​, each once. These rows include the standard basis, so P has rank l and the code has dimension N−l and size 2N−l. There is no dependence involving one row, because no row is zero, or two rows, because no rows are equal. For l≥2, any two distinct nonzero vectors a,b have a distinct nonzero sum a+b, which is another row. These three rows sum to zero. Thus d(C)=3 for l≥2.
The perfectness of a Hamming code also has a direct decoding proof. Given any received word y, its syndrome is yP∈F2l​. A zero syndrome means y∈C. Otherwise it equals exactly one row Pi​. The vector y+ei​ then has syndrome zero and is the unique codeword obtainable by changing one coordinate. There is no other codeword at distance at most one: its necessary correction would have to have the same syndrome, and among zero and all single-coordinate errors the syndromes are precisely the distinct 2l vectors of F2l​. Therefore the radius-one Hamming balls about codewords partition F2N​.
Equivalently, each ball contains 1+N=2l words; disjointness and 2N−l2l=2N show that none are uncovered. Hence every nondegenerate binary Hamming code is a perfect single-error-correcting code. For l=1, the construction is the singleton code {0}⊆F2​, whose one radius-one ball is also the whole ambient space. This deals with the degenerate boundary without falsely claiming its minimum distance is three.

Let the r distinct codewords be x(1),…,x(r)∈F2N​. No linearity assumption is needed. Sum their Hamming distances over unordered distinct pairs:
S=∑1≤i<j≤r​d(x(i),x(j)).
(19)
Each summand is at least the minimum Hamming distance δ, so S≥δr(r−1)/2.
For coordinate a, let ma​ be the number of codewords whose ath bit is 1. Exactly ma​(r−ma​) unordered pairs differ at that coordinate. Summing coordinate contributions gives
S=∑a=1N​ma​(r−ma​)≤∑a=1N​4r2​=4Nr2​,
(20)
since ma​(r−ma​)=r2/4−(ma​−r/2)2. Combining the two bounds and dividing by r>0 gives 2δ(r−1)≤Nr, hence r(2δ−N)≤2δ. Under 2δ>N, division is legitimate, proving the Plotkin bound
r≤2δ−N2δ​​.
(21)
Because r is an integer, it also satisfies the floor of the right-hand side. The binary alphabet is essential to the coordinate count; this proof applies to arbitrary binary block codes, not just linear ones.

Use the homogeneous weight enumerator convention
WC​(s,t)=∑x∈C​swt(x)tN−wt(x).
(22)
Thus s records ones, t records zeros, and the ordinary weight enumerator is WC​(z,1). For a binary linear code C of dimension k and its dual code C⊥, the MacWilliams identity is
WC⊥​(s,t)=∣C∣1​WC​(t−s,t+s)​,
(23)
or, equivalently, WC​(s,t)=∣C⊥∣−1WC⊥​(t−s,t+s). The second form applies the first to the dual and uses (C⊥)⊥=C.
One can verify the variable order directly from the character identity 1C⊥​(y)=∣C∣−1∑x∈C​(−1)x⋅y. If y is not orthogonal to C, translation by a codeword having odd inner product pairs positive and negative terms, giving zero; otherwise all terms are one. After multiplying by swt(y)tN−wt(y) and summing over y, coordinate j contributes t+s when xj​=0, and t−s when xj​=1. Their product is exactly the stated substitution.
For a Hamming code with N=2l−1, its dual is the binary simplex code, generated by the l rows of the usual parity-check matrix H=PT. There are 2l dual words. A nonzero message a∈F2l​ produces the evaluations a⋅v as v runs over all nonzero vectors of F2l​. Exactly 2l−1 of them are one: the nonzero linear functional v↦a⋅v takes each value equally often on the whole vector space, and removing zero removes a zero value only. This proves the constant weight of a binary simplex code.
Put m=2l−1, so N−m=m−1. The dual enumerator is therefore tN+(2l−1)smtm−1. Applying the MacWilliams identity gives the Hamming code weight enumerator
WC​(s,t)=2l1​[(s+t)2l−1+(2l−1)(t−s)2l−1(t+s)2l−1−1]​.
(24)
In one variable this is
WC​(z,1)=2l(1+z)2l−1+(2l−1)(1−z)2l−1(1+z)2l−1−1​​.
(25)
For example, l=3 gives 1+7z3+7z4+z7; l=2 gives 1+z3. For l=1, the expression is 1, agreeing with the singleton code. Setting s=t=1 in the homogeneous formula gives 2N−l, the correct number of codewords.
