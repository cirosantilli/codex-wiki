A linear length-n cyclic code is a subspace closed under cyclic coordinate shifts. Identify a word with its polynomial modulo Xn−1; multiplying by X performs the shift. Thus a cyclic code is an ideal of Fq​[X]/(Xn−1). Its preimage in the polynomial ring is an ideal containing Xn−1, so the Euclidean algorithm gives a unique monic generator g dividing Xn−1. The generator polynomial of a cyclic code is g and the check polynomial of a cyclic code is h=(Xn−1)/g; a word lies in the code exactly when hc≡0(modXn−1).
For the binary length-seven code, the given h factors with
g(X)=X3+X+1,(X3+X+1)(X4+X2+X+1)=X7+1.​
(18)
This cubic has no binary root and is irreducible. Let α be its root in F8​. Since the nonzero multiplicative group has prime order seven and α=1, its seven powers enumerate all nonzero elements. The condition c(α)=0 gives a three-row binary parity-check matrix whose columns are precisely the seven nonzero vectors of F23​. This is Hamming's code in a cyclic coordinate order. It has dimension four, and minimum distance three: no one or two distinct nonzero columns sum to zero, while g itself has weight three. Its sixteen radius-one balls have total size 16(1+7)=128, confirming the original perfect Hamming code.
It actually contains its dual code in this coordinate order. Each parity-check row has four ones, and any two distinct rows have two simultaneous ones, so HHT=0 over F2​. The row space C⊥ therefore lies in kerH=C. Equivalently the dual generator is the reciprocal check polynomial
h∗(X)=X4+X3+X2+1=(X+1)g(X),
(19)
which is divisible by g. Hence there is a three-dimensional subcode equal to the dual, and in any other coordinate order it is equivalent to that dual.
