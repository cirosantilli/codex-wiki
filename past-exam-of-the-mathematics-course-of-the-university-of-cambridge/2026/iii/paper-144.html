A model of cardinality κ is determined up to isomorphism by the unordered pair of cardinalities of its two equivalence classes. At cardinality ℵ0​, both infinite classes must be countable, so there is one isomorphism type. Thus T1​ is categorical theory in ℵ0​.
For every uncountable κ, a model with class sizes (ℵ0​,κ) is not isomorphic to one with sizes (κ,κ). Hence T1​ is not κ-categorical for any uncountable κ; it has no finite models.

The theory is not categorical in any infinite cardinal. In cardinality ℵ0​, one may add no infinite equivalence class or one countably infinite class; these models are not isomorphic. For uncountable κ, one can vary the number and cardinalities of infinite classes while retaining infinitely many classes of every finite size. These choices are isomorphism invariants.

Every finite partial isomorphism between models of T1​ extends by one point. If the new point belongs to a class already represented in the domain, choose an unused point in the corresponding target class. Otherwise choose an unused point in the other target class. Both classes are infinite, so the choice is always possible. The back-and-forth method shows that tuples with the same quantifier-free type have the same complete type. Therefore T1​ has quantifier elimination.

The formula saying that the E-class of x has exactly n elements uses quantifiers and distinguishes elements in differently sized classes. No quantifier-free one-variable formula in the language {E} can do so, since its only atomic information is x=x and E(x,x). Thus T2​ does not eliminate quantifiers.
Expand the language by unary predicates Pn​(x), one for each positive integer n, interpreted as “the E-class of x has size n”. In this definitional expansion, back-and-forth on finite substructures gives quantifier elimination.

Fix n≥1 and let Ei​/Fi​ be the unique degree-n finite-field extension. Łoś theorem shows that
E=∏i​Ei​/U2​
(2)
is a field extension of F of degree n: ultraproducts of chosen bases satisfy the first-order linear-independence and spanning statements.
Conversely, let F(α)/F have degree n, with irreducible minimal polynomial f. Represent its coefficients by polynomials fi​. Irreducibility in fixed degree is first-order, so fi​ is irreducible of degree n for U2​-almost every i. Its root generates Ei​, and the ultraproduct of these roots induces an F-isomorphism F(α)≅E. Hence the degree-n algebraic extension exists and is unique.

A model M is aleph-zero-homogeneous model when, for finite tuples aˉ,bˉ with the same complete type and every c∈M, there is d∈M such that
tp(aˉ,c)=tp(bˉ,d).
(3)
Equivalently, every finite partial elementary map extends by one more element.

Start with the countable model M0​. There are countably many finite tuples and formulas. For every pair aˉ,bˉ∈Mi​ having the same type and every c∈Mi​, use compactness to realize over bˉ the transported type tp(c/aˉ). Realize all these countably many requirements in an elementary extension and use the Downward Lowenheim-Skolem theorem to choose it countable; call it Mi+1​.
The elementary union Mω​=⋃i<ω​Mi​ is countable. Any finite tuples and element in it occur at one stage, and their required matching element appears at the next. Thus Mω​ is an aleph-zero-homogeneous elementary extension of M0​.

Let
M=Z+(Q×Z)
(4)
with the lexicographic order, where the initial Z is one discrete block. This is a countable model of Th(Z,<): it is a discrete order without endpoints, and every interval is either of its prescribed finite length or contains arbitrarily long finite chains.
An element a in the initial block and an element b in a later block have the same one-type. There is, however, a c<b with infinitely many points between c and b, whereas no such c<a exists because every predecessor of a lies at finite distance within the initial block. The type of (b,c) therefore cannot be transported over a, so M is not aleph-zero-homogeneous.

A complete theory T is strongly minimal when, in every model of T, every definable subset of the home sort in one variable, allowing parameters, is finite or cofinite.

b OurBigBook.com
In a strongly minimal theory, model-theoretic algebraic closure is a pregeometry. Given finite tuples aˉ,bˉ of the same type, the induced correspondence extends to an isomorphism between their algebraic closures. If c∈acl(aˉ), transport it through this isomorphism. If c∈/acl(aˉ), its type is the unique generic one over aˉ; choose a corresponding element outside acl(bˉ). Exchange ensures that this choice has the transported type. Hence every finite partial elementary map extends, and every model is aleph-zero-homogeneous.

The theory ACF0​ of algebraically closed fields of characteristic zero is strongly minimal in its field sort. Let
M=Q(t0​,t1​,…)​
(5)
and take κ=ℵ1​. The countable tuples
aˉ=(t1​,t2​,…),bˉ=(t0​,t1​,…)
(6)
have the same type because both are algebraically independent sequences. The element t0​ is independent from aˉ, but there is no element of M independent from bˉ, since bˉ is a transcendence basis and M=acl(bˉ). Thus the partial elementary map aˉ↦bˉ cannot be extended to t0​, so M is not ℵ1​-homogeneous.
