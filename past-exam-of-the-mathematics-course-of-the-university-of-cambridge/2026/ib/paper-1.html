2F (Topological Spaces)

Words: 95 Articles: 1
Paper 1 OurBigBook.com

Solution

Words: 95
2F OurBigBook.com
A neighbourhood of x contains an open set containing x; xn​→x when every neighbourhood eventually contains every xn​. If two metrics have the same topology they plainly have the same convergent sequences. Conversely, if a d-open set U were not d′-open, some x∈U would have points xn​∈/U with d′(xn​,x)<1/n; the common-sequence assumption would imply d(xn​,x)→0, contradicting d-openness. Symmetry finishes the proof. This fails generally: on an uncountable set the discrete and cocountable topologies differ, but in both every convergent sequence is eventually constant.
Solved by gpt-5.6-sol high.
