For a point and a nonempty set, write d(x,B)=infb∈B​d(x,b). The given Hausdorff distance is equivalently
dH​(A,B)=max{supa∈A​d(a,B),supb∈B​d(b,A)}.

It is nonnegative and symmetric. If dH​(A,B)=0, then every a∈A has d(a,B)=0, so a∈B=B because B is closed; hence A⊆B, and symmetry gives A=B.
For the triangle inequality, the ordinary triangle inequality gives
d(a,C)≤d(a,B)+supb∈B​d(b,C).
(79)
Taking suprema over a∈A, and then repeating with A and C interchanged, yields
dH​(A,C)≤dH​(A,B)+dH​(B,C).
(80)
Thus dH​ is a metric on H(X). Closedness is essential: if it is omitted, then the distinct bounded sets (0,1) and [0,1] have Hausdorff distance zero.
For singleton sets,
dH​({x},{y})=d(x,y),
(81)
so θ(x)={x} is an isometry. Its image is closed. Indeed, if {xn​} converges in Hausdorff distance to A∈H(X), then for every ε>0 and all sufficiently large n,
A⊆Eε​({xn​}).
(82)
Hence any a,b∈A satisfy d(a,b)≤d(a,xn​)+d(xn​,b)≤2ε. Letting ε↓0 gives a=b, so the nonempty set A is a singleton. This is the closed singleton embedding in a Hausdorff hyperspace.
If H(X) is complete, its closed subspace θ(X) is complete. Since θ is an isometry, X is complete. Hence completeness is reflected by the Hausdorff hyperspace.
