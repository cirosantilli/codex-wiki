The hidden subgroup problem for a group G is specified by an oracle f:G→S that hides an unknown subgroup H≤G: it is constant on each left coset of H and takes distinct values on distinct cosets. The task is to determine H, usually by finding a generating set for it.

∣ψ⟩=sinθ∣ψG​⟩+cosθ∣ψB​⟩,sin2θ=⟨ψ∣ΠG​∣ψ⟩,

a OurBigBook.com
First construct a controlled unitary gate from the uncontrolled oracle. Keep the supplied ∣v0​⟩ in a reference register. Controlled on an extra qubit, swap the data and reference registers, query U on the register that contains ∣v0​⟩ in one branch, and swap back. Because U∣v0​⟩=∣v0​⟩, that branch is unchanged, while the other branch acquires U on the data. Reversing the control convention with Pauli X gates gives controlled-U. The reference state is returned unchanged, and each use costs one query to U and O(n) controlled-SWAP gates.
Expand ∣b⟩=∑j​bj​∣vj​⟩ in an eigenbasis of U. Exact quantum phase estimation with an m-qubit phase register produces
∑j​bj​∣cj​⟩∣vj​⟩,U∣vj​⟩=e2πicj​/2m∣vj​⟩.
(26)
Apply the available phase gates, controlled by the corresponding bits of cj​, to multiply branch j by
e−2πicj​/2m=λj−1​.
(27)
Then reverse phase estimation. Although no U† oracle was supplied, every eigenvalue obeys λj2m​=1, so U−q=U2m−q. The inverse controlled powers can therefore be implemented with forward calls to U. Since 2m=poly(n), phase estimation and its inverse use only poly(n) queries. The phase register returns to ∣0m⟩, while the data register is
∑j​bj​λj−1​∣vj​⟩=U†∣b⟩​.
(28)
As a direct check, the same spectral promise implies U†=U2m−1.

The HHL algorithm requires coherent, efficient and repeatable preparation of the normalized state ∣b⟩, normally through a known preparation circuit and its inverse; possession of a single unknown physical specimen does not supply that access. The component of b on any discarded or unresolved small-eigenvalue subspace must also be negligible. Here U is a unitary operator, so it is invertible and all its singular values equal one, giving condition number κ=1.
Standard HHL is stated for a Hermitian matrix with an efficient sparse-access or block encoding oracle. A non-Hermitian U can be embedded in the Hermitian block matrix
(0U†​U0​);
(29)
part (a) supplies efficient access to U†. With inverse-polynomial target precision, m=O(logn) phase bits, and an efficient preparation oracle for ∣b⟩, the runtime is poly(n). The output is the normalized quantum state proportional to the solution x, rather than a classical list of all its amplitudes.

Implement the assumed efficient classical algorithm for x↦θx​ as a reversible circuit. On input ∣x⟩∣0s⟩, it computes an O(m)-bit binary expansion of the angle in a work register using poly(m) Toffoli gates and elementary reversible gates. Write the computed angle as a sum of binary-weighted angles. For each angle bit, apply the corresponding controlled single-qubit Ry​ rotation to the target. These rotations have the same axis, so their angles add and produce
∣x⟩∣θx​⟩(cosθx​∣0⟩+sinθx​∣1⟩).
(30)
Finally apply uncomputation to erase the work register. Each Toffoli gate and controlled rotation has a constant-size decomposition into one- and two-qubit gates when arbitrary one-qubit rotations are available. Ignoring the stipulated precision costs, the resulting circuit has size poly(m) and returns every quantum ancilla to zero.
