First form the singleton set {b}=F1​(b,b) and then use F2​ to take a set union:
U(a,b)=F2​(F1​(a,F1​(b,b)),a)=⋃{a,{b}}=a∪{b}.
(1)
The unused second argument of F2​ may be any term. Since x∩c=x∖(x∖c), a term using only the prescribed operation symbols is
G(a,b,c)=F3​(U(a,b),F3​(U(a,b),c)).​
(2)
After substituting the displayed term for both occurrences of U, this is literally a term in F1​,F2​,F3​, and its value is (a∪{b})∩c.

Work in the ambient universe and let a,u∈L. Suppose
L⊨∀x∈a∃!yφ(x,y,u).
(3)
For each x∈a, let yx​ be this unique witness. The relativization φL is a first-order formula, so the ambient Axiom schema of replacement collects the witnesses yx​ into a set. Every witness lies in the constructible hierarchy, hence there is an ordinal α such that
{yx​:x∈a}⊆Lα​.
(4)
For example, take the supremum of one constructible rank for each witness and then increase it by one.
The set Lα​ itself belongs to Lα+1​⊆L. Taking b=Lα​, every x∈a has a witness y∈b satisfying φL(x,y,u). Therefore
L⊨∃b∀x∈a∃y∈bφ(x,y,u),
(5)
which is the stated instance of Replacement.

Suppose V=L. If x∈Lω1​​, then x∈Lα​ for some countable ordinal α. The set Lα​ is transitive and countable, so the transitive closure of x lies in a countable set. Thus x is hereditarily countable, proving
Lω1​​⊆Hℵ1​​.
(6)
Conversely, let x∈Hℵ1​​ and choose a sufficiently large Lθ​ containing x. By the Downward Lowenheim-Skolem theorem, there is a countable elementary substructure N≺Lθ​ that contains every member of TC({x}). The Mostowski collapse theorem gives a transitive collapse of N, and the condensation lemma for the constructible universe identifies it with Lβ​ for a countable ordinal β. Because N contains the transitive closure of x pointwise, the collapse fixes x. Thus x∈Lβ​⊆Lω1​​. Hence
Lω1​​=Hℵ1​​.​
(7)

The Fn forcing order is
Fn(I,J)={p:p is a finite partial function I⇀J}.
(8)
It is ordered by reverse inclusion:
q≤p⟺q⊇p,
(9)
so a stronger condition specifies more values. Its maximal, or weakest, element is the empty function ∅.

Again q≤p means q⊇p, and the maximal element is the empty function. The regularity of κ ensures that the union of a descending sequence of fewer than κ conditions still has domain of cardinality below κ whenever the conditions form a compatible increasing chain of partial functions.

Let A⊆Fn(I,J) be uncountable. Apply the Delta-system lemma to the finite sets domp for p∈A. After passing to an uncountable subset A′, there is a fixed finite root R such that
domp∩domq=R
(11)
for distinct p,q∈A′. Because J is countable and R is finite, there are only countably many functions R→J. A further uncountable subset A′′⊆A′ therefore has the same restriction to R.
Any two conditions in A′′ agree on the intersection of their domains, so their union is a common stronger condition. Thus every uncountable family contains two compatible conditions, and no uncountable antichain exists. Therefore
Fn(I,J) has the countable chain condition.​
(12)

Let c=⋃G and d(n)=c(2n). Define
H={p∈Fn(ω,2)M:p⊆d}.
(13)
This is a filter: restrictions of finite pieces of d remain in H, and the union of two members is a common stronger condition.
To prove genericity, take a dense set D∈M. Let ED​ consist of conditions q∈Fn(ω,2) for which some p∈D satisfies
p(n)=q(2n)(n∈domp).
(14)
The set ED​ is dense. Indeed, given q, first read its finitely many assigned even coordinates as a condition p0​ on ω. Choose p≤p0​ in D, and extend q by setting q(2n)=p(n) at the remaining coordinates of p. Since ED​∈M, the generic filter G meets it. For q∈G∩ED​, the corresponding p∈D is a finite subfunction of d, so p∈H∩D.
Thus H meets every dense subset belonging to M. Moreover, each singleton {(n,d(n))} belongs to H, and hence
H is Fn(ω,2)-generic over M,qquad⋃H=d.​
(15)

The forcing theorem has two parts. The definability lemma says that for every formula φ, the relation
p⊩M​φ(τ1​,…,τn​)
(16)
is definable in M. The truth lemma says that if G is generic over M, then
M[G]⊨φ(τ1G​,…,τnG​)⟺∃p∈Gp⊩M​φ(τ1​,ldots,τn​).​
(17)

Assume the forcing relation and the forcing theorem have been constructed for φ(x,y​). Define
p⊩∃xφ(x,τ)
(18)
to mean that
Dp​={q≤p:∃σ∈Mq⊩φ(σ,τ)}
(19)
is dense below p. This definition is first-order over M, so the definability lemma is preserved.
Suppose p∈G forces the existential statement. Genericity below p gives q∈G∩Dp​ and a name σ with q⊩φ(σ,τ). The truth lemma for φ yields
M[G]⊨φ(σG,τG),
(20)
so the existential statement is true. Conversely, if M[G]⊨∃xφ(x,τG), choose a name σ for a witness. The truth lemma for φ gives q∈G with q⊩φ(σ,τ), and then q⊩∃xφ(x,τ). This proves both directions of the forcing theorem for the existential formula.

Conditions in G are compatible finite functions, so their union F=⋃G is a function (ω1​)M⇀(ω1​)M. For each α<ω1​, the set
Dα​={p:α∈domp}
(21)
is dense: choose a normal function extending p and add its value at α. Genericity makes F total.
If α<β, choose a condition in the filter extending conditions that decide both values. It is contained in a normal function on an ordinal, so F(α)<F(β). Thus F is strictly increasing.
It remains to prove continuity. For every limit δ<ω1​ and γ<ω1​, let Dδ,γ​ contain the conditions p such that δ∈domp and either
p(δ)≤γ
(22)
or there is some α<δ in domp with p(α)>γ. This set is dense. Given p, extend it to a normal function f and add (δ,f(δ)); if f(δ)>γ, continuity of f supplies an α<δ with f(α)>γ, which may also be added.
Now fix γ<F(δ). Since G meets Dδ,γ​, compatibility with the condition deciding F(δ) rules out the first alternative and gives α<δ with F(α)>γ. Therefore values below δ are cofinal in F(δ). Strict increase supplies the reverse bound, so
F(δ)=α<δsup​F(α).​
(23)
Hence F is normal on (ω1​)M in M[G].

The Lévy reflection theorem states that for every finite collection Φ of formulas and every ordinal γ, there is an ordinal α>γ such that, for every φ∈Φ and all parameters a∈Vα​,
V⊨φ(a)⟺Vα​⊨φ(a).​
(24)
Indeed, the ordinals α reflecting all formulas in Φ form a closed unbounded class.

Let α=(ω1​)M and take
φ1​(α)≡“there exists a function f with domf=ω and ranf=α.”
(25)
This formula is upward absolute between transitive models: if the smaller model contains such an f, the assumed absoluteness of “function”, domain, range, and ω shows that the same witness works in the larger model.
The generic union g=⋃G is a total map ω→α, because the conditions deciding each input form a dense set. For every β<α, the conditions putting β somewhere in the range are also dense, so g is surjective. Thus M[G]⊨φ1​(α). But M⊨φ1​(α) because M regards α as its first uncountable ordinal. Hence φ1​ is not downward absolute between M and M[G].

Assume φ(a) is a Delta-one formula in set theory. Thus ZF proves it equivalent to a Σ1​ formula σ and to a Π1​ formula π. Only finitely many axioms of ZF occur in these two formal proofs; collect them, together with the finite fragment needed for bounded-formula absoluteness, into T.
Let M be a transitive class containing a and satisfying T. If M⊨φ, then M⊨σ, and upward absoluteness of Σ1​ formulas gives V⊨σ, hence V⊨φ. If V⊨φ, then V⊨π, and downward absoluteness of Π1​ formulas gives M⊨π, hence M⊨φ. Therefore ZF proves that φ is absolute for every such M.

Conversely, suppose a finite T⊆ZF has the stated absoluteness property. Let
σ(a)≡∃N[N is a transitive set, a∈N, N⊨T, N⊨φ(a)].
(27)
Because T is finite, every satisfaction assertion here can be replaced by the corresponding formula relativization to a class. All quantifiers in the matrix are bounded by N, so σ is Σ1​. Define the Π1​ formula
π(a)≡¬∃N[N is a transitive set, a∈N, N⊨T, N⊨¬φ(a)].
(28)
By the Lévy reflection theorem, ZF proves that for any parameters a there is a level Vα​ containing them and satisfying the finite fragment T. The assumed absoluteness says that every such transitive set agrees with V about φ. Consequently ZF proves
φ(a)↔σ(a)andφ(a)↔π(a).
(29)
Thus φ is both Σ1ZF​ and Π1ZF​, so it is Δ1ZF​.
