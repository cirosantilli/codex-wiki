In a unital C-star algebra A, an element is Hermitian when x=x∗, unitary when x∗x=xx∗=1, and normal when x∗x=xx∗. It is a Positive element of a C-star algebra when x=y∗y for some y, equivalently when it is Hermitian and its spectrum lies in [0,∞).
Suppose first that ∥τ∥=τ(1), and normalize so that both equal one. If x=x∗, the C-star identity gives
∥x+it1∥2=∥(x−it1)(x+it1)∥=∥x2+t21∥≤∥x∥2+t2.

Writing τ(x)=a+ib, we obtain
a2+(b+t)2=∣τ(x+it1)∣2≤∥x∥2+t2

for every real t, which forces b=0. Decomposing an arbitrary x into its Hermitian real and imaginary parts now gives

Let x=x∗. Every character of an algebra on the commutative unital Banach algebra generated by x has norm and value at one equal to one, so the preceding argument makes its value on x real. The character description of the spectrum of an element therefore gives σ(x)⊂R. Iterating the C-star identity,
∥x∥=∥x2n∥1/2n⟶r(x),

so ∥x∥=r(x). If c=∥x∥, then x+c1 has nonnegative spectrum and is positive, as is c1; hence

If 0≤x and ∥x∥≤1, then spectral translation gives
σ(1−x)=1−σ(x)⊆[0,1].
(12)
Thus 1−x is positive and, by the norm--spectral-radius equality for Hermitian elements, ∥1−x∥≤1.
Return to a norm-one τ with τ(1)=1. For 0≤x≤1, the preceding paragraph and reality on Hermitian elements give
τ(x)=1−τ(1−x)≥1−∣τ(1−x)∣≥0.

Scaling proves that τ is a positive functional on a C-star algebra. Every character has norm and value at one equal to one, so every character is positive. On C[0,1], the functional

Conversely, let τ be positive. Writing a Hermitian element as a difference of positive elements shows that τ is real on Hermitian elements. Positivity of
τ((xλ+y)∗(xλ+y))
(15)
for every λ∈C says that the associated quadratic polynomial is nonnegative. Minimizing it in λ gives the Cauchy--Schwarz inequality
∣τ(y∗x)∣2≤τ(x∗x)τ(y∗y)​.
(16)
Taking y=1 yields ∣τ(x)∣2≤τ(x∗x)τ(1). Since 0≤x∗x≤∥x∥21, positivity gives
∣τ(x)∣≤τ(1)∥x∥.
(17)
Together with τ(1)≤∥τ∥, this proves ∥τ∥=τ(1).
Convex combinations preserve positivity and value one at the identity, so the state space S(A) is convex. If x is normal, the unital C-star subalgebra C∗(1,x) is commutative and its Gelfand transform identifies it with C(σ(x)). Choose λ∈σ(x) with ∣λ∣=∥x∥. Evaluation at λ is a state taking x to λ. Its norm-preserving Hahn--Banach extension to A still takes 1 to one, so the norm criterion makes the extension a state τ satisfying ∣τ(x)∣=∥x∥.
The state space is nonempty, convex, and weak-star compact by the Banach-Alaoglu theorem. The Krein-Milman theorem gives an extreme point, so a pure state on a C-star algebra exists. For positive x, the preceding norm-attainment result makes
F={τ∈S(A):τ(x)=∥x∥}
(18)
a nonempty weak-star compact convex set. It is a face: if a convex combination has the maximal possible value on x, each summand does. An extreme point of F exists by Krein--Milman and, because F is a face, is extreme in S(A). It is the required pure state.
