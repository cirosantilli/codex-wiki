A general algorithm in the SCI hierarchy Γ:Ω→M reads a finite set ΛΓ​(A)⊂Λ on each input A. Its output depends only on those values, and whenever another input B has the same values on ΛΓ​(A), the algorithm requests the same finite set and gives the same output. A tower of algorithms of height k satisfies
Ξ(A)=limnk​→∞​⋯limn1​→∞​Γnk​,…,n1​​(A)
(4)
for every A∈Ω. The Solvability complexity index is the least such k, with value zero when one finite algorithm computes Ξ exactly.
We reduce a known height-three finite-column decision problem to spectral computation. Let (aij​)i,j∈Z​ be a bi-infinite zero-one matrix and let Ξcol​ ask whether there is a number D such that every column either contains fewer than D ones or has infinitely many ones in both directions. The lecture lower-bound theorem states
SCI(Ξcol​)G​=3,
(5)
even for unrestricted general algorithms.
For a zero-one sequence a=(ai​)i∈Z​, define Ba​ on ℓ2(Z) to be the identity on coordinates where ai​=0 and the shift from each coordinate with ai​=1 to the next coordinate carrying a one. It is a direct sum of identity pieces and one shift chain. Consequently:
  • finitely many ones give Sp(Ba​)⊂{0,1};
  • infinitely many ones in both directions give the unit circle T;
  • a one-sided infinite sequence gives the closed unit disk D.
For the columns a(j)=(aij​)i​, form the bounded direct-sum operator
C(a)=⨁j∈Z​Ba(j)​.
(6)
Every finite set of matrix entries of C(a) is determined by finitely many entries of a, so this construction respects the finite-information condition for a general algorithm in the SCI hierarchy. The preceding trichotomy implies
Ξcol​(a)=No⟹Sp(C(a))=D,
(7)
whereas
Ξcol​(a)=Yes⟹Sp(C(a))⊂{0}∪T.
(8)
The two cases are separated by the point 1/2: its distance from the spectrum is respectively zero and 1/2.
If a height-two tower Γn2​,n1​​ computed the spectrum of every bounded operator, apply it to C(a) and inspect
αn2​,n1​​=dist(21​,Γn2​,n1​​(C(a))).

Convergence in the Hausdorff distance ensures that the inner limit stabilizes; the outer limit answers Ξcol​ correctly.
