The finite-group Lagrange theorem states that ∣H∣ divides ∣G∣ for every subgroup H≤G, since the disjoint left cosets all have size ∣H∣. In particular, the order of an element divides the group order.
If ∣G∣=p and g=1, the cyclic subgroup ⟨g⟩ has order greater than one and dividing p, so it has order p. Therefore every group of prime order is cyclic.
Let G now be abelian of order p2. If an element has order p2, it generates G, giving G≅Cp2​. Otherwise every nonidentity element has order p. Choose a=1 and b∈/⟨a⟩, which is possible because ∣⟨a⟩∣=p<p2. Commutativity makes
Φ:Cp​×Cp​→G,(i,j)↦aibj
