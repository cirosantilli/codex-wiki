Put m=dimM and n=dimN. The hypothesis says that q is a regular value of F. Since its preimage is nonempty and the differential of a smooth map is surjective there, m≥n.
We use the following finite-dimensional inverse function theorem: if a smooth map H:O→Rm, with O⊂Rm open, has invertible derivative at a, there are open neighborhoods of a and H(a) on which H is a diffeomorphism, with smooth inverse.
Fix p∈F−1(q). Choose coordinate charts centered at p and q, and shrink the source neighborhood so that its image under F lies in the target chart. Its coordinate expression is f=(f1,…,fn) with f(0)=0 and derivative of rank n. Choose n domain coordinates giving an invertible n×n minor, and relabel them as x1,…,xn. Define
H(x)=(f1(x),…,fn(x),xn+1,…,xm).

These are slice charts for an embedded submanifold; reordering coordinates if desired puts the free coordinates first. Giving the level set the subspace topology, these restricted charts are smoothly compatible, as in part (a). This proves the regular level set theorem rather than merely invoking it.
The level set is an embedded submanifold of dimension m−n​. The same coordinates show Tp​Z=kerdFp​: tangent vectors to the slice have zero first n components, which are exactly the components of dFp​. The empty-dimensional case m=n gives a discrete zero-dimensional embedded submanifold.
