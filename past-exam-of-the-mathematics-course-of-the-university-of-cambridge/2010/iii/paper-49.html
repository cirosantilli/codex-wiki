Write N=2n and ∣s⟩=N−1/2∑x=0N−1​∣x⟩. The initial Hadamard gates prepare ∣s⟩ in the search register and ∣−⟩ in the final quantum ancilla. Since the Pauli X gate satisfies X∣−⟩=−∣−⟩, the Boolean quantum oracle acts by quantum phase kickback:
Uf​(∣x⟩∣−⟩)=(−1)f(x)∣x⟩∣−⟩.
(1)
For a single marked entry this is the marked-state phase oracle Oa​=I−2∣a⟩⟨a∣ on the search register. The ancilla stays separate and unchanged throughout.
The Grover diffusion operator is V=2∣s⟩⟨s∣−I, because H⊗n∣0n⟩=∣s⟩. The PDF circuit places one diffusion after each oracle call, so the state before measurement is
(VOa​)k∣s⟩⊗∣−⟩.
(2)
In the supplied amplitude amplification theorem, take ∣ψ⟩=∣s⟩ and ∣ϕ⟩=∣a⟩. Their overlap has modulus 1/N​, so the Grover rotation angle is θ=arcsin(N−1/2). A quantum measurement in the computational basis therefore gives
P(output a)=sin2((2k+1)θ).​
(3)
The inverse sine here is applied to the overlap of the two different states. The converted TeX's self-overlap in the angle definition is a transcription error; the original PDF has ∣⟨ϕ∣ψ⟩∣.

If there is no marked entry, the Boolean quantum oracle is the identity. The uniform superposition state is a positive eigenstate of the Grover diffusion operator:
V∣s⟩=(2∣s⟩⟨s∣−I)∣s⟩=∣s⟩.
(4)
Thus every iteration leaves the full state ∣s⟩⊗∣−⟩ unchanged. The measured search bits have the uniform distribution
P(output x)=N1​(0≤x<N).​
(5)
Only the first n qubits are measured in the printed circuit. If the untouched ancilla were also measured in the computational basis, its bit would be an independent fair bit, giving probability 1/(2N) for each joint outcome.

Use a verified Grover promise test. Since n>1, N≥4. Choose
k=⌊4θπ​⌋,θ=arcsin(N−1/2).
(6)
This is a nearest integer to π/(4θ)−1/2, so ∣(2k+1)θ−π/2∣≤θ. Run the Grover search algorithm for k iterations and measure the candidate x. Make one further oracle query with input ∣x⟩∣0⟩ and measure the answer bit f(x). Declare that a marked entry exists exactly when this bit is one.
In the zero case the verification always returns zero, so the decision is correct with certainty. In the single-marked-entry case, verification returns one exactly when the candidate is a, and
P(correct decision)=sin2((2k+1)θ)≥cos2θ=1−N1​≥43​.
(7)
Finally, arcsinu≥u on [0,1] gives k≤πN​/4. Hence
success probability≥43​,oracle calls=k+1=O(2n​).​
(8)
The verification query is necessary for this decision rule: an unverified search-register label does not itself say whether it is marked.

The Pauli Z gate exchanges the two Hadamard basis states: Z∣+⟩=∣−⟩ and Z∣−⟩=∣+⟩. Multiplying the displayed gate by the Pauli X gate gives
U(θ)X=∣+⟩⟨1∣+e−iθ∣−⟩⟨0∣.
(9)
On the other hand,
e−iθZU(−θ)=e−iθZ(∣+⟩⟨0∣+eiθ∣−⟩⟨1∣)=e−iθ∣−⟩⟨0∣+∣+⟩⟨1∣.
(10)
The two operators agree, proving
U(θ)X=e−iθZU(−θ).​
(11)
Also U(θ)=Hdiag(1,e−iθ)=J(−θ) in the J gate convention. Keeping this angle sign explicit avoids confusing the two conventions for equatorial qubit measurements.

Prepare the three-vertex graph-state wire: start all three qubits in ∣+⟩ and apply Controlled-Z gates on edges 1−2 and 2−3. In this paper's equatorial qubit measurement convention the basis vectors can be chosen as
∣vr​(θ)⟩=2​∣0⟩+(−1)reiθ∣1⟩​.
(12)
The given identity means that measuring an input qubit at angle θ, with outcome r, teleports its state to the next qubit as XrU(θ)∣ψ⟩. Each outcome has probability 1/2, since XrU(θ) is unitary. This is one-bit teleportation with a known Pauli frame.
Measure vertex 1 at angle α and record r. Then measure vertex 2 at angle γ=(−1)rβ, taken modulo 2π, and record s. The controlled-Z on edge 2−3 commutes with the first measurement, so the two teleportation steps can be applied successively. The remaining normalized state is
XsU(γ)XrU(α)∣+⟩.
(13)
For r=0 this is XsU(β)U(α)∣+⟩. For r=1, the relation proved above gives U(−β)X=eiβZU(β). Thus in every branch the remaining state is
eirβXsZrU(β)U(α)∣+⟩.
(14)
The scalar is a global phase and has no effect on probabilities.
Finally measure vertex 3 in the computational basis, obtaining z, and report
k=z⊕s.​
(15)
The Zr byproduct changes only computational-basis phases; Xs changes the output label by s. Hence the corrected bit has exactly the ideal circuit's probability distribution in every branch, not merely on average. The procedure uses only single-qubit measurements after preparing the graph state, adaptive classical angle selection, and deterministic classical output processing.

Use two-bit remote state preparation on a graph-state path. Alice performs the first two measurements from the preceding measurement-based quantum computation: angle α on her first qubit, giving r, then angle (−1)rβ on her second, giving s. She sends the pair (r,s) to Bob, using exactly two classical communication bits.
The branch calculation already gives Bob's state as eirβXsZr∣χ⟩, where ∣χ⟩=U(β)U(α)∣+⟩. Bob applies Xs first and Zr second, so his correction operator is ZrXs. Since X2=Z2=I,
(ZrXs)(XsZr)∣χ⟩=∣χ⟩.
(19)
Thus
Alice sends (r,s);Bob applies ZrXs.​
(20)
The final state is exactly the desired state up to the irrelevant global phase. No postselection is used: all four measurement branches have probability 1/4 and are corrected. Bob does not need the angles themselves; Alice uses them in her measurement choices, while the two bits specify his Pauli correction.

Number the wires from top to bottom as 1,…,5. The first two controlled-NOT gates encode ∣ψ⟩=u∣0⟩+v∣1⟩ into the bit-flip repetition code
u∣000⟩+v∣111⟩
(21)
on data wires 1,2,3. The lower two zero ancillas store an error syndrome. Reading the PDF's four detection CNOTs gives
s4​=b2​⊕b3​,s5​=b1​⊕b3​.
(22)
The syndrome and the data qubit to be flipped are therefore
physical errorIX1​X2​X3​​(s4​,s5​)00011011​recovery targetnone123​​
(23)
This is coherent syndrome extraction for the three-qubit repetition code. The recovery Toffoli gates implement these conditions; the intervening Pauli X gates temporarily turn zero-valued controls into one-valued controls and then restore the syndrome wires. Finally, inverse encoding returns the logical state to the top wire and resets data wires 2 and 3 to zero.
For the specified error X1​, the encoded data becomes u∣100⟩+v∣011⟩. Both terms have syndrome 01, so detection factors out ∣01⟩45​ without revealing the logical amplitudes. Recovery flips data wire 1, restoring u∣000⟩+v∣111⟩, and decoding yields
∣ψ⟩1​⊗∣0⟩2​⊗∣0⟩3​⊗∣0⟩4​⊗∣1⟩5​.​
(24)
The lower four wires need not all return to zero: their syndrome record is independent of the logical state, which is what the correction requirement needs.

Use the Hadamard gate identity H=(X+Z)/2​ on the first data wire. The X1​ branch is corrected as above and has syndrome 01. The Z1​ branch changes the encoded state to α∣000⟩−β∣111⟩, with syndrome 00. No bit-flip recovery is triggered, and decoding leaves Z∣ψ⟩ on the top wire.
By linearity of the full quantum circuit, its output for H1​ is therefore
2​1​(∣ψ⟩⊗∣0001⟩+Z∣ψ⟩⊗∣0000⟩),
(25)
where the four-bit strings are ordered as wires 2,3,4,5. The two syndrome states are orthogonal. Taking their partial trace removes the cross terms, so the reduced density matrix is
ρ=21​(∣ψ⟩⟨ψ∣+Z∣ψ⟩⟨ψ∣Z)=(∣α∣20​0∣β∣2​).​
(26)
The top output undergoes a completely dephasing channel in the computational basis. The bit-flip component is corrected, but the undetected phase component destroys logical coherence after the syndrome is ignored.

The point needing proof is that a corrected error's residual state cannot retain dependence on the logical input. Let Wj​ denote the complete linear map from the logical input to all five output wires for error Ej​. Protection gives Wj​∣0⟩=∣0⟩∣ηj,0​⟩ and Wj​∣1⟩=∣1⟩∣ηj,1​⟩. Applying protection to ∣+⟩ and comparing its two top-qubit components yields
2​∣0⟩∣ηj,0​⟩+∣1⟩∣ηj,1​⟩​=∣+⟩∣ηj,+​⟩,
(27)
so ∣ηj,0​⟩=∣ηj,1​⟩=∣ηj,+​⟩. Denote the common vector by ∣ηj​⟩. Linearity then gives Wj​∣ψ⟩=∣ψ⟩∣ηj​⟩ for every input.
The encoding and all operations surrounding the error are fixed. Replacing the error by E=αE1​+βE2​ consequently replaces the overall map by αW1​+βW2​, giving
WE​∣ψ⟩=∣ψ⟩⊗(α∣η1​⟩+β∣η2​⟩).​
(28)
Because E and the surrounding circuit are unitary, the output is normalized for every normalized input; the residual vector in parentheses thus has norm one. This proves linearity of coherent quantum error correction and hence protection against E. Orthogonality of ∣η1​⟩ and ∣η2​⟩ is not required for this proof.

Use phase-flip protection by Hadamard conjugation. Insert a Hadamard gate on each of the three data wires immediately after the two encoding CNOTs and before the physical error. Insert another Hadamard on each data wire immediately after the error and before syndrome detection. Leave the two syndrome ancillas and every detection, recovery and decoding gate unchanged.
The first layer changes the encoded state to α∣+++⟩+β∣−−−⟩, the three-qubit phase-flip repetition code. The two layers surrounding the error turn the effective error seen by the old circuit into
E′=H⊗3EH⊗3.
(29)
Since H2=I and HZH=X, the four physical cases become respectively I,X1​,X2​,X3​. The original coherent syndrome and recovery circuit corrects all four, as its syndrome table shows. Thus two Hadamard layers on the three data wires, straddling the error, give the required phase-flip protection. The final top wire is the original ∣ψ⟩, not H∣ψ⟩, because the second layer returns the data to the original coding basis before recovery and decoding.

Put N=2n and label the binary digits of x by xn−1​,…,x0​, with x=∑j=0n−1​2jxj​. The Walsh-Hadamard transform prepares the uniform quantum superposition N−1/2∑x​∣x⟩. Applying the phase gate Ra2j​ to the qubit for digit xj​ multiplies its basis amplitude by exp(2πia2jxj​/N). Taking their product gives
∏j=0n−1​e2πia2jxj​/N=e2πiax/N.
(30)
With the most significant qubit written first, this proves
(Ra2n−1​⊗Ra2n−2​⊗⋯⊗Ra​)H⊗n∣0n⟩=N​1​x=0∑N−1​e2πiax/N∣x⟩.​
(31)
Each power is implemented by repeated uses of the supplied gate. The total is ∑j=0n−1​2j=N−1 uses. This realizes dyadic phase-gate identification without needing an unknown controlled gate or asserting a gate-call cost polynomial in n.

The inverse quantum Fourier transform in the original PDF has matrix elements N−1/2e−2πiky/N multiplying ∣y⟩⟨k∣. The converted TeX incorrectly repeats y in the bra; using the actual PDF operator,
F†∣ψ⟩=N1​∑y=0N−1​(∑x=0N−1​e2πi(a−y)x/N)∣y⟩.
(32)
If y=a, every summand of the inner sum is one, so it equals N. If y=a, let q=e2πi(a−y)/N. Then q=1 and qN=1, and the finite geometric series gives ∑x=0N−1​qx=(1−qN)/(1−q)=0. This is orthogonality of roots of unity. Hence
F†∣ψ⟩=∣a⟩.​
(33)
A quantum measurement in the computational basis consequently returns the integer a with probability one.

The eigenvalue on ∣0⟩ of every power is one, and its eigenvalue on ∣1⟩ is e2πiak/N. Thus
Rak​=Ral​⟺e2πia(k−l)/N=1⟺N∣a(k−l).
(34)
If a is odd, its greatest common divisor with N=2n is one. Divisibility can therefore be cancelled, giving
Rak​=Ral​⟺k≡l(mod2n).​
(35)
In particular, the N powers with 0≤k<N are distinct. Each is the phase gate Rm​ with m≡ak(modN), and multiplication by a is a permutation of these residue classes. Equivalently, for any desired m, choose k≡a−1m(modN), where a−1 is the modular inverse. Then Rak​=Rm​, using the representative 0≤k<N and repeated forward applications only. Thus the powers generate the entire set. Once the preceding identification procedure has found a, these powers can also be labelled and selected classically.

Write the normalized qubit as ∣ϕ⟩=c0​∣0⟩+c1​∣1⟩, with ∣c0​∣2+∣c1​∣2=1. Only the ∣1⟩ amplitude changes between the two phase gates, so
(R(θ+δ)−R(θ))∣ϕ⟩=c1​eiθ(eiδ−1)∣1⟩.
(36)
Since ∣eiδ−1∣=2∣sin(δ/2)∣≤∣δ∣,
∥Rm​∣ϕ⟩−R(θ)∣ϕ⟩∥=2∣c1​∣∣sin(δ/2)∣≤∣δ∣.​
(37)
The phase-gate discretization error is uniform over all input states; its exact operator norm is 2∣sin(δ/2)∣. To choose an approximating gate, round Nθ/(2π) to the nearest integer and reduce it modulo N. Taking the shortest circular angle difference gives ∣δ∣≤π/N, and hence a uniform state-vector error at most π/2n. The circular choice handles the identified endpoints 0 and 2π correctly.
