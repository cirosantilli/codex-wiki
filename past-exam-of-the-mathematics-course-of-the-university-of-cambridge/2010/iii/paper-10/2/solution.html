Take the natural parameter range 1≤t≤r≤n and admissible indices 0≤i≤r−t. Larger indices give empty set families. Write q=r−t+1 and set n0​=∞ when discussing the first interval. For the nontrivial interval calculation, t>1 and n>2r−t+1; all prefixes used below then lie inside the ground set.
To compare consecutive complete-intersection candidate families, put a=t+2i and b=t+i. A set in Ai+1​∖Ai​ has exactly b−1 points in [a] and both of the next two points. A set in Ai​∖Ai+1​ has exactly b points in [a] and neither next point. Therefore
Gi​=∣Ai+1​∖Ai​∣=(t+i−1t+2i​)(r−t−i−1n−t−2i−2​),
(7)
Li​=∣Ai​∖Ai+1​∣=(t+it+2i​)(r−t−in−t−2i−2​).
(8)
For 0≤i<r−t these quantities are positive in the present range, and cancellation of binomial coefficients gives
Li​Gi​​=(i+1)(n−r−i−1)(t+i)(r−t−i)​.
(9)
The numerator minus the denominator is
(i+1)(ni+1​−n),ni+1​=q(2+i+1t−1​).
(10)
Thus ∣Ai+1​∣ is larger, equal or smaller than ∣Ai​∣ according as n is smaller, equal or larger than ni+1​. Since these thresholds decrease with the index, nk+1​<n<nk​ implies strict increase up to Ak​ and strict decrease thereafter:
imax​∣Ai​∣=∣Ak​∣.​
(11)
At an interior boundary n=nk+1​, the two consecutive maxima tie. The interval assertion concerns admissible k; taking k>r−t would instead refer to an empty set family and is not a valid interpretation.
The Ahlswede-Khachatrian theorem, in its cardinality form, states
M(n,r,t)=0≤i≤r−tmax​∣Ai​∣.​
(12)
Here Ai​ is interpreted exactly by its intersection with [t+2i], even if that prefix extends beyond [n]. Its size can always be written with mi​=min{n,t+2i} as
∣Ai​∣=∑j=t+ir​(jmi​​)(r−jn−mi​​),
(13)
where impossible binomial coefficients are zero. When n≤2r−t, the whole level is t-intersecting and the formula gives M=(rn​). The nontrivial case has n>2r−t.
First, each candidate is a t-intersecting family: two members contain at least 2(t+i)−(t+2i)=t common points in the prefix. This proves the lower bound for M. We now prove the upper bound, using only the compression and generating-family facts expressly allowed in the question.
The first auxiliary fact is that the usual left coordinate shifts of a set family preserve cardinality and t-intersection. Iterating them produces a left-compressed set family of the same size. The shift Sab​ with a<b replaces b by a only when b is present, a is absent, and the replacement is not already in the set family. A set family is left-compressed when it is fixed by every such shift. Right compression is the reflected notion.
For the second auxiliary fact, a generating family for a uniform set family G means a collection of sets of size at most r with
F={A∈[n](r):G⊆A for some G∈G}.
(14)
The permitted small-support generating lemma for extremal intersecting families is this precise statement: if F is a maximum-cardinality left-compressed t-intersecting set family, n>2r−t, and
n>(r−t+1)(2+j+1t−1​)(j≥0),
(15)
then it has a generating set family supported on [t+2j]. Reflection gives the same assertion for a right-compressed extremal set family, with the supporting interval at the right end. These two auxiliary results are being used as permitted lemmas; the extremal conclusion of the theorem is established in the remaining argument.
Choose a maximum left-compressed set family F. Its complement set family
F∗={[n]∖A:A∈F}
(16)
is right-compressed, has uniformity r′=n−r and intersection parameter t′=n−2r+t, and is extremal for those parameters. Indeed
∣([n]∖A)∩([n]∖B)∣=n−2r+∣A∩B∣,
(17)
so complementation gives a cardinality-preserving bijection between the two classes of intersecting set families. Notice that r′−t′+1=q too.
We need a compatibility observation, which we prove. If G generates F and H generates F∗, then
∣G∪H∣≥n−r+t.​
(18)
Otherwise extend G∪H to a set T of size n−r+t−1. This size is at least both r and n−r because n≥2r−t+1 and t≥1. Choose an r-set A⊆T containing G, and an (n−r)-set B⊆T containing H. Their generating properties imply A,[n]∖B∈F, but
∣A∩([n]∖B)∣=∣A∪B∣−∣B∣≤(n−r+t−1)−(n−r)=t−1,
(19)
a contradiction. This compatibility bound for complementary generating families is the link between the two compression directions.
Suppose first that t>1 and n>2r−t+1 lies strictly between nk+1​ and nk​. Put m=t+2k and h=r−t−k. The small-support lemma gives generators G for F supported on [m]. It also gives generators H for F∗ supported on [m+1,n]. For completeness, the dual inequality required here is
n>q(2+h+1t′−1​).
(20)
Writing D=n−2q, it is equivalent to kD<q(t−1), exactly the upper interval inequality n<nk​; for k=0 it follows from t>1. The dual support length is t′+2h=n−m.
Either every G∈G has ∣G∣≥t+k, or every H∈H has ∣H∣≥n−r−k. If neither assertion held, a pair of smaller generators would have union size at most
(t+k−1)+(n−r−k−1)=n−r+t−2,
(21)
contradicting the compatibility bound. In the first alternative, every member of F has at least t+k points in [m], so F⊆Ak​. In the second alternative, each complement has at least n−r−k points in [m+1,n], leaving its original set with at most r−t−k points there; again F⊆Ak​. Therefore M≤∣Ak​∣, proving the theorem in every strict interval.
At an interior boundary n=nk+1​, with 0≤k≤r−t−1, apply the small-support lemma at index k+1 to the original set family, since n>nk+2​. Its generators are supported on [t+2k+2]. The dual generators are still supported on [t+2k+1,n], by the same dual calculation with h=r−t−k. Either all original generators have size at least t+k+1, or all dual generators have size at least n−r−k: failure of both would give union size at most n−r+t−1, again impossible. The first alternative places F inside Ak+1​, and the second places it inside Ak​. The comparison already proved gives ∣Ak​∣=∣Ak+1​∣, so the common size is M.
It remains to cover the endpoint cases, not to assume them implicitly. For t=1 and n>2r, the small-support lemma with j=0 puts an extremal left-compressed set family's generators inside {1}. Its members must all contain one, giving M≤(r−1n−1​), attained by A0​. For t=1, n=2r, at most one member of each complementary pair can occur, so M≤21​(r2r​)=(r−12r−1​), again attained by A0​. If n<2r, the whole level is intersecting.
For t>1 and n=2r−t+1, complementation changes the problem into a one-intersection problem with uniformity q=r−t+1. Since n=2q+t−1>2q, the preceding case gives
M(n,r,t)=(q−1n−1​)=(rn−1​),
(22)
attained by Ar−t​, the set family of r-sets avoiding the final point. For n≤2r−t, every two r-sets meet in at least 2r−n≥t, so M=(rn​) and Ar−t​ is the whole level. Finally, t=r gives M=1 directly. These cases, the strict intervals and their boundaries cover all 1≤t≤r≤n, completing the proof of the stated maximum formula.
