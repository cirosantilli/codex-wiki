A set family shatters a set Z when its traces on Z include all of P(Z). The Sauer-Shelah lemma says that a set family F⊆P([n]) which shatters no k-set satisfies
∣F∣≤i=0∑k−1​(in​).​
(30)
Equivalently, if ∣F∣ exceeds this sum, it shatters a k-set. Binomial coefficients with index greater than n are zero; if k>n the inequality reduces to the whole-power-set bound. The VC dimension formulation puts k=d+1.
We give the full inductive proof. Split F according to the last coordinate, deleting that coordinate from the present section, and write these two set families on [n−1] as F0​,F1​. Put
C=F0​∪F1​,D=F0​∩F1​.
(31)
The inclusion-exclusion principle gives ∣F∣=∣C∣+∣D∣. If C shattered a k-set, then F would shatter it too. If D shattered a (k−1)-set Z, both versions of each required trace, with and without the last coordinate, would occur in F, which would shatter Z∪{n}. Thus the two mathematical induction bounds apply:
∣F∣≤∑i=0k−1​(in−1​)+∑i=0k−2​(in−1​)=∑i=0k−1​(in​),
(32)
using Pascal's identity. For n=0 the set family has at most one member. For k=1, the intersection section must be empty, since any nonempty set family shatters the empty set. These supply the mathematical induction bases; the forbidden-empty-set case has an empty set family and an empty sum. Sharpness is attained by all subsets of size at most k−1, which cannot shatter a k-set.
Now fix k≥1 in the infinite-ground-set problem. Choose, using the hypothesis with 2k, a set Y of size 2k with at least 22k−1 distinct traces. If its trace set family shattered no k-set, the Sauer-Shelah lemma would give
∣A∣Y​∣≤∑i=0k−1​(i2k​)=222k−(k2k​)​<22k−1,
(33)
a contradiction. Therefore some Z⊆Y of size k is shattered by the trace set family, and hence by A itself. Thus every finite shattering size occurs. The use of 2k makes the contradiction strict, even though the hypothesis only gives a half-power-set lower bound.
An infinite realization does not follow. For a concrete unbounded finite shattering without an infinite universal trace construction, partition X=N into disjoint finite blocks
Bj​={2j(j−1)​+1,…,2j(j+1)​},∣Bj​∣=j,
(34)
and take
A=j≥1⋃​P(Bj​).​
(35)
Every member is finite. Given k, choose Y=Bk​; its trace set family is the full power set, so it has 2k≥2k−1 members and is shattered. However, an infinite Z cannot be contained in one finite block. Choose x,y∈Z from different blocks. No member of A contains both, so {x,y} is not a trace on Z. Consequently there need not be an infinite Z whose traces contain every finite subset of Z.
