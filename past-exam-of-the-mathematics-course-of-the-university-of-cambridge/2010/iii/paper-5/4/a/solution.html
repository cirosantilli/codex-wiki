Let ϕ be a test function supported in [−R,R]. Symmetric cancellation gives
PVx1​(ϕ)=∫0R​xϕ(x)−ϕ(−x)​dx.
(27)
The integrand is bounded by 2∥ϕ′∥∞​, so the limit exists and
​PVx1​(ϕ)​≤2R∥ϕ′∥∞​.
(28)
This is a continuous linear functional on every fixed-support test space, hence a distribution. It also specifies its local order as at most one.
For the boundary value, split the ordinary complex denominator:
x+iε1​=x2+ε2x​−ix2+ε2ε​,ε>0.
(29)
The real part paired with ϕ is
∫0R​x2+ε2x[ϕ(x)−ϕ(−x)]​dx.
(30)
It converges to the principal value by dominated convergence theorem, using the same bound 2∥ϕ′∥∞​. In the second part set x=εt:
∫R​x2+ε2εϕ(x)​dx=∫R​1+t2ϕ(εt)​dt⟶πϕ(0).
(31)
Here ∥ϕ∥∞​/(1+t2) is an integrable majorant. The correct Sokhotski–Plemelj formula is therefore
x+i01​=PVx1​−iπδ.​
(32)
The resulting functional is continuous, with bound 2R∥ϕ′∥∞​+π∥ϕ∥∞​, so it too is a distribution.
The printed PDF has the wrong sign on its delta term. For a real even nonnegative test function with ϕ(0)>0, the principal value is zero while the imaginary part of every regularized integral is negative. Its limit is −πϕ(0), disproving the printed plus sign directly. A plus sign instead belongs to the boundary value (x−i0)−1.
