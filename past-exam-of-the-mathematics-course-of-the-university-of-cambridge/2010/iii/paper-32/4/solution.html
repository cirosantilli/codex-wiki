Let R be the total number of rejected null hypotheses, and let V count rejected null hypotheses that are in fact true. The false discovery proportion and false discovery rate are
FDP=R∨1V​,FDR=E[R∨1V​].​
(32)
Thus the false discovery proportion is zero when there are no rejections, and the false discovery rate averages the realized proportion of erroneous rejections.
For the Benjamini-Hochberg procedure, order the p-values as P(1)​≤⋯≤P(m)​ and define
R=max({k∈{1,…,m}:P(k)​≤αk/m}∪{0}).
(33)
Reject every hypothesis whose p-value satisfies Pi​≤αR/m when R>0, and reject none otherwise. There are exactly R such hypotheses: if a further p-value also met the threshold, its larger rank would satisfy its own, still larger, threshold, contradicting maximality. Under the stated independence and uniform true-null p-values, this procedure has false discovery rate αm0​/m≤α.
For the first modified Benjamini-Hochberg procedure, remove P1​, order the remaining m−1 p-values as Q(1)​,…,Q(m−1)​, and use the shifted critical values α(j+1)/m. Define its rejection count by
R−1​=max({j∈{1,…,m−1}:Q(j)​≤α(j+1)/m}∪{0}).
(34)
Equivalently, insert a zero in place of P1​ and run the ordinary Benjamini-Hochberg procedure on m values; its total rejection count is R(1)=R−1​+1. For r=1,…,m, the Benjamini-Hochberg leave-one-out identity in event form is
{P1​≤αr/m, R=r}={P1​≤αr/m, R−1​=r−1}.​
(35)
To prove it, suppose first that the left event holds. Then P1​ is among the rejected values. Lowering it to zero leaves all ordered p-values at ranks greater than r unchanged, so no new rank can meet its threshold. Rank r still meets its threshold, giving R(1)=r. Conversely, if R(1)=r and P1​≤αr/m, the r−1 rejected remaining values and P1​ all meet the original rank-r threshold. Hence the original count is at least r. Lowering a p-value cannot decrease the rejection count, so the original count is also at most R(1)=r. This proves equality of the events, including possible ties.
For the second modified Benjamini-Hochberg procedure, remove both P1​,P2​, order the remaining p-values as T(j)​, and use shifted critical values α(j+2)/m. Its count is
R−12​=max({j∈{1,…,m−2}:T(j)​≤α(j+2)/m}∪{0}).
(36)
Replacing P1​,P2​ by zeros in the full procedure gives a total of R(12)=R−12​+2 rejections. The same argument gives the Benjamini-Hochberg leave-two-out identity, for r=2,…,m:
{P1​≤αr/m, P2​≤αr/m, R=r}={P1​≤αr/m, P2​≤αr/m, R−12​=r−2}.​
(37)
In the forward direction both replaced values already lie among the first r, so ordered ranks greater than r remain unchanged. In the reverse direction reinserting the two values below the rank-r threshold still leaves at least r qualifying values, while monotonicity under lowering bounds the original count above by r. For r=1, the event of two p-values meeting the displayed threshold while only one is rejected is empty. For m=1 only the first modification is needed.
To calculate the second moment, write Ii​=1{i rejected} for a true null. Expanding the square gives
V2=∑i=1m0​​Ii​+∑1≤i,j≤m0​i=j​​Ii​Ij​.
(38)
For a true-null index i, let R−i​ denote the first modified count after removing Pi​. It is a function only of the remaining p-values, and so is independent of the uniform variable Pi​. The first event identity therefore yields
E(R∨1)2Ii​​=∑r=1m​r21​P(Pi​≤αr/m, R−i​=r−1)=mα​∑r=1m​rP(R−i​=r−1)​=mα​ER−i​+11​.
(39)
For distinct true-null indices i,j, the two independent uniform p-values are independent of the second modified count R−ij​. The second event identity gives
E(R∨1)2Ii​Ij​​=∑r=2m​r21​(mαr​)2P(R−ij​=r−2)=m2α2​.
(40)
The last sum is one because R−ij​ always takes a value in {0,…,m−2}. The ordered pairs in the expansion of V2 number m0​(m0​−1), with no factor of one half.
The true-null p-values are identically distributed and independent, so permutations among their indices leave the law of the full collection unchanged. Thus every R−i​ with i≤m0​ has the same distribution as R−1​, even though the false-null p-values need not be identically distributed. Combining the diagonal and off-diagonal contributions proves the second moment of the Benjamini-Hochberg false discovery proportion:
E(FDP2)=mαm0​​E(A)+m2α2m0​(m0​−1)​,A=R−1​+11​.​
(41)
If the first modified count is instead defined to include the inserted zero, the same answer is A=1/R(1). When m0​=0, both sides are zero; when m0​=1, there are no off-diagonal terms. Finally, repeating the first calculation with denominator R∨1 rather than its square gives E[Ii​/(R∨1)]=α/m, which verifies the claimed exact false discovery rate.
