The printed arrow is a partial-function arrow. Thus the central objects are partial computable functions f:Nk⇀N, with total computable functions as the special case in which every input has an output. Here N includes zero; changing this convention by a computable shift changes none of the results. A program computing f must halt with output f(x) exactly on its domain, and run forever elsewhere. A finite program is a function in intension, whereas its possibly partial input-output map is a function in extension; many programs have the same extension.
A precise machine model is a register machine with finitely many instructions to increment a register, decrement it conditionally, jump, and halt. Registers hold natural numbers. A Turing machine instead uses a finite transition table, a finite alphabet and an unbounded tape. These models simulate one another: encode the finite nonblank tape, state and head position as numbers for the register simulation; conversely represent each register by a finite tape block and implement its increment and decrement by finite scans. Tuple inputs can be encoded by a primitive recursive pairing function. The equivalence of these formal models is a mathematical result. Their identification with every informal effective procedure is the Church–Turing thesis, rather than an additional mathematical theorem about an already formal notion.
There is also an algebraic description. Begin with zero, successor and projections, close under composition of partial functions and primitive recursion, and then under unbounded minimization. The primitive recursion scheme is
f(x,0)=g(x),f(x,n+1)=h(x,n,f(x,n)).
(1)
Applied within the primitive recursive class it produces only total functions, by mathematical induction on n. Unbounded minimization searches y=0,1,… for the first zero of g(x,y); its output is defined only if that search reaches such a zero with every preceding necessary computation defined. Composition is likewise strict about the intermediate values it requires. These schemes compile into machine programs using finite subroutines, loops and an unbounded search loop.
For the converse, encode a machine's finite configurations and finite computation histories using Gödel numbering. Testing that a history starts with the specified input, that every adjacent pair follows the transition table, and that its final configuration halts is primitive recursive: all the tests are bounded by the finite code. Extracting the final output is primitive recursive too. For a suitable checking predicate T and output decoder V this proves the Kleene normal form theorem:
φe​(x)≃V(μsT(e,x,s)).
(2)
The symbol ≃ means equality of values and of definedness. A halting computation has a passing history code and every passing history has its actual output; a nonhalting computation has none. This proves that the partial recursive and machine-computable functions coincide, including their domains of divergence.
Finite programs can be effectively listed. Simulating the program with index e gives a universal partial computable function U(e,x)≃φe​(x). Fixing some inputs is effective syntactically: prepend instructions writing those constants and then call the original program. This proves the S-m-n theorem in this machine presentation. In particular, reductions that construct a program from numerical parameters really do produce its index effectively.
The primitive recursive functions are a proper subclass of the total computable functions. Enumerate all valid unary primitive recursive descriptions, interpreting invalid descriptions as zero. Evaluating any fixed valid description terminates by structural induction. Thus the diagonal map d(n)=gn​(n)+1 is total and computable, but cannot be one of the enumerated primitive recursive maps, since d(e)=ge​(e). This is a total computable diagonal over primitive recursive syntax. The evaluator can terminate on every particular description without itself being primitive recursive.
In contrast, one cannot effectively enumerate exactly the programs for all total computable functions. If such an infinite enumeration were available, wait for its nth program and run it on n, then add one. Totality makes this another total computable function, while its diagonal disagrees with every listed function. Equivalently, there is no total computable universal evaluator listing precisely all total computable maps.
The halting problem is undecidable. If H(e,x) decided whether program e halts on x, construct a program D which halts on input e exactly when H(e,e) says that it does not halt. Taking e to be D's own index gives a contradiction. The halting relation is nevertheless computably enumerable, since finite halting histories can be searched for.
More generally, a set is computably enumerable exactly when it is the domain of a partial computable function. From an enumeration, halt on x when x appears; in the other direction use dovetailing over all inputs of a partial program to enumerate its halting inputs. A set is a computable set exactly when both it and its complement are computably enumerable: dovetail the two searches and return the answer from the one that succeeds. Neither a semidecision procedure nor an unbounded search supplies a uniform negative answer.
Finally, the Rice theorem explains the scope of this obstruction. Let P be a nontrivial property of the extension of a partial computable program. Choose a partial computable g whose P-status differs from that of the nowhere-defined function. Given a program e and input x, effectively form the program which, on z, first waits for e(x) to halt and then computes g(z). If e(x) never halts its extension is nowhere defined; otherwise its extension is g. A decision procedure for P would therefore decide the halting problem. Effective descriptions allow universal simulation and positive verification, but not a decision procedure for every semantic property or for termination.

Represent the arena by a pruned set-theoretic tree T of legal finite positions. Players I and II alternate; every position has a legal continuation. The usual terminal-position convention can also be handled by adding terminal wins and losses at the initial stage. Give the branches the product topology generated by finite-position cylinders, and let A be I's winning open set.
Define the winning-position attractor in an infinite game by transfinite recursion. Start with
W0​={s∈T:[s]⊆A}.
(3)
At a successor stage retain Wα​ and add I-positions with at least one child in Wα​, and II-positions with every child in Wα​. At a limit stage take the union. The increasing sequence stabilizes because the positions form a set: strict increases at arbitrarily many stages would select too many distinct positions. Write W for the stable set. The rank of a position in W is its first entry stage; any positive such rank is a successor ordinal.
If the initial position belongs to W, at every I-position of positive rank choose a child that was present at the preceding stage. Every move by II also leads to a child of smaller rank, by the rule for II-positions. There is no infinite strictly decreasing sequence of ordinals, so every play following this strategy in an infinite game reaches W0​ after finitely many moves. Its complete branch then belongs to A. Hence this is a winning strategy in an infinite game for I.
If the initial position is outside W, every move of I stays outside W. At a II-position outside W at least one child is outside W: otherwise the entry ranks of its set of children have a common ordinal bound, and that position would enter at the next stage. Choose such a child. This gives II a strategy in an infinite game that never enters W0​. A resulting branch cannot belong to A, because A is an open set and would therefore have a finite prefix whose whole cylinder lies in A, namely a member of W0​. Thus II wins. This proves the Gale-Stewart theorem for an arbitrary set-sized arena, in the ordinary metatheory with choice. Countability of the move set was never used.
The restriction on the payoff is essential. Under the axiom of choice, already for binary moves there is an undetermined game. There are c=2ℵ0​ strategies for each player, since a strategy is a binary-valued map on a countable set of positions. List I's strategies σα​ and II's strategies τα​ for α<c. Each strategy is compatible with c different plays, obtained by varying all the opponent's binary moves.
At stage α, choose a fresh play xα​ following σα​ and then a different fresh play yα​ following τα​, avoiding every previously chosen play. Fewer than c plays have been used at that stage, even when c is singular, so these choices are possible. Let B={yα​:α<c}. No I-strategy wins B, because its selected xα​ is outside B; no II-strategy wins, because its selected yα​ is inside B. Future choices avoid all earlier xα​, so they never spoil the first assertion. This is the choice diagonalization of an undetermined game. Consequently determinacy for all payoff sets is incompatible with the axiom of choice. The attractor still makes sense for a nonopen payoff, but an avoiding play may then enter the payoff without ever having a winning finite prefix.

Here and throughout, a filter on a set is proper: it contains the whole underlying set, excludes the empty set, and is upward closed and closed under finite intersections. An improper filter cannot be extended to a proper ultrafilter.
Order the proper filter extensions of F by inclusion. The union of a chain is again a proper filter on a set: any two members already occur in one member of the chain, where their intersection belongs; the empty set never appears. By Zorn lemma, take a maximal proper extension U. If B∈/U, adjoining B must make the generated filter improper, so some C∈U has C∩B=∅. Upward closure then gives Bc∈U. Exactly one of B,Bc belongs to U, proving the ultrafilter lemma.
Let Mi​ be nonempty structures for a common first-order language, and let U be an ultrafilter on the index set I. In the ultraproduct M=∏i​Mi​/U, identify functions f,g when {i:f(i)=g(i)}∈U; interpret function symbols coordinatewise and relations by membership of their coordinate truth sets in U. The Łoś theorem states, for every first-order formula ϕ,
M⊨ϕ([f1​],…,[fn​])⟺{i:Mi​⊨ϕ(f1​(i),…,fn​(i))}∈U.
(4)
Changing representatives changes a coordinate truth set only outside a member of U, so the definitions are well defined.
Prove the theorem by structural induction on formulas. An induction on terms gives tM([fˉ​])=[i↦tMi​(fˉ​(i))], and therefore the required equivalence for atomic equality and relation formulas. For conjunction the truth set is an intersection, and a finite intersection belongs to a proper filter on a set exactly when each constituent does. For negation it is a complement, and the ultrafilter decides exactly one of a set and its complement. These prove the Boolean induction steps.
For the existential step, a witness [g] in M gives, by induction, a member of U on which ϕ(g(i),fˉ​(i)) holds. It is contained in the coordinate existential truth set, so that set belongs to U. Conversely, if
J={i:Mi​⊨∃xϕ(x,fˉ​(i))}∈U,
(5)
choose a coordinate witness g(i) for i∈J, and any element of the nonempty factor otherwise. Then the truth set of ϕ(g(i),fˉ​(i)) contains J. Induction gives a witness [g] in the ultraproduct. Universal quantification follows from negation and existence. This completes the actual proof of the Łoś theorem.
For the compactness theorem, take I to be the set of finite subsets Δ of T, and choose a model MΔ​ of each such subset. The cones
IΓ​={Δ∈I:Γ⊆Δ}(Γ⊆T finite)
(6)
are nonempty and satisfy IΓ1​​∩IΓ2​​=IΓ1​∪Γ2​​. They generate a proper filter on a set, which extends to an ultrafilter U by the proved lemma. For every σ∈T, the coordinate truth set of σ contains I{σ}​∈U. The Łoś theorem therefore gives
Δ∈I∏​MΔ​/U⊨T.​
(7)
This proves the requested compactness theorem. In fact the same proof works without the countability restriction on the language.

Fix an effective syntax encoding for the language. Let Es​ be the finite set of axioms observed in the first s steps of an enumeration of the given semidecidable axiomatization. These finite approximations can be computed in bounded time, even if the original axiom set is empty or finite. For each ϕ∈Es​, form the precisely bracketed logical conjunction
Cs​(ϕ)=s+1 copies of ϕ(⋯((ϕ∧ϕ)∧ϕ)⋯∧ϕ)​​,
(8)
with C0​(ϕ)=ϕ. Let D={Cs​(ϕ):ϕ∈Es​, s≥0}.
Each Cs​(ϕ) is logically equivalent to ϕ, so all members of D follow from the original axioms. Every original axiom eventually belongs to some Es​, and its corresponding member Cs​(ϕ) implies it. Hence D axiomatizes exactly the same theory.
To decide whether a candidate sentence ψ belongs to D, let N be its syntactic length. A conjunction of s+1 copies has length at least s+1, so a representation ψ=Cs​(ϕ) can only use s<N. Compute each Es​ for s<N, construct its finitely many candidates, and compare them literally with ψ. This finite procedure always terminates and accepts exactly D. It does not wait for a nonexistent next axiom, nor assume that conjunction parsing determines the original repeated formula uniquely. Thus D is a decidable equivalent axiomatization, proving the Craig trick.

Use the logical truth constants ⊤,⊥, and put
A′=A[p:=⊤],A′′=A[p:=⊥].
(9)
For a truth assignment with p true, A has the value of A′ and (A′∧p)∨(A′′∧¬p) has the same value. For an assignment with p false, both have the value of A′′. Thus the propositional variable elimination identity is
A≡(A[p:=⊤]∧p)∨(A[p:=⊥]∧¬p).​
(10)
Neither substituted formula contains p.
Let P=Var(A)∖Var(B), and eliminate all the private letters of A by taking
C=⋁ε:P→{0,1}​A[P:=ε],
(11)
where a Boolean assignment substitutes ⊤ or ⊥ for each letter. Then Var(C)⊆Var(A)∩Var(B). Every assignment satisfying A satisfies the disjunct corresponding to its own private-letter values, so A⊨C.
If an assignment satisfies C, choose a disjunct witnessing this, and modify only its values on P to the corresponding ε. The modified assignment satisfies A, hence satisfies B by soundness of A⊢B. Its values on every letter of B have remained unchanged, so the original assignment also satisfies B. Therefore C⊨B. The propositional completeness theorem converts these two valid implications into
A⊢CandC⊢B,​
(12)
proving propositional interpolation constructively.
If the syntax does not initially include ⊤,⊥, they can be admitted as logical constants without adding propositional letters. This convention matters when the common vocabulary is empty: a grammar in which every formula must contain a letter has no letter-free interpolant at all. For example, two tautologies using disjoint letters entail one another but cannot have an interpolant in that grammar. The truth-constant convention supplies exactly the necessary empty-vocabulary case.

Work inside a model V of ZF. Let π:V→V be a definable class bijection, with definable inverse, so that its image and inverse image of every set are sets by Axiom schema of replacement. Define new membership by
xEy⟺x∈π(y).
(13)
This is the Rieger-Bernays permutation model convention used here. Its basic advantage is that every prescribed old set b is the new extension of the object π−1(b). We verify the axioms rather than treating a membership permutation as automatically harmless.
The new axiom of extensionality follows because equality of the new extensions means π(x)=π(y), hence x=y. The new empty set and unordered pair are π−1(∅) and π−1({x,y}). Union and power set are represented by
UnionE​(a)=π−1(⋃u∈π(a)​π(u)),PowE​(a)=π−1({π−1(b):b⊆π(a)}).
(14)
Indeed, the elements of the first object are exactly the new elements of new elements of a; the elements of the second are exactly the objects whose new extensions are subsets of π(a).
Translate an arbitrary formula recursively by replacing each atomic xEy by x∈π(y). This is an ordinary definable formula in the old model. Old axiom schema of separation forms any specified subclass b of π(a), and π−1(b) supplies the new separated set. Old Axiom schema of replacement similarly collects the uniquely specified images of all elements of π(a), and applying π−1 supplies its new representative. This verifies the full schemas, including formulas with unbounded quantifiers.
For axiom of infinity, define e0​=π−1(∅) and
en+1​=π−1(π(en​)∪{en​}).
(15)
Then π(en​)={e0​,…,en−1​}. These objects are distinct by induction: equality of en​ with an earlier em​ would equate old sets of respectively n and m distinct members. Old replacement collects S={en​:n∈ω}, and π−1(S) is a new inductive set. Thus the construction satisfies every axiom of ZF except possibly Axiom of foundation.
Now interchange the old objects ∅ and {∅} and fix everything else. For q=∅ we have π(q)={q}, so its new sole member is itself: q={q}E​. This Quine atom contradicts Axiom of foundation. The identity permutation preserves the original model and its foundation. Hence, relative to consistency of ZF, foundation is independent of the other ZF axioms.
For the further independence result, a full permutation of a model of choice is insufficient. If the old model satisfies axiom of choice, then for any new family a of nonempty new sets, old choice selects g(x)∈π(x) for every x∈π(a). Encode its graph using the new ordered pairs, and represent that graph by π−1. This is a new choice function. We therefore add a hereditary finite-support restriction to a universe with many Quine atoms.
Start now with a model of ZFC. Put an​=ω+n, and let π interchange an​ and {an​} for every n∈ω, fixing other objects. All these transpositions are disjoint: the infinite ordinals an​ are distinct and none is a singleton. In the resulting membership structure, A={an​:n∈ω} is an infinite family of Quine atoms.
Build its universe W by the internal transfinite hierarchy
W0​=A,Wα+1​=A∪{π−1(b):b⊆Wα​},Wλ​=⋃α<λ​Wα​.
(16)
Write W for the union over the old ordinals. Apart from the atomic self-loops, an object's new members have lower construction ranks. Every permutation σ of A therefore extends recursively to W: on atoms use the prescribed permutation, and on other objects put
σ(x)=π−1(σ‘‘π(x)).
(17)
This is well defined and preserves E. A nonatom cannot be sent to an atom, since an extension consisting solely of one atom already represents that atom. Recursing with σ−1 gives the inverse, so these maps are genuine automorphisms.
Say that x has finite support S⊆A if every such permutation fixing S pointwise fixes x. Let H consist of the atoms and the objects with finite support all of whose new members, recursively away from atomic self-loops, belong to H. This is the hereditarily finite-supported Quine-atom model. We check why it still has the required set-theoretic axioms.
It is closed under taking new members, so extensionality remains valid. The empty object and the pure finite ordinals have empty support. Their internally represented infinite collection also has empty support, giving infinity. Pairs and unions use the finite unions of their constituents' supports; all their members remain hereditary members of H.
For a set a∈H, take all objects b∈H whose new extensions are subsets of π(a). They form an old set, since the unrestricted new power set is an old set and membership in H is definable. Its representative has support contained in a support of a, because an automorphism fixing a permutes precisely these hereditary subsets. All its members belong to H. Hence this is the power set required inside H, not a claim that unrestricted external subsets are retained.
For separation, relativize the formula to H. A support for a together with supports of the finitely many parameters fixes the resulting subclass; its members are hereditary, so its representative belongs to H. For replacement, old replacement applied to this relativized definable functional relation collects the range. Its members have a common bound on their construction ranks, by taking the supremum of the set of ranks, so the range's representative lies in W. The same finite union of parameter and domain supports fixes the range by uniqueness of each image. It is therefore hereditary and belongs to H. These arguments verify the full schemas. Thus H⊨ZF−Foundation.
Finally A and the family of its two-element subsets belong to H with empty support. Suppose a choice function c for this family belongs to H, and let S be a finite support for c. Choose distinct atoms u,v∈/S and transpose them. This permutation fixes c and fixes the unordered pair {u,v}E​, but interchanges its two possible selected members. Equivariance would require
c({u,v}E​)=σ(c({u,v}E​)),
(18)
which is impossible. Hence choice fails in H. Together with a model of ZFC, or with its full permuted model satisfying choice and failing foundation, this proves independence of axiom of choice from ZF minus foundation, relative to consistency of ZFC. All hierarchy and support arguments are internal to the starting model; no transitive-model assumption is needed.

For the Ehrenfeucht-Mostowski theorem, let M be an infinite first-order structure and I any linear order. Choose a full Skolem expansion M∗: add witness functions for existential formulas, repeat in the expanded languages, and take their union. We will construct a model of its theory containing distinct generators ci​, i∈I, forming an order-indiscernible sequence.
Adjoin the elementary diagram of M∗, the inequalities ci​=cj​ for i=j, and for every expanded-language formula ϕ(x1​,…,xr​) and every two increasing r-tuples of indices, the sentences
ϕ(ci1​​,…,cir​​)↔ϕ(cj1​​,…,cjr​​).
(19)
Every finite subcollection is satisfiable in M∗. To prove this, choose a countably infinite sequence of distinct elements of M, and for each of the finitely many relevant arities color its increasing index tuples by the finite vector of truth values of the formulas of that arity. Repeated applications of the Ramsey's theorem give an infinite subsequence homogeneous for all these finitely many finite colorings. Interpret the finitely many mentioned ci​ by its elements in their index order. All indiscernibility and distinctness constraints hold, and the finite diagram fragment holds because the ambient structure is still M∗.
By compactness theorem, a model N∗ of the full enlarged theory exists. Its Skolem hull H generated by the ci​ is elementary: whenever an existential formula with parameters in H holds in N∗, its chosen witness function returns a value in H, so the Tarski-Vaught test applies. Its reduct is a model of Th(M). If the index order has size κ, the hull has size at most κ+∣L∣+ℵ0​, and it contains ∣I∣ distinct generators.
Every order automorphism h of I induces the automorphism
t(ci1​​,…,cir​​)⟼t(ch(i1​)​,…,ch(ir​)​).
(20)
To check well-definedness, write any two terms being compared over the same increasing list of their generators. Their equality is an expanded-language formula; indiscernibility of the order-indiscernible sequence preserves its truth under h. The same argument preserves each relation, and the term construction preserves the functions. Applying h−1 gives the inverse. The extension is unique in the specified Skolem language since every hull element is a term in the generators; no uniqueness among all automorphisms of the reduct is being asserted. This proves the Ehrenfeucht-Mostowski theorem, including its usual automorphism consequence.
For simple typed set theory with atoms, use sorts 0,1,…, predicates Si​ for sets, and typed membership from sort i to sort i+1. Atoms have no members, extensionality compares sets, and every well-typed formula defines a set of the next sort. Typical ambiguity is the schema ϕ↔ϕ+ for every closed typed sentence, where the superscript raises all types by one.
Here are concrete full typed models before imposing the ambiguity schema. Choose increasing natural numbers n−1​<n0​<n1​<⋯ and set
Di​=Vω+2ni​​,Si​=P(Di−1​)⊆Di​.
(21)
The auxiliary D−1​ merely interprets the set predicate at the lowest sort. Define typed membership by
x∈i​y⟺y∈Si+1​ and x∈y.
(22)
Then the other objects of Di+1​ are atoms, regardless of their old membership. Every subset of Di​ has its representative in Si+1​, giving comprehension even for formulas with higher-sort quantifiers and parameters. Extensionality holds for the set representatives and atoms have no typed members. The rank gaps leave infinitely many atoms at each sort, and all sorts are infinite.
Consider finitely many ambiguity instances with unraised sentences ϕ1​,…,ϕt​, and choose a fixed window length r sufficient to include every sort used and its auxiliary predecessor. Color every increasing r-tuple of natural numbers by the vector of truth values of these unraised sentences in its finite rank-window interpretation. There are only 2t colors. The Ramsey's theorem gives an infinite homogeneous set. Choose r+1 successive points from it. The first r points and last r points have the same color, while the latter interpretation of ϕj​ is exactly the former model's interpretation of ϕj+​. The auxiliary predecessor shifts too, so this remains true for sentences mentioning the lowest set predicate. Extend the chosen rank sequence arbitrarily to interpret the remaining sorts. This yields a model of typed set theory satisfying all the specified ambiguity instances.
Thus every finite subset of the typed axioms together with all ambiguity instances has a model. Applying multisorted compactness theorem gives
Con(TSTU+Typical ambiguity).​
(23)
The final model satisfies first-order typed comprehension, with quantification over its own sorts and sets as in Henkin semantics.

The exponent-two Erdős-Rado theorem for pairs says that for every infinite cardinal λ,
(2λ)+⟶(λ+)λ2​.​
(24)
In particular, a finite or countable coloring of pairs from (2ℵ0​)+ has an uncountable monochromatic subset. We prove the general statement by an end-homogeneous tree construction.
Let c:[μ]2→ν be any coloring on an ordinal μ. Route a vertex β through an increasing sequence of preceding vertices as follows. Start with the least vertex. After ancestors aη​, η<ξ, have been selected, choose the least remaining candidate γ≤β, above those ancestors, satisfying
c({aη​,γ})=c({aη​,β})(η<ξ).
(25)
The terminal candidate β always qualifies, so the procedure eventually reaches it. Candidate sets shrink and their least elements increase. If an intermediate candidate is γ, its route is precisely the earlier part of the route to β, because all earlier color tests agree. Consequently the routes define a set-theoretic tree on the vertices.
Along a branch, the color from an ancestor to every later branch vertex is constant. Also a node of height α is determined by its sequence of α colors to its ancestors: reconstruct the ancestors as successive least candidates with those prescribed colors, then reconstruct the node as the least final candidate. Thus its level has at most ν∣α∣ nodes.
Apply this with μ=(2λ)+ and ν=λ. If every node had height less than λ+, each level would have size at most λλ≤2λ, and there would be at most λ+ such levels. Their total size would be at most 2λ, contradicting ∣μ∣=(2λ)+. Hence some route has at least λ+ ancestors. For each ancestor mark its constant color to all later route points. Since there are only λ colors, one occurs on λ+ ancestors. Those ancestors form the required monochromatic set. This proves the theorem.
To make the ordinal function precise, one useful ordinal partition-bound function is
f(α)=min{β≥α:for every nonzero cardinal ν<α, β⟶(α)ν2​}.
(26)
The target here is ordinal order type. For infinite α, the proved theorem with λ=∣α∣ supplies a bound (2λ)+: its homogeneous set has order type at least λ+>α, and it handles all the required color counts. Finite targets are handled by finite Ramsey theorem bounds. Thus f is total, nondecreasing and f(α)≥α.
Suppose a sequence of transfinite iterates αξ+1​=f(αξ​), with suprema at limit stages, has supremum an uncountable cardinal κ at a limit stage, with every earlier iterate below κ. Then
θ<κ⟹f(θ)<κ:
(27)
choose an earlier iterate at least θ and use the next one as a bound. If the iteration has already stabilized, it has already found a fixed point instead.
This closure forces κ to be a strong limit cardinal. For any infinite λ<κ, color pairs of distinct binary strings of length λ by their first differing coordinate. This uses λ colors and has no monochromatic triangle: three binary digits at one coordinate cannot be pairwise different. It gives a coloring on 2λ with no homogeneous target of type λ+1. Since λ colors are allowed when the target is the ordinal λ+1, we have
2λ<f(λ+1)<κ.
(28)
Finite exponents satisfy the strong-limit requirement automatically for uncountable κ.
The needed additional condition is the tree property: every tree of height κ, with nonempty levels of size less than κ, has a cofinal branch. In the present convention it forces κ to be a regular cardinal. If κ were singular, take a cofinal sequence of smaller cardinals of length cf(κ) and form the disjoint union of chains of those lengths. This tree has height and total size κ, levels of size at most cf(κ)<κ, but no branch of length κ, a contradiction.
For any ν<κ, apply the preceding color-routing tree to a coloring [κ]2→ν. If a route already has length κ, use it. Otherwise its levels are indexed below κ and each has size
ν∣α∣≤2ν⋅∣α∣<κ
(29)
for infinite exponents, by the strong-limit property; finite cases satisfy the same needed bound directly. The tree has κ nodes, so regularity forces its height to be κ. The tree property supplies a cofinal branch. The ancestor-color partition of that branch has one class of size κ, since ν<κ and κ is regular. Thus κ→(κ)ν2​ for every ν<κ, and
f(κ)=κ.​
(30)
We have proved that an uncountable function-closed cardinal with the tree property is regular and strong limit, hence strongly inaccessible, and that it is the requested fixed point.
The paper's final sentence, read as a claim about the tree property alone, is false. Already ℵ0​ has it by the König infinity lemma but is not uncountable; even with uncountability stipulated, there are relative-consistency models with the tree property at ℵ2​. The latter counterexample is documented in the research account of Mitchell forcing. The rigorous conclusion in the iterated-function context is the one just proved: function closure supplies strong limit, and the tree property supplies regularity and a branch. Strong limit and regularity follow from distinct hypotheses in this context.

This verifies that all stage maps into the limit are elementary.

A model-theoretic ultralimit is the direct limit of a chain of successive ultrapowers along their diagonal elementary maps. It is not the topological notion of a limit along an ultrafilter. We first prove the precise relative embedding lemma needed to synchronize two such limits.
If A≺B, then B embeds elementarily into an ultrapower of A, with the embedding restricting on A to its diagonal map. To prove this Frayne embedding lemma, use the elementary diagram of B with the elements of A treated as named parameters. Every finite fragment Δ of that diagram has a realization in A: replace its finitely many names from B∖A by variables and existentially quantify their conjunction. It is true in B, and hence true in A by elementarity. Choose these simultaneous realizations for each finite fragment, keeping every parameter from A interpreted as itself; give unmentioned names an arbitrary default in the nonempty A.
On the index set of finite fragments, extend the filter of cones {Δ:Δ⊇Γ} to an ultrafilter U. For each b∈B, let gb​(Δ) be its value in the chosen coordinate realization. Every diagram sentence is satisfied on its cone, so the Łoś theorem makes b↦[gb​] an elementary embedding B→AI/U. Inequalities in the diagram ensure injectivity. If b∈A, all its coordinates equal b, giving exactly the diagonal map.
There is also the initial version: if merely A≡B, then A embeds elementarily into an ultrapower of B. A finite fragment of the elementary diagram of A, with all its names replaced by variables, yields an existential sentence true in A and hence in B. The identical finite-fragment and cone construction therefore proves this version without already assuming an embedding.
Start with A0​=A. Use the initial version to place A0​ elementarily in an ultrapower B0​ of B. Relabel embedded copies so we can regard the elementary maps as inclusions. Apply the relative version to A0​≺B0​ to obtain an ultrapower A1​ of A0​ containing B0​, and whose inclusion of A0​ is its diagonal map. Next apply it to B0​≺A1​ to obtain an ultrapower B1​ of B0​ containing A1​, again fixing the earlier diagonal inclusion. Continuing gives an elementary chain
A0​≺B0​≺A1​≺B1​≺A2​≺B2​≺⋯.
(34)
The common union C is elementary over every stage by the elementary chain theorem, and
C=⋃n<ω​An​=⋃n<ω​Bn​.
(35)
The first presentation is a model-theoretic ultralimit of A. The second, preceded by the initial diagonal embedding of B into B0​, is a model-theoretic ultralimit of B. Each consecutive same-letter inclusion is precisely the corresponding ultrapower diagonal map, not just an unspecified elementary embedding. Thus the two limits are identified with the same structure C, proving
A≡B ⟹ A and B have isomorphic model-theoretic ultralimits.​
