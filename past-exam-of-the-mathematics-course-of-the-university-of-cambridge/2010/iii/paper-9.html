For a<b, give the pair {a,b} the color determined by v2​(b−a)mod2, where v2​ is the 2-adic valuation: use red for even valuation and blue for odd valuation. This finite coloring works because the pairs {a,a+d} and {a,a+2d} have valuations v2​(d) and v2​(d)+1. They therefore have opposite colors. In particular, no three-term arithmetic progression has all its pairs monochromatic.
For the second assertion, m=1 is immediate: every singleton is a blue complete arithmetic progression, since it has no pairs to check. Assume m≥2. If some m-term arithmetic progression has all its pairs blue, we are done. Otherwise, every such arithmetic progression contains a red pair. For each (a,d)∈N2, choose, say lexicographically, indices 0≤r<s<m for which {a+rd,a+sd} is red, and color (a,d) by this chosen pair (r,s). This is a finite coloring with at most (2m​) colors.
We need a lattice pattern that works whichever pair becomes the common color. Fix, before applying the Gallai theorem for an integer lattice, the finite set
F=⋃0≤r<s<m​{(si−rj,j−i):0≤i,j<m}⊆Z2.
(1)
Translate F into the positive quadrant and apply the Gallai theorem for an integer lattice to that translated pattern. Absorbing the translation into the base point gives integers a0​,d0​ and q>0 such that (a0​,d0​)+qF⊆N2 is monochromatic. Write (r,s) for its common color. Since (0,0)∈F, the base point itself has positive coordinates.
For each 0≤i,j<m, the parameter point
(a,d)=(a0​+q(si−rj), d0​+q(j−i))
(2)
belongs to that monochromatic copy and has chosen red pair (r,s). Its red endpoints simplify to
a+rd=a0​+rd0​+q(s−r)i,a+sd=a0​+sd0​+q(s−r)j.
(3)
Consequently, putting
A={a0​+rd0​+q(s−r)i:0≤i<m},B={a0​+sd0​+q(s−r)j:0≤j<m},
(4)
gives two m-term arithmetic progressions of positive common difference q(s−r), with every cross-pair red. These arithmetic progressions really are disjoint: the parameter point corresponding to i=m−1,j=0 has positive second coordinate, so d0​>q(m−1). Hence
minB−maxA=(s−r)(d0​−q(m−1))>0.
(5)
This proves the arithmetic-progression bipartite Ramsey dichotomy, including the required disjointness.

Here is the matrix form of Rado's theorem. A matrix A with entries in the rational numbers and columns a1​,…,an​ is a partition regular matrix if every finite coloring of the positive integers admits a vector x∈Nn whose coordinates are monochromatic and for which Ax=0. Its columns condition asks for an ordered partition into nonempty blocks B1​,…,Bs​, with
b1​:=∑i∈B1​​ai​=0,bj​:=∑i∈Bj​​ai​∈spanQ​{ai​:i∈B1​∪⋯∪Bj−1​}(j>1).
(6)
Rado's theorem states that these two conditions are equivalent. Coordinates need not be distinct; positivity is required for every coordinate.
First prove necessity using the finite separating-functional proof of the columns condition. Clearing denominators does not change either the kernel or the columns condition, so assume that A has integer entries. For each pair of disjoint index sets I,B⊆{1,…,n}, with B nonempty, for which bB​=∑i∈B​ai​ is outside the rational linear span of the I-columns, choose an integer linear functional ℓI,B​ such that
ℓI,B​(ai​)=0 (i∈I),ℓI,B​(bB​)=0.
(7)
Such a linear functional exists: extend a basis over the rational numbers of the indicated linear span by bB​, prescribe values zero on the former basis and one on bB​, extend to a basis of the ambient vector space over the rational numbers, and then clear the functional's denominators. There are only finitely many pairs (I,B). Choose a prime number p larger than the absolute values of all their nonzero evaluations; if there are none, choose any prime number.
Color x>0 by its last nonzero digit coloring value, namely
u(x):=x/pvp​(x)(modp)∈{1,…,p−1},
(8)
where vp​ is the P-adic valuation. By partition regularity, choose a positive solution Ax=0 all of whose coordinates have the same nonzero digit u. Group its indices into nonempty blocks B1​,…,Bs​ according to increasing distinct P-adic valuations ν1​<⋯<νs​.
Suppose that a block sum bj​ is outside the rational linear span of the earlier columns, and put I=B1​∪⋯∪Bj−1​, taking I=∅ for j=1. Apply the selected linear functional ℓI,Bj​​ to Ax=0. The earlier terms vanish exactly. Divide the remaining integer equality by pνj​ and reduce modulo p. Later blocks vanish modulo p, while each coordinate in Bj​ contributes its common digit u. We obtain
0≡uℓI,Bj​​(bj​)(modp),
(9)
which is impossible by the choice of p and because u≡0(modp). Thus each block sum lies in the earlier linear span. For the first block, this span is zero, so b1​=0. This proves the columns condition.
For sufficiency, assume the columns condition and choose rational coefficients λij​, for i∈B1​∪⋯∪Bj−1​, such that
bj​+∑i∈B1​∪⋯∪Bj−1​​λij​ai​=0(j>1).
(10)
Choose a positive integer c clearing all these coefficients' denominators and a positive integer p with p≥∣cλij​∣ for every coefficient. Use the permitted monochromatic m-p-c set theorem, in the suffix convention for an m-p-c set, to obtain positive generators z1​,…,zs​ such that the full set
D=⋃h=1s​{czh​+∑j>h​μj​zj​:μj​∈Z, ∣μj​∣≤p}
(11)
is positive and monochromatic. The positivity of the full m-p-c set is important: we do not discard expressions that happen to be negative. For i∈Bh​, set
xi​=czh​+∑j>h​cλij​zj​.
(12)
All these coordinates belong to D, so they are positive and monochromatic. On collecting coefficients of each zj​, their matrix product is
Ax=cz1​b1​+∑j=2s​czj​(bj​+∑i∈B1​∪⋯∪Bj−1​​λij​ai​)=0.
(13)
This explicit Rado solution inside an m-p-c set proves sufficiency and completes the proof of Rado's theorem.
To deduce the Finite sums theorem directly from the columns condition, introduce one positive variable yF​ for each nonempty F⊆{1,…,k} and impose
∑i∈F​y{i}​−yF​=0(∣F∣≥2).
(14)
For k=1 there are no equations and any positive integer works. For k≥2, write aF​ for the column belonging to yF​. Partition the columns into blocks Bj​={F:minF=j} in the order j=1,…,k. Consider the row indexed by a set H with ∣H∣≥2. The sum of the columns in Bj​ has row value
1{j∈H}​−1{minH=j}​.
(15)
For j=1 this is always zero. For j>1 it equals one exactly for those H with minH<j and j∈H. Each such aH​ is the negative coordinate vector in row H, and it belongs to an earlier block. Therefore
∑F∈Bj​​aF​=−∑∣H∣≥2, minH<jj∈H​​aH​(j>1),
(16)
which verifies the columns condition, rather than assuming the desired Finite sums theorem. Apply Rado's theorem to this system. Its monochromatic positive solution satisfies yF​=∑i∈F​xi​ with xi​=y{i}​, and hence
FS(x1​,…,xk​)={i∈F∑​xi​:∅=F⊆{1,…,k}} is monochromatic.​
(17)

Call A⊆N an IP set when it contains an infinite finite-sums set FS(x1​,x2​,…) with all xi​>0. We first need the relative consequence of the Hindman theorem: a finite union can be an IP set only if one of its constituents is an IP set. This does not follow by simply applying the theorem to a coloring of all integers, because its monochromatic finite-sums set might lie outside the given set.
Here is a reduction that proves the partition regularity of IP sets. Suppose FS(xi​)⊆A and A is finitely colored. Index the generators by i≥0. For n>0, let S(n) be the set of positions of the nonzero digits in its binary expansion, and color n by the color of ∑i∈S(n)​xi​. By the Hindman theorem, there are w1​,w2​,…>0 with FS(wi​) monochromatic in this new finite coloring.
We can take disjoint, successively later finite blocks of the wi​ whose sums v1​,v2​,… have separated binary expansion supports. Start with v1​=w1​. Having chosen finitely many blocks, take K larger than every binary position used in their sums. On a fresh tail of the wi​, consider 2K+1 partial sums, including the zero partial sum. Two have the same residue class modulo 2K, by the pigeonhole principle. Their positive difference is a consecutive block sum vj+1​ divisible by 2K. Discard all indices up to that block's end and repeat. Thus every bit of vj+1​ is above every bit in the preceding block sums.
There are no carries in a sum of distinct vj​, so
S(∑j∈J​vj​)=⨆j∈J​S(vj​)(∅=J finite).
(18)
Also FS(vj​)⊆FS(wi​), since the underlying blocks are disjoint. Consequently
yj​:=∑i∈S(vj​)​xi​
(19)
satisfies FS(yj​)⊆FS(xi​)⊆A, with all these sums the same original color. This proves the relative assertion. In particular, if A1​∪⋯∪Ar​ contains an infinite finite-sums set, color its points by the first constituent containing them and apply this argument; one Aj​ is an IP set.
Let I be the family of sets that are not IP sets. It is closed under subsets and, by the preceding argument, under finite unions. It contains every finite set, since positive successive partial sums of an infinite sequence are unbounded. It does not contain N. Therefore
F={A⊆N:Ac∈I}
(20)
is a proper filter on a set: it contains N, excludes the empty set, is upward closed, and is closed under finite intersections. Its members are exactly the IP-star sets, the sets meeting every IP set. Indeed, failure to meet an IP set is equivalent to having an IP complement. This identifies the sets that must belong to the required ultrafilter.
Apply the ultrafilter lemma to extend the IP-star filter F to an ultrafilter U. For completeness, Zorn lemma applies to its proper filter extensions ordered by inclusion, because the union of a chain is still a proper filter on a set. A maximal extension decides every set A: if A cannot be adjoined while keeping the filter proper, some filter member is disjoint from A, forcing Ac into the filter. This is the defining ultrafilter property.
If A∈U were not an IP set, then Ac∈F⊆U, contradicting properness. Hence every member of U contains an infinite finite-sums set. Conversely, any ultrafilter with finite-sums members must contain every IP-star set, since it cannot contain such a set's non-IP complement. Thus this construction captures precisely the forced filter, without making an unnecessary claim about idempotence.
To prove nonuniqueness, put
E=⋃j≥0​([22j,22j+1)∩N).
(21)
For a nonempty finite set of exponents with largest exponent J, the associated sum of distinct powers of four satisfies
4J≤∑j∈F​4j≤34J+1−1​<2⋅4J.
(22)
Thus FS(4j:j≥0)⊆E. Doubling the inequality gives
2⋅4J≤∑j∈F​2⋅4j<4⋅4J,
(23)
so FS(2⋅4j:j≥0)⊆Ec. These alternating dyadic intervals contain disjoint IP sets.
Every member of F meets E and also Ec, because it meets every IP set. A finite intersection of members of F is again a member, so both F∪{E} and F∪{Ec} have the finite intersection property. Extend the proper filters they generate to ultrafilters U0​ and U1​. Each extends F, so the previous argument makes each an ultrafilter with finite-sums members. But E∈U0​ and Ec∈U1​, so
U0​=U1​.​
(24)

Write X=[N]ω for the space of infinite subsets of the natural numbers, and [M]ω for all infinite subsets of an infinite M. A family Y⊆X is a Ramsey set of infinite subsets if for every infinite M there is an infinite L⊆M with either [L]ω⊆Y or [L]ω∩Y=∅.
A non-Ramsey set of infinite subsets is obtained by finite-symmetric-difference parity colouring. Declare A∼B when their symmetric difference is finite, and use the axiom of choice to select a representative R for each equivalence class. Put
ε(A)=∣A△R∣(mod2),Y={A∈X:ε(A)=0}.
(25)
For every infinite L, both L and L∖{minL} belong to [L]ω and have the same representative. Toggling one element changes the parity of the finite symmetric difference, so these two sets have opposite colors. Thus no [L]ω is homogeneous, and Y is not a Ramsey set of infinite subsets. Only finite differences are counted; no parity is being assigned to an infinite cardinal.
We use the Ellentuck topology for the star notation. Its basic neighborhoods are
[s,A]={s∪B:B∈[A]ω},
(26)
where s is a finite stem (the initial segment of each member of the neighborhood) and every element of the infinite reservoir A exceeds maxs; the empty stem is allowed. A star-nowhere dense set N has star-closure with empty star-interior; a star-meagre set is a countable union of star-nowhere dense sets.
We need the following stem-preserving open-set conclusion: a star-open set G has, in every [s,A], an infinite B⊆A such that [s,B]⊆G or [s,B]∩G=∅. Here is the fusion proof for open Ellentuck sets, so that the precise form being used is explicit. A reservoir T accepts a finite extension t of s when [t,T]⊆G, and rejects it when no infinite subreservoir accepts it. Every reservoir can be thinned to decide a prescribed stem: take an accepting subreservoir if one exists, and otherwise it already rejects. Acceptance and rejection are hereditary under further infinite thinning.
First thin A to decide s. If it accepts, we have finished. Otherwise, choose successive points b0​<b1​<⋯, thinning the unused tail after each selection to decide every stem s∪t with t a subset of the finitely many points already selected. Each stage requires only finitely many decisions. The final set B therefore decides every such finite extension, using the tail above its largest point. It rejects s.
For any rejected stem s∪t, only finitely many possible next points b of B have accepting tails for s∪t∪{b}. Otherwise collect infinitely many such points into C. Every member of [s∪t,C] starts with some such b, and its remaining points lie in the accepting tail above b. Hence [s∪t,C]⊆G, contradicting rejection. A second selection now gives C⊆B all of whose finite extensions of s are rejected: at each stage avoid the finitely many forbidden next points for each subset of the chosen prefix. Previous rejections persist on thinning. If Z∈[s,C]∩G, star-openness gives an initial stem s∪t of Z and an infinite tail of Z whose entire neighborhood lies in G. This is an accepting subreservoir for a stem we made rejected, a contradiction. Thus [s,C]∩G=∅, proving the needed open-set conclusion.
Apply this conclusion to G=X∖N∗ when N is star-nowhere dense. This G is star-open and star-dense. The alternative [s,B]∩G=∅ would give a nonempty star-open set inside N∗, contradicting empty interior. Consequently every star-nowhere dense set can be avoided without extending the finite stem.
Now let N=⋃j≥0​Nj​, each Nj​ star-nowhere dense, and fix [s,A]. Construct b0​<b1​<⋯ with nested infinite unused reservoirs. At stage j, let Pj​={b0​,…,bj−1​}. For every t⊆Pj​, in turn, thin the current reservoir using the preceding avoidance property until
[s∪t,Cj​]∩Nj​=∅(t⊆Pj​).
(27)
There are only finitely many such t, and subsequent thinning preserves all previous avoidances. Choose bj​=minCj​ and retain the part of Cj​ above bj​ for the next stage. Put B={bj​:j≥0}. For any Z∈[s,B] and any j, the finite part t=(Z∖s)∩Pj​ is one of the stems tested at stage j, and the rest of Z∖(s∪t) lies in Cj​. Hence Z∈[s∪t,Cj​] and Z∈/Nj​. This proves [s,B]∩N=∅.
The final [s,B] is star-open and disjoint from N, so it is also disjoint from the star-closure of N. Every basic neighborhood therefore has a nonempty open refinement missing that closure. This Ellentuck meagre-set fusion lemma proves
star-meagre ⟹ star-nowhere dense.​
(28)
Indeed, we obtained the stronger completely Ramsey-null property. Testing all subsets of the selected prefix was essential; testing just the entire prefix would not cover every infinite subset of B.

Take τ to be the ordinary topology on infinite subsets, whose basic cylinders [s] fix a finite initial segment. Let
D={Z∈[N]ω:N∖Z is finite}.
(29)
This is a dense countable family of cofinite infinite subsets. It is countable because finite complements form a countable family. Each singleton is τ-closed: distinct increasing enumerations differ at some finite coordinate, which separates them by cylinders. No singleton has interior, since every cylinder admits more than one infinite continuation. Thus every singleton is τ-nowhere dense, and D is τ-meagre.
On the other hand, every cylinder [s] contains the cofinite set s∪{n:n>maxs}, with max∅=0. Hence D is τ-dense, its closure is all of X, and
D is τ-meagre but not τ-nowhere dense.​
(30)
The paper does not define its symbol τ. If the course instead uses it for the Ramsey cone topology, with basic neighborhoods [A]ω and no finite stem, use X itself as the example. For Dj​={Z:minZ=j}, its cone-closure is {Z:j∈Z}: every cone neighborhood of a set containing j contains an infinite subset of minimum j, while a cone based on a set omitting j misses Dj​. This closure has empty interior, because every infinite reservoir can be thinned to omit j. Thus every Dj​ is cone-nowhere dense, and X=⋃j≥1​Dj​ is cone-meagre but is not cone-nowhere dense. This supplies the requested example under either convention, without conflating the two topologies.

For n≥1, let Cn​={Z∈X:n∈/Z}. The presence or absence of n is determined by a sufficiently long finite initial segment, so Cn​ and its complement are open sets in the ordinary topology on infinite subsets. The Ellentuck topology is finer, hence each Cn​ is star-clopen and in particular star-closed. Their union is
⋃n≥1​Cn​=X∖{N}.
(31)
Every basic star-neighborhood [s,A] of N has s={1,…,k} for some k≥0, and its reservoir A contains every integer greater than k. Choosing n>k gives N∖{n}∈[s,A]∩Cn​. Thus N is in the star-closure of the union, but not in the union itself. Therefore
n≥1⋃​Cn​ is not star-closed, although every Cn​ is star-closed.​
(32)
