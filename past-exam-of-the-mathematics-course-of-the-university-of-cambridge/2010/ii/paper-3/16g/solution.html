The cumulative hierarchy is defined by transfinite recursion:
V0​=∅,Vα+1​=P(Vα​),Vλ​=⋃β<λ​Vβ​(λ a limit ordinal).
(46)
The rank of a set is rk(x)=supy∈x​(rk(y)+1), equivalently the least α such that x⊆Vα​. The standard hierarchy properties give rk(Vα​)=α, so every ordinal occurs as a set rank; the ordinal α itself is another example of rank α.
Let x be transitive of rank α, and fix β<α. The supremum formula gives an element of x whose rank is at least β. Choose such an element y of least possible rank. If rk(y)>β, the same supremum formula gives z∈y with rank at least β. Transitivity gives z∈x, and membership strictly decreases rank, contradicting the choice of y. Thus x contains an element of every rank below α.
A nonempty finite set has rank the maximum of finitely many successor ordinals, hence a successor ordinal; the empty set has rank zero. Conversely, for any β, the singleton {Vβ​} has rank β+1. Thus
finite-set ranks are exactly 0 and all successor ordinals.​
(47)
A finite transitive set of rank α contains, by the proved property, distinct elements of every rank β<α. Finiteness therefore forces α<ω. Every finite ordinal is itself a finite transitive set of that rank. Consequently
finite-transitive-set ranks are exactly the finite ordinals.​
(48)
