The empirical distribution function is Fn​(x)=n−1∑i​1Xi​≤x​. For continuous F, the probability integral transform gives independent uniform variables Ui​=F(Xi​). Strict increase of F is unnecessary. More explicitly, generate the observations by Xi​=F−1(Ui​) with the generalized quantile inverse. Then 1Xi​≤x​=1Ui​≤F(x)​, so Fn​(x)=Gn​(F(x)), where Gn​ is the uniform empirical distribution.
Continuity and the limits of F ensure that its range contains (0,1). The endpoint discrepancies for Gn​ are zero. Hence
Dn​=d0≤u≤1sup​∣Gn​(u)−u∣,​

which depends only on n. Equivalently it is max1≤i≤n​{i/n−U(i)​,U(i)​−(i−1)/n}, a function of uniform order statistics. This proves the distribution-free property of the Kolmogorov-Smirnov statistic even when F has flat portions.
Choose cn,α​ from this common distribution so that P(Dn​≤cn,α​)=1−α. The Kolmogorov-Smirnov confidence band is
max(0,Fn​(x)−cn,α​)≤F(x)≤min(1,Fn​(x)+cn,α​)for all x.​
(8)
The event that all these inequalities hold is exactly the event used to choose the critical value, giving simultaneous coverage 1−α. The Glivenko-Cantelli theorem states that for an independent identically distributed sample from any distribution function, continuous or not, supx​∣Fn​(x)−F(x)∣→0 almost surely.
For an integrable r-argument U-statistic kernel, replace it by hs​(x1​,…,xr​)=(r!)−1∑π​h(xπ(1)​,…,xπ(r)​). Every permutation has the same expectation by exchangeability, so this symmetrization of a U-statistic kernel preserves the target functional. For a symmetric U-statistic kernel h and n≥r, the U-statistic is
Un​=(rn​)−1∑i1​<⋯<ir​​h(Xi1​​,…,Xir​​).
