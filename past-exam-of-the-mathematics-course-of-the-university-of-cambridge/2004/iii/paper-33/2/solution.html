Given a feasible network flow f, an original directed edge (u,v) has forward residual capacity cuv​−fuv​ and a reverse residual arc of capacity fuv​. A source–sink graph path in this residual network permits an augmentation by the minimum residual capacity along it: increase forward flows and decrease the corresponding reversed flows. Capacities and flow conservation are preserved, and the flow value increases by that amount.
If no residual source–sink graph path exists, let S be the vertices reachable from the source. The sink is outside S. Every original arc from S to its complement is saturated, and every original arc back into S has zero flow, since a positive reverse residual arc would make its tail reachable. Conservation therefore gives
∣f∣=∑u∈S, v∈/S​fuv​−∑u∈/S, v∈S​fuv​=∑u∈S, v∈/S​cuv​.
(11)
The flow equals this cut capacity, so the max-flow min-cut theorem proves it is maximum.
Termination needs a capacity or path-selection assumption. For integer capacities, starting from zero, every residual capacity and augmentation is integral; each augmentation increases the value by at least one, and the value is bounded by the total source-outgoing capacity. The algorithm therefore terminates. Rational capacities can be scaled to integers. With arbitrary real capacities, unrestricted graph path choices do not guarantee finite termination. A valid uniformly terminating implementation is the Edmonds–Karp algorithm, choosing a shortest residual graph path each time.
Here is why that choice works independently of numerical capacity sizes. Residual distances from the source cannot decrease after augmenting along a shortest graph path. Every newly created residual arc is the reverse of a graph path arc; if it could cause the first distance decrease, its previous distance relation would contradict that decrease. When an arc (u,v) is saturated on a shortest graph path, d(v)=d(u)+1. Before the same direction can be saturated again, it must have been restored by a reverse augmentation on a shortest graph path, at which time d′(u)=d′(v)+1≥d(v)+1=d(u)+2. Each arc is consequently critical only O(∣N∣) times. There are O(∣A∣) arcs and each augmentation saturates at least one, giving O(∣N∣∣A∣) augmentations, each found by Breadth-first search in O(∣A∣) time. Thus the shortest-path Ford–Fulkerson implementation terminates and finds a maximum flow in O(∣N∣∣A∣2) arithmetic operations.
For sports elimination by maximum flow, first give the target team all its remaining wins. This cannot hurt its chance to finish strictly ahead: changing a result to favour it also removes a rival's win. Let w∗ be its resulting win count. If any rival already has at least w∗ wins, strict victory is impossible. Otherwise give each unordered pair of rivals i<j<n one game node. Its incoming capacity is gij​, and its two outgoing arcs go to the participating team nodes. Their capacities may be replaced by the finite number
G=∑i<j<n​gij​,
(12)
since no arc can need more than the total number of remaining rival games. Team i has sink capacity w∗−wi​−1.
An integral flow of value G saturates all game-node incoming arcs. Its two outgoing amounts allocate exactly gij​ wins to the two teams; the team-sink caps keep each rival strictly below w∗. Conversely any successful completion of the league specifies such a flow. Integral capacities and augmentation give an integral maximum flow, so
the target can win strictly ⟺ the maximum flow has value G,​
(13)
after the initial negative-capacity rejection. Each actual game is counted once: making independent nodes for both ordered pairs would double-count it.
The network has O(n2) nodes and arcs. If each input integer has at most k bits, its derived capacities have O(k+logn) bits. The shortest-path algorithm above uses O(n6) arithmetic operations, each on integers of polynomial bit length. Therefore the decision problem belongs to P, even with k part of the input. If k is fixed, even the basic integral-augmentation bound O(G∣A∣)=O(n42k) is polynomial in n. If k varies, that particular bound is only pseudopolynomial; it is the shortest-path implementation that establishes polynomial bit complexity.
