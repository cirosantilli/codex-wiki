For the linear program in maximization form, a nonnegative multiplier y of the resource inequalities gives
cTx≤yTAx≤yTb
(1)
whenever ATy≥c. Equivalently, the Lagrangian is bTy+(c−ATy)Tx; its supremum over x≥0 is finite exactly when ATy≥c. Minimizing this bound gives the dual linear program
minbTy,ATy≥c,y≥0.​
(2)
The displayed inequality proves weak duality directly.
For the final simplex tableau, the basic-variable order is (x2​,x1​). With z1​,z2​ interpreted as the ordinary unpriced slack variables, its constraint equations give
x2​=1−10z1​+z2​​,x1​=2−20z1​+3z2​​.
(3)
The bottom row is read in the reduced-cost convention rj​=cj​−cBT​B−1Aj​, with right side minus the basic objective value. It says the reduced costs of z1​,z2​ are 0,−1/2. Thus optimality requires z2​=0, while z1​ can increase without changing the objective until x2​ reaches zero. The complete primal optimum set is
x1​=2−20θ​,x2​=1−10θ​,0≤θ≤10.​
(4)
Reconstructing a linear program from a final simplex tableau exposes a source inconsistency. The slack columns are
B−1=(1/101/20​1/103/20​),B=(15−5​−1010​).
(5)
Because the first basic column is that of x2​, the original constraint data are
A=(−1010​15−5​),b=B(21​)=(15−5​).
(6)
The slack reduced costs give yT=(0,1/2) and
(c2​,c1​)=yTB=(−5/2,5).
(7)
Consequently the recovered homogeneous linear program is
max(5x1​−25​x2​),−10x1​+15x2​≤−5,10x1​−5x2​≤15,x1​,x2​≥0.​
(8)
Every point in the optimum segment has value 15/2. Since the segment contains a point with both variables positive, complementary slackness forces both dual column inequalities to be equalities. They give the unique dual optimum
y1​=0,y2​=21​,bTy=215​.​
(9)
The printed bottom-right entry is −3, but it must be −15/2 for this linear objective and these constraint rows. Thus no original problem in the stated homogeneous standard form has exactly the entire printed tableau. Changing that one entry to −15/2 gives the reconstructed problem above. Alternatively, if an affine objective is permitted, 5x1​−25​x2​−29​ has the displayed optimum value 3 and unchanged reduced costs; the corresponding affine dual objective is bTy−29​. Both interpretations have exactly the same primal and dual optimizer sets. The discrepancy is in the objective constant, not in the optimal segment.
