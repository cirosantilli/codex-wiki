Independence here is a relative consistency assertion: from a ground first-order model satisfying ZFC, construct a first-order model of each remaining theory in which the omitted axiom fails. The ground axiom of choice is a tool for constructing these countermodels, not an extra axiom imposed on the theories being tested. The constructible universe supplies the usual relative-consistency implication from ZF to ZFC, so this ground choice assumption requires no additional consistency strength. These constructions can be formalized inside an arbitrary ground model; they do not require the stronger assumption that a transitive model exists.
Union. Put λ=ℶω​ and use the hereditarily locally small membership model
Bλ​={x:(∀y∈TC({x})) ∣y∣<λ}.
(1)
The ground cardinal λ is a strong limit cardinal of countable cofinality. This transitive class contains the empty set and ω. Pairing preserves the bound, as does taking a subset, so separation holds for every formula relativized to this class. If an internally definable function has domain a∈Bλ​, ground replacement collects its range r. Since ∣r∣≤∣a∣<λ and every descendant of an element of r already has fewer than λ members, r∈Bλ​. Thus the full functional Axiom schema of replacement holds. For x∈Bλ​, every actual subset of x belongs to the class and
∣P(x)∣=2∣x∣<λ.
(2)
Consequently its entire power set belongs to the class. Extensionality and foundation are inherited from the ground membership relation; ω witnesses infinity. However a={ℶn​:n<ω} belongs to Bλ​, while its only possible union is λ, which does not. All the other ZF axioms hold, and union fails. Bounding the entire transitive closure by <λ instead would give the wrong model: functional ranges at this singular bound need not be hereditarily small.
Power set. Use the transitive class Hω1​​ of hereditarily countable sets. Pairing, union and separation preserve hereditary countability. A functional image of a countable domain is countable, and its members have countable transitive closures; their countable union is countable in the ground ZFC model. This proves replacement. The remaining structural axioms and infinity are inherited. Every actual subset of ω belongs to Hω1​​, but a putative internal power set of ω would contain all these subsets and hence be uncountable by Cantor's theorem. Power set fails in Hω1​​, with every other ZF axiom intact.
Replacement. Use Vω+ω​ in the cumulative hierarchy. At a limit ordinal cutoff, pairing, union, power set and every instance of separation remain below the cutoff; foundation, extensionality and infinity hold as well. With parameter Vω​, define f(n)=Vω+n​ by n finite iterations of power set. The finite iteration witnesses and each value are inside Vω+ω​, so this is an internally definable total function on ω. Its range has rank of a set ω+ω and is absent from the model. This instance of replacement fails.
Extensionality. Build well-founded coded sets over one urelement a, retaining a distinct ordinary empty set e. Membership of an atom is always false, and membership of a set code is its coded extension. Thus a=e but they have identical empty extensions. Pairing, union, separation and replacement are performed on set codes; pure ω witnesses infinity, and the well-founded construction gives foundation. There is a small point concerning the unmodified, untyped Axiom of power set: the atom is vacuously a subset of every object. Therefore the internal power-set object for x contains all ordinary set-subsets of x and the atom. It has exactly the required extension. All remaining ZF axioms hold, but extensionality fails. In the usual typed atom theory, the power-set axiom instead quantifies only over set-subsets.
Foundation. In the ground universe let π exchange ∅ and {∅} and fix all other objects. On the same domain define the Rieger-Bernays permutation model
xEy⟺x∈π(y).
(3)
Since π is a bijection, two objects with the same E-members are equal, so extensionality holds. Any ground collection B of desired members is represented by the object π−1(B). In particular, an E-pair is π−1({a,b}) and the E-union of a is
π−1(⋃b∈π(a)​π(b)).
(4)
An E-subset of a is an object z with π(z)⊆π(a), so its E-power-set object is
π−1({π−1(u):u⊆π(a)}).
(5)
Translate every formula by replacing membership with E; ground separation and replacement collect the required extensions and the same representation supplies their internal witnesses. The E-empty object is e=π−1(∅), and its E-successor operation is s(x)=π−1(π(x)∪{x}). Ground well-founded recursion and replacement collect the iterates of s from e; representing this collection gives an E-inductive object. Thus infinity holds. But for q=∅, π(q)={q}, whence qEq and q has precisely itself as its E-member. Foundation fails.
Infinity. The hereditarily finite sets Vω​ satisfy extensionality, foundation, pairing, union, power set and separation. Each internal domain is externally finite, so every internally definable functional image is finite and belongs to Vω​, proving replacement. No finite object can contain the empty set and all its successive Finite von Neumann ordinals. Infinity fails, and all other ZF axioms hold.
Choice with atoms. For the negative model use the Basic Fraenkel permutation model. Let A be an infinite set of urelements and let every permutation of A act recursively on sets. Keep precisely the hereditarily finitely supported objects: an object has a finite support F⊆A if every permutation fixing F pointwise fixes the object, and every object occurring in its membership ancestry must also have such a support. The class of these objects contains the pure universe and A itself.
Supports for a pair are united; union preserves a support; a formula defining a subset uses the finite union of the supports of its domain and parameters. An internally definable functional range has the same support, since its values are uniquely specified, and its elements are already hereditarily supported. This proves the full separation and replacement schemas. All hereditarily supported set-subsets of a fixed set form its symmetric internal power set; this collection is invariant under the pointwise stabilizer of a support of the original set. For the untyped version add all the atoms, as above. Pure ω, ground well-foundedness and set-extensionality give the remaining axioms.
The family [A]2 of unordered pairs of atoms is hereditarily supported. If it had a choice function f, let F be a finite support of f. Choose distinct a,b∈A∖F. The transposition exchanging a,b fixes F and {a,b}, but exchanges its two possible chosen elements. Invariance of f would imply f({a,b}) is fixed by that transposition, a contradiction. Conversely, the full well-founded universe over the atoms, before restricting to finite supports, satisfies choice when the ground universe does. Both choice and its negation are relatively consistent with the stated weakening of extensionality.

The partition relation λ→(μ)νr​ says that every colouring of the r-element subsets of a set of cardinality λ into ν colours has a homogeneous set of cardinality μ. Define the beth numbers over an infinite cardinal κ by ℶ0​(κ)=κ and ℶn+1​(κ)=2ℶn​(κ). The Erdős-Rado theorem for finite arities gives the precise bound
ℶn​(κ)+⟶(κ+)κn+1​(n<ω).​
(6)
Thus any fixed finite arity and any fixed infinite number of colours admit arbitrarily large infinite monochromatic sets once the starting cardinal is sufficiently large. For pairs, the especially useful case is (2κ)+→(κ+)κ2​. The successor in this bound matters: a binary first-difference colouring on a suitably ordered set of binary sequences supplies the familiar obstruction at 2κ. Also, a theorem for every fixed finite arity is not a theorem homogenizing all arities simultaneously.
The mechanism is to build an end-homogeneous routing tree: each new vertex is routed according to its colours to earlier vertices on its branch. A long branch is end-homogeneous, meaning the colour from a fixed earlier vertex is independent of the later vertex. There are at most κα≤2κ routes of length α<κ+, and the whole collection of short routes has size at most 2κ. Inserting (2κ)+ vertices therefore forces a branch of length κ+. One colour occurs at κ+ earlier vertices on that branch, giving the pair theorem. Iterating the higher-arity version of this routing construction explains the successive powers in the Erdős-Rado theorem for finite arities.
A weakly compact cardinal is an uncountable strongly inaccessible cardinal κ with
κ⟶(κ)22​.
(7)
Equivalent formulations include the tree property at the inaccessible cardinal and compactness for theories of size at most κ in the infinitary language Lκ,κ​: if every subtheory of size <κ has a first-order model, so does the theory.
A measurable cardinal is an uncountable κ carrying a nonprincipal ultrafilter closed under intersections of fewer than κ members. Such an ultrafilter contains no set of size <κ, since all singletons have complements in it and it is kappa-complete. Consequently a cofinal sequence of length <κ would partition κ into too few small pieces, so κ is regular cardinal. If λ<κ and κ distinct subsets of λ existed, choose, for each coordinate of λ, the bit selected by the ultrafilter. Kappa-completeness would make all those bits simultaneously constant on a large set of indices; only one distinct subset could have that bit pattern, a contradiction. Hence 2λ<κ: κ is also a strong limit cardinal.
A supercompact cardinal κ has, for every λ≥κ, a fine ultrafilter that is a normal ultrafilter on small subsets and is kappa-complete on
Pκ​(λ)={x⊆λ:∣x∣<κ}.
(8)
Fine means {x:α∈x} is large for every α<λ. Normal means that a function f with f(x)∈x on a large set is constant on some large set. Equivalently, for every such λ there is an elementary embedding j:V→M with critical point κ, j(κ)>λ, and M closed under λ-sequences from the universe.
These notions form the implication chain supercompact ⇒ measurable ⇒ weakly compact. For the first implication, an embedding as above gives the measure U={X⊆κ:κ∈j(X)}. For the second, use a normal ultrafilter on a cardinal obtained by normalizing its measure. Indeed the ultrapower embedding gives the measure U={X⊆κ:κ∈j(X)}; for a regressive f, j(f)(κ)<κ is a fixed ordinal, yielding the required constant large fibre. Given a pair-colouring, select for each α the measure-one colour on the tail above α. One selected colour occurs on a measure-one set of α's. Normality makes the diagonal intersection of their selected tails measure one; any two members of that intersection have the selected colour. This gives the required partition relation, and the preceding regularity and strong-limit argument gives inaccessibility.

Forcing constructs new first-order models while controlling which ground-model properties survive. Fix a ground model M and a partially ordered set P∈M, writing q≤p when q is the stronger condition. A generic filter is upward closed, directed towards stronger conditions, and meets every ground-model dense subset of a forcing order. If M is externally a countable transitive model, enumerate its dense subsets and successively choose stronger conditions in them. The resulting filter is M-generic. External countability is crucial: this is not a claim that the ground model regards its own universe as countable.
A forcing name is built recursively from pairs (σ,p) of earlier names and conditions. For a generic filter G, its evaluation of a forcing name is
τG​={σG​:(σ,p)∈τ, p∈G},M[G]={τG​:τ∈M}.
(9)
The canonical forcing name xˇ={(yˇ​,1):y∈x} evaluates to x, so M⊆M[G]. Recursive evaluation also proves transitivity. Name ranks bound the ranks of their evaluations, so an ordinal in the extension is below some ground ordinal and is already a ground ordinal. Thus forcing preserves ordinals.
The central link between syntax and generic interpretation is the forcing theorem. The relation p⊩φ(τ1​,…,τn​) is definable in the ground model, and the forcing truth lemma says
M[G]⊨φ((τ1​)G​,…,(τn​)G​)⟺(∃p∈G) p⊩φ(τ1​,…,τn​).
(10)
For an atomic membership assertion, densely many refinements must witness equality with a member-name whose associated condition is compatible with the refinement. Equality is obtained by recursive mutual inclusion of names. For negation, p⊩¬φ means no stronger condition forces φ; for an existential quantification, witnesses must be obtainable densely below p. Induction on name rank establishes the atomic clauses, and induction on formulas establishes definability and the truth lemma. The generic filter meets the relevant dense sets at the existential step. An arbitrary semantic assertion about one chosen generic filter is insufficient: the definable relation must work uniformly for all generic interpretations.
This explains preservation of ZFC. Extensionality and foundation follow from transitivity; canonical names supply infinity. Pair and union names give pairing and union. For separation, restrict a name's members to conditions forcing the defining formula. For replacement, the definable forcing relation lets ground axiom schema of collection bound a set of names for all possible witnesses to the unique outputs; evaluating their collected name gives the range. For power set, let τ name the given set and let D be the set of its member-names. Every subset of τG​ has an equivalent name drawn from P(D×P), by the truth lemma, so a ground set of candidate names collects all its subsets. Finally choose a ground well-order of the relevant names; its evaluated image surjects onto the desired set, and choosing the first name for each value well-orders that set. This is why ordinary forcing over a choice model preserves choice.
For a concrete example, Cohen forcing consists of finite partial functions ω→2, ordered by extension. The generic union c=⋃G is total because deciding each coordinate is dense. For every ground real x, the set of conditions disagreeing with x somewhere is dense, so c=x. This construction changes the universe by adding a genuinely new real without changing its ordinals.
The size and compatibility of conditions determine what else changes. With the countable chain condition for forcing, an ordinal-valued name has only countably many possible values at each coordinate: take a maximal antichain deciding that value. Therefore the possible range of a name for a map with infinite ground domain of cardinality μ lies in a ground set of size at most μ⋅ℵ0​=μ. This prevents cardinal collapse and changes of uncountable regular cofinalities. Forcing by finite partial functions λ×ω→2 is ccc: the delta-system lemma thins any uncountable family of finite domains to a delta-system, and a further thinning makes their values agree on its finite root. Two remaining conditions are compatible. Distinct coordinates add distinct reals.
For example, start with GCH and take λ=ℵ2​. This forcing has size λ and adds λ distinct reals. A nice name for a real uses countably many antichains, and each antichain is countable. The ground arithmetic λℵ0​=λ bounds the number of such names by λ. Hence
M[G]⊨2ℵ0​=ℵ2​,​
(11)
giving a relative-consistency example of the failure of CH. The ground choice of GCH is available through the constructible universe; no claim that every starting model has this arithmetic is needed.
By contrast, countably closed forcing adds no new countable sequences of ground ordinals. Given a name, recursively strengthen a condition to decide each coordinate, then take a lower bound of the descending sequence. That condition decides the entire sequence. Closure and chain conditions thus control different features; neither should be silently substituted for the other.
Further applications include changing cofinalities, adding branches through trees, and constructing prescribed continuum patterns. If the aim is to violate choice, an ordinary generic extension of a choice model will not do: one restricts to a suitable symmetric collection of names, checking the axioms again. These examples also mark a limitation: forcing proves relative consistency, not absolute consistency of the background theory. The countable-transitive-model picture gives a concrete semantic construction; the definable forcing relation and Boolean-valued formulation supply the corresponding formal consistency arguments without asserting that a transitive ground model can be proved to exist.

Use the rooted-tree homeomorphic embedding relation: an injective map of vertices preserves lowest common ancestors, so edges may become paths and the source root may map below the target root. We prove the stronger labelled statement for labels in any well-quasi-ordering Q, with labels increasing under the embedding. Forgetting labels gives Kruskal's tree theorem.
First every infinite sequence in a well-quasi-ordering has an infinite nondecreasing subsequence. Colour its index pairs according as the earlier term is or is not below the later term. Ramsey's theorem gives an infinite constant-colour subsequence; the bad colour would contradict well-quasi-ordering. Applying this successively in each coordinate proves finite product closure of well-quasi-orderings.
We need Higman lemma with its proof. Order finite words over Q by subsequence embedding with increased letters. If there were a bad sequence, choose one w0​,w1​,… minimally: at each position choose a shortest word admitting a bad continuation of the fixed prefix. No word is empty. Write wn​=un​an​, separating the last letter, and choose n0​<n1​<⋯ with an0​​≤an1​​≤⋯. Consider
w0​,…,wn0​−1​,un0​​,un1​​,….
(12)
An earlier prefix word cannot embed in a later unj​​, since it would then embed in wnj​​. Nor can uni​​ embed in unj​​: adding the comparable last letters would embed wni​​ in wnj​​. Thus the displayed sequence is bad, contradicting minimality at n0​, since un0​​ is shorter. Finite words over a well-quasi-order are well-quasi-ordered.
Now suppose labelled rooted trees admit a bad sequence T0​,T1​,…, chosen minimally in vertex count at each position. Let A consist of all proper rooted subtrees of these trees, rooted at a descendant and containing all its descendants. We claim A is well-quasi-ordered. Otherwise take a bad sequence S0​,S1​,… from A. Only finitely many subtrees come from any fixed finite prefix of the Tn​'s, and a bad sequence cannot repeat an object. Thin it so that Si​ comes from Tmi​​ with m0​<m1​<⋯. The sequence
T0​,…,Tm0​−1​,S0​,S1​,…
(13)
is bad: Tj​⪯Si​ would imply Tj​⪯Tmi​​, since a rooted subtree embeds in its host; comparisons within the Si​'s are excluded by their choice. But S0​ is strictly smaller than Tm0​​, contradicting minimality. This proves the claim.
Choose an arbitrary ordering of the children of each Tn​. Record its root label and the finite word of rooted child-subtrees:
(ℓn​, (Tn,1​,…,Tn,rn​​))∈Q×A∗.
(14)
By Higman lemma and finite product closure, two records, with indices i<j, are comparable. Map the root of Ti​ to the root of Tj​, and map its selected child-subtrees into the distinct selected branches of Tj​. Within a branch the embeddings preserve lowest common ancestors; between different branches both lowest common ancestors are the roots. Labels increase everywhere. This gives Ti​⪯Q​Tj​, contradicting badness. Finite labelled rooted trees are well-quasi-ordered by label-monotone homeomorphic embedding. In particular, this proves the unlabelled theorem. A root-preserving variant follows by giving the root a special incomparable label unavailable at nonroot vertices; the general labelled theorem then forces root to root. Adjacency-preserving embeddings are a different, more restrictive relation and do not satisfy the same assertion.
For Friedman's finite form of Kruskal's theorem, fix k∈N and consider finite bad sequences satisfying ∣Ti​∣≤k+i, with indices starting at 1. Their prefixes form a finite bad-sequence tree. At each depth there are only finitely many possible unlabelled tree isomorphism types below the size bound, so this tree is finitely branching. If bad sequences existed at every finite length, König infinity lemma would yield an infinite branch, hence an infinite bad sequence of rooted trees, contrary to what was just proved. Therefore
∀k ∃N ∀(T1​,…,TN​) [(∀i≤N) ∣Ti​∣≤k+i ⟹ (∃i<j≤N) Ti​⪯Tj​].​
(15)
The same proof works with any fixed finite label set. The finite size bounds are what make the bad-prefix tree finitely branching; the proof does not claim a small effective numerical bound.

Work in ZFC. The move alphabet need not be countable; choice permits the selections of moves, strategies and witnesses used below. Assume A=∅; with the usual convention that a player unable to move loses, the empty alphabet is a trivial terminal game. We prove Borel determinacy theorem by strengthening the assertion to the existence of game coverings that unravel payoffs. Simply asserting that determined payoffs are closed under countable unions would not be a proof.
It is useful to allow a tree of legal finite plays with terminal nodes explicitly labelled as losses for either player. For an infinite branch, I wins exactly when it belongs to the payoff C. Projection of a game tree is length-preserving and respects prefixes. At a projected original terminal node the outcome is inherited, but the new tree may also have artificial terminal losses.
A covering of an infinite game has such a projection π:S→T and maps Φ taking a strategy on S to a strategy of the same player on T. Its crucial lifting condition is this: each maximal play x on T following Φ(σ) has a σ-compatible lift y on S, either projecting exactly to x with its inherited terminal outcome, or projecting to a prefix of x and ending in a loss for the player using σ. Its strategy maps must be local in depth: choices up to a given depth use only the upstairs strategy up to that depth. A k-covering preserves the initial k levels and choices. If π−1(C) is clopen, call it an unravelling of a game payoff. A winning upstairs strategy cannot have a compatible premature losing lift; hence any such covering transfers winning strategies downstairs, for the payoff pulled back by π.
First, clopen determinacy with terminal losses holds on any set-sized tree. At a node where all infinite extensions have one fixed winner, the other player can win only by forcing a terminal loss for that winner. Decide that reachability game by the winning-position attractor in an infinite game: begin with the desired losing terminals, add the attacking player's positions with a successor already in the attractor and the defending player's positions with every successor in it, and take unions at limit stages. Entry ranks give a strategy reaching the target; outside the attractor the defender avoids it. If there are no infinite extensions the same reachability analysis still applies. At every remaining position there are infinite extensions in both C and its complement. This remaining tree is well-founded, since an infinite branch through it would contradict clopenness at that branch. Well-founded recursion now assigns a winner upwards from the already decided nodes, choosing a winning successor when the player to move has one. These choices give an actual winning strategy.
Next we construct an announcement-and-challenge covering of a closed payoff. Let C⊆[T] be closed, and choose an even depth l>k. Play initially follows T unchanged. At a nonterminal position p of length l, replace I's next move a by (a,X), where X is any subset of the following set Zp,a​ of exit positions: r strictly extends pa, is nonterminal, and is a shortest such extension along its branch satisfying [Tr​]∩C=∅. If [Tpa​]∩C=∅ already, the first nonterminal extension beyond pa counts as an exit. Distinct exits form a prefix antichain. An original terminal move always keeps its original outcome.
Player II now either accepts and makes an ordinary next move b, or challenges an r∈X and makes the move b prescribed by that r. On acceptance, continue the original play until the first exit r: it is an artificial win for I if r∈X, and an artificial loss for I otherwise. On a challenge, both players are forced to follow r until it is reached, after which the original game resumes without the acceptance stopping rule. The projection forgets the announcements and challenge flags.
An infinite accepted play avoids all exits. Every sufficiently long prefix of its projection therefore has a continuation in C, so closedness implies that the projection is in C. Every infinite challenged play passes through an exit cylinder disjoint from C. Thus among infinite plays the pulled-back payoff is decided by II's acceptance or challenge: it is clopen. This remains true when a particular branch reaches an inherited terminal position before either case produces an infinite play.
Here is the strategy-transfer proof, which also fixes the artificial terminal labels. Given an I-strategy σ upstairs, use its announced ordinary move a downstairs and initially simulate an accepting response. If the projected play never exits, this is an exact lift. If its first exit r is not in the announced X, the accepting lift ends in a loss for I, as allowed. If r∈X, switch to the simulation in which II challenged this particular r. The earlier ordinary prefix is unchanged: all moves through r in the challenged simulation are forced and agree with the observed prefix. Beyond r follow σ in that simulation. This gives an exact compatible lift. Original terminal outcomes are inherited throughout.
For an II-strategy τ upstairs, after seeing pa downstairs, let
Y={r∈Zp,a​:no announcement X makes τ challenge r}.
(16)
For the announcement X=Y, the strategy τ must accept, since a challenge would have to name an element of Y. Use its accepting ordinary response downstairs and simulate that acceptance until an exit. If the exit r belongs to Y, the accepting lift is an artificial loss for II, as required. If r∈/Y, choose an announcement Xr​ for which τ challenges r, and switch to that simulation. Its first ordinary response and all the intervening forced moves agree with the actual prefix r; after r use τ there. This gives an exact lift. Choices of Xr​ use choice. No switch uses unseen future moves, and the definition of Y uses only the strategy's responses at the fixed announcement level. Thus the maps are local in depth. The unchanged initial segment makes this a k-covering.
We now establish the stronger assertion: every Borel payoff on every such game tree admits a k-unravelling for every finite k. Closed payoffs were just handled. Complements need no new construction, since the complement of a clopen pulled-back payoff is clopen.
For countable unions, suppose C=⋃n<ω​Cn​ and the stronger assertion is known for each constituent and for its continuous pullbacks. Starting with T0​=T, choose a covering Tn+1​→Tn​ that unravels the current pullback of Cn​ and preserves at least the first k+n levels and choices. Previously unravelled payoffs remain clopen under further continuous projections. There is a depth-stabilizing inverse limit of game coverings: each finite level eventually ceases to change, and these stable levels form a tree T∞​.
For completeness, the limit retains the covering property, not just the topology. Compose the projections and the depth-local strategy maps; their finite restrictions stabilize. To lift a play following the limit-projected strategy, lift it successively, coherently, from Tn​ to Tn+1​. If all lifts are exact, the stabilized finite prefixes give a compatible play on T∞​. If a premature losing terminal lift occurs, every further lift is either exact or another losing terminal prefix, so its length cannot increase; lengths and then its finite position stabilize. This produces the permitted losing terminal lift in the limit. The choices needed to select successive lifts are available in ZFC. Projections, inherited terminal outcomes and depth-local strategy maps consequently make T∞​→T a genuine k-covering.
On T∞​, the pullbacks of all the Cn​ are clopen, so their union is open. Its complement is closed. Apply the closed-payoff construction once more to unravel this complement; it unravels the union too. Composition gives the desired covering of T. This proves the induction step. Induction on a well-founded construction of a Borel set, whose operations are complementation and countable union starting from open sets, proves the assertion for every Borel payoff. Continuous preimages of a constituent have the same type of construction, so the induction hypothesis used at successive covers is justified. No countability of the move alphabet was used; all enlarged alphabets and trees remain sets.
Finally apply this result to T=A<ω. The unravelled clopen game has a winning strategy by the first argument. The covering lifting condition transfers it to the original game. Therefore
for every Borel C⊆Aω, one player has a winning strategy in G(C).​
(17)
This is a theorem in the usual background set theory with choice; it does not assert unrestricted determinacy for arbitrary, non-Borel payoffs.

Identify the space of infinite subsets of the natural numbers with their increasing enumerations, with the ordinary topology on infinite subsets inherited from the discrete product ωω. This is the sequence convention in the Open Ramsey theorem. For a general infinite ground set, first choose a countably infinite subset and use its enumeration. The theorem cannot mean unrestricted sequences with repetitions: the clopen partition according as the first two entries agree or differ has both colours over every infinite ground set.
For a finite finite stem s and an infinite tail B above maxs, write
[s,B]={s∪X:X∈[B]ω},
(18)
where the enumeration of s precedes the tail. Let O be open. The tail B accepts s if [s,B]⊆O; it rejects s if no infinite subtail accepts it. Both properties persist on infinite subtails, and any stem can be decided by thinning: choose an accepting subtail if one exists; otherwise the current tail already rejects it.
Use deciding all finite stems by fusion. At stage n, choose a new element bn​ from the current tail, then thin the remaining tail to decide each of the finitely many subsets of {b0​,…,bn​}. First decide the empty stem as well. The final selected set B decides every finite stem from B, because all subsequent selections lie in the tail that decided that stem. If B accepts the empty stem, [B]ω⊆O and we are done.
Otherwise the empty stem is rejected. If a stem s⊂B is rejected, only finitely many a∈B above maxs can have the tail B/a accepting s∪{a}. Indeed, if infinitely many such a formed D, then every X∈[D]ω starts with one of them and has its remaining tail in B/a. It follows that [s,D]⊆O, contradicting rejection of s. All other one-point extensions are rejected, since the first fusion has already decided them.
Build an infinite C⊆B recursively. Maintain that every subset of the finite selected prefix is rejected. To select its next element, avoid the finite union of the finitely many accepting-extension obstructions for these rejected stems. Such an element exists, and all the new stems remain rejected. Hence every finite stem from C is rejected. If some X∈[C]ω were in O, openness would supply a finite initial segment s of X whose entire ordinary cylinder is contained in O. The tail C/maxs would accept s, a contradiction. Thus
[C]ω∩O=∅or[B]ω⊆O.​
(19)
In particular every open payoff has an infinite homogeneous set. A finite partition into open colour classes can be handled by successive application of this two-colour assertion.
For an arbitrary partition use finite-symmetric-difference parity colouring. On the infinite subsets of the ground set, declare X∼Y when X△Y is finite, and choose a representative R from each equivalence class. Colour X by
c(X)=∣X△R[X]​∣(mod2).
(20)
For any infinite H, removing one member gives an infinite H′ in the same class and reverses the parity. Thus H and H′ have opposite colours, so neither colour contains all infinite subsets of any infinite ground set. This two-colouring has no infinite homogeneous set. Representative selection uses choice; the construction is deliberately unrestricted by topological regularity.

An ultraproduct converts coordinatewise finite information into a single first-order structure. Let (Mi​)i∈I​ be nonempty structures in a common first-order language, and let U be an ultrafilter on I. In ∏i​Mi​, set
f∼U​g⟺{i:f(i)=g(i)}∈U.
(21)
The ultraproduct ∏i​Mi​/U has these equivalence classes as its elements. Functions are interpreted coordinatewise; a relation holds of classes exactly when it holds on a U-large set of indices. Intersecting finitely many large agreement sets shows that these interpretations are independent of representatives.
The Łoś theorem, which explains the construction's usefulness, says
∏i​Mi​/U⊨φ([f1​],…,[fr​])⟺{i:Mi​⊨φ(f1​(i),…,fr​(i))}∈U.
(22)
Here is the proof. Induction on terms establishes the coordinatewise interpretation of atomic formulas. Finite intersections handle conjunction, and the ultrafilter property handles negation, since precisely one of a set and its complement is large. For an existential quantification, a witness class gives coordinate witnesses on a large set. Conversely, when the coordinate existential truth set is large, select a witness in each of those structures and a default element elsewhere. Its class is a witness in the ultraproduct. This uses choice. Structural induction on formulas now proves the theorem, with universal quantification obtained by negation.
Compactness. If every finite subset of a first-order theory T has a model, take I to be the finite subsets Γ⊆T and choose MΓ​⊨Γ. The cones {Γ:Δ⊆Γ} for finite Δ have the finite intersection property. Extend their filter to an ultrafilter by the ultrafilter lemma. For each φ∈T, its cone is large, so the Łoś theorem makes the ultraproduct satisfy φ. This proves the compactness theorem, including theories of arbitrary set size.
Elementary extensions and nonstandard elements. An ultrapower uses a fixed structure at every coordinate. The diagonal map sending a to the class of the constant function a is an elementary embedding by the Łoś theorem. For a nonprincipal ultrafilter on ω, the class of i↦i in an ultrapower of the natural numbers exceeds every standard integer, because each corresponding tail is large. In an ultrapower of the real ordered field, the reciprocal of this element is positive and smaller than every positive standard reciprocal integer: an infinitesimal. These examples implement ordinary finite statements in a larger structure without claiming that every external subset or second-order assertion transfers.
Saturation. Such an ultraproduct over ω is countably saturated. To see the actual diagonal argument, list a finitely satisfiable type φ0​(x),φ1​(x),… with parameters in the ultraproduct and fix representatives for those parameters. For each n, the set En​ of coordinates admitting a simultaneous witness to its first n formulas belongs to U by the Łoś theorem. Arrange that the En​ decrease and put Dn​=En​∩{i:i≥n}. The Dn​ decrease, belong to U, and have empty intersection. At coordinate i, choose a witness to the first m(i) formulas, where m(i) is the largest n with i∈Dn​, or choose a default element if there is no such n. For each fixed n, m(i)≥n on the large set Dn​. Therefore the resulting class realizes every formula. This proves countable saturation of an ultraproduct over omega; it does not assert saturation at all larger cardinalities.
Algebraic limits. Take finite fields Fp​ indexed by the primes and a nonprincipal ultrafilter. Their ultraproduct is a field of characteristic zero: for every fixed positive integer n, only finitely many primes divide n, so n⋅1=0 on a large set. Every first-order sentence true in all finite fields holds in this infinite field, and more generally so does any sentence true for all but finitely many of the factors. This is a way to create an infinite field retaining uniform first-order information from finite fields. It does not make the field algebraically closed: the first-order sentence that every element is a square already fails in infinitely many of the factors.
Large cardinals. A countably complete ultrafilter gives a well-founded membership ultrapower of the universe. If it had an infinite descending chain represented by fn​, each set
An​={i:fn+1​(i)∈fn​(i)}
(23)
would be large. Countable completeness makes ⋂n​An​ nonempty, giving an actual infinite membership descent at any index in the intersection, contrary to foundation. The Mostowski collapse therefore gives a transitive target and an ultrapower embedding j:V→M.
For a measure on a measurable cardinal κ, every function κ→α with α<κ is constant on a large set: otherwise intersect the fewer than κ complements of all its fibres. Consequently j fixes the ordinals below κ. The class of the identity function is below j(κ) and above every constant class below κ, since all tails are large. Thus j(κ)>κ and its critical point is κ. Fine ultrafilters on Pκ​(λ) that are normal ultrafilters on small subsets and kappa-complete yield the stronger embeddings witnessing supercompact cardinals.
These applications share a single principle: an ultraproduct preserves precisely the first-order information seen by its ultrafilter. Principal ultrafilters merely select a factor; nonprincipal ones can produce new sizes, elements and saturation. Existence of the needed ultrafilters and selection of coordinate witnesses are set-theoretic assumptions, and changing the ultrafilter may change the resulting model.

A BQO, or better-quasi-ordering, strengthens a well-quasi-ordering by testing arrays indexed by arbitrary barriers, rather than just sequences. Let Q be a preorder. A barrier in better-quasi-order theory on an infinite A⊆ω is a family B of nonempty finite increasing sequences such that no member is properly contained in another and every infinite subset of A has a member of B as its initial segment.
For barrier members write s◃t if a finite increasing sequence u has s as an initial segment and has t as an initial segment after deleting the first entry of u. A map f:B→Q is good when some s◃t satisfy f(s)≤f(t). The definition is
Q is BQO ⟺ every map from every barrier into Q is good.​
(24)
Both quantifiers matter: testing only barriers of one fixed finite length is insufficient.
For the singleton barrier B=[A]1, shifted pairs are just {a}◃{b} with a<b. Thus the BQO condition implies the ordinary well-quasi-ordering condition. Barrier arrays can also be viewed through continuous arrays in better-quasi-order theory F:[A]ω→Q, with Q discrete: set F(X)=f(s) for the unique barrier initial segment s of X. This is continuous because that value is fixed by a finite prefix, and comparing X with X∖{minX} is exactly the shift comparison. The general continuous-array formulation is equivalent to the barrier definition; its converse uses refinement of fronts to barriers, rather than the incorrect assertion that every prefix-decision family is already a barrier.
For an illustrative positive example, every well-order is a BQO. If a barrier array into a well-order were bad, its induced F would satisfy
F(X)>F(X∖{minX})>F(X∖{first two entries})>⋯
(25)
for every infinite X. This is an infinite strict descent in a well-order, a contradiction. A finite antichain with equality is also a BQO: the finitely many fibres of the induced continuous array are open, so repeated use of the Open Ramsey theorem gives an infinite A′ on which the array is constant. The comparison of an infinite subset of A′ with its shift is then good.
The implication to a well-quasi-order is strict. The Rado order is
R={(m,n)∈ω2:m<n},(m,n)≤R​(k,l) ⟺ (m=k and n≤l) or n<k.
(26)
It is well-quasi-ordered: if one first coordinate occurs infinitely often, its second coordinates have an increasing pair; otherwise the first coordinates are unbounded, and a later one exceeds the second coordinate of a chosen earlier pair. But take the barrier [ω]2 and f({m,n})=(m,n). For m<n<l, the shift compares (m,n) with (n,l); their first coordinates differ and n<n is false. Every shifted comparison therefore fails. This bad barrier array for the Rado order proves well-quasi-ordering does not imply better-quasi-ordering.
The stronger notion is designed for infinitary closure operations, such as powerset and infinite-sequence constructions, where a mere well-quasi-order can develop new bad arrays. The barrier definition records variable finite amounts of information from an infinite object and is consequently more robust than checking sequences alone.
