The compactness theorem states that a set of first-order sentences has a model if every finite subset has a model. The Upward Lowenheim-Skolem theorem says that an infinite structure M in a language L has an elementary extension of every prescribed infinite cardinality κ≥max(∣M∣,∣L∣,ℵ0​).
Add constants ca​ for all a∈M and the elementary diagram of a structure of M: every sentence with these constants true in M. Add κ further constants di​ and sentences di​=dj​ for i=j. Any finite subset is satisfiable in M, by choosing the finitely many new constants distinctly, since M is infinite. Compactness gives a model containing an elementary copy of M and at least κ elements.
For the exact cardinality, start with that copy and all the di​, a set of cardinality κ. For every existential formula with parameters from this set that holds in the large model, choose one witness. Also close under the language's functions. Repeat countably many times. At each stage there are at most κ formulas and finite parameter tuples, so the union still has cardinality κ. Every existential formula true in the large model with parameters in the union has a witness in the union; an induction on formulas proves that this substructure is elementary. This establishes the exact-size statement without assuming an unproved downward theorem.
A dense total order with a<b is not a well-order: the nonempty set {x:a<x} has no least element, since density supplies a point strictly between a and any proposed least element.
