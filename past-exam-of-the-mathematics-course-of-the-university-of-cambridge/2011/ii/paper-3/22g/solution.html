The Monodromy theorem states that if a holomorphic germ can be analytically continued along every path in a domain, its continuations along paths homotopic with fixed endpoints coincide. In a simply connected domain this gives a single-valued holomorphic function on the whole domain.
Write ζj​=e2πij/n. Remove the radial rays Rj​={tζj​:t≥1} and set U=C∖⋃j​Rj​. This is an open star-shaped domain containing zero, hence simply connected, and h=zn−1 never vanishes there. Locally its logarithm continues along all paths in U, so monodromy gives a holomorphic logarithm L and
h1/r=eL/ron U.​
(104)
Equivalently, integrate h′/h on the simply connected domain and choose the additive constant to obtain eL=h.
Take r copies of the slit domain, labeled by j∈Z/rZ, carrying values e(L+2πij)/r. Across each cut identify banks so that a positive loop around its simple zero increments the sheet index by one. This cyclic gluing produces the unbranched Riemann surface over C∖Z, on which wr=zn−1 is single valued. Completing each finite puncture gives local coordinate w, with
z−ζj​=nζjn−1​wr​+O(w2r).
(105)
There is one ramification point of index r over each of the n roots of unity.
At infinity a loop around all n zeros acts on sheet labels by j↦j+n(modr). With d=gcd(n,r) this permutation has d cycles, each of length r/d. In the compactification there are therefore d points over infinity, each with ramification index r/d. Infinity is unbranched precisely when d=r, namely when r∣n. Counting branch values in the base sphere,
#{branch values of π}=n⟺r∣n;otherwise it is n+1.​
(106)
If “branch points” denotes ramification points upstairs instead, the count is n or n+d respectively, with exactly the same stated equivalence.
