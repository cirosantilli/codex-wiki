The cumulative hierarchy is defined by transfinite recursion:
V0​=∅,Vα+1​=P(Vα​),Vλ​=α<λ⋃​Vα​ for limit λ.​
(43)
Prove transitivity and nesting together by transfinite induction. The empty set is transitive. If Vα​ is transitive, each x∈Vα​ satisfies x⊆Vα​, so Vα​⊆P(Vα​). If y∈x∈P(Vα​), then y∈Vα​⊆P(Vα​); thus the successor stage is transitive. At a limit, if y∈x∈Vλ​, choose an earlier stage containing x and apply its transitivity. The union is transitive and contains every earlier stage. These observations also give Vα​⊆Vβ​ for all α≤β.
By Axiom of foundation and well-founded recursion, define the rank of a set by rank(x)=sup{rank(y)+1:y∈x}. Axiom schema of replacement ensures this is an ordinal. Induction shows every element of x lies in Vrank(x)​, so
x∈Vrank(x)+1​.​
(44)
Thus every set appears in the hierarchy; the argument uses foundation, not the existence of a set containing all sets.
If rank(x)=β, every subset of x has rank at most β, while x itself belongs to P(x). Consequently
rank(P(x))=β+1.​
(45)
Only successor ordinals occur. Conversely rank(Vβ​)=β, so choosing x=Vβ​ realizes every successor β+1. The exact answer is all successor ordinals, excluding zero and nonzero limit ordinals.
