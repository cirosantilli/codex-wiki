An inverse function of f:X→Y is a function h:Y→X satisfying both
h∘f=idX​,f∘h=idY​.
(1)
These are two-sided inverse identities. If f(x)=f(x′), apply h to get x=x′, so f is injective. For every y∈Y, the identity f(h(y))=y supplies a preimage, so f is surjective. Thus f is a bijection.
Conversely, if f is a bijection, each y∈Y has exactly one preimage. Define h(y) to be that preimage. Then f(h(y))=y and h(f(x))=x, giving both identities. Hence a function has a two-sided inverse exactly when it is a bijection. This also makes its inverse function unique.

An equivalence relation is a binary relation that is simultaneously a reflexive relation, a symmetric relation and a transitive relation: x∼x; x∼y implies y∼x; and x∼y, y∼z imply x∼z. The equivalence class of x is
[x]={y∈X:y∼x}.
(3)
Each equivalence class is nonempty by reflexivity, and every x belongs to [x], so the classes cover X. If z∈[x]∩[y], then the symmetric relation and transitive relation properties give x∼z∼y. Every w∈[x] therefore satisfies w∼x∼y, so [x]⊆[y]; the reverse inclusion follows similarly. Thus two classes are either identical or disjoint. The distinct equivalence classes consequently form a set partition of X.
The divisibility-comparability relation is a reflexive relation and a symmetric relation, but is not an equivalence relation. Indeed, 2∼6 and 6∼3, whereas neither 2∣3 nor 3∣2, so transitivity fails.
For the requested four-class construction, partition the positive integers into
C1​={1},C2​={2},C3​={3,5,7,…},C4​={4,6,8,…}.
(4)
Define x≈y exactly when they lie in the same Cj​. Equality of the class label is an equivalence relation. Its four classes are the two finite singletons and the two infinite parity classes displayed above.

The greatest common divisor d=gcd(a,b) is the largest positive integer dividing both a and b. To prove Bezout identity without assuming unique factorization, let d0​ be the least positive member of
{λa+μb:λ,μ∈Z}.
(17)
This set has positive members, for example a, so well-ordering principle supplies d0​. Divide a by d0​ using Euclidean division: a=qd0​+r, 0≤r<d0​. The remainder r=a−qd0​ is another integer linear combination of a,b. Minimality forces r=0, so d0​∣a. The same argument gives d0​∣b. Every common divisor divides every integer linear combination, hence divides d0​. Therefore d0​ is the greatest common divisor, and
gcd(a,b)=λa+μbfor some λ,μ∈Z.​
(18)
This argument also proves that every common divisor divides the greatest common divisor.
The positive integers with the stated product-divisibility property are
n=1orn is a prime number.​
(19)
The case n=1 is immediate. If p is prime and p∤a, its only possible common positive divisor with a is one. By Bezout identity, λp+μa=1. Multiplying by b shows that p∣ab implies p∣b. This proves Euclid lemma directly. Conversely, if n>1 is not prime, it has a divisor r with 1<r<n. Put s=n/r; then 1<s<n. Although n∣rs, neither r nor s is divisible by n, disproving the property for a composite n.
Finally, suppose ab=cd for four distinct primes. Then a∣cd, so Euclid lemma gives a∣c or a∣d. A prime has no positive divisor other than one and itself, so this would mean a=c or a=d, a contradiction. Products of these two disjoint pairs cannot be equal. No form of the fundamental theorem of arithmetic was used: the required prime-divisibility fact was proved from Bezout identity.

For any function f:X→P(X), form the diagonal subset
D={x∈X:x∈/f(x)}.
(38)
If f were surjective, some d∈X would satisfy f(d)=D. Then d∈D would hold exactly when d∈/D, which is impossible. Thus no set surjects onto its power set, including the empty-set case. This is Cantor's theorem proved by the Cantor diagonal argument.
Use real-number pairing by separated digits for an explicit injection R2→R. First map a real number to (0,1) by q(x)=21​+π−1arctanx, and use its unique binary expansion that is not eventually all ones. If q(x)=∑n≥1​an​2−n and q(y)=∑n≥1​bn​2−n, define
J(x,y)=n≥1∑​(32n−1an​​+32nbn​​).​
(39)
This places the two binary digit strings in alternating ternary positions. Such ternary strings, using only digits zero and one, are unique: at a first differing position k, the difference 3−k exceeds the maximum tail ∑j>k​3−j=21​3−k. Thus the output recovers both digit strings and both inputs. The use of base three avoids any endpoint ambiguity caused by interleaving digits in base two.
For a fixed A⊆R2, the affine sections of a planar set are indexed by
I={(a,b)∈R2×R2:b=0}.
(40)
There is an injection ι:I→R, for example by applying J to each coordinate pair and then once more to those two results. Suppose every subset of R were a section of A. Define a function from R to P(R) by assigning to ι(a,b) the corresponding section, and assigning the empty set to every real outside ι(I). Injectivity of ι makes this definition unambiguous. It would be a surjection onto P(R), contradicting the first argument. No planar set has every subset of the real line as a section. Allowing different parametrizations of the same line does not evade this obstruction.
For all countable sets, however, such a planar set does exist. To build one, first encode every real sequence s=(s1​,s2​,…) by one real number. Let ank​ be the canonical binary digits of q(sn​), and choose the explicit indexing
j(n,k)=2(n+k−2)(n+k−1)​+n(n,k≥1).
(41)
This is a bijection from positive integer pairs to positive integers. Define the coding of real sequences by ternary digits
c(s)=∑n,k≥1​3j(n,k)ank​​.
(42)
The same first-differing-digit argument proves that c is injective; all its values lie in [0,1/2]. Now take
A={(c(s),sn​):s∈RN, n≥1}.​
(43)
For every nonempty countable set S⊆R, choose an enumeration s of S, repeating terms if S is finite. On the vertical line with a=(c(s),0) and b=(0,1), the section of A is precisely S: injective sequence coding means no other sequence can contribute extra values in this column. The empty set is the section on the line x=2, since all code columns have first coordinate at most 1/2. This constructs the required universal planar set for countable real sections. No assertion about its other, nonvertical sections is needed.

The relativistic energy of a particle of rest mass m is E=γmc2, where the Lorentz factor is γ=(1−v2/c2)−1/2. Using the binomial series at small v/c gives
E=mc2+21​mv2+O(c2mv4​).​
(75)
The second term is the familiar Newtonian kinetic energy. The first is the rest energy, which remains when v=0. Thus the new physical idea is mass-energy equivalence: a body's mass represents energy mc2 even at rest. The total energy is not merely energy due to motion.

The incident four-momentum has energy E and spatial momentum p=γmv, while the stationary target has energy mc2 and zero spatial momentum. By the relativistic energy-momentum relation, c2p2=E2−m2c4. For the fixed-target threshold for production of equal-mass particles, the squared total centre-of-momentum energy is
W2=(E+mc2)2−c2p2=2mc2(E+mc2).
(76)
In the centre-of-momentum frame, each of the final N particles has energy at least its rest energy mc2. Four-momentum conservation therefore requires W≥Nmc2, and thus
E≥2N2−2​mc2.​
(77)
For the physically relevant N≥2, this is equivalent to γ≥(N2−2)/2. The speed is an increasing function of γ, so
cv​=1−γ−2​≥1−(N2−2)24​​=N2−2NN2−4​​.
(78)
Consequently
v≥N2−2NN2−4​​c.​
(79)
Equality is the kinematic threshold at which all final particles are at rest in their common centre-of-momentum frame. It shows why a collision with a stationary target needs more incident energy than merely the additional rest energy: some laboratory energy must remain as collective motion. A one-particle final state of the specified mass, with no other outgoing energy, is impossible because its invariant energy would be mc2, whereas the two-particle initial state has invariant energy at least 2mc2.
