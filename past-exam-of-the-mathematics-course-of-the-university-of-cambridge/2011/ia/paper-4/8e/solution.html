For any function f:X→P(X), form the diagonal subset
D={x∈X:x∈/f(x)}.
(38)
If f were surjective, some d∈X would satisfy f(d)=D. Then d∈D would hold exactly when d∈/D, which is impossible. Thus no set surjects onto its power set, including the empty-set case. This is Cantor's theorem proved by the Cantor diagonal argument.
Use real-number pairing by separated digits for an explicit injection R2→R. First map a real number to (0,1) by q(x)=21​+π−1arctanx, and use its unique binary expansion that is not eventually all ones. If q(x)=∑n≥1​an​2−n and q(y)=∑n≥1​bn​2−n, define
J(x,y)=n≥1∑​(32n−1an​​+32nbn​​).​
(39)
This places the two binary digit strings in alternating ternary positions. Such ternary strings, using only digits zero and one, are unique: at a first differing position k, the difference 3−k exceeds the maximum tail ∑j>k​3−j=21​3−k. Thus the output recovers both digit strings and both inputs. The use of base three avoids any endpoint ambiguity caused by interleaving digits in base two.
For a fixed A⊆R2, the affine sections of a planar set are indexed by
I={(a,b)∈R2×R2:b=0}.
(40)
There is an injection ι:I→R, for example by applying J to each coordinate pair and then once more to those two results. Suppose every subset of R were a section of A. Define a function from R to P(R) by assigning to ι(a,b) the corresponding section, and assigning the empty set to every real outside ι(I). Injectivity of ι makes this definition unambiguous. It would be a surjection onto P(R), contradicting the first argument. No planar set has every subset of the real line as a section. Allowing different parametrizations of the same line does not evade this obstruction.
For all countable sets, however, such a planar set does exist. To build one, first encode every real sequence s=(s1​,s2​,…) by one real number. Let ank​ be the canonical binary digits of q(sn​), and choose the explicit indexing
j(n,k)=2(n+k−2)(n+k−1)​+n(n,k≥1).
(41)
This is a bijection from positive integer pairs to positive integers. Define the coding of real sequences by ternary digits
c(s)=∑n,k≥1​3j(n,k)ank​​.
(42)
The same first-differing-digit argument proves that c is injective; all its values lie in [0,1/2]. Now take
A={(c(s),sn​):s∈RN, n≥1}.​
(43)
For every nonempty countable set S⊆R, choose an enumeration s of S, repeating terms if S is finite. On the vertical line with a=(c(s),0) and b=(0,1), the section of A is precisely S: injective sequence coding means no other sequence can contribute extra values in this column. The empty set is the section on the line x=2, since all code columns have first coordinate at most 1/2. This constructs the required universal planar set for countable real sections. No assertion about its other, nonvertical sections is needed.
