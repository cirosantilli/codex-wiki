For a linear code X≤Fn, its dual code is
X⊥={y∈Fn:∑i=1n​xi​yi​=0 for every x∈X}.
(1)
The standard bilinear form is nondegenerate. The map Fn→X∗ obtained by restricting the dot-product functional to X is surjective: extend a functional from a basis of X to a basis of Fn, then use the nondegenerate dot product to represent it. Its kernel is X⊥. The rank-nullity theorem therefore gives
dimX⊥=n−dimX.​
(2)
The first proposed description of the dual code is false without self-orthogonality. At length three take X=⟨(1,0,0)⟩. It has the specified dimension, but
X⊥={(0,a,b):a,b∈F2​},
(3)
whereas ⟨X,(1,1,1)⟩ contains (1,0,0) and (1,1,1), neither of which is in X⊥. The natural corrected statement is the odd-length binary self-orthogonal dual extension: if also X⊆X⊥, every word of X has even Hamming weight, the all-ones word lies in X⊥ but not in X, and dimensions then give X⊥=X⊕⟨1⟩.
For a binary self-dual code, x⋅x=0 for every x∈X. In F2​, this equals ∑i​xi​, so every codeword has even Hamming weight. Thus 1⋅x=0 for all x, giving 1∈X⊥=X. The dimension identity yields 2dimX=n, so n is even. Alternatively 1∈X and 1⋅1=0 itself gives evenness. Hence the second assertion is true.
For every n=2m, use
X={(u,u):u∈F2m​},G=(Im​∣Im​).
(4)
This linear code has dimension m, and (u,u)⋅(v,v)=2(u⋅v)=0. Therefore X⊆X⊥; both have dimension m, so equality holds. This constructs a binary self-dual code at every even length. Conversely the dimension identity already proves every self-dual length-n linear code has dimension n/2.
For a nonbinary example, over F5​ take X=⟨(1,2)⟩. Its generator has self-product 1+22=0 in F5​, so X⊆X⊥. Both are one-dimensional, proving
⟨(1,2)⟩≤F52​ is self-dual.​
(5)
