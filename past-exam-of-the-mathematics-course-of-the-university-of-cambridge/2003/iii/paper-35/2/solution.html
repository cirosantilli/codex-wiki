For a classical error-correcting code of length n, alphabet size q, minimum Hamming distance d and M codewords, the Singleton bound is
M≤qn−d+1.
(7)
For a linear [n,k,d]q​ code this is n−k≥d−1. Deleting any d−1 coordinates is injective on the codewords, since two words agreeing on the remaining coordinates would differ in fewer than d positions; this also explains the classical bound.
For an n-qubit quantum code carrying k>0 logical qubits and having quantum code distance d, the quantum Singleton bound is
n−k≥2(d−1).​
(8)
More generally replace k by log2​K for code dimension K>1. The proof applies to degenerate codes too.
Let r=d−1. Purify the maximally mixed encoded input by a reference R of dimension K:
∣Ω⟩=K−1/2∑j=1K​∣j⟩R​∣jL​⟩,S(R)=log2​K=:k.
(9)
Distance d makes erasure of any subset of at most r qubits correctable. The allowed quantum erasure correction condition says that a correctable erased set A is decoupled from R:
ρRA​=ρR​⊗ρA​,S(RA)=k+S(A).
(10)
This is the matrix-element correction condition in another form: all operators on A have constant diagonal matrix elements and zero off-diagonal matrix elements in the logical basis, so tracing the other physical qubits in ∣Ω⟩⟨Ω∣ yields the displayed product.
First justify the sizes needed for the partition. If 2r>n, partition all physical qubits into A,B, both of size at most r. Both sets are correctable. Purity of RAB and the Schmidt decomposition give
k+S(A)=S(RA)=S(B),k+S(B)=S(RB)=S(A).
(11)
Adding forces k=0, a contradiction. Thus 2r≤n, without assuming the bound we aim to prove.
Choose disjoint sets A,B of size r, and let C contain the remaining n−2r qubits. The joint state RABC is pure, so decoupling and Subadditivity of Von Neumann entropy give
k+S(A)=S(RA)=S(BC)≤S(B)+S(C),
(12)
k+S(B)=S(RB)=S(AC)≤S(A)+S(C).
(13)
Adding and cancelling gives k≤S(C). The Von Neumann entropy of D-dimensional states is at most log2​D: for positive eigenvalues pi​, concavity of the logarithm gives ∑i​pi​log2​(1/pi​)≤log2​∑i​pi​/pi​≤log2​D. Here D=2n−2r, so k≤n−2r, proving the quantum bound. The code is assumed to encode information (K>1); a one-dimensional code requires a separate distance convention, since simply re-preparing a known state makes its erasure-correction condition vacuous.
