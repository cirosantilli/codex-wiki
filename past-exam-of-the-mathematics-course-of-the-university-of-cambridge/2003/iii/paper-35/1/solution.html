The Pauli group includes scalar phases Z={±I,±iI}. For a nonzero stabilizer code, its Abelian subgroup must satisfy −I∈/S. Otherwise a common positive eigenvector would satisfy −∣ψ⟩=∣ψ⟩ and vanish; for example S={I,−I} is Abelian but yields no nonzero stabilizer code. We impose this standard admissibility condition.
Every element of such a stabilizer group is Hermitian and squares to I: an imaginary-phase Pauli with square −I is excluded. The associated stabilizer code and its orthogonal projector are
CS​={∣ψ⟩:s∣ψ⟩=∣ψ⟩ for every s∈S},P=∣S∣1​∑s∈S​s.
(1)
The group multiplication proves P2=P, Hermiticity gives P†=P, and its range is exactly the common positive eigenspace. If S has r independent generators, ∣S∣=2r. Every nonidentity element has trace zero, while trI=2n, so
dimCS​=trP=2n−r.​
(2)
Thus it encodes k=n−r logical qubits.
For the symplectic representation of a stabilizer code, label itXaZb by (a,b)∈F22n​, ignoring scalar phase. Products add labels, and
(XaZb)(Xa′Zb′)=(−1)a⋅b′+b⋅a′(Xa′Zb′)(XaZb).
(3)
This is the nondegenerate alternating form ω((a,b),(a′,b′))=a⋅b′+b⋅a′ on the binary symplectic space of Pauli labels. The image L of S is an r-dimensional isotropic subspace of a binary symplectic space, since the generators commute and no nontrivial scalar lies in S. Consequently L⊆L⊥ and r≤n. A binary generator matrix (A∣B) satisfies ABT+BAT=0. Conversely an isotropic subspace can be lifted by choosing commuting Hermitian generators with independent labels; their products cannot equal −I, and the orthogonal projector formula supplies the stabilizer code. The labels of the centralizer of a stabilizer group are L⊥, with nontrivial logical actions represented by L⊥∖L.
For an example, the three-qubit bit-flip repetition code has S=⟨Z1​Z2​,Z2​Z3​⟩ and CS​=span{∣000⟩,∣111⟩}. Its two binary rows have zero X part and Z parts 110,011. The errors I,X1​,X2​,X3​ have respective error syndromes 00,10,11,01, so all single bit flips can be corrected. This is not a stabilizer code correcting every single-qubit error: Z1​ acts as a nontrivial logical phase error.
Let C(S) denote the Pauli centralizer. The exact Pauli error criterion for a stabilizer code is
For all Ea​,Eb​∈E,Ea†​Eb​∈ZS or Ea†​Eb​∈/C(S).​
(4)
Equivalently, no difference of error labels lies in L⊥∖L. The scalar phases in ZS are essential: an error product −I is harmless even though it is not in S.
We prove the criterion. For T=Ea†​Eb​ outside C(S), some s∈S anticommutes with T. Since sP=Ps=P, we have PTP=PsTsP=−PTP, hence PTP=0. If T=λs∈ZS, then PTP=λP. If T∈C(S)∖ZS, it restricts to a unitary operator on the stabilizer code, but
tr(PT)=∣S∣−1∑s∈S​tr(sT)=0:
(5)
no sT is scalar. A scalar restriction would have scalar coefficient zero by this trace equation, contradicting unitarity. Thus this third case is not scalar.
To justify why scalar compressions are exactly what correction requires, suppose one recovery corrects every Ea​. Dilate that recovery to an isometry W including its auxiliary system. Correct recovery of every pure stabilizer code state gives WEa​∣ψ⟩=∣ψ⟩⊗∣ηa​⟩. The auxiliary state is independent of ψ: linearity on basis states and their superpositions forces their auxiliary vectors to coincide. Preservation of inner products then gives
⟨ϕ∣Ea†​Eb​∣ψ⟩=⟨ϕ∣ψ⟩⟨ηa​∣ηb​⟩,
(6)
which is the Knill--Laflamme condition PEa†​Eb​P=cab​P. The three cases above prove necessity of the boxed criterion.
For sufficiency, put errors in the same class when Ea†​Eb​∈ZS. They act identically on the stabilizer code up to scalar phase, so give the same error-image subspace. Under the criterion, different classes give mutually orthogonal subspaces Ea​CS​, because their cross-compressions vanish. Measure which of these subspaces is occupied and apply the inverse of a representative error. This returns every stabilizer code state unchanged; extend the recovery on the orthogonal complement by preparing any fixed stabilizer code state. Linearity also corrects any valid noise channel whose Kraus operators are linear combinations of the specified errors: within each syndrome all amplitudes multiply the same logical state, and trace preservation normalizes the recovered state. This proves sufficiency, including degenerate error classes.
