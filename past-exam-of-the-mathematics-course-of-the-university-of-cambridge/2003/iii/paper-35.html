The Pauli group includes scalar phases Z={±I,±iI}. For a nonzero stabilizer code, its Abelian subgroup must satisfy −I∈/S. Otherwise a common positive eigenvector would satisfy −∣ψ⟩=∣ψ⟩ and vanish; for example S={I,−I} is Abelian but yields no nonzero stabilizer code. We impose this standard admissibility condition.
Every element of such a stabilizer group is Hermitian and squares to I: an imaginary-phase Pauli with square −I is excluded. The associated stabilizer code and its orthogonal projector are
CS​={∣ψ⟩:s∣ψ⟩=∣ψ⟩ for every s∈S},P=∣S∣1​∑s∈S​s.
(1)
The group multiplication proves P2=P, Hermiticity gives P†=P, and its range is exactly the common positive eigenspace. If S has r independent generators, ∣S∣=2r. Every nonidentity element has trace zero, while trI=2n, so
dimCS​=trP=2n−r.​
(2)
Thus it encodes k=n−r logical qubits.
For the symplectic representation of a stabilizer code, label itXaZb by (a,b)∈F22n​, ignoring scalar phase. Products add labels, and
(XaZb)(Xa′Zb′)=(−1)a⋅b′+b⋅a′(Xa′Zb′)(XaZb).
(3)
This is the nondegenerate alternating form ω((a,b),(a′,b′))=a⋅b′+b⋅a′ on the binary symplectic space of Pauli labels. The image L of S is an r-dimensional isotropic subspace of a binary symplectic space, since the generators commute and no nontrivial scalar lies in S. Consequently L⊆L⊥ and r≤n. A binary generator matrix (A∣B) satisfies ABT+BAT=0. Conversely an isotropic subspace can be lifted by choosing commuting Hermitian generators with independent labels; their products cannot equal −I, and the orthogonal projector formula supplies the stabilizer code. The labels of the centralizer of a stabilizer group are L⊥, with nontrivial logical actions represented by L⊥∖L.
For an example, the three-qubit bit-flip repetition code has S=⟨Z1​Z2​,Z2​Z3​⟩ and CS​=span{∣000⟩,∣111⟩}. Its two binary rows have zero X part and Z parts 110,011. The errors I,X1​,X2​,X3​ have respective error syndromes 00,10,11,01, so all single bit flips can be corrected. This is not a stabilizer code correcting every single-qubit error: Z1​ acts as a nontrivial logical phase error.
Let C(S) denote the Pauli centralizer. The exact Pauli error criterion for a stabilizer code is
For all Ea​,Eb​∈E,Ea†​Eb​∈ZS or Ea†​Eb​∈/C(S).​
(4)
Equivalently, no difference of error labels lies in L⊥∖L. The scalar phases in ZS are essential: an error product −I is harmless even though it is not in S.
We prove the criterion. For T=Ea†​Eb​ outside C(S), some s∈S anticommutes with T. Since sP=Ps=P, we have PTP=PsTsP=−PTP, hence PTP=0. If T=λs∈ZS, then PTP=λP. If T∈C(S)∖ZS, it restricts to a unitary operator on the stabilizer code, but
tr(PT)=∣S∣−1∑s∈S​tr(sT)=0:
(5)
no sT is scalar. A scalar restriction would have scalar coefficient zero by this trace equation, contradicting unitarity. Thus this third case is not scalar.
To justify why scalar compressions are exactly what correction requires, suppose one recovery corrects every Ea​. Dilate that recovery to an isometry W including its auxiliary system. Correct recovery of every pure stabilizer code state gives WEa​∣ψ⟩=∣ψ⟩⊗∣ηa​⟩. The auxiliary state is independent of ψ: linearity on basis states and their superpositions forces their auxiliary vectors to coincide. Preservation of inner products then gives
⟨ϕ∣Ea†​Eb​∣ψ⟩=⟨ϕ∣ψ⟩⟨ηa​∣ηb​⟩,
(6)
which is the Knill--Laflamme condition PEa†​Eb​P=cab​P. The three cases above prove necessity of the boxed criterion.
For sufficiency, put errors in the same class when Ea†​Eb​∈ZS. They act identically on the stabilizer code up to scalar phase, so give the same error-image subspace. Under the criterion, different classes give mutually orthogonal subspaces Ea​CS​, because their cross-compressions vanish. Measure which of these subspaces is occupied and apply the inverse of a representative error. This returns every stabilizer code state unchanged; extend the recovery on the orthogonal complement by preparing any fixed stabilizer code state. Linearity also corrects any valid noise channel whose Kraus operators are linear combinations of the specified errors: within each syndrome all amplitudes multiply the same logical state, and trace preservation normalizes the recovered state. This proves sufficiency, including degenerate error classes.

For a classical error-correcting code of length n, alphabet size q, minimum Hamming distance d and M codewords, the Singleton bound is
M≤qn−d+1.
(7)
For a linear [n,k,d]q​ code this is n−k≥d−1. Deleting any d−1 coordinates is injective on the codewords, since two words agreeing on the remaining coordinates would differ in fewer than d positions; this also explains the classical bound.
For an n-qubit quantum code carrying k>0 logical qubits and having quantum code distance d, the quantum Singleton bound is
n−k≥2(d−1).​
(8)
More generally replace k by log2​K for code dimension K>1. The proof applies to degenerate codes too.
Let r=d−1. Purify the maximally mixed encoded input by a reference R of dimension K:
∣Ω⟩=K−1/2∑j=1K​∣j⟩R​∣jL​⟩,S(R)=log2​K=:k.
(9)
Distance d makes erasure of any subset of at most r qubits correctable. The allowed quantum erasure correction condition says that a correctable erased set A is decoupled from R:
ρRA​=ρR​⊗ρA​,S(RA)=k+S(A).
(10)
This is the matrix-element correction condition in another form: all operators on A have constant diagonal matrix elements and zero off-diagonal matrix elements in the logical basis, so tracing the other physical qubits in ∣Ω⟩⟨Ω∣ yields the displayed product.
First justify the sizes needed for the partition. If 2r>n, partition all physical qubits into A,B, both of size at most r. Both sets are correctable. Purity of RAB and the Schmidt decomposition give
k+S(A)=S(RA)=S(B),k+S(B)=S(RB)=S(A).
(11)
Adding forces k=0, a contradiction. Thus 2r≤n, without assuming the bound we aim to prove.
Choose disjoint sets A,B of size r, and let C contain the remaining n−2r qubits. The joint state RABC is pure, so decoupling and Subadditivity of Von Neumann entropy give
k+S(A)=S(RA)=S(BC)≤S(B)+S(C),
(12)
k+S(B)=S(RB)=S(AC)≤S(A)+S(C).
(13)
Adding and cancelling gives k≤S(C). The Von Neumann entropy of D-dimensional states is at most log2​D: for positive eigenvalues pi​, concavity of the logarithm gives ∑i​pi​log2​(1/pi​)≤log2​∑i​pi​/pi​≤log2​D. Here D=2n−2r, so k≤n−2r, proving the quantum bound. The code is assumed to encode information (K>1); a one-dimensional code requires a separate distance convention, since simply re-preparing a known state makes its erasure-correction condition vacuous.

The channel capacity is the supremum of reliable communication rates: a rate R bits per use is achievable if block encoders and decoders using n channel uses can transmit Mn​ messages with error probability tending to zero and liminfn−1log2​Mn​≥R.
A discrete memoryless channel has fixed transition probabilities W(y∣x) on finite input and output alphabets, and
W(y1​,…,yn​∣x1​,…,xn​)=∏j=1n​W(yj​∣xj​).
(14)
Its single-letter capacity formula is
C=PX​max​I(X;Y)=PX​max​(H(Y)−H(Y∣X)),​
(15)
with logarithms to base two. The Shannon second coding theorem identifies this maximum with the operational reliable rate.
For the binary erasure channel, use output symbols 0,1,e, where e is a recognizable erasure flag. Given input x, the output is x with probability 1−p and e with probability p. If Pr(X=1)=a, the output probabilities are (1−p)(1−a),(1−p)a,p. Thus, writing h2​ for binary entropy,
H(Y)=h2​(p)+(1−p)h2​(a),H(Y∣X)=h2​(p),
(16)
and I(X;Y)=(1−p)h2​(a). Its maximum is attained by the uniform input a=1/2, giving
C=1−p bits per channel use,0≤p≤1.​
(17)
In particular the noiseless and complete-erasure endpoints have capacities one and zero. The erasure flag reveals which positions were lost; it does not reveal the erased input values.

For a density matrix ρ on a finite-dimensional Hilbert space, its Von Neumann entropy in bits is
S(ρ)=−tr(ρlog2​ρ)=−j∑​λj​log2​λj​,​
(18)
where λj​ are its eigenvalues and 0log2​0=0. It is the Shannon entropy of the spectrum, is zero for a pure state, and is invariant under unitary conjugation.

The concavity inequality is true, but its printed equality condition is false. At b=1 equality always holds, even for distinct states; for example take ρ1​=∣0⟩⟨0∣ and ρ2​=∣1⟩⟨1∣. The correct statement on 0≤b≤1 is
Equality holds iff b∈{0,1} or ρ1​=ρ2​.​
(19)
For 0<b<1, entropy is therefore strictly concave.
We give the matrix inequality needed for the proof. Define the quantum relative entropy D(τ∥σ)=trτ(log2​τ−log2​σ) if the support of τ is contained in that of σ, and +∞ otherwise. Diagonalize the two states with eigenvalues ri​,sj​, and put qij​=∣⟨i∣j⟩∣2. Each row and column of q sums to one. The elementary scalar inequality
uln(u/v)≥u−v
(20)
follows from xlnx−x+1≥0, with equality exactly at x=1; use limits at zero. Consequently
D(τ∥σ)=ln21​∑ij​qij​ri​ln(ri​/sj​)≥ln21​∑ij​qij​(ri​−sj​)=0.
(21)
Equality forces ri​=sj​ whenever qij​>0. Hence every eigenvector ∣i⟩ of τ is also a σ-eigenvector with eigenvalue ri​, so τ=σ. Conversely identical states give zero relative entropy. This proves nonnegativity of quantum relative entropy and its equality condition, including states with zero eigenvalues under the support convention.
Now set ρ=bρ1​+(1−b)ρ2​. For 0<b<1 its support contains both component supports. Direct expansion gives
S(ρ)−bS(ρ1​)−(1−b)S(ρ2​)=bD(ρ1​∥ρ)+(1−b)D(ρ2​∥ρ)≥0.
(22)
Since both coefficients are positive, equality holds exactly when both component states equal ρ, equivalently ρ1​=ρ2​. At either endpoint the mixture has only one component and equality is automatic. This proves the corrected strict concavity of Von Neumann entropy.

True: quantum entropy is subadditive. Write σ=ρ1​⊗ρ2​. Positivity ensures the support of ρ lies in that of σ. Indeed, if ∣v⟩∈kerρ1​, then ∑j​⟨v,j∣ρ∣v,j⟩=0; all summands are nonnegative, so ρ1/2∣v,j⟩=0 for every j. Thus ρ annihilates kerρ1​⊗K2​, and similarly the kernel from the other factor.
On the resulting support, log2​(ρ1​⊗ρ2​)=log2​ρ1​⊗I+I⊗log2​ρ2​. Using the defining property of the partial trace and nonnegativity of quantum relative entropy proved in part (i),
0≤D(ρ∥ρ1​⊗ρ2​)=−S(ρ)−trρ1​log2​ρ1​−trρ2​log2​ρ2​=S(ρ1​)+S(ρ2​)−S(ρ).
(24)
Hence
S(ρ)≤S(ρ1​)+S(ρ2​).​
(25)
Equality holds exactly for the product state ρ=ρ1​⊗ρ2​. This proves Subadditivity of Von Neumann entropy directly.

For a memoryless quantum channel N, successive uses are described by N⊗n. Its entanglement-assisted classical capacity is the supremum of classical bits per use achievable with error tending to zero when sender and receiver may use unlimited preshared quantum entanglement, independent of the message. Only the channel is used to transmit the message.
For input state ρA​, choose a purification ∣ψρ​⟩RA​ and set ωRB​=(idR​⊗N)(∣ψρ​⟩⟨ψρ​∣). The capacity formula is
CE​(N)=ρA​max​I(R;B)ω​=ρA​max​[S(ρA​)+S(N(ρA​))−S(ωRB​)].​
(26)
Purifications differ only by an isometry on the reference, so this expression depends only on the input density matrix. The quantity optimized is quantum mutual information.
The binary quantum erasure channel sends a qubit to a qubit subspace plus an orthogonal erasure flag:
Ep​(ρ)=(1−p)ρ⊕p∣e⟩⟨e∣,0≤p≤1.
(27)
On the nonerased branch it transmits the entire state, including its coherences. Put s=S(ρ). The entropy of an orthogonal quantum mixture gives
S(Ep​(ρ))=h2​(p)+(1−p)s.
(28)
The reference-output state has two orthogonal branches:
ωRB​=(1−p)∣ψρ​⟩⟨ψρ​∣ ⊕ pρR​⊗∣e⟩⟨e∣.
(29)
The first branch is pure; the second has entropy S(ρR​)=s. Thus S(ωRB​)=h2​(p)+ps and
I(R;B)ω​=s+h2​(p)+(1−p)s−h2​(p)−ps=2(1−p)s.
(30)
A qubit has entropy at most one bit, with equality at ρ=I2​/2. We conclude
CE​(Ep​)=2(1−p) bits per channel use.​
(31)
The endpoint capacities are two and zero. As an operational check, superdense coding encodes four classical messages in one member of a shared Bell pair. A successful channel use lets the receiver identify the message; an erased qubit yields the flag. This induces a four-symbol classical erasure channel of capacity (1−p)log2​4=2(1−p), agreeing with the entropy calculation.
