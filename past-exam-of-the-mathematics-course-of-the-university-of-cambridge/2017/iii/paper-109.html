Write D=∑i=1n​bi​ and let λ denote Lebesgue measure. Necessity follows from measure additivity and monotonicity: the pairwise disjoint Lebesgue measurable sets Bi​ give
λ(⋃i∈I​Ai​)≥λ(⋃i∈I​Bi​)=∑i∈I​bi​.
(1)
For sufficiency, form the finite measurable partition into membership cells
EJ​=(⋂j∈J​Aj​)∖(⋃j∈/J​Aj​),∅=J⊆[n].
(2)
These Lebesgue measurable sets are pairwise disjoint, and Ai​=⋃J∋i​EJ​. Empty cells may be retained. Construct a flow network with a source, one vertex for each index i, one vertex for each cell EJ​, and a sink. Give the source-to-i edge capacity bi​, the i-to-J edge capacity D whenever i∈J, and the J-to-sink edge capacity λ(EJ​).
Consider any cut of a flow network, and let I be its index vertices on the source side. If an index-to-cell edge crosses the cut of a flow network, its capacity alone is D. Otherwise every cell with J∩I=∅ lies on the source side, so the cut of a flow network has capacity at least
∑i∈/I​bi​+∑J:J∩I=∅​λ(EJ​)=D−∑i∈I​bi​+λ(⋃i∈I​Ai​)≥D.
(3)
The cut immediately after the source has capacity D. The max-flow min-cut theorem, valid for finite flow networks with real capacities, therefore supplies a flow of value D. Its cell allocations fiJ​≥0 satisfy
∑J∋i​fiJ​=bi​,∑i∈J​fiJ​≤λ(EJ​).
(4)
It remains to convert these numbers into Lebesgue measurable sets; this uses divisibility of Lebesgue measure. Indeed, for any Lebesgue measurable set E⊆[0,1], the function F(t)=λ(E∩[0,t]) satisfies F(0)=0, F(1)=λ(E) and ∣F(t)−F(u)∣≤∣t−u∣. Thus it has Lipschitz continuity, and the intermediate value theorem supplies a measurable subset of E of any prescribed measure between 0 and λ(E). Successively apply this to the remaining portion of each EJ​, choosing disjoint pieces EiJ​ of measure fiJ​; choose the empty set when fiJ​=0. Then
Bi​=J∋i⋃​EiJ​⊆Ai​,λ(Bi​)=bi​,Bi​∩Bj​=∅ (i=j).​
(5)
This proves the measurable Hall theorem. The splitting step is essential: an arbitrary measure with an atom of a measure would not support the same conclusion. Here inclusion allows equality; even if strict inclusion is required, deleting one point of each nonempty Ai​ from every Bj​ preserves all measures and ensures Bi​=Ai​.

The sharp bound form of the Erdős-Ko-Rado theorem is as follows. If 1≤r≤n/2 and F⊆(r[n]​) is an intersecting family, then
∣F∣≤(r−1n−1​).​
(6)
The uniform set family of all r-element subsets containing one fixed point attains the bound. We prove it by the Katona circle method.
First establish the cyclic interval intersection bound. In any fixed cyclic ordering of [n], at most r cyclic intervals of length r can form an intersecting family. If there is a selected interval, rotate the ordering so that it ends at position n and consists of positions n−r+1,…,n. Intervals ending at positions r,…,n−r are disjoint from it and cannot be selected. Of the remaining intervals, one ends at n; the others have endpoints paired as
(j, j+n−r),1≤j≤r−1.
(7)
The two intervals in each pair are disjoint: one wraps around position n and the other lies in the intervening gap, since n≥2r. At most one of each pair belongs to the intersecting family, giving at most 1+(r−1)=r intervals.
Now count pairs (σ,A) where σ is a permutation of [n] placed on labelled cyclic positions and A∈F occupies r consecutive positions. Each permutation contributes at most r pairs by the cyclic interval intersection bound. Each fixed A contributes nr!(n−r)! pairs: choose its starting position and order the elements inside and outside its interval. Since r<n, the starting position is unique for each such placement. Consequently
∣F∣nr!(n−r)!≤rn!,∣F∣≤nr​(rn​)=(r−1n−1​).
(8)
This completes the Erdős-Ko-Rado theorem proof. At n=2r, complementary r-element subsets are the only disjoint pairs, so choosing one member of every complementary pair gives an extremiser. This describes all equality cases at that boundary. The range n≥2r is essential: for n<2r, the entire uniform set family is an intersecting family.

A bounded-size transversal kernel gives a finite intersection witness for cross-intersecting families, even when the two set families are infinite. We first prove the kernel statement: for any set family F whose members have size at most r, and any integer s≥0, there is a finite subset F0​⊆F with
∣F0​∣≤M(r,s):=∑j=0s​rj
(9)
such that every set H of size at most s is a hitting set for F0​ if and only if it is a hitting set for F.
Use mathematical induction on s. If F is empty, take F0​=∅. For s=0 and nonempty F, choose any one member: the only possible H is empty and is a hitting set for neither family. For the induction step, choose A0​∈F. For each x∈A0​ apply the inductive statement to
Fx​={A∈F:x∈/A}
(10)
with parameter s−1, obtaining Fx,0​. Put F0​={A0​}∪⋃x∈A0​​Fx,0​. Its size is at most 1+rM(r,s−1)=M(r,s). If H is a hitting set for F0​, choose x∈H∩A0​. Every member of Fx,0​ avoids x, so H∖{x} is a hitting set for Fx,0​ and hence for Fx​. Members of F containing x already meet H. Thus H is a hitting set for all of F. The reverse implication follows from inclusion. If A0​=∅, no H is a hitting set for either family, so the implication remains valid. This finite branching proof never assumes F is finite.
Apply the kernel statement with F=A and define X=⋃A∈F0​​A. For each B∈B, the cross-intersecting family condition ensures that B∩X meets every member of F0​, since these members lie inside X. As ∣B∩X∣≤s, it therefore meets every A∈A. We obtain
A∩B∩X=∅for every A∈A, B∈B,∣X∣≤rj=0∑s​rj.​
(11)
In particular, a positive-integer-valued choice valid whether or not 0∈N is
f(r,s)=1+rj=0∑s​rj.​
(12)
Here the constant term of the sum is 1, including when r=0. If either set family is empty, X=∅ suffices. If both are nonempty, the cross-intersecting family condition rules out r=0 or s=0.

Harris' inequality states that, for a product measure on {0,1}n with independent Bernoulli random variables of parameters pi​∈[0,1], increasing events E,F satisfy
P(E∩F)≥P(E)P(F).​
(13)
In particular, the uniform probability measure on the Boolean lattice gives ∣E∩F∣≥∣E∣∣F∣/2n. We give a direct mathematical induction proof, so no stronger correlation theorem is assumed.
Prove more generally that E[fg]≥E[f]E[g] for real coordinatewise increasing functions f,g on the finite cube. For n=0 both are constant and equality holds. For the inductive step let p=pn​, and let fj​,gj​ be the restrictions obtained by setting the last coordinate equal to j∈{0,1}. Write aj​=E[fj​], bj​=E[gj​], using the product measure on the other coordinates. Monotonicity gives a0​≤a1​, b0​≤b1​. By the inductive hypothesis and conditional expectation,
E[fg]​≥(1−p)a0​b0​+pa1​b1​=((1−p)a0​+pa1​)((1−p)b0​+pb1​)+p(1−p)(a1​−a0​)(b1​−b0​)≥E[f]E[g].​
(14)
The nonnegative correction term also handles p=0 and p=1. Taking indicator functions f=1E​, g=1F​ proves Harris' inequality.
For later use, an increasing event E and a decreasing event G have negative correlation of increasing and decreasing events. The complement Gc is an increasing event, so
P(E∩G)=P(E)−P(E∩Gc)≤P(E)(1−P(Gc))=P(E)P(G).
(15)

The printed inclusion symbol here means non-strict inclusion: the PDF explicitly excludes a common member of the two set families. We use ⊆ throughout. Thus a cross-Sperner family pair need not consist of internal antichains; the restriction is between the two families.
Give the Boolean lattice the uniform probability measure, and write N=2n. Form the upward closure of a set family and downward closure of a set family of A:
U={S⊆[n]:some A∈A satisfies A⊆S},D={S⊆[n]:some A∈A satisfies S⊆A}.
(16)
These are respectively an increasing event and a decreasing event. We have A⊆U∩D, whereas the cross-Sperner family condition gives B⊆Uc∩Dc. Set u=P(U) and d=P(D). By negative correlation of increasing and decreasing events, first for U,D and then for Uc,Dc,
N∣A∣​≤P(U∩D)≤ud,N∣B∣​≤P(Uc∩Dc)≤(1−u)(1−d).
(17)
Apply the Cauchy-Schwarz inequality to the unit vectors (u​,1−u​) and (d​,1−d​). It yields
N∣A∣​​+N∣B∣​​≤ud​+(1−u)(1−d)​≤1.
(18)
Therefore the Cross-Sperner inequality is
∣A∣1/2+∣B∣1/2≤2n/2.​
(19)
If the printed inclusion symbol were read as strict inclusion while the explicit exclusion of common members were discarded, this conclusion would fail, for example with both families equal to the middle uniform set family when n=2. The PDF's parenthetical clause fixes the intended convention.

Choose disjoint subsets K1​,K2​⊆[n] of size k and let R=[n]∖(K1​∪K2​). The two-block extremisers for the cross-Sperner inequality are
A={S⊆[n]:K1​⊆S, S∩K2​=∅},B={S⊆[n]:K1​⊈S, S∩K2​=∅}.
(20)
For A∈A and B∈B, some point of K1​ belongs to A but not B, so A⊈B. Some point of K2​ belongs to B but not A, so B⊈A. Thus these form a cross-Sperner family pair.
An element of A fixes its intersections with both blocks and freely chooses its subset of R. An element of B chooses any proper subset of K1​, any nonempty subset of K2​, and any subset of R. Hence
∣A∣=2n−2k=2−2k2n,∣B∣=(2k−1)22n−2k=(1−2−k)22n.​
(21)
The hypotheses ensure that the blocks exist and both set families are nonempty, including when n=2k. Moreover,
∣A∣​+∣B∣​=(1+(2k−1))2(n−2k)/2=2n/2,
(22)
so this construction attains equality in the Cross-Sperner inequality.

Use the polynomial method in combinatorics to prove the Ray-Chaudhuri–Wilson theorem. For each Ai​ define an intersection polynomial over R,
pi​(x1​,…,xn​)=∏ℓ∈L​(∑a∈Ai​​xa​−ℓ).
(23)
At the characteristic vector of a set Aj​, the inner sum is ∣Ai​∩Aj​∣. Therefore
pi​(χAj​​)=0(i=j),pi​(χAi​​)=∏ℓ∈L​(r−ℓ)=0.
(24)
It follows that the restrictions of p1​,…,pm​ to the uniform layer of the Boolean cube
Ωr​={χA​:A⊆[n], ∣A∣=r}
(25)
have linear independence: evaluating any vanishing linear combination at each χAj​​ forces its jth coefficient to be zero.
Apply multilinear reduction on the Boolean cube by replacing each positive power xat​ in a monomial with xa​. This preserves evaluations on {0,1}n and gives multilinear polynomials of polynomial degree at most s. Counting all monomials of degrees up to s would give only ∑j=0s​(jn​), which is too weak. Instead use homogenisation on a uniform layer.
Because L has s distinct integers in {0,…,r−1}, we have s≤r. For T⊆[n] with ∣T∣=j≤s, write xT​=∏a∈T​xa​, with x∅​=1. On Ωr​,
xT​=(s−jr−j​)1​∑S⊇T∣S∣=s​​xS​.
(26)
Indeed, at χA​ both sides vanish if T⊈A; otherwise exactly (s−jr−j​) summands equal 1. The denominator is positive since j≤s≤r. Thus every monomial of degree at most s, restricted to Ωr​, lies in the span of the (sn​) degree-s monomials. This vector space consequently has dimension at most (sn​). The linear independence already proved now gives
m≤(sn​).​
(27)
No additional condition such as r+s≤n is needed: only the spanning upper bound is used, not independence of all degree-s monomials. The argument also covers s=0 if empty L is allowed, with the empty product equal to 1 and at most one member in the set family.
