Write X(t,a)=X(t;0,a) and A(t,x)=X(0;t,x). If u0​∈C1(Rd), the unique global classical solution is
u(t,x)=u0​(A(t,x)).​
(40)
It is C1, and the chain rule makes its value constant along every characteristic curve. The same calculation proves classical uniqueness. No boundedness of u0​ is needed for this classical statement.
For u0​∈L∞, a bounded weak solution on the positive half-line is defined by
∫0∞​∫Rd​u[φt​+divx​(Fφ)]dxdt+∫Rd​u0​(x)φ(0,x)dx=0
(41)
for every compactly supported C1 test function on [0,∞)×Rd. The analogous backward-time identity defines the solution on all real time. The udivF term is essential: this is transport, not the conservative equation ut​+div(Fu)=0.
The same inverse-flow formula defines the unique weak solution, with ∥u(t)∥∞​=∥u0​∥∞​, equality almost everywhere, and a representative continuous into L1 on each compact spatial set. For a direct uniqueness argument, change variables x=X(t,a) in the weak identity and put w(t,a)=u(t,X(t,a)). Using Jt​=(divF)(t,X)J gives
∫w∂t​(Jζ)dadt+∫u0​(a)ζ(0,a)da=0,
(42)
initially for C1 compactly supported ζ. Since J>0 and J,Jt​ are continuous on compact sets, approximation in the spatial parameter permits ζ=η/J: both ζ and ζt​ are uniformly approximable there, which are the only derivatives left in this identity. Hence ∫wηt​+∫u0​η(0)=0 and w=u0​ almost everywhere. This also verifies existence by reversing the argument, and avoids assuming second derivatives of the C1 field. Local L1 continuity follows by approximating u0​ by continuous functions on compact flow tubes.
This is the weak transport solution under characteristic coordinates. The weak-strong uniqueness principle says that a weak solution in the specified class agrees with a classical solution having the same data for as long as that classical solution exists. Here it holds globally in the bounded class whenever the classical initial data are also bounded.
