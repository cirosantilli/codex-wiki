Only times up to τ contribute to the cumulative incidence function for type B, because its cause-specific hazard vanishes afterwards. With q=θA​+θB​>0,
FB​(t)=∫0min(t,τ)​θB​e−qudu,
(50)
so
FB​(t)=θA​+θB​θB​​(1−e−(θA​+θB​)min(t,τ)).​
(51)
This increases before τ and then remains constant; it includes the protection from type B events produced by earlier type A events. If both intensities vanish, FB​=0; if θB​=0, it is also identically zero.
