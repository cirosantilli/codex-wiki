Fix the base convention L0​(X)=X. For a transitive set X, the relative constructible hierarchy is
L0​(X)=X,Lα+1​(X)=Def(Lα​(X)),Lλ​(X)=α<λ⋃​Lα​(X),L(X)=α∈Ord⋃​Lα​(X).​
(10)
Here the definable power set is
Def(A)={{u∈A:(A,∈)⊨φ(u,a)}:φ a first-order formula, a∈A<ω}.
(11)
The satisfaction for a set structure in this definition is a definable set-theoretic relation, obtained by finite syntax coding and recursion on a first-order formula. The transfinite recursion therefore defines a class in ZF.
Each level is a transitive set. For transitive A, every a∈A is a subset of A definable using the parameter a, so A⊆Def(A); also A∈Def(A) using the always-true first-order formula. Thus the levels increase and X∈L1​(X). Starting instead with X∪{X} is another common indexing convention, but it is not the convention used here. The relative universe need not satisfy axiom of choice: arbitrary X need not have an internally available well-order.
