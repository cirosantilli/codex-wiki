Suppose, towards a contradiction, that G∈M. Then D=P∖G is a ground-model set by axiom schema of separation. It is dense. If p∈/G, it already lies in D. If p∈G, atomless forcing order structure gives incompatible forcing conditions q,r≤p. Both cannot belong to the directed filter G, so at least one is a strengthening of p in D.
All compatibility and extension quantifiers range over the same ground-model set P, so this density argument is also valid internally in the transitive model M. Genericity requires G∩D=∅, contradicting the definition of D. Therefore a generic filter for an atomless order is new:
G∈/M.​
(37)
The assumption is essential: a forcing atom determines a ground-model generic filter. For an atom p, the conditions compatible with p form a generic filter Gp​∈M: two such conditions have strengthenings below p, which have a common strengthening by the atom property; every dense set has a member below p. In a general partial order, Gp​ need not be the principal filter above p.
