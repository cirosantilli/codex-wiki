The multiplication of a distribution by a smooth function is ⟨ψT,φ⟩=⟨T,ψφ⟩. If ψ is a Schwartz function, the Leibniz rule shows that φ↦ψφ is a continuous map S→S, so ψT is a tempered distribution. When both ψ and T are radial, ψ∘Rt=ψ, and
⟨(ψT)∘R,φ⟩=⟨T,ψ(φ∘Rt)⟩=⟨T,(ψφ)∘Rt⟩=⟨T,ψφ⟩.
(22)
Thus Multiplication by a radial Schwartz function preserves radial tempered distributions.
For the convolution of a tempered distribution with a Schwartz function, set
(T∗ψ)(x)=⟨Ty​,ψ(x−y)⟩.
(23)
Translations of ψ depend smoothly on x in the Schwartz space, so this is a smooth function with ∂α(T∗ψ)(x)=⟨Ty​,∂αψ(x−y)⟩. The bound for T by finitely many seminorms, together with 1+∣y∣≤(1+∣x∣)(1+∣x−y∣), proves
∣∂α(T∗ψ)(x)∣≤Cα​(1+∣x∣)m.
(24)
Thus the function also defines a tempered distribution. For a radial function ψ, put gx​(y)=ψ(x−y). Then ψ(Rx−y)=ψ(x−Rty)=gx​(Rty), so
(T∗ψ)(Rx)=⟨T,gx​∘Rt⟩=⟨T∘R,gx​⟩=(T∗ψ)(x).
(25)
Hence Convolution with a radial Schwartz function preserves radial tempered distributions.
Smoothing alone need not give a Schwartz function: for the constant tempered distribution T=1 and a Schwartz function with integral one, T∗ψ=1. The radial Schwartz approximation of tempered distributions therefore combines smoothing with a large-radius cutoff. Choose a nonnegative radial mollifier ρ∈Cc∞​, supported in the unit ball with integral one, and a radial cutoff function χ∈Cc∞​ equal to one on the unit ball. Put
ρε​(x)=ε−nρ(x/ε),χj​(x)=χ(x/j),fj​(x)=χj​(x)(T∗ρ1/j​)(x).​
(26)
Each fj​ is a smooth function of compact support, hence a Schwartz function, and the two invariance calculations above make it radial.
It remains to prove convergence, including the simultaneous changes of both scales. With ρˇ​(x)=ρ(−x), the distributional convolution pairing is
⟨fj​,φ⟩=⟨T,ρˇ​1/j​∗(χj​φ)⟩.
(27)
For every fixed m, the Leibniz rule, rapid decay outside the radius-j ball, and the chain rule for χ(x/j) give
qm​((χj​−1)φ)≤jCm​​qm+1​(φ).
(28)
Convolution by ρˇ​ε​ is uniformly bounded in qm​ for 0<ε≤1, because its shifts have size at most one. The mean value theorem applied to φ(x−y)−φ(x) similarly gives
qm​(ρˇ​ε​∗φ−φ)≤Cm​εqm+1​(φ).
(29)
Splitting the error into the convolved cutoff error and the approximate identity error proves
qm​(ρˇ​1/j​∗(χj​φ)−φ)≤jCm′​​qm+1​(φ).
(30)
If ∣⟨T,θ⟩∣≤Cqm​(θ), this yields
∣⟨fj​−T,φ⟩∣≤jC′′​qm+1​(φ).
(31)
