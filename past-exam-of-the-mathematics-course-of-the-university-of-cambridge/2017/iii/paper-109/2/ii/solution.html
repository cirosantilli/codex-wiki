A bounded-size transversal kernel gives a finite intersection witness for cross-intersecting families, even when the two set families are infinite. We first prove the kernel statement: for any set family F whose members have size at most r, and any integer s≥0, there is a finite subset F0​⊆F with
∣F0​∣≤M(r,s):=∑j=0s​rj
(9)
such that every set H of size at most s is a hitting set for F0​ if and only if it is a hitting set for F.
Use mathematical induction on s. If F is empty, take F0​=∅. For s=0 and nonempty F, choose any one member: the only possible H is empty and is a hitting set for neither family. For the induction step, choose A0​∈F. For each x∈A0​ apply the inductive statement to
Fx​={A∈F:x∈/A}
(10)
with parameter s−1, obtaining Fx,0​. Put F0​={A0​}∪⋃x∈A0​​Fx,0​. Its size is at most 1+rM(r,s−1)=M(r,s). If H is a hitting set for F0​, choose x∈H∩A0​. Every member of Fx,0​ avoids x, so H∖{x} is a hitting set for Fx,0​ and hence for Fx​. Members of F containing x already meet H. Thus H is a hitting set for all of F. The reverse implication follows from inclusion. If A0​=∅, no H is a hitting set for either family, so the implication remains valid. This finite branching proof never assumes F is finite.
Apply the kernel statement with F=A and define X=⋃A∈F0​​A. For each B∈B, the cross-intersecting family condition ensures that B∩X meets every member of F0​, since these members lie inside X. As ∣B∩X∣≤s, it therefore meets every A∈A. We obtain
A∩B∩X=∅for every A∈A, B∈B,∣X∣≤rj=0∑s​rj.​
(11)
In particular, a positive-integer-valued choice valid whether or not 0∈N is
f(r,s)=1+rj=0∑s​rj.​
(12)
Here the constant term of the sum is 1, including when r=0. If either set family is empty, X=∅ suffices. If both are nonempty, the cross-intersecting family condition rules out r=0 or s=0.
