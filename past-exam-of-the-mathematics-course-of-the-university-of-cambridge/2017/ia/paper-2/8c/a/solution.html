For real initial data, separation of variables gives
z(t)=1−z0​tz0​​.​
(33)
This includes z0​=0, whose solution is identically zero. Every other real z0​ has a pole at t=1/z0​, so only z0​=0 gives a finite solution on the whole real line. If complex-valued initial data are allowed, a nonreal z0​ has no real-time pole; the whole-real-line conclusion here uses the usual real-valued differential-equation convention.
Along a characteristic curve y=u+ax, the chain rule gives df(x,u+ax)/dx=fx​+afy​. For the homogeneous transport equation this is zero, so f(x,y)=F(y−ax). For the nonlinear equation, the same method of characteristics reduces the problem to df/dx=f2, with initial value g(u). Therefore
f(x,y)=1−xg(y−ax)g(y−ax)​.​
(34)
For differentiable real g, this is the classical solution wherever its denominator is nonzero, on the characteristic intervals containing the initial line. If g(u)=0 for some u, that characteristic blows up at x=1/g(u), y=u+a/g(u). Thus the only real-valued solution bounded on all of R2 has g≡0, giving f≡0.
