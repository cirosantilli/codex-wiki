For each positive integer n, the positive elements of An​ form an infinite set, and the preceding increasing enumeration gives a bijection fn​:N→An​ on these positive elements. The positive integers have a unique decomposition 10n−1q with 10∤q, so these sets are disjoint and exhaust the positive integers.
The printed natural numbers include 0. The trailing-zero count of the representation of 0 is not needed: shift the positive partition down by one and put
g(i,j)=fi+1​(j)−1,i,j∈N.​
(22)
Uniqueness of the trailing-zero count proves the injective function property, and the decomposition of N+1 proves the surjective function property. An explicit decimal trailing-zero pairing function, using the increasing enumeration from the previous part, is
g(i,j)=10i(j+1+⌊9j​⌋)−1.​
(23)
Indeed, the bracket enumerates 1,2,…,9,11,12,…, exactly the positive integers not divisible by 10. This handles both the positive index n and the element 0 without silently changing the PDF's convention.
To enumerate the rational numbers, first enumerate the integers by e(0)=0, e(2r−1)=r, e(2r)=−r for r≥1. The function (i,j)↦e(i)/(j+1) maps N2 onto Q, and composing with g−1 gives a surjective function from N. Choosing the first index representing each rational number gives an injective function Q→N. Thus Q is countably infinite; its infinitude follows because it contains all integers.
