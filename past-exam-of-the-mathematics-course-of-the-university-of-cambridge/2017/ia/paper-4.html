For a Pythagorean triple, each square number is 0 or 1 modulo 3. If neither x nor y were divisible by 3, modular congruence would give z2≡1+1≡2(mod3), impossible for a square number. Thus at least one of x,y is divisible by 3; both can be divisible, as in (9,12,15).
An odd number has square number congruent to 1 modulo 4, whereas an even number has square number congruent to 0. If both x and y were odd numbers, their sum of square numbers would again be 2 modulo 4, which no square number can be. Hence x and y cannot both be odd. They can both be even; the conclusion does not require the Pythagorean triple to be primitive.

The Fermat-Euler theorem states that for an integer a and a positive integer n with gcd(a,n)=1,
aφ(n)≡1(modn),​
(12)
where the Euler totient function φ(n) counts the residue classes coprime to n. For n≥2, choose a reduced residue system r1​,…,rφ(n)​. Multiplication by the unit modulo n a preserves coprimality and is injective on these residue classes: ari​≡arj​(modn) implies ri​≡rj​(modn), because a has a multiplicative inverse modulo n. It therefore permutes the reduced residue system, giving
aφ(n)∏i​ri​≡∏i​ri​(modn).
(13)
The product is also a unit modulo n, so it can be cancelled. This proves the Fermat-Euler theorem. For n=1 every modular congruence is automatic; one may use φ(1)=1.
For a prime number p, the Euler totient function has value φ(p)=p−1. Thus ap−1≡1(modp) whenever p∤a. Multiplying by a, and treating p∣a separately, gives the all-integer version of Fermat's little theorem:
ap≡a(modp)for every integer a.​
(14)
Finally, Wilson theorem states that for every prime number p, (p−1)!≡−1(modp)​. Its converse is also true: an integer n>1 is prime exactly when (n−1)!≡−1(modn). For the converse, any proper divisor 1<d<n would divide both (n−1)! and n, contradicting that congruence.

A set A is a countable set if there exists an injective function A→N, with N={0,1,2,…}. Equivalently, it is a finite set or has a bijection with N. An infinite countable set is called a countably infinite set.
The empty set is included: the empty function into N is injective. This convention distinguishes “countable” from “countably infinite” and will also cover the finite threshold sets in the last part.

Use the well-order of the natural numbers to list A in increasing order. Define recursively
f(0)=minA,f(n+1)=min(A∖{f(0),…,f(n)}).

The remaining set is nonempty because A is infinite and only a finite set has been removed. Each chosen value is larger than the preceding one, so f is an injective function.

A=⋃n=1∞​A(n).

The rotating-frame derivative formula is (dA/dt)S​=(dA/dt)S′​+ω×A. Applying it twice to the position vector, with constant angular velocity, gives
