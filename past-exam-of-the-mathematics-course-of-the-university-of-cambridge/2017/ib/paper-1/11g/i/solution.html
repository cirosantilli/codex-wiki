A real function on a metric space is uniformly continuous if for every ε>0 there is a δ>0 such that, simultaneously for all x,y, d(x,y)<δ implies ∣f(x)−f(y)∣<ε. For a continuous function on a finite closed interval [a,b], suppose this fails. Then there are ε0​>0 and pairs xn​,yn​ with ∣xn​−yn​∣<1/n but ∣f(xn​)−f(yn​)∣≥ε0​. By compactness, some subsequence xnj​​ converges to x∈[a,b]; then ynj​​→x too. Continuity contradicts the image separation. This proves the Heine-Cantor theorem in this setting. Boundedness of the interval matters: x2 on [0,∞) is a counterexample if “closed interval” includes unbounded intervals.
A function is Lipschitz continuous if some finite K≥0 satisfies ∣f(x)−f(y)∣≤Kd(x,y) for every pair. Choosing δ=ε/(K+1) proves uniform continuity.
The first assertion is false. Take f(x)=sin(x2), which is bounded and continuous, and
xn​=2πn+π/2​,yn​=2πn+3π/2​.
