Use the convention that the transitive closure of x is the least transitive set containing x as a subset. Define x0​=x and xn+1​=⋃xn​. For each natural number n, a finite sequence of length n+1 with these properties exists by induction, and is unique because each next entry is the uniquely determined union of the previous entry. Thus the relation sending n to its last entry is a definable function-class, not just a putative recursive specification. The Axiom schema of replacement applied to ω gives the set of all xn​. The Axiom of union then gives
TC(x)=n<ω⋃​xn​.​
(47)
If a∈xn​ and b∈a, then b∈xn+1​, so this set is transitive. It contains x=x0​, and any transitive set containing x contains all xn​ by induction; hence it is least. The convention requiring x itself as an element instead uses TC({x}).
The Axiom of foundation says every nonempty set A has an element a∈A with a∩A=∅. Epsilon induction says that for every formula ϕ,
[∀x((∀y∈xϕ(y))⇒ϕ(x))]⇒∀xϕ(x).
(48)
To derive induction from Foundation, if ϕ(x) fails, form by axiom schema of separation the nonempty set of counterexamples in TC({x}). A Foundation-minimal counterexample has every member satisfying ϕ, by transitivity, contradicting the inductive hypothesis. Conversely, if a nonempty set A has no Foundation-minimal member, every x∈A has a member in A. The formula x∈/A is then progressive: if all members of x are outside A, x must also be outside A. Epsilon induction makes A empty, a contradiction. Thus the two principles are equivalent given the other axioms.
The epsilon-recursion theorem states that for a definable class operation G assigning a unique set to each set-indexed function, there is a unique definable function-class F such that F(x)=G(F∣x​) for every set x. A version with explicit x in the argument is equivalent. Foundation gives well-foundedness and Replacement makes each restriction set-sized. Its ordinal restriction gives transfinite recursion and constructs the printed Cα​.
Here “countable” means at most countable, including finite sets and the empty set. By transfinite induction each Cα​ is transitive, each of its elements is countable, and Cα​⊆Cα+1​. At a successor this follows because a member of Cα​ is a countable subset of Cα​; at a limit use the increasing union. Let ω1​ be the first uncountable ordinal. Every countable subset of Cω1​​ lies in some Cα​ with α<ω1​, since countably many countable ordinal bounds have a countable supremum. It therefore belongs to Cα+1​. Consequently
Cω1​+1​=Cω1​​.​
(49)
There is no earlier stabilization: for every countable ordinal α, induction gives α⊆Cα​, so α∈Cα+1​, while Cα​⊆Vα​ excludes α by its rank. Thus ω1​ is the first such stage. The fixed set is the set of hereditarily countable sets.
