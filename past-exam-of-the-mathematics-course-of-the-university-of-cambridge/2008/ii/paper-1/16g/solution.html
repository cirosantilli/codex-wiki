A well-order is a linearly ordered set in which every nonempty subset has a least element. First note that a well-order cannot be isomorphic to a proper initial segment of itself: the least element moved by such an isomorphism would have exactly the same predecessor set on each side, forcing it to be fixed. The same least-disagreement argument makes an isomorphism between initial segments unique.
Match a∈A to b∈B exactly when their strict predecessor sets are order-isomorphic. The preceding observation makes each match unique. Matches preserve order and fill initial segments on both sides, since restricting an isomorphism matches every earlier element. If both sides had an unmatched element, take the least unmatched a and b. Their predecessor sets would be exactly the already matched segments, so they too would match, a contradiction. Therefore the matching exhausts at least one well-order and gives an isomorphism of that whole set onto an initial segment of the other. Uniqueness follows from the same predecessor-set argument. The whole set is allowed as an initial segment; this includes equal order types.
For ordinal division, let β>0 and choose
γ=sup{η:βη≤α}.
(39)
This supremum is a set ordinal because βη≥η bounds the displayed ordinals by α. Strict increase and continuity of multiplication in the right argument imply βγ≤α<β(γ+1). Take the order type δ of the remaining tail of α after its initial segment of type βγ. Then α=βγ+δ; if δ≥β it would contradict the strict upper inequality. Thus
α=βγ+δ,δ<β.​
(40)
The half-open intervals [βη,β(η+1)) are disjoint, so γ is unique, and uniqueness of the tail gives uniqueness of δ. This is left-divisor ordinal division: the order of multiplication cannot be interchanged.
Apply it with β=ω. The remainder is finite. A nonzero remainder makes ωγ+δ a successor, while a nonzero ωγ is a limit: for successor γ it ends in a full block of type ω, and for limit γ it is the supremum of the earlier blocks. Consequently
