Let d=gcd(a,m). If the linear congruence ar≡b(modm) holds, then b=ar−ms for some integer s, so the greatest common divisor d divides b. Conversely, Bézout's identity gives integers u,v with au+mv=d. If b=dj, multiply this identity by j to obtain a(uj)≡b(modm). Hence
ar≡b(modm) has a solution⟺d∣b.​
(13)
For the number of solutions, write a=da′, m=dm′ and b=db′. The linear congruence becomes a′r≡b′(modm′), where a′,m′ are coprime integers. Multiplication by a′ is invertible modulo m′ by Bézout's identity, so the solutions form one residue class r≡r0​(modm′). Modulo m=dm′, these are exactly
r0​, r0​+m′,…,r0​+(d−1)m′.​
(14)
They are distinct: if two have the same residue class modulo m, then dm′ divides (j−ℓ)m′, forcing d∣j−ℓ; with 0≤j,ℓ<d, this forces j=ℓ. Every other solution differs from r0​ by a multiple of m′, so these exhaust the d solutions.
Finally,
b(m/d)≡0(modm)⟺dm′∣bm′⟺d∣b.
(15)
Combining this with the existence criterion gives the requested equivalent modular congruence.
