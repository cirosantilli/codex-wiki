Past exam of the mathematics course of the University of Cambridge / 2008 / iii / Paper 38 / 5 / Solution

Use a complete directed graph on n≥3 cities, with integral arc costs cij​ and a threshold L. A symmetric cost matrix also represents the undirected travelling salesman problem by orienting a tour. Let the binary variable xij​ indicate that city j follows city i, and forbid self-arcs. The decision integer programming formulation asks whether the following system has a solution:
xij​∈{0,1}(i=j),j=i∑​xij​=1(i=1,…,n),i=j∑​xij​=1(j=1,…,n),i,j∈Si=j​∑​xij​≤∣S∣−1(∅=S⊊{1,…,n}),i=j∑​cij​xij​≤L.​
(27)
The in-degree and out-degree equations make the selected arcs a cycle cover of a directed graph. Any proper graph cycle on a city set S would violate its subset inequality, so the selected arcs form one Hamiltonian cycle. Conversely, a Hamiltonian cycle obeys every inequality: a proper subset cannot contain all the successor arcs of its graph vertices. Thus the binary feasibility system is equivalent to the decision travelling salesman problem. The subset formulation has exponentially many inequalities, which is harmless for this formulation; verifying a proposed tour does not require listing them.
To call this decision problem NP-complete means two separate things. It belongs to NP: a yes-instance has a polynomial-length certificate in computational complexity, namely the cyclic ordering of the cities, and a deterministic algorithm checks distinct visits, the return to the start, and the total cost in polynomial time in the binary input length. It is also NP-hard: every decision problem in NP has a polynomial-time many-one reduction to it, preserving yes and no answers. This is a statement about worst-case computation on finite encodings, not a proof that every individual tour is hard to find or that no polynomial algorithm exists; that last conclusion would require P=NP.
For the strict-threshold decision Max-TSP, choose an integer M≥maxi=j​cij​ and replace each arc cost by cij′​=M−cij​≥0. Every tour uses exactly n arcs, so
C′=nM−C,C≤L ⟺ C′≥nM−L ⟺ C′>nM−L−1.
(28)
Set the new threshold to L′=nM−L−1. Its encoding length, the transformed matrix's encoding length and the computation time are all polynomial in the original input length. If thresholds are required to be nonnegative, take M≥max(0,maxcij​,L+1); the same identity works. Symmetry of costs is preserved. This is a polynomial-time many-one reduction from decision travelling salesman problem to decision Max-TSP, so the latter is NP-hard. A tour is again a polynomially verifiable certificate in computational complexity, now checking strict excess over L′, so
decision Max-TSP is NP-complete.​
(29)
For the approximation algorithm, use the standard nonnegative-length setting on a complete graph; no triangle inequality is required. Solve the maximum-weight assignment problem with diagonal assignments forbidden, for example by applying the Hungarian algorithm to the negative weights. The resulting cycle cover of a directed graph has weight W with W≥OPT, since every tour is an allowed assignment.
If it already has a single graph cycle, it is an optimal tour. Otherwise remove a least-weight arc from each graph cycle. A graph cycle of r≥2 arcs and weight Wr​≥0 loses at most Wr​/r≤Wr​/2. The remaining arcs form vertex-disjoint graph paths covering all cities. Join the endpoint of each graph path to the start of the next, cyclically. The required arcs exist by completeness, and their nonnegative weights cannot diminish the retained weight. The resulting single Hamiltonian cycle therefore satisfies
ALG≥2W​≥2OPT​.​
(30)
The Hungarian algorithm takes O(n3) arithmetic operations, and finding the graph cycles, cutting them and patching the graph paths takes O(n) further operations. For rational or integer weights these operations have polynomial encoding length, giving polynomial time. With symmetric costs, the same directed construction is a valid undirected tour after forgetting its orientation. This is the cycle-cover patching half-approximation for Max-TSP.
Nonnegativity is essential to this multiplicative guarantee. If arbitrary signed weights were allowed, giving every arc cost −1 would make every tour have weight −n, while half the optimum is −n/2. No tour could achieve the requested bound. Thus “length” has its usual nonnegative meaning in the approximation assertion.
