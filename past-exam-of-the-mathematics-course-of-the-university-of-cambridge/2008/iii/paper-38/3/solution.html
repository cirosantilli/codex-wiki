In a minimum-cost flow problem, a directed graph has arc flows fij​, unit costs cij​, lower and upper capacities ℓij​,uij​, and net supplies bi​ summing to zero. The linear program minimizes ∑ij​cij​fij​ subject to the flow balances ∑j​fij​−∑j​fji​=bi​ and ℓij​≤fij​≤uij​.
Give each graph vertex a network dual potential πi​. With the outgoing-minus-incoming oriented incidence matrix B, the optimization Lagrangian is
L(f,π)=cTf+πT(b−Bf)=πTb+∑ij​rij​fij​,rij​=cij​−πi​+πj​.
(18)
Minimizing over the capacity intervals is separable. A candidate feasible flow minimizes this optimization Lagrangian if it takes its lower bound whenever the network reduced cost is positive, its upper bound whenever that network reduced cost is negative, and any allowed value when that network reduced cost is zero. Equivalently, for arcs with distinct lower and upper bounds,
fij​=ℓij​⇒rij​≥0,ℓij​<fij​<uij​⇒rij​=0,fij​=uij​⇒rij​≤0.
(19)
For every other feasible flow g, these conditions give cTf=L(f,π)≤L(g,π)=cTg. This proves the Lagrangian sufficiency theorem certificate, rather than merely stating the capacitated flow optimality conditions.
Put t=f23​. The four flow balances determine
(f12​,f23​,f34​,f41​)=(t+3,t,t+1,t+2).
(20)
Intersecting the four capacity intervals gives 2≤t≤4. In particular,
f(2)=(5,2,3,4)​
(21)
is a feasible flow. Write C=c12​+c23​+c34​+c41​. Its cost along the feasible interval is
cTf(t)=Ct+3c12​+c34​+2c41​.
(22)
Hence f(2) is optimal precisely when C≥0. A network dual potential certificate is
π1​=0,π2​=−c12​,π3​=c41​+c34​,π4​=c41​.
(23)
The three interior arcs have zero network reduced costs and r23​=C, which has the required nonnegative sign at its lower capacity.
For the network simplex algorithm, start with the network simplex tree basis consisting of arcs 12,34,41, and fix nonbasic arc 23 at its lower bound 2. These are exactly the potentials just found. If C≥0, no improving pivot is needed. If C<0, arc 23 enters and its fundamental graph cycle increases all four flows by the same amount. At f(2) the remaining upper capacities are (3,3,2,4), so the simplex ratio test allows an increase of 2. Arc 34 reaches its upper bound and leaves the tree. The new network simplex tree basis has arcs 12,23,41, with potentials
π1​=0,π2​=−c12​,π3​=−c12​−c23​,π4​=c41​.
(24)
Now only the nonbasic arc 34 has a possibly nonzero network reduced cost, namely r34​=C<0. It is at its upper bound, so the sign is optimal. Thus for all real costs the complete answer is
⎩⎨⎧​f(2)=(5,2,3,4),f(t),2≤t≤4,f(4)=(7,4,5,6),​C>0,C=0,C<0.​​
(25)
When C=0, both endpoint basic feasible solutions and every intermediate feasible flow have the same cost.

There are eight tree/bound basic representations, seven distinct basic flow vectors, and two basic feasible solutions. The distinction in the first count matters: the upper bounds on 12 and 23 both give the identical flow (8,5,6,7) at t=5. Thus if “basic solutions” counts vectors rather than basis representations, the answer to (i) is seven; the frequently used count of basis/bound choices is eight. The answer to (ii) is unambiguously two, since only t=2,4 satisfy all capacities.
