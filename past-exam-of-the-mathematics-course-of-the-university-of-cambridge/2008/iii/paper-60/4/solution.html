The n-qubit Pauli group is
Gn​={irP1​⊗⋯⊗Pn​:r∈{0,1,2,3}, Pj​∈{I,X,Y,Z}}.
(30)
A stabilizer group S is an abelian subgroup of Gn​ excluding −I. Its associated stabilizer code is the common positive eigenspace
XS​={∣ψ⟩:s∣ψ⟩=∣ψ⟩ for every s∈S}.​
(31)
The exclusion of −I is necessary for a nonzero code, since no nonzero vector has eigenvalue +1 under −I.
Every s∈S is a signed Hermitian tensor product of Pauli matrices. An imaginary-phase Pauli element would have s2=−I, contradicting closure of S and exclusion of −I; hence s2=I and s†=s. If s=I, it cannot be a nontrivial scalar Pauli element, and at least one of its local factors is X,Y or Z. Each of these has trace zero. Using Tr(A⊗B)=Tr(A)Tr(B) gives Trs=0.
The spectral theorem for Hermitian operators and s2=I show that all eigenvalues are +1 or −1. If their multiplicities are m+​ and m−​, then
m+​+m−​=2n,m+​−m−​=Trs=0.
(32)
Thus the balanced spectrum of a nonidentity stabilizer is
m+​=m−​=2n−1.​
(33)
This concerns a nonidentity stabilizer acting on the entire physical space; on the code every stabilizer acts with eigenvalue +1.
Because all elements commute and square to I, S is a vector space over F2​ under multiplication. Its independent stabilizer generators g1​,…,gr​ satisfy that no nonempty product is I; all 2r products are distinct. The stabilizer-projector formula is
PS​=∣S∣1​∑s∈S​s=∏j=1r​2I+gj​​.
(34)
To verify it, group multiplication gives PS2​=PS​, Hermiticity gives PS†​=PS​, and sPS​=PS​ for every s∈S. Conversely every code vector is fixed by this average, so its range is exactly XS​. All nonidentity stabilizers have trace zero by the preceding proof. Therefore
dimXS​=TrPS​=∣S∣2n​=2n−r.
(35)
For a code of dimension 2k, the number of independent generators is consequently r=n−k​. One can list additional redundant generators, but an independent generating set has exactly this size.
For a correctable Pauli error Eα​, define the syndrome bit sj​(α) to be zero when Eα​ commutes with gj​ and one when it anticommutes. On an encoded state,
gj​Eα​∣ψ⟩=(−1)sj​(α)Eα​∣ψ⟩.
(36)
Measure the commuting stabilizer generators; their eigenvalues reveal the error syndrome without revealing logical amplitudes. In a nondegenerate quantum code, the distinct specified correctable errors have orthogonal images of the code and distinct syndromes. A syndrome therefore identifies the error representative, and applying the inverse Pauli operator Eα†​ restores the encoded state.
If an actual error operator is a coherent linear combination of the specified errors, its state is a sum of these orthogonal syndrome components. Syndrome measurement selects one component, followed by the same inverse operation. The linearity of coherent quantum error correction ensures the logical state is recovered in every outcome. The same procedure handles noise Kraus operators in that error span; it does not require a probabilistic Pauli-noise assumption.
A Pauli error commuting with every stabilizer has the all-zero syndrome and preserves the code space. If it is a stabilizer up to global phase, this silent action is harmless. If it lies in the centralizer of a stabilizer group but is not a stabilizer up to phase, it acts as a nontrivial logical operator, and syndrome measurements cannot detect it. More generally, a non-scalar component PS​EPS​ of an error is an undetectable logical action. This distinguishes harmful undetected errors from scalar actions that satisfy quantum error detection algebraically.
The three-qubit bit-flip repetition code has basis ∣000⟩,∣111⟩ and generators
g1​=Z1​Z2​,g2​=Z2​Z3​.​
(37)
A single phase flip Z1​ commutes with both and has zero syndrome, but
Z1​(α∣000⟩+β∣111⟩)=α∣000⟩−β∣111⟩.
(38)
It is a nontrivial logical phase operation. In particular, PS​Z1​PS​ is not scalar, so the error set {I,Z1​} violates the Knill--Laflamme condition and cannot be corrected. Thus the code corrects single bit flips but not single phase flips; its distance against arbitrary quantum errors is one.
