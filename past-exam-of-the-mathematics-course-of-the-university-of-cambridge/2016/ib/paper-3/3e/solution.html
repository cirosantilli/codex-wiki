The convention in this question counts a point whenever every open neighbourhood meets A, without excluding the point itself. These are adherent points, whose set is the closure A; they differ from limit points under the convention that requires a different point of A in each neighbourhood.
If A is a closed set and x∈/A, the open set X∖A is a neighbourhood of x disjoint from A. Thus every adherent point lies in A. Conversely, if every adherent point lies in A, each x∈/A has an open neighbourhood disjoint from A. Their union is X∖A, which is open. Hence A is closed exactly when it contains all the points specified in the question.
The interior of a set and closure are
Int(A)=⋃{U:U open, U⊆A},A=⋂{F:F closed, A⊆F}.​
(7)
The neighbourhood description of the closure follows because failure to be adherent is equivalent to lying in an open set disjoint from A.
For closure of a connected set, suppose A=U⊔V were a separation into two nonempty relatively open sets. Their intersections with the connected subset A would separate A unless one intersection were empty. Say A⊆U. Choose v∈V and an open set O⊆X with v∈O and O∩A⊆V. Since v∈A, the set O meets A, contradicting A⊆U. Thus the closure of a connected set is connected. The empty-set case holds directly.
