i OurBigBook.com
Use the synchronous group multiplier automata belonging to the automatic structure for a group. Write u⊗v for the padded convolution of words: the shorter tape is completed with a symbol # outside the alphabet, and reading stops when both words over an alphabet have ended. Our convention is
Mx​ accepts u⊗v⟺u,v∈L and ux=v.
(1)
Let N≥1 be at least the number of states of each of these finite-state automata, including Mε​.
Choose a shortest representative v∈L of g. In the first orientation, Mx​ accepts w⊗v; in the other orientation it accepts v⊗w. If ∣v∣>∣w∣+N, the accepting run has more than N transitions after the tape containing w has ended. Two states in that suffix coincide. Delete the intervening nonempty loop. Every deleted column contains # on the fixed tape and a genuine letter on the tape containing v, so the resulting input remains a valid padded convolution of words. The group multiplier automaton still accepts, giving a shorter representative of the same g. This contradicts minimality. Thus a representative can always be chosen with
∣v∣≤∣w∣+N.​
(2)
This argument does not require a symmetric alphabet: the second orientation uses the same Mx​ with its tapes interchanged in the input, rather than a presumed Mx−1​.

Apply the same pumping of a group multiplier automaton to the accepted pair containing the given representative u. Since ∣u∣>∣w∣+N, there is a nonempty loop entirely after the tape containing w has ended. Write u=pqr, with q=ε the letters read during this loop. Repeating the loop any number of times leaves the other tape equal to w, and the group multiplier automaton accepts the resulting padded convolution of words. Consequently
pqkr∈L,pqkr​=g(k≥0).​
(3)
These words over an alphabet have distinct lengths because ∣q∣>0. Hence there are infinitely many representatives of g in L. No uniqueness of representatives was assumed in either part.

b OurBigBook.com
Fix the first tape of the group multiplier automaton Mx​ to be u=a1​⋯am​. Construct its possible runs by dynamic programming, one column at a time. A record consists of a state and a flag indicating whether the output tape has ended. At column i≤m, the first symbol is ai​ and the second symbol may be any letter of the alphabet, or #; after the second tape first uses # it must continue to use #. At later columns the first symbol is #, and an additional column must have a genuine letter on the second tape. Never add a (#,#) column.
Keep one predecessor record and its output symbol for each reachable state-and-flag pair in each layer. Two runs reaching the same record have exactly the same possible future completions, so this merging loses no accepting output. The merged dead state of a finite automaton can be discarded. At each layer i≥m, test whether a reached state is accepting; the initial layer is included when m=0. Upon success, follow predecessor records backwards and omit padding symbols to recover v.
The automatic structure for a group supplies a representative in L of ux, so an accepted padded convolution of words exists and this search terminates. The output is the required representative:
v∈L,v=ux.​
(4)
The search uses only the finite transition table; it does not presuppose a solution to the word problem for a group.

c OurBigBook.com
Part (a)(i), applied to w=u and g=ux, guarantees an accepted output of length at most m+N. Its padded convolution of words has at most m+N columns. Thus the dynamic programming search in part (b) reaches an accepting layer by this bound.
Each layer has at most twice the fixed number of states of Mx​, and each record has at most ∣A∣+1 outgoing choices. These are constants for the fixed automatic structure for a group. Storing a pointer and a symbol takes constant time; copying whole partial output strings at every step would unnecessarily spoil this bound. Reconstruction also takes at most m+N steps. Therefore automatic multiplication has linear time and bounded length increase:
∣v∣≤∣u∣+N,T(u,x)=O(∣u∣+1).​
(5)
For nonempty inputs this is the requested O(∣u∣) time complexity. The additive 1 merely includes the constant work on the empty word.

The regular language L is nonempty because it represents every element of the group. Find any accepted word t=a1​⋯ak​ using Breadth-first search in its finite-state automaton. If t is the empty word, it already represents the identity.
Otherwise begin with t∈L and repeatedly apply the linear-time multiplication in an automatic structure to the letters
ak−1​,ak−1−1​,…,a1−1​.
(6)
These letters belong to A by symmetry of the alphabet. All intermediate words lie in L, and the final word γ represents
tak−1​⋯a1−1​=1.
(7)
Hence an identity representative can be constructed effectively:
γ∈L,γ​=1.​
(8)
This is a finite preliminary computation depending only on the fixed automatic structure for a group; it uses no test for whether an arbitrary word represents the identity.

Write the input word over an alphabet as w=a1​⋯an​. Starting with z0​=γ, obtain zi​ from zi−1​ by linear-time multiplication in an automatic structure with ai​. Mathematical induction gives
zi​∈L,zi​​=a1​⋯ai​,∣zi​∣≤∣γ∣+iN.
(9)
The time complexity of step i is at most a constant times ∣γ∣+(i−1)N+1. Summing the costs gives
T(w)≤C∑i=1n​(∣γ∣+(i−1)N+1)=C(n(∣γ∣+1)+2Nn(n−1)​).
(10)
The automatic structure for a group, N and γ are fixed, so the required representative is
z=zn​,z=w,∣z∣≤∣γ∣+nN,T(w)=O(n2) (n≥1).​
(11)
For the empty word, return γ in constant time.

Construct z as above, and run the equality group multiplier automaton Mε​ on z⊗γ. Both inputs belong to L, so
Mε​ accepts z⊗γ⟺z=γ​⟺w=1.
(12)
The final finite-state automaton run takes O(max(∣z∣,∣γ∣)+1)=O(n+1) time. The word problem for a group is therefore decidable in quadratic time:
Tword​(w)=O(∣w∣2)(∣w∣≥1).​
(13)
The empty word is accepted immediately. Comparing z and γ as literal strings would be incorrect, since an automatic structure for a group need not give unique representatives.

For a finite position s∈A<ω, let [s] be the cylinder set of infinite plays extending s. Because the factors have the discrete topology, these cylinder sets form a basis for the product topology. Put
D={s:[s]⊆G}.
(14)
Membership in D means that I has already secured the outcome, regardless of future moves. Since G is an open set, a play belongs to G exactly when one of its prefixes belongs to D.
Build the winning-position attractor in an infinite game by transfinite recursion. Start with W0​=D, use unions at limit ordinals, and set
Wα+1​=D∪{s:∣s∣ is even and ∃a∈A (sa∈Wα​)}∪{s:∣s∣ is odd and ∀a∈A (sa∈Wα​)}.
(15)
This sequence is increasing: the defining operation is order-preserving, and W0​⊆W1​. It stabilizes at some ordinal. Indeed, if it strictly increased at every successor stage below the successor cardinal number of ∣A<ω∣, choosing one newly added position per stage would inject that larger cardinal into A<ω. Denote the stable set by W. This constructs the needed fixed point directly, without an appeal to an unstated fixed-point theorem.
Every position in W has a least entry ordinal, its rank. Rank zero means membership in D. A positive rank is a successor α+1: at an I-position some extension belongs to Wα​, while at a II-position every extension does. If the empty word belongs to W, I always chooses an extension of smaller rank until D is reached. II's choices also decrease rank before that happens. There is no infinite strictly decreasing sequence of ordinals, so some finite prefix lies in D. This is a winning strategy in an infinite game for I.
If the empty word is outside W, the fixed point equation says that every extension of an I-position outside W is still outside W, and that a II-position outside W has at least one extension outside W. II chooses such an extension. Every resulting prefix avoids D, hence the whole play avoids G by openness. This is a winning strategy in an infinite game for II.
The choices can be made simultaneously by fixing a well-order of A, as allowed by the usual axiom of choice. The argument does not assume that A is countable. Every such open game is determined:
ε∈W⇒I wins;ε∈/W⇒II wins.​
(16)

Rice theorem: every nontrivial extensional property of programs computing partial computable functions has an undecidable index set. More precisely, take an acceptable effective enumeration (φe​) of the unary partial computable functions. If P contains some but not all of these functions, then
IP​={e:φe​∈P} is not computable.​
(17)
“Extensional” means that equality of partial functions, including their domains, preserves membership; no syntactic restriction on program codes is being considered.
We use two standard facts, stated explicitly. The diagonal halting set K={e:φe​(e)↓} is undecidable. For the associated acceptable enumerations φe(r)​ of r-ary partial computable functions, with φe​=φe(1)​, the S-m-n theorem says that for every m,n≥1 there is a total computable function snm​ such that
φsnm​(e,x1​,…,xm​)(n)​(y1​,…,yn​)≃φe(m+n)​(x1​,…,xm​,y1​,…,yn​),
(18)
where ≃ means equality of defined values and equality of undefinedness. Thus fixed parameters in a program can be compiled into its index effectively.
Let ⊥ be the nowhere-defined partial computable function. Choose a partial computable function h whose membership in P is opposite to that of ⊥; this is possible by nontriviality. For each e, construct the program
ψe​(y):first simulate φe​(e);if it halts, simulate h(y) and return its value.
(19)
This is a uniform partial computation. Take an index d for the binary partial computable function (e,y)↦ψe​(y). The S-m-n theorem gives the total computable function q(e)=s11​(d,e) with φq(e)​=ψe​. Crucially,
ψe​={h,⊥,​e∈K,e∈/K.​
(20)
Even when h(y) itself is undefined, the equality of partial functions remains correct. If ⊥∈/P, this gives a many-one reduction of K to IP​; if ⊥∈P, it gives a many-one reduction of K to the complement of IP​. A decision procedure for IP​ would therefore decide K in either case, a contradiction.
The equivalent language formulation says that every nontrivial property of computably enumerable languages depending only on the recognized language has an undecidable index set. Apply the function formulation to the property of a partial computable function that its domain has the specified language property: every computably enumerable language occurs as such a domain.

For (1)(a), a primitive recursive function is obtained by a finite construction from the zero function, successor function and projection functions, using function composition in recursion theory and primitive recursion. The recursion rule, with parameters x, is
f(x,0)=g(x),f(x,n+1)=h(x,n,f(x,n)).
(21)
Here g,h have already been constructed. All these functions are total on nonnegative integers: the initial functions are total, composition preserves totality, and ordinary mathematical induction proves totality of each recursion.
For (1)(b), use a shifted hyperoperation sequence, beginning with addition. Define
H0​(a,0)=a,H0​(a,b+1)=S(H0​(a,b)),
(22)
and, for each fixed r≥0, define
Hr+1​(a,0)=cr​,Hr+1​(a,b+1)=Hr​(a,Hr+1​(a,b)),c0​=0,cr​=1 (r≥1).
(23)
The first three members are therefore addition, multiplication and exponentiation:
H0​(a,b)=a+b,H1​(a,b)=ab,H2​(a,b)=ab.​
(24)
The exponentiation convention includes a0=1, hence 00=1. The next member iterates exponentiation, with H3​(a,0)=1; there is no need for an exceptional domain restriction at a=0.
For (1)(c), H0​ is a primitive recursive function by its displayed recursion. If Hr​ is a primitive recursive function, then
gr​(a)=cr​,hr​(a,b,z)=Hr​(a,z)
(25)
are primitive recursive functions, using constants, projection functions and function composition in recursion theory. Primitive recursion applied to gr​,hr​ gives Hr+1​. Mathematical induction on the fixed rank r proves every member of the sequence is primitive recursive. This does not assert that the joint three-variable evaluator (r,a,b)↦Hr​(a,b) is a primitive recursive function.
For (2), as written, the answer is no: the empty set X=∅ is semidecidable, whereas a total computable function from N to N always has a nonempty range. This is the only obstruction. To prove the stronger useful statement, suppose X is a nonempty computably enumerable set and choose x0​∈X. Fix a Turing machine which halts exactly on the inputs in X. Its bounded halting predicate
B(x,t)=1⟺that machine halts on input x within t steps
(26)
is primitive recursive: encode configurations arithmetically, iterate its total single-step operation t times by primitive recursion, and check the halt state. A halted configuration is kept fixed. This is a bounded simulation, not unbounded waiting.
Fix a primitive recursive pairing function ⟨x,t⟩ with primitive recursive inverse coordinate functions. For example, the Cantor pairing function has inverses obtained by bounded minimization. Define
f(⟨x,t⟩)={x,x0​,​B(x,t)=1,B(x,t)=0.​
(27)
The two coordinate functions, the bounded predicate, and the finite case distinction are primitive recursive functions, so f is a primitive recursive function. Its values always lie in X. Conversely, if x∈X, its computation halts within some finite t, and f(⟨x,t⟩)=x. Thus
X=∅ and X semidecidable ⟹ ∃f primitive recursive with ran(f)=X.​
(28)
The range need not be a computable set; deciding whether a value occurs anywhere in this total enumeration is an unbounded search.

A many-one reduction A≤m​B is a total computable function f:N→N such that
n∈A⟺f(n)∈B.
(29)
A Turing reduction A≤T​B is an oracle machine which, with membership oracle B, halts on every input and computes the indicator function χA​. It may make finitely many adaptive queries on each input. A many-one reduction gives a Turing reduction by a single query, but Turing reducibility allows more general procedures.
The Friedberg–Muchnik theorem states that there are computably enumerable sets A,B with incomparable Turing degrees:
A≤T​BandB≤T​A.​
(30)
Here is a finite-injury priority construction proving it. Effectively enumerate all Turing functionals (Φe​). Arrange the requirements in the priority order
R0​,S0​,R1​,S1​,…,Re​:ΦeA​=χB​,Se​:ΦeB​=χA​.
(31)
Equality would require the Turing functional to be total and give the correct bit at every input; one disagreement or one undefined input defeats it.
Start with A0​=B0​=∅ and enumerate elements without ever removing them. A strategy has a private witness, a flag recording whether it has acted, and a restraint on its oracle. Every new witness is larger than every previously assigned witness and every current higher-priority restraint. Retired witnesses are never reused. The only possible enumeration of a witness is by its owner, so an unacted witness remains outside its target set.
The strategy for Re​ chooses a witness x and waits for a stage at which the bounded simulation gives
ΦeAs​​(x)↓=0.
(32)
On seeing this, put x into B, declare the strategy acted, and impose restraint u on A, where u is the oracle use: one more than the largest queried number, or zero if there were no queries. Initialize every lower-priority strategy, discarding its current witness, acted flag and restraint. An acted strategy does nothing further until initialized. The strategy for Se​ is identical with A,B interchanged. Waiting specifically for zero is enough: if the eventual output is nonzero while the witness stays out, it already disagrees with the target indicator function.
For a completely effective schedule, at stage s visit the first s+1 strategies in priority order. Assign an unassigned witness when visited. Simulate each unacted strategy's computation for at most s steps with the current finite oracle. If some strategy can act, perform the first such action and end the stage; otherwise end after all visits. All steps are finite and algorithmic, so the limiting A,B are computably enumerable sets.
Every lower-priority enumeration respects higher-priority restraints. When its witness was chosen it lay above these restraints. Any subsequent action of a higher-priority strategy would have initialized it, so its current witness remains safe to enumerate. The initialization of all lower strategies also removes their obsolete restraints before they can obstruct a legitimate higher-priority action.
We verify finite injury by mathematical induction on priority. The first strategy is never injured and acts at most once. If all predecessors of a strategy act finitely often, there is a last stage when a higher-priority action initializes it. It is subsequently visited, chooses its permanent witness, and acts at most once. Thus it too acts finitely often and all its lower-priority strategies suffer only finitely many injuries. The scheduling cannot starve a fixed strategy: after the finitely many higher-priority actions, all sufficiently large stages visit it.
Consider the final uninjured Re​ with witness x. If it acts, then x∈B permanently, and every later lower-priority enumeration into A respects its restraint. No later higher-priority action occurs. The preserved computation is therefore
ΦeA​(x)=0=1=χB​(x).
(33)
If it never acts, x∈/B. Were ΦeA​=χB​, the final computation on x would halt with zero and have finite oracle use. The finitely many oracle bits it queries eventually stabilize, and a sufficiently late bounded stage simulation would see exactly this zero computation. The strategy would then act, a contradiction. Hence Re​ holds in this case too. The same reasoning proves every Se​.
All possible Turing reductions in both directions are excluded. This proves the Friedberg–Muchnik theorem; in particular both constructed Turing degrees are noncomputable, since a computable set is Turing reducible to every oracle.

Represent a nonnegative integer n by the Church numeral
n​=λf.λx.fnx.
(34)
A closed lambda term F represents a partial computable function f if, on inputs in its domain, Fn1​​⋯nk​​ reduces to the Church numeral of the value, and on other inputs it produces no Church numeral. We use untyped lambda calculus and normal-order beta reduction.
First every primitive recursive function has such a representation on all inputs. The zero function is represented by a constant 0​, the projection functions by λx1​⋯xk​.xi​, and the successor function by
Succ=λnfx.f(nfx).
(35)
For function composition in recursion theory, substitute the represented inner functions into the represented outer function:
λx.G(H1​x)⋯(Hm​x).
(36)
These constituent functions are total, so there is no undefined argument to be discarded.
For primitive recursion, use Church Booleans and Church pairs:
T=λab.a,F=λab.b,Pair=λabp.pab,Fst=λp.pT,Snd=λp.pF.
(37)
If G,H represent the total functions defining a recursion, put
Stepx​=λp.Pair(Succ(Fstp))(Hx(Fstp)(Sndp)),
(38)
and
R=λxn.Snd(nStepx​(Pair0​(Gx))).
(39)
After j iterations the Church pair contains the counter j​ and the recursively computed value at j, by mathematical induction. Thus this lambda definition of primitive recursion by pair iteration represents the recursion. A structural induction for primitive recursive functions now represents every primitive recursive function.
To pass to arbitrary partial computable functions, use the Kleene normal form theorem in the following form: for every f:Nk⇀N, there are total primitive recursive functions C,U such that
f(x)=U(μt[C(x,t)=0]),
(40)
with f undefined precisely when no such t exists. The predicate checks codes of valid finite halting histories for the chosen program; U extracts their common output. This expresses unbounded minimization of a total predicate, so no earlier undefined test can interfere with the search.
Let C,U be the represented total functions. The Church numeral zero test and a fixed-point combinator are
Zero=λn.n(λz.F)T,Y=λh.(λz.h(zz))(λz.h(zz)).
(41)
Define the search lambda term
Q=Y(λqxt.(Zero(Cxt))(Ut)(qx(Succt))),F=λx.Qx0​.
(42)
All displayed abbreviations expand to finite closed lambda terms; x stands for the fixed finite tuple of input variables. Because YH≡β​H(YH), normal-order beta reduction tests t=0,1,2,…. At the first successful test the Church Boolean selects Ut, which reduces to the correct Church numeral. The unused recursive branch is discarded.
If no test succeeds, every finite search step returns to another head search, never exposing a numeral. The term has no head normal form and hence cannot be beta equivalent to a Church numeral. This last point is why the output operation occurs inside the successful branch: simply applying a possibly argument-discarding outer function to a divergent search would not justify undefinedness. Therefore every computable function is representable, including partial computable functions with their correct undefined inputs:
f(n)↓ f(n)↑ ​⟹ Fn​→β∗​f(n)​;⟹no numeral result.​​
(43)
