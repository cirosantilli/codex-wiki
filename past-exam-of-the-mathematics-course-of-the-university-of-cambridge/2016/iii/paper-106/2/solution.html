For a convex subset of a Banach space, weak closure equals norm closure. The Mazur theorem states that for every convex set C⊆X,
Cw=C∥⋅∥.
(14)
Since every bounded linear functional is norm-continuous, the weak topology is weaker than the norm topology, giving C∥⋅∥⊆Cw.
For the reverse inclusion, use this form of the Hahn-Banach separation theorem: if D is a nonempty norm-closed convex set in a real normed vector space and x∈/D, there is a continuous real-linear functional F such that
F(x)>supd∈D​F(d).
(15)
Apply it to D=C∥⋅∥. In a complex Banach space, use the underlying real space; every continuous real-linear F is the real part of the complex bounded linear functional f(v)=F(v)−iF(iv). The separating strict inequality gives a neighbourhood open for the weak topology of x disjoint from D, so x∈/Cw. The empty set case is immediate. This proves the Mazur theorem.
A weakly null sequence has disjoint convex blocks converging to zero in norm. If xn​w​0, then for every starting index m,

Choose the convex blocks recursively. After selecting the previous terminal index qn−1​, let pn​>qn−1​, and choose a finite convex combination from {xi​:i≥pn​} with norm less than 2−n. Choose qn​ beyond its largest used index, padding the intervening coefficients and the final coefficient with zero. This ensures the printed strict condition pn​<qn​ as well as qn​<pn+1​.
