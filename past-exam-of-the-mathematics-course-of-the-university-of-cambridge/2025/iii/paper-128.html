The Lévy reflection theorem says that for every finite collection Φ of first-order formulas there are arbitrarily large ordinals α such that, for every φ∈Φ and every tuple of parameters a1​,…,an​∈Vα​,
Vα​⊨φ(a1​,…,an​)⟺V⊨φ(a1​,…,an​).
(1)
Equivalently, the ordinals simultaneously reflecting all formulas in Φ form a closed unbounded class.

Let S be a finite subset of ZFC+φ, and let T be the finite collection of axioms of ZFC occurring in S. Choose the finite fragment T∗ supplied by the hypothesis. The Lévy reflection theorem gives a level Vα​ satisfying T∗; the Downward Lowenheim-Skolem theorem gives a countable elementary substructure of that level, and the Mostowski collapse theorem turns it into a countable transitive model M of T∗. By the assumed extension property, M is contained in a countable transitive model N of T+φ, so N satisfies S.
This argument is formalizable over ZFC for each finite T. Hence, if ZFC is consistent, every finite subset of ZFC+φ is consistent. The compactness theorem now gives
Con(ZFC)⟹Con(ZFC+φ).​

Take λ=ω⋅2. This is a limit ordinal greater than ω. There is a recursive well-order code R for ω2: for example, use a recursive pairing of the natural numbers with ω×ω and the lexicographic order consisting of ω successive blocks of order type ω. Since R is definable over Lω​, it belongs to Lω+1​ and hence to Lω⋅2​.
The representation of R is ω2, but
ω2>ω⋅2
(3)
and the ordinals belonging to Lλ​ are exactly those below λ. Thus R∈Lλ​ while its representation is not in Lλ​, violating the second requirement for a coding level of the constructible hierarchy.

Under V=L, the structure Lω1​​ contains a well-order code for every countable ordinal and the representation of every well-order code that it contains. Given any α<ω1​, apply the Downward Lowenheim-Skolem theorem to choose a countable elementary substructure
X≺Lω1​​
(4)
containing α. The Mostowski collapse theorem and condensation identify the transitive collapse of X with Lλ​, where λ=X∩ω1​ is a limit ordinal greater than α.
Elementarity now verifies both coding properties. If a well-order code belongs to Lλ​, its representation is carried into Lλ​ by the collapse. Conversely, every β<λ belongs to X, and elementarity supplies in X a well-order code for β; the collapse fixes this code because it is a relation on ω. Hence Lλ​ is a coding level of the constructible hierarchy. Such λ occur unboundedly below ω1​, so Γ has at least ℵ1​ elements; since Γ⊆ω1​, it has exactly
∣Γ∣=ℵ1​.

The two conventions reverse the order relation. In standard notation for forcing, q≤p means that q is stronger than p. Thus p and q are incompatible forcing conditions when there is no r with r≤p and r≤q, while D⊆P is a dense set when
∀p∈P ∃q∈D (q≤p).
(6)
In Jerusalem notation for forcing, p≤q means that q is stronger than p. Incompatibility therefore means that there is no r with p≤r and q≤r, and density means
∀p∈P ∃q∈D (p≤q).​

Let a,p∈M[G], and suppose a first-order formula ψ(x,y,p) defines exactly one y for every x∈a. Apply the Lévy reflection theorem to the formulas needed to express this assertion, choosing an ordinal α with a,p∈VαM[G]​ such that
M[G]⊨∃yψ(x,y,p)⟺VαM[G]​⊨∃yψ(x,y,p)
(8)
for every x∈a. Therefore every required value lies in the set VαM[G]​.
The already established axiom schema of separation forms the set
b={y∈VαM[G]​:∃x∈aψ(x,y,p)}.
(9)
Functionality makes b exactly the range of the definable function on a. This proves every instance of the Axiom schema of replacement in the generic extension M[G].

Let
d=⋃{s:(s,f)∈G}.
(10)
For each natural number m, conditions whose stem has length at least m form a dense subset of a forcing order, so the generic filter meets all of them and d∈ωω.
Fix h∈ωω∩M. The set
Dh​={(s,f):f(n)>h(n) for every n}
(11)
is dense: from (s,f) replace f by n↦max{f(n),h(n)+1}. Choose (s,f)∈G∩Dh​. Every stronger condition must put each newly added stem value d(n) above f(n), so
d(n)>h(n)
(12)
for every n≥∣s∣. Thus d is a dominating real over M.

Conditions with the same finite stem in Hechler forcing are compatible: (s,f) and (s,g) have the common stronger condition (s,max{f,g}). Since there are only countably many finite stems, Hechler forcing is sigma-centered and hence has the countable chain condition for forcing. It therefore preserves ℵ1M​.
In M, the Continuum hypothesis gives
∣D∣=∣ωω∣=ℵ1​.
(13)
Every real in M[G] has a nice name for a real, and the countable chain condition bounds the number of such names by
∣D∣ℵ0​=ℵ1ℵ0​​=ℵ1​,
(14)
where the last equality uses the ground-model continuum hypothesis. The extension still contains all ground-model reals, already ℵ1​ many, so
M[G]⊨2ℵ0​=ℵ1​.
(15)
Thus forcing once with D preserves the continuum hypothesis.
