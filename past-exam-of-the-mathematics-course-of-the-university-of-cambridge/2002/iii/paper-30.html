Let a1​,…,an​ be distinct elements of a finite field Fq​, with 1≤k≤n. The Reed-Solomon code consists of the evaluation vectors
RSk​(a)={(f(a1​),…,f(an​)):f∈Fq​[X], degf<k}.
(1)
Evaluation is an injective linear map: a nonzero polynomial of degree at most k−1 cannot vanish at all n distinct points. Thus the dimension is k. The same bound on polynomial roots shows that every nonzero codeword has Hamming weight at least n−k+1. Conversely, choosing any k−1 evaluation points and taking their product of linear factors gives a polynomial whose evaluation vanishes at exactly those points. Its Hamming weight is n−k+1. Hence
d=n−k+1.​
(2)
For completeness, deleting d−1 coordinates from a linear code of minimum Hamming distance d is injective on codewords, since two words with the same retained coordinates would differ in fewer than d positions. Therefore qk≤qn−d+1, giving the Singleton bound d≤n−k+1. The Reed-Solomon code attains this bound and is a maximum distance separable code. Multiplying individual coordinates by nonzero field elements changes neither the dimension nor the Hamming weight, so the same proof applies to a generalized Reed-Solomon code.
To specify the generator polynomials of a cyclic code unambiguously, use the primitive cyclic Reed-Solomon code convention. Put n=q−1, choose a primitive element of a finite field ω, and set
Ck,b​=⟨gb​(X)⟩⊆Fq​[X]/(Xn−1),gb​(X)=∏t=bb+n−k−1​(X−ωt).
(3)
Exponents are taken modulo n. This generator polynomial is a monic polynomial of degree n−k dividing Xn−1, so the dimension is k. It agrees with the evaluation form
Ck,b​={(aj1−b​f(aj​))j=0n−1​:degf<k},aj​=ωj.
(4)
Indeed, at a defining exponent t=b,…,b+n−k−1, a monomial f(X)=Xs contributes the finite geometric series ∑j​ajt+1−b+s​. Its exponent lies between 1 and n−1, so the sum vanishes: ωt+1−b+s=1 but its nth power is one. Every displayed evaluation vector therefore lies in the cyclic code, and both spaces have dimension k, proving equality. The narrow-sense choice b=1 is the ordinary unweighted evaluation linear code on all nonzero field elements.
The duality of primitive cyclic Reed-Solomon codes now follows directly. A vector in Ck,b​ has coordinates aj1−b​f(aj​), while a vector in Cn−k,1−b​ has coordinates ajb​h(aj​), with degh<n−k. Their dot product is ∑j​aj​f(aj​)h(aj​). Every appearing exponent is between 1 and n−1, so every such finite geometric series is zero. The two spaces are orthogonal and their dimensions sum to n, giving
Ck,b⊥​=Cn−k,1−b​.​
(5)
Thus the full cyclic family is closed under dual codes. The offset matters: the dual code of the narrow-sense linear code generally has offset zero, rather than one.
For arbitrary evaluation points, the precise statement is closure of generalized Reed-Solomon codes under duality. If C=GRSk​(a,v), put P(X)=∏i​(X−ai​) and ui​=(vi​P′(ai​))−1. Lagrange interpolation shows ∑i​p(ai​)/P′(ai​)=0 whenever degp≤n−2: this sum is the coefficient of Xn−1 in the interpolation formula for p. Taking p=fh with degf<k and degh<n−k proves orthogonality of C and GRSn−k​(a,u). Comparing dimensions gives equality with C⊥. An unweighted evaluation linear code at arbitrary points need not have an unweighted evaluation dual at the same points; the multiplier form and the cyclic offset formula resolve that convention issue.
For the length-15, dimension-11 linear code, choose b=1 and ω∈F16​ as in the field table. Then d=15−11+1=5 and
g1​(X)=∏t=14​(X−ωt).
(6)
The field characteristic is two, and the table gives ω4=ω+1. In the basis 1,ω,ω2,ω3, the four roots are represented by 0010,0100,1000,0011. Their elementary symmetric functions are
s1​s2​s3​s4​​=ω+ω2+ω3+ω4=ω13,=ω3+ω4+ω5+ω5+ω6+ω7=ω6,=ω6+ω7+ω8+ω9=ω3,=ω1+2+3+4=ω10.​
(7)
The repeated terms in s2​ cancel because the field characteristic is two. There are no alternating minus signs in this characteristic, so
g1​(X)=ω10+ω3X+ω6X2+ω13X3+ω0X4,d=5.​
(8)
For example, the coefficient vectors in ascending order are 0111,1000,1100,1101,0001, giving the required single powers of ω.
For the length-10, dimension-6 linear code over F11​, take the table's primitive element of a finite field ω=2 and again b=1. The four roots are 2,4,8,5. Expanding in F11​[X] gives
g2​(X)​=(X−2)(X−4)(X−8)(X−5)=(X2+5X+8)(X2+9X+7)=X4+3X3+5X2+8X+1.​
(9)
Thus
g2​(X)=1+8X+5X2+3X3+X4,d=10−6+1=5.​
(10)
The coefficients are reduced modulo 11, including the constant term 2⋅4⋅8⋅5=1(mod11).
A suitable two-error-correcting Reed-Solomon code over F16​ is precisely the first linear code:
[n,k,d]16​=[15,11,5]16​,g(X)=g1​(X).​
(11)
Two distinct codewords cannot both be within Hamming distance two of a received word, because the triangle inequality would put them at distance at most four. Thus this linear code corrects any two symbol errors. Its generator polynomial has four consecutive defining zeros of a cyclic code, and its dimension and exact minimum Hamming distance have already been proved.

For a binary linear code C⊆F2n​, define the linear functional σ(x)=∑j=1n​xj​∈F2​. This is the parity of the Hamming weight, so the even-weight subcode of a binary linear code is
Cev=ker(σ∣C​).
(12)
If σ∣C​=0, then Cev=C. Otherwise its image is all of F2​, and rank-nullity theorem gives dimCev=k−1. The kernel of a linear map is a linear subspace, proving the required dichotomy including closure under addition.
Let G be a full-rank k×n generator matrix. Messages a∈F2k​ correspond bijectively to codewords aG. If the jth column gj​ is nonzero, the coordinate a↦a⋅gj​ is a nonzero linear functional. Choose a0​ with a0​⋅gj​=1. Translation a↦a+a0​ pairs the messages with coordinate zero and those with coordinate one, so exactly 2k−1 codewords contribute one at position j. Summing over the n columns proves the total weight of a full-support binary linear code formula
x∈C∑​w(x)=j=1∑n​#{a:a⋅gj​=1}=n2k−1.​
(13)
A zero column would contribute zero instead, explaining the hypothesis.
For the Hamming code, use a parity-check matrix H whose columns are all nonzero vectors of V=F2ℓ​, once each. Then CH,ℓ​=kerH and n=2ℓ−1. The sum of all columns is zero: each coordinate occurs as one exactly 2ℓ−1 times, which is even for ℓ≥3. Consequently
(1,…,1)∈CH,ℓ​for every ℓ≥3.​
(14)
Under this column labelling, the support of a vector of a codeword is identified with a set of distinct nonzero columns whose sum is zero. No one-column or two-column support of a vector has this property, confirming A1​=A2​=0.
We can count the low-weight coefficients of a binary Hamming code directly. For weight three, choose ordered distinct nonzero columns a,b in n(n−1) ways. The third must be a+b, which is nonzero and different from both. Every unordered support of a vector has 3! orderings, so A3​=n(n−1)/3!.
For weight four, the first two columns a,b are again distinct and nonzero. The third c must avoid a,b,a+b, giving n−3 possibilities. The fourth is d=a+b+c; it is nonzero because c=a+b, and cannot equal any of the first three because those are distinct. Conversely every ordered zero-sum four-tuple arises in this way. Dividing by 4! gives A4​=n(n−1)(n−3)/4!.
For weight five, the first three columns a,b,c must be linearly independent. If a+b+c=0, the sum condition would force the fourth and fifth to coincide. Thus there are n(n−1)(n−3) choices for the first three. Put t=a+b+c. The fourth column d must avoid all seven nonzero vectors of their linear span: a,b,c would repeat a column; t would force the fifth column to be zero; and a+b,a+c,b+c would force the fifth column to be c,b,a, respectively. Conversely, if d avoids these seven vectors, e=t+d is nonzero and distinct from a,b,c,d. This gives n−7 choices for d and determines e. Dividing by 5! yields
A3​=3!n(n−1)​,A4​=4!n(n−1)(n−3)​,A5​=5!n(n−1)(n−3)(n−7)​.​
(15)
At ℓ=3, the last count is zero, as the argument also shows.
The dual code CH,ℓ⊥​ is the row space of H, so its codewords are aH for a∈F2ℓ​. For nonzero a, the linear functional v↦a⋅v takes value one on exactly half the 2ℓ vectors of V, by the same translation-pairing argument used above. Removing the zero vector removes only a zero value, so the Hamming weight is still m=2ℓ−1. Since H has matrix rank ℓ, distinct a give distinct codewords. This proves the constant weight of a binary simplex code and its full distribution:
A0⊥​=1,Am⊥​=2ℓ−1=n,As⊥​=0 (s=0,m).​
(16)
In particular, the ordinary weight enumerator of the binary simplex code is 1+nzm.
Apply the MacWilliams identity to this dual code, whose size is 2ℓ=n+1. For WC​(z)=∑s​As​zs, the result is
WCH,ℓ​​(z)=n+1(1+z)n+n(1−z)m(1+z)n−m​.
(17)
The coefficient of zs in the second product is a value of the binary Kravchuk polynomials
Ks​(m;n,2)=∑j=max(0,s−(n−m))min(s,m)​(−1)j(jm​)(s−jn−m​).
(18)
These bounds merely enforce 0≤j≤m and 0≤s−j≤n−m. Since n−m=2ℓ−1−1, they agree with the bounds in the PDF. Therefore the requested formula is
As​=2ℓ1​[(sn​)+nKs​(2ℓ−1;n,2)].​
(19)
For a further check on the low-weight counts, n=2m−1 gives
(1−z)m(1+z)m−1=(1−z)(1−z2)m−1.
(20)
Thus K3​(m)=m−1, K4​(m)=(2m−1​), and K5​(m)=−(2m−1​). Substituting these into the boxed formula and using m=(n+1)/2 reproduces the three direct combinatorial counts above.
Finally, at s=n the only possible term in the defining sum has j=m, so Kn​(m)=(−1)m=1, because m=2ℓ−1 is even. Consequently
An​=n+11+n​=1.​
(21)
The unique length-n binary word of weight n is the all-ones word, exactly as proved by the parity-check matrix calculation.

Use F32​=F2​[ω] with ω5=ω2+1. The given primitive polynomial over a finite field makes ω have order 31. For a binary cyclic code, squaring a zero preserves the zero condition: v(ω)2=v(ω2) for v∈F2​[X]. Thus the binary cyclotomic cosets modulo an odd integer governing the four specified zeros are
C1​=C2​=C4​={1,2,4,8,16},C3​={3,6,12,24,17}(mod31).​
(22)
The two displayed orbits are disjoint, each has size five, and together contain 1,2,3,4. Therefore specifying ω and ω3 already forces all four consecutive defining zeros of a cyclic code.
The minimal polynomial of an algebraic element of ω is m1​(X)=X5+X2+1. For ω3, the orbit size shows that its algebraic minimal polynomial has degree five. The candidate m3​(X)=X5+X4+X3+X2+1 vanishes there, since
m3​(ω3)=ω15+ω12+ω9+ω6+1=0.
(23)
For example, the five-bit representations of these terms are 11111,01110,11010,01010,00001, whose sum is zero in F25​. As m3​ is a monic polynomial of degree five and annihilates ω3, it is precisely its algebraic minimal polynomial; no assumption that the provided polynomial list is exhaustive is necessary.
The narrow-sense primitive BCH code is
X={v∈F2​[X], degv<31: v(ω)=v(ω3)=0}.
(24)
Both algebraic minimal polynomials divide each such v, and they are coprime polynomials. Their product is a divisor of X31−1. Hence the generator polynomial is their product. Direct multiplication with field characteristic two gives
g(X)=m1​(X)m3​(X)=X10+X9+X8+X6+X5+X3+1,dimX=21.​
(25)
The designed distance is five, because g vanishes at the four consecutive powers ω,ω2,ω3,ω4.
Here is an explicit BCH bound proof for these zeros. If a nonzero codeword had support of a vector of size ν≤4, with distinct positions i1​,…,iν​ and nonzero coefficients b1​,…,bν​, put λr​=ωir​. Evaluating at the first ν defining powers gives
∑r=1ν​br​λrj​=0(1≤j≤ν).
(26)
The coefficient matrix has determinant (∏r​λr​)∏r<s​(λs​−λr​), a nonzero Vandermonde determinant because the λr​ are distinct and nonzero. It therefore forces every br​=0, a contradiction. Thus the minimum Hamming distance is at least five.
For the matching upper bound, multiplication gives the actual codeword
(1+X2+X3)g(X)=1+X2+X7+X8+X13,
(27)
which has Hamming weight five and degree below 31. Hence
X has parameters [31,21,5]2​.​
(28)
This proves the actual distance without needing the optional theorem. Its numerical hypothesis is also satisfied: with s=5 and the error parameter l=2, 2sl=210=1024, whereas ∑i=03​(i31​)=1+31+465+4495=4992.
Now calculate the root-evaluation syndrome for a cyclic code from the received polynomial. Reduction modulo m1​(X) gives u(X)≡X3, so S1​=u(ω)=ω3. Substitution followed by the same reduction gives u(X3)≡X4+X3+X, whose five-bit representation is 11010=ω9. Thus
S1​=ω3,S3​=u(ω3)=ω9=S13​.​
(29)
The single-error test from two binary BCH syndromes identifies coordinate 3, since a one-bit error Xj has syndromes ωj,ω3j. Flip that coordinate to obtain
ccorrect​(X)=u(X)+X3=X12+X11+X9+X7+X6+X3+X2+1.​
(30)
Both defining evaluations vanish: ccorrect​(ω)=ω3+ω3=0 and ccorrect​(ω3)=ω9+ω9=0. More directly,
ccorrect​(X)=(1+X2)g(X),
(31)
so it is certainly a codeword of X. It is at Hamming distance one from u. Since the minimum Hamming distance is five, no other codeword can be within two errors of u: such a word would be at distance at most three from ccorrect​, contradicting the proved distance. Thus this is the unique bounded-distance decoding under the linear code's two-error guarantee.
The decoded polynomial printed in the original PDF is incorrect. It instead adds X10 to u, giving a polynomial cprinted​=u+X10. Its defining evaluations are
cprinted​(ω)=ω3+ω10=ω25=0,cprinted​(ω3)=ω9+ω30=ω3=0.
(32)
Therefore it is not a codeword, and the request to verify that it belongs to X is a false premise. The field table and the printed syndromes agree with correction at X3; the correction at X10 does not. The boxed corrected polynomial resolves this source error and supplies the intended decoding and membership proof.
