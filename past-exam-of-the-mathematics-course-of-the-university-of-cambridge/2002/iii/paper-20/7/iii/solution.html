OurBigBook.com Words: 128
For a presheaf of sets on a topological space P, define LP=P(∅) and RP=P(S). Then the adjoints to constant presheaves on open sets are
ev∅​⊣Δ⊣evS​.​
(28)
To prove the first adjunction, a natural transformation a:P→ΔA must satisfy aU​=a∅​∘resU,∅​ by naturality at the inclusion ∅⊆U. Hence it is uniquely determined by a function P(∅)→A. Every such function defines a natural transformation by this formula, because restriction maps compose. This gives Nat(P,ΔA)≅Set(P(∅),A).
For the second adjunction, a natural transformation b:ΔA→P satisfies bU​=resS,U​∘bS​, so it is uniquely determined by a function A→P(S). Every such function defines the remaining components by restriction, giving Nat(ΔA,P)≅Set(A,P(S)). Evaluation acts on presheaf morphisms componentwise, so these object assignments are indeed functors. The use of P(∅) is essential: a constant presheaf of sets has value A there, whereas a sheaf has a singleton value there. No sheaf condition is imposed in this question.
