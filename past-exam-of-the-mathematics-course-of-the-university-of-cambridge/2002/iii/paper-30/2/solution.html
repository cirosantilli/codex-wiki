For a binary linear code C⊆F2n​, define the linear functional σ(x)=∑j=1n​xj​∈F2​. This is the parity of the Hamming weight, so the even-weight subcode of a binary linear code is
Cev=ker(σ∣C​).
(12)
If σ∣C​=0, then Cev=C. Otherwise its image is all of F2​, and rank-nullity theorem gives dimCev=k−1. The kernel of a linear map is a linear subspace, proving the required dichotomy including closure under addition.
Let G be a full-rank k×n generator matrix. Messages a∈F2k​ correspond bijectively to codewords aG. If the jth column gj​ is nonzero, the coordinate a↦a⋅gj​ is a nonzero linear functional. Choose a0​ with a0​⋅gj​=1. Translation a↦a+a0​ pairs the messages with coordinate zero and those with coordinate one, so exactly 2k−1 codewords contribute one at position j. Summing over the n columns proves the total weight of a full-support binary linear code formula
x∈C∑​w(x)=j=1∑n​#{a:a⋅gj​=1}=n2k−1.​
(13)
A zero column would contribute zero instead, explaining the hypothesis.
For the Hamming code, use a parity-check matrix H whose columns are all nonzero vectors of V=F2ℓ​, once each. Then CH,ℓ​=kerH and n=2ℓ−1. The sum of all columns is zero: each coordinate occurs as one exactly 2ℓ−1 times, which is even for ℓ≥3. Consequently
(1,…,1)∈CH,ℓ​for every ℓ≥3.​
(14)
Under this column labelling, the support of a vector of a codeword is identified with a set of distinct nonzero columns whose sum is zero. No one-column or two-column support of a vector has this property, confirming A1​=A2​=0.
We can count the low-weight coefficients of a binary Hamming code directly. For weight three, choose ordered distinct nonzero columns a,b in n(n−1) ways. The third must be a+b, which is nonzero and different from both. Every unordered support of a vector has 3! orderings, so A3​=n(n−1)/3!.
For weight four, the first two columns a,b are again distinct and nonzero. The third c must avoid a,b,a+b, giving n−3 possibilities. The fourth is d=a+b+c; it is nonzero because c=a+b, and cannot equal any of the first three because those are distinct. Conversely every ordered zero-sum four-tuple arises in this way. Dividing by 4! gives A4​=n(n−1)(n−3)/4!.
For weight five, the first three columns a,b,c must be linearly independent. If a+b+c=0, the sum condition would force the fourth and fifth to coincide. Thus there are n(n−1)(n−3) choices for the first three. Put t=a+b+c. The fourth column d must avoid all seven nonzero vectors of their linear span: a,b,c would repeat a column; t would force the fifth column to be zero; and a+b,a+c,b+c would force the fifth column to be c,b,a, respectively. Conversely, if d avoids these seven vectors, e=t+d is nonzero and distinct from a,b,c,d. This gives n−7 choices for d and determines e. Dividing by 5! yields
A3​=3!n(n−1)​,A4​=4!n(n−1)(n−3)​,A5​=5!n(n−1)(n−3)(n−7)​.​
(15)
At ℓ=3, the last count is zero, as the argument also shows.
The dual code CH,ℓ⊥​ is the row space of H, so its codewords are aH for a∈F2ℓ​. For nonzero a, the linear functional v↦a⋅v takes value one on exactly half the 2ℓ vectors of V, by the same translation-pairing argument used above. Removing the zero vector removes only a zero value, so the Hamming weight is still m=2ℓ−1. Since H has matrix rank ℓ, distinct a give distinct codewords. This proves the constant weight of a binary simplex code and its full distribution:
A0⊥​=1,Am⊥​=2ℓ−1=n,As⊥​=0 (s=0,m).​
(16)
In particular, the ordinary weight enumerator of the binary simplex code is 1+nzm.
Apply the MacWilliams identity to this dual code, whose size is 2ℓ=n+1. For WC​(z)=∑s​As​zs, the result is
WCH,ℓ​​(z)=n+1(1+z)n+n(1−z)m(1+z)n−m​.
(17)
The coefficient of zs in the second product is a value of the binary Kravchuk polynomials
Ks​(m;n,2)=∑j=max(0,s−(n−m))min(s,m)​(−1)j(jm​)(s−jn−m​).
(18)
These bounds merely enforce 0≤j≤m and 0≤s−j≤n−m. Since n−m=2ℓ−1−1, they agree with the bounds in the PDF. Therefore the requested formula is
As​=2ℓ1​[(sn​)+nKs​(2ℓ−1;n,2)].​
(19)
For a further check on the low-weight counts, n=2m−1 gives
(1−z)m(1+z)m−1=(1−z)(1−z2)m−1.
(20)
Thus K3​(m)=m−1, K4​(m)=(2m−1​), and K5​(m)=−(2m−1​). Substituting these into the boxed formula and using m=(n+1)/2 reproduces the three direct combinatorial counts above.
Finally, at s=n the only possible term in the defining sum has j=m, so Kn​(m)=(−1)m=1, because m=2ℓ−1 is even. Consequently
An​=n+11+n​=1.​
(21)
The unique length-n binary word of weight n is the all-ones word, exactly as proved by the parity-check matrix calculation.
