Let P be the orthogonal projector onto the quantum code X, and choose an orthonormal basis ∣iL​⟩ for it. The necessary and sufficient Knill--Laflamme condition is that one matrix C, independent of the logical labels, satisfies
PEa†​Eb​P=Cab​Pfor all Ea​,Eb​∈E.​
(1)
Equivalently, ⟨iL​∣Ea†​Eb​∣jL​⟩=Cab​δij​. This makes the information in the error label independent of the encoded quantum state. It applies to the whole linear span of the errors, and hence to every noise quantum channel with Kraus operators in that span.
Here is a proof of both directions. For necessity of the Knill-Laflamme condition, let Rμ​ be Kraus operators of a common recovery, so ∑μ​Rμ†​Rμ​=I. Since recovery after Ea​ must return the pure input state, every vector Rμ​Ea​∣ψ⟩ is parallel to ∣ψ⟩. A linear operator on the code which sends every vector to a multiple of itself is scalar: apply it to two basis vectors and their sum to force the two multipliers to agree. Therefore Rμ​Ea​P=cμa​P with no dependence on ∣ψ⟩. It follows that
PEa†​Eb​P=∑μ​PEa†​Rμ†​Rμ​Eb​P=∑μ​cμa∗​cμb​P.
(2)
This proves necessity without assuming in advance that the physical errors have orthogonal syndromes.
For sufficiency, C is positive semidefinite: for any normalized code state and coefficients va​, v†Cv=∥∑a​va​Ea​∣ψ⟩∥2≥0. Diagonalize C by a unitary change of the error basis to get operators Fj​ with PFj†​Fl​P=cj​δjl​P. If cj​>0, Vj​=Fj​P/cj​​ is a linear isometry from the code to an error-image subspace, and distinct such images are orthogonal. If cj​=0, then Fj​P=0. A projective measurement of these image subspaces followed by Vj†​ recovers every logical state. Complete the recovery on the unused orthogonal complement in any trace-preserving manner. For a coherent error ∑j​vj​Fj​, the measurement branch j contains vj​cj​​∣ψ⟩; the branch probability is independent of the logical state, and discarding the syndrome leaves the original state. This is constructive recovery from the Knill-Laflamme condition.
For the usual family of distinct unitary Pauli errors modulo scalar phase, nondegenerate quantum code correction means that different physical errors have orthogonal image subspaces. The precise condition is
Cab​=δab​,⟨iL​∣Ea†​Eb​∣jL​⟩=δab​δij​.​
(3)
For nonunitary errors, replace the unit diagonal by positive norm factors. In an arbitrary error basis the Gram matrix need not initially be diagonal; its positive-eigenvalue modes give the independent syndrome spaces just constructed. A kernel of C exhibits a linear combination of errors acting as zero on the code. In particular two distinct physical errors with the same action on the code cannot be distinguished and give degenerate correction, as in part (c).

Here the number of errors means the number of affected physical qubits: assume that all errors supported on at most t qubits are jointly correctable. It does not mean the cardinality of an arbitrary selected error list. Let F be any Pauli operator of weight at most 2t. Split its support into disjoint sets A,B, each of size at most t, and write F=FA​FB​. Each Pauli factor is Hermitian, so take Ea​=FA​, Eb​=FB​ to get F=Ea†​Eb​, up to an irrelevant scalar phase if different Pauli representatives are used. The Knill--Laflamme condition gives
PFP=PEa†​Eb​P=Cab​P.
(4)
This is precisely quantum error detection: a projective measurement with outcomes P,I−P either detects departure from the code or leaves the accepted logical state unchanged up to a scalar. Some errors can be harmless scalars on the code, particularly for degenerate correction; detection is not required to flag such an error with certainty.
Any linear operator supported on at most 2t qubits is a linear combination of Pauli operators on those qubits, so its code compression is scalar by linearity. Thus
correction of all errors of weight at most t ⟹ detection of all errors of weight at most 2t.​
(5)
This is correction implies detection at twice the weight. The premise about all locations and all error types is essential: merely correcting one selected operator gives no universal statement about every operator of twice its weight.

Use the normalized three-qubit states ∣G±​⟩=(∣000⟩±∣111⟩)/2​. The Shor code has logical basis
∣0L​⟩=∣G+​⟩⊗3,∣1L​⟩=∣G−​⟩⊗3.​
(6)
It encodes α∣0⟩+β∣1⟩ as α∣0L​⟩+β∣1L​⟩, preserving the unknown amplitudes by a linear isometry. It concatenates a three-block phase-flip repetition code with the three-qubit bit-flip repetition code inside each block. Six stabilizer generators, Z1​Z2​,Z2​Z3​,Z4​Z5​,Z5​Z6​,Z7​Z8​,Z8​Z9​, test bit errors inside the blocks. The other two stabilizer generators are
A=X1​X2​X3​X4​X5​X6​,B=X4​X5​X6​X7​X8​X9​.
(7)
All eight commute and have eigenvalue +1 on both logical basis states. They define the [[9,1,3]] stabilizer code. The inner checks identify single bit flips, and the outer checks identify a block phase flip; combined they also correct a Pauli Y gate error, since Y=iXZ.
For the requested phase flip, a Z on any one qubit interchanges ∣G+​⟩ and ∣G−​⟩ in its block. It commutes with the six Z-pair checks. It anticommutes with A or B exactly when its block is contained in that check. The Shor-code phase-flip syndrome is therefore
error blocknone123​(A,B) outcomes(+1,+1)(−1,+1)(−1,−1)(+1,−1)​recoveryIZ1​Z4​Z7​​​
(8)
A projective measurement of the two commuting checks yields the displayed error syndrome without learning α or β: both logical components have the same check eigenvalues after the error. Applying the indicated Pauli Z gate restores every encoded quantum state.
The correction is genuinely degenerate. For i,j in the same block, Zi​Zj​ fixes both ∣000⟩ and ∣111⟩, so Zi​Zj​P=P and consequently Zi​P=Zj​P. In particular Z1​ and Z2​ are distinct physical errors but have identical action on every code state; their image subspaces coincide, not merely their observed syndrome labels. In the Knill--Laflamme condition for I,Z1​,…,Z9​, the error Gram matrix has C00​=1, C0i​=Ci0​=0, and
Cij​={1,0,​i,j in the same block,i,j in different blocks.​
(9)
The zero overlaps between different blocks follow because a phase flip changes a different pattern of orthogonal G+​,G−​ factors; cross-logical overlaps also vanish. Thus C consists of one 1×1 block and three all-ones 3×3 blocks and has rank four, not ten. This both proves correctability of the entire single-phase-error span and exhibits its degeneracy. A coherent sum of phase errors in one block has the same logical action with its coefficients summed, so inability to locate the individual qubit loses no logical information. The two block checks suffice to correct every single phase flip, even though the within-block errors are indistinguishable.

For an n-qubit quantum code with projector P, the quantum code distance is
d=min{wt(F):F is a Pauli operator and PFP∈/CP}.​
(10)
Here the weight counts nonidentity tensor factors. Thus every error supported on fewer than d qubits is detectable, by the Pauli expansion of a quantum error. A scalar action on the code, including a nonidentity stabilizer, is harmless and does not reduce this distance. For a stabilizer code, the equivalent definition minimizes weight among Pauli operators which commute with every stabilizer generator but act nontrivially on the logical information. The Knill--Laflamme condition then guarantees correction of all errors of weight at most t=⌊(d−1)/2⌋, since each pairwise product has weight at most 2t<d.
Suppose the code encodes k logical qubits and is nondegenerate for all errors through weight t. There are
Nt​=∑j=0t​3j(jn​)
(11)
distinct Pauli errors modulo phase: choose the j affected positions and choose X,Y or Z at each. Each error is unitary, so its image of the code has dimension 2k. Nondegeneracy makes these images mutually orthogonal, equivalently the combined vectors Ea​∣iL​⟩ are orthonormal. They all lie in the physical Hilbert space of dimension 2n. Counting dimensions proves the quantum Hamming bound
2kj=0∑t​3j(jn​)≤2n.​
(12)
This dimension argument requires nondegeneracy. For a degenerate code, different errors can share an image, as in the Shor code, and this counting proof cannot be applied unchanged.
For a binary classical code of M words, the Hamming bound is M∑j=0t​(jn​)≤2n: disjoint Hamming balls around the words must fit into all binary strings. The quantum factor 3j is needed because at each erroneous qubit there are three linearly independent nonidentity Pauli operators, not just a classical bit flip. A phase flip is invisible to a computational-basis classical record but changes a quantum superposition. A Y error combines bit and phase effects, and the identity with X,Y,Z spans every one-qubit operator. Quantum correction must protect amplitudes and coherences, and consequently count whole orthogonal logical subspaces rather than just classical words.
For parameters [[5,1,3]], t=1, and
21(1+3(15​))=2⋅16=32=25.
(13)
Thus a nondegenerate such code saturates the bound: the sixteen two-dimensional error images exhaust the physical space. It is a perfect quantum error-correcting code for single-qubit errors. It also has the smallest possible length for nondegenerate single-error protection of one logical qubit: for 1≤n≤4, the required inequality 1+3n≤2n−1 fails.
Here is an explicit realization and its five-qubit stabilizer syndrome table. Write tensor products without multiplication symbols and use
g1​=XZZXI,g2​=IXZZX,g3​=XIXZZ,g4​=ZXIXZ.
(14)
Each pair has an even number of anticommuting single-site factors, so the four stabilizer generators commute. Their binary Pauli labels are independent: no nonempty product has identity label. For example, the X-support at site three fixes the exponent of g3​ in such a product to zero, site five then fixes that of g2​, site one fixes that of g1​, and site two fixes that of g4​. Thus their group has sixteen elements and excludes −I. The common +1 eigenspace has projector P=∏a=14​(I+ga​)/16 and dimension TrP=32/16=2, since all nonidentity Pauli strings have zero trace.
Record a syndrome bit as one when an error anticommutes with the corresponding generator, in order g1​,g2​,g3​,g4​. Direct local commutation gives
site12345​X00011000110001100011​Y10111101111011110111​Z10100101001010010100​​
(15)
These are all fifteen nonzero four-bit error syndromes; the identity has 0000. Distinct errors in this list have a product with nonzero syndrome, so it anticommutes with some ga​. Inserting ga​P=P on both sides gives PEb†​Ec​P=−PEb†​Ec​P=0. The diagonal product is the identity. Hence the Knill--Laflamme condition is exactly Cbc​=δbc​, proving nondegenerate correction. Measure the four commuting checks, apply the unique indicated Pauli error again, and every logical state is recovered. The Pauli expansion of a quantum error extends this recovery to an arbitrary one-qubit noise channel, not just the fifteen discrete errors.
The table also proves that every Pauli operator of weight one or two has nonzero syndrome: a weight-two operator is the product of distinct single-site errors, whose syndromes differ. Therefore the distance is at least three. The operators X=X⊗5 and Z=Z⊗5 commute with all four generators and anticommute with each other. They are nontrivial logical Pauli operators. Multiplication of X by g1​ gives −IYYIX, a weight-three operator with the same logical action; it cannot be scalar on the code because it anticommutes with the invertible logical operator Z. This proves d=3 exactly.
The code consequently detects every two-qubit error and corrects two known-location erasures by the quantum erasure correction criterion, but it cannot correct all two-qubit errors of unknown location. A nontrivial weight-three logical operator can be split into a weight-one and a weight-two error, whose pairwise product violates the correction condition. It also saturates the quantum Singleton bound, since n−k=4=2(d−1). These properties distinguish single-error perfectness from unrestricted protection against larger errors.

Use logarithms to base two, so all entropies are in bits. For a discrete probability distribution p and a density operator ρ with eigenvalues λj​, the Shannon entropy and Von Neumann entropy are respectively
H(p)=−x∑​px​log2​px​,S(ρ)=−Tr(ρlog2​ρ)=−j∑​λj​log2​λj​.​
(16)
Use 0log0=0. The second definition is basis-independent by the spectral theorem; for a density operator diagonal with probabilities px​, it agrees with the first.
The classical relative entropy, or Kullback-Leibler divergence, of p from q is
D(p∥q)=x:px​>0∑​px​log2​qx​px​​.​
(17)
It is +∞ if some px​>0 has qx​=0. The quantum relative entropy is
D(ρ∥σ)=Tr[ρ(log2​ρ−log2​σ)]​
(18)
when the support of ρ is contained in that of σ, and is +∞ otherwise. Matrix logarithms are taken on the corresponding positive supports. In a common eigenbasis this reduces to classical relative entropy; both divergences are nonnegative and are generally asymmetric.
To prove Fano's inequality, let the finite alphabet size be m≥2 and let E indicate an incorrect guess. Since E is determined by (X,Y), the chain rule for conditional entropy first gives
H(E,X∣Y)=H(X∣Y)+H(E∣X,Y)=H(X∣Y).
(19)
Expanding in the opposite order gives
H(E,X∣Y)=H(E∣Y)+H(X∣E,Y).
(20)
Conditioning reduces entropy, so H(E∣Y)≤H(E)=h2​(pe​), the binary entropy function. When E=0, knowledge of Y determines X=f(Y) and the conditional entropy is zero. When E=1, X can lie in at most the m−1 alphabet values other than f(Y). Entropy on m−1 values is at most log2​(m−1): its deficit from that number is the nonnegative relative entropy from the uniform distribution. Averaging the two cases therefore gives
H(X∣E,Y)≤pe​log2​(m−1).
(21)
Combining the two expansions proves
H(X∣Y)≤h2​(pe​)+pe​log2​(m−1).​
(22)
This proof of Fano's inequality via an error indicator works for any alphabet-valued guessing rule, not just an optimal one. If m=1, there is no guessing uncertainty and the claim is simply H(X∣Y)=0; that case is treated separately rather than writing log0.

A measurement in quantum mechanics with outcomes m is specified, in the single-operator-per-outcome description, by linear operators Mm​ satisfying ∑m​Mm†​Mm​=I. Its effects Fm​=Mm†​Mm​ form a positive operator-valued measure. The two measurement postulates are the Born rule for outcomes and the conditional state update:
pm​=⟨ψ∣Mm†​Mm​∣ψ⟩,∣ψ⟩⟼pm​​Mm​∣ψ⟩​(pm​>0).​
(23)
For a density operator the corresponding formulas are pm​=Tr(Mm​ρMm†​) and ρm​=Mm​ρMm†​/pm​. More general quantum instruments have multiple operators for each outcome and sum these terms. For a projective measurement of an observable A=∑m​am​Pm​, take Mm​=Pm​; the outcome value is am​ and the postmeasurement state lies in its eigenspace. A POVM alone specifies probabilities, whereas the measurement operators or instrument also specify the backaction.
For quantum teleportation, Alice and Bob initially share the Bell pair ∣Φ+⟩AB​=(∣00⟩+∣11⟩)/2​. Alice also holds the input ∣ψ⟩C​=α∣0⟩+β∣1⟩, with ∣α∣2+∣β∣2=1. The shared entanglement is a resource; the two transmitted classical bits alone could not transfer an arbitrary unknown quantum state.
Alice applies a controlled-NOT gate with C as control and A as target, then a Hadamard gate to C. Starting from ∣ψ⟩C​∣Φ+⟩AB​, direct expansion gives
21​(∣00⟩CA​∣ψ⟩B​+∣01⟩CA​X∣ψ⟩B​+∣10⟩CA​Z∣ψ⟩B​+∣11⟩CA​XZ∣ψ⟩B​).
(24)
For example, the four receiver vectors are α∣0⟩+β∣1⟩, β∣0⟩+α∣1⟩, α∣0⟩−β∣1⟩, and −β∣0⟩+α∣1⟩. Thus the gate calculation fixes the ordering of the Pauli corrections, including the last branch's sign.
Alice measures C,A in the computational basis, obtaining (a,b). The Born rule gives each outcome probability 1/4, independent of the input amplitudes. Bob's normalized conditional state is XbZa∣ψ⟩. Alice sends the two outcome bits. Bob applies the inverse, ZaXb, and hence
ZaXbXbZa∣ψ⟩=∣ψ⟩.​
(25)
The same circuit is a Bell-basis measurement on Alice's two qubits, expressed using ordinary gates followed by computational-basis measurements. It restores the state without Alice or Bob knowing α,β.
By linearity, the calculation also holds when the input is entangled with a reference: each outcome has branch map ∣ψ⟩↦XbZa∣ψ⟩/2, and after correction every branch is one-half of the identity map. Summing the four corrected density operators gives exactly the original input density operator, with all reference correlations preserved. This is teleportation as an identity channel on a reference. Without the two classical bits Bob must average the four uncorrected states, giving 41​∑a,b​XbZaρZaXb=I/2, so the process cannot signal before the message arrives. The Bell pair is consumed and Alice retains no copy of the unknown state, in accordance with the no-cloning theorem.

Let U be a unitary operator and suppose initially that the target is an eigenstate ∣u⟩ with U∣u⟩=e2πiϕ∣u⟩, 0≤ϕ<1. Use t control qubits, so L=2t. Hadamard gates prepare the uniform superposition L−1/2∑a=0L−1​∣a⟩. For each binary control position j, apply the controlled unitary gate U2j. The resulting state is
L​1​∑a=0L−1​e2πiaϕ∣a⟩∣u⟩.
(26)
Apply the inverse quantum Fourier transform, with convention QFTL​∣j⟩=L−1/2∑a​e2πiaj/L∣a⟩, and measure the control. The exact amplitude and probability are
Aj​=L1​∑a=0L−1​e2πia(ϕ−j/L),pj​=∣Aj​∣2.
(27)
For an exactly representable phase ϕ=j0​/L, orthogonality of roots of unity makes the outcome j0​ certain. Otherwise the finite geometric series gives
pj​=L2sin2(π(ϕ−j/L))sin2(πL(ϕ−j/L))​.
(28)
The estimate is j/L, with phases interpreted modulo one.
To prove an error bound, choose a nearest label j0​ to Lϕ on the circular grid and put d=Lϕ−j0​ in the interval [−1/2,1/2]. For d=0, concavity of sine on [0,π/2] gives ∣sinπd∣≥2∣d∣, while L∣sin(πd/L)∣≤π∣d∣. Therefore the nearest-integer success bound for quantum phase estimation is
Pr(​LJ​−ϕ​R/Z​≤2L1​)≥π24​.​
(29)
Here ∥x∥R/Z​=mink∈Z​∣x−k∣. At an exact grid point the probability is one. If two nearest labels tie, either one separately has the displayed lower bound.
For high confidence one can prove a stronger quantum phase estimation tail bound. Let dj​ be the centered distance between j and Lϕ, chosen with ∣dj​∣≤L/2. The denominator estimate ∣sin(πdj​/L)∣≥2∣dj​∣/L implies pj​≤1/(4dj2​) away from the exact-phase case. A label at circular integer distance ℓ from j0​ has ∣dj​∣≥ℓ−1/2, and there are at most two labels at each such distance. For m≥2, summing the tails gives
Pr(dist(J,j0​)≥m)≤21​∑ℓ=m∞​(ℓ−1/2)21​≤21​∑ℓ=m∞​ℓ(ℓ−1)1​=2(m−1)1​.
(30)
On the complementary event the circular phase error is at most (m−1/2)/L. Thus, for b desired bits of accuracy, take t=b+u with u≥1 and m=2u to obtain
Pr(​LJ​−ϕ​R/Z​≥2−b)≤2(2u−1)1​.​
(31)
Taking u=⌈log2​(1+1/(2ε))⌉ makes the right side at most ε. This adds only O(log(1/ε)) control qubits. Efficient QFT is not by itself a guarantee of efficient controlled powers of an arbitrary U: implementing them by repeated oracle calls uses L−1 calls. The modular-arithmetic application has efficient powers, as follows.
Assume n>1 and gcd(x,n)=1, and let r be the multiplicative order of x modulo n. Define the unitary operator Ux​∣y⟩=∣xymodn⟩ on 0≤y<n, and extend it as the identity on unused computational-basis labels of the binary register. Coprimality makes multiplication a permutation, so this extension really is unitary. The orbit of ∣1⟩ consists of the r distinct states ∣xjmodn⟩. Its modular multiplication eigenstates are
∣us​⟩=r​1​∑j=0r−1​e−2πisj/r∣xjmodn⟩,Ux​∣us​⟩=e2πis/r∣us​⟩,0≤s<r.
(32)
The last relation follows by shifting the index j cyclically; orthogonality follows from the finite Fourier sum. We do not need to know r to prepare one of these eigenstates: the readily prepared target obeys
∣1⟩=r​1​∑s=0r−1​∣us​⟩.
(33)
Running quantum phase estimation on this state produces the mixture of the r eigenphase distributions, each with weight 1/r, because the target eigenstates are orthogonal. Thus it samples a uniformly random phase label s and estimates s/r with the bounds just proved. Equivalently the state before the inverse QFT is L−1/2∑a​∣a⟩∣xamodn⟩, which is obtained by quantum modular exponentiation directly.
The controlled power Ux2j​ multiplies by x2jmodn, whose constant is computed by repeated squaring. Under the assumed efficient modular exponentiation, these controlled multiplications and the QFT use a number of gates polynomial in the register lengths. Taking L>n2 requires only O(logn) phase qubits. The nearest-label event has probability at least 4/π2 and yields an estimate within 1/(2L)<1/(2r2) of s/r. Since r<n, continued-fraction recovery in quantum order finding then identifies the reduced fraction s/r. The denominator is r/gcd(s,r), not necessarily r: when s and r are coprime it is the desired order, and when they are not it is only a divisor. One may test candidate denominators using modular exponentiation and repeat with fresh samples; denominators from successful samples can also be combined by a least common multiple. The probability of a nearest-label sample with s coprime to r is at least (4/π2)φ(r)/r. These qualifications explain exactly what the phase estimate yields without falsely assuming that the unknown order or an eigenstate was available at the start.
