Codon

 ... Biology Genetics Molecular genetics Gene expression Translation (biology) Genetic code
OurBigBook.com Words: 51 Articles: 1
A codon is a three-nucleotide unit read in a specified reading frame during biological translation. For example, GCU specifies alanine in the standard genetic code. Its letters are read 5′→3′.
