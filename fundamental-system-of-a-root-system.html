Fundamental system of a root system (Δ)

 ... Lie theory Lie algebra Semisimple Lie algebra Cartan subalgebra Root-space decomposition Root system
OurBigBook.com Words: 108 Articles: 3
A fundamental system Δ is a basis made of roots such that every root is a linear combination of Δ whose nonzero coefficients all have the same sign. Its members are the simple roots.
