Rank-one matrix update (B=A+uvT)

 Home Mathematics Area of mathematics Algebra Linear algebra
OurBigBook.com Words: 178
A rank-one matrix update changes a matrix A by an outer product uvT. For real vectors u,v∈Rn, its action on an input vector x is
(A+uvT)x=Ax+u(vTx).
(68)
The dot product vTx reads one scalar from the input, and the correction moves the output along u. All correction outputs therefore lie in one linear span. If either vector is zero, the update is zero; otherwise the correction is a rank-one matrix. The full updated matrix need not have rank one.
For example, choose
u=(12​),v=(3−1​),uvT=(36​−1−2​).
(69)
The update sends x=(x1​,x2​)T to the correction (3x1​−x2​)(1,2)T. Although all four entries change, there is only one direction of correction. Adding it to the identity matrix gives B=(46​−1−1​).
This special structure allows existing work to be reused. The matrix determinant lemma updates the determinant using one scalar, and the Sherman–Morrison formula updates the matrix inverse using an outer product. Such formulas are useful when a linear system changes slightly after a new observation or a parameter adjustment: the unchanged part can retain its LU decomposition. The term rank-one describes the rank of the correction, not the size of the entry changes. [ref].
