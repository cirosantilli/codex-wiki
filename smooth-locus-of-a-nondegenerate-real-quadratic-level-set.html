Smooth locus of a nondegenerate real quadratic level set (Cα​={x:xTAx=α},A=AT,detA=0)

The quadratic form gradient gives Dqx​(h)=2xTAh. Since A is invertible, this linear map is nonzero exactly when x=0. The regular level set theorem therefore makes every nonzero point of Cα​ a smooth point of dimension n−1. If α=0, the entire level set is smooth.
If α=0 and the level set contains a nonzero point, the form is an indefinite quadratic form. Its only singular point is the origin. To prove this rather than merely observe a vanishing derivative, use Sylvester's law of inertia to write q=∣u∣2−∣v∣2 with both sign spaces nonzero. The null vectors ei​±fj​ span the whole ambient space. Their straight-line curves through the origin lie in the cone. If a relatively open neighborhood of the origin in the cone were an embedded submanifold, its tangent space would contain all these directions and hence have dimension n. It would then be open in the ambient space, impossible for the zero set of this nonzero quadratic form. Thus the smooth locus is C0​∖{0}.
