String with an endpoint mass

For a uniform string with tension T>0, linear mass density ρ>0, left end fixed, and a freely transverse-moving point mass M≥0 at x=L, the wave equation and endpoint law are
ρytt​=Tyxx​,y(0,t)=0,Mytt​(L,t)=−Tyx​(L,t).
(36)
The last equation is Newton's second law: the string pulls the mass back toward the interior, giving the minus sign. With wave speed c=T/ρ​, a nonzero normal mode has spatial part X(x)=sin(ωx/c) and satisfies
cotcωL​=ρcMω​.
(37)
For M>0, its dimensionless roots q=ωL/c occur once in each (nπ,nπ+π/2), n≥0, because cotq decreases from infinity to zero while Mq/(ρL) increases. For M=0, q=(n+1/2)π: the right end has a homogeneous Neumann boundary condition. There is no nonzero zero-frequency mode, since a linear spatial profile vanishing at the left end and with zero right slope must vanish everywhere.
Multiplying the spatial equation by X and using integration by parts gives
ω2=ρ∫0L​X2dx+MX(L)2T∫0L​(X′)2dx​>0.
(38)
For two different modes, the same calculation gives the weighted inner product orthogonality ρ∫0L​Xm​Xn​dx+MXm​(L)Xn​(L)=0. The endpoint mass therefore contributes to both inertia and mode orthogonality.
