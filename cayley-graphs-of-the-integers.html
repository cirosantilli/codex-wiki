Cayley graphs of the integers (CayS​(Z))

 Home Mathematics Area of mathematics Geometry and topology Geometric group theory Cayley graph
OurBigBook.com Words: 193
For the additive infinite cyclic group Z, the generating set of a group S={−1,1} produces the infinite line: each integer n is adjacent to n−1 and n+1. Adding the moves ±2 gives T={−2,−1,1,2} and additional edges skipping one vertex. Each skip still costs one step in the word metric.
For integers a,b, these word metrics are
dS​(a,b)=∣a−b∣,dT​(a,b)=⌈2∣a−b∣​⌉.
(14)
The absolute value counts unit moves, and the ceiling function counts pairs plus a possible leftover unit. Every T-move changes the integer by at most two, while moves of size two followed by at most one move of size one attain this bound. For example, the graph path 0,1,2,3,4,5 has five steps for S, while 0,2,4,5 has three for T. This calculation gives the concrete comparison
dT​(a,b)≤dS​(a,b)≤2dT​(a,b).
(15)
The picture shows only a finite window of each infinite Cayley graph. By contrast, U={−2,2} alone fails to be a generating set of a group for Z: it generates the subgroup 2Z. Its move graph has two connected components of a graph, the even integers and the odd integers. Within either component the graph distance is ∣a−b∣/2; between different components no finite graph path exists. Adding a shortcut is different from deleting the moves needed for connectivity.
