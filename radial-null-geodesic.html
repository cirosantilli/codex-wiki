Radial null geodesic

 ... Branches of physics Special relativity Minkowski spacetime Minkowski metric Null curve Null geodesic
OurBigBook.com Words: 22
A radial null geodesic in a spherically symmetric spacetime has zero angular momentum and fixed angular coordinates. Its projection is a null curve of the two-dimensional radial Lorentzian metric.
