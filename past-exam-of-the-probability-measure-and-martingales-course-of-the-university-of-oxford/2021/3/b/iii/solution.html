The optional stopping theorem at a bounded stopping time states that an integrable martingale Zn​ satisfies EZT​=EZ0​ whenever T≤n for a fixed finite n. Apply this first to S at T=n∧τ. The simple symmetric random walk cannot cross an integer endpoint without hitting it, so
a≤Sn∧τ​≤b,ESn∧τ​=0.
(49)
The preceding part gives τ<∞ almost surely, hence Sn∧τ​→Sτ​ almost surely. The constant bound C=max{−a,b} permits the dominated convergence theorem, yielding ESτ​=0. Since Sτ​ is either a or b, solving ap+b(1−p)=0 gives its full probability distribution:
P(Sτ​=a)=b−ab​,P(Sτ​=b)=b−a−a​.​
(50)
Now let
Lτ​=∑k=0τ−1​1{Sk​=0}​.
(51)
This counts the visit at time 0, and excludes the exit time. Apply the same bounded-time optional stopping theorem to Mn​=∣Sn​∣−Ln​. For each n it gives
ELn∧τ​=E∣Sn∧τ​∣.
(52)
The visit counts increase to Lτ​, so monotone convergence applies to the left. Dominated convergence applies to the right using ∣Sn∧τ​∣≤C. Consequently Lτ​ is an integrable random variable and
ELτ​=E∣Sτ​∣=(−a)b−ab​+bb−a−a​=b−a−2ab​.​
(53)
This is the origin case of expected occupation before interval exit for a simple symmetric random walk. The argument obtains integrability of the total occupation count before using any unbounded-time optional stopping for M, so it does not presuppose the uniform integrability asked about next. The endpoint probabilities also agree with the standard gambler's ruin calculation.[ref]
