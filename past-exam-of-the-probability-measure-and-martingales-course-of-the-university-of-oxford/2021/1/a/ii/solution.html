Write A=g(X) and B=g(Y). The two conditional expectation identities supply a σ(Y)-measurable version of B and a σ(X)-measurable version of A. Work with those versions, which do not change any almost sure equality. Both lie in L2 space, and the Cauchy-Schwarz inequality makes their product an integrable random variable.
Testing the first conditional expectation identity against B, and the second against A, gives
E[AB]=E[B2],E[AB]=E[A2].
(4)
For completeness, these tests with unbounded multipliers are valid by first using the bounded truncations Bm​=(−m)∨(B∧m) and Am​=(−m)∨(A∧m), then passing to the limit with the Cauchy-Schwarz inequality and convergence in L2. Consequently,
E[(A−B)2]=E[A2]+E[B2]−2E[AB]=0.
(5)
A nonnegative random variable with zero expected value vanishes almost surely. Therefore g(X)=g(Y) almost surely. This is mutual conditional expectation rigidity in L2; it also follows from the equality case for conditional second moments.
For a counterexample to equality of the original random variables, let X give probability 1/4 to each of −2,−1,1,2, set Y=−X, and use the nonconstant function g(t)=t2. Then g(X)=g(Y)=X2 takes both values 1 and 4. It is measurable with respect to both generated sigma-algebras, so both required conditional expectation identities hold. Symmetry gives EX=EY=0, while neither random variable can be zero. Thus
P(X=EX)=P(Y=EY)=0,P(X=Y)=0.​
(6)
