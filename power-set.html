Power set (P(X))

 Home Mathematics Area of mathematics Foundations of mathematics Set theory Set
OurBigBook.com Words: 245 Articles: 1
The power set P(X) is the set of all subsets of X, including the empty set and X itself. It is useful whenever an object is a selection rather than an individual member: a possible collection of active vertices in a graph, for example, belongs to the power set of the vertex set.
For X={a,b,c}, the power set has eight members:
P(X)={∅,{a},{b},{c},{a,b},{a,c},{b,c},{a,b,c}}.
(10)
Each of the three set elements is either included or excluded. More generally, if ∣X∣=n<∞, these n independent binary choices give ∣P(X)∣=2n. This is a bijection between subsets and binary strings of length n, not a probabilistic independence assumption.
Ordering the subsets by inclusion gives a Boolean lattice. In the picture an upward edge adds one member. Complementation reverses inclusion, and union and intersection combine selections. The empty-input case is worth checking: P(∅)={∅} has one member, not zero, consistently with 20=1.
