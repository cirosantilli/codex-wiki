Randomly shifted lattice point process (Π=∑k∈Z​δk+U​)

Let U have the uniform distribution on [0,1) and place a point at every k+U, k∈Z. This is a simple point process, locally finite, and a stationary point process: a translation only changes the phase modulo one, preserving its uniform distribution. For every Borel set A, the Tonelli theorem gives
E[Π(A)]=∑k∈Z​∫01​1A​(k+u)du=∣A∣.
(13)
Its consecutive points are exactly one unit apart, despite having the same intensity measure as a unit-rate Poisson point process. This is the one-dimensional translated-grid construction.[ref]
Every half-open interval of length one contains exactly one point. For A=[0,1/2) and B=[1/2,1), Π(A)+Π(B)=1, each count has the Bernoulli distribution with parameter 1/2, and
Cov(Π(A),Π(B))=0−21​21​=−41​.
(14)
More generally, an interval of length L=m+r, with m a nonnegative integer and 0≤r<1, contains m or m+1 points with probabilities 1−r and r. Its count variance is r(1−r), while a unit-rate Poisson point process has count variance L.
