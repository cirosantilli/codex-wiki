Scalar contraction test for a Cartesian tensor (A′:(RBRT)=A:B ∀B ⟹A′=RART)

 ... Area of mathematics Algebra Linear algebra Multilinear algebra Tensor Quotient theorem for Cartesian tensors
OurBigBook.com Words: 160 Articles: 2
If an array specified in each orthonormal basis has invariant Frobenius inner product with every Cartesian second-rank tensor, it transforms as such a tensor. For a component change R, invariance says (RTA′R−A):B=0 for every matrix B. Nondegeneracy of the Frobenius inner product forces the difference to vanish. Testing every tensor, rather than a single selected tensor, is essential.
