Control point (Pi​)

 Home Mathematics Area of mathematics Analysis Numerical analysis Computer aided geometric design
OurBigBook.com Words: 829 Articles: 3
A control point is an editable geometric handle used to specify a curve or surface through a basis or refinement rule. The handle is part of the representation; it need not be a point on the resulting curve. In a Bézier curve, the control points are the geometric coefficients of the Bernstein basis. Joining them in order gives a control polygon, which makes the handles easy to manipulate without drawing the curve as a chain of line segments.[ref]
For example, use the cubic Bézier curve with control points
P0​=(0,0),P1​=(1,2),P2​=(3,2),P3​=(4,0).
(1)
Its Bernstein basis representation gives
C(t)=(3t+3t2−2t3,6t(1−t)),0≤t≤1,C(1/2)=(2,1.5).
(2)
The greatest height is 1.5, so neither interior control point, both at height 2, lies on this curve. The endpoint control points do lie on it: C(0)=P0​ and C(1)=P3​. This separates interpolation, which requires passage through prescribed data, from an approximating representation, which uses handles to shape a curve without requiring passage through every handle. If measured points must be interpolated, choose control points to satisfy those constraints; simply using the measured points as the handles of a Bézier curve does not enforce interpolation.
Now move only P1​ by the vector h=(0,1), giving P1​=(1,3). With the Bernstein basis and parameter t unchanged, the new curve is
C(t)=C(t)+3t(1−t)2h.
(3)
At t=1/2 this gives C(1/2)=(2,15/8), a displacement (0,3/8) despite moving the handle by a full unit. Both endpoints stay fixed because the coefficient 3t(1−t)2 vanishes there. Thus dragging a control point shapes a whole range of the curve; it does not generally drag an arbitrary selected point on the curve by the same vector. The control-point influence on a curve tells us exactly how much each parameter value moves.
