d-ary heap

 Home Computer science Data structure Heap data structure
OurBigBook.com Words: 147 Articles: 1
A heap data structure stored as a complete rooted tree with up to d children per vertex, where d≥2. The final level is filled from left to right. For zero-based array storage, the parent of entry i>0 is ⌊(i−1)/d⌋, and its child number j∈{0,…,d−1} has index di+j+1 when that index is inside the active heap. There are at most O(1+logd​n) levels containing n entries.
