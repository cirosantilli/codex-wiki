Direct SAT encoding of finite-domain constraints (φP​)

 ... Computer science Theoretical computer science Computational complexity theory Computational problem Search problem Constraint satisfaction problem
OurBigBook.com Words: 132
Represent each original value choice Xi​=v by a Boolean variable pi,v​ and impose an exactly-one constraint for each original variable. For every forbidden tuple (vi​)i∈S​ of a constraint with scope S, add the Boolean clause ⋁i∈S​¬pi,vi​​. A complete original assignment satisfies every constraint exactly when its one-hot indicators satisfy all these Boolean clauses: each forbidden-tuple Boolean clause excludes precisely that joint choice. A satisfying assignment decodes by reading the unique true indicator for each original variable.
For constraint domain sizes qi​, pairwise uniqueness requires ∑i​(2qi​​) Boolean clauses. If a constraint has fC​ forbidden tuples and arity rC​, its contribution is fC​ Boolean clauses and rC​fC​ literal occurrences. Thus bounded arity gives a polynomial-size encoding in explicitly listed domains, whereas enumerating a succinct high-arity relation can be exponential in its description length. Unit propagation on this encoding can be weaker than arc consistency on the original binary constraints.
