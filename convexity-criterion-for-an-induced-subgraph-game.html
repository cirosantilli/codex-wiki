Convexity criterion for an induced subgraph game (v is supermodular⟺wij​≥0 for all i=j)

A loop-free induced subgraph game is a convex cooperative game exactly when all edge weights are nonnegative. Necessity follows by testing the supermodular inequality on two distinct singleton coalitions. For sufficiency,
v(S∪T)+v(S∩T)−v(S)−v(T)=∑i∈S∖T, j∈T∖S​wij​≥0.
(20)
Only edges connecting the two set differences survive cancellation. Loop contributions cancel as well, so the same off-diagonal condition remains sufficient and necessary when self-loops are added.
