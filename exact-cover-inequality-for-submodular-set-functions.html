Exact-cover inequality for submodular set functions (∑i=1t​f(Ti​)≥kf(T))

 ... Area of mathematics Foundations of mathematics Set theory Function Set function Submodular set function
OurBigBook.com Words: 90
Suppose f is a normalised set function and a submodular set function, and T1​,…,Tt​⊆T cover every element of T exactly k times, counting repetitions in the indexed collection. Then the displayed inequality holds. Neither the monotone set function property nor the nonnegative function property is required.
Proof. Fix an ordering of T and write aj​=f(Pj​)−f(Pj−1​) for its successive marginal increments. The chain lower bound for a submodular set function gives f(Ti​)≥∑xj​∈Ti​​aj​. Summing counts each aj​ exactly k times, and ∑j​aj​=f(T). Exact coverage matters because the aj​ may be negative. For a monotone set function, the same argument also allows each element to occur at least k times.
