Transferable utility game (v:2N→R,v(∅)=0)

 Home Mathematics Area of mathematics Mathematical optimization Game theory Cooperative game theory
OurBigBook.com Words: 2k Articles: 28
A finite transferable utility game gives each coalition S⊆N a real value v(S) that its members can distribute among themselves. The usual normalization is v(∅)=0. An efficient payoff vector x satisfies ∑i∈N​xi​=v(N). Simple cooperative games model winning coalitions with values zero and one; convex cooperative games model increasing marginal contributions.
