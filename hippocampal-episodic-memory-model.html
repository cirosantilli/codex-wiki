Hippocampal episodic memory model

 Home Biology Neuroscience Brain Hippocampus
OurBigBook.com Words: 45
A circuit-level hypothesis combining sparse input coding and pattern separation in the dentate gyrus, recurrent autoassociation in hippocampal CA3, and learned pattern association through hippocampal outputs. It explains a route from an incomplete cue to reinstated event content. Context, event order, interference and changing cortical dependence remain requirements beyond a simple fixed-point memory.
