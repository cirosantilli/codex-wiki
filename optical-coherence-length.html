Optical coherence length (Lc​=cτc​)

 ... Optics Physical optics Optical coherence First-order optical coherence Temporal optical coherence Optical coherence time
OurBigBook.com Words: 213 Articles: 1
In this temporal sense, the optical coherence length is Lc​=cτc​, where c is the vacuum speed of light and τc​ is an explicitly chosen optical coherence time. It measures a delay as a vacuum-equivalent path difference; it does not measure transverse spatial optical coherence. [ref].
For the stipulated 1GHz profiles, the 1/e convention gives Lc​≈9.54269cm for the Lorentzian and 15.8896cm for the Gaussian. In a vacuum Michelson interferometer, changing one mirror position by x changes the round-trip delay by 2x/c, so the mirror travel to either of these delays is Lc​/2. In a medium, convert physical travel using the actual group delay, which can depend on frequency. For a narrow line centered at vacuum wavelength λ0​, differentiating ν=c/λ gives Δν≈cΔλ/λ02​; this small-width approximation must use consistently defined spectral widths.
