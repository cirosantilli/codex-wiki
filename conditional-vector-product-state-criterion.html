Conditional-vector product-state criterion

 ... Physics Branches of physics Quantum theory Bell state Reduced density matrix Product state
OurBigBook.com Words: 78
A nonzero bipartite pure state is a product state if and only if all its partial inner products on the first subsystem lie in a common one-dimensional vector subspace of the second. For a product ∣a⟩⊗∣b⟩, every contraction equals ⟨u∣a⟩∣b⟩. Conversely, contract against each vector of an orthonormal basis to write ∣Ψ⟩=∑i​∣i⟩⊗∣χi​⟩. If ∣χi​⟩=ci​∣b⟩ for a common nonzero ∣b⟩, then ∣Ψ⟩=(∑i​ci​∣i⟩)⊗∣b⟩. Zero conditional vectors are allowed. A nontrivial linear dependence relation requires multipliers not both zero; allowing both multipliers to vanish would give no test at all.
