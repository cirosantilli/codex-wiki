Fixed-length lossy code (Rn​=n−1log2​Mn​)

 ... Mathematics Area of mathematics Probability and statistics Information theory Rate-distortion theory Rate-distortion function
OurBigBook.com Words: 60
A fixed-length lossy code maps a block of n source symbols to one of Mn​ messages, then maps that message to a reconstruction block. The encoder and decoder together define the reconstruction. Its rate is log2​Mn​/n bits per source symbol; an implementation using a fixed binary message needs ⌈log2​Mn​⌉ transmitted bits per block. Its performance also depends on expected distortion, block length, and the chosen distortion measure.
