Good rate function (I)

 ... Area of mathematics Probability and statistics Probability theory Convergence of random variables Large deviation principle Rate function
OurBigBook.com Words: 103 Articles: 1
A rate function is a lower semicontinuous map I:E→[0,∞]. It is good if every sublevel set {I≤M} is a compact set. This property controls escapes to infinity and makes the minimizations in the contraction principle for large deviations attain their finite infima. On Rd, a lower semicontinuous rate function tending to infinity with the norm is good.
