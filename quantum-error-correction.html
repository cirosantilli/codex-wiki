Quantum error correction (QEC)

 Home Physics Branches of physics Quantum theory
OurBigBook.com Words: 5k Articles: 57
Quantum error correction protects a logical qubit by encoding its quantum state into a larger Hilbert space, where a specified family of physical errors can be diagnosed and reversed by a common recovery quantum channel. The requirement is to restore every encoded quantum superposition, including its relative phase, rather than only the computational basis states. A quantum error-correcting code specifies which errors have this protection; it does not promise recovery from every possible disturbance.
The beautiful idea is to measure relations between physical qubits that reveal an error syndrome while revealing nothing about the protected logical qubit. For example, the bit-flip repetition code compares neighboring qubits without reading their individual values. Its parity checks can locate one Pauli X gate error while leaving the unknown coefficients intact. Encoding is a linear isometry, consistent with the no-cloning theorem: redundancy in a shared quantum state supplies protection without making independent copies of the unknown input.
Peter W. Shor's 1995 paper [ref], published on 1 October, introduced the nine-qubit Shor code to reduce quantum decoherence in memory. Andrew M. Steane's [ref], published on 29 July 1996 and [ref], connected quantum error correction to classical linear codes; the seven-qubit Steane code protects against arbitrary errors on one physical qubit. These constructions protect relative phase as well as computational basis values, going beyond the elementary bit-flip repetition code.
For an authored account of the mechanism, see John Preskill's [ref], especially section 7.1 on collective parity measurements and section 7.9 on stabilizer codes. Andrew Steane's A tutorial on quantum error correction develops the distinction between correcting a stored quantum state and operating with imperfect quantum gates.

Decoherence-free subspace

Words: 132 Articles: 1
Quantum error correction OurBigBook.com
A subspace on which every operator in a specified noise model acts as a common scalar, so the encoded density operator is preserved without syndrome-dependent recovery. For collective z rotations, the span of ∣01⟩ and ∣10⟩ has zero total Z eigenvalue and is invariant. Protection depends on the collective-noise assumption; independent local rotations do not generally preserve its logical phase.

Two-spin decoherence-free encoding (∣0L​⟩=∣01⟩,∣1L​⟩=∣10⟩)

Words: 74
Decoherence-free subspace OurBigBook.com
The zero-total-Z eigenspace of two spin one-half systems stores one logical qubit. Both basis states satisfy (ZI+IZ)∣ψ⟩=0, so every collective dephasing rotation acts as the identity operator on their span. Also ZZ∣01⟩=−∣01⟩ and ZZ∣10⟩=−∣10⟩, so simultaneous Pauli Z gates preserve every encoded density matrix. For independent rotations, the logical amplitudes instead acquire phases e−i(ϕ1​−ϕ2​)/2 and ei(ϕ1​−ϕ2​)/2, which generally alter their relative phase. The code is not a two-dimensional decoherence-free subspace for arbitrary collective rotations about all axes; the invariant two-spin singlet alone is only one-dimensional.

Quantum error-correcting code (C⊆(C2)⊗n)

Words: 64
Quantum error correction OurBigBook.com
A quantum error-correcting code is a subspace encoding a logical Hilbert space, together with a specified family of noise operators that a common recovery quantum channel reverses on every encoded state. A K-dimensional code carries log2​K logical qubits. For a code projector P, correctability is characterized by the Knill--Laflamme condition; code distance is defined by the smallest undetectable operator weight, not merely by the number of generators.

A concatenated quantum code replaces each physical qubit of an outer code by a logical qubit of an inner code. Correction proceeds from inner blocks to outer blocks. Concatenated quantum error-correcting code OurBigBook.com
Assume independent physical-error probability p, correction of zero or one errors, and failure on every block with at least two errors. The failure map is f(p)=1−(1−p)5−5p(1−p)4. Five-qubit error correcting code ([[5,1,3]])

Words: 114 Articles: 1
Quantum error correction OurBigBook.com
The five-qubit code encodes one logical qubit into five physical qubits and corrects an arbitrary error on one physical qubit. In a nondegenerate realization, the identity and fifteen one-qubit Pauli operators take the two-dimensional code into sixteen mutually orthogonal syndrome subspaces, filling the 32-dimensional physical Hilbert space.

Five-qubit stabilizer syndrome table (S=⟨XZZXI,IXZZX,XIXZZ,ZXIXZ⟩)

Words: 69
Five-qubit error correcting code OurBigBook.com
The four commuting independent stabilizer generators define a two-dimensional stabilizer code. The identity and fifteen single-site Pauli errors have sixteen distinct four-bit error syndromes, so their two-dimensional images form an orthogonal direct sum of the physical space. This proves nondegenerate single-site correction and the perfect quantum error-correcting code property. The operators X⊗5 and Z⊗5 commute with the stabilizer and anticommute with each other. Multiplying X⊗5 by XZZXI gives, up to phase, IYYIX, a nontrivial weight-three logical operator, proving distance exactly three.

Quantum error detection (PEP=cE​P)

Words: 153 Articles: 1
Quantum error correction OurBigBook.com
A code with orthogonal projector P detects an error E when its compression to the code is scalar. A projective measurement of P then either flags departure from the code or, on a successful code-space outcome, leaves the logical state unchanged up to normalization. This includes harmless scalar errors, even though they need not produce a nonzero error syndrome. Detectability extends by linearity to the span of a set of errors. Every Pauli operator of weight less than the quantum code distance is detectable.

Correction implies detection at twice the weight (correct all weights ≤t ⟹ detect all weights ≤2t)

Words: 79
Quantum error detection OurBigBook.com
Split the support of a Pauli operator of weight at most 2t into two sets of size at most t. It is, up to a scalar phase, Ea†​Eb​ for two errors in the correctable family. The Knill--Laflamme condition makes its compression to the code scalar, which is quantum error detection. Expansion in the Pauli basis extends the assertion to every operator supported on at most 2t qubits. The number t counts affected qubits, not the cardinality of an arbitrary selected family of errors.

Nondegenerate quantum error-correcting code

Words: 176 Articles: 2
Quantum error correction OurBigBook.com
For a specified correctable set of distinct Pauli operators modulo phase, a nondegenerate code has mutually orthogonal error images EX. Equivalently, the matrix in the Knill--Laflamme condition is diagonal for that Pauli error set. Each error therefore requires a separate syndrome subspace of dimension equal to the logical code dimension. Degenerate codes can have distinct errors with the same action on the code and do not satisfy this orthogonality counting argument.

Quantum Hamming bound (∑j=0t​3j(jn​)≤2n−k)

Words: 107 Articles: 1
Nondegenerate quantum error-correcting code OurBigBook.com
For unknown-location Pauli operators of weight at most t, there are N(t)=∑j=0t​3j(jn​) physically distinct errors modulo phase, including the identity. A nondegenerate quantum code assigns them mutually orthogonal error-image subspaces, each of dimension 2k, within the 2n-dimensional physical Hilbert space. Hence N(t)2k≤2n. The hypothesis of nondegeneracy is essential to this dimension count.

Perfect quantum error-correcting code (2k∑j=0t​3j(jn​)=2n)

Words: 56
Quantum Hamming bound OurBigBook.com
A nondegenerate quantum code is perfect at correction radius t if its distinct correctable Pauli error images exhaust the physical Hilbert space. Each image has dimension 2k, and their orthogonal direct sum is the whole 2n-dimensional space precisely when the quantum Hamming bound is an equality. This perfectness concerns unknown-location errors of weight at most t; it does not imply correction of every higher-weight error.

Distance of a quantum error-correcting code ([[n,k,d]])

Words: 327 Articles: 3
Quantum error correction OurBigBook.com
An [[n,k,d]] quantum error correction code is a 2k-dimensional subspace of n qubits. Its distance d is the minimum weight of a Pauli operator E for which PEP is not a scalar multiple of the code projector P. Thus every operator supported on fewer than d qubits has scalar compression to the code, by expansion in the Pauli basis. This definition includes degenerate codes; a low-weight operator acting as a scalar does not reduce the distance.

Correctable Pauli error radius (t=⌊(d−1)/2⌋)

Words: 81
Distance of a quantum error-correcting code OurBigBook.com
The guaranteed radius is the largest integer t for which all unknown-location Pauli operators of weight at most t can be corrected together. Pairwise products have weight at most 2t, so 2t<d suffices by the Knill--Laflamme condition. Conversely, split a minimum-weight undetectable Pauli operator between two subsets of its support. If d≤2t, this gives two errors of weight at most t whose pairwise product violates that condition. Consequently d is either 2t+1 or 2t+2; parity cannot be recovered from t alone.

Quantum Singleton bound (n−k≥2(d−1))

Words: 93
Distance of a quantum error-correcting code OurBigBook.com
For a code carrying k>0 logical qubits, two disjoint subsets A,B of d−1 physical qubits are each correctable erasures. Purify the maximally mixed logical input using a reference R, and call the remaining physical subsystem C. Erasure decoupling gives S(RA)=S(R)+S(A) and S(RB)=S(R)+S(B). Purity and Subadditivity of Von Neumann entropy imply 2S(R)≤2S(C), hence k≤n−2(d−1). If two such disjoint subsets would not fit, partition the entire physical system into two correctable subsets; purity and decoupling then force S(R)=0, a contradiction. Thus the partition used in the proof is justified independently of the bound.

Quantum erasure correction (m<d)

Words: 80
Distance of a quantum error-correcting code OurBigBook.com
Errors on a known subset of m qubits are correctable by a distance-d code whenever m<d. Every product Ea†​Eb​ of errors supported on that subset still has support in the same subset, so its compression is scalar. The Knill--Laflamme condition therefore supplies one recovery for every channel on that subset. Equivalently, erasing the subset leaks no logical information to it: if a reference is maximally entangled with the encoded logical system, its joint density operator with the erased subsystem is a product state.

Linearity of coherent quantum error correction

Words: 91
Quantum error correction OurBigBook.com
Suppose fixed unitary encoding and recovery correct each error Ej​ by mapping every logical input ∣ψ⟩ to ∣ψ⟩⊗∣ηj​⟩. The syndrome vector can be taken independent of the logical input: applying linearity to basis inputs and their equal superposition forces their syndrome vectors to agree. Hence an error E=∑j​cj​Ej​ is mapped to ∣ψ⟩⊗∑j​cj​∣ηj​⟩. If E is unitary, this final syndrome vector is normalized and the circuit corrects E. Orthogonality of the syndrome states is not needed for the linear-span argument; it is a separate condition concerning distinguishability of errors.

Necessity of the Knill-Laflamme condition (PEa†​Eb​P=∑μ​cμa∗​cμb​P)

Words: 70
Knill--Laflamme condition OurBigBook.com
If a common recovery quantum channel with Kraus operators Rμ​ restores every pure code state after each error Ea​, then each vector Rμ​Ea​∣ψ⟩ is parallel to ∣ψ⟩. Linearity on basis vectors and their pairwise superpositions forces Rμ​Ea​P=cμa​P, with the scalar independent of the logical state. Insert ∑μ​Rμ†​Rμ​=I between two error operators to obtain the displayed Knill--Laflamme condition. This proves necessity without presuming an orthogonal syndrome description of recovery.

Constructive recovery from the Knill-Laflamme condition (PEa†​Eb​P=Cab​P)

Words: 92
Knill--Laflamme condition OurBigBook.com
The matrix C in the Knill--Laflamme condition is positive semidefinite, since v†Cv is the squared norm of ∑a​va​Ea​∣ψ⟩ for any normalized code state. Diagonalizing it gives linear combinations Fj​ with PFj†​Fl​P=cj​δjl​P. For cj​>0, Vj​=Fj​P/cj​​ is an isometry of the code into an error-image subspace, and these subspaces are orthogonal. Measuring their projectors and applying Vj†​ recovers the logical state. Complete the operation arbitrarily on the orthogonal complement to obtain a quantum channel. This construction corrects every noise map whose Kraus operators lie in the specified error span, including coherent superpositions of error operators.

Stabilizer code (C={∣ψ⟩:gj​∣ψ⟩=∣ψ⟩ ∀j})

Words: 3k Articles: 34
Quantum error correction OurBigBook.com
A stabilizer code is the common +1 eigenspace of a stabilizer group S, an abelian subgroup of the Pauli group excluding −I. Choose r independent stabilizer generators g1​,…,gr​ on n physical qubits. They are commuting Hermitian operators, each squaring to I. The stabilizer subspace and its orthogonal projector are
C={∣ψ⟩:gj​∣ψ⟩=∣ψ⟩ for j=1,…,r},P=∏j=1r​2I+gj​​=∣S∣1​∑g∈S​g.
(1)
The stabilizer-projector formula gives dimC=2n−r, so k=n−r logical qubits remain. Independent here means that no nonempty product of the chosen stabilizer generators is I. Excluding −I is necessary: a vector cannot simultaneously be fixed by I and −I unless it is zero.
For the three-qubit bit-flip repetition code, take g1​=Z1​Z2​ and g2​=Z2​Z3​, with Zj​ the Pauli Z gate on site j and identities elsewhere. The stabilizer group is S={I,Z1​Z2​,Z2​Z3​,Z1​Z3​}. Both stabilizer generators have eigenvalue +1 exactly on the span of ∣000⟩ and ∣111⟩, giving 23−2=2 dimensions for one logical qubit. A projective measurement of these checks distinguishes four orthogonal two-dimensional sectors rather than eight individual computational basis states.
A Pauli error that anticommutes with a stabilizer generator changes that check's sign, producing an error syndrome. A Pauli operator commuting with every check can still act on the logical qubits; the centralizer of a stabilizer group describes these possibilities. Thus the number of checks determines the encoded dimension, while the quantum code distance determines protection against arbitrary local errors. The five-qubit error correcting code, for instance, has four stabilizer generators and quantum code distance three; the three-qubit bit-flip repetition code has two checks but quantum code distance one because a single phase flip is unflagged. [ref].

Symplectic representation of a stabilizer code

Words: 50
Stabilizer code OurBigBook.com
A stabilizer group with r independent generators maps injectively to an r-dimensional isotropic subspace of the binary symplectic space of Pauli labels. For generator rows (A∣B), commutation is ABT+BAT=0 over F2​. Its stabilizer subspace has dimension 2n−r. The labels of the centralizer of a stabilizer group form L⊥; labels in L⊥∖L act as nontrivial logical Pauli operators.

CSS code ([[N,k1​−k2​,d]])

Words: 168 Articles: 1
Stabilizer code OurBigBook.com
For binary linear codes C2​⊆C1​⊆F2N​, the CSS code has basis ∣x+C2​⟩=∣C2​∣−1/2∑y∈C2​​∣x+y⟩ for x∈C1​/C2​. Its X stabilizers come from C2​ and its Z stabilizers from the dual code C1⊥​; their commutation follows from orthogonality. For positive logical dimension, dX​=min{wt(x):x∈C1​∖C2​} and dZ​=min{wt(z):z∈C2⊥​∖C1⊥​}, with quantum code distance d=min(dX​,dZ​). Thus arbitrary errors on at most ⌊(d−1)/2⌋ qubits are correctable. Stabilizer errors are harmless even if their weight is small; the distances exclude them.

Nested-code CSS syndrome recovery (C⊆C′,[[N,dimC′−dimC,d]])

Words: 94
CSS code OurBigBook.com
For binary linear codes C⊆C′, the coset superpositions of the CSS code have X checks labelled by C and Z checks by (C′)⊥. A bit-error pattern a gives the classical syndrome for C′, and a phase-error pattern b gives the syndrome for the dual code C⊥. Errors with 2tX​<mina∈C′∖C​wt(a) and 2tZ​<minb∈C⊥∖(C′)⊥​wt(b) are jointly correctable. Every pairwise Pauli-error product either anticommutes with a check, giving zero code compression, or its low-weight components belong to the stabilizer and give scalar compression. Thus the Knill--Laflamme condition covers coherent superpositions and quantum channels as well as definite bit and phase errors.

Pauli error criterion for a stabilizer code

Words: 92
Local correctability of a stabilizer code OurBigBook.com
Let S exclude −I, let C(S) be its Pauli centralizer, and let Z={±I,±iI}. A set of Pauli errors is jointly correctable exactly when every product Ea†​Eb​ belongs to ZS or lies outside C(S). Outside the centralizer its code compression is zero by anticommutation; in ZS it acts as a scalar. A centralizing operator outside ZS has zero trace on the code but is unitary there, so cannot be scalar. This gives precisely the Knill--Laflamme condition. Scalar phases must be retained when formulating the group criterion.

gj​E=(−1)sj​Egj​,gj​E∣ψL​⟩=(−1)sj​E∣ψL​⟩.

The commuting checks admit joint orthogonal projectors
Πs​=∏j=1r​2I+(−1)sj​gj​​,∑s∈{0,1}r​Πs​=I,Π0​=P.

An error syndrome locates an error only relative to an assumed family and a recovery rule. Two Pauli errors differing by a logical operator can share an error syndrome; see stabilizer-syndrome coset. In the three-qubit bit-flip syndrome table, X3​ and X1​X2​ both give 01. Recovering with X3​ corrects the first but converts the second into the logical operator X1​X2​X3​. Likewise, Z1​ has error syndrome 00 yet changes the encoded relative phase.

Phase-flip repetition code

The n-qubit phase-flip repetition code is stabilized by Xj​Xj+1​ and has codewords ∣+⟩⊗n and ∣−⟩⊗n. It has logical operators Z=X1​ and X=Z1​⋯Zn​, so its distance against phase flips is n.

Logical Hadamard convention for a phase-flip repetition code

Words: 65
Phase-flip repetition code OurBigBook.com
The codewords ∣+++⟩,∣−−−⟩ have residual logical Pauli X gate after an uncorrectable two- or three-site phase error. Precede their encoding by a logical Hadamard gate and follow decoding by its inverse. Since HXH=Z, the same error now acts as a logical Pauli Z gate. Explicitly the encoded coefficients are (α+β)/2​ and (α−β)/2​ for an input α∣0⟩+β∣1⟩. This convention matters when translating physical phase errors into a claimed decoded phase-error channel.

Logical failure of the three-qubit phase-flip repetition code (pL​=3ϵ2−2ϵ3)

Words: 77
Phase-flip repetition code OurBigBook.com
The phase-flip repetition code with codewords ∣+++⟩,∣−−−⟩ corrects any one physical Pauli Z gate error. Its two adjacent-pair error syndromes cannot distinguish an error pattern from its three-bit complement. Minimum-weight recovery therefore leaves no residual error at weight zero or one, and leaves Z1​Z2​Z3​ at weight two or three. This residual operator exchanges the codewords, so inverse encoding gives a logical Pauli X gate. For independent physical phase errors of probability ϵ, the decoded quantum channel is (1−pL​)ρ+pL​XρX, where pL​=3ϵ2(1−ϵ)+ϵ3. For 0<ϵ<1/2, ϵ−pL​=ϵ(1−ϵ)(1−2ϵ)>0.

Phase-flip protection by Hadamard conjugation

Words: 88
Phase-flip repetition code OurBigBook.com
Insert Hadamard gates on every data qubit immediately after encoding by a bit-flip repetition code and immediately before its bit-flip detection and recovery. The intervening physical error is thereby conjugated by H⊗n, and HZH=X turns a single Pauli Z gate error into a single bit flip for the original correction circuit. The encoded logical codewords are now ∣+⟩⊗n and ∣−⟩⊗n. The syndrome ancillas and the final inverse encoding stay unchanged. This protects against phase flips in the new basis; it does not simultaneously correct arbitrary bit flips in the physical basis.

Majority-vote decoding of a repetition code

Words: 35
Phase-flip repetition code OurBigBook.com
For independent errors of probability p<1/2, maximum-likelihood decoding of a repetition code chooses the lower-weight error compatible with the syndrome. This is majority voting, with threshold pc​=1/2 and exponentially vanishing logical-error probability below threshold.

Bit-flip repetition code (∣0L​⟩=∣0⟩⊗m,∣1L​⟩=∣1⟩⊗m)

(4)
This does not produce (α∣0⟩+β∣1⟩)⊗3, which would contain cross terms. For example, encoding ∣+⟩=(∣0⟩+∣1⟩)/2​ produces (∣000⟩+∣111⟩)/2​, whereas three independent copies would have eight equal computational basis amplitudes. The encoding creates quantum entanglement when both coefficients are nonzero and respects the no-cloning theorem.
The three-qubit bit-flip syndrome table corrects the family {I,X1​,X2​,X3​} and its entire linear span, as specified by the Knill--Laflamme condition. It cannot correct arbitrary errors on one physical qubit: the phase flip
Z1​∣ψL​⟩=α∣000⟩−β∣111⟩
(5)
commutes with both checks and acts as logical Z. In particular, it takes the encoded ∣+⟩ to the orthogonal encoded ∣−⟩ with error syndrome 00. Thus its full quantum code distance is one, despite correcting one error of the restricted Pauli X gate type. The Shor code, Steane code and five-qubit error correcting code provide protection against arbitrary one-qubit errors.

Each pair of computational basis words within a row has the same two parities. Consequently the projective measurement reveals the row without distinguishing its two amplitudes. For example, ∣ψL​⟩=(3​/2)∣000⟩+(i/2)∣111⟩ becomes (3​/2)∣010⟩+(i/2)∣101⟩ under X2​. Both checks give −1 with probability one, and applying X2​ restores both coefficients exactly, including the relative phase i.
One implementation uses two quantum ancillas initialized to ∣00⟩. Two controlled-NOT gates from data qubits 1 and 2 to the first quantum ancilla write their parity; two more from data qubits 2 and 3 to the second quantum ancilla write the other parity. Measuring only the quantum ancillas in the computational basis gives (s1​,s2​). Measuring the individual data qubits instead would reveal the encoded computational basis value and destroy the unknown quantum superposition. The existing coherent syndrome extraction for the three-qubit repetition code uses the alternative ordered checks (Z2​Z3​,Z1​Z3​), so its bit labels differ from this table.
The recovery also handles coherent errors. Put E0​=I,E1​=X1​,E2​=X2​,E3​=X3​. Their images of the code are mutually orthogonal, giving PEa†​Eb​P=δab​P, the Knill--Laflamme condition for this family. For any linear combination E=∑a=03​ca​Ea​, its component in sector s(Ea​) is ca​Ea​∣ψL​⟩. Measuring that error syndrome has probability ∣ca​∣2/∑b​∣cb​∣2 on the normalized erroneous state, and recovery Ea​ returns ∣ψL​⟩. More generally one recovery quantum channel corrects every noise quantum channel whose Kraus operators belong to this span. The assumption concerns the whole jointly correctable family; it does not extend to the span of arbitrary single-site Pauli errors. [ref].
A fully computed coherent example is the unitary operator U=exp(−iθX2​)=cosθI−isinθX2​. At θ=π/6 it gives
U∣ψL​⟩=23​​∣ψL​⟩−2i​X2​∣ψL​⟩.
(6)
The error syndromes 00 and 11 occur with probabilities 3/4 and 1/4, independently of α,β. Doing nothing for 00 and applying X2​ for 11 restores the same logical qubit in both branches; the scalar −i in the second branch is an irrelevant global phase. This is an example of linearity of coherent quantum error correction, rather than an assumption that the original error was a classical random bit flip.

Logical failure of the three-qubit bit-flip repetition code (pL​=3p2−2p3)

Words: 314
Bit-flip repetition code OurBigBook.com
Assume that each physical qubit undergoes an independent quantum bit-flip channel with probability p during one storage interval, and that encoding, error syndrome extraction, recovery and decoding are all ideal. Use the three-qubit bit-flip syndrome table to apply the indicated minimum-weight recovery. Zero or one bit flips are corrected. Two bit flips have the same error syndrome as the complementary one-site error: for example, X1​X2​ gives 01, so recovery X3​ leaves X=X1​X2​X3​. Three bit flips give 00 and also leave X. This exchanges ∣000⟩ and ∣111⟩, and therefore acts as a logical Pauli X gate after decoding.
The number of physical bit flips has a binomial distribution with three trials, hence the logical-error probability is
pL​=(23​)p2(1−p)+p3=3p2−2p3.
(7)
For a logical density operator ρ, the decoded quantum channel is exactly ρ↦(1−pL​)ρ+pL​XρX. Here logical failure means a nontrivial logical Pauli X gate error; a particular input such as ∣+⟩ can be invariant under that error. At p=0.1, exactly two flips have probability 3(0.1)2(0.9)=0.027 and three flips have probability (0.1)3=0.001, giving pL​=0.028. The block succeeds with probability 0.972 compared with 0.9 for an unencoded qubit. At p=0.01, pL​=0.000298, illustrating the quadratic suppression of rare independent bit flips.
Factoring the improvement gives
p−pL​=p(1−p)(1−2p).
(8)
Thus one level reduces logical-error probability for 0<p<1/2, is equal at p=0,1/2,1, and makes it worse for 1/2<p<1 under this same decoder. The suppression arises because a logical error requires at least two physical bit flips. With independent disjoint inner blocks, the same noise model and ideal correction at every level, a concatenated quantum error-correcting code has pℓ+1​=3pℓ2​−2pℓ3​, with p0​=p. At p0​=0.1, two levels use nine data qubits and give p2​=3(0.028)2−2(0.028)3=0.002308096.
This calculation describes ideal correction of stored information with the specified quantum bit-flip channel. Repeated correction in time additionally requires a fresh specified noise model for each interval; imperfect quantum gates, faulty measurements and correlated errors change the calculation. The timed bit flip during repetition-code syndrome extraction and exact encoded-state failure with a faulty parity check show concretely why this storage calculation alone is not a fault-tolerance result.

Exact encoded-state failure with a faulty parity check (Pfail​=q+(1−q)(3p2−2p3))

For independent channel bit flips of probability p and the specified extraction fault of probability q, require recovery of an arbitrary input in the original encoded subspace. Every extraction-fault event leaves nonzero error syndrome; without that fault, channel errors are corrected exactly at weight zero or one. Thus success probability is (1−q)[(1−p)3+3p(1−p)2]. Compared with a single unencoded bit-flip channel, strict improvement for 0<p<1/2 requires q<p(1−2p)/[(1−p)(1+2p)]. Shor code ([[9,1,3]])

Words: 192 Articles: 1
Concatenated phase-and-bit-flip repetition code OurBigBook.com
The nine-qubit Shor code encodes one logical qubit with basis vectors ∣0L​⟩=∣G+​⟩⊗3 and ∣1L​⟩=∣G−​⟩⊗3, where ∣G±​⟩=(∣000⟩±∣111⟩)/2​. Six adjacent Z-pair stabilizer generators locate a single bit flip within a block, while X1​⋯X6​ and X4​⋯X9​ diagnose which block has had its relative phase changed. Together they correct every single-qubit Pauli operator, hence every single-qubit error by the Pauli expansion of a quantum error.
A Pauli Z gate on qubit four has phase-check eigenvalues (−1,−1) and leaves all six Z-pair checks positive. Applying Z4​ restores the state. The same phase syndrome arises from Z5​ or Z6​; these have the same action on the code since their pairwise products are stabilizers. This is a degeneracy, not a failure of correction.

⟨ψa​∣Z(w)∣ψa​⟩=(−1)w⋅ta​∣D∣−1∑x∈D​(−1)w⋅x.
