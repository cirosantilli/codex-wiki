Support function (σC​)

 Home Mathematics Area of mathematics Mathematical optimization Convex set
OurBigBook.com Words: 418 Articles: 8
The support function of a nonempty set C is σC​(x)=supv∈C​⟨x,v⟩. It is convex and positively homogeneous, and for a closed convex set its convex conjugate is the indicator function of C.
