Galton-Watson extinction fixed point (q=min{s∈[0,1]:F(s)=s})

 Home Mathematics Area of mathematics Probability and statistics Galton-Watson process
OurBigBook.com Words: 637 Articles: 3
For a Galton-Watson process with one ancestor and offspring probability generating function F, the branching extinction probability q is the smallest fixed point of F in [0,1]. A direct way to find it is to compute extinction by generation n:
q0​=0,qn​=P(Zn​=0),qn+1​=F(qn​),qn​↑q.
(91)
Zero is an absorbing state, so extinction by generation n is exactly the event Zn​=0. [ref]
For F(s)=1/4+s/4+s2/2, the equation is
F(s)−s=21​(s−21​)(s−1)=0.
(92)
Both 1/2 and 1 are fixed points, but iteration from zero selects q=1/2. The first values are q1​=1/4, q2​=11/32, q3​=809/2048≈0.395020, and q6​≈0.462186. Iteration started at 1 would stay at 1 forever and would give the wrong extinction answer for this offspring distribution.
The vertical steps in the figure apply the offspring probability generating function; horizontal steps return to the diagonal to start the next iteration. This gives a useful numerical calculation even when solving F(s)=s explicitly is difficult. For the displayed law, every finite iteration is a lower bound for the eventual branching extinction probability; at generation six, about 0.037814 additional extinction probability remains beyond the current empty families.
Why the smallest fixed point? The ancestor's children's descendant families are independent; given k children, all are empty n generations later with probability qnk​. Averaging gives qn+1​=∑k​pk​qnk​=F(qn​). The increasing extinction events give the limit q, and continuity of the probability generating function yields F(q)=q. For any other fixed point r∈[0,1], q0​≤r and monotonicity of F imply qn​≤r at every step; hence q≤r. [ref]
