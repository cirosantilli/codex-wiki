Monochromatic set (c↾A is constant)

 Home Mathematics Area of mathematics Combinatorics Ramsey theory Finite coloring
OurBigBook.com Words: 134
A subset A⊆X is monochromatic for a finite coloring c:X→C if there is a color i∈C such that
c(a)=ifor every a∈A.
(4)
Equivalently, the restriction of a function c↾A is a constant function, or A lies in one colour class c−1(i). The word describes agreement of colors; it does not require A to equal an entire colour class.
For example, color the integers by integer parity, using red for even and blue for odd. The set {2,4,8} is monochromatic, whereas {2,3} is not. If the colored objects are edges, a monochromatic triangle in a graph means that its three edges form a monochromatic set. In a coloring of r-element subsets of a set S, a homogeneous set for a colouring H⊆S means that the collection of all r-element subsets of H is monochromatic. For pairs, this is a complete graph on H whose edges all have one color, rather than a coloring of the vertices in H.
