Bellman equation (Vt​(s)=maxa​{rt​(s,a)+Vt+1​(Ft​(s,a))})

 Home Mathematics Area of mathematics Mathematical optimization Dynamic programming
OurBigBook.com Words: 641 Articles: 6
A Bellman equation expresses the dynamic programming principle as a recurrence relation for a value function: optimize the current reward plus the best attainable continuation. Let s be a dynamic programming state, At​(s) the allowed actions at time t, rt​(s,a) the immediate reward, and Ft​(s,a) the next dynamic programming state. With terminal time T and terminal reward g, the deterministic finite-horizon Bellman equation is
VT​(s)=g(s),Vt​(s)=maxa∈At​(s)​{rt​(s,a)+Vt+1​(Ft​(s,a))},t=T−1,…,0.
(48)
Here Vt​(s) measures total reward from time t through the terminal reward. Start with g and evaluate backwards; the terminal condition anchors the recurrence relation. For finite nonempty action sets, finite rewards, and finite terminal rewards, a maximum exists at each step. If an optimum need not be attained, use a supremum. A minimization problem instead uses a minimum or infimum. The 0-1 knapsack problem above is the same comparison between an immediate item value plus a continuation and the continuation after skipping. See Bertsekas, MIT lecture 2: the backwards recursion.
In a Markov decision process, the next dynamic programming state St+1​ is random. If rt​(s,a) denotes the expected immediate reward and β is a discount factor, the finite-horizon Bellman equation becomes
VT​(s)=g(s),Vt​(s)=maxa∈At​(s)​{rt​(s,a)+βE[Vt+1​(St+1​)∣St​=s, at​=a]}.
(49)
The conditional expectation averages over the next dynamic programming state before choosing the current action; that action cannot use a future outcome that has not yet been observed. For a finite state space with transition probabilities pt​(s′∣s,a), the continuation term is β∑s′​pt​(s′∣s,a)Vt+1​(s′). Taking β=1 gives the undiscounted finite-horizon problem. With a discount factor 0≤β<1, rewards k steps ahead carry a factor βk, including the terminal reward. A maximizing action for each (t,s) specifies a Markov policy, which contains decisions rather than just optimal scores.
For an infinite horizon with a finite state space, finite nonempty action sets, time-independent transition probabilities, bounded rewards ∣r(s,a)∣≤M, and a discount factor 0≤β<1, the optimal value function satisfies
V(s)=maxa∈A(s)​{r(s,a)+β∑s′​p(s′∣s,a)V(s′)},∣V(s)∣≤1−βM​.
(50)
In this setting the maximizing dynamic programming operator is a contraction mapping in the supremum norm, so the Banach fixed-point theorem gives a unique bounded fixed point and convergence of repeated application to it. See Bertsekas, MIT lecture 15: bounded discounted problems. These hypotheses matter: with one state, one action, zero reward, and β=1, the Bellman equation is merely V(s)=V(s), so every finite constant is a fixed point, although the actual total-reward value function is zero. The average-reward Bellman equation and Hamilton-Jacobi-Bellman equation address other settings with their own conditions.
