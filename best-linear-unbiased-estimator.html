Best linear unbiased estimator

 ... Area of mathematics Probability and statistics Statistical model Statistical modelling Unbiased estimator Linear unbiased estimator
OurBigBook.com Words: 52
A best linear unbiased estimator minimizes covariance among linear estimators unbiased for the same target. In Y=Xβ+ε, assume Eε=0, X is a full-column-rank design matrix and the known covariance matrix Σ is a positive-definite matrix. The best linear unbiased estimator of the coefficient vector is (XTΣ−1X)−1XTΣ−1Y. A spatial trend estimate excludes the correlated residual prediction included in universal kriging.
