Reference signal (r(t))

 Home Mathematics Area of mathematics Control theory Closed-loop control
OurBigBook.com Words: 397 Articles: 1
A reference signal r(t) specifies the desired physical plant output as a function of time. A fixed reference signal is often called a setpoint; a changing reference signal describes a trajectory to follow. A reference signal is a goal, whereas the control input u(t) is the command chosen to achieve that goal. [ref]
Asking for a temperature of 40∘C does not specify a heater command of 40%: dimensional analysis distinguishes the units of these quantities. The reference signal and the measured output must describe the same quantity in the same coordinates before their difference can define a tracking error. An unconverted sensor readout cannot be subtracted directly from a desired temperature.
For example, let y=T−T0​ be temperature rise above a fixed ambient baseline T0​, and write the desired temperature as Td​=T0​+r. A Heaviside step function gives r(t)=R for t≥0, with r(t)=0 before the change: the target rise becomes R at once, although a physical controlled plant generally cannot jump at once. A ramp reference signal r(t)=vt instead asks the temperature rise to increase at a fixed rate v. If R=1∘C and v=0.2∘Cs−1, the first reference signal asks for a lasting one-degree rise; the second asks for a one-degree rise at t=5s and a two-degree rise at t=10s. Here degree Celsius differences are also kelvin differences. A target that grows forever is useful for analytical tests but eventually exceeds a real heater's range.
To make the distinction between a goal and a command concrete, the examples in steady-state tracking error use the first-order low-pass filter as a new controlled plant, rather than the accumulating controlled plant x˙=u+w used in the earlier feedback demonstration:
τy˙​+y=Ku+d,τ>0,K>0.
(13)
The time constant τ has units of time, K has units of plant output per control input, and the additive control disturbance d has the units of y. This d is an equivalent output offset, not the rate-like w in x˙=u+w. A heater interpretation uses y in degree Celsius differences and u in percentage points of heater command, with K in degrees per percentage point; the control input is a command, not a direct measurement of delivered power. With exact measurement, holding y=R requires u=(R−d)/K. Thus even a constant reference signal can require a persistent nonzero control input.
