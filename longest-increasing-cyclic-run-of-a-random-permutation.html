Longest increasing cyclic run of a random permutation

 Home Mathematics Area of mathematics Combinatorics Permutation Uniform random permutation
OurBigBook.com Words: 132
Arrange a uniform random permutation of n distinct ordered elements around a circle, and let L be the greatest number of consecutive entries that appear in increasing order. Put k0​=min{k:k!≥n}. Then P(k0​−2≤L≤k0​)→1 as n→∞.
Let Xk​ count increasing consecutive blocks of length k. Each of the n starting positions succeeds with probability 1/k!, so EXk​=n/k!. For k≤n/2, disjoint blocks have independent relative orders; blocks overlapping with a start displacement s<k are both increasing precisely when their length-k+s union is increasing. Thus
EXk2​=k!n​+2n∑s=1k−1​(k+s)!1​+(k!)2n(n−2k+1)​≤(k!)2n2​+k!2n​.

Consequently Markov's inequality gives P(L≥k0​+1)≤1/(k0​+1), while Chebyshev's inequality gives P(L<k0​−2)≤2/(k0​−1) for sufficiently large n. The latter uses n/(k0​−2)!>k0​−1. Both bounds vanish. These are consecutive cyclic runs; allowing arbitrary skipped entries is a different permutation statistic.
