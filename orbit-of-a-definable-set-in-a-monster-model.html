Orbit of a definable set in a monster model (O(D))

 Home Mathematics Area of mathematics Foundations of mathematics Model theory Monster model
OurBigBook.com Words: 32
If D=ϕ(U,b), its automorphism orbit consists of the sets ϕ(U,f(b)). If this orbit is infinite, saturation constructs ∣U∣ pairwise distinct conjugates, so ∣O(D)∣=∣U∣.
