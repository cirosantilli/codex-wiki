Use the maximum-weight version of Kruskal's algorithm: sort the edges by decreasing weight, start with no edges, and add an edge exactly when it joins different current connected components of a graph. For the maximum over all forests, skip negative-weight edges; removing a negative edge always preserves a forest and increases its weight. Zero-weight edges are optional. The matroid greedy algorithm for the graphic matroid proves this procedure optimal; it maximizes over independent sets rather than requiring a full basis.
The positive edges are considered in the order
12:9,15:8,25:7,23:4,35:3.
(2)
Admit 12 and 15. Reject 25, since it closes the triangle on 1,2,5. Admit 23. Reject 35, since 3 and 5 are already joined by the path 3,2,1,5. Skip both negative edges incident with vertex four. Therefore
F∗={12,15,23},w(F∗)=9+8+4=21.​
(3)
Vertex four is isolated. Requiring a spanning tree would force a negative edge and solve a different optimization problem. With a disjoint-set data structure, sorting dominates the running time, giving O(∣E∣log∣E∣).

On a finite ground set E, a submodular rank function is a set function r:2E→R with the following properties:
​r(∅)=0,A⊆B⟹r(A)≤r(B),r(A)+r(B)≥r(A∪B)+r(A∩B),r(A∪{e})−r(A)∈{0,1}(e∈/A).​
(4)
These are normalization, monotonicity, submodularity, and unit integer increments. In particular its values are nonnegative integers with r(A)≤∣A∣. Equivalently, one can require an integer-valued normalized monotone submodular function with r({e})≤1: diminishing returns then bounds every marginal increment by one. A general real-valued submodular function need not be a matroid rank.

The associated matroid is
M=(E,I),I={A⊆E:r(A)=∣A∣}.​
(5)
Thus the graph's edges are the ground set, and the members of I are its matroid independent sets.
For the specified rank, if (V,A) is a forest, A itself is an allowed choice in the rank maximum, so r(A)=∣A∣. Conversely, if r(A)=∣A∣, some forest F⊆A has ∣F∣=∣A∣. Finiteness forces F=A, so (V,A) is a forest. Hence the independent sets are exactly all forests in G, including the empty forest and forests with isolated vertices.
The matroid independence axioms can also be checked directly. The empty set is a forest, and deleting edges cannot create a cycle. For exchange, let forests I,J have ∣I∣<∣J∣. If every edge of J joined vertices within one component of (V,I), its restriction to each component S would have at most ∣S∣−1 edges. Summing would give ∣J∣≤∣I∣, a contradiction. Thus some edge of J∖I joins two components of I and can be added without creating a cycle. This proves augmentation and identifies M as the graphic matroid.

For A⊆E, write x(A)=∑e∈A​xe​, and let κ(A) count the connected components of (V,A), including isolated vertices. A maximal forest in each component has one fewer edge than vertices, so r(A)=∣V∣−κ(A). The required forest polytope is
P={x∈RE:xe​≥0 (e∈E),x(A)≤∣V∣−κ(A) (A⊆E)}.​
(6)
We prove both inclusions, using the matroid independence polytope argument explicitly.
If I is a forest, I∩A is an independent subset of A, so 1I​(A)=∣I∩A∣≤r(A). Its indicator is nonnegative. All convex combinations of these indicators therefore lie in P.
For the converse, take any real objective vector c. List just its positive-weight edges as e1​,…,ek​ with c1​≥⋯≥ck​>0, put ck+1​=0, and set Si​={e1​,…,ei​}. Run the forest greedy algorithm on these edges and call the output I. At every prefix, the accepted edges form a maximal forest of (V,Si​), so
∣I∩Si​∣=r(Si​).
(7)
Indeed a previously rejected edge still has its endpoints joined later; therefore no rejected prefix edge can augment the chosen forest. A maximal forest spans every prefix component and has the stated size.
For every x∈P, dropping nonpositive objective terms and telescoping now gives
cTx​≤j=1∑k​cj​xej​​=i=1∑k​(ci​−ci+1​)x(Si​)≤i=1∑k​(ci​−ci+1​)r(Si​)=cT1I​.​
(8)
The last equality uses the same telescoping identity for the greedy indicator. If there are no positive coefficients, the empty forest attains the bound zero. Thus every linear objective over P is maximized by a forest indicator.
The singleton inequalities give 0≤xe​≤r({e})≤1, so P is compact. The convex hull Q of the finitely many forest indicators is also compact. If some x∈P were outside Q, the finite-dimensional separating hyperplane theorem would give c with cTx>maxy∈Q​cTy, contradicting the bound just proved. Therefore P⊆Q, completing the convex-hull proof.
An equivalent system indexed by vertex sets is
xe​≥0,x(E(S))≤∣S∣−1(∅=S⊆V),​

where E(S) contains all edges with both ends in S. The rank system implies this since r(E(S))≤∣S∣−1. Conversely, split any edge set A into its vertex components S1​,…,St​. Nonnegativity and the vertex inequalities give x(A)≤∑j​x(E(Sj​))≤∑j​(∣Sj​∣−1)=∣V∣−κ(A). Hence this second system describes the same polytope.

Let item j have weight aj​ and profit pj​. Define D(j,b) as the largest profit obtainable from the first j items with capacity at most the nonnegative integer b. Set D(0,b)=0. The last item is either absent or present once, giving the dynamic programming recursion
D(j,b)={D(j−1,b),max{D(j−1,b),pj​+D(j−1,b−aj​)},​b<aj​,b≥aj​.​​
(10)
The two alternatives exhaust the feasible binary decisions. In the second alternative, deleting item j leaves exactly the smaller subproblem with capacity b−aj​, which proves the recurrence.
Fill rows j=1,…,4, and within each row capacities b=0,…,7. Store which alternative attains each maximum. Backtrack from (4,7): when exclusion was chosen, set xj​=0 and move to (j−1,b); when inclusion was chosen, set xj​=1 and move to (j−1,b−aj​). Ties may be resolved either way. Thus the stored values yield an actual optimal selection, not just its objective value.
For n items and capacity B, the algorithm uses O(nB) arithmetic operations and O(nB) space with the full backtracking table. It is a pseudo-polynomial algorithm, since B is a numerical capacity rather than its bit length. A value-only version can use one row, but must update capacities in decreasing order to avoid reusing the same item.

The assignment constraint matrix has one row for each outgoing sum and one for each incoming sum. The column for xij​ has a one in outgoing row i and incoming row j. Negate all incoming rows. Each column now has exactly one +1 and one −1, the node-arc incidence matrix of the directed bipartite graph from row vertices to column vertices.
Here is a direct proof that this signed matrix is totally unimodular. Consider any square submatrix and induct on its size. If a column has no nonzero entry, its determinant is zero. If a column has one nonzero entry, expansion along it reduces the determinant to plus or minus a smaller subdeterminant, hence to 0,1 or −1. If every column has two nonzero entries, they have opposite signs, so each column sum is zero. The rows are then dependent and the determinant is zero. The size-one case is immediate, completing the induction.
Negating rows only changes signs of square subdeterminants. Thus the original assignment matrix is also a totally unimodular matrix. This proves the total unimodularity of directed incidence matrices argument directly in the required setting.
The integrality theorem for totally unimodular systems says that {x≥0:Ax=b} has integral vertices when A is totally unimodular and b is integral. Redundant equalities cause no problem. Here the row sums also force xij​≤1, so every integral feasible vertex is a binary assignment. The bounded nonempty LP relaxation has an optimal vertex, and therefore an optimal assignment. Hence the assignment problem can be solved by linear programming without a binary search; dedicated methods such as the Hungarian algorithm also exploit its polynomial-time structure. Multiple optimal assignments can have fractional convex combinations, so the conclusion concerns an optimal integral vertex, not every optimal LP point.

Since every reduced weight is nonpositive and every feasible variable is nonnegative, any feasible assignment x satisfies
∑i,j​cij​xij​=∑i​ui​+∑j​vj​+∑i,j​cˉij​xij​≤∑i​ui​+∑j​vj​.
(17)
For x∗, each selected entry has zero reduced weight, and each unselected entry has zero variable. Thus every product cˉij​xij∗​ vanishes and equality holds:
c⋅x∗=i∑​ui​+j∑​vj​=maxc⋅x.​
(18)
The two hypotheses therefore form one optimality certificate: the first provides a universal upper bound, and the second makes the proposed assignment attain it. This is weak duality plus complementary slackness for the maximization assignment problem. For a minimization assignment, the sign reverses: ui​+vj​≤cij​ gives a lower bound, with equality on the selected arcs certifying optimality.

Use the minimization form in this part. Treat every diagonal arc as forbidden, not as a zero-cost loop. The assignment relaxation of the travelling salesman problem requires one incoming and one outgoing arc at each city but permits several disjoint directed cycles. Its optimum is a lower bound on the tour optimum.
At the root choose
u=v=(21​,21​,1,1,21​).
(19)
For every allowed arc, ui​+vj​≤cij​. Their total is seven. The assignment
(1→2→5→1)and(3→4→3)
(20)
uses only tight arcs and has cost 1+1+1+2+2=7. The minimization certificate from part (c) therefore proves
zAP,root​=7.​
(21)
It is not a tour, because it has a three-cycle and a two-cycle.
Branch on the two-cycle. Every five-city tour omits at least one of 3→4 and 4→3, so the children x34​=0 and x43​=0 cover every possible tour. They may overlap, which does not invalidate the bounds.
For the child x34​=0, use
u=(21​,21​,25​,1,21​),v=(21​,21​,1,25​,21​).
(22)
These satisfy ui​+vj​≤cij​ on every allowed arc of that child and sum to ten. The tour
1→2→5→4→3→1​
(23)
has cost 1+1+3+2+3=10 and uses tight arcs, certifying that the child assignment bound is exactly ten.
For the child x43​=0, interchange the roles of cities three and four in those potentials. Its lower bound is again ten, attained by
1→3→4→5→2→1​
(24)
with cost 3+2+3+1+1=10. Thus both first-level assignment optima are already tours.
There is a useful direct interpretation of the improved bound. Split the cities into A={1,2,5} and B={3,4}. A forbidden arc of the two-cycle forces an assignment arc from B to A, and balance forces at least one from A to B. Relative to the root potentials, each crossing arc has reduced cost 3−3/2=3/2, so any child assignment costs at least 7+2(3/2)=10.
The first branching therefore completes the search: each child's lower bound equals a feasible tour value. Hence
zTSP​=10.​
