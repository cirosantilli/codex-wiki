Submodular set function (f(A)+f(B)≥f(A∪B)+f(A∩B))

 ... Mathematics Area of mathematics Foundations of mathematics Set theory Function Set function
OurBigBook.com Words: 17
A set function is submodular if f(A)+f(B)≥f(A∪B)+f(A∩B) for every pair of subsets. Entropy submodularity is a fundamental example.
