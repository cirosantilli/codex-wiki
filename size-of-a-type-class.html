Write na​=nq(a). Arranging na​ copies of each symbol gives the multinomial coefficient
∣Tn​(q)∣=∏a∈A​na​!n!​.​
(80)
The division by the factorials removes permutations among identical copies. In the balanced four-symbol example, ∣T4​(q)∣=4!/(2!2!)=6. For binary symbols this becomes the binomial coefficient (kn​); for three symbols with counts (2,1,1), the class contains 4!/(2!1!1!)=12 strings.
