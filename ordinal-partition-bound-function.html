Ordinal partition-bound function (f(α)=min{β≥α:∀ν<α (β→(α)ν2​)})

OurBigBook.com Words: 110
The colors ν here range over nonzero cardinals. The Erdős-Rado theorem for pairs makes this function total, and target and color monotonicity make it nondecreasing, with f(α)≥α. If an uncountable cardinal κ is closed below itself under f, then it is strong limit. Indeed, coloring distinct binary strings of length λ<κ by their first differing coordinate uses λ colors and has no monochromatic triangle, so f(λ+1)>2λ. If κ also has the tree property, the end-homogeneous tree for any ν<κ has levels of size below κ and a cofinal branch; regularity makes one color occur κ times. Thus f(κ)=κ. This distinguishes function closure plus the tree property from the tree property alone.
