Set shattering (F∣Z​=P(Z))

 ... Mathematics Area of mathematics Combinatorics Extremal set theory Set family Trace of a set family
OurBigBook.com Words: 108 Articles: 1
A set family shatters Z when every subset of Z occurs as a trace of a set family. The largest finite shattered-set size is its VC dimension. The Sauer-Shelah lemma bounds the number of traces when no set of a given size is shattered.
