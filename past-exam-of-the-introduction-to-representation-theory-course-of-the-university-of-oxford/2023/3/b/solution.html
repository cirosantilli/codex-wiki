On the complex vector space CF(G) of class functions, define the linear operator
Tf(g)=f(g−1).
(30)
This is a complex-linear map and satisfies T2=I. It is well-defined on class functions, because inversion of conjugacy classes takes an entire conjugacy class K to another conjugacy class K−1.
Use first the basis consisting of the indicator functions 1K​ of the conjugacy classes. The linear operator T permutes this basis by 1K​↦1K−1​. A permutation matrix has trace equal to the number of fixed basis vectors, so
trT=#{K:K=K−1}.
(31)
The right-hand side counts the real conjugacy classes.
By character orthogonality and completeness, the irreducible characters are another basis of CF(G). Part (a) gives Tχ=χ​. The pointwise complex conjugate of an irreducible character is again an irreducible character: conjugate the representing matrices, and conjugate any hypothetical proper invariant subspace back to contradict irreducibility. Thus T also permutes this basis, and
trT=#{χ∈Irr(G):χ=χ​}.
(32)
Here χ=χ​ means exactly that χ is a real-valued character. Equality of the trace in these two bases proves
#{real-valued irreducible characters}=#{real conjugacy classes}.​
(33)
This is the real character and real conjugacy class counting theorem. The linear operator used in the proof is f↦f∘inv; on the irreducible character basis it agrees with pointwise complex conjugation, although pointwise complex conjugation itself is not a complex-linear map on all class functions.
