Bayesian model evidence (Z)

 Home Mathematics Area of mathematics Probability and statistics Statistical inference Bayesian statistics
OurBigBook.com Words: 1k Articles: 10
The Bayesian model evidence is the prior predictive distribution evaluated at the data D. For a statistical model Hj​ with a normalized prior density πj​, its marginal likelihood is
mj​(D)=p(D∣Hj​)=Zj​=∫p(D∣θj​,Hj​)πj​(θj​∣Hj​)dθj​.
(33)
This is an expected value of the likelihood function under the prior distribution; for discrete statistical parameters, replace the integral by a sum. For continuous observations, mj​(D) is a probability density function value with respect to a specified data reference measure, rather than a probability of one exact observation. Comparisons must use the same data and reference measure. The same mj​(D) normalizes the within-model Bayesian posterior and supplies the between-model comparison in a Bayes factor.[ref]
A normalized prior distribution makes the Bayesian model evidence an average, so it cannot exceed the largest likelihood function value on its support. A broad prior distribution can assign little mass to values that predict the data well, even when one value gives an excellent fit.
