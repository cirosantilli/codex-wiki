Line-Jacobi Fourier spectrum (λr,s​=cosθs​/(2−cosθr​))

 ... Area of mathematics Analysis Numerical analysis Numerical linear algebra Stationary iterative method for a linear system Matrix splitting
OurBigBook.com Words: 94
For the five-point Dirichlet Laplacian on an n×n square grid, a block-Jacobi splitting that solves each horizontal line exactly has blocks tridiag(−1,4,−1). Its tensor-product sine modes have angles θr​=rπ/(n+1) and the displayed iteration matrix eigenvalues. With c=cos(π/(n+1)), its spectral radius is c/(2−c)<1, so it converges on every fixed grid. However the mode r=1,s=n has multiplier −c/(2−c)→−1. It is highly oscillatory between lines and is barely damped. The undamped method is therefore not a uniformly effective smoother for the multigrid method, even though it converges. Convergence and smoothing test different properties of the error spectrum.
