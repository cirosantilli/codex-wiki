Flow network ((G,c,s,t))

 Home Mathematics Area of mathematics Foundations of mathematics Graph theory
OurBigBook.com Words: 4k Articles: 36
A flow network is a directed graph G=(V,E) with distinct source and sink vertices s,t and a nonnegative flow network edge capacity cuv​ on each directed edge (u,v). In the finite setting here, every flow network edge capacity is a finite real number. A feasible flow assigns a nonnegative amount fuv​ to each original directed edge, satisfies the capacity constraints, and obeys flow conservation at every other vertex:
0≤fuv​≤cuv​,∑u:(u,v)∈E​fuv​=∑w:(v,w)∈E​fvw​(v∈/{s,t}).
(1)
These are nonnegative arc amounts. The antisymmetric convention in flow instead records net amounts θuv​=fuv​−fvu​, taking a missing arc amount as zero. The two conventions express the same flow conservation; keeping them distinct makes backward residual network edges easier to interpret.
Think of vertices as routers, directed edges as communication links, flow network edge capacities as available bandwidth, and flow as a steady transmission rate. An intermediate router can distribute incoming traffic among outgoing links, but flow conservation prevents it from creating traffic. The maximum flow problem asks how much total traffic can pass from s to t, allowing several graph paths to share the work. The same flow network language models transportation and abstract resource allocation.[ref]
Our running flow network has vertices V={s,a,b,t} and exactly five directed edges, with flow network edge capacities
(csa​,csb​,cab​,cat​,cbt​)=(3,2,1,2,3).
(2)
The cross edge a→b lets traffic entering a use spare capacity on b→t. With this edge removed, the two separate graph paths can carry only min(3,2)+min(2,3)=4; including it will let the maximum flow reach 5. Thus a link's usefulness depends on the rest of the flow network, rather than just its own flow network edge capacity.
