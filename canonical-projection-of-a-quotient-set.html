Canonical projection of a quotient set (q:X→X/∼,q(x)=[x])

 ... Foundations of mathematics Set theory Finitary relation Binary relation Equivalence relation Quotient set
OurBigBook.com Words: 81
The canonical projection of a quotient set is the function q(x)=[x]. It is surjective: every set element of X/∼ is [x] for some x∈X. Two set elements have the same image exactly when they are related by the equivalence relation. Its fibers are precisely the equivalence classes:
q−1({[x]})=[x].
(20)
Here the left side is the preimage of a singleton subset of the quotient set; its members are the original set elements in the class [x]. In the diagram, the three arrows arriving at [1] start at 1, 4 and 7.
