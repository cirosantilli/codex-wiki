Identity function (id)

 Home Mathematics Area of mathematics Foundations of mathematics Set theory Function
OurBigBook.com Words: 48
The identity function on a set X maps each x∈X to itself: idX​(x)=x. It changes no information. For every function f:X→Y, function composition satisfies f∘idX​=f and idY​∘f=f. The subscripts specify the appropriate source or target set. An inverse function reverses a bijection exactly when the two possible compositions are these identity functions.
