Difference set (A−B)

 Home Mathematics Area of mathematics Combinatorics Additive combinatorics
OurBigBook.com Words: 111
For finite sets A,B⊆G in an abelian group G, their difference set is
A−B={a−b:a∈A, b∈B}=A+(−B),−B={−b:b∈B}.
(18)
Here −b is the additive inverse in G. The difference set records possible displacements from a member of B to a member of A; it is distinct from the set difference A∖B.
For the integer sets A={0,1,2,3} and B={0,1,4,10},
A−AB−B​={−3,−2,−1,0,1,2,3},={−10,−9,−6,−4,−3,−1,0,1,3,4,6,9,10},​∣A−A∣∣B−B∣​=7,=13.​
(19)
The positive differences for B are 1,3,4,6,9,10, each obtained once; reversing each ordered pair supplies the corresponding negative difference. Every nonempty finite set S has 0∈S−S, with ∣S∣ representations (s,s). Swapping the members of an ordered pair also shows S−S=−(S−S). In the cyclic group Z/6Z, the subgroup H={0,2,4} satisfies H−H=H as well as H+H=H.
