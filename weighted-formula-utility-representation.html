Weighted formula utility representation (uR​(v)=∑(ϕ,w)∈R, v⊨ϕ​w)

 Home Mathematics Area of mathematics Mathematical optimization Mathematical finance Utility function
OurBigBook.com Words: 94
A finite rule base pairs propositional formulas with weights and sums the weights of the formulas satisfied by a Boolean valuation. Over a finite set S, associate one Boolean variable to membership of each element. Any utility function u:2S→R is represented by giving each subset's minterm weight u(T). Exactly one rule fires at each valuation, so at most 2∣S∣ rules suffice. This bound counts rules, not the symbols required to write all formulas.
For computational questions, the weight encoding matters. Binary rational numbers permit exact addition and comparison in polynomial time; unrestricted real constants do not specify an ordinary finite input encoding.
