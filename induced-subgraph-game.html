Induced subgraph game (v(S)=∑{i,j}⊆S​wij​)

 ... Mathematics Area of mathematics Mathematical optimization Game theory Cooperative game theory Transferable utility game
OurBigBook.com Words: 212 Articles: 3
A transferable utility game represented by a weighted undirected graph, with one player per graph vertex. A coalition receives the sum of weights of the graph edges in its induced subgraph; absent edges have weight zero. Singleton and empty coalitions have value zero. This is a representation of a transferable utility game, distinct from a graphical description of local payoffs in a normal-form game.
