Radix sort suffix invariant (sp​(k)=kmodRp)

 Home Computer science Algorithm Sorting algorithm Radix sort Least-significant-digit radix sort
OurBigBook.com Words: 144
After p passes, 0≤p≤d, the array is in nondecreasing order of sp​(k)=kmodRp, the integer represented by its p lowest numerical digits. Equivalently it is ordered by the tuple (δp−1​(k),…,δ0​(k)) under lexicographic order, with the most significant processed numerical digit first. Among equal suffixes it retains the original order of the complete sorting records.
The loop invariant has a simple mathematical induction proof. Before any pass, s0​(k)=kmod1=0 for every sort key, so the original array satisfies it. Suppose it holds after p passes. The next stable digit sort puts smaller δp​ groups first and preserves the existing sp​ order within each tie. Since
sp+1​(k)=Rpδp​(k)+sp​(k),0≤sp​(k)<Rp,
(48)
the new array is ordered by sp+1​. Equal new suffixes have equal current numerical digits and equal old suffixes, so their original order is also preserved. Every pass is a permutation of complete sorting records, establishing sorting permutation preservation. At termination p=d, the assumption k<Rd gives sd​(k)=k: the invariant becomes whole-key sortedness, together with stable sorting.
