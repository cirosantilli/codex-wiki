Low-rank approximation (minrankB≤r​∥A−B∥)

 Home Mathematics Area of mathematics Algebra Linear algebra
OurBigBook.com Words: 1k Articles: 1
A low-rank approximation replaces an m×n matrix A by a matrix B of matrix rank at most a chosen integer r, with 0≤r≤min(m,n), while making an explicitly chosen error norm small. The point is to describe many entries using a few shared patterns: an image compression may retain broad brightness patterns while discarding finer ones. The approximation is useful when the saved storage or computation justifies the lost detail. A small matrix rank alone says nothing about the error.
The compact representation is a sum of outer products, equivalently a product of two thin matrices:
B=XY∗=∑j=1r​xj​yj∗​,X∈Cm×r,Y∈Cn×r.
(24)
Here xj​,yj​ are the columns of X,Y, and the star denotes the conjugate transpose; over the real numbers use the transpose. The rank bound for a matrix product gives rankB≤r. Conversely, choose a basis of the column space of B as the columns of X, and put the coordinates of each column of B into Y∗; pad with zero columns if the matrix rank is smaller than r. Each nonzero outer product is a rank-one matrix: it repeats a single column pattern at different strengths across the columns.
Keeping the two factors stores r(m+n) scalars instead of mn. This saves space only when r(m+n)<mn. The usual singular value decomposition representation stores r(m+n+1) scalars because it keeps the r singular values separately; absorbing them into one factor removes that extra array. These are representation sizes at equal scalar precision, before file overhead. See Uschmajew and Vandereycken, §9.2: thin factors and their storage, and Illinois CS 357, Low-rank approximation: storing singular vectors and values.
The factors also give Bz=X(Y∗z) without forming the full matrix B. Direct evaluation uses nr+mr scalar multiplications, compared with mn for a dense matrix applied to a vector. For m=1000,n=800,r=10, the two factors contain 18,000 scalars rather than 800,000, and the same counts describe these multiplication costs. Constructing the factors is a separate cost. Moreover, a low-rank approximation need not be a sparse matrix: the constant 8×8 matrix whose entries are all 1 has matrix rank 1 despite having no zero entries.
For the standard unweighted problem, write a singular value decomposition with p=min(m,n) and singular values σ1​≥⋯≥σp​≥0. Retain the first r paired left singular vectors and right singular vectors:
Ar​=∑j=1r​σj​uj​vj∗​,A0​=0.
(25)
The Eckart-Young-Mirsky theorem says that this same Ar​ minimizes both of the following error norms over all matrices with matrix rank at most r:
minrankB≤r​∥A−B∥F​=∥A−Ar​∥F​=(∑j=r+1p​σj2​)1/2,minrankB≤r​∥A−B∥2​=∥A−Ar​∥2​=σr+1​,
(26)
where σp+1​=0 and an empty sum is zero. Here the Frobenius norm is ∥E∥F​=(∑i,j​∣Eij​∣2)1/2, whereas the operator norm is specifically induced by the Euclidean norm, ∥E∥2​=max∥z∥2​=1​∥Ez∥2​. The first aggregates errors in all entries; the second bounds the worst output error for a unit vector input. These formulas apply to real and complex matrices. [ref]
For A=0, a relative Frobenius norm tolerance ε is met precisely when the discarded squared singular values sum to at most ε2∑j​σj2​. Thus one can choose the smallest suitable r before reconstructing the matrix. Many individually small discarded singular values can still have a large combined error. An operator norm tolerance instead tests only the largest discarded singular value, σr+1​. The two questions can therefore select different ranks.
The following stipulated 8×8 matrix makes the tradeoff visible. Define four real vectors of length 8:
h0​=(1,1,1,1,1,1,1,1)T,h1​=(1,1,1,1,−1,−1,−1,−1)T,
(27)
h2​=(1,1,−1,−1,1,1,−1,−1)T,h3​=(1,−1,1,−1,1,−1,1,−1)T,A=h0​h0T​+83​h1​h1T​+81​h2​h2T​+161​h3​h3T​.
(28)
The vectors hj​/8​ are orthonormal, so this is already a singular value decomposition written as outer products, with positive singular values 8,3,1,1/2. All entries lie between 7/16 and 25/16 and can be displayed as brightnesses. The first component is uniform brightness, the second distinguishes broad blocks, and the last two supply finer alternating patterns. This is a designed arithmetic example, not measured image data.
Here A1​=h0​h0T​ has every entry equal to 1, while A2​=h0​h0T​+3h1​h1T​/8 has entries 11/8 within the two diagonal blocks and 5/8 in the other two blocks. For instance, A11​=25/16 becomes (A2​)11​=11/8: its error is 3/16. The full residual is h2​h2T​/8+h3​h3T​/16, whose Frobenius norm is 1+(1/2)2​=5​/2 and whose operator norm is 1. Since ∥A∥F​=297​/2, the relative Frobenius norm error is 5/297​≈12.97%. Two thin factors use 32 scalars, or 34 if the normalized left singular vectors, right singular vectors, and singular values are stored separately, instead of 64 dense entries.
Retaining three components reduces the Frobenius norm error to 1/2 while using 48 scalars in two factors. Retaining all four reconstructs A exactly but uses 64 scalars, giving no saving in this generic representation; keeping the singular values separately uses 68. Our particular sign patterns could be encoded more economically, but that would exploit an additional structure beyond the general low-rank approximation. The striking feature is that numerical error and storage can both be read from the decomposition, rather than judged only by how smooth the picture looks.
The constraint is deliberately matrix rank at most r. The truncation has rankAr​=min(r,rankA). If rankA<r, the best approximation is A itself, with zero error. Requiring matrix rank exactly r can destroy attainment: for A=diag(1,0) and r=2, the matrices Bδ​=diag(1,δ) have matrix rank 2 for δ>0, and both error norms equal δ. Their error has infimum zero, but no rank-two matrix attains it. If r≤rankA, the displayed Ar​ does have matrix rank exactly r and attains the same minimum under either constraint.
Optimality also does not always mean uniqueness. For 0<r<rankA, the best Frobenius norm approximation is unique when σr​>σr+1​. [ref] A positive tie across the cutoff permits different choices: for A=diag(3,3,1) and r=1, both diag(3,0,0) and diag(0,3,0) have Frobenius norm error 10​ and operator norm error 3. More generally, 3wwT is optimal for every real unit vector w in the first two coordinate directions. Rotating which tied direction is kept changes the approximation. Repeated singular values entirely inside the retained group do not change its sum of outer products. At r=0 the only feasible matrix is zero; at r≥rankA the unique zero-error approximation is A, even if some singular values are tied at zero.
A strict gap does not guarantee uniqueness for the operator norm. For A=diag(3,1) and r=1, every Bt​=diag(t,0) with 2≤t≤4 has matrix rank 1 and error ∥A−Bt​∥2​=max(∣3−t∣,1)=1, which is optimal. Only t=3 minimizes the Frobenius norm, since ∥A−Bt​∥F​=(3−t)2+1​. An unchanged worst direction can hide extra error in another direction under the operator norm.
Finally, these guarantees concern the stated norms and the sole matrix rank constraint. They do not establish that a discarded pattern is noise or irrelevant to a particular task: the finer patterns in our constructed example were put there intentionally. Adding entrywise weights or restrictions on the factors changes the problem, so the Eckart-Young-Mirsky theorem above does not automatically solve it. For historical context, the original 1936 matrix problem is documented in the existing Eckart-Young-Mirsky theorem section.
