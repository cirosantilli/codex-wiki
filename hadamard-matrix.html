Hadamard matrix (H∈{±1}n×n, HHT=nI)

 ... Area of mathematics Algebra Linear algebra Vector space Linear map Matrix
OurBigBook.com Words: 54
A Hadamard matrix is a real square matrix with entries +1 and −1 whose rows are pairwise orthogonal. Each row has squared norm n, so HHT=nI and H/n​ is an orthogonal matrix. In particular H is invertible, with H−1=HT/n. The four-by-four example
H=​1111​1−11−1​11−1−1​1−1−11​​

is symmetric and satisfies H2=4I. It supplies an exact intertwiner in four-tile mixed-boundary transplantation between a disk and a nonorientable surface.
