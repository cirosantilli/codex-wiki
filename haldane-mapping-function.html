Haldane mapping function (r(d)=21​(1−e−2d))

 Home Biology Genetics Genetic linkage Genetic map
OurBigBook.com Words: 244
The Haldane mapping function connects additive genetic map distance to endpoint recombination fraction in a toy model with no crossover interference. Specify the model directly along a transmitted chromatid: the exchange count N in the interval has a Poisson distribution with expected value d, where d is the distance in morgans. Counts in disjoint intervals are independent random variables. This is the transmitted-chromatid convention; d is not the mean number of exchanges across all four chromatids in meiosis.
An odd exchange count changes parental phase. Summing the odd terms of the Poisson distribution gives
r=P(N is odd)=e−d∑k=0∞​(2k+1)!d2k+1​=21−e−2d​.
(8)
For 0≤r<1/2, the inverse and short-interval approximation are
d=−21​log(1−2r),r=d−d2+O(d3).
(9)
Here log is the natural logarithm. At d=0.2, the recombination fraction is 0.16483997698; at r=0.2, the distance is 0.2554128119 morgans, or about 25.5413 centimorgans. The linear approximation r≈d is useful only near zero. The recombination fraction approaches 1/2 as d grows; r=1/2 has no finite inverse in this model.
The model is a useful baseline, not a universal rule for every interval during meiosis. Crossover interference can change the relationship between distance and recombination fraction. For the count convention and assumptions, see Weeks, Tang and Kwon (2009): genetic map functions and exchange-count conventions. Haldane's original paper is bibliographically recorded as The combination of linkage values, and the calculation of distances between the loci of linked factors, Journal of Genetics 8 (1919), 299–309, in Selected Genetics Papers of J. B. S. Haldane, edited by K. Dronamraju (1990), contents.
