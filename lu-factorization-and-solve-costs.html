LU factorization and solve costs (32​n3+2rn2)

 ... Mathematics Area of mathematics Analysis Numerical analysis Numerical linear algebra LU decomposition
OurBigBook.com Words: 187
For classical dense Gaussian elimination over the real numbers, count each scalar addition, subtraction, multiplication or division as one arithmetic operation. At step k, there are n−k elimination multipliers to divide out and (n−k)2 remaining entries, each requiring one multiplication and one subtraction. Thus this implementation's unpivoted factorization count is
F(n)=∑k=1n−1​((n−k)+2(n−k)2)=6n(n−1)(4n+1)​=32​n3+O(n2).
(84)
Here O uses Big O notation. Partial pivoting adds O(n2) comparisons and row movement, leaving the leading arithmetic count unchanged. The leading 32​n3 count agrees with the standard dense LU decomposition analysis.[ref]
With unit L, forward substitution uses n(n−1) arithmetic operations. Back substitution uses another n(n−1) plus n diagonal divisions. Together these cost 2n2−n per right-hand side; applying a stored row permutation moves n entries and requires no scalar arithmetic. In Big O notation, Reusing LU factors for multiple right-hand sides therefore costs
32​n3+2rn2+O(n2+rn),
(85)
whereas refactorizing for each of the r right-hand sides costs 32​rn3+O(rn2). For n=1000 and r=10, the leading counts are about 6.87×108 versus 6.69×109 arithmetic operations, nearly a tenfold saving. These are operation counts, not measured runtimes: memory access and optimized matrix multiplication also affect speed.[ref]
