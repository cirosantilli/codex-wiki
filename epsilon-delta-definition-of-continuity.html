Epsilon-delta definition of continuity (∀ε>0 ∃δ>0)

 ... Area of mathematics Analysis Real analysis Calculus Limit of a function Continuous function
OurBigBook.com Words: 326 Articles: 1
A function f:D→R is continuous at a∈D when
for every ε>0 there is a δ>0 such thatx∈D, ∣x−a∣<δ ⟹ ∣f(x)−f(a)∣<ε.
(70)
First choose the required output tolerance ε; then choose an input tolerance δ that works for every allowed function input in that window. Picking a different δ separately after seeing each x would reverse the quantifiers and lose this guarantee. There is no need to exclude x=a, because the output difference is then zero.
At an isolated point of the domain of a function, choose a small enough window that its only allowed function input is a. This proves continuity there directly. At a point with arbitrarily close other inputs, the same definition is the limit of a function condition f(x)→f(a). For metric spaces, replace the two absolute values by their distance functions; for arbitrary topological spaces, the corresponding definition is a continuous map.
The input tolerance may depend on a. A single choice valid everywhere on the domain of a function is the stronger requirement of uniform continuity. The continuous function x↦x2 on R shows the difference: for any proposed δ>0, the points a=1/δ and b=a+δ/2 have ∣b−a∣<δ, yet b2−a2=1+δ2/4>1. Thus the fixed output tolerance ε=1 admits no global input tolerance on the real line.
