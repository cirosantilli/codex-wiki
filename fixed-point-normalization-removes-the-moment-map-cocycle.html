Fixed-point normalization removes the moment-map cocycle ({μξ​,μη​}=μ[ξ,η]​)

 ... Geometry and topology Differential geometry Symplectic geometry Hamiltonian group action Moment map Moment-map equivariance obstruction
OurBigBook.com Words: 93
Suppose a symplectic Lie group action on a connected symplectic manifold has global component Hamiltonians and a common fixed point p0​. Choose their constants linearly so μξ​(p0​)=0. The difference c(ξ,η)={μξ​,μη​}−μ[ξ,η]​ has zero Hamiltonian vector field because fundamental fields and Hamiltonian fields have compatible Lie-bracket conventions; it is therefore constant. At p0​, all fundamental fields vanish, so both terms in c vanish. Thus c=0 everywhere and the Poisson brackets of the components reproduce the group Lie algebra. For a connected group this also yields coadjoint equivariance. A linear unitary action on a vector space has the origin as such a fixed point.
