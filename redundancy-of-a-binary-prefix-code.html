Redundancy of a binary prefix code (R=ℓˉ−H(X))

 ... Area of mathematics Algebra Coding theory Unique decodability Decipherable code Prefix code
OurBigBook.com Words: 126
The redundancy of a binary prefix code is its expected codeword length minus the Shannon entropy of its source. It measures the excess number of binary digits per source symbol above the information lower bound. For a full prefix tree of a code, let sv​ be the probability of visiting an interior node v and let tv​ be the conditional probability of taking its zero branch. Then
ℓˉ=∑v​sv​,H(X)=∑v​sv​h(tv​),R=∑v​sv​[1−h(tv​)],
(32)
where h is binary entropy. The first identity counts one digit for each visited interior node. The second follows by expanding sv​h(tv​)=sv​log2​sv​−σ0​(v)log2​σ0​(v)−σ1​(v)log2​σ1​(v): the interior terms telescope, leaving the negative sum of leaf probability logarithms. The final identity follows by subtraction. It makes nonnegativity immediate and proves that zero redundancy occurs exactly when each positive-mass branch decision is balanced. Consequently the leaf probabilities then equal 2−ℓx​.
