Radio interferometer calibration

OurBigBook.com Words: 114
Radio interferometer calibration estimates instrumental and propagation effects that alter a complex visibility. A simple narrow-field model is
V12obs​=g1​g2∗​V12sky​+n12​,
(56)
where g1​,g2​ are complex receiver gains and n12​ represents additive noise. A point-like astronomical source of known position and stable strength constrains these gains: its expected complex visibility has a known wave phase and amplitude. A resolved or variable reference source requires a better source model. Errors in the reference model can be transferred into the inferred sky.
In a proposed extension, Martin Ryle described simultaneous observation of a nearby reference point source to correct atmospheric wave phase errors, using an additional dish at each element. He presented this as a possible extension, rather than the standard One-Mile Telescope arrangement.[ref]
