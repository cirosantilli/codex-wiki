Open addressing

 Home Computer science Data structure Hash table
OurBigBook.com Words: 1k Articles: 5
A hash table collision-handling method storing at most one live record per array slot. A hash function chooses a starting slot, and a probe rule chooses further slots. Unlike separate chaining, records occupy the slots themselves.
