Suffix array (SA)

 Home Computer science Data structure
OurBigBook.com Words: 123 Articles: 1
A suffix array stores starting positions of a string's suffixes in lexicographic order. All suffixes starting with a fixed query occupy a consecutive interval. This permits string-searching algorithms to search a compact list of positions instead of storing every suffix explicitly.
