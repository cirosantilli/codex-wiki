Plasmid feature map

 Home Biology Genetics Molecular genetics Plasmid
OurBigBook.com Words: 267
A plasmid feature map records the positions of specified DNA features. Construct an original circular example of total length L=6000 base pairs. Coordinates run clockwise from a chosen zero, and 0 and 6000 label the same boundary. Positions here denote boundaries between base pairs, so the interval from 1000 to 2500 contains 2500−1000=1500 base pairs. This convention avoids counting both endpoints as additional material.
The origin of replication is assigned to 200–700, the selectable marker to 3200–4000 and the plasmid insert to 1000–2500. Other positions are unspecified DNA, not empty gaps. Their lengths account for the entire circle:
500+800+1500+3200=6000.
(1)
The first three terms are the marked regions; the last is all remaining material. Choosing a coordinate zero does not add a physical break. Rotating every coordinate by the same amount changes the drawing's labels without changing any distance around the plasmid.
A gene promoter must function in the recipient for the intended gene expression; copying a plasmid alone does not establish gene expression.[ref] The map therefore supports three separate questions: can the carrier persist, can carriers be recovered, and can the selected DNA perform the proposed task? The galactose induction comparison illustrates the third question in an actual yeast experiment.
