Dilworth's theorem (minimum chain partition size=maximum antichain size)

 ... Mathematics Area of mathematics Foundations of mathematics Set theory Set Partially ordered set
OurBigBook.com Words: 36
Every finite partially ordered set can be partitioned into as many chains in a partial order as its largest antichain. Reachability in an acyclic directed graph is a partial order, so the theorem supplies chains which can be expanded into directed paths, possibly overlapping at intervening vertices.
