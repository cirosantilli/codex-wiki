Transmission Control Protocol

 Home Computer science Computer network Layered network architecture Transport protocol
OurBigBook.com Words: 152 Articles: 5
Transmission Control Protocol provides a reliable ordered byte-stream service between its endpoints, using sequencing, acknowledgements and retransmission. Receipt by that transport does not establish that a receiving application has durably stored the data or completed a user operation.[ref]
