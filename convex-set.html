Convex set ((1−t)x+ty∈C(0≤t≤1))

 Home Mathematics Area of mathematics Mathematical optimization
OurBigBook.com Words: 7k Articles: 102
A convex set permits every intermediate mixture of two of its points. If two choices meet its constraints, continuously averaging them also meets those constraints. This geometric property makes many feasible regions easier to explore: there is no forbidden gap along a straight move between feasible choices.
Formally, a subset C of a real vector space is convex when
x,y∈C,0≤t≤1⟹(1−t)x+ty∈C.
(1)
The parameter t traverses the entire line segment, including both endpoints. The definition does not require a closed subset, a bounded set, or a nonempty interior. The empty set, the whole vector space, and every affine subspace are convex; an open unit disk and a closed unit disk are both convex.[ref]
The triangle inequality verifies the disk example directly: if ∥x∥,∥y∥≤1, then ∥(1−t)x+ty∥≤(1−t)∥x∥+t∥y∥≤1. For the open disk, the last inequality is strict. The unit circle fails the same test: (1,0) and (−1,0) belong to it, but their midpoint (0,0) does not. A curved route along the unit circle connects the endpoints, so being path-connected is weaker than being a convex set.
The distinction between a convex set and a convex function matters. The former concerns where one may choose a point; the latter concerns how a value changes along line segments. Convex optimization combines both: averaging preserves feasibility, and a convex function obeys an upper bound by the corresponding average of endpoint values. A convex set alone does not make an arbitrary objective a convex function or eliminate its inferior local minima.

Convex feasible region for a resource budget (C={(x,y):x≥0, y≥0, x+2y≤6})

Words: 293 Articles: 1
Convex set OurBigBook.com
Consider a stipulated continuous-allocation problem. Amounts x,y of two activities use x+2y units of a common resource, with budget six. The feasible region
C={(x,y)∈R2:x≥0, y≥0, x+2y≤6}
(2)
is a triangle with extreme points (0,0), (6,0) and (0,3). It is the intersection of three closed half-spaces, hence a closed convex set. The general intersection argument is short: a line segment between two points in every constraint set belongs to every constraint set, so it belongs to their intersection.[ref]
For an original numerical check, take A=(1,2) and B=(5,1/4). Their resource totals are 5 and 11/2. Every convex combination Z(t)=(1−t)A+tB is nonnegative and has resource total
Zx​(t)+2Zy​(t)=5+2t​≤211​<6(0≤t≤1).
(3)
In particular the midpoint is (3,9/8), using 21/4 units. This verifies the full line segment, rather than just a plotted sample of it.
This is useful whenever divisible quantities share linear limits: the feasible choices remain compatible under averaging. A new linear equation also preserves this property, because averaging two identical constraint values gives the same value. The affine subspace and closed half-space viewpoints explain this without requiring a separate argument for every budget.

Integer restrictions on a convex feasible region

Words: 72
Convex feasible region for a resource budget OurBigBook.com
If the amounts in the budget example must be integers, the actual feasible region is C∩Z2. Both (0,0) and (1,0) are feasible, but their midpoint (1/2,0) is not. Thus the continuous feasible region is a convex set while the integer-restricted choices are not. Averaging two manufacturing plans may specify half an indivisible item. Integer programming must respect that restriction; using the surrounding convex set is a relaxation, not a proof that its averages are admissible integer plans.

Midpoint test for a closed set

Words: 108
Convex set OurBigBook.com
Checking only midpoints is not enough for an arbitrary subset of a real vector space. The rational numbers contain the midpoint of every pair of rational numbers, but the line segment from 0 to 1 also contains irrational numbers. For instance 2​/2 lies on that line segment and is not rational. This shows why the definition quantifies over every real t∈[0,1].
There is a useful additional hypothesis: a closed subset C⊆Rd containing the midpoint of every pair of its points is a convex set. Repeated bisection includes all points (1−t)x+ty with dyadic rational t∈[0,1]. These coefficients approach every real t∈[0,1]; being a closed subset then includes each limit. This is a short proof outline, and the rational numbers example identifies precisely why a closed subset was required.

Hyperplane separation theorem

Words: 78
Convex set OurBigBook.com
Two nonempty disjoint convex sets in a finite-dimensional real vector space admit a separating nonzero linear functional: for an appropriate h=0 and a, h⋅x≤a≤h⋅y on the respective sets. Strict separation requires additional assumptions, such as one set being compact and the other closed. For an open convex cone C excluding zero, separation from {0} gives h⋅c≥0 for all c∈C; scaling cone elements forces the separating level to be zero. This finite-dimensional result is related to the supporting hyperplane theorem.

Radially open convex set

Words: 78
Convex set OurBigBook.com
A subset C of a real vector space is radially open when, for each x∈C and each vector v, the points x+tv remain in C for all sufficiently small real t. No ambient topology is required. If C is also convex and contains zero, it is absorbing and its Minkowski functional pC​(x)=inf{s>0:x∈sC} is finite and sublinear, with C={pC​<1}. Convexity gives subadditivity; radial openness permits a slight dilation of any point of C, giving the strict inequality.

Compact convex set

A compact convex set K⊆Rn is a compact set that is also a convex set. If K is nonempty, its support function HK​(η)=maxx∈K​x⋅η is finite in every direction. Convex combination (∑i=1n​λi​xi​,λi​≥0,∑i​λi​=1)

Words: 325 Articles: 2
Convex set OurBigBook.com
A convex combination is a finite weighted average of points in a real vector space. For n≥1, it has the form
∑i=1n​λi​xi​,λi​≥0,∑i=1n​λi​=1.
(4)
The nonnegative coefficients forbid subtracting a component, and their unit sum keeps the result on the same affine scale as the inputs. With two points it parametrizes their line segment; equal coefficients give their centroid. A convex set contains every finite convex combination of its points. Conversely, the two-point case already gives the defining property of a convex set.[ref]
The distinction from a linear combination is concrete. Combining (0,0) and (2,0) with coefficients −1 and 2 gives (4,0), outside their line segment, despite the unit coefficient sum. Using two coefficients both equal to one gives (2,0) here, but their sum is two, so it is not a convex combination with those coefficients. A numerical output may happen to coincide with a point admitting a different convex representation; the definition applies to the specified coefficients.

Convex combinations in a triangle (λ1​=1−x/6−y/3,λ2​=x/6,λ3​=y/3)

Every allocation (x,y) in the convex feasible region for a resource budget is a convex combination of its three extreme points:
(x,y)=λ1​(0,0)+λ2​(6,0)+λ3​(0,3),λ2​=6x​,λ3​=3y​,λ1​=1−6x​−3y​.
(5)
The condition x+2y≤6 is exactly λ1​≥0; nonnegative x,y give the other two nonnegative coefficients. Thus the half-space description and the convex hull description encode the same triangle. At (2,1) all three coefficients are 1/3, and at (3,9/8) they are 1/8, 1/2, 3/8. The green and orange points in the budget diagram therefore have two complementary interpretations: direct resource constraints and mixtures of extreme choices.
The three extreme points alone are not a convex set, because their midpoints are absent. Their convex hull fills the whole triangle. More generally, Caratheodory theorem bounds how many generating points are needed for one convex combination in a finite-dimensional real vector space; its geometric content is that a complicated collection can describe each attainable average with a short representation.

Triangulation of a convex polygon

Words: 68
Convex polygon OurBigBook.com
A triangulation of a convex polygon divides a convex polygon into triangles using diagonals between its existing vertices of a polytope, with no diagonal crossings in the interior. For m≥3 vertices it uses m−3 diagonals and produces m−2 triangles. Fixing one boundary edge, its adjacent triangle separates two smaller polygon regions; summing over the possible third vertices of a polytope gives the Catalan recurrence. Thus the number of triangulations of a convex polygon is Cm−2​, with Cn​ the Catalan number. A quadrilateral has two choices and a pentagon has five.

For independent uniform points in 0≤y≤x≤1 with the two diagonal endpoints, the displayed formula is exact. Order the k intermediate points so that both coordinates increase, and write the k+1 positive coordinate spacings as (ui​) and (vi​), with each sum equal to one. The two spacing vectors have uniform simplex measure, independently, and the full ordered-coordinate region has volume 1/(k!)2. Simultaneous permutation of the spacing pairs preserves that measure, so all (k+1)! orders of the ratios vi​/ui​ have equal volume. Strictly increasing ratios characterize a convex chain and automatically place the intermediate points below the diagonal. Thus its ordered volume is 1/((k!)2(k+1)!). There are k! ways to assign labels, and uniform triangle density is 2k, giving the formula. Consequently the first moment method bounds the probability of any length-k chain among n points by (kn​)2k/(k!(k+1)!).

Extreme point (extC)

Words: 936 Articles: 6
Convex set OurBigBook.com
An extreme point of a convex set is a point that cannot be made by genuinely mixing two different points of the set. For a convex set C in a real vector space, the condition on p∈C is
p=(1−t)y+tz,y,z∈C,0<t<1⟹y=z=p.
(8)
Thus p lies on no open line segment between two distinct points of C. It is enough to exclude midpoint representations: if p lies inside a line segment, two nearby points on opposite sides have midpoint p.[ref]
The square [−1,1]2 has just four extreme points, at (±1,±1). In a convex combination giving a corner, each coordinate is already at its largest or smallest allowed value, forcing both input points to agree with that corner. In contrast, the boundary point (1,0) is not extreme:
(1,0)=21​(1,−1)+21​(1,1).
(9)
It is the midpoint of two other points on the same edge. An interior point also admits a small line segment through it.
The unit disk D={z∈R2:∥z∥2​≤1} has a different shape: every point on its unit circle is extreme. For a unit vector p, the Cauchy-Schwarz inequality gives
p⋅z≤∥p∥2​∥z∥2​≤1(z∈D),
(10)
and equality is possible only at z=p. If a convex combination equals p, applying this linear functional forces both ingredients to attain that equality. Both must therefore be p. Extremality need not look like a sharp corner.
These points help describe all allowable mixtures. Every (x,y)∈[−1,1]2 is a convex combination of its four corners, with the weight on (a,b)∈{−1,1}2 equal to (1+ax)(1+by)/4. For the unit disk, write z=rp, with 0≤r≤1 and p a unit vector; at zero choose any p. Then
z=21+r​p+21−r​(−p).
(11)
Two extreme points suffice for that mixture. The Krein-Milman theorem gives a much broader reconstruction: a nonempty compact convex set in a locally convex space whose topology is Hausdorff is the closed convex hull of its extreme points.
Mark Krein and David Milman published their reconstruction theorem in 1940. Milman's colleagues describe that result and its subsequent use as a method of representing convex sets through their extreme points.[ref]

Exposed point

Words: 133

An exposed point is a point uniquely selected by maximizing a linear functional. In Rd, a point p of a convex set C is exposed if some vector c satisfies
cTp>cTz(z∈C, z=p).
(12)
Geometrically, a supporting hyperplane touches the convex set only at p. Every exposed point is an extreme point: a convex combination that attains the maximum can put positive weight only on maximizers, and there is only one.[ref]
The unit disk calculation in extreme point exposes every point of the unit circle. For a corner (a,b) of the square, c=(a,b) exposes it: ax+by attains two only at (a,b). However, maximizing x exposes no single point on the right edge, since all of them have the same objective value. A linear functional may have several optimal points, even when some of them are extreme.
