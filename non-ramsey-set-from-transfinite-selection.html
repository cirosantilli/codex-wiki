Non-Ramsey set from transfinite selection

 ... Mathematics Area of mathematics Combinatorics Ramsey theory Space of infinite subsets of the natural numbers Ramsey set of infinite subsets
OurBigBook.com Words: 63
Using the axiom of choice, enumerate all infinite subsets Aα​ of the positive integers in order type 2ℵ0​. By transfinite recursion, choose two previously unused infinite subsets Xα​,Yα​ of each Aα​. This is possible because each [Aα​]ω has cardinality 2ℵ0​ and fewer choices have been made at stage α. The set {Xα​} is not a Ramsey set of infinite subsets, since every [Aα​]ω meets both it and its complement.
