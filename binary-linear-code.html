Binary linear code (C≤F2n​)

 Home Mathematics Area of mathematics Algebra Coding theory Linear code
OurBigBook.com Words: 368 Articles: 7
A linear code over the two-element finite field. Its dimension r gives 2r codewords. Its weight enumerator in the convention WC​(s,t)=∑c∈C​sw(c)tn−w(c) is symmetric in s,t exactly when the all-ones word belongs to C: adding that word complements every bit and replaces weight w by n−w. Conversely symmetry makes the coefficient of sn equal the coefficient of tn, which is one.
