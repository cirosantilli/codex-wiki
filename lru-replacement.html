LRU replacement

 Home Computer science Operating system Virtual memory Paging Page replacement
OurBigBook.com Words: 38
Evict the least recently accessed eligible item. Exact recency tracking on every memory reference can be expensive, whereas accesses to a buffer cache already pass through software. Recency captures temporal locality but can be defeated by a one-pass scan.
