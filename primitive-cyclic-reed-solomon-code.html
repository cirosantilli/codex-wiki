Primitive cyclic Reed-Solomon code (Ck,b​=⟨∏ℓ=bb+n−k−1​(x−ωℓ)⟩)

 ... Mathematics Area of mathematics Algebra Coding theory Linear code Reed-Solomon error correction
OurBigBook.com Words: 181 Articles: 2
Let n=q−1 and let ω be a primitive root of unity in Fq​. The length-n cyclic code with consecutive zeros of a cyclic code ωb,…,ωb+n−k−1 has dimension k. It equals the generalized Reed-Solomon code of vectors (ωj(1−b)f(ωj))j=0n−1​, degf<k. The choice b=1 is the unweighted Reed-Solomon code on these evaluation points; allowing other offsets makes this family closed under dual codes.
