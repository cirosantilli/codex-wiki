For a stable input with path action I(a)=∫−∞0​g(a˙s​)ds, a workload x requires some interval of length t with average input near C+x/t. Jensen inequality bounds its cost below by tg(C+x/t); taking the supremum workload and then the infimum over t yields the displayed lower bound. Constant-rate burst paths give the matching upper bound. At zero the typical-rate path has zero cost; negative workloads have infinite rate. If no finite-cost rate exceeds C, every positive workload has infinite rate.
