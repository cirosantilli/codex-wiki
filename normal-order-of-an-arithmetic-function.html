Normal order of an arithmetic function

 Home Mathematics Area of mathematics Number theory Analytic number theory
OurBigBook.com Words: 54 Articles: 1
A positive function g(n) is a normal order of an arithmetic function f(n) when, for every ϵ>0, all but o(x) integers n≤x satisfy ∣f(n)−g(n)∣<ϵg(n).
