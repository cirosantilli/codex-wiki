For pk​=xk+1​−xk​ and yk​=∇f(xk+1​)−∇f(xk​), the Quasi-Newton secant equation requires Bk+1​pk​=yk​. It reproduces the observed change of gradient along the latest step. If Bk+1​ is a positive-definite symmetric matrix and pk​=0, necessarily pkT​yk​=pkT​Bk+1​pk​>0. A line search satisfying the weak Wolfe conditions ensures this: with pk​=αk​sk​,
pkT​yk​≥αk​(β2​−1)∇f(xk​)Tsk​>0.

This necessary curvature condition is also sufficient for the existence of some positive-definite symmetric matrix mapping pk​ to yk​. In an orthonormal basis whose first vector is pk​/∥pk​∥, its first column must be (a,b)T=yk​/∥pk​∥, with a=pkT​yk​/∥pk​∥2>0. The block matrix with first row (a,bT) and lower-right block bbT/a+I has a positive Schur complement, so is positive-definite.
