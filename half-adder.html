Half adder (a+b=s+2c)

 ... Theoretical computer science Computational complexity theory Circuit complexity Boolean circuit Combinational logic Adder
OurBigBook.com Words: 50
A combinational logic circuit adding two input bits a,b to a sum bit s=a⊕b and carry bit c=a∧b. An exclusive or gate and an AND gate implement it. The identity a+b=(a⊕b)+2(a∧b) follows by checking the four input pairs. A half adder has no input carry, so adding three equally weighted bits needs a different circuit or multiple stages.
