Optimal stochastic conversion of a two-qubit pure state (pmax​=min{1,s/t})

 Home Physics Branches of physics Quantum theory Bell state Local operations and classical communication
OurBigBook.com Words: 96
Write a source and target in Schmidt decomposition with squared coefficients (1−s,s) and (1−t,t), where 0<s,t≤1/2. If s≥t, Nielsen's pure-state conversion theorem allows deterministic conversion. If s<t, the Schmidt-tail entanglement monotone gives p≤s/t. Alice attains this bound with a local two-outcome measurement in quantum mechanics whose success Kraus operator is Ks​=diag(s(1−t)/(t(1−s))​,1) and whose failure operator is Kf​=diag(1−s(1−t)/(t(1−s))​,0). They obey Ks†​Ks​+Kf†​Kf​=I. The successful unnormalized state is s/t​ times the target, and failure leaves a product state. A classical message tells Bob which branch occurred. Known local changes of Schmidt bases allow the same protocol for arbitrary two-qubit pure states with these coefficients.
