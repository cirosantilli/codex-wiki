Vector field along a curve (V∈Γ(γ∗TM))

 ... Algebraic topology Fiber bundle Vector bundle Pullback vector bundle Pullback tangent bundle Vector field along a map
OurBigBook.com Words: 48
A vector field along a curve γ:I→M is a smooth section of a vector bundle with V(t)∈Tγ(t)​M. Its values may differ at distinct times mapping to the same base point. The covariant derivative along a curve differentiates its time-dependent coefficients using the pulled-back connection on a vector bundle; it does not require extending it to one ambient vector field.
