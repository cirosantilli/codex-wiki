Bayes factor (B01​)

A Bayes factor measures how data change the relative support for two specified statistical models. Write mj​(D)=p(D∣Hj​) for their Bayesian model evidence and define the direction explicitly:
BF10​(D)=m0​(D)m1​(D)​.
(33)
For positive finite m0​(D),m1​(D), a value above one favors H1​ over H0​; a value below one favors H0​ over H1​. Reversing the comparison gives B01​=BF01​=1/BF10​, the opposite direction used in some formulas below.
For mutually exclusive, exhaustive H0​,H1​ with positive prior probabilities, divide their two Bayes' theorem formulas. Their common data normalizer cancels, leaving
posterior oddsP(H0​∣D)P(H1​∣D)​​​=BF10​m0​(D)m1​(D)​​​prior oddsP(H0​)P(H1​)​​​.
(34)
The Bayes factor therefore multiplies prior odds into posterior odds. It is evidence conditional on the specified statistical models and their within-model prior distributions; it is not P(H1​∣D). Model prior probabilities supply a separate input.[ref]
For an original stipulated example, consider ten independent and identically distributed Bernoulli trials, with heads as success. Compare H0​:p=0.4 with H1​:p=0.7, both fixed before seeing the data. Take D to be one particular ordered sequence containing eight heads and two tails. The likelihood function under either point model is p8(1−p)2, so
BF10​=0.480.620.780.32​=(0.40.7​)8(0.60.3​)2=2621445764801​≈21.9909706.
(35)
If P(H1​)=0.1, the prior odds for H1​ against H0​ are 1/9. Hence the posterior odds are 21.9909706/9≈2.4434412, and
P(H1​∣D)=9+BF10​BF10​​=81240975764801​≈0.7095928.
(36)
Equal model prior probabilities would instead give BF10​/(1+BF10​)≈0.956505. The same Bayes factor can thus accompany different posterior probabilities. These statements condition on the two-model comparison; they do not establish that either statistical model describes a real coin.
Using the heads count K=8 instead of the ordered sequence changes the sample space. The binomial distribution assigns it mass (810​)p8(1−p)2. The same binomial coefficient multiplies both models' Bayesian model evidence and cancels in their Bayes factor. Mixing an ordered-sequence numerator with a count denominator would introduce an erroneous factor of 45.
Fix the candidate statistical models, their parameter prior distributions, and model prior probabilities before using the current data for this update. The Bayes factor is useful because it separates evidence from model prior odds, but it still depends on the parameter prior distributions. An improper prior has an arbitrary multiplicative normalization: multiplying its kernel by c multiplies its formal marginal likelihood by c, even if the within-model posterior distribution is normalizable. Without a separately justified convention, the ordinary Bayes factor is then undefined up to arbitrary constants.[ref]
