Locally admissible word for a transition matrix (Ax0​x1​​⋯Axn−1​xn​​=1)

OurBigBook.com Words: 73
A finite word over an alphabet is locally admissible for a zero-one symbolic transition matrix if every consecutive pair is permitted. Its length counts symbols, so length n+1 corresponds to n transitions. The number with endpoints i,j is (An)ij​ by matrix multiplication. Local admissibility does not always imply occurrence in a two-sided subshift of finite type: the matrix (00​10​) permits the word (1,2) but admits no two-sided sequence. If every row and column has a nonzero entry, every locally admissible word extends in both directions.
