Dilaton Euler-characteristic weighting (gs−χ​=gs2g−2​)

 Home Physics Branches of physics String theory String coupling String genus expansion
OurBigBook.com Words: 33
A constant dilaton contributes Φ0​χ(Σ) to the Euclidean worldsheet action by the Gauss-Bonnet theorem. With string coupling gs​=eΦ0​ and Euler characteristic χ=2−2g, the path-integral weight is gs2g−2​. Canonically normalized external closed-string vertices add one power of gs​ each.
