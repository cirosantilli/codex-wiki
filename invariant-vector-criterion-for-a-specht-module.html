Invariant vector criterion for a Specht module ((Sλ)Sn​)

In positive characteristic p, (Sλ)Sn​ is nonzero exactly when λi​≡−1(modpti​) for every adjacent pair, where ti​ is least with λi+1​<pti​. The only invariant line in Mλ is generated by the sum zλ​ of all tabloids. The map ψi,v​ sends it to (λi​λi​+λi+1​−v​)zλ(i,v)​. Thus the kernel intersection theorem for Specht modules gives vanishing of (jλi​+j​) modulo p for 1≤j≤λi+1​. By Lucas's theorem, all these binomial coefficients vanish exactly when the last ti​ base-p digits of λi​ are p−1.
