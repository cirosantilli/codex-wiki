Character annihilator (H⊥)

 Home Mathematics Area of mathematics Analysis Fourier transform Additive character
OurBigBook.com Words: 44
For a nontrivial additive character ψ on a local field, the character annihilator of an additive subgroup H is H⊥={y:ψ(xy)=1 for all x∈H}. If OF⊥​=πcOF​, then (πnOF​)⊥=πc−nOF​. This is a character pairing construction, distinct from the annihilator of a module.
