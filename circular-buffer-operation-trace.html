Circular buffer operation trace

 Home Computer science Data structure Circular buffer
OurBigBook.com Words: 237
Start with C=5, h=0, n=0 and immutable labels. Perform enqueue(A), enqueue(B), dequeue(), enqueue(C), enqueue(D), dequeue(), enqueue(E), enqueue(F), enqueue(G). The removals return A and B. The interleaved insertions and removals make the front advance before the array fills; slot reuse does not require waiting for the FIFO queue to become empty.
At step 7, E occupies physical slot 4 and the next-write array index wraps to 0. At step 8, F reuses slot 0, giving the physical layout in the preceding diagram. At step 9, G replaces the stale contents of slot 1: the physical array is (F,G,C,D,E) but the logical sequence is (C,D,E,F,G). Now h=w=2, yet n=5 makes the state full rather than empty.
The displayed h,n,w values are related by w=(h+n)mod5 after every call. They are shown together to explain the invariant; an implementation need store only two. For the rejecting FIFO queue, every successful removal returns the earliest accepted label not already removed. The representation independence example supplies the general proof through its abstraction function; this trace makes the wrapped physical storage visible.
