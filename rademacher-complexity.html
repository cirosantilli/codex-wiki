Rademacher complexity

For independent and identically distributed random variables Z1​,…,Zn​ and independent Rademacher signs ε1​,…,εn​, the Rademacher complexity of a function class F is
Rn​(F)=EZ,ε​[supf∈F​n1​∑i=1n​εi​f(Zi​)].
(60)
It measures how strongly the class can correlate with independent random signs on a random sample.
