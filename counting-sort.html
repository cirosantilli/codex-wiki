Counting sort (T(n,K)=O(n+K))

 Home Computer science Algorithm Sorting algorithm
OurBigBook.com Words: 61
Counting sort uses integer sort keys in {0,…,K−1} directly as indices into an array of counts. Constant-cost counting and indexing give O(n+K) time complexity in Big O notation. To retain complete sorting records, cumulative counts locate their output ranges; filling each range from its end while scanning the input backwards gives stable sorting. Emitting bare sort keys from counts would discard associated data. The K term matters when the key range is large.[ref]
