Modulo-sixteen obstruction for the negative unit descent class

OurBigBook.com Words: 69
For y2=x3+ax2+bx with a≡8 and b≡9(mod16), the square class −1 in a two-isogeny descent would require coprime integers u,v and an integer N with N2=−u4+au2v2−bv4. If u is odd and v even, the right side is 15 modulo 16; if u is even and v odd, it is 7; if both are odd, it is 14. None is a square modulo 16. Therefore −1 does not occur in the two-torsion square-class homomorphism image.
