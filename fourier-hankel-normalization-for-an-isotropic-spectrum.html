Fourier-Hankel normalization for an isotropic spectrum (f​(ν)=2πH0​f(ν))

 Home Mathematics Area of mathematics Analysis Fourier transform Hankel transform
OurBigBook.com Words: 51
For the Cartesian convention f​(q)=∫R2​f(r)e−iq⋅rdr, an isotropic function has f​(ν)=2π∫0∞​f(r)J0​(νr)rdr. Its inverse is f(r)=(2π)−1∫0∞​f​(ν)J0​(νr)νdν. The self-reciprocal Hankel transform instead uses FH​=f​/(2π). In particular f(0)=∫FH​(ν)νdν. Mixing these spectral conventions changes attenuation coefficients by 2π.
