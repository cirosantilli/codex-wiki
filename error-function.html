Error function (erf)

 ... Area of mathematics Analysis Real analysis Calculus Integral Gaussian integral
OurBigBook.com Words: 1k Articles: 8
The error function records the signed area under a Gaussian function between zero and a variable endpoint:
erf(x)=π​2​∫0x​e−t2dt.​
(30)
For a negative real number x, reversing the integration limits makes this integral negative. The normalization uses the Gaussian integral: the full area of e−t2 is π​, so its positive half contributes one after multiplication by 2/π​. The same definition extends to a complex number z along any path from zero to z, giving an entire function.[ref]
For example, erf(0)=0, erf(1)≈0.842701, and erf(−1)≈−0.842701. A finite positive endpoint captures only part of the positive Gaussian integral; erf(x) approaches one as x→+∞ but never reaches it at a finite real x.
The useful idea is to name a recurring integral once instead of carrying it through every calculation. The error function and the normal distribution express probabilities and quantiles through this area, while an error-function diffusion front describes how diffusion smooths a sharp jump. The complementary error function retains the small area left in the tail.
The fundamental theorem of calculus gives
erf′(x)=π​2​e−x2>0.
(31)
Thus the real-axis error function is strictly increasing, with values in (−1,1). Its integrand is an even function, so the error function is an odd function, erf(−x)=−erf(x). The derivative also gives erf′′(x)=−4xe−x2/π​: the curve is concave for x>0 and convex for x<0. These real-axis properties do not imply boundedness throughout the complex plane; the existing quadrant asymptotics of the error function describe a different behavior in other directions.
