General-sum game

 Home Mathematics Area of mathematics Mathematical optimization Game theory
OurBigBook.com Words: 36
A game whose players' utilities are specified separately, without assuming a fixed sum. Improving one player's utility need not worsen another's. A finite perfect-information game can be solved by backward induction using entire utility tuples and each moving player's own coordinate, as in max-n search.
