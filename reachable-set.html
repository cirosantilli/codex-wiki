Reachable set (RT​(x0​)={x(T;x0​,u):u admissible})

 Home Mathematics Area of mathematics Control theory Reachability in control theory
OurBigBook.com Words: 392
The reachable set RT​(x0​) collects all endpoints attainable from x0​ at exactly T by admissible control inputs. If arrival any time up to T is allowed, use R≤T​(x0​)=⋃0≤t≤T​Rt​(x0​), with R0​(x0​)={x0​}. These definitions differ: a general dynamical system may drift away after early arrival, so waiting need not preserve the target. The reachable set is always relative to a declared input class and any constraints on the entire path.
For the double integrator starting from (0,0), now require measurable functions as control inputs with ∣u(t)∣≤1 almost everywhere. Write (p,v) for its endpoint at T>0. Two integrals determine the endpoint:
v=∫0T​u(t)dt,p=∫0T​(T−t)u(t)dt.
(7)
Our mathematical example has the exact reachable set
RT​(0)={(p,v):∣v∣≤T,−4T2​+2Tv​+4v2​≤p≤4T2​+2Tv​−4v2​}.
(8)
To see the upper boundary, fix v: put u=1 first and u=−1 last, switching at s=(T+v)/2. This maximizes the weighted integral for position because early commands have the largest weight T−t; the required net velocity fixes s. Formally, (T−t)−(T−s)=s−t has the same sign as this maximizing command, so changing to any other admissible command with the same integral cannot increase p. Reversing the order gives the lower boundary. Pointwise convex combinations of these two commands preserve v and attain every intermediate p, so the formula describes the whole region, not merely a bound. The extreme commands are bang-bang control.
In particular, the bounded double integrator can move from rest to position d and rest again exactly when ∣d∣≤T2/4. Its minimum duration is therefore 2∣d∣​ in these normalized units. With freely chosen time every rest-to-rest distance is attainable; with a fixed deadline many are excluded. Changing the amplitude bound to ∣u∣≤a with a>0 scales this condition to ∣d∣≤aT2/4. This shows why specifying the controls matters even when the Kalman rank criterion gives full rank of a matrix.
In closed quantum control, a density operator reachable set lies inside its unitary orbit of a density operator, since coherent evolution preserves the spectrum. That orbit need not be fully reachable under the available control inputs.
