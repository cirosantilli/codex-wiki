The cumulative hierarchy is the transfinite recursion
V0​=∅,Vα+1​=P(Vα​),Vλ​=α<λ⋃​Vα​(λ a nonzero limit ordinal).​
(1)
Here P is the power set. The class V=⋃α∈Ord​Vα​ consists of all sets in ZF, by the Axiom of foundation and Axiom schema of replacement.

Solution

ii OurBigBook.com
Two facts about a transitive set A drive the transfinite induction. First, A⊆P(A): every x∈A is a subset of A. Second, P(A) is a transitive set: if x∈y∈P(A), then x∈A, hence x⊆A, hence x∈P(A).
Starting with V0​=∅, these facts prove the successor step. At a limit ordinal λ, the union of the earlier increasing transitive sets is transitive: if x∈y∈Vλ​, some α<λ contains y in Vα​, and transitivity puts x there too. The union contains every earlier stage. Thus the induction gives both transitivity and Vβ​⊆Vα​ whenever β≤α.
Finally Vα​⊆Vα​, so Vα​∈P(Vα​)=Vα+1​. The Axiom of foundation gives Vα​∈/Vα​. This witnesses strictness:
Vα​ is transitive,Vα​⊊Vα+1​.​
(2)
This is the transitivity and strict growth of the cumulative hierarchy.

Fix x∈Vδ​. Since δ is a limit ordinal, choose β<δ with x∈Vβ​. Transitivity gives x⊆Vβ​. Every subset u⊆x therefore belongs to Vβ+1​=P(Vβ​), and consequently
P(x)⊆Vβ+1​,P(x)∈Vβ+2​⊆Vδ​.
(3)
The last inclusion uses β+2<δ, since a finite number of successor steps remains below a limit ordinal. In particular every subset of x is also an element of the transitive set Vδ​.
Take y=P(x). For any u∈Vδ​, transitivity ensures that the internal statement u⊆x agrees with the external one. Hence
(Vδ​,∈)⊨∀u(u∈y↔u⊆x).
(4)
Such a y∈Vδ​ exists for every x∈Vδ​, so (Vδ​,∈) satisfies the Axiom of power set. This power-set axiom at limit ranks actually holds for every nonzero limit ordinal; the stated restriction δ>ω is sufficient.

Every finite ordinal belongs to Vω​, so ω⊆Vω​ and ω∈P(Vω​)=Vω+1​. However, ω∈/Vω​, whose elements are the hereditarily finite sets.
Suppose y∈Vω+1​ were an internal power set of ω. Internally ω⊆ω, and ω is an available element of the structure. Thus the Axiom of power set would require ω∈y. But y∈P(Vω​) means y⊆Vω​, which would put ω∈Vω​, a contradiction. Therefore
(Vω+1​,∈)⊨PowerSet.​
(5)
This proves power-set failure at the first rank above V omega by an internal obstruction, including the subset ω itself.

A bounded formula in set theory, or Σ0​ formula in the Lévy hierarchy, uses only bounded quantifiers ∃u∈v and ∀u∈v, with the usual Boolean connectives. A Sigma-one formula in set theory has the form
∃u1​⋯∃um​θ(u,x),
(6)
where θ is a bounded formula in set theory; harmless logically equivalent rearrangements are allowed. A Pi-one formula in set theory is defined with a universal unbounded block instead.
A Delta-one formula modulo ZF is a first-order formula φ(x) for which there are such Σ1​ and Π1​ formulas σ,π with
ZF⊢∀x(φ↔σ),ZF⊢∀x(φ↔π).​
(7)
Equivalently, both φ and ¬φ have Sigma-one formulas in set theory provably equivalent to them in ZF. These are levels of the Lévy hierarchy, with bounds by sets.

Begin with bounded formulas in set theory. Atomic membership and equality have the same interpretation on shared elements of U1​⊆U2​, each a transitive class. Boolean connectives preserve agreement. For a bounded quantifier with bound a∈U1​, every member of a lies in U1​ by transitivity. Its quantifier range is therefore exactly the same in both structures. Structural induction proves set-theoretic absoluteness for every bounded formula in set theory.
A Sigma-one formula in set theory is upward absolute: witnesses in U1​ are still witnesses in U2​, and the bounded matrix agrees. A Pi-one formula in set theory is downward absolute, by negation or by restricting its universal quantifiers.
For the given Delta-one formula modulo ZF φ, select a Σ1​ equivalent σ and a Π1​ equivalent π. Both structures satisfy ZF, so both equivalences hold in both structures. Upward absoluteness of σ proves the forward implication, and downward absoluteness of π proves the reverse implication. Thus Delta-one absoluteness gives
U1​⊨φ(a)⟺U2​⊨φ(a)(a∈U1n​).​
(8)

There is a bounded definition of omega. Transitivity has the bounded definition Trans(x)≡∀u∈x∀v∈u(v∈x). An ordinal is a transitive set of transitive sets on which membership is a strict total order; this too has a bounded formula in set theory, since ZF supplies well-foundedness by the Axiom of foundation.
Define the bounded predicate
L(x)≡Ord(x)∧x=∅∧∀y∈x∃z∈x(y∈z).
(9)
For an ordinal, this says that it is a nonzero limit ordinal. It follows in ZF that
x=ω⟺L(x)∧∀y∈x¬L(y),​
(10)
since ω is the least nonzero limit ordinal. The right side is a bounded formula in set theory; consequently it is absolute between the specified transitive models. This also shows directly that those models have the same ω.

Use the convention that the transitive closure TC(x) is the least transitive set containing x as a subset. In ZF, transfinite recursion and Axiom schema of replacement construct
x0​=x,xn+1​=⋃xn​,t=⋃n<ω​xn​.
(11)
Then x⊆t. If a∈b∈t, some n has b∈xn​, whence a∈xn+1​⊆t. Thus t is transitive. If another transitive set s contains x, induction gives xn​⊆s for every n, and hence t⊆s. This proves existence and uniqueness of the transitive closure.
Let W(w) be the bounded definition of omega above. The displayed construction can be expressed as
∃w∃f∃r[W(w)∧f:w→r∧ran(f)=r∧f(0)=x∧∀n∈w(f(n+1)=⋃f(n))∧y=⋃r].
(12)
Here the brackets abbreviate a bounded formula in set theory: use the permitted bounded function and union predicates, bound the values of f by r, and bound each successor index by w. Ordered-pair graph access is bounded; ran(f)=r says every value in r occurs at an index in w. Any auxiliary sets used for the graph coding may be put in the initial existential block. Thus this is a Sigma-one formula in set theory defining y=TC(x).
Denote this formula by T(x,y). Existence and uniqueness give the ZF equivalence
¬T(x,y)⟺∃z(T(x,z)∧z=y).
(13)
The right side is again Σ1​, after combining existential blocks. Consequently T is a Delta-one formula modulo ZF, so Delta-one absoluteness applies. Therefore transitive closure is Delta-one definable and is ZF-absolute. If closure is instead required to contain x as an element, apply exactly this construction to {x}; the absoluteness conclusion is unchanged.

Use the usual cardinal arithmetic with the axiom of choice. The König theorem for cardinal numbers states that for any index set I and cardinal numbers κi​<λi​,
i∈I∑​κi​<i∈I∏​λi​.​
(14)
Represent the cardinal numbers as initial ordinals. Let A={(i,α):i∈I,α<κi​} and B=∏i∈I​λi​. There is an injection A→B: send (i,α) to the function whose ith coordinate is α+1 and whose other coordinates are zero. The unique nonzero coordinate identifies i, and its value identifies α. All values are allowed because α+1≤κi​<λi​.
For any proposed surjection F:A→B, its ith row has at most κi​ elements, so
{F(i,α)(i):α<κi​}=λi​.
(15)
Choose bi​ to be the least omitted ordinal. The function b=(bi​)i∈I​ belongs to B and differs from F(i,α) at coordinate i, for every (i,α)∈A. Thus F is not surjective. Cardinal comparison now gives the strict inequality. If I=∅, the conclusion is 0<1, also valid.

For an infinite cardinal number κ, its cofinality is
cf(κ)=min{∣A∣:A⊆κ, supA=κ},
(16)
viewing κ as an initial ordinal. Equivalently it is the smallest cardinal number which is the domain size of a cofinal map into κ.
Put λ=2κ and μ=cf(λ). Suppose μ≤κ, and choose cofinal ordinals αi​<λ for i<μ. Put ai​=∣αi​∣<λ. Their union is λ, so infinite cardinal arithmetic gives
λ≤∑i<μ​ai​≤λμ=λ.
(17)
Apply the König theorem for cardinal numbers to ai​<ai+​. Each successor cardinal ai+​ is at most λ, whence
λ=∑i<μ​ai​<∏i<μ​ai+​≤λμ≤(2κ)κ=2κ⋅κ=2κ=λ.
(18)
Here the last equalities use the currying law for cardinal exponentiation and square of an infinite cardinal. This contradiction proves the cofinality of a power-set cardinal bound
cf(2κ)>κ.​
(19)

Put μ=cf(κ) and choose cofinal ordinals αi​<κ, i<μ. With ai​=∣αi​∣, the same union comparison and infinite cardinal arithmetic give ∑i<μ​ai​=κ. Since ai​<κ, their successor cardinals satisfy ai+​≤κ. The König theorem for cardinal numbers therefore gives
κ=i<μ∑​ai​<i<μ∏​ai+​≤κμ=κcf(κ).​
(20)
This König bound for the Gimel function applies to regular and singular cardinals alike; choosing cofinal ordinals also covers successor cardinal numbers.

Take the Beth number
κ=ℶω​=n<ωsup​ℶn​,ℶ0​=ℵ0​,ℶn+1​=2ℶn​.​
(21)
Cantor's theorem makes this sequence strictly increasing. It is a countable cofinal sequence in κ, while no finite set is cofinal in the limit ordinal κ. Hence cf(κ)=ℵ0​. Consequently
2cf(κ)=2ℵ0​=ℶ1​<ℶω​=κ.​
(22)
Thus Beth omega is a singular strong limit above the continuum. No Continuum hypothesis is needed for the example.
