Conditioning on a sum can create dependence (X⊥Y⇒X⊥Y∣X+Y)

 ... Area of mathematics Probability and statistics Probability theory Random variable Independent random variables Conditional independence
OurBigBook.com Words: 254
Let X,Y be independent random variables, each with a Bernoulli distribution of parameter 1/2, and put S=X+Y. Unconditionally, the four ordered pairs (0,0),(0,1),(1,0),(1,1) each have probability 1/4. On the event S=1, only (0,1) and (1,0) remain, each with conditional probability 1/2. Thus
P(X=1,Y=1∣S=1)=0=P(X=1∣S=1)P(Y=1∣S=1)=41​.
(19)
Knowing that exactly one trial succeeded makes observing one outcome informative about the other. This violates conditional independence given S, even though the original random variables are independent. Given S=0 or S=2, both variables are constant random variables and are conditionally independent there; that does not repair the failure at S=1, an event of positive probability.
The conditional covariance here is E[XY∣S=1]−E[X∣S=1]E[Y∣S=1]=0−1/4=−1/4. Both conditional variances are 1/4, so the conditional correlation coefficient is −1: within the selected group, Y=1−X. These conclusions follow from restricting a finite sample space, without positing any physical interaction between the trials.
This example and the shared-environment example establish both logical directions: independent random variables need not be conditionally independent, and conditionally independent variables need not be independent. When S is represented as the joint result of two inputs in a causal directed acyclic graph, conditioning on it has the collider structure associated with collider bias. A probability calculation by itself establishes a dependence relation, not a physical causal mechanism or an intervention.
