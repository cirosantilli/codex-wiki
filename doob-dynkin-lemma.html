Doob-Dynkin lemma (Z is σ(X)-measurable⟹Z=g(X))

 ... Mathematics Area of mathematics Analysis Real analysis Measure theory Measurable function
OurBigBook.com Words: 103
For real random variables X,Z, if Z is measurable with respect to the sigma-algebra generated by a random variable X, there is a Borel measurable function g:R→R with Z=g(X). To prove the bounded case, approximate Z pointwise by finite-valued simple functions Zm​. Each level set is X−1(B) for a Borel set B, so each approximation factors as Zm​=gm​(X) with gm​ a Borel measurable function. Apply scalar clipping to gm​ with a common bounded interval and use its limit superior to obtain g. For unbounded finite Z, apply the bounded case to the one-to-one bounded continuous function t↦arctant, then invert on (−π/2,π/2) and assign arbitrary values elsewhere. Exact measurability gives exact factorization; assumptions after adjoining null sets give an almost surely equal version.
