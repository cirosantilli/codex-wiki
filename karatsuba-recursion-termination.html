Karatsuba recursion termination

 Home Computer science Algorithm Karatsuba multiplication
OurBigBook.com Words: 153
For the sum-based Karatsuba three-product identity, a safe fixed base-case threshold is three digits or more. Return zero directly if either operand is zero; at or below the threshold, use ordinary digit-by-digit multiplication. Otherwise split by the maximum current operand length and invoke Karatsuba multiplication on (a,c), (b,d), and (a+b,c+d).
Each recursive operand has at most ⌈n/2⌉+1 digits. This is strictly less than n for n≥4, proving termination. A rule stopping only at one digit does not supply this guarantee: in base two, 3=112​ splits into 1,1, whose sum is 2=102​, still two digits. An implementation must choose a sufficient threshold or explicitly handle such nonshrinking calls. Leading zero padding must not be repeatedly added in a way that defeats the decreasing size measure.
For signed integers, multiply absolute values with the same nonnegative procedure and restore the sign afterwards. This changes the representation bookkeeping, rather than the three-product identity.
