Root string (Sα,β​=Φ∩(β+Zα))

OurBigBook.com Words: 187 Articles: 1
A root string is the set Sα,β​=Φ∩(β+Zα) for roots α,β of a root system Φ. For nonproportional roots α and β of a reduced crystallographic root system, the roots of the form β+nα form an unbroken root string β−pα,…,β+qα, and p−q=⟨β,α∨⟩. The root-string theorem explains the endpoint relation. If β=±α, zero is missing and this consecutive-string statement does not apply.
