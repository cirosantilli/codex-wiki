Binary Golay code (G23​=[23,12,7])

 ... Area of mathematics Algebra Coding theory Block code Binary block code Perfect code
OurBigBook.com Words: 361 Articles: 6
The length-23 binary Golay code is the cyclic code over F2​ generated by
g(X)=1+X+X5+X6+X7+X9+X11.
(1)
It has dimension 12, minimum Hamming distance 7, and its radius-3 Hamming balls partition F223​. Its parity extension has length 24, dimension 12, and minimum Hamming distance 8.
