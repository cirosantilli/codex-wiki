Absolute value (∣x∣)

 Home Mathematics Area of mathematics Analysis Real analysis Convex function
OurBigBook.com Words: 217 Articles: 2
The absolute value function is convex by the triangle inequality:
∣tx+(1−t)y∣≤t∣x∣+(1−t)∣y∣.
(104)
For a real number x, its absolute value is x when x≥0 and −x otherwise; for a complex number z, it is the nonnegative magnitude zz​.
