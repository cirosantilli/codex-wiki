Fixed-parameter tractability (f(k)NO(1))

 Home Computer science Theoretical computer science Computational complexity theory Parameterized complexity
OurBigBook.com Words: 58
A parameterized decision problem is fixed-parameter tractable if an algorithm decides every instance of encoded length N and parameter k in running time at most f(k)Nc, for a computable function f and a constant c independent of k. The distinction is in the exponent: 2kN3 has this form, whereas an Nk bound alone does not establish fixed-parameter tractability. Branching on an uncovered edge gives a fixed-parameter tractable vertex cover decision problem.
