QR decomposition by Givens rotations (R=ΩA,Q=ΩT)

 Home Mathematics Area of mathematics Analysis Numerical analysis Givens rotation
OurBigBook.com Words: 448
Successive Givens rotations eliminate entries below the diagonal of a matrix. For an m×n matrix with m≥n, process columns k=1,…,n; within column k, rotate rows k,j for each j>k whose entry needs elimination. Apply each Givens row-pair update to columns k,…,n. Both rows are zero in earlier columns, so these operations preserve earlier eliminations. No assumption of full column rank is needed to perform the eliminations.
For a concrete example, take
A=​340​052​​.
(106)
First use G1​=G12​(3/5,4/5), then G2​=G23​(3/13​,2/13​):
G1​A=​500​432​​,R=G2​G1​A=​500​413​0​​.
(107)
The entry in position (3,1) was already zero, so its elimination was skipped. The second Givens rotation combines the remaining pair (3,2)T in column two. This yields the full QR decomposition
Q=G1T​G2T​=​3/54/50​−12/(513​)9/(513​)2/13​​8/(513​)−6/(513​)3/13​​​,A=QR.
(108)
The first two columns of Q and first two rows of R give the reduced QR decomposition. Direct multiplication verifies both QR=A and QTQ=I. For these displayed factors evaluated in binary64 floating-point arithmetic, the Frobenius norms ∥A−QR∥F​ and ∥QTQ−I∥F​ are both below 10−14; these measure reconstruction and loss of orthogonality separately.
More generally, if the chronological rotations are G1​,…,Gp​, then
Ω=Gp​⋯G1​,R=ΩA,Q=ΩT=G1T​⋯GpT​.
(109)
Each factor is an orthogonal matrix, so Q is too. For a rectangular matrix, R has zeros below its diagonal; its leading n×n block is an upper triangular matrix. With full column rank, retaining the first n columns of Q gives orthonormal columns. To impose a positive diagonal when necessary, flip matching columns of Q and rows of R, preserving their product.
For a linear least-squares problem, apply the same chronological Givens rotations to the right-hand side b, obtaining z=Ωb, without explicitly constructing Q. Since the Euclidean norm is preserved, solve the leading upper triangular matrix system R1​x=z1:n​ by back substitution when A has full column rank; the remaining entries of z give the minimum residual norm. In the example, b=(0,0,1)T gives z=(0,2/13​,3/13​)T, x=(−8/65,2/13)T, and minimum residual Euclidean norm 3/13​.
The locality is useful for a sparse matrix or an existing QR decomposition needing an extra row: only two rows change at each step, and the new row can be eliminated against the stored upper triangular matrix. For an n×n factor, this extra-row procedure takes n rotations and O(n2) arithmetic operations. Locality does not guarantee preservation of sparsity: mixing rows can create nonzeros wherever either row had one. For a fully populated m×n input, the straightforward elimination uses ∑k=1n​(m−k) rotations, each touching n−k+1 columns, giving O(mn2) work. Storage layout, zero patterns and implementation affect speed; this count alone establishes no universal advantage over other QR decomposition algorithms.
The Euclidean norm preservation explains the appeal for numerical stability: exact rotations do not amplify a perturbation's length. Rounded coefficients and Givens row-pair updates still introduce roundoff error. Small reconstruction and orthogonality residuals check the computed factors, while the condition number of the original problem still controls how accurately a linear least-squares problem determines its solution.
