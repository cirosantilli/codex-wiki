Simplex objective update for a priced slack variable (z+∑j​(ρj​−p1j=k​)xj​=z0​)

 ... Mathematics Area of mathematics Mathematical optimization Linear programming Simplex method Simplex tableau
OurBigBook.com Words: 81
If a variable xk​ gains an objective coefficient p, the new objective is z=zold​+pxk​. Substitute this in the old canonical objective equation and eliminate any remaining basic-column coefficients using the constraint rows. If xk​ is nonbasic, this simply subtracts p from its objective-row coefficient. When a slack variable is sold, rename the old slack as the sales quantity; its equation already gives the correct equality and no new slack is added. Reoptimization can then start directly from the altered simplex tableau.
