Bell-LaPadula model

 Home Computer science Computer security Access control
OurBigBook.com Words: 88 Articles: 2
A classification-based information confidentiality model restricting subject accesses to prevent forbidden information flow. The simple security property restricts reading above clearance; the Bell-LaPadula star property restricts information flow through current reads and writes. It is not a complete data integrity policy.
