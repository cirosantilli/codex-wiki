Phase retardation (δ=2πΔnd/λ0​)

OurBigBook.com Words: 364 Articles: 1
For the overlapping monochromatic wave components, let d be the thickness and λ0​ the vacuum wavelength. Define Δn=ns​−nf​>0 using the slow and fast refractive indices. With complex amplitude convention ei(kz−ωt), the accumulated slow-minus-fast phase difference is
δ=(ks​−kf​)d=λ0​2π​(ns​−nf​)d.
(6)
This is the optical path difference Δnd expressed as a wave phase. It is a signed accumulation convention; with the opposite time convention the sign reverses. The outgoing polarization of an electromagnetic wave depends on δ modulo 2π. Here the positive slow-minus-fast Δn differs from the signed principal-index ne​−no​ used in the parent birefringence entry when ne​<no​.
For an original worked example, stipulate Δn=0.0100 at λ0​=600nm and a uniform thickness d=15.0μm. These are design assumptions, not measured material data. The optical path difference is 150nm, so
δ=2π600nm150nm​=2π​.
(7)
It is a quarter-wave plate. At the same wavelength and refractive indices, doubling d to 30.0μm gives δ=π, a half-wave plate. A 1.0μm thickness increase changes δ by π/30, or 6∘; retaining the same birefringence at 500nm would instead give δ=3π/5 for the 15.0μm plate. Real refractive indices also vary with wavelength, so this last calculation explicitly neglects optical dispersion.
For these equal transmitted wave amplitudes, orthogonal projection onto a polarizer crossed with the initial 45∘ linear polarization gives a simple independent readout. After removing a common wave phase, the component complex amplitudes are proportional to (1,eiδ)/2​; orthogonal projection onto (1,−1)/2​ gives (1−eiδ)/2. Squaring its modulus yields I⊥​/Iin​=sin2(δ/2): zero at d=0, one half at 15μm, and one at 30μm. This assumes ideal polarizers, negligible specular reflection and wave absorption, overlapping components and stable relative wave phase. It measures a periodic function of phase retardation, so one brightness measurement cannot determine the thickness uniquely.
