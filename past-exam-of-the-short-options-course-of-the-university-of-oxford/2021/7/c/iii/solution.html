Let T be the unique minimum spanning tree. If e=ab is an edge outside T, adding it creates a unique graph cycle consisting of e and the tree graph path PT​(a,b). Every edge f on that graph path has w(f)<w(e): otherwise the distinct weights would give w(f)>w(e), and replacing f by e would produce a cheaper spanning tree. This is the minimum spanning tree cycle property in exchange form.
By the domination inequality in (i), it follows more strongly that
w(PT​(a,b))<w(e).​
(83)
Now consider any simple graph path P from v to u that is not the tree graph path. It must use an edge outside T. Replace every such edge by the corresponding tree graph path. Each replacement strictly reduces length and produces a walk entirely in T. Removing any repeated-vertex excursions leaves the unique tree graph path PT​(v,u) and can only reduce length further. Therefore
w(PT​(v,u))<w(P).
(84)
So every root-to-vertex graph path in T is the unique shortest graph path in G, and
TMST​=Tshortest,v​.​
(85)
The argument works for every choice of root v.
