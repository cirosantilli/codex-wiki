Single-error test from two binary BCH syndromes (S1​=αj,S3​=α3j=S13​)

For a binary cyclic code with defining zeros of a cyclic code α and α3, a single error in coordinate j has polynomial Xj and syndromes S1​=αj, S3​=α3j. If S1​=0 and S3​=S13​, recover j from the exponent of S1​, flip that coordinate, and verify that the resulting polynomial vanishes at both roots. When the linear code has minimum Hamming distance at least five, this verified correction is the unique codeword within two errors. The syndrome relation alone should not replace checking the corrected word.
