Error bound (∣f​−f∣≤ε)

 Home Mathematics Area of mathematics Analysis Numerical analysis Approximation error
OurBigBook.com Words: 50
An error bound is an established upper bound on a specified approximation error, on a stated domain and under stated assumptions. A numerical comparison at selected points can test an approximation but does not by itself establish a bound throughout that domain. An absolute error bound controls ∣f​−f∣; a relative error bound additionally specifies the reference scale.
