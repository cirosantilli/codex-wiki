Bresenham's line algorithm

 Home Computer science Computer graphics Raster graphics
OurBigBook.com Words: 72 Articles: 1
Jack Bresenham's raster graphics algorithm selects a thin sequence of pixels to represent a line segment by exact incremental integer arithmetic. For a first-octant segment with 0≤Δy≤Δx, a scaled midpoint line decision chooses between the next same-row and next higher-row pixels.
