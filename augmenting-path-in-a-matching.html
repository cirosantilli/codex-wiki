Augmenting path in a matching

 Home Mathematics Area of mathematics Foundations of mathematics Graph theory Matching (graph theory)
OurBigBook.com Words: 582 Articles: 2
An augmenting path in a matching M is a nonempty alternating path in a matching with distinct endpoints that are both unmatched vertices in a matching. Its first and last edges lie outside M. Thus it has k+1 unselected edges and k selected edges, for some k≥0. Taking the symmetric difference
M′=M△E(P)=(M∖E(P))∪(E(P)∖M)
(6)
removes the selected edges on P and inserts its unselected edges. Each internal vertex exchanges one selected edge for another; each endpoint gains its first selected edge. All choices away from P stay in place, so M′ is a matching in a graph with ∣M′∣=∣M∣+1.[ref]
For an explicit repair, let the path graph P6​ have vertices 1,2,3,4,5,6 in that order and start with
M={(2,3),(4,5)},P=(1,2,3,4,5,6).
(7)
The endpoints 1 and 6 are initially unmatched vertices in a matching. Along P the edges are outside, inside, outside, inside, outside M. Remove (2,3) and (4,5), then add (1,2),(3,4),(5,6) together:
M′=M△E(P)={(1,2),(3,4),(5,6)}.
(8)
This raises the cardinality from two to three and gives a perfect matching. Six vertices allow at most three disjoint pairs, so it is also a maximum cardinality matching. The initial M is already a maximal matching: every unused edge touches a matched vertex. Augmentation succeeds because it can replace earlier choices instead of only adding to them.
One unused edge joining two unmatched vertices in a matching is the shortest possible augmenting path in a matching. Longer augmenting paths in a matching reassign several partners, explaining why a stalled greedy matching need not be optimal. For edge benefits we​, the change in total benefit is
∑e∈E(P)∖M​we​−∑e∈E(P)∩M​we​,
(9)
which need not be positive even though the cardinality increases. A maximum-weight matching therefore needs a different optimality test. In an assignment equality graph an augmenting path in a matching moves toward a perfect matching while preserving zero reduced costs on matched edges; this is the setting used by the Hungarian algorithm.
