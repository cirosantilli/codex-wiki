Disjoint-set representative (find(x))

 Home Computer science Data structure Disjoint-set data structure
OurBigBook.com Words: 69
A disjoint-set representative is a chosen member of a block of a set partition. It may be any member; it need not be the minimum, the first inserted member or a permanent identifier. A merge may change the disjoint-set representative of an existing member. At any one state, the required rule is
find(x)=find(y)⟺x,y belong to the same block.
(23)
If an application needs the minimum member, store it separately with the disjoint-set representative and update that extra information on merging.
