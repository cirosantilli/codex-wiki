This is the sum of content monomials of colorings up to the group action. It equals the cycle index specialized at tr​=pr​(x). One may first use finitely many colors; stabilization defines the corresponding homogeneous symmetric function. Calling the specialized cycle index a cycle indicator makes ZG​=FG​ an equality in the same variables.
