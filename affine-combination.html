Affine combination (∑i​λi​Pi​,∑i​λi​=1)

 Home Mathematics Area of mathematics Geometry and topology Affine geometry Affine space
OurBigBook.com Words: 356 Articles: 1
An affine combination is a weighted point P=∑i=0k​λi​Pi​ with ∑i=0k​λi​=1. The coefficients can be negative. The sum is meaningful in an affine space without selecting a preferred origin: relative to any point O, it means P=O+∑i​λi​(Pi​−O). Affine maps preserve these weighted points. [ref]
For an original example in the Euclidean plane, take A=(0,0), B=(2,0) and C=(0,2). Then P=41​A+21​B+41​C=(1,21​) lies inside their triangle. Its coefficients are nonnegative, making it a convex combination. In contrast, R=−21​A+23​B=(3,0) is beyond B: it is an affine combination but not a convex combination of these three points. Negative weights allow extrapolation, rather than only interpolation inside the convex hull.
For the affine map T(x,y)=(2x+y+1,y−2), the same weights produce T(P)=(27​,−23​) from T(A),T(B),T(C), and produce T(R)=(7,−2) from T(A),T(B). Thus one can compute a weighted point before transforming the vertices or afterwards, obtaining exactly the same point.
This is useful whenever an object is built from weighted control points: its construction commutes with an affine map, so transforming the control points transforms the constructed object as well. The sum of the weights is the essential condition; no assumption about lengths or angles is needed.
