Newton polynomial (pn​(x)=∑k=0n​f[x0​,…,xk​]∏i=0k−1​(x−xi​))

The Newton polynomial expresses the interpolation polynomial in products that successively vanish at all previously used interpolation nodes. With yi​=f(xi​), the coefficients are divided differences:
pn​(x)=f(x0​)+∑k=1n​f[x0​,…,xk​]∏i=0k−1​(x−xi​).
(153)
A triangular divided difference table computes all its coefficients using exactly n(n+1)/2 divisions. The Newton polynomial and the Lagrange polynomial have the same polynomial degree bound and the same nodal values, hence are equal by uniqueness of polynomial interpolation.
For f(0)=1, f(1)=2, f(2)=5, the complete divided difference table is
xi​012​f[xi​]125​f[xi​,xi+1​]13​f[xi​,xi+1​,xi+2​]1​​
(154)
The first divided differences are 1 and 3, and their divided difference is (3−1)/(2−0)=1. Reading the top entries gives
p2​(x)=1+1(x−0)+1(x−0)(x−1)=1+x+x(x−1)=x2+1.
(155)
The initial term fits (0,1); adding x also fits (1,2); adding x(x−1) fits (2,5) while leaving the first two data values unchanged. This is the practical beauty of the Newton polynomial: each new correction respects all previous interpolation constraints.
If a new distinct interpolation node xn+1​ with value yn+1​ arrives, append one term:
pn+1​(x)=pn​(x)+c∏i=0n​(x−xi​),c=∏i=0n​(xn+1​−xi​)yn+1​−pn​(xn+1​)​.
(156)
For example, appending (3,11) to the three-point data gives c=(11−10)/(3⋅2⋅1)=1/6, hence p3​(x)=x2+1+x(x−1)(x−2)/6. Changing the order of the interpolation nodes changes the Newton polynomial coefficients and products, but not the final interpolation polynomial in exact arithmetic.
The products also permit nested evaluation analogous to Horner's method. If ak​=f[x0​,…,xk​], start with bn​=an​ and work backwards by bk​=ak​+(x−xk​)bk+1​; the answer is b0​. The three-point example becomes 1+x[1+(x−1)], needing two multiplications for each evaluation. This organization is useful when adding observations incrementally or evaluating a stored Newton polynomial many times; the Runge phenomenon still depends on the interpolation nodes rather than on which representation is used.
