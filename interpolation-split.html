Interpolation (g(xi​)=yi​)

 Home Mathematics Area of mathematics Analysis Numerical analysis
OurBigBook.com Words: 3k Articles: 24
Interpolation constructs a function agreeing exactly with prescribed values at sample points. The resulting function is an interpolant. Choosing a family determines how missing values are filled: polynomial interpolation selects a polynomial, while linear interpolation joins adjacent samples by straight segments. The McShane extension theorem instead permits any Lipschitz function with a specified bound and provides envelopes controlling all allowed choices.
