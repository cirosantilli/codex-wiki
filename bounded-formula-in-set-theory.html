Bounded formula in set theory (Δ0​)

 ... Foundations of mathematics Set theory Class (set theory) Transitive class Formula relativization to a class Set-theoretic absoluteness
OurBigBook.com Words: 91 Articles: 1
A bounded formula in set theory has every quantifier in one of the forms ∀x∈y or ∃x∈y. Such formulas are absolute between transitive models containing their parameters.
