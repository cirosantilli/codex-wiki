Transitive group action

 Home Mathematics Area of mathematics Algebra Group theory Group action
OurBigBook.com Words: 1k Articles: 14
A group action on a nonempty set X is transitive when every two points lie in the same orbit of a group action, equivalently when for all x,y∈X there is a group element g with g⋅x=y. There is exactly one group orbit: every position is reachable from every other. Requiring X=∅ avoids calling the group action on the empty set transitive merely because the quantified statement has no points to test.[ref]
Here a left group action of a group G means a function G×X→X, written (g,x)↦g⋅x, satisfying
e⋅x=x,(gh)⋅x=g⋅(h⋅x),
(11)
where e is the identity element. Products move the point by h first, then by g. Transitivity says that an orbit map G→X, g↦g⋅x, is surjective for every x∈X; it suffices to check one chosen point.[ref][ref]
For example, the symmetric group S3​ acts on X={1,2,3} by σ⋅i=σ(i). This is a transitive group action, but it is not a free group action: the stabilizer subgroup of 1 is {e,(23)}. Both the transposition (12) and the cyclic permutation (123) send 1 to 2. In contrast, the cyclic group C3​=Z/3Z acts on itself by k⋅x=k+x(mod3), using modular arithmetic. The group element sending x to y is uniquely k=y−x(mod3). These two group actions reach the same number of points, but only the second has unique transport between them.
The stabilizer subgroup Gx​={h∈G:h⋅x=x} measures the ambiguity of transport. If g0​⋅x=y, then
{g∈G:g⋅x=y}=g0​Gx​,Gy​=g0​Gx​g0−1​.
(12)
The first set is a left coset, and the second identity says that stabilizer subgroups in one group orbit are conjugate subgroups. Briefly, g⋅x=g0​⋅x exactly when g0−1​g∈Gx​. Thus, for a finite group in a transitive group action, the orbit-stabilizer theorem gives ∣G∣=∣X∣∣Gx​∣, and there are exactly ∣Gx​∣ transports for each pair of points. The example counts are 6=3⋅2 for S3​ and 3=3⋅1 for C3​. This separates the number of reachable positions from the number of ways to reach each one.[ref]
