Solution set of a linear system ({x:Ax=b}=x0​+kerA)

 Home Mathematics Area of mathematics Algebra Linear algebra System of linear equations
OurBigBook.com Words: 89
For a consistent linear system Ax=b, choose one solution x0​. By linearity, Ax=b if and only if A(x−x0​)=0, so its solution set is the translate x0​+kerA of the kernel. Over the real numbers, this gives exactly one solution when the kernel is zero and infinitely many when the kernel contains a nonzero vector: x0​+tz is a distinct solution for each real t if z=0 lies in the kernel. An inconsistent linear system has an empty solution set. The dimension of a nonempty solution set, regarded as an affine space, is the nullity of A.
