Image edge

 Home Computer science Image processing
OurBigBook.com Words: 138 Articles: 3
An image edge is a rapid grey-value transition, modeled as a large gradient or a jump discontinuity. It differs from an edge of a graph. Variational models can penalize image edge length, while diffusion image processing estimates image edge directions to limit image smoothing across them.
