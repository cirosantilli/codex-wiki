Truth-matrix countermodel for a Hilbert axiom set (N(0)=N(1)=0)

 ... Mathematical logic Propositional logic Proposition Logical connective Logical truth Matrix semantics for a propositional proof system
OurBigBook.com Words: 78
Take ordinary material logical implication on {0,1}, designate 1, and interpret negation by the constant-zero operation N. Then A→(B→A) and (NB→A)→(NA→B) are always designated, and modus ponens rule and logical implication discharge preserve consequence. But (NB→NA)→(A→B) is false for A=1,B=0. Thus the first two schemes and the deduction rule do not derive the last scheme. This detects the loss of a genuine classical-negation principle even though all the displayed schemes are tautologies under the usual classical negation.
