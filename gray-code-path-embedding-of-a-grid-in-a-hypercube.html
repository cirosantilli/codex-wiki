Gray-code path embedding of a grid in a hypercube

 Home Mathematics Area of mathematics Combinatorics Grid graph
OurBigBook.com Words: 40
The order 00,01,11,10 is a Gray code through the four vertices of Q2​. Applying this identification independently in n coordinate pairs makes [4]n=P4n​ a spanning subgraph of the hypercube graph Q2n​. Therefore every vertex boundary in Q2n​ contains the corresponding boundary in [4]n.
