Elementary set shift (Sij​)

 Home Mathematics Area of mathematics Combinatorics Extremal set theory
OurBigBook.com Words: 122 Articles: 2
For i<j, replace a member A containing j but not i by (A∖{j})∪{i} only when the replacement is absent. An elementary set shift preserves family size and the intersecting family property. The inclusion ∂(Sij​F)⊆Sij​(∂F) shows that it cannot increase the lower shadow.
