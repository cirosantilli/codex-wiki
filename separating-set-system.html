Separating set system (∀i=j ∃A: i∈A, j∈/A)

 Home Mathematics Area of mathematics Combinatorics Extremal set theory
OurBigBook.com Words: 82
A set family on a finite set separates ordered pairs if each ordered pair of distinct points has a member containing the first point and omitting the second. If its members are A1​,…,Am​, assign each point the characteristic vector of its incidences, or equivalently Ti​={a:i∈Aa​}. Separation in both directions says precisely that the Ti​ form an antichain in the Boolean lattice on m coordinates. Thus the Sperner theorem gives n≤(⌊m/2⌋m​). Conversely, any antichain of n distinct subsets of [m] supplies such a set family by transposing its incidence table.
