In superdense coding, Alice applies a local Pauli operator to her half of the shared Bell state. Choose a phase bit u and a parity bit v, and encode them using XvZu on Alice's qubit. With the standard definitions of the Bell states,
uv00011011​Alice’s operatorIXZXZ​Bell state, up to global phaseΦ+=(∣00⟩+∣11⟩)/2​Ψ+=(∣01⟩+∣10⟩)/2​Φ−=(∣00⟩−∣11⟩)/2​Ψ−=(∣01⟩−∣10⟩)/2​​​.
(1)
Alice sends her qubit to Bob. He now holds both halves and performs a Bell-basis measurement, recovering uv without error. Equivalently, a CNOT gate with Alice's qubit as control, followed by a Hadamard gate on that qubit, maps these states to their computational labels up to global phases. Four distinguishable alternatives give two classical bits per transmitted qubit, with one shared entangled pair consumed per use.
The initial entanglement distribution is independent of the later message and can be completed beforehand. Bob's local reduced density matrix before Alice's transmission is I/2 for every encoding, so quantum no-signalling prevents it from carrying her choice. This does not make the entangled pair free: if a qubit transmission is used to distribute it, counting that transmission as well gives two qubit transmissions for the two-bit message. The quoted dense-coding rate counts the subsequent message-bearing transmission with entanglement already shared.

A realized message x has self-information I(x)=−log2​px​. The average information per source message is its Shannon entropy,
H(M)=−pA​log2​pA​−pB​log2​pB​−pC​log2​pC​.​
(2)
The average reaches log2​3≃1.58496 bits per message at pA​=pB​=pC​=1/3. Individual rare realizations can have larger self-information; this bound concerns the average.
The given strings form a prefix code with lengths ℓA​=1 and ℓB​=ℓC​=2. To attain the entropy bound without redundancy, the resulting long bit stream must carry one bit of information per bit: unbiased bits with no predictable dependence. For an independent source, the dyadic source matched to a complete prefix code has
pA​=2−1=21​,pB​=pC​=2−2=41​.​
(3)
These probabilities make the encoded stream equivalent to parsing independent fair bits using the code tree. Its expected codeword length and source entropy agree:
ℓ=H(M)=21​⋅1+41​⋅2+41​⋅2=23​ bits per message.​
(4)
Here “optimal” means attaining the Shannon bound. If it means only an optimal prefix code among symbol-by-symbol binary prefix codes, the probabilities are not unique: for three positive-probability symbols, this tree is optimal whenever pA​ is a largest probability. Huffman coding need not attain entropy exactly for nondyadic probabilities.
Concatenating the specified source-message encodings gives
AABCACBA ⟼ 0∣0∣10∣11∣0∣11∣10∣0=001011011100.
(5)
Pack consecutive bits in pairs, rather than allocating a fresh Bell pair to each variable-length source word:
00∣10∣11∣01∣11∣00.
(6)
Under the mapping in part 1, transmit
Φ+, Φ−, Ψ−, Ψ+, Ψ−, Φ+.​
(7)
The block uses six message-bearing qubit transmissions and six preshared Bell pairs. Source-message boundaries are recovered by parsing the decoded prefix bit stream.

The actual resource is a two-component Bell resource in dense coding. Applying the same local encoder XvZu to
∣χ⟩=5​2∣Φ+⟩+∣Φ−⟩​
(8)
gives a superposition of the intended Bell state with amplitude magnitude 2/5​ and its phase-label partner with amplitude magnitude 1/5​. A Bell-basis measurement therefore reports the wrong Bell state with probability 1/5, independently of uv. With our labeling, only the phase bit u flips:
(u,v)=(u⊕N,v),P(N=1)=51​.
(9)
The first bit of each pair passes through a binary symmetric channel with error 1/5; the second bit is correct. A uniformly chosen bit from the full stream consequently has
Pbit error​=21​⋅51​=101​.​
(10)
This bit error probability depends on the Bell labeling. The Bell-label Hamming distance and bit errors rule multiplies the wrong-symbol probability by the number of bit positions changed. For example, relabel Φ+,Φ−,Ψ+,Ψ− as 00,11,01,10. Both wrong-state partner pairs then differ in two bits, giving bit error probability 1/5 instead of 1/10. The physical wrong-Bell-state probability remains 1/5.
For the entropy-matched independent source in part 2, the transmitted bit stream is fair, and consecutive two-bit labels are uniform. Write the binary entropy as h2​(p)=−plog2​p−(1−p)log2​(1−p). If a bit position is chosen uniformly and its phase/parity position is forgotten, the pooled corresponding-bit pair is a binary symmetric channel with error 1/10. Its mutual information is
I(B;B)=1−h2​(1/10)≃0.531004 bits.​
(11)
The bit-position information in a binary channel distinguishes this pooled quantity from the information in the decoded blocks. Alice and Bob know which bit is first in each Bell label. Conditioned on that position J, the first bit gives 1−h2​(1/5) bits and the second gives one bit. Thus
I(B;B∣J)=1−21​h2​(1/5)≃0.639036 bits per bit.​
(12)
Equivalently, the joint mutual information between the two-bit input and output labels is 2−h2​(1/5)≃1.278072 bits per transmitted Bell label for the prescribed Bell measurement. Pooling without the position loses usable side information; it is not interchangeable with this block rate. The stated fair-input values use the optimal source distribution above; biased source bits require their actual joint distribution.
