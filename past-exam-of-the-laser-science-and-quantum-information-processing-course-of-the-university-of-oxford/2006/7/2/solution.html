A realized message x has self-information I(x)=−log2​px​. The average information per source message is its Shannon entropy,
H(M)=−pA​log2​pA​−pB​log2​pB​−pC​log2​pC​.​
(2)
The average reaches log2​3≃1.58496 bits per message at pA​=pB​=pC​=1/3. Individual rare realizations can have larger self-information; this bound concerns the average.
The given strings form a prefix code with lengths ℓA​=1 and ℓB​=ℓC​=2. To attain the entropy bound without redundancy, the resulting long bit stream must carry one bit of information per bit: unbiased bits with no predictable dependence. For an independent source, the dyadic source matched to a complete prefix code has
pA​=2−1=21​,pB​=pC​=2−2=41​.​
(3)
These probabilities make the encoded stream equivalent to parsing independent fair bits using the code tree. Its expected codeword length and source entropy agree:
ℓ=H(M)=21​⋅1+41​⋅2+41​⋅2=23​ bits per message.​
(4)
Here “optimal” means attaining the Shannon bound. If it means only an optimal prefix code among symbol-by-symbol binary prefix codes, the probabilities are not unique: for three positive-probability symbols, this tree is optimal whenever pA​ is a largest probability. Huffman coding need not attain entropy exactly for nondyadic probabilities.
Concatenating the specified source-message encodings gives
AABCACBA ⟼ 0∣0∣10∣11∣0∣11∣10∣0=001011011100.
(5)
Pack consecutive bits in pairs, rather than allocating a fresh Bell pair to each variable-length source word:
00∣10∣11∣01∣11∣00.
(6)
Under the mapping in part 1, transmit
Φ+, Φ−, Ψ−, Ψ+, Ψ−, Φ+.​
(7)
The block uses six message-bearing qubit transmissions and six preshared Bell pairs. Source-message boundaries are recovered by parsing the decoded prefix bit stream.
