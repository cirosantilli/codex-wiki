Rank-nullity theorem (dimV=dimkerT+dimimT)

 Home Mathematics Area of mathematics Algebra Linear algebra Kernel of a linear map
OurBigBook.com Words: 522 Articles: 2
The rank-nullity theorem accounts for the input dimensions of a linear map: the number of independent invisible input directions plus the number of independent reachable output directions equals the input dimension. For T:V→W over a field, with finite-dimensional domain of a function V,
dimV=dimkerT+dimimT.​
(12)
Here dimkerT is the nullity, and dimimT is the rank of a linear map. The kernel lives in the input vector space, while the image of a linear map lives in the output vector space. For an m-by-n matrix of matrix rank r, the formula is n=(n−r)+r: the number of columns counts input coordinates. [ref]
For a computed example over the real numbers, take
A=(10​20​),T(x,y)=A(xy​)=(x+2y,0).
(13)
The kernel is span{(−2,1)} and the image of a linear map is span{(1,0)}. Each has dimension one, so the two input dimensions split as 2=1+1. The vector (3,1) can be written
(3,1)=(1,2)+(2,−1),T(1,2)=(5,0),T(2,−1)=(0,0).
(14)
The second summand is undetectable: T(3,1)=T(1,2). The picture uses the standard dot product to choose a visible direction perpendicular to the kernel; this is a convenient geometric choice, not an extra hypothesis of the rank-nullity theorem.
This explains a practical tradeoff in a linear system. If T(x0​)=b, every other input with output b is x0​+k for k∈kerT. The nullity therefore counts independent freedom in an existing solution; the rank counts independent reachable output directions. In the example, T(x,y)=(3,0) has all solutions (x,y)=(3−2t,t), while T(x,y)=(3,1) has none. The cokernel records this failure of reachability.
For an m-by-n matrix, injectivity requires matrix rank n, and surjectivity requires matrix rank m. When m=n, these conditions differ. For example, B:R3→R2 with B(x,y,z)=(x+2y,0) has rank one and nullity two, because kerB=span{(−2,1,0),(0,0,1)}. The input accounting is 3=2+1, although only one of two output directions is reached.
Proof outline: extend a basis k1​,…,kq​ of the kernel to a basis k1​,…,kq​,v1​,…,vr​ of V. Every output is a linear combination of T(v1​),…,T(vr​) because the ki​ vanish under T. If a linear combination of the T(vj​) is zero, the corresponding combination of the vj​ lies in the kernel; linear independence of the full basis forces all its coefficients to vanish. Thus the added basis vectors give a basis of the image of a linear map. Counting them proves the formula.
