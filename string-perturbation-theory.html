String perturbation theory

 Home Physics Branches of physics String theory String coupling
OurBigBook.com Words: 280 Articles: 6
String perturbation theory expands amplitudes in powers of the String coupling by summing over worldsheet topologies. It is reliable where the local effective coupling eΦ(X) is small.
