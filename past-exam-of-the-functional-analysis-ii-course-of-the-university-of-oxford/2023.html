In a real Hilbert space, weak convergence in a Hilbert space means
xn​⇀x⟺⟨xn​,z⟩⟶⟨x,z⟩ for every z∈X.​
(1)
By the Riesz representation theorem, every continuous linear functional on X has the form u↦⟨u,z⟩. Thus this is exactly weak convergence, defined by convergence under every continuous linear functional.

For each real a, define the sublevel set Ka​={u∈K:F(u)≤a}. Continuity of F and closure of K make Ka​ a closed set in X; the convex function inequality makes it a convex set. The preceding result therefore makes every Ka​ a sequentially weakly closed set. Equivalently, F has weak lower semicontinuity along sequences in K.
Every Ka​ is bounded. This is immediate if K is bounded. Otherwise, an unbounded Ka​ would contain un​ with ∥un​∥≥n, contradicting the assumed coercive function condition F(un​)→∞.
Choose z∈K and put ℓ=infK​F∈[−∞,F(z)]. Choose a minimizing sequence (un​) entirely in KF(z)​, with F(un​)→ℓ; when ℓ=−∞, require F(un​)≤−n for sufficiently large n. It is bounded by the previous paragraph.
The weak subsequence of a bounded Hilbert-space sequence theorem gives unj​​⇀u0​. This applies even if X is not separable: the closed linear span of the sequence is a separable Hilbert space; successive extraction makes every coefficient in a countable Hilbertian basis converge, the common norm bound gives square-summable limiting coefficients by the Bessel inequality, and approximation by finite linear combinations proves weak convergence. Orthogonal decomposition extends that conclusion to all test vectors in X. Since K is a sequentially weakly closed set, u0​∈K.
For any real a>ℓ, a tail of (unj​​) lies in Ka​, so u0​∈Ka​. If ℓ=−∞, this would give F(u0​)≤a for every real a, impossible because F is real-valued. Thus ℓ is finite; letting a↓ℓ gives F(u0​)≤ℓ, while the definition of infimum gives the reverse inequality. Therefore
u0​∈K,F(u0​)=u∈Kmin​F(u).​
(8)
This proves minimum of a coercive convex functional on a Hilbert space by the direct method in the calculus of variations, with bounded sublevel sets supplying the required weak sequential compactness in a Hilbert space.

The Banach-Steinhaus convergence theorem can be stated as follows. Let X be a normed space, Y a Banach space, and An​∈B(X,Y). If
supn​∥An​∥<∞
(9)
and An​d converges in Y for every d in a dense subset D⊆X, then An​x converges for every x∈X. The pointwise limit A is a bounded linear operator and
An​x⟶Ax(x∈X),∥A∥≤nliminf​∥An​∥.​
(10)
If X is also a Banach space, the uniform operator norm bound is necessary: pointwise convergence implies pointwise boundedness, so the Banach-Steinhaus theorem, namely the Uniform boundedness principle, supplies it. The limit is convergence in the strong operator topology; it need not be convergence in operator norm.
To see the sufficient direction, write C=supn​∥An​∥. For d∈D the triangle inequality gives
∥An​x−Am​x∥≤2C∥x−d∥+∥An​d−Am​d∥.
(11)
First approximate x by d, then let m,n→∞. Completeness of Y gives the limit. Linearity passes to limits, and ∥Ax∥=limn​∥An​x∥≤(liminfn​∥An​∥)∥x∥ gives the displayed bound. If a candidate bounded linear operator A:X→Y is already given and An​d→Ad on D, the same approximation proves convergence to Ax even when Y is merely a normed space.

The open mapping theorem states that a surjective bounded linear operator T:X→Y between Banach spaces is an open map: T(U) is an open set in Y whenever U is an open set in X. Equivalently, there is δ>0 such that
BY​(0,δ)⊆T(BX​(0,1)),​
(15)
where both displayed balls are open. In particular, a bijective bounded linear operator between Banach spaces has a bounded inverse, the bounded inverse theorem.

Use the closed unit ball BX​ first, and put C=T(BX​)​. This is a convex set symmetric about zero. If BY​(y0​,r)⊆C, then −y0​∈C, so taking midpoints gives
BY​(0,r/2)⊆C.

Write δ=r/2. By scaling,
BY​(0,2−jδ)⊆T(2−jBX​)​(j≥1).
(17)
Fix y with ∥y∥<δ/2. Starting with r0​=y, recursively choose xj​∈X such that
∥xj​∥≤2−j,rj​=rj−1​−Txj​,∥rj​∥<2−j−1δ.
(18)
At each step the previous residual lies in the open ball on the left of the scaled inclusion, so the definition of closure permits this approximation. BY​(0,δ/2)⊆T(BX​).
(19)
Scaling by 1/2 now gives the slightly smaller open ball
BY​(0,δ/4)⊆T(BX​(0,1)).​
(20)
This proves the assertion whether the original unit ball is taken open or closed. Only completeness of X was used; the normed space Y need not be complete. The argument is geometric correction for approximate surjectivity.

For n≥1 put Cn​=T(nBX​)​, with closure taken in Y. Then
T(X)=⋃n=1∞​T(nBX​)⊆⋃n=1∞​Cn​.
(21)
If every Cn​ has empty interior, then each Cn​ is a nowhere dense set, because it is closed. Each T(nBX​) is then a nowhere dense set too. Consequently T(X) is a meagre set, that is, a set of the first category in Y.
Otherwise some Cn​ has nonempty interior. Scaling gives nonempty interior of T(BX​)​. The geometric correction for approximate surjectivity proved in the preceding part gives an open ball about zero inside T(BX​). Since T(X) is a vector subspace, it then equals Y: scale any y∈Y into this ball and scale its preimage back. Hence T(X) is a closed set.
Thus, in fact, the stronger operator range category dichotomy holds:
T(X)=YorT(X) is meagre in Y.​
(22)
In particular T(X) is closed or of the first category, as required. The only substantive theorem used here is the preceding geometric correction for approximate surjectivity: for a bounded linear operator from a Banach space to a normed space, nonempty interior of the closure of the image of the unit ball implies nonempty interior of the image itself. Its series proof was given there, so this proof does not require the Baire category theorem or completeness of Y.

Let J:C([0,1])→L1(0,1) send a continuous function to its almost everywhere equivalence class. The domain with the supremum norm and the target with the L1 norm are Banach spaces, and
∥Jf∥L1​=∫01​∣f(t)∣dt≤∥f∥∞​.
(23)
Thus J is a bounded linear operator, and the requested vector subspace is J(C([0,1])).
To show this image of a linear map is not closed, consider the continuous functions
fn​(t)=min{1,max{0,n(t−1/2)}}(n≥2)
(24)
and g=1(1/2,1)​. Their L1 norm difference is the area of one triangle:
∥Jfn​−g∥L1​=∫1/21/2+1/n​(1−n(t−1/2))dt=2n1​⟶0.
(25)
But g has no continuous function representative. Indeed, a continuous function equal to zero almost everywhere on (0,1/2) must be identically zero there: any nonzero value would persist on an open interval of positive Lebesgue measure. Likewise any continuous representative would be identically one on (1/2,1). Continuity at 1/2 makes these requirements incompatible. Therefore g∈/J(C([0,1])), although it lies in its closure.
The preceding operator range category dichotomy proves continuous functions are meagre in L1:
J(C([0,1])) is of the first category in L1(0,1).​
(26)

Use the intended space of Hilbert-Schmidt operators, with the given Hilbert-Schmidt inner product linear in its first argument. It remains to prove completeness in its Hilbert-Schmidt norm. Let (Tn​) be a Cauchy sequence in that norm. The bound ∥Tn​−Tm​∥≤∥Tn​−Tm​∥2​ makes it a Cauchy sequence in operator norm. The space B(X) is a Banach space, so Tn​→T in operator norm for some bounded linear operator T.
