For each real a, define the sublevel set Ka​={u∈K:F(u)≤a}. Continuity of F and closure of K make Ka​ a closed set in X; the convex function inequality makes it a convex set. The preceding result therefore makes every Ka​ a sequentially weakly closed set. Equivalently, F has weak lower semicontinuity along sequences in K.
Every Ka​ is bounded. This is immediate if K is bounded. Otherwise, an unbounded Ka​ would contain un​ with ∥un​∥≥n, contradicting the assumed coercive function condition F(un​)→∞.
Choose z∈K and put ℓ=infK​F∈[−∞,F(z)]. Choose a minimizing sequence (un​) entirely in KF(z)​, with F(un​)→ℓ; when ℓ=−∞, require F(un​)≤−n for sufficiently large n. It is bounded by the previous paragraph.
The weak subsequence of a bounded Hilbert-space sequence theorem gives unj​​⇀u0​. This applies even if X is not separable: the closed linear span of the sequence is a separable Hilbert space; successive extraction makes every coefficient in a countable Hilbertian basis converge, the common norm bound gives square-summable limiting coefficients by the Bessel inequality, and approximation by finite linear combinations proves weak convergence. Orthogonal decomposition extends that conclusion to all test vectors in X. Since K is a sequentially weakly closed set, u0​∈K.
For any real a>ℓ, a tail of (unj​​) lies in Ka​, so u0​∈Ka​. If ℓ=−∞, this would give F(u0​)≤a for every real a, impossible because F is real-valued. Thus ℓ is finite; letting a↓ℓ gives F(u0​)≤ℓ, while the definition of infimum gives the reverse inequality. Therefore
u0​∈K,F(u0​)=u∈Kmin​F(u).​
