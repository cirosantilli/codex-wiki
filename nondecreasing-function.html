Nondecreasing function (x<y⟹f(x)≤f(y))

 ... Mathematics Area of mathematics Analysis Real analysis Calculus Monotonic function
OurBigBook.com Words: 78
A real-valued function f:D→R is a nondecreasing function if every pair x<y in its domain of a function satisfies f(x)≤f(y). Flat intervals are allowed, unlike for a strictly increasing function. For example,
p(x)=min(1,max(0,x))=⎩⎨⎧​0,x,1,​x≤0,0<x<1,x≥1​
(113)
is a continuous nondecreasing function, but it repeats its output on each flat interval.
A nondecreasing function can also be discontinuous. The step function F(x)=0 for x<0 and F(x)=1 for x≥0 has a jump discontinuity at zero without ever decreasing. It is the cumulative distribution function of a random variable that equals zero with probability one; quantile functions handle such jumps through a generalized inverse. Nondecreasing allocation functions permit critical-value payments in single-parameter mechanisms.
