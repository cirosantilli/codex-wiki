Closed-loop control (e(t)=r(t)−ym​(t))

Feedback control selects a control input using observations of the actual controlled plant. In a tracking loop, compare the reference signal r with the measured output ym​ to form the tracking error e=r−ym​, then let the controller change u. The control input changes the plant output, which is measured again: that return path closes the loop. A controller can use earlier observations as well as the latest one. [ref]
For the ideal controlled plant, proportional control u=2(1−x) initially commands u(0)=2. As x approaches 1, the command shrinks. When a positive control disturbance pushes x above 1, the tracking error becomes negative and the control input pushes back. The result is a bounded offset rather than the continuing drift of open-loop control. Integral action can remove that offset by remembering past tracking errors.
A control selected from the observed current state, rather than specified only as a function of the initial state and time. For xt+1​=xt​+ut​ and stage cost xt2​+2xt​ut​+7ut2​, the infinite-horizon feedback ut​=−xt​/3 gives xt​=(2/3)tx0​ and total cost 2x02​. The finite-horizon Bellman coefficients satisfy Π0​=0, Πs​=6(1+Πs−1​)/(7+Πs−1​) and increase to two, proving optimality.
