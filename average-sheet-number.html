Average sheet number (S=Af​(X)/A(Y))

 ... Isolated singularity Classification of isolated singularities Pole Meromorphic function Nevanlinna theory Ahlfors covering surface theory
OurBigBook.com Words: 42
For a holomorphic map between metric Riemann surfaces, the average sheet number is the pulled-back source area divided by the target area. The area formula identifies it with the average number of preimages counted with multiplicity. The same definition over a target region D gives SD​=Af​(f−1D)/A(D).
