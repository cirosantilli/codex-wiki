Flow network ((G,c,s,t))

 Home Mathematics Area of mathematics Foundations of mathematics Graph theory
OurBigBook.com Words: 4k Articles: 39
A flow network is a directed graph G=(V,E) with distinct source and sink vertices s,t and a nonnegative flow network edge capacity cuv​ on each directed edge (u,v). In the finite setting here, every flow network edge capacity is a finite real number. A feasible flow assigns a nonnegative amount fuv​ to each original directed edge, satisfies the capacity constraints, and obeys flow conservation at every other vertex:
0≤fuv​≤cuv​,∑u:(u,v)∈E​fuv​=∑w:(v,w)∈E​fvw​(v∈/{s,t}).
(1)
These are nonnegative arc amounts. The antisymmetric convention in flow instead records net amounts θuv​=fuv​−fvu​, taking a missing arc amount as zero. The two conventions express the same flow conservation; keeping them distinct makes backward residual network edges easier to interpret.
Think of vertices as routers, directed edges as communication links, flow network edge capacities as available bandwidth, and flow as a steady transmission rate. An intermediate router can distribute incoming traffic among outgoing links, but flow conservation prevents it from creating traffic. The maximum flow problem asks how much total traffic can pass from s to t, allowing several graph paths to share the work. The same flow network language models transportation and abstract resource allocation.[ref]
Our running flow network has vertices V={s,a,b,t} and exactly five directed edges, with flow network edge capacities
(csa​,csb​,cab​,cat​,cbt​)=(3,2,1,2,3).
(2)
The cross edge a→b lets traffic entering a use spare capacity on b→t. With this edge removed, the two separate graph paths can carry only min(3,2)+min(2,3)=4; including it will let the maximum flow reach 5. Thus a link's usefulness depends on the rest of the flow network, rather than just its own flow network edge capacity.

Lower bounds on network flow (ℓe​≤fe​≤ce​)

Words: 69
Flow network OurBigBook.com
A prescribed minimum amount on each directed edge can be removed by substituting fe​=ℓe​+xe​. The new capacity constraints are 0≤xe​≤ce​−ℓe​. For a circulation with vertex demands using net inflow dv​, the adjusted demand is dv′​=dv​−(∑u​ℓuv​−∑w​ℓvw​). Solving the adjusted problem and adding ℓ back gives a one-to-one correspondence of feasible solutions. In particular, removing a lower bound on u→v increases u's residual demand and decreases v's by that amount.

A network circulation is a flow with zero net supply at every vertex. A feasible residual network circulation changes one feasible flow into another with the same prescribed supplies. It decomposes into directed cycles, giving the negative-cycle optimality test for minimum-cost flow.

Circulation with vertex demands (∑u​fuv​−∑w​fvw​=dv​)

Words: 74
Circulation in a flow network OurBigBook.com
A flow on a directed graph satisfying capacity constraints and a specified net inflow dv​ at each vertex. Positive dv​ denotes consumption and negative dv​ supply. Summing all balances cancels each edge once as inflow and once as outflow, so ∑v​dv​=0 is necessary. With balanced demands and no lower bounds, add a source edge of flow network edge capacity −dv​ into every supply vertex and an edge of flow network edge capacity dv​ from each demand vertex to a new sink. A maximum flow saturating all auxiliary edges exists exactly when the demands are feasible.

An internal vertex capacity bounds the total flow through that vertex, equivalently its total inflow or outflow by flow conservation. Replace the vertex by an input and output vertex, direct incoming edges to the input and outgoing edges from the output, and connect input to output with an edge of the vertex capacity. This converts the constraint into an ordinary flow network edge capacity.

Maximum flow problem (maxf​∣f∣)

Words: 736 Articles: 7
Flow network OurBigBook.com
The maximum flow problem maximises the strength of a flow from a source to a sink subject to flow conservation and flow network edge capacities. For the nonnegative arc amounts used in flow network, its objective is net outflow from the source:
∣f∣=∑v:(s,v)∈E​fsv​−∑u:(u,s)∈E​fus​=∑u:(u,t)∈E​fut​−∑v:(t,v)∈E​ftv​.
(3)
The equality follows by summing flow conservation over all internal vertices. Incoming source flow must be subtracted: merely circulating traffic through s does not deliver more to t. The max-flow min-cut theorem identifies the optimum with the least cut capacity of a cut of a flow network. A feasible flow and a cut of a flow network of equal value certify optimality without requiring a particular choice of augmenting paths.
For the five-edge flow network with flow network edge capacities (3,2,1,2,3), take
(fsa​,fsb​,fab​,fat​,fbt​)=(3,2,1,2,3).
(4)
Every capacity constraint holds with equality. Flow conservation at a is 3=1+2, and at b it is 2+1=3. The strength of a flow is ∣f∣=3+2=5, also 2+3=5 entering t. This flow consists of 2 units on the graph path s→a→t, 2 on s→b→t, and 1 on s→a→b→t. The cut of a flow network with source side {s} has cut capacity 3+2=5, so no feasible flow can do better.
Even a seemingly poor first augmenting path s→a→b→t, carrying 1, does not cause failure in this example. It leaves residual network capacity 2 along s→a→t and 2 along s→b→t. These two subsequent augmenting paths yield values 1, 3, and 5, and produce exactly the flow above. Backward residual network edges become essential in the unit-capacity example under residual network, where this same first choice blocks every unused forward route.
Discrete assignment is another reason to study maximum flow. Put unit-capacity edges from s to job vertices, from each job to eligible worker vertices, and from workers to t. An integral flow selects a matching in a graph: each job and worker participates at most once, and the strength of a flow counts assigned jobs. The integral max-flow theorem therefore turns maximum cardinality assignment into maximum flow. Minimizing assignment costs is the related assignment problem, modeled by minimum-cost flow.[ref]

Sports elimination by maximum flow

Words: 101
Maximum flow problem OurBigBook.com
For a league in which every remaining game gives exactly one win, first give the target team all its remaining wins, obtaining W. Make a node for each unordered pair of other teams, with source capacity equal to their remaining games. Route each game-node flow to one of its two teams, and cap the team's total additional wins at W−wi​−1 for a strict target victory. A negative cap immediately rules out success. Otherwise an integral maximum flow saturating every game-source arc specifies the winners of all games and proves feasibility. Each actual game is counted once; duplicating ordered pairs changes the problem.

Treatment capacity as a sink arc

Words: 71
Maximum flow problem OurBigBook.com
In a flow network for treatment facilities, the amount treated at a facility is represented by a directed arc from it to the sink, with that arc's capacity equal to its treatment limit. Untreated fluid may pass through the facility independently of how much is treated there. Thus the treatment limit is not a bound on total incoming flow. Flow conservation at a facility equates incoming flow with outgoing untreated flow plus its sink-arc flow.

Server connectivity under component failures (kmax​=λ−1)

To find the smallest link failure set separating a client from every server, add a common sink with sufficiently large-capacity server arcs and give original links unit capacities in both directions. The max-flow min-cut theorem identifies the minimum failure count λ. Unit-capacity vertex splitting also charges intermediary node failures. Edmonds–Karp algorithm

Words: 76
Maximum flow problem OurBigBook.com
This maximum flow algorithm repeatedly augments along a shortest residual path found by breadth-first search. Residual distances from the source never decrease. If the same arc becomes saturated again after being restored by a reverse augmentation, the distance to its tail has increased by at least two. Thus each arc is critical only O(∣V∣) times, yielding O(∣V∣∣E∣) augmentations. Each search costs O(∣E∣), so the total time is O(∣V∣∣E∣2). Termination with no residual source-sink path supplies a max-flow min-cut theorem certificate.

Flow network edge capacity (cij​)

Flow network OurBigBook.com
A directed edge capacity is the upper bound cij​≥0 on the feasible nonnegative flow through that edge. In a residual network, its forward residual capacity is cij​−fij​ and its backward residual capacity is fij​. Increasing every edge capacity need not increase the maximum flow by that same amount, because a cut of a flow network can contain several edges.

Cut of a flow network

Words: 699 Articles: 3
Flow network OurBigBook.com
A source-to-sink cut of a flow network is a partition of a set (S,V∖S) of the vertex set of a flow network, with s∈S and t∈/S. Its cut capacity sums the flow network edge capacities of directed edges leaving S.[ref]
The side S may contain any selection of the other vertices; its induced subgraph need not be a connected graph. For the five-edge flow network with flow network edge capacities (csa​,csb​,cab​,cat​,cbt​)=(3,2,1,2,3), S={s} gives the partition of a set ({s},{a,b,t}). Only s→a and s→b leave this side, so its cut capacity is 3+2=5. Choosing S={s,b} instead puts a→b across the boundary in the incoming direction: its flow network edge capacity is excluded.
The left panel pairs a feasible flow of flow value 5 with a cut of a flow network of cut capacity 5, proving that each is optimal. The right panel uses the same feasible flow but a different cut of a flow network: the outward flow is 3+3=6 and the backward flow is 1, giving net flow 6−1=5. That cut capacity is 6, so it supplies a valid but less sharp bound. The dashed boundary marks a partition of a set, rather than an additional edge or a proposed route.

Minimum cut

Words: 206 Articles: 1
Cut of a flow network OurBigBook.com
A minimum cut is a cut of a flow network of least cut capacity for the prescribed source s and sink t. The max-flow min-cut theorem equates that least cut capacity with the greatest flow value.[ref]
To certify a particular minimum cut, exhibit a feasible flow whose flow value equals its cut capacity. Every feasible flow is bounded above by every cut capacity, so this single equality proves both optimalities.[ref]
In the running example, the four possible source sides {s}, {s,a}, {s,b} and {s,a,b} have cut capacities 5,5,6,5, respectively. The feasible flow of flow value 5 therefore certifies three different minimum cuts. A minimum cut need not be unique; the optimum cut capacity is the same for all of them. Merely saturating many edges does not give this certificate: flow conservation and the particular cut of a flow network must also be checked.

Cut capacity (c(S,Sc)=∑u∈S,v∈/S​cuv​)

Words: 319
Cut of a flow network OurBigBook.com
The cut capacity of (S,Sc), with Sc=V∖S the complement of a set, is
c(S,Sc)=∑(u,v)∈E:u∈S,v∈/S​cuv​.
(5)
Only outward directed edges contribute; incoming and internal edges contribute nothing.[ref]
Here is the accounting behind the bound, using nonnegative original edge amounts fuv​ in a finite flow network. Sum the divergence of a flow over the vertices in S:
∑v∈S​divf(v)=∑v∈S​(∑w:(v,w)∈E​fvw​−∑u:(u,v)∈E​fuv​).
(6)
An edge with both endpoints in S appears once with a plus sign at its tail and once with a minus sign at its head, so those contributions cancel. An outward edge appears only with a plus sign; an incoming edge appears only with a minus sign. Since s∈S, t∈/S and every other vertex satisfies flow conservation, the left side is the flow value. Thus
∣f∣=∑(u,v)∈E:u∈S,v∈/S​fuv​−∑(u,v)∈E:u∈/S,v∈S​fuv​≤∑(u,v)∈E:u∈S,v∈/S​cuv​=c(S,Sc).
(7)
The inequality uses two facts separately: each forward flow is at most its flow network edge capacity, and each backward flow is nonnegative. This is the weak duality bound underlying the max-flow min-cut theorem. It is an accounting proof, requiring no choice of augmenting paths.
For S={s,b} in the running example, explicitly add the two divergences of a flow:
divf(s)+divf(b)=(fsa​+fsb​)+(fbt​−fsb​−fab​)=fsa​+fbt​−fab​=3+3−1=5.
(8)
The internal s→b edge cancels. The a→b edge is a genuine original directed edge entering S, so its flow is subtracted; this is different from a backward edge in a residual network. Its flow network edge capacity is neither added to nor subtracted from cut capacity, which remains csa​+cbt​=6.
Equality in the bound holds precisely when every outward edge is saturated and every incoming edge carries zero flow, because
c(S,Sc)−∣f∣=∑(u,v)∈E:u∈S,v∈/S​(cuv​−fuv​)+∑(u,v)∈E:u∈/S,v∈S​fuv​,
(9)
and every term is nonnegative. For S={s} the two outward edges are saturated and there are no incoming edges, so the gap is zero. For S={s,b} all outward edges are still saturated, but the incoming flow of 1 gives a gap of 1. This explains exactly why the second cut of a flow network is not a minimum cut.

Flow (θ)

Words: 831 Articles: 6
Flow network OurBigBook.com
In a finite directed graph G=(V,E) with distinct source and sink vertices s,t, a flow records an amount fuv​ on each original directed edge. For a feasible flow in a flow network, these amounts satisfy the capacity constraints 0≤fuv​≤cuv​ and flow conservation at every vertex other than s,t.[ref]
The antisymmetric convention records signed net amounts instead:
θuv​=fuv​−fvu​,θvu​=−θuv​,divθ(v)=∑w∈V​θvw​=0(v∈/{s,t}),
(10)
taking missing edge amounts as zero. The paired signs describe one net transfer, rather than two independent transfers.[ref]
For example, if separate original directed edges u→v and v→u carry 3 and 1, their net amount is θuv​=2. This signed record loses the separate amounts: fuv​=2, fvu​=0 would give the same net amount. When checking capacity constraints on actual edges, keep the original amounts or specify the signed bounds carefully; when summing flow conservation, either record gives the same divergence of a flow.
For the running flow network, choose the original edge amounts
(fsa​,fsb​,fab​,fat​,fbt​)=(3,2,1,2,3)=(csa​,csb​,cab​,cat​,cbt​).
(11)
Every capacity constraint holds. At a, incoming flow 3 equals outgoing flow 1+2; at b, incoming flow 2+1 equals outgoing flow 3. This feasible flow has flow value 5, computed at s or t.
The total of all five edge amounts is 11, but the flow value is 5. A unit passing through several edges appears several times in that total. Concretely, route 2 units along each of the directed paths s→a→t and s→b→t, and 1 along s→a→b→t. Their delivered amounts sum to 2+2+1=5, while their edge usages sum to 2⋅2+2⋅2+1⋅3=11. The cut of a flow network S={s} certifies that this delivery rate is already a maximum flow.
Flow conservation is useful because it makes a local ledger predict a global delivery rate: intermediate vertices only redistribute the resource. An additional network circulation can change the individual edge amounts without changing the flow value. Counting net delivery rather than total edge usage prevents such recirculation from masquerading as increased output.

Divergence of a flow (divθ)

Words: 249 Articles: 1
Flow OurBigBook.com
The divergence of a flow at a vertex v is net outward flow. For original nonnegative edge amounts and their signed net record, respectively,
divf(v)=∑w:(v,w)∈E​fvw​−∑u:(u,v)∈E​fuv​=∑w∈V​θvw​.
(12)
Positive divergence of a flow means net supply, negative divergence of a flow means net demand, and zero is flow conservation. This is the same sign convention as flow balance.
In the running example, the divergences of a flow at (s,a,b,t) are (5,0,0,−5). Adding the four divergences of a flow gives zero: every edge contributes positively at one endpoint and negatively at the other. In a finite flow network, this cancellation explains why net supply at s equals net demand at t.

Flow conservation

Words: 161
Divergence of a flow OurBigBook.com
Flow conservation requires equal total inflow and outflow at every vertex other than the source and sink:
∑u:(u,v)∈E​fuv​=∑w:(v,w)∈E​fvw​(v∈/{s,t}).
(13)
Equivalently, the divergence of a flow is zero there.[ref]
This is a steady accounting condition: an intermediate vertex neither creates the routed resource nor accumulates it. Splitting is allowed; equality between individual incoming and outgoing edges is not required. For the running flow, the equation at a is fsa​=fab​+fat​, or 3=1+2, and at b it is fsb​+fab​=fbt​, or 2+1=3.
Capacity constraints alone do not ensure flow conservation. For instance, changing only fab​ from 1 to 0 keeps every edge amount within its flow network edge capacity, but leaves an excess inflow of 1 at a and an excess outflow of 1 at b. It is therefore not a feasible flow. Changing all affected edge amounts together to (fsa​,fsb​,fab​,fat​,fbt​)=(2,2,0,2,2) restores both equations and gives flow value 4.

Strength of a flow (∣f∣)

Words: 158
Flow OurBigBook.com
The strength of a flow, also called its flow value, is net outflow from s, equivalently net inflow to t:
∣f∣=∑v:(s,v)∈E​fsv​−∑u:(u,s)∈E​fus​=∑u:(u,t)∈E​fut​−∑v:(t,v)∈E​ftv​.
(14)
The notation ∣f∣ denotes this signed value, rather than an absolute value.[ref]
The equality follows by summing the divergence of a flow over all vertices: the internal vertices contribute zero by flow conservation, while every edge cancels between its two endpoints. Hence divf(s)=−divf(t). For the running flow, ∣f∣=3+2=2+3=5.
Net outflow matters even when the source has incoming edges. As a separate example, give s→a, a→s and s→t flow network edge capacities 2,2,3 and flow amounts 2,2,3. At a, flow conservation reads 2=2. The source sends 5 units along outgoing edges but receives 2 back, so the flow value is 5−2=3, exactly the amount arriving at t. The two-edge network circulation through a raises total edge usage without increasing net delivery.

Max-flow min-cut theorem (maxf​∣f∣=minS:s∈S,t∈/S​c(S,V∖S))

Words: 1k Articles: 13
Flow network OurBigBook.com
For a finite flow network with finite nonnegative real flow network edge capacities, the greatest strength of a flow of a feasible flow equals the least cut capacity of a source-to-sink cut of a flow network:
maxf feasible​∣f∣=minS⊆V:s∈S,t∈/S​∑(u,v)∈E:u∈S,v∈/S​cuv​.
(16)
For a maximum flow, the vertices reachable from the source in the residual network define a minimum cut whose outgoing original edges are saturated and whose incoming original edges carry zero flow.[ref]
Why is a cut of a flow network an upper bound? Sum flow conservation on its source side S. Internal edge contributions cancel, leaving
∣f∣=∑(u,v)∈E:u∈S,v∈/S​fuv​−∑(u,v)∈E:u∈/S,v∈S​fuv​≤∑(u,v)∈E:u∈S,v∈/S​cuv​=c(S,V∖S).
(17)
Only directed edges leaving S contribute to cut capacity. Directed edges entering S are subtracted in net flow, so adding their capacities to the upper bound would lose the intended bottleneck. This inequality is weak duality; the theorem says the bound is attained, an instance of strong duality. Its beauty is that a routing plan and a separating boundary independently witness each other's optimality.
In the running flow network, the two internal vertices give four possible source sides. For S={s}, the cut capacity is csa​+csb​=3+2=5. For S={s,a} it is csb​+cab​+cat​=2+1+2=5. For S={s,b} it is csa​+cbt​=3+3=6; the incoming edge a→b contributes nothing to that cut capacity. Finally, S={s,a,b} gives cat​+cbt​=2+3=5. Thus the minimum cut has cut capacity 5, matching the explicitly computed maximum flow.
Ford and Fulkerson's 1956 paper opens with a railway-capacity question attributed there to T. Harris and proves a minimal-cut theorem as Theorem 1. Its original formulation uses graph paths carrying nonnegative amounts; the residual reachability certificate for maximum flow below gives the finite directed flow network proof used here.[ref]

Residual reachability certificate for maximum flow

Words: 135
Max-flow min-cut theorem OurBigBook.com
In a finite flow network, a maximum flow exists because the feasible flow set contains the zero flow and is a compact set: the capacity constraints bound every coordinate, and they and flow conservation define a closed set. The strength of a flow is a continuous function, so the extreme value theorem gives an attained maximum. An augmenting path in the residual network would permit positive augmentation, contradicting maximality. The source-reachable vertices in the residual network therefore define a cut of a flow network whose outgoing original edges are saturated and incoming original edges carry zero flow. Flow conservation makes the strength of a flow equal to this cut capacity, proving the max-flow min-cut theorem.
Existence and strong duality for finite real flow network edge capacities do not imply finite termination for every choice of augmenting paths in the Ford-Fulkerson algorithm. With irrational capacities, some choices can continue forever. With integer capacities, Integrality of the Ford-Fulkerson algorithm instead forces finite termination; rational capacities reduce to that case by a common denominator. Choosing shortest augmenting paths as in the Edmonds–Karp algorithm avoids dependence on capacity magnitudes.[ref]

Uniform capacity perturbation of a flow network (v(ε)=minS​(c(S)+εm(S)))

Words: 94
Max-flow min-cut theorem OurBigBook.com
If every directed edge capacity increases by ε, a cut of a flow network with m(S) outgoing edges gains εm(S). By the max-flow min-cut theorem, the new maximum flow value is
v(ε)=minS:s∈S,t∈/S​(c(S)+εm(S)).
(18)
For a finite flow network, this is a nondecreasing concave piecewise-linear function, and its active cut can change as ε varies. Two unit-capacity edge-disjoint two-edge source-to-sink paths gain 2ε, refuting an invariably exact ε increase. If there is a directed source-to-sink path, every cut has at least one outgoing edge and the increase is at least ε; without a path it can be zero.

Residual network (Gf​)

Words: 717 Articles: 7
Max-flow min-cut theorem OurBigBook.com
For a feasible flow f, each original directed edge u→v supplies a forward residual network edge of capacity cuv​−fuv​ and a backward one v→u of capacity fuv​; zero-capacity residual edges may be omitted. The forward edge permits an increase, while the backward edge permits cancellation of existing flow. In particular, backward residual capacity is the amount already sent, rather than unused original capacity. If both original orientations exist, keep their residual contributions separate, or add capacities for contributions with the same direction. An augmenting path uses these permitted changes while preserving flow conservation and the capacity constraints.
To see why cancellation matters, give all five directed edges s→a, s→b, a→b, a→t, b→t unit flow network edge capacities. Starting from zero flow, an augmenting path s→a→b→t carrying 1 yields
(fsa​,fsb​,fab​,fat​,fbt​)=(1,0,1,0,1),∣f∣=1.
(19)
The remaining unused original edges are s→b and a→t, which do not form a source-to-sink graph path. However, the backward residual edge b→a has capacity fab​=1. Consequently the residual network contains the augmenting path s→b→a→t, with residual capacities 1,1,1.
Augment by 1: increase fsb​ and fat​ from 0 to 1, and decrease fab​ from 1 to 0. The result is
(fsa​,fsb​,fab​,fat​,fbt​)=(1,1,0,1,1),∣f∣=2.
(20)
Now flow conservation is 1=0+1 at a and 1+0=1 at b. The final flow sends one unit along each of s→a→t and s→b→t. The cut of a flow network S={s} has cut capacity 1+1=2, proving this is a maximum flow. Traversing b→a in the residual network revised the earlier routing decision; it did not send actual traffic along a nonexistent original edge.

Residual maximum flow is the remaining optimality gap (fres∗​=f∗−f)

For an undirected capacitated network, write the net edge flow as yij​=−yji​, and the directed residual capacity as cij​−yij​. On every source–sink cut, residual capacity is the original cut capacity minus the current net flow value f. Taking the minimum over cuts and applying the max-flow min-cut theorem to each network gives the displayed remaining-flow identity.

Augmenting path (Δ=mine∈P​cf​(e)>0)

Words: 293 Articles: 4
Residual network OurBigBook.com
An augmenting path is a source-to-sink graph path P of positive capacities in the residual network. Its bottleneck is Δ=mine∈P​cf​(e)>0. Add Δ to original flow on forward residual edges and subtract Δ on backward residual edges. Each internal vertex still satisfies flow conservation, and the bottleneck guarantees every capacity constraint. The resulting feasible flow has strength of a flow ∣f∣+Δ. In the unit-capacity residual network example, Δ=1, and the subtraction on a→b is precisely what allows the value to rise from 1 to 2.
Widest augmenting path (maxP:s⇝t​mine∈P​cres​(e))
Words: 127 Articles: 1
Augmenting path OurBigBook.com
An augmenting path maximizing the possible increase in flow, namely its smallest residual network edge capacity. If the remaining maximum flow is F>0 and the original undirected network has m edges, a path has bottleneck at least F/m. Otherwise the vertices reachable through arcs of capacity at least F/m define a cut of capacity strictly less than F, contradicting the max-flow min-cut theorem. Only one directed arc per original crossing edge contributes to that cut.
Geometric convergence of widest-path augmentation (Fk​≤(1−1/m)kf∗)
Words: 56
Widest augmenting path OurBigBook.com
Starting from zero flow, a widest augmenting path increases the current flow by at least Fk​/m, where Fk​ is its remaining optimality gap. Therefore Fk+1​≤(1−1/m)Fk​. Integer capacities keep this gap integer, so a gap below one is zero. The method takes O(mlogf∗) augmentations for f∗≥2, or uniformly O(mlog(1+f∗)); zero maximum flow requires no augmentation.
Ford-Fulkerson algorithm
Words: 94 Articles: 1
Augmenting path OurBigBook.com
The Ford-Fulkerson algorithm repeatedly augments a feasible flow along an augmenting path. When no such path remains, the source-reachable vertices in the residual network define a cut of capacity equal to the flow value, proving optimality by the max-flow min-cut theorem.
Integrality of the Ford-Fulkerson algorithm
Words: 58
Ford-Fulkerson algorithm OurBigBook.com
Starting from the zero flow with integer capacities, every residual capacity and every augmenting bottleneck is an integer. Each augmentation therefore preserves integer edge flows and raises the flow value by at least one. Since the value is bounded by the total capacity leaving the source, the algorithm terminates after finitely many augmentations with an integral maximum flow.
