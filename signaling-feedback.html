Signaling feedback

 Home Biology Signal transduction
OurBigBook.com Words: 2k Articles: 24
Signaling feedback returns the effect of a downstream event to an earlier stage of signal transduction, closing a loop analogous to feedback control. Trace the causal arrows: if an earlier relay activates a later relay and the later relay changes the earlier relay's activity, the return path closes the loop. Negative feedback opposes the initiating change; positive feedback reinforces it. Signaling feedback is a possible property of signal transduction, not a requirement of every pathway.
For a schematic example, let relay A activate relay B. If B inhibits A, increased A eventually produces an opposing influence: negative feedback. If B activates A, increased A produces a reinforcing influence: positive feedback. These signs describe effects on activity, rather than the direction in which molecules travel. A closed loop containing two inhibitions can have positive feedback, because inhibiting an inhibitor reinforces the original change. The sign belongs to the whole loop.
Negative feedback can restrain excessive activation and help preserve a usable range of responses. Positive feedback can support a decisive transition: Alberts and colleagues describe an enzyme whose product increases its own activity. Such reinforcement can contribute to switchlike behavior, but a positive feedback arrow alone does not prove bistability. A different structure, an incoherent feedforward loop, sends opposing influences forward from the same input; inhibition there is not a downstream return. [ref] [ref]
A worked mathematical model shows why negative feedback does not automatically produce complete signaling adaptation. Let s be a fixed normalized input, r a normalized response, g≥0 a dimensionless feedback gain, and τ>0 a time constant. Suppose response removal contributes −r and a return proportional to the response contributes −gr. The ordinary differential equation is
τdtdr​=s−r−gr=s−(1+g)r.
(3)
Setting the derivative to zero gives the equilibrium point r∗​=s/(1+g). A displacement δr=r−r∗​ obeys τd(δr)/dt=−(1+g)δr, so its decaying exponential function establishes asymptotic stability. For a unit input switched on at t=0, initial condition r(0)=0, g=2 and τ=1 second,
r(t)=31−e−3t/τ​,r(1s)≃0.316737,limt→∞​r(t)=31​.
(4)
The negative feedback reduces the eventual response from 1 to 1/3, but this response rises monotonically and never returns to its zero baseline. Attenuation and complete signaling adaptation are different properties. This deliberately simple mathematical model specifies no molecular pathway; integral action provides a contrasting way to remove a lasting offset in a stable feedback control system. [ref]
