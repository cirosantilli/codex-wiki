Bounded set

 Home Mathematics Area of mathematics Analysis Topological analysis Metric space
OurBigBook.com Words: 92 Articles: 2
A subset A of a metric space is bounded if it lies in some finite-radius ball: there are x and R<∞ such that d(x,a)≤R for every a∈A.
