Separating vector for an operator algebra (aΩ=0⟹a=0)

 ... Mathematics Area of mathematics Analysis Functional analysis Operator algebra Cyclic vector for an operator algebra
OurBigBook.com Words: 165 Articles: 3
A vector is separating for an operator algebra when evaluation at that vector is injective. A cyclic vector for the commutant of an operator algebra is separating for the original algebra: if aΩ=0, then a vanishes on its dense commutant orbit.
