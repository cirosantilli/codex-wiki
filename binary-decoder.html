Binary decoder

 ... Computer science Theoretical computer science Computational complexity theory Circuit complexity Boolean circuit Combinational logic
OurBigBook.com Words: 42
A combinational logic circuit mapping a binary input code to selected output lines. In a one-of-k register-address decoder, line i is asserted exactly when the address equals i, optionally combined with an enable. This selects which processor register may capture a common write-data word.
