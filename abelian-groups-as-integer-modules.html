Abelian groups as integer modules (Z-modules⟷abelian groups)

 ... Mathematics Area of mathematics Algebra Commutative algebra Module theory Module (mathematics)
OurBigBook.com Words: 107
Every abelian group has exactly one unital module structure over the integers. For n>0, define nm by adding m to itself n times, put 0m=0, and put (−n)m=−(nm). The module axioms force this action, so no additional choice is involved. Moreover, every Abelian group homomorphism respects it and is a module homomorphism. See David McKinnon's Modules, the integer-scalar example.
For example, in the free module Z2,
3(2,−1)+(−2)(1,4)=(4,−11).
(18)
In the cyclic group Z/6Z, the same repeated-addition rule gives 42=8=2 and 32=0. The scalar 3 is nonzero in the scalar ring Z, even though it kills the nonzero module element 2. Thus the scalar ring and the module must be kept distinct.
