Downward absoluteness of cardinalhood

 ... Foundations of mathematics Set theory Class (set theory) Transitive class Formula relativization to a class Set-theoretic absoluteness
OurBigBook.com Words: 51
If a larger transitive model regards an ordinal κ as a cardinal number, then a smaller transitive model does too: any bijection in the smaller model witnessing otherwise would remain in the larger one. The converse can fail when the larger model contains a new bijection between κ and a smaller ordinal.
