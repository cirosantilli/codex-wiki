Strictly increasing function (x<y⟹f(x)<f(y))

 ... Mathematics Area of mathematics Analysis Real analysis Calculus Monotonic function
OurBigBook.com Words: 187 Articles: 1
A real-valued function f:D→R is a strictly increasing function if every pair x<y in its domain of a function satisfies f(x)<f(y). It is therefore injective, and each output has at most one preimage. Its inverse function on its image of a function is also strictly increasing. Every strictly increasing function is a nondecreasing function; the converse fails when outputs repeat.
The polynomial f(x)=x3 is a strictly increasing function on the real line, although its derivative f′(x)=3x2 is zero at zero. Indeed, for x<y,
y3−x3=(y−x)(x2+xy+y2)>0,
(114)
because x2+xy+y2=(x+y/2)2+3y2/4 can vanish only when x=y=0. Thus a positive derivative everywhere is sufficient on a real interval, but is not necessary for a strictly increasing function.
Strict monotonicity does not ensure continuity: g(x)=x for x<0 and g(x)=x+1 for x≥0 is a strictly increasing function with a jump discontinuity. Its image of a function omits [0,1), so the inverse function exists only on the actual image of a function, rather than on all the real numbers.
