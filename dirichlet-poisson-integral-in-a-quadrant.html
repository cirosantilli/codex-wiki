The conformal map w=z2 sends x,y>0 to the complex upper half-plane. For bounded continuous boundary values g2​ on the horizontal axis and g1​ on the vertical axis with equal corner values, set f(s)=g2​(s​) for s>0 and f(s)=g1​(−s​) for s<0. The bounded harmonic function with those Dirichlet boundary conditions is
u(z)=π1​∫R​∣s−z2∣2Im(z2)f(s)​ds.
(36)
Equivalently, if z2=a+ic with c>0, this is π2c​∫0∞​r[g2​(r)/((r2−a)2+c2)+g1​(r)/((r2+a)2+c2)]dr. The Poisson kernel is a positive approximate identity, so the prescribed edge values are attained. Boundedness is essential for uniqueness on this unbounded domain.
