Rayleigh radial thresholds and quantiles (P(R>r)=e−r2/(2σ2))

OurBigBook.com Words: 163
For r≥0, integration gives the survival function and cumulative distribution function
P(R>r)=e−r2/(2σ2),FR​(r)=1−e−r2/(2σ2).
(29)
Solving FR​(rp​)=p gives the quantile function
rp​=σ−2log(1−p)​,0<p<1.​
(30)
[ref]
For the chosen positioning model σ=2cm,
P(R≤2cm)=1−e−1/2≃0.3935,P(R≤4cm)=1−e−2≃0.8647.
(31)
The disk of radius one component standard deviation therefore contains about 39.35% of outcomes; the familiar one-dimensional normal interval percentage does not apply to a two-dimensional disk. The 95% and 99% radial thresholds are
r0.95​≃4.8955cm,r0.99​≃6.0697cm.​
(32)
A circle defined by R=rp​ itself still has probability zero; its enclosed disk carries the stated probability.
The closed-form quantile function also gives inverse transform sampling: if U has uniform distribution on (0,1), then σ−2logU​ has Rayleigh distribution. Using 1−U instead gives the same law. Endpoints are excluded so that the logarithm stays finite.
