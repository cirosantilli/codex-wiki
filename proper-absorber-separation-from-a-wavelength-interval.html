Proper absorber separation from a wavelength interval (ℓ≃cΔλ/[H(z)(1+z)λrest​])

 ... Physics Branches of physics Cosmology Scale factor (cosmology) Cosmological redshift Cosmological wavelength-redshift relation
OurBigBook.com Words: 40
A local redshift spacing between absorbers corresponds to proper path length cΔz/[H(z)(1+z)]. Using the same rest-frame transition for all lines gives Δz=Δλ/λrest​. This conversion assumes cosmological redshift dominates the line spacing and uses a local Hubble-rate approximation.
