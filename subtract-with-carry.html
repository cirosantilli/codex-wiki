Subtract with carry

 Home Computer science Central processing unit Processor register Carry flag
OurBigBook.com Words: 52
With the ARM architecture family's no-borrow convention, subtract with carry forms X−Y−(1−Cin​). The same adder used for addition can form X+(2n−1−Y)+Cin​. If its output is Z+2nCout​, rearranging proves X−Y−(1−Cin​)=Z−2n(1−Cout​). Thus complementing the second operand implements both the result and the correctly chained borrow information.[ref]
