File-system directory

 Home Computer science Operating system File system
OurBigBook.com Words: 95 Articles: 1
A file containing directory entries. Each entry supplies a name in that file-system directory; two entries in the same file-system directory cannot have the same name. In an inode-based file system, a file-system directory has its own inode, and its contents describe names of other objects. [ref]
