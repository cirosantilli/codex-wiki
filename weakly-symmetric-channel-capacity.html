Weakly symmetric channel capacity (C=log2​m−H(one row))

 Home Mathematics Area of mathematics Probability and statistics Information theory Channel capacity
OurBigBook.com Words: 847 Articles: 5
For a discrete memoryless channel with m output symbols, suppose every row of the transition matrix is a permutation of every other row and all column sums agree. Such a communication channel has
C=log2​m−H(one row).
(104)
The row Shannon entropy is the same for every input, so H(Y∣X) has that fixed value for every input probability distribution. The remaining term H(Y) is at most log2​m by maximum entropy on a finite alphabet.
A uniform input attains the bound. If there are ℓ input symbols, the total of all transition probabilities in the matrix is ℓ; equal column sums must therefore each be ℓ/m. Multiplication by the uniform input mass 1/ℓ gives output mass 1/m in each column. Hence H(Y)=log2​m, which proves the displayed formula. The cyclic ternary channel capacity, binary symmetric channel capacity, and ternary symmetric channel capacity are concrete applications of this symmetry calculation.
