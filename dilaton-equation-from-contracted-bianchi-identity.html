Dilaton equation from contracted Bianchi identity (□g​φ−2∣∇φ∣2=C)

 ... String theory Bosonic string theory Polyakov action String nonlinear sigma model Sigma-model beta function Leading metric-dilaton Weyl condition
OurBigBook.com Words: 165 Articles: 2
Diverging Rab​+2∇a​∇b​φ=0 and using the contracted Bianchi identity and Ricci identity gives ∇b​(R+4□g​φ−4∣∇φ∣2)=0. The trace equation R+2□g​φ=0 then gives □g​φ−2∣∇φ∣2=C, with C constant on each connected component. Zero does not follow from the tensor equation alone. The additional dilaton anomaly coefficient fixes C=(D−26)/(3α′) at leading order for the bosonic string without an antisymmetric background. In critical dimension it is zero; noncritical backgrounds have a central-charge-deficit term.
