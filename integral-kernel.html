Integral kernel (K(x,y))

 Home Mathematics Area of mathematics Analysis Functional analysis Integral operator
OurBigBook.com Words: 191 Articles: 4
An integral kernel is a function or distribution specifying an integral operator through (Tf)(x)=∫K(x,y)f(y)dy. A Green function is an integral kernel that inverts a differential operator under specified boundary conditions.
