Bellman-Ford algorithm (δ(s,v))

 Home Mathematics Area of mathematics Foundations of mathematics Graph theory Shortest path problem
OurBigBook.com Words: 2k Articles: 3
The Bellman-Ford algorithm solves the single-source shortest path problem in a finite directed graph with finite real edge weights, allowing negative weights. It repeatedly applies edge relaxation, so an improved tentative distance can improve its neighbours on a later visit. This makes it a label-correcting shortest-path algorithm.[ref] If no negative-cost directed cycle is reachable from the source, at most ∣V∣−1 complete passes suffice for all distances; a further check detects a reachable negative-cost directed cycle.[ref]
There are two orientations to keep distinct. The usual single-source problem asks for distances from s, extending routes along outgoing directed edges. The Bellman inequalities above instead concern distances to a sink r, prepending incoming directed edges to known routes. The All-to-one Bellman-Ford recurrence below preserves that convention. Reversing every directed edge, with its weight unchanged, converts one problem into the other.
Here is an original single-source example with source S, vertex set V={S,A,B,C,T}, and precisely these directed edges:
wSA​=4,wSB​=5,wAB​=−2,wBC​=3,wCT​=2,wAT​=8.
(5)
The negative edge A→B is harmless: this directed graph has no directed cycle. Its best route to T is S→A→B→C→T, of cost 4−2+3+2=7. The other routes to T cost 12 through S,A,T and 10 through S,B,C,T.
Initialize d(S)=0 and the other tentative distances to ∞. In each pass apply single-source edge relaxation, d(v)←min{d(v),d(u)+wuv​}, scanning in the order A→T, C→T, B→C, A→B, S→B, S→A. Skip a candidate with d(u)=∞. The figure records labels after each complete pass and uses current labels immediately: it is an in-place trace. In pass 2, B→C still uses d(B)=5, giving 8; only later does A→B lower B to 2. Pass 3 carries that improvement to C, and pass 4 carries it to T. The final labels in order (S,A,B,C,T) are (0,4,2,5,7); the final shortest-path predecessors are S,A,B,C for A,B,C,T respectively.
The scan order explains the delay. Scanning instead as S→A, S→B, A→B, B→C, C→T, A→T gives those same final labels in just one in-place pass. The Synchronous Bellman-Ford recurrence has a precise bound on the number of edges used by a recorded route; an in-place pass can propagate along several edges and need not have that interpretation. Both implementations have the ∣V∣−1 pass guarantee under the stated no-reachable-negative-cycle hypothesis.
With a stored list of edges, complete-pass Bellman-Ford algorithm has time complexity O(∣V∣∣E∣+∣V∣) and uses O(∣V∣) extra space for labels and shortest-path predecessors, using Big O notation and constant-cost arithmetic. The extra ∣V∣ accounts for initialization even when E is empty. A pass with no strict decrease permits early termination. A queue variant instead revisits outgoing edges of vertices whose labels improved; the authored implementation provides this alternative and has O(∣V∣∣E∣) worst-case running time on its usual nontrivial instances.[ref] For nonnegative weights, the Dijkstra algorithm and its existing distance-frontier figure explain how permanent labels can avoid these repeated passes; the existing edge relaxation figure illustrates one update at a time.
