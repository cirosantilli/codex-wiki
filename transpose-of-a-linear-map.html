Transpose of a linear map (T∗:W∗→V∗,T∗(φ)=φ∘T)

 Home Mathematics Area of mathematics Algebra Linear algebra Dual space
OurBigBook.com Words: 327 Articles: 4
For a linear map T:V→W, the dual map T∗:W∗→V∗ sends a linear functional φ on the output space to the input measurement T∗(φ)=φ∘T. It reverses direction because a measurement of the output can be evaluated on an input by first applying T:
(T∗φ)(v)=φ(Tv).
(115)
For T(x,y)=(x+y,2y) and φ(u,v)=2u−v, the input measurement is T∗φ(x,y)=2(x+y)−2y=2x. The output measurement ignores the part of this transformation contributed by y.
If T has matrix A in specified bases, a row representing φ changes to ℓA. Storing the coefficients of a linear functional as a column in the corresponding dual basis gives ATℓT, explaining why the transpose of a linear map is represented by the matrix transpose. This algebraic operation uses no inner product; it agrees with a matrix transpose even over the complex numbers, rather than automatically introducing complex conjugation. The adjoint operator is defined using an inner product and is a different construction. [ref].
In finite dimension, the kernel and image of the dual map are described by annihilators of vector subspaces:
kerT∗=(imT)∘,imT∗=(kerT)∘.
(116)
