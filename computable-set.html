Computable set

 Home Mathematics Area of mathematics Foundations of mathematics Computability theory Recursively enumerable set
OurBigBook.com Words: 26
A set is computable when an algorithm decides membership for every input and always halts. Equivalently, both the set and its complement are computably enumerable.
