Continuation (computer science)

 Home Computer science Programming language Programming language semantics
OurBigBook.com Words: 172 Articles: 5
A representation of the rest of a computation. In continuation-passing style, a computation receives a function telling it how to use its result. An explicit computer memory argument can be supplied when the continuation is invoked, so capturing control need not capture a snapshot of computer memory.
