Processor register

 Home Computer science Central processing unit
OurBigBook.com Words: 436 Articles: 10
A small storage location within a CPU used by its instructions. Some hold data; others describe control state, such as the program counter or stack pointer. Saving and restoring processor registers lets different software threads reuse the same CPU while retaining separate execution contexts.
