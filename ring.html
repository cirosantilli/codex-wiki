Ring (R)

 Home Mathematics Area of mathematics Algebra Commutative algebra
OurBigBook.com Words: 9k Articles: 187
A ring is a set R with two binary operations, addition and multiplication, satisfying three requirements. Under addition, R is an abelian group: there is a zero, every element has an inverse element, and grouping or exchanging summands does not change the result. Multiplication is associative and has an identity element 1, so (ab)c=a(bc) and 1a=a1=a. Finally, both versions of the distributive property hold:
a(b+c)=ab+ac,(a+b)c=ac+bc.
(19)
Here every ring is unital, but the zero ring, with 0=1, is allowed. Commutativity of multiplication is an additional condition defining a commutative ring. These conventions agree with [ref].
The integers form a ring with their usual operations. The polynomial ring Z[X] is another: addition combines coefficients, while multiplication uses the distributive property. For example,
(1+2X)(3−X)=3+5X−2X2.
(20)
The same rules justify symbolic calculations in both rings; this is why one definition can organize apparently different kinds of arithmetic. In every ring, a0=0a=0, and a(−b)=−(ab). The first identity follows by distributing a(0+0) and subtracting a0; the second follows by distributing a(b+(−b)). Thus familiar sign rules are consequences of the structure.
Order still matters in some rings. In the matrix ring M2​(R), take
A=(10​00​),B=(01​10​).
(21)
Then matrix multiplication gives
AB=(00​10​),BA=(01​00​).
(22)
Nevertheless, matrix multiplication is associative, distributes over addition, and has the identity matrix as its identity element. This is a valid ring. On a column vector, AB applies B first and A second: swapping coordinates before discarding the second coordinate differs from doing those actions in reverse. The failure of commutativity records a meaningful difference in function composition.
