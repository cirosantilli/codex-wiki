For nonconserved order-parameter dynamics, microscopic reversibility with equilibrium weight proportional to e−F/(kB​T) requires
σ2=2ΓkB​T.
(14)
Indeed the Onsager--Machlup path probability gives log(PF​/PB​)=−2Γ∫p˙​δF/δpdt/σ2=−2Γ(F2​−F1​)/σ2. Equating this to the detailed balance value proves the relation. The functional chain rule is understood with the same midpoint convention as the path action.
