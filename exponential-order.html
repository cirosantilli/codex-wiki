Exponential order (∣f(t)∣≤Meat(t≥T))

 Home Mathematics Area of mathematics Analysis Integral transform Laplace transform
OurBigBook.com Words: 48
A function has exponential order a∈R if some M>0 and T≥0 give the displayed bound. Bounded functions, including sine, have exponential order zero; e−2t has exponential order −2. The bound need not use the smallest possible a. Together with piecewise continuity, it guarantees a Laplace transform for Res>a.
