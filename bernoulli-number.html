Bernoulli number (Bn​)

 Home Mathematics Area of mathematics Number theory
OurBigBook.com Words: 156 Articles: 3
The Bernoulli numbers in the convention B1​=−1/2 are defined by t/(et−1)=∑n≥0​Bn​tn/n!. The first values are 1,−1/2,1/6,0,−1/30. The function t/(et−1)+t/2 is even, so all odd-index values beyond B1​ vanish.
