Software object

 Home Computer science Programming language Object-oriented programming
OurBigBook.com Words: 162 Articles: 3
An object combines an identity, state and operations exposed through an object interface. Distinct software objects can hold equal data while remaining different by object identity. Reference aliasing occurs when multiple references designate the same object, so a state update through one reference can affect observations through another.
