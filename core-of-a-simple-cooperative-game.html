Core of a simple cooperative game (Core(v)={x≥0:∑i​xi​=1, xi​=0 for non-veto players})

OurBigBook.com Words: 94
For a monotone simple cooperative game with empty value 0 and grand-coalition value 1, the core of a cooperative game consists exactly of the nonnegative unit-total payoff vectors supported on veto players.
For the proof, singleton core conditions give xi​≥0. Every winning coalition must receive at least 1, the full available total, so all players outside it receive zero. A positively paid player therefore belongs to every winning coalition and is a veto player. Conversely, a unit-total nonnegative allocation supported on veto players gives every winning coalition exactly 1 and every losing coalition at least 0. These are precisely the core inequalities. The core is thus nonempty if and only if a veto player exists.
