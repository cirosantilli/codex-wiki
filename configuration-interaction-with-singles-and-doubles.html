Configuration interaction with singles and doubles

 Home Chemistry Quantum chemistry Configuration interaction
OurBigBook.com Words: 37
configuration interaction retaining a reference determinant and its single and double excitations. Conventional matrix-vector iterations have leading O(o2v4) work for occupied and virtual dimensions o,v, hence O(N6) when both grow with system size. Truncated CI is not generally size extensive.
