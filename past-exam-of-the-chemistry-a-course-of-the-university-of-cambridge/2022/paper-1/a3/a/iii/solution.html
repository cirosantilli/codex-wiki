Use rovibrational spectroscopy combination differences so that the band origin cancels. With the assignments above, R(2) and P(4) end at the same upper level J′=3, giving
ν[R(2)]−ν[P(4)]=B′′{4⋅5−2⋅3}=14B′′.
(31)
Likewise R(3) and P(3) start at the same lower level J=3, so
ν[R(3)]−ν[P(3)]=B′{4⋅5−2⋅3}=14B′.
(32)
Only the printed wavenumbers are needed:
B′′=14720.91−700.22​=1.47786 cm−1,​
(33)
B′=14723.90−703.15​=1.48214 cm−1.​
(34)
Thus B′−B′′≃0.00429 cm−1. The rotational constants differ only slightly, so the average moment of inertia changes little on vibrational excitation. The upper value is slightly larger, corresponding to a slightly smaller effective moment of inertia. This sign is possible for a bending excitation; the intuition that excitation must always lengthen a diatomic bond is not a general rule for a polyatomic bend.
The rounded printed values are internally consistent: fitting all six positions to the same elementary model gives approximately ν∗​=711.9945 cm−1, B′′=1.47797 cm−1 and B′=1.48203 cm−1, with residuals below 0.002 cm−1. The displayed combination-difference values have more digits than their physical accuracy; the meaningful scale is about 1.48 cm−1.
