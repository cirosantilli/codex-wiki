Finite-time spectral boundary transform (Gj​(k,t)=∫0t​eω(k)sgj​(s)ds)

 ... Area of mathematics Analysis Differential equation Ordinary differential equation Boundary value problem Global relation for a linear boundary value problem
OurBigBook.com Words: 124 Articles: 1
A boundary trace transformed over a finite time interval using the dispersion relation of a linear partial differential equation. For integrable trace data and a polynomial dispersion function, it is an entire function of the complex spectral parameter. Its growth depends on Reω(k); multiplying by e−ω(k)t changes the integrand to the causal factor e−ω(k)(t−s).
