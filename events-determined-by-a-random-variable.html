Events determined by a random variable ({X∈D}=X−1(D))

Define the head-count random variable X:Ω→{0,1,2} by
X(TT)=0,X(HT)=X(TH)=1,X(HH)=2.
(4)
The four elementary outcomes are inputs to this function; its three numerical values are outputs. Each fiber of a function collects all outcomes giving one value. Under the fair independent model, adding the masses in each fiber gives the probability mass function
P(X=0)=41​,P(X=1)=41​+41​=21​,P(X=2)=41​.
(5)
Consequently the output values are not equally likely, although the inputs are. Using the reduced sample space {0,1,2} with these masses gives the same head-count probability distribution; assigning 1/3 to each value would describe a different model.
A question about a random variable's value becomes an event on the original sample space by taking an inverse image:
{X∈D}=X−1(D)={ω∈Ω:X(ω)∈D}.
(6)
For a real-valued random variable, this is an event whenever D is a Borel set, by measurability. In this finite example every subset of {0,1,2} is allowed. In particular,
{X≥1}=X−1({1,2})={HH,HT,TH},P(X≥1)=21​+41​=43​.
(7)
This is the same “at least one head” event counted above, expressed through an observable.[ref]
Every event determined by X is a union of complete fibers. There are 23=8 such events, whereas the full power set of Ω has 24=16. In particular, the first-head event A={HH,HT} is not determined by X: it contains HT but excludes TH, although both give X=1. Choosing an observable makes calculations simpler precisely by forgetting distinctions; the useful choice is one that retains the distinctions the question needs.
