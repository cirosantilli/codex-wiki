networkx.org/documentation/stable/reference/algorithms/generated/networkx.algorithms.matching.max_weight_matching.html
The max_weight_matching documentation specifies unrestricted-weight optimization by default, distinguishes the optional maximum-cardinality constraint, and gives cubic running time in the number of vertices. Its notes distinguish exact integer arithmetic from possible precision effects for floating-point weights. These details specify the maximum-weight matching subroutine needed for minimum-weight edge cover by matching savings.
