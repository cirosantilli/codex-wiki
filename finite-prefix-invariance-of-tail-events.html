Finite-prefix invariance of tail events

 ... Mathematics Area of mathematics Probability and statistics Probability theory Independent sigma-algebras Tail sigma-algebra
OurBigBook.com Words: 153
On the full Cartesian product Ω=RN with its product sigma-algebra, take the coordinate random variables Xj​(x)=xj​. A product-measurable set A is a tail event if and only if membership is unchanged whenever two sequences differ in finitely many coordinates. The measurability condition is essential: invariance alone is not a license to assign a probability to an arbitrary subset.
For the forward implication, fix m. An event in σ(Xm+1​,Xm+2​,…) cannot distinguish points with the same remaining coordinates. Since a tail event belongs to this sigma-algebra for every m, every finite change preserves membership.
For the converse, freeze the first m coordinates to zero. The insertion map
im​(ym+1​,ym+2​,…)=(m entries0,…,0​​,ym+1​,ym+2​,…)
(28)
is a measurable function for the product sigma-algebras. Thus Bm​=im−1​(A) is a measurable set. Invariance gives A=πm−1​(Bm​), where the coordinate projection πm​ discards the first m entries. Hence A∈σ(Xm+1​,Xm+2​,…) for every m. The same argument works on {0,1}N. On a general probability space, coordinates need not admit arbitrary replacements, so the defining intersection of sigma-algebras remains the reliable formulation.
