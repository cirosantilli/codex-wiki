Equality-only grouping lower bound ((2n​))

 Home Computer science Algorithm Equality test
OurBigBook.com Words: 74
In the comparison model exposing only an equality test between otherwise opaque values, partitioning n values into equivalence classes takes Ω(n2) tests in the worst case. Run the algorithm on pairwise distinct values. If any pair remains untested, changing just those two values to equal is consistent with every answer observed so far but changes the required output partition. Every pair must therefore be tested. With a compatible total order, comparison sort can instead group equal values in O(nlogn) time.
