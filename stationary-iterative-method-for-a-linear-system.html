Stationary iterative method for a linear system

 Home Mathematics Area of mathematics Analysis Numerical analysis Numerical linear algebra
OurBigBook.com Words: 3k Articles: 30
A stationary iteration has the form
x(k+1)=Hx(k)+v,
(94)
with a fixed iteration matrix H. It converges for every initial vector exactly when the spectral radius satisfies ρ(H)<1.
This is an iterative method whose update matrix remains fixed.
