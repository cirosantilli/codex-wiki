Difference-set overlap bound on an interval

 ... Area of mathematics Analysis Fourier analysis Convolution Convolution of L infinity and L1 functions Steinhaus theorem
OurBigBook.com Words: 42
If a measurable set E⊆[0,L] has measure m(E)=L/2+α, then for ∣t∣<2α the sets E and E+t lie in an interval of length L+∣t∣, so
m(E∩(E+t))≥2m(E)−(L+∣t∣)>0.
(222)
Thus (−2α,2α)⊆E−E. This quantitative overlap argument is a bounded form of the Steinhaus theorem.
