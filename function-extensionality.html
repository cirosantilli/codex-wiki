Function extensionality (f=g⟺∀x∈A, f(x)=g(x))

 Home Mathematics Area of mathematics Foundations of mathematics Set theory Function
OurBigBook.com Words: 53
For two mathematical functions f,g:A→B with the same domain and codomain, equality is equivalent to equality of their values at every argument. In the set-theoretic representation, their graphs of functions then contain exactly the same ordered pairs. This permits a function identity to be proved by fixing an arbitrary argument and proving the resulting value equality.
