Choice diagonalization of an undetermined game

 ... Area of mathematics Foundations of mathematics Set theory Descriptive set theory Infinite game of perfect information Determined infinite game
OurBigBook.com Words: 85
With the axiom of choice, enumerate both players' binary-move strategies in an infinite game in length c. Each strategy admits c compatible plays. At stage α, reserve a fresh play following I's strategy as a loss for I, and a fresh play following II's strategy as a win for I. Avoid all previously reserved plays, which number less than c. The collection of the second reservations is a payoff set against which neither player has a winning strategy in an infinite game. This uses no regularity assumption on c.
