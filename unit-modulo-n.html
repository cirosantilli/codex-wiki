Unit modulo n

 Home Mathematics Area of mathematics Number theory Modular arithmetic Modular congruence
OurBigBook.com Words: 271
For a positive integer modulus n, a residue class [a]n​ is a unit when it has a modular multiplicative inverse: some integer u satisfies au≡1(modn). Modulo twelve, the units are exactly
[1]12​,[5]12​,[7]12​,[11]12​.
(139)
In particular, five is its own modular inverse, since 5⋅5=25≡1(mod12). Multiplying all twelve residue classes by five gives a permutation; multiplying the outputs by five recovers the inputs. By contrast, multiplying by six gives only zero and six, with six inputs for each output. It cannot be reversed.
In general, the exact criterion is
[a]n​ is a unit⟺gcd(a,n)=1.
(140)
For the forward direction, au−kn=1 implies every common divisor of a,n divides one. Conversely, if their greatest common divisor is one, Bézout's identity supplies ua+vn=1, so u is a modular inverse. The extended Euclidean algorithm computes these coefficients. The units form the unit group (Z/nZ)× under multiplication. [ref]
Multiplicative cancellation while keeping the same integer modulus is valid for a unit modulo n: from ca≡cb(modn), multiply by a modular inverse of c to get a≡b(modn). A nonunit cannot be cancelled as a general rule. For example, 6⋅0≡6⋅2(mod12), yet 0≡2(mod12). Thus division by six cannot undo this multiplication; solving a linear congruence instead keeps track of all possible classes.
This distinction marks the boundary between commutative rings and fields. Modulo a prime number p>1, every nonzero residue class is a unit, so Z/pZ is a finite field. Modulo twelve it is a commutative ring with zero divisors, and is not a field. For n=1, the sole class satisfies [0]1​=[1]1​ and is a unit; this one-element zero ring is not a field. [ref]
