Information projection (q∗=argminq∈C​D(q∥p))

 ... Mathematics Area of mathematics Probability and statistics Information theory Type (information theory) Method of types
OurBigBook.com Words: 997 Articles: 7
An information projection chooses the probability distribution that satisfies a constraint while departing least from a reference law in relative entropy. The constraint might specify an expected value, several marginal probability distributions, or another convex set of permissible laws. The reference is held fixed: the variable is the first argument of D(q∥p). Reversing the arguments gives a different minimization problem.
For a finite alphabet A, take a positive reference probability mass function p(a)>0 and a nonempty closed convex set C in the probability simplex. Then
q∗=argq∈Cmin​D(q∥p),D(q∥p)=a:q(a)>0∑​q(a)lnp(a)q(a)​.​
(86)
The minimum exists and its minimizing probability distribution is unique. In this article, natural logarithms give nats. Using base-two logarithms rescales the objective without changing the minimizer.[ref]
If p already meets the constraint, its information projection is p itself by relative entropy nonnegativity. If not, a constraint can change the relative weights of outcomes without specifying every weight individually. Relative entropy minimization under a mean constraint gives an especially useful example: it tilts the reference law rather than choosing an arbitrary distribution with the right average.
