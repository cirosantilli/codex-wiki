DMA buffer synchronization

 Home Computer science Computer bus Direct memory access
OurBigBook.com Words: 75
Coordinating CPU and device access to a DMA buffer, including any required memory cache maintenance and ordering. A completed device write must be made visible before the CPU consumes it. The Linux kernel distinguishes coherent mappings from streaming mappings needing synchronization at ownership changes; even coherent mappings can require ordering of writes. [ref][ref]
