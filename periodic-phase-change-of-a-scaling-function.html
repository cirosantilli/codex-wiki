Periodic phase change of a scaling function

 ... Area of mathematics Analysis Fourier analysis Wavelet Multiresolution analysis Scaling function
OurBigBook.com Words: 199 Articles: 1
If a periodic unimodular function a and its inverse have absolutely summable Fourier coefficients, replacing φ​0​ by φ​=aφ​0​ preserves the orthonormal integer-translate span and integrability of an integrable scaling function. In physical space this is an absolutely summable combination of integer function translations. The new MRA low-pass filter is m(t)=a(2t)m0​(t)/a(t). A rough phase can therefore preserve the multiresolution analysis while changing MRA low-pass filter regularity.
