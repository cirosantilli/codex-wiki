Multiplicative order (ordn​(a))

 Home Mathematics Area of mathematics Number theory
OurBigBook.com Words: 852 Articles: 5
For coprime integers a,n with n>1, the multiplicative order is the least positive integer d such that
d=ordn​(a),ad≡1(modn).
(261)
It counts the distinct powers in the cyclic subgroup generated by the congruence class of a. Thus it is an order of a group element in the unit group (Z/nZ)×.[ref]
For example, the modular exponentiation 2kmod7, starting at k=0, produces 1,2,4,1,2,4,…. The first return to one takes three steps, so ord7​(2)=3. Starting at the congruence class three and repeatedly multiplying by two instead gives 3,6,5,3,…: these are the other three units modulo seven, outside the cyclic subgroup generated by two.
Euler's theorem guarantees a return to one at exponent φ(n), where φ is Euler's totient function. Thus the multiplicative order exists for every unit.[ref] In fact,
ordn​(a)∣φ(n).
(262)
By Lagrange's theorem, the size of the cyclic subgroup divides the size of the unit group, which is Euler's totient function. For two modulo seven, this is 3∣6; the multiplicative order need not equal Euler's totient function. If a≡1(modn), its multiplicative order is one.
The coprime integers hypothesis is necessary: if ad=1+kn, any common divisor of a and n divides one. For instance, powers of two modulo eight give 1,2,4,0,0,…, with no positive-exponent return to one. This sequence eventually settles, but two has no multiplicative order modulo eight.
