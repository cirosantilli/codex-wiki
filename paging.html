Paging

 Home Computer science Operating system Virtual memory
OurBigBook.com Words: 5k Articles: 29
Paging divides an address space into fixed-size memory pages and main computer memory into equally sized page frames. Here assume byte addressing, one memory page size P=2b bytes, and an unsigned virtual address v. Its virtual page number q and offset d are
q=⌊Pv​⌋,d=vmodP,0≤d<P.
(8)
The brackets denote the floor function, and mod gives the remainder in Euclidean division. If the page table maps q to physical frame number f and permits the access, the physical address is
a=fP+d.
(9)
The low b bits are unchanged; the other bits select the memory page or page frame. A bit shift and bit mask can extract these fields. [ref]
For a 16-bit virtual address and P=256=28 bytes, take v=0x1234=4660 in hexadecimal. Then q=18=0x12 and d=52=0x34. A mapping to f=7=0x07 gives
a=7⋅256+52=1844=0x0734.
(10)
Thus the eight high bits choose a mapping; the eight low bits choose the same position in the resulting page frame. The 256-byte size is for illustration, not a claim about an actual architecture's supported memory page sizes.
The useful freedom is that adjacent memory pages can occupy unrelated page frames. In the diagram, virtual pages 0x12 and 0x13 occupy page frames 0x07 and 0x02; virtual addresses 0x12ff and 0x1300 are consecutive, but translate to physical addresses 0x07ff and 0x0200. Uniform units simplify placement and page replacement, at the cost of page table storage and unused bytes within partly filled memory pages. For example, placing 300 bytes in exclusive 256-byte page frames requires two page frames, leaving 512−300=212 bytes unused.
