Asymptotic rate-distance function (αq​(δ))

 ... Mathematics Area of mathematics Algebra Coding theory Linear code Code rate
OurBigBook.com Words: 36
The asymptotic rate-distance function is αq​(δ)=limsupn→∞​n−1logq​Aq​(n,max{1,⌈δn⌉}). It is the best asymptotic code rate available at the specified relative minimum distance. A limsup is used because the definition does not assume an ordinary limit exists.
