Moment-map equivariance obstruction (κ(X,Y)={μX​,μY​}−μ[X,Y]​)

 ... Area of mathematics Geometry and topology Differential geometry Symplectic geometry Hamiltonian group action Moment map
OurBigBook.com Words: 207 Articles: 2
For a weakly Hamiltonian left Lie group action on a connected symplectic manifold, choose ιXf​​ω=df. Fundamental vector fields and Hamiltonian vector fields are both antihomomorphisms, so the displayed difference is constant. The Jacobi identity for the Poisson bracket makes it a two-cocycle. Changing μX​ by b(X) changes the difference by −b([X,Y]). Thus its class in Lie algebra cohomology obstructs choosing an equivariant moment map. For a connected group, vanishing of this class gives infinitesimal and group equivariance.
