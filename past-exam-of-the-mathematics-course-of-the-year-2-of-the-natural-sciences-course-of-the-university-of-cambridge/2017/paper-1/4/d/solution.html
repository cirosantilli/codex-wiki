For an integrable applied voltage, the convolution theorem gives
I(ω)=[(γ1​+iω)2+p12​a1​p1​​+(γ2​+iω)2+p22​a2​p2​​]V(ω).
(26)
The integrated electric current is the zero-frequency transform, Q=I(0). Since V(0) can be arbitrary, zero total electric charge for every such input is equivalent to
γ12​+p12​a1​p1​​+γ22​+p22​a2​p2​​=0.​
(27)
For nonzero p1​,p2​, this can be written
a2​a1​​=−p1​(γ22​+p22​)p2​(γ12​+p12​)​.​
(28)
Because both amplitudes are positive, nonzero p1​,p2​ must have opposite signs. If exactly one pi​ is zero there is no cancellation with positive amplitudes; if both vanish the kernel is identically zero and any amplitudes work. In particular, if both frequency parameters were additionally required to be positive, no such nontrivial system would exist. The PDF requires positivity of ai​,γi​, but allows real fixed pi​.
This is zero-frequency cancellation of a causal response kernel. The phrase arbitrary voltage is understood within a class for which the net-charge integrals exist; a permanent DC input need not have finite total charge.
