Shapley value of an airport game (ϕj​=λ∑i=1j​Ni​si​−si−1​​)

 ... Mathematical optimization Game theory Cooperative game theory Transferable utility game Cooperative cost game Airport problem
OurBigBook.com Words: 154
Suppose the distinct required runway lengths are 0=s0​<s1​<⋯<sk​, with ni​>0 users of type i, constant cost λ≥0 per unit length, and suffix counts Ni​=∑ℓ=ik​nℓ​. Then every type-j user has the displayed Shapley value. For layer i, exactly Ni​ users require it. The first of them in a uniformly random permutation contributes its entire cost λ(si​−si−1​). Each requiring user has probability 1/Ni​ of being first. Linearity of the Shapley value sums these expected marginal contributions across the layers that user needs.
The allocation lies in the cost core. Its payments sum to the full runway cost. For any coalition S, its total payment toward layer i is λ(si​−si−1​)∣S∩Ri​∣/Ni​, where Ri​ is the set of users requiring that layer. This is zero if S needs no such layer, and at most the full layer cost otherwise. Summing gives ∑j∈S​ϕj​≤c(S). Suffix counts followed by prefix sums compute all distinct type payments in O(k) arithmetic operations.
