Supremum of an open disc under product and lexicographic orders

 ... Set theory Set Partially ordered set Upper and lower bounds Upper bound in a partially ordered set Least upper bound in a partially ordered set
OurBigBook.com Words: 72
For D={(x,y):x2+y2<1}, the product order gives least upper bound (1,1), because each coordinate has supremum one. The lexicographic order instead has no least upper bound. Every point (1,v) is an upper bound, but (1,v−1) is a strictly smaller upper bound; a point with first coordinate below one cannot bound the disc. The same geometric set therefore has different order-completeness behavior under the two partial orders. Neither conclusion is determined by the usual drawing alone.
