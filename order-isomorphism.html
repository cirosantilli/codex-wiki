Order isomorphism (x<y⟺f(x)<f(y))

 ... Mathematics Area of mathematics Foundations of mathematics Set theory Set Total order
OurBigBook.com Words: 19
An order isomorphism is a bijection preserving and reflecting the order relation. It transfers well-foundedness and order type between a coded order and its ordinal interpretation.
