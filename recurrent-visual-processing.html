Recurrent visual processing

 Home Biology Neuroscience Sensory system Vision Ventral visual stream
OurBigBook.com Words: 58
Visual computation in which activity feeds back within or between processing stages, allowing later representations to depend on earlier internal states. Time-resolved object-recognition measurements constrain this contribution more strongly than a static accuracy score, although a delay alone does not identify one circuit.[ref]
