Time dilation (Δt=γΔτ)

 Home Physics Branches of physics Special relativity Lorentz factor
OurBigBook.com Words: 3k Articles: 16
If one clock measures a proper time interval Δτ while moving at constant speed v in an inertial frame, that frame measures Δt=γΔτ, where γ is the Lorentz factor. The two spacetime events must lie on that clock's world line.
Suppose a clock moving at 0.6c advances by 4μs between two ticks. Set t=x=t′=x′=0 at the first tick. The laboratory's synchronized clocks assign Δt=1.25×4=5μs. During that interval the clock travels Δx=0.6c×5μs=3cμs, approximately 899.38m. The Minkowski interval checks the result:
s2=−c2(5μs)2+(3cμs)2=−c2(4μs)2.
(5)
Both frames therefore recover the same 4μs of proper time. This calculation is useful whenever a process is timed on a moving apparatus but described using laboratory clocks.
A light clock makes the mechanism visible. Two mirrors separated by h perpendicular to the motion exchange a pulse; define one tick as its complete return to the lower mirror. In the clock's rest frame the tick takes Δτ=2h/c. In the laboratory each half-tick lasts T and the light traverses a diagonal, so the Pythagorean theorem gives
(cT)2=h2+(vT)2,T=γh/c,Δt=2T=γΔτ.
(6)
For h=1m and v=0.6c, each leg covers 1.25m while the mirrors move 0.75m. The return tick lasts 2.5m/c instead of 2m/c: the light has the same speed of light in both accounts. [ref].
Reciprocal time dilation is consistent: each inertial frame times the other frame's single moving clock using its own synchronized clock network. These comparisons use different simultaneous spacetime events. Comparing reunited clocks instead requires their complete world lines, as in the twin paradox.
