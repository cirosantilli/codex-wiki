Let K(f) be the complete current-to-voltage frequency response from detector input to readout, in V/A. For a real stable linear time-invariant system, the shot contribution to the output voltage variance is
σv,shot2​=∫0∞​2qI∣K(f)∣2df=∫−∞∞​qI∣K(f)∣2df.
(48)
If K(f)=RF​GH(f) with feedback electrical resistance RF​, a reference voltage gain G, and dimensionless normalized frequency response H, then
Bn​=∫0∞​∣H(f)∣2df,σv,shot2​=2qIRF2​G2Bn​.
(49)
This is the effective noise bandwidth for unit reference magnitude. The transimpedance amplifier factor RF​ converts electric current to voltage; G multiplies voltage. Neither is an additional noise source merely because it amplifies an existing fluctuation. In contrast, a real amplifier adds input voltage noise and input current noise, and its feedback resistor contributes thermal electrical noise. Those terms need their own transfers to the output. In particular, input voltage noise generally has a different transfer from an injected detector electric current. Simply multiplying every input specification by RF​G is incorrect.
For a unit-gain exponential low-pass filter, with time constant τ>0,
h(t)=τ1​e−t/τ(t≥0),H(f)=1+2πifτ1​,Bn​=4τ1​=2π​fc​,fc​=2πτ1​.
(50)
The cutoff frequency fc​ is not Bn​. An independent time-domain derivation sums independent event contributions to give
Var(ifiltered​)=λq2∫0∞​h(t)2dt=2τqI​.
(51)
The same reasoning for a rectangular averaging gate has h=1/T on [0,T] and zero elsewhere, hence effective noise bandwidth 1/(2T) and variance qI/T, agreeing with the shot noise counting model. Equal numerical durations T=τ do not make these two different linear filters equivalent.
