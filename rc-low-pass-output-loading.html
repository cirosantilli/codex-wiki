RC low-pass output loading (HL​(ω)=KL​/(1+iωτL​))

 Home Electrical engineering Signal processing Linear filter Low-pass filter RC low-pass filter
OurBigBook.com Words: 219
A real electrical load can draw electric current from the output. For a load resistor RL​>0 across the capacitor, Kirchhoff's current law instead gives
Rvin​−vout​​=Cdtdvout​​+RL​vout​​.
(80)
Therefore the loaded continuous-time frequency response is
HL​(ω)=1+iωτL​KL​​,KL​=R+RL​RL​​,τL​=R+RL​RRL​​C.
(81)
Loading reduces the eventual gain and shortens the time constant. With the constructed values and RL​=10kΩ, KL​≈0.81967, τL​≈84.754μs, and the corner relative to the loaded low-frequency gain moves to 1.8778kHz. A 3V step now approaches 2.4590V. A quicker rise alone would conceal the error in the final voltage.
With the ideal input voltage source set to zero, the output impedance seen by the electrical load is
Zout​(ω)=1+iωRCR​.
(82)
This follows from Thévenin's theorem: the resistor and capacitor are then in parallel. A sufficient small-loading condition is ∣ZL​(ω)∣≫∣Zout​(ω)∣ over the frequencies of interest. An oscilloscope is itself an electrical load: its input electrical resistance and cable or probe capacitance can both change the response. Pure extra parallel capacitance increases C and lowers the corner, whereas a finite parallel electrical resistance gives the different gain-and-corner changes above.
The definition of input also matters. If voltage is prescribed inside a source with series electrical resistance Rs​, the unloaded response to that internal source uses R+Rs​. If the actual voltage at the filter input terminal is measured, the ratio of output to that measured input still uses R. Measuring both terminals avoids mistaking a source setting for the voltage delivered to the filter.
