Winding number of a continuous closed path

 Home Mathematics Area of mathematics Analysis Complex analysis Winding number
OurBigBook.com Words: 109 Articles: 1
If γ:[0,1]→C∖{0} is continuous and closed, choose a continuous lift θ such that
∣γ(t)∣γ(t)​=e2πiθ(t).
(83)
Then wind(γ,0)=θ(1)−θ(0)∈Z. This agrees with the contour-integral definition when the path is piecewise smooth.
