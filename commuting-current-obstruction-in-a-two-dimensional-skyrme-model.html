Commuting-current obstruction in a two-dimensional Skyrme model ([R1​,R2​]=0,∂i​Ri​=0 ⟹ Ri​=0)

 ... Physics Branches of physics Quantum field theory Classical field-theory soliton Skyrme model Derrick dimension test for the Skyrme model
OurBigBook.com Words: 79
For a smooth finite-energy static planar Skyrme model field, Derrick scaling gives zero quartic energy, hence [R1​,R2​]=0 pointwise. The quartic first variation then vanishes, leaving the sigma-model equation ∂i​Ri​=0. The right-current Maurer-Cartan equation gives ∂1​R2​−∂2​R1​=[R1​,R2​]=0. Each current component is therefore harmonic on the plane and square-integrable. The mean-value estimate on expanding disks makes each component zero, so U is constant. This excludes smooth finite-energy planar static solutions of this potential-free SU(2) model, without misapplying the same conclusion to a pure curved-target sigma model.
