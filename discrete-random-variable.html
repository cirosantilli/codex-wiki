Discrete random variable

 Home Mathematics Area of mathematics Probability and statistics Probability theory Random variable
OurBigBook.com Words: 96
A random variable is discrete when some finite or countable set D⊆R has P(X∈D)=1. Its probability mass function is pX​(x)=P(X=x); these nonnegative masses sum to one. An event determined by the value has probability P(X∈A)=∑x∈A∩D​pX​(x). Values outside D may still occur on a zero-probability event without changing this definition.
Countable support need not consist of integers: a random variable constantly equal to 3/2 is discrete. Integer-indexed tail-sum formulas therefore require a separate integer-valued hypothesis. For the dice sum in random variable, the expected value is ∑s=212​spS​(s)=7 and the variance is ∑s=212​(s−7)2pS​(s)=35/6; the same answer follows by adding the variances of its independent summands.
