Neumann boundary-value problem

Words: 127 Articles: 1
Boundary value problem OurBigBook.com
A boundary value problem with prescribed outward normal derivative, or the associated weighted flux, on the boundary. Its boundary data are Neumann boundary data. For an elliptic divergence-form operator without a zeroth-order term, integration over the domain imposes a compatibility condition between total source and boundary flux. A connected domain generally leaves a constant undetermined, fixed by a mean or reference value.

Uniqueness of the Neumann problem

Words: 71
Neumann boundary-value problem OurBigBook.com
On a connected bounded domain, two harmonic potentials with the same normal derivative differ by a constant. Their difference u has ∇2u=0 and ∂n​u=0. Green's first identity gives ∫∣∇u∣2dV=∫∂Ω​u∂n​udA=0, so the gradient vanishes. In a multiply connected magnetic core, also fix the circulation around each independent hole: a curl-free magnetic field intensity with nonzero circulation need not be the gradient of a single-valued scalar potential. After those circulations have been matched, apply the scalar-potential uniqueness argument to the difference field.

Boundary trace of a function (γu=u∣∂Ω​)

Words: 72
Boundary value problem OurBigBook.com
For a sufficiently regular function on a domain Ω, its boundary trace is the restriction to ∂Ω, using the limit from within the domain when necessary. In a half-line evolution problem, the traces fj​(t)=∂xj​u(0,t) are boundary values of the spatial derivatives. An initial value does not generally determine every such trace without the partial differential equation and suitable boundary conditions. The Sobolev trace operator extends classical restriction continuously to appropriate Sobolev spaces, where pointwise values need not be defined.

Oblique derivative boundary condition (a∂n​q+b∂τ​q=g)

Words: 424 Articles: 5
Boundary value problem OurBigBook.com
An oblique derivative boundary condition prescribes a linear combination of the outward normal derivative and the tangential derivative on a boundary. Its strictly oblique case has a nonzero normal coefficient; a zero normal coefficient is a limiting tangential condition. Both trace directions must be tracked when constructing a global relation. On unbounded domains, regularity at corners and a growth condition at infinity are separate parts of an admissible boundary value problem.

Corner compatibility for collinear oblique derivative data (β1​+β2​=π/2 ⟹ h2​(0)=−h1​(0))

Words: 61
Oblique derivative boundary condition OurBigBook.com
For a solution with a continuous gradient at a quadrant corner, the prescribed derivative directions are (−sinβ1​,cosβ1​) and (cosβ2​,−sinβ2​). When β1​+β2​=π/2, these vectors are negatives of one another. Their corner data must therefore be opposite. Imposing h1​(0)=h2​(0) as well forces both to vanish. Smooth decay of separate boundary functions alone does not ensure this local compatibility condition for an overdetermined linear system.

Homogeneous corner ambiguity in a quadrant Laplace problem

Words: 89
Rational-angle oblique derivative problem on a quadrant OurBigBook.com
For tangential data with β1​=β2​=0, the harmonic function q=xy has zero prescribed data on both axes but a growing nonzero derivative. For normal data with β1​=β2​=π/2, q=log∣z∣ also has zero prescribed data, and qz​=1/(2z) decays at infinity but is singular at the corner. Riemann-Hilbert problem (F+​−F−​=J)

Words: 403 Articles: 5
Boundary value problem OurBigBook.com
Find functions analytic on the two sides of a contour whose boundary values obey a prescribed jump, with suitable normalization at infinity and other distinguished points. An additive jump J on a counterclockwise closed contour is solved by the Cauchy integral formula F(k)=(2πi)−1∫J(ζ)/(ζ−k)dζ, subject to the normalization and compatibility conditions. The Sokhotski–Plemelj theorem verifies the jump.
