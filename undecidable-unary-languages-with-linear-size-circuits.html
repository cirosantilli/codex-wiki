Undecidable unary languages with linear-size circuits (UA​={1n:n∈A})

 ... Computer science Theoretical computer science Computational complexity theory Circuit complexity Circuit family Polynomial-size circuit family
OurBigBook.com Words: 68
For any set of lengths A, choose at length n a constant-zero Boolean circuit when n∈/A, and an AND of all inputs when n∈A. This uses O(n+1) gates. If A is undecidable, so is UA​, yet it belongs to P/poly. Since all NP languages are decidable by certificate enumeration, this proves P/poly is not equal to NP; it does not resolve containment in the other direction.
