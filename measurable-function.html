Measurable function

 Home Mathematics Area of mathematics Analysis Real analysis Measure theory
OurBigBook.com Words: 824 Articles: 7
A function f:(X,A)→(Y,B) between measurable spaces is measurable when f−1(B)∈A for every B∈B.
