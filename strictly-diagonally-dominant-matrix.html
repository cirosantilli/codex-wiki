Strictly diagonally dominant matrix

 ... Algebra Linear algebra Vector space Linear map Matrix Diagonally dominant matrix
OurBigBook.com Words: 28
A matrix is strictly diagonally dominant when every diagonal-dominance inequality is strict. A real symmetric strictly diagonally dominant matrix with positive diagonal is positive definite by the Gershgorin circle theorem.
