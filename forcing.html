Forcing antichain

Words: 35
Forcing OurBigBook.com
A subset of a forcing order whose distinct members have no common stronger extension. A maximal forcing antichain has a compatible member for every condition. For forcing by nodes of a set-theoretic tree, ordered by extension, this coincides with a tree antichain.

Cardinal collapse (κ∈/CardM[G])

Words: 27
Forcing OurBigBook.com
A forcing collapses a ground-model cardinal κ if it forces a bijection from a smaller ordinal onto the ground ordinal κ. The ordinal itself is preserved; its being an initial ordinal is lost.

Cofinality-preserving forcing (cfM[G](α)=cfM(α))

Words: 23
Forcing OurBigBook.com
A forcing is cofinality-preserving over a transitive model M if every generic extension has the same cofinality for every ground ordinal. The values are compared as ordinals, which forcing preserves.

Martin's axiom (MAκ​)

Words: 42
Forcing OurBigBook.com
For a cardinal number κ, MAκ​ says that for every forcing with the countable chain condition for forcing and every family of at most κ dense subsets, some filter in an ordered set meets them all. Full Martin axiom asserts this for all κ<2ℵ0​. The strict upper bound is part of the definition.

Countable forcing

Words: 133 Articles: 3
Forcing OurBigBook.com
A forcing order that is countable inside the ground model. It has the countable chain condition and preserves ω1​. Internal countability is distinct from external countability of the entire model.

One-Cohen-real preservation of GCH (GCH preserved by one Cohen real)

Words: 54
Countable forcing OurBigBook.com
Over a Generalized continuum hypothesis ground model, adding one Cohen real preserves every infinite power 2λ=λ+. For the countable forcing, nice subset forcing names for λ number at most (2ℵ0​)λ=2λ in the ground model. Old subsets give the matching lower bound and the countable chain condition for forcing preserves cardinals. Starting from the constructible universe, the new real is nonconstructible while the constructible levels remain unchanged.

Countable forcing preserves Suslin trees

Words: 22
Countable forcing OurBigBook.com
A ground-model Suslin tree remains Suslin after countable forcing. A new uncountable chain or antichain would contain an uncountable ground-model subset by the ground-model uncountable subset lemma for countable forcing.

Ground-model uncountable subset lemma for countable forcing

Words: 26
Countable forcing OurBigBook.com
An uncountable set of ground-model elements in a generic extension by countable forcing contains an uncountable ground-model subset. Partition membership witnesses according to the countably many forcing conditions.

Separative forcing order (p≤q⟹∃r≤p (r⊥q))

Words: 46
Forcing OurBigBook.com
In standard notation for forcing, an order is separative if p≤q implies that some r≤p is incompatible with q. Separativity does not imply an atomless forcing order: the one-point order is separative and has a forcing atom. Its only generic filter is a ground-model set. Atomlessness is the hypothesis in generic filter for an atomless order is new.

Forcing atom

Words: 236 Articles: 3
Forcing OurBigBook.com
A condition is an atom if every two stronger conditions are compatible forcing conditions. This is a compatibility definition, not necessarily minimality in an arbitrary partial order. An atomless forcing order is one in which every condition has two incompatible strengthenings.

A forcing atom determines a ground-model generic filter (Gp​={q∈P:q is compatible with p})

Words: 93
Forcing atom OurBigBook.com
For a forcing atom p in a ground-model forcing order, Gp​ is a ground-model generic filter. It contains p and is upward closed. For q,r∈Gp​, choose q′≤p,q and r′≤p,r. The atom property gives s≤q′,r′, so s∈Gp​ is a common strengthening of q,r. Thus Gp​ is a filter in an ordered set. Every dense subset of a forcing order has some d≤p, and d∈Gp​. The defining compatibility predicate is bounded to the ground-model set of conditions, so axiom schema of separation forms Gp​ inside the ground model. For a nonminimal atom, this filter can strictly contain the principal filter above p.

Atomless forcing order

Words: 108 Articles: 1
Forcing atom OurBigBook.com
An order is atomless if it has no forcing atom, equivalently every condition has a pair of incompatible forcing conditions below it. For a fixed order belonging to a transitive model, this property is absolute because its quantifiers range over the unchanged set of conditions. Infinite-domain Fn forcing with at least two possible values is atomless: prescribe different values at one fresh coordinate.

Generic filter for an atomless order is new (G∈/M)

Words: 53
Atomless forcing order OurBigBook.com
If a generic filter G for an atomless forcing order belonged to its ground model, then the complement P∖G would be a dense ground-model set. A condition outside G is already there; a condition in G has two incompatible strengthenings, at least one outside its directed filter. Genericity would then require meeting the complement, a contradiction.

Product forcing (P×Q)

Words: 199 Articles: 2
Forcing OurBigBook.com
The conditions are pairs with coordinatewise extension: (p,q)≤(p′,q′) exactly when p≤p′ and q≤q′. The projection of a product-generic filter is a pair of factor filters whose Cartesian product is the original filter. Each is ground-model generic, and mutual genericity for product forcing makes the second generic over the extension by the first.

Mutual genericity for product forcing

Words: 91
Product forcing OurBigBook.com
If H=G0​×G1​ is generic for product forcing over M, then G1​ is generic over M[G0​]. For a name D˙ for a dense subset of the second factor, take p0​∈G0​ forcing density. Ground-model pairs with first coordinate incompatible with p0​, or with first coordinate below p0​ forcing the second into D˙, form a dense product set. The existential clause of syntactic forcing and the membership clause for a canonical forcing name give the density witnesses. The product filter meets this set, cannot use the incompatible case, and hence its second projection meets D˙G0​.

Projection of a product-generic filter (H=G0​×G1​)

Words: 65
Product forcing OurBigBook.com
For a generic filter H in product forcing, let G0​,G1​ be its coordinate projections. They are filters in an ordered set. Given p∈G0​ and q∈G1​, choose separate pairs witnessing their membership and then a common strengthening in H. Upward closure puts (p,q) in H, proving the displayed equality. Every ground-model dense factor set lifts to a dense product set, proving genericity of each projection over the ground model.

Infinite-reservoir stem forcing (P={(n,s,A):s∈ωn, A∈[ω]ω})

Words: 82
Forcing OurBigBook.com
A condition consists of a finite sequence and an infinite reservoir of allowed future values. A stronger condition extends the sequence, shrinks the reservoir, and takes all newly appended values from the old reservoir. Stem values may repeat. The union of the generic stems is an unbounded real over a model: for every ground-model function g and every threshold K, the conditions whose stem already has some k≥K with g(k)<s(k) form a dense subset of a forcing order. An infinite subset of ω always supplies a sufficiently large value.

Unbounded real over a model (f≤∗g(g∈M∩ωω))

Words: 37
Forcing OurBigBook.com
A function f∈ωω is unbounded over a model M if for every g∈M∩ωω, infinitely many k satisfy g(k)<f(k). Equivalently, no ground-model function eventually dominates it. This is weaker than being a dominating real over M.

Cardinal-preserving forcing

Words: 43
Forcing OurBigBook.com
A forcing order preserves cardinals over a ground model if every ground-model cardinal number remains a cardinal in every generic extension. This assertion and any sufficient chain condition for forcing are evaluated inside the ground model. External countability of a countable transitive model does not make all of its forcing orders internally ccc.

Forcing name (τ∈MP)

Words: 276 Articles: 7
Forcing OurBigBook.com
A forcing name is a recursively built set of pairs (σ,p), where σ is a lower-rank forcing name and p is a forcing condition. Ground-model names are interpreted using a generic filter to form the generic extension.

Forcing name rank (nrk(τ))

Words: 36
Forcing name OurBigBook.com
The ordinal assigned recursively by nrk(τ)=sup{nrk(σ)+1:(σ,p)∈τ}. It measures dependency on subnames and justifies generic evaluation by recursion. The ordinary rank of a set also accounts for the coding of the ordered pairs and the forcing conditions; it need not equal this dependency rank of a set.

Choice preservation by well-ordered names (M⊨AC⟹M[G]⊨AC)

Words: 49
Forcing name OurBigBook.com
If the ground model has axiom of choice, well-order the set of subnames appearing in a forcing name for an arbitrary extension set. Evaluate those activated by the generic filter. Each element of the extension set has a least preimage index; ordering by these indices well-orders the set. Only ground choice and the ZF part of the forcing theorem are needed.

Nice forcing name

Words: 30
Forcing name OurBigBook.com
A name for a subset of a ground-model set, given coordinatewise by antichains in a forcing order. For countable-chain-condition forcing, each coordinate uses a countable antichain, which bounds the number of names for reals.

Paired forcing name (ν(τ,τ′)G​={τG​,τG′​})

Words: 47
Forcing name OurBigBook.com
For the condition-first forcing name convention, pair every condition with each of two names τ,τ′. Under any nonempty generic filter, the evaluation of a forcing name is then {τG​,τG′​}, the unordered pair of the two values. Equal values give a singleton. With the name-first convention, reverse the two components of each syntactic pair.

Forcing name for the complement of a generic filter

Words: 40
Forcing name OurBigBook.com
The forcing name {(pˇ​,q):p,q∈P, q⊥p} evaluates to P∖G. If p∈/G, genericity applied to {q:q≤p or q⊥p} supplies an incompatible member of G. If p∈G, directedness prevents such a member.

Evaluation of a forcing name (val(τ,G))

Words: 18
Forcing name OurBigBook.com
Interpret a forcing name recursively by val(τ,G)={val(σ,G):∃p∈G ((σ,p)∈τ)}. The collection of interpreted ground-model names is the generic extension.

Canonical forcing name (xˇ)

Words: 21
Forcing name OurBigBook.com
The canonical forcing name for a ground-model set x is xˇ={(yˇ​,1):y∈x}. Its evaluation of a forcing name under every generic filter is x.

Finite-function collapse to countable size (Col(ω,κ))

Words: 101 Articles: 1
Forcing OurBigBook.com
For an infinite ground-model cardinal number κ, use finite partial functions from ω to κ, ordered by reverse inclusion. The union of a generic filter is a surjection ω→κ. The order has size κ, hence the κ+-chain condition, and preserves cardinals at least κ+.

GCH preservation by a finite-function collapse

Words: 57
Finite-function collapse to countable size OurBigBook.com
If the ground model satisfies the Generalized continuum hypothesis, a finite-function collapse to countable size of κ preserves it. The old κ+ becomes the new ℵ1​, and there are at most 2κ=κ+ names for subsets of ω. For every old cardinal λ≥κ+ there are at most 2λ⋅κ=2λ=λ+ names for subsets of λ. Cardinal preservation by chain-condition forcing and Cantor theorem turn these upper bounds into the required equalities.

Dense subset of a forcing order

Words: 166 Articles: 3
Forcing OurBigBook.com
A subset D of a forcing order P is dense if every p∈P has a stronger condition q≤p in D. This order-density condition is the one used by a generic filter; it is distinct from density in an arbitrarily specified topology.

Dense above a forcing condition (∀q≥p ∃r≥q (r∈D))

Words: 48
Dense subset of a forcing order OurBigBook.com
For the convention that larger conditions are stronger, density above p means every strengthening of p has a further strengthening in D. It is the extension-cone density usually called dense below a forcing condition when smaller conditions are stronger. The sign must be translated with the order convention, rather than copied unchanged.

Dense below a forcing condition

Words: 76 Articles: 1
Dense subset of a forcing order OurBigBook.com
A set D⊆P is dense below p when every q≤p has an extension r≤q belonging to D.

Dense-below generic meeting lemma

Words: 55
Dense below a forcing condition OurBigBook.com
If p∈G and a ground-model set D is dense below a forcing condition p, then the generic filter G meets D. Add all incompatible forcing conditions with p to D. The enlarged set is globally dense: a condition compatible with p first has a common strengthening, then a further strengthening in D. Genericity meets the enlargement, and directedness excludes its incompatible part.

Generic filter

Words: 648 Articles: 15
Forcing OurBigBook.com
A filter G⊆P is generic over a model M when it meets every dense subset of P belonging to M.

Maximal-antichain criterion for genericity (∣G∩A∣=1 for every ground maximal antichain A)

Words: 50
Generic filter OurBigBook.com
A filter is generic over its ground model exactly when it meets each ground-model maximal forcing antichain in one point. Extensions of a maximal antichain form a dense set, while any ground dense set contains an antichain maximal in the whole forcing. Directedness permits at most one antichain member in a filter.

Rasiowa–Sikorski lemma

Words: 46
Generic filter OurBigBook.com
If M is a countable transitive model, P∈M, and p∈P, enumerate the dense subsets of P belonging to M and recursively choose a decreasing sequence starting below p that meets each one. Its upward closure is a generic filter over M containing p.

Generic extension

Words: 529 Articles: 12
Generic filter OurBigBook.com
If G is a generic filter over a countable transitive model M, the generic extension M[G] consists of the interpretations by G of all forcing names in M.

Power-set failure in an increasing union of generic extensions

Words: 59
Generic extension OurBigBook.com
Let Mn+1​=Mn​[Gn​] for a fixed atomless forcing order P, and N=⋃n<ω​Mn​. If a set A∈N were its internal power set of P, choose n with A∈Mn​. The next generic filter Gn​ belongs to N, so Gn​∈A; transitivity of Mn​ implies Gn​∈Mn​, contradicting generic filter for an atomless order is new. The chain is increasing but need not be an elementary chain.

Power set in a generic extension (ΠτG​=PM[G](τG))

Words: 86
Generic extension OurBigBook.com
For a forcing name τ, let U consist of pairs (ρ,p) where (ρ,r)∈τ for some r≥p. Every ground-model subset ν of U is a name whose value is contained in τG. Every subset σG⊆τG has an equivalent such name: retain those (ρ,p)∈U with p⊩ρ∈σ. The atomic membership truth lemma for forcing proves equality of values. Collect all these names from the ground-model power set PM(U) into a single outer name, pairing each with every condition. Its value is the full internal power set, without presupposing that power set in the extension.

A generic extension of a transitive model has exactly the same ordinals as its ground model. Rank induction on names bounds every value; transitivity and agreement on membership make ordinalhood absolute.

Atomic membership truth lemma for forcing
Words: 63
Syntactic forcing relation OurBigBook.com
For forcing names σ,τ and a generic filter G, σG∈τG exactly when some p∈G syntactically forces σ∈τ. Assuming the equality truth lemma, interpreted membership supplies an active pair (ρ,r)∈τ and a condition in G forcing σ=ρ; a common strengthening forces membership. Conversely the defining equality witnesses occur dense below a forcing condition forcing membership. The dense-below generic meeting lemma supplies one in G, and the equality truth lemma recovers interpreted membership.
Existential clause of syntactic forcing
Words: 54
Syntactic forcing relation OurBigBook.com
For the usual recursive syntactic forcing relation, p⊩∗∃xφ(x) means that conditions q≤p forcing φ(σ) for some forcing name σ are dense below a forcing condition p. This density clause proves the existential step of the forcing theorem from the truth lemma for each named instance. A generic filter containing p meets that dense set after it is augmented by conditions incompatible with p.
Separation in a generic extension

Let x˙,a˙1​,…,a˙n​ be forcing names and let φ be a formula. The name
y˙​={(τ,r):∃q((τ,q)∈x˙∧r≤q∧r⊩∗φ(τ,a˙1​,…,a˙n​))}
(1)
belongs to the ground model by axiom schema of separation. The forcing theorem shows that its value in a generic extension is exactly
y˙​G={z∈x˙G:M[G]⊨φ(z,a˙1G​,…,a˙nG​)}.
(2)

Over a model of Generalized continuum hypothesis, add ℵ3​ Cohen reals with finite binary partial functions. The Delta-system lemma proves the countable chain condition for forcing. The generic reals give the continuum lower bound ℵ3​, while nice forcing names for subsets of ω1​ number at most (ℵ3​)ℵ1​=ℵ3​ in the ground model. Cardinal preservation then gives 2ℵ0​=2ℵ1​=ℵ3​.

Countable chain condition for finite-function forcing (Fn(X,Y,ω) is ccc for countable Y)

Words: 60
Fn forcing OurBigBook.com
The order Fn(X,Y,ω) has the countable chain condition for forcing whenever Y is countable. For an uncountable family of conditions, apply the Delta-system lemma to the finite domains. On their common finite root there are only countably many assignments, so thin to an uncountable family agreeing on that root. Any two conditions now have a compatible union. For binary Cohen forcing, there are only finitely many root assignments.

Generic coordinate reals for finite-function forcing (cξ​(n)=(⋃G)(ξ,n))

Words: 74
Fn forcing OurBigBook.com
For Fn forcing on κ×ω with values in 2, the generic filter union is total by the dense coordinate-domain requirements. For each pair of distinct rows, the set of conditions giving them opposite bits at some column is dense: choose a column untouched in both finite rows. Thus the rows are distinct subsets of ω and provide an injective function from the ground-model ordinal κ into the extension's power set of ω. This construction alone does not prove preservation of its ground-model cardinal number status.

Possible-values lemma for chain-condition forcing

Suppose P has the κ-chain condition and f˙​ is forced to be a function from an ordinal μ to an ordinal λ. For each ξ<μ, a maximal antichain in a forcing order deciding f˙​(ξ) has size below κ. Hence the ground model has a set Bξ​⊆λ of size below κ containing every possible value of f˙​(ξ).

Cardinal preservation by chain-condition forcing

Words: 58

If κ is a regular cardinal and P has the κ-chain condition, then forcing with P preserves every cardinal number and cofinality at least κ. Indeed, a proposed surjection f:μ→λ with μ<λ has its range contained in ⋃ξ<μ​Bξ​ from the possible-values lemma for chain-condition forcing. The regularity of κ and infinite cardinal arithmetic make this union have cardinality below the ground-model cardinal λ, a contradiction.

Every uncountable subset of a Knaster forcing has an uncountable pairwise compatible subset. The property implies the countable chain condition for forcing. Finite Cohen forcing has this property by the delta-system lemma and agreement on the finite root. A Knaster forcing times any CCC forcing is CCC
Knaster forcing preserves Suslin trees
Words: 65
Knaster forcing OurBigBook.com
If T is a normal splitting Suslin tree and P is Knaster, then P×T is CCC, so P forces that the ground tree is still CCC Countable levels and splitting persist. A new cofinal branch would give an uncountable antichain by splitting, so none is added. This permits adding many Cohen reals while retaining a Suslin tree, and distinguishes Knaster preservation from an unjustified preservation claim for every CCC forcing.

Closed forcing (κ-closed)

Words: 327 Articles: 6
Forcing OurBigBook.com
A forcing order is κ-closed when every decreasing sequence of conditions of length below κ has a lower bound. Countably closed forcing adds no new countable sequences of ground-model elements and in particular adds no new real numbers.

Closed forcing adds no short ground-valued sequences ((αB)M=(αB)M[G])

Words: 73
Closed forcing OurBigBook.com
If a forcing is κ-closed in the ground model, then it adds no functions from a ground ordinal α<κ into a ground set B. Recursively decide each value inside the ground model and take common stronger bounds at limit stages and after the final step. Conditions deciding a whole ground function are dense below any condition asserting this type of function. The dense-below generic meeting lemma ensures the generic filter meets that dense subset of a forcing order. One arbitrary bound need not be in the filter in an ordered set.

Closed forcing adds no short ordinal sequences

Words: 122 Articles: 1
Closed forcing OurBigBook.com
If a ground-model order is λ-closed, it adds no ordinal-valued functions with domain μ<λ. Recursively decide each name value inside the ground model, using closure at intermediate limit stages and once more at the end. Below each starting condition, conditions deciding the entire function are dense. A generic filter meets them by the dense-below generic meeting lemma. The recursion must be internal to the ground model, since its closure property only covers its own sequences.

A λ-closed forcing order preserves a ground-model cardinal number λ, even when it is singular. A proposed surjection from an ordinal below λ to λ would be an old function because closed forcing adds no short ordinal sequences, contradicting old cardinalhood. This concerns λ and smaller cardinals; closure alone does not supply preservation of all larger cardinals.

The finite-condition Lévy collapse Lv(κ) consists of finite partial functions p with domp⊆κ×ω and p(α,n)<α, ordered by reverse inclusion. The generic union gives a surjection ω→α for every infinite α<κ. Finite Lévy collapse to omega-one (κ=ω1M[G]​)

Words: 54
Finite-condition Lévy collapse OurBigBook.com
With κ an uncountable regular cardinal, finite partial functions on κ×ω assigning a value below the first coordinate collapse every ground ordinal below κ to countable size. The Delta-system lemma gives the κ chain in a partial order condition; the possible-values lemma for chain-condition forcing then preserves the regularity of κ. Therefore κ becomes the extension ω1​. Strong inaccessibility is enough but is not needed for this identification.

Maximal-antichain sizes in the finite Lévy collapse (0<∣A∣<κ)

Words: 62
Finite-condition Lévy collapse OurBigBook.com
For a regular uncountable κ, the finite-condition collapse has the κ chain in a partial order condition, by a regular-cardinal Delta-system lemma and thinning to identical assignments on the finite root. Thus every maximal forcing antichain has ground-model size less than κ. There is no fixed size: for any nonzero cardinal μ<κ, assigning all values below μ at the one coordinate (μ,0) is a maximal forcing antichain of size μ.
