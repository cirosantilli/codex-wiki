Covariance function (C(s,t))

 Home Mathematics Area of mathematics Probability and statistics Probability theory Stochastic process
OurBigBook.com Words: 166
For a real-valued stochastic process (Xt​) with finite second moments, write m(t)=EXt​. Its covariance function is
C(s,t)=Cov(Xs​,Xt​)=E[(Xs​−m(s))(Xt​−m(t))].
(8)
The diagonal gives the variance at each time; off-diagonal values record linear dependence between times. For the independent standard normal random variables above, CX​(m,n)=1{m=n}​, whereas the shared Gaussian process Yn​=Z has CY​(m,n)=1 for all m,n. For a fair simple random walk on the integer line, C(m,n)=min(m,n); Brownian motion has the continuous-time counterpart C(s,t)=min(s,t). These formulas quantify how much random history the observations share.
Every covariance function is a positive-semidefinite kernel. Indeed, for any real coefficients a1​,…,ak​,
∑i,j=1k​ai​aj​C(ti​,tj​)=Var(∑i=1k​ai​Xti​​)≥0.
(9)
Thus a proposed covariance function must make every finite covariance matrix positive semidefinite. For a Gaussian process, the mean function and the covariance function determine every finite-dimensional distribution, including degenerate ones such as the shared process. Conversely, any real positive-semidefinite kernel satisfying C(s,t)=C(t,s), together with a specified mean function, defines consistent multivariate normal distributions; the Kolmogorov extension theorem then constructs a Gaussian process. For a general stochastic process, covariance alone does not determine the full law. The exceptional completeness of this description is what makes Gaussian process regression possible with a mean and a covariance model.
