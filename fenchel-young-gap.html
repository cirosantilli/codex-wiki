Fenchel–Young gap (Gf​(x,p)=f(x)+f∗(p)−p⋅x)

 ... Mathematics Area of mathematics Mathematical optimization Convex optimization Convex conjugate Fenchel–Young inequality
OurBigBook.com Words: 279
The Fenchel–Young gap is the nonnegative discrepancy
Gf​(x,p)=f(x)+f∗(p)−p⋅x≥0
(63)
for a proper convex function and its convex conjugate. It can be +∞. When f∗(p) is finite, it is the vertical distance between f(x) and its affine minorant ℓp​(x)=p⋅x−f∗(p). The Fenchel–Young gap vanishes exactly when p∈∂f(x), so it measures whether an input and a slope satisfy the subgradient relation.
For the convex quadratic function f(x)=x2/2, completing the square gives
Gf​(x,p)=2x2​+2p2​−px=2(x−p)2​.
(64)
At x=−1 and p=2, the function value is 1/2 and the tangent line 2x−2 has value −4, giving a Fenchel–Young gap of 9/2. In Rn, the same calculation for f(x)=∥x∥22​/2 gives f∗(p)=∥p∥22​/2 and Gf​(x,p)=∥x−p∥22​/2, half the squared Euclidean norm of the mismatch.
An exact optimization error certificate. Fix a slope p with f∗(p)<+∞ and minimize the linearly tilted objective function hp​(z)=f(z)−p⋅z. By the definition of the convex conjugate, infz​hp​(z)=−f∗(p), so
hp​(x)−infz​hp​(z)=Gf​(x,p).
(65)
This identity holds even when the infimum is not attained. Thus a computed finite Fenchel–Young gap is exactly the error in objective value for this minimization problem. For the convex quadratic function, Gf​(x,p)≤ε implies ∣x−p∣≤2ε​. A general proper convex function need not convert a small gap into a small distance: the absolute value has zero gap at p=1 for every x≥0.
The Fenchel–Young gap also connects convex analysis to optimal transport. For a proper convex function Φ, define Kantorovich potentials u(x)=∥x∥22​/2−Φ(x) and v(y)=∥y∥22​/2−Φ∗(y). The half-squared Euclidean distance cost satisfies ∥x−y∥22​/2−u(x)−v(y)=GΦ​(x,y). For a transport plan with finite integrated cost and integrable Kantorovich potentials, integrating this identity gives the difference between transport cost and the potentials' bound. This is the same local subgradient mismatch summed over transported pairs.
