Relaxation heuristic

 Home Computer science Theoretical computer science Computational complexity theory Computational problem Search problem
OurBigBook.com Words: 276 Articles: 3
A heuristic function obtained by solving an easier problem that permits every original transition and possibly additional ones, with original transitions costing no more in the easier problem. Every original solution remains available, so the easier optimum is an admissible heuristic.
If h is the exact distance to the relaxed goal set, each original transition also gives h(s)≤c(s,a,s′)+h(s′) by taking that transition and then a relaxed optimal continuation. Thus this construction gives a consistent heuristic when original goals have relaxed distance zero. For a four-direction grid walk, deleting obstacles gives Manhattan distance; deleting a pursuer's capture constraint supplies another relaxation. The resulting estimate can remain finite when the original goal is unreachable.
