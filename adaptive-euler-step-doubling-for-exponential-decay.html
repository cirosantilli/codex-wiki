Adaptive Euler step doubling for exponential decay (y′=−y,y(0)=1)

 Home Mathematics Area of mathematics Analysis Numerical analysis Error control for ODE solvers
OurBigBook.com Words: 636
Consider the nonstiff scalar initial value problem y′=−y, y(0)=1, on 0≤t≤8. Its exact solution is the exponential decay y(t)=e−t. Use step-doubling error estimation with the explicit Euler method: from the same numerical starting value yn​, form one coarse step Cn​ and two half steps giving Fn​:
Cn​=(1−hn​)yn​,Fn​=(1−hn​/2)2yn​,en​=Fn​−Cn​=4hn2​yn​​.
(8)
Accept yn+1​=Fn​ when the absolute and relative error tolerances test En​=∣en​∣/sn​≤1 passes, with sn​=10−5+10−3max(∣yn​∣,∣Fn​∣). There is no Richardson extrapolation in the accepted value. Both approximations have order of a numerical method one, while this local error estimator has step exponent r=2. Consequently the adaptive step-size controller uses a square root, not a cube root:
qn​=min(5,max(0.2,0.9En−1/2​)),hnext​=qn​hn​.
(9)
Start with h0​=1. A rejected trial retains both tn​ and yn​, caps qn​ at one, and retries. A zero estimate uses qn​=5. Before every trial, cap hn​ at 8−tn​. Stop with a failure if floating-point arithmetic gives tn​+hn​=tn​, or after 100000 trials. These rules specify the example completely; they are not a prescription for every ordinary differential equation solver.
The first two trials, h=1 and h=0.2, have E≈247.525 and E≈9.90099 and are rejected. The next trial has h≈0.0572049 and E≈0.81 and is accepted. For positive decreasing numerical values, sn​=10−5+10−3yn​, so the local error estimator gives
En​=4(10−3+10−5/yn​)hn2​​.
(10)
When the relative term dominates, this suggests nearly constant accepted steps, approximately 2(0.9)10−3​. When yn​ falls below the crossover size 10−5/10−3=0.01, the absolute term increasingly permits longer steps. The sharp final decrease in h only lands on t=8; it does not indicate a sudden loss of smoothness.
The actual signed local defect from the same numerical input is
ℓn​=yn​e−hn​−Fn​=yn​(4hn2​​−6hn3​​+O(hn4​)).
(11)
Here O is Big O notation, obtained from Taylor's theorem for the exponential function. Thus en​ agrees with the leading term as hn​→0, but is not identical to ℓn​. At h=1, yn​=1, the estimate is 0.25 while the actual local defect is e−1−1/4≈0.117879. Their closeness improves for the smaller accepted steps. Had we added en​ using Richardson extrapolation, the accepted formula would instead be yn​(1−hn​+hn2​/2), of order of a numerical method two; the same raw difference would still scale as hn2​ and would not estimate that improved value's leading hn3​ defect.
The global error gn​=yn​−e−tn​ obeys an exact recurrence relation involving the actual local defects:
gn+1​=e−hn​gn​−ℓn​,g0​=0.
(12)
Each previous global error contracts, yet the local defects keep adding. In the plotted run, 101 steps are accepted and two trials are rejected. Every accepted En​ is at most approximately 0.81, while the largest ∣gn+1​∣/sn​ is approximately 38.6927. At t=8, the numerical value is approximately 0.00027184218, compared with the exact e−8≈0.00033546263, giving absolute error approximately 6.36204×10−5. The right-hand plot deliberately scales actual global error by the same sn​ used for local acceptance; it is not a new global error tolerance test.
Tightening both absolute and relative error tolerances by a factor ten gives 315 accepted steps and endpoint absolute error approximately 2.14922×10−5; tightening both by a factor one hundred gives 991 accepted steps and endpoint absolute error approximately 6.94171×10−6. This is a convergence comparison for this particular initial value problem. The endpoint error decreases by about a factor three per tenfold tightening, rather than by ten: a first-order Euler method accumulates defects across many steps, while its local error estimator varies quadratically with h. A variable-step global ODE error bound needs propagation information as well as accepted local tests.
The absolute stability boundary remains a separate constraint. On the Dahlquist test equation y′=−λy with λ>0, the accepted two-half-step formula has stability function R(−λh)=(1−λh/2)2. It strictly damps perturbations only for 0<λh<4. Its local error estimator is λ2h2yn​/4, which can pass an absolute-tolerance test at tiny yn​ even outside this damping interval. In a stiff two-mode linear system, a fast mode can therefore constrain the step long after its visible amplitude has become small. An adaptive step-size controller does not turn an explicit Euler method into an A-stable method. Official solver documentation likewise distinguishes explicit Runge-Kutta methods for nonstiff problems from implicit Runge-Kutta methods and backward differentiation formulas for stiff equations.[ref]
