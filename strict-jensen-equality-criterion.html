Strict Jensen equality criterion (E[f(X)]=f(EX)⟺X=EX a.s.)

 ... Mathematics Area of mathematics Analysis Real analysis Convex function Jensen's inequality
OurBigBook.com Words: 145
Let X be an integrable random variable taking values in an open interval I. Suppose f:I→R is a differentiable strictly convex function. Then its expected value has equality in Jensen's inequality exactly when X is constant almost surely.
First m=EX lies in I: at each finite endpoint, taking the expected value of the strictly positive distance to that endpoint gives a strictly positive distance for m. A tangent affine function supports f at m, so
h(t)=f(t)−f(m)−f′(m)(t−m)≥0.
(116)
Strict convexity forces h(t)>0 for t=m. Indeed, equality at another point would force the graph to coincide with its supporting line on the connecting line segment, contradicting strict convexity. Therefore
E[f(X)]−f(m)=E[h(X)]≥0,
(117)
and the right side is zero exactly when X=m almost surely.
The tangent affine function of X is an integrable random variable, so f(X) has an integrable negative part. Thus E[f(X)] is well defined, possibly +∞, even if absolute integrability was not assumed. Equality to f(m) automatically excludes that infinite case.
