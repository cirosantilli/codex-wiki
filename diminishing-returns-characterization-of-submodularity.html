Diminishing returns characterization of submodularity (Δx​f(A)≥Δx​f(B)(A⊆B, x∈/B))

 ... Area of mathematics Foundations of mathematics Set theory Function Set function Submodular set function
OurBigBook.com Words: 111
For a real-valued set function on a finite ground set, the displayed marginal increment comparison is equivalent to submodularity. The interpretation is that an additional item contributes no more after more items have already been chosen. This concerns relative increments, which may be negative; it does not assert the monotone set function property.
Proof. Applying the defining inequality for a submodular set function to A+x and B gives the comparison immediately. Conversely, list A∖B={x1​,…,xm​} and compare adding these elements, in the same order, first to A∩B and then to B. At every step the first conditioning set is contained in the second, so the first marginal increment is at least the second. The telescoping sums give
f(A)−f(A∩B)≥f(A∪B)−f(B),
(3)
which rearranges to submodularity.
