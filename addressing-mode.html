Addressing mode

 Home Computer science Instruction set architecture
OurBigBook.com Words: 222 Articles: 5
An addressing mode specifies how an instruction obtains an operand or forms an effective memory address. Examples include immediate operands, processor register operands, base-plus-displacement memory access and scaled processor register indexing.
