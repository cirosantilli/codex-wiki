Nullity of a linear map (n(T)=dimkerT)

 Home Mathematics Area of mathematics Algebra Linear algebra Kernel of a linear map
OurBigBook.com Words: 354
The nullity of a linear map T:V→W is n(T)=dimkerT, the dimension of its kernel. It counts independent input directions that can change without changing the output. For a finite-dimensional vector space V, the rank-nullity theorem gives
n(T)=dimV−rankT.
(6)
For an m×n matrix A of matrix rank r, this is n−r, using the number of columns, not the number of rows. This dimension identity is [ref].
The nullity answers a practical question about a linear system: once one input is known to produce the requested output, how much freedom remains? If T(x0​)=b, its fiber of a function over b is
T−1({b})=x0​+kerT.​
(7)
Indeed, T(x)=T(x0​) exactly when T(x−x0​)=0. Thus every nonempty fiber is an affine subspace of dimension n(T), with the same direction space as the kernel. The kernel itself is the fiber over zero. Outputs outside the image of a linear map have empty fibers; the nullity does not guarantee existence, and we assign no solution-space dimension to an empty fiber here.
In the diagram, F:R2→R2 has matrix (10​10​), matrix rank one and nullity one. Its kernel has basis (1,−1), and the full solution of F(x,y)=(c,0) is (x,y)=(c,0)+s(1,−1). One free scalar moves the solution along a straight line; the output (c,1) is impossible.
The existing three-input example T(x,y,z)=(x+y,z) instead has rank two and nullity one. Its image of a linear map is all of R2, and
T−1({(a,b)})=(a,0,b)+span{(1,−1,0)}.
(8)
Every output has a solution straight line. In contrast, U(x,y,z)=(x+y,0) has rank one and nullity two, with kernel basis (1,−1,0),(0,0,1). Its reachable output (a,0) has the solution affine subspace
(x,y,z)=(a,0,0)+s(1,−1,0)+u(0,0,1),s,u∈R,
(9)
a plane, while (a,b) with b=0 has no solution. These two linear maps have the same input and output dimensions but different freedom and reachability. Computing the kernel separates what an output determines from what an extra constraint would have to fix. For either example, a basis of the kernel gives one independent free scalar per basis vector, which is why nullity measures freedom rather than the number of solutions.
