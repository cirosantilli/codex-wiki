Singular value (σj​≥0)

 Home Mathematics Area of mathematics Algebra Linear algebra Singular value decomposition
OurBigBook.com Words: 611 Articles: 4
The singular values of a matrix measure stretching of Euclidean norm. They are the nonnegative square roots of the eigenvalues of A∗A, counting the min(m,n) diagonal slots of the singular value decomposition; when n>m, A∗A has additional zero eigenvalues. Nonnegativity follows from x∗A∗Ax=∥Ax∥22​≥0, so A∗A is a positive semidefinite matrix. For the preceding 2×2 matrix,
ATA=251​(241288​288409​),AAT=(250​01​).
(21)
Both have eigenvalues 25,1, giving singular values 5,1. In particular,
σ1​=max∥x∥2​=1​∥Ax∥2​=∥A∥2​.
(22)
Here the operator norm uses Euclidean norm: no unit vector stretches more than fivefold. Zero singular values identify lost directions; the number of positive singular values equals the matrix rank. This summarizes both amplification and information loss with nonnegative numbers.[ref]
Small positive singular values also explain sensitivity in an inverse problem. For a square invertible matrix, the matrix inverse sends uj​ to vj​/σj​: a weak forward response becomes strong inverse amplification. The condition number for Euclidean norm is σ1​/σn​, equal to 5 in our example. To see a larger effect, keep the same right singular vectors but change the second singular value to ε=0.01:
Aε​=(3−4ε/5​43ε/5​),δb=0.001u2​,δx=Aε−1​δb=0.1v2​=(−0.08,0.06)T.
(23)
The output perturbation has Euclidean norm 0.001, but the recovered input changes by 0.1. Its hundredfold amplification follows from the direction of the perturbation, not just its size. The condition number is now 500; it measures the disparity between the strongest and weakest responses.[ref]
