Jones matrix (Jout​=MJin​)

 Home Physics Wave Polarization (waves) Jones calculus
OurBigBook.com Words: 137 Articles: 1
A Jones matrix is a complex two-by-two linear transformation of a Jones vector through a deterministic nondepolarizing optical element. Successive elements multiply in reverse reading order. An ideal linear polarizer along a real transverse unit vector a has matrix aaT. A common nonzero scalar phase does not change the output polarization of waves.
