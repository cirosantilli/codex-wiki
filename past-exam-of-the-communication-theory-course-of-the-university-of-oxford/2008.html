Write pxy​=P(X=x,Y=y), px​=∑y​pxy​, and qy​=∑x​pxy​. In bits the mutual information is
I(X;Y)=∑pxy​>0​pxy​log2​px​qy​pxy​​.
(1)
Terms with zero joint probability contribute zero. On its positive support apply −logt≥1−t with t=px​qy​/pxy​:
(loge​2)I(X;Y)≥∑pxy​>0​(pxy​−px​qy​)=1−∑pxy​>0​px​qy​≥0.
(2)
Equality requires equality in every logarithmic inequality and no product mass outside the joint support, hence pxy​=px​qy​ everywhere. Conversely that factorization makes every term zero. Thus mutual information is nonnegative and vanishes exactly for independence. For countable alphabets the same conclusion follows from the relative-entropy inequality, allowing the value +∞.

The entropy chain rule gives
I(X;Y)=H(X)−H(X∣Y)=H(Y)−H(Y∣X).
(3)
Conditional entropy is nonnegative, so I(X;Y)≤min(H(X),H(Y)). For finite entropies, if H(X)≤H(Y), equality holds exactly when H(X∣Y)=0, meaning X is a function of Y almost surely. If H(Y)≤H(X), interchange the variables. When their entropies are equal, equality requires both functional relations. Zero conditional entropy has this characterization because each conditional probability distribution must be a point mass.

For a finite probability distribution,
H(X)=−∑pi​>0​pi​log2​pi​,
(8)

Define H(X∣Y)=∑y​P(Y=y)H(X∣Y=y). The joint entropy identity H(X,Y)=H(Y)+H(X∣Y) follows by writing pxy​=qy​px∣y​ and expanding its logarithm. If Y=g(X), then H(Y∣X)=0 and H(X,Y)=H(X), giving the desired decomposition.
Group the first two symbols together and keep the third separate. If c<1, the identity becomes
H(a,b,c)=h(c)+(1−c)h(1−ca​),
(10)
where h(t)=−tlog2​t−(1−t)log2​(1−t). Binary entropy is at most one, with equality precisely at 1/2. Hence
H(a,b,c)≤h(c)+1−c=H((1−c)/2,(1−c)/2,c).
(11)
Equality holds exactly when a=b=(1−c)/2. When c=1, a=b=0, so the same conclusion holds at the boundary.

The capacity of a discrete memoryless channel is C=maxPX​​I(X;Y), in bits per channel use. For the binary symmetric channel with crossover probability p, H(Y∣X)=h(p) and H(Y)≤1. A uniform input makes the output uniform, attaining
CM​=1−h(p)​.
(12)
For the binary erasure channel, let E be its erasure indicator. This flag is visible in the output and independent of the input. If there is no erasure, the output reveals the input; otherwise it reveals nothing. Consequently
I(X;Y)=(1−ϵ)H(X),CN​=1−ϵ​,
(13)
again attained by a uniform input. These formulas include crossover probabilities zero and one, and complete erasure.

Let X be the original input, U the output of the first channel, and Y the final output. The independent erasure flag is observable from Y. The mutual information chain rule, conditioning on that flag, gives
I(X;Y)=(1−ϵ)I(X;U)+ϵ⋅0.
(14)
The same uniform input maximizes I(X;U) as in the binary symmetric channel. Thus
C=(1−ϵ)(1−h(p))​.
(15)
This scaling works because the erasure event is independent of both the input and the first channel noise.

Unique decipherability makes the map from (X1​,…,Xm​) to the concatenated binary string M injective. Entropy is unchanged by an injective relabelling, and memorylessness gives independence, hence
H(M)=H(X1​,…,Xm​)=mH(X).
(16)
Given L=ℓ, the string has at most 2ℓ possibilities. The entropy bound for finite alphabets therefore gives H(M∣L=ℓ)≤ℓ. Averaging,
H(M∣L)≤EL=mE∣c(X)∣.
(17)
The random length cannot simply be discarded: it can also carry information. Let ℓmax​ be the maximum codeword length, finite since the alphabet is finite. Since L is a function of M and takes at most mℓmax​+1 values,
mH(X)=H(L)+H(M∣L)≤log2​(mℓmax​+1)+mE∣c(X)∣.
(18)
Divide by m and let m→∞. This proves E∣c(X)∣≥H(X)​. The conclusion also covers a deterministic source; the source's lowercase x in its final expectation denotes the random source letter.

The entropy is
H(S)=413​−163log2​3+5log2​5​​.

To construct a Huffman code, work with integer weights 2,2,3,4,5. Merge the two twos to make four. Of the remaining weights 3,4,4,5, merge three with the original four to make seven, and merge the new four with five to make nine. Finally merge seven with nine. Resolving the tie in this way gives, for example,
c(x1​)=110,c(x2​)=111,c(x3​)=00,c(x4​)=01,c(x5​)=10.
(20)
This is a prefix code and Huffman's optimality theorem makes it optimal. Its expected length is
ℓˉ=3(1/8+1/8)+2(3/16+1/4+5/16)=9/4​.
(21)
Different choices at a tied merge can give different optimal codewords with the same expected length.

Let ℓˉ=E∣c(X)∣. The Huffman encoder emits an average of wℓˉ binary digits per minute. Shannon's noisy-channel coding theorem states that for a discrete memoryless channel of capacity K, every information rate strictly below K bits per use is achievable with error probability tending to zero as block length grows; rates above K are not achievable for unrestricted messages.
Thus a channel code carrying the Huffman bitstream reliably with buffering and arbitrarily long blocks can be chosen whenever
rK>wℓˉ,r>Kwℓˉ​​.
(22)
The strict inequality supplies positive coding and buffering slack. Huffman's expected-length bound is H(X)≤ℓˉ<H(X)+1 for a nontrivial finite source. Therefore the simpler bound r>w(H(X)+1)/K is sufficient without knowing its exact Huffman lengths.
Distinguish this bitstream construction from the absolute source-channel limit. The noiseless source coding theorem permits long source blocks to be compressed to any rate above H(X) bits per source symbol, with arbitrarily small overhead. Together with channel coding, this gives the sharper limiting requirement rK>wH(X); rK<wH(X) is impossible by the source-channel converse. Further compression can exploit redundancy remaining in a single-symbol Huffman stream, so wℓˉ/K need not be the universal minimum channel symbol rate. At K=0 a positive-entropy source cannot be sent reliably at a finite rate.

A binary prefix code assigns each source symbol a distinct finite binary word, with no assigned word a prefix of another. It is instantaneous because a decoder can identify the symbol as soon as its last digit arrives, without reading digits from the next word. Such a code is optimal when it minimizes
ℓˉ=∑x​px​∣c(x)∣
(23)
among all binary prefix codes for that source distribution. Symbols of zero probability may be removed from the optimization.

Make a rooted binary tree with an edge labelled zero for the first branch and one for the second branch at each interior node. Put each source symbol at the leaf reached by following the successive digits of its codeword. The prefix property ensures no assigned word ends at an ancestor of another assigned word.
The route of a codeword is its root-to-leaf path; its length is the number of edges on that path, equal to the number of binary digits in the word. For an optimal tree with positive leaf probabilities, every interior node has two children: a node with just one child could be contracted, shortening all words below it and strictly reducing the expected length. The diagram in the earlier Huffman calculation is one such full binary tree.

The redundancy is R=ℓˉ−H(X), measured in bits per source symbol. Write sv​=σ0​(v)+σ1​(v) for the total mass passing through interior node v. Counting each codeword's length as one for each interior node its route visits gives
ℓˉ=∑x​px​∑v on its route​1=∑v∈N​sv​.
(24)
The entropy can be split into the conditional binary decisions along that route. Algebraically each node contributes
sv​h(σ0​(v)/sv​)=sv​log2​sv​−σ0​(v)log2​σ0​(v)−σ1​(v)log2​σ1​(v).
(25)
Summing telescopes: each non-root interior mass appears once positively as a parent and once negatively as a child. The root term is 1log2​1=0 and the remaining leaf terms sum to −∑x​px​log2​px​=H(X). Hence
H(X)=∑v∈N​sv​h(σ0​(v)/sv​).
(26)
Subtracting this identity from the expected-length identity proves
R=v∈N∑​(σ0​(v)+σ1​(v))[1−h(σ0​(v)+σ1​(v)σ0​(v)​)]​.
(27)
Thus redundancy is the sum of the probability-weighted imbalances of the binary branch decisions. Nodes with no mass contribute zero by continuity. The formula holds for every full prefix tree, even without optimality.
