For finite-valued random vectors, the conditional entropy is the average of the entropies of the conditional distributions:
H(X∣Y)=y:pY​(y)>0∑​pY​(y)[−x∑​p(x∣y)log2​p(x∣y)]​.
(1)
Use 0log2​0=0 and omit zero-probability conditioning events. Equivalently,
H(X∣Y)=−∑x,y:p(x,y)>0​p(x,y)log2​pY​(y)p(x,y)​.
(2)
The base two makes all information quantities measured in bits; changing the logarithm base scales them by a positive constant and preserves the inequalities.

Apply Gibbs inequality to the joint distribution and the product of its marginals. Restrict to the Cartesian product of their positive supports, so the reference probabilities are strictly positive as the supplied inequality requires. Expanding gives
0≤∑x,y​p(x,y)log2​pX​(x)pY​(y)p(x,y)​=H(X)−H(X∣Y).
(3)
This proves the second inequality. For the first, apply the same argument to the conditional joint distribution of (X,Z) for each y with pY​(y)>0, and average with those probabilities:
0≤∑y​pY​(y)I(X;Z∣Y=y)=H(X∣Y)−H(X∣Y,Z).
(4)
Here the conditional support restriction again removes zero marginal probabilities. Thus
H(X∣Y,Z)≤H(X∣Y)≤H(X)​.
(5)
The nonnegative differences are conditional mutual information and mutual information, respectively.

Factoring a joint probability into successive conditional probabilities and taking the expected negative logarithm gives the chain rule for entropy:
Hn​=∑r=1n​H(Xr​∣X1​,…,Xr−1​).
(6)
At r=1 this means the unconditional entropy. Removing conditioning can only increase each term by part (a), so Hn​≤∑r​H(Xr​).
Write X−r​ for the vector omitting coordinate r. Another application of the chain rule gives H(X−r​∣Xr​)=Hn​−H(Xr​). Therefore
∑r​H(X−r​∣Xr​)=nHn​−∑r​H(Xr​)≤(n−1)Hn​.
(7)
Divide by n−1>0 to obtain the required averaged inequality. The case n=1 is excluded precisely because that denominator vanishes.

The chain rule for entropy, with Xr​ placed last, gives
Hn​=H(X−r​)+H(Xr​∣X−r​).

Since X−r​ includes all the preceding coordinates, conditioning monotonicity gives
H(Xr​∣X−r​)≤H(Xr​∣X1​,…,Xr−1​).
(9)
This proves the first assertion for every r, including r=1. Sum over r: the conditional terms on the right sum to Hn​ by the ordinary chain rule. Thus
nHn​≤∑r​H(X−r​)+Hn​,Hn​≤n−11​r∑​H(X−r​)​.

For each r, conditioning on all the other coordinates gives no greater conditional entropy than conditioning only on the preceding ones. Summing and using the chain rule for entropy gives directly

In the terminology used here, a block code assigns a distinct word of the same length to every source symbol. For a binary code with m symbols this common length must satisfy 2ℓ≥m. The equal-length property is what matters in this question; elsewhere the term can also refer more generally to coding blocks of source symbols.

A prefix code has no codeword that is a proper prefix of another. Its code tree therefore places source symbols at leaves. It is instantaneous because the decoder knows that a source symbol has ended as soon as its leaf is reached, without needing to inspect later transmitted symbols.

A compact code or optimal prefix code minimizes the expected codeword length ∑x​px​ℓx​ for the given source probabilities and coding alphabet. The relevant comparison here is among binary prefix codes. The minimum is also the minimum among uniquely decodable codes, since the Kraft-McMillan inequality permits every uniquely decodable length list to be realized by a prefix code with the same lengths.

Solution

Words: 198
b OurBigBook.com
Every internal node of an optimal binary prefix tree has two children. If one had only one child, remove that one-edge detour from all descendant words. Prefix-freeness is preserved and at least one positive-probability word becomes shorter, strictly lowering the expected length. Thus the tree is full.
Take a leaf at maximum depth L. Its sibling exists because the tree is full. That sibling cannot be an internal node, since a descendant would be deeper than L. Hence it is another leaf at depth L, and the corresponding codewords differ only in their final bit. This is the deepest sibling property of an optimal prefix code.
A finite full binary tree satisfies Kraft equality, ∑x​2−ℓx​=1, by dividing mass equally down each branch from the root. If all 2n lengths were at least n, with at least one strictly greater, that sum would be less than 2n2−n=1, a contradiction. Since the code is not a block code, the alternative that all lengths equal n is excluded. Therefore some word has length below n. Also a longest word must have length above n: if all lengths were at most n and some shorter, the Kraft sum would exceed one.

Suppose every sum of two distinct probabilities exceeds every third probability. If an optimal code were not a block code, part (b) gives two deepest sibling leaves x,y at depth L>n and a leaf z at depth ℓ<n. Replace the sibling pair by a leaf labelled z, and replace the former z leaf by two children labelled x,y. The resulting tree is still a prefix tree, and other word lengths are unchanged. The change in expected length is
(px​+py​)(ℓ+1−L)+pz​(L−1−ℓ)=(L−ℓ−1)(pz​−px​−py​)<0.
(12)
Here L−ℓ−1≥1. This contradicts optimality. Thus every optimal code is a block code.
Conversely, suppose distinct x,y,z satisfy px​+py​≤pz​. Starting with the complete length-n code, arrange x,y as a sibling pair, which is possible by permuting the source labels. Its parent at depth n−1 does not contain z. Label that parent z, and split the old z leaf into children x,y. This gives lengths n−1 for z, n+1 for x,y, and n otherwise, with expected length
n+px​+py​−pz​≤n.
(13)
If the optimal mean length is below n, no optimal code can be a block code: any injective binary block code for 2n symbols has length at least n. If the optimal mean is n, the constructed non-block code itself is optimal. In either case there is an optimal non-block code. This proves the reverse implication, including the equality case, and hence the strict inequality in the criterion is necessary.
This is the optimality of a fixed-length code for a power-of-two alphabet.

For finite-valued variables, mutual information is
I(X;Y)=x,y∑​p(x,y)log2​pX​(x)pY​(y)p(x,y)​=H(Y)−H(Y∣X)​.
(14)
Terms of zero joint probability are zero. A discrete memoryless channel has fixed transition probabilities W(y∣x) on finite alphabets, and conditional on an input sequence its outputs are independent with the product law ∏i​W(yi​∣xi​). Its channel capacity is
C=PX​max​I(X;Y)​
(15)
bits per channel use. The maximum is over all input distributions, with the transition law held fixed.

Let E record whether the second stage erased the symbol, and write its output as Z. The erasure marker is outside the original output alphabet, so E is determined by Z. Independence makes E independent of both X and the first output Y. The chain rule for mutual information therefore gives
I(X;Z)=I(X;E,Z)=I(X;E)+I(X;Z∣E)=(1−p)I(X;Y).
(19)
The erased branch gives zero information because its output is constant; the unerased branch has exactly the original joint input-output law. Maximizing over the same input distributions gives
Ccomposite​=(1−p)C​.
(20)
This includes p=0 and p=1. It is the capacity after independent output erasure; input-dependent erasure would not justify the independence step.
