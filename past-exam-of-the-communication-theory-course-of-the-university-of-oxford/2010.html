a OurBigBook.com
A binary code assigns a finite bit string to each source symbol. Use nonempty codewords for an unframed variable-length stream. The code is uniquely decodable if no two distinct finite sequences of source symbols produce the same concatenated bit string. It is a prefix-free code if no codeword is an initial segment of a different codeword.
To prove unique decoding of a prefix code, suppose two concatenations agree. Their first codewords both begin the same bit string, so the shorter is a prefix of the longer. The prefix condition forces the first codewords to be equal. Cancel them and repeat. Since the codewords are nonempty, this process ends with both symbol sequences exhausted at the same time; otherwise a nonempty remainder could not equal the empty string. Hence the source sequences agree.
The code {0,01} is not a prefix code, since 0 is a prefix of 01. Nevertheless it is uniquely decodable: decode from the right. A final 1 forces the last codeword to be 01, whereas a final 0 forces it to be 0. Removing that final word recursively gives a unique parsing. Thus the converse fails.

For finite-valued random vectors, write p(x,y)=P(X=x,Y=y) and pY​(y)=P(Y=y). The conditional entropy is the average entropy of the posterior distributions:
H(X∣Y)=∑y:pY​(y)>0​pY​(y)[−∑x​p(x∣y)log2​p(x∣y)].
(10)
Equivalently, H(X∣Y)=−∑x,y:p(x,y)>0​p(x,y)log2​p(x∣y). Since p(x,y)=pY​(y)p(x∣y), splitting the logarithm gives
H(X,Y)​=−x,y∑​p(x,y)log2​pY​(y)−x,y∑​p(x,y)log2​p(x∣y)=H(Y)+H(X∣Y)​.​
(11)
Use the usual convention 0log2​0=0 and omit conditionals at zero-probability outputs. The same identities hold for countable alphabets whenever the entropy sums are well-defined, without subtracting two infinite quantities.

Given an output y of positive probability, the ideal observer chooses a symbol maximizing the posterior:
g(y)∈x∈Aargmax​P(X=x∣Y=y).​
(18)
Ties may be broken arbitrarily, and the choice at an impossible output does not matter. This is maximum a posteriori decoding. It minimizes conditional error at each y, because a deterministic decision x is correct with probability P(X=x∣Y=y); a randomized decision is a weighted average of these success probabilities and cannot exceed their maximum.
Write Πy​=maxx​P(X=x∣Y=y). Then w(y)=1−Πy​. Applying the two cases from part (b) to the posterior distribution gives
H(X∣Y=y)≥2(1−Πy​)=2w(y).
(19)
Average with respect to the output law to obtain the conditional entropy upper bound on minimum decoding error:
Ew(Y)≤21​H(X∣Y).​
(20)
This is an upper bound on the optimum error probability; it does not hold for arbitrary deliberately poor decoding rules.

For a finite joint distribution, the mutual information is
I(X;Y)=x,y∑​p(x,y)log2​pX​(x)pY​(y)p(x,y)​=H(Y)−H(Y∣X)=H(X)−H(X∣Y).​
(21)
Zero-probability terms contribute zero. It measures the reduction in uncertainty about one variable upon observing the other.
A discrete memoryless channel has discrete input/output alphabets and a fixed transition matrix W(y∣x). Over successive uses it obeys
P(Y1​=y1​,…,Yn​=yn​∣X1​=x1​,…,Xn​=xn​)=∏j=1n​W(yj​∣xj​).
(22)
Thus the output at a use depends on that input and no other channel history. Its channel capacity is
C=pX​max​I(X;Y),​
(23)
in bits per use for base-two logarithms. On finite alphabets the maximum exists by continuity on the probability simplex; for more general discrete alphabets one uses a supremum.

Fix the channel matrix W. The mixed input induces the mixed output q3​=λq1​+(1−λ)q2​. The concavity of information entropy implies
H(q3​)≥λH(q1​)+(1−λ)H(q2​).
(24)
For completeness, the difference is λD(q1​∥q3​)+(1−λ)D(q2​∥q3​)≥0 by Gibbs inequality, including zero coordinates with the usual conventions.
On the other hand, conditional output entropy is linear in the input law:
H(Y3​∣X3​)=∑x​p3​(x)H(W(⋅∣x))=λH(Y1​∣X1​)+(1−λ)H(Y2​∣X2​).
(25)
Subtracting gives the concavity of mutual information in the input distribution:
I(X3​;Y3​)≥λI(X1​;Y1​)+(1−λ)I(X2​;Y2​).​
(26)
This makes maximizing mutual information over the input probability simplex a concave optimization problem: a local maximum is global. It also justifies averaging input distributions over channel symmetries when searching for an optimum, since symmetry averaging cannot lower the achieved mutual information. The channel itself is held fixed throughout.

Let the input probabilities be (s,t,u) and put v=s+u=1−t. The output distribution and conditional entropy are
q=(2s​,1−2v​,2u​),H(Y∣X)=s+u=v.
(27)
For fixed v, the first and third output masses sum to v/2. Their entropy is maximized when they are equal, so s=u=v/2. Equivalently, if v>0,
H(Y)=h2​(v/2)+(v/2)h2​(s/v)≤h2​(v/2)+v/2.
(28)
The same bound holds at v=0 by continuity. Therefore I(X;Y)≤h2​(v/2)−v/2, with equality for symmetric outer input probabilities. Writing z=v/2∈[0,1/2], differentiate:
dzd​(h2​(z)−z)=log2​z1−z​−1.
(29)
The unique zero is z=1/3; strict concavity makes it the global maximum. Thus v=2/3 and
pX​=(1/3,1/3,1/3),C=h2​(1/3)−1/3=log2​(3/2).​
(30)
The optimum output is (1/6,2/3,1/6).

Every row has Shannon entropy 1, so H(Y∣X)=1 for every input law. Since the output alphabet has three symbols, Gibbs inequality gives H(Y)≤log2​3. The uniform input gives
q=(2p1​+p2​​,2p1​+p3​​,2p2​+p3​​)=(1/3,1/3,1/3),

Let the input law again be (s,t,u). The second output symbol has probability 1/2 regardless of the input, and the two remaining output probabilities sum to 1/2. Hence
H(Y)≤h2​(1/2)+21​⋅1=23​,
(33)
with equality when the first and third output symbols each have probability 1/4. The row entropies are 1,3/2,1, so
H(Y∣X)=1+2t​,I(X;Y)≤21​−2t​≤21​.
