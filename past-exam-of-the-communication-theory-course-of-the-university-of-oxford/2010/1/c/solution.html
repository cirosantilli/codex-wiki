For a one-symbol deterministic source the displayed construction assigns the empty word and gives H=EL=0. This zero-bit convention is valid when the number of source emissions is supplied separately. It is not an unframed uniquely decodable code: concatenating different numbers of empty words gives the same bit string. If positive-length unframed words are required, the shortest deterministic code has length 1, so the strict upper bound EL<H+1 requires the nontrivial-source assumption.
