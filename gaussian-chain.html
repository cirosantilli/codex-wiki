Gaussian chain (⟨eik⋅(Rn​−Rm​)⟩=e−k2b2∣n−m∣/6)

OurBigBook.com Words: 172 Articles: 1
An ideal Gaussian chain is a polymer model whose independent segment vectors have zero mean and isotropic Gaussian distribution. If ⟨∣r∣2⟩=b2, each Cartesian variance is b2/3, so a displacement across ℓ links has density (3/(2πℓb2))3/2exp[−3R2/(2ℓb2)] and characteristic function exp[−k2b2ℓ/6]. The continuous-contour version uses the same characteristic function for any contour separation. It is the large-scale limit of a freely jointed chain, while allowing unbounded Gaussian segment lengths and omitting interactions between distant parts of the chain.
