For a set function f:2V→R, the four properties are:
  • A normalised set function satisfies f(∅)=0.
  • A nonnegative function satisfies f(S)≥0 for every S⊆V.
  • A monotone set function satisfies f(A)≤f(B) whenever A⊆B⊆V.
  • A symmetric set function satisfies f(S)=f(V∖S) for every S⊆V.
Here monotone set function means nondecreasing under inclusion; it does not require strict increase.

The intersection–union definition of a submodular set function is
f(A)+f(B)≥f(A∩B)+f(A∪B)(A,B⊆V).
(1)
The diminishing returns characterization of submodularity says that its marginal increments decrease as the conditioning set grows:
Δx​f(A):=f(A∪{x})−f(A)≥f(B∪{x})−f(B)=:Δx​f(B)(A⊆B, x∈/B).
(2)
To obtain diminishing returns from submodularity, apply the intersection–union inequality to A∪{x} and B. Their intersection is A and their union is B∪{x}, giving exactly the displayed comparison.
Conversely, assume diminishing returns, and enumerate A∖B={x1​,…,xm​}. Put Cj​=(A∩B)∪{x1​,…,xj​} and Dj​=B∪{x1​,…,xj​}. Since Cj−1​⊆Dj−1​ and xj​∈/Dj−1​, summing the marginal increment comparisons gives the telescoping sum
f(A)−f(A∩B)=∑j=1m​Δxj​​f(Cj−1​)≥∑j=1m​Δxj​​f(Dj−1​)=f(A∪B)−f(B).
(3)
Rearrangement proves submodularity. When A∖B is empty, both sums are zero, so the proof includes that case.

The monotone decomposition of a submodular set function subtracts each element's smallest possible marginal increment. For x∈V, define
dx​=f(V)−f(V∖{x}),h(S)=f(∅)+∑x∈S​dx​,g(S)=f(S)−h(S).
(10)
The set function h is a modular set function: the contributions of each element, and the constant f(∅), cancel in
h(A)+h(B)=h(A∩B)+h(A∪B).
(11)
Subtracting this equality from the submodularity inequality for f proves that g is a submodular set function. Also g(∅)=0, so it is a normalised set function.
For x∈/S, the inclusion S⊆V∖{x} and diminishing returns imply
Δx​g(S)=Δx​f(S)−dx​≥0.
(12)
Adding elements one at a time now proves that g is a monotone set function. Since it starts at zero, it is also a nonnegative function. Thus f=g+h has all the required properties.
Here modular set function means equality in the intersection–union identity; a constant term is allowed. If one imposed the additional convention h(∅)=0, the claimed decomposition of an arbitrary f would require f(∅)=0. The displayed constant is essential for the problem as stated. For V=∅, take g=0 and h=f.

A matroid is a pair (X,I), where X is a finite ground set and I⊆2X is its collection of matroid independent sets, satisfying the matroid independence axioms:
  • ∅∈I.
  • If I∈I and J⊆I, then J∈I.
  • If I,J∈I and ∣I∣<∣J∣, some x∈J∖I satisfies I∪{x}∈I.
The last axiom is augmentation. In particular, every maximal matroid independent set within a given subset has maximum cardinality there: otherwise augmentation would enlarge it.

i OurBigBook.com
On fixed labelled ground sets of cardinality 1,2,3, the numbers of matroids are respectively 2,5,16.
For one element, the element is either a loop of a matroid or a nonloop, giving two choices. For two elements, rank of a matroid zero and two each give one possibility. At rank of a matroid one, the nonloops form any nonempty subset, giving 22−1=3 more possibilities: total 1+3+1=5.
For three elements, classify by the total rank of a matroid. At rank of a matroid zero every element is a matroid loop; at rank of a matroid three every subset is a matroid independent set. At rank of a matroid one, choose any nonempty subset of nonloops; exactly the empty set and their singletons are matroid independent sets. This gives seven possibilities.
At rank of a matroid two, either exactly two elements are nonloops, giving three choices for the remaining loop of a matroid, or all three are nonloops. In the latter case, pairs that are matroid dependent sets define parallel elements of a matroid. There can be no such pair, giving the uniform matroid U2,3​, or exactly one such pair, giving three choices. There cannot be exactly two such pairs: if {a,b} and {a,c} were matroid dependent sets but {b,c} a matroid independent set, augmentation from {a} to {b,c} would fail. If all three pairs were matroid dependent sets, the rank of a matroid would be one. Hence rank of a matroid two gives 3+1+3=7 examples.
Every listed possibility satisfies augmentation: the only nontrivial comparison on three elements is from a singleton to a two-element matroid independent set, and with at most one two-element matroid dependent set at least one addition works. The total is therefore 1+7+7+1=16.

Up to matroid isomorphism, the numbers for n=1,2,3 are 2,4,8. A matroid isomorphism may relabel elements but preserves which subsets are matroid independent sets.
For n=1, the loop of a matroid and the nonloop are different types. For n=2, there is one type each at rank of a matroid zero and two, and two types at rank of a matroid one, distinguished by having one or two nonloops. Thus there are four.
For n=3, the seven labelled examples of rank of a matroid one reduce to three types, distinguished by having one, two or three nonloops. The seven labelled examples of rank of a matroid two also reduce to three types: one loop of a matroid and two independent elements; no matroid loops and one pair of parallel elements of a matroid; or the uniform matroid U2,3​. Different choices of labels within each description are isomorphic. Together with the unique types of rank of a matroid zero and three, this gives 1+3+3+1=8. The rank of a matroid, number of matroid loops and presence of parallel elements of a matroid distinguish every type just listed.

The rank of a matroid on a subset A⊆X is
r(A)=max{∣I∣:I⊆A, I∈I}.​

A⊆B⟹r(A)≤r(B),r(A)≤r(A+x)≤r(A)+1.

We first justify the submodularity of matroid rank, which will also support later arguments. Choose a maximal matroid independent set I0​ in A∩B, extend it to a maximal matroid independent set IA​ in A, and then to one IU​ in A∪B. These extensions exist by successive additions, and their sizes are the respective values of the rank of a matroid. No element of IU​∖IA​ lies in A: such an element could have been added to IA​, contradicting maximality in A. Therefore I0​∪(IU​∖IA​) is an independent subset of B, giving
r(A∩B)+r(A∪B)−r(A)≤r(B).
(15)
Now let Y⊆Z and x∈σ(Y). If x∈Z, then x∈σ(Z) by (ii). Otherwise apply submodularity of matroid rank to Y+x and Z, whose intersection is Y:
r(Z+x)+r(Y)≤r(Y+x)+r(Z)=r(Y)+r(Z).
(16)
The monotonicity of the rank of a matroid supplies the opposite bound r(Z+x)≥r(Z), so equality holds. Thus x∈σ(Z), proving σ(Y)⊆σ(Z).

Use Tutte's theorem on perfect matchings: a finite graph has a perfect matching if and only if, for every S⊆V, the number q(S) of connected components of a graph of odd integer order in G−S is at most ∣S∣.
First, the handshaking lemma gives 3∣V∣=2∣E∣, so ∣V∣ is an even integer. Fix S=∅. For each connected component of a graph C of odd integer order in G−S, let d(C) count its edges to S. Counting vertex degrees inside C gives
3∣C∣=2∣E(C)∣+d(C).
(21)
Thus d(C) is an odd integer; it is positive because G is a connected graph. If d(C)=1, its unique outgoing edge is a bridge. Distinct such components yield distinct bridges, so there are at most two of them. Every other such component has d(C)≥3. Therefore
3q(S)−4≤∑C:∣C∣ odd​d(C)≤3∣S∣.
(22)
The last inequality holds because each vertex of S has vertex degree three. Furthermore,
q(S)≡∣V∖S∣≡∣S∣(mod2),
(23)
since components of even integer order do not affect parity, and ∣V∣ is an even integer. If q(S)>∣S∣, this parity forces q(S)≥∣S∣+2, contradicting the bound 3q(S)≤3∣S∣+4.
For S=∅, the only component is the whole connected graph, of even integer order, so q(∅)=0. Thus every S satisfies the criterion, and G has a perfect matching. This proves the perfect matching theorem for a cubic graph with at most two bridges directly from Tutte's theorem on perfect matchings.

Choose a perfect matching M from (i). Every vertex has exactly two incident edges in E∖M, so this spanning subgraph is a disjoint union of graph cycles. Orient each graph cycle cyclically, and let s(v) be the next vertex after v along its oriented graph cycle.
For each uv∈M, take the three-edge sequence
s(u), u, v, s(v).
(24)
Its four vertices are distinct. Each s(u)=u and s(v)=v because the graph is a simple graph. Also s(u)=v and s(v)=u, since uv belongs to M, rather than E∖M. Finally s(u)=s(v) because the successor map s is a bijection on the disjoint graph cycles. Thus this is a graph path of length exactly three.
Every edge of M is used once as a middle edge. Every edge of E∖M is used once as the outgoing edge of its tail, whose unique edge of M determines which graph path contains it. Hence these graph paths are pairwise edge-disjoint and cover E. This is the three-edge path decomposition from a perfect matching.

The sharp approximation algorithm factor is c=2. Charge each edge e of an optimal maximum-weight matching Mo​ to an edge of the greedy matching Mg​. If e∈Mg​, charge it to itself. Otherwise it was rejected because a previously selected edge g∈Mg​ shared an endpoint; charge e to one such g. Since the scan is in nonincreasing weight order, w(e)≤w(g).
Each g∈Mg​ receives at most two charges, since each of its two endpoints meets at most one edge of the matching in a graph Mo​. If g∈Mo​, only its own charge is possible. Thus
w(Mo​)≤2w(Mg​).​
(26)
This inequality also covers the edgeless graph, for which both weights are zero and the displayed ratio in the question is undefined.
For tightness, take a four-vertex path graph with weights 1,1+ε,1 in order, where 0<ε<1. The greedy matching chooses only the middle edge, of weight 1+ε, whereas the optimal matching in a graph chooses both outer edges, of total weight 2. Hence
w(Mg​)w(Mo​)​=1+ε2​⟶2(ε↓0).
(27)
To obtain infinitely many different sizes, for each k≥2 take k disjoint copies with ε=1/k. Their weights add, so their ratio is 2/(1+1/k)→2. All weights are strictly positive, and the middle edge is uniquely heaviest in each copy. With all three weights equal to 1, a permitted tie order selecting each middle edge first attains ratio 2 exactly. The greedy two-approximation for maximum-weight matching is therefore best possible.

Assume G has no isolated vertex; otherwise an edge cover does not exist. In particular, a one-vertex connected graph is an excluded degenerate case of the statement.
Let M be a maximum cardinality matching, of size m(G), and let U be its unmatched vertices in a matching. There is no edge joining two vertices of U, since adding it would enlarge M. Choose one incident edge for each u∈U. These chosen edges are distinct and outside M, so together they form an edge cover of size
m(G)+∣U∣=m(G)+∣V∣−2m(G)=∣V∣−m(G).
(28)
Consequently e(G)≤∣V∣−m(G).
For the opposite bound, let F be a minimum-cardinality edge cover. It is inclusion-minimal. Every selected edge has an endpoint of vertex degree one in (V,F): otherwise deleting that edge would leave both endpoints covered. Each connected component of a graph of (V,F) is therefore a star graph. To see this, a component can have at most one vertex of vertex degree greater than one; a shortest graph path between two such vertices would contain an edge whose endpoints both have vertex degree greater than one. A component with no such vertex is a single edge, also a star graph.
If there are t such star graphs, each has one fewer edge than vertices, so ∣F∣=∣V∣−t. Select one edge from each component to get a matching in a graph of size t. Hence m(G)≥t=∣V∣−e(G), proving the edge cover and matching identity
e(G)+m(G)=∣V∣.​
(29)

B=∑v∈V​cv​,p(uv)=cu​+cv​−w(uv).

FM​=M∪{ev​:v is an unmatched vertex of M}.

w(FM​)≤w(M)+∑v unmatched​cv​=B−∑e∈M​p(e).

To prove optimality, take a minimum-weight edge cover and remove redundant edges until it is inclusion-minimal. Nonnegative weights ensure that its weight does not increase, so it remains optimal. As proved in (i), its components are star graphs. Choose one edge from each star graph, forming a matching in a graph N.
In a star graph with center a, selected leaf b, and other leaves L, this choice contributes w(ab)+∑v∈L​cv​ to B−p(N). Each other leaf v has its edge av available, so cv​≤w(av). Thus this contribution is at most the weight of that star graph. Summing over components yields
B−p(N)≤OPT.
(33)
Since M maximizes saving, p(M)≥p(N), and consequently
OPT≤w(FM​)≤B−p(M)≤B−p(N)≤OPT.
(34)
All inequalities are equalities. Therefore FM​ is a minimum-weight edge cover. This proof also handles zero weights and duplicate cheapest-edge choices.
Finding all cv​ and constructing FM​ takes O(∣V∣+∣E∣) time. A general-graph maximum-weight matching polynomial-time algorithm supplies the only substantial step; the documented routine runs in O(∣V∣3) arithmetic time. Exact rational or integer weights avoid floating-point comparisons affecting optimality.[ref]
