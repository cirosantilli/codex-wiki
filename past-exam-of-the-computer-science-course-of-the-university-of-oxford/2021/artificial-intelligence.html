All three variants are complete search algorithms under the usual finite-branching factor, nonnegative-heuristic function assumptions. Here 0≤h≤h∗, with zero at goals; the supplied positive lower bound on step costs is also essential. The root is processed once before a parent-dependent priority is needed.[ref] Completeness means finding a solution if one exists, not necessarily terminating when none exists.
Fix a finite solution path. Every search node on that path has a finite priority, so let K bound all of its relevant priorities. For ordinary A-star search and the second variant, the priority is at least g(n). Thus any search node with priority at most K has depth at most ⌊K/ϵ⌋. In the third variant the priority is at least g(n′), so its depth is at most ⌊K/ϵ⌋+1. A finitely branching search tree has finitely many search nodes at these depths. Therefore finitely many earlier search nodes can delay each successive search node on the chosen solution path; eventually its goal is generated or selected, as appropriate.
Moving the goal test to generation cannot destroy that existence guarantee, although it can destroy optimality. Likewise the altered parent-dependent priorities remain bounded below by the accumulated cost to the search node or its parent, which is enough for this completeness argument. If “admissible” were interpreted to allow arbitrarily negative estimates, the lower-bound argument would need an additional hypothesis; the conventional nonnegative interpretation is being used explicitly. For the literal upper-bound-only interpretation, all three can fail completeness: attach an infinite unit-cost dead-end chain with g(nd​)=d and h(nd​)=−2d beside a finite goal branch beginning with a cost-3 edge and estimate zero. Its successive low priorities can starve the finite branch. Every negative chain estimate is still at most its infinite true remaining cost.

None of the three variants is an optimal search algorithm in general. The following single search tree supplies counterexamples for all three. Its heuristic function is nonnegative, admissible and even a consistent heuristic.
The least-cost goal is G4​, reached at cost 1+3=4; the other goal G5​ costs 5. Assign h(S)=0, h(P)=3, and zero to both goals. For the first variant, expanding S generates G5​ and immediately returns it, before P can be expanded. A goal test at generation therefore returns cost 5.
For priority g(n)+h(n′), the root's children have priorities 1 for P and 5 for G5​. Expanding P generates G4​ with priority 4+3=7. The algorithm next selects G5​, again returning cost 5.
For priority g(n′)+h(n), the root's children instead have priorities 3 for P and 0 for G5​. The suboptimal goal is selected immediately. The example uses no tie-breaking assumption. In contrast, ordinary A-star search with its goal test on selection compares the genuine estimated total costs and returns G4​.

Maintain a certified solution-cost ceiling and prune only search nodes whose lower bound strictly exceeds it. Initially let B=∞, or set B=u(r) at the root r when that value is finite. Whenever a search node n is generated, update
B←min{B, g(n)+u(n)}.
(1)
Run ordinary A-star search with f(n)=g(n)+h(n) and a goal test when removing a search node from the search frontier. Discard a generated search node, or a queued search node encountered after a later bound improvement, if
f(n)>B.​
(2)
This is branch and bound using a lower bound f and an upper bound B. A finite u(n) certifies that some goal is reachable from n within that remaining-cost ceiling; for a dead end, h∗(n)=∞ forces u(n)=∞ too. Every finite quantity g(n)+u(n) is consequently at least the global optimum C∗.
On an optimal solution path, admissible heuristic estimates ensure f(n)≤C∗≤B. Hence no search node of that path is pruned. The finite-branching factor and positive step-cost hypotheses from (a) still ensure completeness, and the usual A-star search argument makes the first selected goal optimal. A smaller bound can remove branches earlier; it need not improve every instance.
The strict inequality matters: u is only a numerical bound and need not provide an actual stored solution path. If B=C∗, pruning at f(n)≥B could remove every optimal continuation. Nor may the algorithm return a path merely because its lower bound meets B when no witnessing path has been constructed. With an actual incumbent solution, the familiar equality-pruning variant can instead retain and return that incumbent.

The comparator alone cannot generally reproduce informed A-star search priorities. A valid weaker fallback is uniform-cost search, namely A-star search with h=0. The issue is that ordering h∗(n) and h∗(m) does not supply the numerical difference needed to compare g(n)+h∗(n) with g(m)+h∗(m).
For example, take accumulated costs g(n)=5, g(m)=1. Remaining costs h∗(n)=1, h∗(m)=2 rank n ahead under κ but give total estimates 6 and 3, so informed A-star search selects m. Remaining costs 1 and 10 give the same pairwise comparator ranking but totals 6 and 11, selecting n. Thus the comparator's ordering cannot simply replace the cardinal heuristic function inside f=g+h.
If “do A-star search” includes choosing any available admissible heuristic, set it identically to zero and prioritize by the known accumulated cost g. Apply the goal test on removal from the search frontier. This is complete and optimal under the stated finiteness and step-cost assumptions, but it does not recover the unavailable perfect-heuristic function ordering or its search reduction. The distinction is between implementing the informed priority from κ and retaining the algorithm's guarantees through this uninformed special case.

Minimax search applies because this is a finite, deterministic two-player zero-sum game with perfect information. Each move assigns a previously unassigned Boolean variable, so play terminates after exactly N moves. Both players observe the whole partial Boolean valuation, and there are no chance moves. Give terminal positions payoff +1 when the propositional formula is true and −1 when it is false, measured for A. At an A-node take the maximum child value and at a B-node the minimum. Backward induction then computes the winner and a corresponding winning strategy.

For N≥3, depth and history-tree size can be infinite, while a sufficient finite state bound is 2⋅5N. The number of possible completed histories also becomes unbounded. With variables p,q,r, first let A assign p and B assign q. Both can then keep flipping their own variable, leaving r unassigned. After four such flips the same assignment, ownership and player-to-move recur. Arbitrarily many repetitions can precede assignment of r, so there are infinitely many distinct finite complete histories as well as legal infinite plays.
A state must now record ownership: for each variable the possibilities are unassigned, A-owned false, A-owned true, B-owned false, and B-owned true. Include the player to move, since flips break the old link between turn parity and the number assigned. This gives
∣V∣≤2⋅5N.​
(5)
Many encoded positions are unreachable, so this is an upper bound. Each nonterminal state has at most 2N legal moves: two assignments per unassigned variable and one flip per variable owned by the acting player. Thus the finite directed graph has at most 2N∣V∣ edges even though its unrolled game tree is infinite. The 2N possible final Boolean valuations are unchanged, but they no longer count distinct plays or complete ownership states. For N=1,2, no player gets a legal opportunity to flip before all variables are assigned, so the original finite bounds still apply.

Solve the finite state graph by winning-set fixed-point iteration, treating positions outside both winning regions as draws. A naive recursive minimax search over histories may run forever around a cycle. Store each ownership-sensitive state once, with a player-to-move flag and all legal successors.
Let TA​ and TB​ be terminal states where the propositional formula is true and false, respectively. Initialize WA0​=TA​. Repeatedly add nonterminal positions as follows:
WAk+1​=WAk​∪{s controlled by A:∃s′∈Succ(s), s′∈WAk​}∪{s controlled by B:Succ(s)⊆WAk​}.
(6)
For WB​, start at TB​ and exchange the players in the existential and universal conditions. Terminal states keep their original labels and are excluded from these predecessor rules, avoiding a vacuous all-successors test at a terminal loss. Each process stabilizes after at most ∣V∣ strict growth steps; predecessor counters implement both regions via the winning-position attractor in an infinite game construction in O(∣V∣+∣E∣) graph time.
The admission round supplies a decreasing rank. At a state controlled by the winning player, choose a successor of smaller rank; at an opposing state, every successor already has smaller rank. Hence these strategies force a finite terminal win. The two winning regions are disjoint. Outside both, each player can keep the play outside the opponent's winning region, so neither can force a terminal win against best defence. Under the convention in (h), assign those remaining positions value 0; the other regions have values +1 and −1.
This is a finite reachability game calculation, with memoryless strategies read from successor choices. Merely calling the first back-edge encountered a draw is unsound: a cycle can have an exit through which one player can force a win.

A sufficient sequential bound is Tmax​=4m+2 for any physically valid initial and goal states, assuming every bucket is directly reachable. A goal must be consistent with the stated one-hand and one-location invariants. No bound can guarantee a satisfying plan for an inconsistent goal, such as requiring the same ball in two buckets simultaneously.
Here is a constructive bound independent of the number of buckets. If the hand initially holds a ball, drop it in the current bucket, costing at most one action. For each ball that should end in a bucket, move to its current bucket, pick it up, move to its target bucket, and drop it: at most four actions per ball, omitting unnecessary actions. If the final state requires a held ball, reserve it for last, move to its current bucket and pick it up, costing at most two more actions. Finally move the arm to its prescribed final location, costing at most one action.
If the final hand is empty, this costs at most 1+4m+1=4m+2. If it holds a ball, only m−1 balls need bucket placement, giving at most 1+4(m−1)+2+1=4m for m≥1. Thus the common bound is valid. A partially specified, physically consistent goal can first be completed to a valid target state. For the special goal of putting all balls in one bucket with no specified final arm location, 4m is already a sufficient bound.
A separate finite-state check is available: physically valid configurations number
∣S∣=n(nm+mnm−1)=nm(n+m),
(15)
counting an empty hand or the choice of a held ball, and the arm's location. A shortest plan never repeats a state, so ∣S∣−1 also bounds a shortest solution whenever one exists. The constructive bound is much smaller.
For an encoding requiring a fixed horizon, permit idle layers, or run SATPlan through all horizons up to the bound. A plan shorter than Tmax​ need not be padded by arbitrary physical actions. The sequential bound also suffices for a parallel encoding, since a serial plan is a permitted special case.

Use backward deletion of achieved goal requirements; this decides precondition-free ground STRIPS planning in polynomial time. Let I be the initial set of true facts, G the positive conjunctive goal set and A the ground actions. Assume the usual disjoint add and delete lists; if both lists contain a fact, first normalize the net effect according to the action semantics.
Maintain residual goal set R=G and an initially empty list L. While R⊈I, look for an action a satisfying
Del(a)∩R=∅,Add(a)∩R=∅.​
(19)
If no such action exists, reject. Otherwise record a in L and replace R by R∖Add(a). When R⊆I, return the actions in reverse order of recording. All actions are applicable because their precondition sets are empty.
For soundness, the selected action can be put last in a plan for the current residual goals: it supplies the removed goals and deletes none of the goals still being required. Reversing all recorded selections makes the final state satisfy the original G.
For completeness, suppose R is not already satisfied initially but a plan achieves it. Consider the last action in that plan that changes any fact of R. Its effective changes cannot delete any member of R, because no later action repairs it; it must add at least one member. Thus a candidate exists. Moreover any candidate chosen by the algorithm is safe: removing some requirements gives a subset of R, so a plan for R, if one exists, also establishes the smaller goal set. Appending the chosen last action then restores the removed requirements without harming the rest. Mathematical induction therefore preserves solvability during all choices.
Each successful iteration removes at least one residual goal, so there are at most ∣G∣ iterations and the returned plan has at most ∣G∣ actions. Scanning all actions and their effect lists per iteration is polynomial in the input size, for example O(∣G∣∣A∣∣P∣) with simple fact-set representations over P. Merely taking the union of all add effects would be unsound, since actions can delete each other's achievements. This algorithm is the last-achiever algorithm for precondition-free planning.
