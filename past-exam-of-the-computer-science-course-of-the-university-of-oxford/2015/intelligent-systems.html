Let V be the set of Boolean variables occurring in T or the initial query Q, and put N=∣V∣. Represent a current query by a subset R⊆{¬p:p∈V}: the Boolean literals in this set are the outstanding obligations. The initial state is R=Q, and the goal test is R=∅.
An action chooses a Horn clause C∈T with positive Boolean literal p, provided ¬p∈R. Its search transition model is precisely the given resolution inference rule:
R⟼R′=(C∪R)∖{p,¬p}.
(1)
Thus it removes the obligation ¬p and inserts all negative Boolean literals of C. Repeated Boolean literals merge because queries are sets. A Horn clause without a positive Boolean literal supplies no action under the rule specified in this paper; it must not be treated as an additional way of finishing the query.
Give every action unit cost. A graph path with ℓ actions gives a proof containing ℓ+1 queries, so minimizing either quantity gives the same shortest proof. Uniform-cost search orders the search frontier by the number of actions already taken and applies the goal test when removing a search node for expansion. Recording parent actions reconstructs the proof.
There are at most two choices, present or absent, for each of the N negative Boolean literals. Therefore
c(R,C,R′)=1,∣S∣≤2N.​
(2)
This bounds the state space, including the empty query, rather than the possibly infinite search tree of action histories.[ref]

A-star search is best-first search with priority
f(u)=g(u)+h(s(u)),0≤h(s)≤h∗(s),h(goal)=0.​
(3)
Here u is a search node, s(u) is its state, g(u) is its accumulated path cost, and h∗(s) is the minimum remaining cost to any goal state, interpreted as ∞ if no goal is reachable. The inequality defines an admissible heuristic. Thus f(u) is a lower bound on the cost of any solution extending that particular action history.
Initialize the search frontier with the root. Repeatedly remove a search node of least f, apply the goal test, and, if it is not a goal, insert its applicable-action children with their updated g and f. In tree search, different action histories remain distinct search nodes even when they reach the same state; there is no global visited-state set.
For the finite branching factor and unit costs here, an admissible heuristic ensures that any first goal removed is optimal. If a cheaper solution existed, the search frontier would contain an unexpanded prefix of it with f at most that cheaper cost, contradicting selection of the more expensive goal. Nonnegative h also means only finitely many search nodes can have f below any fixed finite cost, so a finite solution will eventually be reached. This does not guarantee termination when no proof exists.

Termination is not guaranteed. Take
Q={¬p},T={{p,¬q},{q,¬p}}.
(4)
Both members of T are valid Horn clauses with distinct underlying Boolean variables. The only possible continuation alternates
{¬p}⟼{¬q}⟼{¬p}⟼⋯.
(5)
The empty query is unreachable. With the admissible heuristic h=0, ordinary A-star search keeps generating the next search node forever, despite there being only two reachable states.
A modification requiring no additional stored state collection is to impose the known search depth bound
L=2N−1,do not expand a non-goal node with g=L.​
(6)
The unit-cost g already stored by A-star search is also its search depth; the bound is a scalar computed from the input, not a closed set. Apply the goal test before refusing expansion at the bound.
To prove completeness of this modification, remove any segment between two equal states in a successful proof. The successor choices after the later occurrence are available at the earlier occurrence because the search transition model depends only on the current query. Repeating this removal gives a proof with no repeated states, hence at most 2N−1 actions. In particular, a shortest proof never needs a repeated state, since every removed segment has positive cost. The depth restriction therefore preserves a shortest proof whenever one exists.
The restricted search tree has finite depth and finite branching factor, so it is finite. A-star search must then either remove a goal or exhaust the search frontier and report failure. Its existing search frontier may still be large; the modification saves a separate visited-state collection, not all storage used by tree search.

∣R′∣≥∣R∣−1.

Use the shortest path distances in the directed dependency graph to define
h2​(R)={0,max{∣R∣, 1+max¬p∈R​dG​(p)},​R=∅,R=∅.​​
(9)
The additional 1 counts the final use of a positive unit Horn clause, which corresponds to a fact rather than an edge of G.
To justify the new lower bound, consider any complete proof from R and fix ¬p∈R. At some step this obligation must be removed using a Horn clause with head p. If that Horn clause is the fact {p}, we have already found a dependency graph path of length zero ending at a fact. Otherwise select one negative body Boolean literal ¬q. Immediately after the step it belongs to the query, whether newly inserted or merged with an existing obligation. It must subsequently be removed. Record the edge p→q and repeat this argument at its later removal.
The selected removal times strictly increase. Since the proof is finite and ends with no obligations, this chain eventually uses a fact. A proof of ℓ actions therefore produces a dependency walk of at most ℓ−1 edges from p to a fact. Removing any cycles from that walk gives dG​(p)≤ℓ−1. Hence 1+dG​(p)≤ℓ for every initial obligation. If dG​(p)=∞, no such proof exists. Combining this bound with the admissible heuristic ∣R∣ by taking their maximum preserves admissibility.
For a strict improvement, use
T={{p,¬q},{q,¬r},{r}},R={¬p}.
(10)
Here dG​(p)=2, so h1​(R)=1 while h2​(R)=3. The three successive obligations are ¬p,¬q,¬r, followed by the empty query, so the improved bound is exact.
Do not sum all the values 1+dG​(p) without an additional argument: different obligations may share work. For example, with T={{p,¬r},{q,¬r},{r}}, the query {¬p,¬q} takes three actions, while that sum would be four.

When the values of several admissible heuristics are already available, choose their maximum:
h(R)=imax​hi​(R).​
(11)
Every hi​(R)≤h∗(R), so their maximum is still an admissible heuristic. It has heuristic dominance over their minimum and their arithmetic average, which are also admissible heuristics but give no larger lower bound. Thus the maximum supplies the most informative generally valid choice among these alternatives.
Their sum can overestimate by counting the same remaining action repeatedly. If two heuristic functions both give the exact value 1 at a state one action from the goal, their sum gives 2. A valid sum requires extra structure such as dividing each action's cost between the component estimates; admissibility of the components alone does not provide that structure.
Larger admissible values reduce the region g+h<C∗ that A-star search must expand before an optimal solution of cost C∗ can be removed. This is a statement about heuristic dominance, not a strict claim about running time under every tie-breaking rule or evaluation cost.

Use two STRIPS action schemas, for a destination topped by a coin and for an empty destination. In both, x is a coin, s,t are distinct stack constants, and y is either a different coin or g. In the first, z is a coin distinct from x and, when y is a coin, also distinct from y. These are restrictions on action grounding, so no new type or inequality predicates are needed.
For MoveToCoin(x,y,z,s,t), use
Pre=Del=Add=​{Topmost(x,s),OnTop(x,y),Topmost(z,t),Smaller(x,z)},{Topmost(x,s),OnTop(x,y),Topmost(z,t)},{Topmost(y,s),OnTop(x,z),Topmost(x,t)}.​
(15)
For MoveToEmpty(x,y,s,t), use
Pre=Del=Add=​{Topmost(x,s),OnTop(x,y),Topmost(g,t)},{Topmost(x,s),Topmost(g,t)}∪{{OnTop(x,y)},∅,​y=g,y=g,​{Topmost(y,s),Topmost(x,t)}∪{{OnTop(x,g)},∅,​y=g,y=g.​​
(16)
The last cases are a compact notation for two ordinary action schemas, one with y a coin and one with y=g. In the second case, OnTop(x,g) already holds and is left unchanged: the same ground object represents the base of every stack. Its stack identity is carried by Topmost, so moving a singleton stack to an empty location still changes two top markers even though its support remains g.
Each ground action applies only if Pre⊆S and updates the STRIPS state by
S′=(S∖Del)∪Add.​
(17)
The preconditions require the moved coin to be exposed and the destination to be either exposed or empty. A coin destination additionally requires the moved coin to be smaller. The delete list removes its old support relation when that support changes, removes its old source-top marker, and removes the destination's old top marker. The add list exposes its former support and installs it as the destination top.
To prove that no incorrect plans arise, induct on the action history. Initially every coin has exactly one support; the stacks are disjoint decreasing chains ending at g; and each stack has exactly one correct top marker. An applicable action removes just the top coin from one such chain and attaches it to a different chain, or creates a singleton chain. The size precondition preserves decreasing order; distinct stack parameters prevent moving onto one's own stack; and updating both top markers preserves their accuracy. The unchanged chain segments retain their support relations. These planning state invariants therefore hold after every action. Only the k named stacks can be used, enforcing the stack limit.
Conversely, every legal physical move has a source top x, a uniquely determined former support y, and either an empty target or a target top z larger than x. The corresponding ground action has exactly these preconditions and effects. Thus the encoding permits all legal moves and preserves physical legality from the initial state.[ref]

In terms of minimum plan length, allowing more stacks can only help:
L∗(n,k+1)≤L∗(n,k).​
(19)
Every legal plan using at most k stacks remains legal with k+1 available: simply ignore the new stack. The inequality need not be strict. For n=1, one move suffices for every k≥2.
With k≥n+1, put each of the n−1 smaller coins on its own spare stack, move the largest coin to the destination, and then place the smaller coins on it in decreasing size order. This uses 2n−1 moves. Every smaller coin must leave the initial stack before the largest coin's first move. It cannot move just once directly to the final stack and stay there, since that would block the largest coin's eventual arrival. Thus each smaller coin requires at least two moves, while the largest coin requires at least one. Hence
L∗(n,k)=2n−1(k≥n+1).
(20)
Compared with the three-stack value 2n−1, the physical task can therefore become substantially easier.
The difficulty of finding an optimal plan is a different issue. Each legal state is determined by assigning every coin to one of the k labelled stacks, whose size order is then forced. There are kn such assignments, so the state space and possible branching factor grow with k. An uninformed search algorithm can therefore face more alternatives even when the optimal plan becomes shorter. Likewise, a simple recursive strategy for three stacks need not immediately supply the best strategy with more stacks. The defensible answer is that the required number of moves never increases, while computational search effort need not decrease.

Two general constructions are delete-relaxation heuristics and abstraction heuristics. Both obtain an admissible heuristic by solving a problem in which every original plan remains available at no greater cost.
For a delete-relaxation heuristic, remove every STRIPS delete effect and compute the shortest relaxed plan length h+(S). A relaxed action never makes a true fact false. Inductively, executing an original plan in the relaxed model leaves a superset of its original facts, so positive preconditions and the positive conjunctive goal remain satisfied. Therefore
h+(S)≤h∗(S).​
(21)
The exact relaxed optimum can itself be expensive to find; merely taking the length of an arbitrary relaxed plan does not guarantee an admissible heuristic. One can instead use a proven lower bound on the relaxed optimum.
For this coin encoding, removing delete effects loses the requirement to free an occupied stack and the requirement to destroy and later rebuild support relations. From the initial state, relaxed moves can successively move c1​,c2​,…,cn​ from s1​ to s2​ using the empty-destination action: Topmost(g,s2​) is never deleted, and exposing each next source coin is still allowed. The original support-chain goal facts are never deleted either. After these n actions, Topmost(g,s1​) and Topmost(c1​,s2​) also hold, so the entire goal from part (a) holds. Thus h+(I)≤n, showing why this relaxation misses much of the exponential work needed with three stacks.
For an abstraction heuristic, project states onto selected information and project each action onto its effect on that information. Forgetting a selected collection of planning fluents, and their preconditions and goals, gives one general construction for STRIPS. Define the abstract transition relation to include every projected original transition, with cost at most the original cost. The exact abstract distance is then a lower bound because any original goal-reaching graph path projects to an abstract goal-reaching walk:
habs​(S)≤h∗(S).​
(22)
For the coin puzzle, a useful state abstraction remembers the stacks occupied by a chosen subset of coins and ignores the other coins, contracting the support chains past ignored coins. Moving an ignored coin leaves the abstract state unchanged; moving a retained coin is a legal move in the smaller Tower of Hanoi instance. Precomputing exact abstract goal distances gives a pattern database. This can retain stacking and spare-stack restrictions that the delete-relaxation heuristic loses. Larger retained subsets give potentially stronger information but require more storage and preprocessing. Maxima of these admissible heuristics remain safe; unqualified sums can double-count moves.

Always true. Replace every all-different constraint by the pairwise inequalities on its scope. Then solutions are precisely the proper graph colourings of the primal graph using values from D as colours. Put t=tw(P).
A graph of treewidth t has a proper graph colouring with at most t+1 colours. Here is a constructive proof. In a width-t tree decomposition, remove any leaf bag contained in its neighbor. If more than one bag remains, a leaf bag has a vertex absent from its neighbor. The running-intersection property means that vertex occurs only in the leaf bag, so every neighbor of the vertex belongs to that bag. It has at most t neighbors. If only one bag remains, it has at most t+1 vertices and the same degree bound holds.
Remove the chosen vertex and repeat; deleting vertices cannot increase the width of the restricted tree decomposition. Now colour in reverse removal order. At most t already coloured neighbors forbid colours, so one of t+1 colours is always available. Since the integer inequality ∣D∣>t gives ∣D∣≥t+1, this produces a satisfying assignment:
∣D∣>tw(P) ⟹ Sol(P)=∅.​
(35)
The common unrestricted constraint domain and the exclusively all-different constraints are essential: arbitrary constraint relations do not reduce to graph colouring in this way.
