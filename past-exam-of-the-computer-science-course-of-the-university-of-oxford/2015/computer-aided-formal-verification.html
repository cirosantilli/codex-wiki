Follow the binary decision diagram from its top decision node to a terminal node, choosing the outgoing arrow specified by each tested Boolean variable. If x=0, the left y decision node returns y, independently of z. If x=1, the right y decision node returns one when y=1 and otherwise returns z. Thus the truth table, with rows in the order (x,y,z), is:

Splitting the Boolean function according to the first tested Boolean variable gives
f=(¬x∧y)∨(x∧((¬y∧z)∨y)).
(1)
The identity y∨(¬y∧z)=y∨z follows by considering y=0 and y=1. Using it and distributing Boolean conjunction over Boolean disjunction,
f=(¬x∧y)∨(x∧y)∨(x∧z)=y∨(x∧z)​.
(2)
The first two terms combine to y because x∨¬x=1. This also explains the truth table: y=1 always makes the output one, while with y=0 the output is one exactly when both x and z are one.

A reduced ordered binary decision diagram is obtained by sharing equal terminal nodes, removing a decision node whose two children are equal, and sharing decision nodes with the same tested Boolean variable and the same ordered pair of children. Apply these rules to the binary decision tree in part (c) as follows.
  • Merge the three zero terminal nodes into one zero terminal node, and merge the five one terminal nodes into one one terminal node.
  • At (z,y)=(0,0) the x decision node has children (0,0). Remove it and redirect its incoming arrow to zero.
  • At (z,y)=(0,1) and (z,y)=(1,1) the two x decision nodes each have children (1,1). Remove both and redirect their incoming arrows to one.
  • The remaining x decision node, at (z,y)=(1,0), has children (0,1), so retain it.
  • The y decision node under z=0 now has children (0,1), while the one under z=1 has children (x,1). These are different, so neither can be merged or removed. The top z decision node also has different children.
The left panel below is therefore the resulting reduced ordered binary decision diagram. Its full description is
Decision nodeTestZero childOne child
rzuv
uy01
vyw1
wx01
There are 4+2=6​ vertices: four decision nodes and two terminal nodes.
The original binary decision diagram also has four decision nodes and two terminal nodes, and is already reduced for x<y<z: the two y decision nodes have different children and no decision node has two equal children. Thus reversing the order has not made this example smaller. Indeed y∨(x∧z) is unchanged by interchanging x and z, and the new binary decision diagram is the original one with those two labels exchanged. The uniqueness of a reduced ordered binary decision diagram applies to a fixed variable ordering of a binary decision diagram; it does not assert that every ordering has the same size.

Choose the variable ordering of a binary decision diagram y<x<z. The Boolean cofactor with y=1 is the constant one, while the Boolean cofactor with y=0 is x∧z. Consequently the right panel in part (d) has the following arrows:
y: (0→x, 1→1),x: (0→0, 1→z),z: (0→0, 1→1).​
(3)
Here an entry such as 0→x denotes the zero arrow to the x decision node. There are 3+2=5​ vertices: three decision nodes and two terminal nodes, saving one decision node relative to either of the previous orderings. Testing y first is effective because its one branch settles the entire Boolean function immediately. The ordering y<z<x works equally well.
This is also minimal among ordinary binary decision diagrams for this Boolean function. Each Boolean variable is essential: setting y=0,z=1 leaves f=x; setting y=0,x=1 leaves f=z; and setting x=z=0 leaves f=y. If a Boolean variable were never tested, the represented Boolean function could not depend on it. Thus at least three decision nodes are necessary, and the construction attains that bound.

A transition relation requires an explicit interpretation of the Boolean variables as current and next state bits. Take the four states q00​,q01​,q10​,q11​. Encode the current state by (u,x) and the next state by (y,z), and define
qux​→qyz​⟺R(u,x,y,z)=y∨(x∧z)=1.​
(4)
The extra current bit u is deliberately unused by the Boolean formula. A four-state transition system normally needs four bits to describe a pair of states; a Boolean formula using only three of them simply describes a transition relation independent of the fourth bit.
When x=0, the condition is y=1, so the permitted next states are q10​ and q11​. When x=1, the condition is y∨z, so the permitted next states are q01​,q10​,q11​. The resulting adjacency matrix, with rows and columns both ordered q00​,q01​,q10​,q11​, is
AR​=​0000​0101​1111​1111​​.
(5)
The directed graph below plots all ten directed edges, including the three self-loops. No arrow enters q00​, but it is a valid state with two outgoing arrows. Every state has a successor. As permitted, no initial states are distinguished.

a OurBigBook.com
Use the two incoming initial arrows in the source figure: I={s0​,s3​}. An atomic proposition is true precisely at the states whose displayed labels contain it. In particular, c is false at every state. Hence GF¬c is true on every infinite path in a transition system, and the first implication in the fairness assumption imposes no restriction.
Write p=a∧b. The remaining implication is FGp→GF¬b. By the linear temporal logic duality ¬FGp=GF¬p, it is equivalent to
GF¬p∨GF¬b=GF¬p,
(6)
since ¬b implies ¬p. Thus a path is fair exactly when it visits states not labelled with both a and b infinitely often. This condition also follows directly: if p eventually holds forever, then b eventually holds forever and the required GF¬b is impossible; if p does not eventually hold forever, the implication has a false antecedent.
Every initial path in a transition system in the upper component either alternates forever between s0​ and s1​, or makes finitely many alternations and then stays at s2​. These are all fair: the first visits s1​ infinitely often, and the second visits s2​ infinitely often; neither state satisfies a∧b.
In the lower component, a path in a transition system can stay at s3​ forever, or leave it after finitely many visits and pass through s4​ to s5​. The constant path in a transition system s3ω​ is unfair because a∧b holds forever while ¬b never holds. Every departing path in a transition system is fair because s5​ satisfies neither a nor b. Here vω means infinite repetition of the finite word v. Therefore
FairPaths(TS)=​{(s0​s1​)ω}∪{(s0​s1​)ns2ω​:n≥1}∪{s3m​s4​s5ω​:m≥1}.​​
(7)
This notation lists initial paths in a transition system. If one instead allows arbitrary starting states, their suffixes starting at s1​,s2​,s4​,s5​ are fair as well; the fair paths in a transition system from each initial state, and hence all verdicts below, are unchanged.

Denote the three families found in part (a) by A=(s0​s1​)ω, Bn​=(s0​s1​)ns2ω​ and Cm​=s3m​s4​s5ω​, where n,m≥1. All are fair paths in a transition system. The verdicts are
(TS⊨fair​φi​)i=16​=(false,false,false,false,true,false).​
(8)
Each verdict follows from the infinite path in a transition system semantics, rather than from a finite prefix alone.
For φ1​=FGa, take C1​=s3​s4​s5ω​. From s4​ onwards, a is always false, so there is no time after which a is always true. Therefore the first specification fails, with fair counterexample C1​. The path in a transition system A is another fair counterexample, because it encounters s1​, where a is false, infinitely often. Each Bn​ does satisfy FGa, since s2​ satisfies a forever.
For φ2​=(X¬a)→FGa, take A. Its next state is s1​, so X¬a is true, but FGa is false as just shown. Thus the second specification fails, with fair counterexample A. Alternatively, C1​ has next state s4​, making its antecedent true and its consequent false. For Cm​ with m≥2, the next state is still s3​, so this implication is true there because its antecedent is false; this does not rescue a universally quantified specification.
For φ3​=Ga, the fair path in a transition system C1​ reaches s4​, where a is false. Thus the third specification fails, with fair counterexample C1​. In fact every fair initial path in a transition system reaches s1​ or s4​, so none satisfies Ga.
For φ4​=bUG¬b, strong until requires an eventual position satisfying G¬b, together with b at every earlier position. On A, b is true forever, so G¬b never holds. Thus the fourth specification fails, with fair counterexample A. On each Bn​, b holds until entry into s2​, after which ¬b holds forever. On each Cm​, b holds until entry into s5​, after which ¬b holds forever. These latter paths in a transition system satisfy the strong until requirement.
For φ5​=bWG¬b, weak until permits either the preceding strong until behavior or Gb. Every Bn​ and Cm​ satisfies the strong until behavior, and A satisfies Gb. These exhaust the fair initial paths in a transition system. Therefore the fifth specification holds on every fair initial path. Allowing the left operand to continue forever is exactly what distinguishes this answer from the previous one.
For φ6​=(XXb)UG¬b, the two next-time operators belong to the left operand of strong until. The fair path in a transition system C1​ has b true at positions zero and one, then false at every position from two onwards. Therefore G¬b first holds at position two. But XXb is false already at position zero, since b is false at position two. A witness for strong until cannot occur at zero or one, where its right operand is false, or at two or later, where its left operand has already failed. Thus the sixth specification fails, with fair counterexample C1​.
Indeed, every fair initial path in a transition system fails the sixth specification. On A, the right operand never holds. On Bn​ and Cm​, let j≥2 be the first position of the permanent ¬b tail. The left operand XXb is false at j−2, strictly before any possible right-operand witness. This also checks that the two next-time operators cannot be ignored or shifted onto the whole strong until formula.

To apply bounded model checking, seek an initial path in a transition system satisfying
fair∧¬φ1​≡GF¬(a∧b)∧GF¬a.
(9)
A satisfying assignment for its bounded encoding is enough to disprove the specification. Use a lasso path: positions q0​,…,qk​ follow the transition relation, and a final arrow returns from qk​ to some qℓ​, 0≤ℓ≤k. The repeated part is qℓ​⋯qk​. On such a lasso path, GFr is equivalent to having r true at some position of the repeated part.
For this example an explicit Boolean formula for the bounded search is
Ek​=​I(q0​)∧i=0⋀k−1​T(qi​,qi+1​)∧ℓ=0⋁k​(T(qk​,qℓ​)∧i=ℓ⋁k​¬(a(qi​)∧b(qi​))∧i=ℓ⋁k​¬a(qi​)).​
(10)
Here I(q) means q∈{s0​,s3​} and T(q,r) means that the source diagram has the arrow q→r; each can be encoded by finite Boolean variables for the states. The loop requirements are the fairness assumption and the negated specification respectively. Unrolling the transition relation and adding a loop closure is the usual bounded model checking construction.[ref]
At bound k=0, an initial self-loop would be needed. The only such choice is q0​=s3​, whose repeated label satisfies a∧b and a. It violates both loop requirements. The other initial state, s0​, has no self-loop. Thus E0​ has no satisfying assignment.
At bound k=1, choose
q0​=s0​,q1​=s1​,ℓ=0.​
(11)
Both required arrows s0​→s1​ and s1​→s0​ exist. At q1​, a is false and hence a∧b is false, so both repeated-part requirements are true. Equivalently, the label values are a(q0​)=b(q0​)=b(q1​)=1 and a(q1​)=c(q0​)=c(q1​)=0. These values give a satisfying assignment of E1​, representing the fair counterexample (s0​s1​)ω. Consequently
TS⊨fair​FGa.​
(12)
Here the bound counts forward arrows before the returning arrow, so k=1 stores two positions and describes a two-state repeated part. There is no need for a completeness bound: the exhibited fair counterexample settles the negative answer. These satisfying assignments are checked directly; no claim of executing an external SAT solver is needed.

Write A=Sat(Φ)⊆S. All arguments depend only on this given satisfaction set; they do not require an additional convention for the printed notation Φ∈2AP. For a state s, let Post(s)={t:s→t}. The power set 2S is ordered by set inclusion.
Take X⊆Y⊆S and any s∈H(X). By the definition of H, we have both s∈A and Post(s)⊆X. By transitivity of set inclusion, Post(s)⊆Y, so s∈H(Y). Since this applies to every member of H(X),
X⊆Y ⟹ H(X)⊆H(Y).​
(13)
Thus H is an order-preserving function, which is the meaning of monotonicity here. This proof does not need either finiteness or the absence of terminal states.

Let GΦ​=Sat(∀□Φ). By computation tree logic semantics, a state belongs to GΦ​ exactly when every infinite path in a transition system starting there stays in A=Sat(Φ) at every position, including position zero. There are no terminal states, so every state lies at the start of an infinite path in a transition system.
If s∈GΦ​, then s∈A. For any successor t of s, every infinite path in a transition system from t can be prefixed with s. Hence every such continuation stays in A, so t∈GΦ​. Thus Post(s)⊆GΦ​ and s∈H(GΦ​).
Conversely, if s∈H(GΦ​), then s∈A and every successor belongs to GΦ​. Every infinite path in a transition system from s therefore has its first state in A and its entire remaining tail in A. Consequently s∈GΦ​. Both inclusions give
H(GΦ​)=GΦ​,​
(14)
so the desired satisfaction set is a fixed point of H.

Every state has at least one successor, so Post(s)⊈∅ for every s∈S. Therefore
H(∅)=A∩∅=∅.​
(15)
The empty set is always a fixed point. Whenever GΦ​ is nonempty, it is therefore an additional, distinct fixed point.
For an explicit example, take a one-state transition system with S={s}, the self-loop s→s, and A=S. Then GΦ​=S and H has the two distinct fixed points ∅ and {s}. This example meets the requirement of no terminal states.
The wording does not guarantee distinct additional fixed points for every instance. For example, if A=∅, then H(X)=∅ for every X and its only fixed point is GΦ​=∅. Thus additional fixed points can occur, but need not occur. The universal example ∅ is distinct precisely when the desired satisfaction set is nonempty, as also follows from the greatest fixed point argument below.

Let X be any fixed point of H. Then
X=H(X)=A∩{s:Post(s)⊆X},
(16)
so X⊆A and every successor of every member of X belongs to X. Take s0​∈X and an arbitrary infinite path in a transition system s0​s1​s2​⋯ from s0​. By mathematical induction, every si​ belongs to X: the base case is the choice of s0​, and si​∈X implies si+1​∈Post(si​)⊆X.
Since X⊆A, the whole path in a transition system stays in A. The path in a transition system was arbitrary, so s0​⊨∀□Φ. Thus s0​∈GΦ​, and since s0​ was arbitrary in X,
X⊆GΦ​.
(17)
Part (b) proves that GΦ​ itself is a fixed point. Therefore
Sat(∀□Φ)=νX.H(X),​
(18)
the greatest fixed point with respect to set inclusion. In fact the same induction works for every X⊆H(X), showing why a successor-closed set of good states certifies this universal property.

Start with every state, and repeatedly discard a state that is outside A=Sat(Φ) or has any successor outside the current candidate set. Use a fresh set on each iteration so that the displayed procedure computes exactly H(X):
function Sat_AG(S, Post, A):
    X = copy(S)
    repeat:
        Y = empty_set()
        for s in S:
            if s in A and every t in Post(s) belongs to X:
                insert s into Y
        if Y == X:
            return X
        X = Y
This is fixed-point iteration X0​=S, Xi+1​=H(Xi​). The first step gives X1​=A, because every successor is a state of S. Thus X1​⊆X0​. If Xi​⊆Xi−1​, the order-preserving function property gives
Xi+1​=H(Xi​)⊆H(Xi−1​)=Xi​.
(19)
The candidate sets therefore form a descending chain under set inclusion.
Every fixed point Z is contained in every Xi​: initially Z⊆S, and Z⊆Xi​ implies Z=H(Z)⊆H(Xi​)=Xi+1​. At return, X=H(X), and X contains every fixed point. The returned set is consequently the greatest fixed point, so X=Sat(∀□Φ)​ by part (d).
The iteration also has a direct interpretation. X1​ contains precisely the states satisfying Φ now; X2​ retains those satisfying it now and at all immediate successors; later rounds extend the checked horizon one step at a time. The stable set enforces the condition at every future position.

Yes: the procedure always terminates after finitely many steps. If an iteration does not return, then Xi+1​⊊Xi​. Thus at least one state is permanently removed. A finite set of ∣S∣ states can suffer at most ∣S∣ such strict decreases, after which the next equality test must return. Therefore the procedure makes at most
∣S∣+1 evaluations of H​
(20)
when started from X0​=S, counting the final evaluation that detects equality. The bound also covers S=∅, where the first evaluation already returns. Each evaluation inspects finitely many states and successors, so every individual step terminates as well. Finiteness, rather than monotonicity alone, supplies this finite termination bound.
