The two-interval approximation by one interval supplies an approximation guarantee for every input probability distribution D. Merge overlapping target intervals, and write the target positive set as at most two disjoint ordered intervals I1​,I2​. Put pj​=D(Ij​) and p=p1​+p2​. If there is only one nonempty component, the target already belongs to the interval hypothesis class and has zero misclassification risk. If the interval notation permits empty intervals and the target is empty, choose that same empty interval in H.
In the two-component case, choosing the heavier component as the hypothesis loses only the lighter component, so its misclassification risk is
min(p1​,p2​)≤2p​.
(40)
Alternatively, choose the single interval J spanning both components. This produces no false negatives, and its false positives lie in the gap. Its misclassification risk is at most 1−p. Both candidates are in H, so there exists an interval h∗ with
errD​(h∗)≤min(2p​,1−p)≤31​.
(41)
For the last step, use p/2≤1/3 if p≤2/3, and 1−p≤1/3 if p≥2/3. This avoids any assumption that an empty interval or the whole real line belongs to H.
Use empirical risk minimization over intervals on independent labelled examples. The generalization result needed here is the VC uniform convergence theorem: for a binary hypothesis class of finite VC dimension v, there is a universal constant A such that, for any labelled-data probability distribution and 0<η,δ<1, a sample size
m≥η2A​(vlogη2​+logδ2​)
(42)
ensures, with probability at least 1−δ, that every hypothesis's empirical misclassification risk differs from its misclassification risk by at most η. This theorem does not require the labels to be realizable by the hypothesis class.[ref]
The interval hypothesis class has VC dimension two: any two ordered points can receive all four labellings, whereas an interval cannot label three ordered points 1,0,1. Take η=1/24 and choose an interval h minimizing the empirical misclassification risk. On the simultaneous convergence event,
errD​(h)​≤err(h)+η≤err(h∗)+η≤errD​(h∗)+2η≤31​+121​=125​=21​−121​.​
(43)
Therefore
C is weakly PAC learnable using H,γ=121​.​
(44)
Since v and η are fixed constants, O(1+log(1/δ)) examples suffice, which is polynomial in 1/δ as required by the paper's definition of weak PAC learning.
For completeness, empirical risk minimization over intervals is computationally effective. Sort the sample and group equal coordinates, since one interval cannot split identical inputs. Give each group weight equal to the number of positive labels minus the number of negative labels in that group. The number of empirical mistakes made by an interval is the total number of positives minus the total weight of the consecutive groups it contains. Select the consecutive block of maximum weight, or select a finite interval outside the sample if every nonempty block has negative weight. This enumerates all possible sample labellings by intervals and attains the minimum empirical misclassification risk; sorting and a maximum-block scan are sufficient. The time complexity is O(mlogm).
