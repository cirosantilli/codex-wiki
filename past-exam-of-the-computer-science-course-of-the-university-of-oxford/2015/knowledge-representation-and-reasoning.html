For resolution, a first-order sentence is in clausal normal form when it is a universally quantified logical conjunction of first-order clauses:
∀xˉi=1⋀m​j=1⋁ki​​Lij​,​
(10)
where every Lij​ is a first-order literal, meaning an atomic formula or the logical negation of an atomic formula. The quantifiers are often left implicit and the first-order clauses treated as a set. The empty first-order clause represents falsity; an empty set of first-order clauses represents truth.
A convention that allows an arbitrary quantifier prefix followed by a conjunctive matrix is weaker: that is a prenex normal form with a conjunctive matrix. The elimination of existential quantifiers by Skolemization is the extra step relevant to resolution and to part (ii).

The usual transformation to clausal normal form preserves equisatisfiability, but not necessarily logical equivalence​. Removing implications and distributing logical conjunction and logical disjunction preserve logical equivalence. Skolemization introduces new symbols and chooses witnesses as functions of preceding universally quantified variables.
For example,
φ=∀x∃yR(x,y)⟼ψ=∀xR(x,f(x)).
(11)
On the domain {0,1}, let R be equality. Then φ is true. Expand this same first-order structure by interpreting f as the constant function with value 0. The resulting first-order structure falsifies ψ at x=1. Interpreting f as the identity instead satisfies ψ.
Thus every model of ψ has a reduct satisfying φ, and a model of φ can be expanded with suitable witnesses to satisfy ψ. That model-expansion property gives equisatisfiability, not logical equivalence for every interpretation of the added function. If “CNF” means a conjunctive matrix with existential quantifiers retained, Skolemization has not yet happened and an equivalent form is possible; this is why the convention must be specified.

An exponential increase is unavoidable for an equivalent conjunctive normal form over the original variables. Consider the linear-size Boolean formula
Fn​=⋁i=1n​(pi​∧qi​).
(12)
Distributing gives the 2n Boolean clauses
Fn​≡⋀(r1​,…,rn​)∈{p1​,q1​}×⋯×{pn​,qn​}​(r1​∨⋯∨rn​).
(13)
To prove that the growth is necessary, fix one choice ri​∈{pi​,qi​}. Let αr​ make every ri​ false and its partner true. Each pair then contains a false variable, so Fn​ is false. Any equivalent conjunctive normal form must contain a Boolean clause C falsified by αr​ and entailed by Fn​.
Every individual term pi​∧qi​ entails C, because that term implies Fn​. After tautological Boolean clauses are discarded, this forces C to contain a positive pi​ or positive qi​ for every i: otherwise set both variables in that pair true and independently falsify all Boolean literals of C, contradicting the entailment. Since C is false at αr​, it must contain the false member ri​, never its true partner. Consequently the same C cannot be false at any different αs​. The 2n different assignments therefore require at least 2n different Boolean clauses.
Writing the answer already takes Ω(2n) time in the worst case​. This obstruction applies to first-order logic as well, since the example can be expressed using ground unary atomic formulas. It concerns exact equivalence without auxiliary symbols. A Tseytin transformation can produce a polynomial-size equisatisfiable conjunctive normal form with auxiliary variables, so the statement must not be extended to that different task.

The algorithm is incorrect: it can return true for a non-entailed ground atom​. Its recursive calls return only Booleans. They do not return and propagate the first-order substitutions obtained while satisfying earlier rule premises.
Take distinct constants a,b,c, facts
F={P(a),Q(b)},
(14)
and the single Datalog rule
P(x)∧Q(x)→H(c).
(15)
Ask for H(c). The head matches the goal without binding x. In line 15, the recursive call for P(x) succeeds by first-order unification with P(a), but returns only true. The next recursive call still receives Q(x) with x unbound, and succeeds by first-order unification with Q(b). Neither subgoal is the visited head H(c), so the visited test does not stop these calls. Both recursive results are true, and the algorithm returns true for H(c).
However, the least Herbrand model is just {P(a),Q(b)}. No single constant makes both P(x) and Q(x) true, so the rule cannot derive H(c). The two individually successful premises need one consistent first-order substitution. A correct backward chaining procedure must thread answer first-order substitutions through the remaining premises and backtrack when they cannot be extended; forward chaining on ground Datalog instances is another way to avoid this error.

A fragment has the finite model property if every satisfiable sentence in the fragment has a finite model​. This does not mean that every model is finite, nor that there is one uniform bound on model size for the entire fragment.
ALC has the finite model property, including satisfiability with respect to finite TBoxes. A tableau algorithm for ALC uses finitely many possible labels and direct blocking in description logic to obtain a finite representation of a model. The resulting finite-model claim is a property of the logic; termination alone, for an arbitrary procedure, would not establish it.
Full first-order logic does not have the finite model property. For example, the first-order sentence
(∀x¬R(x,x))∧(∀x∀y∀z((R(x,y)∧R(y,z))→R(x,z)))∧(∀x∃yR(x,y))
(16)
requires an irreflexive transitive relation with a successor for every element. It is satisfied by the usual strict order on the natural numbers. In a nonempty finite domain, repeatedly taking successors eventually repeats an element; transitivity would then force R(x,x), contradicting irreflexivity. Hence this satisfiable first-order sentence has no finite model.

For plain EL, every concept is satisfiable with respect to every EL TBox​. On a one-element domain, interpret every atomic description logic concept as the whole domain and every description logic role as the full binary relation. A structural induction makes every EL description logic concept denote that element. Every general concept inclusion is consequently true, including cyclic ones. The decision procedure can therefore always answer yes on well-formed inputs.
For EL with bottom, concept satisfiability with respect to general TBoxes is P-complete​ under the usual logarithmic-space reductions. Polynomial-time completion propagates atomic inclusions, conjunction consequences and existential requirements; deriving ⊥ for the queried description logic concept detects unsatisfiability. There are polynomially many such labels and normalized relationships to propagate.
For the lower bound, encode a monotone Boolean circuit with a starting description logic concept S. Give each input gate labelled one an inclusion S⊑Gi​. Encode an AND gate by Gi​⊓Gj​⊑Gk​, and an OR gate by Gi​⊑Gk​ and Gj​⊑Gk​. Finally add Gout​⊑⊥. Then S is unsatisfiable exactly when the circuit output is one. The complement version is also P-complete, since P is closed under complement. Thus allowing ⊥ changes a trivial satisfiability problem into a nontrivial polynomial-time one. The bottom-inclusive convention is also reflected in the [ref].

Fix a signature, adding a fresh constant if it otherwise has no ground terms. Its Herbrand universe U is the set of all ground terms, and its Herbrand base B is the set of all ground atoms over U. A Herbrand interpretation is identified with a subset I⊆B: precisely its members are true. Function symbols and constants have their term interpretations.
A least Herbrand model of a knowledge base K is a Herbrand model M satisfying
M⊨KandM⊆J for every Herbrand model J⊨K.​
(30)
If it exists, it is unique. This is stronger than being minimal: a minimal model merely has no strictly smaller model contained in it.
For a positive definite Datalog program with facts, let T add every fact and the head of every ground rule whose body is already true. Starting from the empty set and repeatedly adding consequences yields
M=n≥0⋃​Tn(∅)=⋂{J:J is a Herbrand model of K},​
(31)
where T is taken inflationary, so it also retains its input. Every added ground atom belongs to every model, and the union is closed under every finite rule body. These two facts establish that it is the least Herbrand model. The intersection assertion is guaranteed here by the definite Horn form, not for arbitrary knowledge bases.

But the empty Herbrand interpretation falsifies the disjunctive fact. This is a contradiction. Taking the intersection of all models therefore fails because that intersection need not itself be a model.

A Herbrand interpretation I is a stable model when it is the least Herbrand model of its stable model reduct KI. To form the reduct, ground the rules, delete each rule with a premise notA for which A∈I, and remove the remaining occurrences of not and their atoms.
For I1​, the rules concerning N in the reduct are
Year(N)∧DivisibleBy(N,400)Year(N)∧DivisibleBy(N,4)Year(N)​→Leap(N),→Leap(N),→Common(N),​
(36)
together with Year(N). No rule has a divisibility atom in its head, so forward chaining produces no divisibility facts and no leap fact. Ground rules for the other constants cannot fire because their year premises are absent. Thus
LM(KI1​)={Year(N),Common(N)}=I1​.
(37)
Therefore I1​ is stable​.
For I2​, the rule using notDivisibleBy(N,100) is deleted. The common-year rule is retained without its negative premise, since Leap(N) is absent. Crucially, the reduct does not convert atoms already in I2​ into facts. Its least Herbrand model is again {Year(N),Common(N)}. The two divisibility atoms in I2​ have no support. Hence
I2​ is not stable.​
(38)
Inspecting these two interpretations alone is not sufficient for skeptical entailment. That requires every stable model to contain Common(N). Here we can finish the argument: every reduct has no rule deriving divisibility atoms, so every stable model has empty divisibility relation. Its leap relation must then be empty as well. The common-year rule consequently derives Common(N), and the only year fact is Year(N). Thus I1​ is the unique stable model, and
K∣≈Common(N).​
(39)
This final uniqueness argument, rather than the examination of just two candidate interpretations, establishes the required universal claim.

A safe one-rule Datalog with negation example with no stable model is
notP(a)→P(a).​
(40)
There are no variables, so no safety condition is violated. If P(a) is absent from a proposed stable model, its reduct contains the fact P(a), whose least Herbrand model contains P(a). If P(a) is present, the rule is deleted, and the reduct has empty least Herbrand model. Either choice disagrees with its reduct's least Herbrand model. Additional unsupported atoms cannot repair the disagreement. Hence there is no stable model.

For polynomial-time many-one reductions, an unconditional example is the empty language:
L=∅ is in NP and is not NP-complete.​
(41)
A procedure that rejects every input decides it in constant time, so it belongs to P and hence NP. It is not NP-hard: the nonempty formal language {0} belongs to NP, but no many-one reduction f can satisfy
0∈{0}⟺f(0)∈∅.
(42)
The right-hand side is always false. Thus the hardness condition fails without assuming P=NP. Giving an ordinary nontrivial problem in P would not establish the requested separation unconditionally, because that would require excluding the possibility P=NP.

ii OurBigBook.com
The halting problem is an unconditional example:
HALT is NP-hard but not NP-complete.​
(43)
Reduce SAT to it as follows. Given a Boolean formula φ, construct a Turing machine Mφ​ that ignores its input, enumerates all Boolean valuations of φ, and halts if it finds a satisfying one. If none satisfies φ, it enters an infinite loop after the enumeration. Then
φ∈SAT⟺⟨Mφ​,ε⟩∈HALT.
(44)
The construction of the machine description takes polynomial time; the potentially exponential running time of the constructed machine is irrelevant to the time needed to compute the polynomial-time reduction. Since SAT is NP-complete, this proves NP-hardness of the halting problem.
Every problem in NP is decidable, by enumerating the finitely many polynomial-length certificates and running the verifier. The halting problem is undecidable, so it is outside NP and therefore cannot be NP-complete.

The satisfiability problem is decidable​. Partition the positive facts according to their predicate symbols. Let AT​ contain those using description logic concepts or description logic roles from T. Run an ordinary ALC knowledge base consistency procedure on (T,AT​). Return no if it is inconsistent, and yes otherwise.
The no answer is sound because any model of the whole knowledge base would restrict to a model of (T,AT​). For the converse, take a model I of that ALC part. Keep its domain, individual interpretations and TBox predicates. Interpret every predicate used by the positive Datalog rules as the full relation of its arity on this same domain. This is possible because those predicates are disjoint from the TBox predicates. Every Datalog rule head is then true under every variable assignment, so every positive rule and every remaining positive fact is satisfied. Predicates occurring only in facts can likewise be interpreted as full relations. Any individual name not already interpreted can denote an arbitrary domain element.
Consequently,
(T,R,A) is satisfiable⟺(T,AT​) is satisfiable.​
(45)
The argument depends on both restrictions in the question: disjoint predicate vocabularies and positive rule heads. A rule concluding ⊥ would not be made true by filling all relations. Sharing constants alone causes no problem, since the expansion uses the same domain and the same interpretations of those constants.
