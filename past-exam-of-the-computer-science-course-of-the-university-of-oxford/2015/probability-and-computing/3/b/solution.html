Betty's scheme is biased for every n≥2. The output HnTn occurs precisely when the first n tosses are heads: the algorithm stops there and appends n tails. Thus
P(HnTn)=2−n.
(35)
For comparison, take the output (HT)n. Its first 2n−2 symbols contain n−1 heads and n−1 tails, so neither stopping threshold has been reached. The next symbol is the nth head, at which point the last tail is appended. Its unique generating prefix has length 2n−1, giving
P((HT)n)=2−(2n−1).
(36)
Therefore
P((HT)n)P(HnTn)​=2n−1>1(n≥2).​
(37)
The faster stopping rule does not produce a uniform distribution on a finite set of balanced binary sequences. For example, at n=2 the six outputs have the following exact probabilities:
OutputBettyUniform target
HHTT1/41/6
HTHT1/81/6
HTTH1/81/6
THHT1/81/6
THTH1/81/6
TTHH1/41/6
For n=1, the two possible outputs each have probability 1/2, so that special case is uniform. For n=0, simply return the empty output.
