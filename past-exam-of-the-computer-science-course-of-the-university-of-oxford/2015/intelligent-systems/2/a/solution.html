Index the coins so that c1​ is smallest and cn​ largest. Choose s1​ as the initial stack and s2​ as the destination, assuming k≥2. The static predicate facts describing size are
Ssize​={Smaller(ci​,cj​):1≤i<j≤n}.
(12)
No size comparison with g is needed: moving onto empty ground will have a separate action schema. The initial STRIPS state is
I=Ssize​∪{OnTop(ci​,ci+1​):1≤i<n}∪{OnTop(cn​,g),Topmost(c1​,s1​)}∪{Topmost(g,sj​):2≤j≤k}.​
(13)
Under the closed-world assumption, all other ground ground atoms are false. In particular, the initial state contains just one predicate fact naming the top of each stack. The predicate OnTop names the immediate support, not every coin farther below.
An explicit positive conjunctive goal is the following set of required ground atoms:
Ggoal​={OnTop(ci​,ci+1​):1≤i<n}∪{OnTop(cn​,g),Topmost(c1​,s2​)}∪{Topmost(g,sj​):j=2}.​
(14)
A state succeeds when it contains Ggoal​. The static predicate facts in Ssize​ persist automatically. Starting from I, the planning state invariants proved below make this goal exactly the desired completed stack on s2​ with all other stacks empty. If any new stack is acceptable, the choice of s2​ loses no generality because the initially empty stacks are interchangeable.
