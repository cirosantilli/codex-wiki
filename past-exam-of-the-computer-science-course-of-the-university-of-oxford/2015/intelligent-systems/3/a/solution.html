Use one variable Xr,c​ for each cell, with 1≤r,c≤9. An empty cell has constraint domain {1,…,9}; a clue containing d has singleton constraint domain {d}. Thus all clues are retained automatically.
For every row r impose AllDifferent(Xr,1​,…,Xr,9​), and for every column c impose AllDifferent(X1,c​,…,X9,c​). For each a,b∈{0,1,2} impose an all-different constraint on
{X3a+i,3b+j​:1≤i,j≤3}.
(23)
These are the nine prescribed boxes. There are 27 all-different constraints altogether. Nine pairwise distinct values chosen from a set of nine values must use every value exactly once, so these restrictions are precisely the Sudoku requirements. Equivalently, expand each all-different constraint into pairwise binary constraints Xr,c​=Xr′,c′​ for cells sharing a row, column, or box.
81 variables, clue-restricted domains, and 27 all-different constraints.​
