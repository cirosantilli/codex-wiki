Using the absorbed TBox with its primitive inclusion, translate description logic concepts as unary predicates and description logic roles as binary predicates. Concept satisfiability means that some element belongs to A⊓C, while every element satisfies the TBox axioms. The required first-order sentence is
∧∧​∃x(A(x)∧C(x))∀u(A(u)→¬B(u))∀u(C(u)↔∃vP(u,v)).​​
(26)
Only Tu​ is included here, as requested. There is no requirement to satisfy (1), (2) or (3). For instance, one element with A=C={d}, B=∅ and P={(d,d)} satisfies this first-order sentence.
Alternatively, unfolding the absorbed TBox first gives the existential first-order sentence ∃x∃y(A0​(x)∧¬B(x)∧P(x,y)). The interpretation of the eliminated names is then recovered by A=A0​∖B and C={x:∃yP(x,y)}.
