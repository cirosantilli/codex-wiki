An exponential increase is unavoidable for an equivalent conjunctive normal form over the original variables. Consider the linear-size Boolean formula
Fn​=⋁i=1n​(pi​∧qi​).
(12)
Distributing gives the 2n Boolean clauses
Fn​≡⋀(r1​,…,rn​)∈{p1​,q1​}×⋯×{pn​,qn​}​(r1​∨⋯∨rn​).
(13)
To prove that the growth is necessary, fix one choice ri​∈{pi​,qi​}. Let αr​ make every ri​ false and its partner true. Each pair then contains a false variable, so Fn​ is false. Any equivalent conjunctive normal form must contain a Boolean clause C falsified by αr​ and entailed by Fn​.
Every individual term pi​∧qi​ entails C, because that term implies Fn​. After tautological Boolean clauses are discarded, this forces C to contain a positive pi​ or positive qi​ for every i: otherwise set both variables in that pair true and independently falsify all Boolean literals of C, contradicting the entailment. Since C is false at αr​, it must contain the false member ri​, never its true partner. Consequently the same C cannot be false at any different αs​. The 2n different assignments therefore require at least 2n different Boolean clauses.
Writing the answer already takes Ω(2n) time in the worst case​. This obstruction applies to first-order logic as well, since the example can be expressed using ground unary atomic formulas. It concerns exact equivalence without auxiliary symbols. A Tseytin transformation can produce a polynomial-size equisatisfiable conjunctive normal form with auxiliary variables, so the statement must not be extended to that different task.
