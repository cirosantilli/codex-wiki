The empty set is always a fixed point. Whenever GΦ​ is nonempty, it is therefore an additional, distinct fixed point.
For an explicit example, take a one-state transition system with S={s}, the self-loop s→s, and A=S. Then GΦ​=S and H has the two distinct fixed points ∅ and {s}. This example meets the requirement of no terminal states.
The wording does not guarantee distinct additional fixed points for every instance. For example, if A=∅, then H(X)=∅ for every X and its only fixed point is GΦ​=∅. Thus additional fixed points can occur, but need not occur. The universal example ∅ is distinct precisely when the desired satisfaction set is nonempty, as also follows from the greatest fixed point argument below.
