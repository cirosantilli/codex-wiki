OurBigBook.com Words: 115
Find the salesperson identifiers satisfying each price condition using relational selection and relational projection:
L=πsalespersonid​(σprice=10000​S),H=πsalespersonid​(σprice=30000​S).
(10)
Intersect these identifier sets, relational join the result to the salesperson records, and apply relational projection to names:
πname​(P⋈empid=salespersonid​(L∩H)).​
(11)
If intersection is not a primitive of the chosen relational algebra, use L∩H=L−(L−H) with relational difference. There is no need to access Car: the foreign key already ensures that every sale refers to a car.
Intersecting names instead of identifiers is wrong. Two different salespeople called Alex, one making only 10000 sales and the other only 30000 sales, would make Alex appear in both name sets although neither person satisfies the condition. Nor can one sale satisfy both price tests: the two distinct prices require distinct sale records.
