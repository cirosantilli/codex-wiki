Let the oriented vertices be a,b,c, in an order such that n=(b−a)×(c−a) points out of the front face. The given nondegeneracy guarantees n=0. A ray with nonzero direction r approaches the front face only if
n⋅r<0.
(30)
Reject n⋅r≥0. This combines back-face culling with rejection of parallel rays, including the coplanar case for this ordinary surface-hit test. The ray-plane intersection parameter is
λ=n⋅rn⋅(a−o)​.
(31)
Reject λ<0; for rays launched from existing surfaces use a positive lower cutoff to avoid counting the launch surface. Form p=o+λr.
Finally determine whether p lies inside the triangle. For u=b−a, v=c−a, w=p−a, compute
D=(u⋅u)(v⋅v)−(u⋅v)2>0,
(32)
β=D(v⋅v)(w⋅u)−(u⋅v)(w⋅v)​,γ=D(u⋅u)(w⋅v)−(u⋅v)(w⋅u)​.
(33)
These solve p=a+βu+γv. The barycentric coordinates are (1−β−γ,β,γ), so the complete acceptance criterion is
n⋅r<0,λ≥0,β≥0,γ≥0,β+γ≤1;p=o+λr.​
(34)
The inequalities include the edges and vertices. A renderer sharing edges between triangles should use a consistent numerical edge convention; small floating-point arithmetic errors near a shared boundary should not create cracks. Normalizing n is unnecessary for this intersection calculation because its scale cancels.
