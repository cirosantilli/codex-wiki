The unique fixed point principle says that a suitably guarded recursion has a unique solution in the chosen CSP semantic model. In particular, for a guarded process expression F(X),
P=F(P),Q=F(Q)⟹P=Q.​
(1)
The same principle applies to a mutually recursive system: two tuples satisfying the same guarded equations are componentwise equal. Thus an algebraic proof may show that a candidate satisfies the defining equations, instead of comparing arbitrarily long executions individually.
A guarded recursion must make visible progress before re-entering its recursive dependency. For an equation built from CSP prefixing and CSP choice, the usual sufficient condition is that every recursive occurrence lies behind a visible CSP prefixing operation. For mutually recursive equations, every dependency cycle must pass such a guard. The guard must survive enclosing operators: an event subsequently removed by CSP hiding does not provide visible progress. Equivalently, in the usual semantic formulation the recursion functional must be contractive in observable depth. Merely seeing an arrow somewhere before the variable is insufficient.

Let X=P {a,b,d}​∥{a,b,c}​ Q. In this CSP alphabetized parallel composition, a,b require both participants, d belongs only to the left participant and c only to the right participant. Expand the reachable states using CSP prefixing and CSP external choice:
XYWZ​=a→Y,=b→Z□d→W,=b→Z,=c→X.​
(3)
For example, after the synchronized b, the left participant is back at P but the right participant is at c→Q. The left participant's proposed a is blocked until the right participant has performed c. Similarly, after a,d, only the synchronized b is possible. Thus there is no extra interleaving to include.
Eliminating Y,W,Z gives the guarded equation
X=a→(b→c→X□d→b→c→X).
(4)
Consequently choose the sequential CSP process
R=a→(b→c→R□d→b→c→R).​
(5)
The unique fixed point principle first establishes R=X.
Now let E=XΘ{c}​X. The CSP exception operator follows its left operand until that operand performs c, includes this c in the visible behaviour, and then switches to its right operand. Applying its CSP step law to the four-state expansion yields
E=a→(b→c→X□d→b→c→X)=X.
(6)
The switch occurs exactly where the ordinary execution already returns to X. Therefore E=X=R. The answer uses neither a CSP exception operator nor a CSP parallel composition operator, and the argument gives equality in all three standard CSP semantic models.

Use a chain of identical storage cells, each retaining the first value it sees and passing later values to the next cell. On the return journey it passes the next cell's reversed output before emitting its own retained value. This turns the chain into a distributed LIFO stack.
Here is one cell template. Its ports l,r carry incoming values towards the tail; v,u carry returning values towards the front. Each port carries values in T∪{end}, with the sentinel value outside T:
CellHold(x)Drain(x)​=l?x:T→Hold(x),=(l?y:T→r!y→Hold(x))□(l.end→r.end→Drain(x)),=(v?y:T→u!y→Drain(x))□(v.end→u!x→u.end→STOP).​
(7)
An input such as l?x:T abbreviates an indexed CSP external choice over the corresponding CSP events. An output r!y is the CSP prefixing action r.y. There is no extra controller process.
For n≥1, take n copies of this same template. Introduce channels di​,ui​ for 0≤i≤n and apply port CSP event renaming to copy i, for 1≤i≤n, as follows:
l.x↦di−1​.x,r.x↦di​.x,v.x↦ui​.x,u.x↦ui−1​.x.
(8)
At the front put d0​=in and u0​=out. Adjacent cells synchronize on every shared di​ or ui​ CSP event. The two tail channels dn​,un​ are sentinel-only: dn​.end and un​.end are local tail CSP events, with no other participant required. Disable all dn​.x,un​.x for x∈T. Formally, use a partial relational CSP event renaming for the last copy, omitting the pairs for its r.x,v.x with x∈T; an unmapped transition is blocked. This explicitly prevents a fictitious tail from generating data.
Let Ci​ be the resulting port-renamed cell and Ai​ its visible alphabet. With H consisting of the internal link CSP events, including the two tail CSP events, the answer is
Reversen​=(∥i=1n​[Ai​] Ci​)∖H.​
(9)
Here the indexed operator is CSP alphabetized parallel composition: each CSP event is synchronized by all cells whose alphabets contain it. There are exactly n storage-cell processes; port wiring and the sentinel-only tail adapt their interfaces, without adding a helper process. The local tail CSP events are hidden, as are all inter-cell communications.
To see correctness, after inputs x1​,…,xn​ have propagated, cell i retains xi​. The input sentinel value propagates to the tail. The last cell performs its two local tail CSP events, then returns xn​,end. Inductively, if the suffix after cell i returns xn​,…,xi+1​,end, cell i relays those values, replaces the final sentinel value by xi​,end, and stops. Hence the external output is
out.xn​,…,out.x1​,out.end,​
(10)
and starts only after in.end. Shared links provide synchronization rather than an assumption that all cells take steps simultaneously. For the degenerate known-empty input, no storage is needed: the interface is simply in.end→out.end→STOP.

In the displayed network, the first k cells retain values and cell k+1 is still in its initial Cell state. It accepts only a value in T, so it cannot accept the incoming sentinel value. For k=0 the first cell blocks the external sentinel value; for 0<k<n a stored cell blocks while trying to pass it to an empty neighbour. Thus
k<n⟹deadlock before any reversed output.​
(11)
To handle shorter inputs, add an empty-cell branch l.end→u.end→STOP to the initial state. An empty cell then terminates the downward scan and immediately returns an empty sequence. For a finite CSP trace s, let L(s) be its sequence of values on left and O(s) its sequence of values on right, with channel names removed. Restrict the external alphabet to these two channels. The behavioural CSP trace specification for an unbounded FIFO buffer is
∀s∈traces(P):O(s)⪯L(s),​
(14)
where ⪯ means prefix of a list, not merely subsequence. Outputs must therefore occur in input order, cannot duplicate or invent values, and cannot precede their inputs. Applying the condition to every CSP trace also checks every execution prefix.
For a legal s, write L(s)=O(s)⌢q(s), so q(s) is the pending FIFO queue content. Define the events that must remain available by
E(q)={left.x:x∈T}∪{∅,{right.head(q)},​q=⟨⟩,q=⟨⟩.​
(15)
In addition to the CSP trace condition, require the behavioural CSP stable failure condition
∀(s,X)∈failures(P):X∩E(q(s))=∅.​
(16)
Thus an unbounded FIFO buffer cannot stably refuse any new input, and a nonempty FIFO buffer cannot stably refuse its oldest pending output. An empty FIFO buffer can refuse every output. Readiness of an input and readiness of an output are required together; the environment may choose either. These conditions do not require an output while the environment refuses to accept it. In a CSP failures-divergences model specification, also exclude CSP divergence; the stable-readiness condition alone does not rule out an implementation that loops internally forever without reaching a CSP stable state.

BUF(q)​=(left?x:T→BUF(q⌢⟨x⟩))□{STOP,right.head(q)→BUF(tail(q)),​q=⟨⟩,q=⟨⟩.​​

P=BUF(⟨⟩)⊓STOP.​
(18)
An execution choosing the first branch can perform every legal CSP trace satisfying the prefix of a list condition in part (a). Maximizing the number of CSP traces does not pick a unique process in the finer models: other processes with the same complete legal CSP trace set and extra refusals also qualify.

If f is injective, the equation is true:
f(PA∥​Q)=f(P)f(A)∥​f(Q)(f injective).​
(19)
For a CSP event a∈A, the original CSP parallel composition permits a exactly when both operands can perform a. After CSP event renaming, the corresponding rule requires the same image f(a) in both operands. Injectivity ensures that matching images came from the same event, and that an event outside A cannot acquire the image of one inside A. Independent transitions remain independent, and CSP internal actions are unchanged. Matching these transition rules gives a strong bisimulation, hence equality in all three standard CSP semantic models.
For a non-injective f, the equation need not hold. Let
P=a→STOP,Q=b→STOP,A={a,b},a=b,f(a)=f(b)=c.
(20)
On the left, both events require synchronization but the other operand offers the wrong event, so PA∥​Q=STOP. On the right, both renamed operands offer c, which can synchronize:
f(PA∥​Q)=STOP=c→STOP=f(P)f(A)∥​f(Q).​
(21)
The failure is already visible in the CSP traces model. A particular non-injective CSP event renaming may still preserve a particular composition; it is the unrestricted equivalence that fails.

Use fresh event tags to tell apart an action by P and an interrupting action by Q. Put B=Σ∖A and introduce a disjoint copy B′={a′:a∈B}. Let f fix A and map each a∈B to a′, and put S=A∪B′. Define a process that always accepts an event from S by
RUN(S)=□x∈S​x→RUN(S),
(28)
and an ordinary CSP interrupt handler by
I=□a∈B​a′→RUN(S).
(29)
Finally let g fix every original event and send a′ back to a. A simulation containing no occurrence of the new operator is
R=g((P△I)S∥​f(Q)).​
(30)
Here △ is the ordinary CSP interrupt, and the CSP event renaming g is applied after the CSP parallel composition. It is non-injective, so part (c) explains why moving it inside would be unsafe.
Before the interrupt, P's events in A synchronize with f(Q) on the same events. Its events outside A are unprimed and do not synchronize with f(Q). Meanwhile Q's events outside A are primed; they synchronize with I and thereby interrupt and discard P. After the first such event, the left operand is RUN(S), so it imposes no further restriction on f(Q); final CSP event renaming then yields exactly the remaining behaviour of Q.
For a formal strong bisimulation, relate a pre-interrupt state JA​(P0​,Q0​) to
g((P0​△I)S∥​f(Q0​)),
(31)
and an already-interrupted state Q0​ to
g(RUN(S)S∥​f(Q0​)).
(32)
The three visible cases match the rules in part (d), including both transitions when both operands offer the same event outside A. A CSP internal action of Q0​ never activates I, while a CSP internal action of P0​ remains possible exactly until the interrupt. The controller adds no CSP internal actions. Thus transitions match in both directions and related derivatives remain related.
Consequently this simulation is stronger than merely CSP trace equivalent:
R=T​JA​(P,Q),R=F​JA​(P,Q),R=FD​JA​(P,Q).​
(33)
It preserves CSP stable states, their enabled-event sets and their CSP stable failures, and matches every possible infinite run of CSP internal actions. In particular, it introduces neither a premature commitment nor a new CSP divergence. A different simulation that guesses an interrupt with a hidden handshake would need a separate refusal analysis; the visible tagging construction above needs no hidden handshake.

Let V={0,…,N−1}, let A⊆V track active nodes, and let D⊆V track nodes that have announced shutdown. Let Ring contain every message CSP event. Safe(A,D)​=□n∈A∖D​idle.n→Safe(A∖{n},D)□□n∈V∖(A∪D)D=∅​​active.n→Safe(A∪{n},D)□□n∈V∖DA=∅​​shutdown.n→Safe(A,D∪{n}).​

Safe(V,∅)⊑T​System∖Ring.​
(41)

The trigger is specifically the first-round reception ring.0.true. A CSP trace restriction cannot by itself guarantee progress after this event, because a finite prefix is compatible with both completion and an indefinitely delayed completion. We need to exclude both a stable refusal to continue and CSP divergence, so use the CSP failures-divergences model.
Here is an explicit conditional check that imposes no progress requirement before the trigger. Build the reachable labelled transition system of System and observe coordinator rounds with a two-phase monitor: it starts in the first-return phase and toggles on each ring.0.b. Collect the set H of system derivatives immediately after a true return in the first-return phase. This distinguishes the survey's return from the decision's return, without changing any system transitions. For fixed finite N, the set is finite. Define
ShutPostFinish(D)​={shutdown.n:n∈V},=⊓H∈H​(H∖(Σ∖Shut)),={STOP,⊓n∈V∖D​shutdown.n→Finish(D∪{n}),​D=V,D=V.​​
(42)
Here ⊓ denotes CSP internal choice. Perform the single CSP refinement check
Finish(∅)⊑FD​Post.​
(43)
Equivalently, check each post-trigger derivative H individually against Finish(∅) after the displayed CSP hiding. If the trigger is unreachable, the conditional property is vacuously true and there is no post-trigger check to perform.
The CSP internal choice in Finish deliberately permits any next shutdown, including an implementation that offers only one of the remaining shutdowns. It forbids a stable refusal of all remaining shutdowns, has no CSP divergence, and permits at most N distinct shutdowns before STOP. A CSP external choice over all remaining nodes would instead demand simultaneous readiness for every remaining shutdown and would unnecessarily reject the protocol's sequential delivery.
After hiding all other actions, endless internal work becomes a CSP divergence and a blocked unfinished state becomes a forbidden CSP stable failure. Since there are only N possible shutdown actions and duplicates are excluded by CSP traces, every maximal progressing execution must complete all N. As usual for untimed CSP, this progress claim assumes the environment allows shutdown signals to occur; it supplies no wall-clock deadline. No fairness assumption requiring the coordinator eventually to initiate a survey has been smuggled into this conditional check.
For the defined system the check succeeds. Immediately after the trigger all statuses are idle and frozen. The only message work left is the second round: node 0 sends the decision to node 1, nodes 1 through N−1 forward it, and node 0 receives it. These are exactly N more message transfers. Each node then has its one shutdown action, and the message can advance even while an earlier node's shutdown is pending. Thus there are no remaining status changes, no message cycle, and no unfinished global state in which every action is blocked. The measure
remaining second-round transfers+remaining shutdown signals​
(44)
starts at 2N, is nonnegative, and decreases on every subsequent transition. This excludes any hidden infinite run; before all shutdowns finish there is either an enabled message transfer or an enabled shutdown signal. The operational argument proves the conditional claim for every N≥2; finite state enumeration is only a supporting check.

At the first displayed event the coordinator has started and all nodes are idle. Node 1 has received true and is frozen, but node 2 can still activate before receiving the token. It forwards false, so the entire second round carries false and nobody shuts down. After the final idle.2, all nodes are idle again. The coordinator may then perform active.0,idle.0 forever without starting another survey. This is an infinite execution with no shutdown and no assumption of fairness that would exclude it.
Therefore
The proposed eventual-shutdown property fails in general, already for N=3.​
(46)
This does not contradict part (e): its stronger trigger, the true first-round return, never occurs in the failed survey. For the special N=2 ring, starting by ring.1.true already samples and freezes the only non-coordinator. If both nodes are idle at that event, this particular counterexample is impossible and the successful-survey progress argument applies. The general claim in the question must cover larger rings, where the unsampled downstream node exists.
