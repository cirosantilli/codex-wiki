This is a safety property: a bad shutdown or a later reactivation has a finite bad CSP trace. Use the CSP traces model. Let V={0,…,N−1}, let A⊆V track active nodes, and let D⊆V track nodes that have announced shutdown. Let Ring contain every message CSP event. Define the following specification over the status-signal alphabet:
Safe(A,D)​=□n∈A∖D​idle.n→Safe(A∖{n},D)□□n∈V∖(A∪D)D=∅​​active.n→Safe(A∪{n},D)□□n∈V∖DA=∅​​shutdown.n→Safe(A,D∪{n}).​
(40)
Use the CSP refinement check
Safe(V,∅)⊑T​System∖Ring.​
(41)
The specification offers a shutdown only if the active set is empty, and offers no activation once D is nonempty. A trace violating either requirement is therefore absent from the specification. Recording D also prevents duplicate shutdowns and any status change by an already shut-down node. CSP hiding removes message details irrelevant to this finite bad-prefix check; a CSP traces model check alone does not assert eventual progress.
The system satisfies the check. After the first message has passed nodes 1,…,i, its bit is the Boolean conjunction of their being idle when sampled. Every sampled node is then frozen until it forwards the second-round decision. A true bit returning to node 0 therefore means that every non-coordinator is idle and still frozen; the coordinator has itself remained idle. A true decision consequently reaches only idle nodes, each of which proceeds to shutdown rather than returning to Free. No node can subsequently become active. A false decision permits no shutdown at all.
