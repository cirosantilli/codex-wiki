Using the standard maximum form of a linear program, write
maxcTxsubject to Ax≤b,x≥0,​
(24)
where x∈Rn, A∈Rm×n, b∈Rm, and c∈Rn. The inequalities are coordinatewise, and cTx is the objective function. General linear programs can be put in this form: reverse the sign of a minimization objective function, reverse lower-bound linear inequalities, replace an equality by two opposite linear inequalities, and replace each unrestricted variable by the difference of two nonnegative variables. Some conventions instead call the equality-constraint version standard form; the convention here is the maximum-with-upper-bounds convention.
Introduce nonnegative slack variables xn+i​=bi​−∑j=1n​aij​xj​. The equivalent slack form of a linear program is
zxn+i​xj​​=j=1∑n​cj​xj​,=bi​−j=1∑n​aij​xj​(1≤i≤m),≥0(1≤j≤n+m).​​
(25)
The original variables are initially nonbasic and the slack variables basic. More generally, a slack form of a linear program specifies disjoint index sets N,B and writes
z=v+∑j∈N​cj​xj​,xi​=bi​−∑j∈N​aij​xj​(i∈B),xi​≥0(i∈N∪B).
(26)
Thus each basic variable and the objective function are expressed using only nonbasic variables. Setting all nonbasic variables to zero gives the associated basic solution, which is a feasible solution exactly when the resulting basic values are nonnegative. The slack form of a linear program does not itself require that initial basic solution to be feasible.
