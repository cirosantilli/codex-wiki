A nondeterministic finite automaton, allowing the epsilon transitions used in this paper, is a tuple
M=(Q,Σ,δ,q0​,F),δ:Q×(Σ∪{ε})⟶P(Q).
(1)
Here Q is a nonempty finite set of automaton states, Σ is a finite alphabet, P(Q) is the power set of Q, q0​∈Q is the initial automaton state, and F⊆Q is the set of accepting automaton states. The symbol ε∈/Σ denotes the empty word. Membership r∈δ(q,a) permits an automaton transition from q to r consuming a when a∈Σ, or consuming nothing when a=ε.
The recognized formal language is
L(M)={w∈Σ∗:some finite path from q0​ to a state in F has label w}.​
(2)
The label of a graph path is the concatenation of its labels with all occurrences of ε omitted. Thus acceptance requires consuming the entire input word; a single successful choice of automaton transitions suffices. A path of length zero is allowed, so the empty word is accepted whenever q0​∈F, or an accepting automaton state is reachable by epsilon transitions. If epsilon transitions are excluded from the definition of a nondeterministic finite automaton, the displayed version is called an Epsilon-NFA.

Use state elimination for finite automata, with regular expression labels on a generalized finite automaton. Add a fresh initial automaton state s with sε​q0​, and a fresh final automaton state f with q2​ε​f. Only f is now accepting. Missing labels represent the empty language, and parallel alternatives are combined by union.
When eliminating an internal automaton state k, update every surviving label by
Rij​⟵Rij​∪Rik​(Rkk​)∗Rkj​.
(5)
The added regular expression describes entering k, traversing its loop zero or more times by Kleene star, and leaving it. This accounts for exactly the graph paths newly bypassing k.
First eliminate q1​. Its only incoming and outgoing labels are both 1, and it has no loop. The graph path through it contributes 11, so the label from q0​ to q2​ becomes
R02​=ε∪11.
(6)
The other relevant labels are still R00​=0, R20​=0, and R2f​=ε.
Next eliminate q2​. It has no loop, so the new loop at q0​ and the new label to f are
R00​R0f​​=0∪(ε∪11)0=0∪110,=(ε∪11)ε=ε∪11.​
(7)
Finally eliminate q0​. The label from s to f is
ε(0∪110)∗(ε∪11).
(8)
Thus an equivalent regular expression is
(0∪110)∗(ε∪11).​
(9)
For an independent interpretation, every completed return to q0​ consumes either 0 or 110: the latter traverses q1​,q2​ before returning. The last visit to q2​ consumes either nothing or 11. Consequently every run of ones has length exactly two, and successive such runs require at least one zero between them. In particular, consecutive copies of 11 without a separating zero are not accepted.

Let A=(Q,{0,1},δ,q0​,F) be a deterministic finite automaton recognizing L. Construct a nondeterministic finite automaton B with automaton state set Q×{0,1}. Its second coordinate records whether the extra zero has already been consumed. Start at (q0​,0) and make exactly the automaton states in F×{1} accepting.
For each q∈Q, i∈{0,1}, and a∈{0,1}, include the ordinary automaton transition
(q,i)a​(δ(q,a),i).
(10)
Also include the extra automaton transition
(q,0)0​(q,1)(q∈Q).​
(11)
This consumes the inserted zero without changing the simulated automaton state of A. At a zero in layer zero, both the ordinary and extra choices are available. There are no automaton transitions from layer one back to layer zero.
If xy∈L, run A on x in layer zero, consume the extra zero by the displayed automaton transition, and run A on y in layer one. The resulting run accepts x0y in B.
Conversely, every accepting run of B starts in layer zero and finishes in layer one, so it uses exactly one extra automaton transition. Split its input as x0y at that move. Removing that consumed zero leaves precisely a run of A on xy, ending in F. Hence xy∈L. The construction also permits an insertion at either end, including insertion into the empty word.
Therefore L(B)=L′. Since B has 2∣Q∣ automaton states, L′ is a regular language. This is a single-symbol insertion into a regular language.
L′=L(B) is regular.​

No: regular languages are not closed under countably infinite intersection. Let Σ={0,1} and put
K={0n1n:n≥0},Li​={w∈Σ∗:∣w∣≥i}∪{0n1n:2n<i},i≥1.
(13)
The first term in Li​ has regular expression (0∪1)i(0∪1)∗, where the fixed power i means i copies. The second term is a finite language, a finite union of single words. Their union is therefore a regular language.
If w∈K, then for each i either ∣w∣≥i or w belongs to the second term, so w∈Li​. If w∈/K, choose i>∣w∣. It belongs to neither term of Li​. Consequently
i=1⋂∞​Li​=K.​
(14)
The formal language K is not a regular language. Indeed, for a proposed pumping length p≥1, the pumping lemma for regular languages applied to 0p1p must pump a nonempty block consisting only of zeros. Repeating that block increases the number of zeros without increasing the number of ones, leaving K. This contradiction proves the counterexample. Finite intersection closure does not extend to this infinite intersection of regular languages.

A nondeterministic pushdown automaton is a tuple
M=(Q,Σ,Γ,δ,q0​,Z0​,F),δ:Q×(Σ∪{ε})×Γ⟶Pfin​(Q×Γ∗).
(15)
Here Q is a nonempty finite set of control states, Σ a finite input alphabet, Γ a finite stack alphabet, q0​∈Q the initial control state, Z0​∈Γ the initial stack symbol, and F⊆Q the final control states. The notation Pfin​ requires each transition to have only finitely many choices. Since the domain is finite, the whole transition specification is finite.
A pushdown automaton configuration is (q,w,α)∈Q×Σ∗×Γ∗, recording the control state, unread input word, and stack contents. Write the top of the stack on the left. For a∈Σ, the one-step relation is
(q,aw,Xβ)⊢M​(r,w,γβ)if (r,γ)∈δ(q,a,X).
(16)
An epsilon transition instead has
(q,w,Xβ)⊢M​(r,w,γβ)if (r,γ)∈δ(q,ε,X).
(17)
Thus a move replaces the top stack symbol X by the word γ, whose leftmost symbol becomes the new top. It consumes one input symbol or no input symbol. Under this convention there is no move from an empty stack.
For acceptance by final state, the recognized formal language is
L(M)={w∈Σ∗:(q0​,w,Z0​)⊢M∗​(f,ε,α) for some f∈F, α∈Γ∗}.​
(18)
Here ⊢M∗​ allows any finite number of moves, including zero. The entire input must have been consumed; the final stack need not be empty. Acceptance requires at least one such run of the nondeterministic pushdown automaton.

A context-free grammar is an ambiguous grammar if some word in its generated formal language has two distinct parse trees. Equivalently, that word has two distinct leftmost derivations from the start nonterminal symbol. A leftmost derivation always expands the leftmost remaining nonterminal symbol.
Two arbitrary grammar derivations of the same word do not by themselves prove ambiguity: expanding independent nonterminal symbols in a different order can describe the same parse tree. Requiring distinct parse trees, or distinct leftmost derivations, avoids that issue.
Ambiguity means two distinct parse trees for at least one word.​

Use the standard conversion of a context-free grammar to a pushdown automaton, implementing a leftmost derivation on a stack. Take control states qs​,q,qf​, input alphabet {a,b}, stack alphabet {S,T,U,a,b,⊥}, initial control state qs​, initial stack symbol ⊥, and sole final control state qf​. The symbol ⊥ is a fresh stack bottom marker. As in part (a), the top of the stack is written on the left.
Initialize with
δ(qs​,ε,⊥)={(q,S⊥)}.
(22)
In control state q, replace a top nonterminal symbol by one of its production rule right-hand sides:
δ(q,ε,S)δ(q,ε,U)δ(q,ε,T)​={(q,UST),(q,ST),(q,ε)},={(q,a),(q,aT)},={(q,b)}.​
(23)
The replacements are written in the order in which they are to be processed. For example, replacing S by UST leaves U on top; an implementation using individual push operations pushes T, then S, then U.
Match and pop top terminal symbols by
δ(q,a,a)={(q,ε)},δ(q,b,b)={(q,ε)}.
(24)
Finally include
δ(q,ε,⊥)={(qf​,⊥)}.
(25)
All unlisted transitions have no choices; qf​ has no outgoing transitions. This is acceptance by final state, leaving the bottom marker on the stack. Taking the last transition too early cannot cause false acceptance, because an unread input suffix remains and qf​ cannot consume it.
For correctness, after initialization the stack contains the unprocessed part of a sentential form. Expanding a top nonterminal symbol simulates one step of a leftmost derivation, and popping a matching terminal symbol transfers it to the already-read input prefix. Thus if the input prefix consumed so far is u and the stack above ⊥ is α, then S⇒G∗​uα. Acceptance gives S⇒G∗​w for the entire input w.
Conversely, any leftmost derivation of w specifies choices of these transitions: expand the next nonterminal symbol, and read each resulting leading terminal symbol when it reaches the top. After all symbols of w are consumed, only ⊥ remains, enabling the move to qf​. The nondeterministic pushdown automaton therefore recognizes exactly L(G). The empty word is accepted by choosing S→ε after initialization.
L(M)=L(G),F={qf​}.​

Every generated word satisfies
#b​(w)≥#a​(w),
(27)
where #a​,#b​ count occurrences of the indicated terminal symbols. To see this, follow the unique chain of S occurrences in a parse tree. Each use of S→UST introduces one a from U, at least one b from its rightmost T, and possibly one further b from U→aT. Each use of S→ST adds one b and no a. The terminating S→ε contributes neither. Hence no generated word has more a symbols than b symbols.
Also, for every n≥0, the word anbn is generated: apply S→UST exactly n times, choose U→a each time, then use S→ε and all remaining T→b.
Suppose L(G) were a regular language, and let p≥1 be a pumping length from the pumping lemma for regular languages. Apply it to w=apbp. Every allowed decomposition w=xyz with ∣xy∣≤p and ∣y∣>0 has y=ar for some r≥1. Pumping twice gives
xy2z=ap+rbp,
(28)
which violates the proved counting inequality and hence is not generated. This contradicts the pumping lemma for regular languages. Therefore L(G) is not a regular language. Ambiguity was not used: the obstruction is the unbounded constraint on symbol counts.
L(G) is not regular.​

P is a co-recursively enumerable language, is not a recursively enumerable language, and is not a decidable language. The stipulated order on halting times includes ∞≥∞.
First, failure has a finite witness. For valid machine descriptions,
⟨N1​,N2​⟩∈/P⟺∃x ∃t∈N:[N1​(x) halts after exactly t transitions]∧[N2​(x) has not halted by t].
(30)
Indeed, a strict inequality t(N1​,x)<t(N2​,x) forces the first halting time to be finite. The second can be either a larger finite time or infinity. Whether the displayed condition holds for fixed x,t is decidable by a finite simulation, including the initial configurations when t=0.
Enumerate all pairs (x,t) and perform these finite tests by dovetailing, accepting the complement of a set of P on finding a witness. Equivalently, at stage s, inspect all inputs of length at most s through s transitions. A genuine violation eventually appears; if there is no violation, the procedure never accepts. Malformed descriptions or differing input alphabets can be recognized and accepted as nonmembers immediately. Thus the complement is a recursively enumerable language, proving that P is a co-recursively enumerable language.
For non-enumerability, use the standard result that the complement of a set of the halting problem
H={⟨M,w⟩:M halts on w}
(31)
is not a recursively enumerable language. Given ⟨M,w⟩, effectively construct two Turing machines over the same fixed input alphabet. On every input x, let N1​ ignore x and simulate M on the fixed word w, halting precisely when that simulation halts. Let N2​ loop forever on every input.
If M does not halt on w, both halting times are infinity for every x, so the pair belongs to P. If M halts on w, the first halting time is finite while the second is infinity, so the pair does not belong to P. Therefore
⟨M,w⟩∈/H⟺⟨N1​,N2​⟩∈P.​
(32)
This is a many-one reduction from non-halting to the pointwise running-time domination problem. Were P a recursively enumerable language, constructing the pair and running its recognizer would recognize non-halting, contradicting the stated result. Hence P is not a recursively enumerable language. Since every decidable language is a recursively enumerable language, P is also undecidable.
P is co-R.E., not R.E., and undecidable.​

Fix a deterministic, single-tape Turing machine with tape cells indexed by the integers. A precise definition is the tuple
M=(Q,Σ,Γ,δ,q0​,qacc​,qrej​),δ:(Q∖{qacc​,qrej​})×Γ⟶Q×Γ×{L,R}.
(34)
Here Q is a nonempty finite set of control states, Γ a finite tape alphabet with a designated blank symbol □, Σ⊆Γ∖{□} the input alphabet, q0​∈Q the initial control state, and qacc​,qrej​∈Q distinct halting control states. The transition function is total on the displayed domain. The Turing machine instruction δ(q,a)=(r,b,D) means to write b over the scanned a, enter control state r, and move the head one cell in direction D.
A Turing machine configuration is (q,τ,h), where q∈Q, h∈Z is the head position, and τ:Z→Γ is the tape-content function, equal to □ outside a finite set. Its next-configuration relation is
(q,τ,h)⊢M​(r,τ′,h+d)
(35)
if δ(q,τ(h))=(r,b,D), with d=−1 for D=L and d=1 for D=R, and
τ′(j)={bτ(j)​j=h,j=h.​
(36)
There is no successor to either halting Turing machine configuration.
For input w=a0​⋯an−1​, the initial Turing machine configuration is C0​(w)=(q0​,τw​,0), where τw​(j)=aj​ for 0≤j<n and is blank elsewhere. In particular, the initial tape for the empty word is entirely blank. The recognized formal language is
L(M)={w∈Σ∗:C0​(w)⊢M∗​(qacc​,τ,h) for some τ,h}.​
(37)
The relation ⊢M∗​ permits any finite number of transitions. An input outside L(M) may reach the rejecting control state or run forever; recognition does not require halting on every input.

The formal language is a regular language. A regular expression for it is
(ab)∗(bc)∗.​
(38)

The formal language is not a regular language. Let K denote it and consider the infinitely many prefixes
ui​=(ab)i,i≥0.
(39)
For any i=j, append the word zi​=(bc)i. Then ui​zi​∈K, whereas uj​zi​∈/K: the latter word has j occurrences of a and i occurrences of c, and every word of K has equal numbers of those two symbols.
Thus ui​ and uj​ are not Myhill-Nerode equivalent. There are infinitely many Myhill-Nerode equivalence classes, so the Myhill-Nerode theorem rules out a finite-state automaton recognizing K. Equivalently, if two such prefixes left a deterministic finite automaton in the same automaton state, appending zi​ could not distinguish their acceptance, giving the same contradiction.
K is not regular.​

The formal language is a context-free language. A context-free grammar with start nonterminal symbol S is
S→AB,A→aAb∣ε,B→bBc∣ε.​
(41)
The production rule for A nests one a on the left and one b on the right on each recursive use, so A generates exactly ambm for m≥0. Similarly, B generates exactly bncn for n≥0. The start production rule concatenates these words, yielding
ambmbncn=ambm+ncn.
(42)
Conversely, every choice of nonnegative integers m,n is achieved by using the recursive production rules exactly m,n times before their epsilon productions. Hence this context-free grammar generates precisely the required formal language, including all cases where either count is zero.

The formal language is not a context-free language. Suppose otherwise, and let p≥1 be a pumping length from the pumping lemma for context-free languages. Choose
w=apbp2cp.
(43)
This word belongs to the formal language, since its middle exponent is the product of the two outer exponents. The pumping lemma for context-free languages would give
w=uvxyz,∣vxy∣≤p,∣vy∣>0,
(44)
with uvixyiz in the formal language for every integer i≥0.
Let α,β,γ be the respective numbers of a,b,c symbols in the two pumped pieces v,y together. The window vxy cannot contain both an a and a c: it would have to contain the entire middle block of length p2, plus at least those two outer symbols, exceeding p. Hence
αγ=0,1≤α+β+γ≤p.
(45)
Pump once extra, taking i=2. The resulting symbol counts are p+α, p2+β, and p+γ. A necessary condition for membership, regardless of whether the block order survives, is
p2+β=(p+α)(p+γ),or equivalentlyβ=p(α+γ),
(46)
where αγ=0 was used.
If α+γ=0, then β>0, contradicting that equality. If α+γ≥1, then
β≤p−(α+γ)<p≤p(α+γ),
(47)
again contradicting it. Thus every permissible decomposition fails at i=2. This contradicts the pumping lemma for context-free languages and proves the claim. The obstruction is the multiplicative block-count language: a bounded local change cannot preserve the product constraint.
{ambmncn:m,n≥0} is not context-free.​

The problem is decidable. We need exactly one accepted word, even if that word has several accepting runs in the nondeterministic finite automaton.
First convert the input nondeterministic finite automaton to an equivalent deterministic finite automaton D using the subset construction, taking epsilon closure where necessary. In the finite transition directed graph of D, test whether an accepting automaton state is reachable from the initial automaton state. This is the standard finite automaton emptiness test. If none is reachable, the recognized formal language is empty, so answer no.
Otherwise retain a graph path to an accepting automaton state and read its labels to obtain one accepted word w. If the initial automaton state is accepting, w may be the empty word. Build a complete deterministic finite automaton for the singleton formal language {w}: it tracks the matching prefix of w, accepts only after exactly its full length, and enters a rejecting sink on a mismatch or any extra input symbol.
Complement that complete deterministic finite automaton by exchanging accepting and rejecting automaton states. Form its product with D, accepting exactly when the D coordinate accepts and the other coordinate accepts. This product recognizes
L(D)∩(Σ∗∖{w})=L(D)∖{w}.
(49)
Apply the finite automaton emptiness test again. Answer yes if and only if this difference is empty. The first test guarantees that w belongs to L(D); the second guarantees there is no different accepted word. All constructions have finitely many automaton states and all reachability tests terminate. This gives a singleton-language test for finite automata.
Decidable: test L(D)=∅ and L(D)∖{w}=∅.​

The problem is undecidable. Reduce the halting problem to it. Given a Turing machine M and input word w, construct a Turing machine T over {a,b,c} with the following behavior on input x:
  • If x=ε, reject.
  • If x=ε, simulate M on the fixed word w. If that simulation ever halts, whether accepting or rejecting, accept x; otherwise continue the simulation forever.
This is an effective construction: M,w are fixed data stored in the description of T. Its recognized formal language is
L(T)={{ε}∅​M halts on w,M does not halt on w.​​
(51)
Therefore T accepts exactly one input word if and only if M halts on w. A supposed decision procedure for the singleton-language problem for Turing machines, applied to the constructed T, would decide the halting problem. The standard undecidability of the halting problem excludes that possibility.
The singleton-language problem for Turing machines is undecidable.​
