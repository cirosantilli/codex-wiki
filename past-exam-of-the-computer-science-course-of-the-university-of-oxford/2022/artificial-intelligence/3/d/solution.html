Write F⊆{1,…,N}2 for the prescribed occupied cells, with k=∣F∣. The source’s lowercase n in its coordinate bound is read as the stated board size N. If two prescribed queens already attack each other, no completion exists. Each model below correctly expresses that impossibility as well as consistent inputs.
Model 1: one Boolean variable per cell. Let Brc​∈{0,1} indicate occupancy. Require
∑r=1N​∑c=1N​Brc​=N,Brc​=1((r,c)∈F),
(17)
and impose Brc​+Bst​≤1 for every two distinct cells sharing a row, a column or a diagonal. Equivalently, impose exactly one queen in each row and column and at most one on each diagonal. Explicit diagonal constraints are
∑r−c=d​Brc​≤1(−(N−1)≤d≤N−1),∑r+c=u​Brc​≤1(2≤u≤2N).
(18)
Together with the total-count constraint and the attacking-pair binary constraints, these force exactly the intended boards. The count and diagonal-sum constraints are legitimate many-variable constraints; this model need not be binary.
Model 2: one variable per labeled queen. Let Qi​=(Ri​,Ci​)∈{1,…,N}2 for 1≤i≤N. Enumerate F={f1​,…,fk​} and restrict Di​={fi​} for i≤k. For every i<j, impose the binary constraint
Ri​=Rj​,Ci​=Cj​,∣Ri​−Rj​∣=∣Ci​−Cj​∣.
(19)
There are exactly N variables and distinct rows, so these are N distinct queens. Labeling the prescribed queens does not lose a board completion: the queens are physically indistinguishable, and any completion can be labeled to give the prescribed ones those indices. It does create redundant assignments for the remaining labels.
Model 3: one variable per row. Let Cr​∈{1,…,N} be the queen’s column in row r. For every r<s, require
Cr​=Cs​,∣Cr​−Cs​∣=s−r,
(20)
and impose Cr​=c for every (r,c)∈F. These restrictions give N queens, one per row; the all-different constraint on the columns gives one per column. For N nonattacking queens on N rows, exactly one per row is forced by the pigeonhole principle, so no solutions are lost. Inconsistent prescribed positions in a single row give incompatible unary restrictions. All three are exact constraint satisfaction problem encodings of the queens completion problem.
