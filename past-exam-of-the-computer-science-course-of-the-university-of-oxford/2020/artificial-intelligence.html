With the conventional strictly positive step costs, the five answers in printed order are false, false, true, true, true. The third answer needs that positivity convention: it is false in general if zero-cost edges and unrestricted ties are admitted. Take the goal test on selection from the search frontier, and assume a finite reachable problem with a reachable goal state; finite branching factor and a positive lower bound on step costs give the corresponding tree search guarantees on an infinite problem. These assumptions make the usual A-star search guarantees precise.[ref]
For the first assertion, use a directed graph with transitions s→t of cost 10, s→x of cost 1 and x→t of cost 1, where t is the only goal state. The perfect heuristic is h∗(s)=2, h∗(x)=1, h∗(t)=0. Greedy best-first search selects the direct goal of cost 10 because its priority is zero. The least path cost is 2. Knowing the exact remaining distance does not account for an expensive transition already taken.
The same counterexample settles the second assertion. Greedy best-first search selects s,t, while A-star search selects s,x,t: after expanding s, the A-star search priorities are 2 for x and 10 for the direct copy of t. Thus even the expanded state sets differ.
For the third assertion, let the current nonterminal search node have finite remaining distance h∗(s). The first transition of a least-cost continuation has some successor s′ with
h∗(s)=c(s,s′)+h∗(s′)>h∗(s′).
(1)
Every older entry in the search frontier has estimate at least h∗(s), since the current entry was selected with minimum estimate. A newly generated successor with strictly smaller estimate therefore wins over every older entry. Whichever new successor is selected has smaller remaining distance than the current search node, so the argument repeats. Consequently the selected search nodes form one parent–child chain; include the selected goal, or append it if “expanded” excludes goal processing. This greedy perfect-heuristic descent does not imply least path cost, as the first counterexample demonstrates.
The zero-cost qualification is substantive. Give s two successors a,b of cost 1, add a→x of cost 0, and add x→t and b→t of cost 1. The perfect heuristic has values 2 at s, 1 at a,b,x and 0 at t. Alphabetical priority ties let greedy best-first search select s,a,b,t, which is not one graph path. Thus the unqualified third assertion requires a cost or tie convention absent from the printed text.
For the fourth assertion, a least remaining distance satisfies
h∗(s)≤c(s,s′)+h∗(s′)
(2)
on every edge, by taking that edge and then a least-cost continuation. Thus h∗ is a consistent heuristic. The usual A-star search graph search finalizes each expanded state's least path cost and returns a least-cost goal.
For the fifth assertion, write C∗=h∗(s0​). Before a goal is selected, an unexpanded prefix of an optimal graph path remains on the search frontier, with f=g+h∗=C∗. A-star search therefore selects only search nodes with f≤C∗. Since g≥0,
h∗(n)≤g(n)+h∗(n)≤C∗=h∗(s0​).​
(3)
This compares remaining cost, not search depth or accumulated path cost. The statement can fail with negative costs; those are outside the convention used here.

Let the input words be s,t, let L be their common length, let Σ be the finite alphabet, and let DL​ contain the dictionary words of length L. Unequal input lengths immediately make the puzzle impossible because a mutation preserves length. A word ladder search problem can use the state space S=DL​∪{s}, with initial state s; including s handles an input word not itself in the dictionary.
At word w, an action is a position–letter pair (i,ℓ) with 1≤i≤L, ℓ∈Σ and ℓ=wi​, permitted precisely when replacing wi​ by ℓ gives w′∈DL​. The search transition model returns that w′, and the goal test is w=t. If s=t, the empty sequence is accepted; if t∈/DL​ and s=t, no transition can reach t.
Assign each permitted transition cost 1. A search node at search depth k has
g(n)=j=1∑k​1=k.​
(4)
Thus minimizing path cost is exactly minimizing the number of mutations. Uniform-cost search, with repeated states handled by graph search and the goal test on selection, finds a shortest word ladder if one exists. Because all costs are equal, breadth-first search gives the same optimal-length guarantee.

The proposed Hamming distance is both an admissible heuristic and a consistent heuristic. Write
h(w)=∣{i:wi​=ti​}∣.
(5)
Every position differing from the target must change at least once along any successful word ladder. One mutation changes only one position, so every solution from w has at least h(w) steps. This proves h(w)≤h∗(w), including an unreachable target with h∗(w)=∞. Dictionary restrictions may force extra changes, but cannot remove that lower bound.
Adjacent words differ in one position, so their Hamming distances to t differ by at most one. Since every transition costs one,
h(w)≤1+h(w′),h(t)=0.
(6)
These are exactly the consistent heuristic conditions. Equivalently, allowing all length-L words gives a relaxation heuristic whose exact distance is the Hamming distance; restoring the dictionary can only increase the minimum required number of steps.

The difficulty is representing dictionary membership and the one-letter relationship in positive conjunctive STRIPS preconditions; a finite dictionary nevertheless admits an exact encoding. Pure STRIPS does not provide string indexing, a “differs in one position” operator, arbitrary disjunctive tests or a procedure that calls a dictionary lookup. Those relationships must be represented by ground facts or compiled into ground actions.
One exact whole-word encoding uses a planning fluent At(w) and a static predicate Next(w,w′) containing exactly the permitted dictionary mutations. For the action schema Change(w,w′), use
PreAddDel​={At(w),Next(w,w′)},={At(w′)},={At(w)}.​
(7)
Initialize At(s) and the static transition facts, and use goal At(t). Only one At fact is true initially. Each applicable ground action deletes it and adds exactly its permitted successor, so mathematical induction proves that exactly one current-word fact remains true and that every plan is a legal word ladder. Conversely, every legal word ladder directly supplies a plan. An isolated non-dictionary start is handled as in (c). A shortest plan has the fewest mutations.
This encoding moves the hard lexical relationship into preprocessing. For N dictionary words, checking all ordered pairs takes O(N2L) character comparisons, although indexing can do better; the number of stored transitions is at most NL(∣Σ∣−1) when all states are dictionary words. The STRIPS representation is finite, but its size and preprocessing cost matter.
A position-based representation instead uses planning fluents Letter(i,ℓ). Changing position i must delete its old letter and add its new one; all other positions persist through the STRIPS update rule. Merely requiring each position to contain a letter admits non-dictionary strings. A disjunction over all dictionary words is not a positive conjunctive STRIPS precondition. It can be compiled into separate ground actions, each requiring every letter of a valid source word and changing one position to reach a valid destination. This again enumerates lexical cases and can be large. Arbitrary letter changes followed by an unconstrained “validate” action are unsound: several illegal intermediate strings could otherwise lead to a legal goal. Legality must hold after every mutation, not only at the endpoint.

For a finite constraint satisfaction problem, remove values violating unary restrictions before starting. The following backtracking algorithm makes independent copies of constraint domains at each branch, so failed forward checking cannot contaminate a sibling branch.
SOLVE(P):
    D := domains of P after unary filtering
    if some D[X] is empty: return failure
    return SEARCH({}, D)

SEARCH(assignment, D):
    if every variable is assigned: return assignment
    X := SELECT-UNASSIGNED-VARIABLE(assignment, D, P)
    for v in ORDER-DOMAIN-VALUES(X, assignment, D, P):
        if X=v is compatible with the current assignment:
            next_assignment := assignment extended by X=v
            next_domains := a deep copy of D
            next_domains[X] := {v}
            if INFERENCES(X, v, next_assignment, next_domains, P) succeeds:
                result := SEARCH(next_assignment, next_domains)
                if result is not failure: return result
    return failure
SELECT-UNASSIGNED-VARIABLE implements minimum remaining values: choose an unassigned variable with the smallest current constraint domain. Break ties by the degree heuristic, choosing the variable constrained to the greatest number of other unassigned variables; a fixed final tie rule makes execution reproducible. ORDER-DOMAIN-VALUES may use any complete ordering; ascending values suffice here.
INFERENCES implements forward checking: for each unassigned neighbor Y of X, remove every value incompatible with X=v, and fail if any constraint domain becomes empty. For higher-arity constraints, reject any completely instantiated violation and use a sound chosen filtering rule; the stated neighbor test is the usual binary case. Forward checking never removes a value used by a possible extension of the current assignment. Exhausting every surviving value therefore makes this finite backtracking procedure both sound and complete.[ref][ref]

Forward checking makes minimum remaining values respond to current restrictions rather than the original constraint domain sizes. After X=v, its neighbors may have fewer choices, become forced or lose all choices. Minimum remaining values then selects the newly constrained variable early, while an empty constraint domain triggers immediate failure. The two mechanisms expose failure sooner and reduce wasted backtracking.
Forward checking only tests an unassigned neighbor against the newly assigned value. It need not check whether two still-unassigned variables have mutually supporting values. Arc consistency requires every value at either end of each binary constraint to have support in the other constraint domain, and AC-3 propagates deletions until this condition stabilizes or a constraint domain becomes empty.[ref]
For example, let X,Y,Z initially have constraint domains {1,2} with constraints X=Y and Y=Z. Assigning X=1 makes forward checking reduce DY​ to {2}, but leaves DZ​={1,2}. Arc consistency also deletes 2 from DZ​, leaving {1}. Neither procedure alone decides every general constraint satisfaction problem: a triangle of two-valued inequalities satisfies arc consistency but is unsatisfiable.

Cutset conditioning selects a cycle cutset C: deleting its vertices makes the binary constraint graph a forest. Enumerate assignments to C, reject those violating internal constraints, and filter each remaining constraint domain against the chosen cutset values. Solve the residual components by tree-structured constraint satisfaction. Stop at a successful assignment, or report failure after all cutset assignments fail. Completeness follows by considering the restriction of any full solution to C; soundness follows by checking internal, crossing and residual constraints. With maximum constraint domain size q and k cutset variables, a typical bound is O(qk(n−k)q2) for the residual forest work, with cutset and crossing checks added explicitly.[ref]
Here take C={c,e}. The residual constraint graph has vertices a,b,d and only edges ab,ad, a tree rooted at a. Choose the consistent cutset values c=3,e=1. Filtering against these assignments gives
Da​={1,2},Db​={2},Dd​={2,4}.
(13)
The upward support pass from b deletes a=2, because b can only equal 2. The pass from d retains a=1, which has support 2 or 4. Assign a=1 at the root and then supported child values b=2,d=2. Together with c=3,e=1, this gives the solution in (c).
No singleton cycle cutset exists: deleting a,b,d or e leaves, respectively, a triangle on bce,acd,abc or abc; deleting c leaves the cycle in a graph a−b−e−d−a. Thus the two-element choice is also minimum, although the algorithm only requires a valid cutset.

Use an exactly-one constraint for each finite-domain variable and a Boolean clause forbidding each disallowed constraint tuple. Let the variables be X1​,…,Xn​, with explicitly listed finite constraint domains Di​, and let constraint C have distinct-variable scope SC​ and allowed relation RC​⊆∏i∈SC​​Di​. Introduce a Boolean variable pi,v​ for every v∈Di​, interpreted as Xi​=v. The direct SAT encoding of finite-domain constraints is
φP​=⋀i​[(⋁v∈Di​​pi,v​)∧⋀{u,v}⊆Di​, u=v​(¬pi,u​∨¬pi,v​)]∧⋀C​ ⋀t∈FC​​(⋁i∈SC​​¬pi,ti​​),FC​=(∏i∈SC​​Di​)∖RC​.
(14)
In the middle logical conjunction, each unordered distinct pair is included once. The first Boolean clause requires at least one value, the pairwise Boolean clauses permit at most one, and a final Boolean clause is false exactly when all coordinates of one forbidden tuple are selected. The formula is in conjunctive normal form. An empty constraint domain produces an empty Boolean clause, correctly making the instance unsatisfiable.
For soundness of the reduction, a solution x of the constraint satisfaction problem gives the Boolean valuation pi,v​=1 exactly when v=xi​. Every exactly-one constraint holds; a forbidden tuple differs from x on at least one scoped coordinate, making its negative Boolean clause true. Thus x supplies a satisfying assignment for φP​.
Conversely, a satisfying assignment selects a unique value xi​ for every Xi​. If a constraint failed, the selected scoped tuple would belong to FC​, and its entire negative Boolean clause would be false. That contradicts satisfiability. Hence x is a solution. Decoding takes O(∑i​∣Di​∣) by scanning the value indicators. This proves P has a solution if and only if φP​ is satisfiable.
For explicit size accounting, put qi​=∣Di​∣, rC​=∣SC​∣ and fC​=∣FC​∣. There are ∑i​qi​ Boolean variables,
K=n+∑i​(2qi​​)+∑C​fC​
(15)
Boolean clauses, and
L=∑i​qi​+2∑i​(2qi​​)+∑C​rC​fC​
(16)
literal occurrences. These formulas count nonempty scopes; a false zero-arity constraint contributes an empty Boolean clause, while a true one contributes none. Formula storage is O(K+L) literal-sized records; a bit-level encoding also stores indicator indices. With maximum constraint domain size q, m constraints and maximum arity r, this is bounded by O(nq2+mrqr) for nontrivial domains and scopes. In the common binary case it is O((n+m)q2).
The input representation matters: listing all forbidden tuples costs up to ∏i∈SC​​qi​ tests per constraint. This is polynomial for bounded arity and explicitly represented domains, but can be exponential in the description length of a succinct high-arity constraint. The translation is valid in that case without constituting a polynomial-size reduction. If a compact constraint is supplied as a polynomial-size Boolean circuit, one may instead encode that circuit using auxiliary Boolean variables and local conjunctive normal form equivalences, with size proportional to the circuit. No compact representation is silently assumed.
For the instance in (c), after unary filtering there are 17 indicators. The five at-least-one Boolean clauses, 22 pairwise at-most-one Boolean clauses and 24 forbidden-equality Boolean clauses give 51 Boolean clauses. Setting only pa,1​,pb,2​,pc,3​,pd,2​,pe,1​ true encodes the displayed solution.

The translation gives a sound and complete route through an optimized SAT solver; it trades access to general-purpose SAT machinery against encoding cost and the possible loss of constraint-specific structure. Modern SAT solvers use efficient unit propagation, adaptive branching and clause learning. Learned Boolean clauses can summarize conflicts involving many original variables, allowing later branches to avoid repeating the same failed combination. The reduction also offers a standard, reusable interface: improvements to a SAT solver can benefit many finite-domain constraint satisfaction problems.
The Boolean formula may be much larger than the original constraint satisfaction problem, especially for a succinct high-arity relation. One original variable becomes many indicators, and general branching may lose the interpretation that the minimum remaining values and degree heuristic exploit directly. Native constraint propagation can exploit a relation without enumerating all its forbidden tuples. Even in the binary case, stronger propagation does not follow just from switching to SAT.
For example, take DX​={1,2}, DY​={a,b,c}, and let the only allowed pairs be (1,c),(2,a),(2,b). The forbidden-pair encoding contains ¬pX,1​∨¬pY,a​ and ¬pX,1​∨¬pY,b​. If pY,c​ becomes false, arc consistency deletes X=1 because it has no support. Yet the direct encoding has no unit Boolean clause forcing ¬pX,1​: both a,b remain possible individually, so plain unit propagation does not make that deletion. A SAT solver can eventually derive it through additional reasoning or search. Conversely, clause learning can combine information beyond the local consistency enforced by AC-3. Neither approach uniformly dominates: performance depends on representation, propagation strength and the instance's structure; both still face exponential worst-case search on general inputs.

Depth-first search computes minimax search values with much less live storage and naturally supports alpha-beta pruning. A parent's value needs only its current best child value and the next child to visit. Once a child subtree has been evaluated, its internal search nodes can be discarded; a final value cannot usually be computed from a nonterminal frontier alone.
With branching factor b and horizon d, breadth-first search stores a frontier of order bd. A depth-first search implementation storing sibling lists uses O(bd) space complexity; lazy successor generation can reduce this to O(d) frames plus game-state storage. Both unpruned traversals have O(bd) time complexity for b>1. Depth-first search also supplies a completed sibling outcome early, allowing alpha-beta pruning to reject later subtrees before generating them.

Use utilities from A's viewpoint, with A maximizing and B minimizing. The following alpha-beta pruning code assumes a finite horizon or terminating game tree; leaf evaluation uses terminal utility when available and a specified horizon estimate otherwise.
ALPHABETA(state, depth, alpha, beta, maximizing):
    if state is terminal or depth == 0:
        return EVALUATE(state)
    if maximizing:
        value := -infinity
        for child in SUCCESSORS(state):
            value := max(value, ALPHABETA(child, depth-1, alpha, beta, false))
            alpha := max(alpha, value)
            if alpha >= beta: break
        return value
    else:
        value := +infinity
        for child in SUCCESSORS(state):
            value := min(value, ALPHABETA(child, depth-1, alpha, beta, true))
            beta := min(beta, value)
            if alpha >= beta: break
        return value
Call the root with (−∞,+∞) and record the child giving the greatest root value. In a nonterminal game state, SUCCESSORS must supply the game's legal moves, including any mandatory pass; a player with no moves must be handled according to the rules rather than left as an accidental empty loop.
The bound α records an outcome already available to MAX on the active ancestor path; β records one already available to MIN. At a MIN node, once a child gives value at most α, further children can only decrease the node's minimum, so MAX need not choose that branch. The dual argument applies at MAX when its current value is at least β. Returned values from cut-off subtrees can be bounds rather than exact local minimax search values, while the unrestricted root value is exact. Equal-value pruning preserves that value; retaining the first best root action gives a fixed tie rule.[ref]

With excellent move ordering, the new horizon is approximately 2d; without a move ordering assumption, no doubling is guaranteed. For b>1, a full minimax search to depth d visits Θ(bd) search nodes, so the budget n has d≈logb​n. Perfectly ordered alpha-beta pruning evaluates only about Θ(bd′/2) leaves at depth d′. More precisely, for a complete uniform game tree, the best leaf count is b⌈d′/2⌉+b⌊d′/2⌋−1. Equating the dominant costs gives
bd′/2≈n≈bd,d′≈2logb​n≈2d.​
(17)
Constant factors and rounding affect the exact horizon. Poor move ordering can leave the cost at Θ(bd′), giving no asymptotic depth improvement. For b=1, there is no branching to prune and the doubling argument does not apply.[ref]

Propagate an entire utility pair from a child chosen to maximize the component of the player whose turn it is. This is the two-player case of max-n search. At a terminal node let V(s)=(UA​(s),UB​(s)). At an A-node choose
s∗∈argmaxs′∈Children(s)​VA​(s′),V(s)=V(s∗),

The usual alpha-beta pruning inference fails because increasing B's utility need not decrease A's utility. A partially explored B-node may have found a child unfavorable to A, but B may prefer an unseen child favorable to A as well. An observed low A-coordinate therefore supplies no upper bound on the A-coordinate ultimately propagated by B.
For a concrete counterexample, let a root A-node already have an alternative outcome (1,0). In another B-node, the first explored child yields (0,1). A zero-sum-style cutoff would discard its remaining children because 0<1. But an unseen child with outcome (100,2) is preferred by B, and makes the complete B-node return (100,2), which A strictly prefers to its incumbent. Such a cutoff changes the answer.
The problem persists even after observing a large B-coordinate: without a known relation between coordinates or useful global utility bounds, an unseen pair may have still larger values for both players. Hence there is no generally valid ordinary scalar alpha-beta pruning rule for unrestricted general-sum games. This does not rule out all search pruning: additional bounds, dominance information or a relationship between players' utilities can justify specific cutoffs, as in (g).

Consider a B-node whose parent is an A-node with an already completed incumbent outcome having A-coordinate α. At the B-node, let (x,y) be the best completed child pair found so far according to B's coordinate. Every remaining child can be skipped, and this B-option discarded by its parent, if
ϵ−y≤α,equivalently y≥ϵ−α.​
(22)
Use a strict inequality if ties must remain open; equality is safe under the fixed rule that the parent retains its already selected child on an A-coordinate tie. This is a nearly-zero-sum pruning rule.
To prove it, note first that a completed max-n search value is some terminal utility pair: each backup copies one entire child pair. Thus the nearly-zero-sum inequality holds at every completed subtree, not just at leaves. Since B maximizes its own coordinate, the ultimately selected pair (u,v) at this B-node has v≥y. Therefore
u+v≤ϵ⟹u≤ϵ−v≤ϵ−y≤α.
(23)
The already available A-option is at least as good, so remaining children of this B-node cannot alter the parent's selected continuation under the stated tie rule. The second half of the two-sided nearly-zero-sum condition also gives x+y≥−ϵ, hence
u≤ϵ−y≤x+2ϵ.
(24)
Consequently x+2ϵ≤α is another sufficient cutoff, useful if one phrases the test using the observed A-coordinate. The pair-based test is sharper: the value of y can certify a cutoff even when the conservative x+2ϵ test cannot.
When ϵ=0, every pair satisfies y=−x, and the rule reduces to x≤α, the ordinary MIN-node alpha-beta pruning cutoff. The extra 2ϵ in the A-coordinate-only condition is necessary in general: an observed pair (−1,0) satisfies the bound for ϵ=1, but B prefers an unseen (1−δ,δ) for 0<δ<1. A increases by almost 2ϵ; using just x+ϵ as the upper bound would be invalid.
Implementation must discard the ruled-out B-option at its parent rather than return (x,y) as an exact completed utility pair. The proof uses an actual completed alternative at that parent; it does not authorize passing arbitrary distant ancestor bounds through general-sum game backups as if every scalar alpha-beta pruning invariant still held. With these local certified cutoffs, an induction over completed subtrees preserves the selected pair and hence the root outcome.
