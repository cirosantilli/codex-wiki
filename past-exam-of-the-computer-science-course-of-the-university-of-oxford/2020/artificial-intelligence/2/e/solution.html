Use an exactly-one constraint for each finite-domain variable and a Boolean clause forbidding each disallowed constraint tuple. Let the variables be X1​,…,Xn​, with explicitly listed finite constraint domains Di​, and let constraint C have distinct-variable scope SC​ and allowed relation RC​⊆∏i∈SC​​Di​. Introduce a Boolean variable pi,v​ for every v∈Di​, interpreted as Xi​=v. The direct SAT encoding of finite-domain constraints is
φP​=⋀i​[(⋁v∈Di​​pi,v​)∧⋀{u,v}⊆Di​, u=v​(¬pi,u​∨¬pi,v​)]∧⋀C​ ⋀t∈FC​​(⋁i∈SC​​¬pi,ti​​),FC​=(∏i∈SC​​Di​)∖RC​.
(14)
In the middle logical conjunction, each unordered distinct pair is included once. The first Boolean clause requires at least one value, the pairwise Boolean clauses permit at most one, and a final Boolean clause is false exactly when all coordinates of one forbidden tuple are selected. The formula is in conjunctive normal form. An empty constraint domain produces an empty Boolean clause, correctly making the instance unsatisfiable.
For soundness of the reduction, a solution x of the constraint satisfaction problem gives the Boolean valuation pi,v​=1 exactly when v=xi​. Every exactly-one constraint holds; a forbidden tuple differs from x on at least one scoped coordinate, making its negative Boolean clause true. Thus x supplies a satisfying assignment for φP​.
Conversely, a satisfying assignment selects a unique value xi​ for every Xi​. If a constraint failed, the selected scoped tuple would belong to FC​, and its entire negative Boolean clause would be false. That contradicts satisfiability. Hence x is a solution. Decoding takes O(∑i​∣Di​∣) by scanning the value indicators. This proves P has a solution if and only if φP​ is satisfiable.
For explicit size accounting, put qi​=∣Di​∣, rC​=∣SC​∣ and fC​=∣FC​∣. There are ∑i​qi​ Boolean variables,
K=n+∑i​(2qi​​)+∑C​fC​
(15)
Boolean clauses, and
L=∑i​qi​+2∑i​(2qi​​)+∑C​rC​fC​
(16)
literal occurrences. These formulas count nonempty scopes; a false zero-arity constraint contributes an empty Boolean clause, while a true one contributes none. Formula storage is O(K+L) literal-sized records; a bit-level encoding also stores indicator indices. With maximum constraint domain size q, m constraints and maximum arity r, this is bounded by O(nq2+mrqr) for nontrivial domains and scopes. In the common binary case it is O((n+m)q2).
The input representation matters: listing all forbidden tuples costs up to ∏i∈SC​​qi​ tests per constraint. This is polynomial for bounded arity and explicitly represented domains, but can be exponential in the description length of a succinct high-arity constraint. The translation is valid in that case without constituting a polynomial-size reduction. If a compact constraint is supplied as a polynomial-size Boolean circuit, one may instead encode that circuit using auxiliary Boolean variables and local conjunctive normal form equivalences, with size proportional to the circuit. No compact representation is silently assumed.
For the instance in (c), after unary filtering there are 17 indicators. The five at-least-one Boolean clauses, 22 pairwise at-most-one Boolean clauses and 24 forbidden-equality Boolean clauses give 51 Boolean clauses. Setting only pa,1​,pb,2​,pc,3​,pd,2​,pe,1​ true encodes the displayed solution.
