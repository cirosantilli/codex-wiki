Let Z be the set of isolated vertices of the finite simple graph G=(V,E). Introduce a nonnegative integer xv​ for every vertex. Use the integer program
maximizesubject to​v∈V∑​xv​xu​+xv​≤1xv​≤1xv​≥0,xv​∈Z​​for every {u,v}∈E,for every v∈Z,for every v∈V.​​
(8)
Every nonisolated vertex belongs to an edge, whose inequality and the other endpoint's nonnegativity already imply xv​≤1. The explicit bounds on Z therefore make all variables binary. For an integer feasible point, S={v:xv​=1} is an independent set, and its cardinality is the objective. Conversely the indicator vector of any independent set is feasible. Thus the optimal value is the maximum independent set size. Including the isolated-vertex bounds is essential for an arbitrary graph; without them the formulation would be unbounded whenever an isolated vertex is present.
