Use nonnegative amounts on the original directed edges of the flow network. A feasible flow is a function f:E→R≥0​ satisfying the capacity constraints f(u,v)≤c(u,v) and flow conservation at every internal vertex:
∑u:(u,v)∈E​f(u,v)=∑w:(v,w)∈E​f(v,w)(v∈/{s,t}).
(1)
Its flow value is net outflow at the source,
∣f∣=v:(s,v)∈E∑​f(s,v)−u:(u,s)∈E∑​f(u,s).​
(2)
Summing flow conservation shows that this is also net inflow at the sink. Subtracting incoming flow matters when the source has incoming edges.
An s–t cut of a flow network is a partition of a set (S,V∖S) with s∈S and t∈/S. Its cut capacity is the total outward flow network edge capacity,
c(S,V∖S)=∑(u,v)∈E:u∈S,v∈/S​c(u,v).
(3)
Incoming edges do not contribute to this sum. Equivalently, one may use the antisymmetric net-flow convention, but the nonnegative arc convention above will also be used in the subsequent reductions.

Sum net outflow over all vertices in the source side S. An internal directed edge occurs once positively and once negatively, so it cancels. All internal vertices have zero net outflow by flow conservation, and the sink is outside S. Therefore
∣f∣=∑(u,v)∈Eu∈S,v∈/S​​f(u,v)−∑(u,v)∈Eu∈/S,v∈S​​f(u,v).
(4)
The second sum is nonnegative, while every term in the first satisfies its capacity constraint. Consequently,
∣f∣≤(u,v)∈Eu∈S,v∈/S​∑​c(u,v)=c(S,V∖S).​
(5)
This is direct accounting from flow conservation; it does not invoke the max-flow min-cut theorem.

A path-cycle matching is exactly an edge subset whose resulting subgraph has maximum degree at most two: every nontrivial connected component of a graph of this form is a graph path or a cycle in a graph. Thus the task is a bipartite b-matching problem with bound two at every vertex.
Find a bipartition L,R, orient every original edge from L to R, and add a source s and sink t. Give each arc s→u, for u∈L, flow network edge capacity two; each original arc u→v flow network edge capacity one; and each arc v→t, for v∈R, flow network edge capacity two. Compute an integral maximum flow and select the original edges whose flow is one. The integral max-flow theorem guarantees such an integral optimum.
By flow conservation, at most two selected edges touch each vertex, so they decompose into the required vertex-disjoint paths and cycles in a graph. Conversely, any permissible path-cycle matching gives a feasible flow: send one unit through its middle arc for each selected edge, with the outside arc amounts equal to the endpoint degrees. In both directions, the flow value equals the number of selected edges. Maximizing either quantity therefore maximizes the other.
The blue edges in this example form a four-cycle in a graph and a one-edge graph path; the dashed edge is unused. Their five units of flow are optimal: the two left vertices a,b can each contribute at most two selected edges, and c has only one incident edge.
The constructed flow network has ∣V∣+2 vertices and ∣E∣+∣V∣ arcs. A polynomial-time algorithm for maximum flow, such as the Edmonds–Karp algorithm, followed by a traversal of the selected subgraph, gives an efficient solution.

Separate the forced integer portion from the choice of rounding direction. Put pij​=⌊aij​⌋ and qij​=aij​−pij​. Define residual demands
ri​=∑j​qij​=∑j​aij​−∑j​pij​,cj​=∑i​qij​=∑i​aij​−∑i​pij​.
(6)
These are nonnegative integers, since the original row and column sums are integers. Also ∑i​ri​=∑j​cj​=:T. Each fractional part satisfies 0≤qij​<1.
Construct a flow network with a vertex for each row and column, source-to-row arcs of flow network edge capacity ri​, row-to-column arcs of flow network edge capacity one exactly where qij​>0, and column-to-sink arcs of flow network edge capacity cj​. The amounts qij​ themselves define a fractional feasible flow of flow value T. No flow can exceed T, the total source flow network edge capacity. Because all constructed flow network edge capacities are integers, an integral maximum flow also has flow value T and saturates every source and sink arc.
Let hij​ be its middle-arc flow, taking hij​=0 when that arc is absent. Then hij​∈{0,1}, and the required answer is
bij​=⌊aij​⌋+hij​.​
(7)
At an already integral entry no middle arc exists, so that entry stays fixed. At a nonintegral entry the two possibilities are precisely its floor and ceiling. Flow conservation gives ∑j​hij​=ri​ and ∑i​hij​=cj​, preserving every original row and column sum.
This is matrix rounding with fixed margins. There are m+n+2 vertices and at most mn+m+n arcs. Exact rational arithmetic computes the floors and residual demands in polynomial time in the encoded input length; the resulting flow network edge capacities are small integers, so there is no need to scale by a potentially large common denominator.

First give w the vote of every voter whose allowed set contains w. Let their number be K. This loses no possible strict victory: starting with any winning assignment, changing such a ballot to w increases w's score and weakly decreases an opponent's score. Thus a winning assignment exists exactly when one exists with these K ballots fixed.
Every remaining voter must now be assigned to an allowed opponent, and each opponent may receive at most K−1 votes. If any allowed set is empty, there is no valid election assignment. With at least two candidates, K=0 immediately makes a unique victory impossible. With only the candidate w, every nonempty ballot set forces that candidate, so the answer is yes under the question's strict-comparison definition.
For the remaining case K≥1, make a flow network with a vertex for each remaining voter and each opponent. Add source-to-voter arcs of flow network edge capacity one, voter-to-opponent arcs of flow network edge capacity one for the allowed choices, and opponent-to-sink arcs of flow network edge capacity K−1. Compute an integral maximum flow. Then
w can be the unique winner⟺∣fmax​∣=n−K.​
(8)
A flow saturating all voter arcs assigns each remaining voter to exactly one allowed opponent, by integrality and flow conservation. The sink-arc capacity constraints give every opponent strictly fewer than K votes. Conversely, any winning assignment with the fixed K votes defines just such a saturating feasible flow. The flow network has at most n+m+2 vertices and O(n+m+∑i​∣Ci​∣) arcs, hence the decision takes polynomial time.

An extreme point p∈P cannot be written as a nontrivial convex combination of two distinct points of P: if p=λu+(1−λ)v with u,v∈P and 0<λ<1, then u=v=p.
A vertex of a linear polyhedron is a feasible point at which the active constraints include n linearly independent row normals. Equivalently, some n independent bounding hyperplanes intersect uniquely at that point. This definition does not require P to be bounded or full-dimensional. For a linear polyhedron, it is also equivalent to the point uniquely maximizing a suitable linear function: sum the selected active inequalities to construct one such linear function.

Only z,w have printed nonnegativity restrictions; x,y are unrestricted. In four-dimensional space, a vertex of a linear polyhedron needs four independent active constraints. There are exactly four available constraints, so all must be active. Solving them gives
z=w=0,y=3,2x−y=1,
(12)

One can also see uniqueness geometrically from the slack variables s1​=1−2x+y−5w and s2​=3−y−z−w. The feasible region is in affine bijection with the nonnegative orthant in (s1​,s2​,z,w):
y=3−s2​−z−w,x=2−21​s1​−21​s2​−21​z−3w.
(13)
That orthant has only the origin as an extreme point, giving the same unique vertex of a linear polyhedron.

Let B=AT and choose any column probability vector q, for example the first coordinate unit vector. Because A has nonnegative entries and each row sums to one, B maps the probability simplex
Δ={v∈Rn:v≥0, 1Tv=1}
(24)
into itself: Bv≥0 and 1TBv=(A1)Tv=1Tv=1.
The iterates Bjq need not converge, so take their arithmetic averages,
xN​=N1​∑j=0N−1​Bjq∈Δ.
(25)
A telescoping sum gives
BxN​−xN​=NBNq−q​.
(26)
Both vectors on the right before subtraction have L1 norm one, so ∥BxN​−xN​∥1​≤2/N→0.
The probability simplex is closed and bounded in finite-dimensional Euclidean space, hence compact by the Heine-Borel theorem. It follows that a subsequence xNj​​ converges to some x∈Δ. Passing to the limit in the displayed identity, using continuity of the linear map B, gives ATx=Bx=x, with x≥0 and ∑i​xi​=1.
This proves stationary distribution existence for a finite Markov chain without any Markov chain irreducibility or aperiodicity assumption. Those stronger hypotheses concern uniqueness and convergence, not the existence required here.

A parameterized decision problem is fixed-parameter tractable if there is an algorithm deciding inputs of encoded length N and parameter k in running time at most f(k)Nc, where f is a computable function and c is a constant independent of k. Arbitrarily expensive dependence on the parameter is permitted; putting k in the exponent of N does not by itself establish fixed-parameter tractability.
For a minimization problem with nonnegative costs, a factor-two approximation algorithm runs in polynomial time, always returns a feasible solution, and satisfies cost(ALG)≤2OPT on every feasible input. A feasible solution also satisfies OPT≤cost(ALG). If the optimum is zero, the guarantee requires an answer of zero cost.

The vertex cover decision problem takes a finite simple graph G and a nonnegative integer k, and asks whether there is a vertex cover of cardinality at most k. The optimization problem asks for a minimum vertex cover, with cost equal to its cardinality.
For the decision problem, if there are no edges, accept; if there is an edge but k=0, reject. Otherwise choose an edge uv and branch: either include u and recurse on G−u with budget k−1, or include v and recurse on G−v with budget k−1. Accept if either branch accepts. Every vertex cover contains at least one endpoint of uv, so every possible solution is retained by at least one branch. Conversely, adding the selected endpoint to a vertex cover returned by the smaller instance covers all original edges. This proves correctness by induction on the remaining budget.
The search tree has depth at most k and at most 2k leaves. Processing each node in O(∣V∣+∣E∣) time gives O(2k(∣V∣+∣E∣)) running time, establishing fixed-parameter tractability.
For optimization, greedily build a maximal matching M: repeatedly select an edge and discard every edge touching either endpoint. Return the set C of all endpoints of M. Any edge with neither endpoint in C could be added to M, contradicting maximality; thus C is a vertex cover. Since the edges of a matching in a graph have pairwise disjoint endpoint sets, every vertex cover must contain at least one different vertex for each of them. Therefore
∣C∣=2∣M∣≤2τ(G)=2OPT.​
(27)
The greedy construction takes polynomial time, and can be implemented in O(∣V∣+∣E∣) with adjacency lists. It needs only a maximal matching, not a maximum matching.

Write U′=U∖{y} and F′={B∖{y}:B∈F}. If A is a basis for the original instance, replace each member A by A∖{y}. Deletion commutes with unions, so the resulting family generates every member of F′ and has at most ∣A∣ members.
Conversely, take a basis A′ for the reduced instance. Lift each of its members by
L(A′)={A′∪{y},A′,​x∈A′,x∈/A′.​
(29)
If B∖{y} is represented as a union of reduced basis sets, the same union of their lifts agrees with B on U′. It contains y exactly when one of the selected reduced basis sets contains x, namely exactly when x∈B. By the assumed incidence equivalence in a set family, this occurs exactly when y∈B. First discard duplicate input sets, and let m=∣F∣. If m>2k, reject by part (i); this rejection can be encoded as the fixed no-instance U={u}, F={{u}}, k=0 of the set basis problem. Otherwise, represent each ground element x by its incidence column
σ(x)=(1x∈B​)B∈F​∈{0,1}m.
(30)
Keep one element from each class of equal columns. By repeatedly applying part (ii), this preserves the answer. The reduced number of elements q satisfies
m≤2k,q≤2m≤22k.​
(31)
Relabel these representatives and store their reduced incidence matrix. Its mq membership bits, the dimensions and k have encoded length bounded solely by a computable function of k; the leading incidence bound is 2k+2k. Thus this is a kernelization, even though it is not a polynomial kernel. Forming columns and grouping identical ones takes polynomial time in the original explicit input length. To test m>2k, compare bit lengths or truncate exponentiation at m+1; never construct an enormous 2k merely to perform this preprocessing comparison.
For completeness, the bounded instance can be solved explicitly. Enumerate all ordered lists of k subsets of the q-element ground set, allowing empty members to pad shorter bases. There are at most 2kq such lists. For a candidate basis and each reduced input set B, form the union of every candidate basis set contained in B. If this union equals B, a representation exists; if it does not, no union of that candidate's members can represent B, because any member not contained in B would add a forbidden element. Testing every B therefore verifies a candidate in time polynomial in m,q,k.
The preprocessing is polynomial in the original input length, and the remaining search depends only on k. Hence the set basis problem is fixed-parameter tractable with respect to k. Empty input families and k=0 are covered by the same empty-union convention.

Assume the standard nonempty instance convention 1≤k≤n, and set d(v,v)=0. Start with no centers. Pick any city still farther than 2r∗ from every selected center, add it as a center, and mark every city within distance 2r∗ of it as covered. Stop when all cities are covered.
Distinct chosen centers have pairwise distance greater than 2r∗. Fix an optimal set of k centers and assign each city to one optimal center within distance r∗. Two cities assigned to the same center have distance at most 2r∗ by the triangle inequality. Thus no two chosen centers can be assigned to that same optimal center. The pigeonhole principle shows that the greedy procedure selects at most k centers and has radius at most 2r∗. If fewer than k are selected, add arbitrary distinct cities; this cannot worsen the radius.
With the supplied radius, a straightforward implementation updates coverage in O(n) time per selected center, hence takes O(nk) distance tests. The argument also handles r∗=0. It is the packing bound underlying the metric k-center problem.

The optimum radius is a distance from some city to a selected city, so it belongs to
D={0}∪{d(u,v):u,v∈V, u=v}.
(32)
Sort the distinct values of D, try them in increasing order, and run part (i)'s greedy procedure with each trial value r. Declare a trial successful when all cities are covered using at most k centers; stop a failed trial as soon as a (k+1)st center would be selected. The trial r=r∗ must succeed by part (i), so the first successful value r satisfies r≤r∗. Its output has
R≤2r≤2r∗.​
(33)
There are O(n2) candidate distances and O(n2) work per trial, giving a polynomial-time algorithm with running time O(n4), plus sorting. Success at r need not mean that radius r itself is feasible; only the radius-2r guarantee is used.
A faster alternative is the farthest-first traversal. Choose any first center, then repeatedly choose a city farthest from its nearest current center until k have been chosen. Let R be the resulting radius. If R>0, adjoin a city attaining that distance. At every earlier selection, the maximum distance to the then-current center set was at least R, so all pairs among these k+1 cities are at distance at least R. Two belong to the same optimal radius-r∗ closed ball, giving R≤2r∗ by the triangle inequality. If R=0, the guarantee is immediate. Maintaining nearest-center distances gives O(nk) distance evaluations without knowing r∗.
