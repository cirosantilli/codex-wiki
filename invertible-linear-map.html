Invertible linear map

 ... Area of mathematics Analysis Real analysis Calculus Multivariable calculus Differentiable map
OurBigBook.com Words: 23
An invertible linear map is a linear bijection; its inverse is also linear.
Invertibility adds a bijection requirement to the definition of a linear map.
