Representational dissimilarity matrix (Dij​=1−corr(zi​,zj​))

 ... Probability and statistics Statistical model Statistical modelling Statistical learning Multivariate pattern analysis Representational similarity analysis
OurBigBook.com Words: 45
A matrix whose entry Dij​ describes how differently a system responds to stimuli i and j. One convention is Dij​=1−corr(zi​,zj​) when the response vectors have nonzero variance. Such a dissimilarity need not satisfy every metric axiom. Model comparison must control fitted transformations and use held-out data.
