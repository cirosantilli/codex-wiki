Matrix-chain dynamic programming (m[i,j])

 Home Computer science Algorithm Matrix-chain multiplication
OurBigBook.com Words: 360
Let Ai​ have matrix dimensions pi−1​×pi​, where p0​,…,pn​ are positive integers. For 1≤i≤j≤n, define m[i,j] as the minimum scalar multiplication cost of the contiguous matrix product Ai​⋯Aj​. The endpoints (i,j) of an integer interval identify a dynamic programming state. A single matrix needs no matrix multiplication, giving the base case m[i,i]=0. At the final matrix multiplication, split after Ak​:
m[i,j]=mini≤k<j​(m[i,k]+m[k+1,j]+pi−1​pk​pj​),i<j.
(2)
The two subproducts have matrix dimensions pi−1​×pk​ and pk​×pj​, regardless of their internal grouping. The recurrence relation adds their optimal costs and the final scalar multiplication cost.[ref]
Why is this optimal substructure? For a chosen final split k, replacing either subproduct's grouping by a cheaper one leaves its matrix dimensions and exact matrix product unchanged, so it decreases the whole cost by the same amount. Therefore an optimal grouping can use optimal groupings on both sides. Conversely, each candidate in the recurrence relation joins two achievable groupings. Mathematical induction on j−i+1, starting with the single-matrix base case, proves that the minimum is achievable and no grouping is cheaper.
There are also overlapping subproblems: while evaluating the different final splits of ABCD, the cases A(BCD) and (ABC)D both request the cost of BC. Recursion without reuse recomputes this answer; memoization or a dynamic programming table stores it once. Fill the table by increasing length j−i+1, so both dependencies are ready. Record an attaining split s[i,j] alongside each cost.[ref]
The dynamic programming table has n(n+1)/2 cost entries. For length ℓ, there are n−ℓ+1 entries and ℓ−1 possible splits, so the exact number of candidate evaluations is
∑ℓ=2n​(n−ℓ+1)(ℓ−1)=6n(n−1)(n+1)​.
(3)
Under the unit-cost assumption that arithmetic operations, comparisons and access to stored costs each take constant time, this gives time complexity O(n3) and space complexity O(n2), using Big O notation. These bounds concern choosing a grouping from the matrix dimensions; they exclude the subsequent matrix multiplication work. If the dimensions or costs require arbitrarily long integers, their arithmetic and storage costs must also be counted.
