Panjer claim-count class (pn​=(a+b/n)pn−1​)

 ... Mathematics Area of mathematics Probability and statistics Actuarial statistics Aggregate claims model Claim count distribution
OurBigBook.com Words: 182 Articles: 2
The nonnegative integer laws whose probabilities satisfy this recurrence for all n≥1. Their probability generating function solves (1−az)G′(z)=(a+b)G(z). This is the (a,b,0) count class used in the Panjer aggregate algorithm; the count recurrence itself should be distinguished from that aggregate recursion. It includes the Poisson distribution, binomial distribution, and negative binomial distribution with suitable parameters.
