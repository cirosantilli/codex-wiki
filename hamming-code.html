Hamming code

 Home Mathematics Area of mathematics Algebra Coding theory Linear code
OurBigBook.com Words: 632 Articles: 11
The binary Hamming code of redundancy r has parameters [2r−1,2r−r−1,3]. Its parity-check matrix has every nonzero vector of F2r​ as a column.
