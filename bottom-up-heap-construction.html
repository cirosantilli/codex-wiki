Bottom-up heap construction (∑h≥1​⌊n/2h⌋<n)

 Home Computer science Data structure Priority queue Binary heap
OurBigBook.com Words: 80
Construct a binary heap from an array by processing internal nodes backwards, applying sift down at each. The complete binary tree shape ensures that the subtrees below the current node have already been repaired. The number of nodes whose height is at least h is at most ⌊n/2h⌋, so charging each repair by its height gives total work at most a constant multiple of n+∑h≥1​⌊n/2h⌋<2n. The construction takes Θ(n) time in either heap orientation, whereas inserting entries separately has an O(nlogn) worst-case bound.
