Certificate complexity of a Boolean function (C(f)=maxx​min{∣S∣:S certifies f(x)})

OurBigBook.com Words: 121 Articles: 1
A query certificate fixes some input coordinates to their values in a chosen input and must force the output for every completion. The smallest such size is C(f,x); maximizing over accepted or rejected inputs gives C1​(f) or C0​(f), and maximizing both gives C(f). A one-sided maximum over an empty output class is defined as zero. This is query certificate complexity, distinct from polynomial verification of a witness in NP.
