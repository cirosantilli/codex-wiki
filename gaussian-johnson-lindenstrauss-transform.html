Gaussian Johnson–Lindenstrauss transform (T(x)=k−1/2Gx)

 ... Mathematics Area of mathematics Analysis Functional analysis Metric embedding Johnson–Lindenstrauss lemma
OurBigBook.com Words: 770 Articles: 2
Draw a k×D random matrix G whose entries are independent random variables with the standard normal distribution, and set
T(x)=k​1​Gx.
(22)
The factor 1/k​ makes the expected value of the squared L2 norm equal to the original squared L2 norm. This Gaussian Johnson–Lindenstrauss transform is a linear map, generally not an orthogonal projection: its rows are not required to be orthogonal vectors. [ref]
For the fixed finite set S, let 0<δ<1 be an allowed failure probability, and define
c(ε)=4ε2​−6ε3​>0.
(23)
With log denoting the natural logarithm, a sufficient integer target dimension is
k≥⌈c(ε)log(n(n−1)/δ)​⌉.
(24)
Then one draw of this specified random matrix satisfies all the squared Euclidean distance bounds simultaneously with probability at least 1−δ. Since c(ε)≥ε2/12, the simpler sufficient bound k≥⌈12ε−2log(n(n−1)/δ)⌉ also works. Both are sufficient bounds for this argument; they do not claim the smallest possible target dimension.
This is a probability statement about a map drawn independently of the fixed finite set. It implies existence because the success probability is positive, but permits failed draws. The set cannot be chosen after inspecting the map with this same guarantee. In particular, no single draw preserves every possible finite set in the ambient Euclidean space when k<D.
