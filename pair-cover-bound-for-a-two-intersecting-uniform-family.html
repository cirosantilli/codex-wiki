Pair-cover bound for a two-intersecting uniform family

 ... Area of mathematics Combinatorics Extremal set theory Set family Intersecting family Two-intersecting family
OurBigBook.com Words: 33
Fix a member of size r. Every other member of a two-intersecting family contains a pair from that fixed member. Counting all r-sets containing these pairs gives ∣F∣≤(2r​)(r−2n−2​) for a uniform set family.
