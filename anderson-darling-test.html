The test rejects for large values of this tail-weighted empirical discrepancy. For a specified continuous null, its standard limiting statistic is ∫01​B0(u)2/[u(1−u)]du, using a Brownian bridge. The reciprocal variance weight gives tail deviations more influence than the Cramér–von Mises criterion. If null parameters are estimated, fitting must be included when computing or simulating its reference law.
