Logarithmic scale (u=logb​(x/x0​))

 ... Area of mathematics Analysis Real analysis Calculus Exponential function Logarithm
OurBigBook.com Words: 851 Articles: 4
A logarithmic scale places a positive quantity x according to a logarithm, so equal ratios occupy equal distances. For example, 1,2,4,8 are equally spaced under the natural logarithm because every successive difference is ln2. An ordinary linear scale instead gives equal distances to equal differences: 1,2,3,4.
For a base b>1 and a positive reference x0​, define the axis position
u=logb​(x/x0​),x>0.
(27)
The reference has the same units as x, making x/x0​ a dimensionless quantity. The distance between two positions is
u2​−u1​=logb​(x2​/x1​).
(28)
Multiplying both values by the same positive factor preserves that distance. Replacing x0​ by cx0​ translates every position by −logb​c; changing the base rescales positions through logb​z=lnz/lnb. Neither change alters which ratios receive equal gaps.
In base ten, the values 1,10,100,1000 occupy positions 0,1,2,3 when x0​=1. The differences between neighboring values grow from nine to ninety to nine hundred, but every step spans one order of magnitude. The values 2,20,200 occupy positions 0.30103,1.30103,2.30103: the same spacing shifted by log10​2. This lets one plot small and large positive quantities together while keeping equal proportional changes equally visible.
A logarithmic scale is a rule for position, not an instruction to relabel the tick marks with their logarithms. A mark labelled 100 still means the original value one hundred. Ordinary real logarithms exclude zero and negative inputs. Omitting such values or clipping them to a plotting boundary does not give them genuine logarithmic positions; the plotting choice needs to be clear.[ref]
