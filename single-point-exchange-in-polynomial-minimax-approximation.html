Single-point exchange in polynomial minimax approximation (∣hnew​∣−∣h∣=∑j​∣wj​∣∣wη​∣​(M−∣h∣))

Suppose a reference polynomial q has nonzero alternating errors of magnitude ∣h∣, and another point η has error magnitude M>∣h∣. Insert η and delete a reference point so that the retained errors, in spatial order, still alternate. Solving the new alternation equations gives the displayed strict increase in reference height, with wj​=∏k=j​(zj​−zk​)−1 on the new ordered set. To prove this, apply the order-(n+1) divided difference to the old and new degree-at-most-n polynomials. Both vanish, so the new signed height is the sum of the old errors times wj​, divided by ∑j​(−1)jwj​. All these signed weight products have one sign. Its absolute value is therefore the positive weighted average of one value M and n+1 values ∣h∣.
For an interior η, replace the endpoint of its containing reference interval with the same error sign. If η is exterior, replace the nearest endpoint when the signs agree; if they disagree, insert η and drop the farthest endpoint. These rules preserve ordered alternation. The nearest point with the same sign need not be an adjacent point on an irregular grid, and an unqualified nearest-same-sign replacement does not ensure the strict increase.
