Treatment coding

 ... Area of mathematics Probability and statistics Statistical model Statistical modelling Normal linear model R linear-model formula
OurBigBook.com Words: 52
Treatment coding sets one reference level in a regression factor to zero and represents each other level by an indicator column. With two interacting factors, a main-effect coefficient compares levels at the other factor's reference level; an interaction coefficient is a difference of these contrasts. A joint nested-model F-test can be significant even when some individual coefficient tests are not.
