Optical path length (∫nds)

 Home Physics Branches of physics Optics Physical optics Wavefront
OurBigBook.com Words: 1k Articles: 7
An optical path length measures how much propagation wave phase a path accumulates, expressed as the distance that would accumulate the same wave phase in vacuum. A centimetre in a uniform medium with refractive index 3/2 has optical path length 1.5cm, although its geometric length remains 1cm. This makes optical path length useful whenever two contributions must arrive with matching wave phases, from an optical lens to a Michelson interferometer. [ref]
For a specified path γ at fixed angular frequency ω, the optical path length is the line integral
OPLγ​(ω)=∫γ​n(r,ω)ds,ds=∣dr∣,OPL=∑j​nj​Lj​ for uniform segments.
(23)
Here s is geometric arc length, and n is the phase refractive index, evaluated at the same frequency everywhere. The propagation interpretation assumes a stationary linear medium with isotropy, a real positive scalar refractive index and negligible loss, on a valid geometrical optics branch. The path can curve; at sharp interfaces apply the appropriate matching conditions to each segment. A prescribed curve has a mathematical line integral, but it predicts a propagation wave phase only when it represents the physical branch. [ref] Optical fibers can require a mode wavenumber rather than the bulk refractive index along a guessed light ray. [ref]
Fix the vacuum wavelength λ0​=c/f=2πc/ω, with frequency f=ω/(2π) and vacuum wavenumber k0​=2π/λ0​. In a locally uniform medium the wavelength is λ=λ0​/n, while the frequency stays unchanged at a stationary interface. With the convention Φ=k0​S−ωt+ϕ0​, propagation from a specified starting wave phase contributes
ϕprop​=k0​OPL,δ=δref​+k0​(OPL2​−OPL1​)(mod2π).
(24)
The relative reference δref​ includes launch wave phases and any extra wave phase from mirrors, beam splitters or coatings. Thus k0​OPL is a propagation contribution, not an absolute detector wave phase independent of the apparatus. If the reference contributions stay fixed, a change in optical path difference h changes the phase difference by 2πh/λ0​. Using the material wavelength again in this formula would count the refractive index twice. [ref]
A motivating measurement turns invisible optical oscillations into a slowly changing electrical signal. MIT's teaching experiment uses a laser, a beam splitter, two returning mirrors, an amplified photodiode, an oscilloscope and a calibrated mirror actuator driven by a function generator. The returning beams overlap on the photodiode; one channel records detector voltage and another the actuator drive. The measured observable is the changing light intensity, including its maxima and minima, rather than direct timing of an optical cycle. A calibrated displacement per drive voltage and the spacing of the extrema relate geometric motion to the phase difference. The guide infers the laser wavelength from known actuator calibration; conversely, with independently known vacuum wavelength and ambient refractive index, the same relation calibrates mirror motion. These two unknowns cannot both be inferred from fringe spacing alone. [ref]
For a proposed change-of-medium measurement, keep the mirrors fixed and put a transparent cell of internal length L in one arm. Compare its contents at refractive indices na​ and nb​, leaving its windows in place. At normal incidence the two traversals give
ΔOPL=2L(nb​−na​),Δδ=λ0​4πL(nb​−na​)​,N=2πΔδ​=λ0​2L(nb​−na​)​.
(25)
Here N is the signed number of whole interference fringe cycles plus any resolved fractional cycle, counted continuously. A mirror displacement x instead gives ΔOPL=2namb​x; distinguish this double-pass factor from a single pass in a Mach-Zehnder interferometer. OpenStax's gas-cell worked example provides the same double-pass reasoning; it is a teaching calculation rather than a published measurement dataset.[ref]
An exact toy calculation makes the sensitivity visible. Stipulate λ0​=600nm, L=10mm and nb​−na​=3/100000=0.00003. Then ΔOPL=600nm and Δδ=2π: a full interference fringe cycle, despite unchanged geometric lengths. For a continuous change nb​−na​=q(3/100000), let 0≤q≤2 and choose the initial detector phase difference to be zero. Equal coherent detected arm contributions of light intensity I0​ predict
4I0​I(q)​=21+cos(2πq)​=cos2(πq).
(26)
The plot is this stipulated model: q=1/2 gives a minimum, q=1 restores a maximum, and the reference level is chosen by adjustment of the apparatus. It contains no measured values or assigned properties of a real gas. The equivalent mirror travel in vacuum is 300nm per cycle. A single endpoint light intensity cannot distinguish q=0 from q=1; the continuous fringe count carries the missing information.
For an interpretable cell measurement, establish the initial phase difference with a small calibrated mirror scan, then track slow changes through successive interference fringes. Measure the dark signal and each arm separately, keep photodiode gain within its linear range, align both beams on the same region and match their linear polarizations. Monitor interferometric visibility and keep arm delays within the useful optical coherence time. Record cell length, contents, pressure and temperature; return to the starting condition to check drift. Changes in window deformation, cell length, external air or mirror position also change optical path length, so a reference cell or an independently monitored mechanical path is needed to isolate the contents' refractive index. These controls are deductions from the model, not a claim that the illustrated apparatus was operated. Loss of fringe count leaves a whole-cycle ambiguity; at an intensity extremum the first derivative with respect to phase difference vanishes, so a scan around phase quadrature is more sensitive to small changes. Broadband illumination, unstable optical coherence, vibration and strong loss can invalidate a simple one-frequency inference.
