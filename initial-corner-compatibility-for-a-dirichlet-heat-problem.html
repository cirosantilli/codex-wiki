Initial corner compatibility for a Dirichlet heat problem

 ... Area of mathematics Analysis Differential equation Ordinary differential equation Boundary condition Dirichlet boundary condition
OurBigBook.com Words: 174
For the forward diffusion equation ut​=κuyy​ on 0<y<L, with κ>0 and homogeneous Dirichlet boundary conditions, a solution continuous on the closed initial-boundary domain can take initial data u(0,y)=ϕ(y) only if ϕ(0)=ϕ(L)=0. These equalities express the same corner value through the initial condition and the boundary condition.
An incompatible endpoint value does not prevent an interior or L2 space initial-data solution. For example, on 0<y<1 the initial ramp ϕ(y)=y gives
u(t,y)=π2​∑n=1∞​n(−1)n+1​e−κn2π2tsin(nπy).
(91)
It satisfies both zero endpoint values for every t>0 and tends to y at every fixed 0<y<1 as t↓0, also in the L2 norm. It cannot extend continuously to (0,1) with both the initial value one and the boundary value zero. Each sine term vanishes at the endpoint, so the series cannot silently repair that pointwise contradiction.
If the equation is written aut​=uyy​, the intended forward heat coefficient requires a>0. For a<0, the ramp's coefficients would grow like en2π2t/∣a∣/n, failing square summability for every t>0. This example distinguishes an incompatible corner from the separate ill-posedness of backward diffusion.
