Occurs check

 Home Computer science Programming language Type system Type variable
OurBigBook.com Words: 128
The occurs check tests whether a type variable occurs inside the expression proposed as its replacement during type unification. After discarding a trivial equation such as α=α, solving α=τ by a type substitution requires that α not occur in τ. Thus α=int→β is permitted when α and β are distinct, but α=α→β is rejected in our finite simple type grammar.
There is a short reason for the rejection. If a finite replacement T for α existed, with replacement B for β, the equation would become T=T→B. The right side's abstract syntax tree has one new arrow node plus the nodes of T and B, so it has strictly more nodes than T. Equal finite type expressions cannot have different sizes. Recursive types are a different design: they explicitly describe self-reference and specify how it interacts with typing judgments.
