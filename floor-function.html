Floor function (⌊x⌋)

 ... Mathematics Area of mathematics Analysis Real analysis Calculus Floor and ceiling functions
OurBigBook.com Words: 440 Articles: 7
The floor ⌊x⌋ is the greatest integer not exceeding the real number x. Equivalently, ⌊x⌋=m exactly when m≤x<m+1, for an integer m. The floor function is constant on each such half-open interval and has a discontinuity of a function at each integer.
For nonnegative integers N and positive integers k, ⌊N/k⌋ is the number of complete groups of size k that fit into N items. With N=102 and k=20, five complete groups use 100 items. Euclidean division writes 102=20⋅5+2, retaining the two-item remainder rather than treating the quotient 102/20=5.1 as a number of complete groups.
