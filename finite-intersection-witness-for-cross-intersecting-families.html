Finite intersection witness for cross-intersecting families

 ... Area of mathematics Combinatorics Extremal set theory Set family Intersecting family Cross-intersecting family
OurBigBook.com Words: 82
For cross-intersecting families A,B with member sizes at most r,s respectively, there is a finite set X with ∣X∣≤r∑j=0s​rj such that A∩B∩X=∅ for every A∈A,B∈B. Take a bounded-size transversal kernel A0​ preserving hitting sets of size at most s and set X=⋃A∈A0​​A. For each B, the set B∩X is a hitting set for A0​, hence for all of A. This proves the assertion even for infinite set families; if either family is empty, take X=∅.
