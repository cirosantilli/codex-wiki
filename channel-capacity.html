Channel capacity (C=maxPX​​I(X;Y))

 Home Mathematics Area of mathematics Probability and statistics Information theory
OurBigBook.com Words: 2k Articles: 10
Channel capacity is the best reliable information rate available through a specified communication channel. For a discrete memoryless channel with finite input and output alphabets, fixed transition probabilities W(y∣x), and no input-cost constraint, it is
C=maxPX​​I(X;Y)
(103)
in bits per channel use, when the mutual information uses base-two logarithms. The maximization varies the input probability distribution, while keeping the communication channel fixed. A large input alphabet or a large output information entropy alone does not determine how much information gets through: the receiver needs information about the input, rather than merely unpredictable output.
The operational meaning comes from the Shannon second coding theorem. A block code represents one of M possible messages by a word of length n, giving a rate log2​M/n bits per use. Take the message label from the uniform distribution on a finite set of those M choices when measuring average decoding-error probability. For every fixed rate R<C, there are sequences of such block codes whose decoding-error probability tends to zero as n grows; a rate above C cannot have vanishing decoding-error probability. This is an asymptotic limit, rather than a promise that an arbitrary finite block code at a rate below C works well. See MIT 18.310, Shannon's Noisy Coding Theorem, sections 1–2.
For a binary symmetric channel with crossover probability p=0.1, the binary symmetric channel capacity is approximately 0.53100441 bits per use. Thus a binary code rate R=1/2 lies below the limit, while R=3/4 lies above it. At R=1/2, two transmitted symbols represent one message bit on average; the redundancy helps distinguish messages after noise. This does not split individual physical symbols into fractional pieces.
The result is useful because it separates two tasks. Computing channel capacity establishes the target imposed by the transition probabilities; constructing an effective block code attempts to approach that target with acceptable delay and decoding effort. The surprise is that reliability can improve indefinitely without forcing every positive rate to disappear. In his 1948 paper, Shannon defines noisy channel capacity in section 12 and develops its operational significance in section 13, Theorem 11. His original formulation uses information per unit time; the fixed-duration channel-use convention here expresses the same rate question per symbol. [ref].
