Free variable in a linear system

 Home Mathematics Area of mathematics Algebra Linear algebra System of linear equations
OurBigBook.com Words: 43
A free variable in a linear system is an unknown whose coefficient column is not a pivot column in row echelon form. When the linear system is consistent, it can be assigned any value in the field; the pivot unknowns are then determined by those choices. This use of “free” differs from a free variable in mathematical logic.
