Arithmetic function (f:Z>0​→C)

 Home Mathematics Area of mathematics Number theory
OurBigBook.com Words: 7k Articles: 74
An arithmetic function is a function whose domain of a function is the positive integers, usually taking values in the complex numbers. Thus f(1),f(2),… are its values; f(0) is outside this domain of a function. Examples include the divisor function, with τ(12)=6, and the sum-of-divisors function, with σ1​(12)=28. Studying an arithmetic function packages a question about each positive integer into one object whose values can be combined using Dirichlet convolution. [ref]
