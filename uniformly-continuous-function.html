Uniformly continuous function (∀ε>0 ∃δ>0 ∀x,y∈D)

 ... Area of mathematics Analysis Real analysis Calculus Limit of a function Continuous function
OurBigBook.com Words: 963 Articles: 1
A uniformly continuous function has one input tolerance valid throughout its domain of a function. For f:D→R, with D⊆R, uniform continuity means
∀ε>0 ∃δ>0 ∀x,y∈D:∣x−y∣<δ ⟹ ∣f(x)−f(y)∣<ε.
(82)
Choose the output tolerance ε first, then a positive δ valid for every pair of function inputs. It may depend on ε, the function and its domain of a function, but not on the pair’s location. The absolute values measure input and output distance.[ref]
Compare the quantifier order with the epsilon-delta definition of continuity:
continuity throughout D:uniform continuity on D:​∀a∈D ∀ε>0 ∃δ>0 ∀x∈D,∀ε>0 ∃δ>0 ∀a∈D ∀x∈D.​
(83)
Both lines end with ∣x−a∣<δ⇒∣f(x)−f(a)∣<ε. In the first, δ can depend on the point a; in the second, it is chosen before a. Thus uniform continuity implies continuity at every point. Each requested ε gets its own shared tolerance.
For an exact example, take the polynomial function f(x)=x2 on the closed interval D=[0,2]. For every pair of function inputs in that interval, polynomial factorization gives
∣x2−y2∣=∣x−y∣∣x+y∣≤4∣x−y∣.
(84)
Consequently δ=ε/4 works everywhere on this domain of a function. With ε=0.4, the common tolerance is δ=0.1. Near the right endpoint, for example, x=1.92 and y=2 have input distance 0.08 and output distance 4−1.922=0.3136<0.4. The bound is sufficient; it does not claim the largest admissible input window at each point.
On the whole real line, the same polynomial function is a continuous function but fails uniform continuity. Take the sequences xn​=n and yn​=n+1/n, for positive integers n. Then
∣xn​−yn​∣=n1​⟶0,∣xn2​−yn2​∣=2+n21​>2.
(85)
For any proposed δ>0, choose an integer n>1/δ. The inputs are closer than δ, yet their outputs violate the fixed tolerance ε=1. The sequences need not themselves have a finite limit: their mutual distance is what tends to zero. This is the obstruction captured by the sequential criterion for uniform continuity. Restricting the domain of a function to [0,2] removes these escaping pairs.
A uniformly continuous function need not be a bounded function. The identity function f(x)=x on the real line has ∣f(x)−f(y)∣=∣x−y∣, so δ=ε always works, although its image of a function is the unbounded real line. Uniform continuity controls changes between nearby inputs, not the overall size of outputs. Likewise, an unbounded domain of a function does not by itself prevent uniform continuity.
The square root g(x)=x​ supplies a different common tolerance on the interval [0,∞). Assuming x≥y≥0, put u=x​ and v=y​. Since 0≤u−v≤u+v,
(u−v)2≤(u−v)(u+v)=x−y.
(86)
Interchanging the inputs when necessary proves
∣x​−y​∣≤∣x−y∣​.
(87)
Thus δ=ε2 guarantees uniform continuity on the entire domain of a function, including zero. For ε=0.4, any input distance below 0.16 suffices. The pairs (0,0.09) and (4,4.09) both have input distance 0.09; their output distances are respectively 0.3 and 0.09/(4.09​+2)<0.0225. The common guarantee accommodates quite different local sensitivities.
This Hölder continuity bound allows a curved tolerance rule. It is weaker than a Lipschitz bound: at zero the output change divided by the input change is
∣h−0∣∣g(h)−g(0)∣​=h​1​⟶∞(h↓0).
(88)
No finite Lipschitz constant works near zero, even though uniform continuity does. A Lipschitz function does have uniform continuity, choosing δ=ε/L when its Lipschitz bound L is positive; when L=0 it is a constant function.[ref]
For general metric spaces, replace the absolute values by the respective distance functions. The Heine-Cantor theorem gives an existence guarantee: every continuous function on a compact metric space is uniformly continuous. In particular, continuity on a finite closed interval provides a common tolerance, even when no simple formula for it is known.[ref]
For a short proof outline, fix ε>0. Continuity gives each point a an open ball of radius ra​>0 within which outputs differ from f(a) by less than ε/2. The open balls of half these radii still cover the domain of a function. Compactness supplies a finite subcover. Take δ to be the smallest half-radius in this finite set. Two inputs closer than δ lie together in one of the original open balls, so the triangle inequality bounds their output distance by ε. The beautiful step is that the compact set turns local choices into finitely many choices, whose minimum stays positive.
A shared tolerance also makes uniformly continuous functions preserve Cauchy sequences: after choosing δ for ε, all sufficiently late input pairs are closer than δ, so all corresponding output pairs are closer than ε. Unlike a convergent sequence argument, this does not require an input limit inside the domain of a function. It is why uniform continuity is useful for extending a function toward missing endpoints and for the decay argument below.
