Johnson–Lindenstrauss lemma

 Home Mathematics Area of mathematics Analysis Functional analysis Metric embedding
OurBigBook.com Words: 1k Articles: 8
For 0<ε<1 and any n points in a Hilbert space, there is a linear map into Euclidean dimension O(ε−2logn) that multiplies every pairwise distance by a factor between 1−ε and 1+ε.
The striking feature is that the target dimension depends on the number of points and the allowed error, independently of the ambient dimension. Fix a finite set S={x1​,…,xn​}⊂RD, with n≥2, and 0<ε<1. An equivalent sufficient statement uses squared Euclidean distances: a linear map T:RD→Rk exists, with k=O(ε−2logn), such that
(1−ε)∥xi​−xj​∥22​≤∥Txi​−Txj​∥22​≤(1+ε)∥xi​−xj​∥22​(1≤i<j≤n).
(21)
The finite-set theorem cited here supplies an explicit sufficient target dimension for this squared-distance formulation. [ref]
Taking square roots gives distance factors 1−ε​ and 1+ε​, which lie inside [1−ε,1+ε]. Conversely, bounds 1±ε on distances only give squared-distance bounds (1±ε)2; the same numerical tolerance should not be silently used for both. Under the squared-distance bounds, the bi-Lipschitz distortion is at most (1+ε)/(1−ε)​.
The Johnson–Lindenstrauss lemma preserves this fixed finite set, rather than every vector in the ambient Euclidean space. A linear map with k<D has a nonzero kernel by the rank-nullity theorem, so some nonzero vectors collapse completely. For finitely many points in a real Hilbert space, apply the finite-dimensional argument on their linear span and extend by orthogonal projection onto that linear span. If the sufficient target dimension exceeds the ambient dimension, the identity map already preserves every Euclidean distance exactly, with zero padding if a larger target is requested.
