Adiabatic invariance of the action

 ... Branches of physics Classical mechanics Hamiltonian mechanics Integrable Hamiltonian system Action-angle variables Action variable
OurBigBook.com Words: 151 Articles: 4
When a Hamiltonian parameter varies slowly compared with the orbital period and no separatrix is crossed, the action changes only at higher adiabatic order.
The action is an adiabatic invariant under these assumptions; other slowly varying systems can have different adiabatic invariants.
