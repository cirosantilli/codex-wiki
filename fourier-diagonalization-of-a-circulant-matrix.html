Fourier diagonalization of a circulant matrix (C=F−1diag(Fc)F)

Use the negative-exponential forward discrete Fourier transform and the 1/N-normalized inverse discrete Fourier transform:
Fkn​=e−2πikn/N,(F−1)nk​=N1​e2πink/N.
(76)
For the circulant matrix with first column c, the discrete Fourier mode wn(k)​=e2πikn/N is an eigenvector with eigenvalue
λk​=ℓ=0∑N−1​cℓ​e−2πikℓ/N=(Fc)k​.​
(77)
Indeed, substitution into circular convolution gives
(Cw(k))n​=∑ℓ=0N−1​cℓ​e2πik(n−ℓ)/N=wn(k)​λk​.
(78)
The columns of F−1 are w(k)/N, so the diagonalization of a matrix takes the form
C=F−1diag(λ0​,…,λN−1​)F.
(79)
The roots of unity give orthogonality of these eigenvectors; dividing each w(k) by N​ makes the basis orthonormal. Consequently, every complex circulant matrix is a normal matrix, including ones that are not Hermitian matrices.
The sign convention matters. For c=(1,2,0,0)T, the circulant matrix is
C=​1200​0120​0012​2001​​,(λ0​,λ1​,λ2​,λ3​)=(3,1−2i,−1,1+2i).
(80)
Changing the direction of the shift or the sign in the discrete Fourier transform changes which complex eigenvalue goes with which discrete Fourier mode. A real symmetric example alone would conceal that distinction.
For a linear system Cx=b, put x=Fx and b=Fb. The equation becomes N independent scalar equations
λk​xk​=bk​.
(81)
If every λk​ is nonzero, divide to find the unique vector x and apply the inverse discrete Fourier transform. If some λk​=0, a vector x satisfying the linear system exists exactly when bk​=0 at every such index; the corresponding xk​ remain free. This is a concrete version of the Fredholm alternative in a finite-dimensional setting.
With an appropriate Fast Fourier transform, multiplication or a compatible solve takes O(NlogN) arithmetic operations, instead of forming a dense matrix and applying general Gaussian elimination. The gain comes from the periodic structure; an arbitrary matrix does not have this shared basis of discrete Fourier modes.[ref]
