Degree-two even elliptic function (f=(a℘+b)/(c℘+d))

 ... Analysis Complex analysis Elliptic function Weierstrass functions Weierstrass elliptic function Even elliptic functions are rational in the Weierstrass function
OurBigBook.com Words: 63
An even elliptic function descends through the degree-two quotient map ℘ to a rational function R on the Riemann sphere. If the original function also has degree two, composition of map degrees gives 2=2degR, so R has degree one. Consequently it is a Möbius transformation with ad−bc=0. The shift sn(z+K,k) is even and has degree two, providing an example for the common period lattice of the Jacobi elliptic sine and ℘.
