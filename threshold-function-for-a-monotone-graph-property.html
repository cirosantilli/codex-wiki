Threshold function for a monotone graph property

 ... Area of mathematics Foundations of mathematics Graph theory Random graph Erdős-Rényi model Monotone graph property
OurBigBook.com Words: 26
A function p∗(n) is a threshold when the property holds with probability tending to zero for p/p∗→0 and with probability tending to one for p/p∗→∞.
