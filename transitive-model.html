Transitive model

 Home Mathematics Area of mathematics Foundations of mathematics Set theory Transitive set
OurBigBook.com Words: 198 Articles: 4
A transitive model of set theory is a transitive set or transitive class whose membership relation is the ambient membership relation and which satisfies the specified set-theoretic axioms.
