Dirty buffer

 Home Computer science Operating system File system Buffer cache Buffered device block
OurBigBook.com Words: 48
A valid buffered device block with modifications still owed to its backing location. Until successful buffer cache writeback, simply reassigning its buffer cache key would lose those modifications. “Dirty” records a write obligation; a write of identical contents can still mark the structure dirty. Repeated buffered writes can leave only the latest contents to be transferred.
