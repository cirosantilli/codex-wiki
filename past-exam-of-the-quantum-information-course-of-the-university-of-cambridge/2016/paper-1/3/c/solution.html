Quantum error correction encodes a logical qubit into a larger Hilbert space, diagnoses a specified error family with an error syndrome, and reverses it without learning the protected logical amplitudes. It must preserve arbitrary superpositions, not just distinguish two classical codewords.
The bit-flip repetition code encodes
α∣0⟩+β∣1⟩⟼α∣000⟩+β∣111⟩.
(18)
Measure the commuting stabilizer generators Z1​Z2​ and Z2​Z3​ using ancillary qubits. Their outcomes reveal the parity relations, with the three-qubit bit-flip syndrome table
errorIX1​X2​X3​​(Z1​Z2​,Z2​Z3​)(+1,+1)(−1,+1)(−1,−1)(+1,−1)​recoveryIX1​X2​X3​​​​
(19)
Both codewords have the same parity checks, so the syndrome does not reveal α or β. For example, the X2​ error produces α∣010⟩+β∣101⟩; applying X2​ restores the encoded superposition. A coherent combination of correctable errors is also recoverable after the syndrome is recorded in an ancilla, by linearity.
This three-qubit code corrects one bit flip, not every one-qubit error. A physical Z1​ changes the relative logical phase without a nontrivial bit-flip syndrome. General single-qubit noise is a linear combination of I,X,Y,Z; protecting arbitrary single-qubit errors therefore needs a code such as the Shor code, the Steane code or the five-qubit code, with the corresponding enlarged syndrome structure.
The general exact-recovery criterion is the Knill--Laflamme condition. For code projector P and error operators Er​, there must be constants Crs​ such that
PEr†​Es​P=Crs​Pfor every r,s.​
(20)
It expresses that the syndrome information can depend on the error but not on the logical state. Encoding entangles several physical qubits; it does not create independent copies of an unknown input, so it respects the no-cloning theorem. Fault-tolerant implementations must also prevent noisy syndrome extraction and recovery gates from spreading an initially correctable error into an uncorrectable one.
