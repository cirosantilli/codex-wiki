 Home Computer science Algorithm Selection algorithm
OurBigBook.com Words: 474 Articles: 2
A selection algorithm that uses array partitioning around a pivot and recursively searches only the side containing the desired order statistic. If there are s entries before the placed pivot, an earlier rank is unchanged and a later rank is reduced by s+1. Segment length strictly decreases, proving algorithm termination. The same reduction can update local bounds in a loop, using constant auxiliary space.
Balanced reductions give linear work by a geometric series, while repeatedly discarding only a constant number of entries can give quadratic work. For distinct entries and independent uniform random pivots, a pivot in the middle half has probability at least one half and reduces the retained length to at most three quarters, up to rounding. The expected number of attempts for each such reduction is bounded, so summing expected work over geometric size scales gives O(n) expected time. This random-pivot guarantee is not a worst-case guarantee for a deterministic median-of-three heuristic. With duplicates and a strict two-way partition, random pivot choice alone can also fail to shrink an all-equal segment; a three-way partition treats equal keys together.
