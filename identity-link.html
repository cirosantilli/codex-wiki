Identity link (g(μ)=μ)

 ... Area of mathematics Probability and statistics Statistical model Statistical modelling Generalized linear model Link function
OurBigBook.com Words: 44
The identity link function equates the response mean with the linear predictor. In a generalized linear model it gives μi​=xiT​β. It is the canonical link function for the normal distribution. For response families whose means must remain positive or between zero and one, using the identity link requires corresponding restrictions on the linear predictor.
