Arc consistency

 ... Computer science Theoretical computer science Computational complexity theory Computational problem Search problem Constraint satisfaction problem
OurBigBook.com Words: 431 Articles: 3
A directed requirement for a binary constraint Rij​: every remaining x∈Di​ has at least one support y∈Dj​ with (x,y)∈Rij​. Revising the arc i→j deletes unsupported values from Di​; it does not directly delete values from Dj​. Full arc consistency requires the condition in both directions on every edge of the constraint graph. On general graphs, it need not imply that a complete solution exists.
