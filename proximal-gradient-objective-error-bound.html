Proximal gradient objective error bound (ϕ(xk)−ϕ(x∗)≤L∥x0−x∗∥2/(2k))

 ... Mathematics Area of mathematics Mathematical optimization Convex optimization Proximal operator Proximal gradient method
OurBigBook.com Words: 76
For ϕ=f+h, with f a convex function having an L-Lipschitz gradient and h a proper convex function with a well-defined proximal operator, the proximal gradient method with step size 1/L satisfies the displayed bound whenever a global minimizer x∗ exists. The one-step subgradient inequality and descent lemma give
ϕ(xj+1)−ϕ(x∗)≤2L​(∥xj−x∗∥2−∥xj+1−x∗∥2).
(76)
The objective function values are nonincreasing. A telescoping sum over j=0,…,k−1, followed by comparison of the last error with the arithmetic mean of the errors, proves the result. The bound controls the last objective function error without requiring a strongly convex function or a unique minimizer.
