Lanford contraction proof of the Feigenbaum fixed point

 ... Dynamical systems Discrete dynamical system Interval map Unimodal interval map Period-doubling renormalization operator Feigenbaum renormalization fixed point
OurBigBook.com Words: 43
An approximate analytic fixed point of the period-doubling renormalization operator can be certified by a frozen Newton correction for a fixed-point equation. A coefficient Banach space, rigorous residual and derivative bounds, and an a posteriori contraction ball give existence and local uniqueness in the full function space. Interval arithmetic controls finite computations; analytic estimates control the infinite coefficient tail.
