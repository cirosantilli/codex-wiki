Ternary Hamming code as a cyclic code (g(X)=∏j=0s−1​(X−α3j))

 ... Area of mathematics Algebra Coding theory Linear code Hamming code Ternary Hamming code
OurBigBook.com Words: 69
For odd s≥3, put n=(3s−1)/2 and choose α of order n in F3s​. Because n is odd, the powers αi, 0≤i<n, represent every projective point once. The cyclic code defined by c(α)=0 is therefore monomially equivalent to a ternary Hamming code, with the displayed generator polynomial of a cyclic code. This statement requires a qualification: at s=2, every ternary cyclic length-four, dimension-two code has a weight-two generator, so none has Hamming distance three.
