Number of ultrafilters on an infinite set (∣Ult(X)∣=22∣X∣)

 ... Mathematics Area of mathematics Foundations of mathematics Set theory Filter (set theory) Ultrafilter
OurBigBook.com Words: 49
The finite-trace independent family construction gives 2∣X∣ independent subsets of an infinite X. Each binary assignment generates a proper filter and, in ZFC, has an ultrafilter extension. Different assignments force incompatible membership decisions, giving 22∣X∣ distinct ultrafilters. The matching upper bound follows because every ultrafilter is a subset of P(X).
