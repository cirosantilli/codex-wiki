Distinguish reflection at the input terminal, reflection at the receiving load, and a returned signal that traverses the free-space link twice. The input antenna is initially matched, so its direct terminal reflection is zero.
In the usual weak-coupling, matched-port two-port network model for the antenna pair, let the forward and reverse wave amplitude transfer coefficients be t21​ and t12​. Electromagnetic reciprocity gives equal power transfer factors ∣t21​∣2=∣t12​∣2=F, where F=(Ga​λ/(4πd))2 from part (a). The receiving-load reflection returns wave amplitude t12​ΓL​t21​ to the original input port. The load-mismatch contribution to the returned power is therefore
Prload​=Pi​∣ΓL​∣2F2=Pi​(Zt​+Zi​Zt​−Zi​​)2(4πdGa​λ​)4.​

For fixed gains and impedances this returned power scales as λ4: it contains two link traversals. By contrast, the reflected power at the receiving load before that return traversal is Pi​F∣ΓL​∣2∝λ2. Calling that local reflected power the power already back in the input line would omit one propagation loss.
The original wording does not specify an antenna scattering model. The boxed result is the load-dependent echo in an ideal matched-port link, with structural scattering and residual input coupling neglected. The actual total input return can include coherent scattering from the receiving antenna even when ΓL​=0; gains and effective areas alone do not specify that background. If “reflected back” means only the direct reflection at the stated matched transmitting antenna, its value is 0. These meanings should not be conflated; the λ4 result requires the two-pass echo interpretation and its stated model.
