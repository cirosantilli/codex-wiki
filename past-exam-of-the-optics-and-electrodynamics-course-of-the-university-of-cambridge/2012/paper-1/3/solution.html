Use E(z,t)=Re[Jei(kz−ωt)]. A Jones vector J=(Jx​,Jy​)T records the two transverse complex amplitudes. The amplitude ratio and relative phase determine the polarization ellipse; a common nonzero scalar does not change the polarization. A fixed Jones vector describes fully polarized monochromatic light, not an unpolarized statistical mixture.
Linear birefringence gives orthogonal principal polarizations different refractive indices. Put ny​−nx​=Δn>0, so x is the fast axis. A plate of thickness d gives slow-minus-fast phase retardation
δ(ω)=cωdΔn(ω)​.
(14)
The thinnest quarter-wave plate has
d=2ω0​Δn(ω0​)πc​=4Δn(ω0​)λ0​​.​
(15)
Here λ0​=2πc/ω0​ is the vacuum wavelength. For linear input at angle θ to the fast axis, the output at design frequency is (cosθ,isinθ)T up to common phase. Axis-aligned input remains linear; equal nonzero components at 45∘ modulo 90∘ give circular polarization; other input angles give elliptical polarization. There is no need to spatially separate the two components.[ref]
For waveplate retardance detuning, define
ϵ=cωdΔn(ω)​−2π​≃cd​[Δn0​+ω0​Δn0′​](ω−ω0​).
(16)
Neglecting material dispersion reduces this to ϵ=(π/2)(ω−ω0​)/ω0​. Remove the common fast-axis phase. Then Q=diag(1,ieiϵ). A similar half-wave plate of twice the thickness has twice the retardation, giving H=diag(1,−e2iϵ). The shared error parameter presumes the same material and matched thickness ratio.
For the half-wave and quarter-wave achromatic circularizer, the first fast-axis angle is α=15∘ and the second is γ=α+β=75∘. With the stated passive rotation convention,
Jout​=R(−γ)QR(γ)R(−α)HR(α)(10​).
(17)
An explicit expression valid for the given shared error is obtained by putting z=eiϵ and defining
vx​=cos2α−z2sin2α,vy​=sinαcosα(1+z2),
(18)
Jout​=((cos2γ+izsin2γ)vx​+(1−iz)sinγcosγvy​(1−iz)sinγcosγvx​+(sin2γ+izcos2γ)vy​​).
(19)
At ϵ=0, the half-wave plate rotates the linear input to 30∘, which is −45∘ relative to the second fast axis. Thus
J0​=2​ei75∘​(1−i​).​
(20)
This is circular polarization. With our time convention its fixed-point electric vector is proportional, after a time-origin shift, to (cosωt,−sinωt); this specifies the rotation without relying on conflicting handedness conventions.
Expanding the exact product to first order gives
Jout​=(0.183+0.683i0.683−0.183i​)+ϵ(−0.433+0.116i0.116+0.433i​)+O(ϵ2).
(21)
These coefficients are rounded to three significant figures. Before rounding, the derivative is exactly J0′​=iκJ0​, with κ=(3−3​)/2. The Jones-component ratio sensitivity therefore vanishes:
Jx​Jy​​=J0x​(1+iκϵ)J0y​(1+iκϵ)​+O(ϵ2)=−i+O(ϵ2).​
(22)
Only common phase changes at first order. This proves compensation for the prescribed input near the design frequency, not exact achromatic performance throughout the visible spectrum for arbitrary input polarization.
