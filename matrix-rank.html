Matrix rank (rankA)

 ... Area of mathematics Algebra Linear algebra Vector space Linear map Matrix
OurBigBook.com Words: 1k Articles: 8
The matrix rank of an m×n matrix A over a field F is the dimension of its column space, equivalently the dimension of its row space. It counts linearly independent column directions, with 0≤rankA≤min(m,n). Counting nonzero matrix entries gives a different quantity: an all-ones matrix can have arbitrarily many nonzero matrix entries and still have matrix rank one.[ref]
Consider the following matrix over the real numbers, with columns written as vectors:
A=​121​241​362​​,c1​=​121​​,c2​=​241​​,c3​=​362​​=c1​+c2​.
(34)
The vectors c1​,c2​ are linearly independent: αc1​+βc2​=0 requires both α+2β=0 and α+β=0, so β=α=0. The third column adds no new direction to their linear span, hence rankA=2 despite all nine matrix entries being nonzero. The second row likewise repeats twice the first row.
The column space is a plane through the origin:
colA=span{c1​,c2​}=⎩⎨⎧​​u2uv​​:u,v∈R⎭⎬⎫​.
(35)
Every output has second coordinate twice its first coordinate. Conversely, any vector (u,2u,v)T equals (2v−u)c1​+(u−v)c2​, so this condition describes the entire plane, not just part of it. For example, b=(1,2,0)T=−c1​+c2​ is attainable, whereas b′=(1,3,0)T lies outside the plane.
Elementary row operations expose the same count algebraically. Apply R2​←R2​−2R1​ and R3​←R3​−R1​, interchange the last two rows, multiply the second row by −1, and subtract twice the second row from the first. The resulting reduced row echelon form is
R=​100​010​110​​.
(36)
There are two pivot columns, so the matrix rank is two. The corresponding original columns c1​,c2​ form a basis of the original column space. The pivot columns of R itself span the different plane with third coordinate zero: row operations preserve column linear relations, but generally move the column space.[ref]
Solving the homogeneous linear system Rx=0 gives x1​+x3​=0 and x2​+x3​=0. Taking the free variable x3​=t gives
kerA=span{(−1,−1,1)T},rankA+dimkerA=2+1=3.
(37)
The kernel is the input direction that trades one unit of each of the first two columns for one unit of the third. This trade leaves the output unchanged. The rank-nullity theorem expresses the general balance: for an m×n matrix of matrix rank r, the nullity is n−r. The column space describes reachable outputs; the kernel describes invisible changes to inputs.[ref]
For the attainable output b, one solution is x0​=(−1,1,0)T. Every solution lies in the affine solution space of a linear equation
x=x0​+t(−1,−1,1)T=​−1−t1−tt​​,t∈R.
(38)
Indeed, Ax0​=b and A(−1,−1,1)T=0. Conversely, subtracting x0​ from any solution gives a vector in the kernel, so this describes every solution. For b′, the same row operations on the augmented matrix expose 0=1: the second requirement demands 3 where twice the first requires 2.
In general, a linear system Ax=b is solvable exactly when appending b leaves the matrix rank unchanged:
rank[A∣b]=rankA.
(39)
Appending a vector outside the column space adds an independent direction. When a solution x0​ exists, every solution is x0​+kerA, because A(x−x0​)=0. Thus one count predicts both how many output directions are reachable and, through the rank-nullity theorem, how many independent input directions remain free.[ref]
