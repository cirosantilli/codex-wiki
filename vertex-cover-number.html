Vertex cover number (τ(G))

 ... Mathematics Area of mathematics Foundations of mathematics Graph theory Vertex cover Minimum vertex cover
OurBigBook.com Words: 234
The vertex cover number records the size of a minimum vertex cover:
τ(G)=min{∣C∣:C⊆V(G), C is a vertex cover of G}.
(21)
The vertex cover number is a number, while a minimum vertex cover is a set attaining it. For the cycle graph C5​, the independence number is 2, so the complement correspondence gives τ(C5​)=5−2=3. The vertex cover {1,3,4} above attains this size.
Every matching in a graph gives a lower bound on the vertex cover number. Its edges have no shared endpoints, so covering each selected edge requires a different vertex. Thus, for any matching in a graph M and any vertex cover C,
∣M∣≤∣C∣,ν(G)≤τ(G),
(22)
where ν(G) is the matching number. Exhibiting a matching in a graph and a vertex cover of the same size certifies that both are optimum. Kőnig's theorem for bipartite matching says that every finite bipartite graph admits this equality: ν(G)=τ(G).[ref]
For the complete bipartite graph K2,3​, let the left vertices be L={a,b} and the right vertices be R={x,y,z}. All six edges join L to R. Selecting C=L covers every edge; selecting M={ax,by} gives a matching in a graph of size two. The lower bound and this vertex cover give 2≤τ(K2,3​)≤2, so τ(K2,3​)=ν(K2,3​)=2. The remaining vertices R form a largest independent set of size three. Crossings of drawn edges are not extra vertices.
The bipartite graph hypothesis matters. In a triangle in a graph, any two vertices form a minimum vertex cover, while any two edges share an endpoint. Hence τ(K3​)=2 and ν(K3​)=1. Similarly, the cycle graph C5​ has τ(C5​)=3 and ν(C5​)=2. The inequality for the matching number remains valid, but equality can fail.
