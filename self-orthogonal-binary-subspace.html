Self-orthogonal binary subspace (W⊆W⊥)

 ... Mathematics Area of mathematics Algebra Coding theory Linear code Binary linear code
OurBigBook.com Words: 87 Articles: 1
A linear subspace W⊆F2n​ is self-orthogonal if u⋅v=0 for every u,v∈W. The standard bilinear form is nondegenerate, whence dimW+dimW⊥=n and dimW≤⌊n/2⌋. The condition with u=v means every vector has even Hamming weight. Such a binary linear code gives the linear algebra behind the Eventown theorem.
