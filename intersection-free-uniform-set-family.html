Intersection-free uniform set family

 ... Mathematics Area of mathematics Combinatorics Extremal set theory Set family Uniform set family
OurBigBook.com Words: 101 Articles: 1
An intersection-free uniform set family is a uniform set family F with no three distinct members A,B,C satisfying A∩B⊆C. For distinct members of a rank-r family, ∣A∩B∣<r, so using strict containment gives the same restriction. Fixing one member turns the other members' intersections with it into distinct antichain traces, giving the antichain trace bound for intersection-free families.
