Periodic covariance function (kP​(t,t′)=A2exp[−2ℓ−2sin2(π(t−t′)/P)])

 ... Mathematics Area of mathematics Probability and statistics Probability theory Stochastic process Gaussian process
OurBigBook.com Words: 113 Articles: 1
This covariance function is periodic with period P>0. Map time to the circle u(t)=(cos(2πt/P),sin(2πt/P)) and pull back a Gaussian kernel; since ∥u(t)−u(t′)∥2=4sin2(π(t−t′)/P), this proves positive semidefiniteness. A Gaussian process with this kernel has Var(f(t+P)−f(t))=0 and therefore repeats at every fixed phase. Replacing the inner π by 2π changes the actual period to P/2.
