Decision-tree depth (D(f))

 Home Computer science Theoretical computer science Computational complexity theory Decision tree model Decision tree
OurBigBook.com Words: 272 Articles: 5
The decision-tree depth D(f) of a Boolean function f is the smallest possible maximum number of input coordinates queried along any root-to-leaf path of a decision tree computing f.
