Relative constructible universe (L(A))

 ... Area of mathematics Foundations of mathematics Set theory Definable power set Constructible hierarchy Constructible universe
OurBigBook.com Words: 742 Articles: 7
For a transitive set X, the relative constructible universe L(X) is the union of the relative constructible hierarchy, starting at L0​(X)=X, applying the definable power set at successors and taking unions at limit ordinals. It is the smallest inner model of ZF containing X and all its members. For an arbitrary set A, take the base X to be the transitive closure of {A}, so that A∈X. Axiom of choice need not hold for an arbitrary base; the construction uses initial parameters rather than a predicate relativization.
