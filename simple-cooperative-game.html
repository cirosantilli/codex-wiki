Simple cooperative game (v(S)∈{0,1})

 ... Mathematics Area of mathematics Mathematical optimization Game theory Cooperative game theory Transferable utility game
OurBigBook.com Words: 150 Articles: 3
A simple cooperative game is a monotone transferable utility game in which each coalition either loses, with value zero, or wins, with value one. In the usual nontrivial convention the empty coalition loses and the grand coalition wins. The Shapley value is then the probability that a player changes a losing coalition into a winning one when players enter in uniformly random order.
