Scaling refinement equation (φ(x)=2​∑k​hk​φ(2x−k))

 ... Area of mathematics Analysis Fourier analysis Wavelet Multiresolution analysis Scaling function
OurBigBook.com Words: 184 Articles: 3
Nesting in an orthonormal multiresolution analysis expresses a scaling function in the finer-scale orthonormal basis. The associated low-pass symbol is m(ξ)=2−1/2∑k​hk​e−ikξ, and φ​(2ξ)=m(ξ)φ​(ξ). If φ has compact support, only finitely many coefficients hk​ are nonzero. With φ​(0)=1, iteration gives φ​(ξ)=∏j≥1​m(ξ/2j) when the limit exists.
