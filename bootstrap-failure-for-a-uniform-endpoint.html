Bootstrap failure for a uniform endpoint (P∗​(X(n)∗​=X(n)​)=1−(1−1/n)n)

 ... Mathematics Area of mathematics Probability and statistics Statistical model Statistical modelling Bootstrapping (statistics)
OurBigBook.com Words: 68
For a continuous uniform distribution on [0,θ], the scaled maximum gap n(θ−X(n)​)/θ tends to a unit-rate exponential distribution. An ordinary bootstrap sample includes the unique observed maximum with probability 1−(1−1/n)n→1−e−1. The bootstrap maximum gap therefore retains an atom at zero, whereas the target limit is continuous. This proves failure of the ordinary empirical bootstrap for this endpoint functional; consistency of the endpoint estimate alone does not justify resampling its extreme-value limit.
