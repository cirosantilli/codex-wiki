Flow coboundary (h=Fu)

 Home Physics Branches of physics Dynamical systems Dynamical system Smooth flow
OurBigBook.com Words: 97 Articles: 1
A smooth function h is a flow coboundary if h=Fu for some smooth function u, where F is the flow generator. Equivalently u(ϕt​x)−u(x)=∫0t​h(ϕs​x)ds. Thus its integral over every periodic orbit is zero. For a transitive Anosov flow, the Livsic theorem supplies the converse and smooth regularity.
