Resident set

 Home Computer science Operating system Virtual memory
OurBigBook.com Words: 27
The set of an operating-system process's memory pages currently present in main computer memory. A resident set may omit recently used memory pages after page replacement, or retain memory pages that have left the chosen working set window.
