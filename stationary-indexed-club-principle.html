Stationary-indexed club principle (♣S​)

 ... Foundations of mathematics Set theory Ordinal Club set Stationary set Club principle
OurBigBook.com Words: 41
For a stationary S⊆ω1​, there are cofinal ladders Aδ​⊂δ of order type ω, indexed by limit ordinals in S, such that every uncountable X⊆ω1​ contains one of these ladders. This predicts a contained ladder, whereas stationary diamond principle predicts a whole initial segment.
