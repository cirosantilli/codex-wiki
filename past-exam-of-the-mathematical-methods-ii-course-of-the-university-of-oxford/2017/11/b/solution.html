An interior stationary point has fx​=fy​=0. Assuming twice continuous differentiability nearby, the two-dimensional Taylor series about it is
f(p+h)=f(p)+21​hTHh+o(∣h∣2),H=(AB​BC​),
(29)
where A=fxx​, B=fxy​ and C=fyy​. Let D=AC−B2. The second-derivative test gives a strict local minimum if D>0,A>0, a strict local maximum if D>0,A<0, and a saddle point if D<0.
For example, if A=0, the quadratic form is A(hx​+Bhy​/A)2+(D/A)hy2​, which proves these sign tests. If D=0, the quadratic part is inconclusive: x4+y4 has a minimum while x4−y4 has a saddle at the origin, although both have zero Hessian matrix there. Higher-order terms or direct inequalities must then be examined.
