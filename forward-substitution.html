Forward substitution (yi​=(ci​−∑j<i​lij​yj​)/lii​)

OurBigBook.com Words: 64
Forward substitution solves a linear system Ly=c with a lower triangular matrix L and nonzero diagonal, from the first row downward:
yi​=lii​ci​−∑j=1i−1​lij​yj​​,i=1,…,n.
(80)
The first sum is empty, so y1​=c1​/l11​. Each subsequent row uses only components already found. For a unit triangular matrix L, omit the division because lii​=1. The complementary procedure, back substitution, solves an upper triangular matrix system from the last row upward.[ref]
