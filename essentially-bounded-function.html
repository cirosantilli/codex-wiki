Essentially bounded function (∣f∣≤M almost everywhere for some M<∞)

 ... Mathematics Area of mathematics Analysis Real analysis Lp norm L-infinity norm
OurBigBook.com Words: 99
A measurable function is essentially bounded if some finite nonnegative real number M bounds its absolute value almost everywhere. The exceptional null set may contain arbitrarily large values. With Lebesgue measure on [0,1], a function equal to zero outside {1/n:n∈N>0​} and equal to n at 1/n is essentially bounded despite being unbounded pointwise: its exceptional countable set is a null set, so M=0 works. Its L-infinity norm is zero because it represents the zero equivalence class in Lp space.
Contrast this with f(x)=1/x on (0,1]. For every M≥1, the values exceeding M occupy (0,1/M), a set of positive Lebesgue measure. Hence no finite almost everywhere bound works, and this function is not essentially bounded. Being finite at every input does not imply essential boundedness.
