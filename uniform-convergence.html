Uniform convergence (∥fn​−f∥∞​→0)

 Home Mathematics Area of mathematics Analysis Real analysis Sequence and series
OurBigBook.com Words: 1k Articles: 13
A sequence of functions fn​:X→Y converges uniformly to f:X→Y, where Y is a metric space with metric d, precisely when
∀ε>0∃N∈N>0​∀x∈X∀n≥N:d(fn​(x),f(x))<ε.
(71)
For real numbers, use the absolute value d(u,v)=∣u−v∣. Compare the universal quantification and existential quantification:
pointwise:uniform:​∀x∀ε>0∃N∀n≥N,∀ε>0∃N∀x∀n≥N.​
(72)
The decisive change is whether N can depend on x. Uniform convergence implies pointwise convergence.[ref]
For functions taking values in real numbers on a nonempty domain of a function, the supremum error is En​=supx∈X​∣fn​(x)−f(x)∣, allowing +∞. Then uniform convergence is equivalent to En​→0. The supremum need not be a maximum: pointwise strict bounds below ε only give En​≤ε, so use tolerance ε/2 when proving this equivalence. This single error bound controls every possible input, including one chosen after seeing the index.
For fn​(x)=xn and its pointwise limit on [0,1], the error is zero at one but approaches one as x→1 from below. Consequently
En​=supx∈[0,1]​∣fn​(x)−f(x)∣=1
(73)
for every positive integer n. This supremum is never attained: below one the error is xn<1, and at one it is zero. Deleting the endpoint leaves the same supremum error on [0,1). To disprove uniform convergence directly, choose ε=1/2: for any proposed N, take n=N and x=2−1/N<1. The error equals 1/2, violating the strict tolerance. Thus a moving input defeats every proposed common threshold.
On the smaller interval [0,a], for a fixed 0≤a<1, the pointwise limit is zero and
En​=maxx∈[0,a]​xn=an⟶0.
(74)
For 0<a<1 and 0<ε<1, the exact first successful common threshold is
N(a,ε)=⌊logalogε​⌋+1.
(75)
The logarithm and floor function turn an infinite approximation statement into a finite stopping rule. At a=0.8, 0.820=0.01152921504606846976 fails tolerance 0.01, while 0.821=0.009223372036854775808 succeeds. At a=1/2 and ε=1/8, the ratio is exactly three: N=4 is necessary because equality is insufficient. For a=0, every error is zero. The domain of a function determines whether one threshold can certify every input.
For another explicit stopping rule, let hn​(x)=x/(n+1) on [0,1]. Its uniform limit is zero and its supremum error is 1/(n+1). For every ε>0, N=max{1,⌈1/ε⌉} works, using the ceiling function. Unlike xn on [0,1], it controls even the endpoint.
The practical beauty of uniform convergence is that one quantitative bound can survive further operations: the uniform limit theorem preserves continuity, and uniform convergence preserves integrals on a compact interval controls accumulated error. Differentiation needs additional hypotheses, such as uniform derivative convergence with an anchored value. These results distinguish an approximation that looks accurate at selected inputs from one that justifies replacing a whole function in a calculation.
