Monodromy matrix of a periodic linear system (N=X(P)X(0)−1)

 ... Area of mathematics Analysis Differential equation Ordinary differential equation Linear differential equation Floquet theory
OurBigBook.com Words: 378
For the homogeneous linear differential equation Y˙=K(t)Y with continuous coefficient matrix of period P>0, the monodromy matrix of a periodic linear system is the one-period map from Y(0) to Y(P). If X is any fundamental matrix,
N=X(P)X(0)−1,Y(P)=NY(0).
(72)
Its eigenvalues are the Floquet multipliers. Multipliers are nonzero, since a fundamental matrix is invertible. Changing the starting phase conjugates N, so the Floquet multipliers and Jordan blocks are independent of that choice.[ref]
This turns a continuous-time problem into repeated matrix multiplication:
Y(nP)=NnY(0).
(73)
If Nv=mv, the associated solution of a differential equation obeys Y(t+P)=mY(t) at every time, not merely at the sampled times. In particular, Nv=v gives a nonzero P-periodic solution, and every nonzero P-periodic solution arises this way. If Nv=−v, the state changes sign after one period and repeats after two. A unit-modulus Floquet multiplier different from 1 need not give repetition after one period, and a generalized eigenvector in a nontrivial Jordan block need not even give bounded motion.
For the scalar example under periodic solution, N is the one-by-one matrix (e2πa). Numerically solving a matrix problem uses the same idea: integrate one initial value problem for each column of X(0)=I through one period, then compute the eigenvalues of X(P). This is useful when an explicit solution of a differential equation is unavailable: one period determines the Floquet growth rate over arbitrarily many periods.
For piecewise constant coefficients, which are also covered by the one-period construction, N is the time-ordered product of the segment matrix exponentials, with the earliest segment on the right. For example, take period P=2 and alternate
K1​=(00​10​)(0≤t<1),K2​=(01​00​)(1≤t<2).
(74)
Since K12​=K22​=0,
N=eK2​eK1​=(11​12​),m±​=23±5​​,γ=21​log23+5​​≈0.4812.
(75)
Replacing the coefficient by its mean would instead give eK1​+K2​=(cosh1sinh1​sinh1cosh1​) and the incorrect rate 0.5. The matrices do not commute. The scalar mean-coefficient formula therefore cannot simply be transferred to matrix systems. Nevertheless the Liouville formula for a fundamental matrix gives the correct determinant even in the noncommuting case:
detN=exp(∫0P​trK(t)dt).
(76)
In the example, this is 1=m+​m−​; it fixes the product of the Floquet multipliers, rather than either multiplier separately.
In Sur les équations différentielles linéaires à coefficients périodiques (1883), Gaston Floquet calls a function satisfying f(t+P)=mf(t) periodic of the second kind, and distinguishes the genuinely periodic function obtained when m=1. This historical terminology captures precisely the difference between repetition of the coefficient and repetition of the state.[ref]
