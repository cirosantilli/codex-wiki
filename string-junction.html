String junction

 ... Physics Branches of physics String theory Type II string theory Type IIB superstring theory (p,q) string
OurBigBook.com Words: 60
At a junction of (p,q) strings, their oriented charge vectors sum to zero. A static junction also balances the tension vectors. Supersymmetry further correlates spatial directions with charge phases so that the arms share kappa symmetry projectors. Additional independent conditions reduce the common Killing spinor space; an aligned dyonic string alone does not reduce its fraction relative to an aligned fundamental string.
