Adaptive Euler-Heun integration of exponential growth

Continue the initial value problem y′=y, y(0)=1, to t=4 using the Euler-Heun embedded pair. Choose absolute and relative error tolerances atol=10−3 and rtol=0, so the scalar scale is s=10−3 throughout. This intentionally absolute-only test makes the local and accumulated errors directly comparable. Start with h=0.2, accept the Heun's method endpoint precisely when E=∣d∣/s≤1, and after every trial use the capped adaptive step-size controller
hnext​=hmin(2,max(0.2,0.9E−1/2)).
(6)
For E=0 use the growth factor two. Cap every trial at 4−tn​; on rejection retain the old time and state. These choices specify an original computation, rather than a claim about the defaults of a particular software solver.
The initial trial has E=20 and is rejected. Retrying from (0,1) with h=0.9(0.2)/20​≈0.0402492236 gives E=0.81 and is accepted. The run takes 315 accepted steps and one rejected trial. Increasing exponential growth makes the local error estimator ∣d∣=∣yn​∣h2/2 grow at a fixed h, so subsequent steps shrink roughly like ∣yn​∣−1/2. The final step is additionally shortened to land at t=4.
The right panel plots errors against the accepted-step number, all divided by the same s. The actual Heun local defect uses the restarted exact endpoint yn​ehn​, while actual global error uses etn+1​. All accepted E are at most one, and the actual Heun local defects here are even smaller, at most about 0.01143s. Nevertheless the endpoint is yN​≈54.5833912205, versus e4≈54.5981500331, with absolute error about 0.0147588=14.7588s. Passing local tests therefore does not certify the original trajectory's global error.
This failure of a global guarantee has an exact explanation for this example. Put R(h)=1+h+h2/2 and gn​=etn​−yn​. Then
gn+1​=ehn​gn​+yn​(ehn​−R(hn​)).
(7)
Each new local defect is added to the previous error amplified by ehn​. Iterating this identity, rather than merely inspecting E, accounts for accumulation. The variable-step global ODE error bound describes the corresponding mechanism for more general ordinary differential equations.
Repeating with atol=10−2 gives 98 accepted steps, one rejection and endpoint absolute error about 0.153252; with atol=10−4 it gives 1001 accepted steps, two rejections and endpoint absolute error about 0.00145642. Accuracy improves on this smooth problem, but the endpoint error remains about fifteen times the requested local scale. A different initial value problem can amplify or damp defects differently.
