Nonabelian norm-residue kernel theorem

 ... Algebraic number theory Class field theory Adele ring Idele group Idèle class group Norm group of an abelian extension
OurBigBook.com Words: 39
For a finite Galois extension L/K with group G, the kernel of the global reciprocity map CK​→Gab is NL/K​CL​. It follows that this norm group equals the norm group from the maximal abelian subextension L[G,G]/K.
