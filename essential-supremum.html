Essential supremum (esssupμ​f)

 Home Mathematics Area of mathematics Analysis Real analysis Measure theory
OurBigBook.com Words: 264
The essential supremum is the upper bound for a measurable function after disregarding null sets for a specified measure μ. Its definition is
esssupμ​f=inf{M∈R:μ({x:f(x)>M})=0},
(55)
with values allowed in the extended real number line. A supremum controls every value; an essential supremum controls values almost everywhere. It therefore depends on the chosen measure, as well as on the function. [ref].
For a worked example, use Lebesgue measure on [0,1] and put
f(x)={10,x,​x=1/2,x=1/2.​
(56)
Its supremum is ten, attained at 1/2. But its essential supremum is one: f≤1 outside the singleton {1/2}, which is a null set. Every candidate M<1 fails, because the interval (max(0,M),1) has positive Lebesgue measure and includes values larger than M; changing one point cannot remove that interval. In particular, μ({f>0.8})=0.2, while μ({f>1})=0.
Why is this useful? Lebesgue integrals ignore changes on null sets, and Lp spaces identify functions that agree almost everywhere. The L-infinity norm uses esssup∣f∣ so it respects that identification. For this nonnegative example the supremum norm is ten and the L-infinity norm is one; replacing f(1/2) by 1/2 changes the former while leaving the latter unchanged. [ref].
The measure qualification is essential. For μ=δ1/2​, the Dirac measure concentrated at the exceptional input, that singleton has measure one and this function has essential supremum ten. A set ignored by one measure need not be ignored by another. The lower counterpart is the essential infimum, with essinff=−esssup(−f).
