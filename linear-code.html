Linear code

 Home Mathematics Area of mathematics Algebra Coding theory
OurBigBook.com Words: 496 Articles: 20
A binary linear [n,k,d] code is a k-dimensional subspace of F2n​ with least nonzero weight d. A parity-check matrix presents it as a kernel.
