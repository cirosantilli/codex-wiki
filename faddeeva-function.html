Faddeeva function (w(z)=e−z2erfc(−iz))

 ... Real analysis Calculus Integral Gaussian integral Error function Complementary error function
OurBigBook.com Words: 97 Articles: 1
The Faddeeva function is an entire function built from the complementary error function. Its integral representation for Imz>0 is w(z)=(iπ)−1∫−∞∞​e−t2/(t−z)dt, as normalized in NIST's integral representation. Its reflection identity is w(−z)=2e−z2−w(z), directly from the odd function property of the error function.
