Backward search

 Home Computer science Algorithm String-searching algorithm
OurBigBook.com Words: 48
Backward search finds a query's matching interval in a suffix array by processing the query from right to left. With inclusive one-based interval [l,r], prepending c changes it to [C(c)+Occ(c,l−1)+1,C(c)+Occ(c,r)]. An empty interval means no match. This works through the occurrence-order property of the last-to-first mapping.[ref]
