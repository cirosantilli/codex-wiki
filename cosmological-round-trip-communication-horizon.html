Cosmological round-trip communication horizon (dround​(t)=2a(t)​∫t∞​a(t′)dt′​)

 ... Physics Branches of physics General relativity Causal hierarchy Observer event horizon Cosmological event horizon
OurBigBook.com Words: 62
A light signal sent from a comoving observer to a comoving reflector at separation χ, and immediately returned, consumes conformal time 2χ. The supremum of the initial physical reflector distances allowing a return is therefore half the cosmological event horizon radius. Equality generally requires infinite return time; finite-time reception requires a strictly smaller distance. For a cosmological domain wall network with a∝t2, the supremum is t/2=1/H.
