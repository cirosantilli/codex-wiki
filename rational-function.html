Rational function

 ... Analysis Complex analysis Isolated singularity Classification of isolated singularities Pole Meromorphic function
OurBigBook.com Words: 229 Articles: 4
A rational function is a quotient p/q of polynomials, with q nonzero. After cancelling common factors, it defines a holomorphic map from the Riemann sphere to itself.
