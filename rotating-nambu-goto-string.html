Rotating Nambu–Goto string

 ... String theory Bosonic string theory Worldsheet String embedding map Induced worldsheet metric Nambu–Goto action
OurBigBook.com Words: 212 Articles: 3
A straight rigidly rotating classical string has speed of light at a free endpoint. Its energy and angular momentum satisfy a Regge trajectory. A segment with one anchored and one free end has J=E2/(πT), twice the slope of the string with two free ends.
