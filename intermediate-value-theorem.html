Intermediate value theorem

 ... Area of mathematics Analysis Real analysis Calculus Limit of a function Continuous function
OurBigBook.com Words: 104 Articles: 3
If f:[a,b]→R is continuous and y lies between f(a) and f(b), then some c∈[a,b] satisfies f(c)=y.
