Linear sieve

 Home Computer science Algorithm Number-theoretic sieve
OurBigBook.com Words: 47
A number-theoretic sieve that visits each composite number exactly once, through its smallest prime factor. Keep a growing list of prime numbers; for each i, generate ip only for stored primes p≤spf(i). Each composite m has a unique representation m=spf(m)(m/spf(m)) admitted by this rule, giving O(N) arithmetic updates up to N.
