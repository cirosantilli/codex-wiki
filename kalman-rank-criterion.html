Kalman rank criterion (rankC=n)

 Home Mathematics Area of mathematics Control theory Controllability
OurBigBook.com Words: 131
For a finite-dimensional continuous-time linear time-invariant system x˙=Ax+Bu on Rn, with constant matrices A,B over the real numbers, no state constraints, and every piecewise continuous function u:[0,T]→Rm allowed as a control input without an amplitude bound, controllability in any fixed T>0 is equivalent to the controllability matrix having rank of a matrix n. The same equivalence holds with all square-integrable functions as inputs. A stronger useful statement is
RT​(x0​)=eATx0​+imC,T>0,
(2)
where eAT is a matrix exponential and imC is the column space. Thus a rank of a matrix r<n leaves only an r-dimensional affine subspace reachable at that time. [ref]
The Kalman rank criterion allows arbitrarily large commands as T shrinks. It does not assert controllability with bounded control inputs, nor test a general nonlinear dynamical system just by counting its inputs. For the double integrator, B=(0,1)T and AB=(1,0)T give two independent directions, despite there being only one control input.
