Exponent reduction for units (ak≡akmodφ(n)(modn))

 Home Mathematics Area of mathematics Number theory Euler's theorem
OurBigBook.com Words: 316
For a unit modulo n a and a nonnegative integer k, division with remainder writes k=qφ(n)+r with 0≤r<φ(n). Euler's theorem then gives
ak=(aφ(n))qar≡ar(modn).
(31)
This replaces a potentially enormous exponent by a small remainder. The exponent itself is reduced modulo Euler's totient function, while the powers are reduced modulo n: these are different integer moduli.
For a worked modulo-fifteen calculation, seven is coprime to fifteen and φ(15)=8. Therefore
2029=253⋅8+5,72029≡75(mod15).
(32)
Use exponentiation by squaring on the remaining exponent 5=(101)2​, reducing after each multiplication:
72≡49≡4,74≡42≡1,75≡1⋅7≡7(mod15).
(33)
Thus 72029mod15=7. Modular exponentiation supplies the computation; Euler's theorem supplies the optional shortening of its exponent. Exponentiation by squaring also works for nonunit bases, without using this shortening.
The guaranteed exponent φ(n) is a common return exponent and an upper bound on the shortest period; it need not be that period. The multiplicative order d=ordn​(a) is the least positive return exponent for the chosen unit. The Carmichael function λ(n) is the least positive return exponent that works for every unit. Their precise relation is
ordn​(a)∣λ(n)∣φ(n).
(34)
Either smaller return exponent can replace φ(n) in exponent reduction for units. Modulo fifteen, ord15​(7)=λ(15)=4<8=φ(15), so 2029=507⋅4+1 gives 72029≡7 immediately. For base four the multiplicative order is only two, smaller even than λ(15). A return at exponent eight alone does not prove that the multiplicative order is eight.[ref]
If the reduced exponent is zero, the rule gives ak≡a0=1, and still requires a unit. Applying it to the nonunit three would falsely predict 38≡30=1(mod15); the actual residue is six. For negative exponents, first interpret the power using a modular multiplicative inverse, as in modular exponentiation.
