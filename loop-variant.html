Loop variant (V)

 Home Computer science Algorithm Algorithm correctness Loop invariant
OurBigBook.com Words: 149
A decreasing measure used to prove algorithm termination. A nonnegative integer loop variant must strictly decrease after every completed body whose condition was true; the body itself must terminate.[ref]
The prefix maximum correctness example uses V=n−k. It counts unread entries and is independent of whether the new entry changes the maximum. Ties therefore cannot stall progress: k increases even when best stays the same. An integer bounded below cannot strictly decrease indefinitely, which supplies the missing algorithm termination argument.
Strict decrease and a lower bound are insufficient for arbitrary real numbers. The positive sequence 1,1/2,1/4,… strictly decreases and is bounded below by zero, but never reaches zero. Choosing an integer measure avoids this failure.
