= Coding theory
{wiki}

Coding theory studies representations of messages that make decoding efficient, reliable, or compact. In <channel coding>, messages are mapped to separated <codewords>, so a corrupted word can still be recognized as coming from one particular message. In <lossless source coding>, a <prefix code> instead assigns short descriptions to frequent symbols. The objectives differ, but both exploit structure in the set of allowed words.

The simplest error-correction example sends $0$ as $000$ and $1$ as $111$. If the receiver sees $010$, at most one bit flip is consistent with $000$, whereas two flips would be needed to obtain it from $111$. A <repetition code> therefore recovers the original by taking the <majority function> of the received <bits>. The <Hamming distance> between the valid <codewords> is three: the spaces of one-error outputs around them do not overlap. This turns error correction into geometry in a discrete space.

The central tradeoff is between <code rate> and <minimum distance>. Additional separation makes correction possible but leaves fewer words available for messages at a fixed length. The <Hamming bound> counts disjoint error neighborhoods, while <linear codes> turn encoding and error detection into computations with <matrices> over <finite fields>. These connections explain why <combinatorics>, <linear algebra>, and <probability theory> all enter the subject.

Richard W. Hamming's *Error Detecting and Error Correcting Codes* appeared in the *Bell System Technical Journal* in April 1950, pp. 147–160. Its introduction motivates automatic correction through failures in digital computing, and its constructions go beyond detecting an error to identifying and correcting its location.\a[https://zoo.cs.yale.edu/classes/cs323/doc/Hamming.pdf][Hamming, Error Detecting and Error Correcting Codes, 1950]{ref}

= Channel coding
{parent=Coding theory}

Channel coding represents messages with <codewords> chosen to withstand transmission errors. An <error-correcting code> deliberately supplies redundancy, so a receiver can distinguish nearby corrupted outputs and recover the message. <Lossless source coding> instead removes predictable redundancy; practical communication can use both operations. The <Shannon second coding theorem> relates achievable rates on a <discrete memoryless channel> to its <channel capacity>.

= Code encoding
{parent=Coding theory}

Code encoding maps messages injectively to <codewords>. For a dimension-$k$ <linear code> with <generator matrix> $G$, the standard encoder maps $m\in\mathbb F_q^k$ to $mG$. The redundancy makes error detection and recovery possible; for a <Reed-Solomon code>, encoding can instead evaluate a message <polynomial> at the chosen field elements.

= Systematic encoding
{parent=Code encoding}

A systematic encoder retains the message symbols unchanged in designated coordinates of its <codeword> and calculates the remaining check symbols. For a <linear code>, choosing an invertible set of $k$ columns of a <generator matrix> and changing its row <basis> gives this form.

= Systematic polynomial encoding of a cyclic code
{parent=Systematic encoding}
{title2=$c(x)=x^{n-k}M(x)-(x^{n-k}M(x)\bmod g(x))$}

For a length-$n$, dimension-$k$ <cyclic code> with <generator polynomial> $g$ of degree $n-k$, let the message <polynomial> satisfy $\deg M<k$. Subtracting the remainder upon <polynomial division> by $g$ makes the displayed word divisible by $g$. The remainder has degree less than $n-k$, so the highest $k$ coordinates retain the coefficients of $M$. This gives <systematic encoding> without losing any message information.

= Gilbert–Varshamov bound
{c}
{parent=Coding theory}
{wiki}

For codes over an alphabet of size $q$, the greedy packing argument gives $A_q(n,d)\ge q^n/V_q(n,d-1)$, where $V_q(n,r)=\sum_{j=0}^r\binom nj(q-1)^j$. A maximal distance-$d$ code has radius-$(d-1)$ Hamming balls covering the entire space; counting their union proves the lower bound. The linear refinement is the <Varshamov bound for linear codes>.

= Worst-case correction guarantee from the Gilbert–Varshamov bound
{parent=Gilbert–Varshamov bound}
{title2=$R\leq1-h_2(2p),\quad0\leq p<1/4$}

A binary <code rate> $R$ is guaranteed with correction of every error pattern of <Hamming weight> at most $t=\lfloor pN\rfloor$ when $R\leq1-h_2(2p)$ and $p<1/4$. Choose <minimum Hamming distance> $2t+1$. The <Gilbert–Varshamov bound> and <entropy bound for a Hamming ball> give at least $2^{N(1-h_2(2p))}$ codewords. To deduce vanishing error probability for a <binary symmetric channel> with crossover probability $p$, use strict inequality in the rate condition and a correction radius $(p+\varepsilon)N$; the <weak law of large numbers> then controls the tail. Correcting exactly the mean number of errors does not by itself ensure reliable transmission.

= Asymptotic Gilbert–Varshamov bound
{parent=Gilbert–Varshamov bound}
{title2=$\alpha_q(\delta)\ge1-H_q(\delta)$}

For $0\le\delta\le1-1/q$, take logarithms of the <Gilbert–Varshamov bound> and apply the <Hamming ball volume exponent>. The <Varshamov bound for linear codes> gives the same achievable lower bound within linear codes for prime-power $q$.

= Varshamov bound for linear codes
{c}
{parent=Gilbert–Varshamov bound}

For a prime-power alphabet size $q$, a linear $[n,k,\ge d]$ code exists if $V_q(n-1,d-2)<q^{n-k}$. Choose parity-check columns successively, avoiding combinations of at most $d-2$ earlier columns. Fewer than $q^{n-k}$ vectors are forbidden, so such a choice is possible. No set of at most $d-1$ columns is dependent, and the resulting kernel has dimension at least $k$.

= Codeword
{parent=Coding theory}
{title2=$c\in C$}

A <codeword> is a member of the specified set of words used to encode messages. For a <linear code> specified by a <parity-check matrix> $H$, the <codewords> are precisely the vectors satisfying $Hc=0$. The <minimum distance> between distinct codewords controls error correction.

= Codeword length
{parent=Codeword}
{title2=$\ell(c)$}

The codeword length is the number of alphabet symbols in a <codeword>. For a binary word it counts bits; in a <prefix code>, it is the depth of the corresponding leaf in the code tree.

= Block code
{parent=Coding theory}
{wiki}

A <block code> assigns source messages to words of a fixed length over an <alphabet>. Its codewords form a subset of that fixed-length word space; a <binary block code> uses the two-symbol <finite field> $\mathbb F_2$.

= Binary block code
{parent=Block code}

A binary $[n,m,d]$ code is a set of $m$ distinct words in $\mathbb F_2^n$ whose minimum pairwise <Hamming distance> is $d$. Here $n$ is the block length and $m$ is the number of codewords.

= Error-correcting code
{parent=Binary block code}
{wiki}

An error-correcting code is a set of <codewords> chosen with enough separation to recover a transmitted message after specified errors. For equal-length words and bit-flip errors, separation is measured by <Hamming distance>. If the <minimum distance> is $d$, any nonzero pattern of at most $d-1$ flips changes a valid word into an invalid word and can therefore be detected. Every pattern of at most $t=\lfloor(d-1)/2\rfloor$ flips can be corrected by choosing the unique nearby <codeword>.

The distinction matters. A distance-two code detects a single flip but need not locate it; a distance-three code corrects a single flip. The <triangle inequality> explains the correction threshold: a received word within distance $t$ of two distinct <codewords> would put those <codewords> within distance $2t<d$, a contradiction. Actual decoders also need an efficient way to find the nearby word; a <parity-check matrix> and <syndrome decoding> exploit the structure of a <linear code> to do this.

= Repetition code
{parent=Error-correcting code}
{wiki}

A binary repetition code represents one <bit> by repeating it $n$ times, using <codewords> $0^n$ and $1^n$. Their <Hamming distance> is $n$, and the <code rate> is $1/n$. For odd $n$, the <majority function> recovers the input whenever fewer than half the positions have flipped. Even $n$ allows a tied vote, so a decoder must specify how it handles that case.

For $n=3$, the received words $000,001,010,100$ decode to zero; $111,110,101,011$ decode to one. The decoder therefore corrects every single flip. This guarantee concerns the number of flipped positions, independent of any probabilistic model.

If each position passes independently through a <binary symmetric channel> with crossover <probability> $q$, a decoded error requires at least two flips. The <binomial distribution> gives
$$
P_{\mathrm{error}}=3q^2(1-q)+q^3=3q^2-2q^3.
$$
At $q=0.1$, the uncoded error <probability> is $0.1$, while the three-bit code's decoded error <probability> is $0.028$. This improvement costs three transmitted <bits> per message <bit>. For $0<q<1/2$, $3q^2-2q^3<q$; for $q>1/2$, one should first exploit the known tendency to invert symbols rather than applying the same majority rule blindly.

{title=Three-bit majority decoding corrects one flip and lowers the error probability at the cost of rate}

Independent flips are an essential assumption for the displayed formula. If a single common disturbance flips all three positions together with <probability> $q$, repetition provides no improvement. More efficient <error-correcting codes> distribute redundancy across larger message blocks; repetition is useful as a transparent example of the geometry and the reliability–rate tradeoff.

The Hamming distance between two equal-length words is the number of coordinates in which they differ.

= Hamming space
{parent=Hamming distance}
{c}

The Hamming space of length $n$ over a <finite field> $\mathbb F_q$ is the set $\mathbb F_q^n$ equipped with <Hamming distance>, the number of coordinates at which two words differ. The <Hamming weight> of a word is its distance from zero.

= Diameter of a set family
{parent=Hamming distance}
{title2=$\operatorname{diam}(\mathcal F)=\max_{A,B\in\mathcal F}|A\triangle B|$}

= Hamming diameter
{c}
{synonym}

This is the maximum Hamming distance between the characteristic vectors of members of a set family. In a down-set, one can replace a pair by disjoint subsets with the same union, so the maximum distance equals the largest size of a union of two members. A t-intersecting family has diameter at most $n-t$.

= Normalized Hamming distance
{parent=Hamming distance}
{title2=$\overline d_H(x,y)=d_H(x,y)/n$}

On binary words of length $n$, <normalized Hamming distance> is the fraction of differing coordinates. Unlike unscaled <Hamming distance>, it makes the <Hamming cubes> a <Lévy family> under uniform <probability measures>.

= Hamming cube
{parent=Hamming distance}
{c}
{title2=$\{-1,1\}^n$}

= Discrete hypercube
{synonym}

The <Hamming cube> is $\{-1,1\}^n$, or equivalently $\{0,1\}^n$, equipped with <Hamming distance>. Under its uniform <probability measure>, the distance from a fixed vertex has the <binomial distribution> with parameters $n,1/2$. This converts geometric ball sizes into probability tails.

= Exponential packing of a Hamming cube
{parent=Hamming cube}
{title2=$|S|\geq e^{9n/32},\quad d_H(s,s^{\prime})\geq n/8$}

An <inclusion-maximal separated set> of separation $an$ covers the <Hamming cube> by strict-radius $an$ balls. The <Hoeffding lower-tail bound for Hamming balls> then gives at least $e^{2n(1/2-a)^2}$ selected vertices. At $a=1/8$ this yields $e^{9n/32}$ vertices, all separated by at least $n/8$.

= Hamming distance between unlabelled bipartitions
{c}
{parent=Hamming distance}
{title2=$\Delta(S,T)=\min\{|S\triangle T|,|S\triangle T^c|\}$}

This <Hamming distance> on partitions identifies a group with its complement because exchanging the two group names does not change the partition. Complementation is an <isometry> of the ordinary <Hamming distance>, so minimizing over this two-element group action gives a quotient metric and preserves the <triangle inequality>. Negating a zero-one indicator is not complementation; with $\pm1$ membership vectors, it is.

= Sign rounding bound for a unit eigenvector
{parent=Hamming distance between unlabelled bipartitions}
{title2=$\Delta(\widehat S,S)\leq n\|\widehat v\widehat v^\top-vv^\top\|_F^2$}

Suppose $v_i=\pm1/\sqrt n$ encodes the true partition and $\widehat v$ is a unit estimated <eigenvector>. Every coordinate of the wrong sign contributes at least $1/n$ to $\min_{\sigma=\pm1}\|\widehat v-\sigma v\|_2^2=2(1-|\widehat v^\top v|)$. Since this is at most $2(1-|\widehat v^\top v|^2)$, which is the squared Frobenius distance between the rank-one <orthogonal projection matrices>, the bound follows. Coordinates estimated as zero may be assigned consistently to either group.

= Hamming ball
{title2=$B_r(x)$}
{parent=Hamming distance}
{c}

The Hamming ball of radius $r$ about a word $x$ is the set of words whose <Hamming distance> from $x$ is at most $r$.

= Hamming ball volume exponent
{c}
{parent=Hamming ball}
{title2=$\lim_{n\to\infty}n^{-1}\log_qV_q(n,\lfloor\rho n\rfloor)=H_q(\rho)$}

For $0\le\rho\le1-1/q$, the exponential growth rate of a q-ary Hamming ball is $H_q(\rho)$. <Stirling's formula> gives the exponent of each summand $\binom ni(q-1)^i$, and the sum lies between its largest term and $n+1$ times that term. Above the entropy-maximizing radius fraction, the exponent is one.

= Hoeffding lower-tail bound for Hamming balls
{parent=Hamming ball}
{c}
{title2=$2^{-n}|B_{an}|\leq e^{-2n(1/2-a)^2}$}

For a uniform vertex of the <Hamming cube>, distance from a fixed vertex is the sum of $n$ <independent> <Bernoulli random variables> with parameter $1/2$. The lower-tail <Hoeffding inequality> implies that the fraction of vertices at distance at most $an$, $0<a<1/2$, is at most $e^{-2n(1/2-a)^2}$. Strict-radius balls satisfy the same upper bound.

= Entropy bound for a Hamming ball
{parent=Hamming ball}
{title2=$\sum_{j\leq\rho n}\binom nj\leq e^{nh(\rho)}$}

For $0<\rho\leq1/2$, the number of binary words within <Hamming distance> $\rho n$ of a fixed word is at most $e^{nh(\rho)}$, with the <binary entropy function> in natural logarithms. In $1=\sum_j\binom nj\rho^j(1-\rho)^{n-j}$, each summand weight for $j\leq\rho n$ is at least $\rho^{\rho n}(1-\rho)^{n(1-\rho)}=e^{-nh(\rho)}$. Also $h''(\rho)=-1/(\rho(1-\rho))\leq-4$, so $\log2-h(1/2-a)\geq2a^2$. These two bounds give the approximate-recovery denominator in the <list-decoding Fano inequality>.

= Perfect code
{parent=Binary block code}
{wiki}

A code of minimum distance $d$ is perfect if its <Hamming balls> of radius $\lfloor(d-1)/2\rfloor$ partition the ambient word space. Every word then has a unique nearest codeword within the code's error-correction radius.

= Binary Golay code
{parent=Perfect code}
{wiki}
{title2=$G_{23}=[23,12,7]$}

The length-$23$ <binary Golay code> is the <cyclic code> over $\mathbb F_2$ generated by
$$
g(X)=1+X+X^5+X^6+X^7+X^9+X^{11}.
$$
It has <dimension> $12$, <minimum Hamming distance> $7$, and its radius-$3$ <Hamming balls> partition $\mathbb F_2^{23}$. Its <parity extension> has length $24$, <dimension> $12$, and <minimum Hamming distance> $8$.

= Extended binary Golay code
{parent=Binary Golay code}
{title2=$G_{24}=[24,12,8]$}

The extended binary Golay code is the <parity extension> of the length-$23$ <binary Golay code>. It is a <self-dual code> and a <doubly even code>, with <minimum Hamming distance> eight. Its radius-three <Hamming balls> are disjoint but do not cover its <Hamming space>; it is not a <perfect code>.

= Three-error syndrome decoding of extended Golay code
{parent=Extended binary Golay code}

For a binary <symmetric matrix> $A$ with $A^2=I$, the <syndrome> of an error $(p,q)$ relative to the column <parity-check matrix> $(I;A)$ is $s=p+qA$. An error of total <Hamming weight> at most three has at most one nonzero bit in one half. Test $s$, each $s+A_i$, $sA$, and each $sA+A_i$ for weights at most three, two, three and two respectively. These identify $(s,0)$, $(s+A_i,e_i)$, $(0,sA)$ and $(e_i,sA+A_i)$. For the <extended binary Golay code>, <minimum Hamming distance> eight guarantees that at most one such error exists.

= Systematic-matrix proof of extended Golay distance
{parent=Extended binary Golay code}

Suppose a binary <symmetric matrix> $A$ satisfies $A^2=I$, has one row of <Hamming weight> eleven and eleven rows of <Hamming weight> seven, and every sum of two distinct rows has <Hamming weight> six. Then $(I\mid A)$ generates a <self-dual code>. Its rows have weights twelve or eight; their mutual orthogonality makes every generated word <doubly even>. A weight-four word $(u,uA)$ would have left-half weight one, two, three or four. The first two cases are excluded by the stated row weights; weight three would force $uA$ to be a unit vector and hence $u$ to be a row of $A$; weight four would force $uA=0$. Thus weight four is impossible and the <minimum Hamming distance> is eight.

= Golay generator polynomial
{parent=Binary Golay code}
{c}

The <generator polynomial of a cyclic code> defining the <binary Golay code> is $1+X+X^5+X^6+X^7+X^9+X^{11}$.

= BCH and parity-extension proof of the binary Golay distance
{parent=Binary Golay code}
{c}

A root $\beta$ of the binary <Golay generator polynomial> has order $23$, and the <Frobenius endomorphism> shows that $\beta,\beta^2,\beta^3,\beta^4$ are roots: $2^8\equiv3\pmod{23}$. The <BCH bound> gives <minimum Hamming distance> at least five. The <circular autocorrelation of the binary Golay generator> makes its <parity extension> <doubly even>, excluding original weights five and six. The generator itself has <Hamming weight> seven, proving that the distance is exactly seven.

= Circular autocorrelation of the binary Golay generator
{parent=Binary Golay code}

The polynomial identity $(X+1)g(X)g^{\mathrm{rev}}(X)=X^{23}+1$, where $g^{\mathrm{rev}}(X)=X^{11}g(X^{-1})$, implies
$$
g(X)g(X^{-1})\equiv1+X+\cdots+X^{22}\pmod{X^{23}-1}.
$$
Every coefficient is the binary <inner product> of the coefficient vector of $g$ with one cyclic shift. Thus every such <inner product> is one. Appending a parity bit to the cyclic shifts gives mutually orthogonal weight-eight vectors, so <orthogonal generators of doubly even codes> applies.

= Singleton bound
{c}
{parent=Binary block code}
{wiki}

For a code of length $n$, size $M$, and minimum distance $d$ over an alphabet of size $q$, puncturing $d-1$ coordinates gives the Singleton bound
$$
M\leq q^{n-d+1}.
$$

= Plotkin bound
{c}
{parent=Binary block code}
{wiki}

The Plotkin bound limits a code whose minimum distance is more than the average distance between unrestricted words. For a binary code with $n<2d$ and even $d$,
$$
M\leq2\left\lfloor\frac d{2d-n}\right\rfloor.
$$

= Punctured code
{parent=Puncturing (coding theory)}

Puncturing a code at one coordinate deletes that coordinate from every codeword. For a code of minimum distance $d\geq2$, puncturing preserves its number of words and gives minimum distance $d$ or $d-1$.

= One-time pad
{parent=Coding theory}
{wiki}

For messages in a <finite additive group>, a one-time pad encrypts $X$ as $C=X+K$, where the key $K$ is uniform and <independent random variables>[independent] of $X$, as long as the message, and never reused. Then $C$ is uniform and <independent random variables>[independent] of $X$, giving <perfect secrecy>.

= Two-time pad attack
{parent=One-time pad}

If two plaintexts are encrypted by adding the same one-time-pad key, subtracting the ciphertexts cancels the key and reveals the difference of the plaintexts. Redundancy in natural language or another structured message space can then reveal both messages, so a one-time pad must never reuse key material.

= Perfect secrecy
{parent=One-time pad}
{wiki}

An encryption scheme has perfect secrecy when the ciphertext and plaintext are <independent random variables>, so observing the ciphertext does not change the plaintext's <probability distribution>.

= Malleability of an additive one-time pad
{parent=One-time pad}

If an interceptor knows that an additive one-time-pad ciphertext $C$ encrypts plaintext $P$ and wants it to decrypt as $P'$, replacing it by
$$
C'=C-P+P'
$$
works without knowing the key, since $C'=P'+K$.

= Secret sharing
{parent=Coding theory}
{wiki}

A secret-sharing scheme distributes shares of a secret so that authorized collections can reconstruct it while unauthorized collections reveal no information about it.

= Threshold secret sharing
{parent=Secret sharing}

An $(r,s)$ threshold secret-sharing scheme issues $s$ shares: every collection of at least $r$ shares reconstructs the secret, while every collection of fewer than $r$ shares has a distribution independent of the secret.

= Shamir's secret sharing
{c}
{parent=Threshold secret sharing}
{wiki}

Shamir's secret sharing places a secret $N$ at the constant term of a random polynomial $f\in\mathbb F_p[X]$ of degree at most $r-1$ and issues distinct nonzero evaluation pairs $(x_i,f(x_i))$. Any $r$ shares recover $f$ by <polynomial interpolation>. Given fewer than $r$ shares, every candidate constant term has the same number of compatible coefficient tuples, which gives perfect secrecy.

= Perfect secrecy of Shamir's threshold scheme
{parent=Shamir's secret sharing}
{c}

Conditioned on any $r-1$ shares in <Shamir's secret sharing>, each candidate secret in $\mathbb F_p$ remains equally likely. Appending $(0,N)$ to those shares determines exactly one degree-at-most-$(r-1)$ polynomial for every candidate $N$, by the nonzero <Vandermonde determinant>.

= Discrete memoryless channel
{parent=Coding theory}
{wiki}

A discrete memoryless channel has finite input and output alphabets and transition probabilities $P(y\mid x)$. Conditional on the input symbols, different channel uses have independent outputs governed by the same transition probabilities.

= Finite-alphabet erasure channel
{parent=Discrete memoryless channel}
{title2=$Y=X\text{ with probability }1-f,\quad Y=e\text{ with probability }f$}

A finite-alphabet erasure channel transmits the input symbol unchanged with probability $1-f$ and replaces it by a distinct erasure flag with probability $f$, independently of the symbol. Given the flag, the posterior remains the input distribution; otherwise the input is known. Thus its <mutual information> is $(1-f)H(X)$.

= Capacity of a finite-alphabet erasure channel
{parent=Finite-alphabet erasure channel}
{title2=$C=(1-f)\log_2k$}

For a <finite-alphabet erasure channel> with $k$ input symbols, $I(X;Y)=(1-f)H(X)$. Maximizing <Shannon entropy> at the uniform input gives <channel capacity> $C=(1-f)\log_2k$ bits per use, by the <Shannon second coding theorem>.

= Binary erasure channel
{parent=Discrete memoryless channel}
{wiki}

A binary erasure channel transmits each input bit correctly with probability $1-\varepsilon$ and replaces it by an erasure symbol with probability $\varepsilon$. Its <channel capacity> is $1-\varepsilon$ bits per use.

A Z-channel transmits one binary input without error while the other can change into the first. Unlike a <binary symmetric channel>, its errors are one-sided.

= Noisy-channel coding theorem
{parent=Coding theory}
{wiki}

= Shannon second coding theorem
{c}
{synonym}

For a discrete memoryless channel, operational capacity equals
$$
C=\max_{P_X}I(X;Y).
$$
Rates below $C$ admit codes whose error tends to zero, while rates above $C$ cannot have vanishing error.

= Reliable transmission rate
{title2=$R$}
{parent=Noisy-channel coding theorem}

A rate $R$ is reliably achievable through a channel when there is a sequence of length-$n$ channel codes with $M_n$ messages such that
$$
\liminf_{n\to\infty}\frac{\log_2M_n}{n}\geq R
$$
and their decoding-error probability tends to zero.

= LFSR
{synonym}
{c}

A binary linear-feedback shift register of degree $d$ updates a $d$-bit state by shifting and inserting a fixed linear combination over $\mathbb F_2$. With recurrence
$$
s_{n+d}=a_{d-1}s_{n+d-1}+\cdots+a_0s_n,
$$
its feedback polynomial is $x^d+a_{d-1}x^{d-1}+\cdots+a_0$.

= Output sets of different-length linear-feedback registers
{parent=Linear-feedback shift register}

Under the convention that a register emits each shifted-out symbol, its first $d$ output symbols are exactly its initial fill. Thus a binary register of length $d$ has $2^d-1$ distinct outputs from nonzero fills. For lengths $r<s$, at least one longer-register output is absent from the shorter register, guaranteeing a pair of unequal nonzero outputs. The two sets need not be disjoint: recurrences $s_{n+1}=s_n$ and $s_{n+2}=s_n$ both generate constant ones. Nor must they intersect: the length-one recurrence and $s_{n+2}=s_{n+1}+s_n$ have no common nonzero output, since constant ones fail the second recurrence.

= Feedback polynomial
{parent=Linear-feedback shift register}

The feedback polynomial records the coefficients of an <LFSR> recurrence. With the convention
$$
s_{n+d}=a_{d-1}s_{n+d-1}+\cdots+a_0s_n,
$$
it is $x^d+a_{d-1}x^{d-1}+\cdots+a_0$.

= Feedback shift register
{parent=Linear-feedback shift register}
{wiki}

A feedback shift register updates a finite state by shifting its stored symbols and inserting the value of a feedback function of the previous state. The feedback function need not be linear.

The Berlekamp-Massey algorithm finds the shortest linear recurrence satisfied by a finite sequence over a field. It processes symbols incrementally, updating the connection polynomial whenever the current recurrence has a nonzero discrepancy.

= Minimum recurrence length after a new discrepancy
{parent=Berlekamp-Massey algorithm}
{title2=$L'\geq r+1-L$}

Suppose a connection polynomial $C$ of degree at most $L$, with recurrence span $L$ gives zero recurrence discrepancies through index $r-1$ but a nonzero discrepancy at $r$. If a polynomial $D$ of span $L'$ successfully explains the prefix through $r$ and $L+L'\leq r$, evaluate the coefficient at $r$ in the convolution $(CD)x$. Applying $D$ first makes it zero. Applying $C$ first leaves its nonzero discrepancy at $r$, because the earlier discrepancies vanish and $D$ has constant coefficient one. This contradiction gives the displayed lower bound. It is the minimality step used by the <Berlekamp-Massey algorithm>; the algorithm cancels the new discrepancy with a shifted earlier failed polynomial.

= Minimal recurrence for the binary prefix 11001011
{parent=Berlekamp-Massey algorithm}

The shortest binary linear recurrence producing the prefix $11001011$ has length three:
$$
x_n=x_{n-2}+x_{n-3}.
$$
Its connection polynomial is $1+D^2+D^3$.

= Period bound for a linear-feedback shift register
{parent=Linear-feedback shift register}

A degree-$d$ binary register has $2^d$ states. The zero state is fixed, so a nonzero periodic orbit has length at most $2^d-1$.

= Feedback-polynomial parity condition for maximal period
{parent=Linear-feedback shift register}

A maximal-period feedback polynomial cannot have $1$ as a root. Over $\mathbb F_2$, this says
$$
1+a_{d-1}+\cdots+a_0\ne0,
$$
so an even number of the coefficients $a_i$ equal one and the full monic polynomial has an odd number of nonzero coefficients.

= Zero-run lower bound for a linear-feedback shift register
{parent=Linear-feedback shift register}

If an output prefix contains $d$ consecutive zeros followed by a one, no register of degree at most $d$ can generate it: the all-zero state would have been reached and would remain zero forever.

= Minimal linear-feedback shift register for the prefix 100000001
{parent=Zero-run lower bound for a linear-feedback shift register}

The seven consecutive zeros followed by one force degree at least eight. Degree eight is attained by $s_{n+8}=s_n$, with initial state $10000000$ and feedback polynomial $x^8+1$.

= Trace-generated maximal-period linear-feedback sequence
{parent=Linear-feedback shift register}

Let $K=\mathbb F_{2^d}$, let $\alpha$ generate $K^\times$, and let $T:K\to\mathbb F_2$ be nonzero linear with <nondegenerate bilinear form> $(x,y)\mapsto T(xy)$. If the <minimal polynomial> of $\alpha$ is $P(X)=X^d+\sum_{j<d}c_jX^j$, then $x_n=T(\alpha^n)$ satisfies
$$
x_{n+d}=\sum_{j<d}c_jx_{n+j},
$$
so it is produced by an LFSR of length at most $d$. Its period is exactly $2^d-1$: any period $r$ would imply $T((\alpha^r-1)y)=0$ for every $y\in K$, hence $\alpha^r=1$ by nondegeneracy.

= Linear code
{parent=Coding theory}
{wiki}

A binary linear $[n,k,d]$ code is a $k$-dimensional subspace of $\mathbb F_2^n$ with least nonzero weight $d$. A parity-check matrix presents it as a kernel.

= Monomial equivalence of linear codes
{parent=Linear code}

Two <linear codes> are monomially equivalent if a permutation of coordinates followed by multiplication of individual coordinates by nonzero <field> elements takes one to the other. This preserves <dimension> and <Hamming distance>. Choosing different representatives for projective parity-check columns produces this equivalence.

= Maximum distance separable code
{parent=Linear code}
{title2=$d=n-k+1$}

= MDS code
{synonym}
{c}

A nonzero length-$n$, dimension-$k$ <linear code> is maximum distance separable if its <minimum Hamming distance> equals $n-k+1$, attaining the <Singleton bound>. <Reed-Solomon codes> and <generalized Reed-Solomon codes> provide examples because a nonzero polynomial of degree at most $k-1$ has at most $k-1$ distinct <polynomial roots>.

= Reed-Solomon error correction
{parent=Linear code}

= Reed-Solomon code
{c}
{synonym}

= RS code
{synonym}
{c}

For distinct elements $a_1,\ldots,a_n$ of a <finite field>, a Reed-Solomon code consists of the evaluation vectors $(f(a_1),\ldots,f(a_n))$ of <polynomials> with degree less than $k$. It has <dimension> $k$ and <minimum Hamming distance> $n-k+1$, so it is a <maximum distance separable code>. A nonzero polynomial has at most its degree many distinct <polynomial roots>. <Primitive cyclic Reed-Solomon codes> use all nonzero field elements, ordered as powers of a <primitive root of unity>; arbitrary evaluation sets need not give a <cyclic code>.

= Primitive cyclic Reed-Solomon code
{parent=Reed-Solomon error correction}
{title2=$C_{k,b}=\langle\prod_{\ell=b}^{b+n-k-1}(x-\omega^\ell)\rangle$}

Let $n=q-1$ and let $\omega$ be a <primitive root of unity> in $\mathbb F_q$. The length-$n$ <cyclic code> with consecutive <zeros of a cyclic code> $\omega^b,\ldots,\omega^{b+n-k-1}$ has dimension $k$. It equals the <generalized Reed-Solomon code> of vectors $(\omega^{j(1-b)}f(\omega^j))_{j=0}^{n-1}$, $\deg f<k$. The choice $b=1$ is the unweighted <Reed-Solomon code> on these evaluation points; allowing other offsets makes this family closed under <dual codes>.

= Reed-Solomon key equation
{parent=Primitive cyclic Reed-Solomon code}
{c}
{title2=$\Lambda(z)S(z)\equiv\Omega(z)\pmod{z^{n-k}}$}

With <syndromes> $S_\ell=\sum_i E_i X_i^{b+\ell}$ and distinct error-location values $X_i$, form $S(z)=\sum_{\ell=0}^{n-k-1}S_\ell z^\ell$ and the <error locator polynomial> $\Lambda(z)=\prod_i(1-X_i z)$. There is an <error evaluator polynomial> $\Omega$ of degree less than the number of errors satisfying the key equation. When the number of errors is at most $\lfloor(n-k)/2\rfloor$, the <Berlekamp-Massey algorithm> or <extended Euclidean algorithm> recovers these polynomials, normalized by $\Lambda(0)=1$.

= Duality of primitive cyclic Reed-Solomon codes
{parent=Primitive cyclic Reed-Solomon code}
{title2=$C_{k,b}^\perp=C_{n-k,1-b}$}

For $n=q-1$ and $a_j=\omega^j$, the two evaluation forms are $a_j^{1-b}f(a_j)$ and $a_j^b h(a_j)$, with $\deg f<k$ and $\deg h<n-k$. Their <dot product> is $\sum_j a_j f(a_j)h(a_j)=0$, since every appearing exponent is between one and $n-1$ and the sums of those powers of $a_j$ vanish. Comparing <dimensions> proves equality with the <dual code>. In particular, the dual of the unweighted evaluation code has multipliers $a_j$; it need not be an unweighted evaluation code on the same ordered points.

= Generalized Reed-Solomon code
{parent=Reed-Solomon error correction}
{title2=$\operatorname{GRS}_k(a,v)$}

= GRS code
{synonym}
{c}

A generalized Reed-Solomon code consists of $(v_i f(a_i))_{i=1}^n$, where the evaluation points are distinct, all coordinate multipliers $v_i$ are nonzero, and $\deg f<k$. It remains a <maximum distance separable code>. Its <dual code> is another generalized Reed-Solomon code with dimension $n-k$ and multipliers proportional to $v_i^{-1}\prod_{j\ne i}(a_i-a_j)^{-1}$.

= Code rate
{parent=Linear code}
{title2=$R=k/n$}

For a linear code of length $n$ and dimension $k$ over $\mathbb F_q$, the code rate is $R=k/n$. There are $q^k$ possible messages represented by $q^k$ <codewords> of length $n$. More generally a block code $C\subseteq\mathbb F_q^n$ has rate $\log_q|C|/n$. This is a dimensionless redundancy measure, distinct from information transmitted per unit physical time.

= Asymptotic rate-distance function
{parent=Code rate}
{title2=$\alpha_q(\delta)$}

The asymptotic rate-distance function is $\alpha_q(\delta)=\limsup_{n\to\infty}n^{-1}\log_q A_q(n,\max\{1,\lceil\delta n\rceil\})$. It is the best asymptotic <code rate> available at the specified <relative minimum distance>. A limsup is used because the definition does not assume an ordinary limit exists.

= Binary linear code
{parent=Linear code}
{title2=$C\leq\mathbb F_2^n$}

A <linear code> over the two-element <finite field>. Its dimension $r$ gives $2^r$ codewords. Its <weight enumerator> in the convention $W_C(s,t)=\sum_{c\in C}s^{w(c)}t^{n-w(c)}$ is symmetric in $s,t$ exactly when the all-ones word belongs to $C$: adding that word complements every bit and replaces weight $w$ by $n-w$. Conversely symmetry makes the coefficient of $s^n$ equal the coefficient of $t^n$, which is one.

= Total weight of a full-support binary linear code
{parent=Binary linear code}
{title2=$\sum_{x\in C}\operatorname{wt}(x)=n2^{k-1}$}

A length-$n$, dimension-$k$ <binary linear code> has full support when no coordinate vanishes on every <codeword>, equivalently when the union of the <supports of a vector> of all codewords covers every coordinate. Every coordinate is then a nonzero <linear functional> on the message <vector space> $\mathbb F_2^k$. Translation by a <vector> on which it is one pairs the zero and one fibers, so exactly $2^{k-1}$ <codewords> contribute one in that coordinate. Summing these contributions proves the formula. If there are $r$ nonzero columns in a full-rank <generator matrix>, the same argument gives $r2^{k-1}$ instead.

= Even-weight subcode of a binary linear code
{parent=Binary linear code}
{title2=$C^{\mathrm{ev}}=\ker(\sigma|_C)$}

For a <binary linear code> $C$, the <linear functional> $\sigma(x)=\sum_jx_j$ records <Hamming weight> modulo two. Its <kernel of a linear map> is the even-weight subcode. If $\sigma|_C$ vanishes, this is all of $C$; otherwise <rank-nullity theorem> gives <dimension> $\dim C-1$. This also proves closure under addition without treating ordinary integer weight as a linear function.

= Doubly even
{synonym}

A <binary linear code> is <doubly even> when the <Hamming weight> of every codeword is divisible by four.

= Orthogonal generators of doubly even codes
{parent=Doubly even code}

Suppose the generators of a <binary linear code> have <Hamming weights> divisible by four and have pairwise zero binary <inner products>. Their <linear span> is <doubly even>: for any two vectors,
$$
\operatorname{wt}(u+v)=\operatorname{wt}(u)+\operatorname{wt}(v)-2|\operatorname{supp}(u)\cap\operatorname{supp}(v)|.
$$
The binary <inner product> says the intersection size is even. Induction on the number of generators in a sum proves divisibility by four.

= Self-orthogonal binary subspace
{parent=Binary linear code}
{title2=$W\subseteq W^\perp$}

A <linear subspace> $W\subseteq\mathbb F_2^n$ is self-orthogonal if $u\cdot v=0$ for every $u,v\in W$. The standard <bilinear form> is <nondegenerate>, whence $\dim W+\dim W^\perp=n$ and $\dim W\leq\lfloor n/2\rfloor$. The condition with $u=v$ means every vector has even <Hamming weight>. Such a <binary linear code> gives the <linear algebra> behind the <Eventown theorem>.

= Odd-length binary self-orthogonal dual extension
{parent=Self-orthogonal binary subspace}
{title2=$C^\perp=C\oplus\langle\mathbf1\rangle$}

If a <self-orthogonal binary subspace> has odd length $n$ and <dimension> $(n-1)/2$, its <dual code> is obtained by adjoining the all-ones word. Self-orthogonality makes every <codeword> even-weight, so $\mathbf1\in C^\perp$ but $\mathbf1\notin C$. Comparing <dimensions> proves the formula. The <dimension> hypothesis alone is insufficient: $C=\langle100\rangle$ at length three is a counterexample.

= Single parity-check code
{parent=Binary linear code}
{title2=$C=\{x\in\mathbb F_2^n:\sum_i x_i=0\}$}

= Simple parity check code
{synonym}

The code consisting of all even-weight binary words. For $n\geq1$ its dimension is $n-1$, and its <weight enumerator> is $[(t+s)^n+(t-s)^n]/2$, by selecting the even terms of the <binomial theorem>. The length-one code contains only zero.

= Tetracode
{parent=Linear code}
{title2=$T\le\mathbb F_3^4$}

= Ternary tetracode
{synonym}

The two-dimensional ternary <linear code> generated by $(0,1,1,1)$ and $(1,1,-1,0)$. Its eight nonzero words have exactly three nonzero entries, with precisely two opposite words for each position of the zero coordinate.

= Weight enumerator
{parent=Linear code}
{title2=$W_C(s,t)$}

The homogeneous <weight enumerator> of a length-$n$ <linear code> $C$ is the <polynomial>
$$
W_C(s,t)=\sum_{x\in C}s^{\operatorname{wt}(x)}t^{n-\operatorname{wt}(x)}.
$$
Its coefficients count words of each <Hamming weight>. In this convention $W_C(1,1)=|C|$; some references interchange $s,t$.

= MacWilliams identity
{parent=Weight enumerator}
{c}

For a binary <linear code> of dimension $k$ and its <dual code>, the <weight enumerator> convention $s^{\operatorname{wt}(x)}t^{n-\operatorname{wt}(x)}$ gives
$$
W_{C^\perp}(s,t)=2^{-k}W_C(t-s,t+s).
$$
To prove it, insert $\mathbf1_{C^\perp}(y)=2^{-k}\sum_{x\in C}(-1)^{x\cdot y}$ into the enumerator sum. Summing independently over each coordinate of $y$ yields a factor $t+s$ if $x_j=0$ and $t-s$ if $x_j=1$.

= Parity bit
{parent=Linear code}
{wiki}

A parity bit records whether the number of one bits in a word is even or odd and can detect every error that flips an odd number of bits.

= Parity computation by CNOT gates
{parent=Parity bit}
{title2=$W|x\rangle|y\rangle=|x\rangle|y\oplus\bigoplus_jx_j\rangle$}

Apply one <CNOT gate> from each input <qubit> to the same target. Their actions commute because controls remain unchanged and each contribution is added modulo two. This reversible circuit computes the <parity bit> with exactly one <two-qubit gate> per input, and its inverse is the same circuit. Unlike measuring the inputs to compute parity classically, the unitary preserves <quantum superposition> and can be uncomputed after phase application.

= Griesmer bound
{c}
{parent=Linear code}
{wiki}

Every binary linear $[n,k,d]$ code satisfies
$$
n\geq\sum_{j=0}^{k-1}\left\lceil\frac d{2^j}\right\rceil.
$$
Puncturing on the support of a minimum-weight codeword reduces the rank by one and leaves minimum distance at least $\lceil d/2\rceil$, which proves the bound inductively.

A parity-check matrix $H$ for a <linear code> $C$ satisfies

= Root-evaluation parity-check matrix of a cyclic code
{parent=Parity-check matrix}

For a <cyclic code> whose <generator polynomial> has distinct roots $\alpha_1,\ldots,\alpha_r$ in a <splitting field> $E$, the rows $(1,\alpha_i,\ldots,\alpha_i^{n-1})$ impose precisely the codeword conditions $c(\alpha_i)=0$. Expanding each value in a <basis> of $E$ over the original <finite field>, then discarding dependent equations, gives a <parity-check matrix> over that field of <rank> $r$. Alternatively choose one root from each <Frobenius conjugate> orbit and expand its value in the field it generates.

= Parity-check dependencies determine minimum distance
{parent=Parity-check matrix}
{title2=$d(C)=\min\{|S|:\text{the coordinate checks indexed by }S\text{ are dependent}\}$}

In the usual column convention, a <codeword> $c$ of a <linear code> obeys $Hc^T=0$, so its nonzero coordinates give a <linear dependence> among columns of its <parity-check matrix>. Conversely a dependence gives a nonzero codeword supported on those coordinates. Minimizing the support gives the <minimum Hamming distance of a linear code>. In the transposed convention $cP=0$, the corresponding objects are the rows of $P$. The size of a dependent set means the number of its coordinate positions, even when some check vectors coincide.

= Polynomial multiplication parity-check matrix
{parent=Parity-check matrix}

A binary check polynomial $h=\sum_{j=0}^{N-1}h_jX^j$ modulo $X^N+1$ gives the circulant matrix $B_{ti}=h_{t-i\bmod N}$ representing multiplication by $h$. Its kernel is the cyclic code. Selecting independent rows gives a parity-check matrix of rank equal to the redundancy, even when the supplied polynomial is not the canonical check polynomial.

= Reciprocal-polynomial parity-check matrix
{parent=Parity-check matrix}

If a binary length-$N$ cyclic code has generator of degree $r$ and check polynomial $h$ of degree $N-r$, use the coefficient vectors of $h^*,Xh^*,\ldots,X^{r-1}h^*$ as the rows of a parity-check matrix. They have distinct leading positions and are independent. Their scalar products with a word are the coefficients of $X^{N-r},\ldots,X^{N-1}$ in its product with $h$, which vanish for codewords.

= Syndrome
{title2=$s=Hy^T$}
{parent=Parity-check matrix}

The syndrome of a received word $y$ with respect to a <parity-check matrix> $H$ is $s=Hy^T$. It vanishes exactly when $y$ is a codeword and otherwise identifies the coset containing the error pattern.

= Syndrome decoding
{parent=Syndrome}
{title2=$s=Hy^T=He^T$}

For a <linear code> with <parity-check matrix> $H$, write the received word as $y=c+e$, where $c$ is a <codeword> and $e$ an error pattern. Its <syndrome> depends only on the error because $Hc^T=0$. A syndrome decoder chooses a representative error $\widehat e$ with that syndrome and returns $y-\widehat e$. Choosing a minimum-<Hamming weight> representative gives <minimum-distance decoding>; within the guaranteed correction radius it recovers the unique transmitted <codeword>. Several representatives may tie outside that radius.

= Syndrome classification of code cosets
{parent=Syndrome}
{title2=$\mathbb F_q^N/C\cong\mathbb F_q^{N-k}$}

For a rank-$(N-k)$ parity-check matrix of a linear code $C$, two words have equal syndromes exactly when their difference lies in $C$. Thus attainable syndromes label cosets bijectively. For a received word $c+e$, its syndrome is that of the error $e$, so minimum-weight representatives provide <minimum-distance decoding>.

A coset leader is a minimum-Hamming-weight word in a coset of a linear code. It represents a most economical error pattern with the associated syndrome. Several leaders can tie; they need not be unique outside the code's guaranteed correction radius.

= Parity-check extension of a linear code
{parent=Linear code}

The parity-check extension of a binary <linear code> appends to each codeword the sum of its coordinates in $\mathbb F_2$, making every extended word have even <Hamming weight>.

= Shortened code
{parent=Linear code}

Shortening a code at one coordinate first retains only words with a chosen symbol there and then applies <puncturing (coding theory)> at that coordinate. The minimum distance cannot decrease. In a binary code one coordinate-symbol fibre contains at least half of the words.

= Dual code
{title2=$C^\perp$}
{parent=Linear code}
{wiki}

The dual code $C^\perp$ consists of the words orthogonal to every word of $C$ under the standard dot product. A <parity-check matrix> for $C$ is a <generator matrix> for $C^\perp$.

= Self-dual code
{parent=Dual code}
{title2=$C=C^\perp$}

A <linear code> is self-dual when it equals its <dual code> under the standard <dot product>. For a length-$2k$ code with a rank-$k$ <generator matrix> $G$, this is equivalent to $GG^T=0$: orthogonality gives inclusion in the <dual code>, and equal <dimensions> give equality. Over $\mathbb F_2$, a <generator matrix> $(I\mid A)$ therefore generates a self-dual code exactly when $AA^T=I$.

= Binary self-dual code contains the all-ones word
{parent=Self-dual code}

For a binary <self-dual code>, every word $c$ satisfies $c\cdot c=0$. In characteristic two this is $\sum_i c_i=0$, so the all-ones word is orthogonal to every <codeword> and lies in the <dual code>, hence the code itself. The <dual code> <dimension> identity gives even length and half-length <dimension>.

= Reed-Muller code
{c}
{parent=Linear code}
{wiki=Reed–Muller_code}

The binary Reed-Muller code $\operatorname{RM}(d,r)$ evaluates Boolean polynomials of degree at most $r$ on $\mathbb F_2^d$. It has parameters
$$
\left[2^d,\sum_{j=0}^r\binom dj,2^{d-r}\right].
$$
The dimension counts square-free monomials, and the minimum weight follows inductively from the decomposition $(u,u+v)$.

= Bar product of binary linear codes
{title2=$C_1|C_2$}
{parent=Reed-Muller code}

For length-$n$ binary linear codes $C_2\subseteq C_1$, their bar product is
$$
C_1|C_2=\{(u,u+v):u\in C_1,\ v\in C_2\}.
$$
It has length $2n$ and dimension $\dim C_1+\dim C_2$.

= Minimum distance of a bar product
{parent=Bar product of binary linear codes}

If $C_2\subseteq C_1$ have minimum distances $d_2,d_1$, respectively, then
$$
d(C_1|C_2)=\min(2d_1,d_2).
$$
Indeed, $\operatorname{wt}(u)+\operatorname{wt}(u+v)\geq\operatorname{wt}(v)$, while the words $(u,u)$ and $(0,v)$ attain the two candidate bounds.

= Parity-check matrix of a bar product
{parent=Bar product of binary linear codes}

If $H_i$ is a <parity-check matrix> of $C_i$, then a parity-check matrix of $C_1|C_2$ is
$$
\begin{pmatrix}H_1&0\\H_2&H_2\end{pmatrix}.
$$
Its equations say that the first half $u$ lies in $C_1$ and that the sum of the two halves lies in $C_2$.

= Reed-Muller bar-product recursion
{c}
{parent=Bar product of binary linear codes}

For $0<r<d$,
$$
\operatorname{RM}(d,r)
=\operatorname{RM}(d-1,r)
\mid\operatorname{RM}(d-1,r-1).
$$
Consequently
$$
\dim\operatorname{RM}(d,r)=\sum_{j=0}^r\binom dj.
$$

= Dual of a Reed-Muller code
{c}
{parent=Reed-Muller code}

Under the standard binary inner product,
$$
\operatorname{RM}(d,r)^\perp
=\operatorname{RM}(d,d-r-1).
$$
The product of representing polynomials has degree at most $d-1$, so its evaluation word has even weight; equality follows by comparing dimensions.

= Hamming's code

The binary Hamming code of redundancy $r$ has parameters $[2^r-1,2^r-r-1,3]$. Its parity-check matrix has every nonzero vector of $\mathbb F_2^r$ as a column.

= Ternary Hamming code
{parent=Hamming code}
{title2=$[(3^s-1)/2,(3^s-1)/2-s,3]_3$}

For $s\geq2$, use one nonzero representative from each one-dimensional subspace of $\mathbb F_3^s$ as a <parity-check matrix> column. The <rank> is $s$; no zero or proportional columns imply <minimum Hamming distance> at least three. Two independent columns and the representative of their sum give a weight-three relation, proving equality. Every nonzero <syndrome> uniquely identifies one column and one nonzero error value.

= Ternary Hamming code as a cyclic code
{parent=Ternary Hamming code}
{title2=$g(X)=\prod_{j=0}^{s-1}(X-\alpha^{3^j})$}

For odd $s\geq3$, put $n=(3^s-1)/2$ and choose $\alpha$ of order $n$ in $\mathbb F_{3^s}$. Because $n$ is odd, the powers $\alpha^i$, $0\leq i<n$, represent every projective point once. The <cyclic code> defined by $c(\alpha)=0$ is therefore monomially equivalent to a <ternary Hamming code>, with the displayed <generator polynomial of a cyclic code>. This statement requires a qualification: at $s=2$, every ternary cyclic length-four, dimension-two code has a weight-two generator, so none has <Hamming distance> three.

= Ternary Hamming code as a negacyclic code
{parent=Ternary Hamming code}
{title2=$C=\{c:c(\beta)=0\},\quad\operatorname{ord}(\beta)=3^s-1$}

Set $n=(3^s-1)/2$ and let $\beta$ be a <primitive element of a finite field> $\mathbb F_{3^s}$. The powers $1,\beta,\ldots,\beta^{n-1}$ represent every projective point once. Their <kernel> code is a <ternary Hamming code>. Since $\beta^n=-1$, its <polynomial> description is a <negacyclic code>, generated by the <minimal polynomial of an algebraic element> $\beta$ over $\mathbb F_3$.

= Hamming code as a cyclic code
{parent=Hamming code}
{c}

Let $\omega$ generate $\mathbb F_{2^s}^{\times}$, $s\geq2$, and set $n=2^s-1$. The binary <cyclic code> defined by $c(\omega)=0$ has a <parity-check matrix> consisting of every nonzero vector of $\mathbb F_2^s$ once, after choosing a <basis> and ordering its columns. It is therefore a <Hamming code>. Its <generator polynomial> is the <minimal polynomial of an algebraic element> $m_\omega(x)=\prod_{j=0}^{s-1}(x-\omega^{2^j})$, of degree $s$.

= Hamming code weight enumerator
{c}
{parent=Hamming code}
{title2=$W_C(s,t)=2^{-l}\bigl((s+t)^N+(2^l-1)(t-s)^m(t+s)^{m-1}\bigr)$}

Here $N=2^l-1$, $m=2^{l-1}$ and the <weight enumerator> convention is $W_C(s,t)=\sum_{c\in C}s^{\operatorname{wt}(c)}t^{N-\operatorname{wt}(c)}$. The <dual code> is the <binary simplex code>, with enumerator $t^N+(2^l-1)s^m t^{m-1}$. The <MacWilliams identity> gives the formula. For $l=3$, the ordinary enumerator $W_C(z,1)$ is $1+7z^3+7z^4+z^7$; for $l=1$, the degenerate one-word code has enumerator $t$.

= Low-weight coefficients of a binary Hamming code
{parent=Hamming code weight enumerator}
{title2=$A_3=\frac{n(n-1)}6,\quad A_4=\frac{n(n-1)(n-3)}{24},\quad A_5=\frac{n(n-1)(n-3)(n-7)}{120}$}

For $n=2^\ell-1$, a <codeword> in a <Hamming code> is a subset of the nonzero <vectors> of $\mathbb F_2^\ell$ whose sum is zero. Ordered weight-three <supports of a vector> are determined by two distinct nonzero <vectors>, giving $n(n-1)$ choices. For weight four, the third <vector> must avoid the three nonzero <vectors> in the <linear span> of the first two, giving $n(n-1)(n-3)$ choices. For weight five, the first three must be linearly independent, and the fourth must avoid all seven nonzero <vectors> in their <linear span>, giving $n(n-1)(n-3)(n-7)$ choices. The final <vector> is their sum. Dividing by $3!$, $4!$, and $5!$ counts unordered <supports of a vector> and proves the displayed <weight enumerator> coefficients.

= Extended Hamming code
{parent=Hamming code}
{title2=$[8,4,4]$}

Adding an overall <parity bit> to the <Hamming code of length seven> gives an eight-bit <linear code> with <minimum Hamming distance> four: every resulting weight is <even>, every original nonzero weight is at least three, and a weight-three word extends to weight four. Thus it detects up to three errors when testing <codeword> membership and corrects one error. Joint single-error correction and double-error detection uses the overall parity together with the seven-bit <syndrome>.

= Hamming code of length seven
{c}
{parent=Hamming code}
{title2=$[7,4,3]$}

The <binary linear code> known as the <Hamming code> of length seven is the <kernel> of a $3\times7$ <parity-check matrix> whose columns are all the nonzero vectors of $\mathbb F_2^3$. Its <dimension> is four. No one-column or two-column sum vanishes, but some three-column sum does, so its <minimum Hamming distance> is three. The <syndrome> of a one-bit error is its column, uniquely identifying the erroneous position.

= Binary simplex code
{parent=Hamming code}

The binary simplex code is the dual of the binary Hamming code. For redundancy $r$ it has parameters $[2^r-1,r,2^{r-1}]$.

Its relation to the <Hamming code> is duality, not equality of the code families.

= Constant weight of a binary simplex code
{parent=Binary simplex code}
{title2=$\operatorname{wt}(aH)=2^{l-1}\quad(a\ne0)$}

When the columns of $H$ are every nonzero vector in $\mathbb F_2^l$, a nonzero row vector $a$ defines a nonzero <linear functional> $v\mapsto a\cdot v$. Exactly half the $2^l$ input vectors take value $1$: translation by any vector on which the functional is $1$ pairs its zero and one fibres. Removing the zero input removes only a zero value. Thus every nonzero word in the <binary simplex code> has <Hamming weight> $2^{l-1}$.

= Perfectness of a Hamming code
{parent=Hamming code}

A Hamming code has $2^{2^r-r-1}$ words, and each radius-one Hamming ball contains $1+(2^r-1)=2^r$ vectors. Its minimum distance is three, so these balls are disjoint, and their total size is $2^{2^r-1}$. They therefore partition the ambient space, making the code perfect.

= Minimum-distance error-detection and correction guarantee
{parent=Linear code}

A code of minimum Hamming distance $d$ detects every pattern of at most $d-1$ errors and uniquely corrects every pattern of at most $\lfloor(d-1)/2\rfloor$ errors. The correction claim follows because Hamming balls of that radius around distinct codewords are disjoint.

= Cyclic code
{parent=Coding theory}
{wiki}

A length-$n$ cyclic code over $\mathbb F_q$ is an ideal of $\mathbb F_q[X]/(X^n-1)$. It is generated by a monic divisor of $X^n-1$.

= Negacyclic code
{parent=Cyclic code}
{title2=$C\triangleleft\mathbb F_q[X]/(X^n+1)$}

A <linear code> is negacyclic if $(c_0,\ldots,c_{n-1})$ being a <codeword> implies that $(-c_{n-1},c_0,\ldots,c_{n-2})$ is a <codeword>. <Polynomial> identification makes it an <ideal> modulo $X^n+1$. For odd $n$, the substitution $X\mapsto-X$ gives a <monomial equivalence of linear codes> between negacyclic and <cyclic codes>.

= Defining zeros of a cyclic code
{synonym}

A zero of a <cyclic code> is a <polynomial root> of its <generator polynomial>, taken in a <splitting field>. Every <codeword>, represented as a <polynomial>, vanishes there. For a <repeated-root cyclic code>, the <multiplicity of a root> must also be retained: ordinary evaluations alone need not determine the code.

= Repeated-root cyclic code
{parent=Cyclic code}

A repeated-root cyclic code has length divisible by the characteristic of its field, so the polynomial $X^N-1$ has repeated factors. Its generator can involve powers of those factors. In characteristic two, length $2^t$ gives $X^{2^t}+1=(X+1)^{2^t}$.

= Repeated-root parity-check matrix
{parent=Repeated-root cyclic code}

If the <generator polynomial of a cyclic code> has distinct roots $\alpha_i$ with multiplicities $m_i$, a word belongs to the code exactly when $c^{[\ell]}(\alpha_i)=0$ for $0\leq\ell<m_i$, where $c^{[\ell]}$ is its <Hasse derivative>. The corresponding rows have entries $\binom j\ell\alpha_i^{j-\ell}$ for $j\geq\ell$ and zero otherwise. Expansion in a <basis> of the <splitting field> gives equations over the original <finite field>; an independent selection has <rank> $\sum_i m_i$.

= Binary cyclic codes of length a power of two
{parent=Repeated-root cyclic code}

For $N=2^t$, the binary cyclic codes are exactly the nested ideals generated by $(X+1)^j$ for $0\le j\le N$. They have dimensions $N-j$ and canonical check polynomials $(X+1)^{N-j}$. The endpoint ideals are the entire word space and the zero code.

= Check polynomial of a cyclic code
{parent=Cyclic code}
{title2=$h(X)=(X^N-1)/g(X)$}

= Check polynomials of a cyclic code
{synonym}

For a cyclic code with monic generator $g\mid X^N-1$, the canonical check polynomial is $h=(X^N-1)/g$. A word $a$ belongs to the code exactly when $ah$ is zero modulo $X^N-1$, since cancellation in the polynomial ring turns this condition into $g\mid a$. The kernel condition alone allows additional polynomials: it is equivalent to $\gcd(\widetilde h,X^N-1)=h$. Requiring the monic divisor of the modulus singles out the canonical choice.

= Binary cyclic codes of length five
{parent=Cyclic code}

Over $\mathbb F_2$, $X^5-1=(X+1)(X^4+X^3+X^2+X+1)$ and the degree-four factor is irreducible: it has no linear root and is not divisible by the sole irreducible quadratic $X^2+X+1$. The four monic divisors give precisely four <cyclic codes>: the full five-dimensional space, the four-dimensional even-weight code, the one-dimensional repetition code, and the zero code. Their <generator polynomials of a cyclic code> are respectively $1$, $X+1$, $X^4+X^3+X^2+X+1$, and $X^5-1$.

= Generator polynomial of a cyclic code

= Generator polynomial
{synonym}

The unique monic divisor $g(X)$ of $X^n-1$ generating a cyclic code is its generator polynomial. The code has dimension $n-\deg g$.

= Root-evaluation syndrome for a cyclic code
{parent=Generator polynomial of a cyclic code}

Let $\alpha$ be a root of the <generator polynomial of a cyclic code> $g(X)$. Every codeword $c(X)$ satisfies $c(\alpha)=0$, so a received word $r=c+e$ satisfies $r(\alpha)=e(\alpha)$. For a single-symbol error $e(X)=aX^j$, the evaluation $r(\alpha)=a\alpha^j$ identifies its value and position when the relevant powers of $\alpha$ are distinct.

= Single-error test from two binary BCH syndromes
{parent=Root-evaluation syndrome for a cyclic code}
{title2=$S_1=\alpha^j,\quad S_3=\alpha^{3j}=S_1^3$}

For a binary <cyclic code> with <defining zeros of a cyclic code> $\alpha$ and $\alpha^3$, a single error in coordinate $j$ has <polynomial> $X^j$ and <syndromes> $S_1=\alpha^j$, $S_3=\alpha^{3j}$. If $S_1\ne0$ and $S_3=S_1^3$, recover $j$ from the exponent of $S_1$, flip that coordinate, and verify that the resulting <polynomial> vanishes at both roots. When the <linear code> has <minimum Hamming distance> at least five, this verified correction is the unique <codeword> within two errors. The <syndrome> relation alone should not replace checking the corrected word.

= Dual of a cyclic code
{parent=Cyclic code}

The dual of a cyclic code is cyclic. If $g(X)h(X)=X^n-1$, then the dual generator is the monic reciprocal polynomial $h^*(X)$.

= Binary cyclic codes of length seven
{parent=Cyclic code}

Over $\mathbb F_2$,
$$
X^7-1=(X+1)(X^3+X+1)(X^3+X^2+1).
$$
Its eight monic divisors generate the eight cyclic codes of length seven: the whole-space, even-weight, two Hamming, two simplex, repetition, and zero codes.

= BCH code
{parent=Cyclic code}
{c}
{wiki}

Given a primitive $n$th root $\alpha$, a BCH code of design distance $\delta$ has a generator polynomial vanishing at $\delta-1$ consecutive powers $\alpha^b,\ldots,\alpha^{b+\delta-2}$.

= Designed distance
{parent=BCH code}
{title2=$d(C)\geq\delta$}

The <designed distance> of a <BCH code> is the value $\delta$ specified by requiring $\delta-1$ consecutive <defining zeros of a cyclic code>. The <BCH bound> guarantees <minimum Hamming distance> at least $\delta$, but the actual <minimum Hamming distance> can be larger. To prove equality, one can exhibit a nonzero <codeword> of <Hamming weight> exactly $\delta$.

= Binary cyclotomic coset modulo an odd integer
{parent=BCH code}
{title2=$C_i=\{i,2i,4i,\ldots\}\pmod n$}

= Binary cyclotomic cosets modulo an odd integer
{synonym}

For odd $n$, multiplication by two permutes the residues modulo $n$. Its orbit through $i$ is the <binary cyclotomic coset modulo an odd integer>. If $\alpha$ has order $n$ in a <finite field> whose <field characteristic> is two, the <Frobenius automorphism> sends $\alpha^i$ to $\alpha^{2i}$. Hence the <minimal polynomial of an algebraic element> $\alpha^i$ over $\mathbb F_2$ is $\prod_{j\in C_i}(X-\alpha^j)$. Its coefficients are fixed by Frobenius and lie in $\mathbb F_2$, and its degree is the orbit size. Thus a binary <cyclic code> containing one <defining zero of a cyclic code> must contain the full orbit as zeros.

= Error locator polynomial
{title2=$\sigma(Z)$}
{parent=BCH code}
{wiki}

For error locations $i_1,\ldots,i_\nu$ in a cyclic code with primitive root $\alpha$, the error locator polynomial is $\sigma(Z)=\prod_h(1-\alpha^{i_h}Z)$. Its roots encode the error positions.

= Chien search
{parent=Error locator polynomial}
{c}
{wiki}

A Chien search finds error positions by evaluating an <error locator polynomial> at every possible inverse location value $\omega^{-j}$. A zero identifies coordinate $j$. Using the recurrence between successive powers of $\omega$ avoids recomputing all monomials from scratch.

= Error evaluator polynomial
{parent=Error locator polynomial}
{title2=$\Omega(z)$}

For errors $E_i$ at distinct nonzero locations $X_i$, the evaluator associated with syndromes $S_\ell=\sum_i E_iX_i^{b+\ell}$ is $\Omega(z)=\sum_i E_iX_i^b\prod_{h\ne i}(1-X_hz)$. Its degree is smaller than the number of errors. Together with the <error locator polynomial> it gives the <Reed-Solomon key equation> and the <Forney algorithm> for error magnitudes.

= Forney algorithm
{parent=Error evaluator polynomial}
{c}
{wiki}
{title2=$E_i=-X_i^{1-b}\Omega(X_i^{-1})/\Lambda'(X_i^{-1})$}

For distinct error locations and the syndrome convention $S_\ell=\sum_i E_iX_i^{b+\ell}$, the displayed formula recovers the error magnitudes from the <error evaluator polynomial> and <error locator polynomial>. At $z=X_i^{-1}$, the evaluator is $E_iX_i^b\prod_{h\ne i}(1-X_h/X_i)$, whereas the locator's <formal derivative> is $-X_i\prod_{h\ne i}(1-X_h/X_i)$. Their quotient gives the formula; the denominator is nonzero because the locations are distinct.

= BCH bound
{parent=BCH code}
{c}

The minimum distance of a BCH code is at least its design distance. A hypothetical word of smaller weight yields a square Vandermonde system from the consecutive-root equations; its support elements are distinct, so the determinant is nonzero and every word coefficient must vanish.

= Parity extension

Appending a parity bit makes every word even-weight. A binary $[n,m,d]$ code becomes an $[n+1,m,d^+]$ code, where
$$
d^+=
\begin{cases}
d,&d\text{ even},\\
d+1,&d\text{ odd}.
\end{cases}
$$

= Hamming bound
{c}
{parent=Coding theory}
{wiki}

A binary length-$n$ code of size $M$ and distance at least $2t+1$ satisfies
$$
M\sum_{j=0}^t\binom nj\le2^n.
$$
Equality means the code is perfect.

The <Hamming bound> packs disjoint balls of radius approximately $\delta n/2$. Taking logarithms and using the <Hamming ball volume exponent> gives the bound for $0\le\delta\le1$.

= Rabin cryptosystem
{c}
{parent=Coding theory}
{wiki}

= Rabin-Williams scheme
{c}
{synonym}

Rabin encryption sends $m$ to $m^2$ modulo a product of two secret primes. Decryption computes the four square roots by the Chinese remainder theorem.

= Repeated-message attack on the Rabin cryptosystem
{c}
{parent=Rabin cryptosystem}
{title2=$m^2\bmod N,\ m^2\bmod N'$}

For coprime moduli $N,N'$ and $0<m<\min(N,N')$, the <Chinese remainder theorem> recovers the integer $m^2$ uniquely in $[0,NN')$ from the two ciphertexts. An ordinary integer square root then recovers the message. If distinct semiprime moduli share a factor, their greatest common divisor instead reveals factors of both moduli. Learning one message in the coprime case does not by itself give a general factoring algorithm or a decryption key for other ciphertexts.

= Factorization from distinct square roots modulo a semiprime
{parent=Rabin cryptosystem}

If $N=pq$ and $x^2\equiv y^2\pmod N$ while $x\not\equiv\pm y\pmod N$, then
$$
N\mid(x-y)(x+y),
$$
and $\gcd(x-y,N)$ is a nontrivial factor of $N$.

= Square-root oracle reduction for Rabin encryption
{c}
{parent=Factorization from distinct square roots modulo a semiprime}
{title2=$\mathbb P(y\not\equiv\pm x\bmod N)=1/2$}

For $N=pq$ with distinct odd primes, choose a uniform unit $x$ and give only $x^2\bmod N$ to an oracle returning any square root $y$. Conditional on this square, $x$ is uniform among four roots and independent of the oracle's choice. With probability one half, $y$ is not $\pm x$, and $\gcd(x-y,N)$ is a nontrivial factor. Thus full inversion of the squaring map yields randomized <integer factorization>; this reduction does not equate arbitrary partial leakage with full inversion.

= Chosen-square attack on Rabin authentication
{parent=Factorization from distinct square roots modulo a semiprime}

If a purported authentication service returns a square root of every chosen square modulo a Rabin modulus, a verifier who knows one root obtains a different root with substantial probability and can factor the modulus. Repeating the challenge therefore reveals the private key.

= Discrete logarithm problem
{parent=Coding theory}

= Discrete logarithm
{synonym}

Given a cyclic group generator $g$ and an element $h$, the discrete logarithm problem asks for an exponent $a$ such that $g^a=h$.

= Diffie-Hellman key exchange
{c}
{parent=Coding theory}
{wiki=Diffie–Hellman_key_exchange}

Alice publishes $g^a$ and Bob publishes $g^b$ in a public cyclic group; each can then compute the shared secret $g^{ab}$. Its security relies on the difficulty of recovering the exponents or otherwise solving the computational Diffie--Hellman problem.

= Multilateral Diffie-Hellman key exchange
{parent=Diffie-Hellman key exchange}

In a <cyclic group> with generator $g$, $n$ participants with secret exponents $a_j$ can exchange $n$ tokens around a ring. Token $j$ starts at $g^{a_j}$ and is successively exponentiated by its next $n-2$ recipients before being sent to the final recipient, whose exponent is the only one missing. That recipient completes the exponentiation locally. Each token makes $n-1$ transmissions, and everyone obtains $g^{\prod_j a_j}$. Thus $n(n-1)$ transmitted group elements suffice. As with two-party <Diffie-Hellman key exchange>, authentication is needed.

= Unique decodability

Unique decodability means that every encoded message has at most one decomposition into codewords.

= Decipherable code

= Uniquely decodable code
{synonym}

A code is decipherable, or uniquely decodable, when every finite concatenation of codewords has at most one decomposition into source codewords.

= Suffix code
{parent=Decipherable code}

A <decipherable code> is suffix-free when no codeword is a proper suffix of another. Reversing all its words gives a <prefix code>. Consequently it is uniquely decipherable: read a concatenation from the right, where the last codeword is determined uniquely, and continue by induction.

= Optimal source code

= Optimal code
{synonym}

For a fixed source distribution and code alphabet, an optimal <uniquely decodable code> minimizes expected codeword length. <Huffman coding> gives an optimal binary <prefix code>, and the equivalence of attainable uniquely-decodable and prefix-code lengths gives the same minimum for both classes.

= Prefix code
{parent=Decipherable code}

In a prefix code no codeword is the prefix of another, so concatenated messages have unique instantaneous decoding.

= Prefix code for a rare geometric success
{parent=Prefix code}
{title2=$\mathbb E L=n+\bigl(1-(1-2^{-n})^{2^n}\bigr)^{-1}$}

For a success index $J$ with <geometric distribution> of parameter $q=2^{-n}$, write $J-1=2^nQ+R$, $0\leq R<2^n$. Encode $Q$ by $Q$ ones followed by zero, then encode $R$ in exactly $n$ <bits>. This <prefix code> has length $n+Q+1$. Since $\mathbb P(Q\geq k)=(1-q)^{k2^n}$, its expected length is the displayed expression, at most $n+e/(e-1)$. Thus a very rare success can be communicated in approximately the logarithm of its inverse <probability>, rather than one <bit> per trial.

= Kraft–McMillan inequality
{parent=Prefix code}
{c}
{wiki}

= Kraft inequality
{c}
{synonym}

The lengths of every decipherable binary code satisfy
$$
\sum_i2^{-l_i}\leq1.
$$
Conversely, any positive integer lengths satisfying this bound can be realized by a <prefix code>.

= McMillan inequality
{c}
{parent=Kraft–McMillan inequality}

The lengths of a finite <uniquely decodable code> satisfy $\sum_a2^{-l(a)}\leq1$, even when the code is not a <prefix code>. Distinct concatenations of $r$ codewords remain distinct; counting the possible binary strings of each total length bounds $(\sum_a2^{-l(a)})^r$ by $r\max_a l(a)$. Taking $r$th roots proves the claim.

= Equivalence of decipherable and prefix code lengths
{parent=Kraft–McMillan inequality}

Prescribed positive word lengths admit a <decipherable code> if and only if they admit a <prefix code>. Counting length-$L$ concatenations of $m$ words proves the <Kraft inequality> for any <decipherable code>; choosing free vertices of the ordered $D$-ary <tree> constructs a <prefix code> whenever this inequality holds. Each <prefix code> has <unique decodability>.

= Total length lower bound for a decipherable binary code
{parent=Kraft–McMillan inequality}

If a decipherable binary code has $N$ codewords of lengths $l_1,\ldots,l_N$, then
$$
\sum_{i=1}^N l_i\geq N\log_2N.
$$
This follows by applying the entropy lower bound with the uniform source distribution.

= Shannon-Fano coding
{parent=Prefix code}
{c}
{wiki=Shannon–Fano_coding}

Shannon-Fano coding comprises two related <prefix code> constructions. Shannon coding assigns lengths $\lceil-\log_2p_i\rceil$ to symbols of probability $p_i$; Fano coding recursively partitions the ordered symbols into groups of nearly equal total probability and assigns a bit at each partition.

= Shannon coding
{c}
{parent=Prefix code}
{wiki}

= Cumulative Shannon code
{parent=Shannon coding}

Order source probabilities as $p_1\geq\cdots\geq p_N$, put
$$
b_i=\sum_{j<i}p_j,
\qquad
l_i=\lceil-\log_2p_i\rceil,
$$
and take the first $l_i$ binary digits of $b_i$ as the codeword for symbol $i$. Since $b_j-b_i\geq p_i\geq2^{-l_i}$ for $j>i$, two cumulative probabilities cannot lie in the same dyadic interval selected by the earlier codeword. The resulting code is prefix-free.

= Competitive optimality of the Shannon code
{c}
{parent=Cumulative Shannon code}

If the Shannon length is $l_S(x)=\lceil\log_2(1/p_x)\rceil$ and $l_C$ is the length of any binary decipherable code, then
$$
\mathbb P\{l_S(X)\geq l_C(X)+k\}\leq2^{-k+1}.
$$
Thus the probability that the Shannon code loses to another code by $k$ or more bits decreases exponentially in $k$.

= Entropy lower bound for prefix codes

Every binary prefix code has expected length at least its source entropy; Shannon lengths achieve expected length strictly below $H+1$.

For a discrete memoryless source of entropy $H$, every uniquely decodable binary code has expected length at least $H$. Shannon code lengths satisfy $H\leq\overline\ell<H+1$, and block coding can make the expected length per source symbol arbitrarily close to $H$.

= Binary symmetric channel
{parent=Coding theory}
{wiki}

A binary symmetric channel independently flips each transmitted bit with a fixed crossover probability $p$.
Its channel matrix is
$$
\begin{pmatrix}1-p&p\\p&1-p\end{pmatrix}.
$$

= Undetected error
{parent=Binary symmetric channel}

An error is undetected by codeword-membership checking when the received word is a different valid codeword. For a linear code this occurs exactly when the nonzero channel-error vector is itself a codeword.

= Completely noisy binary symmetric channel
{parent=Binary symmetric channel}

At crossover probability $p=1/2$, the two rows of the <transition matrix> of a <binary symmetric channel> coincide. Its output is then <independent random variables>[independent] of its input and its <binary symmetric channel capacity>[capacity] is zero.

= Positive-rate coding bound below one-quarter crossover
{parent=Binary symmetric channel}

If $p<1/4$, choose $p<\delta<1/4$. Binary codes of relative minimum distance above $2\delta$ have positive asymptotic rate by a greedy packing bound, and nearest-codeword decoding fails only when more than $\delta n$ channel errors occur. That probability tends to zero.

= Maximum a posteriori decoding
{parent=Coding theory}

Maximum a posteriori decoding chooses the codeword maximizing prior probability times channel likelihood and minimizes average decision error.

= Maximum-likelihood decoding
{parent=Coding theory}
{wiki}

Maximum-likelihood decoding chooses the codeword under which the received word has greatest conditional probability.

= Minimum-distance decoding
{parent=Coding theory}
{wiki}

Minimum-distance decoding chooses a codeword closest to the received word; on a binary symmetric channel with $p<1/2$, it is maximum-likelihood decoding under Hamming distance.

= Bounded-distance decoding
{parent=Minimum-distance decoding}

For a code of <minimum Hamming distance> $d$ and radius $t$ with $2t<d$, bounded-distance decoding returns the unique <codeword> within <Hamming distance> $t$ of the received word, or reports failure if none exists. The disjointness of radius-$t$ <Hamming balls> gives uniqueness. It guarantees recovery when at most $t$ errors occurred, but a word produced by more errors can be nearer to a different codeword and be miscorrected.
