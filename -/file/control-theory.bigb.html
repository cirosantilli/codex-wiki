= Control theory
{wiki}

Control theory studies dynamical input-output systems, feedback, stability, and response.

= State estimation
{parent=Control theory}
{wiki}

State estimation infers an unobserved dynamical state from noisy observations and a model of its evolution.

= Kalman filter
{c}
{parent=State estimation}
{wiki}

The Kalman filter recursively computes the conditional mean and covariance of the state in a linear system with Gaussian initial state and Gaussian noise.

= Scalar static-state Kalman update
{parent=Kalman filter}

Suppose $x\mid\mathcal F\sim N(\widehat x,V)$ and the new observation is $y=x+\eta$, where $\eta\sim N(0,R)$ is independent. Then
$$
\mathbb E[x\mid\mathcal F,y]
=\widehat x+\frac{V}{V+R}(y-\widehat x),
\qquad
\operatorname{Var}(x\mid\mathcal F,y)
=\frac{VR}{V+R}.
$$
The coefficient $V/(V+R)$ is the scalar Kalman gain.

= Linear-quadratic-Gaussian control
{c}
{parent=Control theory}
{wiki}

Linear-quadratic-Gaussian control combines a linear system, Gaussian uncertainty, a quadratic cost, and feedback based on a <Kalman filter> state estimate.

= Separation principle
{parent=Linear-quadratic-Gaussian control}
{wiki=Separation_principle}

In a linear-quadratic-Gaussian control problem, the optimal control applies the full-information linear-quadratic feedback law to the conditional state estimate. The control gain is independent of the state-estimation error covariance.

= Continuous Lyapunov equation
{title2=$AX+XA^T+Q=0$}
{c}
{parent=Control theory}

= Lyapunov equation
{c}
{synonym}

The continuous Lyapunov equation is $AX+XA^T+Q=0$. If every eigenvalue of $A$ has negative real part, it has a unique solution for each $Q$, and a positive-definite $Q$ gives a positive-definite $X$.

= Transfer function
{parent=Control theory}
{wiki}

For a linear time-invariant system with zero initial data, the transfer function is the Laplace-domain ratio $G(s)=Y(s)/F(s)$. A rational causal system is BIBO stable when all poles lie in the open left half-plane.

= Nyquist stability criterion
{parent=Transfer function}
{c}
{wiki}

Let $L$ be the open-loop transfer function. The winding of its Nyquist plot around $-1$, together with the number of unstable open-loop poles, determines the number of unstable zeros of $1+L$, which are the closed-loop poles.
