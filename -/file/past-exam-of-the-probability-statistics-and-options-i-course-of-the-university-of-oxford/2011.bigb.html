Gx=\{gx:g\in G\},\qquad G_x=\{g\in G:gx=x\}.

For a <regular tetrahedron>, rotations fixing a vertex rotate about the line from that vertex through the opposite face centre. Their angles are $0,2\pi/3,4\pi/3$, so the <stabilizer> is a <cyclic group> of order three. Rotations act transitively on the four <vertices>, giving $|G_1|=4\cdot3=12$ by the <orbit-stabilizer theorem>.

For a <cube>, the corresponding axis is the body diagonal through the fixed vertex and its opposite. The three incident edges can be cyclically permuted by the same three angles, so again the <stabilizer> is cyclic of order three. The <orbit> has eight vertices. Hence
$$
\boxed{|G_1|=12,\qquad |G_2|=24.}
$$

Realize the cube's vertices as $(\pm1,\pm1,\pm1)$ and take the four with coordinate product $+1$. They form a <regular tetrahedron>, and their negatives form the other one. A <prime number> is an integer $p>1$ whose only positive divisors are $1$ and $p$. The restriction $p>1$ excludes the unit $1$.

The <fundamental theorem of arithmetic> says that every integer $n>1$ is a product of <prime numbers>, uniquely up to reordering. Equivalently, $n=\prod_p p^{a_p}$ for a unique family of nonnegative integer exponents, only finitely many of which are nonzero.

If the complete list of <prime numbers> were $p_1,\ldots,p_k$, then $N=p_1\cdots p_k+1>1$ would have a prime divisor by the <fundamental theorem of arithmetic>. No $p_i$ divides it, since $N\equiv1\pmod{p_i}$. This contradicts completeness of the list. Hence **there are infinitely many prime numbers**.

Suppose there were only finitely many <prime numbers> congruent to $5$ modulo $6$, and list them as $p_1,\ldots,p_k$. The list is nonempty since it contains $5$. Let $N=6p_1\cdots p_k-1$. This contradiction proves **there are infinitely many primes congruent to $5$ modulo $6$**.

The <Lebesgue outer measure> is
$$
m^*(E)=\inf\left\{\sum_j|I_j|:E\subseteq\bigcup_j I_j,\ I_j\text{ open intervals}\right\}.
$$
The <Lebesgue inner measure> is $m_*(E)=\sup\{m(K):K\subseteq E,\ K\text{ compact}\}$, with $m_*(\varnothing)=0$. For a bounded set inside a finite interval $I$, this is equivalently $|I|-m^*(I\setminus E)$.

A set is <Lebesgue measurable> if it satisfies <Carathéodory's criterion>:
$$
\boxed{m^*(A)=m^*(A\cap E)+m^*(A\setminus E)\quad\text{for every }A\subseteq\mathbb R.}
$$
For finite outer measure this is equivalent to equality of inner and outer measure. For a general unbounded set, an equivalent local criterion is $m_*(E\cap[-n,n])=m^*(E\cap[-n,n])$ for every positive integer $n$. Merely writing $m_*(E)=m^*(E)=\infty$ would not establish measurability.

A <null set> has <Lebesgue outer measure> zero. Equivalently, for every $\varepsilon>0$ it can be covered by countably many open <intervals> whose total length is less than $\varepsilon$. Such a set is automatically <Lebesgue measurable> and has <Lebesgue measure> zero.

For <sigma-finite measures>, <Tonelli's theorem> states that the double <integral> of a nonnegative measurable function equals either iterated integral, allowing $+\infty$. <Fubini's theorem> states that if a measurable function is absolutely integrable, its sections are integrable almost everywhere, both iterated integrals exist, and they equal the double integral.

Assign any value at $(0,0)$, which does not affect <Lebesgue integrability>. Near that corner set $s=x+y$ and $t=(x-y)/(x+y)$. Then $x=s(1+t)/2$, $y=s(1-t)/2$, and the absolute <Jacobian determinant> is $s/2$. On $0<s<1$, the full range is $-1<t<1$, so
$$
\iint_{x+y<1}|F(x,y)|\,dx\,dy
=\frac12\int_0^1 s^{2-\alpha}\,ds\int_{-1}^1|t|\,dt
=\frac12\int_0^1s^{2-\alpha}\,ds.
$$
The remaining part of the unit square has $x+y\geq1$ and is harmless. The <improper power integral> is finite precisely when $\alpha<3$. Under the given restriction,
$$
\boxed{F\text{ is Lebesgue integrable exactly for }2<\alpha<3.}
$$
For those values, the change $(x,y)\mapsto(y,x)$ preserves the square and changes the sign of $F$. Absolute integrability justifies this change of variables, giving
$$
\boxed{\iint_{\mathbb R^2}F(x,y)\,dx\,dy=0.}
$$
For $\alpha\geq3$ the positive and negative parts each diverge, so symmetry does not define a Lebesgue integral.

An <open cover> of a <topological space> is a collection of open subsets whose union is the whole space. A <compact space> is one for which every <open cover> admits a finite <subcover>. The <subspace topology> on $A\subseteq Y$ consists of sets $A\cap O$ with $O$ open in $Y$.

Let $\{U_j\}$ cover $f(X)$ by relatively open sets, and write $U_j=f(X)\cap O_j$ with $O_j$ open in $Y$. By <continuity>, $\{f^{-1}(O_j)\}$ is an open cover of $X$. A finite subcollection covers $X$ by <compactness>, and its corresponding $U_j$ cover $f(X)$. Thus **a continuous image of a compact space is compact**.

For an image that is not closed, take $X$ to be a singleton and $Y=\{0,1\}$ with the <indiscrete topology>. Send the sole point to $0$. This map is continuous and $X$ is compact, while $f(X)=\{0\}$ is not closed in $Y$, whose only closed sets are $\varnothing$ and $Y$. A <Hausdorff> hypothesis on the target would exclude this example.

A <sequence> $x_n$ converges to $x$ if every open <neighbourhood> of $x$ contains all sufficiently late terms. A <Hausdorff space> separates any two distinct points by disjoint open neighbourhoods.

If a sequence had distinct limits $x,y$ in a <Hausdorff space>, choose disjoint open neighbourhoods $U$ of $x$ and $V$ of $y$. Convergence to each limit implies that all sufficiently late terms lie in both $U$ and $V$, contradicting $U\cap V=\varnothing$. Hence **a convergent sequence in a Hausdorff space has a unique limit**.

The <product topology> on $X\times Y$ has as a <basis of a topology> the rectangles $U\times V$ with $U$ open in $X$ and $V$ open in $Y$; arbitrary unions of such rectangles are its open sets.

For distinct points $(x_1,y_1),(x_2,y_2)$, at least one coordinate differs. If $x_1\ne x_2$, disjoint open neighbourhoods $U_1,U_2$ in the <Hausdorff space> $X$ give disjoint open neighbourhoods $U_1\times Y,U_2\times Y$ of the two points. If the second coordinates differ instead, use $X\times V_1,X\times V_2$. Thus **a product of two Hausdorff spaces is Hausdorff**.

For the quotient map $q:X\to X/{\sim}$, the <quotient topology> is defined by
$$
U\subseteq X/{\sim}\text{ open}\iff q^{-1}(U)\text{ open in }X.
$$
Take the <Hausdorff space> $X=\mathbb R$ and identify two numbers precisely when they are both rational or both irrational. The quotient has two points. The inverse images of its singleton subsets are $\mathbb Q$ and $\mathbb R\setminus\mathbb Q$, neither of which is open in $\mathbb R$, since each is dense and has dense complement. Hence the quotient has the <indiscrete topology> and is not <Hausdorff>.

A $k$-dimensional embedded <submanifold> of $\mathbb R^n$ is a subset $M$ such that near each $p\in M$ there is a smooth <diffeomorphism> of ambient open neighbourhoods that sends $M$ to the coordinate plane $\mathbb R^k\times\{0\}^{n-k}$. More precisely, for some open $U\ni p$ and diffeomorphism $\Phi:U\to V\subseteq\mathbb R^n$,
$$
\Phi(M\cap U)=V\cap(\mathbb R^k\times\{0\}^{n-k}).
$$
Thus locally the subset has $k$ freely varying smooth coordinates.

Let $P=F_{y'}$ and $Q=F_{y''}$. For a smooth <variation> $y+\varepsilon\eta$, the <first variation> is
$$
\delta J=\int_a^b(F_y\eta+P\eta'+Q\eta'')\,dx
=\int_a^b(F_y-P'+Q'')\eta\,dx+[(P-Q')\eta+Q\eta']_a^b.
$$
Here the last expression follows by two integrations by parts. Taking variations supported in the interior and applying the <fundamental lemma of the calculus of variations> gives the <Euler-Lagrange equation for a second-derivative functional>:
$$
\boxed{F_y-\frac{d}{dx}F_{y'}+\frac{d^2}{dx^2}F_{y''}=0.}
$$
If both endpoint values and slopes are free, their independent variations force the <natural boundary conditions for second-derivative functionals>
$$
\boxed{Q=0,\qquad P-Q'=0\quad\text{at }a,b.}
$$
If an endpoint value or slope is fixed instead, its corresponding variation vanishes and the associated natural condition is not required.

For $H=y''Q-y'(Q'-P)-F$, differentiate using the <chain rule>:
$$
H'=y'(P'-Q''-F_y)-F_x.
$$
The <Euler-Lagrange equation> cancels the first term. Consequently $H'=-F_x$, and if there is no explicit $x$ dependence,
$$
\boxed{H=y''F_{y''}+y'\bigl(F_{y'}-(F_{y''})'\bigr)-F\text{ is constant}.}
$$
This is a <Beltrami identity for a second-derivative functional>.

A <streamline> is a curve whose tangent is parallel to the instantaneous fluid <velocity field>. In steady flow one may parametrize it by $d\mathbf r/ds=\mathbf u(\mathbf r)$. Dotting the steady <Euler equations> with $\mathbf u$ eliminates the cross-product term, since $\mathbf u\cdot((\nabla\times\mathbf u)\times\mathbf u)=0$. Hence
$$
\boxed{\mathbf u\cdot\nabla\left(p+\tfrac12\rho|\mathbf u|^2\right)=0,}
$$
which is <Bernoulli's principle> along each streamline.

For the supplied field, $xu+yv=0$, so along a streamline
$$
\frac{d}{ds}(x^2+y^2)=2xu+2yv=0.
$$
Writing $r^2=x^2+y^2$, the tangential speed is $v_\theta=-br+c/r$ and the radial speed is zero. Both $r$ and $|\mathbf u|^2=(-br+c/r)^2$ are constant around each nonstagnant circular streamline. The Bernoulli quantity is constant there, so **the pressure is constant on every such circle**.

If a circle is wholly stagnant, the same conclusion follows directly from the steady <Euler equations>: on it $\mathbf u=0$ and $\nabla|\mathbf u|^2=0$, hence $\nabla p=0$. Equivalently the radial momentum equation gives $\nabla p=\rho(-br+c/r)^2\mathbf e_r/r$ and no angular pressure variation, including at zero tangential speed. Thus **$p$ is constant on $x^2+y^2=a^2$ for every nonzero $a$**, with no exception for a stagnation circle.

Use the convention that positive vortex strength is counterclockwise and complex velocity is $u-iv$. A <complex potential of a two-dimensional potential flow> for the superposed <uniform flow> and two <point vortices> is

\boxed{W(z)=Uz+\frac{\Gamma}{2\pi i}\log(z-a)-\frac{\Gamma}{2\pi i}\log(z+a).}

Local choices of logarithm branch change no velocity. Differentiation gives
$$
W'(z)=U-\frac{i\Gamma a}{\pi(z^2-a^2)}.

\boxed{z_\pm=\pm\sqrt{a^2+\frac{i\Gamma a}{\pi U}}.}

A free <point vortex> moves with the velocity induced by the other vortex and the background, omitting its own singular field. At either vortex, the other induces vertical velocity $-\Gamma/(4\pi a)$, while the background contributes $(U,0)$. Their velocities are therefore equal. \boxed{\mathbf V=\left(U,-\frac{\Gamma}{4\pi a}\right),\qquad

A <Poisson distribution> with parameter $\lambda\geq0$ has
$$
\boxed{\mathbb P(X=k)=e^{-\lambda}\frac{\lambda^k}{k!},\quad k=0,1,2,\ldots;\qquad
\mathbb E[X]=\operatorname{Var}X=\lambda.}
$$
For $\lambda=0$ it is concentrated at zero. For $\lambda>0$, shifting the index in the defining series gives $\mathbb E[X]=\lambda$ and $\mathbb E[X(X-1)]=\lambda^2$, so $\operatorname{Var}X=\lambda^2+\lambda-\lambda^2=\lambda$.

\boxed{k\geq\max\left(0,\left\lceil\log_2\frac{L}{2\epsilon}\right\rceil\right).}
$$
If iterations instead count midpoint evaluations starting with the initial midpoint as evaluation one, the usual bound is $n\geq\lceil\log_2(L/\epsilon)\rceil$, with at least one evaluation unless an endpoint root has already been found. Stating the counting convention avoids an apparent one-step discrepancy.

= Solution
{parent=b}
{c}

The following <R programming language> function uses the factored polynomial for evaluation, handles endpoint and midpoint roots, and returns a midpoint only once its error bound is at most `eps`:

```
bisect <- function(a, b, eps = 1e-8, maxiter = 1000L) {
  f <- function(x) x * (x - 1) * (x - 2) * (x - 5)
  stopifnot(length(a) == 1L, length(b) == 1L,
            is.finite(a), is.finite(b), a < b,
            length(eps) == 1L, is.finite(eps), eps > 0)
  fa <- f(a)
  fb <- f(b)
  if (fa == 0) return(a)
  if (fb == 0) return(b)
  if (sign(fa) == sign(fb)) stop("Endpoints must bracket a sign change")
  for (i in seq_len(maxiter)) {
    m <- a + (b - a) / 2
    fm <- f(m)
    if (fm == 0 || (b - a) / 2 <= eps) return(m)
    if (sign(fm) == sign(fa)) {
      a <- m
      fa <- fm
    } else {
      b <- m
    }
  }
  stop("Iteration limit reached")
}
```

Each update preserves the sign-changing bracket, and the stopping bound is the half-width of that bracket. Thus <continuity> and the <intermediate value theorem> justify the returned root approximation.

At the left endpoint $f(-1)=36>0$. If $b=2$, the endpoint is exactly a root and the function above immediately returns $2$. For $2<b\leq4$, $f(b)<0$, so the first midpoint is $m=(b-1)/2$.

If $2<b<3$, then $1/2<m<1$ and $f(m)<0$. The first retained bracket is $[-1,m]$, containing only the root zero, so the iterates converge to zero. If $b=3$, the first midpoint is exactly the root one and is returned. If $3<b\leq4$, then $1<m\leq3/2$ and $f(m)>0$. The retained bracket is $[m,b]$, containing only the root two, so the iterates converge to two. Hence
$$
\boxed{\text{returned root}=\begin{cases}
2,&b=2,\\0,&2<b<3,\\1,&b=3,\\2,&3<b\leq4.
\end{cases}}
$$
This illustrates <root selection by bisection with multiple roots in the initial bracket>: bisection guarantees a root, but which root it chooses depends discontinuously on the starting endpoint.
