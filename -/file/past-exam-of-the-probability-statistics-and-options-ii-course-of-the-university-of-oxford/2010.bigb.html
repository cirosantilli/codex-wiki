The <monotone convergence theorem> states that if nonnegative measurable functions $h_n$ increase <almost everywhere> to $h$, then $\int h=\lim_n\int h_n$, allowing infinity. The <dominated convergence theorem> states that if measurable $h_n\to h$ <almost everywhere> and $|h_n|\le g$ for an <integrable> $g$, then $h$ is <integrable> and $\int h_n\to\int h$.

In any <topological space> a closed subset of a <compact> set is <compact>: add its open complement to an open cover and take a finite subcover of the <compact> set. However, <compact> subsets need not be closed in a general space. In the indiscrete two-point space a singleton is <compact> but not closed. Conversely a closed subset need not be <compact>: $\mathbb R$ itself is closed in $\mathbb R$ but the cover $\{(-n,n):n\ge1\}$ has no finite subcover.

In a <Hausdorff space> every <compact subset> $K$ is closed. Given $x\notin K$, separate $x$ and each $k\in K$ by disjoint neighborhoods; <compactness> selects finitely many neighborhoods covering $K$, and the intersection of their companion neighborhoods of $x$ misses $K$. Thus the complement is open. Closedness still need not imply <compactness>, as the same real-line example shows. It does imply <compactness> if the ambient space is <compact>.

In a <metric space> <compactness> implies <boundedness>: finitely many radius-one balls cover the set, so their centers have a finite maximal distance from any fixed center and the triangle inequality gives a global bound. The converse is false. An infinite set with discrete metric $d(x,y)=1$ for $x\ne y$ is <bounded>, but its singleton cover has no finite subcover. It is even closed and <complete>, so closedness plus <boundedness> alone does not suffice in general <metric spaces>.

<Differentiability> at $x_0$ means that a <linear map> $L:\mathbb R^n\to\mathbb R^m$ exists such that $f(x_0+h)=f(x_0)+Lh+o(\|h\|)$. Since finite-dimensional <linear maps> are <bounded>, the right side tends to $f(x_0)$ as $h\to0$, proving <continuity>.

For the final product assertion, write $f(x_0+h)=Lh+r(h)$, where $r(h)=o(\|h\|)$, and $g(x_0+h)=g(x_0)+s(h)$ with $s(h)=o(1)$. Since $f(x_0)=0$,
$$
F(x_0+h)-F(x_0)-\langle Lh,g(x_0)\rangle=\langle Lh,s(h)\rangle+\langle r(h),g(x_0)+s(h)\rangle=o(\|h\|).
$$
<Cauchy sequence>[Cauchy]–Schwarz and <boundedness> of $g$ near $x_0$ justify the last estimate. Thus $\boxed{dF(x_0)h=\langle df(x_0)h,g(x_0)\rangle}$; <differentiability> of $g$ is unnecessary because $f(x_0)=0$.

```R
merge_sort <- function(x) {
  n <- length(x)
  stopifnot(n >= 1L)
  if (n == 1L) return(x)
  m <- n %/% 2L
  left <- merge_sort(x[seq_len(m)])
  right <- merge_sort(x[(m + 1L):n])
  nl <- length(left)
  nr <- length(right)
  out <- integer(n)
  i <- j <- k <- 1L
  while (i <= nl && j <= nr) {
    if (left[i] <= right[j]) {
      out[k] <- left[i]
      i <- i + 1L
    } else {
      out[k] <- right[j]
      j <- j + 1L
    }
    k <- k + 1L
  }
  if (i <= nl) out[k:n] <- left[i:nl]
  if (j <= nr) out[k:n] <- right[j:nr]
  out
}
```

```R
    trace <- c(trace, next_x)
    n <- length(trace)
    if (n >= 3L && abs(trace[n] - trace[n - 2L]) <= tol*(1 + abs(next_x)))
      return(list(x = next_x, converged = FALSE,
                  reason = "two-cycle", trace = trace))
    x <- next_x
  }
  list(x = x, converged = FALSE, reason = "iteration limit", trace = trace)
}
```

A sufficiently close start near $-0.7692923542$ converges to the <local minimum>[minimum]. The <derivative> cubic has exactly one real root: after $x=1+t$ it is proportional to $t^3-2t+2$, whose local <maximum> and <local minimum>[minimum] are both positive, so it crosses zero only once, on the left. Since the quartic tends to $+\infty$ in both directions and its <second derivative>[curvature] at that <stationary point> is positive, this is the unique <global minimum>. The function reports convergence rather than assuming that every starting point must reach it.

At $x=1$, the <derivative> and <second derivative>[curvature] are $f'(1)=8$, $f''(1)=-8$, so the next iterate is $2$. At $x=2$, they are $f'(2)=4$, $f''(2)=4$, so the next iterate is $1$. Hence
$$
\boxed{1\longmapsto2\longmapsto1\longmapsto2\longmapsto\cdots.}
$$
The undamped <algorithm> does not converge to a <local minimum>[minimum]; it has an exact <two-cycle>. The implementation in (iii) detects this after returning to one and reports failure. This example illustrates why the local convergence result in (ii) does not justify global success.
