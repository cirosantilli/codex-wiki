Write $\Box A$ for the <arithmetical provability predicate> applied to the <Gödel number> of $A$. Use the <Hilbert-Bernays-Löb derivability conditions> that belong to the course meaning of a provability predicate: external <necessitation rule>, internal <modus ponens rule>, and <positive introspection>. No incompleteness theorem is needed here.

If $S\vdash G$, <necessitation rule> gives $S\vdash\Box G$. The displayed <Gödel sentence> equivalence also gives $S\vdash\neg\Box G$. These two theorems contradict the assumption that $S$ is a <consistent first-order theory>. Therefore
$$
\boxed{S\text{ consistent}\ \Longrightarrow\ S\nvdash G.}
$$
For this part alone, the external <necessitation rule> condition suffices; the stronger internal conditions are used in the next part.

= Solution
{parent=b}

Again abbreviate provability by $\Box$. The <Gödel sentence> equivalence gives $S\vdash G\to\neg\Box G$. Internalizing this implication using the first two <Hilbert-Bernays-Löb derivability conditions> gives
$$
S\vdash\Box G\to\Box\neg\Box G.
$$
<Positive introspection> also gives $S\vdash\Box G\to\Box\Box G$. Internal <modus ponens rule> combines proofs of a sentence and its <negation> into a proof of a contradiction; a contradiction implies any sentence. Consequently
$$
S\vdash\Box G\to\Box\neg G.
$$
These are syntactic manipulations of provability, not an appeal to <soundness>. If $S\vdash\neg\Box\neg G$, taking the contrapositive of the last implication gives $S\vdash\neg\Box G$, and the diagonal equivalence gives $S\vdash G$. Part (a) rules that out for a consistent theory. Hence
$$
\boxed{S\nvdash\neg\Box\neg G\quad\text{when }S\text{ is consistent}.}
$$

= Solution

An <arithmetic> theory is <one-consistent> if there is no <bounded arithmetic formula> $\delta(x)$ for which it proves $\exists x\,\delta(x)$ and also proves $\neg\delta(\overline n)$ for every standard <natural number> $n$. A finite tuple of existential witnesses can be coded by one <natural number>. The associated <Sigma-1 soundness> property says that every $\Sigma_1$ sentence it proves is true in the standard <natural numbers>.

Suppose first that the theory is one-consistent, but proves a false $\Sigma_1$ sentence $\exists x\,\delta(x)$. For every standard $n$, $\neg\delta(\overline n)$ is then a true bounded sentence. Bounded completeness makes each such sentence a theorem, violating one-consistency.

Conversely suppose the theory is $\Sigma_1$-sound. If it proved both the existential sentence and every negated standard instance, soundness would supply an actual witness $n$. Its positive instance $\delta(\overline n)$ is a true bounded sentence and hence provable. Together with the assumed negative instance this would make the theory inconsistent; an inconsistent theory proves a false $\Sigma_1$ sentence, contrary to soundness. Thus
$$
\boxed{\text{one-consistency}\ \Longleftrightarrow\ \Sigma_1\text{-soundness}}
$$
under the stated bounded-completeness assumption. In particular either condition implies that the theory is a <consistent first-order theory>.

= Solution

By part (c), <one-consistency> gives <Sigma-1 soundness> and hence ordinary consistency. First, $S$ cannot prove $\neg G$: if it did, the diagonal equivalence would give $S\vdash\Box G$. This is a $\Sigma_1$ sentence, so soundness would make it true. The stipulated standard interpretation of the <arithmetical provability predicate> would then supply an actual proof of $G$, contradicting consistency.

Now suppose $S\vdash\Box\neg G$. This too is a $\Sigma_1$ theorem. Soundness and the standard correctness of the predicate would imply that there is an actual $S$-proof of $\neg G$, which was just excluded. Therefore
$$
\boxed{S\text{ one-consistent}\ \Longrightarrow\ S\nvdash\Box\neg G.}
$$
The two applications of soundness concern the provability assertions, not the truth of arbitrary <arithmetic> sentences.

Write $\operatorname{Prf}(n,m)$ for the specified proof relation and $R(n)$ for its <Rosser provability predicate>. If $R(\overline n)$ is true in the standard <natural numbers>, its existential witness $m$ is the code of an actual proof of the expression with code $n$. Thus that expression is provable.

Conversely, suppose an actual proof has code $m$. If <Peano arithmetic> is consistent, there is no proof of the <negation> at all, in particular none with code at most $m$. The same $m$ therefore witnesses the bounded proof-order condition as well as the positive proof condition. Hence
$$
\boxed{\mathbb N\models R(\overline n)\ \Longleftrightarrow\ PA\vdash E_n}
$$
under consistency. For numbers that do not code well-formed expressions, neither side holds under the usual proof coding. This is an external equivalence of theoremhood; it does not establish every internal <derivability conditions> for $R$.

Let $\bot$ abbreviate the fixed false <arithmetic> equality, and fix an actual proof of $\neg\bot$ with code $m$. For a proposed proof code $y\geq m$, that known proof of the <negation> already violates the bounded negative-proof test in $R(\ulcorner\bot\urcorner)$.

For the finitely many codes $y<m$, either one is an actual proof of $\bot$, in which case <Peano arithmetic> is inconsistent and proves the requested conclusion by explosion, or none is. In the latter case the finitely many true bounded facts $\neg\operatorname{Prf}(\ulcorner\bot\urcorner,\overline y)$ are all provable by bounded completeness. Their conjunction excludes every code below $m$. The positive bounded fact that $m$ proves $\neg\bot$ is likewise provable. Splitting $y<m$ and $y\geq m$ inside <arithmetic> now gives
$$
\boxed{PA\vdash\neg R(\ulcorner\bot\urcorner).}
$$
Thus the consistency statement for this <Rosser provability predicate> is provable. The argument uses only a fixed finite initial segment of proof codes; it does not prove the usual unbounded consistency statement.

**The external <necessitation rule> assertion is valid.** Suppose $PA\vdash X$ and fix a proof code $m$. If $PA$ is inconsistent the assertion follows by explosion. Otherwise there is no actual proof of $\neg X$. Each of the finitely many bounded checks up to $m$ is therefore a true bounded <arithmetic> fact and is provable. Together with the positive proof check at $m$ this gives
$$
\boxed{PA\vdash X\ \Longrightarrow\ PA\vdash R(\ulcorner X\urcorner).}
$$

**The requested internal modus-ponens assertion needs an additional coding property.** Combining a proof of $X$ and a proof of $X\to Y$ produces a proof of $Y$, but its code can exceed both original codes. The two Rosser hypotheses exclude proofs of $\neg X$ and $\neg(X\to Y)$ only up to their respective witness bounds. They provide no bound excluding proofs of $\neg Y$ below the new proof code. Ordinary internal <modus ponens rule> for the unbounded provability predicate does not fill this gap.

Consequently the premises printed here do not, just by themselves, justify
$$
R(\ulcorner X\to Y\urcorner)\to(R(\ulcorner X\urcorner)\to R(\ulcorner Y\urcorner)).
$$
This property varies with the <Rosser proof-order dependence>: some specially chosen proof predicates satisfy it, while general Rosser proof predicates need not. https://sartemov.ws.gc.cuny.edu/files/2012/10/Artemov-Beklemishev.-Provability-logic.pdf[Provability Logic, printed page 87: dependence of Rosser <modus ponens rule> on proof numbering]{ref}.

The reference to a proof predicate “as given in the course” would need an explicit additional proof-order lemma to establish this part for that particular coding. Standard correctness on numeral instances and the ordinary <Hilbert-Bernays-Löb derivability conditions> alone are insufficient. The next solution gives the intended argument with the missing condition stated explicitly.

**Assume additionally that the internal modus-ponens condition requested in part (c) holds for this $R$.** If <positive introspection> also held for every sentence, then $R$ would satisfy all three <Hilbert-Bernays-Löb derivability conditions>: external <necessitation rule> was proved in part (c), <modus ponens rule> is the added condition, and introspection is the supposition.

The diagonal lemma applies to $R$ just as to any <arithmetic> formula. The usual <Gödel second incompleteness theorem> for a predicate with these conditions would then imply
$$
PA\nvdash\neg R(\ulcorner\bot\urcorner)
$$
when $PA$ is consistent. Part (b) proves the opposite. Therefore the three conditions cannot all hold, and under the added modus-ponens hypothesis there must be some sentence $X$ such that
$$
\boxed{PA\nvdash R(\ulcorner X\urcorner)\to R(\ulcorner R(\ulcorner X\urcorner)\urcorner).}
$$
This is the intended contradiction argument and requires no identification of a particular $X$.

Without that extra hypothesis, the valid conclusion is only that **at least one of internal <modus ponens rule> and <positive introspection> fails**. Rosser predicates can be constructed that satisfy <positive introspection>, so a failure of that condition cannot be inferred from the printed general assumptions alone. https://arxiv.org/abs/1902.06863[Rosser provability and the second incompleteness theorem: constructions with different derivability conditions]{ref}. The distinction concerns proof coding, not a missing page of the exam.

Abbreviate the <arithmetical provability predicate> by $\Box$, with the <Hilbert-Bernays-Löb derivability conditions> understood. <Löb's theorem> says
$$
\boxed{S\vdash\Box A\to A\quad\Longrightarrow\quad S\vdash A.}
$$
Choose a diagonal sentence $D$ with $S\vdash D\leftrightarrow(\Box D\to A)$. Internalizing its forward implication gives $S\vdash\Box D\to\Box(\Box D\to A)$. Internal <modus ponens rule> gives $\Box(\Box D\to A)\to(\Box\Box D\to\Box A)$, while <positive introspection> gives $\Box D\to\Box\Box D$. Combining these yields $S\vdash\Box D\to\Box A$.

Now use the assumed theorem $\Box A\to A$. It follows that $S\vdash\Box D\to A$, and the reverse direction of the diagonal equivalence gives $S\vdash D$. External <necessitation rule> gives $S\vdash\Box D$, and the previously derived implication gives $S\vdash A$. This proves the theorem from the supplied fixed-point property and the derivability conditions.

The <Gödel second incompleteness theorem> states that a consistent <arithmetic> theory in this setting cannot prove its own consistency sentence $\operatorname{Con}_S=\neg\Box\bot$. If it could, it would prove $\Box\bot\to\bot$; applying Löb's theorem with $A=\bot$ would make it inconsistent. Therefore $\boxed{S\nvdash\operatorname{Con}_S}$ when $S$ is consistent.

= Solution
{parent=b}

The language of <Gödel-Löb logic> has <propositional variables>, $\bot$, implication, and the unary operator $\Box$; the other <logical connectives> are abbreviations. Its axioms are all classical <tautologies>, the distribution scheme $\Box(A\to B)\to(\Box A\to\Box B)$, and the Löb scheme $\Box(\Box A\to A)\to\Box A$. Its rules are <modus ponens rule>, <necessitation rule> of theorems, and uniform substitution.

For a single boxed equation $p\leftrightarrow\Box C(p)$, set $F=\Box C(\top)$. The identity supplied in the source gives directly $GL\vdash F\leftrightarrow\Box C(F)$. If $p$ does not occur, take $F=\Box C$ instead.

Proceed by induction for a system of $m$ equations, allowing other <propositional variables> as parameters. Treat $p_1,\ldots,p_{m-1}$ as parameters in the last equation and put
$$
D(p_1,\ldots,p_{m-1})=\Box C_m(p_1,\ldots,p_{m-1},\top).
$$
The one-variable result proves $D\leftrightarrow\Box C_m(p_1,\ldots,p_{m-1},D)$. Substitute this $D$ for $p_m$ in the first $m-1$ equations. They are still boxed equations, so induction supplies solutions $F_1,\ldots,F_{m-1}$. Define $F_m=D(F_1,\ldots,F_{m-1})$.

By construction, the first $m-1$ equations hold after this substitution; substituting into the theorem for $D$ proves the last. Hence
$$
\boxed{GL\vdash F_i\leftrightarrow\Box C_i(F_1,\ldots,F_m)\quad(1\leq i\leq m).}
$$
The elimination introduces no new parameter letters and removes every unknown letter. This gives a constructive <simultaneous boxed fixed-point elimination in GL>.

Take the outermost boxed subformulas of $X(p)$ containing the distinguished letter. Because $X$ is modalized in $p$, every occurrence of $p$ lies inside one of these boxes. The supplied decomposition therefore has the form
$$
X(p)=H(\Box C_1(p),\ldots,\Box C_m(p)),
$$
where $H$ has no occurrence of $p$. Other letters and subformulas not involving $p$ may be retained as parameters in $H$ and the $C_i$.

Introduce temporary letters $q_1,\ldots,q_m$ and solve the boxed system
$$
q_i\leftrightarrow\Box C_i(H(q_1,\ldots,q_m))
$$
by part (b), obtaining $Q_i$ without the temporary letters or $p$. Put $F=H(Q_1,\ldots,Q_m)$. Each solved equation gives $GL\vdash Q_i\leftrightarrow\Box C_i(F)$. The supplied replacement-of-equivalents principle then gives
$$
\boxed{GL\vdash F\leftrightarrow H(\Box C_1(F),\ldots,\Box C_m(F))=X(F).}
$$
Only letters already present in $X$, apart from the removed $p$, occur in the constructed $F$. If $p$ is absent from $X$ to begin with, take $F=X$. This is the <modalized fixed-point theorem for GL>, proved by finite elimination rather than a semantic completeness argument.

One can take

A <complete theory> is $\kappa$-categorical when it has a model with underlying <cardinality> $\kappa$ and any two of its models of that <cardinality> are <isomorphic structures>. Thus categoricity means uniqueness up to isomorphism at the specified <cardinal>, not a unique underlying set or a unique isomorphism.

For the infinite <cardinals> relevant here, the existence clause is automatic from the stated infinite model and the <Löwenheim-Skolem theorem>. One may equivalently require exactly one isomorphism class of models of size $\kappa$.

{parent=4}
{scope}

= Solution
{parent=b}

An $n$-type over the empty set is a set $p(x_1,\ldots,x_n)$ of formulas of the language, with no additional parameters, jointly consistent with $T$. Equivalently every <finite set> is simultaneously satisfiable with $T$. A <complete type> decides every formula in these variables: for each $\varphi$, exactly one of $\varphi$ and $\neg\varphi$ belongs to $p$.

A principal type has an isolating formula $\theta(x)$ consistent with $T$, such that $T\models\forall x(\theta(x)\to\varphi(x))$ for every $\varphi\in p$. For a <complete type> this is an <isolated type>; its isolator determines the entire type. A principal <partial type> may be weaker than a <complete type>, so its isolator need not decide all formulas.

A tuple $a\in A^n$ realizes $p$ if $\mathcal A\models\varphi(a)$ for every formula in $p$. The model omits $p$ if it contains no such tuple. Thus omission is a simultaneous failure of realizing the whole type, even though each finite fragment can be realized.

= Solution

Let $\theta(x)$ isolate the principal type. Consistency with $T$ means $T\cup\{\exists x\,\theta(x)\}$ is satisfiable. Because $T$ is a <complete theory>, it must imply $\exists x\,\theta(x)$; the alternative would make that extension inconsistent.

Therefore every model of $T$ has a tuple $a$ satisfying $\theta$. Each implication $T\models\theta\to\varphi$ then makes $a$ satisfy every member of the type. Hence
$$
\boxed{\text{Every principal type is realized in every model of }T.}
$$
Completeness is what turns possible realization of the isolating formula into realization in every model.

The <countable> <omitting types theorem> says that for a consistent theory in a <countable> language and countably many nonprincipal types of finite arities, there is a <countable> model omitting all those types. In particular a nonisolated <complete type> of $T$ can be omitted in a <countable> model.

Interpret “definable” here as **without parameters**. If parameters were allowed freely, every infinite structure would have infinitely many definable singleton sets, and the claimed implication would be false even for a <dense linear order without endpoints>.

Infinitely many distinct parameter-free definable subsets of $A^n$ imply infinitely many complete $n$-types: if there were only $r$ such types, each formula would select a subset of those $r$ types, giving at most $2^r$ distinct definable subsets. There must also be a nonisolated <complete type>. To see this, suppose each <complete type> $p$ had an isolator $\theta_p$. The family of their basic open sets covers the <type space>. Its <compactness theorem> gives a finite subcover, which would account for only finitely many <complete types>, a contradiction. Equivalently apply logical <compactness theorem> to $T\cup\{\neg\theta_p(c):p\text{ complete}\}$.

Choose a nonisolated type $p$. The <omitting types theorem> gives a <countable> model omitting it, while part (d) gives a <countable> model realizing it. An <isomorphism of structures> preserves realization of parameter-free types, so these models are not isomorphic. Thus $\boxed{T\text{ is not }\aleph_0\text{-categorical}}$.

Take the standard <successor structure> and its disjoint union with one two-sided integer successor chain:
$$
\boxed{\mathcal N,\qquad\mathcal N\ \sqcup\ (\mathbb Z,z\mapsto z+1).}
$$
Both interpret the named zero in the natural-number component. The <classification of models of the successor theory> describes every model as this distinguished one-sided chain together with an arbitrary collection of two-sided chains. Its axioms are <injectivity> of $s$, zero outside its range, a predecessor for every nonzero element, and absence of finite cycles. These axioms are complete; equivalently the theory has the successor quantifier-elimination property explained in the concept proposal.

Consequently both displayed structures are models of the standard <complete theory>. They are not isomorphic: any isomorphism must fix zero and hence every element $s^n(0)$. The first structure has no other elements; the second has the entire extra integer chain. Being in that additional component is an isomorphism invariant even though being outside all standard iterates of zero is not expressible by one <first-order formula>.

Consider the <partial type>

Each finite fragment is realized by a sufficiently large standard <natural number>, so it is consistent. It is omitted in the standard <successor structure>, since each of its elements equals one of the named iterates.

The distinguished chain generated by zero is <countable>, and every other component in the <classification of models of the successor theory> is a <countable> copy of the integer successor chain. A model of <cardinality> $\aleph_1$ therefore has exactly $\aleph_1$ additional components: a finite or <countable> collection would be <countable>, while the union of $\kappa$ <countable> components has size $\max(\kappa,\aleph_0)$.

Given two such models, match their zero chains in the forced way and choose a <bijection> between their additional components. On each component choose an origin and match corresponding integer iterates; this commutes with successor. The union of these maps is an <isomorphism of structures>. Existence is given by a disjoint union with $\aleph_1$ integer chains. Hence
$$
\boxed{T_S\text{ is }\aleph_1\text{-categorical}.}
$$
The same argument works at every <uncountable> <cardinal>. <Countable> models can still differ by the number of extra components, as part (ii) shows.

A <term-generated model> is a structure in which every element is the value of a <closed term> of the original language. Equivalently its <substructure> generated by the empty set, including interpretations of named constants, is the entire structure. This is the relevant meaning of “term model” for a model of an arbitrary <complete theory>, rather than a claim about one particular syntactic construction.

Each <closed term> $t$ gives the parameter-free defining formula $x=t$. Thus
$$
\boxed{\text{term-generated}\ \Longrightarrow\ \text{pointwise definable}.}
$$
The next parts show that pointwise definability implies atomicity, and <countable> atomicity is equivalent to primeness. Therefore property (i) implies all three other properties.

= ii
{parent=a}
{scope}

= Solution
{parent=ii}

An element $a$ is parameter-free definable if some formula $\theta(x)$ of the original language has $a$ as its unique solution in the structure. Saying this for every element makes the model <pointwise definable>.

If a finite tuple has individually defining formulas, their conjunction uniquely defines that tuple. Its <complete type> is isolated by this conjunction: for each formula $\varphi$, the sentence saying the unique tuple does or does not satisfy $\varphi$ is decided by the <complete theory>. Thus
$$
\boxed{\text{pointwise definable}\ \Longrightarrow\ \text{atomic}.}
$$
It follows that the <countable> model is also prime. The converse implication to property (i) fails. In $(\mathbb N,<,0)$ every element is defined by having exactly $n$ predecessors, but the only <closed term> in this language is the constant $0$. This infinite model is pointwise definable and is not term-generated.

{parent=a}
{scope}

= Solution
{parent=iii}

An <atomic model> is a model in which every finite tuple realizes an isolated <complete type> over the empty set. For a <complete theory> in a <countable> language, every <countable> atomic model is prime. The underlying argument is a <back-and-forth method> in the one-sided form needed for an embedding: enumerate the atomic model, and extend a finite partial elementary map one element at a time using an isolating formula for the enlarged tuple. The target model has the required witness because the already matched tuple has the same <complete type>.

Thus property (iii) implies property (iv). It need not imply pointwise definability or term-generation. The <countable> <dense linear order without endpoints> with a single named point, for example $(\mathbb Q,<,0)$, is atomic: <quantifier elimination for dense linear orders without endpoints> isolates a tuple by its finite order-and-equality pattern relative to zero. But order <structure automorphisms> fixing zero move every nonzero rational. Such elements are not parameter-free definable, and no <closed term> names them. This supplies the failed implications (iii)$\not\Rightarrow$(ii) and (iii)$\not\Rightarrow$(i).

= Solution
{parent=iv}

A <prime model> admits an <elementary embedding> into every model of its <complete theory>. In the <countable> setting a prime model is atomic. If a tuple in the prime model had a nonisolated <complete type>, the <omitting types theorem> would give a model omitting that type; an <elementary embedding> of the prime model into it would realize the omitted type, a contradiction.

Combining the four parts, all positive implications are exactly those generated by
$$
\boxed{(\mathrm i)\ \Longrightarrow\ (\mathrm{ii})\ \Longrightarrow\ (\mathrm{iii})\ \Longleftrightarrow\ (\mathrm{iv}).}
$$
The structure $(\mathbb N,<,0)$ refutes (ii)$\Rightarrow$(i). The structure $(\mathbb Q,<,0)$ is a <countable> atomic and hence prime model of its <complete theory>, while failing both (i) and (ii); it refutes every remaining reverse arrow, including (iv)$\Rightarrow$(i) and (iv)$\Rightarrow$(ii). The counterexamples therefore cover all ordered pairs of distinct properties not forced by the boxed chain.

An <omega-saturated model> realizes every <complete type> of a finite tuple over every <finite set> of its domain. It suffices to require this for one-variable types: realize the coordinates successively, enlarging the finite parameter set at each step.

**Every <complete theory> here has such a model, with no countability requirement on its size.** Start with a model of size at most $\lambda=2^{\aleph_0}$. There are at most $\lambda$ types over its <finite sets>, because the language is <countable> and each such type is a set of formulas in a <countable> collection. By the <compactness theorem> and the <elementary diagram> construction, pass to an <elementary extension> realizing all these types, keeping size at most $\lambda$ by the <Löwenheim-Skolem theorem>.

Repeat this for stages $0,1,2,\ldots$ and take the union of the elementary chain. Any finite parameter set in the union lies in some stage, and every type over it is realized at the next stage. The union is therefore omega-saturated. <Countable> language does not by itself guarantee that a <countable> saturated model exists.

Suppose $T$ is an <omega-categorical theory>. By the <Ryll-Nardzewski theorem>, every finite-arity <complete type> over the empty set is isolated. Let $p(x,a)$ be a <complete type> over a finite tuple in the unique <countable> model $M$, and take an <elementary extension> realizing it at $b$. The joint type of $(b,a)$ is isolated by a formula $\theta(x,y)$.

The <complete type> of $a$ contains $\exists x\,\theta(x,y)$, since this formula is true of $a$ in the extension. Hence it is true of $a$ in $M$, and some $b'\in M$ satisfies $\theta(b',a)$. Isolation of the joint type implies that $b'$ realizes $p$. Thus the <countable> model is an <omega-saturated model>.

**The converse fails.** The complete <successor theory> from question 4 has a <countable> model
$$
M=\mathcal N\ \sqcup\ \bigsqcup_{j\in\mathbb N}\mathbb Z_j
$$
with countably infinitely many two-sided successor components. It is omega-saturated. Over finitely many parameters, a complete one-variable type either fixes a finite successor/predecessor translate of a parameter or zero, or asks for a point in no component represented by those parameters and zero. The first kind is realized in the named component, and the second in an unused integer component. The quantifier-elimination description of <classification of models of the successor theory> shows there are no other cases.

Nevertheless this theory is not omega-categorical: $M$ and its standard model $\mathcal N$ are <countable> and not isomorphic. Thus existence of a <countable> saturated model is strictly weaker than <countable> categoricity.

Expand the language by a constant $c_a$ for every element of the structure. Its <diagram of a structure> consists of all atomic and negated atomic sentences true in this expanded structure. Its <elementary diagram>, also called the complete diagram, consists of all <first-order sentences> true in the expansion.

For a model $M$ of the diagram, the map $a\mapsto c_a^M$ is injective because the diagram includes all required inequalities. It preserves functions and constants by the corresponding equations, and it preserves and reflects relations by the positive and negative atomic sentences. Thus it is a <structure embedding> onto a <substructure> of the reduct of $M$. Conversely, a structure containing an isomorphic copy of the original as a <substructure> can interpret the new constants at that copy and satisfy its diagram.

For the elementary diagram the same argument works for every formula, not just atomic ones. The map is therefore an <elementary embedding>. Conversely any <elementary embedding> gives an expansion satisfying the elementary diagram. These are characterizations up to the named copy; a model of either diagram may have additional unnamed elements.

For a structure in a <countable> language and any subset $C$ of its domain, there is an <elementary substructure> containing $C$ of <cardinality> at most $\max(|C|,\aleph_0)$. In particular a finite or <countable> $C$ lies in a <countable> <elementary substructure>. This is the downward <Löwenheim-Skolem theorem>.

Construct it directly inside the given structure $A$. Start with $C_0$ containing $C$, the interpretations of the constants, and one element if needed to ensure a nonempty domain. Given $C_n$, for every formula $\exists x\,\varphi(x,a)$ with its finite parameter tuple from $C_n$ that is true in $A$, choose one actual witness in $A$ and place it in $C_{n+1}$. Retain $C_n$ as well. There are at most $\max(|C|,\aleph_0)$ choices at each stage. Let $B=\bigcup_{n<\omega}C_n$.

The construction closes $B$ under every function of the language: for a tuple in $C_n$, the formula $x=f(a)$ forces its unique value into the next stage. Thus $B$ carries the induced <substructure>, and it has the asserted <cardinal> bound.

Prove elementarity by <structural induction>. <Atomic formulas> agree by the induced-substructure construction; <logical connectives> preserve agreement. For an existential formula with parameters in $B$, if it is true in $A$, all its parameters occur in some $C_n$, so the chosen witness lies in $C_{n+1}\subseteq B$. The induction hypothesis makes its matrix true in $B$. In the other direction a witness in $B$ is also a witness in $A$, again by induction. This is the <Tarski-Vaught test>, with its witness argument proved explicitly. No completeness or <compactness theorem> theorem enters the construction.

<Skolem's paradox> is the apparent conflict between a <countable> model of a sufficiently strong <set theory> and that model's theorem asserting the existence of <uncountable> sets. Downward <Löwenheim-Skolem theorem> gives a <countable> elementary model whenever an appropriate infinite model exists; internally the same model still proves, for example, that its real-number set is <uncountable>.

The two uses of “<countable>” quantify over different collections of functions. Externally the whole model, and therefore the elements it regards as members of its real-number set, can be enumerated. Internally a set is <countable> only if an enumerating function exists among the sets of the model. The external enumeration need not be an element of the model.

Thus there is no contradiction: the model's assertion is that **no function it contains** is the required enumeration. <Cantor's theorem> remains valid inside the model. The model need not be transitive or have the actual standard <natural numbers> for this explanation; the essential issue is the restriction of internal quantifiers to its own domain.
