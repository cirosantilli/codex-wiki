= Quantum error correction
{title2=QEC}
{wiki}

Quantum error correction protects a <logical qubit> by encoding its <quantum state> into a larger <Hilbert space>, where a specified family of physical errors can be diagnosed and reversed by a common recovery <quantum channel>. The requirement is to restore every encoded <quantum superposition>, including its relative phase, rather than only the <computational basis> states. A <quantum error-correcting code> specifies which errors have this protection; it does not promise recovery from every possible disturbance.

The beautiful idea is to measure relations between physical <qubits> that reveal an <error syndrome> while revealing nothing about the protected <logical qubit>. For example, the <bit-flip repetition code> compares neighboring <qubits> without reading their individual values. Its parity checks can locate one <Pauli X gate> error while leaving the unknown coefficients intact. Encoding is a <linear isometry>, consistent with the <no-cloning theorem>: redundancy in a shared <quantum state> supplies protection without making independent copies of the unknown input.

Peter W. Shor's 1995 paper https://journals.aps.org/pra/abstract/10.1103/PhysRevA.52.R2493[Scheme for reducing decoherence in quantum computer memory]{ref}, published on 1 October, introduced the nine-<qubit> <Shor code> to reduce <quantum decoherence> in memory. Andrew M. Steane's https://journals.aps.org/prl/abstract/10.1103/PhysRevLett.77.793[Error Correcting Codes in Quantum Theory]{ref}, published on 29 July 1996 and https://users.physics.ox.ac.uk/~Steane/pubs/Steane_PRL95.pdf[available from its author's site]{ref}, connected <quantum error correction> to classical <linear codes>; the seven-<qubit> <Steane code> protects against arbitrary errors on one physical <qubit>. These constructions protect relative phase as well as <computational basis> values, going beyond the elementary <bit-flip repetition code>.

For an authored account of the mechanism, see John Preskill's https://www.preskill.caltech.edu/ph229/notes/chap7.pdf[Quantum Error Correction lecture notes]{ref}, especially section 7.1 on collective parity measurements and section 7.9 on <stabilizer codes>. Andrew Steane's https://users.physics.ox.ac.uk/~Steane/pubs/Steane_2006.pdf[A tutorial on quantum error correction] develops the distinction between correcting a stored <quantum state> and operating with imperfect <quantum gates>.

= Decoherence-free subspace
{parent=Quantum error correction}
{wiki=Decoherence-free_subspaces}

A subspace on which every operator in a specified noise model acts as a common scalar, so the encoded <density operator> is preserved without syndrome-dependent recovery. For collective $z$ rotations, the span of $|01\rangle$ and $|10\rangle$ has zero total $Z$ eigenvalue and is invariant. Protection depends on the collective-noise assumption; independent local rotations do not generally preserve its logical phase.

= Two-spin decoherence-free encoding
{parent=Decoherence-free subspace}
{title2=$|0_L\rangle=|01\rangle,\quad|1_L\rangle=|10\rangle$}

The zero-total-$Z$ <eigenspace> of two <spin one-half> systems stores one <logical qubit>. Both basis states satisfy $(ZI+IZ)|\psi\rangle=0$, so every <collective dephasing> rotation acts as the <identity operator> on their span. Also $ZZ|01\rangle=-|01\rangle$ and $ZZ|10\rangle=-|10\rangle$, so simultaneous <Pauli Z gates> preserve every encoded <density matrix>. For independent rotations, the logical amplitudes instead acquire phases $e^{-i(\phi_1-\phi_2)/2}$ and $e^{i(\phi_1-\phi_2)/2}$, which generally alter their <relative phase>. The code is not a two-dimensional <decoherence-free subspace> for arbitrary collective rotations about all axes; the invariant two-spin singlet alone is only one-dimensional.

= Fault-tolerant quantum computation
{parent=Quantum error correction}

<Quantum computation> organized so that the spread of physical errors can be controlled by <quantum error correction>. Error thresholds depend on the noise model, code, operations and architecture. A correct ideal gate decomposition alone does not establish fault tolerance.

= Quantum error-correcting code
{parent=Quantum error correction}
{title2=$\mathcal C\subseteq(\mathbb C^2)^{\otimes n}$}

= Quantum code
{synonym}

A quantum error-correcting code is a subspace encoding a logical <Hilbert space>, together with a specified family of noise operators that a common recovery <quantum channel> reverses on every encoded state. A K-dimensional code carries $\log_2K$ logical qubits. For a code projector $P$, correctability is characterized by the <Knill--Laflamme condition>; code distance is defined by the smallest undetectable operator weight, not merely by the number of generators.

= Logical qubit
{parent=Quantum error correction}
{title2=$\alpha|0_L\rangle+\beta|1_L\rangle$}

A <logical qubit> is a two-dimensional encoded quantum subsystem with chosen orthonormal logical basis states $|0_L\rangle,|1_L\rangle$. An encoding <linear isometry> sends $\alpha|0\rangle+\beta|1\rangle$ to $\alpha|0_L\rangle+\beta|1_L\rangle$. In a <concatenated quantum error-correcting code>, one level's <logical qubit> supplies one <qubit> of the next outer code.

= Concatenated quantum error-correcting code
{parent=Quantum error correction}

A concatenated quantum code replaces each physical <qubit> of an outer code by a <logical qubit> of an inner code. Correction proceeds from inner blocks to outer blocks. For independent errors and ideal correction, a logical-error map $f$ iterates as $p_{\ell+1}=f(p_\ell)$. This recursion describes the code/channel model and does not by itself include errors in encoding and recovery gates.

= Five-qubit concatenation threshold
{parent=Concatenated quantum error-correcting code}
{title2=$p_{\ell+1}=10p_\ell^2-20p_\ell^3+15p_\ell^4-4p_\ell^5$}

Assume independent physical-error <probability> $p$, correction of zero or one errors, and failure on every block with at least two errors. The failure map is $f(p)=1-(1-p)^5-5p(1-p)^4$. Factoring $f(p)-p$ gives $p(1-p)(4p^3-11p^2+9p-1)$. The unique interior threshold is the root of $4p^3-11p^2+9p-1=0$. Below it concatenation decreases the failure <probability> toward zero. Two levels give $f(f(p))=1000p^4+O(p^5)$, compared with $10p^2+O(p^3)$ at one level.

= Five-qubit code
{synonym}

The five-qubit code encodes one logical <qubit> into five physical <qubits> and corrects an arbitrary error on one physical <qubit>. In a nondegenerate realization, the identity and fifteen one-qubit <Pauli operators> take the two-dimensional code into sixteen mutually orthogonal syndrome subspaces, filling the 32-dimensional physical <Hilbert space>.

= Five-qubit stabilizer syndrome table
{parent=Five-qubit error correcting code}
{title2=$S=\langle XZZXI,IXZZX,XIXZZ,ZXIXZ\rangle$}

The four commuting independent <stabilizer generators> define a two-dimensional <stabilizer code>. The identity and fifteen single-site <Pauli errors> have sixteen distinct four-bit <error syndromes>, so their two-dimensional images form an <orthogonal direct sum> of the physical space. This proves nondegenerate single-site correction and the <perfect quantum error-correcting code> property. The operators $X^{\otimes5}$ and $Z^{\otimes5}$ commute with the stabilizer and anticommute with each other. Multiplying $X^{\otimes5}$ by $XZZXI$ gives, up to phase, $IYYIX$, a nontrivial weight-three logical operator, proving distance exactly three.

= Quantum error detection
{parent=Quantum error correction}
{title2=$PEP=c_EP$}

A code with <orthogonal projector> $P$ detects an error $E$ when its compression to the code is scalar. A <projective measurement> of $P$ then either flags departure from the code or, on a successful code-space outcome, leaves the logical state unchanged up to normalization. This includes harmless scalar errors, even though they need not produce a nonzero <error syndrome>. Detectability extends by linearity to the span of a set of errors. Every <Pauli operator> of weight less than the <quantum code distance> is detectable.

= Correction implies detection at twice the weight
{parent=Quantum error detection}
{title2=$\text{correct all weights }\leq t\ \Longrightarrow\ \text{detect all weights }\leq2t$}

Split the support of a <Pauli operator> of weight at most $2t$ into two sets of size at most $t$. It is, up to a scalar phase, $E_a^\dagger E_b$ for two errors in the correctable family. The <Knill--Laflamme condition> makes its compression to the code scalar, which is <quantum error detection>. Expansion in the Pauli basis extends the assertion to every operator supported on at most $2t$ <qubits>. The number $t$ counts affected qubits, not the cardinality of an arbitrary selected family of errors.

= Nondegenerate quantum error-correcting code
{parent=Quantum error correction}

= Nondegenerate quantum code
{synonym}

For a specified correctable set of distinct <Pauli operators> modulo phase, a nondegenerate code has mutually orthogonal error images $E\mathcal X$. Equivalently, the matrix in the <Knill--Laflamme condition> is diagonal for that Pauli error set. Each error therefore requires a separate syndrome subspace of dimension equal to the logical code dimension. Degenerate codes can have distinct errors with the same action on the code and do not satisfy this orthogonality counting argument.

= Quantum Hamming bound
{parent=Nondegenerate quantum error-correcting code}
{title2=$\sum_{j=0}^t3^j\binom nj\leq2^{n-k}$}

For unknown-location <Pauli operators> of weight at most $t$, there are $N(t)=\sum_{j=0}^t3^j\binom nj$ physically distinct errors modulo phase, including the identity. A <nondegenerate quantum code> assigns them mutually orthogonal error-image subspaces, each of dimension $2^k$, within the $2^n$-dimensional physical <Hilbert space>. Hence $N(t)2^k\leq2^n$. The hypothesis of nondegeneracy is essential to this dimension count.

= Perfect quantum error-correcting code
{parent=Quantum Hamming bound}
{title2=$2^k\sum_{j=0}^t3^j\binom nj=2^n$}

A <nondegenerate quantum code> is perfect at correction radius $t$ if its distinct correctable <Pauli error> images exhaust the physical <Hilbert space>. Each image has dimension $2^k$, and their <orthogonal direct sum> is the whole $2^n$-dimensional space precisely when the <quantum Hamming bound> is an equality. This perfectness concerns unknown-location errors of weight at most $t$; it does not imply correction of every higher-weight error.

= Distance of a quantum error-correcting code
{parent=Quantum error correction}
{title2=$[[n,k,d]]$}

= Quantum code distance
{synonym}

An $[[n,k,d]]$ <quantum error correction> code is a $2^k$-dimensional subspace of $n$ <qubits>. Its distance $d$ is the minimum weight of a <Pauli operator> $E$ for which $PEP$ is not a scalar multiple of the code projector $P$. Thus every operator supported on fewer than $d$ qubits has scalar compression to the code, by expansion in the Pauli basis. This definition includes degenerate codes; a low-weight operator acting as a scalar does not reduce the distance.

= Correctable Pauli error radius
{parent=Distance of a quantum error-correcting code}
{title2=$t=\lfloor(d-1)/2\rfloor$}

The guaranteed radius is the largest integer $t$ for which all unknown-location <Pauli operators> of weight at most $t$ can be corrected together. Pairwise products have weight at most $2t$, so $2t<d$ suffices by the <Knill--Laflamme condition>. Conversely, split a minimum-weight undetectable Pauli operator between two subsets of its support. If $d\leq2t$, this gives two errors of weight at most $t$ whose pairwise product violates that condition. Consequently $d$ is either $2t+1$ or $2t+2$; parity cannot be recovered from $t$ alone.

= Quantum Singleton bound
{parent=Distance of a quantum error-correcting code}
{title2=$n-k\geq2(d-1)$}

For a code carrying $k>0$ logical <qubits>, two disjoint subsets $A,B$ of $d-1$ physical qubits are each correctable erasures. Purify the maximally mixed logical input using a reference $R$, and call the remaining physical subsystem $C$. Erasure decoupling gives $S(RA)=S(R)+S(A)$ and $S(RB)=S(R)+S(B)$. Purity and <subadditivity of Von Neumann entropy> imply $2S(R)\leq2S(C)$, hence $k\leq n-2(d-1)$. If two such disjoint subsets would not fit, partition the entire physical system into two correctable subsets; purity and decoupling then force $S(R)=0$, a contradiction. Thus the partition used in the proof is justified independently of the bound.

= Quantum erasure correction
{parent=Distance of a quantum error-correcting code}
{title2=$m<d$}

Errors on a known subset of $m$ <qubits> are correctable by a distance-$d$ code whenever $m<d$. Every product $E_a^\dagger E_b$ of errors supported on that subset still has support in the same subset, so its compression is scalar. The <Knill--Laflamme condition> therefore supplies one recovery for every channel on that subset. Equivalently, erasing the subset leaks no logical information to it: if a reference is maximally entangled with the encoded logical system, its joint <density operator> with the erased subsystem is a <product state>.

= Linearity of coherent quantum error correction
{parent=Quantum error correction}

Suppose fixed unitary encoding and recovery correct each error $E_j$ by mapping every logical input $|\psi\rangle$ to $|\psi\rangle\otimes|\eta_j\rangle$. The syndrome vector can be taken independent of the logical input: applying linearity to basis inputs and their equal superposition forces their syndrome vectors to agree. Hence an error $E=\sum_jc_jE_j$ is mapped to $|\psi\rangle\otimes\sum_jc_j|\eta_j\rangle$. If $E$ is unitary, this final syndrome vector is normalized and the circuit corrects $E$. Orthogonality of the syndrome states is not needed for the linear-span argument; it is a separate condition concerning distinguishability of errors.

= Knill--Laflamme condition
{c}
{parent=Quantum error correction}
{wiki}

A code projector $P$ corrects errors $\{E_a\}$ exactly when $PE_a^\dagger E_bP=C_{ab}P$ for every pair.

= Necessity of the Knill-Laflamme condition
{parent=Knill--Laflamme condition}
{title2=$PE_a^\dagger E_bP=\sum_\mu c_{\mu a}^*c_{\mu b}P$}

If a common recovery <quantum channel> with <Kraus operators> $R_\mu$ restores every pure code state after each error $E_a$, then each vector $R_\mu E_a|\psi\rangle$ is parallel to $|\psi\rangle$. <Linearity> on basis vectors and their pairwise superpositions forces $R_\mu E_aP=c_{\mu a}P$, with the scalar independent of the logical state. Insert $\sum_\mu R_\mu^\dagger R_\mu=I$ between two error operators to obtain the displayed <Knill--Laflamme condition>. This proves necessity without presuming an orthogonal syndrome description of recovery.

= Constructive recovery from the Knill-Laflamme condition
{parent=Knill--Laflamme condition}
{title2=$PE_a^\dagger E_bP=C_{ab}P$}

The matrix $C$ in the <Knill--Laflamme condition> is positive semidefinite, since $v^\dagger Cv$ is the squared norm of $\sum_av_aE_a|\psi\rangle$ for any normalized code state. Diagonalizing it gives linear combinations $F_j$ with $PF_j^\dagger F_lP=c_j\delta_{jl}P$. For $c_j>0$, $V_j=F_jP/\sqrt{c_j}$ is an isometry of the code into an error-image subspace, and these subspaces are orthogonal. Measuring their projectors and applying $V_j^\dagger$ recovers the logical state. Complete the operation arbitrarily on the orthogonal complement to obtain a <quantum channel>. This construction corrects every noise map whose <Kraus operators> lie in the specified error span, including coherent superpositions of error operators.

= Stabilizer code
{parent=Quantum error correction}
{wiki}
{title2=$\mathcal C=\{\,|\psi\rangle:g_j|\psi\rangle=|\psi\rangle\ \forall j\,\}$}

A <stabilizer code> is the common $+1$ <eigenspace> of a <stabilizer group> $S$, an <abelian subgroup> of the <Pauli group> excluding $-I$. Choose $r$ independent <stabilizer generators> $g_1,\ldots,g_r$ on $n$ physical <qubits>. They are commuting <Hermitian operators>, each squaring to $I$. The <stabilizer subspace> and its <orthogonal projector> are
$$
\mathcal C=\{\,|\psi\rangle:g_j|\psi\rangle=|\psi\rangle\text{ for }j=1,\ldots,r\,\},\qquad
P=\prod_{j=1}^r\frac{I+g_j}{2}=\frac{1}{|S|}\sum_{g\in S}g.
$$
The <stabilizer-projector formula> gives $\dim\mathcal C=2^{n-r}$, so $k=n-r$ <logical qubits> remain. Independent here means that no nonempty product of the chosen <stabilizer generators> is $I$. Excluding $-I$ is necessary: a vector cannot simultaneously be fixed by $I$ and $-I$ unless it is zero.

For the three-<qubit> <bit-flip repetition code>, take $g_1=Z_1Z_2$ and $g_2=Z_2Z_3$, with $Z_j$ the <Pauli Z gate> on site $j$ and identities elsewhere. The <stabilizer group> is $S=\{I,Z_1Z_2,Z_2Z_3,Z_1Z_3\}$. Both <stabilizer generators> have <eigenvalue> $+1$ exactly on the span of $|000\rangle$ and $|111\rangle$, giving $2^{3-2}=2$ dimensions for one <logical qubit>. A <projective measurement> of these checks distinguishes four <orthogonal> two-dimensional sectors rather than eight individual <computational basis> states.

A <Pauli error> that anticommutes with a <stabilizer generator> changes that check's sign, producing an <error syndrome>. A <Pauli operator> commuting with every check can still act on the <logical qubits>; the <centralizer of a stabilizer group> describes these possibilities. Thus the number of checks determines the encoded dimension, while the <quantum code distance> determines protection against arbitrary local errors. The <five-qubit error correcting code>, for instance, has four <stabilizer generators> and <quantum code distance> three; the three-<qubit> <bit-flip repetition code> has two checks but <quantum code distance> one because a single <phase flip> is unflagged. https://www.preskill.caltech.edu/ph229/notes/chap7.pdf[Preskill, §7.9.1: stabilizers, syndromes and logical operators]{ref}.

= Symplectic representation of a stabilizer code
{parent=Stabilizer code}

A <stabilizer group> with $r$ independent generators maps injectively to an r-dimensional isotropic subspace of the <binary symplectic space of Pauli labels>. For generator rows $(A\mid B)$, commutation is $AB^T+BA^T=0$ over $\mathbb F_2$. Its <stabilizer subspace> has dimension $2^{n-r}$. The labels of the <centralizer of a stabilizer group> form $L^\perp$; labels in $L^\perp\setminus L$ act as nontrivial logical Pauli operators.

= CSS code
{c}
{parent=Stabilizer code}
{wiki}
{title2=$[[N,k_1-k_2,d]]$}

= Calderbank–Shor–Steane code
{c}
{synonym}

For binary <linear codes> $C_2\subseteq C_1\subseteq\mathbb F_2^N$, the CSS code has basis $|x+C_2\rangle=|C_2|^{-1/2}\sum_{y\in C_2}|x+y\rangle$ for $x\in C_1/C_2$. Its X stabilizers come from $C_2$ and its Z stabilizers from the <dual code> $C_1^\perp$; their commutation follows from orthogonality. For positive logical dimension, $d_X=\min\{\operatorname{wt}(x):x\in C_1\setminus C_2\}$ and $d_Z=\min\{\operatorname{wt}(z):z\in C_2^\perp\setminus C_1^\perp\}$, with <quantum code distance> $d=\min(d_X,d_Z)$. Thus arbitrary errors on at most $\lfloor(d-1)/2\rfloor$ <qubits> are correctable. Stabilizer errors are harmless even if their weight is small; the distances exclude them.

= Nested-code CSS syndrome recovery
{parent=CSS code}
{title2=$C\subseteq C',\quad [[N,\dim C'-\dim C,d]]$}

For binary <linear codes> $C\subseteq C'$, the coset superpositions of the <CSS code> have $X$ checks labelled by $C$ and $Z$ checks by $(C')^\perp$. A bit-error pattern $a$ gives the classical <syndrome> for $C'$, and a phase-error pattern $b$ gives the syndrome for the <dual code> $C^\perp$. Errors with $2t_X<\min_{a\in C'\setminus C}\operatorname{wt}(a)$ and $2t_Z<\min_{b\in C^\perp\setminus(C')^\perp}\operatorname{wt}(b)$ are jointly correctable. Every pairwise Pauli-error product either anticommutes with a check, giving zero code compression, or its low-weight components belong to the stabilizer and give scalar compression. Thus the <Knill--Laflamme condition> covers coherent superpositions and <quantum channels> as well as definite bit and phase errors.

= Centralizer of a stabilizer group
{parent=Stabilizer code}

The Pauli centralizer $C(S)$ consists of Pauli operators commuting with every stabilizer. Elements of $C(S)\setminus S$, modulo stabilizers and phases, are the nontrivial logical Pauli operators.

= Local correctability of a stabilizer code
{parent=Stabilizer code}

If every pairwise product $E_a^\dagger E_b$ has weight below the code distance, it cannot be a nontrivial logical operator. The Knill--Laflamme conditions then hold for the whole error set.

= Pauli error criterion for a stabilizer code
{c}
{parent=Local correctability of a stabilizer code}

Let $S$ exclude $-I$, let $C(S)$ be its Pauli centralizer, and let $\mathcal Z=\{\pm I,\pm iI\}$. A set of <Pauli errors> is jointly correctable exactly when every product $E_a^\dagger E_b$ belongs to $\mathcal ZS$ or lies outside $C(S)$. Outside the centralizer its code compression is zero by anticommutation; in $\mathcal ZS$ it acts as a scalar. A centralizing operator outside $\mathcal ZS$ has zero trace on the code but is unitary there, so cannot be scalar. This gives precisely the <Knill--Laflamme condition>. Scalar phases must be retained when formulating the group criterion.

= Dressed stabilizer under a weak local perturbation
{parent=Stabilizer code}

Quasi-adiabatic continuation carries each stabilizer to a quasi-local conserved operator for the perturbed low-energy space. Bare Pauli errors are then only approximately correctable because the dressed operators have exponentially small non-Pauli tails.

= Distance of a stabilizer code
{title2=$d$}
{parent=Stabilizer code}

The distance is the minimum weight of a Pauli operator that preserves the code space but acts nontrivially on its logical information.

= Error syndrome
{parent=Stabilizer code}
{wiki}

An <error syndrome> is the list of outcomes obtained by measuring a chosen ordered family of <stabilizer generators>. Write $s_j=0$ for <eigenvalue> $+1$ and $s_j=1$ for <eigenvalue> $-1$. For a definite <Pauli error> $E$ on a code state, the rule is
$$
g_jE=(-1)^{s_j}Eg_j,\qquad g_jE|\psi_L\rangle=(-1)^{s_j}E|\psi_L\rangle.
$$
The commuting checks admit joint <orthogonal projectors>
$$
\Pi_s=\prod_{j=1}^r\frac{I+(-1)^{s_j}g_j}{2},\qquad
\sum_{s\in\{0,1\}^r}\Pi_s=I,\qquad \Pi_0=P.
$$
For <density operator> $\rho$, the <Born rule> gives outcome <probability> $\operatorname{tr}(\Pi_s\rho)$ and conditional state $\Pi_s\rho\Pi_s/\operatorname{tr}(\Pi_s\rho)$ when that <probability> is nonzero. A definite <Pauli error> has one deterministic <error syndrome> independent of the encoded amplitudes. A coherent <linear combination> of <Pauli errors> may occupy several sectors, so measuring the <error syndrome> selects a sector; recovery preserves the <logical qubit> when the entire error family is jointly correctable. https://www.preskill.caltech.edu/ph229/notes/chap7.pdf[Preskill, §§7.2 and 7.9.1]{ref}.

An <error syndrome> locates an error only relative to an assumed family and a recovery rule. Two <Pauli errors> differing by a logical operator can share an <error syndrome>; see <stabilizer-syndrome coset>. In the <three-qubit bit-flip syndrome table>, $X_3$ and $X_1X_2$ both give $01$. Recovering with $X_3$ corrects the first but converts the second into the logical operator $X_1X_2X_3$. Likewise, $Z_1$ has <error syndrome> $00$ yet changes the encoded relative phase.

= Stabilizer-syndrome coset
{parent=Error syndrome}

Two Pauli errors have the same stabilizer syndrome exactly when their product lies in the centralizer of the stabilizer group. Thus a syndrome identifies a coset $E_sC(S)$, while logical operators inside that coset remain indistinguishable.

= Phase-flip repetition code
{parent=Stabilizer code}

The $n$-qubit phase-flip repetition code is stabilized by $X_jX_{j+1}$ and has codewords $|+\rangle^{\otimes n}$ and $|-\rangle^{\otimes n}$. It has logical operators $\overline Z=X_1$ and $\overline X=Z_1\cdots Z_n$, so its distance against phase flips is $n$.

= Logical Hadamard convention for a phase-flip repetition code
{parent=Phase-flip repetition code}

The codewords $|+++\rangle,|---\rangle$ have residual logical <Pauli X gate> after an uncorrectable two- or three-site phase error. Precede their encoding by a logical <Hadamard gate> and follow decoding by its inverse. Since $HXH=Z$, the same error now acts as a logical <Pauli Z gate>. Explicitly the encoded coefficients are $(\alpha+\beta)/\sqrt2$ and $(\alpha-\beta)/\sqrt2$ for an input $\alpha|0\rangle+\beta|1\rangle$. This convention matters when translating physical phase errors into a claimed decoded phase-error channel.

= Logical failure of the three-qubit phase-flip repetition code
{parent=Phase-flip repetition code}
{title2=$p_L=3\epsilon^2-2\epsilon^3$}

The <phase-flip repetition code> with codewords $|+++\rangle,|---\rangle$ corrects any one physical <Pauli Z gate> error. Its two adjacent-pair <error syndromes> cannot distinguish an error pattern from its three-bit complement. Minimum-weight recovery therefore leaves no residual error at weight zero or one, and leaves $Z_1Z_2Z_3$ at weight two or three. This residual operator exchanges the codewords, so inverse encoding gives a logical <Pauli X gate>. For independent physical phase errors of probability $\epsilon$, the decoded <quantum channel> is $(1-p_L)\rho+p_LX\rho X$, where $p_L=3\epsilon^2(1-\epsilon)+\epsilon^3$. For $0<\epsilon<1/2$, $\epsilon-p_L=\epsilon(1-\epsilon)(1-2\epsilon)>0$.

= Phase-flip protection by Hadamard conjugation
{parent=Phase-flip repetition code}

Insert <Hadamard gates> on every data qubit immediately after encoding by a <bit-flip repetition code> and immediately before its bit-flip detection and recovery. The intervening physical error is thereby conjugated by $H^{\otimes n}$, and $HZH=X$ turns a single <Pauli Z gate> error into a single bit flip for the original correction circuit. The encoded logical codewords are now $|+\rangle^{\otimes n}$ and $|-\rangle^{\otimes n}$. The syndrome ancillas and the final inverse encoding stay unchanged. This protects against phase flips in the new basis; it does not simultaneously correct arbitrary bit flips in the physical basis.

= Majority-vote decoding of a repetition code
{parent=Phase-flip repetition code}

For independent errors of probability $p<1/2$, maximum-likelihood decoding of a repetition code chooses the lower-weight error compatible with the syndrome. This is majority voting, with threshold $p_c=1/2$ and exponentially vanishing logical-error probability below threshold.

= Bit-flip repetition code
{parent=Stabilizer code}
{title2=$|0_L\rangle=|0\rangle^{\otimes m},\quad |1_L\rangle=|1\rangle^{\otimes m}$}

The $m$-<qubit> <bit-flip repetition code> stores one <logical qubit> in $|0_L\rangle=|0\rangle^{\otimes m}$ and $|1_L\rangle=|1\rangle^{\otimes m}$. Its <stabilizer generators> are $Z_jZ_{j+1}$ for $j=1,\ldots,m-1$, and its logical operators are $\overline X=X_1\cdots X_m$ and $\overline Z=Z_1$. Interchanging the <Pauli X gate> and <Pauli Z gate> gives the <phase-flip repetition code>. For odd $m$, <majority-vote decoding of a repetition code> corrects up to $(m-1)/2$ physical <Pauli X gate> errors, assuming ideal operations and a noise family containing only these bit flips.

For $m=3$, prepare two <quantum ancillas> in $|00\rangle$ and apply <controlled-NOT gates> from the input <qubit> to each of them. By <linearity>, encoding sends
$$
(\alpha|0\rangle+\beta|1\rangle)|00\rangle\longmapsto
|\psi_L\rangle=\alpha|000\rangle+\beta|111\rangle,\qquad |\alpha|^2+|\beta|^2=1.
$$
This does not produce $(\alpha|0\rangle+\beta|1\rangle)^{\otimes3}$, which would contain cross terms. For example, encoding $|+\rangle=(|0\rangle+|1\rangle)/\sqrt2$ produces $(|000\rangle+|111\rangle)/\sqrt2$, whereas three independent copies would have eight equal <computational basis> amplitudes. The encoding creates <quantum entanglement> when both coefficients are nonzero and respects the <no-cloning theorem>.

The <three-qubit bit-flip syndrome table> corrects the family $\{I,X_1,X_2,X_3\}$ and its entire <linear span>, as specified by the <Knill--Laflamme condition>. It cannot correct arbitrary errors on one physical <qubit>: the <phase flip>
$$
Z_1|\psi_L\rangle=\alpha|000\rangle-\beta|111\rangle
$$
commutes with both checks and acts as logical $\overline Z$. In particular, it takes the encoded $|+\rangle$ to the <orthogonal> encoded $|-\rangle$ with <error syndrome> $00$. Thus its full <quantum code distance> is one, despite correcting one error of the restricted <Pauli X gate> type. The <Shor code>, <Steane code> and <five-qubit error correcting code> provide protection against arbitrary one-<qubit> errors.

= Three-qubit bit-flip syndrome table
{parent=Bit-flip repetition code}
{title2=$(g_1,g_2)=(Z_1Z_2,Z_2Z_3)$}

Measure the commuting <stabilizer generators> $g_1=Z_1Z_2$ and $g_2=Z_2Z_3$ in that order. Use <error syndrome> bit $0$ for <eigenvalue> $+1$ and bit $1$ for <eigenvalue> $-1$. For $X_j$ the <Pauli X gate> on physical <qubit> $j$, every row holds for arbitrary normalized $\alpha,\beta$. This ordered parity-check convention follows https://www.preskill.caltech.edu/ph229/notes/chap7.pdf[Preskill, §7.1]{ref}:

|| Error

| $\alpha|000\rangle+\beta|111\rangle$

| $X_1$

| $(-1,+1)$

| $X_1$

| $X_2$
| $\alpha|010\rangle+\beta|101\rangle$

Each pair of <computational basis> words within a row has the same two parities. Consequently the <projective measurement> reveals the row without distinguishing its two amplitudes. For example, $|\psi_L\rangle=(\sqrt3/2)|000\rangle+(i/2)|111\rangle$ becomes $(\sqrt3/2)|010\rangle+(i/2)|101\rangle$ under $X_2$. Both checks give $-1$ with <probability> one, and applying $X_2$ restores both coefficients exactly, including the relative phase $i$.

One implementation uses two <quantum ancillas> initialized to $|00\rangle$. Two <controlled-NOT gates> from data <qubits> 1 and 2 to the first <quantum ancilla> write their parity; two more from data <qubits> 2 and 3 to the second <quantum ancilla> write the other parity. Measuring only the <quantum ancillas> in the <computational basis> gives $(s_1,s_2)$. Measuring the individual data <qubits> instead would reveal the encoded <computational basis> value and destroy the unknown <quantum superposition>. The existing <coherent syndrome extraction for the three-qubit repetition code> uses the alternative ordered checks $(Z_2Z_3,Z_1Z_3)$, so its bit labels differ from this table.

The recovery also handles coherent errors. Put $E_0=I,E_1=X_1,E_2=X_2,E_3=X_3$. Their images of the code are mutually <orthogonal>, giving $PE_a^\dagger E_bP=\delta_{ab}P$, the <Knill--Laflamme condition> for this family. For any <linear combination> $E=\sum_{a=0}^3c_aE_a$, its component in sector $s(E_a)$ is $c_aE_a|\psi_L\rangle$. Measuring that <error syndrome> has <probability> $|c_a|^2/\sum_b|c_b|^2$ on the normalized erroneous state, and recovery $E_a$ returns $|\psi_L\rangle$. More generally one recovery <quantum channel> corrects every noise <quantum channel> whose <Kraus operators> belong to this span. The assumption concerns the whole jointly correctable family; it does not extend to the span of arbitrary single-site <Pauli errors>. https://www.preskill.caltech.edu/ph229/notes/chap7.pdf[Preskill, §7.2: correction of an error span]{ref}.

A fully computed coherent example is the <unitary operator> $U=\exp(-i\theta X_2)=\cos\theta\,I-i\sin\theta\,X_2$. At $\theta=\pi/6$ it gives
$$
U|\psi_L\rangle=\frac{\sqrt3}{2}|\psi_L\rangle-\frac{i}{2}X_2|\psi_L\rangle.
$$
The <error syndromes> $00$ and $11$ occur with <probabilities> $3/4$ and $1/4$, independently of $\alpha,\beta$. Doing nothing for $00$ and applying $X_2$ for $11$ restores the same <logical qubit> in both branches; the scalar $-i$ in the second branch is an irrelevant <global phase>. This is an example of <linearity of coherent quantum error correction>, rather than an assumption that the original error was a classical random bit flip.

= Logical failure of the three-qubit bit-flip repetition code
{parent=Bit-flip repetition code}
{title2=$p_L=3p^2-2p^3$}

Assume that each physical <qubit> undergoes an independent <quantum bit-flip channel> with <probability> $p$ during one storage interval, and that encoding, <error syndrome> extraction, recovery and decoding are all ideal. Use the <three-qubit bit-flip syndrome table> to apply the indicated minimum-weight recovery. Zero or one bit flips are corrected. Two bit flips have the same <error syndrome> as the complementary one-site error: for example, $X_1X_2$ gives $01$, so recovery $X_3$ leaves $\overline X=X_1X_2X_3$. Three bit flips give $00$ and also leave $\overline X$. This exchanges $|000\rangle$ and $|111\rangle$, and therefore acts as a logical <Pauli X gate> after decoding.

The number of physical bit flips has a <binomial distribution> with three trials, hence the logical-error <probability> is
$$
p_L=\binom32p^2(1-p)+p^3=3p^2-2p^3.
$$
For a logical <density operator> $\rho$, the decoded <quantum channel> is exactly $\rho\mapsto(1-p_L)\rho+p_LX\rho X$. Here logical failure means a nontrivial logical <Pauli X gate> error; a particular input such as $|+\rangle$ can be invariant under that error. At $p=0.1$, exactly two flips have <probability> $3(0.1)^2(0.9)=0.027$ and three flips have <probability> $(0.1)^3=0.001$, giving $p_L=0.028$. The block succeeds with <probability> $0.972$ compared with $0.9$ for an unencoded <qubit>. At $p=0.01$, $p_L=0.000298$, illustrating the quadratic suppression of rare independent bit flips.

Factoring the improvement gives
$$
p-p_L=p(1-p)(1-2p).
$$
Thus one level reduces logical-error <probability> for $0<p<1/2$, is equal at $p=0,1/2,1$, and makes it worse for $1/2<p<1$ under this same decoder. The suppression arises because a logical error requires at least two physical bit flips. With independent disjoint inner blocks, the same noise model and ideal correction at every level, a <concatenated quantum error-correcting code> has $p_{\ell+1}=3p_\ell^2-2p_\ell^3$, with $p_0=p$. At $p_0=0.1$, two levels use nine data <qubits> and give $p_2=3(0.028)^2-2(0.028)^3=0.002308096$.

{title=Ideal repetition-code correction suppresses independent bit flips below one half}

This calculation describes ideal correction of stored information with the specified <quantum bit-flip channel>. Repeated correction in time additionally requires a fresh specified noise model for each interval; imperfect <quantum gates>, faulty measurements and correlated errors change the calculation. The <timed bit flip during repetition-code syndrome extraction> and <exact encoded-state failure with a faulty parity check> show concretely why this storage calculation alone is not a fault-tolerance result.

= Coherent syndrome extraction for the three-qubit repetition code
{parent=Bit-flip repetition code}
{title2=$(s_4,s_5)=(b_2\oplus b_3,b_1\oplus b_3)$}

Encode $u|0\rangle+v|1\rangle$ as $u|000\rangle+v|111\rangle$. Four <controlled-NOT gates> copy the displayed two data parities into initially zero <quantum ancillas>. No logical amplitude is measured. The <error syndromes> $00,01,10,11$ correspond respectively to no bit flip and bit flips on data qubits $1,2,3$. Conditional <Toffoli gates>, with temporary <Pauli X gates> implementing zero-valued controls, undo the indicated error. Inverse encoding yields the original logical state and a separate syndrome state. A phase flip has zero bit-flip syndrome and remains as a logical phase error; this three-qubit code is not a general single-qubit-error code.

= Timed bit flip during repetition-code syndrome extraction
{parent=Coherent syndrome extraction for the three-qubit repetition code}
{title2=$s=(e_2\oplus e_3,e_1\oplus e_2\oplus f)$}

Suppose the first ancilla records parity $q_2\oplus q_3$, then a fault of value $f$ flips $q_2$, and the second ancilla records parity $q_1\oplus q_2$. For incoming bit-error pattern $e$, the observed <error syndrome> is the displayed pair, while the final data error before recovery is $d=e\oplus(0,f,0)$. When $f=1$, the observed syndrome differs from the actual data syndrome by $(1,0)$. Applying the usual minimum-weight recovery leaves a nonzero syndrome, so the state is outside the code space even when the channel itself made no error. This is a timing-dependent failure of this simple extraction circuit, not a general obstruction to fault-tolerant <quantum error correction>.

= Exact encoded-state failure with a faulty parity check
{parent=Timed bit flip during repetition-code syndrome extraction}
{title2=$P_{\mathrm{fail}}=q+(1-q)(3p^2-2p^3)$}

For independent channel bit flips of probability $p$ and the specified extraction fault of probability $q$, require recovery of an arbitrary input in the original encoded subspace. Every extraction-fault event leaves nonzero <error syndrome>; without that fault, channel errors are corrected exactly at weight zero or one. Thus success probability is $(1-q)[(1-p)^3+3p(1-p)^2]$. Compared with a single unencoded bit-flip channel, strict improvement for $0<p<1/2$ requires $q<p(1-2p)/[(1-p)(1+2p)]$. A different decoder or an added later ideal recovery changes the performance criterion and must be specified separately.

= Concatenated phase-and-bit-flip repetition code
{parent=Stabilizer code}

Replacing every qubit of an $n$-qubit <phase-flip repetition code> by an $m$-qubit <bit-flip repetition code> gives a code with logical $Z$- and $X$-operator weights $m$ and $n$, respectively, and hence distance $\min(m,n)$.

= Shor code
{c}
{parent=Concatenated phase-and-bit-flip repetition code}
{title2=$[[9,1,3]]$}

The nine-qubit Shor code encodes one logical <qubit> with basis vectors $|0_L\rangle=|G_+\rangle^{\otimes3}$ and $|1_L\rangle=|G_-\rangle^{\otimes3}$, where $|G_\pm\rangle=(|000\rangle\pm|111\rangle)/\sqrt2$. Six adjacent $Z$-pair <stabilizer generators> locate a single bit flip within a block, while $X_1\cdots X_6$ and $X_4\cdots X_9$ diagnose which block has had its relative phase changed. Together they correct every single-qubit <Pauli operator>, hence every single-qubit error by the <Pauli expansion of a quantum error>.

A <Pauli Z gate> on qubit four has phase-check eigenvalues $(-1,-1)$ and leaves all six $Z$-pair checks positive. Applying $Z_4$ restores the state. The same phase syndrome arises from $Z_5$ or $Z_6$; these have the same action on the code since their pairwise products are stabilizers. This is a degeneracy, not a failure of correction.

= Shor-code phase-flip syndrome
{c}
{parent=Shor code}
{title2=$(X^{\otimes3}_1X^{\otimes3}_2,\ X^{\otimes3}_2X^{\otimes3}_3)$}

Group the nine physical <qubits> into three blocks and write $B_r$ for the product of three <Pauli X gates> in block $r$. The commuting <stabilizer generators> $B_1B_2$ and $B_2B_3$ have eigenvalue $+1$ on both logical codewords. A <Pauli Z gate> in blocks one, two or three gives syndromes $(-,+)$, $(-,-)$ or $(+,-)$ respectively. Apply a Z gate to any one qubit of the indicated block to recover the logical state. Z errors at distinct locations within a block act identically on the code, so this correction is degenerate.

= Steane code
{c}
{parent=Stabilizer code}
{wiki}

The Steane code is a seven-qubit CSS stabilizer code encoding one logical qubit with distance three.

= Nondegenerate phase-flip correction in the Steane code
{parent=Steane code}
{title2=$\langle\psi_a|Z(u)^\dagger Z(v)|\psi_b\rangle=\delta_{ab}\delta_{uv}$}

Write the <Steane code> basis as uniform <quantum superpositions> over a binary <linear code> $D$ and a disjoint coset $t+D$, where $D$ is the even-weight part of the length-seven <Hamming code>. For $Z(w)=\bigotimes_{j=1}^7Z_j^{w_j}$, diagonal <Pauli Z gates> cannot connect the two cosets. Within coset $t_a+D$, the overlap is
$$
\langle\psi_a|Z(w)|\psi_a\rangle=(-1)^{w\cdot t_a}|D|^{-1}\sum_{x\in D}(-1)^{w\cdot x}.
$$
If $w\notin D^\perp$, translation by a word $x_0\in D$ with $w\cdot x_0=1$ negates this sum, so it vanishes. Since the <dual code> $D^\perp$ is the length-seven <Hamming code> of minimum <Hamming distance> three, every nonzero $w$ of <Hamming weight> one or two has vanishing overlap. Taking $u,v$ from $\{0,e_1,\ldots,e_7\}$ proves the displayed identity. The eight two-dimensional error images are <orthogonal>, so their <projective measurement> determines the <error syndrome> without revealing the logical state; applying the identified <phase flip> again recovers every code state. This proves <nondegenerate quantum error-correcting code> behaviour for the identity and all single-site <phase flips>, including their coherent linear span.

A color code places qubits on a three-colorable lattice and assigns X-type and Z-type stabilizers to each colored plaquette.

= String operator in a topological code

A string operator creates excitations at its endpoints. Multiplying by a successive segment moves an endpoint because the shared intermediate excitation is toggled twice.

= Surface code
{parent=Stabilizer code}
{wiki}

The surface code is a topological stabilizer code whose electric and magnetic excitations are bosons with mutual-semion braiding.

= Surface code on a chain of spheres
{parent=Surface code}

Join $n$ spheres pole to pole and draw $m$ longitude edges on each sphere. Qubits on edges, two-edge face $Z$ stabilizers, and vertex $X$ stabilizers realize the concatenated phase-and-bit-flip repetition code. A pole-to-pole path has weight $n$, while a dual equatorial cut has weight $m$.

= Surface-code decoding as a random-bond Ising model
{c}
{parent=Surface code}

For independent bit flips, summing the probabilities of all error chains in one syndrome and logical class equals, up to a class-independent factor, the partition function of a random-bond <Ising model>. A reference error fixes bond signs and products of star stabilizers become Ising spin configurations.

= Ground-state splitting of a surface-code cylinder
{parent=Surface code}

On a cylinder with equal anyon-condensing boundaries, the two topological ground states split only through a virtual string implementing a logical operator. A perturbation of strength $h$ produces a splitting of order $J$ times a path-counting factor times $(|h|/J)^d$, where $d$ is the shortest supported logical-string length.

= Toric code
{parent=Surface code}
{wiki}

The toric code has commuting star and plaquette stabilizers. Its electric and magnetic excitations are bosons with mutual-semion statistics, and their fusion is a fermion.

= Surface-code anyon model
{parent=Toric code}

The surface-code anyons are $1,e,m,f=e\times m$. They obey $e^2=m^2=f^2=1$; $e$ and $m$ are bosons with mutual full-braiding phase $-1$, while their composite $f$ is a fermion.
