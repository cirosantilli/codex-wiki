= Foundations of mathematics
{wiki}

Foundations of mathematics asks what our objects mean, what we assume about them, and why an argument establishes its conclusion. <Set theory> gives a common language for collections and <functions>; <mathematical logic> makes the structure of statements and deductions precise. A <mathematical definition> fixes a meaning, an <axiom> supplies an assumption, and a <mathematical proof> explains what follows. Separating these roles makes results reusable: once the <group> axioms are enough for a conclusion, that conclusion applies to every <group>, regardless of how its members are represented.

The assumptions can change the answer to a familiar calculation. Over the <real numbers>, $x^2=x$ factors as $x(x-1)=0$, so $x$ is zero or one. The same reasoning holds in any <integral domain>, because a product can be zero only when a factor is zero. In the <ring> of <integers> modulo six, however, $3^2\equiv3$ and $4^2\equiv4\pmod6$: there are four solutions, represented by $0,1,3,4$. The extra solutions are <idempotents>, and the failed step involves <zero divisors>. Writing the domain is part of explaining the answer.

This precision also reveals surprising possibilities. A two-dimensional grid of <natural numbers> is a <countable set>, while all infinite <binary sequences> form an <uncountable set>. The <Cantor pairing function> supplies a complete enumeration of the first; <Cantor's diagonal argument> defeats every proposed enumeration of the second. Both arguments are short, yet distinguish two sizes of infinity. The subject's appeal is this ability to turn a vague question into one whose assumptions, construction, and limits can all be inspected.

= Mathematical definition
{parent=Foundations of mathematics}

A specification of the meaning of a mathematical term or notation. A structural definition specifies conditions, such as the <group> axioms; a definition by a <universal property> characterizes an object by its arrows. Such a characterization does not by itself prove that the object exists. For example, existence of an <exponential object> is an additional property of a <category>.

= Recursive triple colouring with no computable infinite homogeneous set
{parent=Computability theory}
{title2=$c:[\mathbb N]^3\to2$}

Let $K_s$ be increasing finite stage approximations to a noncomputable <computably enumerable set> $K$. For $x<y<z$, colour the triple zero exactly when $K_y\cap[0,x]=K_z\cap[0,x]$. An infinite homogeneous set has colour zero, since each bounded approximation eventually stabilizes. Its first two elements above any requested bound recover the final approximation at that bound, so the homogeneous set computes $K$. Thus no infinite homogeneous set is <computable>. This illustrates the difference between a <Ramsey's theorem> existence result and an effective construction.

= Jockusch triple coloring computing the halting set
{c}
{parent=Computability theory}
{title2=$c(x,y,z)=\mathbf1\{K_y\cap x\ne K_z\cap x\}$}

Let $K_s$ be a computable increasing finite-stage enumeration of the <halting problem> set $K$. Color $x<y<z$ by whether the approximations below $x$ differ at stages $y,z$. This is a recursive two-color partition of triples. An infinite homogeneous set cannot have color one: for fixed $x$, the finite approximation below $x$ eventually stabilizes. If its color is zero, choose $x$ from that set above an input $n$, then another member $y>x$; agreement with arbitrarily large later stages gives $K(n)=K_y(n)$. Thus every infinite homogeneous set computes $K$, and none is a <recursive set>. This makes the failure of an effective version of <Ramsey's theorem> explicit.

= Function in intension
{parent=Computability theory}

= Functions in intension
{synonym}

A function in intension is a finite program or formal construction description. Its associated <function in extension> is the partial or total input-output map it denotes. A <Gödel number> records the description rather than identifying all descriptions with the same extension.

= Function in extension
{parent=Function in intension}

= Functions in extension
{synonym}

A function in extension is a <function> specified by its domain and the value at each input in that domain. Distinct <functions in intension> can have this same extension. Properties of the extension of an arbitrary program are semantic properties, to which <Rice theorem> applies when the property is nontrivial.

= Binary diagonally noncomputable function
{parent=Computability theory}
{title2=$f:\mathbb N\to\{0,1\},\quad\varphi_e(e)\downarrow\Longrightarrow f(e)\ne\varphi_e(e)$}

A total binary-valued <function> is diagonally noncomputable if it differs from each defined diagonal value in an effective enumeration of <partial computable functions>. Nonbinary diagonal outputs are automatically different. No such <function> is computable: its own program index would contradict the defining condition. Choosing the opposite bit at every defined binary diagonal value proves existence without supplying a computable procedure.

= Bounded simulation of a computation
{parent=Computability theory}

A bounded simulation records whether a specified deterministic program has halted, with a specified output, within a given finite number of steps. This is a primitive recursive predicate of the program code, input and time bound. <Peano arithmetic> can verify genuine finite computation certificates and prove that two different outputs cannot both be the first halting output.

= Productive set
{parent=Computability theory}
{title2=$W_e\subseteq P\Longrightarrow p(e)\downarrow\in P\setminus W_e$}

A set $P$ is productive when a <partial computable function> returns an element of $P$ outside any <computably enumerable> subset supplied by its index. The <function> must halt for every index of a subset of $P$, including finite subsets. Productive sets are not <computably enumerable>.

= Productivity of arithmetic truth
{parent=Productive set}

Uniformly diagonalize against the formula expressing membership in $W_e$ to obtain a sentence saying that its own code is not in $W_e$. If every enumerated sentence is true, this new sentence cannot be enumerated, and hence is true. Its code is a computable new element of <arithmetic truth> outside $W_e$.

= Kolmogorov complexity
{parent=Computability theory}
{c}
{title2=$C_U(\sigma)$}
{wiki}

<Kolmogorov complexity> measures the length of a shortest effective description of an object. Fixing an <optimal description machine> gives an invariant quantity up to an additive machine-dependent constant. <Plain Kolmogorov complexity> is especially convenient for counting descriptions shorter than a <binary string>.

= Plain Kolmogorov complexity
{parent=Kolmogorov complexity}
{title2=$C_U(\sigma)=\min\{|p|:U(p)=\sigma\}$}

For a fixed <optimal description machine> $U$, the <plain Kolmogorov complexity> of a <binary string> is the minimum length of a finite program producing it. The admissible programs need not satisfy a prefix restriction. There are at most $2^n-1$ descriptions shorter than $n$, which is the counting fact behind the existence of <incompressible strings>.

= Incompressible string
{parent=Plain Kolmogorov complexity}
{title2=$C_U(\sigma)\geq|\sigma|$}

A <binary string> is incompressible relative to a fixed <optimal description machine> when its <plain Kolmogorov complexity> is at least its length. A counting argument gives at least one such string at each length, and their set is immune.

= Immunity of incompressible strings
{parent=Incompressible string}

If an infinite <computably enumerable> family contained only <incompressible strings>, select its first enumerated string of length at least $n$. This is a total computable selection rule, and its selected string has a description of length $O(\log n)$ encoding the threshold. For large $n$ that is shorter than the selected string. This contradiction proves immunity.

= Optimal description machine
{parent=Kolmogorov complexity}
{title2=$C_U(\sigma)\leq C_V(\sigma)+c_V$}

A description machine is a partial computable map from finite binary programs to finite binary outputs. It is optimal if, for every other description machine $V$, there is a constant $c_V$ such that $C_U(\sigma)\leq C_V(\sigma)+c_V$. Encoding an interpreter index in a fixed prefix gives the constant-overhead descriptions used in incompressibility arguments.

= Undecidable decision problem
{parent=Computability theory}

= Undecidable
{synonym}

A decision problem for which no <algorithm> terminates with the correct yes-or-no answer on every input. For example, if the <diagonal halting set> had a decision algorithm, a program could halt on its own code exactly when that algorithm says it does not halt, producing a contradiction. An <undecidable decision problem> may still admit a partial procedure that terminates on every yes-instance.

= Finite-injury priority construction
{parent=Computability theory}

A finite-injury priority construction orders countably many requirements so that each has finitely many predecessors. A strategy may discard lower-priority strategies' current witnesses and restraints when it acts. If each requirement acts finitely often after its last such initialization, induction on priority shows that every requirement is injured only finitely often and eventually has a stable strategy. The <Friedberg–Muchnik theorem> is a central example.

= Priority restraint
{parent=Finite-injury priority construction}
{title2=$r\in\mathbb N$}

= Oracle restraint
{synonym}

A <priority restraint> protects finitely many oracle answers by requiring lower-priority enumerations to avoid positions below a numerical bound. Higher-priority action can cancel the <priority restraint> by initializing its owner. After the last such injury, the protected computation is permanent.

= Preservation of a restrained oracle computation
{parent=Priority restraint}
{title2=$B\restriction u=B_s\restriction u\Longrightarrow\Phi_e^B(x)=\Phi_e^{B_s}(x)$}

An oracle computation queries only finitely many positions. If the oracle remains unchanged below its use, the same computation has the same output. In a <finite-injury priority construction>, a successful requirement imposes this bound on lower priorities; the induction that higher priorities stop acting then makes the disagreement permanent.

= Private-witness diagonalization for incomparable enumerable sets
{parent=Finite-injury priority construction}

To prevent a <Turing functional> $\Phi_e^B$ from computing the <indicator function> of an enumerated <set> $A$, reserve a permanently unique fresh witness $x$. On observing a convergent computation with <oracle use> $u$, enumerate $x$ into $A$ if the answer is zero; otherwise keep it out. Restrain subsequent lower-priority enumerations into $B$ below $u$. Higher-priority actions may initialize this strategy and retire its witness, but witnesses are never reused. In a <finite-injury priority construction>, <mathematical induction> on priority shows that the final computation, if observed, remains correct as a computation from the final oracle and disagrees with $A$ at $x$. If no computation is ever observed after the final initialization, the final oracle computation diverges, since any convergent computation uses only finitely many eventually stable oracle bits.

= Friedberg–Muchnik theorem
{c}
{parent=Finite-injury priority construction}
{wiki}

There are <computably enumerable sets> $A,B$ with $A\not\leq_TB$ and $B\not\leq_TA$. A <finite-injury priority construction> alternates requirements preventing oracle programs for $B$ from computing $A$ and programs for $A$ from computing $B$. Each requirement uses a private witness, enumerates it when the opposing computation gives zero, and restrains the oracle segment preserving that disagreement. Verification inducts on priority. Both degrees are noncomputable and strictly below the halting degree, resolving <Post problem>.

The incomparable-degree formulation is stated in https://people.math.wisc.edu/~slempp/papers/prio.pdf[Steffen Lempp's notes, section 1.1].

= Finite injury
{parent=Finite-injury priority construction}

An injury discards a strategy's current witness or restraint when a higher-priority action changes its assumptions. Finite injury means that each strategy experiences only finitely many such resets. The final uninjured strategy must still be checked to satisfy its requirement; finite injury alone is not the conclusion.

= Turing reducibility
{c}
{synonym}

A set $A$ is Turing-reducible to $B$ when an <oracle machine> with membership oracle $B$ computes the characteristic function of $A$. Unlike a <many-one reduction>, it may make adaptive queries and reverse or combine oracle answers.

= Oracle-assisted finite-extension construction
{parent=Turing reduction}

Build an infinite oracle as an increasing union of finite <binary strings>. With the <diagonal halting set> as an oracle, decide whether some finite extension makes a specified <Turing functional> halt with a binary output at a fresh input. In a yes case, preserve that finite computation and commit the opposing set's bit to the opposite value. In a no case, no subsequent infinite extension can yield a characteristic-function value there. Length growth makes the resulting sets computable in the halting oracle.

= Turing functional
{c}
{parent=Turing reduction}
{title2=$\Phi_e^B(x)$}

A Turing functional is a partial computation performed by an <oracle machine>, viewed as a function of both the oracle $B$ and input $x$. Oracle programs admit an effective enumeration. Every convergent computation inspects only a finite part of its oracle, recorded by its <oracle use>.

= Oracle use
{parent=Turing functional}
{title2=$u$}

The use of a convergent oracle computation is one more than its largest queried position, or zero if there are no queries. Preserving the oracle below this number preserves the computation. This finite dependence supplies the restraints in a <finite-injury priority construction>.

= Turing degree
{c}
{parent=Turing reduction}
{wiki}

The Turing degree of a set is its equivalence class under mutual <Turing reducibility>. Degrees inherit the partial order induced by Turing reducibility. The <Friedberg–Muchnik theorem> gives incomparable degrees represented by <computably enumerable sets>.

= Kleene–Post incomparability theorem
{c}
{parent=Turing degree}
{title2=$0<\mathbf a,\mathbf b<0',\quad\mathbf a\not\leq\mathbf b,\ \mathbf b\not\leq\mathbf a$}

There are incomparable <Turing degrees> strictly between the computable degree and the degree of the <diagonal halting set>. An <oracle-assisted finite-extension construction> alternately defeats each <Turing functional> in the two directions. Since the sets are computable in the halting oracle, their degrees are at most $0'$; incomparability makes them nonzero and strictly below $0'$. This theorem does not require the constructed sets to be <computably enumerable>. The <Friedberg–Muchnik theorem> supplies that stronger conclusion.

= Post problem
{c}
{parent=Turing degree}

Post problem asks whether a <computably enumerable set> can have a <Turing degree> strictly between the computable degree and the degree of the <halting problem>. The <Friedberg–Muchnik theorem> answers yes by constructing two incomparable computably enumerable degrees.

= Church–Turing thesis
{c}
{parent=Computability theory}
{wiki}

The Church–Turing thesis asserts that every effectively calculable function is computable by a formal model equivalent to a <Turing machine>. It identifies an informal notion of effective procedure with a mathematical class rather than stating a theorem within one formal system.

= Pairing function
{title2=$\langle x,y\rangle$}
{parent=Computability theory}
{wiki}

A pairing function is a computable bijection from $\mathbb N_0^2$ to $\mathbb N_0$ whose inverse coordinate functions are also computable. Iterating it gives computable encodings of every fixed finite tuple of nonnegative integers.

= Primitive recursive pairing function
{parent=Pairing function}
{title2=$\langle x,y\rangle$}

A <pairing function> whose forward map and two inverse coordinate functions are <primitive recursive functions>. For example, the Cantor pairing function $\langle x,y\rangle=(x+y)(x+y+1)/2+y$ has such inverses: find the diagonal index by <bounded minimization> over integers at most the encoded value, then recover $x,y$ by subtraction. It enables finite tuples to be decoded within a <primitive recursive> construction.

= Decimal trailing-zero pairing function
{parent=Pairing function}
{title2=$g(i,j)=10^i(j+1+\lfloor j/9\rfloor)-1$}

The bracket enumerates the positive <integers> not divisible by $10$. Every positive <integer> has exactly one decomposition into a power of $10$ times such an integer, so this formula is a <bijection> from $\mathbb N^2$ to $\mathbb N$. Subtracting one in the codomain includes zero without requiring a trailing-zero convention for its decimal representation. For the inverse, write $N+1=10^i q$ with $10\nmid q$, then $j=q-1-\lfloor q/10\rfloor$.

= Register machine
{parent=Computability theory}
{wiki}

A register machine has finitely many states and finitely many addressed registers, together with instructions that inspect and modify register contents and change state. A computed partial function is defined by the contents at the halt state.

= String register machine
{parent=Register machine}

In a string register machine, $+_a(k,q)$ appends $a$ to register $k$; $?_a(k,p,q)$ branches according to whether its final letter is $a$; $?_\varepsilon(k,p,q)$ tests emptiness; and $-(k,p,q)$ branches to $p$ when empty, or deletes the final letter and branches to $q$ otherwise.

= Characteristic-function register machine
{parent=String register machine}

A machine computes the characteristic function of a language $X$ when it halts on every input with the one-letter output $1$ for inputs in $X$ and $0$ for inputs outside $X$.

= One-register separation for equal block lengths
{parent=Characteristic-function register machine}

Two string registers can recognize $\{a^nb^n:n>0\}$ by storing one marker per $a$ and removing one per $b$. A machine with only its input register cannot: two different terminal $b$-block lengths eventually reach the same state and remaining prefix, forcing equal outputs for one member and one nonmember.

= String register-machine suffix test
{parent=Characteristic-function register machine}

To recognize words ending in a fixed symbol $a$, test the final input letter, choose one of two erasing loops, and append $1$ after the accepting loop or $0$ after the rejecting loop. The empty word follows the rejecting branch.

= Complementing a characteristic-function register machine
{parent=Characteristic-function register machine}

Replace the original halt state by a continuation state that tests whether its one-letter output is $0$ or $1$, removes it, appends the other symbol, and enters a new halt state. This computes the complement language without changing termination behavior.

= Primitive recursive syntax and arity checking
{parent=Primitive recursive function}

For a decidable coding of finite construction trees, the codes of arity-$i$ <primitive recursive functions in intension> are decidable. Check initial-function tags, then verify the child arities at each composition and recursion node. This is a terminating finite syntax check, distinct from asking whether an arbitrary program's extension happens to be <primitive recursive>.

= Total computable diagonal over primitive recursive syntax
{parent=Primitive recursive syntax and arity checking}
{title2=$d(n)=F_{p_n}(n)+1$}

Enumerate all valid unary <primitive recursive functions in intension> by their decidable codes $p_n$, and interpret each extension $F_{p_n}$. The <function> $d(n)=F_{p_n}(n)+1$ is a <total computable function>, since each finite construction terminates. If it were <primitive recursive>, some $F_{p_j}$ would equal $d$, giving $d(j)=d(j)+1$. Repeated extensions in the syntax enumeration do not affect this argument.

= Primitive recursive function in intension
{parent=Primitive recursive syntax and arity checking}

= Primitive recursive functions in intension
{synonym}

A valid finite construction expression from the <initial functions of recursion theory> by <function composition in recursion theory> and <primitive recursion>. Its extension is a <primitive recursive function>. The construction grammar supplies both a decidable syntax and a total computable interpreter, but no uniformly primitive recursive interpreter for all valid codes.

= Bounded halting predicate
{parent=Primitive recursive function}
{title2=$B(e,x,t)$}

For a fixed effective machine coding, the predicate that program $e$ on input $x$ halts within $t$ steps is <primitive recursive>. Code finite configurations, iterate a total single-step function by <primitive recursion>, and test for the halt state. This supplies a bounded simulation even though the unrestricted <halting problem> is undecidable.

= Bounded minimization
{parent=Primitive recursive function}
{title2=$\mu y\leq b$}

Search over the finite interval $0\leq y\leq b$ for the least witness to a <primitive recursive> predicate, with an explicitly chosen default if there is none. The result is a <primitive recursive function>, by scanning this finite interval using <primitive recursion>. This differs from <unbounded minimization>, which may fail to terminate.

= Predecessor function
{title2=$\operatorname{pred}$}
{parent=Primitive recursive function}

The predecessor function on the nonnegative integers is $\operatorname{pred}(0)=0$ and $\operatorname{pred}(n+1)=n$. This is a <primitive recursive function> by primitive recursion from the zero and projection functions.

= Function composition in recursion theory
{parent=Primitive recursive function}

Given a $m$-ary function $g$ and $k$-ary functions $h_1,\ldots,h_m$, composition forms

= Primitive recursion
{parent=Primitive recursive function}
{wiki}

From $g:\mathbb N^k\to\mathbb N$ and $h:\mathbb N^{k+2}\to\mathbb N$, primitive recursion defines
$$
f(\mathbf x,0)=g(\mathbf x),
\qquad
f(\mathbf x,n+1)=h(\mathbf x,n,f(\mathbf x,n)).
$$

= Composition-only recursive function
{parent=Primitive recursive function}

The functions generated from the initial functions using composition alone are exactly
$$
f(\mathbf x)=c
\quad\hbox{or}\quad
f(\mathbf x)=x_i+c
$$
for a constant $c\in\mathbb N$. Structural induction proves necessity, and iterating the successor function on zero or a projection proves sufficiency.

= Structural induction for primitive recursive functions
{parent=Primitive recursive function}

To prove a property of every primitive recursive function, prove it for the zero, successor, and projection functions, then prove that it is preserved by composition and by primitive recursion. This is structural induction on the finite construction of the function.

= Every primitive recursive function is total
{parent=Structural induction for primitive recursive functions}

The initial functions are total, composition preserves totality, and ordinary induction on the recursion argument shows that primitive recursion applied to total functions is total. Structural induction therefore proves that every primitive recursive function is total.

= Existential bounded representation of a primitive recursive function
{parent=Primitive recursive function}

The graph of every primitive recursive $f:\mathbb N^k\to\mathbb N$ has a formula
$$
y=f(\mathbf x)\quad\Longleftrightarrow\quad
\exists\mathbf z\,\delta(y,\mathbf x,\mathbf z)
$$
in the language of ordered rings, where every quantifier inside $\delta$ is bounded. Composition uses existentially quantified intermediate values, while primitive recursion uses a boundedly checked code for the finite sequence of intermediate values.

= Gödel beta-function sequence coding
{c}
{parent=Existential bounded representation of a primitive recursive function}

The Gödel beta function codes finite sequences by remainders:
$$
\beta(b,c,i)=r
\quad\Longleftrightarrow\quad
r<1+(i+1)c\ \land\ \exists q\leq b\,[b=q(1+(i+1)c)+r].
$$
Choosing $c$ sufficiently large and divisible by the relevant small integers makes the moduli pairwise coprime, so the <Chinese remainder theorem> codes any prescribed finite sequence.

= Factorial graph formula via remainder coding
{parent=Gödel beta-function sequence coding}
{title2=$F(n,y)$}

The graph of the <factorial> function has a fixed-length <first-order formula> in the <language of ordered rings> interpreted on the <natural numbers>. A remainder code records $a_0=1$, $a_n=y$, and $a_{i+1}=(i+1)a_i$ for every $i<n$. Uniqueness of remainders proves $y=n!$; sufficiently large pairwise-coprime moduli and the <Chinese remainder theorem> supply a code for every input. Formula length is independent of the input variable's value, although substituting a numeral adds its encoding length.

= Finite witness array coding
{parent=Gödel beta-function sequence coding}

In a <primitive recursion>, an existential representation of the step <function> may need a different witness tuple at every time. Code each coordinate of the finite witness array by a separate beta-function code pair. All row witnesses then have bounded remainder quantifiers under the bounded time quantifier, while the finitely many code pairs remain in the outer unrestricted existential block.

= Computably enumerable

A set is computably enumerable when a program halts precisely on its members. Equivalently, it is the domain of a <partial computable function> or some algorithm lists its elements.

= Simple set
{parent=Recursively enumerable set}

A <computably enumerable set> is simple when its <complement of a set> is an <immune set>: the complement is infinite and contains no infinite <computably enumerable> subset. Equivalently, it is coinfinite and meets every infinite <computably enumerable set>. A simple set is not decidable.

= Sparse-witness construction of a simple set
{parent=Simple set}

Enumerate all <computably enumerable sets> as $W_e$. For each $e$, once a witness $x>2e$ appears in $W_e$, enumerate one such witness into $X$ and never act for $e$ again. Every infinite $W_e$ supplies a witness. Only requirements $e<n$ can put numbers into $[0,2n]$, so at least $n+1$ numbers in that interval stay outside $X$. Thus $X$ is a <simple set>. The proof uses a numerical bound rather than an infinitude test.

= Immune set
{parent=Recursively enumerable set}

An <immune set> is infinite but contains no infinite <computably enumerable> subset. Thus its infinitude cannot be witnessed by any effective infinite listing that stays entirely inside the set. Finite strings can be treated as natural-number codes for this definition.

= Nonempty computably enumerable sets are primitive recursive ranges
{parent=Recursively enumerable set}
{title2=$X=\operatorname{ran}(f)$}

Every nonempty <computably enumerable set> $X\subseteq\mathbb N$ is the range of a <primitive recursive function> $f:\mathbb N\to\mathbb N$. Choose $x_0\in X$, decode $n=\langle x,t\rangle$ using a <primitive recursive pairing function>, and output $x$ if the recognizing machine halts within $t$ steps, or $x_0$ otherwise. The <bounded halting predicate> makes this function <primitive recursive>, and every member of $X$ occurs for a sufficiently large bound. The <empty set> is excluded because such a function is total.

= Rice theorem
{c}
{synonym}

Every nontrivial extensional property of partial computable functions or computably enumerable languages is undecidable.

= Infinite-domain index set
{parent=Index set}

For an effective enumeration $f_{w,1}$ of unary partial computable functions,
$$
\mathbf{Inf}=\{w:\operatorname{dom}(f_{w,1})\text{ is infinite}\}
$$
is an index set.

= Infinite-domain range-restriction index set
{parent=Infinite-domain index set}

For a nonempty set $X$ of words, the property
$$
w\in\mathbf{Inf}
\quad\hbox{and}\quad
\operatorname{ran}(f_{w,1})\subseteq X
$$
is a nontrivial extensional property of unary partial computable functions: the nowhere-defined function fails it, while any total constant function with value in $X$ satisfies it. The <Rice theorem> therefore makes its index set undecidable.

= Cofinite index set
{parent=Index set}

The cofinite index set contains codes whose enumerable language has finite complement.

= Padding lemma
{parent=Computability theory}

The padding lemma produces infinitely many syntactically distinct program indices for the same computed function or language.

= Dovetailing
{parent=Computability theory}
{wiki=Dovetailing_(computer_science)}

Dovetailing interleaves finite stages of multiple computations so that every computation that halts is eventually observed.

= S-m-n theorem
{c}
{synonym}

The S-m-n theorem says that fixed inputs can be compiled into program codes by a total computable transformation. For every $m,n\geq1$, there is a total computable $s_n^m$ such that
$$
f_{s_n^m(e,x_1,\ldots,x_m),n}(y_1,\ldots,y_n)
=f_{e,m+n}(x_1,\ldots,x_m,y_1,\ldots,y_n)
$$
whenever either side is defined.

= Computable function
{parent=Computability theory}
{wiki}

= Partial computable function
{synonym}

= Partial recursive function
{synonym}

A partial function is computable when a program returns its value on every input in its domain and runs forever on inputs outside its domain.

= Universal partial computable function
{parent=Computable function}
{title2=$U(e,\mathbf x)\simeq\varphi_e(\mathbf x)$}

A universal partial computable function simulates the program with index $e$ on input $\mathbf x$, reproducing both its output and its divergence. Decode the finite program and repeatedly apply its transition rule. This gives a <partial computable function> of the code and inputs. There can be no total computable evaluator whose rows are precisely all <total computable functions>, because $n\mapsto U(n,n)+1$ would be a missing diagonal row.

= Kleene normal form theorem
{parent=Computable function}
{c}
{title2=$f(\mathbf x)=U(\mu s\,[C(\mathbf x,s)=0])$}

For every <partial computable function> $f(\mathbf x)$, there are total <primitive recursive functions> $C,U$ such that
$$
f(\mathbf x)=U(\mu s\,[C(\mathbf x,s)=0]).
$$
Here $C$ is zero exactly on codes of valid halting computation histories for the chosen program and input, and $U$ extracts the final output. Coding finite configurations and finite histories makes checking every local step a bounded primitive recursive operation. If a computation halts, some history code passes and every passing code has the same output; if it does not halt, none passes. This is the usual normal-form version with the program index fixed; a universal predicate can also retain that index as an input.

= Mu operator
{title2=$\mu$}
{parent=Computable function}
{wiki}

= Unbounded minimization
{synonym}

For a partial function $g(\mathbf x,y)$, unbounded minimization defines
$$
f(\mathbf x)=\mu y\,[g(\mathbf x,y)=0]
$$
as the least $y$ at which $g$ is zero, provided the preceding required computations are defined. If no such $y$ is found, $f(\mathbf x)$ is undefined. Closing the <primitive recursive function>[primitive recursive functions] under this operation gives the partial recursive functions.

= Total computable function
{parent=Computable function}

= Recursive function
{synonym}

A <total computable function> is a <computable function> whose domain is the entire input space.

A total computable function is a computable function whose domain contains every allowed input.

= Provably total computable function
{parent=Total computable function}

For a theory of arithmetic $T$ and a program index $e$, the function $\varphi_e$ is provably total in $T$ when $T$ proves its canonical totality sentence
$$
\forall x\,\exists y\,\operatorname{Comp}(e,x,y).
$$
If $T$ is recursively axiomatized, the indices of its provably total functions form a computably enumerable set.

= Truncated computation function
{parent=Computable function}

For a program code $e$, input $x$, and time bound $t$, the truncated computation simulates program $e$ on $x$ for at most $t$ steps and reports either its output or that no halt occurred within the bound. This is a total computable function of $(e,x,t)$.

= Arithmetical hierarchy
{parent=Computability theory}
{wiki}

The arithmetical hierarchy classifies sets by alternating blocks of number quantifiers over computable predicates.

= Bounded quantifier
{parent=Arithmetical hierarchy}

A bounded quantifier has the form $\exists x<t\,\varphi$ or $\forall x<t\,\varphi$, where the term $t$ does not contain $x$. It ranges over a finite initial segment in the standard natural numbers.

= Arithmetic bounded formula
{parent=Bounded quantifier}
{title2=$\Delta_0$}

= Bounded arithmetic formula
{synonym}

An <arithmetic bounded formula> uses only quantifiers bounded by <arithmetic> terms, such as $\exists u<t$ and $\forall u<t$, with the bound not containing the quantified variable. Existential bounded representation of a <primitive recursive function> places all unrestricted existential variables in a single outer block.

= Delta-0 formula
{c}
{title2=$\Delta_0$}
{parent=Bounded quantifier}

A $\Delta_0$ formula is an arithmetical formula in which every quantifier is bounded.

= Sigma-1 formula
{c}
{parent=Arithmetical hierarchy}

A $\Sigma_1$ formula is equivalent to $\exists\mathbf y\,\delta$ with $\delta$ bounded. A $\Pi_1$ formula is equivalent to $\forall\mathbf y\,\delta$ with $\delta$ bounded.

= Pi-1 formula
{c}
{parent=Sigma-1 formula}

= Sigma-1 set
{parent=Arithmetical hierarchy}
{c}

A set $A$ is in $\Sigma_1$ exactly when it is the domain of a partial computable function. Equivalently, there is a computable predicate $R$ such that
$$
x\in A\quad\Longleftrightarrow\quad\exists t\,R(x,t).
$$

= Pi-2 set
{parent=Arithmetical hierarchy}
{c}

A set is in $\Pi_2$ when membership can be written with one universal block followed by one existential block over a computable predicate. Equivalently, in the word-function formulation, there is a partial computable $f$ such that
$$
w\in P\quad\Longleftrightarrow\quad
\forall v\;f(w,v)\mathbin\downarrow.
$$

= Totality problem
{parent=Pi-2 set}

For an effective enumeration of computably enumerable languages $W_v$, the totality problem is
$$
\mathbf{Tot}=\{v:W_v=\mathbb W\}.
$$
It is $\Pi_2$-complete: a $\Pi_2$ condition $w\in P\iff\forall x\,f(w,x)\downarrow$ maps effectively to a program whose domain is $\{x:f(w,x)\downarrow\}$.

= Totality problem is not computably enumerable
{parent=Totality problem}

If all indices of total computable functions could be enumerated as $e_0,e_1,\ldots$, then
$$
g(n)=\varphi_{e_n}(n)+1
$$
would be total and computable. Some $e_k$ would index $g$, giving $g(k)=g(k)+1$. Thus the totality problem is not computably enumerable.

= Recursively inseparable sets
{parent=Computability theory}

Disjoint sets $A,B\subseteq\mathbb N$ are recursively inseparable when no recursive set $C$ satisfies $A\subseteq C$ and $B\cap C=\varnothing$.

= Lambda calculus
{title2=$\lambda$-calculus}
{parent=Computability theory}
{wiki}

Lambda calculus forms terms from variables, abstraction, and application, and computes by substitution.

= Lambda model
{parent=Lambda calculus}

A lambda model interprets variables, <lambda application> and <lambda abstraction> so that <capture-avoiding substitution> agrees with environments and all <beta equivalence> equations hold. A <reflexive domain> gives such an interpretation. Validity of <eta conversion> requires an extra inverse law and does not follow merely from a retraction.

= Reflexive domain
{parent=Lambda model}

A <pointed complete partial order> $D$ is reflexive when there are <Scott continuous maps> $e:[D\to D]\to D$ and $p:D\to[D\to D]$ with $p\circ e=\mathrm{id}$. Define $a\cdot b=p(a)(b)$ and interpret <lambda abstraction> using $e$. The inverse law gives beta soundness; $e\circ p=\mathrm{id}$ additionally gives eta soundness.

= Graph model of lambda calculus
{parent=Reflexive domain}
{title2=$P\omega$}

= Pomega model
{synonym}
{c}

Let $P\omega=\mathcal P(\mathbb N)$ ordered by <subset>. Encode a finite subset $u$ and output $n$ by a natural number $\langle u,n\rangle$. Define $a\cdot b=\{n:\exists u\subseteq b\text{ finite},\ \langle u,n\rangle\in a\}$ and $e(f)=\{\langle u,n\rangle:n\in f(u)\}$. Every <Scott continuous map> satisfies $f(b)=\bigcup_{u\subseteq b\text{ finite}}f(u)$, proving that application is the projection of a retraction. <Lambda abstraction> has graph $\{\langle u,n\rangle:n\in\llbracket M\rrbracket_{\rho[x:=u]}\}$.

= Approximation theorem for the graph model
{parent=Graph model of lambda calculus}
{title2=$\llbracket M\rrbracket_\rho=\bigcup_{A\in\mathcal A(M)}\llbracket A\rrbracket_\rho$}

The interpretation of a <lambda term> in the <graph model of lambda calculus> is the union of the interpretations of all its <finite Böhm approximants>. Every finite indexed interpretation reduces monotonically to an indexed normal approximant. Taking the union over all occurrence indices gives one inclusion; replacing subterms by bottom and using beta soundness gives the other. This identifies denotational information with finite observable parts of a <Böhm tree>.

= Indexed lambda term
{parent=Graph model of lambda calculus}
{title2=$\Lambda_\bot^{\mathbb N}$}

An indexed <lambda term> assigns a natural number to every subterm occurrence; one also admits a constant $\bot$ with empty interpretation. In the <graph model of lambda calculus>, every syntax constructor is interpreted as usual and then intersected with $\{0,\ldots,n\}$ at its occurrence index $n$. All indexed interpretations are finite subsets of the unindexed interpretation, and their directed union recovers that interpretation.

= Indexed beta reduction
{parent=Indexed lambda term}

Use the binary finite-set encoding $e_k$ and Cantor code $\langle k,t\rangle$. Contracting $(\lambda x.P^n)^{m+1}Q^p$ gives the substituted body with its root index lowered by taking the minimum with $\min(m,n)$, replacing each occurrence $x^r$ by a copy of $Q$ with root index $\min(m,p,r)$. A zero-indexed abstraction instead substitutes $\bot$ and gives the body root index zero. Indices strictly budget the argument information that can be used by application. Finite-witness inequalities for the pairing code prove that indexed reduction increases the interpretation, although it can decrease the underlying <Böhm tree>.

= Lambda term
{parent=Lambda calculus}

A lambda term is a variable, an abstraction $\lambda x.M$, or an application $MN$, formed recursively from lambda terms $M$ and $N$.

= Lambda application
{parent=Lambda term}

Application $MN$ applies the <lambda term> $M$ to the <lambda term> $N$. It associates to the left: $MNP=(MN)P$. Together with variables and <lambda abstraction>, it generates all <lambda terms>.

= Lambda abstraction
{parent=Lambda term}
{title2=$\lambda x.t$}

A lambda abstraction $\lambda x.t$ binds the variable $x$ in the <lambda term> $t$. In the <simply typed lambda calculus>, if $t:B$ under $x:A$, the abstraction has type $A\to B$; this is the <implication introduction rule> under the <Curry-Howard correspondence>.

= Untyped lambda calculus
{parent=Lambda calculus}

The untyped lambda calculus forms terms from variables, abstraction, and application without assigning types.

= Eta conversion
{parent=Untyped lambda calculus}
{title2=$\lambda x.Mx\equiv_\eta M\quad(x\notin FV(M))$}

Eta conversion expresses extensionality for a <lambda abstraction> whose fresh argument is only passed to a function. The side condition prevents removal of a genuine dependency. In a categorical model with $D\cong D^D$, the inverse laws for <currying> and evaluation validate this conversion as well as <beta reduction>.

= Combinatory logic
{parent=Untyped lambda calculus}
{wiki}

Combinatory logic describes computation by application and fixed combinator constants, eliminating bound variables through <bracket abstraction>. Its intensional weak reduction does not identify every pair of terms that becomes beta-equivalent after translation into <lambda calculus>.

= Bracket abstraction
{parent=Combinatory logic}
{title2=$[x]x=I,\quad[x]T=KT\ (x\notin FV(T)),\quad[x](PQ)=S([x]P)([x]Q)$}

Bracket abstraction removes a free variable from a <combinatory logic term>. The displayed clauses are applied in that order, giving $FV([x]T)=FV(T)\setminus\{x\}$ and $([x]T)A\to^*T[x:=A]$. Under the standard lambda expansions of $S,K,I$, the result is beta-equivalent to $\lambda x.T$. The recursive translation of lambda terms therefore preserves variables and application and reflects weak equivalence, but need not preserve all beta equivalences.

= Combinatory logic term
{parent=Combinatory logic}
{title2=$T::=x\mid S\mid K\mid I\mid TT$}

= CL-term
{c}
{synonym}

A finite applicative expression over free variables and the combinator constants $S,K,I$, with application associating to the left. One may instead take $I$ as the abbreviation $SKK$. There is no variable binder in this syntax.

= Weak combinatory reduction
{parent=Combinatory logic term}
{title2=$KAB\to A,\quad SABC\to AC(BC),\quad IA\to A$}

Weak combinatory reduction closes the displayed contractions under application contexts. Weak equivalence is its reflexive, symmetric, transitive closure. The adjective distinguishes this syntactic reduction from an extensional rule equating functions that agree after an extra argument. A weak normal form has no subexpression matching a contraction rule; a partially applied combinator can be such a normal form.

= Head normal form
{parent=Untyped lambda calculus}

A <lambda term> has head normal form when it beta-reduces to a term $\lambda x_1\cdots x_k.\,yM_1\cdots M_r$ with a variable $y$ at the head. The argument terms need not be in <beta-normal form>. A term with no head normal form cannot be beta-equivalent to a <Church numeral>.

= Böhm tree
{parent=Head normal form}
{c}
{title2=$BT(M)$}

The Böhm tree of an <unsolvable lambda term> is $\bot$. If $M\to_\beta^*\lambda x_1\cdots x_n.yM_1\cdots M_r$ is a <head normal form>, its Böhm tree has root label $\lambda x_1\cdots x_n.y$ and ordered children $BT(M_1),\ldots,BT(M_r)$. The tree may be infinite. <Church-Rosser theorem> and <alpha equivalence> make this independent of the selected head reduct.

= Finite Böhm approximant
{parent=Böhm tree}

A finite Böhm approximant is $\bot$ or a finite <lambda term> in the grammar $\lambda x_1\cdots x_n.yA_1\cdots A_r$, obtained by pruning a <Böhm tree>. Equivalently it is a beta-bottom normal form obtained from a beta-equivalent term by replacing subterms by $\bot$; bottom reduction contracts $\bot N$ and $\lambda x.\bot$ to $\bot$. Its interpretation in the <graph model of lambda calculus> is included in that of the original term.

= Böhm transformation
{parent=Böhm tree}
{c}

A Böhm transformation is a finite composition of <capture-avoiding substitutions> and <lambda applications> to chosen auxiliary terms. It can extract a finite-address subtree of a <Böhm tree> as a substitution instance of the corresponding argument term.

= Böhm-out lemma
{parent=Böhm transformation}
{c}

For a finite path in a <Böhm tree>, choose $q$ at least the head arity at every preceding node. Replace relevant variables by $U_q=\lambda z_1\cdots z_q w.wz_1\cdots z_q$. After exposing each node, supply its initial bound variables with $U_q$, pad its $m$ arguments to $q$, and apply the projection $\lambda z_1\cdots z_q.z_i$ selecting the next child. Each step returns that child with accumulated substitutions, so iteration reaches a substitution instance of the chosen subtree. Tupling preserves all children until selection, even when the same variable occurs at several nodes.

= Böhm separation theorem
{parent=Böhm-out lemma}
{c}

Two distinct closed <lambda terms> in normal form for both <beta reduction> and <eta conversion> admit a separating context that maps them respectively to the two <Church Booleans>. Finite <Böhm trees> and the <Böhm-out lemma> isolate their first genuine head disagreement. The qualification about <eta conversion> matters: distinct beta-normal forms that are eta-equivalent cannot be separated this way.

= Unsolvable lambda term
{parent=Head normal form}

An unsolvable <lambda term> has no <head normal form>, equivalently it is not a <solvable lambda term>. <Capture-avoiding substitution> and <lambda application> preserve unsolvability: until a head variable appears, head contractions proceed within the original term and cannot inspect the supplied terms.

= Easy lambda term
{parent=Unsolvable lambda term}

A closed <lambda term> $E$ is easy if adjoining $E=M$ to the equations of <beta equivalence> remains nontrivial for every closed <lambda term> $M$. If $E$ is easy, then $ET$ is easy for every closed $T$: use the consistent equation $E=\lambda x.M$ to obtain $ET=M$. Since $I$ is not easy and solvability produces $I$ by applications, easy terms are unsolvable. The converse need not hold.

= Solvable lambda term
{parent=Head normal form}

A <lambda term> is solvable if its closure by <lambda abstractions> over its <free variables> can be applied to finitely many closed <lambda terms> to obtain $I=\lambda x.x$ in <beta equivalence>. This is equivalent to having a <head normal form>. A head variable in a <head normal form> can be replaced by a projection returning $I$; conversely <standardization theorem for beta reduction> traces any successful head computation back to a head variable of the original term.

= Beta reduction
{title2=$\beta$-reduction}
{parent=Untyped lambda calculus}

Beta reduction performs <capture-avoiding substitution>:
$$
(\lambda x.M)N\longrightarrow_\beta M[x:=N].
$$

= Diamond property of a reduction relation
{parent=Beta reduction}

= Diamond property
{synonym}

A reduction relation $\to$ has the diamond property if $a\to b$ and $a\to c$ imply a common one-step successor $b\to d\leftarrow c$. For relations allowing an identity step, the same definition includes zero-length joins. A finite grid of these diamonds proves confluence of $\to^*$. Ordinary one-step <beta reduction> fails this property because contracting before duplication can save two separate contractions.

= Church-Rosser property of a reduction relation
{parent=Diamond property of a reduction relation}
{c}

= Church-Rosser property
{synonym}
{c}

A reduction relation has the Church-Rosser property when its <equivalence relation> generated by forward and backward steps satisfies $b\leftrightarrow^*c\Rightarrow\exists d\;(b\to^*d\leftarrow^*c)$. It is equivalent to confluence of $\to^*$. The <Church-Rosser theorem> establishes it for <beta reduction>.

= Parallel beta reduction
{parent=Beta reduction}
{title2=$M\Rightarrow N$}

Parallel <beta reduction> permits simultaneous reduction in the body of a <lambda abstraction> and both sides of an application, together with $(\lambda x.M)N\Rightarrow M'[x:=N']$ when $M\Rightarrow M'$ and $N\Rightarrow N'$. Variables reduce to themselves. Its <capture-avoiding substitution> lemma is $M\Rightarrow M',\ N\Rightarrow N'\Rightarrow M[x:=N]\Rightarrow M'[x:=N']$. Its transitive closure equals ordinary finite beta reduction, while its one-step diamond property yields the <Church-Rosser theorem>.

= Complete development of a lambda term
{parent=Parallel beta reduction}
{title2=$M^\bullet$}

Define $x^\bullet=x$, $(\lambda x.M)^\bullet=\lambda x.M^\bullet$, and develop an application by contracting its root when that root is syntactically a <beta-redex>: $((\lambda x.M)N)^\bullet=M^\bullet[x:=N^\bullet]$. Otherwise $(MN)^\bullet=M^\bullet N^\bullet$. Newly created root redexes need not be contracted. Induction with the substitution lemma proves that if $M\Rightarrow N$, then $N\Rightarrow M^\bullet$. Thus any two parallel reducts share this reduct.

= Normal-order beta reduction
{parent=Beta reduction}

Normal-order beta reduction contracts the leftmost outermost <beta-redex>. If a <lambda term> has a <beta-normal form>, this strategy reaches it. It is useful for implementing <Church Boolean> conditionals because an unused branch can be discarded before it is evaluated.

= Standardization theorem for beta reduction
{parent=Normal-order beta reduction}

A finite <beta reduction> can be rearranged into standard order, contracting earlier residual redexes before later ones. In particular, a <lambda term> with a <head normal form> reaches one by head reduction, and a term with a <beta-normal form> reaches it by <normal-order beta reduction>. Head reduction contracts the outermost redex on the left application spine, including under initial <lambda abstractions>.

= Normal-order normalization theorem
{parent=Normal-order beta reduction}

If an untyped <lambda term> has a <beta-normal form>, leftmost outermost <beta reduction> reaches a normal form. Thus an infinite normal-order computation certifies the absence of a <beta-normal form>. This is the normalization result needed to make a lambda simulation respect undefined outputs.

= Capture-avoiding substitution
{parent=Beta reduction}

Capture-avoiding substitution $M[x:=N]$ replaces the free occurrences of $x$ in $M$ by $N$, renaming bound variables when necessary so that free variables of $N$ do not become bound.

= Beta equivalence
{title2=$\beta$-equivalence}
{parent=Beta reduction}

= Beta equivalent
{synonym}

Beta equivalence is the smallest equivalence relation containing <beta reduction>; equivalently, $M\equiv_\beta N$ when a finite sequence of beta reductions and reversed beta reductions connects $M$ and $N$.

= Undecidability of beta equivalence
{parent=Beta equivalence}

<Beta equivalence> is <semidecidable>: enumerate finite conversion proofs. It is not decidable. A proposed total numeral-valued classifier of two nonempty disjoint <beta equivalence> classes can be reversed by a <Church Boolean> selector; a <self-quoting fixed point> of this reversal then belongs to the opposite class from the classifier output.

= Beta-redex
{title2=$\beta$-redex}

A beta-redex is a subterm of the form $(\lambda x.M)N$, to which <beta reduction> can be applied.

= Beta-normal form
{title2=$\beta$-normal form}
{parent=Beta reduction}

A lambda term is in beta-normal form when it contains no <beta-redex>.

= Combinator

A combinator is a lambda term with no <free variable>[free variables].

The omega combinator is the divergent <untyped lambda calculus> term

\Omega=(\lambda x.xx)(\lambda x.xx),

= Fixed-point combinator
{parent=Combinator}
{wiki}

= Y combinator
{c}
{synonym}

An untyped lambda term $Y$ is a fixed-point combinator when $Yf\equiv_\beta f(Yf)$ for every term $f$.

= Turing fixed-point combinator
{parent=Fixed-point combinator}
{c}
{title2=$\Theta$}

Put $D=\lambda x f.f(xxf)$ and $\Theta=DD$. Then $\Theta f\to_\beta^*f(\Theta f)$. Unlike the <Curry fixed-point combinator>, every finite reduct retains a closed subterm $DD$. Contracting this subterm recreates one; every other generated redex substitutes a variable and preserves it. The <Church-Rosser theorem> therefore proves $Y\not\equiv_\beta\Theta$.

= Curry fixed-point combinator
{parent=Fixed-point combinator}
{c}
{title2=$Y$}

With $A_f=\lambda x.f(xx)$, the <combinator> $Y=\lambda f.A_fA_f$ satisfies $Yf\equiv_\beta f(Yf)$. Every finite reduct of $Y$ is, up to <alpha equivalence>, $\lambda f.f^n(A_fA_f)$: the remaining copy of $A_fA_f$ is its only <beta-redex>.

= Fixed-point theorem for the untyped lambda calculus
{parent=Fixed-point combinator}

Every lambda term $F$ has a fixed point: the term
$$
X=(\lambda x.F(xx))(\lambda x.F(xx))
$$
satisfies $X\equiv_\beta F(X)$. Equivalently, a <fixed-point combinator> such as
$$
Y=\lambda f.(\lambda x.f(xx))(\lambda x.f(xx))
$$
satisfies $YF\equiv_\beta F(YF)$ for every $F$.

= Recursively enumerable fixed-point combinators
{parent=Fixed-point combinator}

The set of <fixed-point combinator>[fixed-point combinators] is <recursively enumerable set>[recursively enumerable]. Enumerate closed lambda terms and finite proofs of <beta equivalence>, and output $Y$ whenever a proof of $Yf\equiv_\beta f(Yf)$ appears for a fresh variable $f$.

= Church encoding
{c}
{parent=Lambda calculus}
{wiki}

<Church encoding> represents data and operations as terms of the <lambda calculus>. A <Church numeral> represents a natural number by repeated function application; a <Church Boolean> selects one of two arguments.

= Church numeral
{title2=$c_n$}
{c}
{parent=Church encoding}

The Church numeral $c_n=\lambda f.\lambda x.f^n x$ encodes the natural number $n$ by iteration.

= Church numeral arithmetic
{c}
{parent=Church numeral}

<Church numeral> successor, addition, multiplication, and exponentiation are represented by $\lambda nfx.f(nfx)$, $\lambda mnfx.mf(nfx)$, $\lambda mnfx.m(nf)x$, and $\lambda mnfx.(nm)fx$. The last term takes the base first and the exponent second. Its outer abstractions preserve the usual numeral normal form at exponent zero, implementing $m^0=1$, including $0^0=1$. At base type $A$, exponentiation uses an exponent at Church type $C_{A\to A}$ and a base at $C_A=(A\to A)\to A\to A$.

= Church numeral zero test
{parent=Church numeral}
{c}
{title2=$\mathsf{Zero}$}

The <lambda term>
$$
\mathsf{Zero}=\lambda n.n(\lambda z.\mathsf F)\mathsf T
$$
returns the <Church Boolean> $\mathsf T$ on $c_0$ and $\mathsf F$ on every positive <Church numeral>. Zero iterations leave the initial true value, while at least one iteration replaces it by false. <Normal-order beta reduction> evaluates a numeral conditional without evaluating an unchosen branch.

= Church pair
{parent=Church numeral}
{c}
{title2=$\mathsf{Pair}=\lambda a b p.pab$}

With the <Church Booleans> $\mathsf T=\lambda a b.a$ and $\mathsf F=\lambda a b.b$, encode a pair by
$$
\mathsf{Pair}=\lambda a b p.pab,\qquad \mathsf{Fst}=\lambda p.p\mathsf T,\qquad \mathsf{Snd}=\lambda p.p\mathsf F.
$$
Then $\mathsf{Fst}(\mathsf{Pair}\,A\,B)\to_\beta^*A$ and the second projection similarly returns $B$. Pairing an iteration counter with a computed value implements <primitive recursion> using only <Church numeral> iteration.

= Lambda-definable function
{parent=Church numeral}

A function $g:\mathbb N^k\to\mathbb N$ is lambda-definable when some <combinator> $G$ satisfies
$$
G c_{n_1}\cdots c_{n_k}\equiv_\beta c_{g(n_1,\ldots,n_k)}
$$
for every tuple of natural numbers.

= Lambda definition of the successor function
{parent=Lambda-definable function}

The <successor function> is lambda-defined on <Church numeral>[Church numerals] by
$$
\operatorname{Succ}=\lambda n.\lambda f.\lambda x.f(nfx),
$$
because $\operatorname{Succ}\,c_n\equiv_\beta c_{n+1}$.

= Lambda definition of primitive recursion
{parent=Lambda-definable function}

Using a <fixed-point combinator>, Church Boolean conditionals, a zero test, and a predecessor term, lambda-definable $g$ and $h$ give
$$
R\mathbf x0=g(\mathbf x),
\qquad
R\mathbf x(n+1)=h(\mathbf x,n,R\mathbf x n).
$$
Normal-order beta reduction evaluates only the selected conditional branch, so this term implements primitive recursion on <Church numeral>[Church numerals].

= Lambda definition of primitive recursion by pair iteration
{parent=Lambda definition of primitive recursion}

If total <functions> $g$ and $h$ are represented by <lambda terms> $G,H$, define
$$
\mathsf{Step}_{\mathbf x}=\lambda p.\mathsf{Pair}(\mathsf{Succ}(\mathsf{Fst}\,p))(H\mathbf x(\mathsf{Fst}\,p)(\mathsf{Snd}\,p)),
$$
and
$$
R=\lambda\mathbf x n.\mathsf{Snd}\bigl(n\mathsf{Step}_{\mathbf x}(\mathsf{Pair}\,c_0\,(G\mathbf x))\bigr).
$$
After $j$ iterations the <Church pair> holds $(c_j,c_{f(\mathbf x,j)})$, proved by <mathematical induction> using the defining recursion equations. Consequently $R$ represents the total <primitive recursive function> $f$. This statement concerns total inputs and total recursion constituents; it is not an unguarded composition theorem for arbitrary partial <functions>.

= Lambda-definable partial function
{parent=Lambda-definable function}

A partial function is lambda-definable when one lambda term maps Church numerals in its domain to the numeral of the output and produces no numeral on inputs outside its domain.

= Lambda representation of partial computable functions
{parent=Lambda-definable partial function}

Every <partial computable function> is represented on <Church numerals> by a closed <untyped lambda calculus> term. First represent all <primitive recursive functions> using zero, successor, projections, composition and <lambda definition of primitive recursion by pair iteration>. Apply the <Kleene normal form theorem> and search successive history codes with a <fixed-point combinator>. Test the represented total predicate using a <Church numeral zero test>; return the decoded output only on the true branch. If no history passes, normal-order head reduction continues the search indefinitely and the term has no <head normal form>, so cannot be in <beta equivalence> with a <Church numeral>. This avoids the incorrect assumption that a lazy outer <function> must evaluate a divergent argument in an unguarded composition.

= Lambda simulation of a Turing machine
{parent=Lambda representation of partial computable functions}
{title2=$\mathsf{Run}=Y(\lambda r c.\mathsf{Halt}\,c\,(\mathsf{Out}\,c)\,(r(\mathsf{Next}\,c)))$}

Represent total machine configuration transitions and tests on <Church numerals> and <Church pairs>, then use a <fixed-point combinator> to iterate until the halting test selects the output. Normal-order <beta reduction> follows the computation. A nonhalting machine gives an infinite required reduction, so the <normal-order normalization theorem> rules out a numeral normal form.

= Strict sequencing of partial numeral computations
{parent=Lambda-definable partial function}
{title2=$\mathrm{Force}=\lambda n.\lambda k.n(\lambda z.z)k$}

The term $\mathrm{Force}\,c_m\,K$ beta-reduces to $K$ for every <Church numeral> $c_m$. If its first argument has no <head normal form>, the whole application has no head normal form. Nesting this operation forces each represented inner computation before applying an outer function, implementing <composition of partial functions> even when an outer projection would discard an argument. The same guard makes <lambda definition of primitive recursion> strict in the preceding recursive value.

= Lambda definition of unbounded minimization
{parent=Lambda-definable partial function}

For a lambda-definable partial $g(\mathbf x,n)$, a fixed-point search term tests $n=0,1,2,\ldots$ and returns the first $n$ for which $g(\mathbf x,n)=0$. If no such value is reached, reduction produces no Church numeral. This realizes <unbounded minimization> and therefore makes every partial recursive function lambda-definable.

= Formal grammar
{parent=Formal language theory}
{wiki}

A grammar $(N,\Sigma,P,S)$ generates the terminal words reachable from $S$ by finitely many productions.

= Variable-based grammar
{parent=Formal grammar}

A variable-based grammar has disjoint finite terminal and variable alphabets $\Sigma,V$, a start variable $S\in V$, and productions $\alpha\to\beta$ in which $\alpha,\beta\in(\Sigma\cup V)^*$ and $\alpha$ contains at least one variable.

= Unreachable nonterminal
{parent=Variable-based grammar}

A nonterminal is unreachable when no word derivable from the start symbol contains it. Productions whose left sides are unreachable do not affect the generated <formal language theory>[language].

= Nonproductive nonterminal
{parent=Variable-based grammar}

A nonterminal is nonproductive when no word derived from it consists entirely of terminal symbols. Every derivation containing such a symbol therefore fails to produce a word in the generated <formal language theory>[language].

= Regular grammar
{parent=Variable-based grammar}
{wiki}

A right-linear regular grammar has productions of the forms $A\to wB$ and $A\to w$, where $A,B$ are variables and $w$ is a terminal word.

= Sentential form of a right-linear regular grammar
{parent=Regular grammar}

Every sentential form reachable from the start variable of a right-linear grammar is either a terminal word $w$ or $wA$, where $A$ is the unique variable and occurs at the right end.

= Accessible variable of a regular grammar
{parent=Regular grammar}

A variable $A$ is accessible when $S\Rightarrow^*wA$ for some terminal word $w$.

= Looping variable of a regular grammar
{parent=Regular grammar}

A variable $A$ is looping when $A\Rightarrow^*wA$ for some terminal word $w$ through a nonempty derivation.

= Terminable variable of a regular grammar
{parent=Regular grammar}

A variable $A$ is terminable when $A\Rightarrow^*w$ for some terminal word $w$.

= Accessible looping terminable variable criterion
{parent=Regular grammar}

If a finite right-linear grammar generates an infinite language, some variable is accessible, looping, and terminable. It is the repeated variable on a sufficiently long accepting derivation.

= Concatenation grammar
{parent=Variable-based grammar}

For grammars $G=(\Sigma,V,P,S)$ and $G'=(\Sigma,V',P',S')$ with disjoint variable sets, introduce a new variable $S_0$ and set
$$
H=(\Sigma,V\cup V'\cup\{S_0\},
P\cup P'\cup\{S_0\to SS'\},S_0).
$$
If both input grammars are variable based, then $L(H)=L(G)L(G')$.

= Regular concatenation grammar
{parent=Concatenation grammar}

Retain every production $\alpha\to\beta$ of $P$ whose right-hand side contains a variable, replace every production $\alpha\to w$ with $w\in\Sigma^*$ by $\alpha\to wS'$, include $P'$, and use $S$ as start variable. If $G$ and $G'$ are right-linear, the resulting grammar is right-linear and generates $L(G)L(G')$.

= Failure of the regular concatenation construction for a nonregular grammar
{parent=Regular concatenation grammar}

The regular construction relies on a regular derivation having exactly one terminal rule, at its end. In a general variable-based grammar several variables may each use terminal productions, so replacing every such production can introduce several copies of the second start variable.

= Concatenation grammar need not be regular
{parent=Concatenation grammar}

Even if both input grammars are regular, the added production $S_0\to SS'$ has two variables on its right-hand side and therefore need not be a regular production.

= Empty word

{parent=Formal language theory}

= Empty string
{synonym}

The empty word is the unique word of length zero. It is the identity element for concatenation.

= Context-free language
{parent=Formal language theory}
{wiki}

A grammar is context-free when each production has one nonterminal on its left.

= Context-free grammar
{parent=Context-free language}
{wiki}

A context-free grammar consists of terminal and nonterminal alphabets, a start symbol, and productions whose left side is one nonterminal. A derivation records the order of substitutions, while a parse tree records their hierarchical structure, so several derivations can represent one parse tree.

= Right-linear grammar
{parent=Context-free grammar}

A right-linear grammar has productions of the form $A\to wB$ or $A\to w$, where $A,B$ are nonterminals and $w$ is a terminal word, possibly empty. Each right-hand side has at most one nonterminal, at its right end. Such grammars generate exactly <regular languages>: regard nonterminals as states and expand each terminal word into a finite path to another state or an accepting endpoint. Conversely the transition graph of a <deterministic finite automaton> gives these productions directly.

= Terminal symbol
{parent=Context-free grammar}

A terminal symbol belongs to the alphabet of completed words and is not replaced by a grammar production.

= Production rule
{parent=Context-free grammar}

A production rule specifies a permitted replacement during a <grammar derivation>. In a <context-free grammar> it has the form $A\to\alpha$, with one nonterminal $A$ on the left.

= Sentence of a formal grammar
{parent=Context-free grammar}

A sentence of a grammar is a terminal word derivable from its start symbol.

= Grammar derivation
{parent=Context-free grammar}

A grammar derivation is a finite sequence of words in which each step replaces one occurrence of a production's left side by its right side. A leftmost derivation always replaces the leftmost available nonterminal.

= Parse tree
{parent=Context-free grammar}
{wiki}

A parse tree places the start symbol at its root, the symbols on the right side of a production at the children of its left-side nonterminal, and terminal symbols at its leaves. Reading the leaves from left to right gives the tree's yield.

= Equivalent grammar
{parent=Context-free grammar}

Two grammars are equivalent when they generate the same formal language.

= Isomorphic grammar
{parent=Equivalent grammar}

Two grammars over a common terminal alphabet are isomorphic when a bijection between their nonterminal alphabets maps one start symbol to the other and maps their productions bijectively after being extended to fix every terminal symbol. Isomorphic grammars are <equivalent grammar>[equivalent].

= Chomsky normal form
{parent=Context-free grammar}
{c}
{wiki}

A context-free grammar is in Chomsky normal form when every production has the form $A\to BC$ or $A\to a$, with $A,B,C$ nonterminals and $a$ a terminal. If the empty word belongs to the language, one commonly also permits the exceptional rule $S\to\epsilon$ under the usual restriction on the start symbol.

= Epsilon production
{title2=$A\to\epsilon$}
{parent=Chomsky normal form}

An epsilon production is a grammar production whose right-hand side is the empty word.

= Unit production
{title2=$A\to B$}
{parent=Chomsky normal form}

A unit production replaces one nonterminal by one nonterminal and emits no terminal symbols.

= Conversion of a context-free grammar to Chomsky normal form
{parent=Chomsky normal form}

To convert a <context-free grammar> to <Chomsky normal form>, first add a fresh start symbol. Remove <epsilon productions>, retaining the exceptional start production only when the empty word is to remain in the language; then remove <unit productions> and symbols that cannot participate in a terminal derivation. Replace each terminal occurring in a right-hand side of length at least two by a new nonterminal that produces that terminal. Finally split every right-hand side of length greater than two into binary productions using fresh nonterminals.

= Chomsky-normal-form derivation length
{parent=Chomsky normal form}
{c}

A Chomsky-normal-form parse tree for a word of length $n\geq1$ has $n$ terminal productions and $n-1$ binary productions. Every derivation represented by the tree therefore has exactly $2n-1$ steps.

= CYK algorithm
{c}
{parent=Chomsky normal form}
{wiki}

The CYK algorithm decides membership in a <context-free language> given by a grammar in <Chomsky normal form>. It records, for every substring, the nonterminals that derive that substring and combines adjacent substrings using binary productions. For a word of length $n$ and a fixed grammar, it runs in $O(n^3)$ time.

= Weak Chomsky normal form
{parent=Chomsky normal form}
{c}

Weak Chomsky normal form additionally permits ternary productions $A\to BCD$. Compressing a two-step pattern $A\to BE$, $E\to CD$ into $A\to BCD$ preserves its generated yields whenever the intermediate variable has no other role, and saves one derivation step each time the pattern is used.

= Context-free grammar for even palindromes
{parent=Context-free language}

The productions $S\to0S0\mid1S1\mid00\mid11$ generate exactly the nonempty binary palindromes of even length.

= Intersection of a context-free language with a regular language
{parent=Context-free language}

= Closure of context-free languages under regular intersection
{synonym}

The intersection of a context-free language with a regular language is context-free, because a pushdown automaton and a finite automaton can be run in product.

= Closure of context-free languages under concatenation
{parent=Context-free language}

If context-free grammars with disjoint nonterminal alphabets have start symbols $S_1,S_2$, adjoining a new start symbol and the production $S\to S_1S_2$ gives a context-free grammar for the concatenation of their languages.

= Closure of context-free languages under Kleene star
{parent=Context-free language}

If a <context-free grammar> for $L$ has start symbol $S$, adjoining a new start symbol $S_0$ and productions $S_0\to\epsilon\mid SS_0$ gives a context-free grammar for the <Kleene star> $L^*$.

= Unary context-free language is regular
{parent=Context-free language}

Every <context-free language> over a one-symbol alphabet is a <regular language>. Equivalently, the set of word lengths of a unary context-free language is ultimately periodic. This follows, for example, from the one-dimensional case of Parikh's theorem.

= Nested-count context-free grammar
{parent=Context-free language}

A context-free grammar can enforce sums such as $0^n1^m0^{n+m}$ by nesting one matched terminal pair for each independent count.

= Nested two-pair count language
{parent=Nested-count context-free grammar}

The language
$$
\{a^{4r}b^{5s}c^{2s}d^{3r}:r,s\geq0\}
$$
is context-free. The grammar
$$
S\to aaaaSddd\mid T,
\qquad
T\to bbbbbTcc\mid\epsilon
$$
nests the $a,d$ dependency around the $b,c$ dependency.

= Pumping lemma for context-free languages
{parent=Formal language theory}
{wiki}

For some $p$, every sufficiently long $w$ in a context-free language has $w=uvxyz$ with $|vxy|\le p$, $|vy|>0$, and $uv^ixy^iz$ in the language for all $i\ge0$.

= Equal prime block language is not context-free
{parent=Pumping lemma for context-free languages}

The language $\{0^p1^p:p\text{ is prime}\}$ is not context-free. For a proposed pumping length, start with a larger prime $p$. Pumping unequal numbers of zeros and ones breaks equality; if the positive changes are equal to $d$, pumping with exponent $p+1$ gives the composite common block length $p(1+d)$.

= Three-block context-free pumping obstruction
{parent=Pumping lemma for context-free languages}

For a word consisting of three long constrained blocks, a pumpable window shorter than each block cannot alter both outer blocks; pumping then breaks a required three-way count relation.

= Pumping length
{parent=Pumping lemma for context-free languages}

A pumping length is a threshold beyond which every word in the language has a decomposition satisfying the conclusion of the relevant pumping lemma.

= Square-count language is not context-free
{parent=Pumping lemma for context-free languages}

The language $\{a^{m^2}b^{m^2}:m\geq0\}$ is not context-free. Pump a word with both block lengths $p^2$. Unequal changes to the blocks destroy equality; an equal positive change $d\leq p$ makes both lengths $p^2+d$, which lies strictly between consecutive squares $p^2$ and $(p+1)^2$.

= Finite-state machine

= Finite-state automaton
{synonym}

A <finite-state machine> has finitely many states and input-dependent transitions; it may also emit outputs. With designated accepting states it recognizes a <formal language>.

A finite-state automaton recognizes a <formal language> by updating one of finitely many states as it reads each input symbol.

= Dead state of a finite automaton
{parent=Finite-state machine}

A <dead state of a finite automaton> has no path to an accepting state. In a complete <deterministic finite automaton>, all dead states may be merged into one rejecting sink without changing the accepted <formal language>.

= Generalized finite automaton
{parent=Finite-state machine}

= Generalized nondeterministic finite automaton
{synonym}

A finite directed automaton whose <edge> labels are <regular expressions> rather than individual letters. A path accepts concatenations of words in its successive labels, with choices over all accepting paths combined by <union>.

= State elimination for finite automata
{parent=Generalized finite automaton}
{title2=$R_{ij}\gets R_{ij}\cup R_{ik}R_{kk}^*R_{kj}$}

To remove an internal state $k$, replace each surviving label by $R_{ij}\cup R_{ik}(R_{kk})^*R_{kj}$. The added term accounts for entering $k$, traversing its loop any number of times, and leaving it. Fresh initial and final states allow all old states to be eliminated, producing a <regular expression> for the same language.

= Finite-state path expression
{parent=State elimination for finite automata}
{title2=$R_{ij}^{(k)}$}

For numbered states of a <finite-state automaton>, $R_{ij}^{(k)}$ is a <regular expression> describing paths from $i$ to $j$ whose internal states have numbers at most $k$. Splitting a path at its visits to state $k$ gives $R_{ij}^{(k)}=R_{ij}^{(k-1)}+R_{ik}^{(k-1)}(R_{kk}^{(k-1)})^*R_{kj}^{(k-1)}$. At stage zero use individual edge labels and an empty-word option when the endpoints coincide. This proves the automaton-to-expression direction of <Kleene theorem>.

A deterministic finite automaton has finitely many states and one transition for each state-symbol pair.

= Extended transition function of a deterministic finite automaton
{title2=$\widehat\delta$}
{parent=Deterministic finite automaton}

For a transition function $\delta:Q\times\Sigma\to Q$, define
$$
\widehat\delta(q,\varepsilon)=q,
\qquad
\widehat\delta(q,wa)=\delta(\widehat\delta(q,w),a).
$$
The accepted language is $\{w:\widehat\delta(q_0,w)\in F\}$.

= Accessible state of a deterministic finite automaton
{parent=Deterministic finite automaton}

= Accessible states of a deterministic finite automaton
{synonym}

A state is accessible when some input word takes the initial state to it. Removing inaccessible states preserves the accepted language.

= Indistinguishable states of a deterministic finite automaton
{parent=Deterministic finite automaton}

Two states are indistinguishable when every continuation is accepted from both or rejected from both. Distinguishable states admit at least one suffix with different acceptance outcomes.

= Quotient deterministic finite automaton by indistinguishable states
{parent=Indistinguishable states of a deterministic finite automaton}

Indistinguishability is a right-invariant equivalence relation. The quotient has states $[q]$, transition $[q]\mapsto[\delta(q,a)]$, initial state $[q_0]$, and accepting classes represented by accepting states. It accepts the original language and has no two distinct indistinguishable states.

= Irreducible deterministic finite automaton
{parent=Deterministic finite automaton}

A deterministic automaton is irreducible when every state is accessible and every pair of distinct states is distinguishable.

= Parity-counting deterministic finite automaton
{parent=Deterministic finite automaton}

To recognize prescribed parities of several symbol counts, use one state for each tuple of parities. Reading a tracked symbol toggles its coordinate and leaves all other coordinates unchanged. For two tracked symbols this gives four states indexed by $\mathbb Z_2^2$.

= Bounded-run deterministic finite automaton
{parent=Deterministic finite automaton}

To recognize words having at most $m$ consecutive copies of a symbol, use states $0,1,\ldots,m$ recording the current run length and one rejecting sink. Another symbol resets the run length to zero, while the $(m+1)$st consecutive copy enters the sink.

= DFA minimization
{c}
{parent=Deterministic finite automaton}
{wiki}

<DFA minimization> merges states with identical acceptance behavior for every suffix and removes unreachable states. It produces a <minimal deterministic finite automaton>, unique up to renaming states.

= Minimal deterministic finite automaton
{parent=DFA minimization}

A <minimal deterministic finite automaton> is the result of <DFA minimization>. An irreducible deterministic automaton has the fewest states among deterministic automata for its language and is unique up to isomorphism. Its states are the Myhill--Nerode classes.

= Canonical residual automaton
{parent=Minimal deterministic finite automaton}

The canonical residual automaton of a <regular language> has its distinct <left quotients of a formal language> as states, initial state $L$, accepting states those containing the <empty word>, and letter transition $R\mapsto a^{-1}R$. It is a complete <minimal deterministic finite automaton>; every other complete <minimal deterministic finite automaton> for that language is <isomorphic> to it.

= Cycle state in a minimal deterministic finite automaton for a finite language
{parent=Minimal deterministic finite automaton}

In a minimal <deterministic finite automaton> accepting a finite language, any state lying on a nonempty directed cycle is the unique rejecting sink state. It cannot reach an accept state, since traversing the cycle arbitrarily many times would produce infinitely many accepted words. Every state reachable from it also rejects every continuation, so minimality forces all such states to be the same state.

= Binary divisibility automaton
{parent=Minimal deterministic finite automaton}

For a positive integer $m$, binary strings can be tested for divisibility by $m$ with residue states $0,\ldots,m-1$ and transition
$$
r\xrightarrow{b}2r+b\pmod m,
\qquad b\in\{0,1\}.
$$
The initial and accepting residue is zero. For $m=7$, all seven states are reachable and pairwise distinguishable, so this automaton is minimal.

= Accessible unary deterministic finite automaton
{parent=Minimal deterministic finite automaton}

An accessible automaton over one letter consists of a directed tail entering one directed cycle. Its minimal quotient is obtained by merging positions having the same future binary acceptance sequence.

= Extended transition of a nondeterministic finite automaton

\widehat\Delta(q,\varepsilon)=\{q\},\qquad

For $w=a_0\cdots a_{n-1}$, a witnessing sequence from $p_0$ to $p_n$ satisfies $p_{i+1}\in\Delta(p_i,a_i)$. Induction on word length shows that $q'\in\widehat\Delta(q,w)$ exactly when such a sequence runs from $q$ to $q'$.

and accepting subsets that meet the NFA final set.

= Brzozowski automaton
{parent=Nondeterministic finite automaton}
{c}

In the convention used here, a Brzozowski NFA has one final state, every state can reach it, and each word labels a path to it from exactly one starting state.

= Irreducibility of the accessible subset automaton
{parent=Brzozowski automaton}

For distinct accessible subset states, choose a state in their symmetric difference. A word taking it to the unique final state accepts from one subset; uniqueness of the starting state prevents acceptance from the other. Thus the accessible part of the subset automaton is irreducible.

= Regular language
{parent=Formal language theory}
{wiki}

A language is regular exactly when it is accepted by a finite automaton, or equivalently has finitely many Myhill-Nerode classes.

= Pumping lemma for regular languages
{parent=Formal language theory}
{wiki}

For a <deterministic finite automaton> with $N$ states, every accepted word $w$ with $|w|\geq N$ has a decomposition $w=xyz$ such that $|xy|\leq N$, $|y|\geq1$, and $xy^iz$ is accepted for every integer $i\geq0$.

= Proper-power language is not regular
{parent=Pumping lemma for regular languages}

Over an alphabet containing $a,b$, the language $\{w^n:n\geq2\}$ is not <regular language>. Intersecting it with the regular language $a^+ba^+b$ gives exactly
$$
\{a^mba^mb:m\geq1\},
$$
which fails the <pumping lemma for regular languages>.

= Nonregular language satisfying the pumping lemma
{parent=Pumping lemma for regular languages}

Let $K\subseteq\mathbb N$ be undecidable and
$$
L=\{wab^n:w\in\{a,b\}^*,\ n\in K\}\cup b^*.
$$
Pumping its first symbol always stays in $L$, so it satisfies the pumping lemma with pumping length one. Yet $L\cap ab^*=\{ab^n:n\in K\}$ is not regular, because a finite automaton for it would decide $K$.

= Base dependence of regularity for representations of powers of two
{parent=Pumping lemma for regular languages}

The base-two representations of powers of two form the regular language $10^*$. Their base-ten representations are not regular. Pumping a fixed decimal substring of length $d$ would produce powers of two $a_i$ satisfying $a_{i+1}-10^da_i=C$. After division by $a_i$ and passage to large $i$, integrality would force a power of two to equal $10^d$, contradicting unique factorization.

= Myhill-Nerode theorem
{c}
{parent=Formal language theory}
{wiki=Myhill–Nerode_theorem}

A language is regular exactly when indistinguishability by all suffixes has finitely many equivalence classes; these classes form its minimal DFA.

= Myhill-Nerode equivalence
{parent=Myhill-Nerode theorem}
{c}

= Myhill-Nerode equivalent
{synonym}
{c}

For a language $A\subseteq\Sigma^*$, define
$$
v\sim_Aw
\quad\Longleftrightarrow\quad
\forall u\in\Sigma^*,\
vu\in A\Longleftrightarrow wu\in A.
$$
This is a right congruence, and its equivalence classes are the states of the minimal <deterministic finite automaton> for $A$.

= Recursively enumerable language
{parent=Formal language theory}
{wiki}

= Computably enumerable language
{synonym}

A language is computably enumerable when a machine recognizes its members, possibly running forever on nonmembers.

= Halting problem
{parent=Recursively enumerable language}
{wiki}

The halting set is computably enumerable but undecidable, and its complement is not computably enumerable.

= Computable bound on halting time
{parent=Halting problem}
{title2=$t_M(n)\leq f(n)$}

A machine's halting times admit a <total computable function> as a bound on all inputs in its domain if and only if that domain is a <computable set>. A bound decides the domain by finite simulation; conversely, a domain decider allows returning zero outside the domain and the exactly simulated halting time inside it. In particular every machine computing a <total computable function> has an exact computable running-time function, while nontotal machines may or may not have total bounds.

= Halting set
{parent=Halting problem}
{title2=$\Omega(T)$}

The halting set of a <Turing machine> $T$ is the set of inputs on which it eventually halts. For a deterministic machine with a designated terminal state, eventual halting is invariant along every transition edge, even when that edge is traversed backwards. This observation justifies passing from forward computations to symmetric equality derivations in a <semigroup presentation>.

= Diagonal halting set
{title2=$K$}
{parent=Halting problem}

For an effective enumeration of unary partial computable functions, the diagonal halting set is
$$
K=\{e:f_{e,1}(e)\text{ is defined}\}.
$$
Equivalently, for an enumeration $W_e$ of computably enumerable sets, $K=\{e:e\in W_e\}$.

= Many-one completeness of the halting problem
{parent=Diagonal halting set}

Every <recursively enumerable set> many-one reduces to the <diagonal halting set>. If a program halts exactly on $X$, the <S-m-n theorem> produces from $x$ an index $g(x)$ for a unary program that ignores its input and performs that computation on $x$. Then
$$
x\in X\Longleftrightarrow g(x)\in K.
$$
Conversely, a computable preimage of a recursively enumerable set is recursively enumerable.

= Distinct representative of the halting many-one degree
{parent=Many-one completeness of the halting problem}

If $0\notin K$, then
$$
S=\{0\}\cup\{2n+1:n\in K\}
$$
differs from $K$, while the computable map $n\mapsto2n+1$ proves $K\leq_mS$.

= Empirical risk
{title2=$\widehat R_n$}
{parent=Empirical risk minimization}

The empirical risk of a hypothesis $h$ on observations $z_1,\ldots,z_n$ is the sample-average loss
$$
\widehat R_n(h)=\frac1n\sum_{i=1}^n\ell(h,z_i).
$$

= Loss function
{parent=Empirical risk minimization}

A loss function assigns a numerical penalty to a prediction and its observed outcome. Its <expected value> is the population risk optimized by a statistical learning procedure.

= Population risk
{title2=$R$}
{parent=Loss function}

The population risk of a prediction rule is its <expected value>[expected] <loss function>[loss] on a fresh observation from the target <probability distribution>.

= Loss class
{parent=Empirical risk minimization}

Given a <hypothesis class> $\mathcal H$ and a <loss function> $\ell$, its loss class is the <function class>
$$
\mathcal F=\{z\mapsto\ell(h,z):h\in\mathcal H\}.
$$
It lets properties of a learning problem be studied through the random fluctuations of the losses themselves.

= Misclassification loss
{title2=$\ell_{0-1}$}
{parent=Loss class}

= Zero-one loss
{synonym}

For a <classifier> $h$ and a labelled example $z=(x,y)$, the misclassification loss is
$$
\ell_{0-1}(h,z)=\mathbf1_{\{h(x)\ne y\}}.
$$
It is also called zero-one loss because it is zero for a correct prediction and one for an incorrect prediction.

= Misclassification risk
{title2=$R(h)$}
{parent=Misclassification loss}

The misclassification risk of a <classifier> is its <expected value>[expected] <misclassification loss>,
$$
R(h)=\mathbb P(h(X)\ne Y)=\mathbb E\ell_{0-1}(h,(X,Y)).
$$

= Conditional misclassification risk
{parent=Misclassification risk}
{title2=$L(C)=\mathbb P(C(X)\ne Y\mid\mathcal T)$}

For a random <classifier> $C$ determined by training information $\mathcal T$, and an <independent> test pair $(X,Y)$, its conditional <misclassification risk> is $L(C)=\mathbb P(C(X)\ne Y\mid\mathcal T)$. It is itself a training-dependent random variable. The <tower property of conditional expectation> gives $\mathbb E L(C)=\mathbb P(C(X)\ne Y)$.

= Empirical misclassification risk
{title2=$\widehat R(h)$}
{parent=Misclassification risk}

On labelled examples $Z_1,\ldots,Z_n$, the empirical misclassification risk is
$$
\widehat R(h)=\frac1n\sum_{i=1}^n\ell_{0-1}(h,Z_i).
$$
An <empirical risk minimization>[empirical risk minimizer] chooses a <classifier> attaining the smallest value over its <hypothesis class>.

= Excess risk
{parent=Empirical risk minimization}

If $h^*$ minimizes the <population risk> over a <hypothesis class>, the excess risk of $h$ is the nonnegative difference $R(h)-R(h^*)$.

= Squared-loss empirical risk for linear prediction
{parent=Empirical risk minimization}

For data $(X_i,Y_i)$ and predictions $h_\beta(X)=\beta^TX$, it is convenient to write
$$
R_n(\beta)=\frac1{2n}\sum_{i=1}^n(\beta^TX_i-Y_i)^2.
$$
Its <gradient> is
$$
\nabla R_n(\beta)=\frac1n\sum_{i=1}^n(\beta^TX_i-Y_i)X_i.
$$

= Shattering coefficient
{title2=$s(\mathcal H,n)$}
{parent=Statistical learning theory}

The shattering coefficient is
$$
s(\mathcal H,n)=\sup_{x_1,\ldots,x_n}
\left|\{(h(x_1),\ldots,h(x_n)):h\in\mathcal H\}\right|.
$$

= Shattering coefficient of a union
{parent=Shattering coefficient}

For binary hypothesis classes,
$$
s(\mathcal H_1\cup\mathcal H_2,n)
\leq s(\mathcal H_1,n)+s(\mathcal H_2,n),
$$
because the label vectors realized by the union form the union of the two sets of realized label vectors.

= VC dimension
{title2=$\operatorname{VC}(\mathcal H)$}
{parent=Shattering coefficient}
{c}
{wiki}

The VC dimension is the largest number of points on which a binary hypothesis class realizes every possible labeling.

= Sauer-Shelah lemma
{parent=VC dimension}
{c}
{wiki=Sauer–Shelah_lemma}

If $VC(H)=D<\infty$, then $s(H,n)\leq\sum_{j=0}^D\binom nj$.

= Half-power-set trace growth forces finite shattering
{parent=Sauer-Shelah lemma}
{title2=$|\mathcal F_{|Y}|\geq2^{2k-1},\ |Y|=2k\Longrightarrow\exists Z\subseteq Y,\ |Z|=k$}

If no $k$-set were shattered, the <Sauer-Shelah lemma> would bound the number of traces by $\sum_{i<k}\binom{2k}{i}=(2^{2k}-\binom{2k}{k})/2<2^{2k-1}$. This strict middle-layer gap contradicts the displayed lower bound. Therefore a family with such traces at every even size has unbounded finite <VC dimension>.

= Sauer-Shelah growth bound
{parent=Sauer-Shelah lemma}
{c}

The elementary estimate $\sum_{j=0}^D\binom nj\leq(n+1)^D$ converts finite VC dimension into a polynomial bound on the number of sample labelings.

= VC dimension bound for lower orthants
{parent=VC dimension}
{c}

The class of lower orthants $\prod_{j=1}^p(-\infty,a_j]$ in $\mathbb R^p$ has VC dimension at most $p$. Among any $p+1$ points, choose a coordinate maximizer for each of the $p$ coordinates. A remaining point cannot be excluded while all those maximizers are included.

= VC dimension of interval indicators
{parent=VC dimension}
{c}

Indicators of real intervals have VC dimension two: two ordered points can be labeled arbitrarily, while an interval containing the two outer points of a triple must contain the middle point.

= VC dimension of intervals and their complements
{parent=VC dimension}
{c}

Intervals together with their label complements shatter three ordered points, but cannot realize an alternating labeling on four, so their VC dimension is three.

= VC dimension of a vector space
{c}
{parent=Statistical learning theory}

The sign class of a $d$-dimensional real <vector space> of functions has VC dimension at most $d$. If $n>d$ points were shattered, the <linear map>[evaluation map] from the function space to $\mathbb R^n$ would have a nonzero vector orthogonal to its image. Choosing labels according to the signs of that vector contradicts orthogonality.

= VC dimension upper bound for Euclidean balls
{c}
{parent=VC dimension of a vector space}

The indicators of closed <Euclidean ball>[Euclidean balls] in $\mathbb R^d$ have VC dimension at most $d+2$. Indeed,
$$
\mathbf1_{\{\lVert x-c\rVert_2^2\leq r^2\}}
=\mathbf1_{\{f_{c,r}(x)\leq0\}},
$$
where
$$
f_{c,r}(x)=\lVert x\rVert_2^2-2c^Tx+\lVert c\rVert_2^2-r^2
$$
belongs to the span of $\lVert x\rVert_2^2,x_1,\ldots,x_d,1$.

= Quadratic feature map
{parent=VC dimension of a vector space}

The map $x\mapsto(x_ix_j)_{i\leq j}$ embeds homogeneous quadratic forms in a linear function space of dimension $d(d+1)/2$.

= Growth bound for homogeneous linear classifiers
{parent=VC dimension of a vector space}

The signs of homogeneous linear forms $x\mapsto x^T\beta$ on $\mathbb R^p$ have VC dimension at most $p$. The <Sauer-Shelah growth bound> therefore gives
$$
s(\mathcal H,n)\leq(n+1)^p.
$$

= Growth bound for signs of m-term linear combinations
{parent=Statistical learning theory}

For $f=\sum_{j=1}^m\alpha_jg_j$ with $g_j$ drawn from a binary class $\mathcal G$, fixing $(g_1,\ldots,g_m)$ leaves an $m$-dimensional linear sign class. Consequently
$$
s(\operatorname{sgn}\mathcal F,n)
\leq(n+1)^m|\mathcal G|^m
$$
when $\mathcal G$ is finite, and in general
$$
s(\operatorname{sgn}\mathcal F,n)
\leq(n+1)^m s(\mathcal G,n)^m.
$$

= Growth bound for a single-hidden-layer sign network
{parent=Growth bound for signs of m-term linear combinations}

A bias-free network with $p$ inputs, $m$ sign-activated hidden nodes, and a thresholded linear output satisfies
$$
s(\mathcal H,n)\leq(n+1)^{(p+1)m}.
$$
The hidden units contribute $s(\mathcal G,n)^m\leq(n+1)^{pm}$ sample patterns, and the output weights contribute $(n+1)^m$.

= AdaBoost
{c}
{parent=Statistical learning theory}
{wiki}

AdaBoost constructs an additive classifier by repeatedly fitting a base classifier to exponentially reweighted observations. Misclassified observations receive greater weight at the next iteration, and the final score is a nonnegative weighted sum of the base classifiers.

= Exponential-loss derivation of AdaBoost
{parent=AdaBoost}
{title2=$\alpha_m=\tfrac12\log[(1-\epsilon_m)/\epsilon_m]$}

At score $F$, the <exponential classification risk> weights observation $i$ proportionally to $e^{-y_iF(x_i)}$. A stage $\alpha G$ multiplies this weight by $e^{-\alpha y_iG(x_i)}$. For weighted error $\epsilon$, the loss multiplier is $(1-\epsilon)e^{-\alpha}+\epsilon e^\alpha$, minimized at the displayed value. Its minimum is $2\sqrt{\epsilon(1-\epsilon)}$. Thus errors gain weight relative to correct observations in the next stage.

= AdaBoost training error bound
{c}
{parent=Exponential-loss derivation of AdaBoost}
{title2=$\widehat R_{01}\le\prod_m2\sqrt{\epsilon_m(1-\epsilon_m)}\le e^{-2\sum_m\gamma_m^2}$}

For <AdaBoost> with initial uniform weights, labels and base predictions in $\{-1,1\}$, and edges $\gamma_m=1/2-\epsilon_m>0$, the training <exponential classification risk> equals the product of stage normalizers. A wrongly classified point has exponential loss at least one, so empirical classification error is bounded by this product. The final inequality uses $\sqrt{1-4\gamma_m^2}\le e^{-2\gamma_m^2}$. The result concerns training error, not a guarantee against overfitting or mislabeled observations.

= Rademacher complexity
{c}
{parent=Statistical learning theory}
{wiki}

For <independent and identically distributed random variables> $Z_1,\ldots,Z_n$ and independent <Rademacher random variable>[Rademacher signs] $\varepsilon_1,\ldots,\varepsilon_n$, the Rademacher complexity of a <function class> $\mathcal F$ is
$$
\mathcal R_n(\mathcal F)
=\mathbb E_{Z,\varepsilon}\left[
\sup_{f\in\mathcal F}\frac1n\sum_{i=1}^n\varepsilon_i f(Z_i)
\right].
$$
It measures how strongly the class can correlate with independent random signs on a random sample.

= Empirical Rademacher complexity
{title2=$\widehat{\mathcal R}$}
{c}
{parent=Rademacher complexity}

For a fixed sample $z_{1:n}$, the empirical Rademacher complexity is
$$
\widehat{\mathcal R}(\mathcal F(z_{1:n}))
=\mathbb E_\varepsilon\left[
\sup_{f\in\mathcal F}\frac1n\sum_{i=1}^n\varepsilon_i f(z_i)
\right].
$$
Taking its <expected value> over the sample gives $\mathcal R_n(\mathcal F)$.

= Rademacher symmetrization inequality
{c}
{parent=Rademacher complexity}

For an <independent and identically distributed random variables>[i.i.d. sample] and an integrable <function class> $\mathcal F$,
$$
\mathbb E\sup_{f\in\mathcal F}
\frac1n\sum_{i=1}^n\bigl(f(Z_i)-\mathbb Ef(Z_i)\bigr)
\leq2\mathcal R_n(\mathcal F).
$$
Introduce an independent ghost sample, replace each expectation by its ghost-sample average using <Jensen inequality>, and then multiply each paired difference by an independent <Rademacher random variable>[Rademacher sign]. Splitting the resulting supremum into its two sample contributions gives the factor two.

= Rademacher excess-risk bound for empirical risk minimization
{c}
{parent=Rademacher complexity}

For a zero-one-valued <loss class> $\mathcal F$, the excess <misclassification risk> of an <empirical risk minimization>[empirical risk minimizer] $\widehat h$ over a population minimizer $h^*$ satisfies
$$
R(\widehat h)-R(h^*)
\leq2\mathcal R_n(\mathcal F)
+\sqrt{\frac{2\log(2/\delta)}n}
$$
with <probability theory>[probability] at least $1-\delta$. The proof combines <Rademacher symmetrization inequality>[Rademacher symmetrization] with the <bounded differences inequality> for the supremum of the empirical excess-loss process.

The observable version is
$$
R(\widehat h)-R(h^*)
\leq2\widehat{\mathcal R}(\mathcal F(Z_{1:n}))
+2\sqrt{\frac{2\log(3/\delta)}n}.
$$
It follows by another application of the <bounded differences inequality> to the <empirical Rademacher complexity>.

= Massart finite-class lemma
{parent=Rademacher complexity}
{c}

For a finite $A\subseteq\mathbb R^n$ with $\max_{a\in A}\lVert a\rVert_2\leq R$, its empirical Rademacher complexity is at most $R\sqrt{2\log|A|}/n$.

= Rademacher bound for bounded weighted indicators
{parent=Rademacher complexity}
{c}

For $|D_i|\leq M$ and a binary class $H$ of VC dimension at most $p$, the vectors $(D_i h(X_i))_{i=1}^n$ have norm at most $M\sqrt n$ and at most $(n+1)^p$ distinct values. The Massart finite-class lemma gives
$$
\widehat R\leq M\sqrt{\frac{2p\log(n+1)}n}.
$$

= Rademacher complexity of a convex hull
{parent=Rademacher complexity}
{c}

A linear functional has the same supremum over a class and its convex hull. Thus taking convex combinations does not increase empirical Rademacher complexity.

= Rademacher contraction lemma
{parent=Rademacher complexity}
{c}

Composition with an $L$-Lipschitz scalar map increases Rademacher complexity by at most the factor $L$ after centering at zero.

= Frobenius norm Rademacher calculation
{parent=Rademacher complexity}
{c}

Independent signs cancel cross terms in $\mathbb E\lVert\sum_i\sigma_iA_i\rVert_F^2$, leaving $\sum_i\lVert A_i\rVert_F^2$.

= Rademacher complexity of quadratic forms
{parent=Rademacher complexity}
{c}

For $h_M(x)=x^TMx$, $M\succeq0$, $\operatorname{tr}M\leq s$, and $\lVert x\rVert\leq C$, the complexity is at most $C^2s/\sqrt n$.

= Expected excess-risk bound for empirical risk minimization
{parent=Rademacher complexity}

With the $1/n$ Rademacher convention, an empirical risk minimizer has expected excess risk at most twice the Rademacher complexity of its loss class.

= Hinge loss
{parent=Statistical learning theory}
{wiki}

The hinge loss is $\max(0,1-yh(x))$ and is one-Lipschitz in the signed margin.

= Active hinge set
{parent=Hinge loss}
{title2=$I(x)=\{i:1-a_ix>0\}$}

For a sample term $\max\{0,1-a_ix\}$, the active hinge set contains indices with $1-a_ix>0$. At strict negative margins the hinge is inactive, while zero margins allow fractional <hinge-loss optimality weights>. Away from zero margins, the active set stays fixed on a sufficiently small candidate solution neighborhood.

= Active-set sensitivity of hinge-loss minimization
{parent=Active hinge set}
{title2=$Dx(a)[h]=(\alpha n)^{-1}\sum_{i\in I}h_i$}

With fixed positive quadratic regularization, if all reference hinge margins are nonzero, the one-dimensional minimizer has local formula $x(a)=(\alpha n)^{-1}\sum_{i\in I}a_i$. The <active hinge set> is verified using continuity of this explicit candidate, then strong convexity identifies it as the optimizer. Its exact Euclidean Lipschitz modulus is $\sqrt{|I|}/(\alpha n)$.

= Hinge-loss optimality weight
{parent=Active hinge set}
{title2=$\lambda_i\in[0,1]$}

The subgradient of $\max\{0,1-a_ix\}$ is $-\lambda_i a_i$, with $\lambda_i=1$ below the margin, $\lambda_i=0$ beyond it and $\lambda_i\in[0,1]$ at equality. For quadratic regularization the one-dimensional optimality condition is $\alpha nx=\sum_i\lambda_i a_i$. The optimizer can be unique even if the weights at equality are not.

= Stability
{parent=Statistical learning theory}
{disambiguate=learning theory}
{wiki}

In <statistical learning theory>, <Stability (learning theory)> measures how much a learned predictor or its loss changes when the training sample is perturbed. <Uniform stability of a learning algorithm> imposes a bound valid at every test example.

= Uniform stability of a learning algorithm
{parent=Stability (learning theory)}

This is a uniform version of <Stability (learning theory)> for learning algorithms. A learning algorithm has uniform stability $\beta$ for a loss when replacing one training example changes the loss at every test example by at most $\beta$.

= Decision tree learning
{parent=Statistical learning theory}
{wiki}

<Decision tree learning> fits predictors by recursively partitioning input space. Leaves predict labels for classification or numerical values for regression; a <regression tree> is the numerical-response case.

= Regression tree
{parent=Decision tree learning}

A <regression tree> is the numerical-response case of <decision tree learning>. A regression tree recursively partitions predictor space by axis-aligned splits. At each leaf, candidate coordinates and thresholds are compared by the residual sum of squares after replacing that leaf by its two children; the selected split minimizes the total criterion. The fitted value in each terminal region is the sample mean there.

= Decision stump
{parent=Regression tree}
{wiki}

A decision stump is a <decision tree> with one split. A regression stump predicts a constant, usually the sample mean, in each of its two terminal regions.

= Conditional variance of a fixed regression-tree partition
{parent=Regression tree}

For a deterministic partition $R_1,\ldots,R_J$ and
$$
\widetilde\gamma_j=\frac1{N_j+1}
\sum_{i=1}^nY_i\mathbf1_{R_j}(X_i),
$$
conditional independence gives
$$
\operatorname{Var}(\widetilde\gamma_j\mid X_{1:n})
=\frac{\sum_i\operatorname{Var}(Y_i\mid X_i)\mathbf1_{R_j}(X_i)}
{(N_j+1)^2}.
$$
If the conditional response variance is at most $\sigma^2$, the prediction variance at an independent test point is at most $\sigma^2J/n$.

= Mathematical proof
{parent=Foundations of mathematics}
{wiki}

A mathematical proof is a finite deductive argument from stated assumptions to a conclusion. It explains why the conclusion follows for every instance covered by its hypotheses. An informal <mathematical proof> can omit routine detail while making its assumptions and deductions clear; a <formal proof> expresses them in a specified formal language with specified inference rules. The distinction between assumptions, <propositions>, and deductions is introduced in \a[https://web.mit.edu/neboat/Public/6.042/proofs.pdf][Leighton and Rubinfeld, What is a proof?, sections 1–3]{ref}.

Checking examples can suggest a pattern, but need not establish a universally quantified claim. For example, the <polynomial> $n^2+n+41$ is a <prime number> for every <integer> $0\leq n\leq39$, as direct trial division verifies. At $n=40$ it equals $1681=41^2$, a <composite number>. Those first forty successes do not prove the claim for all <natural numbers>; one <counterexample> disproves it. The point is not to discard computation: it can find a conjecture, detect a mistake, or verify a finite exhaustive case analysis. The question is whether the cases checked cover the statement being claimed.

For a positive example, the sum of two <even integers> is even: writing them as $2a$ and $2b$ with $a,b\in\mathbb Z$ gives $2a+2b=2(a+b)$, and $a+b$ is an <integer>. This direct argument handles every allowed pair at once. A useful <mathematical proof> therefore does more than certify an answer: it exposes the mechanism and the exact assumptions that make the answer transferable.

= Reductio ad absurdum
{parent=Mathematical proof}
{wiki}
{title2=$(\neg P\Rightarrow\bot)\Rightarrow P$}

= Proof by contradiction
{synonym}

A reductio rejects an assumption by deriving an absurd or contradictory consequence from it. In a classical <mathematical proof> of $P$, assume its negation and derive a <contradiction>. Constructively the same argument yields the double negation of $P$; removing it requires an additional logical principle. This differs from proving a negation directly by deriving a contradiction from the positive assumption.

= Mathematical induction
{parent=Mathematical proof}
{wiki}
{title2=$P(n_0),\quad P(n)\Rightarrow P(n+1)$}

= Induction
{synonym}

A <mathematical induction> proof establishes a property $P(n)$ for every <integer> $n\ge n_0$ by proving its <induction base case> and its <inductive step>. If a counterexample existed, the <well-ordering principle> would give a least one; its predecessor and the inductive implication exclude it. The starting case excludes a counterexample at $n_0$.

The useful idea is to cover infinitely many cases with two finite pieces of reasoning. The <induction base case> starts the chain, and the <inductive step> shows that success at an arbitrary stage propagates to the next. It is especially natural when a construction adds one item at a time: another row of a diagram, another input processed by an <algorithm>, or another term of a <sequence>. The <loop invariant> method is the same propagation idea applied to successive stages of a computation.

For the <triangular number> $T_n=1+2+\cdots+n$, the proposed formula is $T_n=n(n+1)/2$. At $n=1$, both sides are one. Assuming the formula for a fixed positive <integer> $n$, add the next row:
$$
T_{n+1}=T_n+(n+1)=\frac{n(n+1)}2+(n+1)=\frac{(n+1)(n+2)}2.
$$
This is the desired formula at $n+1$, proving the <inductive step>. For example, $T_5=15$ and $T_6=15+6=21$; these numerical cases illustrate the general step rather than replace it.

The second picture explains where the formula comes from: two copies of the triangular arrangement tile an $n$ by $n+1$ <rectangle>. Thus $2T_n=n(n+1)$. The <mathematical induction> argument certifies how the formula continues, while the rearrangement makes its factors visible. Neither picture is restricted to the five rows drawn: both constructions are specified for every positive <integer> $n$.

= Inductive step
{parent=Mathematical induction}
{title2=$P(n)\Rightarrow P(n+1)$}

Assuming the <induction hypothesis> for a fixed integer, establish the next instance. Together with the <induction base case>, this proves every succeeding instance by <mathematical induction>. The hypothesis is conditional within this argument, rather than an unsupported assumption that the desired theorem is already true.

= Induction base case
{parent=Mathematical induction}
{title2=$P(n_0)$}

The starting instance of a <mathematical induction> proof, established directly before the <inductive step> is applied. The implication $P(n)\Rightarrow P(n+1)$ alone can be true when every instance is false. For example, $\sum_{j=1}^n j=n(n+1)/2+C$ with $C\ne0$ has a formally correct successor calculation but a false base case.

= Induction hypothesis
{parent=Mathematical induction}

The assertion assumed for earlier cases during an <induction> proof. It is a conditional assumption inside the induction step, not an assumption that all cases already hold.

= Strong induction
{parent=Mathematical induction}
{wiki}

Strong induction allows the step for an integer to use the result for every smaller integer.

= Backward induction
{parent=Mathematical induction}
{wiki}

Backward induction proves or computes a finite sequence of statements by starting at its terminal index and stepping toward the initial index.

= Counterexample
{parent=Mathematical proof}
{wiki}

A counterexample is one instance satisfying a claim’s hypotheses but not its conclusion, and therefore disproves the universal claim.

= Structural induction
{parent=Mathematical proof}
{wiki}

Structural induction proves a property of every recursively generated object by checking the initial objects and showing that every construction rule preserves the property.

= Probability-preserving bijection

A probability-preserving bijection pairs outcomes of two events without changing their masses, proving the events have equal probability.

= Model theory
{parent=Foundations of mathematics}
{wiki}

Model theory studies mathematical structures through the first-order sentences and formulas they satisfy.

= Finite model theory
{parent=Model theory}

Finite model theory studies logical definability and equivalence on finite <first-order structures>. Unlike unrestricted model theory, first-order compactness is unavailable when models are required to be finite. Locality, bounded-variable games and descriptive characterizations of <complexity classes> are central tools.

= Asymptotic equivalence of formulas
{parent=Finite model theory}

Two formulas with the same free variables are asymptotically equivalent when the probability of their universal equivalence tends to one over the chosen finite-structure distribution. If a quantifier-eliminating extension theory has all its axioms of asymptotic probability one, compactness makes every formula asymptotically equivalent to a quantifier-free one: each particular equivalence follows from finitely many axioms, whose conjunction still has limiting probability one.

= Partial fixed-point logic
{parent=Finite model theory}
{title2=$\mathrm{PFP}$}

= PFP
{synonym}
{c}

Extend <first-order logic> by iterating definable relation operators from the empty relation. If iteration reaches a fixed point, use that relation; if it enters a nontrivial cycle, the partial fixed point is the empty relation. For a fixed arity on a finite universe, a relation requires polynomially many bits and there are exponentially many states, so iteration is evaluable in <PSPACE>. On finite ordered structures this logic captures PSPACE.

= Gaifman graph
{parent=Finite model theory}
{c}

For a relational structure, the Gaifman graph has the same universe. Two distinct elements are adjacent if they occur together in some tuple of some interpreted relation. A tuple's radius-$r$ neighbourhood is the induced structure on the union of its radius-$r$ graph balls, with the tuple marked by constants.

= Hanf locality lemma
{parent=Gaifman graph}
{c}

For a finite relational signature and quantifier rank $q$, matching the numbers of all marked radius-$3^q$ one-point neighbourhood types suffices for two finite structures to satisfy the same first-order sentences of rank at most $q$. Equivalently, a bijection can match the isomorphism types of these marked neighbourhoods point by point. On bounded-degree structures, a threshold version permits large neighbourhood-type counts to differ once both exceed a fixed bound. Long cycles of equal total size give useful exact-count applications.

= Recursive presentation of a structure
{parent=Model theory}

= Computable presentation of a structure
{synonym}

A recursive presentation identifies the domain of a countable structure with a <computable set>, with its basic operations given by <total computable functions> and its basic relations decidable. In a fixed finite signature this makes evaluation of <atomic formulas> effective. A countable structure may have a <recursive presentation of a structure> only for some choices of presentation, or none at all.

= Computable isomorphism
{parent=Recursive presentation of a structure}

A computable isomorphism is an <isomorphism> between presented structures whose underlying map is a <total computable function>. For presentations on $\mathbb N$, its inverse is computable too: enumerate inputs until the required output occurs. Two abstractly <isomorphic> structures with a <recursive presentation of a structure> need not admit a <computable isomorphism> between the chosen presentations.

= Algebraic theory
{parent=Model theory}

A finitary algebraic theory specifies sorts, finite-arity operations and equations between terms. Its internal models can be interpreted in any category with finite products. Finitely presented set-based models generate arbitrary models under filtered colimits and determine its <classifying topos>.

= Finitely presented models of an algebraic theory
{parent=Algebraic theory}
{title2=$\mathbb T_{fp}$}

A finitely presented model is described by finitely many generators and finitely many equations. Model homomorphisms from it commute with filtered colimits. A small skeleton of these models is equivalent to the opposite of the finite-equation part of the algebraic syntactic category.

= Ehrenfeucht-Fraïssé game
{parent=Model theory}
{c}
{title2=$G_n(\mathcal M,\mathcal N)$}

In each round the Spoiler selects an element from either structure and the Duplicator responds in the other. The paired selected elements must preserve all atomic information and equality, giving a <partial isomorphism of structures>. In the infinite game the Duplicator wins by avoiding failure at every finite stage. In a timed game the Spoiler first announces the number of rounds, allowing a different response strategy for each horizon.

= Interval threshold strategy for discrete linear orders
{parent=Ehrenfeucht-Fraïssé game}
{title2=$h_k=2^k-1$}

With $k$ moves remaining, preserve corresponding gap sizes exactly when smaller than $2^k-1$, and otherwise require both gaps to have at least that many points. One move splits a gap; $2^k-1=2(2^{k-1}-1)+1$ permits matching both smaller gaps. This strategy proves that $(\mathbb N,<)$ and $(\mathbb N+\mathbb Z,<)$ agree at every finite quantifier rank despite the second order containing points with infinitely many predecessors.

= Ehrenfeucht-Fraïssé theorem
{parent=Ehrenfeucht-Fraïssé game}
{c}

For a finite relational <first-order language>, with finitely many constants allowed, the Duplicator wins the $n$-round game exactly when the structures are <rank-n equivalent>. Game-winning implies rank equivalence in arbitrary languages; the converse needs a finiteness condition and can fail even for an infinite unary vocabulary. Over a finite relational vocabulary, winning every announced finite horizon is equivalent to <elementary equivalence>.

= Failure of finite-round game equivalence in infinite languages
{parent=Ehrenfeucht-Fraïssé theorem}

For countably many unary predicates $P_i$, let $M$ contain infinitely many copies of each finite membership pattern and let $N$ add an element satisfying all predicates. Every finite vocabulary reduct has infinitely many elements in every Boolean cell in both structures, so $M\equiv N$. The Spoiler nevertheless wins the one-round full-language game by selecting the new element, whose complete atomic pattern has no counterpart in $M$.

= Theory of formally real fields
{parent=Model theory}
{title2=$\mathrm{FRF}$}

= FRF
{c}
{synonym}

The theory of formally real fields consists of the <field> axioms and all sentences asserting that $-1$ is not a sum of $m$ squares, one for each positive integer $m$. The <real closure theorem> and model completeness make the <theory of real closed fields> its <model companion>.

= Theory of nontrivial torsion-free divisible Abelian groups
{parent=Model theory}
{title2=$\mathrm{DAG}$}

= DAG
{c}
{synonym}

This <first-order theory> has as models the nonzero <torsion-free divisible Abelian groups>. Rational division equips them with the structure of <vector spaces over the rational numbers>. A <rational divisible hull> gives an <algebraically prime extension> of each nonzero torsion-free base, while the zero base uses a one-dimensional rational space.

= Theory of torsion-free divisible Abelian groups allowing the trivial group
{parent=Theory of nontrivial torsion-free divisible Abelian groups}
{title2=$\mathrm{DAG}^{\prime}$}

= DAG prime
{c}
{synonym}

Remove the nonzero-model axiom from <DAG>. The inclusion $\{0\}\subseteq\mathbb Q$ is then an inclusion of models but is not a <simple closure>, because $x\ne0$ has a witness only in the larger model. The theory does not have <quantifier elimination>: all closed group terms are zero, so no quantifier-free sentence distinguishes the two models.

= Algebraically prime extension
{parent=Model theory}
{title2=$j=h\circ i$}

= Algebraically prime model
{synonym}

For a <first-order theory> $T$ and $A\models T_\forall$, an algebraically prime extension is a <structure embedding> $i:A\to P\models T$ such that every embedding $j:A\to N\models T$ factors as $j=h\circ i$ for some <structure embedding> $h:P\to N$. The embeddings need not be elementary or unique. A theory has algebraically prime models when every such $A$ has an extension of this kind.

= Reduced product
{parent=Model theory}
{title2=$\prod_{i\in I}\mathcal M_i/F$}

Given nonempty <first-order structures> $\mathcal M_i$ and a proper <filter on a set> $F$, a reduced product identifies product functions $f,g$ when $\{i:f(i)=g(i)\}\in F$. Operations are interpreted coordinatewise, and relations hold when their coordinate truth sets belong to $F$. For an <ultrafilter> this is an <ultraproduct>. <Primitive positive formulas> transfer through an arbitrary proper filter, whereas <logical disjunction> and <logical negation> can fail to transfer.

= Elementary equivalence
{parent=Model theory}
{title2=$\mathcal M\equiv\mathcal N$}
{wiki}

= Elementarily equivalent
{synonym}

Two <first-order structures> are elementarily equivalent when they satisfy the same <first-order sentences>. They need not be isomorphic or embed into one another. Every <elementary embedding> implies <elementary equivalence> of its source and target.

= Monster model
{title2=$\mathcal U$}
{parent=Model theory}

A monster model is a fixed sufficiently saturated and strongly homogeneous model of a complete theory, of a cardinality much larger than every parameter set under discussion.

= Orbit of a definable set in a monster model
{title2=$O(\mathcal D)$}
{parent=Monster model}

If $\mathcal D=\phi(\mathcal U,b)$, its automorphism orbit consists of the sets $\phi(\mathcal U,f(b))$. If this orbit is infinite, saturation constructs $|\mathcal U|$ pairwise distinct conjugates, so $|O(\mathcal D)|=|\mathcal U|$.

= Complete theory
{parent=Model theory}
{wiki}

A consistent first-order theory is complete when it decides every sentence in its language.

= Categorical theory
{title2=$\kappa$-categorical}
{parent=Complete theory}
{wiki}

A theory is $\kappa$-categorical when all of its models of cardinality $\kappa$ are isomorphic.

= Omega-categorical theory
{title2=$\aleph_0$-categorical}
{parent=Categorical theory}
{wiki}

= Aleph-zero-categorical theory
{synonym}

An aleph-zero-categorical theory has, up to isomorphism, exactly one countably infinite model.

= Ryll-Nardzewski theorem
{c}
{parent=Omega-categorical theory}

For a complete theory with infinite models in a countable language, the following are equivalent: the theory is aleph-zero-categorical; every type space $S_n(T)$ is finite; and for every $n$ there are only finitely many formulas in $n$ variables modulo the theory.

= Reduct of an aleph-zero-categorical theory
{parent=Ryll-Nardzewski theorem}

Every reduct of an aleph-zero-categorical theory to a sublanguage is aleph-zero-categorical. There can only be fewer formulas in each arity, so the finite-formula characterization in the <Ryll-Nardzewski theorem> is preserved.

= Morley categoricity theorem
{c}
{parent=Categorical theory}

This theorem is the uncountable categoricity theorem for a <categorical theory>. If a countable first-order theory is categorical in one uncountable cardinal, then it is categorical in every uncountable cardinal.

= Reduct need not preserve uncountable categoricity
{parent=Categorical theory}

Let a language partition the universe into two infinite unary predicates and include a bijection between them. Its complete theory is categorical in every infinite cardinal. The reduct forgetting the bijection is not categorical in any uncountable cardinal, because the two infinite parts can have different cardinalities.

= Nonstandard model of the additive integers
{parent=Categorical theory}

Compactness gives a countable model elementarily equivalent to $(\mathbb Z,+,0)$ that contains a nonzero element divisible by every positive standard integer. It is not isomorphic to $\mathbb Z$, so $\operatorname{Th}(\mathbb Z,+,0)$ is not aleph-zero-categorical.

= Aleph-zero-categoricity of an infinite-dimensional vector space over a finite field
{parent=Categorical theory}

The complete theory of infinite-dimensional vector spaces over a fixed finite field is aleph-zero-categorical: every countably infinite model has countably infinite dimension and is therefore isomorphic to every other such model.

= Diagram
{parent=Model theory}
{disambiguate=mathematical logic}
{wiki}

= Diagram of a structure
{synonym}

The diagram of $M$ is the set of atomic and negated atomic sentences true in the expansion by constants naming every element of $M$. Its elementary diagram contains every sentence true in that expansion. Models of these diagrams correspond respectively to embeddings and elementary embeddings of $M$.

= Elementary diagram of a structure
{parent=Diagram (mathematical logic)}

= Elementary diagram
{synonym}

The elementary diagram of $M$ is the set of all first-order sentences true in the expansion of $M$ by a constant symbol for each element. A model of the elementary diagram contains an elementary copy of $M$.

= Method of diagrams
{parent=Diagram (mathematical logic)}

The method of diagrams adds the diagram or elementary diagram of a structure to a theory and applies compactness. A resulting model supplies an embedding or elementary embedding of the named structure.

= Diagram embedding criterion for universal theories
{parent=Method of diagrams}
{title2=$A\models T_\forall\iff A\hookrightarrow N\models T$}

A <first-order structure> $A$ embeds into a model of $T$ exactly when $A\models T_\forall$. For the nontrivial direction apply the <compactness theorem> to $T\cup\operatorname{Diag}(A)$. If a finite diagram conjunction were inconsistent with $T$, its universal negation after replacing the new constants by variables would belong to $T_\forall$ and contradict its truth in $A$.

= Finitely satisfiable type is realized in an elementary extension
{parent=Method of diagrams}

If a type $p(x)$ over a structure $M$ is finitely satisfiable in $M$, then the elementary diagram of $M$ together with $p(c)$ is finitely satisfiable. Compactness gives an elementary extension of $M$ realizing $p$.

= Inductive first-order theory
{parent=Model theory}

A first-order theory is inductive when unions of chains of its models under embeddings remain models. A theory is inductive exactly when it has an axiomatization by sentences of the form $\forall\bar x\,\exists\bar y\,\varphi(\bar x,\bar y)$ with quantifier-free $\varphi$.

= Model-complete theory
{parent=Model theory}
{wiki}

= Model completeness
{synonym}

= Model-complete
{synonym}

A theory is model-complete when every embedding between its models is elementary. Every model-complete theory is inductive and hence admits a forall-exists axiomatization.

= Model companion
{parent=Model-complete theory}
{title2=$T^*$}
{wiki}

A model companion of $T$ is a <model-complete theory> $T^*$ in the same language with $T^*_\forall=T_\forall$. Equivalently each model of either theory embeds into a model of the other. Alternating these embeddings and using the <elementary chain theorem> proves uniqueness up to logical equivalence. A model companion need not be a syntactic extension of its original theory.

= Theory of real closed fields
{title2=$\mathrm{RCF}$}
{c}
{parent=Model-complete theory}

= RCF
{c}
{synonym}

This is the complete <first-order theory> of <real closed fields>.

The theory of real closed fields is complete and model-complete. In the language of ordered rings it eliminates quantifiers; in the pure language of rings its definable order prevents quantifier elimination.

= Quantifier elimination for ordered real closed fields
{parent=Theory of real closed fields}

= Tarski quantifier elimination theorem
{c}
{synonym}

In the language of ordered rings, the <theory of real closed fields> has <quantifier elimination>. In its pure ring reduct the order is definable by nonzero squares, so model completeness survives, although quantifier elimination does not. Keeping these two language conventions separate is essential when constructing a <model companion>.

= Non-Archimedean real closed field
{c}
{parent=Theory of real closed fields}

A non-Archimedean real closed field contains a positive element larger than every standard integer. Compactness constructs one by adjoining a constant $c$ and the formulas $c>n$ for all natural numbers $n$.

= Model-theoretic proof of Hilbert's seventeenth problem
{c}
{parent=Theory of real closed fields}

Model completeness of real closed fields transfers positivity of a rational function from $\mathbb R$ to real closed extensions of $\mathbb R$. If the function were not a sum of squares, the Artin-Schreier ordering criterion would produce a real closure in which it is negative, giving a contradiction.

= Ehrenfeucht-Mostowski model
{c}
{parent=Model theory}
{wiki}

An Ehrenfeucht-Mostowski model is generated, often as a Skolem hull, by a sequence of order indiscernibles whose finite order types determine their types.

= Order-indiscernible sequence
{parent=Ehrenfeucht-Mostowski model}

A sequence $(a_i)_{i\in I}$ indexed by a <total order> is order-indiscernible when any two increasing finite subsequences of the same length satisfy the same first-order formulas.

= Ehrenfeucht-Mostowski theorem
{c}
{parent=Ehrenfeucht-Mostowski model}
{wiki=Ehrenfeucht–Mostowski_theorem}

Let $M$ be an infinite <first-order structure> and $I$ a <total order>. After choosing a <Skolem expansion> of $M$, an <elementary extension> contains distinct elements $(a_i)_{i\in I}$ forming an <order-indiscernible sequence> in that expanded language. Their <Skolem hull> is an <elementary substructure> in the expanded language, and its reduct is a <first-order model> of $\operatorname{Th}(M)$. Every <order automorphism> of $I$ extends uniquely to a <structure automorphism> of the hull preserving the chosen <Skolem expansion>, by transporting terms in the generators.

Uniqueness need not hold among all <structure automorphisms> of the reduct. For an infinite structure in the pure <logical equality> language, take two distinct nullary <Skolem function> values $c_0,c_1$ in the hull. For an infinite <order-indiscernible sequence>, neither can equal a generator: the expanded formula $x=c_j$ would otherwise hold at every generator, contradicting their distinctness. Swapping $c_0,c_1$ fixes every generator and preserves the pure <logical equality> reduct, while failing to preserve the <Skolem expansion>. Thus the identity <order automorphism> already has two extensions in that reduct.

= Ultraproduct proof of the Ehrenfeucht-Mostowski theorem
{parent=Ehrenfeucht-Mostowski theorem}

Expand an infinite <first-order structure> by <Skolem functions>, choose distinct elements $b_n$, and fix a <nonprincipal ultrafilter> $\mathcal U$ on $\mathbb N$. For each finite subset $F$ of the required index order, form the <ultrapower> over $\mathbb N^F$ using the ordered <Fubini product of ultrafilters>. Pullback along coordinate projections gives coherent elementary maps by the <Łoś theorem>. In their <directed limit of elementary embeddings>, the classes of the coordinate <functions> $\mathbf n\mapsto b_{n_i}$ are distinct and form an <order-indiscernible sequence>; every <first-order formula> on increasing coordinates has the same nested <ultrafilter> test. Their <Skolem hull> gives an <Ehrenfeucht-Mostowski model>. An index-<order automorphism> sends a term in the generators to the same term in the transported generators; indiscernibility makes this well defined. Uniqueness is in the specified <Skolem expansion>, not necessarily in its reduct. If generators must respect a definable infinite order, first produce an increasing <sequence> by an <ultrapower> of finite increasing chains.

= Models with arbitrarily large automorphism groups
{parent=Ehrenfeucht-Mostowski theorem}

Every first-order theory with an infinite model has models whose <automorphism group of a first-order structure>[automorphism groups] have arbitrarily large cardinality. Choose a total order with many order automorphisms and apply the <Ehrenfeucht-Mostowski theorem>.

= Prime model
{parent=Model theory}
{wiki}

A prime model of a complete theory elementarily embeds into every model of that theory.

= Atomic model
{parent=Prime model}
{wiki}

A model is atomic when the complete type over the empty set of every finite tuple is isolated. For a complete theory in a countable language, a model is prime exactly when it is countable and atomic.

= Countable atomic model without a countable saturated model
{parent=Atomic model}

Take a countable structure with countably many independent unary predicates, every finite predicate pattern realized infinitely often, and a constant naming every element. Its complete theory has an <atomic model>: tuples of named elements have types isolated by equations to their names. But every infinite binary predicate pattern, together with inequalities to every named element, is consistent. There are uncountably many such one-types, so no countable <omega-saturated model> exists. Thus existence of a countable atomic model does not imply existence of a countable saturated one.

= Countable atomic model is prime
{parent=Atomic model}

A countable atomic model of a complete theory elementarily embeds into every model. Enumerate it and recursively extend a finite partial elementary map; an isolating formula for the next joint type guarantees a realization in the target.

= One-point extension between atomic models
{parent=Atomic model}

If $M,N$ are infinite atomic models of a complete theory and a finite partial elementary map sends $\bar a$ to $\bar b$, then for every $c\in M$ there is $d\in N$ extending it by $c\mapsto d$. An isolating formula for $\operatorname{tp}(\bar a,c)$ supplies $d$. Back-and-forth therefore makes any two countable atomic models isomorphic.

= Quantifier elimination
{parent=Model theory}
{wiki}

A theory has quantifier elimination when every formula is equivalent modulo the theory to a quantifier-free formula.

= Extension axioms for an unrestricted binary relation
{parent=Quantifier elimination}

For a binary relation with no symmetry or loop restrictions, an extension axiom demands a fresh element realizing any prescribed choices of incoming edges, outgoing edges and its own loop relative to a finite list of distinct parameters. All such axioms together eliminate quantifiers: the quantifier-free type of a parameter tuple determines which witness patterns can occur. These axioms differ from the undirected loop-free <theory of the random graph>.

= Common-substructure test for quantifier elimination
{parent=Quantifier elimination}

A theory $T$ eliminates quantifiers if, whenever two models of $T$ contain isomorphic copies of the same substructure $A$, they satisfy the same formulas over $A$. Equivalently, $T\cup D(A)$ is complete for every substructure of a model of $T$.

= Existential common-substructure test for quantifier elimination
{parent=Common-substructure test for quantifier elimination}

= QET1
{c}
{synonym}

For a <first-order theory> $T$, suppose every existential <quantifier-free formula> over a common <substructure> has a witness in either of two $T$-models exactly when it has one in the other. Then $T$ has <quantifier elimination>. One may test a single quantified variable, since elimination of these formulas inductively eliminates all quantifiers. A language with a constant avoids empty-generated-substructure and quantifier-free-sentence conventions.

= Algebraically prime extension test for quantifier elimination
{parent=Existential common-substructure test for quantifier elimination}

= QET2
{c}
{synonym}

If $T$ has <algebraically prime models> and every inclusion between models of $T$ is a <simple closure>, then $T$ has <quantifier elimination>. For a common base $A$, embed its algebraically prime extension into both models. Simple closure transfers a witness into that extension; the second embedding transfers it to the other model.

= Partial embedding
{parent=Quantifier elimination}

= Partial isomorphism of structures
{synonym}

A partial embedding is an injective map between subsets of structures that preserves and reflects atomic formulas. It therefore preserves every quantifier-free formula.

= Quantifier elimination for algebraically closed fields
{parent=Quantifier elimination}

The theory of algebraically closed fields of a fixed characteristic eliminates quantifiers in the language of rings. Over a parameter field $F$, the complete type of a tuple is determined by the prime ideal of polynomial relations it satisfies.

= Type space of an algebraically closed field over a subfield
{title2=$S_n(F)$}
{parent=Quantifier elimination for algebraically closed fields}

Complete $n$-types over a subfield $F$ of an algebraically closed field correspond to prime ideals of $F[X_1,\ldots,X_n]$, or equivalently to generic points of irreducible affine varieties over $F$. The Stone topology corresponds to the constructible topology: polynomial equalities and inequalities define basic clopen sets.

= Theory of the random graph
{title2=$T_{\mathrm{rg}}$}
{parent=Quantifier elimination}

The theory of the random graph says that the edge relation is irreflexive and symmetric and that, for every two finite disjoint vertex sets, a new vertex is adjacent to every vertex of the first and none of the second.

= Quantifier elimination for the random graph
{parent=Theory of the random graph}

Every small partial embedding of a monster random graph extends by back-and-forth to an automorphism, using saturation and the extension axioms. It is therefore elementary, and the theory of the random graph eliminates quantifiers.

= Algebraic and definable closure in the random graph
{title2=$\operatorname{acl}(A)=\operatorname{dcl}(A)=A$}
{parent=Theory of the random graph}

For every small set $A$ in a monster random graph,
$$
\operatorname{acl}(A)=\operatorname{dcl}(A)=A.
$$
Any vertex outside $A$ has infinitely many conjugates over $A$ with the same adjacency pattern.

= Three-type space of the random graph
{title2=$S_3(T_{\mathrm{rg}})$}
{parent=Theory of the random graph}

The three-types of the random graph are determined by equality and adjacency among three variables. There is one all-equal type, six types with exactly two variables equal, and eight types with all variables distinct, for a total of fifteen.

= Back-and-forth method
{parent=Quantifier elimination}
{wiki}

The back-and-forth method constructs an isomorphism by alternately extending finite partial isomorphisms to include elements from each structure.

= Effective back-and-forth construction
{parent=Back-and-forth method}

An effective back-and-forth construction alternately extends a finite <partial isomorphism of structures> to include the least unused domain and range elements, searching computably for a compatible extension. If extension always exists and its finite compatibility conditions are decidable, the union is a <computable isomorphism>. Decidable presentations of a <dense linear order without endpoints> provide a basic example.

A dense linear order without endpoints is a linear order in which a third point lies strictly between every two distinct points and every point has points both below and above it.

{c}

Add constants $c_0<c_1<\cdots$ to the theory of <dense linear orders without endpoints>. The three countable models have respectively a least upper bound for the named sequence, no upper bound, or upper bounds with no least one. The unbounded model is an <atomic model>; the bounded model with no least upper bound is an <omega-saturated model>. The remaining model omits the type $c_i<x<d$ over its least-upper-bound parameter $d$.

= Ultraproduct
{title2=$\prod_iM_i/\mathcal U$}
{parent=Model theory}
{wiki}

An ultraproduct identifies two sequences when they agree on a set belonging to an ultrafilter and interprets symbols coordinatewise.

= Countable saturation of an ultraproduct over omega
{parent=Ultraproduct}

An <ultraproduct> over a <nonprincipal ultrafilter> on $\omega$ realizes each countable finitely satisfiable type. For the first $n$ formulas, their coordinate simultaneous-witness set $E_n$ belongs to the ultrafilter by the <Łoś theorem>. Replace it by $E_n\cap[n,\infty)$ and choose at coordinate $i$ a witness to as many initial formulas as that coordinate permits. This finite number tends to infinity modulo the ultrafilter, so the resulting product class realizes every formula. More generally countably incomplete ultrafilters admit the same descending-set diagonalization. This statement does not assert saturation at every larger cardinal.

= Ultrapower
{title2=$M^I/\mathcal U$}
{parent=Ultraproduct}

An ultrapower is an <ultraproduct> whose factors are all one structure $M$. Its elements are equivalence classes $[f]$ of functions $f:I\to M$, where $f\sim g$ exactly when $\{i\in I:f(i)=g(i)\}$ belongs to the chosen <ultrafilter> $\mathcal U$.

= Model-theoretic ultralimit
{parent=Ultrapower}

An ultralimit is the direct limit of a chain of structures formed by taking successive <ultrapowers> along their diagonal <elementary embeddings>. At limit stages use the <elementary chain theorem>. This is a different concept from a topological <ultrafilter limit>. Alternating relative ultrapower embeddings constructs isomorphic ultralimits of any two elementarily equivalent structures, without requiring the stronger single-ultrapower isomorphism theorem.

= Alternating ultrapowers give isomorphic ultralimits
{parent=Model-theoretic ultralimit}
{title2=$A\equiv B\Longrightarrow A_\infty\cong B_\infty$}

= Frayne theorem
{c}
{synonym}

The <Frayne embedding lemma> embeds $B$ into an <ultrapower> $A_1$ of $A$. Its relative version embeds $A_1$ into an ultrapower $B_1$ of $B$, fixing the diagonal copy of $B$. Continue alternately over the previously fixed elementary substructure. After coherent identifications one has $B\preceq A_1\preceq B_1\preceq A_2\preceq B_2\preceq\cdots$, while each $A_{n+1}$ is an ultrapower of $A_n$ along its diagonal map, and similarly for $B$. The two cofinal subsequences have the same elementary union. This proves the ultralimit assertion without the stronger single-ultrapower isomorphism theorem.

= Frayne embedding lemma
{c}
{parent=Model-theoretic ultralimit}

If $A\equiv B$, the elementary diagram of $B$ is finitely satisfiable by interpreting its finitely many named elements in $A$. Choose those finite realizations as coordinates, extend the filter of diagram cones to an <ultrafilter>, and use the <Łoś theorem> to embed $B$ elementarily into an <ultrapower> of $A$. If $A\prec B$, work over the named elements of $A$ and keep their coordinates constant. The resulting embedding extends the diagonal map of $A$. This relative assertion allows an alternating chain of ultrapowers to keep every previously embedded substructure fixed.

= Diagonal argument for ultrapower cardinality
{parent=Ultrapower}
{title2=$|M^\kappa/U|>\kappa$}

If $U$ is a <kappa-complete> <nonprincipal ultrafilter> on $\kappa$ and $|M|\geq\kappa$, then $|M^\kappa/U|>\kappa$. Otherwise enumerate representatives $f_\alpha$ for its classes and choose $g(i)\notin\{f_\alpha(i):\alpha<i\}$. Every tail of $\kappa$ belongs to $U$, so $g$ differs modulo $U$ from every representative. The <small set is absent from a complete nonprincipal ultrafilter> lemma supplies the tail property.

= Łoś theorem
{c}
{parent=Ultraproduct}

This theorem characterizes truth in an <ultraproduct>. Łoś's theorem says that a first-order formula holds in an ultraproduct exactly when it holds in a set of factors belonging to the ultrafilter.

= Dense-extension filter semantics
{parent=Łoś theorem}
{title2=$F\Vdash\phi$}

For a family of <first-order structures>, take <free filters> on the index set as worlds, ordered by inclusion, and product sequences as parameters. Force an atom when its coordinate truth set belongs to the filter. Conjunction is local, implication and negation quantify over filter extensions, and a disjunction is forced when every extension has a further extension forcing one disjunct. Existence is witnessed by a product sequence and universality holds for all sequences at all extensions. With the <axiom of choice>, induction on formulas identifies forcing with membership of the classical coordinate truth set. Equivalently, every ultrafilter extension satisfies the formula in its <ultraproduct>. Thus the semantics validates classical logic. A local disjunction rule would fail this identification: a set and its complement can both be absent from a free filter, while their union is the whole index set.

= Infinite field of positive characteristic from an ultraproduct
{parent=Łoś theorem}

For a <prime number> $p$, a <nonprincipal ultrafilter> on $\mathbb N$ gives
$$
K=\prod_{n\geq1}\mathbb F_{p^n}/\mathcal U.
$$
The <Łoś theorem> makes $K$ a <field> of <characteristic of a field>[characteristic] $p$. For every natural number $m$, almost all factors have at least $m$ elements, so $K$ is infinite.

= Elementary extension
{parent=Model theory}

An <elementary extension> is an extension preserving all first-order truth with parameters, hence giving <elementary equivalence>. An extension $N\supseteq M$ is elementary when every formula with parameters from $M$ has the same truth value in both structures.

= Saturated model
{parent=Elementary extension}
{wiki}

A model $N$ is $\kappa$-saturated when every complete type over a subset of size less than $\kappa$ is realized in $N$.

= Omega-saturated model
{parent=Saturated model}
{title2=$\omega$-saturated}

A model is omega-saturated when it realizes every complete finite-tuple type over any finite parameter set. Realizing all one-variable types over finite parameter sets suffices by successively adjoining coordinates. This is weaker than saturation over every countable parameter set.

= Saturated elementary extension theorem
{parent=Saturated model}
{title2=$M\preccurlyeq N,\quad N\text{ is }\kappa\text{-saturated}$}

For every infinite regular <cardinal> $\kappa$, every <first-order structure> has a $\kappa$-saturated <elementary extension>. At one stage use the <compactness theorem> with the <elementary diagram> to realize all <complete types> over <subsets> of the stage having size less than $\kappa$. There is a <set> of such types; finite <subsets> of the enlarged theory are satisfiable because their finitely many witnesses are independent. Iterate for $\kappa$ stages, taking elementary <unions> at limits. Regularity puts any parameter <set> of size less than $\kappa$ inside one stage, and its type is realized at the next one. Passing to a larger <regular cardinal> covers singular requested degrees of saturation as well.

= Countable saturation of a nonprincipal ultraproduct over omega
{parent=Saturated model}
{title2=$\aleph_1\text{-saturation}$}

In a <countable> language, an <ultraproduct> over a <nonprincipal ultrafilter> on $\omega$ realizes every <countable> finitely satisfiable type, including types over countably many parameters. Enumerate the type $\varphi_1,\varphi_2,\ldots$, and let $A_n$ be the ultrafilter-large <set> of coordinates where the first $n$ <first-order formulas> have a simultaneous witness. Put $B_n=\{i:i\geq n\}\cap\bigcap_{j\leq n}A_j$. At coordinate $i$, choose a witness for the largest $n\leq i$ with $i\in B_n$, or an arbitrary element when there is none. For each fixed $n$, the resulting <function> satisfies the first $n$ <first-order formulas> on $B_n$. The <Łoś theorem> then realizes the entire type. Countability of the language and parameter <set> makes the enumeration possible.

= Saturation implies homogeneity
{parent=Saturated model}

A $\kappa$-saturated model has the one-point extension property for partial elementary maps of size below $\kappa$: transport the type of the new element through the map and realize it by saturation. This is $\kappa$-homogeneity; back-and-forth gives the corresponding automorphisms when cardinalities permit.

= Homogeneity plus realization of empty-set types implies saturation
{parent=Saturated model}

= Saturation
{synonym}

If an aleph-zero-homogeneous model realizes every finite type over the empty set, it is aleph-zero-saturated. Realize the joint empty-set type of the parameters and a desired element, then use homogeneity to move the realized parameter tuple to the given one.

= Universal model
{parent=Saturated model}

A model $N$ of cardinality $\kappa$ is universal when every model of the same complete theory having cardinality less than $\kappa$ admits an elementary embedding into $N$.

= Homogeneous model
{parent=Saturated model}

A model $N$ of cardinality $\kappa$ is homogeneous when every partial elementary map between subsets of size less than $\kappa$ extends to an automorphism of $N$.

= Universal homogeneous model is saturated
{parent=Saturated model}

A universal homogeneous model realizes every type over a small parameter set. Embed a small model containing a realization into the universal model, then use homogeneity to move the embedded parameters back to the original ones.

= Small elementary submodel meeting every definable equivalence class
{parent=Saturated model}

Let $N$ be uncountable and saturated, and let a formula define an equivalence relation. If every small elementary submodel of $N$ meets every class, then there are only finitely many classes. Otherwise a small elementary submodel $M$ yields the finitely satisfiable type $\{\neg E(x,m):m\in M\}$, contradicting saturation.

= Elementary chain theorem
{parent=Elementary extension}
{wiki}

The union of an elementary chain of structures has a unique induced structure, and every member of the chain is an elementary substructure of the union.

= Directed limit of elementary embeddings
{parent=Elementary chain theorem}

A directed system of <first-order structures> and coherent <elementary embeddings> has a direct limit into which every member embeds elementarily. Represent an element by a pair consisting of a stage and an element at that stage; identify two representatives when their images agree at a common later stage. Interpret <functions> and relations at a common stage. <Mathematical induction> on <first-order formulas> proves elementarity: for an existential <first-order formula> true at the limit, its witness and parameters occur at a common stage, and elementarity pulls truth back to the stage containing the original parameters. This generalizes the <elementary chain theorem> beyond linearly ordered diagrams.

= Complete type
{parent=Elementary extension}

The complete type of a tuple over parameters records every formula over those parameters that the tuple satisfies.

= Algebraic type
{parent=Complete type}

A complete type is algebraic when it contains a formula having finitely many realizations in a model of the theory. A one-element example is the type containing $x=c$ for a named constant. Such a type cannot gain infinitely many realizations in an <elementarily equivalent> structure. An <isolated type> need not be algebraic: the unique empty-set one-type in a <dense linear order without endpoints> is isolated by $x=x$ and has infinitely many realizations.

= Type space
{title2=$S_n(A)$}
{parent=Complete type}

With its standard topology, this <type space> is a <Stone space>. The type space $S_n^M(A)$ is the set of complete $n$-types over a parameter set $A$ that are consistent with the complete theory of $M$ together with its diagram over $A$.

= Stone topology on a type space
{parent=Type space}
{c}
{title2=$[\varphi]=\{p:\varphi\in p\}$}

For a <type space> $S_n^M(A)$, the basic open set $[\varphi]$ consists of complete types containing the formula $\varphi$. These sets are clopen, satisfy $[\varphi]\cap[\psi]=[\varphi\wedge\psi]$, and distinguish distinct types. The <compactness theorem> makes this topology compact; it is Hausdorff and has a basis of clopen sets.

= Isolated type
{parent=Type space}
{wiki}

= Isolated A-type
{synonym}

A complete type $p\in S_n(A)$ is isolated when some formula $\varphi\in p$ belongs to no other complete type in $S_n(A)$. Equivalently, the basic open set determined by $\varphi$ is the singleton $\{p\}$.

= Density of isolated types from a prime model
{parent=Isolated type}

If a complete countable theory has a prime model, isolated types are dense in every finite-arity type space. Every nonempty basic open set is realized in the prime model, whose finite tuples have isolated types.

= Omitted type
{parent=Type space}

A type $p(x_1,\ldots,x_n)$ is omitted in a structure $M$ when no tuple from $M^n$ realizes every formula in $p$.

= Omitting types theorem
{parent=Omitted type}
{wiki}

Let $T$ be a consistent theory in a countable first-order language. For every countable family of nonisolated finite-arity types of $T$, there is a countable model of $T$ that omits every type in the family.

= Henkin omission extension lemma
{parent=Omitting types theorem}
{c}

Let $p(\mathbf x)$ be a <nonprincipal partial type> over a consistent <first-order theory> $T$. Suppose $T\cup\{\sigma(\mathbf c)\}$ is consistent, with $\sigma$ a finite condition in finitely many new constants, and let $\mathbf t(\mathbf c)$ be a tuple of closed terms. Some $\psi\in p$ leaves $T\cup\{\sigma(\mathbf c),\neg\psi(\mathbf t(\mathbf c))\}$ consistent. Otherwise the original-language <first-order formula>
$$
\theta(\mathbf x)=\exists\mathbf z\bigl(\sigma(\mathbf z)\land\mathbf x=\mathbf t(\mathbf z)\bigr)
$$
is consistent with $T$ and entails every member of $p$, contradicting nonprincipality. Replace all new constants occurring in the condition or terms by variables. This lemma makes the omission requirements dense in a countable <Henkin construction>.

= Realization of a type in an elementary extension
{parent=Type space}

Every complete type over parameters from $M$ is realized in some elementary extension of $M$. Apply compactness to the elementary diagram of $M$ together with a new tuple of constants satisfying the type.

= Total disconnectedness of a type space
{parent=Type space}

Distinct complete types contain opposite choices $\varphi$ and $\neg\varphi$. The corresponding basic clopen sets partition the type space, so every type space is totally disconnected.

= One-types over the natural numbers in the rational order
{title2=$S_1^{(\mathbb Q,<)}(\mathbb N)$}
{parent=Type space}

Quantifier elimination for dense linear orders shows that the one-types over $\mathbb N\subset\mathbb Q$ are determined by cuts: equality to a natural number, one of the intervals between consecutive natural numbers, the ray below zero, or the cut above every natural number. Only the last type is non-isolated.

= Aleph-zero-homogeneous model
{title2=$\aleph_0$-homogeneous}
{parent=Complete type}

A model is aleph-zero-homogeneous when every finite partial elementary map extends by one more element.

= Stable theory
{parent=Model theory}
{wiki}

A complete theory is $\kappa$-stable when $|S_1(A)|\leq\kappa$ for every parameter set $A$ of cardinality $\kappa$. It is omega-stable when this holds for $\kappa=\aleph_0$.

= Fundamental theorem of stability
{parent=Stable theory}

For a complete theory, the following are equivalent: the theory is stable; no formula has the <order property>; and every complete type over every model is definable.

= Definable type
{parent=Fundamental theorem of stability}
{wiki}

A type $p(x)$ over a model $M$ is definable when, for every formula $\varphi(x;y)$, there is an $M$-formula $d_p\varphi(y)$ such that
$$
\varphi(x;b)\in p
\quad\Longleftrightarrow\quad
M\models d_p\varphi(b)
$$
for every tuple $b$ from $M$.

= Stable trace of a definable set
{parent=Definable type}

If $T$ is stable, $M\preccurlyeq N\models T$, and $X\subseteq N^n$ is definable with parameters from $N$, then $X\cap M^n$ is definable with parameters from $M$. Apply definability of the type over $M$ of the parameter defining $X$.

= Omega-stability implies stability in every infinite cardinal
{parent=Stable theory}

For a countable theory, omega-stability implies $|S_n(A)|\leq|A|+\aleph_0$ for every parameter set $A$. Total transcendence gives each type a finite base and a definition over it; counting finite bases and formulas proves the bound.

= Order property
{parent=Stable theory}

A formula $\phi(\bar x,\bar y)$ has the order property for $T$ when arbitrarily long tuples $(a_i),(b_j)$ exist with $\phi(a_i,b_j)$ exactly when $i<j$. Compactness realizes this pattern along every linear order.

= Order property implies instability
{parent=Order property}

If a theory has the order property, a linear order with more than $\kappa$ cuts over a dense subset of size at most $\kappa$ produces more than $\kappa$ distinct types over that subset. Hence a theory with the order property is not $\kappa$-stable for any $\kappa\geq|T|$.

= Strongly minimal theory
{parent=Model theory}
{wiki}

A complete theory is strongly minimal when every definable one-variable subset of every model is finite or cofinite.

= Model-theoretic algebraic closure
{title2=$\operatorname{acl}(A)$}
{parent=Strongly minimal theory}

An element belongs to $\operatorname{acl}(A)$ when it lies in a finite set definable with parameters from $A$.

= Model-theoretic definable closure
{title2=$\operatorname{dcl}(A)$}
{parent=Model-theoretic algebraic closure}

An element belongs to $\operatorname{dcl}(A)$ when it is the unique realization of some formula with parameters from $A$. Equivalently, it is fixed by every automorphism fixing $A$ pointwise.

= Pregeometry
{parent=Model-theoretic algebraic closure}

A <pregeometry> is a finitary closure structure with the exchange axiom, extending the closure description of a <matroid> to possibly infinite underlying sets. A pregeometry is a closure operator with finite character and exchange. Algebraic closure in a strongly minimal theory is a pregeometry.

= Basis of a pregeometry
{parent=Pregeometry}

A basis of a pregeometry is a maximal independent set. Every element lies in the closure of a basis, and the exchange property implies that all bases have the same cardinality.

= Dimension of a pregeometry
{parent=Basis of a pregeometry}

The dimension of a closed set over a smaller closed set is the cardinality of any basis of the larger set over the smaller one. The exchange property makes this cardinality independent of the chosen basis.

= Generic type in a strongly minimal theory
{parent=Pregeometry}

Over an algebraically closed parameter set in a strongly minimal theory, there is a unique nonalgebraic one-type. It is called the generic type: its realizations are precisely the elements outside the algebraic closure of the parameters.

= Independent set in a strongly minimal theory
{parent=Pregeometry}

A set is independent when no element lies in the algebraic closure of the others. Every bijection between independent sets in a strongly minimal monster model is elementary because successive independent elements realize the unique generic type over the algebraic closure of their predecessors.

= Homogeneity of models of a countable strongly minimal theory
{parent=Strongly minimal theory}

In a countable strongly minimal theory, every model is homogeneous. Extend a finite partial elementary map over algebraic closures, choose bases of equal dimension for the remaining pregeometry, map one basis bijectively to the other, and extend over algebraic closure.
