Submodular rank function (r:2E→Z≥0​)

 Home Mathematics Area of mathematics Combinatorics Matroid Rank of a matroid
OurBigBook.com Words: 188
On a finite ground set E, a submodular rank function is a normalised set function r with r(∅)=0, a monotone set function, and a submodular set function, such that r(A∪{e})−r(A)∈{0,1} for e∈/A. Equivalently, require nonnegative integer values, monotonicity, submodularity and r({e})≤1. The diminishing returns characterization of submodularity bounds each marginal by its singleton value. Thus 0≤r(A)≤∣A∣.
These functions are precisely the rank functions of matroids. To see the converse direction, define I={A:r(A)=∣A∣}. It contains the empty set. If B⊆A∈I, the unit marginal bounds give ∣A∣=r(A)≤r(B)+∣A∖B∣, so r(B)=∣B∣ and heredity holds. For augmentation, suppose A,B∈I with ∣A∣<∣B∣. If every e∈B∖A had zero marginal over A, diminishing returns would keep each marginal zero as they are added successively. This would give r(A∪B)=r(A)=∣A∣<∣B∣=r(B), contradicting monotonicity. Some marginal is therefore one, giving an independent augmentation.
Finally any inclusion-maximal I⊆A in this independence family has r(I∪{e})=r(I) for every remaining e∈A∖I. Successively adding them and using diminishing returns shows r(A)=r(I)=∣I∣, so the resulting matroid really has rank r. The forward direction is submodularity of matroid rank. These integer increment conditions distinguish matroid ranks from arbitrary real-valued submodular functions.
