Normalized intermediate-axis model ((I1​,I2​,I3​)=(1,2,3))

Choose an inertia unit I∗​ and an angular speed unit Ω∗​>0, so physical principal moments of inertia are I∗​(1,2,3), physical angular velocity is Ω∗​ω, and normalized time is t=Ω∗​tphysical​. The Euler equations for a torque-free rigid body become
ω˙1​=−ω2​ω3​,ω˙2​=ω3​ω1​,ω˙3​=−31​ω1​ω2​.
(9)
This is a physically admissible ideal planar mass distribution: I3​=I1​+I2​ is the perpendicular axis theorem. A book of finite thickness need not have these exact ratios.
For an original comparison, start with angular velocity (1,ε,0), (ε,1,0) or (ε,0,1), respectively. With ε=0.01, the transverse Euclidean norm stays small about axes one and three, but becomes order one about axis two. For the intermediate-axis start, its linearization gives
ω1​≃εcosh(t/3​),ω3​≃−3​ε​sinh(t/3​),ω2​≃1.
(10)
The hyperbolic functions contain a growing exponential function with rate λ2​=1/3​. Reducing ε tenfold delays reaching the same small transverse amplitude by approximately 3​log10≃3.99 normalized time units, once the growing term dominates. That delays the instability. Once the transverse angular velocity is comparable to the main component, the linearization ceases to describe the motion.
