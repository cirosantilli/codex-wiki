Minimum image norm outside a Euclidean unit ball (min∥x∥≥1​∥Ax∥=λmin​(ATA)​)

 ... Mathematics Area of mathematics Algebra Linear algebra Singular value decomposition Singular value
OurBigBook.com Words: 112
For a real matrix A, let B=ATA. It is positive semidefinite, and the spectral theorem for real symmetric matrices gives xTBx≥λmin​∥x∥2. If λmin​>0, rescaling any longer vector to unit length decreases its image norm, so minimizers lie on the unit sphere. Lagrange multipliers applied to xTBx with ∥x∥=1 give Bx=λx. Thus the minimizers are exactly the unit vectors in the least eigenspace.
If λmin​=0, the minimum is zero and the full argmin consists of all x∈kerA with ∥x∥≥1. Indeed, ker(ATA)=kerA because xTATAx=∥Ax∥2. Restricting the minimizers to the sphere would omit longer kernel vectors in this case. For a ball constraint ∥x∥≤1, the argmin is always kerA intersected with the ball.
