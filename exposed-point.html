Exposed point

 Home Mathematics Area of mathematics Mathematical optimization Convex set Extreme point
OurBigBook.com Words: 133
An exposed point is a point uniquely selected by maximizing a linear functional. In Rd, a point p of a convex set C is exposed if some vector c satisfies
cTp>cTz(z∈C, z=p).
(12)
Geometrically, a supporting hyperplane touches the convex set only at p. Every exposed point is an extreme point: a convex combination that attains the maximum can put positive weight only on maximizers, and there is only one.[ref]
The unit disk calculation in extreme point exposes every point of the unit circle. For a corner (a,b) of the square, c=(a,b) exposes it: ax+by attains two only at (a,b). However, maximizing x exposes no single point on the right edge, since all of them have the same objective value. A linear functional may have several optimal points, even when some of them are extreme.
