Graph (G=(V,E))

 Home Mathematics Area of mathematics Foundations of mathematics Graph theory
OurBigBook.com Words: 5k Articles: 84
A graph describes objects, called vertices, and pairwise connections, called edges. Its vertex set V tells us what the objects are; E records their connections. The basic abstraction retains graph adjacency while discarding positions, angles and Euclidean distances: moving the dots in a drawing changes none of the edges. A crossing of two drawn lines is not an extra vertex unless explicitly designated as one. Even the labels can change: a graph isomorphism is a relabelling that preserves graph adjacency in both directions.[ref]
This makes graphs useful when the question concerns possible connections rather than physical shape. For example, model locations by vertices and direct links by edges; a graph path answers whether one location can reach another. Alternatively, let vertices be activities and edges represent conflicts: a graph coloring then assigns compatible time slots. These are mathematical models, so one must decide which pairwise relationship an edge means before applying graph theory.[ref]
Our running simple graph has
V={A,B,C,D,E,F},E={AB,AC,BC,CD,DE,DF,EF},
(1)
where AB abbreviates the unordered pair {A,B}. It consists of two triangles in a graph, ABC and DEF, joined by CD. The two drawings above have identical graph adjacency, even though their apparent lengths differ. What counts is that C and D are adjacent, whereas A and F are not.
Route questions require precise vocabulary. A walk is a sequence of consecutive adjacent vertices, permitting repetitions; its length counts traversed edges. A trail is a walk that repeats no edge; a graph path repeats no vertex. For a multigraph, the walk must also specify which parallel edge each step uses. For instance, A,B,A,C,D,F is a length-five walk but not a trail, since it uses AB twice. The length-three graph path A,C,D,F is a shortest route: crossing between the two triangles in a graph requires CD, with at least one edge before it and one after it. Thus d(A,F)=3 in graph distance, regardless of the drawing.[ref]
An Eulerian trail uses every edge exactly once, allowing repeated vertices; a Hamiltonian path visits every vertex exactly once, without needing every edge. Here C,A,B,C,D,E,F,D is an Eulerian trail of length seven, whereas A,B,C,D,E,F is a Hamiltonian path of length five. The first repeats C,D; the second omits AC,DF. Calling an Eulerian trail an "Eulerian path" must not be taken to impose our graph path convention.[ref]
The classic historical example is Euler's Königsberg bridge problem: represent the four land regions by vertices and the seven bridges by distinct edges, giving a multigraph. Their degrees of vertices are 3,3,3,5. In a trail using every edge, arrivals and departures pair at every internal vertex, so at most the two endpoints can have odd vertex degree. Four odd degrees of vertices therefore rule out such a route. This early foundational example of graph theory needs neither bridge lengths nor a geographical map. Euler's paper is conventionally associated with 1736, the volume's nominal year; the Euler Archive records its writing in 1735 and publication in 1741.[ref][ref]

Edge set (E(G))

Words: 37
Graph OurBigBook.com
The set of edges of a specified graph. In a simple graph, an edge is determined by its endpoints; a multigraph additionally distinguishes parallel edges with the same endpoints. A subgraph can be specified by selecting a vertex set and an edge set whose endpoints belong to it.

Monotone threshold activation (v activates when ∣N(v)∩A∣≥tv​)

Words: 228 Articles: 1
Graph OurBigBook.com
In a finite graph, start with an active vertex set A0​ and thresholds tv​. An inactive vertex becomes active once sufficiently many neighbours are active, and activated vertices remain active. Add eligible vertices until no more can be added. If C is any threshold-closed set containing A0​, induction shows every activated vertex lies in C. The terminal active set is itself closed, so it is the least such closure and is independent of the eligible-vertex processing order.
For integer thresholds, compute active-neighbour counts and keep a work queue of vertices newly reaching their thresholds. Each vertex is queued once and each edge is inspected a constant number of times, giving O(∣V∣+∣E∣) running time. Strict-majority activation has tv​=⌊deg(v)/2⌋+1, so an isolated inactive vertex never qualifies. A maximum priority queue of activation margins is an alternative implementation.

Closure dominance for asynchronous threshold switching

Words: 106
Monotone threshold activation OurBigBook.com
Allow individual vertices to switch in either direction according to a fixed neighbour threshold, while the objective is to maximize the number in one designated state. Let C be the monotone threshold activation closure of the initially designated vertices. At every time in any legal switching sequence, the designated set remains a subset of C: a loss preserves inclusion, while a gain outside C is impossible because all currently designated neighbours lie in C and the outside vertex has too few neighbours there. This induction proves an upper bound of ∣C∣ on every attainable designated population. The monotone sequence attains C itself and is therefore globally optimal. Temporary losses cannot improve this objective.

Simple graph

Words: 335
Graph OurBigBook.com
An undirected simple graph is exactly a pair of sets
G=(V,E),E⊆{{u,v}:u,v∈V, u=v}.
(2)
Thus every edge is a two-element set of distinct vertices. The unordered pair {u,v} equals {v,u}, so there is no direction. The distinctness condition excludes self-loops, and using a set of edges excludes parallel copies. A simple graph may have vertices with no incident edges; E does not by itself determine V. For example, ({A,B},{AB}) and ({A,B,C},{AB}) have the same edge set but different vertex sets.[ref]
In the six-vertex example, the vertex neighbourhood of C is Γ(C)={A,B,D}, so its degree of a vertex is deg(C)=3. In label order A,B,C,D,E,F, the degree sequence is
(2,2,3,3,2,2),∑v∈V​deg(v)=14=2⋅7=2∣E∣.
(3)
This is the handshaking lemma: count each edge once at each of its two endpoints. The average degree of a graph here is 14/6=7/3. The degree sequence is a compact consistency check on an edge list; an odd sum could not describe any finite undirected graph. It also forces the number of odd degrees of vertices to be even, since the even terms do not affect the parity of the sum.
The adjacency matrix in the figure uses label order A,B,C,D,E,F. Its entry Muv​ is one exactly when {u,v}∈E, and zero otherwise. It is a symmetric matrix with zero diagonal, and each row sum gives the corresponding vertex degree. For example, row C is (1,1,0,1,0,0). The fourteen ones count both directions of the seven undirected edges; they do not indicate fourteen different edges. This translates a picture into a representation suitable for calculation.
The restrictions matter. A directed graph uses an ordered pair to distinguish u→v from v→u, so reachability can depend on direction. A multigraph can contain several distinct edges between the same vertices; adding another CD would raise deg(C) and deg(D) to four without adding a new neighbour. A self-loop at A contributes two to its undirected vertex degree, making it four, because both endpoints lie at A. Specify whether self-loops are allowed in a multigraph. Finally, a weighted graph attaches numerical information to edges: if links carry travel times, minimizing the number of edges need not minimize total time. These are changes to the model, rather than changes to how the same simple graph is drawn.

Three-edge path decomposition from a perfect matching

Words: 105
Cubic graph OurBigBook.com
A finite simple graph that is a cubic graph and has a perfect matching admits a partition of a set of its edges into graph paths of length three.
Proof. Delete a perfect matching M. The remaining spanning subgraph has vertex degree two at every vertex, so it consists of disjoint graph cycles. Orient each cyclically, giving a successor bijection s. Replace each uv∈M by the graph path s(u),u,v,s(v). The four vertices are distinct: the successor edges are not in M, neither is a self-loop, and injectivity of s excludes s(u)=s(v). Every edge of M appears once in the middle, and every other edge appears once at its unique tail. Thus the graph paths cover every edge exactly once. In particular, the perfect matching theorem for a cubic graph with at most two bridges guarantees this decomposition under its hypotheses.

Perfect matching theorem for a cubic graph with at most two bridges

Words: 118
Cubic graph OurBigBook.com
Every finite connected cubic graph with at most two bridges has a perfect matching.
Proof. The handshaking lemma implies that the number n of vertices is an even integer. Fix a nonempty subset S of the vertex set, and let q count the components of G−S of odd integer order. For such a component C, counting vertex degrees gives 3∣C∣=2∣E(C)∣+d(C), where d(C) counts its edges to S. Thus d(C) is a positive odd integer. If it is one, the unique outgoing edge is a bridge; this happens for at most two components. For all others d(C)≥3. Therefore 3q−4≤3∣S∣. Meanwhile q≡n−∣S∣≡∣S∣(mod2). If q>∣S∣, the same parity would force q≥∣S∣+2, contradicting the preceding bound. For S=∅ there is one component of even integer order and hence q=0. Apply Tutte's theorem on perfect matchings.

Triangulate a torus using the seven vertices of the complete graph K7​ and oriented triangles (i,i+1,i+3) and (i,i+3,i+2), with indices modulo seven. Haemers rank bound (c(G)≤rankF​A)

A fitting matrix over a field has nonzero diagonal entries and zero entries at distinct nonadjacent vertices. Its tensor powers fit strong graph powers. On an independent set the restricted matrix is diagonal and nonsingular, so its cardinality is at most the matrix rank. This yields the capacity upper bound over every field.

Incidence matrix (Bve​)

Words: 62
Graph OurBigBook.com
A vertex-edge incidence matrix records which vertices are endpoints of each edge of a graph. The unsigned convention uses entries one at the endpoints, with a convention for loops. Choosing an orientation gives the oriented incidence matrix, with minus one at the initial endpoint and plus one at the terminal endpoint. These are different conventions and should be specified when using the matrix in a computation.

Amenable graph

Words: 106 Articles: 1
Graph OurBigBook.com
A bounded-degree infinite graph is amenable when there are finite nonempty vertex sets Wn​ such that ∣∂+Wn​∣/∣Wn​∣→0, where ∂+Wn​ is the set of vertices outside Wn​ adjacent to it. These are graph Følner sets. Amenability makes surface contributions negligible compared with volume. The square lattice and any periodic finite decoration of it are examples.

Følner set (Wn​)

Words: 53
Amenable graph OurBigBook.com
A finite nonempty vertex set in an amenable graph is a Følner set with tolerance ε if its external boundary has size at most ε times its volume. A graph Følner sequence consists of such sets with tolerances tending to zero. For a bounded-degree graph, every fixed-thickness boundary layer also has negligible relative volume along this sequence.

A bouquet graph consists of one vertex and j self-loops. Its vertex has degree 2j, and its graph excess is j−1. The two-loop bouquet is one of the three possible kernels of a bicyclic graph; in a simple subdivision, each loop must expand to a cycle of length at least three.

Graph OurBigBook.com
An automorphism group is transitive on ordered pairs of vertices at every fixed distance. Grassmann graphs provide examples with the finite general linear group as a distance-transitive automorphism group.

Distance-transitive action on a graph

Words: 64
Distance-transitive graph OurBigBook.com
A subgroup of the graph automorphism group acts distance-transitively when it is transitive on the ordered pairs of vertices at each fixed graph distance. Thus two vertex pairs at the same distance can be matched by one automorphism from that subgroup. Existence of such a subgroup implies that the full automorphism group has the same property, making the graph a distance-transitive graph. The specified subgroup need not be the entire automorphism group.

Symplectic dual polar graph (d(U,W)=m−dim(U∩W))

Words: 70
Distance-transitive graph OurBigBook.com
Vertices are Lagrangian subspaces of a 2m-dimensional symplectic vector space, joined when they intersect in codimension one. A pair with intersection dimension m−r admits a symplectic basis in which U=⟨e1​,…,em​⟩ and W=⟨f1​,…,fr​,er+1​,…,em​⟩. Replacing ei​ successively by fi​ gives an isotropic path of length r, while one edge can increase intersection dimension with a fixed target by at most one. Equal-distance ordered pairs have the same adapted form, so the symplectic group acts distance-transitively.

False twin (N(u)=N(v))

Graph OurBigBook.com
Distinct vertices with equal open neighbourhoods are false twins. They are nonadjacent: adjacency would put one vertex in the other's open neighbourhood but not its own. Equal open neighbourhoods define false-twin classes, which are independent sets and have uniform adjacency to every other such class.

False-twin class ([v]={u:N(u)=N(v)})

Words: 45
False twin OurBigBook.com
A false-twin class is an equivalence class of vertices with identical open neighbourhoods. In edge-triangle symmetrization, merging nonadjacent false-twin classes by cloning the better local score never decreases the objective. A secondary maximization of squared class sizes forces all distinct classes to be adjacent, giving a complete multipartite graph.

The jth power of a graph joins distinct vertices whenever their distance in the original graph is at most j. For example, the square of a cycle adds edges connecting vertices two steps apart. Graph powers turn constraints on short paths into adjacency constraints.

In a cycle square, each triple of consecutive vertices is a clique. A proper three-colouring therefore repeats with period three and closes exactly when the length is divisible by three. Graph cut (∂S={{i,j}∈E:i∈S,j∈/S})

A graph cut consists of the edges joining a vertex subset to its complement. In a two-group stochastic block model, crossing and within-group edges have different Bernoulli distributions. Balanced component cut (max(∣V1​∣,∣V2​∣)≤(k+1)n/(2k+1))

Words: 85
Graph cut OurBigBook.com
If every graph component has at most (k+1)n/[k(2k+1)] vertices, assigning whole graph components to two sides gives an empty graph cut with the displayed bound. To prove it, maximize the smaller side's weight S≤n/2. If S<kn/(2k+1), every component on the larger side has weight at least n−2S, because moving a smaller one would improve the smaller side. There are at least k+1 such components, since their total exceeds k times the permitted maximum weight. Thus n−S≥(k+1)(n−2S), a contradiction. The proof also works for arbitrary positive weights.
