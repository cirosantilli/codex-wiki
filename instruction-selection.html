Instruction selection

 Home Computer science Programming language Compiler
OurBigBook.com Words: 36
Choosing target-machine instructions to implement an intermediate representation. A memory operand using register-offset addressing can cover both an address addition and a load or store; computing the full address into a temporary variable can prevent that covering and add an unnecessary instruction.
