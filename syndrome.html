Syndrome (s=HyT)

 ... Mathematics Area of mathematics Algebra Coding theory Linear code Parity-check matrix
OurBigBook.com Words: 126 Articles: 2
The syndrome of a received word y with respect to a parity-check matrix H is s=HyT. It vanishes exactly when y is a codeword and otherwise identifies the coset containing the error pattern.
