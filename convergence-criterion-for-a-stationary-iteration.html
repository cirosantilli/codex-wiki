Convergence criterion for a stationary iteration (Hk→0⟺ρ(H)<1)

 ... Area of mathematics Analysis Numerical analysis Numerical linear algebra Stationary iterative method for a linear system Iteration matrix
OurBigBook.com Words: 274
A stationary iterative method for a linear system converges to its specified fixed point for every initial vector if and only if its iteration matrix satisfies ρ(H)<1, where the spectral radius is the largest modulus of an eigenvalue.[ref]
For a diagonalizable matrix, write H=VΛV−1. Then Hk=VΛkV−1, so each eigenvector coefficient tends to zero exactly when its eigenvalue has modulus less than one. For a general matrix, the Jordan normal form gives the same result: a Jordan block J=λI+K with a nilpotent matrix K of size m satisfies
Jk=∑j=0min(k,m−1)​(jk​)λk−jKj.
(111)
If 0<∣λ∣<1, every coefficient tends to zero because exponential decay beats any fixed polynomial in k; if λ=0, the block vanishes once k≥m. Conversely, an eigenvector with ∣λ∣≥1 provides an initial error that cannot tend to zero. For a real matrix with complex eigenvalues, the same obstruction appears in the real invariant subspace spanned by the real and imaginary parts of an eigenvector.
The words "every initial vector" matter. For example, H=diag(3/2,1/2) fails the criterion, but e(0)=(0,1)T still tends to zero. Here a generic initial error has a nonzero first coordinate and diverges; the exceptional errors lie on the second coordinate axis. With H=diag(−1,1/2), generic errors oscillate rather than diverge in norm, while the same exceptional axis still converges. Both are valid matrix splittings with M=I and A=I−H. In general the convergent errors form the direct sum of the generalized eigenspaces for ∣λ∣<1; if ρ(H)≥1, this is a proper linear subspace.
A small spectral radius describes eventual convergence, but does not imply that the Euclidean norm of the error decreases on every step for a non-normal matrix. An operator norm bound ∥H∥<1 does give the stepwise estimate ∥e(k)∥≤∥H∥k∥e(0)∥. For a real symmetric matrix, the matrix 2-norm equals its spectral radius, making this particularly direct.
