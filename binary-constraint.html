Binary constraint (Rij​⊆Di​×Dj​)

 ... Computer science Theoretical computer science Computational complexity theory Computational problem Search problem Constraint satisfaction problem
OurBigBook.com Words: 41
A restriction involving two variables in a constraint satisfaction problem, represented by the allowed value pairs Rij​. Multiple restrictions on the same pair can be combined by intersection. For bundle allocation, disjointness and the two directional envy-free allocation inequalities together define one compatibility relation.
