Lebesgue measurable sections (Bx​={y:(x,y)∈B} is measurable for a.e. x)

 ... Mathematics Area of mathematics Analysis Real analysis Measure theory Fubini's theorem
OurBigBook.com Words: 113
For a planar Lebesgue measurable set B, its vertical section Bx​ is a one-dimensional Lebesgue measurable set for x almost everywhere. Write B△C⊆Z with C a planar Borel set and Z a Borel Lebesgue null set. Every section Cx​ and Zx​ is Borel; Tonelli's theorem gives ∫m(Zx​)dx=m2​(Z)=0. Thus m(Zx​)=0 for x almost everywhere, and Bx​△Cx​⊆Zx​ proves the assertion by completeness of Lebesgue measure. No finite-measure condition on B is needed.
Exceptional sections need not be measurable: {0}×A is a planar Lebesgue null set for every A⊆R, even when A is a non-measurable set. Conversely, if both A1​ and A2​ are non-measurable, A1​×A2​ cannot be measurable. Otherwise every x∈A1​ would have to lie in the null exceptional set, making A1​ measurable by completeness of Lebesgue measure.
