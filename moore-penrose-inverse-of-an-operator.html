Moore–Penrose inverse of an operator (A†)

 Home Mathematics Area of mathematics Analysis Inverse problem Normal equation for a linear inverse problem
OurBigBook.com Words: 111 Articles: 1
For a bounded operator A:X→Y between Hilbert spaces, the Moore–Penrose inverse maps admissible data to the unique minimum-norm least-squares solution. If (σj​,uj​,vj​) is a singular system of a compact operator, then
A†y=∑j​σj​⟨y,uj​⟩​vj​
(37)
on the data for which this series converges.
More precisely, its domain is ranA⊕(ranA)⊥. It vanishes on (ranA)⊥ and takes values in (kerA)⊥. An infinite-rank compact operator on infinite-dimensional spaces has singular values approaching zero, so its inverse on its range is generally unbounded; Picard criterion specifies admissible data.
