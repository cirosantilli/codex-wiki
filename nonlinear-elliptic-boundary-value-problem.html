Nonlinear elliptic boundary value problem

 Home Mathematics Area of mathematics Analysis Partial differential equation Elliptic boundary value problem
OurBigBook.com Words: 266 Articles: 4
A nonlinear elliptic boundary value problem contains a nonlinear dependence on the unknown function or its derivatives while retaining an elliptic principal part. Small-data existence can often be proved by applying a fixed-point theorem to the inverse of the linear elliptic part.
