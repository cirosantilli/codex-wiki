Set-theoretic absoluteness

 ... Area of mathematics Foundations of mathematics Set theory Class (set theory) Transitive class Formula relativization to a class
OurBigBook.com Words: 932 Articles: 22
A formula is absolute between transitive classes M⊆N when it has the same truth value in both structures for parameters from M.
