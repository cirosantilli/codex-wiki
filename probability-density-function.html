Probability density function (fX​(x))

 ... Area of mathematics Probability and statistics Probability theory Probability distribution Continuous probability distribution Absolutely continuous probability distribution
OurBigBook.com Words: 681 Articles: 11
A probability density function represents probabilities as areas under a nonnegative measurable function. For a real random variable with an absolutely continuous probability distribution, it satisfies
P(X∈A)=∫A​fX​(x)dx,fX​(x)≥0,∫R​fX​(x)dx=1
(53)
for every Borel set A. Its height is probability per unit of the outcome variable, not the probability of that exact outcome. Thus a probability density function may exceed one, while the probability of a singleton is zero. NIST describes the interval-probability interpretation through integration. [ref].
For the example fY​(y)=2y on [0,1], fY​(0.8)=1.6, but P(Y=0.8)=0 and P(0.7<Y<0.9)=0.92−0.72=0.32. The cumulative distribution function is FY​(y)=y2 within that interval, connecting density height to the local accumulation rate.
Changing the scale changes the density height. If Z=100Y, then fZ​(z)=fY​(z/100)/100=z/5000 on [0,100]. At the corresponding value z=80, its height is 0.016, while P(70<Z<90)=0.32 is unchanged. The factor 1/100 compensates for the wider integration variable. This is a change of variables, not a change in the underlying probabilities.
A probability density function is determined only almost everywhere: changing its values on a Lebesgue measure zero set changes no probabilities. The Cantor distribution has no such representation, and a mixed probability distribution can have both a point mass and a density component, so differentiating its cumulative distribution function does not recover all its mass.
