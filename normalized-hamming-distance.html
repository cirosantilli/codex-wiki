Normalized Hamming distance (dH​(x,y)=dH​(x,y)/n)

 ... Area of mathematics Algebra Coding theory Block code Binary block code Hamming distance
OurBigBook.com Words: 23
On binary words of length n, normalized Hamming distance is the fraction of differing coordinates. Unlike unscaled Hamming distance, it makes the Hamming cubes a Lévy family under uniform probability measures.
