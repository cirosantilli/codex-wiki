Preserve the domain when simplifying a function

 ... Mathematics Area of mathematics Foundations of mathematics Set theory Function Domain of a function
OurBigBook.com Words: 88
An algebraic simplification proves equality only where both original and transformed expressions are defined. If a cancelled factor vanishes at a point, the simplified expression may instead describe an extension to that point. For example,
1+tanx1​=cosx+sinxcosx​

holds only when cosx=0 and cosx+sinx=0. The right side is zero at x=π/2+kπ, but the left side is undefined there. A graph of the original function must retain those holes. The extension may be useful, but it is a different function with a larger domain of a function.
