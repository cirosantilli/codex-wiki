ZF-equivalent bounded formula (Δ0ZF​)

 ... Set theory Class (set theory) Transitive class Formula relativization to a class Set-theoretic absoluteness Bounded formula in set theory
OurBigBook.com Words: 59
A first-order formula is ZF-equivalent bounded if ZF proves it equivalent, with the same free variables, to a syntactically bounded formula in set theory. It need not itself have only bounded quantifiers. Between transitive models of ZF, use the bounded equivalent and the axioms in each model to prove set-theoretic absoluteness. The syntactic bounded-formula result requires only transitivity; the provable-equivalence extension additionally requires the theory used for the equivalence.
