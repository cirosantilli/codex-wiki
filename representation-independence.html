Representation independence

 Home Computer science Encapsulation (computer programming)
OurBigBook.com Words: 339
Representation independence means that clients restricted to the promised API cannot distinguish implementations by the specified results and state transitions. State what observations count: equal returned labels and failure statuses do not imply equal running times, allocations or physical layouts. If the API also promises a resource bound, a replacement must meet that bound too.
Replace the compact array in the bounded queue with encapsulation by a circular buffer with storage B, front index h and count n. Its representation invariant is ∣B∣=C, h,n∈Z, 0≤h<C and 0≤n≤C. Its abstraction function reads the occupied slots using modular arithmetic:
α(B,h,n)=(B(h+i)modC​)i=0n−1​.
(8)
On successful enqueue(x), write B(h+n)modC​=x and increment n. On successful dequeue(), return Bh​, replace h by (h+1)modC and decrement n. Full and empty failures do not alter storage. peek and size have the same abstract meanings as before. Keeping a count distinguishes a full circular buffer from an empty one even when both would have the same next insertion index.
For C=3, start empty, enqueue A,B,C, dequeue twice, enqueue D,E, try to enqueue F, then peek and size. Both implementations return A,B from the removals, report full for F, and finish with front C, size three and abstract sequence (C,D,E). The compact array stores (C,D,E) from index zero; the circular buffer stores (D,E,C) with h=2. Their abstraction functions explain why different stored entries describe the same ordered content.
Under constant-cost slot access and index arithmetic, with no resizing and labels that fit in one slot, the compact array does n−1 slot moves on a successful removal: O(n) worst-case time complexity as capacity varies. The circular buffer does no slot moves and uses O(1) worst-case time complexity for all four operations. Both allocate C slots initially; that construction cost is separate. These are operation-count claims in Big O notation, not measured timings. The short correctness outline checks that each implementation's abstraction function produces the specified new sequence and return value after every successful or rejected call. Repeating that check gives equal traces for clients using only this API.
