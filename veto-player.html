Veto player

 ... Area of mathematics Mathematical optimization Game theory Cooperative game theory Transferable utility game Simple cooperative game
OurBigBook.com Words: 29
A player belonging to every winning coalition. Giving all of the grand-coalition value to a veto player satisfies every core constraint in a nontrivial simple cooperative game. If there are no veto players, its core of a simple cooperative game is empty.
