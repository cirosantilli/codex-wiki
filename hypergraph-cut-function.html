Hypergraph cut function (f(S)=∑e:e∩S=∅, e∖S=∅​w(e))

 Home Mathematics Area of mathematics Foundations of mathematics Graph theory Hypergraph
OurBigBook.com Words: 160
For a weighted hypergraph, the hypergraph cut function totals the weights of hyperedges meeting both a subset and its complement. It is a normalised set function and a symmetric set function. With nonnegative weights it is a nonnegative function and a submodular set function. It is generally not a monotone set function: a single two-element hyperedge of weight one has cut value one on either singleton, but zero on the whole ground set.
Proof of submodularity for nonnegative weights. For one hyperedge e of size at least two, let qe​ indicate whether it is split. Adding x∈/e has zero marginal increment. For x∈e, with x∈/S, the marginal increment is 1 if S∩(e∖{x}) is empty, −1 if it equals e∖{x}, and zero otherwise. These values can only decrease under inclusion of S. Thus diminishing returns holds for qe​, and taking a nonnegative weighted sum preserves it. For a singleton or empty hyperedge, qe​ is identically zero. A negative-weight two-element hyperedge gives a counterexample to submodularity: its two singleton values sum to a negative number, while the values at their union and intersection are zero.
