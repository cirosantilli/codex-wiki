Input impedance (Zin​)

 Home Physics Branches of physics Electromagnetism Electrical circuit Electrical impedance
OurBigBook.com Words: 38
Input impedance is the ratio of a small applied input-voltage phasor to the resulting input-current phasor, with the output termination and operating point specified. A finite input impedance loads a voltage source. For an ideal operational amplifier the input impedance is infinite, so neither input terminal draws current.
