Nonabsoluteness of singular cardinalhood

 ... Foundations of mathematics Set theory Class (set theory) Transitive class Formula relativization to a class Set-theoretic absoluteness
OurBigBook.com Words: 49
The statement that κ is a cardinal number with cf(κ)<κ is generally neither upward nor downward absolute. Upward absoluteness can fail when a larger model collapses the cardinal; downward absoluteness can fail when a larger model adds a short cofinal sequence to a cardinal that the smaller model regards as regular.
