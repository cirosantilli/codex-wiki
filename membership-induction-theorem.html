Membership induction theorem ([∀x((∀y∈xφ(y))→φ(x))]→∀xφ(x))

 Home Mathematics Area of mathematics Foundations of mathematics Set theory Axiom of regularity
OurBigBook.com Words: 97
Membership induction is the schema displayed, with set parameters permitted in φ. The Axiom of foundation proves it by choosing a minimal counterexample in the transitive closure TC({x}) of the singleton containing a counterexample x. Conversely, if a nonempty set a had no membership-minimal element, the property x∈/a would be progressive, so induction would force a to be empty. Thus over ZF without Axiom of foundation, this schema implies Axiom of foundation. It also implies that every set lies in the cumulative hierarchy: bound the stage indices of all members of a set by replacement, then place that set in the next power-set stage.
