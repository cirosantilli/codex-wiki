Procedure type

 Home Computer science Programming language Type system Function type
OurBigBook.com Words: 64 Articles: 1
A data type describing a callable procedure's parameter types and any return type. A traversal callback taking an integer and producing no data result can be passed using an Oberon declaration such as Visit = PROCEDURE(x: INTEGER).
