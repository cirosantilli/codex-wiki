In field characteristic p, the intermediate binomial coefficients in the pth power vanish. Hence
(α+1)p−(α+1)−a=αp+1−α−1−a=0.
(1)
Repeated translation gives all p roots α+j, j∈Fp​. They are distinct because the prime field embeds in F. They exhaust the roots by degree; also the formal derivative of Xp−X−a is −1, so this is a separable polynomial. If one root belongs to F, they all do, and
Xp−X−a=j∈Fp​∏​(X−α−j).​
(2)
This is the root-translation property of an Artin–Schreier polynomial.

The intended hypothesis must be a proper monic factor, with 1≤r≤p−1. Without that restriction the printed deduction is false: every polynomial has the displayed trivial factorization with r=p, even when it has no root in F.
By part 1, the roots in a splitting field are distinct and have the form α+j. The degree-r monic factor is the product of r corresponding linear factors. Comparing the coefficient of Xr−1 using Vieta's formulas gives
−a1​=∑j∈J​(α+j)=rα+∑j∈J​j,∣J∣=r.
(3)
Both a1​ and the sum of prime-field elements lie in F. Since 1≤r<p, the scalar r is nonzero and invertible in F. Therefore α=(−a1​−∑j∈J​j)/r∈F, and part 1 proves the polynomial splits into distinct linear factors over F. In particular an Artin–Schreier polynomial of prime degree is either irreducible or splits completely.

Reduce the monic integer polynomial modulo p. Every u∈Fp​ satisfies up=u, so up−u−1=−1=0. Thus the reduction has no root in Fp​. If it had a proper factor, part 2 would force such a root, a contradiction. Hence it is irreducible over Fp​.
The criterion of irreducibility by degree-preserving reduction modulo a prime, which follows from Gauss's lemma, now applies because the polynomial is monic and its degree is preserved on reduction. Consequently Xp−X−1 is irreducible in Q[X].

The Burnside lemma states that the number of orbits of a finite group action is
∣G∣−1∑g∈G​∣Fix(g)∣.
(4)
For m=2n−1≥3, the dihedral group consists of m rotations rj by 2πj/m, and m reflections rjs, each across the line through one vertex and the midpoint of the opposite edge. Thus ∣G∣=2m=4n−2.
For the pentagon, the identity fixes v5e5 colourings. Each of the four nonidentity rotations has a single cycle on vertices and a single cycle on edges, fixing ve colourings. Each of the five reflections has one fixed vertex and two vertex pairs, and one fixed edge and two edge pairs, fixing v3e3 colourings. 10v5e5+4ve+5v3e3​.​
(5)

Use inverse transform sampling for the categorical draw. Validate a finite nonnegative probability vector, allowing only a small rounding tolerance in its total, then compare a single uniform draw with the cumulative probabilities:
sim1 <- function(p) {
  if (!is.numeric(p) || length(p) == 0L ||
      any(!is.finite(p)) || any(p < 0) ||
      abs(sum(p) - 1) > 1e-12) {
    stop("p must be a nonempty finite probability vector")
  }
  p <- p / sum(p)
  cumulative <- cumsum(p)
  cumulative[length(p)] <- 1
  u <- runif(1)
  as.integer(which(u < cumulative)[1L])
}
The returned value is j when u falls in the interval between the previous cumulative sum and the jth one. That interval has length pj​, so the output has the required probabilities. Strict comparison skips zero-probability categories even if a simulated uniform value equals an interval boundary. Exactly one call to runif(1) is made.

The function below counts the initial uniformly chosen state as the first of the n visited states, and then generates n−1 transitions using the appropriate row of P:
simchain <- function(n, P) {
  if (!is.numeric(n) || length(n) != 1L || !is.finite(n) ||
      n < 1 || n != floor(n)) stop("n must be a positive integer")
  if (!is.matrix(P) || !is.numeric(P) || nrow(P) == 0L ||
      nrow(P) != ncol(P) || any(!is.finite(P)) ||
      any(P < 0) || any(abs(rowSums(P) - 1) > 1e-12)) {
    stop("P must be a finite square stochastic matrix")
  }
  k <- nrow(P)
  state <- sim1(rep(1/k, k))
  counts <- numeric(k)
  counts[state] <- 1
  if (n > 1) {
    for (step in seq_len(n - 1)) {
      state <- sim1(P[state, ])
      counts[state] <- counts[state] + 1
    }
  }
  counts / n
}
Conditional on the current state i, sim1(P[i, ]) selects j with probability Pij​, proving the Markov property with the desired transition matrix. Initialization is uniform by the same sampler. Dividing the visit counts by n gives the requested Empirical occupation proportions of a finite Markov chain, including a valid result when n=1.
