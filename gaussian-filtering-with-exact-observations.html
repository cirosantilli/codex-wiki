Gaussian filtering with exact observations (Rt​=GPt−1​G⊤+Q,Vt​=FRt​F⊤)

In a linear Gaussian state-space model with process noise covariance Q and exact scalar observation Xt​=FSt​, the predictive state covariance includes Q even though there is no separate measurement noise. Here Rt​=GPt−1​G⊤+Q denotes predicted state covariance; it differs from the measurement-noise notation in the general Kalman filter equations. The observation innovation variance is Vt​=FGPt−1​G⊤F⊤+FQF⊤. Omitting the second term incorrectly removes the current process noise. If Vt​>0, Gaussian conditional expectation gives the posterior covariance matrix Pt​=Rt​−Rt​F⊤FRt​/Vt​. This can be a singular matrix because the observed linear combination is then known exactly.
