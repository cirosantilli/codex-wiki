Synchronous sequential circuit (s′=F(s,a),w=G(s,a))

 Home Mathematics Area of mathematics Foundations of mathematics Formal language theory Finite-state machine
OurBigBook.com Words: 453 Articles: 7
A synchronous sequential circuit stores a finite collection of bits s, reads inputs a, and updates all stored bits at each clock edge according to a specified next-state function F. A combinational output is G(s,a); an output that is itself stored is included among the state bits. An initial state is part of a complete design. These equations provide a precise implementation-level description of a finite-state machine without requiring a particular gate drawing.
