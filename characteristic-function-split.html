Characteristic function (φX​(t))

 Home Mathematics Area of mathematics Probability and statistics Probability theory
OurBigBook.com Words: 2k Articles: 22
The characteristic function of a real random variable X is
φX​(t)=E[eitX].
(1)
It determines the probability distribution of X.
Here t∈R and i2=−1. By Euler's formula, its real part and imaginary part are E[cos(tX)] and E[sin(tX)]. The complex exponential has absolute value one, so this expected value exists for every real random variable, even without finite absolute moments. Moreover,
φX​(0)=1,∣φX​(t)∣≤E[∣eitX∣]=1,φX​(−t)=φX​(t)​.
(2)
The bound uses the triangle inequality for a vector-valued integral; the last identity is complex conjugate symmetry.[ref] Consequently the real part is an even function and the imaginary part is an odd function.
For a discrete probability distribution with values xj​ and probabilities pj​, the characteristic function is ∑j​pj​eitxj​: a weighted average of points on the unit circle in the complex plane. For example, if B has the Bernoulli distribution with P(B=1)=1/3 and P(B=0)=2/3, then
φB​(t)=32​+31​eit,φB​(2π/3)=21​+63​​i,∣φB​(2π/3)∣=3​1​.
(3)
Each point being averaged has absolute value one, but their directions partially cancel. At t=π, the same average is 1/3; at t=2π, it returns to one. The characteristic function is thus neither a probability density function nor a probability mass function: its argument is a frequency parameter, and its values can be complex numbers. This Bernoulli distribution has no probability density function with respect to Lebesgue measure, yet its characteristic function is defined at every frequency.
For a probability density function f, the same definition becomes φX​(t)=∫R​eitxf(x)dx, the Fourier transform with the displayed sign convention. The Laplace transform of a nonnegative random variable instead uses e−sX for s≥0, a real decaying weight. For the Bernoulli distribution above, it is 2/3+e−s/3; neither transform is the probability density function. The uniqueness theorem for characteristic functions explains why the oscillating averages still retain the entire probability law, while the characteristic function of a sum of independent variables turns combining laws into multiplication. These two properties make the representation useful even when directly computing a sum's probability distribution is cumbersome.
