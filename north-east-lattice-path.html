North-east lattice path (E=(1,0),N=(0,1))

 Home Mathematics Area of mathematics Combinatorics Lattice path
OurBigBook.com Words: 455 Articles: 1
A north-east lattice path is a lattice path whose allowed steps are E=(1,0) and N=(0,1). From (0,0) to (a,b), with nonnegative integers a,b, it has a east steps and b north steps. The number is
P(a,b)=(ba+b​)=(aa+b​).​
(38)
There is one zero-step north-east lattice path when a=b=0.[ref]
Seven positions, thirty-five paths. To reach (4,3), choose the three positions occupied by north steps in a seven-symbol word. For example, the subset {2,4,7} of {1,2,3,4,5,6,7} gives ENENEEN: putting N exactly in those positions and E elsewhere reconstructs the north-east lattice path. Reading the north-step positions recovers the subset, so these two operations give a bijection. Hence
P(4,3)=(37​)=3⋅2⋅17⋅6⋅5​=35.
(39)
The numerator counts ordered choices of three different positions; each subset occurs in 3!=6 orders. Dividing by this factorial counts each north-east lattice path once. A binary string recording N as 1 and E as 0 gives the same example as 0101001.
This interpretation is useful when arrangements have fixed totals but flexible order: a subset, a binary string, and a north-east lattice path become different views of one selection. It also separates endpoint restrictions from restrictions along the journey. Requiring the lattice path to avoid specified points changes the count; the unrestricted binomial coefficient no longer suffices, but the local north-east lattice path recurrence still suggests how to count allowed arrivals.
