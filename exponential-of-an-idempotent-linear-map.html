Exponential of an idempotent linear map (eαP=(I−P)+eαP)

 ... Algebra Linear algebra Vector space Linear map Linear operator Projection (linear algebra)
OurBigBook.com Words: 46
For an idempotent linear map P, induction gives Pj=P for all integers j≥1. Summing the matrix exponential series therefore proves the displayed identity. The direct sum of its kernel of a linear map and image of a linear map is fixed and scaled by eα, respectively. The result requires no Hermitian matrix hypothesis and is valid for real or complex α.
