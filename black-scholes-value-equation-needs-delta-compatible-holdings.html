Black-Scholes value equation needs delta-compatible holdings (g=px​,hB=p−xpx​)

 ... Mathematics Area of mathematics Mathematical optimization Mathematical finance Black-Scholes model Black-Scholes equation
OurBigBook.com Words: 60
A smooth value function satisfying the Black-Scholes equation admits a self-financing portfolio with the displayed delta hedge. An arbitrary decomposition p=xg+Bh need not be self-financing. For example p=0, g=1, h=−x/B solves the value equation but has portfolio gains dS−ρSdt, which are not zero when volatility is positive. For specified holdings, self-financing is equivalent to the value equation together with g=px​.
