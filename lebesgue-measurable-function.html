Lebesgue measurable function

 ... Mathematics Area of mathematics Analysis Real analysis Measure theory Measurable function
OurBigBook.com Words: 67
A Lebesgue measurable function f:R→R has a Lebesgue measurable set as the preimage of every open subset of R. Equivalently, use every Borel set in the target: the sets whose preimages are measurable form a sigma-algebra containing all open sets. The source carries the Lebesgue sigma-algebra and the target its Borel sigma-algebra. A Borel measurable function on R instead requires the preimages to be Borel in the source as well. Restricting the source to a Lebesgue measurable set uses its induced sigma-algebra.
