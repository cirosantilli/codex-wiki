Absolutely continuous function

 ... Mathematics Area of mathematics Analysis Functional analysis Sobolev space First-order Sobolev space
OurBigBook.com Words: 108 Articles: 1
A function f:[a,b]→R is absolutely continuous exactly when there is a function g∈L1(a,b) such that
f(x)=f(a)+∫ax​g(s)ds.
(11)
Then f is differentiable almost everywhere and f′=g almost everywhere.
