For T>0 and the constant matrices over the real numbers in the Kalman rank criterion, the finite-time Controllability Gramian accumulates the influence of all command times. Its column space equals that of the controllability matrix, and WT​ is a symmetric positive-definite matrix exactly when the controllability matrix has rank of a matrix n. If so, put δ=x1​−eATx0​. Among square-integrable functions steering x0​ to x1​ at T, the command
u∗​(t)=BTeAT(T−t)WT−1​δ
(3)
minimizes ∫0T​∥u(t)∥2dt, with value δTWT−1​δ. Here T in a matrix superscript denotes transpose. This cost is a squared input norm, not necessarily physical energy, and the optimizing command need not satisfy an amplitude bound. [ref]
For the double integrator, eAsB=(s,1)T, so direct integration gives
WT​=(T3/3T2/2​T2/2T​),detWT​=12T4​>0.
(4)
For a rest-to-rest distance d, u∗​(t)=6d/T2−12dt/T3 and the minimum squared input norm is 12d2/T3. Compare the two constant commands in the double integrator example, whose cost is 16d2/T3: both attain the target, but the smooth command costs less. At T=2, d=1, however, u∗​ peaks at 3/2, so it violates ∣u∣≤1 while the two constant commands remain admissible. Controllability, optimal control, and constrained reachability in control theory answer different questions.
