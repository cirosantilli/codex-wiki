Value parameter

 Home Computer science Programming language Programming language semantics Parameter passing
OurBigBook.com Words: 45
A parameter initialized from the actual argument's value. Whether passing an aggregate copies all elements or merely a reference is language-dependent; in whole-array copying semantics, a length-L argument costs Θ(L) per call. This differs from a language that passes an object reference by value.
