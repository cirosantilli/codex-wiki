Plot position x horizontally and ct vertically, with equal length scales, so vacuum light rays have slopes ±1. A possible cause of the spacetime event A must lie on or inside its past light cone, with Δt=tA​−tcause​>0. Equivalently, causality requires ∣Δx∣≤cΔt.
From B to A, Δx=6m and Δt=10−8s. Using c≃3.00×108ms−1, the available light-travel distance is only cΔt=3.00m. In the (−,+,+,+) metric signature, the Minkowski interval is
sBA2​=(Δx)2−c2(Δt)2≃36−9=27m2>0.
(14)
There is spacelike separation, so a signal would need speed 6×108ms−1≃2c:
B cannot cause A.​
(15)
From C to A, Δx=−2m and Δt=1.5×10−8s. Now cΔt=4.50m>∣Δx∣, giving
sCA2​≃4−20.25=−16.25m2<0.
(16)
This is timelike separation, with a possible signal velocity −2/(1.5×10−8)≃−1.33×108ms−1. Therefore
C could cause A, though the coordinates alone do not prove that it did.​
(17)
