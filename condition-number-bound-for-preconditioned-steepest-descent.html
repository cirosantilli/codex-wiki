Condition-number bound for preconditioned steepest descent (Ek+1​≤((κ−1)/(κ+1))2Ek​)

 ... Area of mathematics Analysis Numerical analysis Numerical linear algebra Matrix preconditioning Preconditioned steepest descent
OurBigBook.com Words: 130
Let m=λmin​(B)>0, L=λmax​(B) and κ=L/m=κ2​(B) for the transformed symmetric positive-definite matrix. Then preconditioned steepest descent satisfies
Ek+1​≤(κ+1κ−1​)2Ek​.
(21)
This is a worst-case bound, not necessarily the actual rate. For our scaled example the bound is (1/50)2=0.0004, slightly above its computed factor qM​≈0.000384321291. If the initial transformed error is an eigenvector, exact line search for a positive-definite quadratic removes it in one step, regardless of the full condition number.
A short proof compares exact line search for a positive-definite quadratic with the trial step size α=2/(m+L) in the transformed coordinates. In an orthonormal eigenbasis of B, each error coefficient is multiplied by 1−αλi​, whose absolute value is at most (L−m)/(L+m). Summing λi​ times the squared coefficients bounds the trial energy by the square of this factor. The exact minimizing step size does at least as well. This also explains the terminating case m=L: the trial step removes the entire error in one iteration.
