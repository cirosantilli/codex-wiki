Network address translation (NAT)

 Home Computer science Computer network Internet Internet architecture Middlebox
OurBigBook.com Words: 83 Articles: 2
Network address translation maps IP addresses between address realms. State and path constraints can affect sessions. Network address and port translation additionally maps transport ports. Translation does not itself require decryption of application payloads.[ref]
