Two-chain noncontinuous complete partial order

 ... Foundations of mathematics Set theory Set Partially ordered set Complete partial order Directed-complete partial order
OurBigBook.com Words: 127
Take two increasing countable chains sharing a least element ⊥ and a greatest element ⊤, with interiors a1​<a2​<⋯ and b1​<b2​<⋯ and no comparisons between branches. Each entire interior chain has ⊤ as its least upper bound. A directed set meeting both interiors must contain ⊤. Otherwise it lies within one branch, where it has either a greatest member or least upper bound ⊤. This proves that the partially ordered set is a directed-complete partial order.
The only element way-below an​ is ⊥. Indeed, an element way-below an​ must be below an​, but every positive am​≤an​ fails the way-below relation when tested against {b1​,b2​,…}: its least upper bound is ⊤≥an​, yet it has no member above am​. Nonempty directed sets always contain an element above ⊥, so ⊥≪an​. Thus the elements way-below an​ have least upper bound ⊥=an​, and this is not a continuous poset.
