Left fold (foldl :: (b -> a -> b) -> b -> [a] -> b)

 Home Computer science Programming language Functional programming
OurBigBook.com Words: 327 Articles: 3
A list reduction carrying an accumulator from left to right: foldl s z [] = z and foldl s z (x:xs) = foldl s (s z x) xs. In a lazy language this does not by itself force each intermediate accumulator; its association and evaluation strictness are separate issues. An infinite input spine prevents this operation from returning a result.[ref]
