Dual code (C⊥)

 Home Mathematics Area of mathematics Algebra Coding theory Linear code
OurBigBook.com Words: 125 Articles: 2
The dual code C⊥ consists of the words orthogonal to every word of C under the standard dot product. A parity-check matrix for C is a generator matrix for C⊥.
