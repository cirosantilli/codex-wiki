Limit cardinal

Words: 40
Cardinal number OurBigBook.com
An infinite cardinal number is a limit cardinal if it is not a successor cardinal; equivalently it is an aleph number with zero or a limit ordinal as index. Uncountable limit cardinals are either singular cardinals or weakly inaccessible cardinals. This concerns succession among cardinals, rather than merely being a limit ordinal.

Cardinality (∣X∣)

Words: 119
Cardinal number OurBigBook.com
The cardinality ∣X∣ of a set X expresses its size up to bijection. Two sets have the same cardinality exactly when a bijection pairs their members. For a finite set, cardinality is the ordinary number of set elements. In the presence of the axiom of choice, every set can be assigned the least ordinal in its bijection class as its cardinal number.
An injective function A→B shows that A is no larger than B: different members of A receive different partners in B. If there are injections in both directions, the Cantor-Schröder-Bernstein theorem supplies a bijection. Infinite cardinality records this pairing structure rather than a geometric dimension or density. That is why a line of natural numbers and a grid of natural-number pairs can have the same size, while an interval of real numbers has larger cardinality.

Cofinality of a continuous cardinal hierarchy (cf(ℶδ​)=cf(δ))

Words: 46
Cofinality OurBigBook.com
At a nonzero limit ordinal δ, a strictly increasing continuous sequence of cardinals (κα​)α≤δ​ satisfies cf(κδ​)=cf(δ). A cofinal sequence of indices gives the upper bound. Conversely, bounds for a cofinal set of values must have cofinal indices, giving the lower bound. In particular the assertion applies to Beth numbers.

A map f:δ→α whose range is cofinal: every ξ<α lies below or equals some f(η). It need not be increasing.

Cofinality of an increasing ordinal supremum (cf(supξ<α​γξ​)=cf(α))

Words: 52
Cofinality OurBigBook.com
If α is a nonzero limit ordinal and (γξ​)ξ<α​ is strictly increasing, then cf(supξ<α​γξ​)=cf(α). A cofinal subsequence of the index order gives one inequality. Conversely, a cofinal family in the supremum determines a cofinal family of indices by choosing an index past each of its values. This also explains the cofinality of limit-indexed aleph numbers.

Singular cardinal (cf(κ)<κ)

Words: 205 Articles: 4
Cofinality OurBigBook.com
An infinite cardinal number κ is singular when cf(κ)<κ. Thus a short cofinal function reaches arbitrarily high ordinals below κ. For example, ℵω​ has cofinality ω. The complementary case is a regular cardinal.

Bukovský-Hechler theorem (2κ=limμ<κ​2μ on an eventual plateau)

Words: 32
Singular cardinal OurBigBook.com
If the power-set function is eventually constant below a singular cardinal κ, its constant value persists at κ. Writing θ=cf(κ) gives 2κ=(2<κ)θ. On the plateau choose a cardinal μ≥θ, so (2μ)θ=2μ⋅θ=2μ.

Singular cardinal enumeration (σα​)

Words: 106 Articles: 1
Singular cardinal OurBigBook.com
Write σα​ for the αth uncountable singular cardinal in increasing order. It begins with σ0​=ℵω​ and σ1​=ℵω+ω​. At a nonzero limit ordinal index it is continuous exactly when the supremum of its earlier values is singular. It can jump when that supremum is a weakly inaccessible cardinal. The first member of uncountable cofinality occurs at index ω1​, with value ℵω1​​.
Cardinal fixed point of the singular cardinal enumeration (σκ​=κ)
Words: 49
Singular cardinal enumeration OurBigBook.com
There is an uncountable cardinal number κ with σκ​=κ. Iterate κn+1​=σκn​​ starting with ℵ0​. If there is no earlier fixed point, the increasing supremum κ has countable cofinality, hence is a singular cardinal. The singular cardinal enumeration is cofinal in κ below index κ, and continuity at this singular supremum gives equality.

Singular cardinals hypothesis (ℷ(κ)=max{κ+,2cf(κ)})

The singular cardinals hypothesis asserts that every infinite singular cardinal κ satisfies
2cf(κ)<κ ⟹ ℷ(κ)=κ+.
(1)
Equivalently, ℷ(κ)=max{κ+,2cf(κ)} for every infinite singular cardinal. Here ℷ is the gimel function. The Generalized continuum hypothesis implies this principle, but the principle only constrains the indicated singular-cardinal exponentiation.

Supercompact cardinal (κ)

A cardinal κ is supercompact if for every cardinal λ≥κ there is an elementary embedding j:V→M into a transitive class with critical point of an elementary embedding κ, j(κ)>λ, and Mλ⊆M. This closure supplies every sufficiently small rank segment needed to transfer existential witnesses into M.

If κ is a supercompact cardinal, each true Σ2​ statement, allowing parameters in Vκ​, holds in Vκ​. Write it as an existential witness followed by a Π1​ assertion. Choose a supercompact elementary embedding whose transitive target contains the witness in Vj(κ)​. Downward absoluteness of the universal bounded-matrix assertion puts the witness in that rank segment, and elementarity reflects this to Vκ​.

If κ is Mahlo in V, then it is Mahlo in L. Inaccessibility is downward absolute, and every club in L remains a club in V, where it meets a V-inaccessible ordinal.

Weakly inaccessible cardinal (cf(κ)=κ and κ is an uncountable limit cardinal)

A weakly inaccessible cardinal is an uncountable regular cardinal that is a limit cardinal. It need not be a strong limit cardinal. Under the Generalized continuum hypothesis, it is a strongly inaccessible cardinal, since every smaller infinite λ satisfies 2λ=λ+<κ.

Weakly Mahlo cardinal

A weakly inaccessible cardinal κ is weakly Mahlo if {α<κ:α=cf(α)} is a stationary set. Intersecting this set with the club set of uncountable limit cardinals shows that the weakly inaccessible cardinals below κ are stationary, hence unbounded.

Model of ZFC without weakly inaccessible cardinals

Words: 59
Weakly inaccessible cardinal OurBigBook.com
Consistency of ZFC implies consistency of ZFC with the Generalized continuum hypothesis and no weakly inaccessible cardinals. Pass to the constructible universe. If it has an inaccessible, cut at its least one; that rank segment still models ZFC and the Generalized continuum hypothesis, but has no inaccessibles. In this model the singular cardinal enumeration is continuous at every nonzero limit ordinal index. This is a relative-consistency construction, not a deduction of a transitive model from bare consistency.

Rank cutoff at the first inaccessible limit of inaccessibles (Vι​⊨ZFC+∞IC+¬ILI)
Words: 54

If ι is the least inaccessible limit of inaccessibles, Vι​ models ZFC and internally has unboundedly many inaccessible cardinals, while none of its ordinals is an inaccessible limit of inaccessibles. This proves the corresponding relative-consistency nonimplication.

Worldly cardinals below an inaccessible cardinal

Words: 74
Worldly cardinal OurBigBook.com
Below any uncountable strongly inaccessible cardinal κ, the worldly cardinals contain a closed unbounded subset of κ and hence have cardinality κ. The structure Vκ​ models ZFC. Reflect each finite group from an enumeration of all first-order formulas to a closed unbounded subset of κ, using ∣Vα​∣<κ and regularity for the witness bounds. The countable intersection remains closed unbounded, so its ranks are elementary substructures of Vκ​. Intersect with the closed unbounded subset of infinite cardinal numbers below κ. Uncountability is essential: the regular strong limit ω has no worldly cardinal below it.

Nested transitive models from a worldly cardinal

The transitive collapse fixes transitive subsets lemma preserves M and those ordinals.

Omega-measurable cardinal (ω-measurable)

Words: 90 Articles: 1
Measurable cardinal OurBigBook.com
A cardinal is omega-measurable if it carries a countably complete ultrafilter that is a nonprincipal ultrafilter. Countable completeness rules out countable underlying sets. Such a measure is weaker than the cardinal's own full completeness requirement, but the least omega-measurable cardinal is measurable.
Least omega-measurable cardinal is measurable
Words: 56
Omega-measurable cardinal OurBigBook.com
If κ is the least omega-measurable cardinal and U witnesses it, failure of κ-completeness partitions a member of U into fewer than κ fibres, none belonging to U. The pushforward ultrafilter under the fibre-index map is then a nonprincipal countably complete measure on a smaller cardinal, a contradiction. Thus U is κ-complete and κ is a measurable cardinal.

Measurable cardinal is a strong limit cardinal

Words: 70
Measurable cardinal OurBigBook.com
Let U be a nonprincipal κ-complete ultrafilter on κ. If λ<κ and (Aα​)α<κ​ were distinct subsets of λ, then for every ξ<λ choose the U-large side of the partition according to whether ξ∈Aα​. Their intersection is U-large by κ-completeness, but all its indices label the same subset of λ, so it has at most one member, contradicting nonprincipality. Thus 2λ<κ.

Moved critical point is not an ambient cardinal under GCH

Words: 70
Measurable cardinal OurBigBook.com
For a measure ultrapower j:Vλ​→M with critical point κ, there are at most 2κ equivalence classes of functions κ→κ, so ∣j(κ)∣≤2κ in Vλ​. Countable set

Words: 1k Articles: 17
Cardinal number OurBigBook.com
A countable set is a set that admits an injective function into the natural numbers. It is therefore either a finite set or a countably infinite set.
For a countably infinite set, countability means that its members can be arranged as a sequence in which every member occurs exactly once. The order need not resemble the order already present in the set. For example, the integers can be listed as 0,1,−1,2,−2,…. Simply increasing through positive values would never reach a negative one.
The Cartesian product N2 needs a similar change of strategy. Listing a whole horizontal row first would never finish that row, so later rows would be missed. Instead list pairs by increasing coordinate sum x+y, and within each finite diagonal by increasing y:
(0,0), (1,0), (0,1), (2,0), (1,1), (0,2),….
(7)
Every pair has a finite coordinate sum and therefore appears after finitely many earlier pairs. This is the construction made explicit by the Cantor pairing function. It explains why having two infinite coordinates does not, by itself, mean a larger cardinality.

Countability of disjoint positive-length intervals

Words: 57
Countable set OurBigBook.com
A family of pairwise disjoint real intervals of positive length is countable. Each interval contains a rational number in its interior by the density of the rational numbers. Fix an enumeration of the rational numbers and select the first member lying inside each interval. Disjointness makes this selection an injection into a countable set. The argument also applies to disjoint nonempty open subsets of the real line.

Countability of finite subsets of a countable set (∣{A⊆N:∣A∣<∞}∣=ℵ0​)

Words: 57
Countable set OurBigBook.com
A finite subset A of the natural numbers, numbered from one, has the binary code ∑j∈A​2j−1. Distinct finite subsets give distinct codes, because the largest differing exponent exceeds the sum of all smaller powers of two. Thus the finite subsets form a countable set, although the entire power set is an uncountable set by the Cantor diagonal argument. An enumeration transfers this coding to any countable set.

Countability of integer polynomial rings (∣Z[X1​,…,Xd​]∣=ℵ0​)

Words: 70
Countable set OurBigBook.com
For every fixed positive integer d, the polynomial ring with integer coefficients in d indeterminates is countably infinite. Polynomials of bounded total degree have only finitely many possible monomials, so they are encoded by a finite Cartesian power of the integers. Taking a countable union of countable sets over degree bounds proves countability; constant polynomials supply an infinite subset. Nonzero one-variable polynomials have finitely many real roots, so the real algebraic numbers form a countable set as well.

Countable closure under real polynomial roots (X=⋃n≥0​Bn​)

Words: 93
Countable set OurBigBook.com
Every countable set B of real numbers is contained in a countable set closed under taking all real roots of a polynomial with coefficients in that set. Let ϕ(A) consist of these roots of a polynomial, excluding the zero polynomial. There are countably many finite coefficient lists over a countable set, and each nonzero polynomial has finitely many roots of a polynomial; hence ϕ(A) is countable. Define B0​=B and Bn+1​=Bn​∪ϕ(Bn​). The countable union of countable sets theorem shows that X=⋃n​Bn​ is countable. Every finite coefficient list in X belongs to one stage BN​, so its real roots of a polynomial belong to BN+1​⊆X. Retaining Bn​ at the next stage matters: ϕ(A) need not contain A.

Every family of pairwise disjoint nonempty open disks in the plane is countable. The density of the rational numbers gives each disk a point of the countable set Q2. Fixing an enumeration and taking the first point in each disk yields an injection from disks to labels. This argument requires no countable choice of representatives and is useful when geometric separation would otherwise produce an uncountable family.

Cardinal bound for an increasing chain of countable sets (∣⋃i​Xi​∣≤ℵ1​)

An increasing chain of countable sets has union of cardinality at most ℵ1​. If the union is uncountable, select ℵ1​ of its points and one containing member for each. Every countable member misses one selected point, so linear comparison puts it below that point's chosen member. The chosen subfamily is cofinal, and its union has size at most ℵ1​ by infinite cardinal arithmetic.

Finite Cartesian power of a countable set (Bm)

Countable union of explicitly ordered finite lists without choice

Words: 93
Countable set OurBigBook.com
Given finite lists ℓ0​,ℓ1​,… in a set X, their union of entries has an explicit enumeration from a subset of N2: use the existing positions in each list and a Cantor pairing function. If the union is infinite, successively take the first occurrence of an entry not previously taken, in the order of its natural-number code. The well-order on natural numbers makes each step uniquely determined and yields an injection N→X. No axiom of choice is needed. This does not assert that an arbitrary countable family of unordered finite sets has a countable union in ZF without the axiom of choice.

Countability from vanishing averages of distinct sequences

Words: 63
Countable set OurBigBook.com
If every sequence of distinct elements of a positive-real set A has arithmetic averages tending to zero, then A is a countable set. For each positive integer n, the threshold set {a∈A:a≥1/n} must be finite: an infinite sequence inside it would have averages at least 1/n. The Archimedean property makes A their union, so the countable union of countable sets theorem applies. The hypothesis concerns every distinct-element sequence, not merely one enumeration.

Parabola obstruction to countable line coverings

Words: 63
Countable union of countable sets OurBigBook.com
A parabola parametrized by (t,t2) is in bijection with R and is an uncountable set. Every affine line meets it in at most two points. A countable family of affine lines could therefore cover only countably many points of this parabola, and cannot cover the plane. More generally, an uncountable curve with finite intersection with every permitted member obstructs a countable covering by those members.

Cantor pairing function (π(x,y)=2(x+y)(x+y+1)​+y)

Words: 117
Countable set OurBigBook.com
The Cantor pairing function is an explicit bijection between N2 and N, with the natural numbers numbered from zero:
π(x,y)=2(x+y)(x+y+1)​+y.
(8)
If d=x+y, there are 1+2+⋯+d=d(d+1)/2 pairs on earlier diagonals, and the pair (x,y) is at offset y along diagonal d. The formula therefore gives exactly the enumeration above. For example, π(2,3)=5⋅6/2+3=18.
For the inverse at an index k, find the unique d satisfying d(d+1)/2≤k<(d+1)(d+2)/2, then put y=k−d(d+1)/2 and x=d−y. At k=18, these are d=5, y=3, and x=2. Thus both the encoding and decoding are explicit. The bijection is useful for assigning a single natural number to a pair of indices, and iterating it does the same for fixed-length tuples.

Cantor's diagonal argument (bn​=1−an(n)​)

Words: 285
Countable set OurBigBook.com
Cantor's diagonal argument shows that the set of all infinite binary sequences is an uncountable set. Suppose a proposed enumeration is a(1),a(2),…, where aj(n)​∈{0,1} is coordinate j of row n. Construct a new binary sequence by
bn​=1−an(n)​(n≥1).
(9)
It differs from row n at coordinate n, for every n. It is consequently absent from the entire proposed list, regardless of how that list was chosen. The failure of an enumeration of all binary sequences follows from this precise point of disagreement, rather than from a claim that the list looks too small.
For the displayed window, the first six diagonal bits are 1,0,0,0,1,1, so the new sequence starts 0,1,1,1,0,0. The drawing shows only finitely many rows, but the rule defines every coordinate and excludes every row of an infinite list. This distinguishes the argument from the Cantor pairing function: that construction lists all pairs of finite indices, whereas this one concerns an entire infinite sequence as each object to be listed. Finite binary strings form a countable set; all infinite binary sequences do not.
The connection with power sets is exact: a subset A⊆N corresponds to its indicator function, with a one in position n exactly when n∈A. Changing the diagonal membership bit is the same mechanism as the Cantor's theorem construction D={x:x∈/f(x)}. This reusable method turns a purported complete list into an explicit omitted object.
In his paper [ref], presented in 1891 and printed in the 1890–91 volume in 1892, Cantor uses infinite sequences of two symbols for the diagonal construction and then gives the broader comparison of cardinalities. The binary notation here is a modern presentation of that construction.

Gimel recursion for cardinal exponentiation (ℷ⟹(κ,λ)↦κλ)

Product-sum comparison lemma (κλ≤κ+λ)

Words: 145
Cardinal arithmetic OurBigBook.com
In ZF, let K,L be nonempty. If K×L injects into K⊔L, then there is either an injection or a surjection from K to L.
Indeed, extend the inverse of the given injection to a surjection p:K⊔L→K×L by sending points outside its range to one fixed pair (k∗​,l∗​). If the second coordinate of p restricted to the K-summand covers L, it is the required surjection. Otherwise choose l0​ that it misses. Every (k,l0​) then has its preimage in the L-summand. Except possibly for the default pair, that preimage is unique, so these preimages inject K into L. In the exceptional case they inject K∖{k∗​} into L; either their image is all of L, yielding a surjection from K, or an omitted point extends the map to an injection from K.

Cantor-Schröder-Bernstein theorem (∣X∣≤∣Y∣, ∣Y∣≤∣X∣⇒∣X∣=∣Y∣)

Words: 803 Articles: 2
Cardinal number OurBigBook.com
If there are injections X→Y and Y→X, then there is a bijection X≅Y.
For arbitrary sets X and Y, the precise equivalence is
(∃ injection f:X→Y) ∧ (∃ injection g:Y→X)⟺∃ bijection h:X→Y.
(19)
The reverse direction uses the bijection h and its inverse function. Neither set is assumed to be a subset of the other: the hypothesis concerns functions, rather than containments. The forward direction holds in ZF without the axiom of choice.[ref]
This makes cardinality comparison an antisymmetric relation: if each set is no larger than the other in the sense of an injection, they have equal cardinality. It also gives a practical strategy: build two convenient injections and let the theorem supply the bijection. The Injection-chain proof of the Cantor-Schröder-Bernstein theorem explains how to combine them without losing an output or pairing two inputs with the same output.

Sparse-shift bijection between nonnegative and positive integers (A={2k+1−2:k∈N})

Words: 269
Cantor-Schröder-Bernstein theorem OurBigBook.com
Take X={0,1,2,…}, the nonnegative integers, and Y={1,2,3,…}, the positive integers. Choose the injections
f:X→Y,f(n)=2n+2,g:Y→X,g(m)=m.
(20)
Here g is an inclusion map, while f reaches only the positive even integers. In particular, f is not a bijection: it misses every positive odd integer. Simply using the inverse function of g on its image misses input zero.
The remedy is to follow the alternating injections starting at the missing input zero:
0X​⟶f2Y​⟶g2X​⟶f6Y​⟶g6X​⟶f14Y​⟶g14X​⟶⋯.
(21)
The subscripts distinguish an input in X from an output in Y, even when their numerical values agree. The resulting subset of X is A={0,2,6,14,30,…}. Its sequence of members satisfies a0​=0 and ak+1​=2ak​+2, giving ak​=2k+1−2 by mathematical induction. Define the function
h(n)={2n+2,n,​n∈A,n∈X∖A.​
(22)
The image h(A)={2,6,14,30,…}=A∖{0} covers all the positive members of A exactly once. The other inputs cover Y∖A exactly once by staying fixed. These output sets are disjoint and their union is Y, proving that h is a bijection. In particular, h(0)=2, h(2)=6, h(6)=14, while h(1)=1 and h(4)=4.
For completeness, its inverse function is
h−1(m)={(m−2)/2,m,​m∈A∖{0},m∈Y∖A.​
(23)
The familiar bijection n↦n+1 also works, but this example shows something more specific: the two chosen injections can repair the missing zero by moving only a sparse sequence of inputs. The repair never has to shift the entire set.

Injection-chain proof of the Cantor-Schröder-Bernstein theorem (A0​=X∖g(Y),Ak+1​=g(f(Ak​)))

Words: 387
Cantor-Schröder-Bernstein theorem OurBigBook.com
Given injections f:X→Y and g:Y→X, start with the set difference A0​=X∖g(Y): these are exactly the inputs for which g−1 is unavailable. Follow both functions repeatedly, using the natural-number recursion theorem to define
Ak+1​=g(f(Ak​)),A=⋃k=0∞​Ak​.
(24)
Thus A contains all the X members reachable from any starting point in A0​. The notation f(Ak​) and g(f(Ak​)) denotes images of a function. If A0​ is the empty set, then every Ak​ is empty and g−1 alone gives the desired bijection.
Define a function on all of X by
h(x)={f(x),g−1(x),​x∈A,x∈X∖A.​
(25)
Here g−1 is the inverse function from g(Y) to Y, obtained by restricting the codomain of g to its image. It is well defined because g is injective. Every x∈/A belongs to g(Y), since A0​⊆A, so the second rule is always available where it is used.
The decisive set identity is
g(f(A))=⋃k=0∞​g(f(Ak​))=⋃k=1∞​Ak​=A∖A0​.
(26)
The last equality holds because every Ak​ with k≥1 lies in g(Y), whereas A0​ is disjoint from g(Y). Consequently, for any y∈Y,
g(y)∈A⟺y∈f(A).
(27)
Indeed, g(y) cannot belong to A0​; if it lies in A, the identity gives g(y)=g(f(a)) for some a∈A, and injectivity gives y=f(a). The converse follows directly by applying g.
Now f restricts to a bijection from A onto f(A). The displayed equivalence says that g restricts to a bijection from Y∖f(A) onto X∖A, so its inverse function bijects the remaining inputs with the remaining outputs. The two input sets partition X and the two output sets partition Y. Their combined function h is therefore both injective and surjective.
No choice function is needed: A is fixed by the given injections, and each required g−1(x) is unique. We neither choose a representative from each chain nor enumerate X. This is a proof in ordinary classical ZF, even when no well-ordering of the sets exists there.[ref]
