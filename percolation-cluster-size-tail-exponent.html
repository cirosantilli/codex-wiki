Percolation cluster-size tail exponent (Ppc​​(∣C(0)∣≥s)=s−1/δ+o(1))

The exponent δ describes the tail of the critical cluster seen from a specified vertex of a graph. If the expected number of size-s clusters per site scales as s−τ, weighting by cluster size gives 1/δ=τ−2 when these scaling laws hold.
