Bit-flip repetition code

 Home Physics Branches of physics Quantum theory Quantum error correction Stabilizer code
OurBigBook.com Words: 306 Articles: 3
The m-qubit bit-flip repetition code is obtained from the phase-flip repetition code by interchanging X and Z. It is stabilized by Zj​Zj+1​ and has logical operators X=X1​⋯Xm​ and Z=Z1​.
