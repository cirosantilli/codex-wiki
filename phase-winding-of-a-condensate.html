Phase winding of a condensate (∮dϕ=2πn)

 ... Critical phenomenon Order parameter Topological defect Phase vortex Quantum vortex Quantized circulation
OurBigBook.com Words: 89 Articles: 1
If a condensate order parameter stays nonzero along a closed loop, its phase changes by an integer multiple of 2π. Broken rotational symmetry does not destroy this single-valuedness constraint. In an inhomogeneous ring the winding integer need not label an angular-momentum eigenstate.
