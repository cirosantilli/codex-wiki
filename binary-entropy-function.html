Binary entropy function (H2​(x))

OurBigBook.com Words: 27
The binary entropy function is
H2​(x)=−xlog2​x−(1−x)log2​(1−x).
(45)
It is concave on [0,1] and satisfies H2​(x)≥2x for 0≤x≤1/2 by comparison with the chord from (0,0) to (1/2,1).
