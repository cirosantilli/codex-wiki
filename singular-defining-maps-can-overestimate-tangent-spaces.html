Singular defining maps can overestimate tangent spaces (Ta​(g−1(0))⊆kerDga​ need not be equality)

 ... Mathematics Area of mathematics Geometry and topology Differential geometry Tangent vector Tangent space
OurBigBook.com Words: 80
If the zero set of a differentiable function g is a submanifold, the chain rule always places its tangent space inside kerDga​. Equality follows from the full-rank hypotheses of the regular level set theorem, but may fail for a singular defining function even when the zero set itself is smooth. For g:R→R, g(x)=x2, the zero set is the single point {0}. Its tangent space is zero, while Dg0​=0 has kernel R. One should therefore check the constraint qualification before using the kernel formula.
