Power set in a generic extension (ΠτG​=PM[G](τG))

 ... Area of mathematics Foundations of mathematics Set theory Forcing Generic filter Generic extension
OurBigBook.com Words: 86
For a forcing name τ, let U consist of pairs (ρ,p) where (ρ,r)∈τ for some r≥p. Every ground-model subset ν of U is a name whose value is contained in τG. Every subset σG⊆τG has an equivalent such name: retain those (ρ,p)∈U with p⊩ρ∈σ. The atomic membership truth lemma for forcing proves equality of values. Collect all these names from the ground-model power set PM(U) into a single outer name, pairing each with every condition. Its value is the full internal power set, without presupposing that power set in the extension.
