Expected return (ER)

 Home Mathematics Area of mathematics Mathematical optimization Mathematical finance Investment portfolio
OurBigBook.com Words: 41
The expected value of a random financial return R. For asset return vector R with mean μ, a portfolio of weights w has expected return wTμ by linearity of expectation. This measures average payoff growth rather than a guaranteed realized gain.
