Central character value of a conjugacy-class sum

 Home Mathematics Area of mathematics Algebra Representation theory Character orthogonality
OurBigBook.com Words: 199 Articles: 4
For an irreducible character χ and a conjugacy class C represented by c, the central group-algebra element ∑x∈C​x acts as the scalar
ωχ​(C)=χ(1)∣C∣χ(c)​.
(35)
This scalar is an algebraic integer, since the class sum acts by an integer matrix on the regular representation.
