Trigonometric type-two canonical transformation (F2​(q,P)=cosqsinP)

 ... Physics Branches of physics Classical mechanics Hamiltonian mechanics Canonical transformation Type-two generating function for a canonical transformation
OurBigBook.com Words: 117
The type-two generating function for a canonical transformation F2​(q,P)=cosqsinP defines p=−sinqsinP and Q=cosqcosP. On any branch with 0<q<π and cosP=0, its inverse in mixed coordinates is
q=arccos(Q/cosP),p=−sinP1−Q2sec2P​.
(17)
The square root equals sinq on this branch. Differentiating F2​ proves the generating equations, and F2,qP​=−sinqcosP=0 proves local invertibility by the inverse function theorem. Also d(F2​−PQ)=pdq−PdQ, so the symplectic form obeys dq∧dp=dQ∧dP. This proves the transformation is canonical locally. It is not a single global chart across the inverse-trigonometric branch boundaries.
Since F2​ is independent of time, the transformed Hamiltonian is obtained by substitution, with zero generating-function time correction. An added function of time alone is an irrelevant Hamiltonian freedom, since it leaves Hamilton's equations unchanged.
