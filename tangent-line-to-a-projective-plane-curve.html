Tangent line to a projective plane curve (Tp​C)

 ... Area of mathematics Geometry and topology Algebraic geometry Algebraic variety Algebraic curve Nonsingular point of an algebraic curve
OurBigBook.com Words: 57
For a projective plane curve C=V(F) and a nonsingular projective point p, the tangent is the line Fx​(p)x+Fy​(p)y+Fz​(p)z=0. The coefficients are not all zero, and the Euler theorem for homogeneous functions makes this line pass through p. On an affine chart this is precisely the first-order part of a local defining equation, so the definition agrees with the usual tangent line and is invariant under projective transformations.
