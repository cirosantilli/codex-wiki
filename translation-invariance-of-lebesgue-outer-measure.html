Translation invariance of Lebesgue outer measure (m∗(A+a)=m∗(A))

 ... Area of mathematics Analysis Real analysis Measure theory Outer measure Lebesgue outer measure
OurBigBook.com Words: 50
Translating every interval of a countable cover of A⊆R by a produces a cover of A+a with the same lengths. Taking the infimum of cover lengths gives m∗(A+a)≤m∗(A). Translating back by −a gives the reverse inequality. This proves translation invariance for Lebesgue outer measure on every subset, without first assuming the set is Lebesgue measurable.
