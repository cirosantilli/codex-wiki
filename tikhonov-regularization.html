Tikhonov regularization (xαδ​=(A∗A+αI)−1A∗yδ)

 Home Mathematics Area of mathematics Analysis Inverse problem Regularization of an inverse problem
OurBigBook.com Words: 1k Articles: 19
For a bounded linear operator between Hilbert spaces and α>0, Tikhonov regularization minimizes
∥Ax−yδ∥2+α∥x∥2.
(14)
The quadratic norm penalty makes this functional a strictly convex, coercive function, yielding the unique minimizer displayed in the title. Here A∗ is the adjoint operator and I the identity operator. Our regularization parameter α multiplies the squared norm directly. Hansen's notes instead write λ2∥x∥2: the same reconstruction requires α=λ2, not α=λ.[ref]
For a real matrix with singular value decomposition Avj​=σj​uj​, the exact reconstruction is
xαδ​=∑σj​>0​gα​(σj​)σj2​+ασj​​​​(ujT​yδ)vj​,ϕα​(σ)=σgα​(σ)=σ2+ασ2​.
(15)
The singular-system Tikhonov filter gα​ is the data-to-solution gain; ϕα​ is the fraction of an exact solution mode retained. If yδ=Axtrue​+e, a positive singular value mode has error
vjT​(xαδ​−xtrue​)=−σj2​+αα​vjT​xtrue​+σj2​+ασj​​ujT​e.
(16)
The first term is approximation bias; the second is transmitted measurement noise. Suppressing a weak mode suppresses its true signal too.
For the two-pixel matrix in the inverse problem example and α=0.01 (λ=0.1), the mean and difference attenuation factors are 100/101 and 1/2. Since yδ=q+​/2​+0.12q−​/2​, the reconstruction is
x0.01δ​=101100​2​q+​​+53​2​q−​​=(803/1010197/1010​)≈(0.795050.19505​).
(17)
Its noise contribution is (0.05,−0.05)T, half the direct inverse's, but its exact-data reconstruction is (0.74505,0.24505)T. Consequently its total error Euclidean norm, about 0.28293, exceeds the direct inverse's 0.14142: this parameter sacrifices too much contrast. Taking α=0.001 instead gives (1.04496,−0.04595)T and error about 0.06429. Regularization parameter choice matters; attenuation alone does not guarantee accuracy.
