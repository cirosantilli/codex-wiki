Second Chebyshev function (ψ(x))

 ... Mathematics Area of mathematics Number theory Arithmetic function Von Mangoldt function Chebyshev function
OurBigBook.com Words: 600 Articles: 7
The Second Chebyshev function is the partial sum of the Von Mangoldt function up to a real cutoff x≥0:
ψ(x)=∑1≤n≤x​Λ(n).
(48)
For example, ψ(3)=log6, ψ(4)=log12, and ψ(4.5)=log12. At 4=22 the jump has size log2; between 4 and 5 no new prime power greater than one enters the sum. In contrast, the Chebyshev theta function stays at ϑ(4)=log6.
There is also an exact connection with the least common multiple. For N=⌊x⌋≥1, each prime number p≤N occurs to the highest exponent k for which pk≤N, both in that least common multiple and in the accumulated Von Mangoldt function weights. Thus
ψ(x)=loglcm(1,2,…,N).
(49)
This explains the log2520 value at x=10: the least common multiple is 23⋅32⋅5⋅7. The Chebyshev theta function instead gives the natural logarithm of the primorial 2⋅3⋅5⋅7=210. The additional prime powers retain the highest required multiplicities.
Why is this useful for the distribution of prime numbers? The Prime number theorem has the equivalent forms
π(x)∼logxx​,ϑ(x)∼x,ψ(x)∼x(x⟶∞),
(50)
where π is the prime-counting function and ∼ denotes asymptotic equivalence. Thus an arithmetic function defined using prime factorization has average weight tending to one over long initial intervals of the positive integers. These are substantive asymptotic equivalences, not consequences of the definitions or the Von Mangoldt divisor identity alone. [ref]
The elementary reason the two Chebyshev functions have the same leading behavior is that their difference is small compared with x. Every additional prime power has base p≤x​, and for each such prime number its total extra weight is at most logx. There are at most ⌊x​⌋ such bases, so
0≤ψ(x)−ϑ(x)≤⌊x​⌋logx,xψ(x)−ϑ(x)​⟶0.
(51)
This transfers ψ(x)∼x to ϑ(x)∼x, or conversely, once either is established. Partial summation then relates the Chebyshev theta function to the prime-counting function. The estimate controls the extra prime powers; proving the leading value itself is the harder Prime number theorem problem.
