An outline font stores glyph shapes as geometric boundaries that can be scaled before drawing. Bézier curves provide editable segments of these boundaries. TrueType outlines use quadratic Bézier curves; Type 2 charstrings used in Compact Font Format outlines use cubic Bézier curves. [ref] [ref]
