Equivalence relation (x∼y)

 ... Mathematics Area of mathematics Foundations of mathematics Set theory Finitary relation Binary relation
OurBigBook.com Words: 2k Articles: 16
An equivalence relation says which set elements should count as the same for a particular purpose. In modular arithmetic, for example, distinct integers with the same remainder are equivalent. The relation gathers interchangeable set elements into equivalence classes; the quotient set then treats each whole equivalence class as one object.
Formally, an equivalence relation on a set X is a binary relation R⊆X×X, written x∼y, satisfying three conditions for all x,y,z∈X:
  • Reflexivity: x∼x.
  • Symmetric relation: x∼y implies y∼x.
  • Transitivity: x∼y and y∼z imply x∼z.
These conditions make the equivalence classes a partition of a set: each set element belongs to exactly one class. [ref]
For a worked example, take the finite set X={0,1,…,8} and restrict integer congruence modulo three to X:
x∼y⟺x≡y(mod3)⟺3∣(x−y).
(13)
Reflexivity follows because x−x=0. The symmetric relation property follows by changing the sign of a difference, and transitivity follows by adding x−y and y−z: divisibility by three is preserved in both steps. Thus 0∼3 and 3∼6 force 0∼6. The three equivalence classes are {0,3,6}, {1,4,7} and {2,5,8}. Their members alternate along the number line; membership in an equivalence class need not mean being close together.
The transitivity requirement rules out a tempting alternative. On {0,1,2}, define nearness by the absolute value condition ∣x−y∣≤1. This binary relation is reflexive and symmetric, but 0 is near 1 and 1 is near 2 while 0 is not near 2. Its neighborhoods {0,1}, {0,1,2} and {1,2} overlap without being equal. They are not equivalence classes or a partition of a set.
