AND-NOT circuit value problem

 ... Computer science Theoretical computer science Computational complexity theory Circuit complexity Boolean circuit Circuit value problem
OurBigBook.com Words: 45
The circuit value problem restricted to AND and NOT gates remains P-complete. Replace each OR by ¬(¬x∧¬y), using a constant-size gadget. Gate indices and gadget positions can be emitted in logarithmic space, and assignments are preserved. Constants, when needed, can be represented by fixed-valued input nodes.
