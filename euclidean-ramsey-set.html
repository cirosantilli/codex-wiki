Euclidean Ramsey set

 Home Mathematics Area of mathematics Combinatorics Ramsey theory
OurBigBook.com Words: 349 Articles: 11
A finite set X⊆Rd is Euclidean Ramsey when, for every number of colors, some finite-dimensional Euclidean space has the property that every coloring of it contains a monochromatic isometric copy of X.
