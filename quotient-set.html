Quotient set (X/∼)

 ... Mathematics Area of mathematics Foundations of mathematics Set theory Binary relation Equivalence relation
OurBigBook.com Words: 379 Articles: 1
A quotient set packages each equivalence class as a single new set element. It remembers which class an original set element belongs to and forgets which member of that class it was. For an equivalence relation ∼ on a set X,
X/∼={[x]:x∈X}.
(17)
Each set element of the quotient set is itself a nonempty subset of X. The canonical projection of a quotient set sends an original set element to this entire equivalence class. [ref]
For integer congruence modulo three restricted to X={0,1,…,8}, the quotient set is
X/∼={{0,3,6},{1,4,7},{2,5,8}}={[0],[1],[2]}.
(18)
It has cardinality three. The set {0,1,2} is a choice of equivalence class representatives, not literally this quotient set: 0 is an integer, while [0]={0,3,6} is a set. The function sending each chosen equivalence class representative to its equivalence class is a bijection between these two different sets.
A quotient set alone specifies no arithmetic. To obtain the familiar modular arithmetic example with addition, use integer congruence on the whole set of integers. Its quotient set is Z/3Z={[0]3​,[1]3​,[2]3​}, where [a]3​={a+3k:k∈Z} is an infinite residue class. Define addition by
[a]3​+[b]3​=[a+b]3​.
(19)
The answer must be independent of the equivalence class representatives. If a′=a+3k and b′=b+3ℓ, then a′+b′=a+b+3(k+ℓ), so both sums have the same residue class. This is what it means for the group operation to be well-defined. With this addition, the quotient set is a cyclic group, with identity [0]3​ and inverse [−a]3​ for [a]3​. [ref]
For example, [2]3​+[2]3​=[4]3​=[1]3​. Choosing 5 and −1 as different representatives of an equivalence class for [2]3​ gives the same sum; choosing 8 and 5 gives [13]3​=[1]3​ again. These calculations use residue classes of all integers. Raw addition on the finite X={0,…,8} does not stay in X: 8+8=16∈/X. The formula for addition on Z/3Z therefore cannot be applied as a raw inherited operation on that finite example.
