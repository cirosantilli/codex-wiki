Discrete uniform distribution (pX​(x)=1/n for x∈S)

A discrete uniform distribution gives every element of a nonempty finite set S the same probability. Write n=∣S∣ for its cardinality. A random variable X with this law has support of a probability distribution S and probability mass function
pX​(x)=P(X=x)={1/n,0,​x∈S,x∈/S.​
(8)
The masses sum to n(1/n)=1. Conversely, if all n masses equal p, their sum is np=1, so necessarily p=1/n. Thus equal chances determine the whole law.[ref]
Counting now computes an event's probability: for any set A of possible values,
P(X∈A)=∑x∈A∩S​n1​=n∣A∩S∣​.
(9)
In particular, when A⊆S, the answer is ∣A∣/∣S∣. The intersection matters: values outside the support of a probability distribution contribute zero. This turns a probability question into a combinatorics question, provided that equal chances are justified by the model.
For an ideal fair six-sided die, S={1,2,3,4,5,6} and each face has probability 1/6. The event of an even integer is {2,4,6}, so its probability is 3/6=1/2; the event X≥5 has probability 2/6=1/3. Direct summation gives the expected value EX=21/6=7/2 and the variance Var(X)=91/6−(7/2)2=35/12. The mean 7/2 is a balance point between possible outcomes. These are exact consequences of stipulated fairness, rather than measured frequencies from physical dice.
Uniformity describes probabilities, not distances between values. For a second constructed model, stipulate equal-chance selection from S={1,2,4,8}. Every value has probability 1/4, despite the unequal gaps 1,2,4. Here P(X≥4)=2/4=1/2, while the expected value and variance are
EX=41+2+4+8​=415​,E[X2]=41+4+16+64​=485​,Var(X)=485​−(415​)2=16115​.
(10)
Neither the midpoint of the extreme values, 9/2, nor a formula using only the cardinality gives these moments. For a general numerical support of a probability distribution, use its actual values:
μ=n1​∑x∈S​x,Var(X)=n1​∑x∈S​(x−μ)2.

Choosing an item from a finite list with equal chances is a basic building block of simple random sampling. A bijection that relabels the items preserves equal probabilities, although changing numerical labels can change the expected value and variance. A function that merges labels can destroy uniformity: for the fair-die model, Y=min(X,3) has masses 1/6,1/6,4/6 at 1,2,3, since four faces map to three. Always count the original equally likely outcomes.
An indicator random variable for membership in a set A⊆S has a Bernoulli distribution with parameter ∣A∣/n; counting that event over r independent repetitions gives a binomial distribution with parameters r and ∣A∣/n. Equal chances among individual values need not produce equal chances among aggregated counts.[ref]
