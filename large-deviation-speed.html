Large-deviation speed (aN​)

A large deviation principle with speed aN​→∞ and rate function I means that every open set G and closed set F satisfy
−infG​I≤liminfN​aN−1​logP(XN​∈G),limsupN​aN−1​logP(XN​∈F)≤−infF​I.
(19)
Multiplying the large-deviation speed by c>0 divides the rate function by c. The speed must match the rare-event scale: a fixed exponential random variable divided by Np has speed Np, whereas a sum of N independent random variables with a normal distribution, divided by Np, has speed N2p−1 when p>1.
