Strict order-preserving function (x<y⟹f(x)<f(y))

 ... Area of mathematics Foundations of mathematics Set theory Set Partially ordered set Order-preserving function
OurBigBook.com Words: 38
A strict order-preserving function preserves strict comparisons. Between strict partial orders it may identify incomparable elements. Between strict total orders it is necessarily injective, and in a finite chain it is exactly an increasing injection. It need not reflect comparisons between incomparable elements of general partial orders.
