Unbounded finite shattering without an infinite universal trace (F=⋃j≥1​P(Bj​))

 ... Area of mathematics Combinatorics Extremal set theory Set family Trace of a set family Set shattering
OurBigBook.com Words: 73
Partition an infinite countable set into disjoint finite blocks of unbounded size. The union of their power sets consists entirely of finite sets and shatters each block, so it has unbounded finite VC dimension. Every infinite set meets two different blocks. The pair formed by one point from each can never occur as a trace, since each family member stays in one block. Thus no infinite set has traces realizing all its finite subsets.
