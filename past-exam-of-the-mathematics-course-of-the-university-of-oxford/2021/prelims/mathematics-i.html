dimF​V=dimF​kerT+dimF​imT.​

The transpose is a linear map, so T(A)=A+AT is a linear map on the n2-dimensional vector space Mn×n​(F). Let Eij​ denote a matrix unit. The answer depends on the characteristic of a field.
If charF=2, then T(A)=0 means AT=−A. Such skew-symmetric matrices have zero diagonal, and their entries above the diagonal can be chosen freely. A basis of the kernel of a linear map is Eij​−Eji​ for i<j, giving nullity n(n−1)/2. The image of a linear map consists of all symmetric matrices: T(A) is symmetric, and every symmetric matrix S is T(S/2). If charF=2, then −A=A, so kerT consists of all symmetric matrices, with dimension n(n+1)/2. Every T(A) is symmetric with zero diagonal, and every symmetric zero-diagonal matrix S arises by taking Aij​=Sij​ for i<j and all other entries zero. The image of a linear map therefore has basis Eij​+Eji​ for i<j, and dimension n(n−1)/2. This is the symmetrization map in characteristic two.

Suppose, for a contradiction, that p and q have no common root of a polynomial. Since the polynomial ring C[x] has no zero divisors and p,q=0, the relation ap+bq=0 with a,b not both zero forces both a and b to be nonzero.
By the fundamental theorem of algebra, write

where the αj​ are distinct. For each j, q(αj​)=0. The equality bq=−ap implies that (x−αj​)mj​ divides bq. The multiplicity of a root in polynomial multiplication is the sum of its multiplicities in the factors: factor out the largest powers of x−αj​ and note that the two remaining factors have nonzero values at αj​. Since q(αj​)=0, b must contain (x−αj​)mj​.

there is α∈C with p(α)=q(α)=0.​
(19)
Counting multiplicity of a root is necessary: counting only distinct roots of a polynomial would miss repeated factors.

i OurBigBook.com
The function composition of two bijections f,g:X→X is a bijection, with inverse function (f∘g)−1=g−1∘f−1. Thus function composition is a binary operation on Sym(X). It is associative, since both (f∘g)∘h and f∘(g∘h) send x to f(g(h(x))).
The identity function idX​ is a bijection and satisfies f∘idX​=idX​∘f=f. Every bijection f has an inverse function f−1:X→X, itself a bijection, satisfying f∘f−1=f−1∘f=idX​. These verify all group axioms, so Sym(X) is a group, the symmetric group of X.

ii

Words: 101 Articles: 1
a OurBigBook.com
Solution
Words: 101
ii OurBigBook.com
For a singleton X, the symmetric group contains only the identity function. For a two-element set, it contains the identity function and the transposition exchanging the two elements; the latter squares to the identity function. In both cases all elements commute, so the group is Abelian.
If X contains three distinct elements a,b,c, define the transpositions σ=(a b) and τ=(b c), fixing every other element of X. They are bijections, even when X is infinite. With function composition read from right to left,
(σ∘τ)(a)=b,(τ∘σ)(a)=c.
(43)
Thus they do not commute, so the symmetric group is not Abelian. Since X is nonempty, this proves
Sym(X) is abelian⟺X is finite and ∣X∣≤2.​
(44)

(z∗x)∗(z∗x)=(z∗(x∗z))∗x=(z∗e)∗x=z∗x.
(48)
Thus z∗x is an idempotent element of a semigroup. By i it equals e, proving
z∗x=e.​
(49)
No left identity element or cancellation law is needed for this deduction.

Solution

For any x, choose z with x∗z=e. By ii, z∗x=e as well. Associativity and the right identity element property now give
e∗x=(x∗z)∗x=x∗(z∗x)=x∗e=x.
(50)
Thus e is also a left identity element. The given binary operation is closed on X and associative, e is a two-sided identity element, and each x has the two-sided inverse element z. All group axioms hold, so (X,∗) is a group. This is the one-sided group axioms criterion.

c (Injections on finite and infinite sets)

Words: 143 Articles: 4
5 OurBigBook.com

i

Words: 45 Articles: 1

Solution
Words: 45
i OurBigBook.com
An injective function from a finite set to itself is surjective: its image of a function contains as many distinct elements as the entire set, so it cannot omit one. Thus every element of I(X) is a bijection, and conversely every bijection is injective. Hence
I(X)=Sym(X)for finite X.​
(51)
It is a group under function composition by i.

ii

Words: 98 Articles: 1
c OurBigBook.com
Solution
Words: 98
ii OurBigBook.com
The shift s:N→N, s(n)=n+1, is injective, so s∈I(N). It is not surjective: the least natural number is missing from its image of a function, whether N starts at zero or one. For every t:N→N, the image of a function of s∘t is contained in the image of a function of s, so s∘t=idN​.
The identity function belongs to I(N) and is its identity element under function composition; any group structure using that operation would have this same identity element. Since s has no right inverse element, I(N) is not a group under function composition. It is a monoid, since injectivity is preserved by function composition.

Each left coset gH is nonempty, since it contains g=ge, and every g∈G lies in its own left coset. Suppose aH and bH intersect, say ah1​=bh2​ with h1​,h2​∈H. Then

Fix x∈G. The integer powers of a group element satisfy
xz+w=xzxw,(xw)z=xwz=xzw(z,w∈Z).
(56)
For nonnegative integers these rules follow by associativity and counting factors; negative integers are handled by x−r=(x−1)r, and opposite signs by cancellation of adjacent inverse elements. All factors are powers of the same element, so no abelian group assumption is involved.
It follows that z↦ρ(z,x)=xz is a group homomorphism from the additive group of integers to G, and
ρ(z,ρ(w,x))=ρ(zw,x).​
(57)
The homomorphism uses ordinary addition on Z; composition of the power functions corresponds to ordinary multiplication of exponents.

ii

Solution

Suppose an arbitrary binary operation ⋆ makes Z a group and makes ρ a left group action on G. For any group action, each acting element induces a bijection: the function induced by its inverse element is its inverse function.
In particular, the acting element whose underlying integer is 0 must induce a bijection G→G. But its power function is
x⟼ρ(0,x)=x0=e,
(58)
a constant function. This is injective only when all elements of G equal e. Therefore
G={e}.​
(59)
This proves the power-map group action obstruction for every possible ⋆; it never assumes that ⋆ is ordinary integer multiplication, or that the integer 0 is the acting identity element.

c (Prime divisors of Mersenne numbers)

i OurBigBook.com
If the prime number p divides 2q−1, then p=2, because 2q−1 is odd. Thus the residue of 2 is an element of the multiplicative group of a finite field Zp​, and 2q≡1(modp).
Let d be its order of a group element. The integer division writes q=ad+r with 0≤r<d. Then 1≡2q≡(2d)a2r≡2r(modp), so minimality of d gives r=0. Hence d divides q. Since q is a prime number, d=1 or d=q. The former would give 2≡1(modp), which would mean p divides 1, an impossibility. Consequently
ordp​(2)=q.​
(61)

c OurBigBook.com
Solution
Words: 49

q=ordp​(2)∣p−1.
(62)
Since q and p−1 are positive integers, q≤p−1, and hence
p>q.​
(63)
This applies to every prime factor, including repeated prime factors viewed as the same prime number.

c OurBigBook.com
Solution
Words: 81

Suppose there were only finitely many prime numbers. There is at least one, namely 2, so this finite set would have a largest element q. The integer 2q−1 is greater than 1 and therefore has a prime factor p: for example, its least divisor greater than 1 must be a prime number, since any proper factor of that divisor would contradict minimality.

The orbit of x under conjugation is its conjugacy class

The specified set A is the center of a group Z(G). It contains e. If a,b∈A and y∈G, then
(ab)y=a(by)=a(yb)=(ay)b=y(ab),
(66)
so ab∈A. From ay=ya, multiplying on the left and right by a−1 gives ya−1=a−1y, so a−1∈A. Hence A is a subgroup.
For g∈G and a∈A, the defining commutativity gives gag−1=agg−1=a. Thus the image of each element of A under conjugation is in A, and indeed gAg−1=A. Consequently A=Z(G) is a normal subgroup of G.

A conjugacy class C(x) is a singleton exactly when gxg−1=x for every g∈G, equivalently when gx=xg for every g. Thus the singleton conjugacy classes correspond exactly to elements of the center of a group A, and there are ∣A∣ of them.
Every other conjugacy class has at least two elements. Since the conjugacy classes form a partition of a set G, if r is the number of these remaining classes then 2r≤∣G∣−∣A∣. Consequently
m(G)=∣A∣+r≤∣A∣+2∣G∣−∣A∣​=2∣G∣+∣A∣​.​
(71)
This conjugacy class count bound from the center needs no classification of the finite group.
