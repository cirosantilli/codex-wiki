Let f be continuous in its first variable and uniformly Lipschitz continuous in its second variable, with constant L≥0. Retain the finite-interval smoothness assumptions and the bound ∥τn​∥≤Kh2 from the preceding subpart. We first establish solvability of each implicit step. For a proposed starting state u, the map
Gu​(v)=u+hf(xn​+2h​,2u+v​)
(43)
has Lipschitz constant hL/2. If hL/2<1, the contraction mapping theorem on the complete state space gives a unique next state v=Ψn,h​(u).
To compute a useful Lipschitz constant for the method, introduce its increment function by
Ψn,h​(u)=u+hΦn,h​(u),Φn,h​(u)=f(xn​+2h​,u+2h​Φn,h​(u)).
(44)
For two starting states u,w,
∥Φn,h​(u)−Φn,h​(w)∥≤L∥u−w∥+2hL​∥Φn,h​(u)−Φn,h​(w)∥.
(45)
Rearranging gives the implicit midpoint Lipschitz estimate
Lip(Φn,h​)≤1−hL/2L​,Lip(Ψn,h​)≤Rh​:=1−hL/21+hL/2​.​
(46)
Thus, for example, hL≤1 gives an increment Lipschitz constant at most 2L, uniformly as h→0.
For an explicit global error estimate, set en​=Yn​−yn​. Subtract the numerical formula from the exact-value identity containing hτn​:
en+1​=en​+h[f(xn​+2h​,2Yn​+Yn+1​​)−f(xn​+2h​,2yn​+yn+1​​)]+hτn​.
(47)
The Lipschitz condition and the triangle inequality imply
(1−hL/2)∥en+1​∥≤(1+hL/2)∥en​∥+h∥τn​∥,
(48)
and therefore
∥en+1​∥≤Rh​∥en​∥+1−hL/2Kh3​.
(49)
Iterating this inequality is the elementary discrete Gronwall inequality argument. For L>0, summing the geometric series and using Rh​−1=hL/(1−hL/2) gives
∥en​∥≤Rhn​∥e0​∥+LKh2​(Rhn​−1).
(50)
For hL≤1, Rh​=1+hL/(1−hL/2)≤1+2hL≤e2hL. If nh≤T, this proves
nh≤Tmax​∥en​∥≤e2LT∥e0​∥+LK​(e2LT−1)h2.​
(51)
With the exact initial value, e0​=0, the global error is O(h2) and tends uniformly to zero on every such finite interval. If L=0, the recurrence instead gives ∥en​∥≤∥e0​∥+KTh2, with the same conclusion. Starting values merely converging to the exact initial value also suffice for numerical convergence; second-order accuracy requires their errors to be O(h2). The result concerns exact implicit solves and convergence on fixed finite intervals, not uniform accuracy over an unbounded time interval.
