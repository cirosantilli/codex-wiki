Borel measurable function

 ... Mathematics Area of mathematics Analysis Real analysis Measure theory Measurable function
OurBigBook.com Words: 56
For topological spaces X,Y, a Borel measurable function f:X→Y is a measurable function for the Borel sigma-algebras on both spaces. Equivalently, the preimage of every open set in Y is a Borel set in X. With a different source sigma-algebra A, the phrase measurable into Y with its Borel sigma-algebra means f−1(B)∈A for every Borel B⊆Y; specifying the source is essential.
