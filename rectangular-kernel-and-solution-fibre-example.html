Rectangular kernel and solution-fibre example

Consider the linear map A:R3→R2 represented by the rectangular matrix
A=(10​21​01​),A​xyz​​=(x+2yy+z​).

To compute its kernel, solve the homogeneous linear system x+2y=0, y+z=0. Taking y=t gives x=−2t, z=−t, so
kerA=⎩⎨⎧​t​−21−1​​:t∈R⎭⎬⎫​,v=​−21−1​​,Av=(−2+21−1​)=0.

Thus v represents a null direction of a linear map: decreasing the first input by two, increasing the second by one, and decreasing the third by one changes neither output. Solving the homogeneous linear system is the concrete computation behind a kernel; the column space instead decides which outputs are attainable.[ref]
Now prescribe the nonzero output b=(3,2)T. The linear system Au=b becomes x+2y=3, y+z=2. Again take y=t:
u=​3−2tt2−t​​=u0​​302​​​​+tv​−21−1​​​​,t∈R.
(6)
Direct substitution gives Au0​=(3,2)T, and A(u0​+tv)=Au0​+tAv=b. Conversely, the two linear equations force exactly this form, so no solutions have been omitted. This fiber is an affine subspace of dimension one in the three-dimensional input vector space. It is parallel to the kernel, but does not pass through the origin. For instance, u0​=(3,0,2)T and u1​=(1,1,1)T both give b, while their difference u1​−u0​=v gives zero. Adding u0​ and u1​ gives output 2b, which is another way to see that this nonzero-output fiber is not a vector subspace.
The first and third columns of A are (1,0)T and (0,1)T, a basis of the output vector space. Hence A has matrix rank two and reaches every output. The rank-nullity theorem predicts nullity 3−2=1 before we solve any linear system. It provides a useful completeness check: one nonzero kernel vector already forms a basis here, so a second independent null direction of a linear map would signal a calculation error. In general, matrix rank r for an m×n matrix leaves n−r independent kernel directions, rather than m−r.[ref]
