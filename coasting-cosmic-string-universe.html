Coasting cosmic-string universe (a(t)=B(t−tB​))

An isotropic cosmic string network with ρ=C/a2 has equation-of-state parameter w=−1/3. The Friedmann equation gives a˙2=8πGC/3−K. On the expanding branch with positive right side, a=B(t−tB​), the comoving Hubble radius is constant, and the cosmological density parameter is constant. There is no growing flatness problem, but flatness is not an attractor. If this exact coasting solution extends all the way to tB​, then ∫tB​t​dt′/a(t′) diverges and there is no finite particle horizon. A finite starting time changes that global conclusion.
