Power-set failure at the first rank above V omega ((Vω+1​,∈)⊨PowerSet)

 Home Mathematics Area of mathematics Foundations of mathematics Set theory Axiom of power set
OurBigBook.com Words: 48
Every finite ordinal belongs to Vω​, so ω∈Vω+1​ but ω∈/Vω​. An internal power set y of ω would contain ω itself. Yet y∈Vω+1​ implies y⊆Vω​, making that impossible. This example illustrates why one must check which subsets the structure sees when proving an axiom fails.
