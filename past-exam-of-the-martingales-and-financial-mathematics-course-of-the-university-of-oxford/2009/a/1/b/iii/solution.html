Suppose first that complete convergence holds. For each positive integer j, apply the First Borel-Cantelli lemma to {∣Xn​−X∣>1/j}. Outside a countable union of null events, only finitely many of these exceedances occur for every j. This is almost sure convergence, with no independence assumption.
For the converse, an important point is that independence of Xn​ does not immediately imply independence of Xn​−X. Instead use the fact that an almost-sure limit of independent random variables is constant. Indeed, Z=limsupn​Xn​ is measurable for the tail sigma-algebra. The Kolmogorov zero-one law makes each event {Z≤q}, q∈Q, have probability zero or one. Since Z=X almost surely and X is finite, these probabilities form the distribution function of a point mass: there is a finite constant c with X=c almost surely.
Now {∣Xn​−c∣>ϵ} are independent events. Almost sure convergence says that their infinitely-often event has probability zero. The contrapositive of the Second Borel-Cantelli lemma gives
∑n​P(∣Xn​−c∣>ϵ)<∞.
(9)
Replacing c by the almost surely equal X leaves each probability unchanged. Thus complete convergence and almost sure convergence are equivalent for independent sequences.
