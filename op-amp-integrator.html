Op amp integrator

An op amp integrator places a resistor R between the input source and the inverting input of an operational amplifier, and a feedback capacitor C between that input and the output, with the non-inverting input grounded. For an ideal operational amplifier, Kirchhoff's current law gives vin​/R=−Cdvo​/dt, hence
vo​(t)=vo​(t0​)−RC1​∫t0​t​vin​(u)du,H(s)=−sRC1​.

The initial capacitor charge supplies the integration constant. A parallel feedback resistor Rf​ replaces the transfer by H(s)=−(Rf​/R)/(1+sRf​C): the direct-current gain becomes finite while integration is recovered when ∣sRf​C∣≫1. This limits offset-driven saturation. [ref]
