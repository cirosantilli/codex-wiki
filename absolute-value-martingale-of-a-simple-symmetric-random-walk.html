Absolute value martingale of a simple symmetric random walk (Mn​=∣Sn​∣−∑k=0n−1​1{Sk​=0}​)

Let a simple symmetric random walk start from a deterministic integer S0​=i, and put Ln​=∑k=0n−1​1{Sk​=0}​. Then Mn​=∣Sn​∣−Ln​ is a martingale with M0​=∣i∣. The visit count includes time 0 if i=0.
For every integer s and step ξ∈{−1,1}, the pathwise identity
∣s+ξ∣−∣s∣=sgn(s)ξ+1{s=0}​
(20)
holds with sgn(0)=0. Subtract the indicator function and sum over time to obtain
Mn​=∣i∣+∑k=0n−1​sgn(Sk​)(Sk+1​−Sk​).
(21)
The sign function of the current state is a bounded predictable process for the next increment, so the sum is a martingale transform. Alternatively, averaging the two possible next absolute values shows directly that the conditional drift is 1{Sk​=0}​. Bounds ∣Sn​∣≤∣i∣+n and Ln​≤n verify integrability at each finite time.
This is an absolute-value version of the discrete Tanaka formula. The correction records the occasions when the random walk is at the corner of the absolute-value function; away from zero that function is locally linear along a single step.
