Past exam of the model theory course of the University of Oxford / 2011 / 3 / b / iii / Solution

OurBigBook.com Words: 244
The Łoś theorem states that, for every first-order formula φ(x) and product representatives a1,…,ar,
i∏​Ai​/U⊨φ([a1],…,[ar])⟺{i:Ai​⊨φ(ai1​,…,air​)}∈U.​
(28)
It extends the defining relation-symbol rule to arbitrary first-order formulas, including quantified ones.
Identify the countable index set with N. A nonprincipal ultrafilter on it contains every cofinite set. Let p(x) be a type over a finite parameter set in the ultraproduct M, finitely satisfiable in M. Because the language and parameter set are countable, enumerate it as φ0​(x),φ1​(x),…, with chosen product representatives for the parameters. By finite satisfiability and Łoś,
Xn​={i:Ai​⊨∃x⋀j≤n​φj​(x)}∈U.
(29)
Make these large sets decrease while forcing their intersection to be empty:
Yn​={i:i≥n}∩⋂k≤n​Xk​∈U.
(30)
For each index i, let r(i) be the largest n≤i with i∈Yn​, if one exists. Choose bi​∈Ai​ satisfying the first r(i)+1 first-order formulas; this is possible because i∈Xr(i)​. If no such n exists, choose any bi​.
For each fixed n, every i∈Yn​ has r(i)≥n, so bi​ satisfies φn​. Its coordinate truth set contains Yn​ and belongs to U. Another use of Łoś gives M⊨φn​([b]) for every n. Thus [b] realizes the type. This proves the countable saturation of an ultraproduct over omega, and in particular the ultraproduct is omega-saturated. The construction chooses a finite number of requirements at each coordinate; it does not presume the whole infinite type has a witness in any factor.
