Array (data structure)

 Home Computer science Data structure
OurBigBook.com Words: 1k Articles: 16
A data structure storing entries at numbered positions, usually starting at index zero. The fixed-capacity representation considered here puts equal-sized slots consecutively in computer memory. The number n of occupied slots can be smaller than the capacity; unused slots provide room for later entries. An array of references stores consecutive references, while the objects they identify can be elsewhere. [ref]
Let the first slot have abstract address b and each slot occupy s address units. Then indexed access computes
address(i)=b+is,0≤i<n.
(15)
For toy values b=100, s=4, the slots for A,B,C start at 100,104,108; index 2 goes directly to C through 100+2⋅4=108. These are illustrative slot addresses, not observed allocation addresses. Under the word-RAM (random-access machine) model for time complexity, word-sized arithmetic operations and any addressed computer memory access have constant cost, and the addresses and entries fit in words. Thus one array access takes O(1) time in Big O notation, independently of the index. This is the access assumption needed by binary search. [ref]
Inserting X after B in an array holding A,B,C with one unused slot produces A,B,X,C: first copy C from slot 2 to slot 3, then write X into slot 2. Writing X first would lose C unless it had been saved separately. More generally, insert at index i by copying occupied slots from right to left, then fill the gap; with spare capacity this moves n−i entries and takes O(1+n−i) time in Big O notation, so insertion near the middle has O(n) time complexity. Removing an entry closes the gap by shifting later entries left. [ref]
A fixed-capacity array cannot accept another entry when full. A resizable representation can allocate a larger array and copy the entries. Doubling capacity when full gives O(1) append cost by amortized analysis over a sequence starting empty, but a single append that copies n entries still has O(n) worst-case time complexity. The outline is a geometric series: copied capacities 1,2,4,…,2k sum to 2k+1−1, less than twice the number of appends that triggered the last copy. Middle insertion still pays for its shifts. [ref]
