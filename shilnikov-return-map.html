Shilnikov return map (z′=−μ+Azδcos(Ωlogz+Φ))

 ... Physics Branches of physics Dynamical systems Dynamical system Homoclinic orbit Shilnikov bifurcation
OurBigBook.com Words: 192 Articles: 1
A passage near a saddle-focus contracts a transverse radius by zδ while rotating it by an angle proportional to logz. A smooth global reinjection converts these transverse coordinates into a sinusoidal return in z. The map is defined only for positive passage coordinates that return on the chosen branch. The full two-dimensional map has determinant of order z2δ−1; for δ>1/2 its thin transverse geometry supports a leading one-dimensional approximation. A one-passage orbit has period T=Tg​+λ+−1​log(z0​/z).
