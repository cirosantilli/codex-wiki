Linked list node

 Home Computer science Data structure Linked list
OurBigBook.com Words: 96 Articles: 1
One record holding an item and the references that connect it into a linked list. In the singly linked examples, its next identifies the successor or is null. A linked list node's position in the sequence can change when links change, without moving the linked list node in computer memory.
