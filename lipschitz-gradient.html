Lipschitz gradient (∥∇f(x)−∇f(y)∥2​≤β∥x−y∥2​)

 Home Mathematics Area of mathematics Analysis Numerical analysis Gradient descent
OurBigBook.com Words: 374 Articles: 1
A differentiable function has a β-Lipschitz gradient on a set D if its gradient satisfies Lipschitz continuity there:
∥∇f(x)−∇f(y)∥2​≤β∥x−y∥2​(x,y∈D),β≥0.
(12)
All norms here are the Euclidean norm. The constant limits how fast the gradient changes; it is not a bound on the magnitude of the gradient. For f(x)=(x12​+9x22​)/2, the gradient is the linear map x↦diag(1,9)x. Its operator norm is 9, so β=9 works globally and is sharp by taking x−y=(0,1)T. The gradient itself is unbounded on the whole Euclidean space.
If f has a continuous Hessian matrix on an open convex set D and ∥∇2f(z)∥2​≤β throughout D, integrate that linear map along the line segment from x to y:
∇f(y)−∇f(x)=∫01​∇2f(x+t(y−x))(y−x)dt.
(13)
The operator norm bound proves the displayed Lipschitz continuity. Convexity of the domain keeps the entire line segment inside it. Bounding the Hessian matrix only at the endpoints is insufficient.
