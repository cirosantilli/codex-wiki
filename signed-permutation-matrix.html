Signed permutation matrix

 ... Algebra Linear algebra Vector space Linear map Matrix Permutation matrix
OurBigBook.com Words: 35
A signed permutation matrix has exactly one nonzero entry in each row and column, and every nonzero entry is 1 or −1. It is a product of a diagonal sign matrix and a permutation matrix.
