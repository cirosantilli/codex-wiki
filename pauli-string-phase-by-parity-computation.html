Pauli-string phase by parity computation (eitZ⊗n)

 Home Physics Branches of physics Quantum theory Hamiltonian simulation Simulation of a computable diagonal Hamiltonian
OurBigBook.com Words: 60
The Pauli Z gates give eigenvalue (−1)∑j​xj​ on ∣x⟩. Use parity computation by CNOT gates to put the parity bit in a zero ancilla, apply eitZ to it, and uncompute. The data acquire exactly eit(−1)∑j​xj​, and the ancillary line returns to zero. This compute-phase-uncompute construction needs 2n+1 one- and two-qubit gates. Accumulating parity into the last data line instead uses 2n−1 gates without an extra ancilla. Neither implementation drops the global phase.
