Synchronous 110 detector (zk​=ak−2​ak−1​(1−ak​))

 ... Mathematics Area of mathematics Foundations of mathematics Formal language theory Finite-state machine Synchronous sequential circuit
OurBigBook.com Words: 85
A synchronous sequential circuit emitting a one-cycle pulse at the first low sample after at least two consecutive high samples. Three D flip-flops can implement q1+​=a, q2+​=q1​∧a, and z+=q2​∧¬a, with all updates using the old state. Initializing all state bits to zero excludes a false startup history. The stored output changes only at clock edges. After a detecting low sample, q2​ becomes zero, so the next output is zero regardless of the next input. A longer high run still ends with the same three-sample pattern.
