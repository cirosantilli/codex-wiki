Canonical height of an elliptic curve (h)

This is the elliptic-curve specialization of the Néron–Tate height. For an associated logarithmic projective height h, one normalization is h(P)=limno∞​4−nh([2n]P).
The canonical height is
h(P)=21​limr→∞​4−rh(x(2rP)).
(30)
It is a quadratic form, vanishes on torsion points, and satisfies h(ϕP)=deg(ϕ)h(P) for every isogeny ϕ.
