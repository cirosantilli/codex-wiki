Efron–Stein inequality (Var(Z)≤21​∑i​E(Z−Zi′​)2)

 ... Mathematics Area of mathematics Probability and statistics Probability theory Probability inequality Concentration inequality
OurBigBook.com Words: 748 Articles: 1
The Efron–Stein inequality bounds the variance of a complicated output by the effect of replacing one input at a time. Let X1​,…,Xn​ be mutually independent random variables, not necessarily identically distributed, and Z=f(X1​,…,Xn​) for a measurable function f, with EZ2<∞. Take X1′​,…,Xn′​ with Xi′​ having the same probability distribution as Xi​, all 2n inputs mutually independent. Define
Zi′​=f(X1​,…,Xi−1​,Xi′​,Xi+1​,…,Xn​).
(45)
Use the same function f, keeping every other input fixed. Then
Var(Z)≤21​i=1∑n​E[(Z−Zi′​)2].​
(46)
The expected value averages over both the original inputs and their replacements. An infinite right side gives a trivial bound; under the stated square-integrable condition every term is finite.[ref]
For a concrete four-state example, take independent Bernoulli random variables with P(X1​=1)=0.3 and P(X2​=1)=0.6, and set Z=max{X1​,X2​}. This output records whether either input is one. The states (0,0),(1,0),(0,1),(1,1) have respective probabilities 0.28,0.12,0.42,0.18, so
P(Z=1)=0.72,Var(Z)=0.72(1−0.72)=0.2016.
(47)
Replacing X1​ changes Z only when X2​=0 and X1′​=X1​. A fresh Bernoulli draw can repeat the old value: the replacement is not a forced flip. By independence, the expected value of the squared change is
E[(Z−Z1′​)2]=0.4[0.7(0.3)+0.3(0.7)]=0.168.
(48)
Similarly,
E[(Z−Z2′​)2]=0.7[0.4(0.6)+0.6(0.4)]=0.336.
(49)
Thus Efron–Stein inequality gives 0.2016≤(0.168+0.336)/2=0.252. The larger second contribution reflects both its replacement probability and how often the other input leaves the output sensitive to it.
For the same inputs, consider instead W=X1​+2X2​. The variance of a sum of independent random variables gives
Var(W)=0.3(0.7)+4(0.6)(0.4)=1.17.
(50)
Here E[(W−W1′​)2]=0.42 and E[(W−W2′​)2]=1.92, so the Efron–Stein inequality is exact: (0.42+1.92)/2=1.17. More generally, for W=c+∑i​gi​(Xi​) with square-integrable summands, each contribution 21​E[(W−Wi′​)2] equals Var(gi​(Xi​)) and these variances add exactly.
Independence is essential. Let X1​=X2​=B for a single Bernoulli random variable with parameter 1/2, and take W=X1​+X2​=2B. Its variance is one. If each coordinate is nevertheless replaced by an independent draw from its marginal Bernoulli distribution, each squared-change expected value is 1/2, giving the false proposed upper bound 1/2. Replacement now creates off-diagonal states (0,1) and (1,0) that the original input never visits. The original coordinates fail the hypothesis of Efron–Stein inequality.
The attraction is local calculation: a function may involve many inputs, yet changing one can have a simple effect. Each half squared-change expected value supplies a coordinate's contribution to an upper budget for the total variance. Applying Chebyshev's inequality then bounds a tail probability using that budget. These contributions need not partition the actual variance, as the maximum example shows.
The name commemorates Bradley Efron and Charles M. Stein. Their 1981 paper The Jackknife Estimate of Variance appeared in The Annals of Statistics, volume 9, issue 3, pp. 586–596.[ref]
