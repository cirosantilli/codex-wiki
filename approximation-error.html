Approximation error (xapprox​−x)

 Home Mathematics Area of mathematics Analysis Numerical analysis
OurBigBook.com Words: 223 Articles: 4
For a numerical reference value x and a computed value xapprox​, the signed approximation error is xapprox​−x. Stating the reference matters: comparison with a measured value assesses agreement with that value, rather than with an unknown exact value.
