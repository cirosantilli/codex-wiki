Self-delimiting binary code

 Home Computer science Theoretical computer science Formal language Binary string
OurBigBook.com Words: 48
A self-delimiting code permits a decoder to identify the end of a code without an external length marker. Encoding a binary word of length ℓ by ℓ ones, a zero and the word uses 2ℓ+1 bits. This yields an O(logn) description of a natural number in an incompressibility proof.
