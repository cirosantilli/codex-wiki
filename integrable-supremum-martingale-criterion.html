Integrable-supremum martingale criterion (Esups≤T​∣Ms​∣<∞)

 ... Probability and statistics Probability theory Martingale Continuous-time martingale Local martingale Continuous local martingale
OurBigBook.com Words: 38
If a local martingale has an integrable running absolute supremum on each fixed finite horizon, localization and conditional dominated convergence make it a true martingale. This upgrades polynomial Itô local martingales when maximal moments and bracket moments control all terms.
