The matrix C in the Knill--Laflamme condition is positive semidefinite, since v†Cv is the squared norm of ∑a​va​Ea​∣ψ⟩ for any normalized code state. Diagonalizing it gives linear combinations Fj​ with PFj†​Fl​P=cj​δjl​P. For cj​>0, Vj​=Fj​P/cj​​ is an isometry of the code into an error-image subspace, and these subspaces are orthogonal.
