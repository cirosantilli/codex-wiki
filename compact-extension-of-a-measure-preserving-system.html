Compact extension of a measure-preserving system (AP(X∣Y)​L2=L2(X))

 ... Measure theory Ergodic theory Measure-preserving transformation Measure-preserving system Factor of a measure-preserving system Factor map between measure-preserving systems
OurBigBook.com Words: 160 Articles: 2
An extension for which the relatively almost periodic observables are dense in global L2. Density does not assert that every L2 function already meets the uniform finite-net condition on fibers. Localization yields the positive-measure almost periodic indicator in a compact extension.
