Coefficient matrix (A=(aij​))

 Home Mathematics Area of mathematics Algebra Linear algebra System of linear equations
OurBigBook.com Words: 48
For a linear system ∑j​aij​xj​=bi​, the coefficient matrix A contains the coefficients of the unknowns, with one row per equation and one column per unknown. The system becomes Ax=b. The augmented matrix [A∣b] additionally includes the right-hand-side column; that column is not part of A.
