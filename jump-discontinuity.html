Jump discontinuity

 ... Analysis Real analysis Calculus Limit of a function Continuous function Discontinuity of a function
OurBigBook.com Words: 40
A jump occurs when both finite one-sided limits of a function exist but differ. Unlike an isolated change in value, a jump changes limiting values on whole one-sided neighbourhoods. One-sided Fourier spectrum excludes jumps explains an obstruction to jumps for functions with only nonnegative Fourier coefficients.
