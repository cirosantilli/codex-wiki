Translating accelerated reference frame (mR¨=F−ma¨)

 Home Physics Mathematical physics Reference frame
OurBigBook.com Words: 52
If the origin of a nonrotating reference frame has inertial position a(t) and a particle has relative position R, then r=R+a. Newton's second law becomes mR¨=F−ma¨. The effective inertial force is therefore −ma¨. No rotation-dependent terms arise because the coordinate axes remain parallel to the inertial axes.
