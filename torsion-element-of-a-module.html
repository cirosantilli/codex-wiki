Torsion element of a module (∃r=0: rm=0)

 ... Algebra Commutative algebra Module theory Module (mathematics) Torsion module Torsion submodule
OurBigBook.com Words: 43
For a module over an integral domain, a torsion element is killed by some nonzero scalar. These elements form the torsion submodule: the product of nonzero annihilating scalars annihilates a sum. This scalar-annihilation definition differs from saying that an element has finite order in a group.
