Rank-one downdate along an eigenvector ((A−ρbbT)b=(λ−ρ)b,(A−ρbbT)∣b⊥​=A∣b⊥​)

Let A be a real symmetric positive-definite matrix, and let b be a unit eigenvector with eigenvalue λ>0. The rank-one matrix update C=A−ρbbT changes only the eigenvalue along b, to λ−ρ. Symmetry makes the orthogonal complement b⊥ invariant, and Cw=Aw there because bTw=0.
In detail, write x=tb+w with w⊥b. Then
xTCx=(λ−ρ)t2+wTAw.
(8)
Consequently C is a positive-definite matrix for ρ<λ, singular for ρ=λ, and has exactly one negative eigenvalue for ρ>λ. In dimension at least two the last case is indefinite. In dimension one it is negative definite instead: there is no nonzero orthogonal-complement direction. The distinction matters when classifying a stationary point of a quadratic form.
