Best-bound search

 Home Mathematics Area of mathematics Mathematical optimization Integer programming Branch and bound
OurBigBook.com Words: 52
For minimization, best-bound search expands the active branch and bound node with smallest lower bound. A feasible completed assignment supplies an incumbent upper bound. Nodes with lower bound at least that incumbent can be discarded when only one optimum is needed. Search ends with an optimality certificate when no active node can improve the incumbent.
