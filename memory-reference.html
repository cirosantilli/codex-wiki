Memory reference

 Home Computer science Computer memory
OurBigBook.com Words: 65 Articles: 1
An access to a location in computer memory, such as an instruction fetch, a read or a write. A page-level reference sequence records the corresponding memory page for each access, retaining repetitions and order.
