Null set (μ(N)=0)

 Home Mathematics Area of mathematics Analysis Real analysis Measure theory
OurBigBook.com Words: 63 Articles: 1
A measurable set N is a null set for a measure μ when μ(N)=0. A property holds almost everywhere when its exceptions lie in a null set. With a complete measure, every subset of a null set is measurable and is itself a null set.
