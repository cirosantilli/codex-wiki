Tridiagonal elimination recurrences (mi​=ai​/pi−1​,pi​=bi​−mi​ci−1​)

 Home Mathematics Area of mathematics Analysis Numerical analysis Tridiagonal matrix algorithm
OurBigBook.com Words: 189
Let n≥1. Store the tridiagonal matrix A by its diagonal b1​,…,bn​, lower diagonal a2​,…,an​, and upper diagonal c1​,…,cn−1​. The linear system Ax=d is
ai​xi−1​+bi​xi​+ci​xi+1​=di​,1≤i≤n,
(178)
with the nonexistent endpoint terms omitted. Initialize p1​=b1​ and g1​=d1​. For i=2,…,n, compute the elimination multiplier, modified pivot element, and modified right-hand side:
mi​=pi−1​ai​​,pi​=bi​−mi​ci−1​,gi​=di​−mi​gi−1​.
(179)
These recurrence relations apply the elementary row operation Ri​←Ri​−mi​Ri−1​ after the preceding row has already been reduced. The transformed linear system is an upper bidiagonal matrix:
pi​xi​+ci​xi+1​=gi​(1≤i<n),pn​xn​=gn​.
(180)
Thus back substitution is especially short:
xn​=pn​gn​​,xi​=pi​gi​−ci​xi+1​​(i=n−1,n−2,…,1).
(181)
For n=1, only x1​=d1​/b1​ remains. Check each pivot element before its first division, including pn​ before back substitution.
Equivalently, this constructs an LU decomposition with unit lower bidiagonal matrix L, whose lower diagonal is m2​,…,mn​, and upper bidiagonal matrix U, whose diagonal is p1​,…,pn​ and upper diagonal is c1​,…,cn−1​. The g sweep is forward substitution in Lg=d. There is no fill-in outside these bands when no rows are interchanged. LAPACK's DGTSV source uses these same coefficient and right-hand-side updates in its branch without row interchange.[ref]
