Channel multiplexing

 ... Computer science Operating system Process (computing) Thread (computing) Synchronization (computing) Message passing
OurBigBook.com Words: 79 Articles: 3
Sharing one message-passing channel among multiple logical streams by attaching a stream identity to each transferred value. Independent cancellation requires a protocol that conveys which stream is ending; bounded per-stream flow control can prevent head-of-line blocking from a single unready consumer.
