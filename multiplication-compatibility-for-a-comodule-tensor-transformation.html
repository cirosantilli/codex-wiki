Multiplication compatibility for a comodule tensor transformation (m∗γ=γ∗n)

 ... Algebra Linear algebra Multilinear algebra Coalgebra Comodule Comodule tensor transformation formula
OurBigBook.com Words: 32
For a transformation from the tensor built using n to the tensor built using m, colinearity is m∗γ=γ∗n: ∑m(a(1)​,b(1)​)γ(a(2)​,b(2)​)=∑γ(a(1)​,b(1)​)n(a(2)​,b(2)​). Scalar maps enter this convolution product for coalgebra maps via the common algebra unit.
