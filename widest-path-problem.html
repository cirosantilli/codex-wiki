Widest path problem (maxP:s⇝t​mine∈P​w(e))

 Home Mathematics Area of mathematics Foundations of mathematics Graph theory Path in a graph
OurBigBook.com Words: 60
Find a graph path whose least edge weight is as large as possible. In a connected undirected graph, use the unique route in a maximum spanning tree. Deleting a least-weight edge on that route gives a separating cut of a graph; a heavier crossing edge would improve the tree's total weight, so every competing route contains an edge no heavier than the deleted one. This proves the bottleneck optimum without assuming distinct weights.
