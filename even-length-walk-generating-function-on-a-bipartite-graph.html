Even-length walk generating function on a bipartite graph (ZG0​(x)=∑k≥0​σ2k​x2k)

 ... Mathematics Area of mathematics Combinatorics Lattice path Self-avoiding walk Self-avoiding walk generating function
OurBigBook.com Words: 118 Articles: 1
In a bipartite graph, a self-avoiding walk ends in its starting class exactly when it has even length. If degrees are bounded by Δ, deleting the last edge gives σ2k+1​≤Δσ2k​ and hence ZG0​(x)≤ZG​(x)≤(1+Δx)ZG0​(x) for x≥0. Thus these generating functions have the same radius of convergence.
