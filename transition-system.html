Transition system ((S,→,I,AP,L))

 Home Computer science Algorithm Algorithm correctness Formal verification
OurBigBook.com Words: 216 Articles: 5
A model consisting of a set S of states, a transition relation →⊆S×S, initial states I⊆S, a set AP of atomic propositions, and a label function L:S→2AP identifying which atomic propositions hold at each state. A path in a transition system follows permitted transitions. Some definitions omit labels or initial conditions; specify the convention used in each application.
