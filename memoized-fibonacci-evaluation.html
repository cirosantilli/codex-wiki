Memoized Fibonacci evaluation (Fn​)

 Home Computer science Algorithm Memoization
OurBigBook.com Words: 460
The Fibonacci numbers give an exact example. For a nonnegative integer n, their recurrence relation is
F0​=0,F1​=1,Fn​=Fn−1​+Fn−2​(n≥2).
(26)
To obtain F5​=5 by direct recursion, evaluate F4​ and F3​ separately; computing F4​ also evaluates F3​. The full call tree has 15 occurrences but just six distinct arguments, 0,1,2,3,4,5. Shared dependencies form a Directed acyclic graph because every directed edge goes to a strictly smaller argument. Memoization evaluates a distinct argument on first demand; filling values in increasing argument order is the corresponding bottom-up dynamic programming calculation.[ref]
Use an initially empty hash table memo, shared by every recursive call. Count even the first evaluations of the two base cases, store only completed results, evaluate the left term first, and retain all entries. The following original procedure assumes a nonnegative integer argument:
def cached_fib(n, memo):
    if n in memo:
        return memo[n]
    if n < 2:
        value = n
    else:
        value = cached_fib(n - 1, memo) + cached_fib(n - 2, memo)
    memo[n] = value
    return value
Every self-call must pass through the memoization lookup. Wrapping only the outer call while leaving inner calls uncached retains the repeated work. Test membership rather than whether the stored value is nonzero: F0​=0 is a valid completed result.
For cold F5​, the lookup arguments are 5,4,3,2,1,0,1,2,3. The first six are absent; the last three reuse completed answers. Results are stored on return in argument order 1,0,2,3,4,5, with values 1,0,1,2,3,5. Thus there are nine wrapper calls, six body evaluations and four additions. Repeating F5​ with the same table takes one wrapper call and no body evaluation. Requesting F6​ next evaluates only its body, reuses F5​ and F4​, and stores F6​=8: three wrapper calls, one body evaluation and two hits.
The direct-call count satisfies C0​=C1​=1 and Cn​=1+Cn−1​+Cn−2​. Its exact solution is Cn​=2Fn+1​−1, as substitution into this recurrence relation verifies. With the specified memoization procedure, a cold call at n≥2 evaluates n+1 distinct bodies, makes n−1 additions and makes 2n−1 wrapper calls. There are n−2 hits: each of the n−1 nonbase bodies issues two recursive calls, in addition to the initial call. The difference is between the number of occurrences and the number of distinct subproblems.
