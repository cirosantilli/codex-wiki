A distribution on (a,b) is a continuous linear functional on the space of test functions D(a,b)=Cc∞​(a,b). It has order of a distribution at most m if, for every compact set K⊂(a,b), there is CK​ such that
∣⟨u,ϕ⟩∣≤CK​max0≤j≤m​∥ϕ(j)∥∞​(suppϕ⊆K).
(1)
The order of a distribution is the least such m. When saying “of order m” means merely that this estimate holds, the wording allows a smaller least order.
For each such K, the cutoff function theorem supplies a nonnegative χ∈D(a,b) equal to one near K. If M=∥ϕ∥∞​ and suppϕ⊆K, then Mχ±ϕ≥0 everywhere. Positivity of the linear functional V therefore gives
0≤MV(χ)±V(ϕ),∣V(ϕ)∣≤V(χ)∥ϕ∥∞​.​
(2)
Here V(χ)≥0 is finite and independent of ϕ. This is precisely the local bound for an order-zero distribution, so the given positive distribution is continuous on the space of test functions. The zero distribution also satisfies the estimate.

Convergence ϕj​→ϕ in the space of test functions means that all supports lie in one compact set K⊂R and ∥ϕj(r)​−ϕ(r)∥∞​→0 for every integer r≥0. An eventual common compact support is equivalent, since finitely many initial supports can be added to K.
Write the standard mollifier as ρε​(x)=ε−1ρ(x/ε), where ρ∈D(R) is nonnegative, supported in [−1,1], and has integral one. For 0<ε≤1, the convolution ρε​∗ϕ has support in the fixed compact set suppϕ+[−1,1]. The given convolution derivative identity yields
(ρε​∗ϕ)(r)(x)−ϕ(r)(x)=∫−11​ρ(y)[ϕ(r)(x−εy)−ϕ(r)(x)],dy.
(20)
Each ϕ(r) is uniformly continuous; more explicitly, the mean value theorem bounds the absolute value by ε∥ϕ(r+1)∥∞​∫∣y∣ρ(y)dy, uniformly in x. Thus
ρε​∗ϕ⟶ϕ in D(R).​
(21)
If ϕj​→0 in the space of test functions and K is a common compact support, then ∥ϕj​∥L1​≤∣K∣∥ϕj​∥∞​→0, where ∣K∣ is its Lebesgue measure.
The mollifiers themselves have no limit in the L1 space. If ρε​→g in that norm, then for each δ>0 the integral of ∣g∣ on {∣x∣>δ} is zero, because ρε​ vanishes there for ε<δ. Hence g=0 almost everywhere. This contradicts ∥ρε​∥L1​=1. Therefore ρε​ does not converge in L1(R)​.

Define two open sets by
Z(u)=⋃{U⊆Ω:U open, u∣U​=0},G(u)=⋃{U⊆Ω:U open, u∣U​∈C∞(U)}.
(48)
The support of a distribution and its singular support are
suppu=Ω∖Z(u),singsuppu=Ω∖G(u).​
(49)
Both are relatively closed because the removed sets are open. The locality of distributions gives u∣Z(u)​=0. On an overlap of two open smoothness regions, the two smooth functions represent the same distribution, so their difference is zero almost everywhere and hence everywhere by continuity. They therefore join to one smooth function on G(u). The same partition of unity argument shows that it represents u there.
For u=1ω​, openness of ω implies
supp1ω​=ωΩ.​
(50)
Indeed every neighborhood of a point in this relative closure meets ω in an open set containing a nonnegative test function with positive integral; outside the closure the indicator function is identically zero near the point.
The singular support of an indicator function needs a measure-sensitive boundary. For a Lebesgue measurable set A⊆Ω, define its essential closure by
essclΩ​A={x∈Ω:∣A∩Br​(x)∣>0 whenever r>0 and Br​(x)⊆Ω}.
(51)
Then the general answer is
singsupp1ω​=ωΩ∩essclΩ​(Ω∖ω).​
(52)
Outside this intersection, some ball has either no points of ω or a complement of Lebesgue measure zero. The regular distribution is respectively the constant zero or one on that ball and is smooth. Conversely, at a point of the intersection, every sufficiently small ball has positive Lebesgue measure in both sets. If a smooth function represented the indicator function there, its values would be in {0,1} everywhere: any other value, by continuity, would give a ball of positive Lebesgue measure on which equality almost everywhere fails. On a connected ball such a continuous two-valued function is constant, contradicting the two positive measures.
In particular, the answer need not be the full topological boundary. For Ω=Rn and ω=Rn∖{0}, the indicator function is the constant one almost everywhere, so its singular support is empty although the boundary is {0}. The full relative boundary is the answer when every neighborhood of each boundary point contains a positive Lebesgue measure portion of the complement, as for an open set with smooth boundary.

If u were a smooth function, its Wirtinger derivative ∂zˉ​u=f would also be smooth, contradicting singsuppf=∅. In fact the singular support is exactly preserved here:
singsuppu=singsuppf.​
(59)
One inclusion follows because a differential operator cannot create a singularity where u is smooth. For the reverse inclusion, E is smooth off zero, and its singular support is exactly {0}: if it were smooth near zero, ∂zˉ​E=δ0​ would be smooth there. The support and singular support rules for convolution give singsupp(E∗f)⊆{0}+singsuppf, and adding the smooth entire function h leaves this singular support unchanged. Thus there is no globally smooth solution when the given singular support is nonempty.
