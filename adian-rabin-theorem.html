Adian–Rabin theorem

 ... Geometry and topology Geometric group theory Group presentation Finite group presentation Finitely presented group Markov property of finitely presented groups
OurBigBook.com Words: 126 Articles: 1
No Markov property of finitely presented groups is decidable by an algorithm taking an arbitrary finite group presentation as input. The proof reduces the word problem for a group to property recognition using an effective construction which collapses when an input word is trivial and embeds the input group when it is nontrivial.
