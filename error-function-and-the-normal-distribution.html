Error function and the normal distribution (Φ(z)=21​[1+erf(z/2​)])

For a standard normal random variable Z, its standard normal distribution function is
Φ(z)=2π​1​∫−∞z​e−u2/2du=21​[1+erf(2​z​)].
(32)
The change of variables t=u/2​ and the symmetric distribution of the standard normal random variable give the second expression. For X∼N(μ,σ2) with σ>0, standardization of a normal random variable then gives
P(X≤x)=21​[1+erf(σ2​x−μ​)],P(∣X−μ∣≤aσ)=erf(2​a​),a≥0.
(33)
In particular, the intervals within one, two, and three standard deviations have calculated probabilities about 0.682689, 0.954500, and 0.997300. These values depend on a normal distribution; they are not universal coverage guarantees for an arbitrary random variable. This is the direct connection between a Gaussian function area and the familiar central intervals.
For a small upper-tail probability, use the complementary error function directly:
P(Z>z)=21​erfc(2​z​).​
(34)
Computing this as 1−Φ(z) instead can lose the tail to catastrophic cancellation. The Gaussian tail bound gives another useful estimate without requiring an exact error function value.
