String-frame metric (gab(s)​)

 ... Physics Branches of physics String theory Bosonic string theory Polyakov action String nonlinear sigma model
OurBigBook.com Words: 123 Articles: 1
The string-frame metric is the target metric appearing directly in the kinetic term of the string nonlinear sigma model. With conventional Euclidean dilaton φ, its leading spacetime gravitational action contains −g(s)​e−2φ(R+4∣∇φ∣2). The dilaton-dependent Ricci coefficient distinguishes it from the Einstein-frame metric. Frame changes are local field redefinitions where the conformal factor is finite and nonzero; the Lorentzian dilaton coupling sign convention fixes which named field is φ.
