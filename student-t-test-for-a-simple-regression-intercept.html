Student t test for a simple-regression intercept (T=(α−α0​)/(s1/n+xˉ2/Sxx​​))

 ... Probability and statistics Statistical model Statistical modelling Normal linear model Linear regression Regression intercept
OurBigBook.com Words: 64
For a Gaussian linear model with an intercept and one explanatory variable, n>2 and Sxx​>0, the regression intercept estimator is normal with variance σ2(1/n+xˉ2/Sxx​). The residual variance estimate s2=SSE/(n−2) is independent of the coefficient estimators and (n−2)s2/σ2 has a chi-squared distribution with n−2 degrees of freedom. Consequently the displayed statistic has a Student t-distribution under α=α0​, and a two-sided level-η test rejects for ∣T∣>tn−2,1−η/2​.
