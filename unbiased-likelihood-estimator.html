Unbiased likelihood estimator (EL(θ)=L(θ))

 ... Probability and statistics Statistical inference Bayesian statistics Markov chain Monte Carlo Metropolis–Hastings algorithm Pseudo-marginal Metropolis–Hastings algorithm
OurBigBook.com Words: 41
An unbiased likelihood estimator has expectation equal to the likelihood function at each parameter. A pseudo-marginal algorithm requires this estimator to be nonnegative. Importance sampling provides L=M−1∑j​ℓ(Fj​)pθ​(Fj​)/gθ​(Fj​) for independent random variables Fj​∼gθ​, provided the proposal covers the target support. Relative variance affects the mixing time even though unbiasedness guarantees the correct marginal target.
