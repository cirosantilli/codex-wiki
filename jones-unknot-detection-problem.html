Jones unknot detection problem (VK​(t)=1 ⟹ K≅U ?)

 ... Geometry and topology Knot theory Link Link diagram Kauffman bracket Jones polynomial
OurBigBook.com Words: 109
This asks whether the Jones polynomial equal to one characterizes the unknot among knots. A zero breadth of a Laurent polynomial makes VK​ a monomial; the identities VK​(1)=1 and VK′​(1)=0 then force that monomial to be one. Thus using Jones breadth as a strictly positive complexity for nontrivial knots requires this detection property. To prove the derivative identity, differentiate the Jones polynomial skein relation at one for a crossing change in a knot. Both crossed diagrams have value one, while the smoothed two-component link has value minus two by Jones polynomial evaluation at one, so VK+​′​(1)=VK−​′​(1). Crossing changes reduce to the unknot, whose derivative is zero. The corresponding Alexander polynomial detection property is false, as nontrivial untwisted Whitehead doubles demonstrate. The Jones question is discussed in research on closed four-strand braids.
