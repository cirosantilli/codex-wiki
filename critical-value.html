Critical value (f(xc​))

 Home Mathematics Area of mathematics Geometry and topology Differential geometry Critical point of a smooth map
OurBigBook.com Words: 450
A critical point of a smooth map is an input; a critical value is an output reached from at least one such input. For the fold F(x,y)=(x,y2), all inputs (a,0) are critical points of a smooth map, and all outputs (a,0) are critical values. The identical coordinate pairs live in different copies of R2. To classify an output (a,b), inspect its entire fiber of a function:
F−1(a,b)=⎩⎨⎧​{(a,b​),(a,−b​)}{(a,0)}∅​b>0,b=0,b<0.​
(4)
For b>0 both inputs have matrix rank two, so the output is a regular value. For b=0 its input has matrix rank one, so the output is a critical value. For b<0 the fiber of a function is the empty set, and the output is a regular value despite being outside the image of a function.
In general, for a smooth map f:X→Y, write Cf​ for its set of critical points of a smooth map. Its set of critical values is f(Cf​)⊆Y. Equivalently, q∈Y is a critical value if some p∈f−1(q) has a differential that is not surjective. A regular value requires a surjective differential at every input in that fiber of a function. The universal condition holds vacuously for an empty fiber of a function: every output outside f(X) is a regular value. These quantifiers are explicit in Loring W. Tu, An Introduction to Manifolds, Definition 8.22 and its two following remarks.
The distinction is useful when solving equations. For a smooth map f:Xm→Yn between smooth manifolds without boundary and a regular value q with nonempty fiber of a function, the regular level set theorem makes f−1(q) an embedded submanifold of dimension m−n, with tangent space
Tp​f−1(q)=kerdfp​.
(5)
The implicit function theorem explains the freedom count: locally, n independent equations fix n coordinates and leave m−n free. The rank-nullity theorem gives the same count for the displayed kernel of a linear map. See Eckhard Meinrenken, Differentiable Manifolds, Theorems 1.11 and 1.15 for the local projection description and its consequence for level sets.
For example, H:R2→R, H(x,y)=x2+y2, has gradient (2x,2y) and just one critical point, the origin, with critical value zero. For c>0, its fiber of a function is the circle of radius c​, a one-dimensional embedded submanifold; negative c are regular values with empty fibers. At c=0, the fiber of a function is a single point instead of a circle. A critical value does not force its fiber of a function to be nonsmooth: that singleton is itself a zero-dimensional embedded submanifold, but the regular dimension conclusion 2−1=1 does not apply.
Nor does a single regular input certify a regular value. The scalar smooth function h(t)=t2(t−1) has h−1(0)={0,1} and derivative h′(t)=3t2−2t. The input zero is a critical point, while the input one is regular because h′(1)=1. Their shared output zero is nevertheless a critical value. Conversely, different critical points of a smooth map can share one critical value: f(t)=(t2−1)2 sends both critical inputs −1 and 1 to zero. Counting inputs and counting critical outputs are different tasks.
Finally, for G(t)=(t,t2):R→R2, every output on the parabola is a critical value, and every output off it is a regular value with empty fiber of a function. There is no nonempty regular fiber of a function here, so the negative expression 1−2 never becomes a claimed manifold dimension. Both diagrams show exact mathematical examples, not measured data.
