d-ary min-heap

 Home Computer science Data structure Heap data structure d-ary heap
OurBigBook.com Words: 84
A d-ary heap in which each parent key is no greater than each child key. Transitivity makes the root a minimum. Removing the root requires choosing a smallest child at each downward step, taking O(dlogd​n) time in the usual 2≤d≤n range. Decreasing a key or inserting a new leaf only compares along one chain of parents, taking O(logd​n) time in that range. These priority queue bounds assume constant-time key comparisons and available array capacity. An indexed priority queue must also update its item-to-index table after every swap.
