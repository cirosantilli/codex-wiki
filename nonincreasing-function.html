Nonincreasing function (x<y⟹f(x)≥f(y))

 ... Mathematics Area of mathematics Analysis Real analysis Calculus Monotonic function
OurBigBook.com Words: 73
A real-valued function f:D→R is a nonincreasing function if every pair x<y in its domain of a function satisfies f(x)≥f(y). Equal outputs and flat intervals are allowed. For example, f(x)=−min(1,max(0,x)) is a nonincreasing function, with a falling segment between two flat portions. Requiring f(x)>f(y) instead gives a strictly decreasing function. Negating a nondecreasing function gives a nonincreasing function.
A nonincreasing sequence of natural numbers has finitely many strict drops, so it is eventually constant. This differs from a strictly decreasing sequence, which cannot continue indefinitely within the natural numbers.
