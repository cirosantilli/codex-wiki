A (p,q) string carries p units of fundamental string charge and q units of D1-brane charge. Coprime integers label an elementary primitive charge vector; nonprimitive vectors describe multiple units. The displayed tension uses the string metric and vanishing axion. In the M-theory torus duality, it comes from an M2-brane wrapped on the corresponding primitive one-cycle.
