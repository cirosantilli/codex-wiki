Weight string (q−p=⟨μ,α∨⟩)

 ... Lie theory Lie algebra Semisimple Lie algebra Highest-weight representation Weight vector Weight space
OurBigBook.com Words: 102 Articles: 1
For a finite-dimensional representation of a complex semisimple Lie algebra, the weights on a line μ+Zα form a contiguous string from μ+pα to μ−qα, with q−p=⟨μ,α∨⟩. Restriction to the associated sl2 subalgebra gives nested strings of the same parity, so the string endpoints determine the weight set but not its multiplicities.
