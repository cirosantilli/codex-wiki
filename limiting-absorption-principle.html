Limiting absorption principle

 ... Branches of physics Fluid mechanics Gravity wave Internal wave Atmospheric internal gravity wave Radiation condition
OurBigBook.com Words: 48
Select outgoing waves as a limit of a problem with weak absorption. With time convention e−iωt use Imω>0; with eiωt use Imω<0. The resulting Green function and transform-contour prescriptions determine which poles represent incoming or outgoing waves. This is especially useful when real-axis singularities obscure a Wiener-Hopf factorization.
