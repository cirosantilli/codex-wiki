Profile likelihood

 ... Probability and statistics Statistical model Statistical modelling Maximum likelihood estimation Maximum-likelihood estimator Likelihood function
OurBigBook.com Words: 325 Articles: 5
For a parameter of interest ψ and nuisance parameter λ, the profile likelihood is
Lp​(ψ)=supλ​L(ψ,λ).
(57)
It compares values of ψ after fitting the nuisance parameter as favourably as possible at each value.
