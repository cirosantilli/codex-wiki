Hamming code of length seven ([7,4,3])

 ... Mathematics Area of mathematics Algebra Coding theory Linear code Hamming code
OurBigBook.com Words: 54
The binary linear code known as the Hamming code of length seven is the kernel of a 3×7 parity-check matrix whose columns are all the nonzero vectors of F23​. Its dimension is four. No one-column or two-column sum vanishes, but some three-column sum does, so its minimum Hamming distance is three. The syndrome of a one-bit error is its column, uniquely identifying the erroneous position.
