Application-layer acknowledgement

 Home Computer science Computer network Communication protocol
OurBigBook.com Words: 49
An application-layer acknowledgement confirms a condition specified by an application's communication protocol. Receipt, successful processing and durable storage are different conditions. A Transmission Control Protocol acknowledgement of received bytes does not itself establish any stronger application promise; the relevant endpoint must establish that promise.[ref]
