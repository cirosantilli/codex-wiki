Fix canonical single-particle order (1↑,1↓,2↑,2↓) and write the occupation ket as ∣n1​n2​n3​n4​⟩. The six states in the printed order are ∣1010⟩, ∣1001⟩, ∣0110⟩, ∣0101⟩, ∣1100⟩, ∣0011⟩. The last state is double occupancy on site 2.
For a fermionic raising and lowering operator acting on mode j, the sign is (−1)∑k<j​nk​, and annihilation requires that mode occupied while creation requires it empty. Starting from the second basis state, the hop that reaches the last state is
c2↑†​c1↑​∣1001⟩=c2↑†​∣0001⟩=∣0011⟩.
(22)
It therefore contributes H6,2​=−t. Starting from the third state instead,
c2↓†​c1↓​∣0110⟩=c2↓†​∣0010⟩=−∣0011⟩,
(23)
because the occupied 2↑ mode precedes 2↓. The Hamiltonian's leading −t makes H6,3​=+t. Finally n2↑​n2↓​∣0011⟩=∣0011⟩, so H6,6​=U. No other displayed basis state reaches ∣0011⟩ in one allowed hop. These signs verify the three nonzero entries without assigning distinguishable-particle hopping signs to fermions.
