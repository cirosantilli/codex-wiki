Full row rank (rankA=m)

 ... Algebra Linear algebra Vector space Linear map Matrix Matrix rank
OurBigBook.com Words: 126
An m×n matrix has full row rank when its matrix rank is m, equivalently when its rows are linearly independent vectors. This requires m≤n. Its column space is all of Fm, so the represented linear map is surjective and every linear system Ax=b is solvable. If n>m, its nullity is n−m>0, so solutions are not unique.[ref]
For example, the matrix transpose of the matrix in full column rank is
BT=(10​01​11​).

It has full row rank two. Every output (p,q)T has solutions (p−t,q−t,t)T, with t∈R. A square matrix of size n has full row rank and full column rank together exactly when its matrix rank is n; then it is an invertible matrix. A nonsquare matrix cannot have both properties, and has no two-sided inverse: such an inverse would make its linear map a linear isomorphism between vector spaces of different dimensions.
