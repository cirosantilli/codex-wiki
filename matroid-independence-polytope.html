Matroid independence polytope (PI​(M)={x≥0:x(A)≤rM​(A) for all A⊆E})

For a finite matroid M=(E,I), the convex hull of the indicator vectors of its matroid independent sets is exactly the displayed system, where x(A)=∑e∈A​xe​. It is an integral polytope. The equality x(E)=rM​(E) instead gives the face corresponding to matroid bases; independence does not require that equality.
Proof. If I is independent, ∣I∩A∣≤rM​(A), so every independent indicator and every convex combination of them satisfies the inequalities. For the reverse inclusion, take an arbitrary real objective c. List its positive coordinates in nonincreasing order as c1​≥⋯≥ck​>0, put ck+1​=0 and let Si​ be the first i elements in this ordering. Run the matroid greedy algorithm on these elements, obtaining an independent set I. At every prefix the selected elements are maximal in Si​: an earlier rejected element cannot become admissible after further additions, by heredity. The augmentation axiom implies that every maximal independent set in Si​ has size rM​(Si​). Hence ∣I∩Si​∣=rM​(Si​).

Thus every linear objective is maximized by an independent indicator, with the empty set used if all coefficients are nonpositive. Singleton rank inequalities bound every coordinate between zero and one, making the system compact. If it contained a point outside the compact convex hull of independent indicators, the finite-dimensional separating hyperplane theorem would supply an objective strictly larger at that point than at every independent indicator, a contradiction. This proves equality and integrality without assuming the desired convex-hull description in advance. Negative objective coefficients are discarded explicitly; maximizing over independent sets differs from maximizing over bases when such coefficients occur.
