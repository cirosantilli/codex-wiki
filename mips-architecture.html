MIPS architecture

 Home Computer science Instruction set architecture
OurBigBook.com Words: 165 Articles: 4
A family of reduced instruction set computer architectures. The classic 32-bit integer encoding has five-bit processor register fields, while many branch and jump instructions execute a branch delay slot. These conventions differ from later revisions and must be stated when presenting assembly language.
