Phase oscillator

 Home Physics Branches of physics Dynamical systems Dynamical system
OurBigBook.com Words: 273 Articles: 6
A model retaining an oscillation's phase while neglecting amplitude dynamics. Interactions can synchronize relative phases through phase locking; noise can cause phase slips. The Adler phase equation is a simple example for a coupled relative phase.
