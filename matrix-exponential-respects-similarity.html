Matrix exponential respects similarity (ePAP−1=PeAP−1)

 ... Mathematics Area of mathematics Algebra Linear algebra Operator theory Matrix exponential
OurBigBook.com Words: 52
For an invertible matrix P, induction gives (PAP−1)k=PAkP−1, including k=0. The power series for the matrix exponential is absolutely convergent in every matrix norm, so multiplication by the fixed matrices P,P−1 can be taken through the sum. This proves the displayed identity without any diagonalizability assumption. In particular, if A=PDP−1 with D diagonal, then eA=Pdiag(eD11​,…,eDnn​)P−1.
