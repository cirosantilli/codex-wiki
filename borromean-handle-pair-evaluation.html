Borromean handle-pair evaluation (Ha​=D2/da2​)

 ... Knot theory Colored link Kirby color Normalized Kirby color Kirby killing property Two-strand Kirby projector
OurBigBook.com Words: 70
For a charge-a component threading a pair of zero-framed auxiliary components in the standard Borromean rings surgery arrangement, color both auxiliary components by the normalized Kirby color. Relative to the bare a strand, eliminating this pair contributes Ha​=D2/da2​. The two-strand Kirby projector applied to the two oppositely oriented portions of the a component supplies a factor D/da​ at each of the two eliminations. This local evaluation underlies the surgery calculation of the handle-cut formula for anyon ground-state degeneracy.
