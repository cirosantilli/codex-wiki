If a common recovery quantum channel with Kraus operators Rμ​ restores every pure code state after each error Ea​, then each vector Rμ​Ea​∣ψ⟩ is parallel to ∣ψ⟩. Linearity on basis vectors and their pairwise superpositions forces Rμ​Ea​P=cμa​P, with the scalar independent of the logical state. Insert ∑μ​Rμ†​Rμ​=I between two error operators to obtain the displayed Knill--Laflamme condition. This proves necessity without presuming an orthogonal syndrome description of recovery.
