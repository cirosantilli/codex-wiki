Matrix preconditioner (M)

 ... Mathematics Area of mathematics Analysis Numerical analysis Numerical linear algebra Matrix preconditioning
OurBigBook.com Words: 222 Articles: 1
A matrix preconditioner is an auxiliary invertible matrix whose matrix inverse is cheap to apply and whose use improves the eigenvalues of a linear system. In symmetric positive-definite matrix problems, a symmetric positive-definite matrix M preserves that structure under the symmetric transformation M−1/2AM−1/2.
Applying M−1 means solving Mz=r for a supplied vector r. This notation does not require forming a general matrix inverse. A diagonal matrix gives componentwise divisions; a factored matrix gives auxiliary solves such as forward substitution and back substitution.[ref]
Choosing M=I makes the solve trivial but changes nothing; choosing M=A gives the exact correction but asks us to solve the original linear system.[ref]
