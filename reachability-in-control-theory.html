Reachability in control theory (x1​∈R(x0​))

 Home Mathematics Area of mathematics Control theory
OurBigBook.com Words: 728 Articles: 2
Reachability in control theory asks about a particular initial state x0​ and target x1​: does some admissible control input make x(T)=x1​ at the declared time T, or at some allowed duration? Controllability requires this for every pair in the declared state space. This is a property of state evolution, distinct from graph reachability.
For a linear time-invariant system, solving the ordinary differential equation by a matrix exponential gives
x(T)=eATx0​+∫0T​eA(T−t)Bu(t)dt.
(5)
The first term is the unforced endpoint. Reachability in control theory asks whether the control input can supply exactly the displacement x1​−eATx0​. The timing matters because the same command is carried by different amounts of subsequent dynamics. [ref]
Here is a contrasting mathematical example with one shared control input:
z˙1​=u,z˙2​=u,A=(00​00​),B=(11​),C=(11​00​).
(6)
The controllability matrix has rank of a matrix one. Since dtd​(z1​−z2​)=0, the difference is invariant under every allowed control input. From (0,0) the reachable set is the diagonal z1​=z2​ when input amplitudes are unrestricted: (1,1) is reachable at T=2 using u=1/2, while (1,0) is impossible at every duration.
