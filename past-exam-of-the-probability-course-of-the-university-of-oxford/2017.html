The update defines a time-homogeneous Markov process: given its present value, the next value depends only on independent fresh input. Part (b)(i) identifies an invariant law: initializing with the rate-one exponential distribution preserves that distribution at every time. Part (b)(iii) shows convergence of the one-time laws to this invariant law from every deterministic initial value.
For a countable state space, the analogous countable-state Markov chain convergence theorem says that an irreducible Markov chain that is aperiodic and positive recurrent converges to its unique stationary distribution from every initial state. Here the state space is continuous, so that countable-state theorem does not directly supply the proof; the explicit coupling does. The two conclusions have the same equilibrium interpretation.

The moment-generating function of a real random variable X is
MX​(t)=E[etX]​
(12)
for real t where the expectation is finite. One may regard it as an extended nonnegative function elsewhere. In particular MX​(0)=1; finiteness on a neighborhood of zero is the usual hypothesis for recovering moments and using its local expansion.

A transition matrix P defines an irreducible Markov chain if every state is accessible from every other state:
for every i,j∈S, there is n≥0 with (Pn)ij​>0.​
(27)
Equivalently, all states belong to one communicating class. When i=j, a positive number of steps is necessarily used.

A stationary distribution is a nonnegative row vector π=(πi​)i∈S​ with total mass one that is preserved by one transition:
πi​≥0,i∈S∑​πi​=1,πj​=i∈S∑​πi​Pij​(j∈S).​
(28)
In matrix notation, πP=π. If the initial state has distribution π, so does the state at each later time.

iii OurBigBook.com
For an irreducible Markov chain on a countable state space, the set has either zero or one element. By uniqueness of stationary distributions for an irreducible countable chain, a stationary probability distribution exists exactly in the positive recurrent case, and then
πi​=Ei​Ti+​1​
(29)
for the first return time Ti+​. The right-hand side fixes every entry, proving uniqueness.
For a finite state space, existence is guaranteed, so there is exactly one. A countably infinite state space can have none: the simple symmetric random walk on the integers is irreducible and null recurrent. Periodicity does not affect this existence-and-uniqueness statement.

i OurBigBook.com
The difference process Dn​ is a Markov chain. If the columns are equal, the next block creates a height difference of one. If the difference is k≥1, landing in the taller column increases it to k+1, while landing in the shorter column makes it zero. Therefore its only nonzero transition probabilities are
P(0,1)=1,P(k,k+1)=P(k,0)=21​(k≥1).​
(30)
These probabilities depend only on the present difference, not on the absolute heights or their history. This is the reset-or-increment Markov chain with p=1/2.
For its stationary distribution, the incoming-flow equations give π1​=π0​ and πk​=πk−1​/2 for k≥2. Normalization uses a geometric series:
1=π0​+∑k=1∞​π0​2−(k−1)=3π0​.
(31)
Thus
π0​=31​,πk​=32k−11​(k≥1).​
(32)
The remaining balance equation is also satisfied: the flow into zero is (1−π0​)/2=1/3. Every state can reach zero and every positive state can be reached from zero, so it is an irreducible Markov chain. Its invariant probability distribution makes it positive recurrent, and that distribution is unique.
The maximum-height process Hn​ is not Markov. Starting empty, condition first on the positive-probability history (H1​,H2​,H3​)=(1,1,2). After two blocks the columns were equal, so after three their difference is one. Hence P(H4​=3∣H1​=1,H2​=1,H3​=2)=1/2.
For the history (1,2,2), the first two blocks built one column and the third caught the other column up, leaving equal heights. Hence P(H4​=3∣H1​=1,H2​=2,H3​=2)=1. Both histories have the same time and present height H3​=2, but different predictions. This violates the Markov property and illustrates why a function of a Markov chain need not be Markov.
