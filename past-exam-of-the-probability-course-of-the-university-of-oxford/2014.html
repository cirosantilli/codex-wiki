Convergence in distribution means that the cumulative distribution functions satisfy
P(Xn​≤x)⟶P(X≤x)
(1)
at every x where the cumulative distribution function of X is continuous. Values at its discontinuities need not converge. This definition uses only the probability distributions, so the random variables need not be defined on the same probability space.

Let μ=E[X1​] and σ2=Var(X1​)∈(0,∞). For independent and identically distributed random variables, the central limit theorem states
σn​X1​+⋯+Xn​−nμ​d​N(0,1).​
(2)
The limit is the standard normal distribution. If the variance is zero, then Xi​=μ almost surely; the centered sums are zero, and division by σ is not defined.

The implication convergence in probability implies convergence in distribution follows by comparing nearby events. Fix a continuity point x of the cumulative distribution function FX​ and let ε>0. If X≤x−ε and ∣Xn​−X∣≤ε, then Xn​≤x. Conversely, Xn​≤x and ∣Xn​−X∣≤ε imply X≤x+ε. Thus
FX​(x−ε)−P(∣Xn​−X∣>ε)≤FXn​​(x)≤FX​(x+ε)+P(∣Xn​−X∣>ε).
(3)
The error probability tends to zero by convergence in probability. Taking lower and upper limits and then letting ε↓0, continuity at x squeezes both bounds to FX​(x). This is exactly convergence in distribution.

For x>0, the event Mn​/n≤x says that each of the independent random variables is at most ⌊nx⌋. Hence, for all sufficiently large n,
P(Mn​/n≤x)=(1−⌊nx⌋+11​)n.
(5)
Since n/(⌊nx⌋+1)→1/x and log(1−u)=−u+o(u) as u→0, taking logarithms gives the limit e−1/x. For x≤0 the probability is zero. Therefore
nMn​​d​W,FW​(x)={0,e−1/x,​x≤0,x>0.​​
(6)
This is the Fréchet limit for a reciprocal integer tail, with a Fréchet distribution of shape one. Its cumulative distribution function is continuous even at zero, so the pointwise calculation establishes convergence in distribution.

Write Sn+1​=Sn​+Xn+1​. The new random variable Xn+1​ is independent of the entire history generated by X1​,…,Xn​, hence of (S1​,…,Sn​). This is a Markov chain obtained from independent innovations: conditional on the past, only the current sum enters the next state. Its time-homogeneous transition probabilities are
Pst​=⎩⎨⎧​(t−s)(t−s+1)1​,0,​t>s,t≤s,​s,t∈{1,2,…}.​
(7)
Every jump is a positive integer, and each row sums to one by the probability mass function from part (b).

Integrating etx against the Gamma density gives the moment-generating function of a gamma distribution:
MX​(t)=(r−1)!λr​∫0∞​xr−1e−(λ−t)xdx=(λ−tλ​)r​,t<λ.

Independence makes the moment-generating function of the sum the product of the two moment-generating functions. For t<λ,
MX1​+X2​​(t)=(λ−tλ​)r1​(λ−tλ​)r2​=(λ−tλ​)r1​+r2​.
(10)
The expectations are finite on, for example, (−λ/2,λ/2), as is the moment-generating function of the candidate Gamma distribution. The uniqueness theorem for moment-generating functions therefore applies, proving
X1​+X2​∼Gamma(r1​+r2​,λ).​
(11)
This is additivity of independent gamma distributions with a common rate; a common rate is essential to this specific formula.

The inverse change of variables is y1​=uv, y2​=(1−u)v, on 0<u<1, v>0. Its absolute Jacobian determinant is
​det(v−v​u1−u​)​=v.

The first Markov chain is a finite irreducible Markov chain: its positive-probability directed cycle reaches all four states. The self-loop at state 1 makes it an aperiodic Markov chain. Convergence to an invariant distribution therefore gives
p11(n)​⟶π1​=31​for the first matrix.​
(19)
The second chain alternates between the sets {1,3} and {2,4}. It is a periodic Markov chain with period two, so p11(2m+1)​=0. From either state 2 or state 4 the next-step probability of entering state 1 is 2/3. Therefore p11(2m)​=2/3 for every m≥1. The subsequences have different limits, so the second return-probability sequence does not converge.

Start the Markov chain at a state i and define the strictly positive first return time Ti+​=inf{n≥1:Xn​=i}. A recurrent state satisfies Pi​(Ti+​<∞)=1; a transient state has this probability strictly below one. Equivalently a recurrent state is visited infinitely often almost surely when started there, whereas a transient state receives finitely many visits almost surely. The recurrence criterion by return probabilities gives the equivalent test
i recurrent⟺∑n=0∞​pii(n)​=∞.
(20)
States in a communicating class share this classification. In an irreducible Markov chain all states communicate, so the chain is called a recurrent Markov chain if all its states are recurrent and a transient Markov chain if all are transient.

i OurBigBook.com
Represent the simple random walk by Xn​=ξ1​+⋯+ξn​, where the increments are independent and identically distributed and satisfy P(ξk​=1)=p, P(ξk​=−1)=1−p. They are integrable and have expectation 2p−1, so the strong law of large numbers gives
nXn​​⟶μ=2p−1almost surely.​
(21)
If p=1/2, this nonzero drift implies that Xn​ eventually leaves every fixed finite interval and tends to the appropriate infinity. Hence it visits zero only finitely many times almost surely, so zero is a transient state. By translation of the starting state, every state is transient: the chain is transient for p=1/2. This also covers the deterministic endpoint cases p=0,1, without assuming Markov chain irreducibility at those endpoints.

For the symmetric simple random walk on the integer line, odd return times are impossible. A return after 2m steps requires exactly m positive increments, so
p00(2m)​=(m2m​)2−2m∼πm​1​
(22)
by Stirling's approximation. The resulting sum diverges by the p-series criterion. The recurrence criterion by return probabilities therefore makes zero a recurrent state. The simple random walk is an irreducible Markov chain on Z, so the symmetric chain is recurrent.

This is the synchronous product of simple symmetric random walks, rather than a walk that changes only one coordinate at a time. Independence of the three coordinate processes gives
P((X2m​,Y2m​,Z2m​)=(0,0,0))=[(m2m​)2−2m]3∼(πm)3/21​.
(23)
Odd-time return probabilities vanish. The p-series with exponent 3/2 converges, so the sum of all return probabilities is finite. By the recurrence criterion by return probabilities, the origin is a transient state: the three-dimensional process is transient. From the origin its communicating class consists of integer triples whose coordinates have the same parity; translation gives the same classification for every other class.
