Open file description

 Home Computer science Operating system Process (computing) File descriptor
OurBigBook.com Words: 116 Articles: 1
A record of an open access to a file, including its current position and access mode. Each file descriptor reaches one open file description, but several file descriptors can share it. Separately opening the same ordinary file creates separate open file descriptions with independent positions while still reaching the same inode. Thus file descriptors, open file descriptions and hard links have different counts. [ref]
