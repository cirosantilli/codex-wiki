Return level (zT​=Fannual−1​(1−1/T))

 ... Mathematics Area of mathematics Probability and statistics Probability theory Extreme value theory Return period
OurBigBook.com Words: 547 Articles: 1
A return level answers the inverse question to a return period: which threshold has the specified rarity? Let F(z)=Fannual​(z)=P(Mj​≤z) be the common cumulative distribution function of annual sample maxima in a model with stationarity. For a continuous, strictly increasing F and T>1, the T-year return level is
zT​=F−1(1−T1​),F(zT​)=1−T1​,P(Mj​>zT​)=T1​.
(7)
It has the same units as Mj​, whereas T is a count of annual blocks. Independence between years is unnecessary for this one-year quantile definition; it is needed for the geometric waiting and multi-year formulas under return period. For a discrete probability distribution, use the generalized quantile function F−1(q)=inf{z:F(z)≥q}. Then P(Mj​>zT​)≤1/T, with equality not guaranteed at jumps; an exact requested exceedance probability may be unattainable.
For a concrete standard model, choose the maxima convention of the Gumbel distribution, with location μ and scale b>0:
F(z)=exp[−exp(−bz−μ​)],zT​=μ−blog[−log(1−T1​)].
(8)
The second formula follows by taking logarithms twice and solving F(zT​)=1−1/T. The maxima cumulative distribution function and its inverse are given in NIST: extreme value type I distribution, maximum case. With the deliberately chosen toy values μ=10 and b=2 in arbitrary units, z10​=14.501, z100​=19.200, and z1000​=23.815, rounded to three decimals. In particular, 19.200 is approximately the annual quantile at cumulative probability 0.99; it is not a prediction of the largest observation in the next 100 years. Under independence, the probability that all those annual sample maxima stay below the exact z100​ is 0.99100≈0.366.
The time block matters. If a toy year contains m independent daily blocks, each with exceedance probability q at one fixed threshold, its annual exceedance probability is p=1−(1−q)m, giving annual return period 1/[1−(1−q)m]. The reciprocal 1/q counts daily blocks. Dependence among daily exceedances requires their joint law instead; a threshold crossed on several successive days still produces only one exceedance indicator for that year's sample maximum. The peaks-over-threshold method and declustering of extremes address a different choice of extreme-event sampling.
