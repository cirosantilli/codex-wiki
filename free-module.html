Free module (M≅⨁i∈I​R)

 Home Mathematics Area of mathematics Algebra Commutative algebra Module theory
OurBigBook.com Words: 808 Articles: 13
A free module is a module with a basis of a module (ei​)i∈I​: every element has exactly one expression m=∑i∈I​ri​ei​ with ri​∈R and only finitely many ri​ nonzero. Equivalently, the coefficient map ⨁i∈I​R→M is a module isomorphism. Existence means generation; uniqueness means linear independence in a module. For finite I of size n, this says M≅Rn, a finite free module. See Neil Strickland's Rings, Modules and Linear Algebra, section 11.
The integer lattice Z2 in the opening diagram is a free module over Z with basis of a module e1​=(1,0), e2​=(0,1). For example, (3,2)=3e1​+2e2​, and comparing the two coordinates makes the coefficients unique. A different basis of a module is u=(1,0), v=(1,1), because (a,b)=(a−b)u+bv; in particular (3,2)=u+2v.
By contrast, w1​=(2,0) and w2​=(0,1) are linearly independent in a module, but generate only the submodule 2Z×Z. They miss (1,0) because 2a=1 has no integer solution. They would form a basis over the rational numbers. Even generation need not let one extract a basis of a module: the elements 2,3 generate Z, since 1=3−2, but neither singleton generates it, and 3⋅2−2⋅3=0 is a nontrivial linear relation between them. These are concrete failures of the usual vector space argument that divides by any nonzero coefficient.
The cyclic module Z/6Z has no basis of a module over Z: every element has the nontrivial relation 6m=0, so no nonempty subset is linearly independent in a module, while the empty subset cannot generate this nonzero module. Specifying the scalar ring is essential: over R=Z/6Z, the same additive object is a free module with the one-element basis of a module {1}, since each coefficient is itself a unique class in R.
