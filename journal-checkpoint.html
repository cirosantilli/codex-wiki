Journal checkpoint

 Home Computer science Operating system File system File-system journaling Write-ahead logging
OurBigBook.com Words: 52
Installing committed journal payload at final locations and making those copies durable. Safe retirement follows this completion, not merely submission of the copies. Discarding the journal while some copies remain only in a volatile memory cache can leave an unrecoverable mixture after a crash. Commit establishes a recoverable decision; a journal checkpoint permits reclamation of its journal space.
