Compatibility condition for pure nonlinear transverse waves (∂q​P11​(1,q,0)=0)

For a plane material-coordinate elastic wave with u=(0,w(X1​,t),0), set q=w,X1​​. The longitudinal equation is 0=∂X1​​P11​(1,q,0). Arbitrary nonuniform pure transverse profiles thus require the displayed constitutive compatibility, which does not follow from isotropy alone. If it holds and τ′(q)>0, the shear equation closes as ρ0​wtt​=∂X1​​τ(q) with speed c(q)2=τ′(q)/ρ0​.
