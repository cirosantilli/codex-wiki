Partition of a set

 Home Mathematics Area of mathematics Foundations of mathematics Set theory Set
OurBigBook.com Words: 95 Articles: 1
A partition of a set X is a family of pairwise disjoint nonempty subsets whose union is X. Every equivalence relation defines a partition into equivalence classes, and conversely belonging to the same cell of a partition defines an equivalence relation. The nonempty colour classes of a finite colouring form a finite partition.
