For a nonconstant meromorphic function on the unit disc and q≥3 distinct spherical values, this version of the Nevanlinna second main theorem holds outside a set E with ∫E​dr/(1−r)<∞, as r↑1. The truncated Nevanlinna counting function counts distinct preimages rather than multiplicity. The boundary-distance error is essential and need not be small relative to the characteristic. It follows from the disk Nevanlinna logarithmic derivative lemma and the growth lemma in the variable log(1/(1−r)). The disk error estimate and weighted exceptional-set argument appear in mathweb.tifr.res.in/Documents/Publications/Lectures/tifr17.pdf .
