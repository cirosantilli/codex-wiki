Almost strongly universal hash family (Prh​[h(x)=u,h(y)=v]≤ε/q)

 Home Computer science Hash function
OurBigBook.com Words: 263 Articles: 1
An almost strongly universal hash family relaxes the exact ordered pair balance of a strongly universal hash family. In the convention used here, choose h with the uniform distribution on a finite set from a family with q possible outputs. Every individual output remains uniform, and for every distinct pair of inputs x,y and every specified ordered pair of outputs u,v,
Prh​[h(x)=u,h(y)=v]≤qε​.
(12)
Equivalently, the conditional probability Prh​[h(y)=v∣h(x)=u] is at most ε. This asks how predictable a second output can become after the first is known.
For q=5, strongly universal hash families give ε=1/5: learning one output leaves each specified second output with conditional probability 1/5. A looser guarantee ε=2/5 permits a specified ordered pair to have probability as large as 2/25, while each individual output still has probability 1/5. Summing over the five equal ordered pairs bounds the collision probability by 2/5, rather than the 1/5 required of a universal hash family. Thus an almost strongly universal hash family need not be a universal hash family. Necessarily ε≥1/q, because the q conditional probabilities sum to one; equality recovers a strongly universal hash family. This relaxation is useful in Wegman–Carter authentication, where efficiency can be traded against a quantified forgery bound within a complete message authentication protocol.
