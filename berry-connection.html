Berry connection (Aj​=i⟨ψ∣∂Rj​​ψ⟩)

For a normalized, smoothly chosen instantaneous energy eigenstate ∣ψ(R)⟩, the Berry connection has components Aj​=i⟨ψ∣∂Rj​​ψ⟩. Its line integral around a closed parameter path C gives the Berry phase in a periodic choice of state vector:
γ=∮C​∑j​Aj​dRj​(mod2π).
(36)
Normalization makes the inner product ⟨ψ∣∂Rj​​ψ⟩ purely imaginary, so the Berry connection is real. Changing the representative to eiχ(R)∣ψ⟩ changes the Berry connection to Aj​−∂Rj​​χ. A single-valued phase factor along the closed path changes the line integral by an integer multiple of 2π, leaving eiγ unchanged. If the chosen vector is not periodic, include the endpoint phase:
γ=arg⟨ψ(0)∣ψ(T)⟩+i∫0T​⟨ψ(t)∣ψ˙​(t)⟩dt(mod2π).
(37)
Here ψ denotes the instantaneous energy eigenstate representative, with its dynamical phase removed. This is freedom to choose a representative of a state ray. [ref].
