Second-derivative criterion for convexity (f convex⟺f′′≥0)

 Home Mathematics Area of mathematics Analysis Real analysis Convex function
OurBigBook.com Words: 61
A twice-differentiable real-valued function on an open interval is convex if and only if its second derivative is nonnegative everywhere. If f′′≥0, the mean value theorem makes f′ nondecreasing, which implies the supporting-line and chord inequalities for convexity. Conversely, the slopes of a convex function are ordered; where the second derivative exists, this gives f′′≥0. Strict positivity of f′′ is sufficient for strict convexity, but is not necessary: f(x)=x4 is strictly convex despite f′′(0)=0.
