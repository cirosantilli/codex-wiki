Hamming code weight enumerator (WC​(s,t)=2−l((s+t)N+(2l−1)(t−s)m(t+s)m−1))

Here N=2l−1, m=2l−1 and the weight enumerator convention is WC​(s,t)=∑c∈C​swt(c)tN−wt(c). The dual code is the binary simplex code, with enumerator tN+(2l−1)smtm−1. The MacWilliams identity gives the formula. For l=3, the ordinary enumerator WC​(z,1) is 1+7z3+7z4+z7; for l=1, the degenerate one-word code has enumerator t.
