Spinlock

 ... Operating system Process (computing) Thread (computing) Synchronization (computing) Mutual exclusion Mutex
OurBigBook.com Words: 140 Articles: 1
A mechanism that waits for ownership by repeatedly trying while consuming CPU execution time. A spinlock built from test-and-set can enforce mutual exclusion without guaranteeing starvation freedom. Progress also requires the owner to run and release: if a waiting software thread monopolizes the only CPU while the owner is suspended, exclusive entry alone cannot help.[ref]
