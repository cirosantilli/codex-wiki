Transitive class

 Home Mathematics Area of mathematics Foundations of mathematics Set theory Class in set theory
OurBigBook.com Words: 574 Articles: 14
A class M is transitive when x∈y∈M implies x∈M. Consequently, every member of a member of M is available as an element of the structure (M,∈).
