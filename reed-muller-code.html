Reed-Muller code

 Home Mathematics Area of mathematics Algebra Coding theory Linear code
OurBigBook.com Words: 105 Articles: 3
The binary Reed-Muller code RM(d,r) evaluates Boolean polynomials of degree at most r on F2d​. It has parameters
[2d,∑j=0r​(jd​),2d−r].
(94)
The dimension counts square-free monomials, and the minimum weight follows inductively from the decomposition (u,u+v).
