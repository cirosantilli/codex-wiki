Compact subset of an open set has positive distance from its complement (∅=K⊂Ω, K compact, Ω open⟹d(K,X∖Ω)>0)

In a metric space X, let the nonempty compact set K lie in the open set Ω. If F=X∖Ω is nonempty, the distance to a set d(x,F) is a continuous function of x: the triangle inequality gives ∣d(x,F)−d(y,F)∣≤d(x,y). Since F is a closed set, this distance is strictly positive on K. The extreme value theorem attains its minimum on K, so
d(K,F)=minx∈K​d(x,F)>0.
(18)
If F is empty, the extended-real convention gives d(K,F)=+∞. This result provides a single positive neighbourhood radius that stays inside Ω at every point of K. Compactness is essential: in the real line K={1/n:n≥1}⊂(0,2) has zero distance between two sets from (−∞,0]∪[2,∞), although each point of K has positive distance to a set from that complement.
