A shared coin prevents a zero-one conclusion

Let Z have the fair Bernoulli distribution and set Xj​=Z for every j. Each coordinate has the same fair probability distribution as in the independent model, but the coordinates are dependent: P(X1​=1,X2​=1)=1/2, whereas the product of the marginal probabilities is 1/4. Every future sigma-algebra equals σ(Z), so the tail sigma-algebra also equals σ(Z).
The tail event of infinitely many heads is now exactly {Z=1}, with probability 1/2. For the finite-window events Bm,r​ in infinitely many heads as a tail event,

The sample space can even be the same full Cartesian product {0,1}N in both models: the dependent probability measure assigns mass 1/2 to each of the all-zero and all-one sequences. Then A is the same literal tail event in both models. Only the probability measure and its independence properties change.
