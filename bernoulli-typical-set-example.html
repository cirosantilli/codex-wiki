For n=40, this includes exactly k=8,9,10,11,12. There are (k40​) words with each count: a type class with that many possible orderings. Summing the counts and their probability masses gives

These are fewer than one percent of the 240 possible words, yet they carry nearly 64 percent of the probability. No contradiction is involved: the type classes near ten ones each contain many more individual words.
