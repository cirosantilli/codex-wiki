Continuous nonalgebraic unit interval (x≪y⟺x<y or x=y=0)

 ... Foundations of mathematics Set theory Set Partially ordered set Continuous poset Continuous directed-complete partial order
OurBigBook.com Words: 116
Give the real interval [0,1] its usual total order. Every nonempty directed set has a least upper bound in the real interval, so it is a directed-complete partial order. If x<y≤supD, some d∈D exceeds x; otherwise x would be an upper bound for D. Also 0≪0, since every member of a nonempty D is at least zero. For x>0, the increasing sequence x(1−1/n), n≥1, has least upper bound x but never reaches it, so x≪x. Together with x≪y⇒x≤y, this proves the displayed way-below relation.
For each y>0, the elements way-below y form [0,y), a directed set with least upper bound y; for y=0 they form {0}. Thus this is a continuous poset. Its only compact element is zero, so it is not an algebraic partially ordered set.
