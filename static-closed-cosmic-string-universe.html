Static closed cosmic-string universe (ρs​a2=3K/(8πG))

 ... Physics Branches of physics Cosmology Cosmological perfect-fluid continuity equation Barotropic equation of state Cosmic string network
OurBigBook.com Words: 114 Articles: 1
A closed universe containing only a cosmic string network can remain static. Its Friedmann acceleration equation vanishes identically because Ps​=−ρs​/3, and its Friedmann equation requires ρs​a2=3K/(8πG). Once this conserved normalization is tuned, every positive radius gives a static solution. The usual Hubble-normalized cosmological density parameter is undefined at a static epoch.
