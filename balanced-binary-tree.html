Balanced binary tree

 Home Computer science Data structure Binary tree
OurBigBook.com Words: 183 Articles: 2
A binary tree whose subtree sizes or heights satisfy a stated balance condition. Recursively splitting an n-element sorted list into sizes ⌊n/2⌋ and ⌈n/2⌉−1 gives logarithmic height and child sizes differing by at most one. This is a static construction; ordinary binary search tree insertion does not automatically retain balance.
