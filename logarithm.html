Logarithm (logb​)

 ... Mathematics Area of mathematics Analysis Real analysis Calculus Exponential function
OurBigBook.com Words: 543 Articles: 8
For a positive real base b=1, the logarithm is the inverse function of the exponential function t↦bt:
logb​x=t⟺bt=x,x>0.
(46)
It asks which exponent produces a given positive number. Thus log2​8=3 and log2​(1/8)=−3. The base restrictions matter: b=1 would produce only one value, while a negative base does not define bt as a real-valued function for every real exponent.
The useful transformation is
logb​(xy)=logb​x+logb​y,logb​(x/y)=logb​x−logb​y.
(47)
For example, 8⋅16=128 corresponds to 3+4=7 in base two. Products become sums and ratios become differences. The logarithm does not generally convert a sum into a sum of logarithms. Base conversion uses the natural logarithm: logb​x=lnx/lnb. It also gives d(logb​x)/dx=1/(xlnb), positive when b>1 and negative when 0<b<1.
Historically, John Napier's 1614 Mirifici logarithmorum canonis descriptio presented logarithmic tables and their use, documented in the Smithsonian Libraries' digitized original. Tables made multiplication-heavy calculations more manageable by replacing products with addition and a lookup. The 1619 Constructio title page below belongs to a later publication from the same work on logarithms. These historical publications preceded the modern inverse function and integral presentation used here.
