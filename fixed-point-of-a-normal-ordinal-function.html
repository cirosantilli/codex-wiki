Fixed point of a normal ordinal function (f(α)=α)

 ... Mathematics Area of mathematics Foundations of mathematics Set theory Ordinal Normal function on an ordinal
OurBigBook.com Words: 52
For a strictly increasing ordinal class function continuous at limits, start with α0​=0 and iterate αn+1​=f(αn​). If the sequence stabilizes, its stable value is a fixed point. Otherwise its supremum α is a limit and continuity gives f(α)=supn​f(αn​)=supn​αn+1​=α. Starting the iteration above any prescribed ordinal gives arbitrarily large fixed points.
