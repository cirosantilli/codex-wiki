Use the agreed text encoding to split the plaintext into integer blocks mj​∈{0,…,1072}. RSA encrypts each block by modular exponentiation:
rj​≡mj11​(mod1073).
(9)
Because 1073=29⋅37 is a product of distinct primes, its Euler totient function is φ(1073)=28⋅36=1008. The inverse exponent follows from
11⋅275=3025=1+3⋅1008.
(10)
Thus a decryption exponent is 275, and the three recovered blocks are
mj​≡rj275​(mod1073),0≤mj​<1073,j=1,2,3​.
(11)
To check every block, including blocks not coprime to the modulus, reduce modulo each prime. If mj​ is nonzero modulo 29, Fermat's little theorem gives mj3025​=mj​ because 28∣3024; if it is zero the equality is immediate. The same argument works modulo 37 because 36∣3024. The Chinese remainder theorem then gives the equality modulo 1073. Finally reverse the agreed text encoding. The symbols r1​,r2​,r3​ are unspecified, so there are no numerical message blocks to evaluate further.
