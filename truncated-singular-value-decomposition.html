Truncated singular value decomposition

 ... Mathematics Area of mathematics Analysis Inverse problem Regularization of an inverse problem Spectral regularization method
OurBigBook.com Words: 54
For a singular value decomposition Avj​=σj​uj​, truncated SVD with cutoff τ>0 estimates the inverse action by xτ​=∑σj​≥τ​σj−1​⟨b,uj​⟩vj​. Discarding small singular values limits amplification of data errors; this is a spectral regularization method.
Truncated singular value decomposition retains only singular components above a threshold, or equivalently only a finite leading set of singular vectors.
