Number of maximizing weighted k-Sperner families

 ... Extremal set theory Set family Boolean lattice Antichain k-Sperner family Weighted theorem for k-Sperner families
OurBigBook.com Words: 52
If t is the kth largest rank weight ui​, exactly h levels have weight greater than t, and exactly s have weight t, then there are (k−hs​) maximizing families. For fixed n,k, the possible counts are exactly (js​) with 1≤j≤k and j≤s≤n+1−k+j.
