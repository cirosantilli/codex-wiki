Ancilla preparation for the Bernstein-Vazirani algorithm (H∣1⟩=∣−⟩)

 Home Computer science Algorithm Quantum algorithm Bernstein-Vazirani algorithm
OurBigBook.com Words: 118
The displayed Bernstein-Vazirani algorithm prepares its ancilla qubit in the computational-basis state ∣1⟩ before the first Hadamard gate. At the function oracle it is therefore the −1 eigenstate ∣−⟩ of the Pauli X gate, which enables phase kickback. Preparing ∣0⟩ instead yields ∣+⟩ at the function oracle; target flips leave this state unchanged, so the data contain no information about a.
The Hadamard-conjugated linear oracle makes the more general statement transparent. With zero data and initial ancilla qubit α∣0⟩+β∣1⟩, the full fixed quantum circuit outputs
α∣0⟩⊗n∣0⟩+β∣a⟩∣1⟩.
(3)
For nonzero a, the correct data outcome has probability ∣β∣2. To obtain exact identification for all a, this preparation must have α=0, so it is ∣1⟩ up to global phase. This is a condition on the prescribed preparation circuit: any alternative quantum state preparation that supplies ∣−⟩ at the function oracle is equivalent.
