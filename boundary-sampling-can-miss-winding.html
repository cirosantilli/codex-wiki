Boundary sampling can miss winding

 Home Mathematics Area of mathematics Analysis Complex analysis Argument principle
OurBigBook.com Words: 209
A finite list of function values does not determine the winding number of the intervening image contour. For example, sample γ(t)=eit only at tj​=2πj/4, j=0,1,2,3. The polynomials f(z)=z and g(z)=z5 agree at all four sampled points, because γ(tj​)4=1. Joining those values by straight segments draws the same square for both. Yet their true winding numbers are one and five, and their enclosed zero multiplicities differ by four.
Refining samples can help resolve a given example, but an asserted root count needs a bound controlling what happens between them. One sufficient certificate is to enclose the image of each boundary subarc and its interpolating segment in a convex set that excludes zero. Straight interpolation then gives a homotopy avoiding zero, so the polygon and true image contour have the same winding number. A plot that merely looks closed and avoids zero at its sampled points is not that certificate.
