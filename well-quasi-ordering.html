Well-quasi-ordering (∀(xi​) ∃i<j (xi​≤xj​))

 ... Mathematics Area of mathematics Foundations of mathematics Set theory Set Preorder
OurBigBook.com Words: 927 Articles: 16
A preorder is a well-quasi-ordering if every infinite sequence has indices i<j with xi​≤xj​. An infinite sequence with no such pair is a bad sequence. This formulation handles combinatorial embedding relations that need not be antisymmetric on syntactic codes.
