Ordinal rank function for a relation (ρ:X→Ord)

 ... Mathematics Area of mathematics Foundations of mathematics Set theory Well-founded relation Well-founded recursion
OurBigBook.com Words: 165 Articles: 2
An ordinal-valued function strictly increasing along a relation. For a well-founded set relation, or a set-like class relation, the canonical rank is ρ(y)=sup{ρ(x)+1:xRy}.
