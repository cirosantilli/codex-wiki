Negative unit obstruction for the fourteen-coefficient isogeny cover (N2=−U4+14U2V2−V4)

 ... Genus one curve Elliptic curve Mordell-Weil group Kummer map of an elliptic curve Two-isogeny descent Quartic covering in a two-isogeny descent
OurBigBook.com Words: 68
This quartic covering in a two-isogeny descent has no solution with coprime integers U,V not both zero. If precisely one is odd, the right side is 3 modulo four. If both are odd, their fourth powers are one modulo sixteen and 14U2V2=14 modulo sixteen, so the right side is twelve modulo sixteen. Neither residue is a square. Coprimality excludes the remaining parity case. Consequently the negative unit square class is absent from the two-torsion square-class homomorphism for Y2=X3+14X2+X.
