Image of a function (f(X))

 Home Mathematics Area of mathematics Foundations of mathematics Set theory Image and preimage of a function
OurBigBook.com Words: 208
For a function f:X→Y and a subset E⊆X, its image is
f(E)={f(x):x∈E}={y∈Y: there exists x∈E with f(x)=y}.
(33)
The full image of a function is f(X). The set notation ignores repeated outputs: in the finite example above, f({a,b})={0}, rather than a list containing zero twice. A function collision can therefore reduce the cardinality of an image.
Images of a function preserve unions:
f(E∪F)=f(E)∪f(F).
(34)
An output reached from the union is reached from at least one of its two input sets. For intersections, however, only
f(E∩F)⊆f(E)∩f(F)
(35)
holds in general. In the finite example, take E={a} and F={b}. Their intersection is the empty set, so f(E∩F)=∅. But f(E)=f(F)={0}, giving f(E)∩f(F)={0}. Distinct witnesses in the two input sets can produce the same output.
For an injective function, an output shared by f(E) and f(F) must come from the same input. That input lies in E∩F, so equality holds. Conversely, preserving intersections for every pair of input subsets forces injectivity: two distinct inputs with the same output would give the singleton counterexample above. The image and preimage laws are stated in Jiří Lebl, Basic Analysis I, Propositions 0.3.15–0.3.16; the finite example makes the missing reverse inclusion visible.
