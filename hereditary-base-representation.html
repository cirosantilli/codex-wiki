Hereditary base representation (m=∑i​bei​ci​)

 Home Mathematics Area of mathematics Number theory Integer Positional notation
OurBigBook.com Words: 167 Articles: 4
A hereditary base representation expands not only the number in base b, but also every exponent recursively in that same base. Changing the base at every depth defines the Goodstein base-change operation; replacing it by omega defines an ordinal rank of a Goodstein term.
