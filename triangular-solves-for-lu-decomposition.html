Triangular solves for LU decomposition (Ly=Pb,Ux=y)

 ... Mathematics Area of mathematics Analysis Numerical analysis Numerical linear algebra LU decomposition
OurBigBook.com Words: 174 Articles: 1
Given Pivoted LU decomposition PA=LU, the linear system Ax=b is equivalent to LUx=Pb. Introduce the intermediate vector y=Ux: first use forward substitution to solve Ly=Pb, then back substitution to solve Ux=y. With unpivoted LU decomposition, P=I is the identity matrix, so the first right-hand side is simply b.[ref]
For the factors in Computed three-by-three LU decomposition and b=(7,23,26)T, forward substitution gives
y1​=7,y2​=23−2(7)=9,y3​=26+7−3(9)=6.
(278)
Then back substitution gives
x3​=6/2=3,x2​=(9−3)/3=2,x1​=(7−2−3)/2=1.
(279)
Direct matrix multiplication verifies A(1,2,3)T=(7,23,26)T. More generally, the back substitution recurrence is
xi​=uii​yi​−∑j=i+1n​uij​xj​​,i=n,n−1,…,1.
(280)
The direction matters: the last row contains only xn​, whereas the first row generally involves every unknown. No dense matrix inverse is needed for either triangular solve.
