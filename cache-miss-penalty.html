Cache miss penalty (p)

 Home Computer science Computer memory Cache (computing) Cache miss
OurBigBook.com Words: 33
The additional memory access latency charged for a cache miss beyond a common lookup time in the average memory access time model. It includes obtaining the requested cache block and making the read complete; this model excludes extra costs from writes and overlapping requests.
