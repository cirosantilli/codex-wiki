Use binary units 1KB=210 bytes and 1MB=220 bytes, consistent with the given binary GB convention. Reading one average file takes seek plus rotation plus transfer; moving it requires the same costs again on the write:
tfile​=2(0.005+0.004+8⋅2208⋅210​)=0.019953125 s≈20 ms.​

A half-full 16 GB disk contains 8⋅230 used bytes, or N=220 average files. Under the stated per-file disk compaction model,
T=Ntfile​=20922.368 s≈5.81 hours.​
(10)
A calculation with decimal KB and MB changes the unrounded figures, so the unit convention must be retained consistently. This model charges one seek and rotational delay on each read and each write; it does not assume a single streaming pass over the whole disk.
