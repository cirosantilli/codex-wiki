Use unsigned inputs as in the preceding parts. Store a 16-bit accumulator P, a 16-bit shifted multiplicand M, an eight-bit multiplier Q, and a three-bit iteration binary counter k. The sequential circuit has one 16-bit adder, a 16-bit multiplexer selecting M or zero from Q0​, fixed one-place bit shifts, and load/hold selection for the digital registers. The input values are captured when start is accepted, so later input changes cannot alter the operation.
Use three control states with the following synchronous transition table. All assignments in a row use the old digital register values and occur together at the active clock edge.

Reset selects IDLE and clears the digital registers. Set Z=P and done = 1 exactly in DONE. A start pulse in IDLE launches one multiplication; further pulses during RUN are ignored. Holding start high cannot repeatedly launch operations: DONE waits for it to go low before rearming. The product remains stored while waiting and through the following IDLE state. There are eight RUN clock edges after the loading edge; the last addition is captured before done becomes high.
For correctness, let X0​,Y0​ denote the captured values. After i iterations, for 0≤i≤8, the loop invariant is
Pi​=X0​(Y0​mod2i),Mi​=2iX0​,Qi​=⌊Y0​/2i⌋,

so Pi​+Mi​Qi​=X0​Y0​. Writing Qi​=2q+b, the next accumulation adds bMi​, the left bit shift doubles Mi​, and the logical right shift changes Qi​ to q. Hence the invariant is preserved. At i=8, Qi​=0, giving Z=P8​=X0​Y0​. The largest product is 2552=65025<216, so the accumulator fits. Even the final shifted multiplicand is 256X0​≤65280, so it also fits.
