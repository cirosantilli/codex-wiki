Save the root, move the last active entry to the root, shrink the active prefix, then restore heap order by heapify down:
ExtractMin(A):
    if A.heap_size == 0:
        error "empty heap"
    answer = A[0]
    A[0] = A[A.heap_size-1]
    A.heap_size = A.heap_size-1
    if A.heap_size > 0:
        SiftDown(A,0)
    return answer

SiftDown(A,i):
    while true:
        best = i
        for j = 0,...,d-1:
            c = Child(i,j)
            if c >= A.heap_size:
                break
            if A[c] < A[best]:
                best = c
        if best == i:
            return
        swap A[i], A[best]
        i = best
Only edges descending from the moved entry can violate heap order. If the entry is no larger than every child, the entire heap is valid. Otherwise swapping with a minimum child restores the order at the old position: that child is no larger than the old entry or any sibling. Its original subtree was already ordered, so only the moved entry's new outgoing edges can remain invalid. This is the loop invariant of SiftDown. Each swap moves it down one level, proving termination and correctness.
For 2≤d≤n, the height is O(logd​n), and selecting a minimum child costs at most d comparisons per level. Thus ExtractMin takes O(dlogd​n) time, with O(1) auxiliary storage. Empty and singleton heaps take constant time. For d>n, there is at most one nonroot level and the loop examines at most n−1 actual children, taking O(n); this also lies within O(dlogd​n) for n≥2. The coarser uniform expression O(1+d(1+logd​n)) safely includes all small sizes.
