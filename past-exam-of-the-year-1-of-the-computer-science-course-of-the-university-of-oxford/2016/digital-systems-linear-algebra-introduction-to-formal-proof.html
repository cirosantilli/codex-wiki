Use a synchronous binary counter with three positive-edge-triggered D flip-flops, all driven by the same clock signal. Write their outputs q2​q1​q0​, with q0​ the least significant bit. The next-state Boolean functions are
D0​=¬q0​,D1​=q1​⊕q0​,D2​=q2​⊕(q1​∧q0​).​
(1)
Implement these with one NOT gate, two exclusive or gates, and one AND gate. Connect each Di​ to its corresponding D flip-flop; its output qi​ is address line i. A reset input clears all three flip-flops to zero, so the first selected sensor is sensor zero.
The state sequence is
000→001→010→011→100→101→110→111→000.
(2)
The low bit toggles at every clock edge, the middle bit toggles exactly when the old low bit is one, and the high bit toggles exactly when both old lower bits are one. These are precisely the carry conditions for incrementing a three-bit binary representation. Every possible state belongs to the cycle, so there is no unused state requiring recovery. Choose a clock period allowing the combinational logic to settle before the next capture.

For data inputs d0​,…,d7​ and selection bits s2​s1​s0​, use a three-to-eight binary decoder. Its output ei​ is the minterm that is one exactly when the selection equals the three-bit binary representation of i. For example,

Gate each data input with its decoded selection using an AND gate, then combine all eight results with an OR gate:
z=i=0⋁7​(ei​∧di​).​
(4)
Exactly one ei​ is asserted, so z=di​ for the selected i, regardless of the other data inputs. A direct implementation uses three shared NOT gates, eight three-input AND gates for the binary decoder, eight two-input AND gates for the data, and one eight-input OR gate. Use eight parallel 8:1 multiplexers and one shared three-bit binary counter. If di,j​ is bit j from sensor i, connect d0,j​,…,d7,j​ to multiplexer j. Connect all selection inputs to the binary counter outputs. Then data line j carries dq,j​, so all eight data lines belong to the same selected sensor. Send the three counter outputs to the receiver as the address lines as well.
After reset the receiver sees sensors 0,1,…,7,0,…, one per clock period. Sample the data and address only after the binary counter and multiplexers have settled, for example on the opposite clock edge with a sufficiently long clock period. Changing addresses can otherwise cause transient logic hazards. The transmitter uses eleven signal lines, apart from any shared clock or reset connection.

Split the four-bit unsigned inputs into two-bit halves: X=4XH​+XL​ and Y=4YH​+YL​. Use four copies of the two-bit binary multiplier to compute PLL​=XL​YL​, PHL​=XH​YL​, PLH​=XL​YH​, and PHH​=XH​YH​. Then
XY=PLL​+4PHL​+4PLH​+16PHH​.​
(8)

Use the first eight-bit adder to form R=PHL​+PLH​ after zero-extension, and the second to form Z=W+(R≪2). Thus four two-bit binary multipliers and two eight-bit adders suffice. The fixed left bit shift is also wiring alone.

The calling convention passes the integer argument in $a0, returns the result in $v0, and uses jal with $ra for a call and its return address. The callee returns using jr $ra. Its stack frame grows downwards from $sp and must be removed before returning, restoring the caller's stack pointer.
The $s processor registers are callee-saved registers: a callee that uses $s0 or $s1 must restore their incoming values. The $a, $v, and $t processor registers are caller-saved registers; a caller must preserve any of their values that it needs after a call. Consequently foo keeps its own argument in $s0 and the first call's result in $s1, where nested calls preserve them. Because a nested jal overwrites $ra, foo also saves its incoming return address. Every recursive activation has its own stack frame.
The supplied MIPS instructions use the paper's simplified convention: pseudoinstructions such as subi are accepted, and control transfers have no branch delay slot. The completed code below follows that convention. A hardware implementation with delayed control transfers requires suitable scheduling or nop instructions throughout the supplied code as well.

The entry sequence creates one 12-byte stack frame, then preserves the return address and both used callee-saved registers:
subi $sp, $sp, 12    # allocate three four-byte words
sw   $ra, 0($sp)     # save return address of this activation
sw   $s0, 4($sp)     # save caller's s0
sw   $s1, 8($sp)     # save caller's s1
The closing sequence reverses these effects:
lw   $ra, 0($sp)     # recover return address of this activation
lw   $s0, 4($sp)     # restore caller's s0
lw   $s1, 8($sp)     # restore caller's s1
addi $sp, $sp, 12    # deallocate the frame
jr   $ra            # return to the caller
Loads must precede deallocation because their offsets refer to the current stack frame. The return value in $v0 is deliberately retained. Saving $ra is essential even though it is not an $s processor register: otherwise the second nested call would destroy the address to which this activation must return.

li   $s0, n

Write the determinant in its Leibniz formula for determinants, where Sn​ is the set of permutations of {1,…,n}:
det(A)=∑σ∈Sn​​sgn(σ)∏i=1n​ai,σ(i)​.
(20)
The permutation sign is justified by the given row-interchange property: a permutation matrix is obtained from the identity matrix by row interchanges, and every interchange changes its determinant by a factor −1. Reversing a sequence of interchanges constructs the inverse permutation with the same number of interchanges. Consequently sgn(σ−1)=sgn(σ). The Leibniz formula for determinants can itself be obtained by expanding the rows multilinearly in the standard basis: repeated selected coordinate rows contribute zero, and the remaining terms are precisely these signed permutation matrices.
Since (AT)ij​=aji​, the same formula gives
det(AT)=∑σ∈Sn​​sgn(σ)∏i=1n​aσ(i),i​.
(21)
Reindex the product with j=σ(i) and reindex the sum with τ=σ−1. Both reindexings are bijections, so
det(AT)=∑τ∈Sn​​sgn(τ)∏j=1n​aj,τ(j)​=det(A).
(22)
Thus det(A)=det(AT) for every real square matrix, including singular matrices. This proof does not assume the analogous column-operation rules in order to establish the transpose identity.

Interpret “distinct eigenvalues” as n pairwise distinct eigenvalues in the chosen field. Select a nonzero eigenvector zi​ for each. A single nonzero vector is linearly independent. Suppose inductively that z1​,…,zk​ are linearly independent. If adding zk+1​ made the set linearly dependent, its nontrivial relation would have a nonzero coefficient of zk+1​, since otherwise it would contradict the induction hypothesis. Solving for zk+1​ would place it in the linear span of the first k eigenvectors.
Part (c) would then force λk+1​=λi​ for some i≤k, contradicting pairwise distinctness. Mathematical induction therefore proves that all n selected eigenvectors are linearly independent, forming a basis. If the field is R, the assertion requires n real eigenvalues; a real matrix can instead have nonreal eigenvalues and a eigenvector basis over the complex numbers.

The implication introduction rule opens a subproof with a temporary assumption ϕ, derives ψ, and discharges that assumption to conclude ϕ→ψ. The negation introduction rule opens a subproof with a temporary assumption ϕ, derives logical falsity ⊥, and discharges it to conclude ¬ϕ.
The boxes record the scopes and dependencies of the temporary assumptions. A result derived inside a box cannot be used outside it without the appropriate discharge rule; it may depend on the boxed assumption. Other, surrounding assumptions remain in force. This is how the natural deduction rules distinguish a conditional derivation from an unconditional assertion.

 4  | P ∧ R      assumption (new case)
 5  | P          ∧-elim-L 4
 6  P            ∨-elim 1,2–3,4–5
 7  | P ∧ Q      assumption
 8  | Q          ∧-elim-R 7
 9  | Q ∨ R      ∨-intro-L 8
10  | P ∧ R      assumption (new case)
11  | R          ∧-elim-R 10
12  | Q ∨ R      ∨-intro-R 11
13  Q ∨ R        ∨-elim 1,7–9,10–12
14  P ∧ (Q ∨ R)  ∧-intro 6,13
The essential difference is the final rule: the first proof splits the premise once, while the second splits the goal first and then analyzes the premise twice. Counting only rule applications, both displayed proofs take nine inference steps. The first uses four conjunction elimination steps, two disjunction introduction steps, two conjunction introduction steps and one disjunction elimination; the second replaces one conjunction introduction with a second disjunction elimination. If assumption lines are counted as displayed proof lines, the second is longer, 14 rather than 12, because it opens four case assumptions rather than two. Thus a raw line count and an inference-step count need not agree.

Proof by contradiction, or reductio ad absurdum, has the form
Γ⊢ϕΓ,¬ϕ⊢⊥​RAA,​
(32)
discharging the assumption ¬ϕ. This is the classical rule that concludes ϕ directly, as opposed to the negation introduction rule, which concludes a negation.
To derive double-negation elimination using RAA without assuming double-negation elimination itself, use
1  ¬¬φ   premise
2  | ¬φ  assumption
3  | ⊥   ¬-elim 2,1
4  φ     RAA 2–3
Here line 1 is the negation of line 2. Thus only negation elimination rule inside the subproof, followed by RAA, is needed.

Choose a fresh parameter a. The universal quantifier elimination rule supplies both the implication and its premise at that same parameter:
1  ∀x. (P(x) → Q(x))        premise
2  | ∀x. P(x)               assumption
3  | P(a)                   ∀-elim 2
4  | P(a) → Q(a)            ∀-elim 1
5  | Q(a)                   →-elim 4,3
6  | ∀x. Q(x)               ∀-intro 5, a fresh
7  (∀x. P(x)) → (∀x. Q(x))  →-intro 2–6
The eigenvariable condition holds because a is absent from both undischarged assumptions at line 6. Hence the universally quantified implication is proved.
The proposed version with merely P(x) in the antecedent is not derivable. For a counterexample, take a two-element domain {0,1} with P and Q both true precisely at zero. The universal premise holds. Under the assignment x=0, P(x) is true but ∀xQ(x) is false. By soundness, a formal proof cannot exist. Attempting the previous derivation would fail exactly at universal quantifier introduction rule: the parameter would occur in the undischarged assumption P(x), so it would not be fresh.

Equality introduction rule is reflexivity; equality elimination rule permits substitution of equals in a formula:
Γ⊢t=t​ (=I),Γ⊢ϕ(t)Γ⊢s=tΓ⊢ϕ(s)​ (=E).​
(33)
Terms substituted into ϕ must be free for substitution, so no variable becomes captured. The notation ϕ(s),ϕ(t) means substitution into the same designated free variable positions of one formula; other occurrences may remain fixed. These rules express first-order equality without assuming symmetry or transitivity as additional axioms.

 4  | P(a) → P(b)                                    →-intro 2–3
 5  | a = a                                          =-intro
 6  | b = a                                          =-elim 1,5; φ(u) := (u = a)
 7  | | P(b)                                         assumption
