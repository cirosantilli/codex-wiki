Normalize the amount to r=kmodN, with 0≤r<N; negative k then naturally denotes a right rotation. When r=0, return without touching the elements. Otherwise the map j↦(j+r)modN has g=gcd(N,r) disjoint permutation cycles, each of length N/g. Use representatives 0,…,g−1:
PROCEDURE RotateLeft(k: INTEGER);
VAR r, g, x, y, h, s, j, next: INTEGER; saved: T;
BEGIN
  r := k MOD N;
  IF r # 0 THEN
    x := N; y := r;
    WHILE y # 0 DO h := x MOD y; x := y; y := h END;
    g := x; s := 0;
    WHILE s < g DO
      saved := a[s]; j := s;
      IF j >= N-r THEN next := j-(N-r) ELSE next := j+r END;
      WHILE next # s DO
        a[j] := a[next]; j := next;
        IF j >= N-r THEN next := j-(N-r) ELSE next := j+r END
      END;
      a[j] := saved; s := s+1
    END
  END
END RotateLeft;
The conditional calculation of next implements addition modulo N without first forming a possibly overflowing j+r. Oberon's MOD with positive divisor supplies the nonnegative remainder. The first loop is the Euclidean algorithm, with loop invariant gcd(x,y)=gcd(N,r) and decreasing nonzero remainder.
For the outer loop, cycles with representatives below s are complete and every other cycle retains its original values. In one cycle, write ct​=(s+tr)modN. The inner loop invariant is saved = A[s], j=ct​, and a[cu​]=A[cu+1​] for 0≤u<t, with the remaining sources still untouched. When the next index returns to s, the saved value closes the cycle. The cycle length is N/g: writing N=gN′ and r=gr′ with gcd(N′,r′)=1, the least positive t with tr≡0(modN) is N′. Each residue class modulo g is one cycle, justifying the chosen representatives.
Every element is read once and written once: 2N element accesses, compared with 2Nk for k>1 repetitions of part (b). The zero rotation uses none. The running time is O(N) and auxiliary space is constant; the original array A is proof notation, not a copy made by the program.
