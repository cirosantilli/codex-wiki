Use four request bits r0​,r1​,r2​,r3​ and four grant bits g0​,g1​,g2​,g3​. A high ri​ requests service for the coming allocation period, and a high gi​ identifies the requester granted the resource during the current period. At most one grant may be high. An all-zero grant vector means idle. The synchronous sequential circuit also has a clock and an initialization signal.
Requests are sampled at a clock edge; the resulting allocation appears during the following cycle. This fixes the Moore machine timing convention: current grants depend on the stored state, rather than combinationally on requests that can change within the cycle.

Store three state bits: a two-bit index L∈{0,1,2,3} identifying the most recent recipient, and a valid bit V indicating whether that recipient is receiving service in the current cycle. Then
gi​=V∧[L=i].
(1)
When no requests are present at a decision edge, clear V but preserve L. Preserving L implements round-robin arbitration with idle memory. Four possible last recipients each have an active and an idle state, giving eight states. The four idle states have equal outputs but different future priorities, so they cannot all be merged. One valid reset is L=3,V=0, which gives requester zero first priority at startup.

For a single read-only memory implementing both the next-state and output equations, the address has four request bits plus three present-state bits. Each word contains three next-state bits and four grant bits. Hence
27 words×7 bits=128×7=896 bits.​

An input-output-bound process spends much of its time waiting for input-output, often with short CPU bursts between waits. A CPU-bound process spends most of its time doing useful CPU computation, with comparatively little blocking. These descriptions concern the bottleneck in the workload; an I/O-bound process still needs CPU time.

b OurBigBook.com
With nonpreemptive scheduling, a running process retains the processor until it finishes its current CPU burst, blocks or voluntarily yields. With preemptive scheduling, the operating system may suspend a runnable process and select another one.
Time-slice preemption needs a hardware timer delivering an interrupt after bounded execution time, so control returns to the scheduler even if the running program never yields. Saving and restoring the execution context then lets the interrupted process resume later. The timer mechanism should remain under operating-system control.

Use k clocked processor registers, each storing an n-bit word, two independent combinational read ports and one synchronous write port. Each address requires a=⌈log2​k⌉ bits. The read addresses select two k-to-one multiplexers, each n bits wide. A write-address binary decoder combines its selected line with the global write enable to form the individual enables:
wei​=RegWrite∧[wa=i].
(11)
At the active clock edge, register i captures the common write data if wei​=1, otherwise retaining its word. Reads return the currently stored words selected by their respective addresses. For non-power-of-two k, unused address codes need a specified harmless implementation. A simultaneous read and write of one address follows the chosen edge/read timing; an additional forwarding circuit would be needed if a different bypass convention were required.

On a finite domain {d1​,…,dm​}, ∃xϕ(x) says that at least one of ϕ(d1​),…,ϕ(dm​) holds. A derivation from a fresh generic witness shows how to obtain the same conclusion κ whichever witness works, just as disjunction elimination handles all cases. If empty domains were allowed, the existential premise would be false there; ordinary first-order semantics normally assumes a nonempty domain.
Writing the other open assumptions as Γ, the existential elimination rule in sequent form is
Γ,∃xϕ(x)⊢κΓ,ϕ(v)⊢κ​.
(47)
Combining this with a derivation of the existential premise gives the displayed natural-deduction version. The eigenvariable condition requires v to occur free in neither Γ nor κ, with capture-free substitution in ϕ(v). It is a temporary name for an unspecified witness, not information about a chosen object. Without freshness, the invalid inference ∃xP(x)⊢P(v) would identify an arbitrary named object with that witness. The witness escape restriction prevents this error.
