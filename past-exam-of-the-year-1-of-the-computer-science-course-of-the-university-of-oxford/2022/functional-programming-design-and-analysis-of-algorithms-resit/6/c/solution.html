This version of Kadane's algorithm, named for Joseph Born Kadane, permits the empty subsequence. For j≥1, let Ej​ be the maximum of zero and the weight of a contiguous subsequence ending exactly at position j. Let Bj​ be the best weight anywhere in the first j positions. Use
E0​=B0​=0,Ej​=max(0,Ej−1​+aj​),Bj​=max(Bj−1​,Ej​).​
(8)
A segment ending at j either extends one ending at j−1 or starts at j; the zero candidate permits discarding a negative predecessor and the empty answer. Any best segment of the first j positions either ends at j or already occurs in the first j−1. These two decompositions prove the dynamic programming equations by induction.
Here is an implementation returning endpoints, using zero-based indexing:
best_segment(a):
    end_weight = best_weight = 0
    start = best_lo = best_hi = 0
    for j in range(len(a)):
        trial = end_weight + a[j]
        if trial <= 0:
            end_weight = 0
            start = j+1
        else:
            end_weight = trial
        if end_weight > best_weight:
            best_weight = end_weight
            best_lo, best_hi = start, j+1
    return (best_lo, best_hi, best_weight)
There is exactly one addition per input element, hence n additions and O(n) comparisons. Auxiliary storage is O(1). The all-negative case retains interval [0,0) and weight zero. The example returns [3,6) and weight 8, hence the desired contiguous subsequence.
