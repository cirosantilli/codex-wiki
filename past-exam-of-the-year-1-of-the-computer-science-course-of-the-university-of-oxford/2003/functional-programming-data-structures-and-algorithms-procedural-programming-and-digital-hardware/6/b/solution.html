In binary long division, first double the divisor until it exceeds x, then halve it successively. Keep p = 2^j and d = y*p, so no exponentiation is needed inside a loop:
q := 0; r := x;
j := 0; p := 1; d := y;
WHILE d <= x DO
  d := 2*d;
  p := 2*p;
  j := j+1
END;
WHILE j > 0 DO
  d := d DIV 2;
  p := p DIV 2;
  j := j-1;
  IF r >= d THEN
    r := r-d;
    q := q+p
  END
END
The first loop invariant is q=0, r=x, j≥0, p=2j and d=y2j>0. Every doubling preserves it. For integer inputs, after at most 1+⌊log2​(x/y)⌋ iterations when x≥y, d > x; if x<y, this loop has no iterations. The unbounded increase of y2j proves termination. Equivalently, one can use the decreasing nonnegative loop variant max(0,⌊log2​(x/d)⌋+1) while the guard is true.
At the top of the second loop the loop invariant is
x=qy+r,0≤r<d=y2j,p=2j,q≥0,j≥0.​
(28)
It holds on entry because d > x = r. Suppose the old d is 2d′ and the old p is 2p′. After the three halving assignments, d′=yp′ and the old remainder satisfies 0≤r<2d′. If r<d′, the desired new bound already holds. Otherwise subtracting d′ leaves 0≤r−d′<d′ and adding p′ to q preserves x=qy+r because yp′=d′. The divisions by two are exact: before each halving, j > 0 makes both p and d even.
The loop variant j decreases by one each iteration. At exit j=0, so d = y and the loop invariant gives the required remainder bound. The work per iteration is constant in the unit-cost model, and the two loops have the same number of iterations. For 0<y≤x,
T(x,y)=O(1+log(x/y))=O(log(x+1)).​
(29)
The case x<y, including x=0, takes constant time. These are arithmetic-operation counts with sufficient range for the doubled values; arbitrary-precision arithmetic incurs additional bit complexity. If the inputs were arbitrary positive real numbers, the uniform bound would depend on x/y rather than only x; the stated O(logx) is the conventional integer division interpretation.
