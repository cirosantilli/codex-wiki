Use missing-value search by deficient value intervals: halve the candidate value interval, and apply array partitioning only to the array segment whose entries lie in that interval.
def missing(): Int = {
  require(N < Int.MaxValue)
  var lo = 0; var hi = N + 1
  var l = 0; var r = N
  while (hi - lo > 1) {
    val p = lo + (hi - lo) / 2
    val k = partition(l, r, p)
    if (k - l < p - lo) {
      hi = p; r = k
    } else {
      lo = p; l = k
    }
  }
  lo
}

For the time complexity, after t splits the width is at most ⌈(N+1)/2t⌉, and the scan length is smaller than that width. Summing over the O(log(N+1)) levels gives a geometric series plus logarithmic overhead, hence O(N+1) overall, conventionally O(N) for N≥1. This proof bounds the retained occurrence count by the retained value width; it does not assume that each array partitioning splits the number of occurrences in half. The N=0 case returns zero immediately.
