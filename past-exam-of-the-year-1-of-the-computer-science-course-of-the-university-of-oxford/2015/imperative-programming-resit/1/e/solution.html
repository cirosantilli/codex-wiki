The VAR marker passes a reference parameter, so every recursive call accesses the same array without copying it. Read-only access does not make copying necessary. Under the examination's value parameter convention, omitting VAR copies the whole actual array, not merely the selected segment u[a..b).
If its length is L, the Θ(n+1) calls therefore cost Θ(L(n+1)) for n=b−a. For a whole-input construction, L=n>0:
Θ(n) with VAR,Θ(n2) with whole-array value copying.​
(5)
Copying only the shrinking segments would instead lead to Θ(nlogn), but that is a different parameter passing model from passing the same actual array on every call.
