For the product order, reflexivity follows from ai​≤ai​ in every coordinate. If a⪯b and b⪯a, the antisymmetric relation axiom for the usual real order gives ai​=bi​ for every i, hence a=b. If a⪯b⪯c, transitivity in each coordinate gives ai​≤ci​, hence a⪯c. Thus this is a partial order.
For n≥2, the vectors (1,0,0,…) and (0,1,0,…) are incomparable: each has a coordinate larger than the corresponding coordinate of the other. It is not a total order for n≥2. The dimension qualification matters: for n=1 this is the usual total order on R, so the printed non-totality claim needs the implicit assumption n≥2.

For the pointwise order on real polynomials, p(x)≤p(x) proves reflexivity. Two opposite inequalities imply p(x)=q(x) for every real x; the polynomials are therefore equal, proving the antisymmetric relation axiom. Chaining the inequalities at every x proves transitivity.

The floor function is constant at j on the four consecutive integers 4j,4j+1,4j+2,4j+3. Consequently the partition of a set is {{4j,4j+1,4j+2,4j+3}:j∈N}. Different blocks are disjoint and every nonnegative integer has exactly one quotient and remainder upon division by 4.

Use bisection on f′ when the derivative is cheap and a bracket f′(a)<0<f′(b) is easy to obtain. For a differentiable convex function, f′ is nondecreasing, so such a bracket locates a global minimum, allowing a flat minimizing interval. Without convexity, first isolate a region containing the desired local minimum; arbitrary stationary points need not be minima.
Use golden-section search when reliable function values are available but derivatives are unavailable or expensive. It needs a bracket on which the objective is a unimodal function, commonly found by three ordered points whose middle value is below the two outer values. Those inequalities alone do not prove that the objective is a unimodal function. A convex function supplies the needed shape; for a nonconvex objective, isolate an interval on which it is a unimodal function.
Both methods have linear convergence of bracket width. Bisection contracts the width by 1/2 per new derivative evaluation. Golden-section search contracts it by (5​−1)/2≈0.618 per new function evaluation after initialization, reusing one earlier value. Choose by evaluation cost and bracket availability as well as this contraction factor: comparing iteration counts alone can misidentify the faster method.

Convexity of the components of a vector field is not the decisive criterion for a root-finding problem. Neither method becomes globally reliable merely because each component is convex.
Prefer the Newton root-finding iteration when the Jacobian matrix is available accurately and at reasonable cost. Solve J(xk​)sk​=−f(xk​) rather than explicitly forming an inverse matrix. Near a root with a nonsingular Jacobian matrix and a locally Lipschitz Jacobian matrix, the usual exact iteration has quadratic convergence.
Prefer Broyden's method when evaluating or differentiating the vector field makes a fresh Jacobian matrix expensive. It learns an approximate Jacobian matrix through secant updates using function differences. Under appropriate local regularity and initialization assumptions it has superlinear convergence, generally slower asymptotically than the quadratic convergence of exact Newton steps, but often with cheaper iterations.[ref]
Dimension matters through storage and solves. A full dense Newton factorization costs order d3 arithmetic operations; a dense Broyden approximation uses order d2 storage, and maintained inverse or factorization updates can cost order d2. A naive fresh dense solve can still cost order d3. Sparsity can favour Newton, while very large d can make either dense formulation unsuitable. Neither local rate guarantees convergence from an arbitrary starting point.

iii OurBigBook.com
Gradient descent uses only the current gradient and a suitable step size; its additional storage is order d. It is attractive for very large d or when low per-iteration cost matters most. For a smooth strongly convex function, standard step choices give linear convergence, with a rate sensitive to the condition number. Mere convexity gives a global-minimum interpretation but does not alone imply a linear rate; for nonconvex objectives the usual guarantee concerns stationary points.
BFGS uses successive gradients to update an approximation to inverse curvature, incorporating information that can correct poor scaling. Full BFGS uses order d2 storage and update work. With suitable line searches and local smoothness and positive-curvature assumptions near a nondegenerate minimum, it has superlinear convergence. This often favours it in moderate dimensions when gradients are not extremely cheap relative to the extra work.
Neither gradient descent nor BFGS requires an explicitly evaluated Hessian matrix. Thus an expensive Hessian matrix is compatible with both, rather than a reason to reject BFGS. If an accurate Hessian matrix and its factorization are exceptionally cheap, Newton's method in optimization becomes an additional reasonable option. Convexity helps identify a stationary point as a global minimum; without it, both methods need suitable descent and curvature safeguards. The BFGS update learns curvature from the Quasi-Newton secant equation.[ref]
