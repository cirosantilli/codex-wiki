Generate the fractional bits by repeated doubling, keeping only the unconverted residual:
res(digits) = '.'
var fraction = dec - int_part.toDouble
var out = digits + 1
while (out < res.length) {
  fraction = 2.0 * fraction
  if (fraction >= 1.0) {
    res(out) = '1'
    fraction -= 1.0
  } else res(out) = '0'
  out += 1
}

Doubling exposes the next digit, and subtracting that digit leaves the next residual in [0,1). This proves preservation. The loop variant is res.length−out. The loop fills the whole suffix, even when the residual has become zero; subsequent bits are zero. There is one multiplication per output bit. With F=res.length−digits−1 fractional positions, the result is truncated, with exact-arithmetic error 0≤dec−value(res)<2−F. An integer has an all-zero suffix. No rounding-up step is performed.
