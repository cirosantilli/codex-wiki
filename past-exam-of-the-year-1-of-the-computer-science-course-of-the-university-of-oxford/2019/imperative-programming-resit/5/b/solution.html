Use the row boundary and cache its sum. The restriction on the initial total makes the fixed Int return type of Count meaningful; Display separately checks the requested single-digit coordinate range.
class Chomps(N: Int) {
  require(N > 0 && N.toLong * N.toLong <= Int.MaxValue.toLong)
  private val row = Array.fill(N)(N)
  private var remaining = N * N

  def Count(): Int = remaining

  def Legal(x: Int, y: Int): Boolean =
    0 <= x && x < N && 0 <= y && y < N && x < row(y)

  def Move(x: Int, y: Int): Unit = {
    require(Legal(x, y))
    var j = y
    while (j < N) {
      val next = math.min(row(j), x)
      remaining -= row(j) - next
      row(j) = next
      j += 1
    }
  }

  def Display(): Unit = {
    require(N < 10)
    var y = N - 1
    while (y >= 0) {
      print(y.toString + " ")
      var x = 0
      while (x < N) {
        print(if (x < row(y)) "* " else "  ")
        x += 1
      }
      println()
      y -= 1
    }
    print("  ")
    var x = 0
    while (x < N) {
      print(x.toString + " ")
      x += 1
    }
    println()
  }
}
The additional representation invariant is remaining=∑j=0N−1​row(j). It initially holds. For Move, write row0​ for the boundary at entry. The loop invariant says that rows before y are unchanged, rows from y through j−1 equal min(row0​(i),x), rows from j onwards still equal row0​(i), and remaining equals the sum of the current entries. The loop variant is N−j. Each iteration subtracts exactly the newly removed number of cells from the cache. At exit all affected rows are truncated as required, and the nonincreasing boundary is restored. During a partially completed update it need not be nonincreasing; only the stated loop invariant, not the full externally visible representation invariant, is required internally.
For Display, the outer loop invariant says that exactly the rows with indices greater than y have been printed correctly; its loop variant is y+1. The inner loop invariant says that the current row's first x cells have been emitted correctly; its loop variant is N−x. The final labels loop has the same decreasing loop variant, and prints exactly the first x column labels before each iteration. Short-circuit evaluation in Legal checks both coordinates before indexing. An illegal Move fails before changing the board.
