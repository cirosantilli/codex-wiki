Let the abstract state be the set B of occupied coordinate pairs. For the Boolean array, the abstraction function is α(occupied)={(x,y):occupied(y)(x)}. Its representation invariant requires an N×N Boolean array and the downward-closure property
(x,y)∈B ⟹ (i,j)∈Bwhenever 0≤i≤x, 0≤j≤y.
(8)
Thus B is an order ideal for the coordinatewise partial order. Removing an upper-right rectangle preserves this property. The empty set is allowed after the losing move.
For the row-boundary array, the abstraction function and representation invariant are
α(row)={(x,y):0≤y<N, 0≤x<row(y)},N≥row(0)≥⋯≥row(N−1)≥0.
(9)
The array has length N. Removing at (x,y) replaces each row(j) for j≥y by min(row(j),x). Earlier rows are unchanged. This both implements the abstract removal and preserves the nonincreasing boundary.
Without a cached count, the Boolean representation takes Θ(N2) for Count, O(1) for Legal, O(N2) worst-case for Move, and Θ(N2) for a full-grid Display. The boundary representation takes Θ(N) for Count, O(1) for Legal, O(N) worst-case for Move, and Θ(N2) for the same full-grid Display. Their space complexities are respectively Θ(N2) and Θ(N). A scalar cached total makes Count O(1) in either representation if each move updates it consistently. The implementation below uses that cache with the boundary array, so it achieves constant-time Count and Legal, linear worst-case Move, and linear storage. Full-grid output still takes quadratic time because it emits quadratic many cell positions.
