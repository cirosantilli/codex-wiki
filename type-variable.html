Type variable (α)

 Home Computer science Programming language Type system
OurBigBook.com Words: 443 Articles: 3
A type variable is a placeholder for a type. In a function type α→α, the repeated type variable requires the argument and result types to agree; α→β does not impose that agreement. A type substitution replacing α by int changes α→α to int→int everywhere within that instance.
For the identity function written as the lambda abstraction λx.x, assume x:α in the body. Looking up x gives result type α, so the abstraction rule gives λx.x:α→α. In the pure Hindley-Milner type system, let identity = λx.x in ... gives identity the type scheme ∀α.α→α by let polymorphism. Each use receives fresh type variables: identity 3 chooses int for its instance, and identity true chooses bool for a separate instance. These choices do not change the original type scheme.
For example, let identity = λx.x in let a = identity 3 in identity true is valid and has type bool. By contrast, (λf. let a = f 3 in f true) (λx.x) is rejected by the Hindley-Milner type system: the lambda abstraction binds f to one monomorphic function type. The first call requires its argument type to be int, and the second requires that same type to be bool. Naming the first result with let a does not generalize f. The distinction makes reusable code possible while keeping the assumptions about a supplied argument consistent.
