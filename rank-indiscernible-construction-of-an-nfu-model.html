Rank-indiscernible construction of an NFU model

 ... Set theory New Foundations New Foundations with urelements Type-shifting automorphism Rank-shifting automorphism construction of NFU Rank-shifting NFU model with explicit set predicate
OurBigBook.com Words: 807
NFU has a unary predicate S for sets, atoms have no members, extensionality applies to sets, and comprehension applies to every stratified formula. A stratification assigns integer types to variables so that equality uses equal types and x∈y requires type(y)=type(x)+1. A unary set predicate adds no type difference.
Start with the actual set structure B=(Vω+ω​,∈). This structure satisfies extensionality and every pure-membership separation instance: the subset defined in a set a of rank below ω+ω still has rank below ω+ω. We do not assert that B satisfies replacement or all of ZFC. Expand it by Skolem functions. In it use the sequence of rank objects Vω+n+6​, n<ω. For two such objects d<e in sequence order, we have
d⊊e,∀x(x⊆d⟹x∈e),
(2)
with quantifiers in B. The second statement holds because every subset of Vα​ belongs to Vα+1​, and the later rank is at least α+1.
Introduce constants di​, i∈Z, and require them to be order indiscernibles in the Skolem language, satisfying these two assertions whenever i<j. Also require Vω+5​⊆di​ for every i; this fixed rank object is first-order definable in B. Every finite part of these requirements together with Th(B∗) is satisfiable: color finite increasing tuples of the original rank sequence by the truth values of the finitely many formulas mentioned, and use Ramsey's theorem to get a homogeneous subsequence. The rank assertions hold for every increasing tuple there. The compactness theorem gives a model of the full theory. In its Skolem hull N generated by the di​, the integer shift extends to an automorphism j with j(di​)=di+1​, by the term-transport proof of the Ehrenfeucht-Mostowski theorem. Thus N still satisfies extensionality and all pure-membership separation instances, and
N⊨∀x(x⊆di​⟹x∈di+1​)(i∈Z).
(3)
This is a set-sized first-order model; no satisfaction predicate for a proper-class universe is being assumed.
Externally let Di​={x∈N:N⊨x∈di​}. The automorphism bijects Di​ onto Di+1​. Interpret a typed structure with sort i equal to Di​. At sort i+1, declare y a set exactly when N⊨y⊆di​; otherwise it is an atom. Define adjacent-sort membership by
x∈i​y⟺N⊨(y⊆di​ ∧ x∈y).
(4)
The guard is necessary: a typed atom might have some ordinary N-members in Di​, and those must not become its typed members. Set-extensionality follows from extensionality in N, because the ordinary members of a typed set all lie in Di​. For any typed formula on sort i, its quantifiers can be restricted to the corresponding dl​, its set predicates replaced by subset assertions, and its memberships replaced by the guarded relation. This is an ordinary pure-membership formula of N with finitely many parameters. Separation gives its extension X⊆di​, and the displayed closure assertion gives X∈di+1​. It is therefore a typed set witnessing comprehension. The automorphism shifts these sorted domains and preserves the set flags and guarded memberships.
Collapse the types onto D0​. Define
S(y)⟺N⊨j(y)⊆d0​,xEy⟺S(y) ∧ N⊨x∈j(y).
(5)
Objects not satisfying S have no E-members. If two sets have the same E-members, their images under j are subsets of d0​ with the same ordinary members, so are equal by extensionality of N; injectivity of j gives equality of the original objects.
To verify every stratified comprehension instance, assign a variable v its stratification type t(v) and translate its value a∈D0​ to jt(v)(a)∈Dt(v)​. Equality is preserved. An atomic E(x,y) translates to the guarded adjacent-sort membership because t(y)=t(x)+1; the unary predicate S(y) translates to jt(y)(y)⊆dt(y)−1​. Induction on formulas, using the domain bijections for quantifiers, preserves truth. If the free variable x has type t, typed comprehension produces its extension X⊆dt​, with X∈dt+1​. Put b=j−(t+1)(X)∈D0​. Then S(b) holds, and for every a∈D0​,
aEb⟺N⊨jt(a)∈X⟺φ(a,p​).
(6)
This is exactly the required NFU set. No formula containing the external automorphism j has been used in a separation or comprehension scheme; j only transports values after the pure formula is formed.
The construction also permits the usual infinity requirement. The ordinary ω and its successor graph f are definable in N, hence fixed by j, and lie below Vω+5​, so belong to all the required domains. Under E, the members of ω are still its ordinary N-members. The new Kuratowski pair satisfies
⟨x,y⟩E​=j−2(⟨x,y⟩N​).
(7)
Since j(f)=f, membership of this pair in f under E is equivalent to ⟨x,y⟩N​∈f. Thus f is an internal injection of ω into itself omitting zero, giving a Dedekind-infinite set.
We have built a model of NFU, with infinity if it is included in the formulation, in ordinary ZFC metatheory:
ZFC proves the existence of a model of NFU.​
(8)
In particular Con(ZFC)⇒Con(NFU). This proof does not assume Con(ZFC) as an additional internal axiom: its starting structure is the set Vω+ω​, not a model of ZFC.
