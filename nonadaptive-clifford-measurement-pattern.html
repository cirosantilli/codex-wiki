Nonadaptive Clifford measurement pattern

A path graph state simulates a sequence of Clifford gates J(αj​), αj​∈{0,π/2}, using fixed equatorial qubit measurement bases on successive path vertices. Let sj​ be raw outcomes, tj​=2αj​/π∈{0,1}, and start the Pauli frame at a0​=b0​=0. Matrix commutation and J(−π/2)=XJ(π/2) give
aj​=sj​⊕bj−1​⊕tj​aj−1​,bj​=aj−1​.
(2)
Induction shows the final unmeasured state differs from the ideal circuit output by Xam​Zbm​, up to global phase. A final computational basis result d is corrected to d⊕am​. All bases are fixed, and projectors on distinct vertices commute, so all measurements, including the final one, can occur in a single layer. The frame recurrence is classical outcome processing, not quantum feed-forward.
