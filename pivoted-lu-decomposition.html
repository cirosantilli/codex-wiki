Pivoted LU decomposition (PA=LU)

 ... Mathematics Area of mathematics Analysis Numerical analysis Numerical linear algebra LU decomposition
OurBigBook.com Words: 275
We fix the convention PA=LU: the permutation matrix P acts on the rows of A, and the same row ordering must be applied to b before the Triangular solves for LU decomposition. Equivalently, A=PTLU, since P−1=PT. LAPACK documents its factors as A=PLU instead, so check the defining equation rather than just the letter P.[ref] Partial pivoting selects the largest absolute candidate in the current column, among rows k,…,n, before forming elimination multipliers.[ref]
A zero first pivot element does not imply a singular matrix. For example,
A0​=(02​13​),detA0​=−2,P=(01​10​),PA0​=L(10​01​)​​U(20​31​)​​.

Unpivoted Gaussian elimination would divide 2 by zero. Indeed, no A0​=LU with a unit lower triangular matrix L exists: u11​=0 would force (LU)21​=l21​u11​=0, contradicting (A0​)21​=2. One row interchange resolves the obstruction. For b0​=(1,5)T, use Pb0​=(5,1)T; back substitution then gives x=(1,1)T. Using the original b0​ with these factors would solve a different linear system.
Partial pivoting bounds each elimination multiplier by one in absolute value in exact arithmetic. This helps control roundoff error, but intermediate entries can still grow; it is not an unconditional guarantee of numerical stability for every matrix.[ref] It also does not remove the original problem's condition number. For the diagonal matrix D=diag(1,ε) with 0<ε<1, the condition number in the Euclidean norm is κ2​(D)=1/ε. Row permutations preserve this condition number, because they preserve Euclidean norms. Even an exact solve changes from (1,1)T to (1,1+η/ε)T when the right-hand side changes from (1,ε)T to (1,ε+η)T. This sensitivity is a property of the linear system, not a zero-pivot element failure.[ref]
