Von Mangoldt function (Λ(n))

 Home Mathematics Area of mathematics Number theory Arithmetic function
OurBigBook.com Words: 763 Articles: 17
The Von Mangoldt function is Λ(n)=logp when n is a positive power of a prime number p, and is zero otherwise.
