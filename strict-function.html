Strict function (f(⊥)=⊥)

 Home Computer science Programming language Functional programming
OurBigBook.com Words: 51
A function is strict in an argument if replacing that argument by the bottom value makes the result bottom. This semantic property does not prescribe evaluation order: a function that always diverges is strict without inspecting its argument. Strictness of a structured argument also does not mean evaluation of every component.[ref]
