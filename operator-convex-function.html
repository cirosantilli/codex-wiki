Operator convex function

 Home Mathematics Area of mathematics Analysis Real analysis Convex function
OurBigBook.com Words: 46 Articles: 1
A real function f on an interval I is operator convex when
f(λA+(1−λ)B)≤λf(A)+(1−λ)f(B)
(43)
in the Loewner order for all Hermitian operators A,B with spectra in I and every 0≤λ≤1.
