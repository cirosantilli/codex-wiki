Channel code (c:{1,…,m}→Xn,d:Yn→{1,…,m})

 Home Mathematics Area of mathematics Algebra Coding theory Channel coding
OurBigBook.com Words: 315 Articles: 2
A deterministic fixed-length channel code consists of a channel encoder c and a channel decoder d. It represents m possible messages by length-n input codewords for a communication channel, and estimates the message from the resulting output word. Its code rate is (log2​m)/n bits per channel use. The maximal decoding error probability requires reliable recovery of every message, while an average error criterion depends on the chosen message probability distribution.
