A semantic Gödel fixed point need not be canonical

 ... Foundations of mathematics Mathematical logic First-order logic First-order theory Diagonal lemma Gödel sentence
OurBigBook.com Words: 66
Assuming PA is consistent, the theory S=PA+¬ConPA​ is consistent by second incompleteness. Its false axiom G=¬ConPA​ is provable, so the standard semantic biconditional G↔¬PrS​(┌G┐) is true with both sides false. Thus a true biconditional alone does not make an arbitrary sentence a true canonical Gödel sentence. A canonical Pi-1 construction adds the necessary syntactic or sound-base information. Truth, internal equivalence and canonical construction must be distinguished.
