Root subsystem (Ψ⊆Φ)

 ... Lie theory Lie algebra Semisimple Lie algebra Cartan subalgebra Root-space decomposition Root system
OurBigBook.com Words: 82
A root subsystem of a root system Φ is a subset that is itself a root system in its real span. In particular, if a subspace F is spanned by roots, Φ∩F is a full root subsystem: root reflections in its roots preserve both Φ and F. Reflection-generated subsystems need not contain every ambient root in their span. A pair is a simple root basis only when every subsystem root has integral coordinates of one sign in that pair; merely choosing two independent roots is insufficient.
