Channel feedback

 Home Mathematics Area of mathematics Probability and statistics Information theory Communication channel
OurBigBook.com Words: 52
Information about earlier received outputs made available to the channel encoder while choosing subsequent inputs. For repeat-until-success coding over an erasure channel, an erasure report tells the sender to repeat the current bit, while a success report tells it to advance. A forward code rate calculation must specify whether this return communication is supplied freely or included in the resource count.
