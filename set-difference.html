Set difference (A∖B)

 Home Mathematics Area of mathematics Foundations of mathematics Set theory Set
OurBigBook.com Words: 29
The difference consists of the elements of A not belonging to B. In ZF it exists by axiom schema of separation. It gives complements relative to a fixed tuple domain in finite relation closure for set-theoretic coding.
