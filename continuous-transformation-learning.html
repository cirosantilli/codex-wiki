Continuous transformation learning

 ... Area of mathematics Probability and statistics Statistical model Statistical modelling Statistical learning Unsupervised learning
OurBigBook.com Words: 66
Learning transformation-tolerant representations by combining input-feature overlap, current-activity Hebbian learning and synaptic competition. A new view partly activates an output already learned for an overlapping view, then strengthens its new features onto that output. Chains of overlapping views can link more distant transformations without an explicit temporal trace; dense enough overlap and suitable competition remain conditions.[ref]
