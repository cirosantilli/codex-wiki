Jacobi method

 ... Mathematics Area of mathematics Analysis Numerical analysis Numerical linear algebra Stationary iterative method for a linear system
OurBigBook.com Words: 1k Articles: 11
Writing A=D+L+U, where D is diagonal and L,U are strictly triangular, the Jacobi iteration is
x(k+1)=D−1(b−(L+U)x(k)).
(115)
The Jacobi method solves a linear system by updating every coordinate from the same old vector. It requires every diagonal entry aii​ to be nonzero. Isolating coordinate i in row i gives the simultaneous rule
xi(k+1)​=aii​bi​−∑j=i​aij​xj(k)​​,B=−D−1(L+U)=I−D−1A.
(116)
Here B is the iteration matrix. A sweep computes a complete new vector before replacing the old one, so its coordinate updates can run independently.[ref]
For a sparse matrix, a sweep needs work proportional to the stored nonzero entries, while Gaussian elimination may create fill-in. The Jacobi method is therefore a simple starting point for large linear systems, and the weighted Jacobi method supplies a useful building block of a multigrid method. Its beauty is that a local row correction becomes a global eigenvalue question: the convergence criterion for a stationary iteration is exactly ρ(B)<1.
