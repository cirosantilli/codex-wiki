Transverse mass (mT2​=2pTℓ​pTmiss​(1−cosΔϕ))

 Home Physics Particle detection Transverse momentum Missing transverse momentum
OurBigBook.com Words: 188
For a two-body W boson decay into a charged lepton ℓ and a neutrino, neglect both daughter masses and use natural units c=1. Let Δϕ be the angle between the daughter transverse momenta. Identifying the missing transverse momentum with the neutrino's gives
mT2​=2pTℓ​pTmiss​(1−cosΔϕ).
(53)
This observable uses no pzν​. The 1983 UA1 experiment paper already used transverse mass as a lower bound on parent mass, before making additional decay-model assumptions for a mass estimate.[ref]
The bound follows directly from the energy–momentum relation. For each massless daughter write its four-momentum, using rapidity y and azimuth ϕ, as
pμ=(pT​coshy, pT​cosϕ, pT​sinϕ, pT​sinhy).
(54)
Using the Minkowski inner product with positive time sign, p2=E2−∣p∣2, the two daughter four-momenta give the true parent invariant mass M:
M2=2pTℓ​pTν​[cosh(yℓ​−yν​)−cosΔϕ],M2−mT2​=2pTℓ​pTν​[cosh(yℓ​−yν​)−1]≥0.
(55)
Since coshu≥1, mT​≤M, with equality at equal daughter rapidities when both transverse momenta are nonzero. Thus the unmeasured longitudinal information can enlarge the true invariant mass, but cannot lower it below this ideal transverse mass.
For an original example, stipulate pTℓ​=pTν​=40GeV and Δϕ=π. Then mT​=80GeV. Equal rapidities give M=80GeV; choosing yℓ​−yν​=1 with exactly the same transverse readout gives M=80cosh(1/2)≃90.210GeV. One measured transverse configuration therefore permits different true parent masses.
