Pointed complete partial order (⊥≤x)

 ... Foundations of mathematics Set theory Set Partially ordered set Complete partial order Directed-complete partial order
OurBigBook.com Words: 236 Articles: 4
A directed-complete partial order with a least element. Here directed suprema concern nonempty directed sets. Morphisms are Scott continuous maps and need not preserve the least element. Requiring strictness would change the category and its cartesian-closure argument.
