Fermat test example

 Home Mathematics Area of mathematics Number theory Fermat little theorem
OurBigBook.com Words: 307
For the Fermat primality test, a passing base satisfies an−1≡1(modn). Passing proves only this modular congruence, not that n is a prime number. An odd composite number that passes a coprime base is a Fermat pseudoprime to that base. A Carmichael number passes every coprime base, so even testing all the units would not certify that n is a prime number. [ref]
This small table uses only the bases 2,3,5,11, each reduced modulo n first. A numeric entry is an−1modn: one passes, while any other numeric entry gives a Fermat witness. A "factor" entry records a proper greatest common divisor and stops before modular exponentiation. The prime/composite classification is independently established by trial division or the displayed prime factorization, not by the passing entries. These four bases are illustrative, with no asserted universal coverage or error probability.

For 341=11⋅31, gcd(2,341)=1 and 210=1024=3⋅341+1, so 2340=(210)34≡1(mod341). Yet gcd(3,341)=1 and 3340≡56(mod341), so three is a Fermat witness. One coprime base passes and another fails: being a Fermat pseudoprime depends on the base. Choosing eleven instead reveals the proper factor through gcd(11,341)=11.
For 561=3⋅11⋅17, every coprime base passes: each of 2,10,16 divides 560, so Fermat's little theorem gives a560≡1 modulo each prime factor; the Chinese remainder theorem combines the three modular congruences. Equivalently, the Carmichael function gives λ(561)=80∣560. Bases two and five have greatest common divisor one and pass, but gcd(3,561)=3, gcd(11,561)=11 and gcd(17,561)=17 expose factors. The qualification "coprime" is therefore crucial even for a Carmichael number.
The Fermat primality test is useful because a Fermat witness can prove compositeness using repeated squaring without finding a factor. Its failure to certify a passing candidate motivates stronger primality testing methods such as the Miller-Rabin primality test.
