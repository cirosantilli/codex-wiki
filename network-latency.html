Network latency

 Home Computer science Computer network
OurBigBook.com Words: 74 Articles: 1
Network latency is the delay associated with communication over a network, distinguished from the rate at which data can be transferred. Moving a delivery endpoint closer to demand can reduce some path delay, but does not by itself establish application correctness or independent control.
