The Cantor-Schröder-Bernstein theorem states that injections A↪B and B↪A imply a bijection A≅B.
Let c=∣R∣ and D={S⊆R:S is dense in R}. Clearly ∣D∣≤2c. For the reverse bound, let C be the usual Cantor set, of cardinality c. It is closed with empty interior, so D=R∖C is dense. The map
P(C)⟶D,A⟼D∪A
(20)
is injective, because A=(D∪A)∩C. Applying the Cantor-Schröder-Bernstein theorem gives
∣D∣=2c=22ℵ0​.​
(21)
One can see ∣C∣=c by coding binary sequences as ternary expansions using only digits zero and two, together with the usual ∣{0,1}ω∣=∣R∣. The same fixed D works for all subsets. This is the cardinality of the family of dense subsets of the reals.
