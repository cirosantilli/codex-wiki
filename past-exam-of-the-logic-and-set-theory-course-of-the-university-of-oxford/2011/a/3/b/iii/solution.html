In a two-element first-order structure, ϕ=∀x1​(x0​=x1​) is false for every first-order variable assignment. Blind substitution of x1​ for x0​ yields ∀x1​(x1​=x1​), which is true. This does not express the original property evaluated at the value of the inserted term: it has changed a free parameter into a bound variable.
For a direct failure of the substitution axiom, use θ(x0​)=∃x1​(x0​=x1​). On a two-element domain, ∀x0​θ(x0​) is true, whereas the captured instance ∃x1​(x1​=x1​) is false. Consequently an unrestricted A4 would prove a false implication. The free for substitution condition is necessary for soundness.
