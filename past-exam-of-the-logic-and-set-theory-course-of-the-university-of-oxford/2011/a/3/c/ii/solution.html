 ... Past exam of the logic and set theory course of the University of Oxford 2011 A 3 c ii
OurBigBook.com Words: 164
No such first-order axiom collection can force actual identity when the displayed symbol is treated as an ordinary relation. The duplication obstruction to axiomatizing identity proves this even for an infinite collection of extra axioms.
Start with any nonempty first-order structure A in which the symbol is identity. Form B=A×{0,1} and the surjection π:B→A. Interpret each relation by pulling it back along π; in particular,
EB((a,i),(b,j))⟺a=b.
(15)
Interpret every function on first coordinates as in A and choose second coordinate zero; likewise lift constants with second coordinate zero. Induction on first-order terms gives π(tB(v))=tA(πv). Induction on first-order formulas then gives
B⊨θ[v]⟺A⊨θ[πv].
(16)
The quantifier steps use surjectivity of π, so every witness in A lifts to B.
Every proposed axiom valid with actual equality is therefore true in B under every assignment, along with A1–A7. But EB((a,0),(a,1)) holds for two different domain elements. Thus those axioms cannot enforce identity. The usual interpretation of logical equality as identity is a semantic requirement.
