For nonzero α, consider the exponents η with ωη≤α. The set is nonempty because it contains zero, and bounded because ωη≥η by transfinite induction. Let δ be its supremum. If this supremum is a successor it is attained; if it is a limit, continuity of ordinal exponentiation gives ωδ≤α. The zero case is immediate. Thus δ itself belongs to the set and is its maximum. Maximality gives
ωδ≤α<ωδ+1.​
(29)
Put ρ=ωδ>0. Since ωδ+1=ρ⋅ω=supN<ω​ρN, there is a least positive natural number N with α<ρN. We have N≥2 because ρ≤α. Set n=N−1. Then
ρn≤α<ρ(n+1).
(30)
For ordinals ξ≤α, the final segment of α after its initial segment ξ has an order type ζ satisfying α=ξ+ζ. Apply this with ξ=ρn. If ζ≥ρ, monotonicity would give α≥ρn+ρ=ρ(n+1), a contradiction. Therefore
α=ωδn+ζ,0<n<ω,ζ<ωδ.​
(31)
These intervals also make the leading exponent and coefficient unique. The remainder is unique because addition by a fixed left prefix is strictly increasing in its right operand.
