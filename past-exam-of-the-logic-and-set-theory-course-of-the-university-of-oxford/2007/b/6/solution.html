Use the Kuratowski ordered pair
⟨x,y⟩={{x},{x,y}}.​
(43)
The axiom of pairing first constructs {x} and {x,y}, then constructs the displayed pair of those sets, proving that it is a set.
For any a,b, the intersection of the members of this pair is {a}, and their union is {a,b}. Thus equality of two ordered pairs first gives {a}={c}, hence a=c, and then {a,b}={a,d}. If b=a, this latter set is a singleton and forces d=a. If b=a, its unique member distinct from a is b, forcing d=b. Hence equality of ordered pairs gives equality of both coordinates.
For a set R of ordered pairs, both coordinates of every pair belong to
U=⋃⋃R,
(44)
which is a set by two applications of the Axiom of union. Axiom of separation inside U gives
domR={x∈U:∃y⟨x,y⟩∈R},ranR={y∈U:∃x⟨x,y⟩∈R}.
(45)
These are sets, including when R is empty.
The Axiom of foundation asserts that every nonempty set A has an element a with a∩A=∅. If a descending membership sequence f:ω→V existed, replacement would give the nonempty range set S={f(n):n∈ω}. Foundation would give some f(n) disjoint from S. But f(n+)∈f(n) and f(n+)∈S, contradicting that disjointness. Thus foundation rules out every such sequence.
Conversely suppose there is no descending membership sequence, but foundation fails. There is then a nonempty set A such that a∩A=∅ for every a∈A. The axiom of choice selects a function h on A with h(a)∈a∩A. Choose a0​∈A and use recursion to define
f(0)=a0​,f(n+)=h(f(n)).
(46)
Every value remains in A, and f(n+)∈f(n) for every n. This is the forbidden sequence. Therefore, with the stated choice assumption, foundation is equivalent to the absence of descending membership sequences. The selection step explains exactly where choice is used; dependent choice would suffice.
