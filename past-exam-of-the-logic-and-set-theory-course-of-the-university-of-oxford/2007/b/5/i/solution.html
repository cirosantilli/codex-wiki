The axiom of infinity asserts that an inductive set exists: some set I contains 0=∅ and contains x+=x∪{x} whenever it contains x. Inside one such I, axiom of separation defines
ω={x∈I:x belongs to every inductive subset of I}.
(27)
This intersection is itself inductive and is contained in every inductive set, by intersecting that set with I. It is therefore the set of natural numbers. If a property holds at 0 and passes from n to n+, axiom of separation forms the subset of ω on which it holds. That subset is inductive, so must equal ω. This proves mathematical induction, including properties with set parameters.
Recursion on ω defines the arithmetic operations by
m+0=m,m+n+=(m+n)+,m⋅0=0,m⋅n+=m⋅n+m.
(28)
Existence and uniqueness follow from the recursion theorem on the natural numbers.
For associativity of addition fix m,n and induct on k. At k=0 both sides equal m+n. If the equality holds at k, then
m+(n+k+)=m+(n+k)+=(m+(n+k))+=((m+n)+k)+=(m+n)+k+.
(29)
Thus
m+(n+k)=(m+n)+k.​
(30)
Every step after the induction hypothesis is a defining successor equation, so commutativity has not been used prematurely.
