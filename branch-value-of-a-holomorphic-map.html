Branch value of a holomorphic map

 ... Analysis Complex analysis Riemann surfaces Riemann-Hurwitz formula Ramification index of a holomorphic map Ramification point of a holomorphic map
OurBigBook.com Words: 23
A branch value is the image of a ramification point of a holomorphic map. Away from all branch values, a proper holomorphic map is an ordinary unramified covering.
