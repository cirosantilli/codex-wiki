Phase-corrected exchange network for a CNOT gate (CNOT1→2​=P1​X2​H2​SZ1​SP2​H2​)

With S=P+​+iP−​ the conventional square root of the SWAP gate, P=diag(1,i) the S gate, and operators acting rightmost first, SZ1​S=diag(1,i,−i,−1). Therefore H2​SZ1​SP2​H2​=∣0⟩⟨0∣⊗X−i∣1⟩⟨1∣⊗I. Appending X2​ changes the zero-controlled flip into a one-controlled flip, and P1​ removes the control-dependent phase. This proves the displayed exact CNOT gate identity. Both the exchange branch and the phase gate square-root convention matter; changing either requires recalculating the correction.
