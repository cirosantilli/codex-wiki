Threshold function

 Home Computer science Theoretical computer science Computational complexity theory Circuit complexity Boolean circuit
OurBigBook.com Words: 133 Articles: 2
A threshold Boolean function outputs one exactly when a weighted sum of its input bits reaches a specified threshold. The unweighted threshold function fn,r​ tests whether at least r of its n inputs are one.
