Lebesgue measurable set

 Home Mathematics Area of mathematics Analysis Real analysis Measure theory
OurBigBook.com Words: 28
A Lebesgue measurable set is a member of the completion of the Borel sigma-algebra with respect to Lebesgue measure. In particular, it differs from a Borel set by a null set.
