Lebesgue measurable set

 Home Mathematics Area of mathematics Analysis Real analysis Measure theory
OurBigBook.com Words: 111 Articles: 2
A subset E⊆R is a Lebesgue measurable set when it satisfies Carathéodory's criterion for Lebesgue outer measure: for every subset A⊆R,
m∗(A)=m∗(A∩E)+m∗(A∖E).
(19)
These sets form the Lebesgue sigma-algebra, the completion of the Borel sigma-algebra with respect to Lebesgue measure. Equivalently, E differs from a Borel set by a subset of a Borel null set.
