Mirror return through an ordered polarizer-retarder pair

OurBigBook.com Words: 76
Take a linear polarizer P=diag(1,0) and a reciprocal quarter-wave plate Q=2−1/2(1i​i1​) in fixed physical transverse axes. A near-normal isotropic mirror has M=−I2​ up to global phase. If the source/detector side encounters P before Q, the round-trip matrix is PQMQP=−PQ2P=0. Reversing the filter gives QPMPQ=−QPQ, which transmits half an initially unpolarized intensity. The result is double-pass rejection, not optical nonreciprocity; changing direction without changing the input polarization does not preserve the same physical input state.
