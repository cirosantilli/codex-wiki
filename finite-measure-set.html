Finite-measure set (μ(E)<∞)

 ... Area of mathematics Analysis Real analysis Measure theory Measure Finite measure
OurBigBook.com Words: 34
A finite-measure set is a measurable set on which the ambient measure is finite. Restricting to such a set makes its indicator function belong to every Lp space with finite exponent, enabling local Radon-Nikodym theorem arguments even when the whole measure space is not sigma-finite.
