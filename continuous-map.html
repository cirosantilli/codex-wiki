Continuous map (f:X→Y)

 Home Mathematics Area of mathematics Geometry and topology Topology Topological space
OurBigBook.com Words: 151 Articles: 2
A map f:X→Y between topological spaces is continuous when every open set V⊆Y has an inverse image f−1(V)={x∈X:f(x)∈V} that is an open set in X. The notation denotes a subset, so f need not have an inverse function.
For the continuous map f:R→R, f(x)=x2, with the usual metric topology,
f−1((1,4))=(−2,−1)∪(1,2).
(7)
The two open intervals form an open set; an inverse image can split into separate pieces without violating continuity. The defining condition concerns inverse images, rather than images: here f((−1,1))=[0,1) is not an open set in the real line. Checking this one inverse image illustrates the definition; it alone does not prove continuity for all target open sets.
