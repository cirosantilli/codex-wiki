Function type (τ1​→τ2​)

 Home Computer science Programming language Type system
OurBigBook.com Words: 252
A function type τ1​→τ2​ classifies functions that accept arguments of type τ1​ and produce results of type τ2​ if they return. For example, λx.x+1 has function type int→int in our teaching programming language, while λb.if b then 1 else 2 has function type bool→int. A function type specifies how a function may be used; it does not guarantee that a call returns.
The two central typing judgment rules are
Γ⊢λx.e:τ1​→τ2​Γ,x:τ1​⊢e:τ2​​,Γ⊢fa:τ2​Γ⊢f:τ1​→τ2​Γ⊢a:τ1​​.
(53)
The lambda abstraction rule checks the body under an extended typing context; the lambda application rule checks that the argument has exactly the required type. These rules describe our simple type examples. [ref]
For (λx.x+1)3, assume x:int; both x and 1 have type int, so x+1 has type int. The abstraction therefore has function type int→int. Since 3 has type int, the call has type int and evaluates to 4. Replacing 3 by true fails the argument requirement. This local derivation explains each step without running the program.
Arrows associate to the right: τ1​→τ2​→τ3​ means τ1​→(τ2​→τ3​), a function returning another function. For instance, λx.λy.x+y has function type int→(int→int). Supplying one integer yields a function awaiting the second. Functions can also be arguments: (int→int)→int accepts an integer-to-integer function and has an integer result type.
