Optimal prefix code (minc​L(c))

 Home Mathematics Area of mathematics Probability and statistics Information theory Huffman coding
OurBigBook.com Words: 846 Articles: 6
An optimal prefix code minimizes expected codeword length for a fixed source probability distribution. Here the source alphabet is finite, has n≥2 symbols, and has px​>0 for every symbol; each source symbol receives one codeword over the binary output alphabet {0,1}. Its code tree puts the symbols at leaves. Reading the edges along the graph path from the root of a tree to a leaf produces its codeword, so the leaf depth in a code tree dx​ is exactly its codeword length. Thus
L(c)=∑x​px​dx​,L∗(p)=minc a binary prefix code​L(c).
(153)
For unnormalized positive weights, minimize C(T)=∑x​wx​dx​ instead; the corresponding expected codeword length is C(T)/∑x​wx​. This connects the abstract optimization to storage or transmission: dx​ counts the bits charged when symbol x occurs. Huffman coding attains this minimum; the Huffman sibling property and Huffman sibling contraction explain why. [ref]
For (pA​,pB​,pC​,pD​)=(0.4,0.3,0.2,0.1), a balanced code tree charges every symbol two bits, giving L=2. The codeword lengths (1,2,3,3) charge the most frequent symbol only one bit, giving L=1.9. The choice concerns weighted cost, not just the greatest codeword length: increasing that maximum from two to three can improve the average.
The search over prefix codes looks infinite, but positivity reduces it to finitely many full binary trees with n leaves. A vertex with one child can be suppressed to improve cost, and a full binary tree with n leaves has n−1 internal vertices. There are consequently finitely many such shapes and symbol assignments, so the minimum exists. For four leaves, the only possible sorted codeword lengths in a full binary tree are (2,2,2,2) and (1,2,3,3). Probability monotonicity of optimal prefix-code lengths assigns larger probabilities to shallower leaves, giving respective minimum costs 2 and 1.9 in this example. This is an independent small-instance check of the Huffman code.
These hypotheses matter. With zero weights, suppressing a subtree carrying only zero weight need not strictly improve cost, so an optimal prefix code need not have a full binary tree. A one-symbol source raises the convention of whether an empty codeword is allowed. Both cases are outside the original statement here. Encoding groups of symbols changes the source alphabet and the optimization problem; the minimum here concerns one source symbol per codeword.
