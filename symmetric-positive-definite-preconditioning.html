Symmetric positive-definite preconditioning (B=M−1/2AM−1/2,y=M1/2x)

 ... Mathematics Area of mathematics Analysis Numerical analysis Numerical linear algebra Matrix preconditioning
OurBigBook.com Words: 383 Articles: 1
Let A and M be real symmetric positive-definite matrices. The principal square root of a positive semidefinite matrix construction gives an invertible matrix for each. Set
S=M1/2,B=S−1AS−1,y=Sx,c=S−1b.
(2)
Then Ax=b is equivalent to By=c. This is a matrix congruence, and B is a symmetric positive-definite matrix: BT=B, and for every nonzero vector v,
vTBv=(S−1v)TA(S−1v)>0,
(3)
since S−1v=0. This short proof establishes both requirements for applying the Conjugate gradient method to the transformed linear system.
The left transformed matrix has the same eigenvalues because
M−1A=S−1BS.
(4)
Its correct geometry uses the weighted inner product ⟨u,v⟩M​=uTMv: ⟨u,M−1Av⟩M​=uTAv=⟨M−1Au,v⟩M​. Thus it is symmetric in this inner product, even when it is not a symmetric matrix in ordinary coordinates. The spectral condition number governing the transformed symmetric problem is κ2​(B), not generally κ2​(M−1A).
The Preconditioned conjugate gradient method realizes this transformation using auxiliary solves Mzk​=rk​, without constructing S or its matrix inverse. With fixed M, initialize r0​=b−Ax0​ and p0​=z0​; while rk​=0, use
αk​=pkT​Apk​rkT​zk​​,xk+1​=xk​+αk​pk​,rk+1​=rk​−αk​Apk​,
(5)
then solve Mzk+1​=rk+1​ and set
βk​=rkT​zk​rk+1T​zk+1​​,pk+1​=zk+1​+βk​pk​.
(6)
Stop at a zero linear-system residual before forming another ratio. Positive definiteness makes the denominators positive before termination.[ref]
An invertible matrix alone is insufficient: with A=I and M=diag(−1,1), the left transformed matrix has eigenvalues −1,1, and M has no real symmetric positive-definite matrix square root. Even a valid symmetric positive-definite matrix can worsen conditioning if its scaling is unsuitable, as the next worked example shows.
