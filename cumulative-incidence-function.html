Cumulative incidence function (Fk​(t))

 ... Mathematics Area of mathematics Probability and statistics Survival analysis Competing risks Competing risks model
OurBigBook.com Words: 86 Articles: 1
For event time T and event type J, the cumulative incidence function is Fk​(t)=P(T≤t,J=k). It is the absolute probability that cause k occurs by time t before any competing cause.
