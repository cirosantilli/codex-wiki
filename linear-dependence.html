Linear dependence (∑i​ai​vi​=0,(a1​,…,an​)=0)

 ... Mathematics Area of mathematics Algebra Linear algebra Vector space Linear independence
OurBigBook.com Words: 412 Articles: 2
A finite family of vectors in a vector space over a specified field F is linearly dependent if it has a nontrivial linear relation: ∑i​ai​vi​=0 with ai​∈F and at least one coefficient nonzero. One can then solve for a vector whose coefficient is nonzero as a linear combination of the others; removing that entry preserves the linear span. Repeated vectors in a list give linear dependence: for example (v,v) has the linear relation 1v+(−1)v=0. A list keeps both entries even though the set {v,v} has only one element. Strang's notes illustrate redundant columns by expressing one as the sum of two others.[ref]

The two coefficient triples (2,1,0) and (1,0,1) differ by the nontrivial linear relation (−1,−1,1). In fact all linear combination representations of this target are
(c1​,c2​,c3​)=(2−t,1−t,t),t∈R.
(10)
To check both completeness and correctness, use c1​v1​+c2​v2​+c3​v3​=(c1​+c3​)v1​+(c2​+c3​)v2​. Linear independence of v1​,v2​ forces c1​+c3​=2 and c2​+c3​=1, giving exactly the displayed family. Redundancy therefore preserves attainable targets while allowing their coefficients to move. For solving a linear system, these alternatives matter; for assigning unique coordinate vectors, one instead chooses a basis.
