Last-to-first mapping (LF(r)=C(Lr​)+Occ(Lr​,r))

 Home Computer science Algorithm String-searching algorithm
OurBigBook.com Words: 76
In a sorted cyclic rotation matrix, the last-to-first mapping sends the kth occurrence of a character in the last column to its kth occurrence in the first column. For one-based rows, LF(r)=C(Lr​)+Occ(Lr​,r), where C(c) counts smaller characters and Occ(c,r) counts c in the first r entries of the last column. It moves a rotation's start one character backwards cyclically. Equal characters retain the lexicographic order of their following sequences, which proves the occurrence-order rule.[ref]
