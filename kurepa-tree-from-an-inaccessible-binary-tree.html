Kurepa tree from an inaccessible binary tree

 ... Foundations of mathematics Set theory Set Partially ordered set Set-theoretic tree Kurepa tree
OurBigBook.com Words: 58
Let κ be strongly inaccessible cardinal in the ground model and perform the finite Lévy collapse to omega-one. The ground full binary set-theoretic tree of height κ has all levels of size less than κ, so these levels become countable. Its at least (κ+)M ground branches remain distinct. The chain in a partial order condition preserves (κ+)M, which is the extension ℵ2​. The unchanged ground set-theoretic tree therefore witnesses the Kurepa hypothesis.
