Dynamic dispatch

 Home Computer science Programming language Object-oriented programming
OurBigBook.com Words: 114 Articles: 1
Selection of an instance method implementation using the receiver's runtime type. It operates on the method signature already determined by the language's call typing and overload rules. It does not imply dispatch on every argument's runtime type; in particular, method overloading in Scala normally uses static argument types.
