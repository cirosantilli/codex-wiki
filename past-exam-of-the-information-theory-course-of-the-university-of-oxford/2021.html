The chain rule for conditional entropy gives
H(X,Y∣Z)−H(X∣Z)=H(Y∣X,Z)≥0.
(1)
Indeed, for every conditioning value (x,z) of positive probability, each summand −p(y∣x,z)log2​p(y∣x,z) is nonnegative. Its sum is zero exactly when the conditional probability mass function is concentrated at one value. Averaging over (X,Z) therefore proves both the inequality and its equality criterion: equality holds exactly when Y=f(X,Z) almost surely for some function f. Conditioning values of probability zero impose no restriction. This is a statement about discrete random variables; a differential entropy need not be nonnegative.

Reference-distribution ambiguity: ρ is not defined in the paper. If it is an arbitrary probability mass function, the printed inequality is false. For instance, choose p=(1,0) and ρ=(1/2,1/2). Every empirical distribution equals p, making the printed left side one bit and its right side zero. This is a counterexample for every n≥1.
Under the consistent interpretation ρ=p, the preceding leave-one-out identity for empirical distributions and convexity of relative entropy in its first argument give, for every sample,
D(p​n+1​∥p)≤n+11​∑i=1n+1​D(q​n,i​∥p).
(11)
Deleting any one observation from n+1 independent and identically distributed random variables leaves n independent observations with probability mass function p. Consequently each q​n,i​ has the same distribution as p​n​. They need not be independent of one another. Taking expected values and using linearity of expectation therefore proves
ED(p​n+1​∥p)≤ED(p​n​∥p).​
(12)
Zero coordinates of p are never sampled, almost surely, so the calculation can be restricted to its probability support. In particular the expected values are finite on this finite alphabet.
The discrepancy cannot be removed by silently choosing any fixed reference. Whenever ρ is positive on the probability support of p, direct subtraction and Ep​n​=p give the expected relative entropy decomposition
ED(p​n​∥ρ)=ED(p​n​∥p)+D(p∥ρ).
(13)
Thus the valid arbitrary-reference version has ρ on both sides; the printed mixed-reference version has an additional term whose sign prevents the proposed conclusion.

ii OurBigBook.com
First assume a full-support finite distribution, as stated above. Let L be the largest codeword length and take a tree leaf at depth L. Every existing tree child of its tree parent must also be a tree leaf: an internal tree child would have a descendant deeper than L. If the chosen tree leaf were its tree parent's only tree child, moving its symbol to that tree parent would shorten its codeword by one, preserve the prefix code property, and reduce expected codeword length by its positive probability. That contradicts optimality. The tree parent therefore has at least two tree children, both tree leaves. A second codeword has the same first L−1 digits and a different last digit, proving the required deepest sibling codeword property for a ternary prefix code.
For the literal wording allowing zero probabilities, take p=(1,0,0) and the prefix code (0,10,110). Its expected codeword length is one, which is minimal: with more than one message an empty codeword is impossible, so the positive-probability message must have length at least one. Yet the deepest tree leaf 110 has no sibling codeword. Thus positivity or an additional convention removing redundant zero-weight branches is needed.

Suppose a tree parent at depth n−1, with n<L, has an unused outgoing digit. The missing tree child gives an empty code tree branch at depth n. Move any deepest tree leaf into that position, retaining all other codewords and deleting the abandoned empty branch. The new word has no old word as a prefix, because it lies in an unused branch, and it is not a prefix of any retained word. Its length decreases from L to n. With a full-support finite distribution this reduces expected codeword length by pi​(L−n)>0, contradicting optimality. Hence all three tree children exist, and each has a descendant codeword. With a full-support finite distribution, suppose two distinct tree parents at depth L−1 each have exactly two tree children, both tree leaves. Move one tree leaf from the second pair into the vacant third tree child slot of the first tree parent. Its length remains L, so this relocation does not change expected codeword length. The second tree parent now has a single tree child, which is a tree leaf. Replace that remaining tree child's codeword by the tree parent's word. This preserves the prefix code property and shortens a positive-probability codeword by one. Expected codeword length strictly decreases, a contradiction. If zero-probability symbols are retained without a reduction convention, the claim can fail. The probability mass function (1,0,0,0,0) with prefix code (0,100,101,110,111) has the optimal expected codeword length one, yet contains the two deepest pairs (100,101) and (110,111). c OurBigBook.com
For an odd integer m≥3, ternary Huffman coding repeatedly merges three smallest weights.
Start with one tree leaf for each source symbol, weighted by its probability. While more than one weighted object remains, choose the three objects with least weights, create their common tree parent with weight equal to their sum, and replace the three by that tree parent. Newly created tree parents participate in subsequent choices. Each merge reduces the number of objects by two; an odd number of objects therefore reaches three and then one, never an unmergeable pair. The final object is the tree root of the code tree.
Label the three outgoing edges at each internal vertex by 0,1,2 in any order. The digits along the root-to-leaf graph path give each symbol's codeword. Tree leaves cannot be ancestors of other tree leaves, so this is a prefix code. Ties can be resolved arbitrarily. The expected codeword length is measured in trits, and equals the sum of all merge weights, because each merge adds one digit to every codeword below it.
The structural reason for merging three is that the positive-weight, odd-leaf case has a full ternary tree. Its deepest sibling codeword triple can receive the three least weights by exchanging tree leaf labels, and contracting that triple reduces the problem by two symbols. This explains the recursive construction; a separate optimality proof is not required here.

For a discrete memoryless channel with transition probabilities M(y∣x), the conditional probability of a length-n output given a length-n input factors as
P(Y1​=y1​,…,Yn​=yn​∣X1​=x1​,…,Xn​=xn​)=∏j=1n​M(yj​∣xj​).
(24)
The same transition probabilities apply at each use. Its channel capacity is
C=pX​max​I(X;Y)=pX​max​x,y∑​pX​(x)M(y∣x)log2​∑x′​pX​(x′)M(y∣x′)M(y∣x)​.​
(25)
The unit is bits per channel use. For finite alphabets the maximum exists by continuity on the probability simplex; with more general alphabets one uses a supremum when appropriate.
An (m,n) channel code consists of an encoder c:Vm​→Xn and a decoder d:Yn→Vm​. It represents each of m messages by n input symbols and recovers a message from the n observed output symbols. Its code rate is R=(log2​m)/n bits per use. For each message w, its conditional error probability is P(d(Yn)=w∣W=w); an average error also specifies the message probability distribution, while the maximum error takes the largest conditional error.

b OurBigBook.com
Write T=g(Y). Because T is determined by Y, the chain rule for mutual information gives
I(X;Y)=I(X;Y,T)=I(X;T)+I(X;Y∣T)≥I(X;T).
(26)
This is the data processing inequality. It holds for every input probability distribution. Maximizing each side over that same set of input probability distributions gives Cg(Y)​≤CY​; processing cannot increase channel capacity.
A simple sufficient condition for equality is that g be injective on the reachable output alphabet. Then Y can be recovered from T, giving H(Y∣T)=0 and hence I(X;Y∣T)=0 for every input law. The input that achieves the original channel capacity therefore achieves it after processing as well. Values of g outside reachable outputs are irrelevant.
Injectivity is sufficient rather than necessary. More precisely, for finite alphabets equality in capacity data processing holds exactly when there is an original capacity-achieving input law for which X and Y have conditional independence given T. Sufficiency follows from the displayed gap identity. For necessity, maximize I(X;T) at an input law p∗​; if its maximum equals CY​, then CY​=Ip∗​​(X;T)≤Ip∗​​(X;Y)≤CY​, so both inequalities are equalities. Processing may discard output details unrelated to the input without losing channel capacity.

(38)
Interchanging the two bit values leaves the binary symmetric channel and majority decision unchanged, so P(error∣W=b)=7/250 as well. Both the maximum conditional error and the average error, for any message prior, are therefore 0.028. The probability of correct decoding for each message is 243/250=0.972. These are finite-block error probabilities; a channel-capacity statement alone would not determine them.
