The inequality is true for ordinary addition, and also for addition in a group. For any fixed y, the translation x↦x+y is injective, so it merely relabels the probability masses in the conditional distribution. Since X,Y are independent random variables,
H(X+Y∣Y=y)=H(X∣Y=y)=H(X).
(1)
Averaging over y and using conditioning reduces entropy proves entropy monotonicity under independent addition:
H(X+Y)≥H(X+Y∣Y)=H(X).​
(2)
There is no requirement that X+Y remain in the original finite alphabet. The proof also gives H(X+Y)≥H(Y) by symmetry. Independence matters: for a nonconstant X and Y=−X, the sum is constant while H(X)>0.

Let N=∣X∣≥2 and let E=1{X=Y}​ be the error indicator random variable. Because E is determined by (X,Y), the chain rule for conditional entropy in its two orders gives
H(X∣Y)=H(X,E∣Y)=H(E∣Y)+H(X∣E,Y).
(3)
By conditioning reduces entropy, H(E∣Y)≤H(E). On E=0, knowing Y determines X, so the corresponding conditional entropy is zero. On E=1, at most N−1 symbols remain possible for X. The maximum Shannon entropy of a probability distribution on at most N−1 symbols is log(N−1). Consequently
H(X∣Y)≤H(1{X=Y}​)+Pr(X=Y)log(N−1).​
(4)
For an arbitrary function g:X→X, repeat the argument with Eg​=1{X=g(Y)}​. This is still determined by (X,Y); when it is zero, X=g(Y), and when it is one, X has at most N−1 possibilities for each Y. Thus Fano's inequality gives
H(X∣Y)≤H(1{X=g(Y)}​)+Pr(X=g(Y))log(N−1).​
(5)
Events of zero probability contribute zero to the conditional average, covering the error probabilities zero and one. If N=1, the left side and error probabilities are zero; the trivial conclusion is handled separately instead of writing 0log0 as an ordinary finite product.

For the entropy summand f(x)=−xlogx, differentiation on (0,1) gives
f′(x)=−ln2lnx+1​,f′′(x)=−xln21​<0.
(6)
Since f(x)→0 as x↓0, its continuous extension to [0,1] is a concave function.
Fix 0<v<1 and define the increment Dv​(t)=f(t+v)−f(t) on [0,1−v]. In its interior,
Dv′​(t)=f′(t+v)−f′(t)=−logtt+v​<0.
(7)
Thus the increment is decreasing, and its endpoint values are Dv​(0)=f(v) and Dv​(1−v)=−f(1−v). Therefore
−f(1−v)≤f(t+v)−f(t)≤f(v),∣f(t+v)−f(t)∣≤max{f(v),f(1−v)}.​
(8)
The cases v=0,1 follow directly from the endpoint values.
To obtain the sharper half-interval bound, put G(v)=f(v)−f(1−v). It has G(0)=G(1/2)=0, while
G′′(v)=v(1−v)ln22v−1​≤0(0<v≤1/2).
(9)
Hence G is a concave function on [0,1/2] and lies above the chord joining its zero endpoints. Thus f(v)≥f(1−v) there, proving
∣f(t+v)−f(t)∣≤f(v)(0≤v≤1/2).​

The independent and identically distributed hypothesis factors the joint probability mass function:
pn​(X1​,…,Xn​)=∏i=1n​p(Xi​),n1​logpn​(X1​,…,Xn​)=n1​∑i=1n​logp(Xi​).
(14)
Symbols outside the support of a probability distribution p never occur, almost surely. On its finite positive probability support, logp(Xi​) is bounded, so the strong law of large numbers applies:
n1​logpn​(X1​,…,Xn​)⟶x:p(x)>0∑​p(x)logp(x)=−H(p)almost surely.​
(15)
This is the asymptotic equipartition property with the sign appropriate to a logarithm of a probability mass.

For a fixed estimated probability mass function q, the estimated joint probability mass function is qn​(x1​,…,xn​)=∏i​q(xi​). If q(x)>0 whenever p(x)>0, the strong law of large numbers gives the mismatched asymptotic equipartition property:
n1​logqn​(X1​,…,Xn​)⟶x:p(x)>0∑​p(x)logq(x)=−H(p,q)=−H(p)−DKL​(p∥q)almost surely.​
(16)
Here H(p,q) is cross-entropy, and the last equality is cross-entropy equals entropy plus relative entropy. The Kullback-Leibler divergence measures the extra average logarithmic loss from the estimated law.
If q(x)=0 for some x with p(x)>0, let a=∑x:q(x)=0​p(x)>0. The probability that none of the first n observations belongs to this set is (1−a)n→0. Almost surely such a symbol eventually occurs, after which qn​(X1​,…,Xn​)=0 forever. Thus the limit is −∞, consistent with infinite cross-entropy and infinite Kullback-Leibler divergence.

For fixed ε>0, the asymptotic equipartition property gives Pr(Xn∈/An,ε)→0. The strong law of large numbers applied to Xi​, which are bounded because their numerical alphabet is finite, gives Pr(Xn∈/Bn,ε)→0. The union bound therefore yields
Pr(Xn∈Sn​)≥1−Pr(Xn∈/An,ε)−Pr(Xn∈/Bn,ε)⟶1.
(20)
Since δ>0, eventually Pr(Xn∈Sn​)≥2−δ. Each word in Sn​ has probability mass at most 2−n(H(p)−ε), so
2−δ≤Pr(Xn∈Sn​)≤∣Sn​∣2−n(H(p)−ε).
(21)

∣An,ε∩Bn,ε∣≥2n(H(p)−ε)−δ​
(22)
for sufficiently large n. The key is that the factor 2−δ is a fixed number below one, however small δ is. This is an instance of typical sets with an additional high-probability constraint.

First, the binary translation of a quaternary prefix code is still a prefix code: every translated codeword length is even, and a binary prefix relation would split into complete two-bit blocks, giving a prefix relation between the original quaternary codewords. Binary Huffman coding is optimal among binary prefix codes, so
E∣cB​(X1​)∣≤E∣cQB​(X1​)∣.
(23)
For the other direction, let ℓi​=∣cB​(xi​)∣ and round these binary codeword lengths to quaternary lengths ki​=⌈ℓi​/2⌉. The Kraft inequality gives
∑i​4−ki​=∑i​2−2⌈ℓi​/2⌉≤∑i​2−ℓi​≤1.
(24)
The quaternary converse of the Kraft inequality supplies a quaternary prefix code with lengths ki​. Optimality of the quaternary Huffman code then implies
E∣cQB​(X1​)∣​=2E∣cQ​(X1​)∣≤2i∑​pi​⌈2ℓi​​⌉≤i∑​pi​(ℓi​+1)=E∣cB​(X1​)∣+1.​
(25)
Thus binary translation of an optimal quaternary code costs at most one extra bit per source symbol:
E∣cB​(X1​)∣≤E∣cQB​(X1​)∣≤E∣cB​(X1​)∣+1.​
(26)
The quaternary Huffman code uses the usual adjustment of adding zero-weight dummy leaves when needed. If the alphabet has one symbol, both optimal codes may use the empty codeword, giving the trivial endpoint.

The specified transition law is a binary erasure channel. For an input bit with Pr(X=1)=a, its Shannon entropy is the binary entropy h2​(a). A non-erased output determines X, whereas the erasure symbol leaves its probability distribution unchanged because the erasure event is independent of X. Thus
H(X∣Y)=qH(X),I(X;Y)=(1−q)H(X)=(1−q)h2​(a).
(27)
Maximizing the mutual information over the input probability distribution, h2​(a)≤1 with equality at a=1/2, gives
C=1−qbits per channel use.​
(28)
This includes q=0, a noiseless binary channel, and q=1, a completely erased channel with zero channel capacity.

Use the standard deterministic channel encoder and channel decoder, with m message labels and code rate R=(logm)/n. The Fano's inequality hint printed here replaces log(m−1) by logm−1, which is false in general: take X uniform on {0,1} and Y=2 in the common alphabet {0,1,2}. The error probability is one and its binary entropy is zero, so the proposed bound asserts 1≤log3−1<1. The correct Fano's inequality alone gives (1−Pe​)logm≤n(1−q)+h2​(Pe​), which does not immediately give the requested additive 1/n. The following erasure-pattern counting bound for maximal decoding error proves the displayed claim directly.
The case m≤2 is immediate because R≤1/n. Suppose m>2, put L=logm−1>0, and let w0​ be the message that the channel decoder returns on the all-erased output. Choose W uniformly among the other m−1 messages. Every one of these messages is decoded correctly with probability at least 1−δ, by the assumed maximal decoding error probability bound.
Let S be the random set of unerased coordinates and K=∣S∣. For each fixed S with K=k≥1, at most 2k output words are possible. A deterministic channel decoder can correctly identify at most one message per output word, so its conditional success probability, averaged over these m−1 messages, is at most min{1,2k/(m−1)}. When K=0, success is zero because w0​ was excluded.
For every integer k≥1,
min{1,m−12k​}≤Lk​.
(29)
If k≥L, this is immediate. If k<L, write r=m/2k>2. The elementary inequality logr≤r−1 for r≥2 gives
L=k−1+logr≤k+r−2≤k(r−1)<2kk(m−1)​,
(30)
where the middle inequality is (k−1)(r−2)≥0. This proves the needed scalar bound.
Taking the expectation over erasure patterns, and using EK=n(1−q), yields
1−δ≤Pr(W=W)≤LEK​=logm−1n(1−q)​.
(31)
Consequently the requested bound is valid:
R=nlogm​≤1−δ1−q​+n1​.​
(32)
The use of maximal decoding error probability matters: excluding one message preserves the lower bound on success. The deterministic channel decoder convention also matters; allowing independent randomized guessing would invalidate this particular finite-length claim at q=1.

For 0≤q<1, use repeat-until-success coding over an erasure channel: delete every erasure symbol from the received sequence and retain the non-erased bits in order. Each message bit contributes a string of erasures followed by exactly one correct non-erased copy. The channel encoder advances to the next bit only after this successful copy, so the retained bits are precisely W1​,…,Wn​. Hence
d(Y)=W,Pr(d(Y)=W)=0.​
(33)
Indeed, Pr(Mj​>k)=qk→0, so each stage and the finite collection of n stages terminate almost surely. The protocol uses channel feedback: Alice must know whether an erasure occurred before deciding whether to repeat. This feedback is implicit in the stated algorithm and is not counted as a forward channel use.
At q=1, no stage ever finishes, so there is no terminating zero-error decoder for arbitrary messages. This endpoint is excluded from the operational claim above.

For 0≤q<1, the total number of forward channel uses is Tn​=∑j=1n​Mj​, so the random code rate of a message with n bits is
Rn​=Tn​n​=(n1​∑j=1n​Mj​)−1.
(36)
The independent and identically distributed random variables Mj​ have finite expectation 1/(1−q). By the strong law of large numbers,
Rn​⟶1−qalmost surely.​
(37)
Thus the protocol reaches the binary erasure channel channel capacity in its asymptotic forward throughput while guaranteeing zero error on every completed message. Its random transmission length and use of channel feedback distinguish it from the fixed-length channel codes in part (b). Independent erasure indicators suffice for this calculation; the message bits themselves need not be independent or uniformly distributed. At q=1, the algorithm never produces a completed transmission, so Rn​ as a completed-code rate is undefined; the physical throughput is zero.
