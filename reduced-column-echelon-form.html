Reduced column echelon form (rcef(A)=rref(AT)T)

 ... Algebra Linear algebra Vector space Linear map Matrix Elementary column operation
OurBigBook.com Words: 145
The reduced column echelon form of a matrix A is defined by taking its transpose, forming the reduced row echelon form, and transposing back:
rcef(A)=(rref(AT))T.
(33)
It is obtained from A by elementary column operations. Its nonzero columns precede its zero columns, the topmost nonzero entry of each nonzero column is 1, these leading entries move strictly downward as the column number increases, and each leading entry is the only nonzero entry in its row.
Every elementary column operation preserves the column space, because it and its inverse express each new column as a linear combination of the old columns. Thus the nonzero columns of the reduced form give a basis of the original column space. In contrast, elementary row operations preserve the row space. There is no general identity rcef(A)=rref(A)T: the definition requires reducing AT, not A.
For an invertible matrix of size n, both reduced forms are In​. A singular example showing the distinction is
A=(10​20​),rref(A)=(10​20​),rcef(A)=(10​00​).
(34)
