Bounded-coefficient asset deflator (d(Zt​Sti​)=Zt​Sti​(σt,i​−λt​)TdWt​)

OurBigBook.com Words: 67
For asset dynamics dS=diag(S)(μdt+σdW), let λ=σ−1μ and Z=E(−∫λTdW). The Itô product rule cancels the drift of each ZSi, leaving the displayed stochastic integral. When μ is bounded and σσT≥εI, λ is bounded and the Novikov condition makes Z a true martingale on every finite horizon. If σ is also bounded, each ZSi/S0i​ satisfies the Novikov condition as a stochastic exponential with bounded integrand σi​−λ, so it too is a true martingale.
