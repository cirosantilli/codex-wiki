Bernstein-Vazirani algorithm

 Home Computer science Algorithm Quantum algorithm
OurBigBook.com Words: 319 Articles: 2
The Bernstein-Vazirani algorithm identifies the coefficient string of a linear Boolean function with one Boolean quantum oracle call. It contrasts with the n calls required by the classical query complexity of linear Boolean function identification. Prepare the data qubits at ∣0⟩⊗n and an ancilla qubit at ∣1⟩, apply a Hadamard gate to every wire, query the function oracle, and apply the Hadamard gates again. The full output is ∣a⟩∣1⟩.
The mechanism is Bernstein-Vazirani phase kickback. The Pauli X gate has eigenvector ∣−⟩=(∣0⟩−∣1⟩)/2​ with eigenvalue −1. Thus the target flips become relative quantum phases on the data, giving
2−n/2∑x​(−1)a⋅x∣x⟩=⨂j=1n​2​∣0⟩+(−1)aj​∣1⟩​.
(2)
The final Hadamard transform maps this product to ∣a⟩, so computational-basis measurement recovers every coefficient with certainty. The ancilla preparation for the Bernstein-Vazirani algorithm ensures the required minus sign, and the Hadamard-conjugated linear oracle gives an exact quantum circuit interpretation. One query is optimal for n≥1, since without a query the output cannot depend on the unknown string.
