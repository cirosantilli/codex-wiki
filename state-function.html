State function

 Home Physics Branches of physics Statistical physics Thermodynamics
OurBigBook.com Words: 1k Articles: 2
A state function assigns a value to each equilibrium thermodynamic state of a specified thermodynamic system. Its change depends only on the initial and final states. Internal energy U, entropy S and enthalpy H=U+pV are state functions; here p is pressure and V is volume. Transferred heat Q and work W belong to a thermodynamic process, rather than to a state. A system stores internal energy; it does not store separate inventories of “heat received” and “work received”.[ref]
Use the explicit convention Q>0 for heat entering and Wby​>0 for work done by the thermodynamic system on its surroundings. For a closed system with unchanged endpoint bulk kinetic energy and external potential energy, the first law of thermodynamics reads
ΔU=Q−Wby​,dU=δQ−δWby​.
(6)
The notation dU denotes an exact differential of a state function; δQ and δWby​ denote incremental transfers. Along a reversible thermodynamic process of a simple compressible system,
δWby,rev​=pdV,δQrev​=TdS,
(7)
where T is absolute temperature. These are rules for particular thermodynamic processes, not definitions of stored heat or stored work. In particular, a quasistatic process with friction can remain near thermodynamic equilibrium while producing entropy.[ref]
For any state function F and two equilibrium states A,B, an integral of its exact differential gives
∫AB​dF=F(B)−F(A),∮dF=0.
(8)
The proof is telescoping: add the changes F(xi+1​)−F(xi​) along a subdivided path, and all intermediate values cancel. The smooth limit gives the integral. Conversely, if an integrable differential form has zero integral around every accessible closed path in a connected region, define F(B) by integrating from a reference state. Two routes differ by a closed path, so the definition is unambiguous. This argument needs every accessible loop, rather than a local test that might miss a hole in the domain; see path independence.
The same cancellation does not hold separately for heat and work. A thermodynamic cycle has ΔU=0 but can have nonzero net transfers, with ∮δQ=∮δWby​. Nor does the fact that entropy is a state function make Q/T its general change: the formula dS=δQrev​/T uses a reversible thermodynamic process and its varying temperature.
This distinction makes endpoint calculations powerful. We can compute an internal energy, entropy or enthalpy difference along a convenient reversible reference path even when the actual thermodynamic process is irreversible. Its actual heat and work must still be obtained from its own boundary interactions. The appealing cancellation is visible in two reversible ideal-gas paths between the same states: a different mechanical output requires a matching difference in thermal input, while stored internal energy arrives at the same value.
