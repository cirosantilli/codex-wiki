Put b(v,w)=φ(w)(v). Each φ(w) belongs to the dual space V′, so it is a linear functional. For real numbers a,b0​ and vectors v1​,v2​,w, this gives
b(av1​+b0​v2​,w)=φ(w)(av1​+b0​v2​)=ab(v1​,w)+b0​b(v2​,w).
(31)
The linearity of φ gives linearity in the second argument as well:
b(v,aw1​+b0​w2​)=(aφ(w1​)+b0​φ(w2​))(v)=ab(v,w1​)+b0​b(v,w2​).
(32)
Thus b is a bilinear form.
Its right radical of a bilinear form is exactly kerφ, because
b(v,w)=0 for every v∈V ⟺ φ(w)=0.
(33)
If b is a nondegenerate bilinear form, this kernel is zero. Since V is a finite-dimensional vector space and dimV′=dimV, the rank-nullity theorem makes φ surjective.
Conversely, if φ is surjective, the same dimension equality makes it injective, so the right radical is zero. If v lies in the left radical, then f(v)=0 for every f∈V′, because every f is some φ(w). A nonzero v can be included in a basis and detected by its coordinate functional, so this forces v=0. Both radicals vanish, proving
b is nondegenerate ⟺ φ is surjective.​
(34)
