Gradient of a Sobolev function vanishes on a level set (Du=0 a.e. on {u=t})

 ... Area of mathematics Analysis Distribution theory Distributional derivative Weak derivative Sobolev chain rule
OurBigBook.com Words: 45
If u∈Wloc1,2​, then Du=0 almost everywhere on every level set {u=t}. Choose smooth truncations Φε​(s) with ∣Φε​∣≤2ε, derivative one near zero, bounded derivative, and derivative zero outside (−2ε,2ε). The Sobolev chain rule gives DΦε​(u−t)→1{u=t}​Du in local L2 by dominated convergence theorem, while Φε​(u−t)→0. The limiting weak derivative is therefore zero.
