Nonplanarity by edge counts

 ... Area of mathematics Foundations of mathematics Graph theory Planar graph Euler formula for a connected planar graph Planar graph edge bound
OurBigBook.com Words: 131
The complete graph K5​ has n=5 and m=(25​)=10, exceeding the planar graph edge bound 3⋅5−6=9. Therefore it is not a planar graph. The complete bipartite graph K3,3​ has n=6 and m=3⋅3=9. The general bound allows twelve edges, but the bipartite planar graph edge bound allows only eight, proving nonplanarity.
These are necessary bounds, not a complete planarity test. For an original counterexample, subdivide every edge of K3,3​ once. The resulting simple graph is a connected graph with n=15, m=18, and is bipartite: put all original vertices in one part and all nine new vertices in the other. Both inequalities hold, 18≤39 and 18≤26. Nevertheless, a crossing-free graph drawing would let us trace each two-edge graph path as one curve, producing an impossible embedding of K3,3​. The graph subdivision preserves this obstruction. Kuratowski's theorem supplies a stronger characterization than these counts.
