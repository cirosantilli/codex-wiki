Uniformly most powerful test for a gamma rate (π(θ)=Gnλ​(θcα​))

OurBigBook.com Words: 102
For an independent statistical sample from a gamma distribution with known shape λ>0 and unknown rate θ>0, test θ=θ0​ against θ>θ0​. The alternative-to-null likelihood ratio for any larger rate θ1​ is (θ1​/θ0​)nλexp{−(θ1​−θ0​)S}, where S=∑i​Xi​. This decreases in S, so the Neyman-Pearson lemma gives one common lower-tail ordering for all alternatives.
Let Ga​ be the unit-rate gamma distribution cumulative distribution function with shape a. The uniformly most powerful test of exact test size α∈(0,1) rejects when S<cα​, where cα​=Gnλ−1​(α)/θ0​. Its power function is displayed above. If nλ=1, the sum has an exponential distribution, so cα​=−log(1−α)/θ0​ and π(θ)=1−(1−α)θ/θ0​. Monotonicity of Ga​(θcα​) also makes this test valid and uniformly most powerful for the larger null hypothesis θ≤θ0​.
