A Lavrentiev gap is a strict change in an infimum when the admissible regularity class is restricted, despite retaining the same endpoint values. For example I(u)=∫01​(u3−x)2u′6dx with u(0)=0,u(1)=1 has value zero at the absolutely continuous function u=x1/3. Every Lipschitz competitor has a uniform positive lower energy bound.
