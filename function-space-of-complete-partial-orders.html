Function space of complete partial orders ([D→E])

 ... Set theory Set Partially ordered set Complete partial order Directed-complete partial order Pointed complete partial order
OurBigBook.com Words: 92 Articles: 1
The Scott continuous maps from D to E, ordered pointwise. A nonempty directed family has pointwise supremum, and the constant-bottom function is least. Joint evaluation is Scott continuous: for a directed family of pairs (fi​,xi​), directedness makes diagonal values cofinal among all fi​(xj​). Evaluation and currying make the category of pointed complete partial orders and non-strict Scott continuous maps a Cartesian closed category.
