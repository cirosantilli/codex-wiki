Expected query cost (Eμ​[qT​(X)])

 ... Computer science Theoretical computer science Computational complexity theory Decision tree model Decision tree Decision-tree query cost
OurBigBook.com Words: 159
For a fixed decision tree T and input probability distribution μ, its expected query cost is
Eμ​[qT​(X)]=∑x∈{0,1}n​μ(x)qT​(x).
(15)
Under the discrete uniform distribution on the eight three-bit inputs, the three-bit majority decision tree has
Pr(qT​(X)=2)=Pr(qT​(X)=3)=21​,E[qT​(X)]=2⋅21​+3⋅21​=25​=2.5.
(16)
This is an exact average, not a fractional query made during one execution. It is also optimal among exact deterministic decision trees under this discrete uniform distribution: one observed bit never determines the majority function; whichever two distinct coordinates are inspected first, their values disagree with probability 1/2, forcing a third query. In comparison, querying all three bits unconditionally has the same actual depth three but expected query cost three.
For an arbitrary input probability distribution, the same fixed three-bit majority decision tree gives Eμ​[qT​(X)]=2+Prμ​(X1​=X2​). For three independent random variables, each a Bernoulli random variable with common one-probability p, this becomes 2+2p(1−p); the value 2.5 depends on p=1/2. Averaging over inputs should also be distinguished from averaging over an algorithm's internal random choices at a fixed input.[ref]
