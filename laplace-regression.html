Laplace regression

OurBigBook.com Words: 193
For linear regression with fixed predictor vectors Xi​, assume conditionally independent responses with a common scale b>0:
Yi​∣Xi​∼Laplace(XiT​β,b).
(85)
Each conditional median and mean is XiT​β. The log-likelihood function is −nlog(2b)−S(β)/b, so maximum likelihood estimation minimizes the sum of absolute regression residuals:
S(β)=∑i​∣Yi​−XiT​β∣.
(86)
This is least absolute deviations. With only an intercept, it reduces to the Laplace location and scale maximum likelihood problem, so a sample median is a fitted intercept. Provided the minimum S(β​)>0, the scale estimate is b=S(β​)/n; the conditional standard deviation is 2​b. If the scale is denoted σ instead of b, the conditional standard deviation is 2​σ.
Minimizing a sum of absolute losses does not automatically give a unique coefficient vector. Even an intercept-only fit to an even sample size can have an interval of solutions, and redundant predictor columns can introduce further nonuniqueness. If a fit makes every regression residual zero, the joint likelihood function is unbounded as b↓0, so there is no finite joint maximum-likelihood estimate with positive scale.
The linear growth of absolute loss limits sensitivity to an extreme response at fixed predictors compared with squared-error loss. It does not protect against every outlier: an extreme predictor can have large regression leverage. The numerical example above changes a response in an intercept-only problem, and makes no general claim of immunity to such predictor changes.
