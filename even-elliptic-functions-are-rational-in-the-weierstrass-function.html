Even elliptic functions are rational in the Weierstrass function (f(−z)=f(z)⟹f=Q(℘))

 ... Area of mathematics Analysis Complex analysis Elliptic function Weierstrass functions Weierstrass elliptic function
OurBigBook.com Words: 103 Articles: 1
The Weierstrass elliptic function is the quotient map from the complex torus by z↦−z. An even elliptic function descends through this map; its even Laurent series at each branch point makes the descended function meromorphic there. A meromorphic function on the Riemann sphere is rational, so f=Q(℘).
