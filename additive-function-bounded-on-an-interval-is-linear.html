Additive function bounded on an interval is linear (supa<x<b​∣f(x)∣<∞⟹f(x)=xf(1))

Let f:R→R be an additive function. Suppose ∣f(x)∣≤M for all x in a nondegenerate interval (a,b), meaning a<b. Then f is continuous everywhere and f(x)=xf(1). A finite bound on even one such interval is enough; a bound at one isolated point is not.
Here is a proof outline that turns a finite bound into arbitrarily small outputs. Set z=(a+b)/2 and δ=(b−a)/2. If ∣h∣<δ, then both z and z+h lie in (a,b), so Cauchy's functional equation gives
∣f(h)∣=∣f(z+h)−f(z)∣≤2M.
(13)
Given ε>0, choose a positive integer N with 2M/N<ε. For ∣h∣<δ/N, the argument Nh lies in (−δ,δ), and rational homogeneity of an additive function gives
∣f(h)∣=N∣f(Nh)∣​≤N2M​<ε.
(14)
This proves continuity at zero. Now additive function continuous at one point is linear completes the proof. The key mechanism is that repeated addition magnifies a tiny input without escaping the bounded region, forcing the original output to be small.
