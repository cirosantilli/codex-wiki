Kernel of a linear map (kerT={v:T(v)=0})

 Home Mathematics Area of mathematics Algebra Linear algebra
OurBigBook.com Words: 2k Articles: 8
The kernel of a linear map T:V→W is the vector subspace of inputs sent to zero. Linearity makes it a vector subspace: if T(v)=T(w)=0, then T(av+bw)=0 for all scalars a,b. A vector in the kernel represents a change that the map cannot detect, since T(x+v)=T(x) for every input x.
For T:R3→R2 given by T(x,y,z)=(x+y,z), the zero-output equations are x+y=0 and z=0. Thus
kerT=span{(1,−1,0)}.
(88)
Increasing the first input while decreasing the second by the same amount leaves the output unchanged. For the linear functional φ(x,y)=2x−y, the kernel is the straight line y=2x shown in its diagram. A linear map is injective exactly when its kernel is the zero vector subspace, because T(v)=T(w) is equivalent to T(v−w)=0.
The kernel describes invisible changes, rather than all inputs that produce a specified nonzero output. If T(x0​)=b, the corresponding fiber of a function is the affine solution space of a linear equation x0​+kerT. The difference of two inputs in that fiber belongs to the kernel; an input in that fiber need not. In particular, for b=0 the fiber cannot be a vector subspace, since it does not contain the zero vector.[ref]
For the linear functional S:R2→R, S(x,y)=x+2y, the kernel is span{(2,−1)}. Each fiber S−1({c}) is the parallel straight line (c,0)+span{(2,−1)}. The input vector space is two-dimensional, but the output is one scalar: a whole straight line of inputs collapses to one point of the output real line.
