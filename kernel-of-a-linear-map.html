Kernel of a linear map (kerT={v:T(v)=0})

 Home Mathematics Area of mathematics Algebra Linear algebra
OurBigBook.com Words: 2k Articles: 8
The kernel of a linear map T:V→W is the vector subspace of inputs sent to zero. Linearity makes it a vector subspace: if T(v)=T(w)=0, then T(av+bw)=0 for all scalars a,b. A vector in the kernel represents a change that the map cannot detect, since T(x+v)=T(x) for every input x.
For T:R3→R2 given by T(x,y,z)=(x+y,z), the zero-output equations are x+y=0 and z=0. Thus
kerT=span{(1,−1,0)}.
(1)
Increasing the first input while decreasing the second by the same amount leaves the output unchanged. For the linear functional φ(x,y)=2x−y, the kernel is the straight line y=2x shown in its diagram. A linear map is injective exactly when its kernel is the zero vector subspace, because T(v)=T(w) is equivalent to T(v−w)=0.
The kernel describes invisible changes, rather than all inputs that produce a specified nonzero output. If T(x0​)=b, the corresponding fiber of a function is the affine solution space of a linear equation x0​+kerT. The difference of two inputs in that fiber belongs to the kernel; an input in that fiber need not. In particular, for b=0 the fiber cannot be a vector subspace, since it does not contain the zero vector.[ref]
For the linear functional S:R2→R, S(x,y)=x+2y, the kernel is span{(2,−1)}. Each fiber S−1({c}) is the parallel straight line (c,0)+span{(2,−1)}. The input vector space is two-dimensional, but the output is one scalar: a whole straight line of inputs collapses to one point of the output real line.

Null direction of a linear map (v=0,T(v)=0)

Words: 52
Kernel of a linear map OurBigBook.com
A null direction of a linear map T is represented by a nonzero vector v in its kernel. Every scalar multiple tv is an undetectable displacement: T(x+tv)=T(x). The vector subspace span{v} describes the direction independently of the chosen nonzero representative. More generally, a basis of the kernel supplies all independent null directions of a linear map; their number is the nullity. The zero vector belongs to the kernel but supplies no direction.

Rectangular kernel and solution-fibre example

Words: 335
Kernel of a linear map OurBigBook.com
Consider the linear map A:R3→R2 represented by the rectangular matrix
A=(10​21​01​),A​xyz​​=(x+2yy+z​).
(2)
To compute its kernel, solve the homogeneous linear system x+2y=0, y+z=0. Taking y=t gives x=−2t, z=−t, so
kerA=⎩⎨⎧​t​−21−1​​:t∈R⎭⎬⎫​,v=​−21−1​​,Av=(−2+21−1​)=0.
(3)
Thus v represents a null direction of a linear map: decreasing the first input by two, increasing the second by one, and decreasing the third by one changes neither output. Solving the homogeneous linear system is the concrete computation behind a kernel; the column space instead decides which outputs are attainable.[ref]
Now prescribe the nonzero output b=(3,2)T. The linear system Au=b becomes x+2y=3, y+z=2. Again take y=t:
u=​3−2tt2−t​​=u0​​302​​​​+tv​−21−1​​​​,t∈R.
(4)
Direct substitution gives Au0​=(3,2)T, and A(u0​+tv)=Au0​+tAv=b. Conversely, the two linear equations force exactly this form, so no solutions have been omitted. This fiber is an affine subspace of dimension one in the three-dimensional input vector space. It is parallel to the kernel, but does not pass through the origin. For instance, u0​=(3,0,2)T and u1​=(1,1,1)T both give b, while their difference u1​−u0​=v gives zero. Adding u0​ and u1​ gives output 2b, which is another way to see that this nonzero-output fiber is not a vector subspace.
The first and third columns of A are (1,0)T and (0,1)T, a basis of the output vector space. Hence A has matrix rank two and reaches every output. The rank-nullity theorem predicts nullity 3−2=1 before we solve any linear system. It provides a useful completeness check: one nonzero kernel vector already forms a basis here, so a second independent null direction of a linear map would signal a calculation error. In general, matrix rank r for an m×n matrix leaves n−r independent kernel directions, rather than m−r.[ref]

Noninjective linear measurement (T(x)=T(x′)⟺x−x′∈kerT)

Words: 216
Kernel of a linear map OurBigBook.com
When a measurement model is a linear map T, its kernel records changes that its readout cannot distinguish. For example, the rectangular kernel and solution-fibre example measures only x+2y and y+z. Even exact readouts (3,2) leave the whole fiber u0​+kerA possible. Repeating either readout with greater precision cannot distinguish those inputs: their outputs agree exactly. This ambiguity follows from a nontrivial kernel, rather than from measurement error.
Additional information can remove a null direction of a linear map. In that example, adding a third linear functional that reads y distinguishes u0​+tv, because its third readout is t. More generally, additional linear functionals c1​,…,ck​ give unique recovery of all inputs exactly when
kerT∩kerc1​∩⋯∩kerck​={0}.
(5)
This follows by applying the trivial kernel criterion to the combined linear map x↦(Tx,c1​(x),…,ck​(x)). Merely adding repeated linear equations does not meet this condition. On a finite-dimensional input vector space, each added scalar readout can increase the matrix rank by at most one, so at least dimkerT extra independent readouts are needed for recovery of unrestricted inputs.
Restrictions on the possible inputs can also make recovery unique. If the allowed inputs form a set D, two allowed inputs are indistinguishable exactly when their difference is in the kernel. Thus T is injective on D precisely when no difference of distinct points of D is a kernel vector. Such a restriction is extra information about the input; the original readout alone determines only its fiber.

Nullity of a linear map (n(T)=dimkerT)

Words: 354
Kernel of a linear map OurBigBook.com
The nullity of a linear map T:V→W is n(T)=dimkerT, the dimension of its kernel. It counts independent input directions that can change without changing the output. For a finite-dimensional vector space V, the rank-nullity theorem gives
n(T)=dimV−rankT.
(6)
For an m×n matrix A of matrix rank r, this is n−r, using the number of columns, not the number of rows. This dimension identity is [ref].
The nullity answers a practical question about a linear system: once one input is known to produce the requested output, how much freedom remains? If T(x0​)=b, its fiber of a function over b is
T−1({b})=x0​+kerT.​
(7)
Indeed, T(x)=T(x0​) exactly when T(x−x0​)=0. Thus every nonempty fiber is an affine subspace of dimension n(T), with the same direction space as the kernel. The kernel itself is the fiber over zero. Outputs outside the image of a linear map have empty fibers; the nullity does not guarantee existence, and we assign no solution-space dimension to an empty fiber here.
In the diagram, F:R2→R2 has matrix (10​10​), matrix rank one and nullity one. Its kernel has basis (1,−1), and the full solution of F(x,y)=(c,0) is (x,y)=(c,0)+s(1,−1). One free scalar moves the solution along a straight line; the output (c,1) is impossible.
The existing three-input example T(x,y,z)=(x+y,z) instead has rank two and nullity one. Its image of a linear map is all of R2, and
T−1({(a,b)})=(a,0,b)+span{(1,−1,0)}.
(8)
Every output has a solution straight line. In contrast, U(x,y,z)=(x+y,0) has rank one and nullity two, with kernel basis (1,−1,0),(0,0,1). Its reachable output (a,0) has the solution affine subspace
(x,y,z)=(a,0,0)+s(1,−1,0)+u(0,0,1),s,u∈R,
(9)
a plane, while (a,b) with b=0 has no solution. These two linear maps have the same input and output dimensions but different freedom and reachability. Computing the kernel separates what an output determines from what an extra constraint would have to fix. For either example, a basis of the kernel gives one independent free scalar per basis vector, which is why nullity measures freedom rather than the number of solutions.

Trivial kernel

Words: 237
Kernel of a linear map OurBigBook.com
A linear map T:V→W has a trivial kernel when kerT={0V​}: the zero vector is the only input producing the zero output. The kernel is a singleton set, not the empty set, because every linear map sends zero to zero. Equivalently, its nullity is zero and T is injective. This holds even without a finite-dimensional hypothesis; see Linear Algebra Done Right by Sheldon Axler (4th edition).
The reason this zero-output test controls all outputs is linearity:
T(v)=T(w)⟺T(v−w)=0⟺v−w∈kerT.
(10)
With a trivial kernel, equal outputs force equal inputs. Therefore every equation T(x)=b has at most one solution. Existence is a separate question: b must belong to the image of a linear map. In the fiber description under nullity, x0​+{0} is just the single point x0​.
For example, the linear map J:R2→R3, J(x,y)=(x,y,0), has trivial kernel and full column rank:
J=​100​010​​,kerJ={0},rankJ=2.
(11)
The output (3,4,0) comes from exactly (3,4), while (3,4,1) is unreachable. Conversely, P:R3→R2, P(x,y,z)=(x,y), is surjective and has full row rank, but its kernel is span{(0,0,1)}: every output (a,b) comes from the solution straight line (a,b,s).
For an m×n matrix, a trivial kernel is equivalent to matrix rank n and linear independence of its columns. It can therefore occur only if n≤m. If m=n, the rank-nullity theorem also forces surjectivity, giving an invertible matrix; if m>n, the example J shows why unique recovery of reachable inputs does not imply that every output is reachable. Finally, a trivial kernel guarantees exact uniqueness without guaranteeing numerical stability: the singular matrix example A(t) has trivial kernel for every t=0, even as its condition number grows without bound when t approaches zero.

Rank-nullity theorem (dimV=dimkerT+dimimT)

Words: 522 Articles: 2
Kernel of a linear map OurBigBook.com
The rank-nullity theorem accounts for the input dimensions of a linear map: the number of independent invisible input directions plus the number of independent reachable output directions equals the input dimension. For T:V→W over a field, with finite-dimensional domain of a function V,
dimV=dimkerT+dimimT.​
(12)
Here dimkerT is the nullity, and dimimT is the rank of a linear map. The kernel lives in the input vector space, while the image of a linear map lives in the output vector space. For an m-by-n matrix of matrix rank r, the formula is n=(n−r)+r: the number of columns counts input coordinates. [ref]
For a computed example over the real numbers, take
A=(10​20​),T(x,y)=A(xy​)=(x+2y,0).
(13)
The kernel is span{(−2,1)} and the image of a linear map is span{(1,0)}. Each has dimension one, so the two input dimensions split as 2=1+1. The vector (3,1) can be written
(3,1)=(1,2)+(2,−1),T(1,2)=(5,0),T(2,−1)=(0,0).
(14)
The second summand is undetectable: T(3,1)=T(1,2). The picture uses the standard dot product to choose a visible direction perpendicular to the kernel; this is a convenient geometric choice, not an extra hypothesis of the rank-nullity theorem.
This explains a practical tradeoff in a linear system. If T(x0​)=b, every other input with output b is x0​+k for k∈kerT. The nullity therefore counts independent freedom in an existing solution; the rank counts independent reachable output directions. In the example, T(x,y)=(3,0) has all solutions (x,y)=(3−2t,t), while T(x,y)=(3,1) has none. The cokernel records this failure of reachability.
For an m-by-n matrix, injectivity requires matrix rank n, and surjectivity requires matrix rank m. When m=n, these conditions differ. For example, B:R3→R2 with B(x,y,z)=(x+2y,0) has rank one and nullity two, because kerB=span{(−2,1,0),(0,0,1)}. The input accounting is 3=2+1, although only one of two output directions is reached.
Proof outline: extend a basis k1​,…,kq​ of the kernel to a basis k1​,…,kq​,v1​,…,vr​ of V. Every output is a linear combination of T(v1​),…,T(vr​) because the ki​ vanish under T. If a linear combination of the T(vj​) is zero, the corresponding combination of the vj​ lies in the kernel; linear independence of the full basis forces all its coefficients to vanish. Thus the added basis vectors give a basis of the image of a linear map. Counting them proves the formula.

Equality in the rank-sum and nullity-product inequalities

Words: 71
Rank-nullity theorem OurBigBook.com
For endomorphisms S,T of a finite-dimensional space of dimension d, r(S+T)≤r(S)+r(T) and n(ST)≤n(S)+n(T). If both equalities hold, the first gives r(S)+r(T)≤d, while the second gives 2d−r(S)−r(T)≤d. Thus the rank sum is d, S+T is an isomorphism, and ST=0. Conversely, ST=0 implies imT⊆kerS and hence rank sum at most d, whereas invertibility of S+T gives rank sum at least d. This proves both equalities.

Kernel jump in a parameter-dependent linear map

Words: 62
Rank-nullity theorem OurBigBook.com
For a matrix whose entries depend on a parameter, a nonzero maximal minor certifies a fixed matrix rank away from its zeros. At a zero, other minors must still be checked: one vanishing minor does not itself imply a rank drop. Once the matrix rank is determined, the rank-nullity theorem gives the dimension of the kernel of a linear map. Exceptional parameters can then be solved separately to exhibit the additional kernel of a linear map directions.
