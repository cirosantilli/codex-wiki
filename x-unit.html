X unit (xu)

OurBigBook.com Words: 136
The historical X unit was a practical X-ray wavelength unit, approximately 10−13m. Its scale used an assigned calcite spacing; relative wavelength measurements could be more precise than absolute determinations. Variation between crystal specimens led to calibration using reference spectral lines. An X unit value therefore cannot simply be read as an exact multiple of 10−13m.[ref]
An angular-scale check determines how an indicated rotation corresponds to an angle. A reference line transfers a wavelength scale. An absolute determination ties that scale to an independently established length standard. These are different calibration tasks. Repeating measurements can reduce random scatter without correcting the common scale: if every inferred d is too large by a chosen 0.1%, all inferred absolute wavelengths are too large by 0.1%, while ratios using that same d are unchanged.
