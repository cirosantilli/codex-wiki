Cyclic code

 Home Mathematics Area of mathematics Algebra Coding theory
OurBigBook.com Words: 904 Articles: 20
A length-n cyclic code over Fq​ is an ideal of Fq​[X]/(Xn−1). It is generated by a monic divisor of Xn−1.
