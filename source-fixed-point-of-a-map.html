Source fixed point of a map (∣λj​∣>1 for every multiplier)

 Home Physics Branches of physics Dynamical systems Fixed point stability for an iteration
OurBigBook.com Words: 46
A hyperbolic source fixed point of a smooth finite-dimensional map has every Jacobian eigenvalue outside the unit circle. Forward iteration repels nearby states. For an ordinary differential equation the analogous test instead uses positive real parts, so a source equilibrium criterion should not be substituted into a discrete map calculation.
