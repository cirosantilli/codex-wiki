Chaikin subdivision (Qi​=43​Pi​+41​Pi+1​,Ri​=41​Pi​+43​Pi+1​)

 ... Mathematics Area of mathematics Analysis Numerical analysis Computer aided geometric design Subdivision curve
OurBigBook.com Words: 986 Articles: 2
Chaikin subdivision generates a rounded subdivision curve by repeatedly cutting the corners off a control polygon. Each edge contributes two new control points, one a quarter of the way along the edge and the other three quarters of the way along it. Connecting these new control points in edge order replaces the old corners by shorter line segments. This makes Chaikin subdivision a useful way to draw a smooth outline from a small, editable set of control points, without evaluating B-spline basis functions at each drawing step. Joy presents both the corner-cutting rule and its closed version.[ref]
For a closed control polygon with n≥3 control points P0​,…,Pn−1​, set Pn​=P0​ and interpret indices cyclically. One refinement S gives
Qi​=43​Pi​+41​Pi+1​,Ri​=41​Pi​+43​Pi+1​,0≤i<n,
(25)
and the new control polygon is the ordered sequence
S(P)=(Q0​,R0​,Q1​,R1​,…,Qn−1​,Rn−1​).
(26)
Close it by joining Rn−1​ back to Q0​. Use the old control points for every average in the same refinement; updating them in place would define a different algorithm. One refinement produces 2n stored control points, and k refinements produce 2kn, counting entries even if some coordinates coincide. Open control polygons need an explicit endpoint convention: applying only the interior edge rule discards the original endpoints, whereas retaining endpoints changes the boundary rule. The closed analysis below uses cyclic indices throughout.
For a worked example, start with the rectangular control polygon
P0​=(0,0),P1​=(4,0),P2​=(4,2),P3​=(0,2).
(27)
The first edge gives Q0​=43​(0,0)+41​(4,0)=(1,0) and R0​=41​(0,0)+43​(4,0)=(3,0). Applying Chaikin subdivision to all four edges, including the closing edge, gives exactly eight control points in this order:
(1,0), (3,0), (4,21​), (4,23​), (3,2), (1,2), (0,23​), (0,21​).
(28)
Thus the rectangle becomes an octagonal control polygon. Two refinements have 16 control points, and five have 128. The illustration shows finite control polygons at stages 0,1,2,5; the last is already visually rounded but still consists of line segments.
The convex hull property follows directly from the weights. Each new control point is a convex combination of the endpoints of one old edge, because the weights are nonnegative and sum to one. Consequently, if Hk​ is the convex hull of the stage-k control points, then Hk+1​⊆Hk​. Every later line segment, and every limit point, stays in the original convex hull. This gives a useful geometric enclosure. It also explains why Chaikin subdivision is approximating rather than an interpolation rule: the rectangle's four original corners are outside the first octagon's convex hull, so the limiting curve cannot pass through them. A refinement control polygon generally lies off the limiting curve as well.
For the cyclic uniform rule, the closed limit is the periodic quadratic uniform B-spline curve determined by the original control points. Uniform refers to equal spacing in the spline knot sequence, not equal physical lengths of edges of the control polygon. An infinite uniform control sequence has the corresponding local description; arbitrary open endpoint conventions need separate treatment. Joy derives the quarter-point refinement by splitting quadratic uniform B-spline spans.[ref]
Here is an explicit description of that closed limit, with cyclic indices and a unit parameter span for each original control point:
Ci​(u)=2(1−u)2​Pi−1​+(21​+u−u2)Pi​+2u2​Pi+1​,0≤u≤1.
(29)
Each coordinate is a quadratic polynomial, and the three coefficients form a nonnegative partition of unity. The span runs from (Pi−1​+Pi​)/2 to (Pi​+Pi+1​)/2. Differentiating gives Ci′​(0)=Pi​−Pi−1​ and Ci′​(1)=Pi+1​−Pi​, so adjacent spans have matching values and matching first derivatives. Their second derivatives generally differ. Thus the parameterized curve is C1, generally not C2; degenerate control points can still make its tangent vector vanish. For the rectangle, the span around P1​=(4,0) is
C1​(u)=(2+4u−2u2, u2),C1​(21​)=(27​,41​),
(30)
which rounds the original corner between edge midpoints (2,0) and (4,1). For equally spaced abscissae, the centered Chaikin basis function gives the scalar graph version of this quadratic B-spline representation and has support of width three original grid intervals.
Another useful property is affine equivariance of a geometric basis: refining and applying an affine map commute. For T(x)=Ax+b,
T(Qi​)=A(43​Pi​+41​Pi+1​)+b=43​T(Pi​)+41​T(Pi+1​),
(31)
and the same calculation holds for Ri​. The sum-to-one weights account for the translation. Therefore T(S(P))=S(T(P)) at every refinement, and also for the limit. A designer can apply a shear mapping, translation, or other affine map to the original control polygon and obtain exactly the transformed outline.
For example, compose the shear mapping (x,y)↦(x+y/2,y) with the translation (1,−1) to obtain T(x,y)=(x+y/2+1,y−1). The rectangle's control points become (1,−1),(5,−1),(6,1),(2,1). On its right edge, cutting first gives Q1​=(4,1/2) and then T(Q1​)=(21/4,−1/2). Transforming first and cutting instead gives 43​(5,−1)+41​(6,1)=(21/4,−1/2), the same control point.
Historically, George M. Chaikin published “An algorithm for high-speed curve generation” in Computer Graphics and Image Processing 3(4), December 1974, pages 346–349. Its emphasis was practical curve generation through a recursive algorithm using simple arithmetic, with applications including machine control and three-dimensional curves. The lasting appeal of Chaikin subdivision is how an elementary local average creates an entire smooth B-spline curve.[ref]
