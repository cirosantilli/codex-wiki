Byte-lane immediate

 Home Computer science Instruction set architecture Addressing mode Immediate operand
OurBigBook.com Words: 35
An instruction encoding that stores an eight-bit byte and a two-bit byte-position selector, expanding them to a 32-bit machine word as b28j for 0≤j≤3. Four such values can construct any 32-bit constant using bitwise OR or addition modulo 232.
