Perfect code

 ... Mathematics Area of mathematics Algebra Coding theory Block code Binary block code
OurBigBook.com Words: 392 Articles: 7
A code of minimum distance d is perfect if its Hamming balls of radius ⌊(d−1)/2⌋ partition the ambient word space. Every word then has a unique nearest codeword within the code's error-correction radius.
