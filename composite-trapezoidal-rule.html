Composite trapezoidal rule (Tn​(f)=h(f(a)/2+∑j=1n−1​f(a+jh)+f(b)/2))

On an equal-panel partition of an interval, with h=(b−a)/n, sum the trapezoidal rule over adjacent panels:
Tn​(f)=h[2f(a)​+∑j=1n−1​f(a+jh)+2f(b)​].
(14)
There are n+1 distinct quadrature nodes. Each interior sample belongs to two panels and therefore has quadrature weight h, while each endpoint has quadrature weight h/2. Equivalently, the composite trapezoidal rule integrates the piecewise linear function obtained by linear interpolation exactly.[ref]
For f∈C2[a,b] and K=maxx∈[a,b]​∣f′′(x)∣, summing panel quadrature errors gives
Tn​(f)−I(f)=12b−a​h2f′′(ξ),∣Tn​(f)−I(f)∣≤12b−a​h2K
(15)
for some ξ∈(a,b). Thus panel quadrature errors of order O(h3) accumulate to order O(h2), using big O notation.[ref] On a nonuniform partition of an interval with widths hj​ and largest width H, the bound is K∑j​hj3​/12≤K(b−a)H2/12.
For the polynomial f(x)=x2 on [0,1], direct summation yields
Tn​(f)=31​+6n21​,Tn​(f)−I(f)=−2(Mn​(f)−I(f)).
(16)
Both quadrature errors shrink by exactly four when n doubles, with opposite signs. This exact relation belongs to this polynomial example; the trapezoidal rule is not always twice as inaccurate as the midpoint quadrature rule.
The left plot uses exact polynomial sums; the right adds a common sample bias δ=0.002 to the composite trapezoidal rule. That mathematical model converges to 1/3+δ, showing why smaller panels alone do not ensure accuracy for noisy samples. It illustrates noise sensitivity of a quadrature rule, rather than measured data.
