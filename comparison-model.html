Comparison model

 Home Computer science Theoretical computer science Computational complexity theory
OurBigBook.com Words: 103 Articles: 1
A model in which an algorithm learns the relative order or equality of input keys by comparisons. Lower-bound reductions must preserve the information available to each comparison; transforming numbers and allowing stronger tests without justification can change the model. For intervals (2zi​,2zi​+1) built from integers, every endpoint comparison can be simulated by comparing original keys and then fixed offsets.
