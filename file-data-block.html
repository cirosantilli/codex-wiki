File data block

 Home Computer science Operating system File system Computer file
OurBigBook.com Words: 41
A storage unit holding part of a file's contents. The toy inode references two four-byte file data blocks for six bytes of contents: allocated capacity is 2⋅4=8 bytes, while logical size is 4+2=6 bytes. This counts only the two file data blocks, excluding storage for the inode and directory entries.
