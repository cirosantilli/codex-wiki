Barker acceptance probability (β(x,y)=π(x)q(x,y)+π(y)q(y,x)π(y)q(y,x)​)

OurBigBook.com Words: 91
The Barker acceptance probability accepts a proposal using the displayed ratio. If a=π(x)q(x,y) and b=π(y)q(y,x), the accepted flux is ab/(a+b), symmetric in the two states. This proves detailed balance; define acceptance as zero when a=b=0. Rejected proposals contribute to the diagonal transition probability. Replacing π by an unnormalized target leaves the ratio unchanged. For a common proposal, t/(1+t)≤min(1,t) shows that its acceptance probability never exceeds the Metropolis–Hastings acceptance probability. The name refers to A. A. Barker's work on Monte Carlo methods for a plasma; the initials are retained without an unverified expansion.[ref]
