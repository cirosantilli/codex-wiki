Lagrange polynomial (pn​(x)=∑i=0n​yi​ℓi​(x))

 ... Mathematics Area of mathematics Analysis Numerical analysis Interpolation Polynomial interpolation
OurBigBook.com Words: 825 Articles: 6
The Lagrange polynomial writes the interpolation polynomial as a linear combination of Lagrange cardinal polynomials. Each one selects a single interpolation node, so the data values themselves become the coefficients:
pn​(x)=∑i=0n​yi​ℓi​(x),ℓi​(x)=∏0≤j≤nj=i​​xi​−xj​x−xj​​.
(144)
Distinct interpolation nodes make every denominator nonzero. At xj​, all terms vanish except yj​ℓj​(xj​)=yj​. This gives an explicit construction without solving for monomial coefficients. The elegance of the Lagrange polynomial is that it builds all constraints into the basis, leaving no equations to solve for the data values.
For (x0​,x1​,x2​)=(0,1,2) and (y0​,y1​,y2​)=(1,2,5), substitution gives
p2​(x)=2(x−1)(x−2)​−2x(x−2)+25x(x−1)​=x2+1.
(145)
At x=1/2, the Lagrange cardinal polynomial values are 3/8,3/4,−1/8, so p2​(1/2)=3/8+2(3/4)+5(−1/8)=5/4. A negative Lagrange cardinal polynomial value is allowed: these weights sum to one but need not be probabilities.
The product form is especially useful for deriving differentiation weights from nodal evaluations and quadrature rules. For repeated numerical evaluation, the barycentric interpolation formula reorganizes the same Lagrange polynomial into precomputed weights and sums; it avoids evaluating every full product at every argument.
