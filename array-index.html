Array index (i)

 Home Computer science Data structure Array (data structure)
OurBigBook.com Words: 89 Articles: 1
An integer identifying a position in an array. With zero-based indexing and capacity m, valid array indices are 0,…,m−1. An array index identifies the slot rather than its stored value.
