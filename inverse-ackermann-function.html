Inverse Ackermann function (α(n))

 ... Mathematics Area of mathematics Foundations of mathematics Computability theory Computable function Ackermann function
OurBigBook.com Words: 69
For the displayed Ackermann function convention, one possible inverse-growth scale is α(n)=min{m≥1:A(m,m)≥n} for positive integers n. It gives α(n)=1 through 3, 2 from 4 through 7, and 3 from 8 through 61. Several inverse Ackermann function conventions occur in algorithm analysis; changing convention can shift these small values without changing the very slow growth relevant to the disjoint-set data structure. This inverse-growth definition does not invert a two-variable function as an ordinary one-variable inverse function.
