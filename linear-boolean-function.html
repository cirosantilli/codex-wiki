Linear Boolean function (fa​(x)=a⋅x)

 ... Mathematics Area of mathematics Combinatorics Analysis of Boolean functions Boolean hypercube Boolean function
OurBigBook.com Words: 73
A linear Boolean function is a linear map from F2n​ to F2​. Here F2​ is the two-element finite field, whose addition is exclusive or. Every such function has a unique coefficient binary string a and takes the form
fa​(x)=a⋅x=⨁j=1n​aj​xj​.
(4)
The dot is the binary inner product. To prove the representation, expand x=∑j​xj​ej​ in the standard basis and use linearity, obtaining fa​(x)=∑j​xj​fa​(ej​); thus aj​=fa​(ej​). For example, a=101 gives fa​(x)=x1​⊕x3​. Adding a nonzero constant produces an affine map, not a linear map.
