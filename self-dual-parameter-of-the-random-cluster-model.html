Self-dual parameter of the random-cluster model (psd​(q)=q​/(1+q​))

 ... Probability and statistics Probability theory Percolation theory Site percolation Dependent percolation Random-cluster model
OurBigBook.com Words: 85 Articles: 1
Planar random-cluster duality relates edge odds by [p/(1−p)][p∗/(1−p∗)]=q. The fixed point p=p∗ has odds q​, giving the displayed parameter. A self-dual parameter does not by itself establish a critical threshold on an arbitrary planar graph. At this parameter the symmetric cluster weight at the self-dual parameter makes the primal-dual cluster counts explicit.
