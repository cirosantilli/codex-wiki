Euclidean function

 ... Area of mathematics Algebra Commutative algebra Integral domain Principal ideal domain Euclidean domain
OurBigBook.com Words: 36
A Euclidean function on an integral domain R assigns a nonnegative integer to every nonzero element so that, for a,b∈R with b=0, there are q,r∈R satisfying a=bq+r and either r=0 or d(r)<d(b).
