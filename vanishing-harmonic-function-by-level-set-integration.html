Vanishing harmonic function by level-set integration (U→0 at infinity,ΔU=0 ⟹ U=0)

 Home Mathematics Area of mathematics Analysis Partial differential equation Harmonic function
OurBigBook.com Words: 50
For a smooth harmonic function on a manifold without boundary, assume its nonzero superlevel sets are compact. On a regular positive superlevel set {U>ε}, integration by parts gives ∫∣∇U∣2=−ε∫∂{U>ε}​∣∇U∣≤0. Applying the same argument to −U proves U=0. This avoids assuming an unstated decay rate for the boundary flux at infinity.
