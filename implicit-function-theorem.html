Implicit function theorem

 ... Analysis Real analysis Calculus Multivariable calculus Differentiable map Inverse function theorem
OurBigBook.com Words: 509 Articles: 3
An equation can define a function without giving an explicit formula for it. The implicit function theorem tells us when the constraint F(x,y)=0 determines y uniquely from nearby x, and makes the resulting function continuously differentiable. It is useful when solving an equation explicitly is cumbersome or impossible: the partial derivatives already reveal whether local recovery is possible.
Let F be a continuously differentiable map from an open subset of Rm×Rn to Rn. Suppose F(x0​,y0​)=0 and the partial derivative Dy​F(x0​,y0​) is an invertible linear map. There are open neighbourhoods U of x0​ and V of y0​ and a unique continuously differentiable function g:U→V such that, for (x,y)∈U×V,
F(x,y)=0⟺y=g(x),g(x0​)=y0​.
(168)
Thus the nearby level set is a graph of a function. The derivative of this graph is
Dg(x)=−[Dy​F(x,g(x))]−1Dx​F(x,g(x)).
(169)
The matrix inverse acts on the left; the order matters in several dimensions.
For example, take the unit circle, written as the level set F(x,y)=x2+y2−1=0. At (x0​,y0​)=(3/5,4/5), Fy​=2y0​=8/5=0, so the local upper branch is y=g(x)=1−x2​. Implicit differentiation gives
g′(x)=−Fy​Fx​​=−yx​,g′(3/5)=−3/4.​
(170)
This tangent line slope is available directly from the constraint. The negative square root branch is elsewhere on the same circle; it does not destroy uniqueness near the selected upper point.
At (1,0), however, Fy​=0 and the circle cannot be represented locally as one function y=g(x): just to the left of x=1 there are two nearby values of y. The circle is still smooth there. Since Fx​=2=0, use the other coordinate instead: x=h(y)=1−y2​, with h′(0)=0. A failed coordinate choice is different from a geometric singularity.
The derivative condition is sufficient, not necessary for every possible implicit graph. For F(x,y)=y3, the entire zero set is the smooth graph y=0, even though Fy​ vanishes there. In this case the defining equation itself has a degenerate derivative; the theorem's test gives no conclusion.
The connection to the inverse function theorem is particularly elegant. Augment the constraint to the map H(x,y)=(x,F(x,y)), whose Jacobian matrix is
DH=(IDx​F​0Dy​F​).
(171)
Its determinant is detDy​F. When this is nonzero, locally invert H and set its second output to zero. The recovered second input is g(x). In this way an implicit constraint becomes an ordinary inverse function problem. [ref]
