Convex conjugate (f∗(p)=supx​(p⋅x−f(x)))

 Home Mathematics Area of mathematics Mathematical optimization Convex optimization
OurBigBook.com Words: 2k Articles: 14
The convex conjugate records a function using slopes rather than input positions. Let f:Rn→R∪{+∞} be a proper extended-real function: it is finite somewhere and never takes −∞. Its convex conjugate is
f∗(p)=supx∈Rn​{p⋅x−f(x)}=supx∈domf​{p⋅x−f(x)},p∈Rn,
(49)
where p⋅x is the dot product and domf={x:f(x)<+∞} is the effective domain. An infinite value of f excludes that input from the supremum. The value f∗(p) can be +∞, but cannot be −∞ because an input with finite f(x) supplies a finite lower bound.
The convex conjugate is automatically a convex function, even when f is not convex: each fixed input gives an affine function p↦p⋅x−f(x), and their supremum is convex. It is also lower semicontinuous. It need not be proper: for f(x)=−x2 on R, px−f(x)=px+x2 is unbounded above for every p. The definition and the automatic convexity are discussed in Boyd and Vandenberghe, Convex Optimization (2004), §3.3.1.
The best lower bound with a prescribed slope. Whenever f∗(p) is finite, the affine function
ℓp​(x)=p⋅x−f∗(p)
(50)
is an affine minorant of f. Indeed, an affine function p⋅x+b lies below f everywhere exactly when b≤infx​(f(x)−p⋅x)=−f∗(p). Thus −f∗(p) is the largest possible intercept at slope p. The convex conjugate trades positions for slopes: x specifies where to inspect f, whereas p specifies which global affine minorant to use. Taking the supremum over all these affine minorants produces the biconjugate; the Fenchel-Moreau theorem says this recovers a proper convex function when it is lower semicontinuous.
A quadratic, computed by completing the square. For the convex quadratic function f(x)=x2/2,
px−2x2​=2p2​−2(x−p)2​.
(51)
Consequently f∗(p)=p2/2, and the unique maximizing input is x=p. The affine minorant ℓp​(x)=px−p2/2 is the tangent line at (p,p2/2): its slope is p and its intercept is −f∗(p)=−p2/2. For example, p=2 gives f∗(2)=2 and the tangent line 2x−2, touching at (2,2). This is the same curve described either by its point values or by the intercepts of its tangent lines.
A corner turns into a constraint on slopes. For the absolute value f(x)=∣x∣, if ∣p∣≤1 then px−∣x∣≤0, with value zero at x=0. If p>1, taking x→+∞ makes (p−1)x→+∞; if p<−1, taking x→−∞ does the same. Therefore its convex conjugate is zero on [−1,1] and +∞ outside: it is the indicator functional of a constraint set for this interval. For ∣p∣<1 the unique maximizing input is zero; for p=1 every x≥0 maximizes, and for p=−1 every x≤0 maximizes. The corner's many supporting slopes are exactly the subdifferential ∂f(0)=[−1,1].
A supremum need not be attained. For a differentiable convex function finite on all of Rn, an input maximizes p⋅x−f(x) exactly when p=∇f(x). If f is strictly convex, there is at most one such input; existence is a separate issue. For the exponential function f(x)=ex, the derivative is positive. At p>0, solving p=ex gives x=logp and f∗(p)=plogp−p. At p=0, the supremum of −ex is zero as x→−∞, with no maximizing input. At p<0, px−ex→+∞ as x→−∞. Thus a strictly convex differentiable function can have both unattained finite conjugate values and infinite conjugate values.
