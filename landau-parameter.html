Landau parameter (Fℓs​,Fℓa​)

OurBigBook.com Words: 56
For a three-dimensional isotropic unpolarized spin-one-half Fermi liquid, define fs=(f↑↑​+f↑↓​)/2 and fa=(f↑↑​−f↑↓​)/2. Dimensionless Landau parameters use the spin-summed density of states per volume:
N∗(0)=π2ℏ3m∗pF​​,N∗(0)fs,a(cosθ)=∑ℓ=0∞​Fℓs,a​Pℓ​(cosθ).
(12)
Pℓ​ is a Legendre polynomial; s,a label spin symmetry. No extra (2ℓ+1) multiplies this expansion.[ref] The superscript s on F0s​ is unrelated to the dimensionless wave speed s below.
