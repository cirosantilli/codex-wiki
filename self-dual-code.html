Self-dual code (C=C⊥)

 ... Mathematics Area of mathematics Algebra Coding theory Linear code Dual code
OurBigBook.com Words: 98 Articles: 1
A linear code is self-dual when it equals its dual code under the standard dot product. For a length-2k code with a rank-k generator matrix G, this is equivalent to GGT=0: orthogonality gives inclusion in the dual code, and equal dimensions give equality. Over F2​, a generator matrix (I∣A) therefore generates a self-dual code exactly when AAT=I.
