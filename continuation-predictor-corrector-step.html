Continuation predictor-corrector step (zp​=zk​+htk​)

 ... Mathematics Area of mathematics Analysis Numerical analysis Continuation method Pseudo-arclength continuation
OurBigBook.com Words: 303
For the cubic polynomial, an oriented, normalized tangent vector is
tk​=1+(1−3xk2​)2​(1, 1−3xk2​)​.
(26)
Its Euclidean norm is one and DF(zk​)tk​=0. The sign here follows increasing x; for a general solution branch, choose the sign of each new tangent vector so its dot product with the previous one is positive. First predict zp​=zk​+htk​, then apply Newton method starting at zp​ to
H(z)=(F(z)tkT​(z−zp​)​)=0,DH(z)=(3x2−1tk,x​​1tk,λ​​).
(27)
The second equation keeps the correction on the transverse line in this two-dimensional example; in higher dimensions it is a hyperplane. Solving the linear system DH(z(j))δz=−H(z(j)) and updating z(j+1)=z(j)+δz corrects both coordinates together.
This step gives zp​≈(0.617556,0.424641) and zk+1​≈(0.635532,0.378840). Check both equations: the solution must satisfy x3−x+λ=0 and tkT​(z−zp​)=0. Checking only the first could accept any point on the solution branch. The new x exceeds 1/3​, so the step crosses the continuation fold, even though the predictor's λ exceeds 2/(33​).
At the seed, set a=3xk2​−1. The determinant of the correction Jacobian matrix with the exact unit vector above is
detDH(zk​)=−1+a2​=0.
(28)
At either continuation fold, a=0, tk​=(1,0) and DH(zk​)=(01​10​): the correction remains invertible. More generally, if DF has full rank and a one-dimensional kernel spanned by tk​, adding tkT​ gives an invertible matrix, since a vector annihilated by both rows must be zero. This is a local argument; the old transverse hyperplane need not work arbitrarily far along the curve. Reduce h and retry when correction fails, and check the equations and orientation after successful steps. Scaling state and parameter coordinates also matters, because it changes the Euclidean norm used to normalize the tangent vector.
