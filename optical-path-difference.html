Optical path difference (h=OPL2​−OPL1​)

 ... Physics Branches of physics Optics Physical optics Wavefront Optical path length
OurBigBook.com Words: 87 Articles: 1
An optical path difference subtracts two optical path lengths at the same frequency and with specified endpoints and sign. Its phase difference contribution is k0​h, in addition to any apparatus reference wave phase. For wavefront error, the comparison is usually between an actual wavefront and an ideal reference wavefront.
