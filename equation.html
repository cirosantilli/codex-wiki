Equation (L=R)

 Home Mathematics Area of mathematics Algebra
OurBigBook.com Words: 776 Articles: 5
An equation asserts that two mathematical expressions have the same value. Solving it means finding all allowed assignments to its variables that make that assertion true. It converts a relationship into a constraint: a measurement, a geometric intersection, or an equilibrium model can leave an unknown value to determine.
The allowed values matter. The equation 2x=1 has solution set {1/2} over the rational numbers, but the empty set over the integers. Over the real numbers, x2=1 has two solutions, −1 and 1. A mathematical identity, such as (x+1)2=x2+2x+1, holds for every permitted real x. The familiar equality sign therefore does not by itself say whether one is checking a particular value, solving for an unknown, or stating an identity.
For a worked linear equation over the real numbers,
2x+3=9⟺2x=6⟺x=3.
(2)
The first step subtracts three from both sides; the second divides both sides by the nonzero number two. Reversing the steps recovers the original equation, so these are equivalent equations with the same solution set {3}. Checking the value gives 2⋅3+3=9. The role of reversible operations and the classification by solution sets are described in College Algebra 2e, §2.2: Solving Linear Equations in One Variable.
When the two sides define real-valued functions f and g on a common domain of a function, solutions are exactly the input values at which their function graphs intersect. Equivalently, they are the zeros of a function f−g. This gives a useful connection between symbolic algebra and geometry: rearranging an equation can simplify the comparison without changing the inputs where equality holds.
Not every operation is reversible on every domain of a function. Dividing x(x−1)=0 by x gives x−1=0 only after restricting to x=0; it loses the solution x=0 if that restriction is forgotten. Squaring both sides can instead introduce an extraneous solution, because distinct real numbers can have the same square. The source equation, its domain of a function, and the direction of each implication should travel together.
