Companion matrix (C(f))

 Home Mathematics Area of mathematics Algebra Linear algebra Operator theory
OurBigBook.com Words: 123 Articles: 1
For a monic polynomial f(t)=td+cd−1​td−1+⋯+c0​, its companion matrix represents multiplication by t on the quotient module F[t]/(f) in the basis 1,t,…,td−1. With column vectors it has ones on the subdiagonal and last column (−c0​,…,−cd−1​)T. For example, C(t2+ct+d)=(01​−d−c​). Transposing this matrix gives another common convention, so the subdiagonal convention should be specified when giving entries.
