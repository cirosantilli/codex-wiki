Signed Jones evaluation at minus one (VK​(−1)=ΔK​(−1))

 ... Geometry and topology Knot theory Link Link diagram Kauffman bracket Jones polynomial
OurBigBook.com Words: 56
Use the Conway-normalized Alexander polynomial. Choosing t1/2=i in the Jones polynomial skein relation gives VL+​​(−1)−VL−​​(−1)=−2iVL0​​(−1). The quantities (−1)ℓ−1∇L​(2i) obey the same relation, because smoothing changes the component count by one. Their unlink values agree, so crossing-change induction proves equality for every link. For a knot, the sign is one and ∇K​(2i)=ΔK​(−1). This proves the signed identity, not only equality of knot determinants.
