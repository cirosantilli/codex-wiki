Phase response function (Y′=−DF(U)TY)

 ... Physics Branches of physics Dynamical systems Periodic orbit Limit cycle Phase reduction
OurBigBook.com Words: 47
A periodic phase response function describes the first-order phase shift produced by a perturbation along a limit cycle. With period-one orbit U, choose the periodic adjoint solution normalized by ∫01​Y⋅U′ds=1. The Fredholm solvability condition then projects forcing p to ∫01​Y⋅pds. For voltage-difference coupling, the averaged interaction is h(ϕ)=∫01​Y1(s)U1(s+ϕ)ds.
