Binomial goodness-of-fit with an estimated parameter (θ=mN∑j​jOj​​)

 ... Probability and statistics Statistical model Statistical modelling Statistical hypothesis test Pearson's chi-squared test Pearson chi-squared goodness-of-fit test
OurBigBook.com Words: 113
For N independent groups each containing m independent Bernoulli trials with common probability θ, the group count has a binomial distribution. If Oj​ groups have count j, the maximum-likelihood estimate is θ=∑j​jOj​/(mN). Form the Pearson chi-squared statistic using Ej​=N(jm​)θj(1−θ)m−j. With all m+1 categories retained, an interior true parameter, and sufficiently large expected counts, its null limit is a chi-squared distribution with m−1 statistical degrees of freedom: one degree is removed by the fixed total and another by fitting θ. Small expected counts require care with this approximation. If categories are pooled, the fitted parameter and calibration should correspond to the pooled statistical model; simply pooling a statistic after fitting the unpooled model does not automatically give the usual chi-squared limit.
