Fundamental theorem for line integrals

 ... Area of mathematics Analysis Real analysis Calculus Multivariable calculus Vector calculus
OurBigBook.com Words: 318 Articles: 3
For a continuously differentiable function Φ and a piecewise smooth parametric curve γ from a to b,
∫γ​∇Φ⋅dx=Φ(b)−Φ(a).
(68)
The chain rule converts the integrand into d(Φ(γ(t)))/dt, then the fundamental theorem of calculus supplies the endpoint difference. This is why a conservative vector field has a path independent line integral. For Φ(x,y)=x2+y2, every path from (0,0) to (1,2) gives 5, provided it lies in the domain where the potential is defined.
