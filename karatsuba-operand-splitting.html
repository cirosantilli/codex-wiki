Karatsuba operand splitting (x=aBm+b,y=cBm+d)

 Home Computer science Algorithm Karatsuba multiplication
OurBigBook.com Words: 140
Fix an integer base B≥2. Let x,y≥0 have at most n digits in positional notation, treating zero as one digit. For n>1, set m=⌈n/2⌉ using the ceiling function, and q=Bm. Euclidean division gives
a=⌊x/q⌋,b=x−aq,c=⌊y/q⌋,d=y−cq,
(49)
where 0≤b,d<q and 0≤a,c<Bn−m. The floor function selects the high block; the remainder selects the low block. Both operands must use the same q, including when their actual digit lengths differ.
For odd n, the low block has m digit positions and the high block has n−m=m−1. Leading zero padding aligns a shorter operand without changing its integer value. Padding to a power-of-two length is optional: the split itself works for every n. If power-of-two padding is used, the padded length is less than twice the original length, so it changes only a constant factor in the asymptotic analysis.
