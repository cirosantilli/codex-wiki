Singular matrix

 Home Mathematics Area of mathematics Algebra Linear algebra Invertible matrix
OurBigBook.com Words: 493 Articles: 1
An n×n square matrix A over a field, with n≥1, is singular when it has no matrix inverse. Geometrically, its linear map loses at least one input direction: some nonzero vector v satisfies Av=0, so A(x+v)=Ax. Over the real numbers, the following family makes that loss visible:
A(t)=(10​0t​),A(t)(x,y)=(x,ty).
(60)
For this diagonal matrix, detA(t)=t. Whenever t=0, the input can be recovered as (x,y)=(b1​,b2​/t) and the kernel is {0}. At t=0, the kernel becomes span{(0,1)}: the entire second coordinate is forgotten. Consequently A(0)x=(b1​,b2​) has no solution if b2​=0, and has the solution straight line x=(b1​,s), s∈R, if b2​=0. A singular matrix therefore need not make a particular linear system inconsistent; it prevents unique recovery when that linear system is consistent.
For an n×n square matrix, all these tests describe the same failure:
A singular⟺detA=0⟺rankA<n⟺kerA={0}⟺imA=Fn.​
(61)
Here F is the field of scalars. Equivalently, the columns are linearly dependent, the linear map is neither injective nor surjective, and some outputs cannot be reached. See the invertible matrix equivalences and Strang's MIT 18.06SC lecture summary, Multiplication and inverse matrices, p. 2. Over an infinite field, every consistent linear system for a singular matrix has infinitely many solutions; over a finite field with q elements and nullity d, it has exactly qd solutions. This follows by adding each kernel vector to one solution.
The square hypothesis is essential. For an m×n matrix, injectivity means matrix rank n (full column rank), whereas surjectivity means matrix rank m (full row rank). A rectangular matrix can satisfy one condition without the other; its kernel and image of a linear map give the useful tests without calling it a singular matrix.
Exact singularity also differs from sensitivity. For 0<∣t∣≤1, A(t) is an invertible matrix, but its smallest singular value is ∣t∣ and its condition number in Euclidean norm is 1/∣t∣. A change δb=(0,ε) changes the recovered input by δx=(0,ε/t): with t=1/100 and ε=1/1000, an output change of 0.001 causes an input change of 0.1. These are exact toy values, not measurements. The condition number quantifies this sensitivity before a direction is lost; see Steve Marschner, Condition numbers, §2. A small determinant alone is not a reliable sensitivity test: εI2​ has determinant ε2 yet condition number one for every nonzero real ε, since both singular values shrink equally.
