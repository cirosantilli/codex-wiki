Dyadic source matched to a complete prefix code (ℓ=H(p) ⟺ pi​=2−ℓi​)

OurBigBook.com Words: 68
For a complete binary prefix code with lengths ℓi​, the Kraft inequality is an equality: ∑i​2−ℓi​=1. Put qi​=2−ℓi​. The difference between expected codeword length and Shannon entropy is
ℓ−H(p)=∑i​pi​log2​qi​pi​​.
(37)
The Kullback-Leibler divergence is nonnegative and vanishes exactly when p=q. Hence a complete code is entropy-tight exactly for its dyadic matching source. For example, lengths (1,2,2) match probabilities (1/2,1/4,1/4). Being an optimal prefix code among symbol-by-symbol codes is a weaker condition and does not imply this equality.
