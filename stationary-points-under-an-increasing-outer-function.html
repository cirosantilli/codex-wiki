Stationary points under an increasing outer function (∇(F∘h)=F′(h)∇h)

 Home Mathematics Area of mathematics Analysis Calculus of variations Stationary point
OurBigBook.com Words: 82
Suppose h is differentiable and F′>0 on its range. The multivariable chain rule shows that F∘h has exactly the same stationary points as h. Since F is strictly increasing, the type of every local maximum, local minimum, and saddle point is preserved. If both functions are twice differentiable, then at a stationary point
Hess(F∘h)=F′(h)Hessh,
(14)
so the Hessian matrix signature is unchanged. The hypothesis F′>0 matters for the converse about stationary points: a strictly increasing function such as F(s)=s3 can have a zero derivative and create new stationary points in a composition.
