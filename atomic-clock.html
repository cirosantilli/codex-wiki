Atomic clock

OurBigBook.com Tags: Atomic physics Words: 647 Articles: 3
An atomic clock uses an atomic transition as a frequency reference for an oscillator; counting its calibrated cycles realizes a time interval. In a passive beam implementation, the chemical atoms are repeatedly prepared, interrogated and detected, while feedback control corrects the continuously running oscillator. The Ramsey separated oscillatory fields experiment explains how internal quantum phase becomes a measurable population signal.
The SI second fixes the unperturbed ground state hyperfine structure transition frequency of caesium-133 to exactly 9192631770Hz. This is a defining value for the ideal transition, rather than a guarantee that an operating apparatus has no shifts.[ref]
