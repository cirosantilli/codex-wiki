Loop invariant

 Home Computer science Algorithm Algorithm correctness
OurBigBook.com Words: 331 Articles: 1
A statement true whenever execution reaches a chosen point in a loop, usually immediately before its condition is tested. Establish it initially, preserve it through each iteration, and combine it with the exit condition to establish algorithm correctness. Termination needs a separate argument.[ref]
Write I for the loop invariant, B for the condition, P for the precondition, and Q for the postcondition. Prove that initialization under P establishes I, that a completed body starting with I and B restores I, and that I with false B implies Q.[ref]
In the prefix maximum correctness example, the loop invariant remembers exactly the maximum of the processed prefix and the valid index bounds. The weaker statement best≥a0​ survives every iteration, but does not imply the postcondition: for [3,1,4,4,2], the wrong value 3 satisfies it. A useful loop invariant retains enough information to recover the answer when the condition becomes false.
