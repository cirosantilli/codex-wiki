Discrete uniform moments on an integer interval (EX=(a+b)/2,Var(X)=(n2−1)/12)

Suppose the support of a probability distribution consists of all consecutive integers from a to b, including both endpoints, with a≤b. Its cardinality is n=b−a+1, and a discrete uniform distribution on it satisfies
EX=2a+b​,Var(X)=12n2−1​=12(b−a)(b−a+2)​.
(12)
For a short derivation, set K=X−a, whose possible values are 0,…,n−1. The finite sums give
∑k=0n−1​k=2n(n−1)​,∑k=0n−1​k2=6n(n−1)(2n−1)​,
(13)
and hence
EK=2n−1​,E[K2]=6(n−1)(2n−1)​,Var(K)=6(n−1)(2n−1)​−4(n−1)2​=12n2−1​.
(14)
Adding a shifts the expected value by a and leaves the variance unchanged. For completeness, the first sum follows by pairing k with n−1−k. For the second, sum (k+1)3−k3=3k2+3k+1 from k=0 to n−1: the left side is n3, so inserting the first sum gives the stated result.
The edge case a=b has n=1: X=a with probability one, expected value a, and variance zero. On an arithmetic progression {a,a+h,…,a+(n−1)h} with h>0, the same argument instead gives expected value a+h(n−1)/2 and variance h2(n2−1)/12. Equal spacing is the extra hypothesis behind these formulas; the discrete uniform distribution on {1,2,4,8} requires the general sums above.
