Concatenated quantum error-correcting code

 Home Physics Branches of physics Quantum theory Quantum error correction
OurBigBook.com Words: 124 Articles: 1
A concatenated quantum code replaces each physical qubit of an outer code by a logical qubit of an inner code. Correction proceeds from inner blocks to outer blocks. For independent errors and ideal correction, a logical-error map f iterates as pℓ+1​=f(pℓ​). This recursion describes the code/channel model and does not by itself include errors in encoding and recovery gates.
