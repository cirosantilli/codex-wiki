Repeated-root cyclic code

 Home Mathematics Area of mathematics Algebra Coding theory Cyclic code
OurBigBook.com Words: 141 Articles: 2
A repeated-root cyclic code has length divisible by the characteristic of its field, so the polynomial XN−1 has repeated factors. Its generator can involve powers of those factors. In characteristic two, length 2t gives X2t+1=(X+1)2t.
