Five values force infinitely many simple preimages (∑N≤21​∑N+21​∑Nsimple​)

 ... Isolated singularity Classification of isolated singularities Pole Meromorphic function Nevanlinna theory Nevanlinna second main theorem
OurBigBook.com Words: 68
If a transcendental meromorphic function had only finitely many simple preimages over each of five distinct finite values, their simple counting functions would be O(logr). The displayed multiplicity inequality and the Nevanlinna first main theorem would bound the truncated sum by 5Tf​/2+O(logr). The Nevanlinna second main theorem requires at least 3Tf​ up to its o(Tf​) error, a contradiction. Thus at least one value has infinitely many simple preimages; four other values can remain totally ramified.
