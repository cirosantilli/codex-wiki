Steady Euler flow with vorticity proportional to its stream function

 Home Physics Branches of physics Fluid mechanics Stream function
OurBigBook.com Words: 109
For a smooth planar incompressible flow, use u=ψy​, v=−ψx​, so its scalar vorticity is ω=−Δψ. If ω=λψ for a constant λ, the flow solves the steady constant-density Euler equations with a suitable pressure.
Indeed the vector identity for the convective acceleration gives
(u⋅∇)u=∇(∣u∣2/2)+ω∇ψ.
(55)
Therefore the pressure can be chosen so that the Bernoulli function satisfies p/ρ+∣u∣2/2=C−λψ2/2. Its gradient is −ω∇ψ, exactly the steady momentum equation. It is constant along each streamline, since the stream function is constant there.
For example ψ=sinxcosy satisfies ω=2ψ. Its pressure is p0​−ρsin2x/2+ρsin2y/2. Thus a rotational flow can have an explicit pressure and a streamline-dependent Bernoulli constant.
