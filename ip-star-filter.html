IP-star filter (FIP∗​)

 ... Combinatorics Ramsey theory Hindman theorem Finite-sums set IP set IP-star set
OurBigBook.com Words: 65
The IP-star sets form a proper filter on a set over the positive integers. Indeed, sets that are not IP sets are closed under taking subsets. They are also closed under finite unions, because the partition regularity of IP sets would otherwise put an IP set in one of the union's constituent sets. Taking complements gives upward closure and closure under finite intersections for the IP-star sets. The full set belongs to this filter and the empty set does not.
