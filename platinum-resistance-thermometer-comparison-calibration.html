Platinum resistance thermometer comparison calibration

 ... Statistical physics Thermodynamics Temperature Thermometer Resistance thermometer Platinum resistance thermometer
OurBigBook.com Words: 246
A 1998 NIST account describes stirred comparison baths, a reference SPRT with a 30 Hz resistance bridge, and a temperature-controlled 100Ω reference resistor. The test IPRTs used a 1mA current source, a scanner, and an 8½-digit voltmeter. Separate current and voltage leads made each test probe a four-terminal device; readings in both current directions supplied voltage ratios to the reference resistor.[ref]
Its program bracketed test readings with reference SPRT readings and repeated a block if bath drift was excessive. A check SPRT monitored the system; reference water-triple point measurements checked stability. Sensor depths were matched, and unfamiliar probes underwent immersion tests. Ice and water-triple point readings before and after calibration checked changes. Additional points could test the fitted curve. Reported calibration uncertainties excluded transport, subsequent drift, hysteresis, and the user's measurement system. These are controls and limits of that documented apparatus, not an accuracy promise for all platinum resistance thermometers.[ref]
The inference is a pair: reference temperature from the SPRT, test electrical resistance from the electrical readout. Record measuring electric current, wiring, immersion, and the stated reference scale with each pair. A bath controller's setpoint is not itself the calibrated reference temperature. Returning to a reference and checking intermediate points distinguishes a fitted relation from a reproducible calibration over the intended interval.
