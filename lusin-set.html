Lusin set (∣A∩M∣≤ℵ0​ for every meagre M)

 ... Analysis Topological analysis Metric space Complete metric space Baire category theorem Meagre set
OurBigBook.com Words: 109 Articles: 1
A Lusin set is an uncountable subset A of the real numbers such that A∩M is countable for every meagre set M. Every meagre subset has a meagre Fσ​ cover, so testing those covers suffices. The Lusin set construction under CH gives an example. A Lusin set has no uncountable meagre subset of itself.
