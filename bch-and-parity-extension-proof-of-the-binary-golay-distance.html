BCH and parity-extension proof of the binary Golay distance

 ... Algebra Coding theory Block code Binary block code Perfect code Binary Golay code
OurBigBook.com Words: 49
A root β of the binary Golay generator polynomial has order 23, and the Frobenius endomorphism shows that β,β2,β3,β4 are roots: 28≡3(mod23). The BCH bound gives minimum Hamming distance at least five. The circular autocorrelation of the binary Golay generator makes its parity extension doubly even, excluding original weights five and six. The generator itself has Hamming weight seven, proving that the distance is exactly seven.
