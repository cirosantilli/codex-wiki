Square-root improvement of a normalized conformal map (∣F′(z0​)∣/∣f′(z0​)∣=(1+∣a∣)/(2∣a∣​))

For a univalent function f:Ω→D with f(z0​)=0, suppose a=0 is omitted. Apply the disk automorphism Ta​ so the resulting image omits zero, take a holomorphic square root, then apply the disk automorphism taking the value at z0​ to zero. If Ω is a simply connected domain, the root exists. The resulting normalized univalent map has derivative magnitude multiplied by (1+∣a∣)/(2∣a∣​)>1, since (1−∣a∣​)2>0. Thus a map maximizing the derivative cannot omit an interior disk point.
