Branching form of the tree property

 ... Area of mathematics Foundations of mathematics Set theory Set Partially ordered set Set-theoretic tree
OurBigBook.com Words: 150
For an uncountable cardinal κ, this convention requires a cofinal branch in every separated rooted tree of height κ with fewer than κ immediate successors per node, without bounding level sizes. It is stronger than the usual tree property away from inaccessible cardinals. If cf(κ)<κ, attach chains of cofinally increasing lengths below κ above fewer than κ children of one root; this contradicts the property. If 2λ≥κ for λ<κ, take a binary tree through level λ, choose κ distinct nodes there, and attach to the ξth a chain of length ξ. It has height κ, binary branching, and no cofinal branch. Hence the property implies that κ is a strongly inaccessible cardinal. At such a cardinal a separated tree with small immediate branching has small levels, so this convention agrees with the usual tree property. It is not the different notion called the strong tree property in modern set theory.
