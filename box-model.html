Box model

 Home Mathematics Mathematical model
OurBigBook.com Words: 54
A box model represents a system by finitely many internally uniform compartments. Balances of transported material and local sources give coupled ordinary differential equations. For a constituent's concentration ci​ in fixed box volume Vi​, the stored amount is Vi​ci​; changing volumes requires the balance of that product. A transport-only closed box model preserves total inventory, even when its transport matrix is nonsymmetric.
