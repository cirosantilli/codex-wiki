All-subsequence embedding kernel (K(x,y)=∑u​ϕu​(x)ϕu​(y))

Words: 62
Positive-semidefinite kernel OurBigBook.com
Here ϕu​(x) counts increasing position embeddings of the word u as a subsequence of x. Counting embeddings retains repeated-letter multiplicities. The empty word has one embedding in every string. Prefix dynamic programming computes this positive-semidefinite kernel by F(i,j)=F(i−1,j)+F(i,j−1)−F(i−1,j−1)+1{xi​=yj​}​F(i−1,j−1) with boundary values one. The time complexity is O(∣x∣∣y∣) arithmetic operations, and rolling rows require O(min(∣x∣,∣y∣)) integer cells. Counting pairs of position subsets bounds output bit length by O(∣x∣+∣y∣).

Neural tangent kernel (kNTK​(x,x′))

Words: 85
Positive-semidefinite kernel OurBigBook.com
For a differentiable neural network f(θ,x) and initialization law P, the expected neural tangent kernel is kNTK​(x,x′)=Eθ∼P​⟨∇θ​f(θ,x),∇θ​f(θ,x′)⟩, assuming finite diagonal expectations. At a fixed parameter value the corresponding inner product defines the empirical neural tangent kernel. Both are positive-semidefinite kernels, since a finite quadratic form is respectively an expected squared norm or a squared norm. In suitable infinite-width scalings, the empirical kernel matrix converges to a deterministic limit and remains constant during training. Squared-error gradient flow then has the same training-prediction dynamics as kernel regression with this limit, provided the initial predictions match.

Mercer kernel (k(x,z))

Words: 58
Positive-semidefinite kernel OurBigBook.com
In the compact-domain spectral setting, a Mercer kernel is a continuous symmetric positive-semidefinite kernel on a compact space equipped with a finite full-support measure. Mercer's theorem yields nonnegative eigenvalues and an expansion k(x,z)=∑j​λj​ej​(x)ej​(z), giving features (λj​​ej​(x))j​ in ℓ2. The finite-Gram positivity condition on arbitrary domains is more general than these spectral hypotheses; all such kernels still have a Reproducing kernel Hilbert space realization.

Cauchy-Schwarz inequality for positive-semidefinite kernels (∣k(x,y)∣2≤k(x,x)k(y,y))

Words: 27
Positive-semidefinite kernel OurBigBook.com
A real positive-semidefinite kernel satisfies ∣k(x,y)∣2≤k(x,x)k(y,y). This follows from positivity of its two-point kernel matrix. If a diagonal value is zero, the corresponding off-diagonal values must also vanish.

On the finite formal span of symbols ex​, define B(ex​,ey​)=k(x,y) and extend bilinearly. Polynomial kernel (k(x,z)=(xTz+c)r)

Words: 127
Positive-semidefinite kernel OurBigBook.com
For x,z∈Rd, a polynomial kernel is the positive-semidefinite kernel k(x,z)=(xTz+c)r, where r is a positive integer and c≥0. The case c=0 uses monomials of total degree r; c>0 also includes lower degrees. The feature map weights matter: listing each distinct monomial once with coefficient one generally gives a different inner product.[ref]
For the homogeneous quadratic case in two dimensions, take the scaled quadratic feature map
ϕ(x1​,x2​)=​x12​2​x1​x2​x22​​​,k(x,z)=(xTz)2.
(2)
The inner product identity is explicit:
ϕ(x)Tϕ(z)=x12​z12​+2x1​x2​z1​z2​+x22​z22​=(x1​z1​+x2​z2​)2=k(x,z).
(3)
The factor 2​ accounts for the two equal cross terms in the square. Thus an inner product of three derived coordinates can be obtained from an inner product of the two input coordinates followed by squaring. The kernel trick uses this equality inside an algorithm; the feature map explains which nonlinear functions the algorithm can represent.

Integral closure of positive-semidefinite kernels

Words: 40
Closure property of positive-semidefinite kernels OurBigBook.com
Suppose kτ​ is a positive-semidefinite kernel for every τ and its diagonal entries are integrable. Positivity of each 2×2 kernel matrix gives
∣kτ​(x,y)∣≤kτ​(x,x)kτ​(y,y)​.
(4)
The Cauchy-Schwarz inequality makes every entry integrable, and integrating each nonnegative finite quadratic form shows that ∫kτ​dτ is again a positive-semidefinite kernel.

Reproducing kernel Hilbert space

A reproducing-kernel Hilbert space is a Hilbert space of functions in which point evaluation is continuous and satisfies f(x)=⟨f,k(x,⋅)⟩.

Sum of reproducing-kernel Hilbert spaces (H∑kj​​)

Words: 173 Articles: 1
Reproducing kernel Hilbert space OurBigBook.com
For positive-semidefinite kernels kj​ with Reproducing kernel Hilbert spaces Hj​, the Reproducing kernel Hilbert space of k=∑j​kj​ consists of sums f=∑j​fj​, with
∥f∥Hk​2​=min∑j​fj​=f​∑j​∥fj​∥Hj​2​.
(5)
The minimum is attained uniquely. Indeed, in the Hilbert space direct sum E=⨁j​Hj​, the tuples summing to zero form a closed subspace N: they are the intersection, over inputs x, of the kernels of the continuous maps (fj​)↦∑j​fj​(x). Every affine fibre has a unique representative in N⊥ by orthogonal decomposition by a closed subspace. The vector (kj​(⋅,x))j​ lies in N⊥ and represents evaluation in the quotient; its evaluation at y is ∑j​kj​(y,x), identifying the positive-semidefinite kernel with k.

Common representer coefficients for a sum of kernels

Words: 80
Sum of reproducing-kernel Hilbert spaces OurBigBook.com
For a real-valued loss function depending only on evaluations at x1​,…,xn​, and a positive squared-norm penalty, any minimizing tuple in a sum of reproducing-kernel Hilbert spaces has the form
f​j​=∑i=1n​αi​kj​(⋅,xi​)
(6)
with the same coefficient vector for every component. The tuple must be the unique minimum-norm decomposition of its sum. Apply the representer theorem to that sum and note that the displayed tuple has total squared norm ∑j​αTKj​α=αT(∑j​Kj​)α, exactly the norm of the sum. This argument is conditional on existence of a minimizer; arbitrary loss functions need not attain their infimum.

Kernel trick

Words: 856 Articles: 4
Reproducing kernel Hilbert space OurBigBook.com
The kernel trick evaluates inner products of feature map outputs through k(x,z)=⟨ϕ(x),ϕ(z)⟩ without explicitly constructing those vectors. An algorithm expressed entirely through these inner products can therefore operate on nonlinear derived coordinates using only evaluations of a positive-semidefinite kernel on the original inputs. A classifier linear in the derived coordinates can have a nonlinear boundary in the original coordinates.
The polynomial kernel gives a finite, fully visible example: k(x,z)=(xTz)2 corresponds to ϕ(x)=(x12​,2​x1​x2​,x22​)T. The XOR separation by a product feature below makes the interaction coordinate x1​x2​ useful, while dual prediction with a kernel shows how to predict without calculating it explicitly.
An arbitrary score called a similarity need not be a positive-semidefinite kernel. Symmetry alone, even with nonnegative entries, is insufficient: the symmetric matrix
S=(12​21​)
(9)
has aTSa=−2 for a=(1,−1)T, so it cannot be a Gram matrix of real inner products. A positive-semidefinite kernel requires a positive semidefinite matrix for every finite choice of inputs, not just the observed training data.[ref] The existing Moore-Aronszajn theorem connects this requirement to a Reproducing kernel Hilbert space; this example needs only finite linear algebra.

XOR separation by a product feature (y=−x1​x2​)

Words: 216
Kernel trick OurBigBook.com
Give the four corners of the square the exclusive or labels: +1 when the input signs differ and −1 when they agree. In the following order,
p1​=(1,1),p2​=(1,−1),p3​=(−1,1),p4​=(−1,−1),y=(−1,1,1,−1)T.
(10)
No affine function g(x)=a1​x1​+a2​x2​+b has the required strictly positive scores at p2​,p3​ and strictly negative scores at p1​,p4​: both pairs have midpoint zero, so g(p2​)+g(p3​)=2b=g(p1​)+g(p4​) would have to be both positive and negative. This also rules out perfect classification by a single threshold with a consistent tie rule.
Under the polynomial kernel's quadratic feature map, the two classes become two distinct vectors:
ϕ(p1​)=ϕ(p4​)=(1,2​,1)T,ϕ(p2​)=ϕ(p3​)=(1,−2​,1)T.
(11)
The hyperplane ϕ2​=0 separates them. With w=(0,−1/2​,0)T and b=0, the score and classifier are
f(x)=wTϕ(x)=−x1​x2​,h(x)=sgnf(x).
(12)
All four signed scores yi​f(pi​) equal one. In the input plane the boundary is x1​x2​=0, the union of the coordinate axes; in the derived coordinates it is a single hyperplane. The feature map identifies opposite corners, which is harmless for these labels because opposite corners belong to the same class. A fixed feature map would not separate labels that disagree at identical mapped vectors.

Dual prediction with a kernel (f(z)=∑i​βi​k(pi​,z)+b)

Words: 276
Kernel trick OurBigBook.com
If the weight vector lies in the linear span of the training feature map outputs, write w=∑i​βi​ϕ(pi​). Then
f(z)=wTϕ(z)+b=∑i​βi​k(pi​,z)+b.
(13)
This is a dual representation: coefficients weight training examples rather than feature coordinates. They need not be positive, and need not be unique when the kernel matrix is singular. Some kernel methods instead write βi​=αi​yi​ with αi​≥0 under their own optimization constraints.[ref] The formula is an algebraic conversion for a weight vector in this linear span, not a claim about every possible weight vector. The representer theorem gives a broader reason this form appears in regularized kernel methods.
For the XOR separation by a product feature, let Φ have rows ϕ(pi​)T. The Gram matrix of those rows, equivalently the kernel matrix, is
Φ=​1111​2​−2​−2​2​​1111​​,K=ΦΦT=((piT​pj​)2)ij​=​4004​0440​0440​4004​​.
(14)
Its eigenvalues are 8,8,0,0, so it is a positive semidefinite matrix of rank two, not an invertible matrix. More generally, for any real coefficient vector a and any finite set of inputs,
aTKa=∥∑i​ai​ϕ(pi​)∥22​≥0.
(15)
This proves the positive-semidefinite kernel condition for the displayed polynomial kernel on all of R2, rather than checking only this square.
Here Ky=8y, so the explicit choice β=y/8 gives Kβ=y and ΦTβ=w. Consequently
f(z)=8−k(p1​,z)+k(p2​,z)+k(p3​,z)−k(p4​,z)​=−z1​z2​.
(16)
For the new input z=(1,1/2), the four polynomial kernel evaluations are (9/4,1/4,1/4,9/4)T. Their weighted sum is −1/2, and the sign function predicts −1. No explicit feature map is needed for this calculation. These coefficients were constructed to reproduce the chosen separator; no fitting algorithm or generalization guarantee is being asserted.

Computational tradeoffs of the kernel trick

Words: 190
Kernel trick OurBigBook.com
For d input coordinates, the homogeneous quadratic polynomial kernel has a weighted quadratic feature map with D=d(d+1)/2 distinct monomials. Computing an inner product of already stored mapped vectors costs O(D) arithmetic operations, whereas (xTz)2 costs O(d) using the input vectors. Here O denotes big O notation. Higher fixed degrees can make the dimension gap much larger.
Sample count still matters. With n training examples, materializing a dense kernel matrix stores n2 numbers and requires n(n+1)/2 distinct evaluations using symmetry. A dense direct solve for kernel ridge regression typically takes O(n3) operations after constructing the kernel matrix, while a dual prediction with m nonzero coefficients uses m kernel evaluations. Explicit finite feature maps can be preferable when D is small relative to n, and a stored primal weight vector can make prediction depend on D rather than on n. The kernel trick by Ryan Giordano (sections Ridge regression and The polynomial kernel) explains the change from feature-coordinate equations to training-example equations; neither representation is universally faster.
The kernel trick saves explicit feature construction when the positive-semidefinite kernel is economical to evaluate; it does not remove the cost of optimization, choose a useful positive-semidefinite kernel, or establish generalization. Random Fourier features illustrate a different tradeoff: replacing the exact Gaussian kernel with a finite approximate feature map can reduce dependence on the sample count while introducing approximation error.
