Convolution kernel (Th​f=f∗h)

 Home Mathematics Area of mathematics Analysis Fourier analysis Convolution
OurBigBook.com Words: 112 Articles: 1
A convolution kernel is the fixed function h in an operator Th​f=f∗h. It specifies how shifted input values are weighted. The averaging kernel kε​ above has nonnegative values and integral one; arbitrary convolution kernels need not have either property. A linear time-invariant system uses its impulse response as a kernel when its output admits this representation.
