Binary translation of a quaternary prefix code (L2∗​≤2L4∗​≤L2∗​+1)

 ... Area of mathematics Algebra Coding theory Unique decodability Decipherable code Prefix code
OurBigBook.com Words: 75
Replacing every quaternary digit by its fixed two-bit representation preserves the prefix code property: a binary prefix between translated codewords would end at an even position and hence imply a quaternary prefix. Thus a translated quaternary Huffman code cannot beat binary Huffman coding in expected codeword length.
For the reverse bound, binary prefix code lengths ℓi​ give candidate quaternary lengths ki​=⌈ℓi​/2⌉. Since ∑i​4−ki​≤∑i​2−ℓi​≤1, the Kraft inequality supplies such a quaternary prefix code. Optimality of quaternary Huffman coding and 2⌈ℓi​/2⌉≤ℓi​+1 give 2L4∗​≤L2∗​+1. These quantities are expected codeword lengths for the same source probability distribution.
