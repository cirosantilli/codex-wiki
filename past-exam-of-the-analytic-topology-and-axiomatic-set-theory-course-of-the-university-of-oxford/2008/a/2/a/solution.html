For each point which belongs to at least one Ut​, its membership-index set is a nonempty subset of [0,1], so has an infimum in [0,1]. Assigning the value one to the other points therefore defines f:X→[0,1] everywhere.
For 0<r≤1,
{x:f(x)<r}=⋃t∈D, t<r​Ut​.
(6)
An index t<r gives f(x)≤t<r. Conversely if the infimum is below r, some membership index must be below r. Thus this strict sublevel set is open.
For 0≤r<1 we claim
{x:f(x)>r}=⋃t∈D, t>r​(X∖Ut​​).
(7)
If x∈/Ut​​ and t>r, then x cannot belong to any Us​ with s≤t, since Us​⊆Ut​ for s<t. Hence f(x)≥t>r. Conversely, if f(x)>r, density of D supplies r<t<u<f(x) with t,u∈D. Since x∈/Uu​ and Ut​​⊆Uu​, one has x∈/Ut​​. This proves the identity, and its right-hand side is open.
The remaining sublevel and superlevel sets, for thresholds outside these ranges, are either empty or all of X. Preimages of open rays are consequently open, and these rays generate the usual real topology. Therefore f is continuous. The closure inclusion is what supplies openness of the strict superlevel sets; mere nesting would not suffice.
