In first-order set theory a class in set theory is a definable collection, written schematically {x:θ(x,p​)} using a logical formula and set parameters. A class term is an abbreviation for such a defining condition; it does not add a new kind of object to the quantifiers of ZF. A class in set theory is proper if it is not the collection of elements of any set.
Define the cumulative hierarchy by transfinite recursion:
V0​=∅,Vα+1​=P(Vα​),Vλ​=⋃α<λ​Vα​(λ a nonzero limit ordinal),
(25)
and let V={x:∃α ordinal (x∈Vα​)}. Without foundation this denotes the well-founded part produced by the hierarchy; it must not simply be assumed to contain every ambient set. Transfinite recursion on ordinals and the relevant set constructions remain available in ZF without foundation.
Prove transitivity by transfinite induction. The empty stage is transitive. Suppose T=Vα​ is transitive. Then each member of T is a subset of T, so T⊆P(T). Also P(T) is transitive: if u∈v∈P(T), then u∈T and, by transitivity of T, u⊆T, so u∈P(T). At a limit stage, a union of transitive sets is transitive. This proves transitivity at every stage.
Finally transitivity of Vα​ itself implies that every member is a subset of Vα​, giving
Vα​⊆P(Vα​)=Vα+1​.​
(26)
These successive inclusions and the limit definition also imply Vα​⊆Vβ​ whenever α≤β. The argument has not used foundation. This leaf includes the unnumbered definitions preceding the source's three claims.
