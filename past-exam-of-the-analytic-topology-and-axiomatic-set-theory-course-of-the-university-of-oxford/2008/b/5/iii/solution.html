Fix a logical formula θ(x,y,p​) with parameters in V, and a set a∈V. Suppose ⟨V,∈⟩ satisfies that each x∈a has a unique y with θ(x,y,p​). Relativize every unbounded quantifier in θ to the definable class in set theory V, obtaining an ambient first-order formula θV.
Transitivity of V ensures that every member of a belongs to V. The ambient relation
y∈V ∧ θV(x,y,p​)
(29)
therefore defines a unique ambient set y for every x∈a. Apply ambient replacement to obtain its range set b. By construction every element of b belongs to V, so part (ii) gives b∈V.
Membership in this set b is exactly the range relation required by replacement inside the structure ⟨V,∈⟩. Since the logical formula and parameters were arbitrary, every instance of the replacement scheme holds in the hierarchy class in set theory. The proof uses formula relativization to a class and the closure property from part (ii), not the unsupported assertion that V is the whole ambient universe.
