A topological space is separable if it has a countable dense subset. A subset D is dense when its closure is the whole topological space, equivalently when every nonempty open set intersects D. Countable here permits a finite set, so finite topological spaces and the empty topological space fit the same definition.

A topological space is Lindelöf if every open cover has a countable subcover. We also prove the requested equivalence for metrizable spaces here, after the two source definition leaves.
Choose a compatible metric d. First suppose that D is a countable dense subset. The balls B(d0​,q) with centers d0​∈D and positive rational radii q form a countable topological basis. Indeed, if x∈U and B(x,ϵ)⊂U, choose d0​∈D with d(x,d0​)<ϵ/3 and a rational q between d(x,d0​) and ϵ−d(x,d0​). The triangle inequality gives x∈B(d0​,q)⊂U.
For any open cover, retain the topological basis elements which are contained in some member of the cover, and choose one covering member for each such topological basis element. There are only countably many choices, and the resulting subfamily covers the topological space, since each point has a topological basis neighborhood inside a covering member. Thus a separable metrizable space is Lindelöf.
Conversely, suppose the metric space is Lindelöf. For each positive integer n, the balls B(x,1/n) cover it, so select a countable subcover with centers in a countable set Dn​. The union D=⋃n≥1​Dn​ is countable and dense: if B(x,ϵ) is a nonempty open ball, choose n with 1/n<ϵ. One of the selected radius-1/n balls contains x, so its center lies in D∩B(x,ϵ). Therefore
metrizable: separable⟺Lindelo¨f.​
(1)
The metric hypothesis is used in producing uniform small-ball covers and a countable ball topological basis; the equivalence need not hold for general topological spaces.

Choose countable dense sets DX​⊆X and DY​⊆Y. Their Cartesian product is countable. Every nonempty basic open set of the product topology has the form U×V with U,V nonempty open in their respective topological spaces. Density gives dX​∈DX​∩U and dY​∈DY​∩V, hence (dX​,dY​)∈(DX​×DY​)∩(U×V).
Every nonempty open set in the product contains such a basic open set. Thus DX​×DY​ is dense in X×Y, proving topological separability of the product. If one factor is empty the product is empty and the conclusion holds directly.

The lower limit topology on the real line is the lower limit topology. Every nonempty basic interval [a,b) contains a rational number, so the rational numbers are a countable dense subset. By the preceding product argument, Q2 is dense in the square, proving its topological separability.
Consider the uncountable anti-diagonal
D={(t,−t):t∈R}.
(4)
It is a discrete subset: the basic rectangle [t,t+ϵ)×[−t,−t+ϵ) intersects D only at (t,−t), because both coordinates have increased weakly and their sum can remain zero only if neither increases.
It is also closed. At a point (u,v) off the anti-diagonal, u+v=0. If this sum is positive, every sufficiently small lower-limit rectangle based at (u,v) still has positive coordinate sum. If it is negative, choose ϵ>0 with 2ϵ<−(u+v); then [u,u+ϵ)×[v,v+ϵ) has negative coordinate sum throughout. These neighborhoods avoid D, so its complement is open.
If the square were Lindelöf, its closed discrete subset D would be countable by part (c), contradicting its bijection with R. Hence
the Sorgenfrey plane is separable but not Lindelo¨f.​

{x:f(x)>r}=⋃t∈D, t>r​(X∖Ut​​).

Urysohn's lemma states that, in a normal space, disjoint closed subsets A,B can be separated by a continuous function u:X→[0,1] with u=0 on A and u=1 on B.
First use the shrinking consequence of the separation property of a normal space: if a closed set F lies in an open set G, there is an open W with F⊆W⊆W⊆G. To prove it, separate the disjoint closed sets F and X∖G by disjoint open neighborhoods W,V. Then W⊆X∖V⊆G.
Let D be the dyadic rationals in [0,1]. Set U1​=X∖B, and shrink around A to choose U0​ with A⊆U0​⊆U0​​⊆U1​. At each subsequent dyadic stage, insert between each adjacent pair s<t an open set U(s+t)/2​ such that
Us​​⊆U(s+t)/2​⊆U(s+t)/2​​⊆Ut​.
(8)
The shrinking lemma applies because the first set is closed and contained in the last open set. Induction gives Us​​⊆Ut​ for all dyadic s<t. Part (a) now constructs a continuous u. Each point of A lies in U0​, so has value zero. Each point of B lies in none of the Ut​, so has value one. This proves the lemma.
For the embedding, let I=C(X,[0,1]), a set of continuous functions, and define the evaluation map
e:X→RI,e(x)=(u(x))u∈I​.
(9)
Every coordinate is continuous, so e is continuous in the product topology. The Hausdorff assumption makes singletons closed. For distinct points, Urysohn's lemma applied to their singletons gives a coordinate with different values, so e is injective.
To check the inverse topology, take x∈O with O open. Apply the lemma to {x} and X∖O, choosing a coordinate u with u(x)=1 and u=0 outside O. Then
x∈u−1((1/2,3/2))⊆O.
(10)
This is the preimage of an open coordinate cylinder under e. Thus every original neighborhood is detected by coordinate neighborhoods, and e−1:e[X]→X is continuous. The evaluation map is a topological embedding.

A Hausdorff compactification of X is a pair (h,Y) in which Y is compact Hausdorff and h:X→Y is a topological embedding with dense image.
For a locally compact Hausdorff noncompact topological space, form X∗=X∪{∞} with one new point. Keep all open subsets of X, and take the neighborhoods of infinity to contain sets
{∞}∪(X∖K),K⊆X compact.
(14)
Compact subsets of a Hausdorff space are closed. Finite unions of compact sets are compact, so finite intersections of these basic neighborhoods are again of the same form; their intersections with ordinary open sets are open in X. This specifies a topology restricting to the original one on X.
It is compact: from an open cover choose a member containing infinity. Its complement is contained in some compact K, and finitely many more members cover that compact remainder. It is Hausdorff: two points of X are separated as before; to separate x∈X from infinity, choose an open neighborhood U of x lying inside a compact neighborhood K. The open set U and the infinity neighborhood X∗∖K are disjoint.
The inclusion of X is an embedding. Every basic neighborhood of infinity meets X, because otherwise its compact complement K would equal all of X, contrary to noncompactness. Thus X is dense in X∗. This proves that X∗ is the one-point compactification.

A proper filter F on X is a nonempty family of subsets, closed under finite intersection and passage to supersets, with ∅∈/F. An ultrafilter is a maximal proper filter, equivalently one which contains, for each A⊆X, exactly one of A and X∖A. The pushforward filter is
f∗​F={B⊆Y:f−1[B]∈F}.
(18)
Inverse images preserve intersections and complements. Thus it is a proper filter, and the either-a-set-or-its-complement criterion shows it is an ultrafilter whenever F is one.
Convergence of a filter F→x means that every neighborhood of x belongs to F. A mapping is continuous exactly when F→x implies f∗​F→f(x) for all proper filters and points. The forward implication follows from inverse images of neighborhoods. For the converse apply the criterion to the neighborhood proper filter at x: each inverse image of a neighborhood of f(x) must be a neighborhood of x, which is continuity at x.
A topological space is compact exactly when every ultrafilter converges to at least one point; equivalently every proper filter has a cluster point. For completeness, in a compact space the closed sets A, A∈U, have the finite intersection property, hence a common point x. Every neighborhood N of x belongs to the ultrafilter. Indeed, if N did not, choose an open V with x∈V⊆N. Then V would not belong either, so X∖V would belong. That set is closed and excludes x, contradicting the choice of x in every closure. Conversely, if an open cover has no finite subcover, its closed complements generate a proper filter. An ultrafilter extension cannot converge anywhere, because each point has a covering neighborhood whose complement belongs to that ultrafilter. This proves the compactness criterion using the permitted extension principle.
Now suppose b∈f[A]​. The family
{A∩f−1[V]:V is an open neighborhood of b}
(19)
is a filter base of nonempty sets: closure guarantees each intersection is nonempty, and finite intersections correspond to intersections of neighborhoods. Extend its generated proper filter to an ultrafilter H. It contains A and every f−1[V], so f∗​H→b.
Conversely, if such an ultrafilter exists, each neighborhood V of b has f−1[V]∈H. Its intersection with A∈H is nonempty. Thus V meets f[A], proving
b∈f[A]​⟺∃H ultrafilter:A∈H, f∗​H→b.​
(20)

For every ultrafilter H on X, its image is an ultrafilter on the compact space Y, so it has a limit. That limit is unique because Y is Hausdorff: distinct limits would have disjoint neighborhoods both belonging to the same proper filter. Therefore Λ is well-defined. Since f[X] is dense, every b∈Y lies in f[X]​. Part (a), with A=X, supplies an ultrafilter mapping to b, proving surjectivity.
Suppose disjoint subsets have disjoint image closures. If H=K, choose A∈H not in K; the ultrafilter criterion gives X∖A∈K. Part (a) gives
Λ(H)∈f[A]​,Λ(K)∈f[X∖A]​.

Use the Stone-Čech extension property: a discrete topological space X embeds densely into a compact Hausdorff space βX, and every continuous map from X to a compact Hausdorff space extends continuously to βX. Apply it to the characteristic function χA​:X→{0,1} of an arbitrary subset A; discreteness makes it continuous. Its extension χ​A​ has clopen fibers, and
AβX=χ​A−1​(1).
(23)
Indeed that fiber is closed and contains A, while its openness and density of X show that every point in the fiber is approached by points of A.
If A and B are disjoint, the extension of χA​ is one on A and zero on B, so these closures are disjoint. The inclusion X→βX therefore satisfies the criterion from part (b), and its ultrafilter-limit map is both surjective and injective. Thus
Υ(X)⟷βX,H⟼the unique limit of its image filter.​

In first-order set theory a class in set theory is a definable collection, written schematically {x:θ(x,p​)} using a logical formula and set parameters. A class term is an abbreviation for such a defining condition; it does not add a new kind of object to the quantifiers of ZF. A class in set theory is proper if it is not the collection of elements of any set.
Define the cumulative hierarchy by transfinite recursion:
V0​=∅,Vα+1​=P(Vα​),Vλ​=⋃α<λ​Vα​(λ a nonzero limit ordinal),
(25)
and let V={x:∃α ordinal (x∈Vα​)}. Without foundation this denotes the well-founded part produced by the hierarchy; it must not simply be assumed to contain every ambient set. Transfinite recursion on ordinals and the relevant set constructions remain available in ZF without foundation.
Prove transitivity by transfinite induction. The empty stage is transitive. Suppose T=Vα​ is transitive. Then each member of T is a subset of T, so T⊆P(T). Also P(T) is transitive: if u∈v∈P(T), then u∈T and, by transitivity of T, u⊆T, so u∈P(T). At a limit stage, a union of transitive sets is transitive. This proves transitivity at every stage.
Finally transitivity of Vα​ itself implies that every member is a subset of Vα​, giving
Vα​⊆P(Vα​)=Vα+1​.​
(26)
These successive inclusions and the limit definition also imply Vα​⊆Vβ​ whenever α≤β. The argument has not used foundation. This leaf includes the unnumbered definitions preceding the source's three claims.

A bounded quantifier has the form ∃u∈v or ∀u∈v, abbreviating ∃u(u∈v∧⋯) or ∀u(u∈v→⋯). A Σ0​ logical formula, also called Δ0​, is built from atomic membership and equality logical formulas using Boolean connectives and only bounded quantifiers. It has no unbounded quantifier.
For example z⊆y abbreviates the bounded logical formula ∀u∈z(u∈y). Quantifiers are bounded by an existing variable or parameter, not by an unrestricted class term such as the power set of a parameter unless that set has separately been supplied as a parameter.

∃z1​⋯∃zn​ψ,ψ a Σ0​ formula,​

Use the strict-order convention appropriate to the membership relation. A bounded logical formula is
TO(x) ≡​(∀u∈x)¬(u∈u)∧(∀u∈x)(∀v∈x)(∀w∈x)((u∈v∧v∈w)→u∈w)∧(∀u∈x)(∀v∈x)(u=v∨u∈v∨v∈u).​
(31)
The first clause is irreflexivity, the second transitivity, and the third comparability of distinct elements. Irreflexivity and transitivity exclude u∈v∈u, so distinct elements cannot be ordered in both directions. These are exactly the axioms of a strict total order on the set x, with ∈ as its order relation.
Every displayed quantifier is bounded by x, so TO(x) is Σ0​. The logical formula does not assert that x is transitive as a set, and no such additional assertion is needed to say that the restriction of membership to x is a total order.

There are two ways for a set to fail to be the power set of y: it may contain an object which is not a subset of y, or omit a subset of y. A single existential logical formula expressing these alternatives is
ϕ(x,y)≡∃z[(z∈x∧(∃u∈z)u∈/y)∨(z∈/x∧(∀u∈z)u∈y)].​
(32)
Its matrix is bounded, so this is Σ1​. Its negation is precisely the first-order power-set specification
∀z(z∈x ⟷ (∀u∈z)u∈y).
(33)
We prove the absoluteness fact needed to exclude a logically equivalent Σ1​ logical formula. If M⊆N are transitive sets and all parameters lie in M, bounded logical formulas have the same truth value in ⟨M,∈⟩ and ⟨N,∈⟩. Atomic equality and membership agree because both structures use actual membership. Boolean operations preserve agreement. In a bounded quantifier over v∈M, transitivity ensures that every element of v already lies in M, so the two structures quantify over exactly the same elements of v. Induction on logical formulas proves the claim. It follows that Σ1​ logical formulas are upward absolute: witnesses in M remain available in N, and their bounded matrix retains its truth value.
Now use a finite counterexample, so no existence of a transitive model of ZF is assumed. Let M=4={0,1,2,3}, the Finite von Neumann ordinal, and let N=V4​. These are transitive sets with M⊆N. Set y=2 and x=3, both elements of M. Inside M, the subsets of 2 which are available as elements of the domain are exactly 0,1,2; the remaining domain element 3 is not a subset of 2. Thus M satisfies the displayed power-set specification with x=3.
Inside N, however, the set {1} is also present and is a subset of 2, while {1}∈/3. Thus the same specification is false in N. If ¬ϕ were logically equivalent to a Σ1​ logical formula, its truth in M would transfer upward to N, a contradiction. Therefore
¬ϕ is not logically equivalent to any Σ1​ formula.​
(34)
This proves the requested unrestricted logical non-equivalence. The finite structures are not being claimed to satisfy all of ZF; logical equivalence must hold in them as well as in any models of a stronger theory.

König theorem for cardinal numbers states that if κi​<λi​ for each index i∈I, then
i∈I∑​κi​<i∈I∏​λi​.​
(35)
Represent each cardinal by its initial ordinal, let A={(i,α):i∈I,α<κi​}, and let B=∏i∈I​λi​.
First there is an injection A→B: encode (i,α) by the function which is zero away from i and takes value α+1 at i. The nonzero coordinate identifies i, and its value identifies α. It is valid because α+1≤κi​<λi​; an index with κi​=0 contributes no domain points.
For strictness suppose a surjection F:A→B existed. At coordinate i, the values F(i,α)(i) for α<κi​ occupy fewer than λi​ possibilities. Choose bi​ as the least ordinal below λi​ absent from that set. The resulting b=(bi​)∈B differs from F(i,α) at coordinate i for every (i,α)∈A, contradicting surjectivity.
An injection B→A would produce a surjection A→B by inverting on its image and assigning the zero function elsewhere. It is therefore impossible. The injection in the first direction and impossibility of the reverse give the strict cardinal inequality. This diagonal argument uses the canonical well-orders of the specified cardinals to choose missing coordinate values, rather than an unexplained arbitrary choice at that step.

For an infinite cardinal regarded as an ordinal, its cofinality θ=cf(κ) is the least cardinality of a cofinal subset of κ. Equivalently there is a family (αi​)i<θ​ of ordinals below κ whose supremum is κ, and no smaller indexed family has that property. Since an infinite initial ordinal is a limit ordinal, θ is infinite and in particular nonzero.
Use the diagonal mechanism of König theorem for cardinal numbers directly. Suppose F:κ→θκ were surjective. For each i<θ, the set
Ei​={F(α)(i):α<αi​}
(36)
has cardinality at most ∣αi​∣<κ. Choose the least bi​∈κ∖Ei​. The resulting function b:θ→κ is not in the range: for any α<κ, cofinality supplies i with α<αi​, and then bi​=F(α)(i).
Thus no such surjection exists. Constant functions provide an injection κ→θκ, and an injection in the reverse direction would give a surjection by the same inverse-and-default construction as in part (i). Consequently
κcf(κ)>κ.​
(37)
This argument also handles κ=ℵ0​, when cofinal initial segments are finite; it does not incorrectly assume that smaller cardinals themselves must form a cofinal sequence in every infinite cardinal.

For a set M, let Def(M) consist of the subsets of M definable over the structure ⟨M,∈⟩ by a first-order formula with finitely many parameters from M. It is a set contained in P(M): satisfaction for a set structure and the set of logical formula codes give a uniform set construction of these definable subsets. If M is transitive, every a∈M is one such subset, defined over M by z∈a, so M⊆Def(M).

L0​=∅,Lα+1​=Def(Lα​),Lλ​=⋃α<λ​Lα​(λ a nonzero limit ordinal).

(41)

Every constructible set is well-orderable: the constructible hierarchy has a canonical well-order, obtained by ordering the stage of first appearance, logical formula codes and the already ordered finite parameter lists. Its restriction to any set belonging to L is a well-order in L and remains a well-order in the ambient universe. This does not imply that arbitrary ambient sets are well-orderable.
If a∈L is finite, all its subsets are finite combinations of its elements and hence constructible. Moreover the finite set of all those subsets is constructible by the finite set operations available in L. Thus the full ambient power set P(a) belongs to L.
Conversely, suppose a∈L is infinite and that its full ambient power set belonged to L. A well-order of a supplies an injection j:ω→a by taking its first countably many elements. The map
P(ω)→P(a),u⟼j[u]
(45)
is injective. But P(a)∈L would make that set well-orderable in the ambient universe, and pulling its well-order back along this injection would well-order P(ω). This contradicts the hypothesis. Hence
a∈L:PV(a)∈L⟺a is finite.​
(46)
The superscript emphasizes that the source's final claim concerns the ambient power set. The internal power set PL(a) exists in L for every a∈L by part (ii), including infinite ones.
