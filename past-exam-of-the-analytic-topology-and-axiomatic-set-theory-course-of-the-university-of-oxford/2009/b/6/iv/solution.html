To prove that power-set equality is not upward absolute, use the standard constructible universe theorem: L is a transitive inner model of ZF containing every ordinal, and set rank is absolute between L and V. Since V=L, some rank stage contains a nonconstructible set. Let α be the least ordinal with Vα​⊈L. It is not zero; it cannot be a limit, since a union of earlier stages contained in L is still contained in L. Thus α=β+1 and Vβ​⊆L.
We need not merely this inclusion, but that y=Vβ​ itself belongs to L. Inside L, ZF constructs its own rank stage (Vβ​)L, which is a set of L. By transitivity and rank absoluteness,
(Vβ​)L=Vβ​∩L=Vβ​.
(27)
Consequently y∈L. Let x=(P(y))L, the power set computed in L. Then x∈L and L⊨x=P(y).
By minimality there is z∈Vβ+1​∖L. Externally z⊆Vβ​=y, but z∈/x, because every member of the set x∈L is in the transitive class L. Hence V⊨x=P(y). Taking U1​=L and U2​=V proves power-set equality is not upward absolute, even between transitive models of ZF.
There is no contradiction with absoluteness of z⊆y: that bounded relation agrees whenever both parameters are present in the smaller class. Power-set equality quantifies over all subsets, including a new z absent from the smaller class. The step proving Vβ​∈L is essential; inclusion in a class alone would not imply membership in it.
