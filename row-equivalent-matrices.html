Row-equivalent matrices

 ... Area of mathematics Analysis Numerical analysis Numerical linear algebra Gaussian elimination Row echelon form
OurBigBook.com Words: 103
Two matrices of the same size over the same field are row-equivalent matrices if a sequence of elementary row operations transforms one into the other.[ref] Every operation is reversible, so they have the same row space and the same column linear relations. Writing the entire sequence as multiplication by an invertible matrix gives R=EA and
Az=0 ⟺ Rz=0,Ax=b ⟺ Rx=Eb.
(63)
Thus the kernel is preserved. For a nonzero right-hand side, perform every operation on the whole augmented matrix [A∣b]: changing the coefficients while keeping b fixed generally changes the solutions. The column space instead transforms to EcolA, which need not equal colA.
