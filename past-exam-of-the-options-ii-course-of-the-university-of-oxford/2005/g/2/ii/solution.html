This scalar equation determines λ numerically when needed; no explicit solution is required.
The arch is a global maximum in its smooth function graph regime. For λ>0, the integrand y−λ1+y′2​ is concave and strictly concave in its slope. Its supporting-tangent inequality, integrated against any competing function graph with the same endpoint values, has first-order term zero by the Euler-Lagrange equation. Thus J[y]−λI[y]≤J[y∗​]−λI[y∗​]. On the fixed-length class this is J[y]≤J[y∗​]; strict slope concavity also gives uniqueness.
The source leaves the length range implicit. A twice continuously differentiable function graph of this form needs λ>a, giving 2a<l<πa. At l=2a the straight function graph is the degenerate solution. The semicircle limit l=πa has vertical endpoint tangents and is outside that smooth function graph class. For l>πa, no arc in the claimed smooth function graph family exists, so the stated formula cannot describe a twice continuously differentiable maximizing function graph under those unrestricted data. Allowing overhanging curves changes the admissible class.
