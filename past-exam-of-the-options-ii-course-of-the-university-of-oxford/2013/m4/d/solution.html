The first return time τ1​ has distribution P1​(τ1​=k)=αk​. It is finite almost surely, so state one is recurrent. It is positive recurrent precisely when its mean return time is finite:
E1​τ1​=k≥1∑​kαk​<∞.​
(72)
By irreducibility the same recurrence class contains every state. Thus the condition is finiteness of the expected value of the positive-integer distribution (αk​). If that mean is infinite, the chain is null recurrent, not transient.
