Partition regularity of IP sets

 ... Area of mathematics Combinatorics Ramsey theory Hindman theorem Finite-sums set IP set
OurBigBook.com Words: 125
Every finite coloring of an IP set has a color class that is an IP set. Here is a reduction to the ordinary Hindman theorem. Given FS(xi​) in the original set, color an integer n>0 by the color of ∑i∈supp2​(n)​xi​, where the support consists of positions of its nonzero digits in the binary expansion. The Hindman theorem produces wi​>0 with monochromatic FS(wi​). Replace the wi​ by consecutive, disjoint finite block sums vj​ with separated binary supports: after a block has been chosen, take K above all previously used positions; two of 2K+1 partial sums of a fresh tail agree modulo 2K, so their positive difference supplies the next block sum divisible by 2K. Now binary addition of distinct vj​ has no carries. Therefore yj​=∑i∈supp2​(vj​)​xi​ generates a monochromatic finite-sums set in the original IP set.
