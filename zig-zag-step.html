Zig-zag step

 ... Computer science Data structure Binary tree Binary search tree Splay tree Splaying
OurBigBook.com Words: 35
When a node and its parent occupy opposite left/right directions, rotate the selected node above its parent and then above its grandparent. These two tree rotations move the selected node two levels upward while preserving the binary search tree ordering.
