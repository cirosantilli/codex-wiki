The central limit theorem gives n​(θnMC​−θ)⇒N(0,1), so, with Φ the cumulative distribution function of the standard normal distribution,
P(​θnMC​−θ​<0.01)≈2Φ(0.01n​)−1.

(5)

For routine Monte Carlo integration, the central limit theorem calculation is preferable as a practical budget: it uses about one fifteenth as many draws as the Chebyshev's inequality bound. However, its coverage is approximate. Finite variance alone supplies no universal rate of convergence to the normal distribution; an integrand with large skewness or a heavy-tailed distribution can make the approximation poor even at a large sample count. If an unconditional finite-sample 99% guarantee is required under only the stated assumptions, use the Chebyshev's inequality budget.

Integrating the envelope p≤Mq shows M≥1. One trial of rejection sampling draws Y∼q and an independent U from the uniform distribution on (0,1), and accepts Y if U≤p(Y)/(Mq(Y)). Repeat with fresh independent random variables after each rejection. Ratios need only be evaluated where q>0; the envelope makes the target zero wherever q=0.
For any measurable set B, integration of the conditional probability of acceptance gives
P(Y∈B,accept)=∫B​q(y)Mq(y)p(y)​dy=M1​∫B​p(y)dy.

θmRS​=m1​j=1∑m​ϕ(Xj​).​

Write w=p/q where q>0, assigning zero elsewhere. The envelope ensures 0≤w/M≤1, and π is nonnegative. Integrating its joint probability density over the auxiliary coordinate gives
∫01​π(x,u)du=Mq(x)Mw(x)​=p(x).
(21)
Consequently ∫Ω​∫01​π(x,u)dudx=∫Ω​p(x)dx=1. This proves normalization of a probability distribution; the change of integration order is justified by Tonelli's theorem.
The coordinates are generally dependent. For p(x)>0, their conditional probability density is
π(u∣x)=w(x)M​1[0,w(x)/M]​(u).
(22)
Thus U∣X=x has a uniform distribution on an interval whose endpoint depends on x. They are independent exactly when w(x) is constant for p-almost every x, since only then do these conditional laws agree. In particular, p=q is an exception: X∼p and U∼Unif(0,1/M) are independent. An unconditional answer that they can never be independent would therefore be too strong.

Use the same acceptance indicator functions and set Kn​=∑i=1n​Ai​, Sn​=∑i=1n​Ai​ϕ(Yi​). The rejection sampling estimator based on these n proposals is the mean over the accepted observations:
θnRS​=Kn​Sn​​(Kn​>0).​

For Kn​=0, any fixed convention, such as zero, is harmless asymptotically. The Ai​ are independent and identically distributed random variables with Bernoulli distribution and success probability 1/M, so the strong law of large numbers gives Kn​/n→1/M almost surely. In particular Kn​>0 eventually almost surely. The exact identity
θnIS​=nMKn​​θnRS​​
(27)
then holds whenever Kn​>0. Wherever Sn​=0, it follows that
θnRS​θnIS​​=nMKn​​⟶1almost surely.
(28)
A qualification is missing from the printed claim: the quotient must be defined eventually. A convenient sufficient assumption is Ep​∣ϕ∣<∞ and θ=0. Indeed, another application of the strong law of large numbers gives Sn​/n→θ/M, ensuring that Sn​ is eventually nonzero. This proves the stated quotient limit under that assumption.
As printed, the assertion is false as a universally defined quotient. For example, ϕ≡0 makes both estimates zero for every n. Even excluding that example is insufficient: take p=q to be the uniform distribution on (0,1), M=1, and ϕ(y)=1 for y<1/2 and −1 otherwise. Then Sn​ is a simple symmetric random walk, which returns to zero infinitely often almost surely, leaving the quotient undefined infinitely often.
With integrability but no assumption θ=0, the exact multiplicative identity remains valid, and both estimates converge to θ almost surely. In particular θnIS​−θnRS​→0 almost surely. One may alternatively define the quotient's removable 0/0 cases as MKn​/n; that explicitly extended quantity always converges to one. These are valid repairs of the source's unrestricted statement.

Fix a proposal y with q​(y)>0, and abbreviate B=Mq​(y), H=h(y) and P=p​(y). The envelope says 0≤H≤P≤B. Assuming fresh independent uniform distribution draws at both stages, the law of total probability gives
P(accept∣Y=y)​=BH​+(1−BH​)B−HP−H​=BH​+BP−H​=Mq​(y)p​(y)​​.​
(29)
The second term includes both reaching the residual test and passing it. If H=B, the envelope forces P=B and the first test accepts with probability one; the second-stage 0/0 ratio is never evaluated. This is squeeze rejection sampling.

The following R code implements the given recursion for the Cholesky decomposition. The input is assumed to be a real symmetric matrix that is a positive-definite matrix.
mychol <- function(A) {
  n <- nrow(A)
  if (n == 1L) return(matrix(sqrt(A[1L, 1L]), 1L, 1L))
  j <- 2L:n
  L <- matrix(0, n, n)
  L[1L, 1L] <- sqrt(A[1L, 1L])
  b <- A[j, 1L, drop = FALSE] / L[1L, 1L]
  L[j, 1L] <- b
  S <- A[j, j, drop = FALSE] - tcrossprod(b)
  L[j, j] <- mychol(S)
  L
}
Here tcrossprod(b) is the outer product bbT. The drop = FALSE arguments preserve matrix dimensions, including the final one-by-one subproblem, and the base case also returns a matrix.
To verify correctness, partition A=(ar​rTB​). The code sets ℓ=a​, b=r/ℓ and recursively factors S=B−bbT. This Schur complement is a positive-definite matrix: for z=0,
zTSz=(−rTz/az​)TA(−rTz/az​)>0.
(37)
If CCT=S is the recursive answer, then the returned lower triangular matrix satisfies
L=(ℓb​0C​),LLT=(aℓb​ℓbTbbT+CCT​)=(ar​rTB​)=A.
(38)
The one-dimensional identity starts this mathematical induction proof. Each recursive call reduces the matrix size by one and therefore terminates.

An inverse matrix exists only if the lower triangular matrix has no zero diagonal entries; this necessary assumption is implicit in the request for L−1. Partition

ltinv <- function(L) {
  n <- nrow(L)
  if (n == 1L) return(matrix(1 / L[1L, 1L], 1L, 1L))
  j <- 2L:n
  Cinv <- ltinv(L[j, j, drop = FALSE])
  B <- matrix(0, n, n)
  B[1L, 1L] <- 1 / L[1L, 1L]
  B[j, j] <- Cinv
  B[j, 1L] <- -as.vector(Cinv %*% L[j, 1L, drop = FALSE]) / L[1L, 1L]
  B
}

Each state has exactly k(n−k) neighbours: choose one occupied coordinate and one unoccupied coordinate to swap. The normalized proposal distribution is therefore
q(v∣u)=k(n−k)1​1{v∼u}​.
(41)
The swap relation is symmetric and the number of neighbours is constant, so q(v∣u)=q(u∣v). The discrete uniform distribution used as the prior distribution is also constant on Sk​, with mass (kn​)−1. Both factors cancel in the Metropolis–Hastings acceptance probability.
Let Q=Σ−1 and d=v−u. The displayed multivariate normal distribution presupposes that the covariance matrix Σ is a positive-definite matrix, so Q is a symmetric matrix. Expanding the difference of quadratic forms gives
logπ(u∣x)π(v∣x)​​=−21​{(x−v)TQ(x−v)−(x−u)TQ(x−u)}=dTQ(x−u)−21​dTQd=dTQ(x−2u+v​).​
(42)
Consequently
logα(u,v)=min{0, (v−u)TΣ−1(x−2u+v​)}.​
(43)
The truncation at zero is essential: a log acceptance ratio can be positive, but the logarithm of an acceptance probability cannot.
For the particular proposed swap, let a=i1​ be the coordinate changing from zero to one and b=i2​ the coordinate changing from one to zero. Then d=ea​−eb​, and the untruncated scalar simplifies further to
(Q(x−u))a​−(Q(x−u))b​−21​(Qaa​+Qbb​−2Qab​).​
(44)
Only two rows and four entries of Q are needed for this evaluation. This is Metropolis sampling on fixed-cardinality subsets.

The source's function name suggests a log return value, and (c)(i) asks for logα, while the wording here and in (c)(iv) asks for the acceptance probability. We use the literal probability-returning convention and explicitly exponentiate the result of (c)(i):
mylogapp <- function(x, u, v, sigma_inv) {
  d <- v - u
  log_ratio <- as.numeric(crossprod(d, sigma_inv %*% (x - (u + v) / 2)))
  log_alpha <- min(0, log_ratio)
  exp(log_alpha)
}
Thus mylogapp returns α∈[0,1], and (c)(iv) compares it directly with a uniform distribution draw. Taking the minimum before exponentiating prevents overflow. The arguments u,v are assumed to be valid neighbouring states. A log-returning convention would instead return log_alpha and compare log(runif(1)) with it; the two conventions implement the same Metropolis–Hastings algorithm, provided the caller uses the matching comparison.

Choose k distinct coordinates uniformly for the starting ones; each element of Sk​ then has starting probability 1/(kn​). At each iteration choose one current one and one current zero uniformly and swap them. This implements the normalized proposal distribution from (c)(i), remains in Sk​, and needs just one precomputed matrix inverse.
mymcmc <- function(x, k, sigma) {
  n <- length(x)
  stopifnot(length(k) == 1L, is.finite(k), k == floor(k),
            k > 0L, k < n, is.matrix(sigma),
            all(dim(sigma) == c(n, n)))
  sigma_inv <- invsigma(sigma)
  u <- integer(n)
  u[sample.int(n, k, replace = FALSE)] <- 1L
  draws <- matrix(0, 100L, n)
  for (iteration in seq_len(100L)) {
    ones <- which(u == 1L)
    zeros <- which(u == 0L)
    i <- ones[sample.int(length(ones), 1L)]
    j <- zeros[sample.int(length(zeros), 1L)]
    v <- u
    v[i] <- 0L
    v[j] <- 1L
    alpha <- mylogapp(x, u, v, sigma_inv)
    if (runif(1L) < alpha) u <- v
    draws[iteration, ] <- u
  }
  colMeans(draws)
}
Sampling positions with sample.int and then indexing into ones or zeros also works when k=1 or n−k=1. In R, a call such as sample(ones, 1) would incorrectly sample from 1:ones when ones is a single numeric value greater than one.
The code records the state after each of exactly 100 transitions, including repetitions after rejection. Its answer is the vector Monte Carlo estimator
m=1001​t=1∑100​U(t)≈E[U∣X=x].​
(46)
This estimates the posterior mean coordinate by coordinate; because each coordinate is binary, its entries estimate the posterior probabilities of inclusion. Every stored state has coordinate sum k, so the estimated means lie in [0,1] and sum to k.
For neighbouring states, the symmetry of the proposal and the Metropolis–Hastings acceptance probability give detailed balance:
π(u∣x)q(v∣u)α(u,v)=q(v∣u)min{π(u∣x),π(v∣x)}=π(v∣x)q(u∣v)α(v,u).
(47)
Thus the posterior distribution is a stationary distribution. Any two states in Sk​ can be connected by moving the ones that occupy the wrong positions, and the multivariate normal distribution gives strictly positive target masses. The resulting Markov chain is therefore an irreducible Markov chain, and its long-run state averages estimate the posterior mean.
The requested 100 iterations are a finite approximation, without a convergence guarantee or discarded burn-in. A randomly chosen starting subset has the prior distribution, rather than generally the posterior distribution. No aperiodicity assumption is needed for the finite-state Markov chain ergodic theorem for averages; indeed a uniform two-state target with n=2,k=1 gives a period-two alternating chain. This does not invalidate either the code or the state-average estimator.
