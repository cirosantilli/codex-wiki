Intensity measure of a point process (μ(A)=EΠ(A))

 Home Mathematics Area of mathematics Probability and statistics Probability theory Point process
OurBigBook.com Words: 731 Articles: 4
The intensity measure of a point process Π is its expected counting measure:
μ(A)=E[Π(A)],A∈B(E).
(11)
It may take the value +∞.[ref] Countable additivity follows by applying the monotone convergence theorem to the counts of finite unions of pairwise disjoint observation windows. If μ is locally finite and absolutely continuous with respect to Lebesgue measure, its Radon-Nikodym derivative is the intensity function of a point process λ:
μ(A)=∫A​λ(x)dx.
(12)
This is an expected number per unit volume, not a probability density function for a randomly selected point. For example, a single deterministic point has μ=δ0​, a Dirac measure, and no Lebesgue measure density. The density representation requires its own assumption.[ref]
For a bounded Borel set W, E[NW​]=μ(W), but local finiteness alone does not ensure that this expected value is finite. Conversely, μ(W)<∞ implies NW​<∞ almost surely, even when W is unbounded. A constant finite intensity function of a point process on all of Rd has infinite total intensity measure, although every bounded window has finite expected value.
