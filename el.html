EL (EL)

 Home Mathematics Area of mathematics Foundations of mathematics Mathematical logic Description logic
OurBigBook.com Words: 51 Articles: 1
The description logic generated by atomic concepts, ⊤, conjunction and existential restrictions. Some conventions also allow ⊥; that extension is distinguished here as EL with bottom. Without ⊥, every concept is satisfiable with respect to every EL TBox.
