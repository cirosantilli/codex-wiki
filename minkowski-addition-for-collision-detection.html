Minkowski addition for collision detection (Cobs​=O+(−R))

 Home Mathematics Area of mathematics Geometry and topology Convex geometry Minkowski addition
OurBigBook.com Words: 316
Suppose a robot occupies a closed set R⊆Rn relative to its chosen reference point, and a closed obstacle occupies O. Keep the robot's orientation fixed and allow only translations. At reference position q, its occupied set is q+R. If touching counts as collision, the forbidden positions in this configuration space are exactly
q∈Cobs​​⟺(q+R)∩O=∅⟺q+r=o for some r∈R, o∈O⟺q∈O+(−R),−R={−r:r∈R}.​
(18)
The minus sign reflects the robot through its reference origin: solving q+r=o gives q=o−r. Thus collision checking for a moving shape becomes checking whether one point lies in a fixed Minkowski sum. Steven M. LaValle derives this translational configuration space construction in Planning Algorithms, section 4.3.2, equation 4.37 and Example 4.13.
For a concrete toy example, take the robot rectangle R=[0,2]×[0,1] with its reference point at the lower-left corner, and obstacle rectangle O=[4,6]×[2,4]. Their collision region is the rectangle
O+(−R)=[2,6]×[1,4],λ2​(Cobs​)=4⋅3=12.
(19)
For example, q=(3,3/2) is forbidden: q+R=[3,5]×[3/2,5/2] meets O in [4,5]×[2,5/2], of area 1/2. At q=(2,1) there is just corner contact, which our convention also forbids. Using O+R=[4,8]×[2,5] instead would wrongly miss both reference positions. Only when R=−R, as for an origin-centred disk, does the reflection leave the robot set unchanged.
The same calculation handles bounded additive uncertainty. If the actual reference position is q+e for any e∈E, the union of possible occupied sets is q+(E+R). There exists an allowed error causing contact exactly when
q∈O+(−(E+R))=O+(−R)+(−E).
(20)
Consequently avoiding this set guarantees avoidance for every e∈E in this model. For E=[−ε,ε]2, the example's forbidden region becomes [2−ε,6+ε]×[1−ε,4+ε], with area (4+2ε)(3+2ε). Here −E=E because the error bounds are symmetric; a one-sided error set must still be negated. This is a worst-case geometric bound, not a probability of collision. Rotating the robot requires an orientation-dependent Minkowski sum for each orientation.
