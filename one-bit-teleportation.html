One-bit teleportation

 ... Physics Branches of physics Quantum theory Bell state Local operations and classical communication Quantum teleportation

Apply a Controlled-Z gate to input a∣0⟩+b∣1⟩ and a fresh ∣+⟩ quantum ancilla. Measuring the input in the equatorial qubit measurement basis at angle α, with outcome s, leaves the unnormalized output
2​1​(a∣+⟩+(−1)seiαb∣−⟩)=2​1​XsJ(α)∣ψ⟩.
(7)
Each branch has probability 1/2, independently of the input. The logical output is J(α)∣ψ⟩ with known Pauli frame Xs; the input qubit has been measured, so this does not clone it.
