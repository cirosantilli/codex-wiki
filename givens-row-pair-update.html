Givens row-pair update (x′=cx+sy,y′=−sx+cy)

 Home Mathematics Area of mathematics Analysis Numerical analysis Givens rotation
OurBigBook.com Words: 123
Left matrix multiplication by a Givens rotation replaces rows i,j of a matrix by
Aik′​=cAik​+sAjk​,Ajk′​=−sAik​+cAjk​.
(105)
Both right-hand sides use the old entries. An in-place algorithm must save the first result temporarily, update the second entry, and only then overwrite the first. The reference BLAS DROT implementation follows this order with its temporary DTEMP.[ref]
For elimination in column k, construct (c,s) from (Aik​,Ajk​). This sets the lower component to zero in exact arithmetic. In floating-point arithmetic the computed expression can leave a small remainder; after computing the other updated entries, explicitly store Ajk′​=0 and Aik′​=r. Previously eliminated columns stay zero if both participating rows are already zero there. This is why the ordering in QR decomposition by Givens rotations matters.
