Capability (computer security)

 Home Computer science Operating system Access matrix
OurBigBook.com Words: 94 Articles: 1
An unforgeable reference carrying authority to perform specified operations on an object. In seL4, the operating-system kernel stores security capabilities in protected slots; an integer naming a slot is not itself freely forgeable authority. Guessing another operating-system process's slot number does not give access to its security capability. [ref]
