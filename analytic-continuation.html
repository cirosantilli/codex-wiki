Analytic continuation

 Home Mathematics Area of mathematics Analysis Complex analysis Holomorphic function
OurBigBook.com Words: 119 Articles: 3
An analytic continuation extends a holomorphic function through overlapping connected open sets while preserving its values on their overlap. Continuation along different paths can produce different germs when the domain contains branch points.
