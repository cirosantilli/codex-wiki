Reed-Solomon error correction (RSk​(a1​,…,an​))

 Home Mathematics Area of mathematics Algebra Coding theory Linear code
OurBigBook.com Words: 290 Articles: 4
For distinct elements a1​,…,an​ of a finite field, a Reed-Solomon code consists of the evaluation vectors (f(a1​),…,f(an​)) of polynomials with degree less than k. It has dimension k and minimum Hamming distance n−k+1, so it is a maximum distance separable code. A nonzero polynomial has at most its degree many distinct polynomial roots. Primitive cyclic Reed-Solomon codes use all nonzero field elements, ordered as powers of a primitive root of unity; arbitrary evaluation sets need not give a cyclic code.
