Matrix logarithm (logA)

 ... Area of mathematics Algebra Linear algebra Vector space Linear map Matrix
OurBigBook.com Words: 303 Articles: 4
For a positive-definite Hermitian matrix with spectral decomposition A=Udiag(λj​)U∗, the matrix logarithm is logA=Udiag(logλj​)U∗. More generally it is a branch of the inverse of the matrix exponential when such a branch exists.
