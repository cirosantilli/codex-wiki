Locally Lipschitz function

 Home Mathematics Area of mathematics Analysis Real analysis Lipschitz continuity
OurBigBook.com Words: 24
A function is locally Lipschitz when every point has a neighborhood on which the function satisfies a Lipschitz bound. Continuously differentiable functions are locally Lipschitz.
