Matrix element (Aij​)

 ... Area of mathematics Algebra Linear algebra Vector space Linear map Matrix
OurBigBook.com Words: 79
A matrix element Aij​ is the entry in row i and column j of a matrix A.
For a linear operator T on an inner product space with an orthonormal basis (ei​), its matrix elements are Tij​=⟨ei​,Tej​⟩, using the convention that the inner product is linear in its second argument. For a finite-dimensional space, the expansion Tej​=∑i​Tij​ei​ explains why these numbers represent the linear operator in that basis. In quantum mechanics, the expression ⟨ϕ∣T∣ψ⟩ is also called a matrix element between the two states; it need not be diagonal or an expectation value.
