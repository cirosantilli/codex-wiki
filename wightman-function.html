Wightman function

 Home Physics Branches of physics Quantum field theory Quantized field Propagator
OurBigBook.com Words: 23
A Wightman function is an unordered vacuum correlation function. For a free scalar mode fk​(t), the positive-frequency two-point function is G>(t1​,t2​;k)=fk​(t1​)fk∗​(t2​).
