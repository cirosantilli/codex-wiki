Moore machine (s+=F(s,a), z=G(s))

 Home Mathematics Area of mathematics Foundations of mathematics Formal language theory Finite-state machine
OurBigBook.com Words: 272 Articles: 3
A Moore machine is a finite-state machine whose output depends only on the current state. In a clocked implementation, a state entered at a clock edge determines the following period's output. Specifying an initial state is necessary to define startup behavior.
