Second-order Euler identity for homogeneous functions (xT(∇2f)x=n(n−1)f(x))

 ... Mathematics Area of mathematics Analysis Real analysis Homogeneous function Euler theorem for homogeneous functions
OurBigBook.com Words: 67
Let f be a twice continuously differentiable function on an open domain stable under positive scaling, with f(λx)=λnf(x). Apply the chain rule twice to the scalar function λ↦f(λx) and set λ=1. The result is
i,j∑​xi​xj​∂i​∂j​f(x)=n(n−1)f(x).​
(36)
In two variables, this reads x2fxx​+2xyfxy​+y2fyy​=n(n−1)f. In matrix notation it is xT(∇2f)x=n(n−1)f, where ∇2f is the Hessian matrix. Equivalently, the radial differential operator D=∑i​xi​∂i​ obeys D2f=Df+∑i,j​xi​xj​∂i​∂j​f; substituting Df=nf explains the factor n(n−1).
