Bisection error bound (∣mk​−x∗​∣≤(b−a)/2k+1)

 ... Mathematics Area of mathematics Analysis Numerical analysis Bracketing method Bisection method
OurBigBook.com Words: 231
In exact arithmetic, after k completed halvings the retained root bracket has width Wk​=bk​−ak​ and midpoint mk​, where
Wk​=2kb−a​,mk​=2ak​+bk​​,∣mk​−x∗​∣≤2Wk​​=2k+1b−a​.
(8)
The absolute value bound holds for every zero of a function x∗​ in the current root bracket, including the one approached by continued bisection method updates. A zero of a function discarded with an earlier half need not satisfy later bounds. Before update k≥1, the evaluated candidate is mk−1​, whose corresponding guarantee is (b−a)/2k. After update k, the new midpoint mk​ has the smaller guarantee (b−a)/2k+1, even without evaluating f(mk​).
The guaranteed error halves at every step; the actual absolute value error need not decrease at every step or have successive ratio 1/2. In the square root example it increases from ∣m6​−2​∣≈0.000151062 to ∣m7​−2​∣≈0.003755188, while both errors remain below their guarantees. An exact midpoint zero of a function instead gives zero error and immediate termination. For this example 2​ is an irrational number, so no finite exact halving can produce it as a midpoint.
For a brief proof outline, each retained half has half the previous width and contains a zero of a function by the intermediate value theorem. Every point in the retained root bracket is at most half its width from its midpoint. If the process does not stop at a zero of a function, the nested interval theorem gives one common point as the widths tend to zero; continuity and the opposite endpoint signs force its function value to be zero. Uniqueness in the initial root bracket is unnecessary.
