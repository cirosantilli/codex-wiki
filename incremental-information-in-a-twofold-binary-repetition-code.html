Incremental information in a twofold binary repetition code

 Home Mathematics Area of mathematics Probability and statistics Information theory Mutual information
OurBigBook.com Words: 40
Send a uniform bit twice through independent binary symmetric channels of crossover probability p. The first received bit supplies 1−h2​(p) bits. Since the received bits disagree with probability 2p(1−p), the additional information in the second bit is
h2​(2p(1−p))−h2​(p).
