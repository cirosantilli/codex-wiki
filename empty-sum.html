Empty sum (∑i∈∅​ai​=0)

 ... Mathematics Area of mathematics Arithmetic Addition Summation Sum
OurBigBook.com Words: 56
An empty sum has no terms and is defined to be zero, the identity element for addition. This keeps the rule for combining sums valid when one index set is empty. In a Galton-Watson process, an empty generation contributes an empty sum of offspring counts, so the next generation is empty too. The corresponding convention for multiplication is the empty product, which equals one.
