Injections between successive kernel quotients (kerTi+1/kerTi↪kerTi/kerTi−1)

OurBigBook.com Words: 79
For a linear map T:V→V, set Ki​=kerTi and K0​=0. Since T(Ki+1​)⊆Ki​ and T(Ki​)⊆Ki−1​, the rule v+Ki​↦Tv+Ki−1​ defines a linear map Ki+1​/Ki​→Ki​/Ki−1​. It is injective: if Tv∈Ki−1​, then Tiv=0, so v∈Ki​. In finite dimension, this proves
dimKi+1​−dimKi​≤dimKi​−dimKi−1​.
(3)
The linear map need not be surjective: for T=0 on a nonzero vector space, its i=1 instance is 0→V. For a nilpotent linear map, these dimensions are the increments in the kernel dimensions of powers of a nilpotent map.
