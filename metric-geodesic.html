Metric geodesic (d(γ(s),γ(t))=∣s−t∣)

 ... Mathematics Area of mathematics Analysis Topological analysis Metric space Geodesic metric space
OurBigBook.com Words: 154 Articles: 1
A unit-speed metric geodesic in a metric space is an isometric embedding γ:I→X of a real interval. Every restricted segment realizes the distance between its endpoints. A one-point interval permits a constant segment. In a unit-edge graph, shortest edge paths parametrized by metric path length are metric geodesics; no smooth structure is required. This is stronger than the differential definition of a geodesic in a Riemannian manifold, which need only minimize locally: on a unit circle, an arc of angle 3π/2 is a Riemannian geodesic but its endpoint distance is only π/2.
