Block code

 Home Mathematics Area of mathematics Algebra Coding theory
OurBigBook.com Words: 1k Articles: 30
A block code assigns source messages to words of a fixed length over an alphabet. Its codewords form a subset of that fixed-length word space; a binary block code uses the two-symbol finite field F2​.
