Hereditarily countable set (Hω1​​)

 ... Mathematics Area of mathematics Foundations of mathematics Set theory Cumulative hierarchy Transitive closure
OurBigBook.com Words: 226 Articles: 4
A set is hereditarily countable when its transitive closure is countable. These sets form the transitive set Hω1​​ and all have rank below ω1​.
