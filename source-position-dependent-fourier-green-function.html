Source-position-dependent Fourier Green function (Gr′​(k;ω))

 Home Mathematics Area of mathematics Analysis Green's function
OurBigBook.com Words: 70
A static but spatially inhomogeneous linear operator has time translation symmetry without spatial translation symmetry. At fixed source position r′, one may still Fourier transform its Green function in x=r−r′. The coefficient retains r′ as a parameter. A multiplication by V(r) becomes a convolution with Vr′​(q)=eiq⋅r′V(q), not a spatially diagonal multiplier unless V is constant. Suppressing the source-position subscript is only a notational convention.
