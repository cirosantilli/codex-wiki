An error syndrome is the list of outcomes obtained by measuring a chosen ordered family of stabilizer generators. Write sj​=0 for eigenvalue +1 and sj​=1 for eigenvalue −1. For a definite Pauli error E on a code state, the rule is

For density operator ρ, the Born rule gives outcome probability tr(Πs​ρ) and conditional state Πs​ρΠs​/tr(Πs​ρ) when that probability is nonzero. A definite Pauli error has one deterministic error syndrome independent of the encoded amplitudes. A coherent linear combination of Pauli errors may occupy several sectors, so measuring the error syndrome selects a sector; recovery preserves the logical qubit when the entire error family is jointly correctable. [ref].
An error syndrome locates an error only relative to an assumed family and a recovery rule. Two Pauli errors differing by a logical operator can share an error syndrome; see stabilizer-syndrome coset. In the three-qubit bit-flip syndrome table, X3​ and X1​X2​ both give 01. Recovering with X3​ corrects the first but converts the second into the logical operator X1​X2​X3​. Likewise, Z1​ has error syndrome 00 yet changes the encoded relative phase.
