Extreme point that is not an exposed point

 Home Mathematics Area of mathematics Mathematical optimization Convex set Extreme point
OurBigBook.com Words: 208
The distinction appears at a smooth join between a straight segment and a curved boundary. Consider the convex hull
C=conv(D∪{P}),D={z:∥z∥2​≤1},P=(2,0).
(13)
The upper tangent from P meets the unit circle at T=(1/2,3​/2). The supporting line is
T⋅z=1,T⋅P=T⋅T=1.
(14)
Every point of the unit disk has T⋅z≤1, with equality only at T. Hence the convex face of C where equality holds is exactly the line segment TP.
The point T is extreme. If a nontrivial convex combination of two points of C equals T, both must belong to the convex face TP. Since T is an endpoint of that line segment, both must equal T.
Yet T is not exposed. A nonzero linear functional maximizing at T on C must also maximize there on the included unit disk. Its vector must be a positive multiple of T, by the equality condition in the Cauchy-Schwarz inequality. It then gives P the same value as T. No linear functional can select T alone. Being an extreme point is a property of possible mixtures; being an exposed point adds the ability to distinguish it by one linear objective.
