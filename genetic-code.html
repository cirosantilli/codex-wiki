Genetic code

 Home Biology Genetics Molecular genetics Gene expression Translation (biology)
OurBigBook.com Words: 1k Articles: 15
The genetic code assigns RNA codons to amino acids or termination signals. Four possible nucleobases at each of three positions give 43=64 codons. In the standard genetic code, 61 specify amino acids and three are stop codons; several codons can specify the same amino acid. Variants exist, so state which genetic code is being used. See Clark, Douglas and Choi: genetic code assignments and variants.
