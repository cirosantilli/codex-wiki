Complement of a set (X∖A)

 Home Mathematics Area of mathematics Foundations of mathematics Set theory Set
OurBigBook.com Words: 375 Articles: 1
The complement of a subset A within a specified universal set U contains exactly the set elements of U excluded from A:
Ac=U∖A={x∈U:x∈/A},x∈U⟹(x∈Ac⟺¬(x∈A)).
(5)
Here Ac depends on the chosen universal set. Within U, taking a complement performs logical negation (NOT) on membership. Writing U∖A keeps the ambient set visible when there could be ambiguity.
For A={1,2,3}, B={3,4}, and U={1,2,3,4,5,6}:
U∖A={4,5,6},U∖B={1,2,5,6}.
(6)
If the universal set grows to U′={1,2,3,4,5,6,7}, the same sets have different complements: U′∖A={4,5,6,7} and U′∖B={1,2,5,6,7}. In a database illustration, “records that fail this condition” therefore requires deciding which records are eligible to begin with; those eligible records form U.
For subsets A,B⊆U, De Morgan's laws exchange union and intersection when taking complements:
U∖(A∪B)=(U∖A)∩(U∖B),U∖(A∩B)=(U∖A)∪(U∖B).
(7)
For the same example, failing both conditions leaves U∖(A∪B)={5,6}=(U∖A)∩(U∖B). Failing at least one condition leaves U∖(A∩B)={1,2,4,5,6}=(U∖A)∪(U∖B). This is useful for rewriting exclusion rules into separate membership tests. The symmetry is also pleasing: exchanging union with intersection turns one rule into its partner.
A brief membership proof works in classical propositional logic. For any x∈U, let P mean x∈A and Q mean x∈B. The truth table below checks all four possibilities, with 1 meaning true and 0 false:
P0011​Q0101​¬(P∨Q)1000​¬P∧¬Q1000​¬(P∧Q)1110​¬P∨¬Q1110​​
(8)
Each paired column agrees. Translating logical disjunction (OR), logical conjunction (AND), and logical negation (NOT) back into membership proves the two set equalities. For the general method of reducing set equalities to equivalences in propositional logic, see Lehman, Leighton and Meyer, Mathematics for Computer Science (2015), §4.1.5 and Problem 4.5.
A historical perspective appears in Augustus De Morgan's [ref]: he describes treating each name together with its contradictory name. In the membership viewpoint here, a set and its complement likewise pair a condition with its logical negation.
