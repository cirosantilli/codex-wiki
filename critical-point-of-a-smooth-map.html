Critical point of a smooth map (rankdfx​<dimY)

 Home Mathematics Area of mathematics Geometry and topology Differential geometry
OurBigBook.com Words: 814 Articles: 1
Imagine folding a sheet along its horizontal axis by the smooth map F:R2→R2, F(x,y)=(x,y2). The inputs (a,r) and (a,−r) have the same output. Along y=0, horizontal motion still changes the output, but vertical motion produces no first-order change: F(a,ε)−F(a,0)=(0,ε2). These inputs are critical points of a smooth map even though their differential is not the zero linear map. The missing direction in the target tangent space is what matters.
Precisely, let f:Xm→Yn be a smooth map between smooth manifolds without boundary. An input p∈X is a critical point of a smooth map when its differential
dfp​:Tp​X⟶Tf(p)​Y

is not surjective, equivalently when its rank of a linear map is less than n. An input where it is surjective is a regular point; a map with no critical points of a smooth map is a submersion. The threshold is the target dimension, not min(m,n). In manifold charts, compute the matrix rank of the n×m Jacobian matrix; changes of charts preserve that matrix rank. [ref]

Thus its set of critical points of a smooth map is the entire horizontal axis. Away from that axis, its differential can produce every infinitesimal target displacement. At the axis, it can produce only horizontal ones. This diagnoses where the two inverse branches in the picture merge.
For a scalar smooth function f:X→R, the target dimension is one. A linear map to R fails to be surjective exactly when it is zero, so here a critical point of a smooth map means dfp​=0. In Euclidean space this is precisely the familiar critical point condition ∇f(p)=0: every first partial derivative vanishes. On a Riemannian manifold, it is equivalently ∇g​f(p)=0 for the chosen Riemannian metric; the Riemannian gradient depends on that metric, but whether it vanishes does not. See Loring W. Tu, An Introduction to Manifolds, Proposition 8.23 for the scalar coordinate criterion. The scalar smooth function f(t)=t3 has a critical point at zero without a local maximum or local minimum.
A source of lower dimension gives a different warning. For the smooth map G:R→R2, G(t)=(t,t2), the Jacobian matrix is the column (1,2t)T, of matrix rank one at every input. Every input is a critical point of a smooth map, since the target dimension is two, even though this parametric curve has nonzero velocity everywhere and is an immersion. More generally, if m<n, no differential Tp​X→Tf(p)​Y can be surjective, so every input is critical. The terminology measures the ability to fill target directions, rather than whether the parametrized curve looks smooth.
