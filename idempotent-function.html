Idempotent function (f∘f=f)

 ... Mathematics Area of mathematics Foundations of mathematics Set theory Function Self-map
OurBigBook.com Words: 52 Articles: 1
A self-map f:X→X is idempotent if its function composition with itself leaves it unchanged: f(f(x))=f(x) for every x. Equivalently, every element of its image of a function is a fixed point. For example, the function on {a,b,c} sending a to b, b to b, and c to c is idempotent. A second application makes no further change.
