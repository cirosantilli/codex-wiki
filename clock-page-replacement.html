CLOCK page replacement

 Home Computer science Operating system Virtual memory Paging Page replacement
OurBigBook.com Words: 58
Keep frames in a circular list with a reference flag and a scanning hand. Clear set flags while scanning; choose the first eligible frame with a clear flag. This second chance approximates LRU replacement with cheaper tracking. When hardware reference flags are absent, revoking a mapping and handling its first later page fault can supply a software reference observation.
