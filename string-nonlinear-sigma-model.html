String nonlinear sigma model

 Home Physics Branches of physics String theory Bosonic string theory Polyakov action
OurBigBook.com Words: 939 Articles: 17
The string nonlinear sigma model couples the worldsheet embedding fields to target-space backgrounds such as a metric, a Kalb–Ramond field and a dilaton. Quantum Weyl invariance requires its beta functions to vanish.
