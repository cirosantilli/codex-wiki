Nondegenerate phase-flip correction in the Steane code (⟨ψa​∣Z(u)†Z(v)∣ψb​⟩=δab​δuv​)

Write the Steane code basis as uniform quantum superpositions over a binary linear code D and a disjoint coset t+D, where D is the even-weight part of the length-seven Hamming code. For Z(w)=⨂j=17​Zjwj​​, diagonal Pauli Z gates cannot connect the two cosets. Within coset ta​+D, the overlap is
⟨ψa​∣Z(w)∣ψa​⟩=(−1)w⋅ta​∣D∣−1∑x∈D​(−1)w⋅x.
(1)
If w∈/D⊥, translation by a word x0​∈D with w⋅x0​=1 negates this sum, so it vanishes. Since the dual code D⊥ is the length-seven Hamming code of minimum Hamming distance three, every nonzero w of Hamming weight one or two has vanishing overlap. Taking u,v from {0,e1​,…,e7​} proves the displayed identity. The eight two-dimensional error images are orthogonal, so their projective measurement determines the error syndrome without revealing the logical state; applying the identified phase flip again recovers every code state. This proves nondegenerate quantum error-correcting code behaviour for the identity and all single-site phase flips, including their coherent linear span.
