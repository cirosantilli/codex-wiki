Regularized Jacobi criterion for a degenerate second variation (qη​=q+η∫∣φ′∣2)

 ... Area of mathematics Analysis Calculus of variations Second variation Conjugate point Jacobi positivity criterion
OurBigBook.com Words: 110
For continuous P≥0,Q, a scalar second variation q=∫(Pφ′2+Qφ2) is strictly positive on nonzero fixed-endpoint Lipschitz variations if and only if every regularized form qη​ for η>0 has no conjugate point in (a,b], and the original weak Jacobi boundary problem has no nonzero Lipschitz solution. The Jacobi positivity criterion applies to each regularized coefficient P+η>0. Letting η decrease to zero gives q≥0. For a nonnegative quadratic form, q(φ)=0 forces its mixed bilinear form with every test function to vanish, by considering q(φ+tψ) for both signs of t. This is the weak Jacobi equation, so the kernel condition gives strict positivity. Necessity follows by the same argument in reverse. It distinguishes strict positivity from a uniform coercive estimate when the derivative coefficient degenerates.
