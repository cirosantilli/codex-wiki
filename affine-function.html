Affine function

 ... Area of mathematics Algebra Linear algebra Vector space Linear map Linear function
OurBigBook.com Words: 73 Articles: 1
An affine function on a real or complex vector space has the form x↦Lx+b, where L is a linear map and b is constant. Its derivative is the constant map L. It is linear exactly when b=0.
