Strictly convex function

 Home Mathematics Area of mathematics Analysis Real analysis Convex function
OurBigBook.com Words: 43 Articles: 1
A function f on a convex set is strictly convex when
f(tx+(1−t)y)<tf(x)+(1−t)f(y)
(49)
whenever x=y and 0<t<1.
