Zero-frequency cancellation of a causal response kernel (∫I(t)dt=K(0)V(0))

 Home Physics Branches of physics Statistical physics Linear response theory
OurBigBook.com Words: 68
For an integrable linear response kernel K and input V, the convolution theorem gives I(ω)=K(ω)V(ω). The integrated output is therefore zero for every integrable input if and only if K(0)=∫K(t)dt=0. For a sum of causal damped sines, K(t)=Θ(t)∑j​aj​e−γj​tsin(pj​t), the condition is ∑j​aj​pj​/(γj2​+pj2​)=0. If all aj​ are positive, nonzero terms of both signs are needed; a term with pj​=0 vanishes identically.
