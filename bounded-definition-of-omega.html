Bounded definition of omega (x=ω)

 ... Set theory Class (set theory) Transitive class Formula relativization to a class Set-theoretic absoluteness Lévy hierarchy
OurBigBook.com Words: 56
In ZF, ω is the least nonzero limit ordinal. Ordinality is expressed by a bounded formula in set theory asserting transitivity and strict total membership order, with well-foundedness supplied by the Axiom of foundation. Put L(x)=Ord(x)∧x=∅∧∀y∈x∃z∈x(y∈z). Then x=ω is equivalent over ZF to L(x)∧∀y∈x¬L(y), again bounded. Therefore nested transitive models of ZF have the same ω.
