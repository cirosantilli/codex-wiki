Solution-set condition

 ... Mathematics Area of mathematics Foundations of mathematics Category theory Category Comma category
OurBigBook.com Words: 47
For U:C→D, the left-adjoint solution-set condition requires a weakly initial set in every (D↓U). Equivalently, there is a set of arrows di​:D→UCi​ through which every d:D→UC factors as U(h)di​. The dual right-adjoint condition asks for weakly terminal solution sets in (U↓D).
