A state on a C-star algebra is a positive linear functional of norm one. In the unital case this is equivalent to positivity and x(1)=1. A unital star-homomorphism π:A→B(K) is a cyclic representation of a C-star algebra if it has a vector ξ with π(A)ξ​=K. For the representation associated with a state, the cyclic vector is taken to have norm one.
Use inner products linear in the first argument, as in the displayed formula for the projection in the source. In the Gelfand–Naimark–Segal construction, set
Nx​={a∈A:x(a∗a)=0},⟨[a],[b]⟩=x(b∗a).
(11)
The Cauchy–Schwarz inequality for positive C-star functionals makes this inner product well-defined on A/Nx​. Indeed a null vector pairs to zero with every vector. The set Nx​ is a left ideal: c∗c≤∥c∥21 implies
x((ca)∗(ca))≤∥c∥2x(a∗a),
(12)
so a∈Nx​ implies ca∈Nx​. The same estimate shows that left multiplication induces a bounded operator
πx​(c)[a]=[ca],∥πx​(c)∥≤∥c∥.
(13)
Complete the quotient pre-Hilbert space to Hx​, and extend these operators by continuity. The formula for the inner product gives πx​(c)∗=πx​(c∗), while multiplication and the unit are preserved. Put ξx​=[1]. Then ∥ξx​∥=1, the vectors πx​(a)ξx​=[a] are dense in Hx​, and
x(a)=⟨πx​(a)ξx​,ξx​⟩.​
(14)
This gives the requested cyclic representation for an arbitrary state.
For the specified unit vector η, the functional xη​ is complex-linear and obeys ∣xη​(a)∣≤∥aη∥∥η∥≤∥a∥. Moreover
xη​(1)=1,xη​(a∗a)=∥aη∥2≥0.
(15)
Thus it is positive and has norm exactly one, proving that xη​ is a vector state on a C-star algebra.
The rank-one projection satisfies
(apη​)(ζ)=⟨ζ,η⟩aη.
(16)
If aη=0, this is zero for every ζ, so apη​=0. Conversely, evaluation at ζ=η gives (apη​)η=aη. Hence
aη=0⟺apη​=0.​
(17)
In particular Nxη​​={a:aη=0}={a:apη​=0}.
The concrete GNS space is the completion of A/Nxη​​ with
⟨[a],[b]⟩=xη​(b∗a)=⟨aη,bη⟩.
(18)
Define U0​[a]=aη. The description of the null ideal proves it is well-defined, and the displayed equality proves it is a linear isometry with range Aη. It therefore extends to an isometry U:Hxη​​→Aη​. The extended range is closed, since its domain is complete, and contains the dense set Aη. Thus U is onto the required closure.
In fact here A=B(H), so Aη=H: given any ζ∈H, the bounded rank-one operator b(v)=⟨v,η⟩ζ sends η to ζ. Thus U is a unitary map onto all of H, and Uξxη​​=η.
Finally, on the dense quotient vectors,
Uπxη​​(a)[b]=U[ab]=abη=aU[b].
(19)
Both sides are bounded operators, so this identity extends to all of Hxη​​. Multiplication by the inverse unitary map gives
πxη​​(a)=U−1aU(a∈A).​
(20)
This is the GNS representation of a vector state, with the vector state, null ideal, cyclic vector and intertwining isometry all made explicit.
