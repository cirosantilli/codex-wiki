Row rank (dimrow(A))

 ... Algebra Linear algebra Vector space Linear map Matrix Matrix rank
OurBigBook.com Words: 116
The row rank of a matrix is the dimension of the vector space spanned by its rows. Elementary row operations preserve this row space; multiplication on the right by an invertible matrix preserves all linear relations among the rows.
To see why row rank equals column rank, write a reduced row echelon form as R=EA, where E is a product of elementary matrices and is an invertible matrix. Reversibility of the row operations gives equal row spaces for R and A. Also Rz=0 if and only if Az=0, so the columns have exactly the same linear relations. If R has r nonzero rows, its pivot columns are the first r standard basis vectors of Fm and span its column space. Its nonzero rows are linearly independent, since their matrix entries in the pivot positions form an identity matrix. Both dimensions therefore equal r, and both counts transfer back to A.
