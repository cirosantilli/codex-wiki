Branch point

 Home Mathematics Area of mathematics Analysis Complex analysis
OurBigBook.com Words: 622 Articles: 4
A branch point is a point around which a sufficiently small loop can change a germ of a holomorphic function under analytic continuation. This is a local condition: a large loop around a regular point might also enclose a distant branch point, so that large loop alone cannot classify the regular point. For the complex logarithm and square root, every nonzero point has a local holomorphic branch, but a loop once around 0 changes the chosen branch. [ref]
For z=reit with fixed r>0, start at t=0 with values r​ and logr. Their continuations are
w(t)=r​eit/2,L(t)=logr+it.
(145)
One counterclockwise turn gives w(2π)=−r​ and L(2π)=logr+2πi. At r=4, the square root therefore changes from 2 to −2, while the logarithm changes from log4 to log4+2πi. Two turns restore the square root to 2; no nonzero number of turns restores the logarithm. This distinguishes a two-sheeted algebraic branch point from a logarithmic singularity.
A pole need not be a branch point: 1/z is unbounded near 0, yet 1/(reit)=r−1e−it returns to its starting value after one turn. Conversely, the square-root values tend to 0 at their branch point. The issue is whether a single holomorphic choice survives going around the point, rather than whether the values become large. On the Riemann sphere, infinity is also a branch point of both z​ and logz: in the local coordinate ζ=1/z, these are ζ−1/2 and −logζ, whose continuations around ζ=0 change sign and subtract 2πi, respectively.
