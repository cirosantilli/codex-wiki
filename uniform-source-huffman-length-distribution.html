Uniform-source Huffman length distribution (s=⌈log2​m⌉)

 ... Mathematics Area of mathematics Probability and statistics Information theory Huffman coding Huffman code
OurBigBook.com Words: 45
For m≥2 equiprobable symbols, the maximum codeword length of a binary Huffman code is s=⌈log2​m⌉. Exactly 2s−m codewords have length s−1 and 2m−2s have length s. The balancing exchange for a uniform optimal prefix code restricts the depths to these two levels; counting leaves and using equality in the Kraft inequality determine the numbers.
