Least element (⊥)

 ... Area of mathematics Foundations of mathematics Set theory Set Partially ordered set Greatest element and least element
OurBigBook.com Words: 34
An element ⊥ of a partially ordered set P is a least element if ⊥≤x for every x∈P. A least element is unique: two such elements are below each other, so antisymmetry makes them equal.
