Middlebox

 Home Computer science Computer network Internet Internet architecture
OurBigBook.com Words: 192 Articles: 5
A middlebox performs a function on a communication path beyond ordinary Internet Protocol forwarding, such as address translation, traffic filtering or proxying. The function can be embedded in a device rather than implemented in a separate physical box. Its state and assumptions can affect failure recovery and protocol evolution.[ref]
