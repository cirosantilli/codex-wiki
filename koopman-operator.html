Koopman operator (KF​)

 ... Mathematics Area of mathematics Analysis Real analysis Measure theory Ergodic theory
OurBigBook.com Words: 320 Articles: 6
For a measurable dynamical map F, the Koopman operator acts on observables by KF​g=g∘F. If F is nonsingular, it defines an operator on equivalence classes of measurable functions.
