Integral action (z˙=e)

 Home Mathematics Area of mathematics Control theory Closed-loop control
OurBigBook.com Words: 387 Articles: 1
Integral action adds memory of the tracking error to a controller: z(t)=z(0)+∫0t​e(s)ds. A persistent tracking error keeps changing z, so an equilibrium point with constant z must have e=0. The accumulated value can remain nonzero after the tracking error has vanished, maintaining the control input needed to cancel a constant control disturbance. Convergence still requires a stable feedback control design. [ref]
