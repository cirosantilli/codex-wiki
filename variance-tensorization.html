Variance tensorization (Var(Z)≤∑i​E[Var(Z∣X−i​)])

Write X−i​ for all inputs except Xi​. Under the Efron–Stein inequality hypotheses, variance tensorization is the equivalent conditional variance form
Var(Z)≤i=1∑n​E[Var(Z∣X−i​)].​
(54)
Conditioning freezes the other inputs. Then Z,Zi′​ are independent with the same conditional probability distribution, giving
21​E[(Z−Zi′​)2∣X−i​]=Var(Z∣X−i​).
(55)
Taking expected values explains the factor 1/2.[ref]
For Bernoulli input Xi​ with parameter pi​, let Δi​f be the value of f with coordinate i set to one minus its value with that coordinate set to zero, keeping X−i​ fixed. The two-point conditional variance is
Var(Z∣X−i​)=pi​(1−pi​)(Δi​f)2.
(56)
For the maximum example, Δ1​f=1−X2​ and Δ2​f=1−X1​. The two averaged conditional variances are 0.3(0.7)(0.4)=0.084 and 0.6(0.4)(0.7)=0.168, precisely half the respective resampling terms. In the dependent example X1​=X2​=B, each other coordinate already determines W, so both conditional variances vanish; variance tensorization also fails without independence.
For a short induction proof, separate the last input using the law of total variance. Apply the smaller-dimensional statement to the conditional expectation; Jensen's inequality for the square bounds its coordinate contributions by the original ones. One input gives equality, starting the induction.[ref]
